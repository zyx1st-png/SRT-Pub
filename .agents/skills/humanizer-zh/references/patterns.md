# 中文编辑模式与保真示例

模式是审阅线索，不是作者身份鉴定，也不是必须改写的句型表。保真和用户语体优先；不要为消除模板而补新事实。

| 模式 | 编辑判断 |
|---|---|
| 象征意义、趋势和宣传拔高 | 保留原文已有事实与观点，删无信息的赞词；不补新闻、功能或数据 |
| 模糊归因 | 先查文内出处；缺来源就标缺口，不编机构或年份 |
| 同构段落、机械三段式、反复总结 | 在授权范围内调整；真实分类和必要重复保留 |
| 否定式排比、转折 | 两端都界定概念时保留，空铺垫才精简 |
| 连词、破折号、加粗、标题过密 | 按作用与密度调整；保留导航和引用格式 |
| 系动词回避、刻意同义替换 | 需要时改回“是/有”，专业术语保持一致 |
| 聊天套话进入文章 | 删服务式开场收尾；保留必要证据不确定性 |
| 虚假个性 | 保留原有声纹，不新增“我”的经历、情绪或立场 |

## 示例（合成文本）

原文：此外，这次更新新增离线模式，这一重大突破充分体现了我们对用户体验的不懈追求。

改后：这次更新新增离线模式。

原文：值得注意的是，在 20 次测试中有 3 次超时，原因可能与网络有关。

改后：20 次测试中有 3 次超时，原因可能与网络有关。

原文：专家认为这个方案能将成本降低一半。

处理：保留为待核实主张，在正文外指出缺少专家身份、来源和比较基线。不能改成“这个方案能降低一半成本”，也不能新增某机构的研究。

原文：One 不等于 Bearer；该差别仍须由当前定义源核对。

处理：保留。否定关系在这里承担概念边界，不是装饰性反转。
