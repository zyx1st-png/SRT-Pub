# 结构反模式（跨语言）

这些是编辑线索，不是禁用句法。先核含义与授权范围；不能为更具体而补事实。

| 信号 | 可做的修改 | 保留条件 |
|---|---|---|
| 否定转折制造假戏剧 | 删除不承重的铺垫，直接陈述观点 | 两端界定术语、风险、反例或真实区别 |
| 否定式列举 | 压缩重复宣告 | 每项排除都承担边界 |
| 戏剧化碎句 | 合成自然句 | 作者刻意节奏或文学表达 |
| 反问/Wh- 反复预告 | 直接给原有观点 | 真问题、条件句、教学结构 |
| 虚假主语 | 用已有证据中的主体和动作 | 系统行为、自然过程、技术主语 |
| 被动堆砌 | 归属有依据时改主动 | 学术语体、行为者未知或不相关 |
| 强凑三件套 | 删重复或空词 | 三项真实分类，不删实质项目 |
| 机械步骤 | 合并无依赖的重复说明 | 操作顺序和故障恢复流程 |
| 空总结/价值拔高 | 删无新增信息的收尾 | 推论、转场、作者立场 |
| 对称填充 | 减少重复修饰 | 不能把“两者都要”改成只优先其中一项 |
| 无源引用 | 标注出处缺口 | 原文另处已有可靠出处 |
| 过度加粗/标题/列表 | 减少无用装饰 | 导航、比较、步骤或输出格式需要 |
| 假口语/调试腔 | 改回当前语域 | 原有经历、术语和作者声音 |
| 句长均匀 | 在 scope 内调整节奏 | 列表、平行条件、必要重复 |
| 破折号过密 | 按关系改标点 | 引用、命名、插入语或用户格式要求 |

没有语料与来源时，不用句长标准差、词频倍数或项目数量鉴定 AI 写作。

## 保真示例（合成）

原文：研究表明，远程办公能提高 30% 的生产力。

处理：指出缺来源、样本与指标定义。保留数字作为待核原主张；不能换成另一所大学、年份或百分比。

原文：三年。两个人。一个想法。

可改：两个人，三年，一个想法。

说明：不能补“做成产品”，原文没有交代成果；若用户保留这种节奏，可以不改。

原文：系统在超时后返回 504。

处理：不改。系统是真实行为主体，不应改成“你返回 504”。

原文：速度和质量都要保证。

处理：保留其双重要求；不能为了删对称结构而改成“优先质量”。
