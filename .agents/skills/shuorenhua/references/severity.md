# 严重度分级

Tier 是人工编辑的启发式优先级，不是检测器、词频统计结论或改写授权。事实和语域优先于词表。

- **Tier 1**：上下文中明显无信息的套话、夸大或表演性姿态，优先处理。
- **Tier 2**：词语本身正常，但局部反复出现使语气机械，结合功能评估。
- **Tier 3**：常见词只在全文重复明显影响阅读时调整；专业术语的一致性优先。

不以固定倍数、密度或句长阈值判定作者身份，也不为减少重复而轮换术语。

以下情形优先保留：引用原文、被讨论的词、代码与配置、行业术语、系统主语、技术报告用语、学术被动、具体经历中的口语、中英混排里的字面技术动作。保护规则见 [protected-spans.md](protected-spans.md)。

先确认是否有真实表达问题，再按 SKILL.md 的力度和 scope 修改；Tier 越高也不能越过用户保句、保长度或只审阅的要求。
