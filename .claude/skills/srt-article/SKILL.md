# SRT 文章写作工作流（触发器）

本 skill 是 `Operations/_SRT_ARTICLE_WORKFLOW.md` 的**运行触发层**。被拉起时按下面的流程驱动；**精确的 paste-ready 提示词与完整规则以那份文档为准**——开工前先读它的 §2（命题锻造 prompt）/ §3（分层发散 prompt）/ §8（诊断 prompt），轨迹字段读 `Operations/_SRT_CHOICE_TRACE_LOG.md`。本文件只装"怎么起、按什么次序、哪些红线不能碰"，不复制全文以防漂移。

## 第一设计律（不可违反）

LLM 只做**发散**；**收敛**（锻命题、选结构、定论点、定攻击对象、成文）**只由作者做**。LLM 一旦替作者收敛，就是众数收敛 = AI 味 + 丢锋芒。这条丢了，本工作流退化成"AI 帮我写文章"。

## 入口判定（先做这个，再进流程）

看 ARGUMENTS 和用户首条消息，判定从哪一步进入；**判不出来就问，不猜**：

- **给了碎片或主张** → 逐字留存为 `seed_fragment`（不润色），进锻造（步 1–2）。
- **带着草稿/成稿来，或说"诊断"** → 直接跳步 7 诊断。
- **说"继续 / 接着选"**（跨会话回流）→ 先定位坍缩到哪一层：问作者，或查台账最新条目与本对话；已坍缩的层不重跑，从下一层继续。
- **说"记轨迹 / 补轨迹"** → 直接步 8；事后补记必须标 `late_entry: true`（台账对补记降权）。
- **参数是单个含混的词**（看不出是题目、模式词还是误触）→ 问清再动。
- **用户要的其实是 LLM 代写成品** → 本流程不做（第一设计律）；指向 srt-weixin / srt-zhihu / srt-public-content。

## 被触发时怎么走

1. 用户给的是**碎片** → 先陪他锻成主张；已是**主张** → 直接进锻造。
2. **命题锻造**（doc §2）：当压力测试器，只找会塌的地方，逐条逼作者拍板 → 收敛成一段"锻死命题"请作者确认。不夸奖、不安慰、不替他拍板。
3. **分层递归发散**（doc §3），**层序锁死、不可颠倒**：
   - 层1 思路结构 → 层2 理论内容 → 层3 写作手法（**最后**）。
   - 层2 每引一个 SRT 机件必须**核对 canonical**，拿不准标 `NEEDS_RETRIEVAL`，绝不编造路径/方程/claim level。
   - 每层给 3–4 个**离散互斥**选项（结构承诺，不是仓库摘抄），**给完即停**，等作者选，再用他的选择条件化下一层。不排序、不推荐。
   - **每层坍缩后当场暂存**该层选项全集 + 作者选择，别等收尾凭记忆重构（台账纪律：补记降权）。
4. **收敛成骨架**（doc §5）：作者定论点/攻击对象/闭包边界（对齐 TASTE 第一问与 doc §11 文章气质差量）；LLM 只给**非成文脚手架**，不给成品句子。作者要"看感觉"可给一份标注"校准稿"的可抛样稿（真稿作者亲手写）。
5. 途中冒出新东西 → 用 doc §6"折入 vs 另开"判，别把文章写散；被 park 的真东西记 `pruned`，事后讨还记 `reclaimed`。
6. **作者自己写。**
7. **诊断**（doc §8）：成稿后只报问题（claim 越级 / canonical 冲突 / 懂行读者的雷 / 母题塌缩 / 传播风险——对照 `SRT_TOPIC_ARTICLE_INDEX.md` 对应行 / AI 味），不改写、不给替换句。
8. **记轨迹**（doc §7 + 台账模板）：骨架闭合时就 append 条目，别拖到发布后。LLM 只填 `layered_options`（含被划掉的分支、canonical 核对状态）；`chosen / skipped_mode / reason / closure_boundary / attack_target` 留空请作者亲填，`reason` 当场要到最好（一句话，作者原话）。`article_ref / platform / reader_resistance` 成文、发布后回填。

## 硬红线

- **手法永远最后选**，别让"怎么讲"绑架"讲什么"。
- **一次只发一层**，绝不把多层选项打包塞给作者。
- 理论落笔前**核对 canonical**；大众文也**不越级**（P3 假设别写成定律）。
- 收敛动作字段（`chosen / skipped_mode / reason / closure_boundary / attack_target`）**只作者填**；`seed_fragment` 与 `reason` 必须**作者原话逐字**——润色即污染，整条轨迹作废。
