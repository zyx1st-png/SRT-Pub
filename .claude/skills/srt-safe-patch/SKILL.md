# SRT Local Patch

按根 AGENTS.md 核对目标文件、当前改动和授权范围，读取目标段落及其对应 owner/guardrail。远端名称不同不是自动阻塞条件；实际目标不明或与用户改动冲突时先定位。

## 执行契约

1. **定位**：确认目标文件存在、当前分支/工作包正确，并读取足够上下文。缺文件先按索引确认是否迁移；仍找不到时报告，不创建冒名替代文件。
2. **唯一锚点**：用能唯一定位的上下文锚点实施最小定向编辑；若已有同类护栏，更新或合并，不重复堆叠。
3. **语义边界**：只改授权段落。不得借局部补丁改变公式、定义、claim 硬度或 canonical 地位；companion/annex/bridge 不因补丁升格。
4. **保全**：不整文件重写，不删除或重排无关长段。局部去重仅限与本次补丁直接相关的重复文字。
5. **核验**：检查 diff、链接和适用元数据，确认变更只落在预期位置；只有实际落地的目标才能记为完成。
6. **失败处理**：某一目标受阻时说明具体原因，继续完成其余互不依赖且已授权的补丁；不要用更大范围重写绕过定位失败。

用户明确要求整篇重写或 canonical 定义变更时，退出本技能的局部补丁模式，按根 AGENTS.md 与 freeze/edit protocol 处理该任务。本技能的局部约定不外推成全仓禁令。
