# SRT Local Patch

按根 AGENTS.md 检查目标工作树、当前改动和授权范围，读取目标段落及其对应 owner/guardrail。远端名称不同不是自动阻塞条件；实际目标不明或与用户改动冲突时先定位。

- 使用唯一上下文锚点做最小定向编辑。已有相同护栏时更新或合并，避免重复；这允许替换局部重复文字，不允许扩成整文件改写。
- 来源支撑每一条护栏，不改变公式、定义或 claim 硬度，不提升 companion/annex/bridge 的定义地位。
- 缺少文件先按索引定位是否迁移；仍找不到时报告该目标，继续可独立完成的补丁，不创建冒名替代文件。
- 检查 diff、链接及适用元数据；确认仅改变授权段落，未删除或重排无关内容。
- 简述实际改动、验证和未完成目标即可，不强制五栏报告。

用户要求整篇重写或定义变更时，按根 AGENTS.md 和 freeze/edit protocol 处理那项任务，不把本技能的局部编辑约定推广成全仓禁令。
