# AGING01 Consensus Extension v0.1 — Goal-Conditioned Generative Maintenance

> **定位**：AGING01 的 P3/P4 共识扩展桥，不是新的 SRT ageing master theory，不主张差异化优先，不修改 P0/P1 canonical owner。  
> **任务**：把 Pio-Lopez / Jawanda / Levin 的 goal-directedness、morphostatic setpoint、policy memory 与 multiscale competency，和现有 AGING01 的 ontological friction / selective maintenance / bearer accounting / historical writeback / generative reselectability 接成一个更完整的生命维持框架。  
> **纪律**：共识吸入不等于来源背书 SRT；来源理论中的强主张继续保留为 P3/P4 外部假说与经验路线。

---

## 0. 为什么需要这一层

AGING01 v0.1 已经把 aging 问题从静态 marker / damage burden 推向：

```text
what maintenance path occurred?
who / what bore the consequence?
what was written back?
what remains accessible next time?
```

但它对一个更上游的问题处理较弱：

```text
what is the system trying to maintain?
```

Pio-Lopez, Jawanda & Levin (2026) 提供了一个可吸收但必须有界的答案：多细胞生命的 morphogenesis / regeneration 可以被组织为围绕大尺度 anatomical setpoint 的 homeostatic goal-directed process；单细胞局部 goal 与组织 / 器官层级 goal 不必等价。

这一点可作为 AGING01 的上游组织接口，而不要求 SRT 与该预印本在“aging 的唯一根因”上达成一致。

---

## 1. 共识链：Goal → Friction → Maintenance → Selection → Writeback → Future Maintenance

本桥采用如下**非 canonical、过程级**组织链：

```text
(1) goal / setpoint / desired macrostate
    ↓
(2) mismatch / disturbance becomes maintenance-relevant
    ↓
(3) continued realization imposes a payability / maintenance burden
    ↓
(4) repair / clearance / compensation / regeneration / replacement
    ↓
(5) in some bounded cases: selective-maintenance event candidate
    ↓
(6) consequence is borne / transferred / residualized / written back
    ↓
(7) future maintenance repertoire / switching accessibility changes
    ↓
(8) collective goal alignment may be preserved, weakened, or reorganized
```

The loop can recur:

```text
goal alignment
-> maintenance architecture
-> bearer-specific writeback
-> future policy repertoire
-> later goal alignment
```

This is an **organizing synthesis**, not a theorem.

---

## 2. Goal / setpoint is not `Psi_f`

The source helps answer an upstream question:

> A biological perturbation is maintenance-relevant relative to what?

A bounded answer is:

```text
current state X
vs
maintained / target macrostate X*
```

The target / setpoint specifies which deviations matter for the named maintenance process.

But preserve:

```text
goal / setpoint != Psi_f
mismatch magnitude != Psi_f
bioelectric voltage != Psi_f
ROS / inflammation / protein misfolding != Psi_f
```

`Psi_f` remains owned by `_SRT_PSI_F_CANONICAL.md`. In an aging implementation, a goal-conditioned mismatch may create or expose a payability burden, but the biological source variable does not become identical to canonical ontological friction.

---

## 3. AIGOAL01 guard — morphogenetic goal is not automatically agentive goal selection

The preprint uses “goal-directedness” in the biological / dynamical-systems sense. SRT must cross-read this through AIGOAL01:

```text
goal implementation / completion
!=
goal selection from a supplied set
!=
goal-space generation / revision
```

Therefore the following are prohibited:

```text
morphostatic setpoint -> conscious intention
morphogenesis -> full SRT Selection by definition
bioelectric pattern -> agentive goal selector
cellular collective -> subject / experiencer
anatomical goal maintenance -> proof of autonomous goal generation
```

The source is useful even if the relevant “goal” is entirely subpersonal and implemented by distributed control.

## 4. Two coupled aging axes

The combined framework separates two degradation modes that can coexist.

### 4.1 Maintenance-policy degradation

The large-scale target can remain relatively stable while the implementation repertoire becomes narrower, costlier or more locally compensatory:

```text
same broad tissue-integrity target
+
young system: regeneration / flexible repair
aged system: inflammation / fibrosis / senescence / constrained replacement
```

This is closest to AGING01's maintenance-history topology and generative-reselectability pressure.

### 4.2 Goal-alignment degradation

The system may also lose coordinated commitment to the larger-scale anatomical / physiological target itself:

```text
local component competence remains
BUT
cross-component alignment to the larger target weakens
```

This is the Pio-Lopez / Levin-side contribution.

### 4.3 Coupled loop

A plausible bridge-level loop is:

```text
alignment loss
-> more local / fragmented maintenance
-> costlier compensation and cross-bearer transfer
-> structural writeback
-> further alignment loss
```

This loop is a synthesis hypothesis. It requires domain-specific evidence before empirical use.

## 5. Multiscale bearer accounting

The preprint's multiscale-competency framing is highly compatible with SRT's consequence-bearing discipline.

A maintenance response must be indexed by scale / bearer:

```text
cell
-> clone
-> tissue
-> organ
-> organism
```

Do not ask only:

```text
is this mechanism good or bad?
```

Ask:

```text
for which bearer?
at what timescale?
who gains local stability?
who pays the compensatory cost?
where is burden transferred?
```

A generic allowed pattern is:

```text
local viability gain
AND
higher-scale generative cost
```

Potential biological examples include senescence, clonal expansion, fibrosis, chronic immune activation and cancer-like local autonomy, but each example remains contingent on its own evidence.

---

## 6. Policy memory as a carrier family, not a new SRT variable

Pio-Lopez et al. explicitly discuss memories not only of states but of **policies** — resilient ways of dealing with inputs.

This can be absorbed into AGING01 as a candidate causal-carrier family:

```text
past challenge
-> realized maintenance policy
-> durable change in response thresholds / network / niche / competence
-> altered future policy accessibility
```

Possible carriers include:

- bioelectric network configuration;
- cell-cell signaling topology;
- chromatin / transcriptional competence;
- immune memory;
- clonal composition;
- niche / ECM structure;
- learned / stabilized response thresholds.

But preserve:

```text
policy memory != L2 by definition
policy memory != generative reselectability
policy memory != history itself
```

The causal carrier must remain empirically specified.

---

## 7. Hallmarks are process nodes, not one-to-one SRT translations

The earlier AGING01 table gave each Hallmark of Aging a candidate process role. This consensus extension strengthens a more networked reading:

> one hallmark may act at several stages of the maintenance loop.

Example — cellular senescence can be simultaneously analyzed as:

```text
local damage-response / stabilization path
+ persistent bearer state
+ SASP-mediated cross-bearer consequence
+ coordination / niche modifier
+ later regenerative-path constraint
```

Likewise inflammation can be:

```text
acute payment / coordination response
AND, when persistent,
future friction source + alignment modifier
```

Therefore do not force:

```text
one hallmark -> one SRT box
```

The relevant question is how a process participates in a recurrent maintenance architecture.

## 8. Healthy stability — provisional consensus form

A useful non-canonical working expression is:

```text
healthy stability
≈ goal continuity + policy revisability
```

This does **not** define health.

It captures a bounded intuition consistent with `Core_21c B13`:

- continuity without revisability can become rigid stabilization;
- revisability without higher-scale alignment can become fragmented local adaptation;
- generative health requires present maintenance that does not systematically destroy future consequence-sensitive revision.

Do not scalarize this expression.

## 9. Rejuvenation ladder

This bridge proposes a four-part **evaluation ladder**, not a definition of rejuvenation:

### 9.1 State restoration

```text
marker / transcriptome / methylation / current function becomes younger-like
```

### 9.2 Goal / alignment restoration

```text
cellular collective again coordinates around a healthy large-scale target / setpoint
```

### 9.3 Policy restoration

```text
adaptive maintenance routes / regenerative policies become available again
```

### 9.4 Future generative restoration

```text
later standardized perturbations can be handled with broader, lower-cost,
less path-concentrated, more revisable maintenance
```

Hence:

```text
state restoration
!= necessarily goal restoration
!= necessarily policy restoration
!= necessarily future generative restoration
```

The ladder is designed to prevent marker-reset overclaim, not to require all four levels in every legitimate intervention study.

## 10. Positive comparative cases

### 10.1 Planaria / Hydra / regenerative systems

The source uses highly regenerative organisms as existence-oriented motivation for system-level maintenance and pattern renewal.

SRT-side use should ask:

```text
what is refreshed?
- current state?
- anatomical setpoint?
- coordination architecture?
- maintenance policy repertoire?
- future switching accessibility?
```

Do not infer that regeneration alone proves generative rejuvenation.

### 10.2 Bioelectric rescue

The source routes to experiments where bioelectric intervention can reorganize morphogenetic outcomes despite persistent upstream defects.

This is valuable as a **top-down control interface candidate**:

```text
hardware defect persists
+
regulatory / pattern intervention
-> large-scale phenotype can improve
```

But the primary experiments must be separately verified before using this as aging evidence.

## 11. Relation to Timmons–Brenner / AGING01

The three perspectives can be jointly retained without forcing exclusivity:

```text
Timmons–Brenner pressure:
what actually happened to cells / tissue during the perturbation?

Pio-Lopez / Levin pressure:
what large-scale state is the collective organized to maintain?

AGING01 pressure:
how did the realized maintenance path alter bearer consequences
and what remains possible next time?
```

This yields a compact consensus:

> **Goal specifies what the system is maintaining; friction concerns the burden of continuing to realize it; selection audits which maintenance path actually becomes real when non-equivalent alternatives matter; historical writeback records how that realization changes later maintenance and alignment.**

No sentence above establishes that every maintenance event is SRT Selection.

---

## 12. Empirical program — confirmation and synthesis, not only discrimination

Future work may pursue both shared and differentiating predictions.

### 12.1 Shared-program tests

Measure in the same system:

- large-scale alignment / setpoint readouts;
- damage / burden readouts;
- actual repair / elimination / replacement route;
- bearer-specific consequence distribution;
- later policy repertoire and repeated-challenge capacity.

The objective is to test whether these layers form a coherent maintenance loop.

### 12.2 Consensus-strengthening evidence

The consensus becomes more useful if studies show combinations such as:

```text
same current damage burden
+ different coordination state
-> different maintenance policy
```

or:

```text
same broad target / function
+ different maintenance history
-> different future adaptive repertoire
```

or:

```text
local stabilization
-> higher-scale coordination cost
```

These need not prove a uniquely SRT-specific mechanism to be scientifically valuable.

### 12.3 Distinguishing tests remain optional but available

If later theory advancement requires novelty adjudication, AGING01's existing same-information-budget competitor rules remain active. This consensus extension does not delete the subtractive audit; it changes the research priority from “difference first” to “shared structure first, divergence where consequential”.
