# AGING01 Integration Hook — Selective Maintenance and Aging

## 1. Current disposition

AGING01 is **not** authorized for owner-level integration.

Current state:

```text
P3 bridge exists
+ subtractive audit exists
+ P4 discriminator is specified in outline
- no executed D2-positive comparison
- no N1 result
- no canonical change
```

The hook exists to prevent the new ageing material from being either lost or prematurely promoted.

---

## 2. What may eventually land

Only a narrow native-SRT increment may land:

> In a named biological system, a prior maintenance path may count as historically efficacious when it prospectively changes later maintenance-path accessibility, switching cost or consequence-bearing distribution beyond bounded state / damage / resource / reliability / resilience / misrepair rivals.

Even if supported, this would remain a scoped P3/P4 result unless separately promoted through the claim ladder.

---

## 3. Activation conditions

All of the following are required before any target moves from `pending`:

1. **Concrete bearer and grain** are frozen before outcome inspection.
2. **Maintenance histories** are operationally distinct without relying on SRT labels.
3. **At least two future recovery routes** are independently measurable.
4. Current / pre-rechallenge measurements include bounded rival variables:
   - damage burden;
   - resource / maintenance budget;
   - reserve / redundancy / reliability;
   - ordinary resilience / recovery rate;
   - measured misrepair / persistent structural damage;
   - known clonal / niche / network state where applicable.
5. Rechallenge measures more than recovery speed:
   - path repertoire;
   - path probability;
   - switching / blockade cost;
   - consequence-bearing distribution;
   - later writeback.
6. The SRT-facing event chain separately passes CG-0..CG-4; no gate is inferred from another.
7. A bounded rival comparison is frozen before result inspection.
8. Failure is allowed to close the route at translation level.

---

## 4. Mandatory rival set

At minimum the P4 design must account for the explanatory roles represented by:

```text
Damage / oxidative / proteostasis accounts

Reliability / redundancy architecture
```

The aim is not to defeat entire theories. The aim is to prevent AGING01 from claiming an increment already supplied by a bounded rival on the same target.
