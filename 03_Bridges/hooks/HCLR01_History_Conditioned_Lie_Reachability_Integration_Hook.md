## 2. Insert condition

Do not land HCLR into an active owner merely because the mathematical analogy is elegant.

Activation requires all of the following:

1. a dedicated novelty audit against geometric control theory, nonholonomic control, adaptive control, path dependence, metaplasticity and ordinary hidden-state augmentation;
2. a pre-registered operational distinction between `HEF-3` probability/cost rewrite and `HEF-4` rule/composition rewrite;

4. a commutator / generated-accessibility measure with an independent future-reachability endpoint;
5. active vs master-yoked selection-specificity control;
6. a failure rule that demotes the result rather than adding unconstrained latent generators.

## 3. Suggested future native paragraph for the choice-generation owner

> Historical efficacy need not be restricted to changed response probabilities. A stronger, separately testable form occurs when prior selection changes how currently available operations compose, so that two systems matched on present state and immediate first-order responses differ in higher-order reachable directions. Geometric-control tools provide one candidate implementation of this distinction, but the SRT claim is not that historical write-back is intrinsically Lie-algebraic. The admissible inference is narrower: rule- or composition-level change counts as a stronger historical-effect candidate only when it predicts future accessibility beyond ordinary state, policy, memory-strength and cost variables under pre-registered controls.
