```text

-> maintenance-relevant mismatch
```

The value of this payload is organizational synthesis rather than a claim that SRT uniquely explains aging.

## 3. Required owner guards

Any future owner integration must preserve:

```text
morphogenetic goal != conscious intention
morphostatic setpoint != agentive goal selection
bioelectric pattern != canonical SRT operator
policy memory != L2 by definition
goal / mismatch / inflammation / ROS != Psi_f
generative reselectability remains owned by Core_21c B13
maintenance != Selection by definition
aging != goal loss / policy rigidity / reselectability decline by definition
```

AIGOAL01's completion / selection / goal-space-generation ladder is mandatory whenever “goal” language is used.

## 4. Owner-level integration candidates

### 4.1 AGING01 owner bridge

- replace one-role-per-hallmark reading with recurrent-network / multi-role reading;

### 4.2 Core_21c B13

```text

```

### 4.3 AIGOAL01

No AI claim is changed. AIGOAL01 is used only as a terminology guard:

```text

!= goal selection
!= goal-space generation / revision
```

Biological morphostatic regulation does not collapse that ladder.

## 5. Revival / landing trigger

Move from `pending` only if one of the following occurs:

1. AGING01 receives an owner-level consolidation pass;
2. a primary bioelectric / regenerative aging study directly measures large-scale goal-alignment together with future maintenance-policy flexibility;
3. a cross-domain generative-health synthesis explicitly needs goal continuity / policy revisability language;
4. new evidence requires changing the current guard that morphostatic regulation is weaker than agentive goal selection.

Until then, the consensus bridge itself is sufficient.

## 6. Stop rule

If later evidence shows that goal/setpoint language adds no organizational or empirical value beyond ordinary homeostasis / control theory, retain the SourceCard but downgrade this consensus extension to explanatory translation. Do not protect the vocabulary merely because it is compatible with SRT.
