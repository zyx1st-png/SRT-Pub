# 选择生成条件：跨域工作框架

> **角色说明**：本文件是 T-D 的 P2/P3 跨域框架，不是 SRT canonical、P0/P1 定义、公理、定理或经验结论。
>
> **核心任务**：说明在本审计框架内，一般变化至少在什么结构条件下，才可被提升为选择候选、进入选择性再组织，并进一步支持具有现实后果和历史效力的 bounded Selection-event candidate。
>
> **权限边界（RC-A active-use override）**：former P1-T05 “Real Choice Moment” 已由 RC-A 撤出 P1。本文件不恢复、不替代该 theorem，也不把 CG-0..CG-4 倒投为 Selection 的定义或必要条件。script / habit / gradient / `L_2` automation 本身不推出 `no Selection`。CG pass/fail 只约束本 P2/P3 audit surface，不证明 agency、subjecthood、consciousness、freedom、moral responsibility 或 generative health。

---

## 0. 为什么需要“选择生成条件”

SRT 文本中容易混在一起的至少有四个问题：

1. **审计候选怎样形成**：一般变化怎样获得进入本审计过程的资格；
2. **候选怎样展开**：差异如何经比较和再组织形成方向性路径；
3. **何时建立事件候选**：何时已经出现足以支持 bounded Selection-event candidate 的现实路径、后果与历史证据；
4. **候选是否健康**：该事件候选是否保留修复、退出、学习和未来可再选择性。

“选择生成条件”只直接回答第一项，并为第二、第三项提供审计入口。它不把第四项偷偷塞进 Selection 的基础定义。

本文件采用以下总原则：

> **选择生成条件，是使一般变化能够成为本审计的选择候选，并具备升级为 bounded Selection-event candidate 可能性的一组 P2/P3 结构条件。**

这些条件不是一个脱离尺度和领域的机械清单，也不是 P0 Selection ontology。不同层级可以用不同机制满足它们；本文件只固定跨域功能角色与禁止的偷换。

## 1. 五项工作条件

### CG-0 · 差异能够显现

至少有某种变化、差异或路径分岔能够进入系统的有效作用范围，而不是被边界、尺度、测量方式或既有结构完全抹平。

这里的“显现”不要求：

- 已经存在两个清楚命名的选项；
- 系统能够意识到差异；
- 观察者事先列出全部可能路径。

可能性空间可以是连续的、未枚举的，甚至只在过程展开后才显出差异。CG-0 只要求：至少某些差异对后续动力学不再完全不可见。

**失败情形**：表面上存在多个标签，但所有标签指向同一结果；或系统对相关差异没有任何可进入通道。

### CG-1 · 差异能够被非等价登记

系统对至少两种可能变化不能保持完全等价响应。差异由此获得不同权重、优先级、阻力、吸引力或维持条件，并进入比较关系。

这对应作者裁决中的**最低非中立性**：

> 它是比较得以形成的最低结构门槛，不是偏好、价值判断、意图或选择完成的同义词。

CG-1 不要求一个预先存在的中立尺度。比较尺度可以由边界、资源、历史约束、风险、未来后果或具身关切在过程中共同生成。

**失败情形**：系统只是受到变化推动，但没有任何非等价登记；差异只存在于外部观察者的描述中。

### CG-2 · 非等价差异能够形成路径效力

非等价登记必须进一步改变路径组织，而不只停留在测量、分类或表面输出上。至少出现以下一种现实效力：

- 某一路径被优先稳定、维持或重复；
- 其他路径被排除、压低、延迟或提高返回成本；
- 系统的资源、结构或行动被定向配置；
- 未定形差异被组织成可持续的方向性过程。

CG-2 是从“比较候选”进入“选择性再组织”的关键审计条件。

**边界（RC-A）**：脚本执行、固定反射、梯度跟随和单一路径自动运行可以表现出方向性。若当前冻结事件中没有足够的差异进入和路径重组证据，只能说 **CG-2 / SEA event candidate 未建立**；不能由此反推 `no Selection`。

### CG-3 · 代价或后果能够落到承受位置

路径差异必须产生不能被完全抹去的代价、收益、损失、约束或风险，并落到某个可识别的**后果承受位置**。

承受位置可以是：

- 物理结构的稳定性或资源状态；
- 生命系统的维持条件；
- 主体的具身风险、行动能力或身份连续性；
- 群体、制度或生态系统中被后果实际压到的位置。

必须区分：

- **有后果**不等于有主体；
- **有承受位置**不等于已经证明意识或第一人称经验；
- 后果若被全部外包给另一系统，仍可能支持 bounded Selection-event candidate，但其责任归属与生成健康评价必须重新定位。

**失败情形**：决策界面由一方操作，真实后果却只落到未被纳入模型的另一方；或者所谓代价只是观察者事后赋予的叙述。

### CG-4 · 结果能够获得维持或历史效力

在本事件审计中，若要达到 CG-4，路径形成后结果至少在相关时间尺度上产生持续作用，例如：

- 改变后续可达路径；
- 改变返回成本或转换概率；
- 沉积为记忆、结构、习惯、规则或边界；
- 通过维持、写回或后果回流改变下一轮候选条件。

CG-4 不要求永久不可逆，也不要求每次 Selection 都进入长期记忆。更重要的是，**CG-4 不是 Selection occurrence 的必要定义**：EX-A 保持 `manifest occurrence != anchoring persistence != Stable ISP`。本门只规定本 P2/P3 audit 要把何种历史效力计入 SEA-3 候选。

**与 former P1-T05 的关系**：历史上 CG 框架曾被写成 former P1-T05 的 positive operational supplement。RC-A 已关闭这一关系：CG-0..CG-4 不再承担复现 former P1-T05、区分 real/script Selection 或定义 Selection ontology 的任务。

## 2. 条件不是一条僵硬流水线

五项条件可以近似排列为：

> 差异显现  
> → 非等价登记  
> → 路径效力  
> → 后果承载  
> → 维持、写回或未来约束

但它们在具体系统中可能相互回路化：

- 历史写回会改变下一轮哪些差异可显现；
- 承受位置会改变非等价登记的权重；
- 路径维持会重塑系统边界；
- 后果回流会生成新的比较尺度。

因此本文件提供的是**功能条件矩阵**，不是普遍时间顺序定律，也不是每次 Selection 必经的 ontological chain。

## 3. 三个门槛层级

### 3.1 候选形成门槛

CG-0 与 CG-1 足够强时，一般变化可以成为本审计的选择候选：

- 差异已进入有效作用范围；
- 系统开始对差异作非等价登记。

这还不是 bounded Selection-event candidate。

### 3.2 过程展开门槛

CG-2 出现时，候选进入比较性选择再组织：

- 差异开始改变路径组织；
- 某些路径获得现实方向性。

这对应 T-B 的过程层。

### 3.3 事件候选门槛

当 CG-3 与 CG-4 也达到相关尺度上的有效强度时，才有理由把过程判断为 bounded Selection-event candidate：

- 代价或后果具有承受位置；
- 结果获得维持、写回或未来约束效力。

“相关尺度上的有效强度”仍需领域操作化。本文件不声称已经给出跨所有系统统一的必要充分条件或数值阈值。

## 4. 与选择事件判据的分工

“选择生成条件”问的是：

> 在本 P2/P3 audit 中，该系统是否具备让一般变化进入候选过程并形成现实效力的结构条件？

“选择事件判据”问的是：

> 在这一具体冻结事件中，证据是否足以跨过 CG/SEA 的 bounded candidate 门槛？

二者不能互换：

- 有生成条件，不代表每一刻都建立 event candidate；
- 观察到一次路径变化，也不能自动证明完整生成条件已经被识别；
- 生成条件可以长期存在而暂时休眠；
- event candidate 可以建立但未必生成健康；
- audit failure 不能反推 `no Selection`。

---

## 5. 与“选择脚手架”的分工

选择脚手架是实践层对选择过程的具体支撑和组织，包括：

- 可进入且有现实差异的选项或路径；
- 信息、时间、能力与资源支持；
- 反馈、试错与学习通道；
- 退出、修复和重新开放机制；
- 在适当场景中的可逆窗口与代价缓冲。

它与选择生成条件的关系是：

> **生成条件说明本审计如何建立候选；脚手架说明主体／组织实践中的选择如何更可进入、更可承担、更少被操控，并更可能保持生成健康。**

重要边界：

- 丰富脚手架不是一切 Selection occurrence 的必要条件；
- 一次性、不可逆或资源贫乏情境不能仅因此被排除出 Selection；
- 有菜单、有按钮或有投票界面，不代表 bounded Selection-event candidate 已建立；
- 可逆性通常有助于学习与健康，但不能被写成 Selection occurrence 的普遍必要条件；
- 支撑不足可能使实践层 event candidate 具有惩罚性，却不自动否定其 bounded candidate 地位。

---

## 6. 与生成健康评价的分工

生成健康评价在事件审计之后进一步检查：

- 是否保留或扩展未来可再选择性；
- 是否允许修复、学习、退出或重新开放；
- 是否把维持成本无限外包给其他承受者；
- 是否维持跨时间和跨主体的协调条件。

这些是重要评价维度，但不是 Selection 的基础定义，也不是 CG-0 至 CG-4 对 P0 的反向定义。

因此：

- 一个实践层 bounded event candidate 可以对应错误行动；
- 可以是压迫性的；
- 可以导致自我封闭；
- 生成健康不等于选项数量最大化；
- continued selectability 属 P1-T06 Stable ISP 条件；
- generative reselectability 属 P2/P3 generative-health territory；
- 二者都不能被上提为一次 Selection occurrence 的必要条件。

## 7. 主体与制度层的四类实践判读

以下四类只适用于主体、组织和制度实践层的 **audit / normative shorthand**，不是从物理到意识的普遍本体等级，也不得反向定义 Selection。

### 7.1 未建立事件候选

典型情形：

- 冻结事件内没有足够的路径差异证据；
- 当前输出可能是脚本、强制执行或唯一通道；
- 行为者没有显示改变结果的现实路径效力。

这里的结论只是：**本审计没有建立 bounded Selection-event candidate**。它不等于 `no Selection`；尤其 script / habit / gradient / automation 不能作为本体排除条件。

### 7.2 伪选择

表面提供选项，但本实践审计的关键条件被架空，例如：

- 所有选项通向预先固定的同一结果；
- 差异只存在于标签和界面；
- 选择无法改变资源、路径或后续约束；
- 后果承担者与表面决策者被系统性切断；
- 隐藏结构在选择发生前已经锁死结果。

“伪选择”在此只是一种主体／制度实践评价，核心是表面比较没有获得现实路径效力；它不是 P0 Selection subtype。

### 7.3 惩罚性选择

在本实践审计中 bounded event candidate 已建立，但脚手架和代价结构严重失衡，例如：

- 每个可行选项都附带过高或不成比例的伤害；
- 退出、试错和修复成本被人为抬高；
- 信息和资源被系统性剥夺；
- 后果高度集中于弱势承受者。

不能因其不健康而撤销已经建立的 audit evidence；同时也不能由 candidate 地位推出 freedom 或 moral responsibility。

### 7.4 尊重选择

在实践层 event candidate 已建立，同时脚手架尽量保障：

- 路径差异真实而可理解；
- 反馈、能力和时间支持足够；
- 代价不被恶意放大或隐瞒；
- 退出、修复和重新开放在可行范围内存在；
- 后果承担与决策权尽量不被系统性分离。

“尊重选择”是规范和制度评价，不是自然系统的普遍属性，也不承担 Selection ontology。

## 9. 与 T-B 和 MSD 的接口

### 9.1 与 T-B 的分工

T-B 主要描述：

> 扰动怎样经过显现、比较与选择性再组织形成方向性路径。

T-D 主要描述：

> 在本 audit surface 中，哪些结构条件使这条过程链有资格从一般变化进入候选、过程和 bounded event-candidate 层。

因此：

- T-B 是过程桥；
- T-D 是条件矩阵；
- 两者都不替代当前 P0/P1 owner，也不恢复 former P1-T05。

### 9.2 与 MSD 的分工

`SRT_Selection_Dynamics_MSD_Bridge.md` 串联排除、定形、写入、锚定与回流，并回链既有 canonical 机器。

T-D 不新造一套算子或符号，只为 MSD 各环节补一张前置审计表：

- 差异是否真正进入；
- 非等价响应是否形成；
- 路径是否获得现实效力；
- 代价与后果落在哪里；
- 结果是否改变后续路径。

## 10. 最小审计问题

面对任何“这里发生了选择”的主张，至少追问：

1. **什么差异真实显现了？**
2. **系统在哪个方面不再等价响应？**
3. **哪条路径因此被稳定、排除或提高了返回成本？**
4. **代价、收益、风险或损失落到什么承受位置？**
5. **这一结果怎样改变了后续可达路径或结构？**
6. **当前说的是候选形成、过程展开、event candidate，还是健康评价？**

若只能回答“观察者看见了不同结果”，通常不足以建立本文件的 bounded Selection-event candidate；这仍不等于 `no Selection`。

## 11. 压力测试与降级条件

出现以下情况时，本框架必须降级、拆分或撤回相关强表述：

1. **普通因果转移即可完整解释**：CG 条件没有提供超出一般状态转移、约束或路径依赖的可区分增益。
2. **观察者事后贴标签**：非等价响应、路径效力和承受位置只存在于外部描述中。
3. **历史效力无限稀释**：任何瞬时状态改变都被算作写回，使 CG-4 失去区分力。
4. **承受位置不可识别**：后果归属无法说明，或被隐藏外包却仍声称系统自身承担。
5. **主体性向下投射**：从非等价响应直接推出关切、意图、体验、自由或道德责任。
6. **脚手架与生成条件混写**：把选项丰富、可逆性、退出和资源支持当作一切 Selection occurrence 的普遍必要条件。
7. **健康与事件混写**：因为结果压迫、自我封闭或不可逆，就撤销已建立的 audit evidence，或反过来把 audit evidence 升级为健康／自由证明。
8. **显式二选一偏见**：把两个命名选项当作所有选择的必需形式，排除了连续、涌现和未枚举路径。
9. **跨域机制同一化**：用一套具体物理、生命或认知机制冒充全部层级的统一实现。
10. **RC-A 反向越界**：由 script / habit / gradient / automation 或 CG failure 推出 `no Selection`。

## 12. 本文件不主张什么

本文件不主张：

- 已给出 Selection 的跨域必要充分条件；
- 已发现最低非中立性的统一数值阈值；
- 一切因果变化、适应、优化或学习都是 Selection；
- script / habit / gradient / automation 意味着没有 Selection；
- 有后果承载就必然有主体或意识；
- 多选项、可逆性或退出机制是一切 Selection occurrence 的必要条件；
- 所有 bounded Selection-event candidates 都具有生成健康；
- AI 的分支、记忆或自我更新足以证明 stake、主体性或意识；
- CG / SEA pass 可以证明 agency、subjecthood、consciousness、freedom 或 moral responsibility；
- 本文件可以替代 canonical、当前 P0/P1 owner、领域机制模型或经验验证。

---

## 13. 当前结论

T-D 的首轮工作结论是：

> **在本 P2/P3 审计框架内，一般变化若要被提升为 bounded Selection-event candidate，需要差异显现、非等价登记、现实路径效力、后果承载与历史效力在同一冻结事件链中达到相应门槛。这个结论只规定 CG/SEA 的审计许可，不定义 Selection，也不把历史效力、continued selectability 或 generative reselectability 上提为 Selection 的必要条件。**

这一结论仍是 P2/P3 工作框架。后续必须分别接受物理、生命、主体、社会与 AI 层的支持例、反例和操作化压力测试。
