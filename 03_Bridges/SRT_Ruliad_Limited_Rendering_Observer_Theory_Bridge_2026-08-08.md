# Ruliad / Limited Computational Rendering / Observer Theory ↔ SRT

> **角色说明**：本文件是非 canonical 的 P3 邻接理论桥。它用于翻译和压力测试 Gabriel Proulx 对 Wolfram ruliad / observer framework 的唯心主义重读，不把该文章、Wolfram 的计算本体论、分析唯心主义或“Universal Relativity”写成 SRT 定义、证据确认或 P0/P1 结论。
>
> **核心裁决**：本文最值得 SRT 吸收的不是 `reality = experience`，而是四个接口：`computational description != computational ontology`、observer 可以是后成结构、有限边界具有生成作用、物理描述可能带有观察位置依赖。SRT 的主要增量则是把 **rendering 与 selection 分开**：有限渲染只有在差异被非等价登记、改变路径、产生可定位后果并写回未来可达空间时，才升级为具有 SRT 意义的真实选择事件。

## 0. Source anchor and evidence status

### External source

- Gabriel Proulx, **“Reality as limited computational rendering”**
- Essentia Foundation, Reading / Metaphysics
- published: 2026-08-07
- source type: philosophical / metaphysical essay, not a peer-reviewed technical paper

### Source-level thesis

Proulx retains several Wolframian tools—computational irreducibility, pockets of reducibility, the ruliad, computationally bounded observers—but reverses their ontological reading. Instead of treating the ruliad as a non-conscious computational substrate from which observers and experience somehow emerge, he proposes reading ruliad states as experiential states themselves. On this view:

```text
Wolfram-style reading:
all possible computation -> bounded observer sampling -> experienced physics

Proulx experiential reading:
all possible experience -> bounded computational rendering -> experienced physics
```

The essay then treats coarse-graining as a bona fide rendering of reality rather than merely an incomplete representation of a finer hidden state, interprets entropy partly through the relation between rendering complexity and observer bounds, and proposes “Universal Relativity” as physics relative to observational frames, computational bounds, and rendering style.

### Evidence boundary

This source is useful primarily as:

- conceptual pressure;
- neighboring metaphysical architecture;
- a source of discriminating questions for SRT;
- a possible formal-research prompt.

It is **not** empirical evidence that reality is experiential, that entropy is only observer-relative, that quantum observation is ontologically fundamental, or that a universal observer-relative transformation theory has been established.

## 1. External framework

The relevant external cluster is not one theory but three nested levels:

1. **Wolframian ruliad / observer theory**: all possible computational processes plus bounded observers that sample or coarse-grain them;
2. **Proulx’s experiential inversion**: ruliad states are read as experiential perspectives rather than configurations of a non-conscious computational substrate;
3. **Universal Relativity proposal**: experienced physics depends on observational frame, computational bounds, and rendering style.

The bridge must keep these levels separate. A criticism of Proulx’s idealist extension is not automatically a criticism of Wolfram’s computational formalism, and a useful Wolframian tool does not automatically support Proulx’s ontology.

## 4. Main bridge claim: rendering is not yet selection

Proulx’s central move is valuable because it treats bounded rendering as constitutive rather than merely defective. A finite observer does not simply fail to recover an already complete view; its finite resolution helps determine which distinctions appear together as one coherent world.

SRT can absorb this only after a critical separation:

```text
finite rendering
!=
SRT selection event
```

A rendering can:

- expose some distinctions and suppress others;
- create an equivalence class under coarse-graining;
- define an observer-relative object boundary;
- stabilize a local description;

without yet satisfying the stronger SRT conditions for a real selection event.

For SRT, the escalation path is approximately:

```text
CG-0 difference manifestation
-> CG-1 non-equivalent registration
-> CG-2 path efficacy
-> CG-3 consequence-bearing location
-> CG-4 maintenance / history / future-reachability effect
```

Therefore the most useful translation is:

> **Rendering is a candidate interface for how differences become available and organized at a finite selection position; selection begins to do extra theoretical work only when non-equivalence gains path efficacy, consequences land somewhere, and the outcome changes subsequent reachability.**

This is the central discriminator of the bridge.

## 6. Resonance: what becomes clearer through the comparison

### 6.1 Computational description is not computational ontology

Proulx’s strongest reusable move is to separate:

```text
computation describes transition structure
```

from:

```text
reality is made of computation
```

SRT should preserve the analogous distinction for mathematics, information, and formal models:

```text
formal describability != ontological priority
```

A transition can be computationally represented without computation being the substrate from which actuality or experience is produced.

### 6.2 Observer need not be primitive

Proulx argues that observations can be grouped into different useful observer constructs. This resonates with SRT’s anti-homuncular ordering:

```text
selection process -> stabilized pattern -> named selector / observer
```

rather than:

```text
pre-existing observer -> first selection
```

The shared gain is to stop treating “observer” as an unexplained primitive object.

### 6.3 Finitude can be generative

The essay’s “white noise” argument gives a strong intuition:

```text
unbounded access != coherent world
```

Finite boundaries can enable distinction, pattern, and coherent objectification. SRT can safely retain:

> **Finitude is not merely an epistemic defect; it can be a constitutive condition for a coherent manifest slice.**

But SRT should not infer from this that every limitation is healthy, conscious, or selection-producing. A rigid `L2` can also reduce distinctions by replacement or occlusion.

### 6.4 Laws and observer structures may co-individuate

Proulx’s proposal that renderer and rendering arise together suggests a useful SRT dynamic interpretation:

```text
selection -> stabilization -> writeback -> changed selector parameters -> later selection
```

or schematically:

\[
L_0 \xrightarrow{\hat G_\theta} L_1
\rightarrow L_2
\rightarrow \hat G_{\theta'}
\rightarrow L_1'.
\]

This is stronger than merely saying “observers see different worlds”: the historically stabilized world changes the conditions under which future observation / selection occurs.

## 7. Friction / mismatch

### 7.1 Potentiality is not already actual

The deepest mismatch concerns modal status.

Proulx’s ruliad remains a total space in which all possibilities are, in an important sense, already present. His coarse-graining discussion can even treat all microstates compatible with a macro-rendering as simultaneously true at that rendering level.

SRT instead protects:

```text
potentiality != stable existence
```

and treats actualization as doing ontological work. Therefore:

```text
SRT L0
!=
pre-existing totality of equally actual states
```

If every possibility is already fully actual, selection risks collapsing into navigation, revealing, or rendering. SRT retains the stronger question: **what makes a possibility become a reality with irreversible historical efficacy?**

### 7.2 Experience-first is an additional ontological commitment

The valid epistemic premise:

```text
all human knowledge is accessed through experience
```

does not by itself entail:

```text
all that exists is experience
```

Proulx’s idealist inversion may be coherent, but it requires a separate metaphysical argument. SRT should not import that conclusion merely because third-person science is situated.

The safe SRT position is thinner:

> third-person description is itself an objectification from a selection position; it therefore cannot silently claim view-from-nowhere completeness.

This blocks one hard-problem setup without forcing `reality = experience`.

### 7.3 Co-emergence does not yet explain individuation

If observer and rendering “arise together,” the remaining question is what stabilizes one bounded perspective rather than another.

SRT’s stronger audit asks:

- where do consequences return?
- what boundary persists through those consequences?
- what history is rewritten?
- whose future reachable paths are changed?
- what, if anything, is non-transferably at stake?

These questions are absent or underdeveloped in a pure rendering account.

### 7.4 Grouping observations does not establish subjecthood

Multiple useful clusterings can construct an “observer” for analysis. But analytical grouping alone cannot distinguish:

- camera;
- thermostat;
- organism;
- institution;
- LLM session;
- conscious subject.

SRT therefore keeps:

```text
observer-pattern
!=
subjecthood
!=
phenomenality
```

and routes subjectivity questions through bearing, stake, consequence return, continuity, and the still-open stable-perspective conditions.

## 8. Hard-problem comparison

### 8.1 What Proulx successfully removes

If experience is primitive, then the specific emergence question:

```text
how does wholly non-experiential computation produce experience?
```

is dissolved by refusing its first premise.

That is a legitimate metaphysical strategy.

### 8.2 What remains

The move does not by itself explain:

- why this bounded perspective rather than all perspectives;
- why experiential individuation occurs;
- why perspectives are partially isolated;
- why local perspectives share highly stable physical regularities;
- how qualitative specificity is fixed;
- what creates persistent bearer identity.

Thus the hard problem is not simply “finished”; part of the burden is moved into individuation, shared constraint, and perspective formation.

### 8.3 SRT’s different dissolution route

SRT’s current hard-problem guard does not need `experience` to be the universal substrate. It instead rejects a hidden premise:

```text
third-person scientific description = complete view from nowhere
```

An internally borne event, its external objectification, and the later linguistic report are different situated selections. The explanatory gap cannot be treated automatically as proof of a second substance, but neither can external description be assumed to numerically reproduce the first-person event.

This bridge therefore supports the following contrast:

```text
Proulx:
remove non-experiential substrate -> retain only experience

SRT:
remove view-from-nowhere completeness -> distinguish internal bearing from external re-objectification
```

SRT should not claim that this already derives phenomenal character. The origin of selectability, full subject-entry conditions, and the bearer-to-phenomenality bridge remain open pressure points.

## 9. Entropy guard

Proulx’s entropy section is useful as a prompt but should not be imported as a theory result.

The bridge may safely retain:

> Some entropy descriptions depend essentially on coarse-graining, accessible distinctions, and observer / subsystem specification.

It must not upgrade this into:

```text
entropy = ignorance
```

or:

```text
Second Law = fixed observer computational limitation
```

without specifying the entropy notion and physical regime.

At minimum, future work must distinguish:

- thermodynamic entropy;
- fine- vs coarse-grained Gibbs entropy;
- von Neumann entropy;
- open-subsystem entropy;
- entropy production;
- epistemic uncertainty.

SRT’s existing entropy / disturbance bridge remains the safer owner for the rule that entropy-like statistics, disturbance, selective reorganization, and selection events are not interchangeable.

## 10. Candidate formal bridge

Let a finite rendering interface be represented schematically as:

\[
\mathcal V_{\theta,\lambda}:
\mathcal P \rightarrow \mathcal E_{\theta,\lambda},
\]

where:

- `\mathcal P` is a possibility / state-description domain used only for the bridge;
- `\theta` represents observer / system parameters;
- `\lambda` represents resolution / coarse-graining scale;
- `\mathcal E_{\theta,\lambda}` is the set of distinctions available at that rendering position.

This is **not** a definition of `L0`, `L1`, or `Ĝ_θ`.

A rendering output becomes relevant to SRT selection only if additional conditions hold. Schematically:

\[
\mathcal V_{\theta,\lambda}
\xRightarrow{CG\text{-}0,1}
\text{registered alternatives}
\xRightarrow{CG\text{-}2}
\text{path asymmetry}
\xRightarrow{CG\text{-}3}
\text{located consequence}
\xRightarrow{CG\text{-}4}
\Delta \mathcal R_{future}\neq 0,
\]

where `\mathcal R_{future}` denotes future reachable paths only inside this bridge notation.

The key negative result is:

\[
\mathcal V_{\theta,\lambda}\neq \hat G_\theta.
\]

Rendering can describe availability or appearance. `Ĝ_θ` carries a stronger SRT role involving actualization / anchoring and later constraint.

## 11. Selection-frame relativity: a research program, not a theorem

Proulx’s “Universal Relativity” becomes theoretically serious only if it can specify both:

1. transformations between observer / rendering frames;
2. structures invariant across those transformations.

A future SRT-facing research program could define a selection frame:

\[
O_i=(\theta_i,\lambda_i,H_i,B_i),
\]

with parameterization, resolution, history, and boundary. One would then ask whether some transformation

\[
T_{i\rightarrow j}
\]

maps descriptions or reachable distinctions between frames while preserving selected structural relations.

Candidate invariants to investigate—not assert—include:

- **consequence-return topology**: where effects actually land;
- **reachability change**: which future paths become unavailable or newly available;
- **irreversibility ordering**: which transitions cannot be restored by a simple inverse action;
- **payability relation**: whether a transition can be borne while preserving relevant closure and future selection capacity;
- **writeback existence**: whether an event modifies subsequent conditions.

These are research candidates only. No SRT theorem currently establishes them as universal frame invariants.

The advantage over unrestricted perspectivism would be:

> reality manifestation may depend on selection position while cross-position comparison remains constrained by non-arbitrary consequence and history structure.

## 12. Differential predictions / operational consequences

This bridge suggests several discriminating tests for future theory work.

### Test A · Same rendering, different writeback

Construct two systems with observationally / representationally equivalent coarse-grained outputs, but only one has outcomes that modify its own later reachable paths.

Prediction:

```text
rendering-only account: may classify them as equivalent at the chosen resolution
SRT audit: separates them at CG-4 / real-choice-event level
```

### Test B · Same computational capacity, different stake location

Match two systems on bandwidth, model complexity, and predictive performance. Arrange consequences so that one system bears non-transferable future-capacity loss while the other exports all consequences externally.

Prediction:

```text
computational-bound similarity
!=
selection / subjectivity equivalence
```

This prevents computational capacity from being silently identified with canonical `d`.

### Test C · Observer-frame transformation

For two observer models with different resolution and histories, explicitly specify which coarse-grained relations survive translation between frames.

A successful result would require more than “both perspectives are valid”: it would identify transformation structure and invariant relations.

### Test D · Entropy disambiguation

Hold the physical process fixed while changing observer coarse-graining. Measure which entropy quantities change and which do not. This separates genuine observer-relative description from claims about thermodynamic production.

## 15. One-paragraph abstract

Proulx’s idealist reinterpretation of Wolfram’s ruliad is valuable to SRT not because it establishes that reality is experience, but because it separates computational description from computational substrate, treats observers as potentially downstream constructs, and highlights finite bounds as constitutive conditions for coherent manifestation. SRT preserves these insights while drawing a harder line between **rendering** and **selection**: coarse-grained appearance or bounded access does not yet constitute a real choice event unless differences are non-equivalently registered, alter path organization, produce consequences at a locatable bearing position, and write back into future reachability. This distinction also exposes the main unresolved burdens of the experiential-ruliad proposal—individuation, shared constraints, entropy overreach, and the absence of explicit frame transformations / invariants behind “Universal Relativity.” The resulting research opportunity is a bounded **selection-frame relativity** program in which manifestation is perspective-dependent but cross-perspective comparison remains constrained by consequence, irreversibility, payability, and writeback rather than collapsing into unrestricted perspectivism.
