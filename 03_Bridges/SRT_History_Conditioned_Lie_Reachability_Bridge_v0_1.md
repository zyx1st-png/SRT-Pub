# HCLR01 — History-Conditioned Lie Reachability Bridge v0.1

> **Status / boundary**: P3 mathematical-method bridge with a P4 experimental seed. This file does not redefine selection, `L_2`, `T_dir`, `d-value`, `Psi_f`, memory, agency, subjecthood or consciousness. It does not modify or reinterpret the frozen results of *Identifying History-Dependent Reachability*. Its strongest new claim is a test proposal: selection-specific history may, in some designed systems, alter the composition structure of future-generating transformations even when present state and first-order responses are matched.

## 1. Source anchor and why this is not a symmetry patch

The immediate trigger is Leila Sloman's 2025 Quanta explainer *What Are Lie Groups?*, which emphasizes the productive relation between a smooth global transformation group and its local tangent / Lie-algebra description.

The mathematical step used here goes beyond the Quanta article. Standard geometric control theory shows that primitive vector fields plus iterated Lie brackets can determine local accessibility / controllability under stated regularity conditions. The primary background anchor is:

- H. J. Sussmann & V. Jurdjevic (1972), *Controllability of nonlinear systems*, **Journal of Differential Equations** 12(1):95-116. DOI `10.1016/0022-0396(72)90007-1`.

The relevant lesson for SRT is therefore not:

```text
symmetry proves selection
```

but:

```text
future structure can sometimes be characterized by the generators of allowed change
and by what new directions appear only through their ordered composition.
```

That is a method seed, not ontological evidence.

## 2. Three layers that must remain separate

### 2.1 State layer

A current system state is written as:

\[
x_t \in M.
\]

This tells us where the system is in a declared state space.

### 2.2 Primitive-direction layer

Suppose the system currently admits local update / control directions:

\[
X_1,\ldots,X_k.
\]

Their pointwise span is:

\[
\mathcal D(x)=\operatorname{span}\{X_1(x),\ldots,X_k(x)\}.
\]

This gives immediate first-order directions. It does **not** automatically give all directions reachable by ordered compositions.

### 2.3 Generated-accessibility layer

The iterated Lie closure is schematically:

\[
\operatorname{Lie}\{X_1,\ldots,X_k\}
=
\operatorname{span}\{X_i,[X_i,X_j],[X_i,[X_j,X_k]],\ldots\}.
\]

Under the hypotheses of the relevant control theorem, bracket generation can open local directions not present in the primitive span.

SRT-safe interpretation:

```text
current state
!= immediate direction set
!= composition-generated accessibility
```

No one of these layers should be promoted into a canonical SRT primitive.

## 3. Lie bracket as an order-sensitive history template

For small flows generated by `X` and `Y`, a commutator loop of the form

\[
e^{\epsilon X}e^{\epsilon Y}e^{-\epsilon X}e^{-\epsilon Y}
\]

has a leading nontrivial displacement proportional, up to convention/sign and higher-order terms, to:

\[
\epsilon^2[X,Y].
\]

The disciplined conceptual use is:

> the list of primitive operations may be insufficient; their order-sensitive composition can generate a direction that no primitive operation exposes by itself.

This is useful for SRT because it provides a precise mathematical analogue of a history whose effect cannot be read from an unordered inventory of current operations.

It does **not** imply that every order effect is selection, memory, or historical write-back.

## 4. Boundary result from the existing tiny-MDP

The current confirmatory tiny-MDP must **not** be described as a Lie-algebra rewrite.

Its future phase does the following:

```text
formation history -> memory m
future reset: environment state and Q matched
initial action distribution matched
future reads only m
m exerts bounded retention pull on Q
```

The legal corridor set remains the same. History changes how strongly future policy updates are pulled toward the consolidated path; it does not add or delete primitive actions and no Lie-rank analysis was pre-registered or measured.

Therefore the strongest safe current statement is:

\[
\boxed{
\text{matched present} + \text{different }m
\Rightarrow
\text{different future path probabilities / costs / terminal distributions}
}
\]

This is an `HEF-3`-type result in the current selection-event audit.

Forbidden upgrade:

\[
\text{current S4 result}
\not\Rightarrow
\text{history changed }\operatorname{Lie}\{X_i\}.
\]

The HCLR proposal starts **after** this boundary.

## 5. A useful discrete precursor: update noncommutativity

Although S4 is not a Lie system, its future update already suggests a weaker order-sensitive operator question.

Let:

- `R` = one current-consequence / reward update;
- `M_m` = one memory-retention update.

Define the discrete commutator residual:

\[
C_{R,M}(Q;m)
:=
M_m(R(Q))-R(M_m(Q)).
\]

For a scalar linearized example,

\[
R(q)=q+\beta(r-q),
\]

\[
M(q)=q+\kappa(m-q),
\]

so:

\[
M(R(q))-R(M(q))
=\kappa\beta(m-r).
\]

Thus, when `m != r`, "current consequence then historical retention" and "historical retention then current consequence" do not generally coincide.

Safe interpretation:

```text
history can alter how new consequences compose with current updating
```

Not licensed:

```text
discrete noncommutativity = Lie algebra
noncommutativity = real choice
noncommutativity = consciousness
```

This precursor is useful only for designing a stronger continuous / geometric test.

## 6. P4 toy model: matched state + matched first-order dynamics + different generated reachability

Consider a two-dimensional state space with coordinates:

\[
x=(u,v).
\]

Let the first local direction be:

\[
X_1=\partial_u.
\]

Let a history variable `h` modulate the second field:

\[
X_2^{(h)}
=\partial_u+h\,u\,\partial_v.
\]

At the origin:

\[
X_1(0,0)=(1,0)
\]

and for every `h`:

\[
X_2^{(h)}(0,0)=(1,0).
\]

Therefore two conditions with different histories can be matched on:

1. current state;
2. primitive field values at the current state;
3. first-order local response geometry.

Yet:

\[
[X_1,X_2^{(h)}]
=h\,\partial_v.
\]

Hence:

### Condition A: `h = 0`

\[
\operatorname{rank}\operatorname{Lie}\{X_1,X_2\}(0,0)=1.
\]

### Condition B: `h != 0`

\[
\operatorname{rank}\operatorname{Lie}\{X_1,X_2\}(0,0)=2.
\]

So the two systems can be identical at the level of current state and immediate first-order directions while differing in composition-generated local accessibility.

This produces the stronger target statement:

\[
\boxed{
\text{same present}
+
\text{same first-order local dynamics}
\not\Rightarrow
\text{same future-generating structure}
}
\]

This is a **constructed mathematical possibility**, not yet an SRT result.

## 7. Selection-specific formation requirement

The toy above is not enough. If the experimenter simply sets `h`, the result is only hidden-parameter controllability.

To become an SRT-facing P4 test, `h` must be written by a formation history under a pre-registered selection-specific rule.

Minimal schema:

\[
\dot h
=
\eta\,\phi(a_t,o_t)-\lambda h,
\]

or a declared discrete analogue, where `phi` is action-attributable rather than an arbitrary surprise / volatility signal.

The preferred identification design inherits the existing active / master-yoked logic:

```text
active:
  own action causally predicts own consequence

yoked:
  matched consequence stream is replayed
  consequence is decoupled from the yoked agent's own action
```

Then test whether:

\[
h_{active}\neq h_{yoked}
\]

produces a pre-registered difference in bracket-generated accessibility after matching present state and first-order responses.

This preserves the central negative lesson of the existing history-dependent-reachability program: generic prediction error or generic history dependence is not enough.

## 8. HCLR-v0 experimental skeleton

Working name only:

```text
History-Conditioned Lie Reachability (HCLR-v0)
```

### Stage A — Formation

Generate `active`, `master-yoked`, and, if useful, external-action-sham histories with matched outcome statistics.

Required gate:

```text
history variable must preferentially track action-attributable consequence structure
rather than generic volatility / surprise alone
```

### Stage B — Matching

Before the reachability probe, match:

- current observable state `x0`;
- declared fast controller;
- primitive field values `X_i(x0)`;
- first-order response measurements under small single-operation probes.

The point is to rule out the easy explanation that the active condition simply has stronger immediate controls.

### Stage C — Commutator probe

Run a small closed sequence of primitive controls whose leading residual is bracket-sensitive.

Primary prediction:

\[
\Delta_{comm}^{active}
-
\Delta_{comm}^{yoked}
\neq 0
\]

with scaling consistent with the declared small-loop order before finite-amplitude effects dominate.

### Stage D — Finite-horizon reachability

Measure a declared reachable-set statistic, for example:

- reachable-area / volume estimate;
- target-hit region under bounded control budget;
- rank-sensitive directional probe battery;
- minimal control cost to enter a bracket-only direction.

Prediction:

```text
active and yoked remain matched on state + first-order response
but differ on composition-generated reachability
```

### Stage E — Swap / null controls

At minimum:

- history-null / no-write condition;
- generic-history control that changes a scalar state but not bracket structure;
- history-carrier swap, if architecture permits;
- parameter-matched condition in which `h` differs but the bracket rank is deliberately held fixed.

The last control is essential: otherwise any future difference can be attributed to a generic hidden variable rather than generator-structure change.

## 10. Relation to memory

This bridge sharpens, but does not replace, the current NEURAL25 boundary.

Safe hierarchy:

```text
memory as retained representation
<
memory as future-selection bias
<
possible memory as dynamical grammar rewrite
```

The third line is a P4 possibility only.

A useful experimental contrast is:

```text
weight memory:
  same generators / same composition rules
  changed preference or transition probability

grammar memory:
  matched first-order state and responses
  changed higher-order composition-generated accessibility
```

If no empirical or designed-system case survives this distinction, "memory as dynamical grammar" should be dropped rather than retained as metaphor.

## 11. Novelty gate: where SRT may fail to add anything

This bridge is valuable only if it survives comparison with ordinary path dependence, adaptive control, nonholonomic control, metaplasticity, and state augmentation.

### Failure mode N1 — Markov-state absorption

If every apparent history effect can be fully represented by enlarging the current state to include `h`, then HCLR may be useful engineering but does not by itself establish a new ontological category.

SRT must not answer this by declaring the enlarged state "not really present" without an independent criterion.

### Failure mode N2 — standard control theory already exhausts the discriminator

If the full claim is simply:

```text
parameter-dependent vector fields have parameter-dependent Lie closure
```

then the mathematics is standard and there is no SRT-specific novelty.

Any SRT increment must come from the **identification problem**:

```text
selection-specific formation
+ matched present
+ matched first-order response
+ residual history-conditioned generator structure
+ future consequence
```

and from a test that standard generic history / adaptive-control baselines fail under the same protocol.

### Failure mode N3 — no extra predictive gain

If bracket/rank measures add no out-of-sample prediction of future accessibility after ordinary memory strength, current policy, switching cost and hidden-state estimates are included, then HCLR should be demoted to an explanatory redescription.

### Failure mode N4 — no selection specificity

If active and yoked histories with matched outcome streams induce the same generator / commutator structure, then the selection-specific write-back hypothesis fails for that implementation.

### Failure mode N5 — HEF-4 collapses into HEF-3

If all observed generator effects reduce operationally to ordinary probability or cost changes without an independent rule/composition-level discriminator, classify the result as `HEF-3`, not `HEF-4`.

## 12. Falsifiable claim cluster

### HCLR-P4-1 — matched-first-order divergence

After selection-specific formation and present-state matching, active and yoked conditions can be made indistinguishable on pre-registered first-order single-generator probes while differing on commutator-sensitive probes.

### HCLR-P4-2 — bracket-mediated future access

The commutator-sensitive difference predicts finite-horizon access to a declared target region beyond current state, current policy, scalar memory strength and first-order response measures.

### HCLR-P4-3 — selection-specificity gate

A master-yoked condition receiving matched outcome statistics but lacking own-action consequence coupling does not reproduce the active condition's bracket-sensitive accessibility effect within a pre-registered equivalence bound.

### HCLR-P4-4 — rank-preserving hidden-state control

A control manipulation that changes the history carrier while preserving the declared generated-rank / composition statistic should not reproduce the full reachability effect. Otherwise the bracket statistic is not the load-bearing mediator.

### HCLR-P4-5 — demotion rule

If P4-1 through P4-4 fail, retain only the weaker statement that history can bias future dynamics; do not rescue the bridge by post hoc adding unrestricted latent generators.
