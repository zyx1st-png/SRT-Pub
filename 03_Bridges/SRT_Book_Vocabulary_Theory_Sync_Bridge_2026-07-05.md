## 2. 新候选登记（book-provenance，P2/P3，未采纳前不作 canonical）

### 2.1 给定感 + 对象化三步（对象化/范畴化/默认化）

- **书稿**：给定感 = 对象化、范畴化、默认化三步压缩成功后退入背景留下的稳定效果。
- **理论锚点**：`L_0 §一`「存在不是背景」是同一洞见的本体面；`L_1→L_2` 背景化（Eq-Bridge-L2-01）是机制面。缺的是把「给定感」作为**被命名的现象学目标**登记，以及「对象化三步」作为背景化的**颗粒化机制**登记。
- **登记等级**：P2 canonical interpretation（对已有 `L_0`/`L_2` 结构的现象学重述，非新定理）。
- **边界**：给定感是**被生成的真实感**，不得写成「现实最底层」；对象化三步不得升格为新公理——它是 `L_1→L_2` 背景化在认知尺度的读法。

### 2.2 微效价 + 价值发生链 ⚑（最值得登记的一条）

- **书稿（Q14）**：价值发生链 = **选择性收束 → 微效价 → affordance → 缺失 → 需求 → 锚定 → 价值深度**。其中：
  - **微效价** = 显现界面对具身位的**最小趋避倾斜**，术语表明写「晚于 Q04 最低非中立性」——即 **微效价 ≠ ε_pg**，是 ε_pg 之后、在具身界面上出现的中间构造。
  - **affordance** = 具身位读出的可生成入口，「晚于 Q11 预裁剪」。
- **理论锚点**：`_SRT_D_VALUE_CANONICAL.md` 的 "Value as Non-Substitutability" 给了价值的**结果判据**（不可替代性），但**没有这条从 ε_pg 到价值深度的发生链**，也没有「微效价」这一中间层。这是书稿优化中长出、理论层确实缺的一环。
- **登记等级**：P3 bridge candidate。发生链是**生成序**假说，须与 d-value canonical 的 stake-coupling（R/A/C 门，§2b.1）对账后方可硬化：微效价→affordance→缺失→需求 大致落在「方向进入 `d_stakes` 之前的前赌注结构」，与 `R_i`（真实不可逆风险）的门控是上下游关系。
- **不可替代性两测试**（替换测试／恢复测试）= 对 "Value as Non-Substitutability" 的**操作化**，可直接登记为该节的 book-provenance 测试对（P3/P4）。
- **边界**：微效价不得写成 ε_pg 的同义词（层级不同）；发生链是候选生成序，不是已证定理；不得绕过 d-value stake-gate 直接把「有微效价」读成「有 stake-coupled d」。

### 2.3 预裁剪四机制 ⚑

- **书稿（Q11）**：预裁剪 = 地形在选择者开始选择前已完成的压缩，四机制：**可见性裁剪 / 接触窗口 / 默认通道 / 代价分配**；显式区分于决定论（不替你走那一步）与有限理性（压缩的是搜索空间本身，非搜索能力）。
- **理论锚点**：`P1-T03` `L_2` 下向约束的域内展开。四机制是 `C_{L_2}` 约束项在「选项场预处理」上的四个可观察落点。
- **登记等级**：P2/P3。四机制可作为 `P1-T03` 的 domain-facing 诊断清单登记（非新定理）。
- **边界**：预裁剪 ≠ 决定论、≠ 有限理性（书稿已划界，理论层沿用此双重划界）。

### 2.4 被排开者去向三分（阴影/张力/后续摩擦）⚑

- **书稿（Q06）**：被排除的可能不消失，以三种方式留在地形——**阴影**（"本来可以但没有"的持续参照）/ **张力**（旧结构与新环境的应力）/ **后续摩擦**（改变重选的代价，且随时间上涨）。
- **理论锚点**：MSD 桥把「排开」映射到 `Ĝθ` 支撑集收缩，但**未展开被排开者的去向**。这三分补上了「排除留什么」——与 `Ψ_f` 残余、路径依赖代价、反事实结构相关。
- **登记等级**：P2/P3 candidate。「后续摩擦随时间上涨」是可检验方向（对接 `Ψ_f^{switch}` 的时间累积）。
- **边界**：阴影不得实体化为「平行世界」；它是地形上的结构参照，不是本体存在。

### 2.5 第三态能动性 ⚑（新章 Q15b）

- **书稿（Q15b）**：能动性 = 一个位置不只被后果改写，还能把回流后果带回自身、据此重新进入选择的**非被动能力**。两道边界：**不是自由意志**（有来路，从回流长出）、**不是机械反馈**（要求后果回到会在乎、能承重的位置，而非只绕回输入）。能动性有**程度**（深浅之别，非有无之别）。
- **理论锚点**：`P1-T05` 真实选择时刻 + 承担闭合（`Eq-Evo-03b` 的 `δθ/δσ ≠ 0`）。「第三态」框架（自由意志与机械反馈之间的第三类）是对 P1-T05 的**新articulation**，理论层未以此对立结构登记。
- **登记等级**：P2 canonical interpretation。「程度而非有无」与 d-value 的连续谱一致，可登记为 P1-T05 的 domain 读法。
- **边界**：不得把「第三态」升格为新公理或第三种本体力；它是 P1-T05 + 承担的白话对立面命名，origin-of-selectability 仍受 `P0-04` 暴露点约束（能动性从回流"长出"不等于解决了可选择性起源）。

### 2.6 委托四要件（共同体）

- **书稿（Q23）**：健康代理委托须**有范围、有期限、能撤销、能审查**；通道被结构性关闭时，代理维持的是「回流的外观」而非共同体回流。
- **理论锚点**：`L_0`「委托」词条已有健康委托判据（共同目标维护 + 委托者再选择能力保留）。四要件是该判据的**操作化清单**。
- **登记等级**：P2。可作为 L0 委托词条的 domain-facing 操作化登记（非重定义）。

### 2.7 AI 三型（脚手架型/牢笼型/地形型）⚑

- **书稿（Q24）**：脚手架型（提升判断/行动/承重）/ 牢笼型（替代判断、能力萎缩）/ 地形型（改变多人共同选择的默认环境）。同一 AI 可在不同用法间滑动。
- **理论锚点**：`AI/AI_POSITIONING_NOTE.md` S0–S4 处理的是 AI **自身**的 stake/主体性阶梯；三型处理的是 AI **对使用者与共同地形的作用**——两者正交，理论层缺后一轴。
- **登记等级**：P3 bridge candidate。三型 = 健康/致命 `L_2` 判据（`SRT_OPEN_TENSIONS §4`）在「工具-使用者-共同地形」上的投影：脚手架型=辅助式 L_2、牢笼型=替代式 L_2、地形型=集体 L_2 改写。
- **边界**：三型是作用类型，不是 AI 意识判据；`d_{AI}≈0`（inference-only）不因 AI 是「地形型」而改变。

### 2.8 理论自反自检三问 + 回到生成四条件 ⚑

- **书稿（Q27/Q28）**：理论自反自检三问（是否还增加可见性 / 是否保留后果回流 / 是否保留再选择能力，两问失败=理论变牢笼）；回到生成四条件（不是源头 / 不是终点 / 不切断回流 / 保留缝隙）。
- **理论锚点**：与 2026-07-05 回流到 `Core_24_Discriminating §0b` 的修正纪律（外部裁判门）同源，但那里是**对 SRT 命题预测**的纪律；自检三问是**对任何理论作为使用牢笼**的纪律——两者互补，后者理论层未登记。
- **登记等级**：P2。自检三问 = 健康/致命 `L_2` 判据应用到「理论自身作为 L_2」；回到生成四条件 = 秩序增益四判据 + 缝隙保留的综合。
- **边界**：这是自反纪律，不是新本体层。

### 2.9 17 条原语生成器 ⚑（阅读地图）

- **书稿（`BOOK_INTERLUDE_BIG_QUESTIONS_INVENTORY` §1）**：17 条原语 = 17 个「拆给定」入口，每条形如「某原语 → 拆掉哪个偷渡的给定 → 解锁哪族难题」。
