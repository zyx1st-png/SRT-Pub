## 0. 目的

书稿战略需要给读者一个旧地板的名字：那种「从已经对象化的切片出发、只研究切片之间关联」的默认提问习惯。候选名是「水平因果」。

但「水平因果」在理论层已经是正式术语（`C_H`，Ax-F-03）。若不登记二者关系，会产生两种事故：

1. 书稿用法被误读为 canonical 定义的扩张（违反 canonical freeze）；
2. 理论层 `C_H` 被书稿的宽用法反向污染（术语漂移无审计痕迹）。

本文件一次性登记：两个用法各是什么、关系是什么、边界在哪、公共配对词怎么选、正文可用句是哪些、什么情况算失败。

## 1. 理论层定义：`C_H`

`Philosophy/SRT_Causality_Time.md` §1.1（Ax-F-03）：

$$C_H(A \to B) \equiv P(B \,|\, A,\, L_2)$$

要点：

- **运作域**：L₂ 层内部；无 L₂ 积累则无水平因果。
- **性质**：时序性（A 先于 B）＋条件概率性（因果关系 = L₂ 历史结构下的稳定条件概率）。
- **覆盖范围**：休谟意义上的因果、科学定律、一切可实验检验的因果关系。
- **地位**：Ax-F-03 受保护；`C_H` 在其域内完整有效，两层因果并存不矛盾（同文件 §1.4）。

这是一个**因果类**的定义：它划出哪一类因果关系属于水平层。它不是对某种提问习惯的批评。

## 2. 书稿层用法：「水平因果」作为提问习惯

书稿及公共表达中拟使用的「水平因果」，指的是另一个东西：

> **一种默认提问习惯：从已经对象化的切片（对象、变量、指标、行为数据）出发，只追问切片与切片之间的关联、机制、相关性与预测，而不追问切片本身如何被切出来、切法由谁定、切掉的可能去了哪里、后果是否回到承受的位置。**

关键区别：

| | 理论层 `C_H` | 书稿层「水平因果」 |
|---|---|---|
| 指称对象 | 一类因果关系（L₂ 内、时序、条件概率） | 一种提问习惯 / 认知默认地板 |
| 词性 | 形式定义（有公式） | 公共书写名（无公式） |
| 评价色彩 | 中性，受公理保护 | 中性偏诊断：命名一个盲区，不否定其成功 |
| 语义宽度 | 窄而精确 | 宽：涵盖统计关联、指标治理、还原主义解释习惯等 |
| 权威层级 | Ax-F-03，形式层 | 书稿主张 / 公共表达层，`canonical: false` |

**关系判定**：书稿用法借用了理论层 `C_H` 的方向（都指「在既成对象之间水平地工作」），但语义更宽。它是三层纪律中的「书稿主张」层用法，**不是新的 canonical 定义，不替代、不修订 Ax-F-03**。若后续理论工作需要把「提问习惯」义形式化，须另立 candidate，不得直接改写 `C_H`。

## 3. 为什么书内不配「垂直因果」

理论层的配对词是「垂直因果」（$L_0 \vDash L_1 \vDash L_2$，结构构成）。**书稿与公共表达中不得使用「垂直因果」作为配对词**，三个理由：

1. **必然错读为时序推动。** 理论层垂直因果是**非时序的结构构成**（`Philosophy/SRT_Causality_Time.md` §1.2：「L₀ 不『推动』L₁ 在时间上发生，而是使 L₁ 成为结构上的可能」）。公共读者看到「垂直因果」四个字，几乎必然读成「另一种在时间中推动事件的因果力」——这恰好是理论层明确标为范畴错误的读法。
2. **撞上学界泥潭。** 英语语境中 vertical / downward causation 直接挂到心灵哲学的下向因果世纪争论上，书会被迫继承一整套不属于它的辩护义务。
3. **制造「竞争因果律」的靶子。** 「两种因果」的表述让书看起来在提出一种与物理学竞争的因果机制，招致「拿出你的方程」式攻击；而书稿要做的只是移动提问顺序。

## 4. 推荐配对：「水平因果 / 生成之问」

书内配对词使用**「生成之问」**（语境需要名词形态时可用「生成视野」）。

这个配对刻意**不对称**：一边是因果（名词，一类关系），一边是问（动词，一个时刻）。不对称正是护栏——它把对比从「两种因果机制之争」降为「两个提问时刻之别」：

> 水平因果在切片成形**之后**开始工作；生成之问在切片成形**之前**就到场。

由此，书稿不需要否定水平因果的任何一条成功记录，只需要指出它开始得太晚——对某一类问题而言。

## 5. 正文可用句

以下句子已按 TASTE.md 语域校准，可直接进入正文或公共内容（按各自渠道纪律使用）：

1. **定义句**：
   > 水平因果研究切片和切片之间的关系；生成之问追问这些切片从哪里被切出来、由谁来切、切掉的去了哪里。

2. **传播句**（挂 Q11 预裁剪）：
   > 别只问你选了什么，先问菜单是谁给的。

3. **第零问**（进入四组三问之前的换镜片动作，不是第五组三问）：
   > 在它们相关之前，它们是怎么成为「它们」的？

4. **致敬句**（对手处理姿态，供 Q00 / 幕前·二参考）：
   > 水平因果是人类历史上极其成功的提问方式：它靠「只研究已经稳定下来的东西之间的关系」这个自我限制，换来了预测力和技术回报。本书不打算否定它，只在它前面加一个更早的问题。

5. **硬度钩子**（供幕前·二，面向高认知读者）：
   > 即使是最严格的因果推断，也必须先决定哪些变量存在；变量清单本身不在因果图里。

## 6. 护栏与失败条件

**护栏（全部强制）**：

1. **生成之问不是新物理。** 它是提问顺序，不是因果机制；任何「生成因果律」式表述一律拦下。
2. **不是反科学。** 书稿必须当场让渡水平因果的成功域：在对象边界稳定、后果不需回到具身位的领域，它就是正确工具。
3. **不否定 `C_H`。** Ax-F-03 在其域内完整有效；书稿用法对它零修订。
4. **不升级为 canonical。** 书稿强句（含本文件 §5 各句）不得直接登记为理论定义；回流须走 candidate 流程。
5. **不混同。** 后续正文若使用「水平因果」，指的是本文件 §2 的提问习惯义；凡涉及 `C_H` 公式义，必须显式引用 `Philosophy/SRT_Causality_Time.md`，不得混写。
6. **不用量子类比证明。** 跨领域材料是显影不是证明；量子相邻表述沿用既有禁令（公共内容禁单独成篇，正文守「显影非证明」）。

**失败条件（Q26 风格，写给这个区分自己）**：

- **装饰性死法**：若「生成之问」在具体决策、章节论证或公共内容中从不产生与水平分析不同的判断，则该区分是装饰性的，应当撤回。
- **混同死法**：若书稿用法与 `C_H` 在任一正文或公共成稿中发生混写且未被纠正，本桥失职，须修订本文件并回查成稿。
- **僭越死法**：若「生成之问」开始被表述为一种与科学竞争的因果机制，即触发姿态回退，按 `Governance/SRT_EDIT_PROTOCOL.md` 处理。
