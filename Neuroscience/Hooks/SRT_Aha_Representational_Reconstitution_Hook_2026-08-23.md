# Research Hook: Aha as Representational Reconstitution and Historical Marking

## Hook

The strongest SRT-relevant feature of the Aha/insight literature is not that insight is sudden, pleasant, or memorable. It is that a stable external input can undergo an internally generated representational discontinuity:

```text
external input: X ---------------- X
internal organization: A ----|---- B
                              ^
                             Aha
```

The transition may be stronger than ordinary reweighting inside a fixed candidate space. In Mooney-image insight, an object that was not previously available as a coherent perceptual candidate can become available after rechunking/reorganization.

Candidate discrimination:

```text
selection within a candidate space
!= reweighting existing candidates
!= reconstituting what can count as a candidate
```

This opens a bridge question for SRT:

> Can some selection-relevant transitions change not merely which candidate is selected, but the effective construction of the candidate space itself?

## Two-layer distinction

The insight work usefully separates:

```text
cognitive component:
representational change / reorganization

!=

evaluative component:
suddenness + certainty + positive emotion
```

SRT-side guard:

```text
representation change
!= concern / significance
!= truth
!= Selection theorem
```

False insights can be sudden, certain, pleasurable, and memorable. Therefore:

```text
selection / stabilization strength
!= truth tracking
```

## Historical-writeback hook

Insight predicts later memory, and hippocampal activity plus cortical representational change are associated with subsequent memory. This suggests a bridge sequence:

```text
representational discontinuity
-> transition detection / evaluation
-> enhanced encoding probability
-> persistent trace
-> possible later structural efficacy
```

Do not collapse these stages. PH-IND05 remains controlling:

```text
H0 actual occurrence
!-> H1 persistent trace
!-> H2 L2-grade sedimentation
!-> H3 bearer-indexed history
```

Five-day memory supports persistent trace; it does not by itself prove L2-grade alteration of future selectability.

## Suddenness hook

Exploratory results in Becker et al. suggest that suddenness may contribute specifically to the hippocampal insight-by-subsequent-memory effect. Conceptually:

```text
certainty: "I now believe B"
emotion:   "B is salient / positively valued"
suddenness:"I just underwent A -> B"
```

The third variable indexes transition structure rather than merely the terminal state. This motivates a testable bridge hypothesis:

> Systems may preferentially encode internally generated structural transitions when the new organization strongly departs from the immediately preceding representational organization.

This is compatible with hippocampal mismatch / prediction-error interpretations but must not be reduced to them.

## Link to N10 / BTSP

N10 supplies a candidate micro-mechanism for one-shot L1-to-L2-like hardening. The Aha result supplies a distinct systems-level phenomenon: abrupt representational reorganization coupled to later memory.

Candidate synthesis:

```text
L1 representational transition
+ transition marking / relevance gating
+ plasticity-compatible encoding
-> persistent trace
-> if later accessibility/friction is altered: L2-like historical efficacy
```

The final arrow is a hypothesis, not established by the Aha experiment.

## Real Choice guard

Aha should not be equated with Real Choice Moment or full SRT Selection.

An Aha transition can be:

- involuntary;
- generated by prior unconscious processing;
- wrong;
- non-agentic;
- lacking explicit alternative maintenance;
- lacking bearer-level consequence closure beyond ordinary memory;
- lacking generative reselectability.

Therefore the value of Aha is diagnostic rather than identificatory:

> It is a clean empirical case where the candidate organization can change discontinuously and the transition itself can be preferentially written into history, without thereby proving real choice, agency, truth, or subject-level selection.

## Open questions

1. Does insight change future accessibility/friction for structurally related problems, not only item memory?
2. Can candidate-space reconstitution be operationally distinguished from extreme reweighting in neural representational geometry?
3. Is transition suddenness itself causal for memory, or merely a report-level correlate of a larger latent reorganization?
4. Which forms of representational reconstitution are involuntary, and which can be intentionally induced or reselected?
5. Can a bearer later reopen and revise the newly constituted candidate space, rather than merely repeat the resulting answer?

These questions should remain bridge/lab targets until independently supported.
