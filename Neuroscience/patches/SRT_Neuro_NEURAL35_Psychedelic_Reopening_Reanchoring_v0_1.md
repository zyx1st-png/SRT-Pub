# SRT Neuroscience Patch NEURAL35: Psychedelic Reopening / Re-anchoring Gate

> **Status:** bounded non-canonical P3 neuroscience bridge + P4 differential-test window.
>
> **Novelty audit:** SRT already has ST-A and a P2/P3 generative-reselectability layer. NEURAL35 does **not** create a second definition of reselectability. Its retained increment is the perturbation-side distinction **reopening != reselectability** and the candidate mirror failure mode **under-anchoring**.
>
> **Canonical caution:** this patch does not redefine `L_0/L_1/L_2`, `G_hat_theta`, `d`, `Psi_f`, `T_dir`, Stable ISP, Real Choice Moment, freedom, subjecthood, or consciousness.
>
> **Clinical-use guard:** any treatment-facing, safety-facing, or public clinical use of this patch must also read `Neuroscience/SRT_Neuroscience_Claim_Status.md` before interpretation or communication.

## 0. Source anchor

Primary source:

> Cavallaro et al. (2026), *Mescaline Alters Cerebellar Function, Global Connectivity, and Frequency-Selective Acoustic Gating: A BOLD fMRI Study in Awake Rats*, *Neuroscience Bulletin*. DOI `10.1007/s12264-026-01632-3`.

SourceCard:

```text
Materials/2026/SRC_2026_08_15_Neuro_Cavallaro_Mescaline_Cerebellar_Gating.md
```

Key bounded observations:

```text
mescaline in awake rats
-> cerebellar-weighted BOLD alteration
-> increased distributed cerebellar functional connectivity
-> frequency-dependent acoustic gating change
```

The paper's cerebellar prediction/filter account is a mechanism hypothesis. The study does not measure human ego dissolution, psychotherapy, or subjecthood.

**Evidence-role boundary:** the `Opening x Reanchoring` discrimination below is an **SRT-internal P4 proposal**. Cavallaro et al. provide a bounded existence example that a psychedelic perturbation can alter network organization and sensory gating in a non-uniform way; they are **not** the evidence basis for the human therapeutic-outcome, integration, expectancy, or alliance terms used in the proposed clinical-shaped model comparison.

The frequency-selective PPI result is retained because it directly blocks the crude claim that mescaline merely "opens a sensory gate" in one monotonic direction.

## 1. Why this matters for SRT

A simplistic psychedelic story says:

```text
constraint down
-> more possibilities
-> more flexibility
-> more freedom / better outcome
```

NEURAL35 blocks that chain.

SRT already distinguishes future selectability from mere option count. Psychedelic perturbation makes the distinction experimentally sharp because a system can become more labile while becoming **less** capable of stabilizing action-guiding selections.

The bridge therefore separates:

```text
candidate reopening
!= selection
!= anchoring
!= reselectability
!= healthy later stabilisation
```

This is complementary to existing patches:

- **NEURAL16:** measurement reliability / proxy-mapping gate; BOLD is not direct neural activity or an SRT variable.
- **NEURAL20:** habitual strategy conversion / execution gain / re-selection capacity are separable.
- **NEURAL23:** momentary embodied eligibility can change without becoming selection or consciousness.
- **NEURAL26:** dynamical capacity, candidate accessibility, control authority, expression and write-back are non-identical.

## 2. P3 bridge: accessibility before anchoring

A local sensory / predictive gating change can be represented as changing which candidates remain available for later competition:

```text
candidate field
-> gating / routing / gain change
-> altered candidate accessibility
-> competition / selection
-> anchoring / action coupling
-> consequence / resistance
-> historical writeback
```

The first arrow is not the whole SRT selection process.

Use the local bridge notation:

\[
A_{cand} = \text{candidate accessibility under a declared perturbation / task}.
\]

`A_cand` is **test-local notation only**. Do not add it to the canonical symbol table.

Central non-identity:

\[
\boxed{A_{cand}\uparrow \;\not\Rightarrow\; R_s\uparrow}
\]

where `R_s` is used here only as shorthand for the already-existing generative-reselectability question, not as a new canonical scalar.

---

## 3. P3 bridge: over-hardening versus under-anchoring

ST-A already protects SRT from treating stable closure as automatically healthy: stable ISP maintenance and generative reselectability are not the same burden.

NEURAL35 adds the mirror stress test:

```text
over-hardening / lock-in
<-> bounded generative reselectability
<-> under-anchoring / failure to stabilize
```

### Over-hardening

Existing structure suppresses live re-entry so strongly that meaningful revision becomes unavailable or prohibitively costly.

### Under-anchoring

A perturbation may expand or reshuffle accessible candidates while weakening the ability to stabilize any candidate long enough for action, consequence testing, cross-time comparison, or useful write-back.

`under-anchoring` is a **P3/P4 working label**, not a new P2 or canonical diagnosis. It must not be used as a catch-all explanation for psychosis, psychedelic adverse events, creativity, meditation, or ordinary uncertainty.

### Positive admission rule for an under-anchoring candidate

The label is admitted only when all of the following are prospectively operationalized and observed relative to a declared baseline / control condition:

```text
UA-1 Opening increases:
     previously weak / inaccessible alternatives measurably re-enter competition
     or prior dominance measurably decreases.

UA-2 Reanchoring is disproportionately weak:
     persistence / cross-context stabilization / evidence-sensitive policy retention
     is lower than expected given the measured increase in Opening.

UA-3 The dissociation is selective:
     basic sensorimotor competence, task comprehension and generic performance capacity
     are sufficiently preserved that the result is not reducible to global impairment.

UA-4 Consequence-sensitive stabilization is degraded:
     action-guiding selections show weaker consequence integration and/or unstable
     later re-entry after the perturbation is removed.

UA-5 The pattern survives preregistered nuisance controls:
     arousal, sedation, noise, reward, salience and generic learning do not explain it away.
```

A test-local descriptive contrast may be used:

\[
UA_{local}=z(Opening)-z(Reanchoring),
\]

but **the score alone does not admit the label**. A large value caused only by measurement noise, global impairment, or a floor effect fails UA-3/UA-5. `UA_local` is not a canonical SRT variable.

This makes `under-anchoring` a candidate that can receive positive support or fail, rather than a label defined only by inability to exclude alternatives.

The adaptive target is therefore not maximum closure or maximum openness, but a bounded region informally summarized as:

> **stable enough to act; open enough to revise.**

That sentence is bridge exposition, not a quantitative canonical criterion.

## 4. P3 process decomposition: reopening -> re-selection -> re-anchoring

A perturbation-sensitive process model can be written as:

```text
A. destabilization
   old constraint structure loses some dominance

B. reopening
   previously weak / inaccessible candidates re-enter competition

C. re-selection
   candidates compete under current bearer, history, task and context

D. re-anchoring / re-deposition
   selected trajectories face action, resistance, consequence and later write-back
```

Compressed:

\[
L_{2,old}
\rightarrow \text{destabilization}
\rightarrow \text{reopening}
\rightarrow \text{re-selection}
\rightarrow \text{re-anchoring}
\rightarrow L_{2}'
\]

This expression is an explanatory bridge. It does **not** mean a psychedelic literally returns a person from `L_2` to bare `L_0`, nor that `L_0` is a neural candidate set.

## 5. P3 bearer-context guard

Psychedelic research makes context difficult to treat as inert background. For this patch, preparation, bodily state, social setting, physical environment and interpretive frame are treated as parts of the **declared constraint context** in which re-anchoring occurs.

Permissible bridge reading:

```text
same pharmacological perturbation
+ different bearer history / physiological state / relational context
-> potentially different accessible candidates and later stabilization
```

Do not promote the following local notation into canonical `G_hat_theta`:

\[
L_{1,t}\sim \hat G_{\theta_t}(L_{0,t}\mid B_t\leftrightarrow N_t)
\]

It may be used only as a reminder that bearer and enacted niche must be declared when a P4 experiment claims context-dependent re-anchoring. `B` and `N` are not new canonical symbols here.

The ReSPCT consensus is used only as a trial-reporting / context-design anchor, not as evidence that SRT's bearer–niche ontology is established.

## 6. P3 selfhood guard: ego dissolution is not bearer dissolution

Psychedelic discourse often collapses multiple levels of selfhood.

NEURAL35 preserves:

```text
autobiographical self-model change
!= bodily ownership change
!= agency change
!= subject-position change
!= bearer loss
```

and therefore:

\[
\boxed{\text{ego dissolution} \neq \text{subject dissolution} \neq \text{bearer dissolution}}
\]

This is a boundary statement, not a claim that subjecthood necessarily persists unchanged through every altered state.

A bearer remains the relevant unit for SRT only if the ordinary consequence-return / history / future-selectability conditions are independently met. Retrospective reports alone cannot establish literal subject absence during an acute state.

## 7. P4 hypothesis: opening x re-anchoring

A discriminating SRT-facing test should not ask only whether a perturbation increases entropy, connectivity, subjective intensity, mystical experience, or psychological flexibility.

Candidate models:

\[
M_1: Outcome \sim AcuteIntensity
\]

\[
M_2: Outcome \sim StandardFlexibility
\]

\[
M_3: Outcome \sim Opening + Reanchoring + Opening\times Reanchoring + ConsequenceReturn
\]

where every term must be operationalized independently and preregistered.

### Model-comparison discipline

`M_3` has more degrees of freedom than `M_1` or `M_2`. Therefore **higher in-sample fit is not evidence for NEURAL35**. A valid comparison must preregister at least one complexity-controlled route and preferably more than one:

```text
A. held-out / nested cross-validation of predictive log loss, likelihood or error;
B. information-criterion or penalized-likelihood comparison with declared penalty;
C. equal-complexity rival models built from standard constructs
   (e.g. intensity, flexibility, expectancy, alliance, arousal, salience, reward, learning);
D. nested ablation showing that Opening x Reanchoring and/or ConsequenceReturn
   add reproducible held-out value beyond matched controls.
```

A flexible rival with comparable parameter count is required whenever sample size permits. If `M_3` wins only because it contains more terms, the result is **uninformative** for SRT.

**NEURAL35-P1:** if the SRT bridge has incremental value, long-term adaptive outcome should depend on the interaction between reopening and successful re-anchoring more strongly than on acute destabilization alone, under complexity-controlled out-of-sample comparison.

A stronger bounded prediction is:

```text
too little reopening
-> old structure remains dominant / little revision

bounded reopening + successful re-anchoring
-> greater future re-entry into live choice

large destabilization + weak re-anchoring
-> poor action-guiding stabilization or maladaptive write-back
```

This is not licensed as a clinical treatment rule. It is a P4 model-comparison hypothesis.

## 8. P4 measurement decomposition

A future experiment should avoid one omnibus "flexibility" score and separately measure at least:

### Opening

Candidate measures may include task-specific alternative generation, altered transition accessibility, or reduced prior dominance under a controlled perturbation.

### Re-anchoring

Candidate measures may include persistence of a new action policy under repeated evidence, cross-context transfer, resistance to irrelevant state switching, and successful stabilization after perturbation removal.

### Under-anchoring candidate test

The positive UA-1 through UA-5 rule in §3 must be implemented before using `under-anchoring` as an explanatory label. At minimum the design must demonstrate:

```text
Opening increases
+
Reanchoring is lower than expected conditional on Opening
+
selective action-guiding stabilization fails
+
basic competence is preserved
+
confound controls pass
```

A simple high-switching or high-entropy state is not sufficient.

### Consequence return

The chosen trajectory must produce consequences that return to the same bearer / history-bearing process and alter later choice conditions. Reward, confidence or report alone is insufficient.

### Future re-entry

After stabilization, the new structure must remain revisable under changed evidence. Mere retention is insufficient.

The experiment should explicitly compare these measures with:

- psychological flexibility;
- expectancy;
- therapeutic alliance where applicable;
- arousal / salience;
- reward / valence;
- generic learning / memory;
- acute subjective intensity.

Clinical or treatment-facing operationalization must also follow `Neuroscience/SRT_Neuroscience_Claim_Status.md`.

## 9. Psychedelic therapy / integration boundary

This bridge allows the hypothesis:

```text
post-acute integration may function as one re-anchoring context
```

but does **not** claim:

```text
integration is proven necessary
integration is the unique mediator of benefit
maximum ego dissolution is therapeutically optimal
psychedelics restore SRT reselectability by definition
```

Many trials bundle preparation, drug administration, support and integration. Independent causal decomposition remains incomplete.

Animal critical-period reopening is likewise only an adjacent mechanism anchor:

```text
mouse social-reward critical-period reopening
!= human personality reopening
!= therapeutic re-selection proved
```

Any clinical, therapeutic, safety, or treatment-facing use of this section is subordinate to the folder-level guardrail:

```text
Neuroscience/SRT_Neuroscience_Claim_Status.md
```

NEURAL35 is not a treatment recommendation, dosing rule, patient-selection rule, or clinical-risk model.

## 10. BOLD / mechanism guard inherited from NEURAL16

The Cavallaro study uses BOLD fMRI. Therefore every NEURAL35 use inherits:

```text
measurement reliability
-> mapping stability
-> construct discrimination
-> bounded interpretation
```

Blocked inference:

```text
negative / reduced BOLD
-> reduced neuronal firing
```

unless independently validated in the declared region / state / measurement package.

Also blocked:

```text
functional hyperconnectivity
-> more information
-> more consciousness
-> more freedom
```

Connectivity is a network statistic, not SRT selectability.

## 11. Failure / downgrade conditions

NEURAL35 should be narrowed or retired if preregistered work repeatedly finds any of the following:

1. `Opening x Reanchoring` adds no complexity-controlled out-of-sample predictive value beyond standard flexibility, expectancy, alliance, reward, salience, arousal and generic learning.
2. Adaptive outcome is robustly monotonic with destabilization / plasticity across adequately sampled ranges and does not depend on anchoring quality.
3. Candidate accessibility and action-guiding anchoring cannot be empirically separated.
4. Consequence-return measures add no information beyond ordinary reward / confidence / persistence measures.
5. The proposed `under-anchoring` candidate repeatedly fails its positive UA-1 through UA-5 admission rule, or its apparent signal collapses after controls for measurement noise, acute impairment, sedation, arousal or nonspecific task failure.
6. Psychedelic-specific findings fail to generalize to any non-drug perturbation paradigm, leaving the bridge too narrow to bear a general SRT claim.
7. `M_3` appears superior only under in-sample or under-penalized comparison and loses against held-out or equal-complexity rivals.

Failure of NEURAL35 does not retract ST-A or the P0/P1 core. It retracts this P3/P4 perturbational bridge.
