# NEURAL33 — Distributed ripple coordination and relational reinstatement

> **Boundary**: P3 neuroscience implementation bridge with P4 mechanism-level predictions. This patch does **not** redefine `L_0`, `L_1`, `L_2`, `G_hat_theta`, `Psi_f`, `d`, `T_dir`, memory, consciousness, bearer or subjecthood. It does not identify ripple oscillations with selection, anchoring, global workspace ignition or phenomenality. It isolates a narrower mechanism candidate: **brief cross-region ripple windows can preferentially realize and reinstate behaviorally relevant distributed firing relations that are not exhausted by component firing magnitude alone.**

---

## 1. Why NEURAL33 is not another generic synchrony patch

The useful increment is not:

```text
brain regions synchronize during cognition
```

and not:

```text
ripples occur during memory
```

Those ideas are already broadly available in neuroscience.

The source adds a more discriminating empirical combination:

```text
long-distance co-ripple
+ single-neuron spike timing
+ working-memory load modulation
+ stimulus-specific encoding -> retrieval relation repetition
+ behavioral-efficiency association
```

The central SRT-facing pressure is therefore relational:

> A neural functional state can differ even when local activity magnitude is similar, because the **currently realized relations among distributed components** can differ.

Compact guard:

```text
component state
!=
organizational state
```

## 3. Main bridge claim — transient distributed relational organization

Let a declared neural implementation state contain at least two descriptive families:

```text
X(t) = component / local activity variables
R(t) = currently realized relation variables
```

The source motivates, but does not canonically define, a richer bridge state:

\[
\sigma_{bridge}(t)=\big(X(t),R(t),\Theta(t)\big),
\]

where `Theta(t)` collects timing, phase and physiological context needed for the declared experiment.

The key distinction is:

\[
X(t_1)\approx X(t_2)
\not\Rightarrow
R(t_1)\approx R(t_2).
\]

Two periods can have similar mean firing or power while differing in which distant neuron pairs are temporally coordinated. In the Verzhbinsky dataset, load-related co-ripple changes during maintenance can occur without a significant load-related increase in global mean firing, and rate-corrected spike-timing coordination remains enhanced during co-ripples.

Therefore:

> **Local activation variables alone need not exhaust the neural implementation state relevant to cognition.**

This is a P3 bridge pressure on coordinate choice, not a replacement for the owner neural manifold definition.

## 4. Co-ripple as coordination opportunity, not selection itself

NEURAL33 should cross-read with NEURAL23 rather than collapse into it.

NEURAL23 distinguishes:

```text
selection weight
!= selection opportunity
!= selection friction
```

NEURAL33 adds a plausible neural-domain implementation candidate for part of **coordination opportunity**:

```text
candidate distributed activity
-> brief co-ripple-compatible window
-> enhanced precise cross-region co-firing
-> temporary relational coalition
```

But the following identities are blocked:

```text
co-ripple != selection
co-ripple != L1
co-ripple != G_hat_theta
co-ripple != d-value
co-ripple != Psi_f
co-ripple != consciousness
```

A co-ripple may create or mark a window in which distributed interaction becomes more likely. It does not by itself answer which candidate wins, why it matters, whether it becomes consciously manifest or whether it sediments into later history.

## 5. Relation-level content pressure

The strongest source result is not simply increased co-firing. The paper identifies stimulus-specific cross-region cell-pair co-firing during encoding and asks whether the same pair relation recurs when that same stimulus is later retrieved.

The relation-level object of analysis is therefore schematically:

\[
R_m^{enc}=\{(i,j,\Delta t): i,j\ \text{co-fire during encoding of }m\}.
\]

Retrieval can then be tested for:

\[
R_m^{ret}\sim R_m^{enc}.
\]

The paper finds that such repetition is enriched during co-ripple periods and associated with faster recognition.

Safe SRT pressure:

```text
content-relevant neural organization
may include
reinstatable cross-component relations
```

Blocked overreach:

```text
representation = pairwise relations alone
```

The experiment samples only part of the relevant system and does not show that a complete percept, concept or phenomenal character is exhausted by the recorded relation set.

## 6. Historical re-entry — memory use as present re-instantiation

NEURAL31 already distinguishes:

```text
content constraint
!= historical eligibility
!= retrievability
```

NEURAL33 adds a plausible readout for what successful **re-entry** may look like at the distributed neuronal level:

```text
past encoding relation
-> historical changes persist in the system
-> later cue + current state
-> related distributed relation becomes realizable again
```

Local bridge notation:

\[
P\!\left(R_m^{reentry}\mid C_t,H_m,E_t\right),
\]

where:

- `H_m` = declared history relevant to memory `m`;
- `C_t` = current cue / context;
- `E_t` = current eligibility state in the broad NEURAL23-compatible sense;
- `R_m^{reentry}` = present relation-level reinstantiation.

The useful SRT claim is:

> **Historical efficacy can be expressed as a changed probability that a related organization becomes realizable again.**

This does **not** imply that memory storage is unreal, that synaptic traces are unnecessary or that all memory content is encoded only relationally.

---

## 7. Re-selection is not return to the identical past state

A retrieval event occurs in a system that has continued to change since encoding. Therefore even successful reinstatement should not be modeled as exact microstate identity:

\[
R_m^{(2)}\neq R_m^{(1)}
\]

can coexist with:

\[
R_m^{(2)}\sim R_m^{(1)}
\]

at an experiment-declared functional level.

SRT-facing bridge:

```text
re-selection
!= retrieval of an identical past object

re-selection
can be
history-conditioned re-instantiation of sufficiently similar organization
```

This gives a neural implementation example for the broader SRT distinction between irreversible history and literal reversal of time.

## 8. Four-scale integration hypothesis

NEURAL33 becomes most useful when combined with already-separated SRT neuroscience lines.

### 8.1 Historical timescale — NEURAL31

```text
past experience
-> latent historical eligibility / retrievability changes
```

This asks:

> What has prior experience changed about future re-entry conditions?

### 8.2 Embodied rhythmic timescale — NEURAL23

```text
brain-body temporal state
-> momentary eligibility profile
```

This asks:

> Why is the same candidate more or less admissible now than moments earlier?

### 8.3 Large-scale cortical dynamical context

Existing SRT neuroscience has already retained a bounded large-scale phase-dominance / global-phase-scaffold window:

```text
large-scale cortical phase organization
-> context for local routing / modulation
```

This asks:

> What large-scale dynamical context are local events embedded in?

### 8.4 Brief relational realization — NEURAL33

```text
co-ripple-compatible transient window
-> enhanced cross-region spike coordination
-> content-related relational reinstatement
```

This asks:

> Which distributed organization is actually realized during this brief cognitive window?

### 8.5 Combined but unproven bridge

The bounded integration hypothesis is:

\[
H_t,B_t,P_t,C_t
\rightarrow
\mathcal{L}_t
\rightarrow
W_t
\rightarrow
R_t
\rightarrow
Y_t,
\]

where:

- `H_t` = historical constraints;
- `B_t` = current embodied / physiological timing state;
- `P_t` = large-scale phase / neural dynamical context;
- `C_t` = current cue and task context;
- `L_t` = local bridge label for a current selectability landscape;
- `W_t` = transient coordination window;
- `R_t` = realized distributed relation structure;
- `Y_t` = behavioral, report or later-writeback consequence.

Every symbol in this chain is **local bridge notation**. No term should be imported into canonical SRT without separate owner review.

Most importantly:

```text
compatible evidence across scales
!= one demonstrated causal chain
```

## 9. Why the integration is stronger than `memory = stored copy`

NEURAL33 does not deny stored traces. Instead it separates two questions:

```text
Where / how does history persist?
```

from:

```text
How does history become effective again now?
```

NEURAL31 addresses latent historical eligibility and retrievability. NEURAL33 addresses a possible form of current relation-level re-expression.

Therefore a safer SRT bridge is:

> **Memory persistence can reside in historical changes that bias future re-entry, while memory use is expressed in present reconstruction / reinstantiation under current constraints.**

This is compatible with neuronal engrams, synaptic plasticity, excitability changes, astrocytic eligibility and other substrate mechanisms.

## 10. Interactive network pressure — not a ban on serial processing

The source discusses a focal-sequential versus distributed-interactive distinction and interprets long-range co-ripple coordination, weak further distance attenuation and stimulus-specific relation repetition as evidence compatible with an interactive network phenomenon.

NEURAL33 should preserve the source's mixed architecture:

```text
early sensory / motor stages may remain substantially sequential-hierarchical;
higher association processing may recruit distributed interactive coordination;
rapid reinstatement and slower sequential search can coexist in the same task.
```

Blocked slogan:

```text
A -> B -> C processing is false
```

The source does not justify that universal claim.

## 12. Mechanism-level differential prediction cluster

NEURAL33 should create a new prediction class distinct from the current phenomenon-level matrix.

### Prediction M1 — history × eligibility interaction

If history changes future selectability rather than only adding a fixed retrieval-strength scalar, then:

\[
R_m^{reentry}
=
\beta_0+\beta_1H_m+\beta_2E_t+\beta_3(H_m\times E_t)+\epsilon
\]

should show a non-trivial interaction under declared controls.

Downgrade condition:

```text
history and current state are fully additive across strong replications;
no interaction survives measurement-error and arousal controls.
```

### Prediction M2 — relational residual beyond component activity

After matching or modeling:

```text
firing rate;
ripple power;
local oscillatory event rate;
task load;
stimulus identity;
arousal;
recording quality;
```

relation-level similarity / coordination should retain incremental prediction of retrieval efficiency if `organizational state` adds explanatory structure.

Downgrade condition:

```text
all relation-level behavioral prediction disappears after component-level controls.
```

### Prediction M3 — pre-ripple state predicts content-specific reinstatement

If NEURAL23-like eligibility is more than generic readiness, pre-ripple embodied / neural phase state should predict **which encoding-related relation** is later reinstated, not only whether RT is fast.

Downgrade condition:

```text
pre-state predicts only generic arousal or response speed, never content-specific reentry.
```

### Prediction M4 — same-content reentry tolerates component turnover

Let:

\[
O_V = \frac{|V_1\cap V_2|}{|V_1\cup V_2|}
\]

measure component overlap and `S_R` measure relation-level similarity.

A relational-state account predicts that `S_R` may retain predictive value for same-content recognition after controlling `O_V`.

Downgrade condition:

```text
stable component identity fully explains reinstatement and relation-level residual is zero.
```

### Prediction M5 — historical eligibility affects re-entry more directly than content identity

Crossing NEURAL31 with NEURAL33 suggests a future causal animal test:

```text
manipulate learning-linked historical eligibility substrate
-> change reentry probability / latency / stability
without necessarily abolishing stimulus identity coding
```

This is a bridge prediction only. The Verzhbinsky paper does not manipulate astrocytes or historical eligibility substrates.

### Prediction M6 — retention != current retrievability

Two memories with comparable retained-trace metrics can differ in current relation-level re-entry probability under different current states.

A failure to recall should therefore not be treated as automatic evidence that all relevant historical trace has vanished.

## 13. Strong falsification / downgrade conditions

NEURAL33 should be narrowed substantially if repeated high-quality experiments show that:

1. co-ripple-associated relation repetition does not generalize beyond the current task / clinical sample;
2. all apparent precise coordination is explained by firing-rate, common-input or waveform contamination after stronger causal controls;
3. relation-level metrics add no out-of-sample behavioral prediction beyond node-level features;
4. pre-ripple state cannot predict content-specific re-entry after cue and arousal controls;
5. same-content recurrence requires near-identical component membership and relation metrics add nothing;
6. causal manipulation of the proposed coordination window changes excitability but not relation-specific retrieval;
7. other mechanisms explain the full pattern while ripple timing is epiphenomenal.

Failure of NEURAL33 does not refute SRT core ontology. It refutes or narrows this neuroscience implementation bridge.

---

## 14. Bearer / consciousness guard

The paper studies awake patients performing a working-memory task. It contains no conscious-versus-unconscious contrast and no manipulation of subject boundary.

Therefore:

```text
co-ripple coalition
!= bearer evidence

stimulus-specific distributed coordination
!= phenomenal unity proof
```

A future bearer bridge would require independent evidence that a coordination boundary tracks a subject / consequence-return boundary across dissociations such as anesthesia, split processing or other subject-boundary manipulations.

Until then, NEURAL33 remains a cognition / memory / neural-organization patch.
