# NEURAL30 — Temporal integration closure and state-conditioned object formation

> **Boundary**: bounded P3 neuroscience / consciousness bridge with P4 experimental consequences. This patch does not define `L_0`, `L_1`, `L_2`, `G_hat_theta`, `d`, `Psi_f`, consciousness, subjecthood, or objecthood. It does not identify an EEG scalp topography with an SRT ontological layer. It uses the SQM evidence to sharpen one implementation question: how can a temporally structured history remain neurally operative before being resolved into a unified percept that no longer exposes its generating events separately?

## 1. Source anchor

Primary source:

- Menétrey MQ, Herzog MH, Pascucci D. *Sequential neural dynamics underlie unconscious integration and conscious perception of visual stimuli*. *PLOS Biology* 24(7): e3003894 (2026). DOI `10.1371/journal.pbio.3003894`.
- Full published PDF close-read from the user-supplied attachment.
- Human SQM psychophysics + 128-channel EEG + temporal/cross-condition LDA.
- Data/code route reported by the paper: Zenodo `10.5281/zenodo.20729504`.

The paper's discussion also cites prior work in which prestimulus alpha-band EEG fluctuations predict whether the first or second vernier dominates the reported V–AV percept. That alpha result is supporting literature, not a new result of the present dataset. Respiratory and cardiac phase were not recorded here.

## 2. Why this matters for SRT

Current SRT neuroscience already contains several separations:

```text
NEURAL23:
accessible candidate
!= momentary embodied eligibility

NEURAL28:
identification
!= re-identification

NEURAL29:
retention
!= historical transformation

NEURAL25:
representation
!= accessibility
!= authority
!= expression
!= write-back

NEURAL27:
reportable memory
!= prospective history-use
```

What was still under-specified is the short-timescale transition from **event-specific structured processing** to **one current integrated percept**.

The SQM results add a bounded implementation pressure:

> **Information can remain precisely structured in time without becoming separately manifest as conscious objects, and the current integrated percept can emerge only after that structured history has been combined and resolved.**

This is neither a new canonical layer nor a claim that all consciousness requires 290–450 ms. It is a concrete temporal object-formation bridge.

## 3. Main SRT bridge claim

### NEURAL30 core claim

> **A manifest percept can be temporally local while its content is temporally thick. Neural processing may preserve the chronology of candidate events that never appear as separate conscious objects, then resolve that structured history into a unified percept whose identity is not a simple copy of the event list.**

Short form:

> **Not separately manifest does not mean structureless; current objecthood need not equal the full history that generated it.**

This is a P3 bridge sentence, not a definition of `L_1`, objecthood, or consciousness.

## 4. Source-backed processing decomposition

The source supports a within-paradigm separation of:

```text
physical event occurrence
-> event-specific / chronology-preserving neural representation
-> extended unconscious integration
-> transition in dominant EEG topography
-> integrated-percept / report-associated neural representation
-> later behavioral response
```

The components must remain distinct:

```text
event decodable
!= event separately conscious

integrated representation
!= phenomenal consciousness timestamp

late parietal/P300-like activity
!= consciousness itself

button report
!= percept formation
```

The actual button response occurred around 885–920 ms, substantially later than both the event-specific decoding and the occipital-to-parietal transition.

## 5. Structured history without separate manifestation

The strongest result for SRT is not simply “unconscious processing lasts hundreds of milliseconds.” It is that **the physical timing of an event remains recoverable from neural activity even when the subject cannot access that event as a separate perceptual item**.

Let `H_t` be a local bridge descriptor for the experimentally retained event history over a declared short window. Then the safe relation is:

\[
\operatorname{DecodableStructure}(H_t) > 0
\]

while:

\[
\operatorname{SeparateReport}(e_i) \approx 0
\]

for an individual vernier `e_i` in the integrated V–AV stream.

`H_t` is **not** canonical `L_2`; it is merely a local descriptor for short-timescale retained processing structure.

This supports the negative distinction:

```text
not current explicit object
!=
not currently represented / available to ongoing processing
```

Any stronger claim that this residual history independently constrains later processing remains a P3 mechanism hypothesis unless separately tested.

## 6. Object formation is not event aggregation

The SQM makes a useful objectification pressure visible.

Suppose two physically distinct events are represented as:

```text
A
B
R(A,B)
Δt(A,B)
```

The final percept need not be:

```text
O_A + O_B
```

Instead, the relation, temporal interval and current integration dynamics can contribute to a unitary percept `C`:

\[
C
=
F_{int}\!\left(A,B,R(A,B),\Delta t,H_t\right).
\]

`F_int` is bridge notation only.

SRT-safe use:

> Event history constrains what object can manifest, while the manifest object's boundaries and identity need not preserve the event list one-to-one.

Do not infer that the paper proves SRT's pre-objectification ontology or that relations are ontologically prior to objects. Once `A`, `B`, `A>B`, a rule, or a schema is explicitly identifiable and usable, it is already being handled at an objectification level in current SRT terms.

## 7. Regime transition, not anatomical identity

The decoder activation patterns show an early occipital-dominated regime followed by a later centro-parietal-dominated regime. The transition temporally overlaps the previously behaviorally estimated SQM integration window.

The permitted bridge is:

```text
representation regime A
-> transition
-> representation regime B
```

not:

```text
occipital = L0
parietal = L1
P300 = consciousness
```

The source itself emphasizes that stimulus-locked neural activity does not tell us when the corresponding conscious experience occurs (“vehicle problem”). Even the transition can be a precursor to consciousness or can include processes operating on already-formed perceptual content.

This is therefore a useful **transition marker candidate**, not an ontological locator.

---

## 8. Momentary manifestation can be temporally thick

The authors relate the results to discrete retentional models in which perception can be momentary yet carry information accumulated over a preceding interval.

A bounded bridge expression is:

\[
P_t
=
F_{ret}\!\left(H_{t-\Delta:t}\right),
\]

where:

- `P_t` = current integrated percept descriptor;
- `H_{t-Δ:t}` = the preceding structured processing window;
- `F_ret` = local retention/integration mapping.

None of these are canonical SRT variables.

The conceptual gain is a separation between:

```text
manifestation event / commitment
and
manifested temporal content
```

A relatively discrete current percept does not require the implementation history that constitutes its content to be equally discrete.

---

## 9. Closure timing is state- and sequence-dependent

The SQM data do not support a fixed consciousness frame rate. Processing latencies and the duration of the two topographic regimes vary with where the vernier occurs in the sequence. The authors suggest that later offsets or stream termination can accelerate the resolution of the sequence into a unified percept.

Introduce only as P3/P4 descriptor:

\[
T_{closure}
=
f(H_t,S_t,Task),
\]

where `S_t` denotes the declared current neural/embodied state in a particular experiment.

The point is qualitative:

```text
closure time
!= universal constant
```

`T_closure` must not enter the canonical symbol table without an independent hardening decision.

---

## 10. Access, report, and phenomenality remain separated

The source explicitly states that its paradigm cannot distinguish phenomenal consciousness from access consciousness. Its broad “conscious processing” category can include post-perceptual decision processes.

NEURAL30 therefore preserves:

```text
integrated percept-related representation
!= access fully isolated
!= phenomenal consciousness explained
!= subjecthood
!= bearer formation
```

The P300-like result is especially important as a guardrail: a component correlated with correct report does not become a constitutive signature of experience merely because it is late, widespread or behaviorally predictive.

## 11. Interface with NEURAL23 embodied rhythmic eligibility

NEURAL23 supplies an upstream candidate mechanism:

```text
body / neural phase state
-> momentary selection eligibility
-> competition / gain / gating / stabilization
```

NEURAL30 supplies a distinct downstream object-formation window:

```text
event-specific encoding
-> structured temporal integration
-> regime transition / closure
-> unified percept
```

The combined **hypothesis**, not source finding, is:

```text
endogenous / embodied temporal state
-> candidate eligibility
-> weighted event history
-> integration / closure dynamics
-> integrated percept
```

This is the correct place to connect respiratory, cardiac and neural rhythms to SQM: not by saying “breathing produces consciousness,” but by testing whether phase-conditioned eligibility changes **which event dominates the integrated percept and/or when the integration regime resolves**.

Current paper boundary:

```text
SQM paper measures EEG ERP/decoder dynamics
!=
SQM paper measures respiratory phase
!=
SQM paper measures cardiac phase
```

## 13. P4 experimental consequences

### H-NEURAL30a — respiratory / cardiac phase-conditioned SQM closure

Record EEG + respiration + ECG during SQM. Keep physical V–AV sequences matched while stratifying or experimentally scheduling event onset relative to respiratory and cardiac phase.

Primary outcomes:

1. first- vs second-vernier dominance or a richer percept category if a better report method is used;
2. latency / temporal profile of the occipital-to-parietal regime transition;
3. event-specific decoding duration;
4. late correct-vs-incorrect report decoding.

Model family:

\[
Outcome
\sim
Sequence
+
RespPhase
+
CardiacPhase
+
AlphaState
+
Phase\times Sequence
+
ArousalControls
+
EyeMovementControls.
\]

A phase effect on reaction time alone is weak evidence. The stronger prediction is a differential effect on **integration outcome or closure dynamics** after controlling prestimulus alpha and generic arousal.

Failure condition:

If respiration/cardiac terms add no reproducible prediction beyond alpha, attention, arousal and ordinary sensory timing, keep NEURAL23's general rhythmic-eligibility bridge but reject the proposed specific coupling to SQM closure.

### H-NEURAL30b — same physical history, different endogenous state

Hold the physical sequence constant and compare trials with matched stimulus evidence but different prestimulus neural/embodied states.

Prediction:

```text
same A+B sequence
can yield
different dominance / transition timing
conditional on endogenous state
```

This is a direct test of state-conditioned integration rather than a generic “rhythm influences cognition” claim.

### H-NEURAL30c — matched current percept, different generating histories

Select trials that yield the same final reported percept but arise from different physical sequences (for example, one-vernier vs two-vernier histories when report categories can be meaningfully matched).

Test whether the different histories remain decodable and whether they predict later binding, confidence, adaptation or memory after current report is matched.

A positive residual effect would support:

```text
current percept descriptor
!=
full current historical state
```

without identifying the retained signal with `L_2`.

### H-NEURAL30d — closure acceleration by sequence termination / later evidence

Manipulate the timing of anti-verniers and the termination of the SQM stream while holding total evidence as closely matched as feasible. Test whether later evidence accelerates, delays or qualitatively changes the transition into the integrated-percept regime.

This directly targets the source's suggestion that closure dynamics are flexible and sequence-conditioned.

## 14. Failure conditions

Weaken or reject NEURAL30 if:

1. event-specific timing ceases to be decodable once sensory-energy, attention and eye-movement confounds are rigorously matched;
2. the two-topography organization does not replicate at the individual level or decomposes into task-specific continuous changes with no useful transition structure;
3. richer no-report / graded-report paradigms show that the proposed transition is entirely post-perceptual and has no relation to the formation of the integrated percept;
4. matched-final-percept trials show no residual consequence of different generating histories beyond ordinary sensory aftereffects;
5. endogenous-state effects on integration are fully explained by generic arousal, prestimulus alpha or sensory sensitivity and respiration/cardiac variables add no incremental value;
6. other perceptual paradigms show that the SQM window is a narrow motion-specific artifact — in that case the bridge must remain SQM-local rather than becoming a general consciousness architecture;
7. the bridge starts rescuing itself by calling any temporal smoothing or delayed response “closure.”

Candidate de-materialized sentence for a future neuroscience / consciousness synthesis:

> **A current percept need not be a frame-by-frame copy of current input. In postdictive visual integration, the nervous system can preserve the timing of events that never become separately accessible, then reorganize that temporally structured history into a unitary percept. The relevant transition is therefore better modeled as a flexible change in representational regime than as a fixed anatomical or millisecond marker of consciousness.**

## 17. Abstract

Menétrey, Herzog and Pascucci's SQM study provides a strong P3/P4 bridge for temporal object formation. Single and opposing vernier offsets remain time-specifically decodable during extended unconscious processing; the dominant decoder topography shifts from an earlier occipital pattern to a later centro-parietal pattern associated with the integrated percept and report; correct/incorrect report decoding emerges still later; and the timing of these regimes varies with the sequence rather than following one fixed perceptual clock. The authors explicitly do not identify P300 with consciousness and do not distinguish phenomenal from access consciousness. NEURAL30 therefore uses the paper not as evidence for `occipital=L0`, `parietal=L1`, or a 400 ms consciousness instant, but as a bounded implementation model in which structured event history can remain operative before a unitary percept closes over it. The bridge connects upstream to NEURAL23's phase-dependent embodied eligibility and motivates EEG+respiration+ECG tests of whether endogenous state changes integration dominance or transition timing. Those phase effects remain P4 predictions, not findings of the current paper.
