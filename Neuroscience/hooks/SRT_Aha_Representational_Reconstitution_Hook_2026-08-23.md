## 1. Core hook: stable external input, reconstituted internal organization

The strongest SRT-relevant feature of the Aha/insight literature is not merely that insight is sudden, pleasant or memorable. It is that a stable external input can undergo a strong internally generated representational reorganization:

```text
external input: X ---------------- X
internal organization: A ----|---- B
                              ^
                             Aha
```

Mooney images are particularly useful because the object can become newly available as a coherent percept without a corresponding change in the physical image.

Candidate discrimination:

```text
selection within a candidate space
!= reweighting existing candidates
!= reconstituting candidate accessibility / organization
!= generating a genuinely new concept or comparison dimension
```

The last distinction matters because Mooney recognition usually recruits already learned concepts.

---

## 2. Cognitive component != evaluative component

The insight work separates:

```text
cognitive:
representational change / reorganization

!=

evaluative:
suddenness + certainty + positive emotion
```

SRT-side guards:

```text
representation change
!= concern / stake
!= phenomenality
!= truth
!= Selection theorem
```

False insights can be sudden, certain, pleasurable and memorable. Therefore:

```text
stabilization / closure strength
!= truth tracking
!= adaptive success
```

---

## 3. Suddenness is a transition variable, not proof of neural discontinuity

Conceptually:

```text
certainty:
"I now believe B"

emotion:
"B is positively / negatively marked"

suddenness:
"I just underwent A -> B"
```

The Becker exploratory memory interaction makes suddenness especially interesting as a transition-sensitive variable.

But:

```text
subjective suddenness
!= demonstrated mathematically discrete neural jump
!= established ontological phase transition
```

A gradual latent reorganization may cross a stabilization / report threshold and be experienced as sudden.

Methodological lineage: `PH_MR01_Representational_Gradualism_Integration_Hook.md` supplies the adjacent-case guard. A sharp report threshold is not by itself evidence that the underlying representational / bearer organization has a natural discontinuity.

---

## 4. Network integration != central controller or historical writeback

High-insight trials show stronger functional connectivity / graph integration in a solution-processing network involving VOTC, hippocampus and amygdala.

Safe use:

```text
higher insight
-> more coordinated solution-state network organization
```

Unsafe use:

```text
network integration = chooser
network hub = subject
network integration = L2 writeback
```

The connectivity results should not be promoted beyond the source's network-level evidence.

---

## 5. Historical-writeback hook: occurrence -> trace -> efficacy

Insight predicts later memory, and hippocampal activity plus cortical representational change are associated with subsequent memory.

Candidate source-to-SRT chain:

```text
representational transition
-> transition detection / evaluation
-> enhanced encoding probability
-> persistent trace
-> possible later structural efficacy
```

Do not collapse these stages. PH-IND05 remains controlling:

```text
H0 actual occurrence
!-> H1 persistent trace
!-> H2 L2-grade sedimentation
!-> H3 bearer-indexed history
!-> phenomenal experiencer
```

Five-day item memory supports persistent trace; it does not by itself prove L2-grade alteration of future selectability.

---

## 6. One-shot perceptual learning strengthens the future-facing side

Hachisuka et al. 2026 show that one disambiguating experience can drastically and durably change later visual recognition, with convergent evidence pointing to high-level visual cortex as a likely plasticity substrate.

This creates a useful split:

```text
episodic memory:
"I remember the learning event"

!=

perceptual hardening:
"I now see it this way"
```

The second provides a stronger empirical model of history changing later accessibility.

But:

```text
perceptual hardening
!= generative reselectability
```

and:

```text
one-shot perceptual learning
!= genuinely new concept generation
```

---

## 7. Aha both opens and closes

The full sequence is not simply:

```text
closed -> open
```

but more often:

```text
old organization
-> destabilization / reorganization
-> new candidate accessibility
-> rapid stabilization
-> new closure
```

This matters because a strong Aha can make a new interpretation difficult to unsee.

Thus:

```text
historical efficacy
can increase
while
generative reselectability remains weak
```

## 8. Candidate access / relational restructuring / candidate generation

For future use, distinguish:

```text
1. candidate access shift
2. relational regrouping / restructuring
3. comparison-scale restructuring
4. problem / operator restructuring
```

Mooney insight is strongest at (1), can involve (2), and is weak evidence for (3)-(4).

Kuhnian scientific insight may involve stronger changes in what counts as a relevant problem, comparison or admissible candidate, but the Becker task does not establish this.

## 9. Reopening and reconsolidation pressure

Stable history must not be treated as irreversible sovereignty.

A useful complementary architecture is:

```text
stable structure
-> reactivation
-> possible destabilization
-> updating
-> restabilization
```

Critical guards:

```text
retrieval != reopening
reopening != revision
reopening != reselectability
```

Prediction error / mismatch may help explain why a system reconsiders something, but:

```text
prediction error != Psi_f
```

A discrepancy signal and the actual payability / burden of structural revision are different theoretical roles.

## 11. Identity / stake pressure: a belief can become historically expensive to revise

An initially epistemic belief can acquire downstream coupling:

```text
belief
-> action
-> commitment
-> relationship / status
-> identity
-> future investment
```

Then the effective update problem changes.

The system may compare:

```text
revise belief + revise self-position / history

vs

retain belief + absorb evidence conflict
```

This motivates, but does not canonically define, a separation among:

```text
prediction error:
update pressure

stake structure:
what downstream consequences matter to the bearer

revision burden / payability:
what actual restructuring costs or requires
```

Keep:

```text
identity != d
prediction error != Psi_f
```

## 12. Bearer continuity does not require self-model invariance

A continuing bearer can survive deep representational change.

Working process view:

```text
B_t
-> event / action
-> consequence
-> consequence returns to B
-> B_(t+1) is a transformed continuation
```

Therefore:

```text
same bearer
!= same belief
!= same self-model
!= same narrative
!= same policy
```

Aha is meaningful precisely because the same continuing system can move from not-understanding to understanding.
