## 3. Suggested native paragraph — affect/stake guard

> Affective intensity should not be treated as a direct scalar readout of stake. Some variables can be indispensable to continued existence while remaining phenomenally quiet under normal regulation, whereas localized pain or nausea can become overwhelmingly salient without thereby measuring the total irreversible risk borne by the system. A safer implementation picture separates baseline stake, current deviation, regulatory signal, felt urgency and selected response. Affect may compress consequence-relevant state into an actionable signal; it does not thereby become the canonical stake variable itself.

## 4. Suggested native paragraph — bearer indexing

> Bearer specification is not only an external bookkeeping problem. In biological organisms, continuous internal state readout may also provide an endogenous indexing function: heterogeneous perceptual and reflective contents occur against an ongoing signal that they belong to this living unit. That mechanism can help explain organism-relative access without making interoception sufficient for subjecthood. Momentary self-location remains thinner than a continuing subject with memory, boundary maintenance, counterfactual access and cross-time reidentification.

## 5. Suggested hard-problem pressure paragraph

> Explaining why a state is consequential for one bearer is not yet the same as deriving why there is something it is like to occupy that state. Damasio's life-first account is instructive precisely because it eventually treats homeostatic feeling as intrinsically conscious. SRT should not reproduce the same stopping point by merely replacing `feeling` with `bearing`. The current contribution is strongest when it explains bearer-relative relevance, consequence return and the difference between internal occurrence and external re-objectification; any stronger phenomenal-constitution claim requires its own argument and failure conditions.

## 7. Suggested experimental rows

### Matched stake / different affect

```text
Hold downstream consequence / future-choice impact approximately matched.
Vary current affective salience.
If affect is a readout rather than stake itself, large affect differences can remain.
```

### Matched affect / different future-selectability loss

```text
Hold subjective intensity approximately matched.
Vary irreversible consequence to the same bearer.
If affect is not canonical d, future-selectability loss can differ substantially.
```

### Automatic versus counterfactual escalation

```text
Match internal perturbation.
Compare fixed/local response conditions against conditions requiring cross-domain memory,
inhibition, planning and delayed-consequence comparison.
Test whether conscious/global access tracks counterfactual coordination beyond raw arousal.
```

### Open-loop replay versus same-bearer closed loop

```text
Match sensory/interoceptive statistics where possible.
Compare replay with a live loop whose actions alter the bearer's own later state and options.
Measure learning, persistence, recovery and policy revision.
```

None of these is a direct consciousness detector.

## 8. Do not include

- homeostasis as canonical `d`;
- affect, valence, pain, hunger, thirst, arousal or salience as canonical `d`;
- felt burden as canonical `Psi_f`;
- `sigma_e ~ partial d / partial t` as empirically validated by Damasio;
- weakly/unmyelinated interoceptive pathways as a sufficient cause of qualia;
- `comingling` or analog processing as settled consciousness mechanism;
- brainstem damage as proof that cortex is irrelevant to rich consciousness;
- organism-level coupling as automatic S4 subjecthood;
- Markov blankets or membranes as subjecthood criteria;
- biological nervous systems as a proven substrate-neutral necessity;
- current LLM lack of biological homeostasis as a universal proof against all future artificial consciousness;
- the claim that SRT has solved the hard problem merely because it uses consequence return or bearing language.
