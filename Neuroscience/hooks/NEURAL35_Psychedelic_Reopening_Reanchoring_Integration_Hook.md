# NEURAL35 Integration Hook — psychedelic reopening / re-anchoring

## 1. Intended owner-level increment

NEURAL35 does not add "psychedelic theory" to the SRT core. It supplies one perturbational stress test for an already existing distinction:

```text
continued / generative selectability
!= mere option count or lability
```

The owner-level sentence to preserve is:

> **A perturbation can reopen or reshuffle accessible candidates without improving generative reselectability; adaptive revision additionally requires enough anchoring for action, consequence return, historical write-back and later re-entry into choice.**

Claim level: P3 bridge. Any threshold, dose, biomarker or outcome relation remains P4.

## 3. Suggested native synthesis paragraph

> A selection system can fail on both sides of stabilization. Excessive hardening can suppress meaningful re-entry into alternative trajectories, but increased lability does not automatically restore choice. Perturbations that broaden or reorganize candidate accessibility may also weaken the ability to maintain an action-guiding selection long enough for consequences to return and for later revision to become possible. The useful distinction is therefore between reopening and reselectability: reopening concerns which candidates can re-enter competition, whereas generative reselectability additionally requires anchoring, consequence-sensitive write-back and preservation of future re-entry. Psychedelic states provide one possible perturbation domain for testing this distinction, not its definition.

This paragraph is deliberately de-materialized. Do not insert mescaline, cerebellum or psychedelic therapy into a core owner sentence unless the owner section is explicitly empirical.

---

## 4. Empirical anchor wording

If the Cavallaro study is mentioned in a domain evidence paragraph, use a narrow formulation:

> In awake rats, mescaline produced cerebellar-weighted BOLD changes, increased distributed cerebellar functional connectivity and frequency-dependent acoustic gating changes. The pattern is compatible with a reconfigured accessibility / routing regime, but it does not identify sensory gating with selection, reduced BOLD with reduced neural firing, or the cerebellum with a reality-selection center.

Required inheritance:

```text
NEURAL16 measurement reliability
-> mapping stability
-> construct discrimination
```

---

## 5. Under-anchoring guard

`under-anchoring` may be used only as a local P3/P4 label for:

> a state in which candidate accessibility / switching is high relative to the system's ability to stabilize an action-guiding selection for consequence testing and later revision.

It must not become:

```text
new canonical variable
clinical diagnosis
psychosis synonym
psychedelic adverse-event synonym
opposite of L2 by definition
zero-Psi_f state
high-entropy identity
```

If future data do not distinguish it from nonspecific impairment, arousal, sedation or noise, retire the label.

---

## 6. Bearer / context integration rule

Psychedelic set / setting evidence may motivate explicit context declaration in experiments:

```text
bearer history / current physiology
+ social / physical context
+ perturbation
-> measured reopening and re-anchoring trajectory
```

Do not insert `B` or `N` as canonical symbols. Do not redefine `G_hat_theta` from this hook.

The trial-context literature supports reporting and stratification. It does not establish that any particular context variable is constitutive of SRT subjecthood or consciousness.

## 7. Selfhood boundary

If linked to consciousness / subjecthood synthesis, preserve:

```text

!= autobiographical-self loss in every component
!= subject dissolution

```

Use the psychedelic literature as a decomposition pressure only. Any claim that subjecthood literally disappears requires independent admission criteria and cannot be inferred from acute report language alone.

## 8. P4 prediction landing

The flagship test form is:

```text
baseline rigidity / prior dominance
+ independently measured Opening
+ independently measured Reanchoring
+ same-bearer ConsequenceReturn
-> delayed adaptive outcome / future re-entry
```

Primary comparison:

```text
M1: Outcome ~ AcuteIntensity
M2: Outcome ~ StandardFlexibility
M3: Outcome ~ Opening + Reanchoring + Opening*Reanchoring + ConsequenceReturn
```

Primary failure:

```text
M3 adds no out-of-sample prediction after standard flexibility,
expectancy, alliance, reward, salience, arousal and generic learning controls.
```

A second failure:

```text
more destabilization is monotonically better across a well-sampled range
and re-anchoring quality adds no information.
```

Prefer a non-drug perturbation task first so the bridge is not protected by psychedelic-specific complexity.
