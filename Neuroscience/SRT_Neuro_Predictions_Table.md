# SRT Neuroscience Predictions Table

> **Purpose**: Move SRT neuroscience from reinterpretation to differential prediction.  
> **Status**: Experimental bridge / prediction table. It does not establish confirmed results.  
> **Use rule**: Each row should be translated into a validation package before being treated as an empirical claim.

---

## 0. Core distinction

Mainstream theories often explain:

```text
prediction / error reduction;
access / broadcast;
integration;
reward / policy learning;
salience / arousal.
```

SRT adds:

```text
selection friction: Psi_f;
concern weight: d-value;
manifest anchoring: L1;
hardening / hysteresis: L2;
subjecthood threshold: S0-S6;
closure / reopening cost;
future-selectability consequences.
```

SRT should not claim that these replace mainstream variables. The stronger claim is:

> SRT predicts when access, integration, prediction error, reward, or salience are not enough to explain stabilization, persistence, re-opening cost, or downstream life-shaping effects.

## 1. Theory comparison quick map

| Framework | Primary explanatory target | SRT-compatible reading | SRT-specific addition |
|---|---|---|---|
| Predictive Processing / FEP | prediction, inference, free-energy minimization | model update is one selection-cost regime | `d-value`, `Psi_f` layers, L2 hardening, concern-weighted anchoring |
| GNW | access, broadcast, reportability | access is important for conscious content | pre-access candidate selection + post-access hardening |
| IIT | integration / intrinsic causal structure | integration may support field stability | integration is insufficient without concern, boundary, memory, subjecthood threshold |
| RL | reward, value update, policy learning | reward can be one selection signal | `d-value` is not reducible to reward; hardening has hysteresis and non-substitutability |
| Active inference | action-perception loops under expected free energy | useful for embodied selection | SRT asks what becomes manifest, costly, concern-weighted, and hardened |
| Salience / arousal accounts | priority / intensity | salience can modulate selection | salience is not `d-value`; high salience may fail to sediment |

## 3. Case notes

### 3.1 Blindsight

SRT reading:

```text
local processing / action routing can occur without thick L1 anchoring.
```

Differential prediction:

> If blindsight-like processing is given higher `d-value` through bodily relevance or threat context, SRT predicts stronger attempts at anchoring, higher bodily response, or altered confidence patterns even when explicit report remains weak.

Failure condition:

> If access/report variables alone explain all changes, SRT's anchoring/d-value addition should be narrowed.

---

### 3.2 Bistable perception

SRT reading:

```text
perceptual alternatives are candidates in accessible L0; switching requires re-anchoring and pays Psi_f.
```

Differential prediction:

> Meaningful or self-relevant interpretations should show different switch hysteresis from visually matched neutral interpretations.

Proxy:

```text
switch latency;
reversal cost;
subjective effort;
pupil / autonomic response;
post-switch memory.
```

---

### 3.3 Pain

SRT reading:

```text
pain is not only intense sensation; it is concern-weighted anchoring that threatens future selectability.
```

Differential prediction:

> Pain framed as future-threatening should dominate attention and memory more than equally intense but benign pain.

Failure condition:

> If intensity/arousal fully explains dominance and memory, `d-value` contribution should be narrowed.

---

### 3.4 Dreaming

SRT reading:

```text
dreams are temporary internally generated L1 states under weak external correction.
```

Differential prediction:

> High-d dreams should have greater waking carryover than vivid but low-d dreams.

Proxy:

```text
next-day mood;
decision shift;
recall persistence;
physiological arousal;
identity relevance.
```

---

### 3.5 Anesthesia

SRT reading:

```text
anesthesia disrupts the anchoring / integration / re-entry chain needed for thick L1.
```

Differential prediction:

> Some residual processing may persist without producing post-event L2 sedimentation or reportable thick L1.

Failure condition:

> If one integration/access metric fully predicts all state transitions and memory effects, SRT's multi-variable account should be narrowed.

---

### 3.6 Meditation

SRT reading:

```text
meditation trains the relation between candidate arising, d-value assignment, and automatic L2 closure.
```

Differential prediction:

> Training should reduce automatic hardening of intrusive candidates and lower closure friction for non-identification, beyond general relaxation.

Proxy:

```text
intrusion persistence;
emotional recovery;
habit interruption;
attentional flexibility;
identity-fusion ratings.
```

---

### 3.7 Trauma

SRT reading:

```text
trauma is high-d L1 over-hardening into future-constraining L2.
```

Differential prediction:

> Identity and future-selectability impact should predict symptom persistence beyond arousal and event severity.

Proxy:

```text
intrusion;
avoidance;
identity disruption;
felt future narrowing;
physiological reactivity;
reopening cost.
```

---

### 3.8 Addiction

SRT reading:

```text
addiction is an L2 operator short-circuit: locally low-friction execution with globally high reselection cost.
```

Differential prediction:

> Interventions that increase alternative-path selectability should outperform interventions that only reduce cue reward in some cases.

Proxy:

```text
relapse;
choice latency;
alternative path generation;
cue response;
friction to abstain;
automaticity.
```

---

### 3.9 OCD

SRT reading:

```text
OCD involves high-d risk candidates that fail to close; compulsion repeats because closure friction remains high.
```

Differential prediction:

> Subjective closure and re-opening cost should predict checking repetition beyond explicit probability estimates.

Proxy:

```text
number of checks;
closure rating;
relief duration;
re-opening latency;
uncertainty tolerance.
```

---

### 3.10 Social anxiety

SRT reading:

```text
social evaluation becomes high-d because it threatens future social selectability.
```

Differential prediction:

> Social threats framed as future-role narrowing should produce stronger avoidance and memory than equally negative but non-future-narrowing feedback.

Proxy:

```text
avoidance;
rumination;
memory persistence;
body response;
role / status meaning;
future opportunity rating.
```

## 6. SRT should not overclaim

Do not claim:

```text
SRT already explains all neuroscience better than existing theories.
SRT replaces GNW / IIT / FEP / PP.
Every neural selection is consciousness.
Every high-d process is conscious.
Every habit is L2 in the strong sense.
```

Use instead:

```text
SRT adds variables that may explain persistence, concern-weighting, closure cost,
hardening, and future-selectability effects not fully captured by access,
integration, prediction error, reward, or salience alone.
```

---

## 7. Minimal conclusion

SRT neuroscience becomes empirically stronger when it focuses on five discriminations:

```text
d-value != salience / arousal;
Psi_f != prediction error / task difficulty;
L2 hardening != ordinary memory / habit;
conscious anchoring != access / reportability alone;
pathology != only local symptom intensity, but distorted future-selectability and closure dynamics.
```

The first experimental target should be small differential predictions, not a grand theory-of-everything claim.
