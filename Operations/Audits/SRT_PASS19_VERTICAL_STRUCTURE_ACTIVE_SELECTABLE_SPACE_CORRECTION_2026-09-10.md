# Pass 19 correction — vertical structure is active selectable-space construction

## 1. Correction trigger

The author states:

> **「垂直结构并不是历史被动沉淀的结果，而是一种维系、预测、主动发生的可选空间的构建。也即是选择的含义。」**

This corrects a residual machine framing that still treated Selection-generated verticality as a historical deposit that later constrains future states.

## 2. Retired machine framing

Do not use this as the ontological centre:

```text
past Selection
-> passive historical sediment
-> accumulated vertical structure
-> later constraint / observed stability.
```

This can remain only as a downstream descriptive shorthand for traces or records produced by repeated Selection.

## 3. Corrected author-owned direction

The stronger organization is:

```text
Selection
-> active construction of non-flat selectable space
-> maintenance of what remains selectable
-> forward orientation / anticipation of possible continuations
-> active reconstitution as further Selection occurs.
```

Therefore:

```text
vertical structure is not merely what Selection leaves behind;
vertical structure is part of the active organization performed by Selection.
```

This also sharpens the latest first-person correction:

```text
participant-side stability
!= participants repeatedly reproducing a pre-existing structure;
participant-side stability
= participants actively maintaining / predicting / rebuilding the selectable space from within Selection-positions.
```

## 4. Meaning of historical dependence after correction

Historical dependence is retained but demoted from source to consequence:

```text
earlier Selection changes later selectability: YES
vertical structure = passive historical sediment: NO
```

Earlier Selection matters because it actively reorganized the selectable space. The later system inherits an already-organized possibility field, but its continued existence requires renewed Selection rather than inert persistence of a trace.

## 5. Relation to "whole > parts"

The whole-level surplus should no longer be framed mainly as an accumulated constraint topology.

Current candidate:

> **The surplus of the whole consists in a selectable space that the parts, as positioned selective centres, actively co-construct and maintain. This space is forward-oriented: it structures what the participants can anticipate, enter, support, suppress, or reopen in later Selection. Third-person regularity is the external readout of this ongoing construction.**

Thus the explanatory priority is:

```text
active positioned Selection
-> maintained / anticipated shared selectability
-> multi-subject order
-> observer-visible stability
```

not:

```text
objective stable structure
-> participant behavior.
```

The previous VSEL questions must be re-ranked.

A better next pressure family is:


These are machine-side pressure questions only.
