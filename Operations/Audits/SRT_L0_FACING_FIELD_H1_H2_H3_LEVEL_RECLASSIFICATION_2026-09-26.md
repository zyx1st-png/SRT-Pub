# L0-facing field — H1 / H2 / H3 level reclassification

> Role: machine correction after re-entering the 2026-09-09 / 09-10 pre-object-field audit chain.
>
> Boundary: this file does not claim that H3 is an SRT-specific mechanism. It explicitly records that mature structure learning, representation learning, conceptual reorganization and manifold learning already pay functional field-reconstitution roles.

---

## 0. Executive correction

The current three-way framing:

~~~text
H1 distributed local parameter update
H2 latent generative-state / model update
H3 constraint / geometry reconstruction
~~~

is misleading if read as three mutually exclusive rival explanations.

The 2026-09-09 Pass 4 audit already established that mature non-SRT mechanisms can change:
- state partitions;
- effective feature dimensions;
- conceptual similarity structure;
- neural manifold dimensionality;
- relational geometry;
- attractor / dynamical organization.

The 2026-09-10 Simondon pass further established that even:
- preindividual placement;
- operation -> structure -> later operation;
- emergence of new dimensions;
- pre-object field reconstitution

are not safe SRT-specific residuals.

Therefore:

> **Geometry reconstruction is a system-level consequence that can be implemented by distributed parameter changes and mediated by latent-state / representation learning.**

H1, H2 and H3 should be reclassified by level.

---

## 1. Corrected level map

### H1 — realization / implementation level

Examples:
- synaptic weights;
- gains;
- thresholds;
- coupling strengths;
- plasticity rules;
- local recurrent parameters;
- constraint strengths;
- body-state / sensory coupling parameters.

Question:

> What physical / computational changes carry the history?

H1 may be distributed and highly nonlinear.

H1 alone does not tell us whether the resulting organization is best described as:
- one latent state;
- a changed representation;
- a changed geometry;
- or several independent local updates.

---

### H2 — model / representation / state-organization level

Examples:
- latent causes;
- learned task states;
- generative-model variables;
- concept organization;
- learned feature basis;
- low-dimensional task manifold;
- context state;
- learned policy / value representation.

Question:

> What internal state / representation organizes the effects of H1?

H2 can itself change:
- dimensionality;
- partitions;
- category boundaries;
- similarity relations;
- state availability.

Therefore:

~~~text
latent-state update
!= fixed state-space reweighting by definition.
~~~

A sufficiently rich H2 model can realize substantial H3 geometry change.

---

### H3 — effective field / reachability-geometry level

Examples of observable / inferable consequences:
- changed equivalence classes;
- changed boundary placement;
- changed neighborhood relations;
- changed transition reachability;
- changed perturbation stability;
- changed spontaneous grouping;
- changed object / event / category formation;
- changed cross-context generalization.

Question:

> What changed in the system's effective space of possible differentiation / continuation?

H3 is therefore a **level of consequence / organization**, not automatically a separate mechanism.

---

## 2. Why this matters

Without the level correction, a false discriminator appears:

~~~text
latent model update
vs
geometry reconstruction
~~~

But in mature learning systems:

~~~text
distributed parameter update [H1]
-> learned latent / representational organization [H2]
-> changed effective geometry [H3]
~~~

can all describe the same process at different grains.

Therefore an experiment showing H3 does not by itself falsify H1 or H2.

Likewise, fitting an H2 model does not prove that H3 is explanatorily dispensable.

The correct question is whether the H3 description adds:
- compression;
- prediction;
- causal intervention targets;
- cross-domain invariants;
- or recursion structure

beyond a sufficiently rich H1/H2 model.

~~~text

-> state partition changes
~~~

## 5. The L0-facing field should now be treated as a cross-level target

Current safest neutral reading:

> **L0-facing field = the whole-system effective organization of differential future reachability / differentiability, induced by but not identical to any one implementation variable or latent-state description.**

This is a target of explanation.

It is not yet:
- an independent substance;
- a neural object;
- a new primitive;
- a canonical SRT owner.

### Cross-level mapping

~~~text
H1 implementation / constraints
    |
    v
H2 latent / representational organization
    |
    v
H3 effective reachability / differentiability geometry
    |
    v
local objectification / action / judgment
    |
    v
consequence / history
    |
    +----> H1 / H2 / H3 reconstitution
~~~

This is recursive, not temporally rigid.

## 6. Four evidence grades for a whole-field claim

The current programme should not jump from "geometry changed" to "whole field exists."

Use four grades.

### E1 — descriptive geometry

Evidence:
- RSA / manifold / dimensionality / similarity geometry differs by history or context.

Supports:

~~~text
measured representation changed.
~~~

Does not establish:
- whole-field unity;
- causal relevance;
- recursion;
- L0-facing interpretation.

Examples:
- category-learning representational stretching;
- conceptual reorganization;
- PFC geometry changes across learning.

### E2 — predictive geometry

Require H3-level structure to predict held-out:
- grouping;
- category boundaries;
- transition choices;
- objectification;
- generalization;
- anomaly detection

better than strong local-feature and latent-state baselines.

Supports:

~~~text
geometry is not merely descriptive;
it carries prospective information about later differentiation.
~~~

Still not causal.

### E3 — causal geometry

Intervene on a field-relevant global condition or network organization and show coordinated changes across multiple otherwise matched local readouts.

Required pattern:

~~~text
intervention
-> structured geometry change
-> multi-readout objectification / transition change
~~~

with local item statistics / explicit knowledge controlled.

This supports a causal organizational role.

### E4 — recursive field reconstitution

Strongest neutral target:

~~~text
history / consequence
-> measurable geometry change
-> that geometry mediates later recutting / objectification
-> new local actualisations feed back
-> later geometry changes again.
~~~

E4 is the first grade that strongly matches the author's current whole-field intuition.

Even E4 would not establish primitive Selection or SRT ontology.

---

## 7. Strong absorption rule

A whole-field construct earns no extra scientific role if a strong H2 model:

1. captures the same H3 geometry;
2. predicts the same held-out local objectifications;
3. survives the same interventions;
4. accounts for recursive update;
5. does so without an extra field-level variable or loss of explanatory clarity.

Then:

~~~text
field language = translation / visualization / integration layer
scientific increment = ZERO
~~~

This result must be allowed.

Conversely, H3 becomes independently useful only if it supplies a stable, cross-readout organizational variable or operator that:
- compresses many H1/H2 changes;
- predicts novel local outcomes;
- supports intervention;
- and recurs across reconstitution.

---

## 8. Strongest current discriminator is not "geometry changed"

The critical difference should be:

~~~text
ordinary representation update
vs
whole-field coordinated recutting
~~~

but this phrase must be operationalized.

Candidate neutral criterion:

> After a declared history manipulation, does one low-dimensional / structured change in effective geometry jointly explain changes in multiple local equivalence, grouping, transition and objectification probes better than independent local updates and strong latent-state models?

This is testable.

But it remains compatible with:
- representation learning;
- active inference;
- enactivism;
- constraint closure.

Therefore it is a cognition discriminator, not an SRT novelty discriminator.

## 9. Revised CN-2 architecture

CN-2 should now compare explanations by level.

For every experiment specify:

### Implementation account
What H1 variables change?

### Latent / representational account
What H2 state or representation changes?

### Field / geometry account
What H3 whole-system geometry changes?

### Reduction test
Can H3 be fully reconstructed from H1/H2 with no loss?

### Increment test
Does an H3 variable / operator add held-out prediction or causal leverage?

### Recursive test
Does consequence-induced H3 change predict the next round of objectification?

### SRT mapping
Only after all above:
which SRT roles, if any, map onto the neutral result?

No ontology conclusion follows automatically.

---

## 10. Exact next research target

Do not search for a phenomenon where geometry merely changes.

Search for a design where one history / consequence manipulation causes a coordinated reorganization across several different local probes while:

- current local stimuli are matched;
- explicit rule knowledge is matched;
- local transition frequencies are matched where feasible;
- a strong latent-state / generative-model baseline is fitted;
- the same inferred H3 geometry predicts held-out objectification / grouping / transition outcomes.

Candidate domains:
- category recutting under changed consequence structure;
- context-dependent event segmentation;
- affordance-field reorganization;
- learned task geometry with transfer to novel stimuli;
- theory-shape / conceptual recutting as a downstream assay.

Preferred first formal question:

> **Is there a common geometry transformation that explains multiple recutting effects better than task-specific local updates or a single fitted latent-state label?**

This is the next valid neutral target.
