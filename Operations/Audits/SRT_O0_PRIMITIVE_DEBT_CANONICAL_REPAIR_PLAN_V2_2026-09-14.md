# O0 primitive-debt canonical repair plan v2

Planning only. No canonical edit is authorized.

## Controlling rule

Primitive generativity carries two co-primitive burdens: non-maximal indifference and actualising Selection. Neither is temporally or causally prior. Primitive orientation is not goal, value, probability, or continuation preference. Primitive openness is not an inventory of formed possibilities.

## Primary semantic scope

The first future repair must cover five semantic owners together:

1. `Core_Law/SRT_L0_Metaphysics.md`
2. `Core/SRT_Core_01_Axioms.md`
3. `Core/SRT_Core_12a_Ontology_L0L1.md`
4. `Governance/SRT_CLAIM_LADDER.md §0A`
5. `_SRT_T_DIR_CANONICAL.md`

### L0 metaphysics

Keep subjectless Selection, finite event indexing, actual occurrence / anchoring / Stable ISP separation, irreversibility separation, and non-pregiven time. Rewrite latent-field language so potentiality is a modal reading of generativity rather than a primitive container. Retype intrinsic granularity and `κ0` as stronger formal commitments rather than the definition of minimum O0.

### Core 01

Remove primitive proof-load from the old strong epsilon theorem: no `B>=2` over `B<=1` primitive ranking, no primitive continuation preference, and no use of `ε_pg` as the automatic ground of universal value direction. Do not silently redefine `ε_pg` as O0. Repair `MA-1` so the metaphysical minimum comes from the accepted G0 structure rather than `κ0` as a prior formal ground.

### Core 12a

Keep `κ0` only at independently justified formal strength. It may remain an anisotropic realization candidate, but it must not define or sufficiently ground G0, and its cost geometry must not be read as primitive value or continuation ranking. Its necessity relative to G0 remains OPEN.

### Claim Ladder §0A

Keep the contentless-structural boundary. Change Gate 0 from a named ontology-membership registry into a type filter. Remove governance protection of the old epsilon branch ranking. Named quantities obtain their status from their actual owners, not from Gate 0 examples.

### T_dir

Keep the operational readability / reorientation core. Re-anchor T_dir to an independently established local direction reference. The reference is an argument role, not a new universal field. T_dir may measure access to a direction; it may not prove that universal value or an order-direction exists in every Selection.

## Synchronization surfaces

After semantic edits, synchronize only as reflections of owner meaning:

- `_SRT_SYMBOL_TABLE.md`
- `_SRT_CROSS_DOMAIN_MATRIX.md`
- `CANONICAL_REGISTRY.md`
- split mirrors and generated context/index files required by governance

## Non-targets

Do not broaden the first repair into One, Stable ISP, Bearer, Concern, responsibility, all-things-considered ethics, B13 generative health, politics, or empirical bridges. Do not reopen former P1-T07 unless a direct current contradiction is found.

## Merge invariant if later authorized

At one merge point, main must satisfy all five conditions: L0 carries G0; Core 01 no longer carries strong primitive epsilon; Core 12a no longer back-defines G0 through `κ0`; Gate 0 no longer protects the old epsilon ranking; T_dir no longer proves universal embedded value.

## Acceptance tests

- no possibility-container reification
- modal openness preserved
- O0 and S0 distinct but non-sequential
- no primitive `B>=2 > B<=1` theorem remains
- `ε_pg` is not silently renamed O0
- `κ0` is not silently deleted and does not define G0
- Gate 0 remains governance rather than ontology owner
- T_dir keeps operational usefulness without universal-value proof-load
- O1 / O2-C are not imported backward into L0
- terminal Selection remains genuine
- One / Bearer / Agency definitions remain untouched
- ST-A / B13 hardening remains intact
- registries reflect owners only

The author gate is closed. Primitive theory expansion has reached a stop condition. The next step is a final pre-landing review of this five-owner scope. Canonical edits remain unauthorized.
