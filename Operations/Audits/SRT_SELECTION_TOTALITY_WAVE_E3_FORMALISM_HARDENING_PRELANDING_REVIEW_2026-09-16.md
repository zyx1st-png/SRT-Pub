# E3-A findings — L1 Formalism

## F1. File-level claim strength is too high

The file remains `claim_level: P1-candidate` and says most equation structures are P1-candidate except selected model branches. After D3/E1/E2 this is too strong.

The file should become a bounded conditional formal/model hub. Formal closure does not establish ontology, subjecthood, suffering, health or direction.

## F2. sigma dynamics still re-import old subject / consciousness thresholds

Current text still treats:

```text
sigma_self = self-consciousness condensation threshold
chi jump = second-order self-consciousness writeback
T-IND-3 second phase transition
sigma -> 1 = pathological attractor
```

as theorem-like structural dynamics.

Current owner truth is:

```text
sigma_sr = P2 model-local / replaceable coordinate
sigma_sub/self = P3/P4 model coordinates unless calibrated
exact subject sufficiency = OPEN
self-consciousness-as-condensate = P2 interpretation only
```

Therefore sigma ODEs may remain as declared model candidates, but cannot carry universal subject / self-consciousness phase transitions or natural pathology thresholds.

## F3. old P1-T02 time / writeback inheritance remains

Symbol table still says:

```text

```

E1 removed this inheritance. P1-T02 only owns occurrence non-equivalence; retained writeback / history requires retained efficacy.

`w(t)` may remain as a declared model writeback parameter, but not as a universal P1-T02 consequence.

## F4. d_c / d_narrow still act as natural health-pathology coordinates

Formalism must inherit that typing.
