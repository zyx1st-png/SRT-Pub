# GRG Civilizational false-convergence audit — Pass 1

## 0. Question

Can the first three civilizational cases be compressed into one GRG relation without erasing source-native mechanisms?

Cases:

~~~text
CIV-001 Internet standards / interoperability
CIV-002 antimicrobial resistance
CIV-003 Montreal Protocol / ozone recovery
~~~

## 1. Result

~~~text
ONE-RELATION COMPRESSION = FAIL

X3 externalized generative expectation:
  CIV-001 = candidate support
  CIV-003 = candidate support
  CIV-002 = DO NOT MAP AS PRIMARY X3

X4 present success -> future-option reconstruction / depletion:
  CIV-002 = candidate support
  CIV-003 = secondary possible mapping
  CIV-001 = not primary
~~~

This is a positive constraint result.

The first civilizational pass does not yield one universal relation.

## 2. CIV-001 and CIV-003 — real structural overlap

Both cases contain:

~~~text
multiple relatively autonomous participants
-> explicit external representation of expected future behavior
-> distributed adoption / implementation
-> changed compatibility or environmental trajectory
-> feedback / review / revision
~~~

This overlap is stronger than shared vocabulary.

A pre-existing document / rule changes what later participant action counts as compatible with the relation.

Candidate burden:

~~~text
X3 — externalized generative expectation
~~~

However the mechanisms differ materially.

### CIV-001

~~~text
expectation carrier = technical specification / protocol
maintenance = implementation, interoperability, review, operational use
adoption provenance = largely voluntary / ecosystem dependent
primary consequence = technical compatibility / interoperability
~~~

### CIV-003

~~~text
expectation carrier = treaty commitments / controlled-substance schedules
maintenance = domestic implementation, reporting, scientific panels,
              technology/economic assessment, institutional revision
adoption provenance = international legal commitment
primary consequence = production/consumption change + environmental trajectory
~~~

Therefore:

~~~text
shared GRG burden
!= same institution
!= same enforcement
!= same evidence
!= same normative standing
~~~

## 3. New framework dimension: expectation embodiment / enforcement provenance

Pass 1 exposes a missing declaration.

For any externalized generative expectation, record how it becomes operative.

Provisional provenance types:

~~~text
P-TECH  technical interface / compatibility constraint
P-LEGAL legal / treaty obligation
P-MKT   market / price / contract incentive
P-ORG   organizational procedure / hierarchy
P-NORM  social norm / reputational enforcement
P-INFRA material / infrastructural constraint
P-MIXED mixed provenance
~~~

These are programme routing labels only.

They should not be treated as equivalent causal mechanisms.

## 4. CIV-002 — reject false X3 assimilation

AMR also involves expectations, guidelines and institutions, but its primary source-native relation in this pass is not an externalized rule system.

The central mechanism is:

~~~text
antimicrobial use
-> biological selective environment
-> changing resistant-pathogen prevalence
-> altered future treatment effectiveness
~~~

Therefore CIV-002 is better routed to:

~~~text
X4 — current intervention reconstructs future option conditions
~~~

This matters because forcing CIV-002 into X3 would hide the biological mechanism and make "expectation" so broad that any policy context qualified.

## 5. New framework dimension: consequence horizon / position split

CIV-002 also pressures the civilizational schema to keep:

~~~text
immediate local benefit
!=
population-level long-horizon consequence
~~~

Mandatory comparison fields for future cases:

- immediate beneficiary position;
- delayed affected position;
- local versus distributed consequence;
- time horizon;
- externalized cost;
- whether future option loss is reversible.

This dimension is relevant to many civilizational systems but must not be assumed universal.

## 6. Montreal is genuinely multi-relation

CIV-003 plausibly pays more than one burden:

~~~text
X3 externalized expectation
+
X4 future-condition reconstruction
+
G11 reflexive grammar learning
~~~

This is not a reason to call it "more GRG".

It means one historical case can instantiate several independently testable relations.

The framework must support many-to-many mapping:

~~~text
one case -> multiple candidate relations
one relation -> multiple heterogeneous cases
~~~

## 7. Normativity pressure

The three cases also show why functional normativity must remain indexed.

### Internet standards

Conformance can be evaluated relative to interoperability.

### AMR

Current treatment benefit can conflict with future population-level treatment effectiveness.

### Montreal Protocol

Implementation can be evaluated relative to ozone-protection goals.

None of these functional comparisons settles:

- distributive justice;
- rights;
- legitimacy;
- political priority;
- moral worth.

Therefore:

~~~text
functional generative expectation
!= full moral ought
~~~

survives the first civilizational pass.

## 8. Framework revision earned

The first three cases earn two concrete additions to GRG method:

### R-CIV-1 — expectation embodiment provenance

Externalized expectations must state how they become causally operative.

### R-CIV-2 — position / horizon consequence split

A case must distinguish current local payoff from distributed later consequence when the relation crosses positions or timescales.

These are framework-method revisions, not canonical ontology additions.
