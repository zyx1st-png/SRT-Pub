# Minimal property genesis test — graspability without presupposing an object

> Goal: test whether an actively formed relational bridge can become a reusable property before a stable object representation is assumed. This is a conceptual pressure test, not an experiment and not a canonical definition.

## 0. Hard anti-smuggling constraints

The starting system is NOT allowed to contain:

~~~text
object token
object identity
object boundary
property label
'cup' concept
graspability flag
predefined affordance class
complete state-space inventory
~~~

Allowed at the start:

- changing sensory input;
- proprioceptive / body state;
- available actions;
- contact / resistance / movement feedback;
- short history;
- differential relevance / task or viability pressure where declared.

The point is to see whether a reusable relation can earn the role of a property from trajectories alone.

---

## 1. Stage P0 — undivided sensorimotor variation

At P0 there is only changing coupling:

~~~text
sensory pattern_t
+ body state_t
+ action_t
-> sensory/body consequences_t+1
~~~

No statement such as:

~~~text
'this is one object'
or
'this thing is graspable'
~~~

is available.

Important:

A local sensory patch may recur, but recurrence alone is not objecthood.

---

## 2. Stage P1 — active traversal creates a candidate relation

The system acts.

Example:

~~~text
move hand toward region
-> contact
-> close fingers
-> change force
-> external sensory pattern begins to co-move with hand
~~~

The key event is not success in one trial.

It is that action creates an experienced transformation connecting otherwise separate sensorimotor states.

Candidate bridge episode:

~~~text
before contact
<-> approach / close / force
<-> stable contact / co-movement
~~~

This is the first place where an active bridge can exist.

Still:

~~~text
one successful episode
!= property
!= Gate bridge
!= object
~~~

---

## 3. Stage P2 — recurrence under variation

Now vary:
- angle;
- distance;
- hand pose;
- approach path;
- moderate perturbation;
- sensory appearance.

If some structure repeatedly survives:

~~~text
certain body-environment relation
+ suitable action family
-> stable controllable coupling
~~~

then the system has more than a memorized trajectory.

The important invariant is not a visual shape by itself.

It is a relation:

> **under a family of changing states, there exists a reproducible way of entering and maintaining controllable coupling.**

This is close to mature affordance theory and learning, so it is not an SRT novelty claim.

---

## 4. Stage P3 — when does the relation become a property?

Proposed minimum criterion:

A bridge earns **property-candidate** status only when all four conditions hold.

### P3.1 Cross-instance compression

Several distinct trajectories can be treated as realizations of the same reusable relation.

### P3.2 Prospective use

The relation can guide a new attempt before the full action is executed.

### P3.3 Perturbation tolerance

The relation remains useful under a declared range of changes.

### P3.4 Counterfactual control value

If the bridge were unavailable or wrong, later action / prediction would measurably differ.

Then:

~~~text
repeated active bridge
+ compression
+ prospective reuse
+ robustness
+ future efficacy
-> property candidate
~~~

This is stronger than mere correlation.

---

## 5. 'Graspable' as relational property, not intrinsic feature

Under this test:

~~~text
graspable
!= property contained inside a pre-given object
~~~

Instead:

~~~text
graspable
= compressed summary of a stabilized
  body-world-action relation
  that can be prospectively reused
~~~

The same environmental structure may be graspable for one body configuration and not another.

Therefore graspability is naturally relational.

This matches mature affordance accounts and does not establish SRT distinctiveness.

Representative sources:
- Bonaiuto & Arbib 2015, *Learning to grasp and extract affordances*, Biological Cybernetics 109:639–669. DOI 10.1007/s00422-015-0666-2.
- Vilarroya 2014, *Sensorimotor event: an approach to the dynamic, embodied, and embedded nature of sensorimotor cognition*, Frontiers in Human Neuroscience 7:912. DOI 10.3389/fnhum.2013.00912.

---

## 6. Critical transition — property before object

The property-before-object thesis survives this toy case if:

~~~text
the system can reuse 'graspable-like' bridge structure
across episodes
before it has a stable identity representation
for the external source of those episodes.
~~~

In plain terms:

> The system may first know how to enter a stable relation, before it knows what enduring thing the relation belongs to.

This is compatible with developmental evidence that object individuation and later property / kind use can dissociate, so object cognition should not be treated as one undifferentiated capacity.

Representative sources:
- Croteau, Cheries & Xu 2026, *The development of kind concepts: Insights from object individuation*, Psychological Review 133(1):134–155. DOI 10.1037/rev0000527.
- Xu 1999, *Object individuation and object identity in infancy: the role of spatiotemporal information, object property information, and language*, Acta Psychologica 102(2–3):113–136.
- Leslie, Xu, Tremoulet & Scholl 1998, *Indexing and the object concept: developing 'what' and 'where' systems*, Trends in Cognitive Sciences 2(1):10–18. DOI 10.1016/S1364-6613(97)01113-3.

---

## 7. But graspability alone does not generate an object

One property is not enough.

Why?

Because the same graspable relation may be realized by many different external configurations.

Therefore:

~~~text
graspable bridge
-/> unique object identity
~~~

To move toward objecthood, additional bridges must become mutually predictive.

Candidate examples:
- shape continuity across viewpoint change;
- common motion under manipulation;
- persistence through temporary occlusion;
- resistance / weight regularity;
- spatial boundary regularity;
- repeated action consequences returning to the same local trajectory.

---

## 8. Stage O1 — bridge co-reinstantiation

Suppose several independently learned bridges repeatedly reappear together:

~~~text
view-change bridge
+ grasp bridge
+ common-motion bridge
+ resistance bridge
+ occlusion-return bridge
~~~

At first they can remain separate skills / regularities.

But if their co-occurrence becomes highly predictive, representing them separately becomes inefficient.

Then a new compression becomes useful:

~~~text
one persistent relational locus
that predicts the joint reappearance
of multiple bridges
~~~

This is the first **proto-object node** candidate.

Important:

The proto-object node is not assumed at P0.
It is introduced only after relational closure provides compression / prediction benefit.

---

## 9. Stage O2 — relational closure criterion for object candidate

A stronger object candidate requires at least:

### O2.1 Multi-bridge coherence
Several properties / bridges reinstantiate together.

### O2.2 Transformation continuity
They remain linked across changes in viewpoint / position / action.

### O2.3 Boundary usefulness
Treating some changes as internal to the same locus and others as external improves prediction / action.

### O2.4 Re-entry
After interruption / occlusion / release, the bridge network can be reinstantiated as a continuation rather than rebuilt from zero.

### O2.5 Joint counterfactual load
Changing the proposed object node changes predictions across multiple bridges at once.

Only then does an object-level compression earn explanatory work.

Working chain:

~~~text
active bridge
-> reusable property
-> several properties co-reinstantiate
-> relational closure
-> proto-object node
-> stable objectification
~~~

---

## 10. Object identity as compression of bridge dependence

Current machine candidate:

> **An object is introduced when treating several actively stabilized relations as belonging to one continuing locus compresses and improves prediction / control better than treating them as independent bridges.**

This avoids:

~~~text
object first
-> properties attached later
~~~

and also avoids:

~~~text
any stable relation
-> object
~~~

Objecthood requires closure across several relations.

---

## 11. Gate interpretation

This toy case gives a clearer multiscale Gate picture.

### Gate genesis

~~~text
active sampling / coupling
-> robust reusable relation
~~~

### Property-level Gate

~~~text
bridge compression
-> 'graspable-like' invariant
-> biases later candidate actions
~~~

### Object-level Gate

~~~text
multiple bridges close around one persistent locus
-> object node
-> later perception / action is pre-structured by that node
~~~

### Current pass/suppress use

~~~text
formed bridge / object structure
-> some live actions become easy / admissible
-> others suppressed / irrelevant
~~~

This supports, but does not prove, the hypothesis that valve-like gating can be the short-timescale use of earlier actively formed relational infrastructure.

---

## 12. Content -> control consequence

Now return to the conscious target:

> “拿起杯子。”

If mature 'cup' objectification is a compression of many actively formed bridge relations, then activating the target need not transmit a detailed motor script.

Instead:

~~~text
foreground 'cup / pick up'
-> reinstate object-level relational closure
-> selectively activate grasp / reach / orientation / feedback bridges
-> lower candidate geometry changes
-> distributed action unfolds
~~~

This gives a concrete mechanism candidate for:

~~~text
content
-> structural constraint
~~~

without content = motor program.

---

## 13. Hardest failure modes

The route fails or must split if:

### F1
A property cannot be reused before an object identity variable is already present.

### F2
Graspability is fully explained as direct feature-to-policy mapping and no reusable relational bridge adds compression / transfer.

### F3
Multiple properties do not benefit from a common object-level closure variable.

### F4
The same formal 'Gate' operation cannot nontrivially describe bridge formation and later pass / suppress use.

### F5
Active exploration adds only more data, not a different relational organization.

### F6
Property / object structure has no future causal role beyond retrospective labeling.

---

## 14. Strong mature-neighbor pressure

This architecture overlaps heavily with existing work:

- affordances as relations between situation features and agent abilities — Vilarroya 2014, DOI 10.3389/fnhum.2013.00912;
- learned grasp affordances and motor parameters through trial-and-error — Bonaiuto & Arbib 2015, DOI 10.1007/s00422-015-0666-2;
- active exploration and manipulation as a route to affordance / causal learning in robotics — Bohg et al.-style active manipulation line; see the 2022 Frontiers in Robotics and AI review, PMID 35865329;
- object individuation as separable from later property / kind identification — Croteau, Cheries & Xu 2026, DOI 10.1037/rev0000527; Leslie et al. 1998, DOI 10.1016/S1364-6613(97)01113-3;
- action affordance depending on attended action-relevant properties, not every visible property — Tipper, Paul & Hayes 2006, DOI 10.3758/BF03193875.

Therefore the current value is integration / generative ordering, not established novelty.

## 16. Revised next pressure test

The next clean question is:

> **What is the minimal closure operation that turns several independently useful properties into one object without simply postulating an object identity token?**

Candidate comparison cases:

~~~text
A. same graspability, different shape / motion
B. same shape, different graspability
C. multiple properties that always co-reinstantiate
D. properties that sometimes split and recombine
~~~

This should reveal whether 'object' is:
- a compression node;
- a boundary / closure operation;
- a prediction-control convenience;
- or something stronger still required by SRT.
