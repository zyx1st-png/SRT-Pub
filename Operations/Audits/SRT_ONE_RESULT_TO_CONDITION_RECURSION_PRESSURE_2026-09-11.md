# One onset — Selection result becoming later Selection condition

## 1. Author-side anchor

The author has already ruled:

> `结构也只是选择的一种成绩。`

and later clarified:

```text
Selection history changes the pre-object vertical relational field;
that changed field conditions later vertical generation / Selection-position reconstitution.
```

This suggests a more compact formulation of the One-onset candidate.

## 2. Ordinary causal chain is too weak

Do not infer:

```text
x_t causes x_(t+1)
-> One.
```

Any dynamical system can satisfy that.

Likewise:

```text
past affects future
-> One
```

is too weak.

## 3. Stronger relation — result-to-condition recursion

Machine-side candidate:

```text
Selection S_t
-> produces / achieves local vertical organization V_t;

V_t
-> materially becomes part of the conditions from which later Selection S_(t+1) occurs;

S_(t+1)
-> reconstitutes / transforms local vertical organization V_(t+1);

V_(t+1)
-> again conditions later Selection.
```

Compact shape:

```text
Selection result
-> later Selection condition
-> new Selection result
-> later Selection condition
-> ...
```

When this recursion is localized to a lineage-sensitive vertical process, it is a stronger One-onset candidate than generic causal continuity.

## 4. Why this matches the current One / Selection-position repartition

The same cycle supports both relations:

```text
One
= the continuing localized process-unit across result-to-condition reconstitution;

Selection-position
= the current vertical result insofar as it functions as the operative condition / from-where for later Selection.
```

Thus Selection-position is not a second entity added after One; it is the time-local operational phase of the continuing vertical process.

## 5. One onset versus One stability

Minimal onset candidate:

```text
S_t -> V_t -> conditions S_(t+1) -> V_(t+1)
```

where `V_(t+1)` is genuinely reconstituted relative to the same local lineage and is again an operative Selection condition.

Stability thereafter is graded:

```text
more recurrence;
more perturbation tolerance;
more component replacement tolerance;
stronger lineage-specific regeneration;
more robust continuation under active reconstruction.
```

No fixed scalar threshold is introduced.

## 6. Multiple-One consequence

Multiple Ones require multiple distinguishable result-to-condition recursions:

```text
S_A -> V_A -> later S_A-like reconstitution loop;
S_B -> V_B -> later S_B-like reconstitution loop;
```

with relative continuation separability between the lineages.

This is stronger than multiple peaks because a peak can be merely a current result of one global pattern without being a lineage-specific later Selection condition.

## 7. Bearer guard

Result-to-condition recursion is still thinner than Bearer closure.

```text
One / position recursion:
Selection-produced vertical organization conditions later Selection;

Bearer recursion:
consequences generated from the position return to / become own-history of the organization
that must reconstitute the later position.
```

Therefore:

```text
result-to-condition recursion
!= consequence ownership.
```

## 8. Relation to active Selection

Once the result-to-condition loop exists:

```text
passive continuation-oriented Selection
= mainly uses / repairs the inherited vertical condition;

active Selection
= reconstructs the organization that determines what can become a later Selection condition.
```

This connects the One architecture directly to the author-confirmed active/passive distinction without making active Selection necessary for minimal One onset.

## 9. Mature-neighbor guard

Operation -> structure -> later operation, recursive organization and process continuity are already strongly neighbor-paid in Simondon, Luhmann, autonomy / autopoiesis and generic dynamical systems.

Therefore this relation is retained as an SRT architectural organization, not a local novelty claim.

The SRT-specific role currently under reconstruction is how this recursion is typed through:

```text
subjectless Selection
+
vertical manifestation / relative-background organization
+
lineage-relative One / Selection-position formation.
```

No distinctiveness verdict follows.
