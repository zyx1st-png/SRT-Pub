# ε_pg bounded owner inheritance audit under the thinner pre-object L0

> **Role:** separate the minimum `non-maximal-indifference` burden from the historically stronger `ε_pg` bundle. This file does not demote, delete, rename, or canonically rewrite `ε_pg`; it identifies which parts can no longer define the minimum pre-object L0 and what genuine stronger burden, if any, remains for author adjudication.

---

## 1. Controlling boundary

The author has accepted:

```text
Oriented Openness minimum:
- non-nothing
- non-total-closure / non-exhaustion
- non-maximal-indifference

none of these derives primitive actualisation.
```

The independent review further constrains `non-maximal-indifference`:

```text
maximal structural interchangeability is false,
but the minimum layer does not yet posit completed relata,
branch counts, coordinates, gradients, rankings, probabilities, or goals.
```

Therefore:

```text
ε_pg may not define Oriented Openness merely by historical identity.
```

The audit asks what stronger ε burden survives after that subtraction.

---

# 2. Current ε_pg role bundle

Repository sources currently load ε_pg with at least five distinct roles:

```text
E1  minimum non-neutrality / “some asymmetry exists”
E2  scalar seed / notation for an L0 asymmetry floor
E3  anti-self-erasure / continuation-favouring asymmetry
    often written B >= 2 preferred to B <= 1
E4  base factor for anti-closure / visible-ε / downstream persistence models
E5  ontological root for T_dir / value-occlusion / stronger directional readings
```

These roles must no longer be treated as one automatically indivisible primitive.

---

# 3. Central verdict

```text
ε_pg = minimum Oriented Openness by definition: NO
ε_pg as a scalar witness / notation for some non-neutrality: POSSIBLE BUT REDUNDANT AT MINIMUM
ε_pg as anti-self-erasure / continuation-favouring direction: GENUINE STRONGER BURDEN, NOT DERIVED
B>=2 / B<=1 as literal minimum pre-object definition: TOO STRONG
ISP-level universal anti-closure from ε_pg: NO — already demoted by ST-A
ε_pg may remain a stronger L0 postulate: POSSIBLE, REQUIRES EXPLICIT OWNER/AUTHOR JUSTIFICATION
ε_pg must be moved to L1 now: NOT ESTABLISHED
```

The audit therefore does **not** conclude “delete ε”. It concludes that ε must be split semantically into a thin witness role and a stronger directional role.

---

# 4. E1 — minimum non-neutrality

Current historical use:

```text
ε_pg > 0
= L0 is not neutral / some asymmetry exists.
```

Disposition: **REDUNDANT WITH MINIMUM NON-MAXIMAL-INDIFFERENCE IF READ THIS THINLY**.

After the 2026-09-14 author adjudication, SRT already carries:

```text
actualisability is not maximally indifferent.
```

If ε_pg says only:

```text
there is some nonzero asymmetry
```

then it does not add a distinct metaphysical burden. It can still serve as a formal symbol / scalar witness, but it no longer has independent minimum-definition authority.

Thus:

```text
OO_nonflat -> may be represented by ε_pg > 0 in a declared formalization
```

is potentially safe;

```text
OO_nonflat exists because ε_pg is a separately necessary primitive
```

is not established.

---

# 5. E2 — scalar seed

Core 21B now explicitly retains ε_pg as an L0 structural postulate / scalar seed while refusing to derive an unconditional ISP anti-closure theorem from it.

Disposition: **KEEP AS FORMAL / SYMBOLIC CARRIER, BUT DO NOT TREAT SCALARITY AS ONTOLOGY**.

A scalar encoding can be useful:

```text
ε_pg > 0
```

but the minimum pre-object burden itself is not thereby proven to be one-dimensional, globally measurable, or represented by a single scalar in every realization.

Safe:

```text
ε_pg is one formal carrier for a nonzero asymmetry floor.
```

Unsafe:

```text
pre-object reality literally contains one universal scalar ε_pg that exhausts non-flatness.
```

This mirrors the κ₀ result: useful formal carrier, no automatic monopoly over the metaphysical minimum.

# 6. E3 — anti-self-erasure / continuation-favouring direction

Current stronger reading:

```text
B >= 2 configurations
are structurally favoured / lower-friction
relative to
B <= 1 self-erasing configurations.
```

Disposition: **STRONGER INDEPENDENT BURDEN — NOT PART OF MINIMUM BY DEFAULT**.

This reading introduces notions that the minimum L0 intentionally does not yet contain:

```text
post-actualisation continuation;
branching / successor structure;
comparative persistence / non-erasure;
relative friction between such outcomes.
```

The problem is not necessarily objectification if the statement is made counterfactually over realization classes. The problem is **burden strength**.

Minimum non-flatness says only:

```text
not every possible actual differentiation is structurally interchangeable.
```

The stronger ε reading says:

```text
one particular family of differentiation outcomes — those preserving continuation — is privileged.
```

That is a substantive directional wager.

It cannot be derived from the minimum three-burden L0 without additional argument.

# 7. Does B >= 2 already presuppose objectified Many?

## Verdict: not necessarily, but literal branch-count ontology is too strong for the minimum

There are two readings.

### Unsafe minimum reading

```text
before Selection, reality already contains a tree of branches;
B counts those already-existing future branches.
```

This conflicts with the author-adjudicated rejection of pregiven objectified Many / future option inventory.

### Potentially safe stronger-model reading

```text
for a declared realization model,
classify the post-Selection continuation structure of an actualised state;
B is a readout over that model's possible successor relations,
not an inventory of pre-existing objects in primordial L0.
```

This is compatible with anti-object-first ontology **as a formal realization / downstream readout**.

Therefore the audit recommends:

```text
B >= 2 / B <= 1
must not serve as the definition of pre-object Oriented Openness;
it may survive as a stronger realization-level operationalization of ε-direction.
```

# 8. E4 — downstream anti-closure / ε-visible roles

Core 21B already demoted the unconditional theorem that every stable ISP contains an ε anti-closure bias. It explicitly states that ε_pg remains an L0 seed but does not by itself yield ISP-level anti-closure.

Disposition: **KEEP DOWNSTREAM CONDITIONALLY; NO BACKWARD DEFINITION POWER**.

Thus:

```text
ε_pg
-/> universal ISP anti-closure
-/> stable ISP
-/> Bearer
-/> agency
-/> consciousness
```

Any visible-ε, ν_block, anti-closure, health, or reorganizability construct must retain its own premise set.

These downstream uses cannot be cited backwards as proof that the minimum L0 contains continuation-favouring direction.

---

# 9. E5 — T_dir / value / normative grounding

Disposition: **HOLD — STRONGER DIRECTIONAL INHERITANCE**.

If ε_pg is retained as an independent stronger directional postulate, it may continue to ground some downstream directional interpretations.

If ε_pg is reduced to a mere scalar witness of generic non-flatness, those downstream value / T_dir claims lose that specific ground and require another owner-level basis.

Therefore the current L0 thinning creates a real fork:

```text
Fork A — retain ε_dir as stronger L0 directional postulate
Fork B — reduce ε_pg to formal witness of generic non-flatness
Fork C — route continuation-favouring direction downstream
```

This audit does not choose the fork because that would alter substantive L0 directionality beyond the already accepted author adjudication.
