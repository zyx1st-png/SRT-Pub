# Differential reconstitution dependence — common audit grammar

## 1. Purpose

Recent #931 work introduced several apparently different relations:

```text
One onset;
multiple-One separability;
Bearer consequence attribution;
multiscale bearing.
```

A useful machine-side compression is possible without declaring a new ontology primitive.

Common question:

> **Which prior difference is actually load-bearing for reconstitution of which later operative lineage?**

Call this only for audit purposes:

```text
differential reconstitution dependence.
```

## 2. One onset

For a candidate local vertical process A:

```text
prior vertical result V^A_t
-> materially participates in reconstituting later operative locus P^A_(t+1).
```

The relevant dependence is:

```text
history / result of A
-> later reconstitution of A.
```

This supports One onset when the relation is genuine rather than observer-imposed similarity.

## 3. Multiple-One differentiation

For A and B:

```text
H_A and H_B
```

need not be stored in separate places.

Multiple-One pressure asks whether:

```text
effect(H_A | reconstitute A)
!= effect(H_A | reconstitute B)

and / or

effect(H_B | reconstitute B)
!= effect(H_B | reconstitute A)
```

in a nontrivial way.

Thus different lineages have relatively non-interchangeable continuation conditions.

This supports relative continuation separability without causal isolation.

## 4. Bearer attribution

For already-admitted One A and consequence q:

```text
q
-> retained change
-> materially alters later reconstitution of P^A.
```

Bearer pressure asks whether q becomes **A-indexed history** because it is constitutive of A's later reconstitution.

The source of q can be:

```text
A itself;
B;
environment;
relation AB;
institution / social structure;
other.
```

Source identity is separate from Bearer attribution.

## 5. Multiscale bearing

If A and higher-order AB are independently admitted Ones, then q may satisfy:

```text
q -> reconstitution_A
and
q -> reconstitution_AB
```

at the same time.

Therefore the relation grammar permits:

```text
multiple Bearer scales
```

without requiring one exclusive physical boundary.

## 6. State perturbation versus history-bearing dependence

Weak:

```text
q changes current state of A
but not the organization by which later P^A is reconstituted.
```

Stronger:

```text
q changes later reconstitution conditions of A.
```

Only the second supports Bearer history writeback.

Thus differential reconstitution dependence is about later formation conditions, not raw state sensitivity.

## 7. Common grammar, different typed relations

The same grammar must not erase the distinctions.

### One relation

```text
TYPE O:
prior Selection-generated vertical result
-> later reconstitution of same lineage.
```

### Bearer relation

```text
TYPE B:
consequence q
-> later reconstitution of an already-admitted One-lineage.
```

### Self-consequence / agency relation

```text
TYPE A:
Selection from One O
-> q
-> later reconstitution of O.
```

### Relation-level / JFS relation

```text
TYPE J:
Selections from multiple positions
-> relation-level vertical organization
-> later participant and / or relation-level reconstitution.
```

One grammar, different source and target typing.

## 8. Why this helps conceptual economy

Without this compression, SRT risks accumulating separate words for:

```text
continuation;
identity;
own-history;
return;
writeback;
position regeneration;
multiscale attribution.
```

The common grammar shows that many of these questions concern one structural family:

```text
past difference
-> which later reconstitution is it constitutive for?
```

The ontology claims remain typed by what the past difference is and what later process it reconstitutes.

## 9. Anti-collapse guards

Do not infer:

```text
differential reconstitution dependence = new canonical primitive;
differential dependence = scientific novelty;
any causal effect = reconstitution dependence;
any history correlation = lineage relation;
any q affecting future state = Bearer;
any shared q = collective subject.
```

The relation must be load-bearing for the relevant later operative organization.

## 10. Counterfactual form — pressure only

For candidate target X:

```text
with historical difference h
vs
without / washed-out h
```

ask whether later reconstitution of X's operative organization differs materially, while avoiding opportunistic post hoc redefinition of X.

This is conceptual discipline only. It does not authorize a new shuffled-writeback experiment route or Level-2 claim.

## 11. Relation to history localization

The grammar is deliberately location-neutral.

```text
h can be distributed;
q can be externally stored;
implementation can be shared;
```

while still having differential reconstitution roles.

Therefore:

```text
where is history?
```

is replaced by:

```text
which later lineage / scale is this history constitutive for?
```

## 12. Relation to vertical structure

The target of reconstitution is not an arbitrary hidden state.

In the current workline it is specifically the organization from which later Selection proceeds:

```text
operative non-flat / vertical Selection-position.
```

Therefore the common grammar remains anchored in the author's vertical-structure direction rather than becoming generic causal process ontology.

## 13. Compact synthesis

```text
Selection
-> vertical result V

TYPE O:
V_t -> later P_(t+1)
= One continuation

TYPE B:
q -> later P_(t+1)
= q-bearing / own-history pressure

= self-consequence / agency closure

TYPE J:
P_A + P_B selections -> V_AB -> later P_A / P_B / P_AB
= relation-level reconstruction / JFS pressure.
```
