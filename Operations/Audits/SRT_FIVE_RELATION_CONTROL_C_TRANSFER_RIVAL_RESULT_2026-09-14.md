# Five-relation minimum tool — Control C transfer / strongest-rival result

> **Boundary:** noncanonical architecture audit. C0 is a frozen scenario-transfer test, not a human behavioral experiment. It cannot establish empirical social truth or normative correctness.

## 0. Executive verdict

The five-relation semantics transfer across the frozen human-AI / organization cases **without rewriting the relation meanings**.

However, strongest-neighbor pressure remains decisive:

```text
no C0 deletion error is locally unique to SRT;
a mature rival family pays each local distinction;
a fair composite can reconstruct all five cases;
SRT's current gain is architecture-level compression / typing discipline,
not established non-substitutability.
```

Therefore:

```text
C-S1 frozen semantic transfer = PASS
C-S2 deletion-error availability = PASS at scenario/audit level
C-S3 rival cannot remove error without equivalent distinction = PARTIAL
C-S4 SRT requires fewer domain-specific theory switches than rival composite = PLAUSIBLE
C-S5 structural rather than normative = PASS

whole-architecture non-substitutability = NOT ESTABLISHED
scientific distinctiveness = NOT ESTABLISHED
```

---

## 1. Frozen relation semantics did transfer

The same five questions were used in both target domains:

```text
Generation — what becomes operative / manifest?
Standing — what has actually formed as a continuing unit / stronger standing?
Shaping — what structures later candidate generation / reachability?
Bearing — where do consequences/exposure land?
Revision — who/what can revise shaping conditions themselves?
```

No sixth relation was required and no relation definition had to be rewritten for the five C0 cases.

This is a positive U4-style transfer result at **audit / conceptual mapping level only**.

---

## 2. Case C0-ALG-SHAPING-NO-STANDING

### SRT full typing

```text
algorithmic recommendation = strong Shaping
independent algorithm Standing = not established
user consequence channels = remain separately typed
Revision = not established merely from recommendation power
```

### Deleted error

```text
strong causal influence / shaping
-> falsely promoted to standing / agency / subject-like status.
```

### Strongest rival payment

Active Inference / Markov-blanket approaches, autonomy theory and extended-cognition debates can all distinguish environmental or extended causal contribution from an independently individuated agent boundary.

Therefore this error is **neighbor-paid**.

SRT contribution here is the reusable guard:

```text
Shaping != Standing.
```

Local novelty: NO.

---

## 3. Case C0-AGGREGATE-GAIN-EXTERNALIZED

### SRT full typing

```text
aggregate performance gain = one scale/result
burden incidence = position-specific Bearing question
future selectability loss = separate downstream effect
revision access = separate again
```

### Deleted error

```text
aggregate improvement
-> local degradation disappears in aggregation.
```

### Strongest rival payment

Externality theory, principal-agent / responsibility analysis, capability-style real-opportunity analysis and distributive institutional theory can all represent this failure.

Therefore the local distinction is **strongly neighbor-paid**.

SRT contribution is the typed connection to the same Standing/Shaping/Revision grammar used outside social theory.

Local novelty: NO.

---

## 4. Case C0-SCAFFOLD-SUBSTITUTION

### SRT full typing

```text
immediate performance gain = not enough
scaffold = Shaping
withdrawal fragility / endogenous candidate-generation decline = selectability effect
ability to alter scaffold = Revision question
```

### Deleted error

```text
performance gain
-> falsely read as endogenous capacity / future-selectability gain.
```

### Strongest rival payment

Distributed/extended cognition, cognitive offloading, automation-bias / skill-decay and scaffold literatures already distinguish assistance from substitution and can use withdrawal fragility as a diagnostic.

Local novelty: NO.

SRT architecture gain: the same distinction is linked to L2 Shaping and Revision rather than treated as an isolated cognition-only issue.

## 5. Case C0-POLICY-NOT-REVISION

### SRT full typing

```text
behavior/policy change inside fixed generator = adaptation
change to candidate-generation rule/boundary/scaffold = Revision
```

### Deleted error

```text
frequent adaptation
-> falsely classified as generator revision.
```

### Strongest rival payment

Meta-learning, structure learning, adaptive control, Active Inference with model learning and evolutionary/open-ended search all pay this distinction strongly.

Control B fresh replication already showed the distinction can be implemented, but that calibration does not support SRT distinctiveness.

Local novelty: NO.

## 6. Case C0-COLLECTIVE-STANDING-WITH-LOWER-CHANNELS

### SRT full typing

```text
higher-order collective Standing may form;
lower formed positions do not disappear by definition;
lower consequence channels remain separately typed;
shared L2 may shape both levels.
```

### Deleted error

```text
higher-level standing
```

### Strongest rival payment

Transitions-in-individuality, multilevel selection, multiscale competency and participatory sense-making / interaction-autonomy traditions all provide strong precedents for nested levels in which higher-order organization appears without simply making lower-level organization conceptually vanish.

Local novelty: NO.

SRT architecture gain: explicit coupling to consequence-return and future-selectability bookkeeping across levels.

## 7. R-single result

No single tested family cleanly pays every C0 burden with one native vocabulary.

Extended Active Inference / FEP is the strongest coherent single-family pressure because it can cover:

```text
nested agents/boundaries;
policy selection;
learning/model revision;
agent-niche shaping;
multi-agent / collective organization.
```

But position-specific non-outsourcable consequence incidence and the strict separation of Shaping / Standing / Bearing are not automatically mandatory coordinates of the framework.

This means SRT retains a **compression candidate**, not a local-mechanism win.

---

## 8. R-composite result

A fair composite can cover all five cases using, for example:

```text
Active Inference / adaptive control
+
enactivism / autonomy / participatory sense-making
+
distributed cognition / cognitive offloading
+
capability / externality / responsibility theory
+
transitions-in-individuality / multilevel selection.
```

The composite must switch local theoretical languages across cases, but those switches are ordinary domain-theory moves rather than obviously ad hoc repairs.

Therefore the following strong claim fails at present:

```text
"Without SRT these distinctions cannot be made."
```

The defensible weaker claim is:

> SRT offers one typed grammar for carrying the distinctions across domains without silently identifying causal influence, standing, consequence-bearing and revision.
