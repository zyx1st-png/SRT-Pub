# Active Selection vs 2026-08-09 second-order Selection

> **Role:** remove parallel-concept ambiguity exposed by external review. This is a crosswalk, not a canonical renaming.

## 1. Earlier author-confirmed second-order Selection

The 2026-08-09 ChoiceMap records a stronger four-part source-intuition gate:

```text
1. own-consequence return;
2. comparison-scale rewrite;
3. selectable-space change;
4. continued efficacy in later real Selection.
```

Its key meaning is not merely parameter learning. Past Selection participates in changing what differences can appear, enter comparison, and count as alternatives in later Selection.

PH-IND03 later preserved that route and explicitly compared it with transductive restructuring while warning that generic restructuring is not enough.

## 2. #931 position-indexed Active Selection

The later #931 author adjudication accepts a broader post-One relation:

```text
already-admitted One O
-> current Selection-position P^O
-> P^O is load-bearing in asymmetric actualisation among reconstructive continuations
-> organizational writeback changes later selectability
-> position-indexed Active Selection candidate.
```

This does not require:

```text
self-caused consequence return;
comparison-scale rewrite specifically;
consciousness;
reflective intention;
meta-selector.
```

## 3. Relation between the two concepts

They are **overlapping but not identical**.

Safe current crosswalk:

```text
position-indexed Active Selection
= broader reconstruction-mode category;

2026-08-09 second-order Selection
= stronger historical specialization in which reconstruction reaches
  the distinctions/comparison regime itself and is tied to the
  same historical position's borne consequences.
```

Tentative relation:

```text
second-order Selection candidate
⊂
position-indexed Active Selection candidate
```

but only when the candidate system independently pays the relevant formed-position / One standing. The subset symbol is a working organizational relation, not a canonical theorem.

## 4. What happened to condition (1) — own-consequence return?

It is **retained** for the older second-order specialization.

It is **not** a requirement for generic Active Selection.

Therefore:

```text
external trigger + position-mediated W2 reconstruction
may qualify as Active Selection;

but without own-consequence return
it does not thereby satisfy the 2026-08-09 I5 second-order gate.
```

This is the main substantive difference between the two routes and must be explicit in future use.

## 5. Comparison-scale rewrite vs W2

`comparison-scale rewrite` is one possible deep W2 realization, but W2 is broader.

Examples of W2-like reconstruction can include changes in:

```text
admissible continuation relations;
which transitions are reachable;
which differences are amplified/suppressed;
which branches count as continuation of the One;
which action/problem dimensions can be generated.
```

Only the last family necessarily approaches the older comparison-scale-rewrite idea.

Thus:

```text
all second-order Selection candidates should be W2-like;
not all W2 Active Selection candidates are second-order Selection.
```

## 6. PH-IND03 S1/S2/S3 crosswalk

PH-IND03 distinguishes:

```text
S1 outcome selection
S2 modulatory selection
S3 transductive restructuring
```

Current relation:

```text
S1/S2/S3 are neighbor/process classifications;
W1/W2 are audit depth labels;
Active/Passive are SRT selection-mode labels;
second-order Selection is an older stronger source-intuition specialization.
```

No one-to-one identity is authorized.

In particular:

```text
S3 can be W2-like without being Active_O;
crystal growth can be transductive without formed-position Active Selection;
W2-like restructuring alone does not establish One, Bearer, agency or subjecthood.
```

## 7. Current naming discipline

Use:

```text
Active Selection
when the broad reconstruction-mode relation is intended;

second-order Selection
only when the stronger 2026-08-09 own-consequence + comparison-scale gate is paid;

self-consequence closure
for the source-return relation independent of whether comparison-scale rewrite occurs.
```

Do not silently use the three labels as synonyms.
