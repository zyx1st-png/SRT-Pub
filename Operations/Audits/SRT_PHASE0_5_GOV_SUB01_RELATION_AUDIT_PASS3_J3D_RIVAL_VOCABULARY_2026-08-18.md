# Phase 0.5 · GOV-SUB01 Relation Audit · Pass 3 — J3-D Rival-Vocabulary Stress

> **Scope**: broad-`K` conceptual stress only. No canonical theory is edited. The purpose is to test whether the primitive role currently named `Selection` can be replaced by independently specified rival vocabulary while preserving the locked P0 boundaries.
>
> **Important**: failure to find a clean replacement does not prove Selection is fundamental, true, unique, or empirically established. GOV-SUB01 explicitly forbids that inference.

---

## 0. Verdict

Three rival-vocabulary families were stress-tested against the J3 locked targets.

| Rival family | Pre-objectification preserved? | Determinate actuality preserved? | No prior chooser preserved? | EX-A preserved? | Hidden reparameterization? | Result |
|---|---:|---:|---:|---:|---:|---|
| **V1 pre-given state-space transition** | **no** | yes, downstream | yes possible | yes possible | low | loses the SRT target by starting after objectification |
| **V2 pre-objective asymmetric actualisation** | yes | yes | yes | yes | **high / decisive concern** | preserves targets only by restating the primitive role under new words |
| **V3 domain mechanism substitute** | usually no at P0 scope | yes within domain | usually yes | can be added | medium-high | useful realization model, not a cross-domain primitive replacement |

The stress therefore yields **no broad-`K` rival that is both independently specified and lossless on the locked P0 targets**.

But the reason is important:

- V1 and V3 lose the **pre-objectification** target by assuming an already specified state/object architecture;
- V2 preserves that target only by saying, in effect, that a non-objectified possibility undergoes an effective asymmetrical determination into manifest actuality — which is functionally the role currently called Selection.

Therefore the current result is **hidden-reparameterization pressure**, not a positive proof of Selection.

### Residue consequence

For the **primitive role currently named Selection**:

**`P unresolved primitive admission`** is now the most disciplined GOV-SUB01 residue at this stage.

Meaning:

> current Phase-0.5 work has not derived the primitive role from a prior independently specified vocabulary, and broad-`K` replacements either start too late or re-import the same role under another name.

For **specific non-neutrality / `ε_pg`**:

**remain `R4 compensated / unresolved`**.

Nothing in J3-D shows that `ε_pg` must define Selection occurrence.

### Option pressure

J3-D does **not** support J3-C.

It gives mild support to retaining **J3-A as the current canonical posture** while leaving the exact actualisation/non-neutrality relation unresolved.

J3-B remains possible only if a future audit can show that generic non-neutrality is analytically necessary **without** collapsing into a tautological renaming of determinate actualisation.

## 1. Locked target set

This pass uses the exact J3-D targets from the author packet.

### `Y_J3-1` — pre-objectification boundary

Do not require a complete pre-given menu of objects, states, relations or admissible transformations before manifestation.

### `Y_J3-2` — determinate actuality

Preserve the distinction:

```text
non-objectified / not-yet-determinate potential
-> determinate manifest event
```

### `Y_J3-3` — no prior chooser

No subject, agent, selector entity or stable ISP may be required before the primitive process.

### `Y_J3-4` — EX-A occurrence / persistence split

The replacement must preserve:

```text
manifest occurrence
!= anchoring persistence
!= Stable ISP
```

### `Y_J3-5` — no hidden reparameterization

A rival fails as a reduction if it defines its substitute by the very role it claims to eliminate.

Forbidden example:

```text
actualizer := whatever turns a possibility into actuality
```

and then:

```text
therefore Selection is unnecessary; use actualizer
```

That is renaming, not subtraction.

## 2. V1 — ordinary transition in a pre-given state space

### 2.1 Rival vocabulary

The cleanest conventional replacement is something like:

```text
state space S exists
current state s_i exists
transition rule T exists
T(s_i) -> s_j
```

Optionally add stochasticity, constraints, asymmetry, path dependence or non-equilibrium dynamics.

This vocabulary can be independently specified without using the word Selection.

### 2.2 What it preserves

It can represent:

- determinate state transitions;
- stochastic or constrained evolution;
- irreversible transitions;
- later history and hysteresis;
- occurrence vs persistence if separately modeled;
- no prior conscious chooser.

### 2.3 What it loses

It begins with:

```text
S, s_i, T
```

already objectified enough to define states, relations and admissible transformations.

That violates `Y_J3-1`, because SRT's P0 question is specifically prior to treating the full object/state architecture as given.

The rival can say:

> once a state space exists, determinate transitions occur.

It does **not** answer the same target:

> how does a determinate manifest slice become available for state-space description at all?

### 2.4 Result

V1 is a valid **L1/domain realization vocabulary** but not a lossless P0 replacement.

Classification:

**`R3` as a replacement for many downstream implementation targets; insufficient for the locked P0 primitive-role target.**

This is a target mismatch, not evidence that ordinary dynamics is scientifically wrong.

## 3. V2 — pre-objective asymmetric actualisation vocabulary

### 3.1 Rival vocabulary

To preserve `Y_J3-1`, remove the pre-given state space and use minimal process language:

```text
non-objectified possibility / indeterminacy
+ an effective asymmetrical constraint / transition
-> determinate manifestation
```

No chooser or subject is required.

### 3.2 What it preserves

V2 can preserve all four substantive targets:

- pre-objectification;
- determinate actuality;
- no prior chooser;
- occurrence distinct from persistence.

### 3.3 Hidden reparameterization test

The crucial question is whether:

```text
effective asymmetrical actualisation
```

has an independent definition that does not already mean:

> the process by which one not-yet-determinate possibility becomes determinate and manifest.

At the current cross-domain P0 level, no such independent specification is available in the audited sources.

If the rival defines the phrase structurally by:

```text
whatever makes a difference become determinate
```

it has simply replaced:

```text
Selection
```

with:

```text
asymmetric actualisation
```

while preserving the same primitive stopping point.

That does not reduce ontology. It changes vocabulary.

### 3.4 Does generic asymmetry solve the problem?

Not yet.

One can require:

```text
some non-neutral difference-making must be effective
```

but unless the role is independently characterized, this may be analytic restatement:

```text
a determinate difference occurs
-> the process was not wholly neutral with respect to that difference
```

This is compatible with J3-B, but it does not establish that the specific `ε_pg` postulate is the needed carrier, nor that a new non-neutrality relation should be added to P0-01.

### 3.5 Result

V2 is the strongest rival on target preservation but fails the clean-subtraction test through **hidden reparameterization risk**.

Classification:

**`R4 compensated / unresolved` as a rival reduction.**

It keeps J3 open rather than defeating the primitive role.

## 4. V3 — domain mechanism substitute

### 4.1 Rival family

Examples of broad mechanism vocabularies include:

- constraint satisfaction;
- spontaneous symmetry breaking;
- stochastic collapse / sampling;
- attractor entry;
- Bayesian / variational updating;
- control or reinforcement transition;
- chemical / biological selection dynamics;
- measurement / readout mechanisms.

This pass does not endorse any one of these as universal.

### 4.2 Strength

Within a declared domain, such mechanisms can provide much more `E_mech` specificity than primitive Selection language.

They can explain:

- which variables change;
- under what dynamics;
- with what probabilities;
- under which interventions;
- with which measurable costs.

### 4.3 P0 mismatch

Every concrete mechanism requires enough prior structure to specify:

```text
variables
states
constraints
law / update rule
measurement partition
or domain entities
```

That makes it valuable **after** manifestation/objectification, but it does not by itself preserve the cross-domain P0 pre-objectification target.

A mechanism can instantiate the primitive role in a domain without replacing the question that primitive role was introduced to mark.

### 4.4 Result

V3 is not a clean broad-K P0 replacement.

Classification:

**domain-level `R2 implementation substitutable` for particular realizations, not for the locked cross-domain primitive role.**

## 5. Cross-rival comparison

The stress exposes a two-horn structure.

### Horn 1 — independently specified rival

If the rival is independently formalized enough to avoid renaming, it normally begins with an already objectified state / variable / law architecture.

Then:

```text
independent specification
-> loses Y_J3-1 pre-objectification
```

### Horn 2 — preserves pre-objectification

If the rival stays prior to objectification, it must use a thin process role such as:

```text
asymmetrical determination
actualisation
manifestation
constraint-effective differentiation
```

But then:

```text
preserves Y_J3-1..4
-> risks defining the substitute by the same role as Selection
```

This is not an impossibility proof. It is the current audit result under the available rival families.

## 6. Evaluation-vector result

### `E_cf`

No rival currently yields a clear P0 counterfactual that SRT can state and the rival cannot **while preserving the same target**.

Therefore:

```text
J3-D
!= D2 progress
```

### `E_mech`

V1/V3 are more mechanistically specific downstream but start after the P0 target. V2 matches the target but adds little independent mechanism.

### `E_orient`

Selection-first vocabulary has a real current orientation function:

> it prevents the theory from silently treating the object/state description as prior to the manifestation event it is trying to explain.

Whether that orientation role is enough to justify permanent P0 primitive status is **not decided** by this pass.

### Framework-identity loss

A broad-K model can preserve downstream dynamics while dropping the pre-objectification commitment. That is not a lossless rewrite of SRT; it is a thinner/different framework.

## 7. GOV-SUB01 residue routing

### Primitive Selection role

Current evidence supports:

**`P unresolved primitive admission`**.

Why not `N1`?

Because no empirical or formal indispensability proof has been established. The role survives the audited rival stress, but survival does not prove necessity.

Why not `R2/R3`?

Because no independently specified replacement preserves all locked P0 targets without either changing the target or renaming the role.

### Generic non-neutrality role

**`R4 compensated / unresolved`**.

The primitive actualisation phrase may contain the role analytically; the audit cannot yet tell whether that is legitimate compression or masking.

### Specific `ε_pg`

No new residue verdict is assigned beyond the existing unresolved status for its relation to primitive actualisation.

In particular:

```text
P role for Selection
!-> ε_pg is P
```

and:

```text
V2 needs generic asymmetry language
!-> ε_pg defines Selection
```

## 8. Consequence for J3 options

### J3-C — constitutive `ε_pg` / non-neutrality gate

**Not supported.**

The stress supplies no reason to add a new Selection-occurrence criterion. Doing so would change the target rather than audit it.

### J3-B — analytic absorption

**Still live but unproven.**

The V2 stress shows why generic non-neutrality may appear analytically unavoidable, but it also shows the tautology risk.

### J3-A — distinct co-present postulates

**Safest current canonical posture.**

It preserves the existing architecture while acknowledging that the relation is not derived.

### J3-D — rival stress first

**Executed in this pass.**

Result: no clean reduction; primitive role remains `P`, specific non-neutrality relation remains `R4`.
