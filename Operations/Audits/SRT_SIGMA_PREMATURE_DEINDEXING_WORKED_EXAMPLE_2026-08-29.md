# Sigma as a worked example of premature de-indexing

> **Purpose:** reinterpret already-completed sigma probes under the 2026-08-29 Constitution + Domain blueprint. This file adds no new probe result and does not redefine sigma. It records what the existing failures can and cannot support methodologically.

## 1. Existing evidence

The sigma decision packet already records:

### E1 — representation sensitivity

Equivalent operator behavior can be preserved under an invertible parameter-coordinate transformation while the bare ratio changes:

```text
sigma_sr: 0.5 -> 10/11 ~= 0.9091
```

No current C1–C4 rule fixes a unique gauge/metric that blocks this example.

### E2/E3 — attribution is not uniquely closed

Current owners do not provide one general unique allocation rule for mixed self/external causal history. They also use non-identical trace semantics:

```text
Individuation: P's own prior-output writeback
T-PROJ-1: L2-writeback contribution
Collective Selection: shared L2 reclassified as internal relative to declared collective boundary
```

### E4 — provenance is not control

The same model can have a very high bare trace/source share while a control/Jacobian-like readout assigns very little current causal control to that trace channel. External ablation can dominate despite high provenance magnitude.

These are existing audit results; this worked example does not upgrade them.

---

## 2. New retrospective reading

The original motivating phrase contains an indexical burden:

```text
P's own prior history
```

To turn that phrase into a portable scalar, a formal model must decide at least:

```text
what unit P is
where P's boundary is
what counts as history
how mixed causes are attributed
what representation/metric measures magnitude
whether the target is provenance, endogeneity, dependence or control
what changes when scale/collective boundary changes
```

The sigma probes show that these decisions were not uniquely determined by the bare ratio itself.

Therefore sigma is a useful repository-local illustration of this methodological risk:

> a bearer-indexed, boundary-sensitive relation was compressed toward a single common coordinate before the objectification/attribution contract was fully declared.

Call this **premature de-indexing**.

---

## 3. What this example does NOT show

It does not prove:

```text
mathematics cannot represent indexical relations
formalism cannot carry perspective
all scalar representations are invalid
bearer relations are ineffable
first-person language is epistemically superior
```

Mathematics can model indexed, contextual, relational, gauge-dependent and observer-relative structures.

The narrower lesson is:

```text
formal representation
requires declared objectification choices
and cannot bootstrap the bearer/unit/boundary
that its own variables already presuppose.
```

---

## 4. Relation to the new Constitution method

At Constitution level, the lesson is a guard:

- do not use a scalar as the ground of `from here` before explaining what `here` is;
- do not turn an attribution problem into a natural-coordinate claim by notation;
- do not let a portable representation erase the very bearer relation under investigation.

At Domain level, the lesson becomes constructive:

- formalization is allowed;
- declare unit/boundary/grain/equivalence/history-loss/position-loss;
- state whether the variable measures source, control, dependence, endogeneity or another typed relation;
- test representation robustness where the claim requires it.

---

## 5. Why this is stronger than a post-hoc excuse

The worked example is useful because the failure modes were discovered before the current methodological interpretation was articulated.

However, that chronology only supports a **retrospective explanatory fit**, not a proof of the Constitution.

Safe wording:

> The Constitution + Domain reconstruction explains why the sigma architecture was vulnerable to exactly these kinds of ambiguity: it tried to make a portable public readout do work that still depended on undeclared bearer/boundary/indexing choices.

Unsafe wording:

> Sigma failed, therefore SRT proves formal science erases the bearer.
