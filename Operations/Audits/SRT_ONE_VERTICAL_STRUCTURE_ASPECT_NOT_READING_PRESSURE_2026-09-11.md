# One / vertical structure semantic pressure — ontological aspect, not observer-side reading

## 1. Trigger

Constructive integration sharpened the working proposal from a static-looking formula:

```text
One ~= lineage-indexed vertical organization
```

toward language such as:

```text
One = continuation-side reading / projection of an ongoing Selection-driven individuation process.
```

That move avoids one danger but creates two others.

## 2. Pressure A — `reading / projection` risks epistemic collapse

The author has repeatedly distinguished ontological One from cognitive One. Therefore the phrase:

```text
One = continuation-side reading
```

is unsafe if read literally. It can imply that One exists only because an observer takes a process under a certain description.

That would collapse:

```text
ontological One
```

into:

```text
cognitive / observer-side One.
```

The current reconstruction requires the opposite distinction:

```text
ontological One:
a real continuation-unity in the Selection-generated vertical organization;

cognitive One:
an objectification / recognition / boundary-marking relation that may later support or reshape that ontological continuation.
```

Therefore `reading`, `projection`, and similar epistemic terms should not be the primary ontology wording.

## 3. Pressure B — `individuation` risks importing a neighbor as the SRT owner term

Simondon strongly pays processual individuation, ongoing individuation, individual-milieu co-genesis and transduction. That is a constructive resource and a serious pressure.

But replacing SRT's own root vocabulary with:

```text
ongoing individuation
```

would create a different error:

```text
constructive integration
-> terminological takeover by a mature neighbor.
```

SRT's author-owned centre in the current workline is instead:

```text
Selection
-> active construction / maintenance / anticipation of vertical selectable organization
-> One / position formation where continuation becomes established.
```

Therefore `individuation` should remain a comparator / translation / realization term where useful, not the primary internal name of the SRT process unless later author adjudication explicitly chooses it.

## 4. Current preferred C-layer wording

Use:

> **Ontological One is the continuation-unity constituted when a Selection-generated vertical organization is reconstituted relative to its prior vertical history across further Selection.**

And:

> **Selection-position is the operative / from-where aspect of that same continuing vertical organization insofar as it non-neutrally conditions further Selection.**

Important distinction:

```text
aspect
!= observer-side reading
```

Here `aspect` marks two real relations borne by one organization:

```text
continuation relation:
what continues through reconstitution?
-> One

operative relation:
from where / through what non-flat organization does later Selection proceed?
-> Selection-position candidate
```

Neither relation requires a cognitive observer to exist.

## 5. One is neither snapshot nor a second substance

The refinement preserves both anti-collapse constraints:

```text
One != any single V_t snapshot
```

and:

```text
One != a second substance added behind the vertical process.
```

The One candidate is the real diachronic unity of the vertical reconstitution relation itself.

Machine shorthand:

```text
V_t --Selection-mediated reconstitution--> V_(t+1)

where the later organization is constituted relative to the prior vertical history

=> continuation-unity candidate O
```

This remains weaker than strict numerical identity.

## 6. Selection-position is not merely a synonym for One

If One and Selection-position are two aspects of the same formation-layer organization, they remain conceptually non-identical:

```text
One:
indexes diachronic continuation / unity.

Selection-position:
indexes operative asymmetry / situated from-where for later Selection.
```

Possible cases remain open in which a thin ontological One has weak or diffuse operative localization, or a transient vertical organization has positional efficacy without yet satisfying the One-continuation burden. The current proposal should not close those edge cases by definition.

## 7. Revised compact architecture

```text
minimum non-neutrality
-> subjectless Selection
-> event-level verticalization
-> recurrent / re-entering vertical organization
-> Selection-mediated reconstitution relative to prior vertical history
-> continuation-unity emerges

same continuing vertical organization:
  continuation aspect -> ontological One
  operative aspect    -> ontological Selection-position candidate
```

Then, separately:

```text
consequence return + reconstitution coupling
-> Bearer candidate

perspective-bearing / stable ISP criteria
-> subject-position where admitted

relation-level continuation
-> higher-order One candidate

T-COLL-1
-> collective ISP where admitted.
```

## 8. Terminology recommendation

Prefer, at the present C-layer:

```text
vertical reconstitution
continuation-unity
continuing vertical organization
lineage-relative reconstitution
```

Use with caution:

```text
lineage-indexed vertical organization
```

because it can sound object-like but remains useful audit shorthand.

Avoid as primary SRT ontology wording:

```text
One = reading / projection
One = ongoing individuation
One = stable structure
One = self-maintaining system.
```

`individuation` remains valuable when explicitly discussing Simondon or cross-theory translation.
