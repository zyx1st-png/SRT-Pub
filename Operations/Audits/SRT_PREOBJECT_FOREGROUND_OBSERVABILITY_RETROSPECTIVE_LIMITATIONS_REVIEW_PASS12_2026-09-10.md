# Retrospective limitation review — pre-object field / foreground-bounded observability

> **Question:** did earlier limitation / absorption judgements accidentally treat reproduction of downstream observable dynamics as reproduction of the SRT pre-object ontology?
>
> **Rule:** historical negative results are not deleted. Each is reclassified only by the strongest claim it actually paid.

## 0. Review standard

Use four distinct targets:

```text
D1 LOCAL DYNAMICS
   can a mature theory reproduce the observed mechanism / transition pattern?

D2 STATE-SPACE REPRESENTATION
   can the relevant history / field / position be encoded as ordinary state,
   hidden state, latent variable, attractor, policy, topology or parameter?

D3 PRE-OBJECT CONSTITUTION
   does the account explain the genesis of objectifiable state / option / boundary
   without presupposing the completed object-style state-space as the floor?

D4 OBSERVATION RELATION
   is observation a neutral window onto a pre-given complete state,
   or is the directly observable item already the manifest / foreground side
   of a differentiating operation?
```

A result at D1 or D2 is not automatically a result at D3 or D4.

This distinction is strongly continuous with existing SRT source material. `Q03` already says that the pre-object field is neither a hidden warehouse of finished objects nor already formatted information, and that measuring / describing it in object form performs the very cut whose genesis is at issue. The 2026 selection-realism paper likewise diagnoses object-first ontology as beginning from determinate objects, states, predicates and boundaries after the constitutive work has already been hidden.

## 1. Cycle 1 — history-location / recurrence collapse

Historical result:

```text
stable vs shuffled history writeback
-> ordinary recurrent predictor reproduced candidate dynamics
-> history-location Level-2 route retired
```

### What remains valid

**RETAIN.** The experiment genuinely showed that the tested operational difference inside an already declared state / memory / locus architecture can collapse into ordinary recurrence / credit assignment.

The Cycle-1 model was already careful not to equate its matched control state with a complete metaphysical state. It explicitly says `C_t is not claimed to be a complete metaphysical state` and rejects the need for a hidden non-Markovian provenance variable.

Therefore the new pre-object distinction does **not** rescue the failed toy.

### What must be narrowed

The experiment only tested:

```text
post-objectified carrier architecture
+
explicitly declared loci / history channels
+
observable downstream recurrence
```

It did not test:

```text
whether the loci / options / state variables themselves are prior to Selection;
whether the generating pre-object field is equivalent to that explicit state-space;
whether the observation surface is only the foreground of an earlier differentiation.
```

**Retrospective disposition:**

```text
Cycle-1 recurrence-collapse result: RETAIN
claim that it pressures pre-object ontology: NOT PAID
route retirement: RETAIN for history-location / writeback discriminator
broader SRT limitation inferred from it: NARROW
```

## 2. Cycle 2 — Simondon + Luhmann + adaptive dynamics absorption

Historical result:

```text
fair mature composite reproduces nearly all visible downstream phenomenology;
Level 1 survives only narrowly as dependency / placement;
Level 2 HOLD;
scientific distinctiveness NOT ESTABLISHED.
```

Later Passes 2–6 strengthened this subtraction further with WTA, representation learning and Turing / activator-inhibitor realizations.

### What remains valid

**RETAIN at D1/D2.** Mature theories clearly pay:

```text
preindividual / non-pregiven individuation;
two-sided differentiation;
competition / inhibition;
operation -> structure -> later operation;
endogenous organizer / position formation;
field / representation reorganization;
regeneration and ordinary history dependence.
```

SRT must not claim local mechanism ownership for those structures.

### What is reopened

The earlier inference occasionally approached:

```text
visible SRT-shaped causal architecture is reproduced
-> pre-object SRT architecture is substantially absorbed
```

That implication is now too strong unless the comparator also addresses D3/D4.

A Turing pattern, WTA network or latent-state learner can reproduce foreground/background-like output while still being written from a third-person model in which the relevant variables, state domain and update law are supplied as already determinate.

That does not refute those models. It means the comparison question changes.

The live issue is now:

> Does the rival merely model an objectified realization **after the cut**, or does it provide an ontologically equivalent account of how a pre-object field becomes a determinate observable without presupposing a complete option/state inventory?

### Important correction to Pass 5/6 language

The findings:

```text
pre-object field as local novelty residual: NOT SAFE
bilateral enhancement/suppression as local novelty residual: NOT SAFE
```

remain valid.

But they must not be upgraded to:

```text
pre-object non-objectifiability / observation-after-Selection is absorbed.
```

That exact axis was not the target of those passes.

**Retrospective disposition:**

```text
local-mechanism subtraction: RETAIN
D1/D2 absorption: RETAIN
pre-object/observation ontology absorption: REOPEN / NOT TESTED AT REQUIRED STRENGTH
Level 2 HOLD: RETAIN pending new route
framework-level value: REOPENED under current U-mode
```

## 3. Cycle 3 — creative actualisation / Whitehead / Barad

Historical result:

```text
Whitehead strongly pays continuous creation / many->one / potentiality->actuality;
Barad strongly pays determinate articulation without pregiven independent relata;
Cycle-3-specific creative language largely Level 0;
no new Level 2 found.
```

### What remains valid

**RETAIN.** `creation`, `actualisation`, `many become one`, `generated boundary`, and `no pre-existing human chooser` are not safely SRT-exclusive.

### Why this line now becomes more important, not less

Barad is no longer merely a novelty subtractor. Her agential-cut / phenomenon architecture is a **direct strongest-neighbor candidate for D3/D4**, because it also denies that independent relata simply precede the constitutive cut.

Likewise Simondon remains strong for preindividual individuation.

Therefore the new insight does **not** automatically restore Cycle 3. Instead it changes the strongest-neighbor question from:

```text
who else has creative actualisation?
```

to:

```text
who else denies that a complete objectified state-space is ontologically prior,
and what exactly is the relation between constitutive differentiation and observation in that account?
```

**Retrospective disposition:**

```text
Cycle-3 local novelty subtraction: RETAIN
Whitehead-only creative comparison as decisive core test: DEPRIORITIZE
Barad / Simondon comparison on objectification-observation axis: REOPEN / PRIORITIZE
Cycle-3 Level verdicts: DO NOT REVERSE YET
```

## 5. IRR-B — complete current causal state / global residue

Historical IRR-B uses a strong discipline:

```text
genuine Selection leaves causally effective residue somewhere in the complete present state / enlarged environment;
no hidden history beyond a genuinely complete present causal state.
```

### What remains valid

At an operational / model layer, this is a useful anti-magic guard. SRT should not claim different futures from two causally identical modeled states merely by attaching an invisible provenance token.

### What must now be layer-qualified

The phrase:

```text
complete present causal state
```

cannot silently become an L0 ontological premise if the current core question is whether a **complete objectifiable state-space is itself downstream of Selection**.

Two uses must be separated:

```text
MODEL-COMPLETE STATE
= complete relative to a declared scientific representation / intervention algebra;

ONTOLOGICALLY COMPLETE PRE-SELECTION STATE
= claim that reality before Selection is exhaustively objectifiable as a finished state vector.
```

IRR-B can retain the first without prejudging the second.

Therefore the no-hidden-history discipline survives, but it no longer licenses:

```text
there must exist a fully objectified complete state description prior to Selection.
```

**Retrospective disposition:**

```text
IRR-B anti-hidden-provenance guard: RETAIN
complete-state language as model-relative: RETAIN / CLARIFY
complete-state language as L0 ontological exhaustion: NOT LICENSED
IRR-B Level-1 historical verdict: DO NOT REVERSE
relation to pre-object ontology: REOPEN
```

## 6. Physical Selection trigger / Level-2 admission problem

Historical blocker:

```text
first identify an event as genuine Selection by a non-circular physical admission surface;
then test a downstream residue / reversal consequence.
```

This is sound for **empirical discrimination** if `identify` means an operational classification rule.

But the new author priority exposes a possible category error if the requirement is read more strongly:

```text
observe Selection from outside before Selection has produced an observable foreground.
```

Under foreground-bounded observability, every empirical admission surface is already a **post-Selection evidence interface**. It cannot be ontologically prior evidence in the same sense that a directly observed pre-existing state variable would be.

Therefore Level-2 work should distinguish:

```text
ONTOLOGICAL ADMISSION
what Selection is / why objectifiable determinacy is downstream;

EMPIRICAL PROXY ADMISSION
what post-Selection foreground/readout pattern licenses a bounded test.
```

The second may test consequences of the theory without claiming direct observation of L0.

**Retrospective disposition:**

```text
need for non-circular empirical proxy: RETAIN
requirement to directly observe pre-Selection ontology: REJECT AS CATEGORY ERROR
old physical-trigger blocker: REFRAME, not automatically solved
```

## 10. Strongest-neighbor re-selection for the new core axis

The next comparison must not use WTA, RL or generic control theory as the principal philosophical rival. Those are useful D1/D2 pressures but begin too late for the core D3/D4 question.

The strongest currently known neighbor set is:

```text
BARAD
phenomena / intra-action / agential cut / determinate separability;
strongest direct pressure on constitution + measurement/objectification.

SIMONDON
preindividual metastability / transduction / individual-milieu co-genesis;
strongest pressure on pre-object individuation without finished individual.

WHITEHEAD
actual occasions / concrescence / actuality from potentiality;
strong pressure on actualisation-before-enduring-object, weaker on the specific observation-cut issue.

PHENOMENOLOGICAL HORIZON
manifest object always appears against a non-thematized horizon;
strong observation-side analogy, but may remain subject-relative and therefore not automatically world-side ontology.

STATE-SPACE / CONTROL / LATENT-MODEL THEORY
strong reduction pressure on the claim that any apparent background can simply be encoded as hidden state;
not itself the strongest ontology neighbor.
```

The key question for each is no longer `can it reproduce the dynamics?` but:

> **Does it treat the complete objectifiable state-space as ontologically prior, or does it also make objectifiable determinacy / observable articulation downstream of a constitutive cut? If the latter, what exactly remains SRT-specific in the foreground/background Selection relation?**

## 12. Main consequence for programme interpretation

The largest retrospective correction is methodological:

```text
reproducing the observable foreground dynamics
!=
reproducing the ontology of how something becomes observable / determinate.
```

Previous audits were often correct about the first question and then conservative about the whole theory. The new author priority requires a dedicated audit of the second question before those conservative judgements are allowed to stand as theory-wide limitations.
