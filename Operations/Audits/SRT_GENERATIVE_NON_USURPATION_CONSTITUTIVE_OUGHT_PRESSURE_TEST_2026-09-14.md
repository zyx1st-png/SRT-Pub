# Generative non-usurpation as a constitutive ought — pressure test

> **Role:** machine-side pressure test of whether the new generativity-first / cross-position reconstruction can yield a limited `ought` without importing a pregiven moral goal, maximizing option count, privileging larger scales, or turning every formed position into an inviolable moral bearer. This file is noncanonical and does not settle the author gate.

---

## 1. Target question

Current reconstruction already supports the following candidate distinctions:

```text
O0
primitive generative directionality / non-maximal indifference

O1-X
better / worse for a formed position X
with respect to independently specified recurrent generative relations

O1-R
better / worse for a cross-position relation R
where R is independently established as a real generative relation

O1-H
better / worse for a genuine higher-order whole-position H
only where H is independently formed
```

The unresolved question is stronger:

```text
Can any genuine O2 constraint arise from these relations themselves,
without saying in advance that autonomy, equality, survival,
option count, happiness, coordination, or the largest whole is morally supreme?
```

Central result of this pressure test:

```text
YES, a limited constitutive / relation-typed ought appears defensible;
NO, a complete categorical moral ought does not yet follow.
```

---

# 2. First correction — non-usurpation cannot be a universal preservation law

Unsafe candidate:

```text
Every real Selection-position ought always to be preserved
and may never be overridden, dissolved, transformed or replaced.
```

Reject.

Counterexamples include:

```text
malignant / parasitic formed processes;
medical excision;
formation / education involving temporary asymmetry;
emergency coordination;
voluntary delegation;
merger / transformation;
irreversible commitment;
self-sacrifice;
terminal Selection.
```

Therefore:

```text
real position
-/> universal inviolability;

local O1 standing
-/> complete moral standing;

loss of a position
-/> wrong automatically.
```

This is consistent with the existing separation among One, Stable ISP, Bearer, Concern and agency.

---

# 3. Stronger candidate — participant-status consistency

The promising non-usurpation burden is not:

```text
never constrain Y.
```

It is:

```text
Do not count Y as a constitutive generative participant in relation R
while recurrently replacing the very Selection contribution
by which Y participates in R.
```

Call this **participant-status consistency**.

Suppose relation `R(X,Y)` is independently described as a multi-position generative relation in which Y's Selection-generated differences are load-bearing for R's further formation.

Then the following pair is structurally inconsistent:

```text
Claim 1:
Y remains a genuine generative participant in R.

Claim 2:
X may recurrently determine Y's future Selection conditions
such that Y's own Selection no longer materially returns into R.
```

If Claim 2 becomes true strongly enough, one of the following must be admitted:

```text
R has changed type;
Y is no longer a constitutive participant;
the relation has become asymmetric delegation / control;
Y's participation has been hollowed out;
or the original multi-position description was false.
```

The theory must not preserve the label while erasing the constitutive relation.

This is the first genuinely strong route from anti-objectification to a normative constraint.

---

# 4. Why this is not yet a moral equality theorem

Participant-status consistency does not say:

```text
X and Y must have equal power;
X and Y must have equal influence;
all asymmetry is wrong;
all override is wrong;
all positions have equal moral worth.
```

It says only:

```text
A relation cannot coherently claim a position as a load-bearing source
while structurally treating that same position as if its future
could be generated entirely elsewhere.
```

Thus asymmetry can be real and sometimes constitutive.

The issue is whether the asymmetry:

```text
remains typed and accountable as asymmetry
or
masquerades as participation after participation has been structurally removed.
```

---

# 5. Three levels of O2 should now be separated

The old binary split `O2-R responsibility` vs `O2-D deontic ought` is too coarse for the new reconstruction.

A cleaner working split is:

## O2-C — constitutive ought

Question:

```text
What must a relation do / not do if it is to remain the kind of generative relation it claims to be?
```

Example:

```text
If R is genuinely co-generative,
R must not systematically erase one constituent source-role
while continuing to classify it as co-generative participation.
```

This is a type-preservation / relation-integrity norm.

It is conditional but non-arbitrary once the relation type is established.

## O2-A — attributable answerability / controlled relational rewrite

Question:

```text
When a formed agent-position can materially rewrite R,
what consequences of that rewrite are attributable back to that position?
```

This requires stronger agency conditions such as effective intervention, attribution continuity, uptake / revision capacity and relevant access to the relational consequences.

It is not implied by One or Selection-position alone.

## O2-M — all-things-considered moral / deontic authority

Question:

```text
When multiple positions, relations and scales conflict,
what should finally be done?
```

This remains OPEN.

Therefore:

```text
O2-C may be constitutively grounded;
O2-A is a strong agency-dependent candidate;
O2-M is not yet closed.
```

# 6. A finite actionable principle without a universal scalar

The strongest current candidate is a **generative non-usurpation dominance rule**.

Given two feasible relation-transitions `T_a` and `T_b` under the same declared scope and objective:

```text
1. both accomplish the same independently declared local / relation-level task;
2. T_a leaves every admitted constitutive position / relation no worse
   with respect to its declared generative standing than T_b;
3. T_a leaves at least one admitted position / relation strictly less substituted,
   less hollowed out, or more capable of materially re-entering later Selection;
4. no independently established higher-order standing is worse under T_a;
```

then:

```text
T_a structurally dominates T_b.
```

Within that declared scope, the theory can say:

```text
prefer / ought-select T_a over T_b
```

without inventing a total utility function or universal weighting rule.

This is analogous to a partial-order dominance relation, but the compared dimensions are typed generative relations rather than preference satisfaction or option counts.

### Important limit

When condition 2 or 4 fails because there is a real tradeoff:

```text
STOP.
```

The dominance rule does not decide the conflict.

That is not a defect. It prevents the theory from hiding a moral weighting scheme inside a structural comparator.

---

# 7. `ought` is about generative rewriting, not retrieving the correct option

The new route is compatible with the author guard:

```text
Selection != retrieval of one accurate pregiven option.
```

Therefore O2-C should not be phrased primarily as:

```text
you should pick option B.
```

A more native formulation is:

```text
When Selection rewrites the future generative relation,
that rewrite is constrained by the constitutive standing
of the positions and relations it claims to preserve / instantiate.
```

The normative object is therefore initially:

```text
relation-transforming Selection
```

rather than a completed menu item.

This is a much closer fit to SRT's generative ontology.

---

# 8. Delegation is not usurpation automatically

A position can authorize another position to act for it.

Thus:

```text
delegation != generative substitution automatically.
```

A plausible delegation relation includes some combination of:

```text
scope;
duration;
traceable attribution;
return / feedback;
revision or revocation where possible;
continued relevance of the delegating position's Selection;
```

These are not yet universal necessary-and-sufficient conditions.

The core distinction is:

```text
Delegation:
Y's generative standing partly structures the authority relation itself.

Usurpation:
Y's standing is invoked or presupposed,
but Y's Selection ceases to be load-bearing for the relation.
```

This gives a structural basis for later political notions of authorization and legitimacy without defining them at L0.

---

# 9. Parenting / formation asymmetry

A child / learner case is important because it defeats a simplistic anti-interference rule.

Temporary asymmetry may be compatible with generativity-first normativity if the relation is genuinely formation-oriented:

```text
current control by X
-> contributes to formation / recovery of Y's later generative standing
rather than
-> permanently substituting X for Y as the source of Y's future.
```

Guard:

```text
claimed developmental benefit
!= proof of legitimacy.
```

The relation still requires independent evidence that the asymmetry is formation-serving rather than merely self-justifying domination.

Exact developmental / guardianship criteria are downstream and domain-specific.

---

# 10. Emergency override

Emergency cases support the same distinction.

A temporary override may be structurally admissible when:

```text
a real relation / whole is at risk;
normal distributed Selection cannot operate under the perturbation;
the override is typed as exceptional rather than ordinary participation;
and the relation contains a route back toward ordinary constituent re-entry where feasible.
```

Unsafe inference:

```text
whole exists
-> whole may permanently override members.
```

The emergency route does not establish whole sovereignty.

It only shows that asymmetric Selection can sometimes preserve the conditions for later multi-position generation.

---

# 11. Malignant / predatory generators

A tumour, parasitic process or predatory institution can possess local O1 relations.

That fact does not force universal non-usurpation toward it.

Reason:

```text
local better / worse-for X
!= X has protected moral standing in every wider relation.
```

If a genuine whole-position H is independently established and X's local generativity is constitutively destructive of H, then:

```text
better-for X
and
worse-for H
```

can both be true.

No global ranking follows automatically.

Bearer / Concern / agency / whole-formation and domain-level standing remain relevant to any stronger moral conclusion.

---

# 12. Self-sacrifice and voluntary closure

The framework must allow a formed agent to participate in reducing or ending its own local generative standing.

Therefore:

```text
self-preservation is not the universal SRT ought;
maximal future option count is not the universal SRT ought;
continuation is not mandatory merely because O1 can describe continuation as locally better in one dimension.
```

A voluntary commitment can be generatively meaningful precisely because it closes alternatives and forms a new path.

Thus the target is not openness without closure.

The target is correct typing of who / what is generating the closure and how that closure rewrites the relation.

---

# 13. Anti-smuggling test for O2-C

To count as constitutively derived rather than morally imported, an O2-C claim should pass all of the following:

```text
C1  relation R is independently specified before evaluative language;
C2  constituent positions are independently admitted;
C3  their source-roles in R are structurally specified;
C4  the alleged violation can be stated as a contradiction / type change
    in those non-evaluative relation facts;
C5  no premise uses good / healthy / legitimate / deserving / just
    to establish the violation;
C6  the result is scoped to R unless an independently formed wider position exists;
C7  real tradeoffs are not silently converted into a total ranking.
```

If these conditions fail, the theory is probably importing the desired normativity through its definitions.

---

# 14. Hume-gap consequence

This pressure test does not produce:

```text
pure neutral facts
-> logically deduced complete morality.
```

Instead it strengthens the `Dissolution Rather Than Derivation` route in a narrower way.

Traditional thin typing:

```text
X did A;
Y underwent B;
then a value premise must be externally added.
```

SRT generative typing:

```text
X and Y are formed generative positions;
R is constituted by their load-bearing Selection relations;
Selection by X rewrites the conditions under which Y can still participate in R;
that rewrite may preserve R, change R's type, or hollow out one claimed constituent role.
```

Once the relation is typed this way, some `ought` statements are constitutive conditions of the relation's own claimed form.

But this yields only:

```text
relation-typed constitutive normativity
```

not yet:

```text
all-things-considered categorical morality.
```

Thus current Hume result should be stated as:

```text
partial constitutive dissolution strengthened;
complete deontic closure still OPEN.
```

---

# 15. Relation to anti-objectification

This reconstruction gives anti-objectification a stronger ontological meaning.

Objectification is not only:

```text
representing Y as an object in cognition.
```

A deeper generative form is:

```text
R continues to count Y as a participant
while the effective production of Y's future relation-state
is recurrently displaced to X or another source.
```

Call this **generative objectification / substitution** as a structural diagnostic.

The strongest safe claim is:

```text
generative objectification is a failure of participant-status consistency
within relations that constitutively depend on Y as a generative source.
```

Do not yet infer:

```text
all objectification = complete moral wrong;
all asymmetry = objectification;
all replacement = objectification.
```

# 17. Next gate

The next author decision should not ask whether non-usurpation is simply morally good.

It should ask whether the author accepts this narrower architecture:

```text
1. non-usurpation is relation-relative before it is moral-universal;
2. participant-status consistency can ground a constitutive ought;
3. scoped dominance can produce finite actionable preference without total ranking;
4. delegation / formation / emergency asymmetry remain possible when correctly typed;
5. stronger moral standing and genuine tradeoff resolution remain downstream / OPEN.
```

Only after that gate should SRT attempt a stronger bridge from constitutive generative normativity to rights, justice, responsibility or political legitimacy.
