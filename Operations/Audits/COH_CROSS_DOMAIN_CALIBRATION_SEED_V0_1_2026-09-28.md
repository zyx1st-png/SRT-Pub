## 2. Method-level hypotheses being tested

### H-M1 — scale dependence is informative, not a defect

Expected pressure case: E1 versus E2.

~~~text
same reaction-diffusion event
= O-T at field scale
= C-R<->O at pattern scale.
~~~

If blind scorers treat this as contradiction, nested-cut guidance is too weak.

### H-M2 — constitution needs a relative/framework split

Expected pressure:

~~~text
E2 pattern formation -> C-R;
D3 protocol specification -> C-F relative to runtime;
E4 threshold -> not C-F.
~~~

### H-M3 — current operation and history must remain separable

Expected pairs:

~~~text
C1 current precedent rule vs C2 inherited precedent field;
D1 current transition mechanism vs D2 installed-base inheritance;
A1 current model operation vs A2 learned prior carried forward.
~~~

### H-M4 — evidence/access must remain orthogonal

Expected pressure:

~~~text
F1 neural readout of re-identification
does not become constitution merely because it is observable;
archive/readout/probe status is not itself H.
~~~

### H-M5 — dramatic change is not automatically constitution

Expected negative controls:

~~~text
E4 nucleation threshold;
F3 discontinuous memory-strategy transition.
~~~

### H-M6 — the method should sometimes add little

B1/B2 are expected to show limited incremental clarity because niche-construction literature already separates modification, selection pressure, inheritance and evolutionary response.

If every case is scored as HIGH added clarity, the method is likely self-congratulatory.

## 3. Cases especially important for failure detection

### C3

Case of first impression should not be upgraded to constitution merely because no controlling precedent exists.

### D3

Tests whether the method can represent externally supplied constitution without pretending the runtime system generated its own framework.

### E1/E2

Tests whether the same event can legitimately receive different burden assignments at different cuts.

### F3

Tests the shortcut:

~~~text
phase transition / discontinuity -> constitution
~~~

which should fail.

## 4. What would count against COH

Treat any of the following as method pressure, not reviewer error:

~~~text
1. independent scorers cannot reproduce the O vs H separation even with explicit later-effect criteria;
2. C-R vs C-F remains unstable after scale/cut declaration;
3. most cases require MIXED/UNDETERMINED despite adequate sources;
4. Added Clarity is mostly LOW because source-native disciplines already make every useful distinction;
5. the method creates artificial differences that do not change explanation, experiment or comparison;
6. external-design cases cannot be represented without ad hoc exceptions.
~~~
