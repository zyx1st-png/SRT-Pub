# R1 author gate — canonical owner for One / Selection-position

## 0. Why this gate exists now

PR #940 has canonically repaired P1-T06 so Stable ISP is a strong recurrent standing criterion rather than the first appearance of perspective, the formation law for a selective centre, or a subject-position gate.

That repair exposes the next unresolved ownership question rather than answering it:

```text
subjectless Selection
-> active non-flat / vertical selective organization
-> recurrent localized formed unity
-> One / Selection-position
-> stronger standing / bearing / subject relations downstream
```

The current reconstruction has author-adjudicated meaning for the middle term, but no unambiguous canonical owner yet.

This audit prepares the author decision. It changes no canonical file and does not itself select an option.

---

## 1. Minimum meaning already paid by author adjudication

The owner must be able to preserve all of the following without strengthening them:

```text
A. Selection precedes a completed chooser / One.

B. Vertical organization is actively generated / regenerated through Selection;
   it is not defined as passive historical sediment.

C. Not every event-level verticalization is a One.

D. One is a localized, lineage-relative, processual formed unity;
   its diachronic continuation is Selection-mediated recurrent reconstitution.

E. Selection-position_t is the time-local operative from-where
   of that continuing organization.

F. One / Selection-position
   != Stable ISP automatically
   != Bearer automatically
   != subject-position automatically
   != phenomenality automatically.

G. History / writeback may condition continuation and later reconstitution,
   but history alone is not the ontological source of verticality.
```

Still OPEN and therefore prohibited from being silently settled by owner design:

```text
formal necessary-and-sufficient One theorem;
all vertical structures -> One;
One-level perspective universal sufficiency;
strict numerical identity;
unique successor after branching;
Bearer necessary/sufficient conditions;
One -> Stable ISP implication;
One -> subject-position implication;
phenomenality;
new Level 1 standing;
scientific distinctiveness.
```

---

## 2. Owner criteria

A suitable owner should satisfy six constraints.

```text
C1 upstream fidelity:
keep Selection -> vertical formation -> One / Selection-position order visible.

C2 claim-level fidelity:
do not present an open reconstruction as a stronger P1 theorem than paid.

C3 downstream separation:
do not collapse One into Stable ISP, Bearer, subject-position or collective ISP.

C4 cross-domain neutrality:
do not make a domain bridge or empirical proxy define the ontology.

C5 single-owner clarity:
there should be one semantic definition authority with downstream crosslinks.

C6 manageable blast radius:
avoid forcing simultaneous resolution of sigma, d, T_dir, subjecthood,
collective subjecthood or phenomenality.
```

## 3. O1 — refine 21C B13 `formed process` into One

Current B13 lives in:

`Core/SRT_Core_21c_Bridge_Hypotheses.md`

and is explicitly P2/P3. Its present three-level distinction is:

```text
formed process
-> structurally stable ISP
-> generatively healthy ISP.
```

### Strengths

- minimal file proliferation;
- already sits adjacent to Stable ISP / generative-health distinctions;
- low local edit count.

### Blocking problem

The current One / Selection-position burden is intended as ontology/formation architecture upstream of Stable ISP. B13 is a bridge / canonical-interpretation layer whose own file header forbids P2/P3 material from overriding higher ontology owners.

Promoting One by rewriting `formed process` inside B13 would therefore create the wrong authority direction:

```text
bridge-layer distinction
-> foundational formation ontology
```

It would also leave active vertical generation without a proper owner and encourage readers to reconstruct One from stabilization language rather than from the Selection-first formation spine.

### Verdict

```text
O1 = NOT RECOMMENDED
C1: weak
C2: weak
C3: acceptable
C4: fail / layer inversion risk
C5: superficially simple
C6: good locally, poor semantically
```

B13 should remain a crosswalk surface, not the primary owner.

## 4. O2 — insert thin One standing into 21B / P1

Candidate owner:

`Core/SRT_Core_21b_Constitutive_Theorems.md`

Possible shape:

```text
P1-Txx Formed One / Selection-position standing
```

between primitive Selection and P1-T06 Stable ISP.

### Strengths

- places One upstream of Stable ISP in the core reading path;
- no separate canonical file;
- strong discoverability and cross-domain visibility.

### Main problem 1 — claim hardness

21B is explicitly the P1 theorem set: claims internal to SRT once P0 is granted.

But current One work has author-adjudicated **direction and typed boundaries**, while these remain OPEN:

```text
formal necessary/sufficient One theorem;
D4b;
D4c;
universal One-level perspective sufficiency.
```

A positive One definition can be canonical without yet deserving an unconditional P1 theorem label. Putting it directly into 21B risks converting an accepted reconstruction architecture into a stronger theorem merely because of file placement.

### Main problem 2 — missing canonical formation owner upstream

The repaired ontology requires:

```text
Selection-generated active non-flat / vertical organization
before
One / Selection-position.
```

Current L0 canonically supplies subjectless Selection, finite positionality and the actualisation floor, but it does not own the later `active vertical organization` reconstruction in the #938 sense.

Therefore a 21B One theorem would face an undesirable choice:

```text
(a) cite a noncanonical vertical-formation premise;
(b) omit the premise and make historical recurrence look like the source of One;
(c) silently canonize vertical formation inside the One theorem itself.
```

All three are poor first-owner designs.

### Verdict

```text
O2 = PLAUSIBLE LATER, NOT RECOMMENDED AS FIRST OWNER
C1: incomplete unless vertical formation is simultaneously landed
C2: theorem-overstatement risk
C3: good after #940
C4: good
C5: good
C6: medium / hidden semantic blast radius
```

21B should crosslink the eventual owner and may later host derived P1 consequences once the formation relation is hardened.

## 5. O3 — dedicated thin L1 canonical formation owner

Recommended concrete form:

```text
Core_Law/SRT_One_Formation.md
id: SRT-ONE-FORMATION
layer: L1
claim_mode: canonical or bounded hybrid
claim hardness: typed internally; no automatic new Level assignment
```

The file would be deliberately narrow. It would own only the formation semantics needed to bridge L0 subjectless Selection to downstream standing architectures.

### Proposed owner scope

```text
1. active vertical formation
   = Selection generates / regenerates a non-flat relation of manifestation,
     relative backgrounding and later selectability;
   != passive sediment.

2. One
   = localized, lineage-relative, processual formed unity
     whose continuation is Selection-mediated recurrent reconstitution.

3. Selection-position_t
   = time-local operative from-where of that continuing One.

4. continuity boundary
   history / writeback can condition later reconstitution
   but does not by itself generate verticality or establish One.

5. separation guards
   verticalization != One automatically;
   One != Stable ISP;
   One != Bearer;
   One != subject-position;
   One != experiencer.
```

It would explicitly leave perspective sufficiency, Bearer, subjecthood, sigma/d/T_dir and numerical identity outside its positive definition.

### Why this fits the repository architecture

The repository already uses `Core_Law/` L1 owner files for concept families whose canonical semantic role is broader than a single P1 theorem and whose internal claims have mixed hardness, e.g. Individuation, Irreversibility, Collective Selection and Suffering.

One / Selection-position now has the same architectural need: a semantic owner, not yet an unconditional theorem package.

### Required downstream synchronization after author approval

A bounded C-risk landing would likely touch:

```text
NEW  Core_Law/SRT_One_Formation.md
EDIT CANONICAL_REGISTRY.md
EDIT Core/SRT_Core_21b_Constitutive_Theorems.md
     -> crosslink P1-T06 downstream of the formation owner; no new One theorem required
EDIT Core/SRT_Core_21c_Bridge_Hypotheses.md B13
     -> formed-process / Stable-ISP crosswalk, not owner
EDIT Core_Law/SRT_Individuation.md
     -> scope guard: subject-position individuation is downstream of formed position;
        do not settle sigma ontology in this landing
EDIT Core_Law/SRT_Collective_Selection.md only if a minimal higher-order-One crosslink is mechanically required;
     otherwise defer semantic collective repair.
```

The landing should avoid d, T_dir, phenomenality, suffering and Level-2 work.

### Cost

- adds one canonical owner and registry entry;
- requires careful backlink discipline;
- creates modest owner proliferation.

Those costs are visible and governable. They are preferable to hiding formation ontology inside a bridge or theorem file whose claim level is wrong.

### Verdict

```text
O3 = RECOMMENDED
C1: strongest
C2: strongest
C3: strongest
C4: strongest
C5: strong
C6: medium but explicit / controllable
```
