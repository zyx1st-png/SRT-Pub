An overly strong dialogue formula was:


The dialogue pressure that “every recall is learning” captures the reconstructive intuition but is too universal.



The Extended Mind literature is a strong counterexample family to that anatomical cut.

Therefore the **review recommends** a closure-based rather than anatomical typing. The corrected trace marks this as M-level / pending author second adjudication rather than silently presenting it as the author's settled replacement meaning.

## 4. External theory pressure

## 4.1 Robert Epstein — useful anti-copy pressure, overstrong anti-representation conclusion

Source:

Robert Epstein, “The Empty Brain,” Aeon, 2016.
https://aeon.co/essays/your-brain-does-not-process-information-and-it-is-not-a-computer

Epstein is strongest when attacking literal computer-file metaphors:

- stored environmental copies;
- memory registers;
- retrieval of unchanged internal replicas.

But his broader rhetoric says organisms do not develop representations, memories, encoders, decoders and similar internal constructs at all.

That universal negative is not supported by the current neuroscience landscape.

Disposition:

~~~text
ANTI-LITERAL-COPY PRESSURE = INHERIT
NO MEMORY TRACE / NO REPRESENTATION OF ANY KIND = REJECT AS OVERSTRONG
~~~

## 4.2 Engram theory — blocks “nothing is stored,” supports dynamic historical structure

Strong sources:

1. Choucry A, Nomoto M, Inokuchi K. “Engram mechanisms of memory linking and identity.”
   Nature Reviews Neuroscience 25, 375–392 (2024).
   DOI: 10.1038/s41583-024-00814-0
   https://www.nature.com/articles/s41583-024-00814-0

2. Tomé DF et al. “Dynamic and selective engrams emerge with memory consolidation.”
   Nature Neuroscience 27, 561–572 (2024).
   DOI: 10.1038/s41593-023-01551-w
   https://www.nature.com/articles/s41593-023-01551-w

3. Guskjolen A, Cembrowski MS. “Engram neurons: Encoding, consolidation, retrieval, and forgetting of memory.”
   Molecular Psychiatry 28, 3207–3219 (2023).
   DOI: 10.1038/s41380-023-02137-5
   https://www.nature.com/articles/s41380-023-02137-5

Pressure:

- memory is linked to persistent, manipulable neuronal / synaptic substrates;
- these substrates can be necessary / sufficient in bounded recall paradigms;
- engrams can be dynamic, selective, reconfigured and history-dependent;
- forgetting can arise from retrieval failure or trace degradation.

Therefore the dialogue should not say:

~~~text
memory storage = false.
~~~

Safer:

~~~text
literal experiential copy storage = rejected;
persistent dynamic memory-supporting substrate = compatible;
retained history constrains later generation = plausible bridge.
~~~

This is one of the most important narrowing corrections.

Classic sources:

## 4.4 Neural decoding — blocks “decodable = represented”

Source:

Kriegeskorte N, Douglas PK.
“Interpreting encoding and decoding models.”
Current Opinion in Neurobiology 55, 167–179 (2019).
DOI: 10.1016/j.conb.2019.04.002
https://pmc.ncbi.nlm.nih.gov/articles/PMC6705607/

This literature warns that successful prediction / decoding does not by itself establish:

- what information is represented for the organism;
- that the brain uses the experimenter's decoder;
- a unique representational format;
- causal use by the cognitive system.

Therefore the dialogue's guard is sound:

~~~text
experimenter can decode X
-/-> organism stores / represents X in the strong content sense.
~~~

However, this does not prove that online perceptual representation is impossible. It only blocks the inference from decodability alone.
