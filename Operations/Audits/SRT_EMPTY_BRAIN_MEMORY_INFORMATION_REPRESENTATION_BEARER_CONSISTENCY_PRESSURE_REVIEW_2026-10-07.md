# Consistency and pressure review — “Empty Brain” dialogue: memory, information, representation, Gate and Bearer continuity

## 0. Review status

**Verdict: PASS FOR NONCANONICAL LANDING / CANONICAL = HOLD.**

This review tests three things:

1. dialogue-internal consistency;
2. compatibility with current repository owners / OPEN guards;
3. pressure from strong external neighboring theories and empirical literatures.

This is a **same-session machine pressure review**, not an independent C-class pre-merge review. No C-class canonical semantic edit is present in this package, so `Governance/SRT_EDIT_PROTOCOL.md` does not require an independent semantic reviewer before merge.

The package is acceptable as provenance + bounded analysis if the narrowing guards in this file remain attached.

## 1. Executive result

### PASS

The central chain is internally coherent and substantially aligned with existing repository direction:

~~~text
past interaction
-> historical transformation
-> retained effective constraint
-> later Selection / objectification changes
~~~

rather than:

~~~text
experience
-> stored experiential copy
-> later retrieval of that same copy.
~~~

The dialogue also coherently separates:

~~~text
numerical internal identity
from
task / transform / coarse-graining equivalence;
~~~

and:

~~~text
event-local Position
from
diachronic continuity.
~~~

### HOLD / quarantine

The following dialogue judgments exceed current canonical closure and must remain noncanonical:

- total Gate/history erasure terminates numerical bearer identity;
- gradual total replacement preserves numerical bearer identity;
- exact copying produces two bearers after divergence;
- merge produces a new higher-order bearer while lower-level bearers may persist;
- nested bearer architecture;
- agent/proxy consequence-history closure as sufficient or near-sufficient bearer criterion;
- one shared deeper generative source for multiple bearers.

Current owners leave exact One boundary, strict identity, branch identity and merge identity OPEN.

## 2. Dialogue-internal consistency

### 2.1 Memory line — PASS after narrowing

The dialogue's strongest stable form is:

~~~text
memory
!= stored experiential content-copy;

memory can involve
retained history-bearing organization
that constrains later generation.
~~~

This is coherent with the author's statements that representation is regenerated and with the later latent-Gate discussion.

Potential contradiction resolved:

- earlier shorthand risked saying “nothing is stored”;
- later discussion required persistent Gate / historical efficacy.

The correct reconciliation is:

~~~text
no literal copy-store claim
!= no persistent neural / bodily / relational trace.
~~~

### 2.2 Forgetting — REVISE / narrowed in source trace

An overly strong dialogue formula was:

~~~text
forgetting = current inability to regenerate.
~~~

That is too narrow.

External memory science distinguishes at least:

- retrieval / accessibility failure;
- degradation / weakening / remodeling of memory-supporting traces.

The source trace now records the weaker statement.

### 2.3 Recall as learning — REVISE / narrowed

The dialogue pressure that “every recall is learning” captures the reconstructive intuition but is too universal.

Safer:

~~~text
retrieval can change the later memory state
through updating / reconsolidation / re-encoding,
but durable modification is not guaranteed on every retrieval.
~~~

### 2.4 Internal versus external Gate — PASS only after spatial de-biasing

The author's direct distinction:

> “内部的gate会持续地产生影响。保存到数据库里的外部 Gate并不影响bearer的连续性。”

is coherent if “internal” means:

> constitutive of the continuing bearer history / consequence / future-selection closure.

It becomes vulnerable if interpreted anatomically as:

~~~text
inside skull = constitutive
outside skull = noncognitive.
~~~

The Extended Mind literature is a strong counterexample family to that anatomical cut.

Therefore the source trace correctly rewrites the burden in closure terms rather than location terms.

## 4. External theory pressure

## 4.1 Robert Epstein — useful anti-copy pressure, overstrong anti-representation conclusion

Source:

Robert Epstein, “The Empty Brain,” Aeon, 2016.
https://aeon.co/essays/your-brain-does-not-process-information-and-it-is-not-a-computer

Epstein is strongest when attacking literal computer-file metaphors:

- stored environmental copies;
- memory registers;
- retrieval of unchanged internal replicas.

But his broader rhetoric says organisms do not develop representations, memories, encoders, decoders and similar internal constructs at all.

That universal negative is not supported by the current neuroscience landscape.

Disposition:

~~~text
ANTI-LITERAL-COPY PRESSURE = INHERIT
NO MEMORY TRACE / NO REPRESENTATION OF ANY KIND = REJECT AS OVERSTRONG
~~~

---

## 4.2 Engram theory — blocks “nothing is stored,” supports dynamic historical structure

Strong sources:

1. Choucry A, Nomoto M, Inokuchi K. “Engram mechanisms of memory linking and identity.”
   Nature Reviews Neuroscience 25, 375–392 (2024).
   DOI: 10.1038/s41583-024-00814-0
   https://www.nature.com/articles/s41583-024-00814-0

2. Tomé DF et al. “Dynamic and selective engrams emerge with memory consolidation.”
   Nature Neuroscience 27, 561–572 (2024).
   DOI: 10.1038/s41593-023-01551-w
   https://www.nature.com/articles/s41593-023-01551-w

3. Guskjolen A, Cembrowski MS. “Engram neurons: Encoding, consolidation, retrieval, and forgetting of memory.”
   Molecular Psychiatry 28, 3207–3219 (2023).
   DOI: 10.1038/s41380-023-02137-5
   https://www.nature.com/articles/s41380-023-02137-5

Pressure:

- memory is linked to persistent, manipulable neuronal / synaptic substrates;
- these substrates can be necessary / sufficient in bounded recall paradigms;
- engrams can be dynamic, selective, reconfigured and history-dependent;
- forgetting can arise from retrieval failure or trace degradation.

Therefore the dialogue should not say:

~~~text
memory storage = false.
~~~

Safer:

~~~text
literal experiential copy storage = rejected;
persistent dynamic memory-supporting substrate = compatible;
retained history constrains later generation = plausible bridge.
~~~

This is one of the most important narrowing corrections.

## 4.3 Reconsolidation / updating — supports generativity, not universal rewrite

Classic source:

Dudai Y. “The restless engram: consolidations never end.”
and related reconsolidation literature; a useful review is:
Nader K, Hardt O. “A single standard for memory: the case for reconsolidation.”
Nature Reviews Neuroscience 10, 224–234 (2009).
https://www.nature.com/articles/nrn2590

Pressure:

Retrieval can return a consolidated memory to a labile state and support updating, but not every retrieval event guarantees the same degree or kind of durable change.

Disposition:

~~~text
recall can regenerate / update = SUPPORTED DIRECTION
every recall necessarily creates durable new memory = TOO STRONG
~~~

## 4.4 Neural decoding — blocks “decodable = represented”

Source:

Kriegeskorte N, Douglas PK.
“Interpreting encoding and decoding models.”
Current Opinion in Neurobiology 55, 167–179 (2019).
DOI: 10.1016/j.conb.2019.04.002
https://pmc.ncbi.nlm.nih.gov/articles/PMC6705607/

This literature warns that successful prediction / decoding does not by itself establish:

- what information is represented for the organism;
- that the brain uses the experimenter's decoder;
- a unique representational format;
- causal use by the cognitive system.

Therefore the dialogue's guard is sound:

~~~text
experimenter can decode X
-/-> organism stores / represents X in the strong content sense.
~~~

However, this does not prove that online perceptual representation is impossible. It only blocks the inference from decodability alone.

## 4.5 Hyperalignment — supports cross-bearer equivalence without numerical state identity

Sources:

1. Haxby JV et al.
   “A common, high-dimensional model of the representational space in human ventral temporal cortex.”
   Neuron 72(2), 404–416 (2011).
   DOI: 10.1016/j.neuron.2011.08.026
   https://pmc.ncbi.nlm.nih.gov/articles/PMC3201764/

2. Haxby JV et al.
   “Hyperalignment: Modeling shared information encoded in idiosyncratic cortical topographies.”
   eLife / review perspective, 2020.
   https://pmc.ncbi.nlm.nih.gov/articles/PMC7266639/

Pressure:

Individual brains can have idiosyncratic fine-scale cortical topographies while transformations align their population-response geometry into a common model space.

This is highly compatible with the dialogue distinction:

~~~text
internal implementation identity = NO;
cross-subject geometric equivalence under transform = YES.
~~~

It does **not** prove the SRT Gate interpretation; hyperalignment itself uses representational / information-space language.

Disposition:

~~~text
EMPIRICAL REALIZATION PRESSURE = SUPPORTIVE
SRT INTERPRETATION = OPTIONAL / NOT PROVEN
~~~

## 4.6 Extended mind — pressure against skull-bound “internal Gate”

Source:

Clark A, Chalmers D.
“The Extended Mind.”
Analysis 58(1), 7–19 (1998).
DOI: 10.1093/analys/58.1.7
https://doi.org/10.1093/analys/58.1.7

The extended-mind argument pressures any simple equation:

~~~text
cognitive = intracranial.
~~~

An external notebook, device or other artifact may become constitutively integrated under strong coupling / availability / functional-role conditions.

This does not imply that every database copy is part of the bearer.

The dialogue's better distinction is therefore:

~~~text
spatially external / internal
!=
scaffold / bearer-constitutive closure.
~~~

This is a substantive improvement over the initial wording.

## 4.7 Shannon information — semantic claim must remain scoped

Source:

Claude E. Shannon.
“A Mathematical Theory of Communication.”
Bell System Technical Journal 27 (1948), 379–423, 623–656.
https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf

Shannon explicitly brackets semantic meaning from the engineering problem and defines information through message alternatives / probabilities.

Therefore a dialogue claim such as:

~~~text
information is constructed by a bearer
~~~

cannot be allowed to read as a universal denial of Shannon information.

The accepted form is:

~~~text
semantic / cognitive information as meaning-for-a-bearer
is relation- and task-dependent.
~~~

No claim is made here against formal information theory.

## 4.8 Gibsonian ecological information — second information pressure

Useful reviews:

- “The History and Philosophy of Ecological Psychology”
  https://pmc.ncbi.nlm.nih.gov/articles/PMC6280920/
- “Defining the Environment in Organism–Environment Systems”
  https://pmc.ncbi.nlm.nih.gov/articles/PMC7358536/

Gibsonian ecological psychology treats structured environmental arrays as carrying information that can specify affordances without requiring an internal representational reconstruction in the conventional sense.

This creates a productive contrast:

~~~text
Shannon information
!= ecological information
!= semantic / cognitive information
!= SRT dialogue Gate scaffold.
~~~

The current package should not attempt to collapse these meanings.

## 5. Representation terminology pressure

The dialogue reached a clean narrow use:

> representation = absent-object / generative surrogate Gate organization.

This is conceptually useful because it prevents:

~~~text
any neural discriminability
=> representation.
~~~

But it is not standard scientific usage.

Many cognitive neuroscience models use “representation” for online perceptual population structure as well.

Therefore this package must say:

~~~text
SRT dialogue working definition
!= universal definition of representation.
~~~

`Philosophy/patches/SRT_Philosophy_PH_MR01_Representational_Gradualism_Adjacent_Case_Audit_v0_1.md` already separates:

- evidence for representation;
- ontological degree / boundary of representation;
- representation from Bearer / phenomenality.

The present trace should be routed as an additional bounded pressure, not a replacement of PH-MR01.
