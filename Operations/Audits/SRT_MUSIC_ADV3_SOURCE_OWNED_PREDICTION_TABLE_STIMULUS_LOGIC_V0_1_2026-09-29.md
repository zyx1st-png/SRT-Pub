# Music ADV-3 source-owned prediction table + stimulus logic v0.1

> Role: paper-only design hardening for the only surviving Music E2 design candidate after PR #1087.
>
> Boundary: no experiment, no preregistration, no SRT-specific residual, no Bearer / HP-B / PH-QUAL inference, no cross-domain synthesis.

## 0. Starting point

PR #1087 left only one design question:

~~~text
Can predictability and unfinishedness be cleanly orthogonalized
after strongest tonal-attraction / closure / statistical baselines,
with any later residual also predicting at least one independent probe?
~~~

This file does not assume the answer is yes.

Its first task is to specify what the strongest comparator families already predict.

## 1. Variable discipline

The 2x2 must separate two different burdens.

### 1.1 Predictability

Working meaning:

> How strongly the current local statistical / schematic context constrains the next cadence outcome before it occurs.

Candidate operational families:
- local conditional probability learned during the session;
- IDyOM information content / entropy where implementable;
- Bayesian / tonal expectation estimates;
- independent expectancy manipulation check.

Do not define predictability using the same completion rating that the design is intended to explain.

### 1.2 Completion / unfinishedness

Working meaning:

> Whether the heard cadence / phrase is experienced as locally closed or as requiring / inviting further continuation.

Candidate structural anchors:
- authentic tonic closure;
- deceptive / non-tonic open ending;
- half-cadential dominant ending where appropriate.

Candidate later readouts:
- completion judgment;
- "could stop here" judgment;
- end-imminence / closure rating;
- boundary placement.

Do not define completion as low entropy or high predictability.

## 3. Immediate consequence — the 2x2 dissociation is not itself an SRT residual

Even a perfect empirical pattern:

~~~text
A high predictability + high completion
B high predictability + high unfinishedness
C low predictability  + high completion
D low predictability  + high unfinishedness
~~~

can in principle be jointly paid by:

~~~text
statistical expectation model
+
tonal closure / attraction model
+
tension model
+
event-boundary model.
~~~

Therefore:

> Factorial dissociation is a construct-validity result, not an SRT increment result.

An E2 residual would require a stronger multi-probe / transfer burden after the combined baseline is paid.

## 4. Primary stimulus logic — ADV-3A local-statistical adaptation x cadence closure

### 4.1 Why use local adaptation?

Natural tonal music couples:
- frequent events;
- stable events;
- expected events;
- closing events.

Trying to find four naturally occurring quadrants risks merely selecting different harmonic functions.

A stronger route is to manipulate local probability by exposure while keeping cadence type as the closure factor.

Existing cadence-adaptation work reports that expectations for rare cadences can increase with local repetition / probability, supporting short-term belief updating over entrenched long-term statistics.

### 4.2 Candidate cadence families

Closing target family:

~~~text
PAC-like authentic tonic closure
~~~

Open / unfinished target family:

~~~text
deceptive cadence (DC) as primary candidate
or
half cadence (HC) as secondary open-ending family.
~~~

Reason for preferring DC in the first paper design:
- it can begin from a strong authentic-cadence setup;
- it deviates at the target;
- it leaves a non-tonic harmonic result and is commonly treated as relatively open;
- rare-cadence adaptation already supplies a relevant statistical-learning precedent.

HC remains useful as an independent robustness family because dominant endings are strongly associated with continued openness.

### 4.3 Order-/window-conditioned local probability design — source-fidelity correction

Chander–Aslin did **not** train different key identities to predict different cadence types. They held the global incidence of a priori likely vs unlikely cadences at 50–50 and changed **item order**, so the local probability of the unlikely cadence varied over the unfolding experiment.

Therefore the primary ADV-3A implementation should follow that logic more closely.

Illustrative design logic only:

~~~text
Window / phase W_PAC:
PAC locally frequent
DC locally rare

Window / phase W_DC:
DC locally frequent
PAC locally rare

global session incidence:
PAC ≈ DC
~~~

Exact window length and probability ratio are not frozen here.

Candidate conceptual cells:

~~~text
A:
PAC encountered when current local history favors PAC
= high local predictability + structurally closing

B:
DC encountered when current local history favors DC
= high local predictability + structurally open

C:
PAC encountered when current local history favors DC
= lower local predictability + structurally closing

D:
DC encountered when current local history favors PAC
= lower local predictability + structurally open
~~~

Primary implementation principle:

> Treat local expectedness as a **continuous online quantity** estimated from the preceding trial history, not merely as a categorical block label.

Order schedules should be counterbalanced so that:
- global PAC/DC incidence remains matched;
- early vs late experiment position is not confounded with one cadence type;
- local-probability trajectories reverse across schedules;
- no explicit key-to-cadence rule is needed;
- participants can learn incidentally from the unfolding statistics.

Source-fidelity guard:

~~~text
Chander-Aslin
supports:
item-order / local-statistical adaptation;

does not establish:
the exact window size,
the exact probability ratio,
or successful orthogonalization of predictability and completion.
~~~

### 4.4 Why this is stronger than a simple PAC-vs-DC comparison

A simple comparison:

~~~text
PAC
vs
DC
~~~

confounds:
- schematic expectancy;
- local transition frequency;
- target stability;
- closure;
- tension.

The order-/window-conditioned schedule tries to separate:
- what is locally likely **given the immediately preceding session history**
from
- what counts as tonal closure.

It also reduces the explicit contingency-learning risk created by the discarded K1/K2 key-cue version.

## 5. The critical bottleneck — expectedness separation, not absolute low-P PAC

The source-fidelity audit shows that the idealized cell:

~~~text
C = absolutely low predictability + high completion
~~~

is too strong as a default empirical requirement.

PAC carries a strong long-term schematic prior. Chander–Aslin found short-term adaptation without showing that the PAC prior was globally erased.

Therefore the primary gate is:

~~~text
same PAC-like closing class
under different local histories
-> independently verified expectedness separation
while
completion / closure remains stably high.
~~~

### C-separation failure rule

If the online / manipulation-check expectedness for PAC changes only trivially across the source-faithful order schedules:

~~~text
ADV-3A' = FAILED ORTHOGONALIZATION.
~~~

Do not reinterpret experimental frequency as psychological predictability.

### Completion-preservation failure rule

If the local-history manipulation substantially erodes the PAC-vs-DC completion contrast:

~~~text
ADV-3A' = FAILED CONSTRUCT SEPARATION.
~~~

The four-cell diagram remains a visualization only; the primary analysis target is a continuous crossed relation:

~~~text
online local expectedness q_t
x
cadence closure class.
~~~

## 6. Backup stimulus logic — ADV-3B model-screened closing targets

If Cell C fails under local adaptation, use a paper-only search for:

> a cadence / target that is structurally stable / closing but relatively improbable under strong statistical models.

Candidate logic:

~~~text
high closure
= stable tonic / closing-schema evidence;

low predictability
= low held-out probability under IDyOM / Bayesian / corpus model
  before human outcome ratings are inspected.
~~~

Do not hand-pick a "surprising tonic" because it sounds theoretically useful.

Required route:

1. generate / collect candidate cadence excerpts;
2. score statistical expectedness independently;
3. score closure structure independently;
4. select candidate C only from predeclared model disagreement;
5. then inspect human data later, if an experiment is separately authorized.

If no robust C candidates exist:

~~~text
ADV-3B = FAILED;
2x2 route contracts.
~~~

## 7. Source-owned qualitative prediction table for ADV-3A

The following is a prediction contract, not a claim that every source computes these exact four values numerically.

| Family | A: high-P PAC | B: high-P DC | C: low-P PAC | D: low-P DC |
|---|---|---|---|---|
| local statistical / Bayesian adaptation | high local expectedness | high local expectedness if adaptation succeeds | lower local expectedness if adaptation succeeds | lower local expectedness |
| long-term tonal schema | PAC strongly licensed | DC remains weaker / non-tonic despite local learning | PAC remains schematically strong — threat to C manipulation | DC weak / non-tonic |
| cadence closure models | high closure | low / incomplete closure | high closure | low / incomplete closure |
| Bharucha / tonal stability | stable tonic resolution | unstable / non-tonic residual relation | stable tonic resolution | unstable / non-tonic residual relation |
| implication / musical-force families | closure / reduced continuation force expected | continuation / unresolved implication may remain | closure despite local rarity | unresolved continuation plus local rarity |
| Huron-style expectation | local and schematic expectation can both favor PAC-like resolution | locally learned expectation may raise DC predictability while schematic expectation still favors tonic resolution — predictable-but-open is therefore not novel | schematic PAC expectation may prevent true low-P | local rarity and schematic non-tonic status can both lower expectedness |
| Farbood / TenseMusic | tension depends on path and surface features, not the 2x2 label alone | same | same | same |
| online Bayesian / local-frequency model | high when recent trial history favors PAC | high when recent trial history favors DC | lower when recent history disfavors PAC | lower when recent history disfavors DC |
| standard IDyOM STM | **not automatically applicable to cross-trial adaptation** because the official STM learns incrementally within each melody from an initially empty state | same limitation | same limitation | same limitation |
| IDyOM LTM / combined corpus expectation | preserves long-term schematic pressure favoring corpus-typical continuations; useful as a long-term comparator, not a substitute for the online session learner | same | PAC prior may remain high despite local rarity | DC prior may remain low despite local frequency |
| event / boundary models | closing PAC may strengthen boundary signal | open DC may weaken or delay boundary | closing PAC may still strengthen boundary despite low local P | open DC likely weak / delayed boundary |

Crucial implication:

> B is not the SRT residual. Strong theories already make it plausible that a continuation can be highly expected yet still structurally open.

The design value of B is to force the study to stop equating predictability with completion.

## 8. Measurement separation — avoid circular factor definition

A future experiment, if ever authorized, should not use one sample / one rating to define both predictors and outcomes.

Paper-level preferred separation:

### Predictability construction / check
- exposure schedule / conditional frequency is fixed ex ante;
- model-based probability is computed independently;
- a separate manipulation-check sample or separate trials may rate expectedness.

### Completion construction / outcome
- cadence type supplies a stimulus-side structural anchor;
- existing music-theory descriptions treat PAC-like authentic endings as stable/resolved and HC/DC families as relatively open/unresolved;
- **Sears 2020 end-imminence ratings are not sufficient to validate post-event completion**;
- completion / "could stop here now" therefore requires a separate post-event manipulation check or independent sample;
- that check must be fixed before any E2 outcome analysis and must not be redefined after seeing the main results.

### Independent second probe
At least one:
- phrase boundary placement;
- next-event continuation choice;
- end-imminence response;
- memory grouping;
- later reinterpretation measure.

Tension may be included but should not be the only second probe because several mature models already directly predict it.

## 9. Fair combined baseline

The adversarial baseline should not be a strawman single model.

Declare a stacked / ensemble comparator family:

~~~text
B*
=
statistical expectation
+ tonal closure / attraction
+ continuous tension
+ event-boundary prediction.
~~~

Possible source-owned components:

~~~text
online Bayesian / rolling local-probability expectation model
+
IDyOM LTM / corpus-statistical expectation
+
cadence class / Lerdahl-Narmour-Bharucha structural terms
+
Farbood or TenseMusic tension
+
event-segmentation / grouping predictor.
~~~

Future model comparison must control:
- parameter count / model complexity;
- training-data leakage;
- stimulus-selection leakage;
- held-out evaluation;
- whether one model was tuned on the same human ratings used as outcomes.

No SRT-side model gets extra flexibility merely because it is "integrative."

## 10. What would actually count as E2-PREPARATION progress?

Not:

~~~text
main effect of local probability;
main effect of cadence closure;
interaction between the two;
B cell exists.
~~~

Those results are already compatible with strong neighbors.

Worth preserving for a future prereg preparation only if:

1. ADV-3A or ADV-3B achieves verified orthogonalization;
2. the strong combined baseline B* is frozen;
3. at least two outcome families are specified;
4. a single predeclared context-organization variable predicts a coordinated cross-probe residual or transfer pattern;
5. the same residual is not obtained merely by adding model outputs with unconstrained weights;
6. failure permits full source absorption.

Until then:

~~~text
E2 residual = NONE
SRT increment = NONE
preregistration = NO
experiment = NO
~~~

## 11. Kill / contraction rules

### K1 — predictability manipulation fails

If local adaptation does not create separable high / low expectedness:

~~~text
ADV-3A = FAIL
~~~

### K2 — PAC expectedness cannot be separated across local histories

If the same PAC-like closing class shows no meaningful independently verified expectedness shift across the source-faithful order schedules:

~~~text
continuous crossed-design orthogonalization = FAIL OR CONTRACT
~~~

### K3 — combined baseline fully pays the pattern

If B* predicts:
- completion;
- expectedness;
- second probe;
with no stable held-out residual:

~~~text
ADV-3 E2 residual
= NO LOCAL COMPARATIVE INCREMENT.
~~~

### K4 — residual exists only in tension ratings

If the residual does not transfer to a second probe:

~~~text
do not promote to E2 whole-geometry candidate.
~~~

### K5 — residual requires post-hoc weights / stimulus exclusion

If the candidate only works after inspecting outcomes and retuning the relation:

~~~text
design = INVALID FOR E2 PROMOTION.
~~~

### K6 — local probability manipulation erases the closure factor

If repeated local exposure makes PAC and DC / HC converge so strongly in completion judgments that the closing-vs-open structural contrast is no longer stable:

~~~text
2x2 construct separation = FAIL.
~~~

Do not rename the remaining learned difference as "unfinishedness."

### K7 — predictability depends only on explicit contingency strategy

If participants can obtain the high/low predictability manipulation only by explicitly discovering the order schedule / trial contingency, and the effect does not survive an incidental-learning implementation:

~~~text
the manipulation may remain useful for generic prediction research,
but it is not evidence for pre-object / pre-explicit musical orientation.
~~~

This does not automatically invalidate the behavioral design; it changes the explanatory level of the result.
