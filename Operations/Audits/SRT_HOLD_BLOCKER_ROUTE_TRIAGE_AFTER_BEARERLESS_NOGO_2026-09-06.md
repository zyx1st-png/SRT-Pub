
This is more operational than the bearerless-metaphysics route.

### 1.2 Strongest-neighbor pressure

Primary comparison anchors now checked at source level:

- Barandiaran, Di Paolo & Rohde (2009), `Defining Agency`, DOI 10.1177/1059712309343819: a genuine agent must define its own individuality, be an active source of activity, and regulate activity relative to norms.
- Mossio & Moreno (2010), `Organisational closure in biological organisms`, PMID 21162371: biological organization is characterized by a specific causal regime of organisational closure generated by mutually constraining material structures.

These create a **matching-coherence problem**.

If an allegedly autonomous unit can simply be discarded and replaced by an untouched checkpoint while the relevant burden closes elsewhere, a mature autonomy/enactivist account can reply:

```text
the replaced instance was not the same continuing autonomous individual;
or
the larger checkpoint/deployment infrastructure was the relevant organized unit.
```

Thus a naive `same autonomy, different non-outsourcing` pair can collapse by **boundary reselection**.

### 1.3 Can the route be repaired without cheating?

A narrower pair remains coherent:


For example:

```text

```

But then the result is already largely visible in ordinary system identity / fault-tolerance / continuity terms:

```text

B preserves service function by replacement.
```

SRT may classify:

```text

```

more explicitly, but no independent downstream prediction has yet been shown once unit boundary and state history are correctly declared.

## 2. Candidate route B — irreversibility / reversal / state restoration

### 2.1 Why this is more upstream

P0-03 currently states minimally:

```text
once a Selection is anchored into L1 and leaves history in L2,
it cannot be treated as never having occurred;
any reversal is itself a new Selection event with its own trace.
```

The L0 metaphysics prose is stronger:

```text
Selection changes the possibility landscape;
a later erasure is a new Selection;
there is no inverse Selection operation;
spacetime-level reversal is described as structurally impossible.
```

But the 2026-09-02 intra-file role audit explicitly classifies these stronger irreversibility/time claims as:

```text
strong metaphysical theory / conceptual bridge + historical formalization
```

and states that they do **not** receive immunity merely from appearing in L0.

Therefore this route is pressureable.

### 2.2 External physics pressure

Relevant mature results include:

- Korotkov & Jordan (2006), PRL 97, 166805: weak measurement undoing is possible probabilistically.
- Schindler et al. (2013), PRL 110, 070403: a fully projective measurement on one ion can be deterministically reversed at the encoded logical-information level using quantum error correction; the information needed for recovery is distributed over additional ions.
- Loschmidt-echo / time-reversal experiments can coherently reverse substantial quantum dynamics; imperfect return can arise from perturbations, control error and many-body sensitivity.
- Bennett's reversible-computation analysis preserves the in-principle distinction between logical reversibility and logically irreversible erasure; logically reversible operations need not carry the ordinary Landauer erasure cost merely because they are computations.

These results do **not** by themselves show that a past event becomes `never happened`.

They do show that SRT must distinguish:

```text
state / information restoration
from
historical-event erasure.
```

### 2.3 Cheap positive reading — already absorbed

A weak SRT reading says:

```text
system S is restored,
but recovery required controller / ancilla / environment / protocol history;
therefore the enlarged causal state is not the pre-event state.
```

This is compatible with ordinary quantum information theory and reversible control.

It does not earn Level 1 or Level 2 for SRT.

### 2.4 Tempting strong reading — already blocked internally

A stronger candidate would say:

```text
complete current causal state is identical
+
history differs
-> future differs.
```

But Cycle 1 explicitly rejected this requirement:

> if complete current causal state genuinely contains every causally effective historical residue, requiring different futures adds an unnecessary non-Markovian metaphysical claim.

Therefore the HOLD blocker cannot be paid by silently resurrecting this route.

### 2.5 The genuine unresolved fork

What has **not** yet been author-adjudicated at the required precision is the relation between P0-03 and perfect restoration.

Three readings must be separated:

#### IRR-A — historical-fact / path reading

```text
a Selection occurred;
a later inverse-looking process is a second event;
the path/history contains both events;

if the complete present causal state is genuinely restored,
no extra future causal difference is required solely because the past path differed.
```

This preserves:

```text
state restoration != event-never-occurred
```

without adding hidden causal state.

#### IRR-B — unavoidable present causal residue

```text
every actualising Selection must leave some causally effective residue
in the complete current state / enlarged environment;
therefore exact complete-state restoration after genuine Selection is impossible.
```

This is stronger than the Cycle-1 no-hidden-history guard but does not require history-beyond-state: it says the states were never truly identical.

If author-owned, this could become a physics-facing Level-1 candidate because it forbids a class of exact global reversal models.

It would still need a domain-native Level-2 specification defining:

```text
what counts as complete enough;
what residual must remain;
how ordinary controller/environment records are subtracted;
what observation could distinguish SRT from ordinary enlarged-state bookkeeping.
```

#### IRR-C — history beyond complete state

```text
complete current causal state can be identical,
but different histories still change future dynamics.
```

This directly reopens the Cycle-1 rejection and commits SRT to an extra non-Markovian / history-indexed causal structure beyond the declared complete state.

No current author record licenses this move.
