# Minimum unifying tool — D1–D3 deletion / discriminator pass

> **Boundary:** noncanonical machine audit. This pass does not thicken primitive Selection, promote nonclosure to L0, edit the Spine, assign novelty or close Level 2 HOLD.

---

## 0. Executive result

The deletion tests separate three different kinds of burden that had been at risk of being collapsed into one “open Selection” story.

```text
D1 generative non-finality / reselectability
= NOT a primitive Selection admission condition;
= stronger formed-system / generative-health axis.

D2 manifest / Selection-relative-background verticality
= CURRENT primitive Selection typing;
= deletion changes the canonical ontology and collapses toward generic actualisation/process.

D3 position-indexed consequence / burden / future-selectability routing
= NOT primitive;
= downstream formed/L2 architecture axis with real discriminatory force in multi-position systems.
```

Therefore the likely shape of SRT's **minimum unifying tool** is not a thicker universal ontology chain.

It is a layered instrument:

```text
A. thin ontology spine
   +
B. typed cross-cutting axes that switch on only when the relevant formed structure exists.
```

This conclusion follows existing author decisions better than adding `nonclosure`, `payability`, `scaffold`, or `reselectability` as new universal rungs.

## 1. D1 — pre-object actualisation without generative non-finality

### Test

Assume a system has a genuine SRT primitive Selection event:

```text
non-flat openness
-> subjectless actual differentiation
-> manifest / relative-background vertical relation.
```

Now delete the stronger condition:

```text
selection rules / generator remain revisable;
current result cannot become practically absorbing;
formed system preserves generative reselectability.
```

Does the primitive Selection event cease to be Selection?

### Repository answer

**No.**

The August ST-A author decision explicitly separates:

```text
1 event trace / occurrence;
2 organization continuity;
3 local dynamical stability;
4 generative health / rule-revisability.
```

It states that generative reselectability is important for generative health but is **not a necessary definition of a Selection occurrence**.

Therefore:

```text
generative non-finality
cannot be back-promoted into primitive Selection admission
without reopening an already-settled author boundary.
```

### Classification consequence

A system can therefore exhibit:

```text
genuine Selection history
+
strong stabilization
+
poor or lost generative reselectability.
```

Examples at the abstract structural level include:

```text
absorbing institutional rule;
pathological attractor;
rigid learned policy;
scaffold-dependent competence;
locked generator that still produces outputs.
```

The SRT distinction is then:

```text
Selection occurred
!=
the resulting formed system remains generatively healthy.
```

### D1 verdict

```text
non-finality as primitive ontology = REJECT
non-finality / reselectability as cross-layer evaluative axis = RETAIN
July source intuition = downstream/formed interpretation, not L0 rewrite
```

## 2. D2 — indefinite process openness without Selection-relative verticality

### Test

Take a mature process theory that supplies:

```text
preindividual / metastable openness;
ongoing transformation;
structure -> later operation;
continued individuation;
non-finality.
```

But do not require every generative event to have SRT's exact event typing:

```text
manifest side
/
Selection-relative background side
as one asymmetric actual differentiation.
```

Does SRT treat the rival process as already containing primitive Selection?

### Answer

**No, not automatically.**

Simondon is the clean negative control.

The repository already credits him with:

```text
preindividual metastability;
transduction;
operation <-> structure;
individual + milieu formation;
continued individuation;
problem-dimension change.
```

Yet current canonical SRT still types primitive Selection more narrowly as:

```text
actual differentiation
= manifestation / relative backgrounding
= event-level verticality.
```

This is not a vocabulary requirement: the rival would have to show a source-native relation playing the same dependency role.

### Why deletion matters downstream

If primitive verticality is deleted and only generic process differentiation remains, then the current One route changes from:

```text
Selection-generated vertical organization
-> later Selection
-> renewed vertical organization
-> One
```

into:

```text
generic produced structure
-> later process
-> renewed structure
-> process unity.
```

That replacement would make One far more substitutable by Simondon/process ontology and would erase the post-#970 reason SRT requires **vertical recurrence rather than generic recurrence**.

Thus D2 is a genuine dependency difference even though its local historical novelty remains under severe Barad/Whitehead/Deleuze pressure.

### D2 verdict

```text
manifest / relative-background verticality = LOAD-BEARING IN CURRENT SRT ONTOLOGY
same-event exact non-substitutability = NOT ESTABLISHED
removing it = substantive architecture change
```

## 3. D3 — vertical/non-final process without position-indexed burden routing

### Test

Allow a rival to pay:

```text
constitutive differentiation;
iterative non-final process;
formation;
future-condition modification;
learning / niche reconstruction;
possibly even generator revision.
```

But remove the explicit downstream questions:

```text
who authorizes?
who executes?
who benefits?
who bears?
who repairs?
where does consequence return?
whose future selectability changes?
```

Does anything important disappear from SRT?

### Answer

**Yes, but at formed/L2 and multi-position layers, not primitive ontology.**

Without incidence typing, aggregate system language can classify the following as successful:

```text
coordination improves;
forecast error falls;
output efficiency rises;
collective option count expands;
system persistence strengthens.
```

while hiding:

```text
one position bears the irreversible cost;
another receives the benefit;
a third loses exit / revision capacity;
the burden-bearing position cannot write consequences back into the generator.
```

SRT's `Collective_Selection` and book-level scaffold diagnostics are specifically built to distinguish these cases.

### Hard negative control 1 — efficient externalization

```text
institution / algorithm
-> lower aggregate coordination cost
-> high system stability
-> burden shifted to subgroup P_i
-> P_i loses exit / repair / candidate-generation capacity
-> authorizer/beneficiary P_j receives little negative writeback.
```

A pure aggregate-efficiency or system-stability description can call this improvement.

SRT high-level diagnosis can say:

```text
system-level performance improved
AND
position-specific generative health degraded.
```

These judgments are not contradictory because the level and incidence differ.

### Hard negative control 2 — scaffold substitution

```text
scaffold raises immediate performance
-> endogenous judgment / candidate generation no longer bears load
-> consequence return is intercepted
-> withdrawal causes collapse / high exit cost.
```

Again:

```text
performance support
!=
capacity formation.
```

Q19's support/substitution/atrophy/lock-in path and its tests for capability sedimentation, payable exit and consequence return instantiate this distinction.

### Hard negative control 3 — nominal option expansion

```text
menu size rises
but
actual reachability / payability / consequence-driven rule revision falls.
```

SRT refuses to equate option count with future selectability.

### D3 verdict

```text
position-indexed incidence/burden routing = NOT primitive
but = INDEPENDENTLY LOAD-BEARING FOR L2 / collective / civilizational SRT
local novelty = NOT ESTABLISHED
cross-domain compression value = LIVE
```

## 4. Result — three strata of the minimum tool

The phrase “minimum unifying tool” should no longer be treated as one flat list of ontology claims.

### Stratum I — universal ontology spine

Current canonical minimum:

```text
non-flat openness
-> finite-position-indexed subjectless Selection
   = manifest / relative-background verticality
-> regenerative vertical formation
-> One.
```

### Stratum II — formed-process axes

Activate only where the relevant continuity/history exists:

```text
later-condition efficacy;
continued selectability;
relative continuation / One strength;
future-selectability transformation;
passive maintenance vs active reconstruction;
generative reselectability.
```

These are not required for every primitive event.

### Stratum III — L2 / multi-position axes

Activate where history, scaffold and multiple consequence-bearing positions exist:

```text
background scaffold / pre-cropping;
position-indexed consequence routing;
payability / exit / maintenance burden;
authorizer-executor-beneficiary-bearer separation;
externalization;
scaffold support vs substitution;
collective generative health.
```

Language / institution / habit belong here as L2 scaffold realizations under the author's #974 correction.

## 5. What the minimum tool now looks like

A disciplined use of SRT across domains would not ask every question everywhere.

Instead it first types the layer, then applies the relevant questions.

```text
EVERY TARGET DOMAIN:
What is the relevant actual differentiation?
What is manifest / operative and relatively backgrounded?
Is this mapping genuinely pre-object/generative or only an object-level analogy?

IF A FORMED CONTINUITY EXISTS:
What retained structure changes later Selection?
What remains selectable?
Is maintenance passive or does Selection reconstruct later selectability?

IF L2 / SCAFFOLD EXISTS:
What history has become background infrastructure?
What is pre-cropped before explicit choice?
Does scaffold support or substitute endogenous capacity?

IF MULTIPLE FORMED POSITIONS EXIST:
Who authorizes / executes / benefits / bears / repairs?
Whose future selectability changes?
Where do cost and consequence return?
Can affected positions revise the generator/scaffold?
```

This is much more precise than claiming one literal mechanism operates identically from quantum physics to civilization.

## 6. Consequence for strongest-neighbor strategy

The search for a single theory that “equals SRT” is now less informative.

Neighbor pressure should be performed **by stratum**:

```text
Stratum I strongest neighbors:
Barad / Whitehead / Deleuze / Simondon.

Stratum II strongest neighbors:
Simondon / autonomy / active inference / niche construction / evolvability / open-ended evolution.

Stratum III strongest neighbors:
Luhmann / distributed cognition / capability / institutional theory /
principal-agent / externality / collective action / cultural evolution.
```

SRT's architecture-level value can only be claimed if the typed transitions between these strata do explanatory work that cannot be reproduced by merely juxtaposing the neighbor families.

## 7. Current machine judgment

The present evidence favors:

```text
minimum ontology
!=
minimum unifying tool.
```

More precisely:

> **The ontology can remain thin while the unifying tool is a typed, layer-sensitive grammar that tracks how Selection-generated structure becomes later condition, how future selectability changes, and—only at formed multi-position levels—where burden, consequence and revisability reside.**

This solves a major pressure created by the user's ambition:

```text
cross-domain unification
without
forcing language, institution, agency, payability or generative health
into primitive L0 ontology.
```

It also preserves the anti-objectification origin rather than letting high-level social concepts define the primitive.

## 8. Is this already an author gate?

Not yet for theory content.

The remaining machine burden is one final architecture pressure:

> Can the three-stratum tool generate a **nontrivial cross-stratum inference** that is not merely “use different mature theories at different levels”? 

If no such inference exists, the tool is a disciplined synthesis / research checklist.

If such an inference exists, SRT may have an architecture-level surplus.

The next bounded pass should therefore search only for cross-stratum implications, especially:

```text
I -> II:
Does primitive verticality constrain what counts as legitimate future-selectability transformation?

II -> III:
Does One/formed-position continuity constrain attribution of L2 scaffold effects and burden routing?

III -> II feedback:
Can L2 scaffold externalization predict degradation of formed-position generative reselectability even while aggregate performance improves?

III -> I prohibition:
Which social/cognitive scaffold properties must NOT be back-projected into primitive Selection?
```

Only after this pass is an author architecture choice unavoidable.
