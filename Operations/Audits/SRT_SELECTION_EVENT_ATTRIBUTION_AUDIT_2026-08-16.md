# Selection Event Attribution Audit

> **Role**: continue after the author ruling that SRT theorizes `Selection`, not a new taxonomy of `Choice`.
>
> **Question**: when should a current event be attributed as a new selection event at a declared scale, and when is it better described as the execution / unfolding of constraints sedimented by prior selection history / `L2`?
>
> **Hard boundary**: this audit does not redefine P0-01, P0-03, `Psi_f`, `d`, or P1-T05. It is intended to expose where the current architecture already decides the issue and where a real author decision remains.

---

## 0. Executive result

The main result is a **scale-sensitive separation between Selection and Choice/Agency**.

### Result 1 — script execution does not imply absence of Selection

The canonical P0 selection primitive does not contain an anti-script clause. P0-01 says that non-objectified potential acquires a determinate manifest distinction through primitive actualisation; P0-03 gives selection historical asymmetry when it leaves trace.

Therefore:

> **A scripted or deterministic process may still instantiate / carry selection at some scale.**

The fact that a process is scripted only blocks promotion to the narrower P1-T05 `Real Choice Moment`; it does not by itself erase selection ontology.

### Result 2 — “new selection now” is a scale-and-boundary attribution question

At a declared macro scale, a current path may be fully fixed by prior `L2` constraints. In that case the safest statement is:

```text
no new macro-scale selection is established at this event boundary;
current macro dynamics are the unfolding of prior selective sedimentation.
```

This does **not** imply:

```text
no selection occurs anywhere in the underlying process.
```

Lower-scale actualisation / selection may still occur.

### Result 3 — the author's four features split across different claim levels

The four supplied features do not currently form one universal definition:

1. **irreversible change** — closest to P0-03 / core historical asymmetry;
2. **suppression / manifestation** — close to P0-01 actualisation plus downstream reachable-set effects;
3. **survival / embodied-position relevance** — strongly aligned with stake-coupled `d` and bearer-level bridges, but not currently universal across all P0 selection;
4. **friction rewrite** — highly SRT-native at bridge/dynamics level, but not currently proven as a universal postcondition of every bare P0 event.

### Result 4 — one genuine author fork remains

The unresolved author-level question is:

> **Is survival / embodied-position relevance intended as a universal necessary condition of Selection, or as a stronger condition that appears only once selection is instantiated in life / subject / stable-bearer systems?**

Current canonical architecture implies the second. Choosing the first would materially revise P0's scope.

## 1. Canonical baseline

### 1.1 P0-01 is broader than Choice

P0-01 fixes:

```text
non-objectified potential
-> determinate manifest distinction
```

through the primitive selection / actualisation role.

Its boundary explicitly says that the axiom does not itself specify:

- domain mechanism;
- empirical substrate;
- stable selector;
- consciousness condition.

So P0 selection is not currently defined by agency, deliberation, subjecthood, or biological survival.

### 1.2 P0-03 supplies historical asymmetry

P0-03 says that once selection is anchored into `L1` and leaves history in `L2`, it cannot be treated as never having occurred; reversal is itself a new selection event.

This supports the author's intuition:

> selection is first an irreversible change.

But P0-02 still distinguishes event actuality from anchoring persistence. Therefore “every actual event must strongly rewrite future friction / stable history” is stronger than the current minimum architecture.

### 1.3 P1-T05 is narrower

P1-T05 adds an anti-script / anti-habit / anti-gradient / anti-`L2`-automation boundary for `Real Choice Moment`.

That exclusion must not be back-projected onto P0 selection as though:

```text
scripted -> therefore no selection
```

The correct inference is only:

```text
scripted by itself -> not enough for P1-T05 Real Choice Moment
```

## 2. Why deterministic execution can still carry Selection

Consider the correct-SHA GitHub transaction.

At the software-workflow scale:

```text
correct SHA
-> deterministic validation passes
-> commit/ref state changes
```

The transition is scripted.

But several distinct claims must be separated.

### Claim A

```text
Is this a P1-T05 Real Choice Moment?
```

No positive verdict follows; the anti-script guard blocks that promotion.

### Claim B

```text
Does the event contain real asymmetric actualisation / path manifestation / historical update?
```

Yes at the declared software state-transition level: one transition becomes actual, alternatives are excluded, and the repository state is changed.

### Claim C

```text
Does that prove primitive P0 selection is empirically isolated as a unique mechanism?
```

No. Ordinary transaction theory explains the implementation.

So the coherent SRT reading is:

> a deterministic mechanism may instantiate a selection-bearing transition without being an instance of deliberative / agentive choice and without proving SRT-specific mechanism superiority.

This removes the need to invent `Live Choice` just to protect Selection from scripts.

## 3. Scale-sensitive event attribution

### 3.1 The problem

Suppose a habit has been formed through prior selection history:

```text
past events
-> L2 sedimentation
-> strong current policy / attractor / habit
-> present action
```

At the behavioral scale, the present action may be almost fully constrained by the prior structure.

If SRT calls every downstream execution a wholly new selection at the same scale, `L2` loses explanatory force: sedimentation never actually reduces current selectivity.

If SRT calls the whole process “no selection,” P0 becomes inconsistent with its own selection-first lower-level ontology.

### 3.2 Resolution

Selection attribution must be indexed to a declared scale / boundary / event unit.

At scale `lambda`:

```text
new selection at lambda
```

should require evidence that a currently effective difference at `lambda` enters a non-equivalent actualisation that is not exhausted by the already-frozen macro constraint description.

If the macro description fully predicts the path from pre-event `L2` state and no live macro alternative is established, the correct result is:

```text
new selection at lambda: NOT ESTABLISHED
historical/L2 execution at lambda: sufficient description
```

while leaving open:

```text
selection at finer scale lambda-1
```

This is not a new ontology term. It is a scope rule for attribution.

## 4. Author feature 1 — irreversible change

### 4.1 Strong support

This is the cleanest overlap with current core architecture.

A selection event that leaves effective history cannot later be treated as never having occurred.

### 4.2 Necessary clarification

Irreversibility should mean historical non-erasure, not necessarily:

- thermodynamic irreversibility in a strict physical sense;
- inability to restore a similar macrostate;
- permanent persistence of every local effect.

A return to an earlier-looking state can still carry a new historical trace.

### 4.3 Attribution use

A current event with no new trace / no new historical increment at the declared scale is weak evidence for a new selection event there.

But irreversible trace alone remains insufficient, because a deterministic script can create one.

## 5. Author feature 2 — suppression / manifestation

### 5.1 Core affinity

P0-01 actualisation already has an asymmetry:

```text
non-objectified potential
-> determinate manifest distinction
```

At lower claim levels this can be operationally read as:

- one continuation becomes effective;
- others are excluded / suppressed / made less reachable;
- a path acquires causal continuation.

### 5.2 Important guard

Do not require a pre-enumerated menu of completed alternatives.

“Suppression” can mean that competing continuation tendencies / relations lose effective access without presupposing a warehouse of fully formed objects.

### 5.3 Attribution use

A merely passive state drift with no non-equivalent suppression / manifestation structure is weak as a selection-event candidate.

But again, fixed winner-take-all circuitry or deterministic thresholding can satisfy this operational pattern. So it does not solve event attribution alone.

## 6. Author feature 3 — survival / embodied-position relevance

This is where the current architecture reaches an author fork.

### 6.1 Strong existing support at stake-bearing levels

Canonical `d` is explicitly stake-coupled:

```text
d(x) = || partial U / partial S ||
```

with `S` read as irreversible Survival/Stake state.

Its proxy admission rules require that relevant directions:

- carry irreversible risk;
- align with utility / concern;
- return consequences to the subject closure / identity continuity / later selection capacity.

So survival / embodied-position relevance is already central once the theory is talking about **stake-bearing subjects / systems**.

### 6.2 Why it is not currently universal P0

P0-01 explicitly does not require:

- a stable selector;
- subjecthood;
- consciousness;
- a domain-specific survival mechanism.

The P3 ghost-operator / scale-consistency bridges also preserve the possibility of selection readings below biological / conscious scales.

Therefore current architecture implies:

```text
Selection can be more primitive than survival-bearing Selection.
```

### 6.3 Consequence

The author's statement “Selection is survival-related and affects embodied position” has two possible readings:

#### Reading S1 — universal

```text
all genuine Selection must have a survival / maintenance / bearer stake
```

This would require a major reconstruction of P0 and pre-life / non-subject selection claims.

#### Reading S2 — embodied strengthening

```text
when Selection is instantiated in a life / stable-bearer / subject system,
its significance is stake-coupled and returns to embodied maintenance / future selectability
```

This is highly compatible with existing `d`, bearer, CG-3, stable-ISP, and agency architecture.

A4/A5 cannot choose between S1 and S2 without author instruction.

## 7. Author feature 4 — friction rewrite

### 7.1 Strong SRT affinity

The author's intuition fits several existing patterns:

- a chosen / stabilized path can become easier to re-enter;
- alternative paths can become harder or more costly;
- local stabilization can reduce within-path burden while increasing switching / escape burden;
- history changes later constraints and payability.

This gives a useful selection-native picture:

```text
Selection
-> manifests / suppresses
-> leaves history
-> reshapes later friction landscape
```

### 7.2 Why it is not yet universal P0

P0-01 itself does not say every actualisation must produce a measurable future `Psi_f` change.

P0-02 separates occurrence from persistence; an event may be actual without already being a persistent object or stable organization.

Therefore the strongest current safe reading is:

> **friction rewrite is a major signature of selection that has acquired anchoring persistence / downstream historical efficacy, not yet a proven necessary condition of every bare event-level actualisation.**

### 7.3 Future experimental value

Unlike the abandoned `Live Choice` route, friction rewrite is promising because it is already a native quantitative interface candidate:

- within-path cost before/after;
- switching cost before/after;
- recovery / reversal cost;
- hysteresis;
- local vs global friction change.

But this should be tested as a P3/P4 selection-history prediction, not promoted directly into P0.

## 9. What actually distinguishes current selection attribution

The audit cannot derive a fully positive necessary-and-sufficient criterion.

But it can identify the correct burden:

### Current-event increment test

Freeze before the event:

```text
B_lambda = boundary / scale
H_pre    = relevant selection history / L2 state
Pi_pre   = declared macro policy / constraint family
F_pre    = declared friction / reachability structure
D_t      = focal effective difference
```

Then ask:

1. Does `H_pre + Pi_pre + F_pre` already fix the macro continuation within the declared tolerance?
2. If yes, does intervening on `D_t` reveal any new non-equivalent macro differentiation not already encoded in that structure?
3. Is there a new historical increment whose content cannot be reduced to “the pre-existing rule executed as specified” at that scale?
4. Does the event alter future reachable / friction structure in a way that is not already a predetermined output of the frozen macro rule?

If all answers collapse into the prior rule, do not claim a new macro-scale selection event merely because lower-level physical actualisation occurred.

If a remainder survives, it becomes a **current selection increment candidate** for further bounded-rival testing.

No new canonical symbol is proposed for that remainder.

## 10. Consequence for the earlier A2/A3 program

The earlier program made the wrong object do too much work.

It asked:

```text
what positive property makes Choice live?
```

The selection-native reconstruction asks instead:

```text
what part of the current irreversible differentiation
is genuinely attributable to the current event at this scale,
rather than to prior selective sedimentation?
```

This is better aligned with SRT because:

- Selection remains primary;
- Choice/agency can remain a downstream special case;
- script execution need not be metaphysically selection-free;
- L2 receives a real explanatory role as sedimented selection history;
- scale dependence is explicit;
- no new Choice vocabulary is required.

## 12. Author gate

One question now genuinely requires author intervention.

### Gate S — scope of survival / embodied relevance

Which reading is intended?

#### `S1 — universal stake reading`

> A genuine Selection is always in some sense survival / maintenance / bearer relevant. Selection without a stake-bearing embodied position is not full Selection.

**Consequence**: major P0 revision pressure; pre-life / non-subject selection claims must be reworked or demoted.

#### `S2 — embodied strengthening reading`

> Selection is ontologically broader. Once selection is instantiated in a life / stable-bearer / subject system, survival / maintenance / future-selectability stakes become a stronger defining constraint of that embodied selection regime.

**Consequence**: highly compatible with current P0 + `d` + bearer / stable-ISP architecture; no immediate P0 rewrite.

#### `S3 — author rewrite`

Specify a third relation between Selection and survival / embodied position.

## 13. Stop rule

Stop here because:

1. script ≠ absence of Selection is clarified;
2. Selection and P1-T05 Choice/Agency are no longer conflated;
3. selection attribution is made scale/boundary-sensitive;
4. the four author-supplied features are mapped to current claim levels;
5. irreversible change and suppress/manifest fit the core most directly;
6. friction rewrite is preserved as a persistence/history signature rather than overpromoted;
7. only survival / embodied relevance still creates a genuine P0-scope fork.

**Final disposition:** no new `Choice` terminology; continue under `Selection`; author decision required only for Gate S.
