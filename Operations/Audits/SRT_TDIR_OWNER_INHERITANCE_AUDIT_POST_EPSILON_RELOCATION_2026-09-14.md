# T_dir owner inheritance audit after epsilon direction relocation

> **Role:** bounded machine-side audit of `_SRT_T_DIR_CANONICAL.md` after the author accepted that minimum pre-object L0 does not contain a primitive continuation / non-self-erasure / order direction. This file does not edit T_dir canonical wording or settle its final formal object.

---

The accepted author direction now says:

```text
minimum pre-object L0
```

# 2. Current T_dir contains two different theories

Current `_SRT_T_DIR_CANONICAL.md` contains a relatively thin operational core and a much stronger metaphysical interpretation.

## T-A — operational readability / reorientation

Current useful structure:

```text
T_dir tracks whether a system can access / read a direction signal
in its own selection dynamics
and whether that signal can enter reorientation / recalibration.
```

The current v0 role is approximately:

```text
R_self(Dir)
*
A_reorient(Dir)
```

with explicit guards:

```text
T_dir != valence
T_dir != confidence
T_dir != semantic coherence
T_dir != reward
T_dir != behavioral bias
T_dir != commitment strength
```

This layer does not logically require a primitive L0 value field.

## T-B — primitive value-hiddenness metaphysics

Current stronger prose also says, in effect:

```text
value is embedded in Selection itself;
every Selection carries an order direction;
order direction exists even when the system cannot read it;
meaning is local access to that direction;
nihilism mistakes hidden value for absent value.
```

This layer **does** require a positive universal direction already present in Selection.

Under the accepted epsilon relocation, T-A and T-B can no longer remain fused.

```text
T_dir should be deleted wholesale: NO
```

The smallest coherent reconstruction is:

```text
Direction must be established by a downstream owner first;
T_dir then measures access / readability / usable reorientation
with respect to that direction.
```

not:

```text

```

# 4. The missing argument of T_dir

The current notation:

```text
T_dir(P,t)
```

can sound as if there is one universal direction object that every system either sees or fails to see.

After the accepted relocation, the machine-side reconstruction requires an explicit conceptual argument:

```text
T_dir(P,t | D_ref)
```

where `D_ref` is not a new canonical symbol here, but a placeholder meaning:

```text
the independently established directional relation
whose self-readability is being assessed.
```

Possible downstream `D_ref` families include:

```text
D2 — successor / continuation relation in a declared model;
D4 — continued-selectability standing;
D5 — generative reselectability / consequence-sensitive revisability;
D6 — situated order-gain / normative comparison relation.
```

Different `D_ref` types must not be silently identified.

Thus:

```text
T_dir with respect to continued selectability
!=
T_dir with respect to generative reselectability
!=
T_dir with respect to a moral / social comparison criterion.
```

The current scalar notation may remain operationally useful, but its interpretation must declare what direction is being read.

# 5. Def-T-1 audit

Current core idea:

```text
T_dir := readability of the system's own selection-order direction.
```

Disposition: **KEEP FUNCTION / REWRITE REFERENCE OBJECT**.

Safe reconstructed role:

```text
T_dir tracks the degree to which a formed system can access a
specified, independently grounded direction in its own selection dynamics
and use that access in reorientation / recalibration.
```

Unsafe:

```text
selection-order direction exists universally because Selection itself contains value.
```

The phrase `秩序方向 / order direction` therefore cannot remain self-grounding. It must point to a downstream owner or be replaced by a more neutral `typed direction relation`.

# 6. R_self / A_reorient audit

The strongest surviving part of current T_dir is the separation between:

```text
R_self — can the system itself read / access the relevant direction?
A_reorient — can the read signal enter actual recalibration / reorientation?
```

This distinction remains useful after epsilon relocation.

It also becomes theoretically cleaner:

```text
D_ref establishes that a direction relation exists;
R_self establishes internal access;
A_reorient establishes use in self-modification / navigation;
T_dir does not establish D_ref itself.
```

This avoids circularity:

```text
old risk:
T_dir > 0 proves direction exists
because direction exists T_dir can measure it.

new dependency:
D_ref established independently
-> T_dir measures self-readability / reorientation with respect to D_ref.
```

### Important boundary

`A_reorient` overlaps structurally with D5 generative reselectability but is not identical to it.

A system may reorient behavior while leaving its own comparison rules, boundaries and candidate-generation conditions unchanged.

Therefore:

```text
behavioral reorientation
!= generative reselectability.
```

Current T_dir guard already points in this direction and should be preserved.

# 7. `T_dir = 0` semantics must change

Current stronger reading can be paraphrased:

```text
T_dir = 0:
order direction exists, but system is blind to it.
```

That is too strong after the new author decision.

Safe conditional reading:

```text
If D_ref has been independently established,
T_dir = 0 means the system lacks relevant self-access / usable reorientation
with respect to that D_ref under the declared measurement regime.
```

Without established `D_ref`, one cannot infer:

```text
hidden value exists;
the system merely fails to see it.
```

This is the central value-hiddenness correction.

# 9. Value-hiddenness thesis

## Current strong thesis

```text
value is never absent;
it is always in Selection and may only be hidden.
```

Disposition: **DEMOTE / REWRITE REQUIRED**.

The accepted C-direction does not support universal value-presence at the primitive Selection layer.

A safer downstream thesis is conditional:

```text
where a typed directional / normative relation has been independently established,
a formed system may be more or less able to read that relation in its own dynamics.
```

This preserves the important phenomenon of **directional occlusion** without asserting primitive cosmic value.

### Consequence for nihilism language

The claim:

```text
nihilism is simply a diagnostic error that mistakes hidden universal value for absence
```

is no longer supported as an unconditional core metaphysical conclusion.

At most it may survive as a bounded interpretive hypothesis in cases where:

```text
a downstream direction is independently established
+
the relevant system fails to read it.
```

### One requirement

Does T_dir require a formed One?

Current machine verdict:

```text

for a weak external proxy of directional responsiveness: not necessarily,
  but that weak proxy should not be called full T_dir without owner authorization.
```

Reason: `R_self` and `A_reorient` presuppose a sufficiently formed same-system relation over time. One formation is the thinnest current semantic owner for a formed process-unity / operative Selection-position. Exact necessity remains open because current T_dir owner has not been rebuilt against One.

This should become an explicit owner question rather than an implicit assumption.
