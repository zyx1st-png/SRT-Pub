# U1 cross-domain structural invariance — Pass 10

> **Boundary:** this pass tests only `U1 cross-domain structural invariance`. It does not assign Level 1/2, does not claim that Turing / WTA / Simondon are identical to SRT, does not promote a new canonical chain, and does not turn a recurring diagram into evidence by itself.

## Runtime mode lock

```text
research_mode = U
root_question = can SRT organize recurring Selection / field-reconstitution structures across genuinely different domains into a disciplined ontological unification without demanding domain-local novelty first?
comparative_claim = none
named_comparator = Turing / activator-inhibitor; recurrent WTA; Simondon transduction as source-native mapping cases, not novelty opponents
n_mode_triggered = false
```

U-mode is controlling because this pass seeks a source-neutral cross-domain invariant, not an exclusive SRT residual.

## 0. Why this pass is different from Passes 2–6

Passes 2–6 mostly asked whether a local SRT-looking role was already available in mature neighbors.

That was useful for subtraction, but it repeatedly drifted toward:

```text
neighbor-paid
-> narrower residual
-> stronger neighbor
-> narrower residual
```

The current author positioning changes the task.

This pass asks instead:

```text
if each domain keeps its own mechanism and vocabulary,
what source-neutral dependency structure genuinely recurs?
```

The result may be weaker than the current SRT formulation. That is acceptable. U1 fails if the only way to obtain a common structure is to translate every source into SRT first.

## 1. Source-native chain A — Turing / activator–inhibitor pattern formation

Using the source-native structure already established in Pass 6:

```text
nearly homogeneous reaction–diffusion field
+ local fluctuation
+ local self-enhancement
+ broader / longer-range inhibition
-> spontaneous symmetry breaking
-> localized maximum / stripe / polarity / organizer
-> spatially differentiated downstream development
```

In stronger developmental variants:

```text
organizer / pattern formation
-> slower competence / source-density change
-> changed conditions for later organizer formation
```

Important domain-specific content that must remain Turing-side:

```text
reaction kinetics
diffusion coefficients
activator / inhibitor chemistry
spatial scale
boundary conditions
biological competence variables
```

The cross-domain audit must not appropriate those as SRT ontology.

## 2. Source-native chain B — recurrent WTA / competitive selection

Using Pass 2's mature circuit family:

```text
+ competitive or feedback inhibition
-> dynamically generated winner / non-winner separation
-> winning population drives selected downstream output
-> recurrent state may retain the choice
-> changed input / option configuration can produce a new winner
```

In adaptive extensions:


Important domain-specific content that must remain WTA-side:

A key asymmetry relative to Turing and Simondon must be preserved:

## 4. First anti-translation result — the strongest SRT-shaped chain is NOT invariant

A tempting common chain would be:

```text
pre-object field
-> simultaneous manifestation + background suppression
-> Selection-position / One
-> historical sedimentation
-> reconstituted future Selection field
```

U1 does **not** currently support treating that whole chain as source-neutral invariant across all three domains.

### 4.1 `pre-object field` is not invariant across the three

Turing and Simondon begin before the relevant organizer / individual is completed.

Many mature WTA models, however, begin with already individuated option representations.

Therefore:

```text
pre-object / pre-option starting point
= NOT U1-INVARIANT ACROSS ALL THREE
```

### 4.2 explicit manifestation + suppression is not invariant across the three

Turing activator–inhibitor and WTA competition source-natively contain coupled enhancement and suppression.

Simondon's source-native transduction grammar does not require that exact bilateral competitive mechanism in the inspected material.

Therefore:

```text
same-event enhancement + active suppression
= NOT U1-INVARIANT ACROSS ALL THREE
```

### 4.3 strict historical writeback is not invariant across the three

Adaptive WTA and stronger reaction–diffusion / developmental variants can retain slower structural changes.

Fixed-law WTA can pay active competition while failing the strict washout form of SED-B.

Therefore:

```text
strict SED-B retained history carrier
= NOT U1-INVARIANT ACROSS ALL THREE AS A FAMILY-LEVEL REQUIREMENT
```

### 4.4 `One` is not a source-neutral shared object

Organizer, winner state and individuated being are not automatically one ontological kind.

Therefore:

```text
organizer = winner = individual = SRT One
```

is prohibited as a U1 shortcut.

## 5. Narrow invariant candidate I*

After subtracting the non-invariant stronger terms, a narrower dependency structure survives.

Define a machine-only U1 candidate `I*`:

```text
I1 RELATIONAL NON-FLATNESS / PLURALITY
   the relevant configuration contains multiple locally consequential
   differences, tensions, alternatives or potential continuations;

I2 ENDOGENOUS DIFFERENTIAL ORGANIZATION
   the process itself transforms that configuration into a more
   differentiated local organization; the decisive relation is not
   merely an externally attached label;

I3 OPERATIVE LOCAL STRUCTURE
   the produced local organization becomes causally / operationally
   relevant to what happens next;

I4 DOWNSTREAM CONDITIONING
   subsequent transitions / structuring occur under conditions changed
   by, or organized relative to, the produced structure;

I5 RECURSIVE / RECONSTITUTIVE CONTINUATION
   the process can continue through further differentiation,
   replacement, propagation or regeneration rather than ending at one
   static descriptive classification.
```

`I*` is deliberately weaker than current SRT ontology. It is an audit abstraction, not a proposed definition of Selection.

|---|---|---|---|---|
| I1 relational non-flatness / plurality | fluctuations + spatially coupled activator/inhibitor possibilities | multiple represented options / competing populations | disparity / incompatibility / metastable tensions | **PAID** |
| I2 endogenous differential organization | symmetry breaking / patterned activation | recurrent competition produces winner/non-winner separation | transduction produces local structuring / new dimensions | **PAID — mechanism differs** |
| I3 operative local structure | peak / organizer / polarity becomes developmentally effective | winner state drives downstream output / may persist | constituted local structure becomes effective condition | **PAID** |
| I4 downstream conditioning | organizer / inhibitor field structures later differentiation | winner / recurrent state conditions later circuit/output evolution | structure conditions next transductive operation | **PAID — timescale differs** |
| I5 recursive / reconstitutive continuation | regeneration / further patterning | winner replacement / repeated competition; adaptive extension strengthens this | transduction propagates; operation–structure recursion | **PAID — narrow** |

This is enough for a **narrow U1 pass**.

It is not enough for a full-isomorphism claim.

## 7. What is genuinely invariant, in plain language

The strongest source-neutral statement currently supported is:

> Across these otherwise different domains, a relational configuration containing consequential differences is not merely read out. An endogenous process differentiates it into a locally operative organization; that produced organization then changes the conditions under which later process continues, and the cycle can recur through further differentiation, propagation, replacement or regeneration.

Compactly:

```text
relational plurality / tension
-> endogenous differential organization
-> operative local structure
-> later process conditioned by that structure
-> renewed / propagated / regenerated differentiation
```

This is the current U1 invariant candidate.

## 8. Why U1 is only PASS — NARROW

Three restrictions matter.

### Restriction A — the invariant is weaker than SRT

`I*` does not yet entail:

```text
Selection is ontologically prior to existence
Selection is exactly manifestation + relative backgrounding
strict SED-B is necessary
Selection-position is irreducible to state-space dynamics
Bearer / consequence closure
One-formation in the full SRT sense
```

Those remain separate SRT claims / questions.

### Restriction B — the mechanisms are radically different

The mapping preserves:

```text
reaction–diffusion chemistry != neural competition != philosophical transduction
```

U1 only says that one dependency skeleton can be abstracted without erasing those differences.

### Restriction C — I* may still be too generic

A broad family of process / dynamical theories may satisfy:

```text
current organization affects later organization
```

If so, `I*` may be a true cross-domain invariant but too weak to carry useful explanatory compression.

That is not a U1 failure by itself.

It is the exact burden for **U2 explanatory compression** and **U3 exclusion power**.

## 9. Early exclusion probes for U3

Without turning this pass into U3, three negative cases already clarify that `I*` is not intended to mean “anything changes over time.”

### E1 — static external classification

```text
observer labels state A as category X
-> no endogenous reorganization
-> no changed downstream causal condition
```

Fails I2 / I3 / I4.

### E2 — externally imposed fixed winner with no endogenous differentiation

```text
one channel is permanently privileged by construction
-> alternatives never enter a live competitive / differentiating relation
```

May have asymmetry, but fails the relevant I2 endogenous differential organization burden.

### E3 — transient output with no operative carry-forward

```text
input
-> output label
-> system returns with no role for the produced organization in later process
```

Fails I3 / I4 and usually I5.

These are only preliminary mapping guards. U3 still requires a fuller exclusion audit.

## 10. Consequence for SRT's unification claim

The result should be read in two directions at once.

### Positive result

There is a real, non-verbal cross-domain dependency skeleton available across three very different source traditions.

Therefore:

```text
U1 cross-domain structural invariance
= PASS — NARROW
```

This is stronger than saying the domains merely “look similar.”

### Limiting result

The full current SRT chain is not yet the demonstrated invariant.

The repeated source-neutral core is presently closer to:

```text
relational plurality
-> endogenous differentiation
-> operative local structure
-> changed continuation conditions
-> recurrent / reconstitutive continuation
```

than to the full SRT-specific formulation.

Therefore U1 does **not** yet establish framework-level SRT value by itself.

---

## 11. The next test is now sharply defined: U2 + U3

After U1, the key question is no longer:

```text
do the three domains share anything?
```

They do, narrowly.

The next question is:

> Does SRT explain why this dependency skeleton recurs, compress otherwise separate explanatory commitments, and constrain the mapping more strongly than generic process/dynamical language already does?

That splits naturally into:

```text
U2 EXPLANATORY COMPRESSION
Does the SRT layer do more than restate I*?

U3 EXCLUSION / MAPPING DISCIPLINE
Which processes satisfying some parts of I* must still NOT count
as Selection / Selection-position / SRT realization, and why?
```

A U2 failure would mean U1 found a real pattern but SRT has not yet shown non-redundant explanatory work.

A U3 failure would mean the unification is too permissive to be informative.
