# Order-gain / reorganizability inheritance audit after epsilon relocation

> **Role:** machine-side audit of whether the current four order-gain criteria and the stronger reorganizability direction can survive after the author removed primitive continuation / non-self-erasure value from minimum L0. This file does not edit the four criteria, `d`, `T_dir`, Concern, Bearer, ethics, or any canonical owner.

---

## 1. Controlling change

The accepted direction now forbids the inference:

```text
minimum L0 epsilon
-> continuation is primitively better
-> four order-gain criteria are projections of that primitive value
```

But this does not automatically invalidate downstream structural comparison.

The audit question is:

```text
Can SRT still compare trajectories as more / less generatively viable,
coordinated, non-outsourcing, or reselectable
without a primitive L0 value direction?
```

Central answer:

```text
YES, as a downstream typed comparator;
NO, as a theorem already derived from primitive Selection alone.
```

---

# 2. Current four-criterion package

Current companion exposition and d-value usage employ:

```text
1. 可延续 — continuation / non-exhaustion of future enabling conditions
2. 可协调 — differences remain organizable / coexistent rather than forced into destructive incompatibility
3. 不外包 — consequences are not systematically displaced to positions with no effective return / correction channel
4. 可再选择 — later selection / revision is not prematurely locked out
```

The existing texts often describe all four as an operational projection of `初心`, `ε`, or an intrinsic order direction.

That grounding no longer survives unchanged.

The criteria themselves, however, mostly refer to **post-Selection relational properties** and can therefore be re-grounded.

---

# 3. The four criteria do not sit at one ontological layer

A key result of the audit is that the four criteria are not four faces of one primitive L0 quantity.

They span different downstream burdens:

```text
可延续
-> D2/D4: successor availability, continuation conditions, continued selectability

可协调
-> cross-difference / cross-position organization; requires articulated multiplicity and a declared relation scale

不外包
-> consequence routing / return / affected-position structure; requires explicit consequence topology and often stronger bearing / stake questions

可再选择
-> D5: consequence-sensitive revisability / generative reselectability, not raw option count
```

Therefore the conjunction is best treated as a **higher-order downstream comparator across several relation types**, not as one L0 gradient unpacked four ways.

---

# 4. Criterion 1 — 可延续

Current intuition:

```text
Does this trajectory consume the conditions required for its own or relevant future continuation?
```

This survives epsilon relocation.

But it must be typed.

Possible objects include:

```text
continuation of any later Selection relation;
continuation of a formed One;
continued-selectability of the same Stable ISP;
continuation of a collective / ecological enabling condition.
```

These are not equivalent.

Therefore every strong use of `可延续` should declare:

```text
what is continuing;
for whom / which process / which scale;
over what horizon;
under what perturbation class;
what counts as termination or external reset.
```

### Guard

```text
continuation alone != good.
```

A rigid harmful institution may be highly continuable. A parasite may persist. A locked-in process may remain stable.

Thus criterion 1 cannot carry normativity by itself.

---

# 5. Criterion 2 — 可协调

Current intuition:

```text
Can differences remain jointly organizable rather than requiring erasure or destructive mutual incompatibility?
```

This also survives without primitive epsilon, but only after articulated multiplicity exists.

It cannot be a minimum pre-object burden because `coordination` already presupposes:

```text
multiple distinguishable positions / processes / demands / constraints;
a relation among them;
a scale at which compatibility is assessed.
```

### Guard

```text
coordination != homogeneity;
coordination != absence of conflict;
coordination != Pareto improvement automatically;
coordination != moral legitimacy.
```

A highly coordinated exploitative structure is possible.

Therefore criterion 2 is independent from non-outsourcing and reselectability.

---

# 6. Criterion 3 — 不外包

Current intuition:

```text
Does the trajectory obtain its local gain by displacing costs / consequences
onto positions that cannot return those consequences into the relevant correction process?
```

This criterion is especially important after epsilon relocation because it supplies a genuinely relational burden that primitive L0 could never carry.

It presupposes:

```text
actual consequences;
affected positions or processes;
return / feedback channels;
a distinction between local beneficiary and consequence bearer;
a declared correction / comparison locus.
```

This is already downstream of primitive Selection.

### Relation to Bearer

Do not collapse:

```text
not-outsourcing diagnostic
=
typed Bearer theorem.
```

One can operationally detect cost externalization between modeled positions without having proved SRT's stronger `Bearer` gate.

But when the claim becomes:

```text
this consequence normatively belongs to this same One / bearer and cannot be outsourced,
```

Bearer / exposure / concern owners become relevant.

### Guard

```text
feedback exists
!= consequence is adequately borne;
externality measured
!= moral responsibility fully assigned.
```

---

# 7. Criterion 4 — 可再选择

This criterion requires the sharpest correction.

Unsafe reading:

```text
more options / more branches = better.
```

That would recreate the old `B>=2` epsilon logic and is already rejected as a minimum ontology.

The strongest current owner-compatible reading is:

```text
consequences can return strongly enough to revise
comparison rules,
boundaries,
candidate-generation or reopening conditions.
```

This is **generative reselectability / reorganizability**, not option count.

Thus criterion 4 should inherit D5 rather than old L0 epsilon.

### Guard

```text
option diversity != reselectability;
metastability != reselectability;
non-absorption != reselectability;
behavioral switching != reselectability;
```

The target is rule/boundary/generation revisability under consequence return.

---

# 8. Why the conjunction remains interesting

The four criteria catch different failure modes:

```text
continuable but uncoordinated;
coordinated but externally exploitative;
non-outsourcing but rigidly locked;
reselectable locally but destructive to its enabling substrate;
```

Therefore the package can remain a useful **multi-axis downstream comparator**.

But the old claim:

```text
all four are necessary because epsilon would otherwise be violated
```

is no longer a valid grounding.

The package's justification must instead be explicit:

```text
each criterion blocks a distinct downstream failure mode
that matters to the declared generative / relational comparison.
```

Whether the four are jointly necessary and sufficient for every normative context is **not established**.

---

# 9. Reorganizability becomes the structural center, not a new primitive

Current OPEN-TENSIONS already states that the normative distinction work is carried by reorganizability rather than by epsilon alone.

After the new author decision, that direction becomes even more important.

A promising architecture is:

```text
minimum L0:
no value content

post-Selection formation:
actual consequences and histories

reorganizability:
can consequences revise the structures that organize later Selection?

four-criterion comparator:
assesses continuation, coordination, outsourcing and reselectability
across declared positions / scales / horizons
```

This avoids both extremes:

```text
primitive cosmic morality
and
purely arbitrary subjective preference.
```

But it remains a **theory commitment about what comparison matters**, not a theorem mechanically forced by bare actuality.

---

# 10. The Hume problem must be reformulated

Some current exposition says SRT solves the is/ought problem because normativity grows directly from Selection / convergence.

After epsilon relocation, that wording is too strong.

SRT can still claim a distinctive route:

```text
normative comparison is not attached to static facts from outside;
it becomes possible when actual Selection histories create
consequence-bearing, revisable relational structures
that can be compared for continuation, coordination, outsourcing and reselectability.
```

But the following deduction is not established:

```text
Selection occurs
therefore
these four criteria are normatively mandatory.
```

The theory still needs an explicit author-level stance on why **reorganizability / non-outsourcing / coordinated continuation** deserve normative authority rather than merely descriptive interest.

This is now a cleaner and more honest normativity problem than hiding the answer inside primitive epsilon.

---

# 11. Objectivity of value must also narrow

A future safe claim could be:

```text
within a declared set of positions, horizons, interfaces and consequence channels,
a trajectory can be comparatively more robust under the four structural tests.
```

That is stronger than subjective preference.

But it does not yet license:

```text
universe-global moral optimum;
one total ranking across all scales;
all tradeoffs disappear;
the four criteria have unique weights;
```

Thus `objective direction` should mean something like:

```text
structurally testable comparative relation under declared scope
```

rather than:

```text
pre-existing cosmic value vector.
```

---

# 12. Relation to `d`

Current d-value owners already state that d expansion alone is not order gain and that the four criteria must constrain a wider-scope comparison.

This basic separation survives.

But the grounding changes:

```text
old:
d expansion is evaluated by criteria that project primitive epsilon / order.

new candidate:
d expansion changes which consequences / positions enter effective concern;
the four criteria evaluate the resulting downstream relational trajectory.
```

Thus:

```text
d tells what enters effective stake / concern scope;
order-gain criteria tell how the resulting trajectory performs under typed structural tests;
T_dir may tell how readable / usable a chosen direction is to the system;
none of these defines the others.
```

This division is cleaner than the current vertical inheritance from epsilon.

---

# 13. Relation to T_dir

The T_dir inheritance audit concluded that T_dir needs an independently typed direction reference.

The four-criterion comparator could provide one D6 direction family:

```text
D_ref(order-gain)
= comparative change under the declared four structural dimensions.
```

Then T_dir would ask:

```text
can the formed system read and use this comparative direction in its own reorientation?
```

But T_dir must not be used to prove that the four criteria are valid.

Dependency must remain:

```text
comparator established
-> direction typed
-> T_dir assesses readability / reorientation
```

not the reverse.

# 15. Machine recommendation

Keep the four criteria as a downstream research / normative comparator, but change their theoretical justification from:

```text
projection of primitive L0 epsilon
```

to:

```text
a multi-axis test of realized relational consequences
under declared position / scale / horizon / feedback conditions.
```

Treat **reorganizability / generative reselectability** as the central anti-lock-in structural axis, while preserving `可延续 / 可协调 / 不外包` as independent checks that prevent reselectability from being confused with mere flexibility.

Do not claim necessity / sufficiency for all morality until separately defended.

# 16. Next author gate

The next author question is no longer about epsilon. It is about the source of normative authority:

```text
Does the author accept that SRT's stronger direction / value should be grounded
not in a primitive pre-object value bias,
but in downstream consequence-bearing relational structure,
with reorganizability / generative reselectability as the central anti-lock-in axis
and 可延续 / 可协调 / 不外包 / 可再选择 as a scoped multi-criterion comparator?
```

If accepted, this would still **not** prove that the four criteria are a complete moral theory. It would fix where SRT's normativity begins and what kind of thing it is.
