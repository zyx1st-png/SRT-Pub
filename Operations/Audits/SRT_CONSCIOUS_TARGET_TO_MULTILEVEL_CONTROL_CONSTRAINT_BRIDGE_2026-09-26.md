# Conscious target -> multilevel control constraint bridge

> Boundary: machine analysis after author acceptance of the target-objectification / gate-objectification distinction. No new primitive, no canonical edit, no claim that consciousness is necessary or sufficient for cognitive control.



> **Control-line scope guard (post-review):** this file concerns cognitive / interventional control and agency routing (HP-A / PH-AG). It does not reopen frozen HP-B phenomenal admission. Unless explicitly marked otherwise, "foreground" means **foreground_obj** (cognitive / interventional objectification), not **foreground_phen**; **manifest_OF** is not inferred from conscious access.

---

## 0. Executive result

The key problem is not whether a conscious goal can influence action. Mature cognitive-control theory already strongly supports goal-dependent top-down bias.

The sharper question is:

> **What converts a foreground target from merely represented / globally accessible content into a structuring constraint that can reorganize multiple lower-level gates?**

This audit separates six roles:

~~~text
1. CONTENT ACCESS
   the target is represented / consciously available

2. TARGET MAINTENANCE
   the target remains active across time

3. CONTROL ADMISSION / ALLOCATION
   the system commits control resources / relevance to this target

4. STRUCTURING BIAS
   the target changes which lower-level couplings, candidates, errors
   or transitions are supported / suppressed

5. DISTRIBUTED EXECUTION
   lower systems solve the detailed sensorimotor problem

6. CONSEQUENCE / WRITEBACK
   outcome, error, friction and success reshape later control conditions
~~~

These roles can dissociate.

---

## 1. Mature-neighbor payment

### Miller-Cohen PFC control

Source-native burden:

~~~text
actively maintained goal representation
-> bias signals to other brain systems
-> guided flow of activity
-> task-appropriate input / internal-state / output mapping
~~~

This directly pays much of:

~~~text
coarse target
-> many lower processes constrained
without detailed motor micromanagement.
~~~

Therefore this is not SRT-specific.

### O'Reilly-Frank PFC-BG gating

The PBWM line explicitly tries to deconstruct the executive homunculus.

Core idea:

~~~text
basal-ganglia learning
-> dynamic gating of which PFC representations are updated / maintained
-> strategic task-appropriate control
~~~

This pays a mechanistic version of:

~~~text
not every represented content becomes current control state.
~~~

### Expected Value of Control

EVC separates:
- expected payoff;
- required control intensity;
- control effort / cost;

and asks whether, where and how much control to allocate.

This strongly pressures any claim that conscious access alone grants control authority.

### Affordance competition

Potential actions are specified in parallel and receive multiple biasing influences from prefrontal and basal-ganglia systems.

This pays the lower action-candidate competition layer.

### Global Neuronal Workspace

GNW pays:

~~~text
selected representation
-> amplification / sustained recurrent processing
-> global availability to local processors.
~~~

But:

~~~text
global availability
!= control allocation
!= structuring bias
!= bearer-owned target
~~~

by definition.

## 3. Conscious access is neither sufficient nor necessary for control

### Conscious but weakly controlling

Examples:
- a passing thought;
- an intrusive image;
- a consciously perceived distractor;
- a verbally endorsed goal with insufficient control allocation;
- a goal blocked by high switching / initiation cost.

So:

~~~text
conscious content
-/> cross-level control by itself.
~~~

### Strong control without full reflective consciousness

Examples:
- trained skill;
- habit;
- automatic task set;
- learned action bias;
- pre-reflective affordance sensitivity.

So:

~~~text
control bias
-/> reflective consciousness.
~~~

The target bridge therefore concerns a subset:

> consciously foregrounded targets that become system-level structuring constraints.

---

## 4. Candidate transition: content -> maintained target -> structuring bias

A safer architecture than 'conscious target = gate' is:

~~~text
foreground target
-> maintained control-relevant state
-> admitted / allocated as current constraint
-> structuring bias over multilevel gates
-> distributed execution
~~~

The target can remain coarse.

It need not specify:
- detailed motor commands;
- exact sensory trajectories;
- every intermediate state;
- all correction rules.

It only needs to constrain enough of the lower solution space that distributed control converges toward the intended continuation.

---

## 5. What gives a target control standing?

Machine-only decomposition:

### CS1 — persistence / maintenance

The target must remain available long enough to influence downstream selection.

### CS2 — current relevance

The target must matter relative to the current operative organization / task / concern.

### CS3 — executable coupling

There must be lower-level pathways capable of translating the target into altered candidate / error / action conditions.

### CS4 — control allocation

The system must allocate sufficient control to the target rather than a competitor.

### CS5 — cost / friction compatibility

Reconfiguration and initiation burden must remain payable enough for the target to become behaviorally effective.

### CS6 — feedback closure

Consequences must be usable to maintain, correct, abandon or revise the target-guided configuration.

These are audit roles, not a definition or necessary-and-sufficient theorem.

## 7. New conceptual distinction — access vs control

The strongest current distinction is:

~~~text
ACCESS
= this content is available to the system / consciousness

CONTROL
= this content changes the organization of later selection / gating
~~~

Possible cases:

| Access | Control | Example class |
|---|---|---|
| low | low | irrelevant background process |
| low | high | automatic skill / habit / nonconscious bias |
| high | low | conscious distractor / idle thought / weak intention |
| high | high | maintained conscious target guiding multilevel control |

This 2x2 prevents:

~~~text
consciousness = control
global broadcast = agency
goal representation = successful execution
~~~

## 8. Relation to gate objectification

Target objectification and gate objectification now occupy different points.

~~~text
TARGET OBJECTIFICATION
-> establishes what the system is trying to bring about

CONTROL ADMISSION / STRUCTURING BIAS
-> makes that target causally organize lower gating

DISTRIBUTED EXECUTION
-> lower system attempts realization

if success:
   gate remains transparent

if persistent bearer-relevant failure:
   controlling gate / expectation / constraint may itself become objectified
   -> reflective revision
~~~

Thus consciousness may contribute twice:

1. stabilize a coarse target across multiple subsystems;
2. expose a failing background constraint so that the constraint itself can be revised.

These are different control functions.

## 9. What is actually new in the current synthesis?

Not new individually:
- top-down goal bias;
- working-memory gating;
- control allocation;
- action competition;
- conscious global access;
- automatic control;
- learning turning rules into action-organizing biases.

Potentially useful synthesis:

> **A target can move from objectified content to an action-organizing structural role; if the resulting multilevel gating fails in a bearer-relevant way, the gate itself may become objectified and revisable.**

Compact recursion:

~~~text
objectified target
-> structuring bias
-> multilevel gate reconfiguration
-> action
-> consequence
-> friction / correction
-> gate objectification where needed
-> gate revision
-> new field
~~~

This is currently an integration architecture, not a distinctiveness claim.

## 10. Strongest next question

> **What determines the transition from conscious/global access to control-effective structuring bias?**

Candidate observable dissociations:
- conscious goal present but no behavioral control;
- same explicit goal, different control allocation;
- same explicit goal, different learned skill / L2 mapping;
- same goal and skill, different friction / switch cost;
- unconscious bias controlling behavior despite absent explicit report;
- gate conflict entering awareness only after repeated failed correction.

This question is narrower and more testable than 'how does consciousness control behavior?'

## 12. Second correction — control efficacy does not require bearer ownership

Rapid instructed task learning is a strong counterexample to any architecture that makes bearer-owned concern necessary for basic target-to-control conversion.

A human can receive a novel externally supplied rule and rapidly reorganize behavior around it.

Therefore:

~~~text
externally instructed target
-> can gain control efficacy

without proving:
-> bearer-owned concern
-> intrinsic stake
-> subject-level authorship
~~~

This matches the existing agency guard:

~~~text
control efficacy
!= authorship
!= stake ownership
!= subjecthood
~~~

### Consequence for the present architecture

Do not put Bearer / Concern inside the minimal mechanism that converts a target into a structuring bias.

A safer decomposition is:

~~~text
MINIMAL CONTROL ROUTE

target representation / instruction
+ maintenance
+ learned task / sensorimotor mappings
+ control allocation
-> structuring bias
-> multilevel gate reconfiguration
-> behavior
~~~

Then separately:

~~~text
AGENCY / OWNERSHIP THICKENING

continuing One / Bearer
+ concern / stake
+ self-related access
+ consequence return
+ history writeback
+ revision
-> target / action counts as mine in a stronger sense
~~~

This is a major anti-overloading correction.

## 13. External instruction clarifies the 'cup' example

Compare two cases.

### Case A — externally assigned target

An experimenter says:

> "When the green light appears, pick up the cup."

The rule can rapidly guide behavior.

The target has control efficacy.

But that alone does not tell us:
- whether the target matters to the person;
- whether the person endorses it;
- whether the consequence reshapes a bearer-level concern;
- whether the action expresses autonomous agency.

### Case B — bearer-relevant target

The person forms:

> "I need to pick up the cup because I am thirsty."

Now the target may be tied to:
- bodily state;
- concern;
- expectation;
- self-relevant consequence;
- future correction.

Both can use similar cognitive-control machinery.

The difference is not basic gating efficacy.

The difference is how the target is indexed into the continuing organization and where consequences land.

Therefore:

> **Bearer / Concern should qualify ownership, mattering and writeback — not be used as a universal prerequisite for top-down control.**

## 14. Access -> control -> ownership should remain three separate questions

Current machine decomposition:

~~~text
ACCESS:
is the target consciously / globally available?

CONTROL:
does the target structurally bias later selection and gating?

OWNERSHIP:
is that direction integrated into the continuing bearer /
concern / consequence structure as its own?
~~~

Possible combinations include:

| Access | Control | Ownership | Example class |
|---|---|---|---|
| high | low | low | consciously noticed irrelevant content |
| high | high | low / weak | externally instructed task |
| low | high | low / unclear | automatic priming / trained bias |
| low | high | high-ish | skilled pre-reflective action |
| high | high | high | deliberate self-endorsed action candidate |

The table is illustrative, not a formal taxonomy.

This separation prevents the following collapses:

~~~text
consciousness = control
control = agency
agency = subjecthood
task relevance = concern
goal pursuit = bearer ownership
~~~

## 15. Revised role of structural Expectation

Structural Expectation should also not be forced into every low-level control event.

A narrower use:

> **Expectation becomes especially relevant when the target expresses a prospective organization of what should / can happen next, and that prospective structure persists across lower-level execution and correction.**

Thus:

~~~text
simple instructed rule
may guide action
without paying the full structural-Expectation burden;

self-maintained prospective target
may recruit structural Expectation
as a higher-order organizing constraint.
~~~

This distinction remains OPEN and should be checked against the 2026-09-20 expectation owner before hardening.

### Layer 1 — control mechanics

~~~text

-> maintenance

-> execution
~~~

Strongly mature-neighbor paid.

~~~text

-> gate / expectation becomes foreground
-> reflective revision
~~~

Strongly overlaps GNW / metacognitive / cognitive-control theories.

### Layer 3 — bearer-owned agency

~~~text
direction belongs to a continuing One / Bearer
+ matters through concern / stake
+ consequences return to same continuing organization
+ history changes later selection

~~~

This is where SRT-specific typing may be most useful, but distinctiveness remains unestablished.

## 17. Revised next question

The question should no longer be:

> How does consciousness control behavior?

Nor:

> How does Bearer create the control field?

Use:

> **What converts an accessible target into a control-effective structuring bias, and what additional conditions convert that controlled direction into bearer-owned agency?**

This creates a clean two-step research programme:

~~~text
STEP A
access / representation
-> control efficacy

STEP B
control efficacy
-> ownership / agency / consequence-indexed revision
~~~

Do not require Step B to explain Step A.
