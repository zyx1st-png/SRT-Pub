# O0/S0 vs bare actualism — blind non-redundancy collapse test

> BLIND-STEP FREEZE: written before targeted lookup of mature criticism aimed at this exact comparison. Later source checking goes into a separate follow-up.

## 1. Strong rivals

BA-C — completed-structure actualism:
- determinate actual facts/events are real;
- a complete actual structure plus laws/relations exhausts ontology;
- no extra primitive Selection is required.

BA-P — process actualism:
- reality genuinely becomes/occurs;
- events and relations are ontically real;
- actuality is not a static substance inventory;
- no separate Selection primitive is required.

BA-O — open generative process actualism:
- reality genuinely becomes;
- future/possibility need not be exhausted by a completed pregiven inventory;
- new relational organization may arise;
- actuality is determinate when it occurs;
- no separate Selection or O0/S0 package is required.

BA-O is the strongest collapse rival. If SRT differs only verbally, record collapse pressure.

## 2. What cannot count as the increment

After the author's reversible-actuality adjudication, none of these is sufficient:
- irreversibility, entropy production, retained residue or persistence;
- novelty, probability, chooser/Bearer, value or aim;
- pre-given alternatives, rule rewrite, richer state-space;
- merely saying reality changes or the future is open.

## 3. Candidate SRT residue

Current minimum appears to link four burdens:

K1 actuality — a determinate difference becomes operative/manifest reality.

K2 relative backgrounding — actualisation simultaneously establishes a relative manifest/background role structure for the finite actualising position.

K3 non-preclosure — reality is not exhausted by completed determinate actuality or a completed pregiven outcome inventory.

K4 non-flatness — the generative relation cannot be fully flattened into maximally role-interchangeable neutral occurrence.

The test is whether the conjunction and dependence structure K1-K4 adds anything beyond BA-O.

## 4. Blind predictions

PRED-1: BA-C should be easy for O0 to oppose; this has low evidential value.

PRED-2: BA-P/BA-O will likely absorb generic becoming, openness, novelty and relationality. None counts as SRT increment.

PRED-3: the strongest possible residue is actualisation-relative role asymmetry: actuality institutes a finite-position-indexed manifest/background relation under non-preclosed generativity.

PRED-4: this residue may still collapse into mature relational/process ontology. If so, semantic redescription is not derivational indispensability.

PRED-5: strong gain requires a deletion-sensitive downstream dependency. Replacing K1-K4 with BA-O must make some later distinction unavailable, circular, or less compressed, and a mature rival must not restore it at equal/lower burden.

Candidate downstream burdens for later testing:
- formed One generated rather than stipulated;
- explicit object boundaries downstream rather than primitive;
- possibility/reachability generated rather than assumed;
- generative transformation changing which differences become load-bearing;
- formed partitions not back-defining their own formation.

PRED-6: if no deletion-sensitive dependency survives, record:

Selection-totality + O0/S0 = coherent metaphysical reading/compression stance;
primitive explanatory indispensability = NOT ESTABLISHED.

## 5. Representation-invariance pressure

The manifest/background asymmetry must not be created solely by analyst notation.

Future test: under legitimate structure-preserving redescription, does the same occurrence preserve non-interchangeable roles, or can foreground/background be swapped without changing any world-facing relation?

If roles are freely swappable, K2/K4 are model-relative and provide no primitive gain.

If not, SRT must state what world-facing relation fixes the asymmetry without importing observer perspective, value, temporal arrow, retained consequence, or a predeclared option set.

## 6. Reversible actuality sharpens K4

Because reversible genuine actuality remains Selection:

non-role-interchangeability != universal temporal/dynamical irreversibility.

Any surviving K4 must concern actualisation-role asymmetry, not a universal arrow of time.

## 7. Matched-world test

World BA-O:
- genuine events occur;
- process is open/generative;
- future possibilities are not a completed warehouse;
- relations and new organization can emerge;
- all observed facts match the SRT world;
- no Selection primitive.

World SRT:
- same observed events and open process;
- actuality is Selection-facing actuality;
- O0/S0 adds actualisation-relative non-flatness and manifest/background role structure.

Question: what difference follows that is not merely terminological?

Allowed success modes:
1. constitutive difference with independent motivation;
2. derivational difference — later SRT result depends non-circularly on it;
3. comparative compression — several burdens unified with fewer assumptions;
4. prospective discrimination — a structural case is forbidden/predicted differently.

If none applies: BA-O COLLAPSE = NOT RESOLVED.
