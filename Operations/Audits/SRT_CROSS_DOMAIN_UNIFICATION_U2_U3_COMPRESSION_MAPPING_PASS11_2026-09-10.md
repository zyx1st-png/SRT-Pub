# U2 explanatory compression + U3 mapping discipline — Pass 11

> **Runtime mode:** `research_mode = U`.
>
> **Input:** Pass 10 found a narrow source-neutral cross-domain invariant `I*` across Turing / activator–inhibitor, recurrent WTA and Simondonian transduction.
>
> **Boundary:** this pass does not define canonical Selection, Sedimentation, Selection-position, One or Bearer. It asks whether the current SRT organization does real explanatory/diagnostic work beyond the generic invariant, and whether it can exclude bad mappings without inventing a new ontology ladder.

## 0. U1 input retained

Pass 10's narrow invariant is:

```text
relational plurality / tension
-> endogenous differential organization
-> operative local structure
-> later process conditioned by that structure
-> renewed / propagated / regenerated differentiation
```

This is a real cross-domain dependency skeleton, but it is deliberately weaker than SRT.

The immediate danger is obvious:

```text
if SRT only renames I*,
then the framework adds little beyond generic process language.
```

U2 therefore asks what explanatory organization is gained by the SRT layer.

U3 asks whether that organization constrains mappings strongly enough to prevent `everything dynamic = Selection`.

---

## 1. U2 test A — does SRT merely rename the U1 invariant?

A minimal generic-process description can already say:

```text
current organization
-> differential transition
-> new organization
-> later transition depends on new organization
```

That description can cover large classes of dynamical, developmental, learning and process systems.

Therefore the following move does **not** earn U2:

```text
I* occurs in several domains
-> call I* Selection
-> declare ontological unification
```

If that were the whole SRT contribution, explanatory compression would be mostly verbal.

**Verdict:** `I*` alone does not pay U2.

---

## 2. U2 test B — what current SRT distinctions actually reorganize the cases?

The current author / repository work contains a stronger set of distinctions than `I*` alone.

### 2.1 Event-level differentiation vs retained result

The current Cycle-2 work distinguishes:

```text
Selection event
!=
sedimentation / retained historical result
```

This prevents an ordinary current asymmetric state or instantaneous WTA winner from automatically becoming historical sedimentation.

Cross-domain gain:

- WTA: fast winner formation can be separated from plastic writeback;
- reaction–diffusion: current concentration pattern can be separated from slower competence/source-density change;
- Simondon: local operation can be distinguished from the constituted structure that conditions later operation.

The domain mechanisms remain different, but the same distinction prevents a recurring conflation.

### 2.2 Produced structure vs `from-where` for later differentiation

Current author work separates:

```text
some structure exists
```

from the stronger Selection-position question:

```text
a re-identifiable / non-arbitrary causal position exists
from which later Selection-like differentiation resumes.
```

This blocks the shortcut:

```text
any stable peak / attractor / output
= Selection-position
```

Cross-domain gain:

- organizer, winner state and individuated structure can be compared for their later causal role without being declared identical;
- passive persistence can be separated from active reconstitution;
- later-selection origin can be asked independently of Bearer cognition.

### 2.3 Structural / ontological position vs Bearer / cognitive continuity

The author has further separated:

```text
Selection-position
= primary structural / ontological role

Bearer
= primarily cognitive / continuity-attribution specialness
```

This prevents another recurring collapse:

```text
causal persistence
= bearerhood
= subjecthood
= cognitive identity
```

That distinction is not supplied by the narrow generic `I*` invariant.

### 2.4 Manifest foreground vs full pre-object field

The current foreground-observability line is still partly provisional, so it cannot be promoted here as a settled U2 result.

But it exposes a useful organizing distinction:

```text
what is manifest / directly registered in an event
!=
the full relational field from which the differentiation arose
```

This is conceptually different from ordinary partial sensor observability, and remains under bounded N-mode pressure.

It is therefore a live candidate for future compression, not a paid U2 component here.

---

## 3. U2 result — structural/diagnostic compression is partly paid

The current SRT layer does more than rename `I*` because it repeatedly separates distinctions that domain-local descriptions can otherwise leave bundled differently:

```text
current differential event
vs retained historical result

operative structure
vs reconstituted from-where

Selection-position
vs Bearer / cognitive continuity

manifest foreground
vs full pre-object relational condition
```

This produces a common diagnostic grammar across domains.

The gain is not:

```text
SRT derives the reaction-diffusion equations;
SRT derives WTA circuit parameters;
SRT derives Simondon's transduction.
```

The gain currently supported is narrower:

> SRT supplies a common set of distinctions for asking where a domain process performs differential actualization, where its result is retained, when that retained organization becomes a later causal origin, and when a cognitive/continuity bearer is being added rather than assumed.

Therefore:

```text
U2 structural / diagnostic explanatory compression:
PARTIALLY PAID
```

But:

```text
U2 generative / causal compression
= NOT YET ESTABLISHED
```

No current result shows that one SRT principle derives why the heterogeneous local mechanisms must have their specific forms.

---

## 4. U2 anti-overclaim — classification is not yet deep explanation

The present framework may be useful even if its first gain is diagnostic rather than predictive.

But the repository must not inflate:

```text
common distinctions
```

into:

```text
complete causal theory of all three domains.
```

A stronger U2 would eventually need at least one of:

```text
one dependency that explains why apparently separate distinctions recur;
one cross-domain derivation that reduces independent assumptions;
one domain problem made simpler because the SRT decomposition removes a false conflation;
one transfer where a distinction learned in domain A reveals a missing variable / control in domain B.
```

Those belong to later U2/U4 work.

---

## 5. U3 principle — mapping must be role-specific, not identity-by-shape

U3 does not need a new ontology ladder.

It needs a rule:

> map only the specific SRT role for which the domain-native source independently pays the required dependency; do not promote the whole domain object into the whole SRT ontology.

Thus:

```text
Turing organizer may pay an endogenous-position role
!= organizer is therefore a full SRT One

WTA winner may pay event-level competitive differentiation
!= winner state therefore pays sedimentation or Bearer

Simondon transduction may pay preindividual operation/structure recursion
!= transduction therefore source-natively pays explicit WTA-style suppression
```

This role-specific mapping is the main U3 guard.

## 6. U3 exclusion tests already supported

### X1 — purely observer-added classification

Case:

```text
world/process remains unchanged
observer groups outcomes into A / B
```

There is no domain-native endogenous differential organization and no produced causal structure.

Therefore it cannot be promoted as a world-side Selection realization merely because the analyst drew a foreground/background distinction.

```text
U3 disposition: EXCLUDE as Selection realization on this basis alone
```

### X2 — static externally imposed asymmetry

Case:

```text
channel A is fixed by construction as always dominant
no live endogenous differentiation among alternatives occurs
```

The system may be asymmetric, but the asymmetry alone does not pay the event-level generation role under current author work.

```text
U3 disposition: NOT SUFFICIENT for Selection-event mapping
```

This does not mean external constraints can never participate in Selection; it means pre-imposed inequality is not by itself evidence of the selecting operation.

### X3 — transient output with no later causal role

Case:

```text
input
-> transient output
-> produced output plays no causal/organizational role in later process
```

Such an event may exhibit a momentary differential output, but it cannot pay sedimentation or Selection-position merely from that output.

```text
U3 disposition:
possible event-level resemblance;
NOT sufficient for sedimentation / Selection-position
```

### X4 — fast-state dependence mislabeled as historical sedimentation

Case:

```text
history H1 -> current fast state x1
history H2 -> current fast state x2

standardized reset makes x1 = x2
under same law and input future trajectories coincide
```

Then no independently retained historical writeback has been demonstrated under the strict Cycle-2 audit interpretation.

```text
U3 disposition:
DO NOT map current-state hysteresis alone to strict SED-B
```

The exact timescale boundary remains author-sensitive, so this is an audit exclusion, not a canonical definition.

### X5 — stable structure mislabeled as Selection-position

Case:

```text
stable peak / attractor / representation exists
```

but no independent demonstration shows that it is a re-identifiable, non-arbitrary causal `from-where` from which later differential generation repeatedly resumes.

```text
U3 disposition:
stability alone != Selection-position payment
```

### X6 — organizer / winner / individual identity shortcut

Case:

```text
Turing organizer
WTA winner
Simondon individual
```

These objects arise under different mechanisms and theoretical commitments.

Their shared mapping to one SRT role must be earned role by role.

```text
U3 disposition:
organizer = winner = individual = One
is PROHIBITED as an inference shortcut
```

### X7 — generic hidden-state augmentation

Case:

```text
Z_t = enlarged third-person state
```

The mere ability to write additional variables does not by itself settle whether the constitutive Selection-position relation has been preserved, eliminated or only re-described.

Conversely, SRT may not reject the enlarged model merely by calling it third-person.

```text
U3 disposition:
state augmentation alone = NO VERDICT
```

This remains the bounded N-mode issue in the current observability / dynamical-closure workline.

## 7. U3 positive admission rule — minimum source-neutral payment

Without defining canonical Selection, a proposed cross-domain realization should at minimum state:

```text
1. DOMAIN-NATIVE PROCESS
   what the source itself says happens;

2. SRT ROLE CLAIMED
   event-level differentiation / retained consequence /
   Selection-position / Bearer / other bounded role;

3. DEPENDENCY MATCH
   what source-neutral causal or structural dependency is shared;

4. NON-MATCHES
   which SRT roles the domain case does NOT pay;

5. BREAK CONDITION
   what fact would invalidate the mapping.
```

If items 2–5 are missing, the mapping is not mature enough to count as unification evidence.

This is an audit format, not a new governance stack.

## 8. U3 result — exclusion power is real but incomplete

The current SRT organization is not infinitely permissive.

It can already reject or downgrade:

```text
observer-only classification;
static imposed asymmetry as sufficient Selection evidence;
transient output as sedimentation / position;
fast hysteresis as strict historical writeback;
stability as sufficient Selection-position;
cross-domain object identity by analogy;
generic hidden-state notation as an automatic winner for either side.
```

Therefore:

```text
U3 mapping / exclusion power:
PASS — NARROW
```

But U3 is not complete because several boundaries remain open:

```text
exact irreversibility burden for an event-level Selection mapping;
exact sedimentation timescale / carrier boundary;
foreground-bounded observability SPD-B* is still provisional;
state-space reducibility of Selection-position remains open;
full One / Bearer admission criteria are not settled by this pass.
```

## 10. Why U4 is now the decisive next test

U1–U3 can still be satisfied by a well-organized philosophical taxonomy.

U4 asks whether the framework actually travels.

A strong test is not:

```text
after seeing domain B, describe it with SRT language
```

but:

```text
use a distinction or dependency extracted in domain A
BEFORE inspecting the decisive result in domain B
-> predict a missing distinction, control, failure mode or research question
-> then check whether domain B supports / rejects it.
```

Candidate transfers suggested by current work include:

```text
Turing / WTA distinction between generated center and background
-> ask in individuation / One-formation what plays the causal background role;

fast-state vs retained writeback distinction
-> ask in another domain whether apparent history survives a reset / reconstitution test;

Selection-position vs stable-state distinction
-> ask whether a candidate locus merely persists or genuinely serves as the from-where of renewed differentiation;

foreground vs full-field distinction
-> ask whether an observation protocol silently equates manifest output with complete generating conditions.
```

These are candidate U4 probes only. They are not yet evidence of transfer success.
