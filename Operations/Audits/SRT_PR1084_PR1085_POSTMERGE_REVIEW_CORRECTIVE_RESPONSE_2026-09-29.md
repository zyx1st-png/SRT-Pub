## 2. #1084 corrective — no-gain governance

### 2.1 Three independent consequences

The prior rule separated local claim state from theory inventory, but did not adequately separate programme allocation.

Corrected governance now requires:

~~~text
A scoped comparative-claim state
B programme / resource-allocation state
C theory-inventory / owner state
~~~

A local no-increment result usually blocks A.

Repeated no-increment can still trigger B:

~~~text
stop-loss / contraction / HOLD / root-return.
~~~

C changes only under an independent owner-level / author / reciprocal-pressure reason.

This preserves the GRG §8.1 precedent:

~~~text
programme stopped
!= all motivating relations deleted.
~~~

### 2.2 Retained-without-payoff trigger

The amendment already prohibits indefinite absorption of negative results, and AGENTS already requires root-return after two consecutive substitution passes yielding only narrower residuals.

The new default relation-level trigger is:

~~~text
same proposed relation
+ two consecutive competent mappings
+ no earned compression
+ no transfer
+ no new reciprocal constraint
-> ChoiceMap / root-return before a third convergence case.
~~~

Possible outcomes include continue-with-sharper-form, HOLD, lower priority, split, revise or withdraw.

This is not an automatic deletion rule.

### 2.3 Farther gain must pay farther comparators

The discovery domain cannot count as confirming survival.

Prospective upgrade requires:

## 4. Stronger music comparators

The original route's generic "predictive music model" and surprisal / entropy baseline were too weak for tension / unfinishedness.

External metadata / abstract checks support the following strong comparator families.

### 4.1 Tonal tension / attraction / closure

- Lerdahl & Krumhansl (2007), Modeling Tonal Tension, DOI 10.1525/mp.2007.24.4.329:
  prolongational structure + pitch space + surface tension + attraction jointly predict tension.
- Bharucha (1996), Melodic Anchoring, DOI 10.2307/40286176:
  unstable tones are modeled as demanding resolution to stable pitch neighbors under proximity + asymmetry.
- Larson & VanHandel (2005), Measuring Musical Forces, DOI 10.1525/mp.2005.23.2.119:
  musical gravity / magnetism / inertia predict experienced melodic tendencies.
- Narmour (1991), DOI 10.2307/40286156:
  top-down / bottom-up implication-realization systems distinguish implication, realization and closure.
- Huron (2006), Sweet Anticipation, DOI 10.7551/mitpress/6575.001.0001:
  ITPRA separates imagination, tension, prediction, reaction and appraisal; schematic and veridical expectation must be distinguished.

### 4.2 Dynamic / computational tension

- Farbood (2012), DOI 10.1525/mp.2012.29.4.387:
  temporal / multidimensional tension model with attentional and memory windows.
- Barchet, Rimmele & Pelofi (2024), DOI 10.1371/journal.pone.0296385:
  TenseMusic automatically predicts continuous tension from six extracted features.
- Sears et al. (2020), DOI 10.1177/0305735618803676:
  continuous cadence-expectancy ratings show closure expectation dynamics.

### 4.3 Statistical / latent tonal expectation

- Temperley (2004), DOI 10.1177/102986490400800204:
  Bayesian key / tonal inference extends to tension, ambiguity and expectation.
- Pearce & Wiggins (2012), DOI 10.1111/j.1756-8765.2012.01214.x:
  IDyOM supplies explicit statistical-learning predictions for musical expectation.

Therefore condition B:

~~~text
high predictability + high unfinishedness
~~~

is not informative unless these stronger tonal-attraction / closure models fail to absorb it.
