# Directional-generation -> HP-B upstream crosswalk

## 0. Purpose

This audit asks whether the 2026-09-27 ChoiceMap / reverse-metaethics author reconstruction supplies a missing upstream burden for the 2026-09-25 HP-B mechanism candidate.

It does **not** edit the HP-B hook, reopen a canonical owner, or claim that the hard problem is solved.

## 1. New author-controlled input

Current author-accepted preformal direction:

```text
L1-facing better/worse direction
= pre-object;

directional sensing
and
generative recutting
= two facings of one L1 event;

the underlying event need not itself be phenomenal;

under formed phenomenal-access conditions,
one facing can become consciously felt;

during fluent operation the directional-generative relation can remain transparent;

mismatch / friction / directional deviation / required reorganization
can make that relation more foreground-relevant.
```

Historical author source line:

```text
L0-facing primitive Selection
-> source-line of L1 directional-generative polarity
-> later formed differentiation into
   Expectation / Bearer-related exposure / Concern-value / moral structures.
```

## 2. Source return to the 2026-09-25 HP-B line

The current HP-B hook already contains:

```text
Bearer
+ formed Gate geometry
+ Concern / Expectation
+ constitutive Ontological Friction
+ selective normalization / higher-order integration
+ background-to-foreground process
+ same-Bearer Selection-position reconfiguration
-> phenomenal presence candidate.
```

It also types:

```text
valence / directional feel
<- direction of deformation relative to

```

That 09-25 architecture answered:

> why a formed Bearer might require a felt foreground mode rather than only unconscious control.

It did **not** independently solve:

> where the relevant direction itself ultimately comes from.

## 3. New upstream pressure

The 09-27 author reconstruction suggests:

```text
Concern
and

may not be ultimate sources of direction.

They may be formed differentiations / typings
of a more basic L1 directional-generative event.
```

Therefore a possible deeper dependency is:


This is a machine reconstruction candidate, not a theorem.

## 4. Important correction to avoid circularity

A future HP-B account should avoid the circular-looking shortcut:

```text
Expectation / Concern
define direction;

direction then explains
Expectation / Concern-shaped feeling.
```

If the present source line survives pressure, a cleaner relation is:

```text
upstream directional-generative organization
-> formed Expectation / Concern typings;

those formed typings then locally specify
how the current Bearer realizes, constrains and accesses
that direction under current history / position.
```

Thus formed Expectation / Concern can remain indispensable local coordinates without being the ultimate direction source.

## 5. Gate geometry gets a more precise upstream role

The 09-25 line emphasized:

```text
Gate
~ stable coarse-graining geometry.
```

The new candidate adds:

```text
directional-generative event
-> participates in what distinctions / equivalences / cuts
   become stabilized as Gate geometry.
```

Therefore Gate need not be the origin of direction.

Candidate dependency:

```text
directional generation
-> gate formation / recut
-> stable objectification;

under unresolved burden:
directional generation + strained Gate
-> foreground reconfiguration.
```

This helps distinguish:

```text
direction source
!= Gate geometry
!= T_dir
!= valence readout.
```

## 6. Mismatch is an amplifier / revealer, not the origin

The current HP-B hook already guards:

```text
mismatch != origin of all friction;
mismatch = amplifier / boundary-revealing condition.
```

The 09-27 author adjudication is compatible with that.

Keep:

```text
directional-generative event can operate continuously;

mismatch / friction / failed absorption
can increase foreground relevance
and therefore make the direction more consciously available;

but mismatch is not required to create direction itself.
```

This prevents the new route from becoming an error-only theory of feeling.
