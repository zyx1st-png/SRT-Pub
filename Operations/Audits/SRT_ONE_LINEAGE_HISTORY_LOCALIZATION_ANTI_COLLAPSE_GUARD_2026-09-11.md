# One-lineage work — history-localization anti-collapse guard

## 1. Retired route must stay retired

Cycle 1 already established:

```text
history-localization / shuffled-writeback as an independent Level-2 route:
RETIRED;

operational partition:
collapsed to ordinary recurrence / credit assignment;

no v3 by merely improving history routing.
```

The current One-lineage work must not silently revive that route under new names.

## 2. Current question is not where history is stored

Invalid inference:

```text
history is locally stored in A
-> therefore A is a One.
```

Also invalid:

```text
history is distributed in the field
-> therefore no local One can form.
```

The current author ruling explicitly allows pre-Bearer Selection sedimentation to remain in `多`.

Therefore material / representational localization of memory is not the One criterion.

## 3. Current live relation — lineage-conditional causal role

The stronger C-layer relation is:

> a distributed historical difference can remain in the wider field while having a non-equivalent causal role in regenerating one local vertical lineage rather than another.

Machine shorthand:

```text
location(H)
!= decisive;

effect(H | reconstitute A)
may differ from
effect(H | reconstitute B).
```

This is not a claim that `H` is a separately measurable scalar or token.

## 4. Contrastive dependence, not provenance token

A useful pressure question is:

```text
Can two candidate lineages be exposed to a historical / perturbational contrast
that changes A's reconstitution path without forcing the same continuation change in B?
```

If yes, this supports relative continuation separability.

But do not infer:

```text
A-history token exists;
B-history token exists;
unique provenance carrier exists;
strict identity solved.
```

The relation can be distributed, relational and many-to-many.

## 5. Shuffled-writeback resemblance guard

A swap / shuffle thought experiment may still be used as a conceptual probe, but only to ask whether continuation dependencies are contrastively different.

It must not be reported as:

```text
new Level-2 route;
new experiment family;
scientific distinctiveness;
proof of nonordinary dynamics.
```

The previous exact-copy / recurrence-collapse result remains controlling scientific pressure.

## 6. One versus Bearer remains intact

```text
One:
lineage-conditional reconstitution can be supported by field-distributed history;

Bearer:
consequences become own-history / return to the organization that must reconstitute the later position.
```

Therefore:

```text
lineage-conditional causal role
!= consequence ownership.
```
