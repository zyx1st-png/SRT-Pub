# Functional continuity vs bearer continuity — mature-neighbor prepass

> **Status:** pre-adjudication routing only. This file does not select a final strongest neighbor, does not assign Level 0/1/2, and does not substitute an orientation map for source-native mature-neighbor verification.

---

## 1. Why a prepass is useful

The author gate offers several meanings that face different strongest neighbors. Selecting one universal rival before the author fixes the intended claim would invite weak-neighbor gaming.

Current sequencing therefore is:

```text
AI option split
-> owner subtraction
-> neighbor-family prepass
-> AUTHOR ADJUDICATION
-> source-native strongest-neighbor verification on selected meaning

```

## 2. Empirical generic baseline — reusable computation / neural degeneracy

Osako 2026 already establishes a strong ordinary scientific baseline:

```text
same computation can be reused across different informational contents
functional neural organization can be task/region dependent
mPFC can show clearer functional clustering
PPC can remain more multiplexed
training history can sculpt coding geometry
ordinary data-constrained RNN learning can reproduce key reuse/history effects
```

Therefore any SRT claim based only on:

```text
functional reuse
modularity
history-shaped geometry
performance relevance
recurrent interaction
```

starts below Level 1. These are baseline scientific phenomena, not bearer discriminators.

## 3. Neighbor family by candidate reading

### FC-A — functional-position sufficiency

Likely strongest pressure family:

```text
functionalism / computational role identity / multiple realization
```

Common problem:

> Under what conditions can different physical realizations count as the same functional organization or role?

Expected pressure on SRT:

- if bearer identity is exhausted by causal/functional role, SRT may add only vocabulary;
- if two replaceable implementations are functionally equivalent, FC-A has little resource for explaining why only one is the same consequence bearer.

Full source-native verification is deferred until the author actually endorses an FC-A-like claim.

### FC-B — consequence-closure continuity

Likely strongest pressure families:

```text
organizational closure / autonomy / enactivism
processual biological individuality
```

Common problem:

> What makes a changing system one continuing self-maintaining organization whose own changes matter to its later organization?

Expected pressure:

- organizational closure already pays a large part of self-maintenance, boundary and own-operation continuity;
- process ontology already pays material turnover with process continuity;
- SRT cannot earn Level 1 from `same unit bears consequences` unless its dependency / case partition differs from these mature accounts.

Repository Nave work is useful pressure here because it already forced the distinction between process continuity, history-bearing, history-constituted continuity and consequence non-outsourcing, but it is not sufficient by itself to choose the strongest neighbor for a new author claim.

### FC-C — higher-order bearer with migrating functions

Likely strongest pressure families:

```text
process ontology
biological individuality / hierarchical organization
multiple realization / degeneracy
```

Common problem:

> How can a higher-order individual remain the same while its parts, mechanisms or local functions turn over, migrate or reorganize?

Expected pressure:

- this decomposition is already natural to process and biological-individuality accounts;
- SRT only gains structural content if it changes what counts as the continuing unit, how consequence attribution works, or which replacement/migration cases count as equivalent.

This candidate may still be valuable as an anti-collapse guard even if it remains Level 0.

### FC-D — role/closure co-constitution

Likely strongest pressure families:

```text
Simondonian individuation / transduction
organizational closure / autopoiesis
dynamical / adaptive coevolutionary networks
```

Common problem:

> How can operations and the organization that supports further operations emerge together rather than presupposing a completed individual?

Expected pressure:

- Cycle 2 has already shown heavy absorption here;
- generic adaptive networks can generate role specialization, topology change and persistent loci;
- Simondon-like and organizational-closure accounts can absorb non-pregiven individuation and recursive structure formation.

FC-D therefore has the highest burden for any future Level-1 claim.

---

## 4. Candidate common problem without SRT vocabulary

A provisional cross-family formulation is:

> **When the same function can be repeatedly realized by changing components, what distinguishes continuity of a role from continuity of the individual or process to which consequences belong?**

A stronger version, if the author chooses B/C/D, is:

> **What makes successive realizations parts of one continuing consequence-bearing process rather than merely equivalent, replaceable or coordinated realizations of the same function?**

These formulations intentionally avoid `Selection`, `One`, `Bearer`, `L2` and other SRT vocabulary.

---

## 5. Prospective non-substitutability targets

After author adjudication, a Level-1 candidate would need to change at least one of:

```text
unit:
  what is counted as the continuing entity when functions migrate?

identity criterion:
  what continuity is required beyond same functional role?

boundary:
  where does consequence ownership close?

case equivalence:
  when are replacement / migration / checkpoint / duplicated-service cases equivalent?

dependency:
  does bearer continuity presuppose functional continuity,
  or can functions be recruited inside an already continuing bearer,
  or do function and bearer co-form?
```

A Level-2 route would require an additional domain-native discriminator; none is claimed here.
