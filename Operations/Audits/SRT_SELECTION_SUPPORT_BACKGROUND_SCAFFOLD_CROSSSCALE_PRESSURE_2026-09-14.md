# Selection / support-background / scaffold cross-scale pressure
## From pre-object actualisation to cultural and institutional support without silently changing grammar

> **Boundary:** machine-side pressure audit only. It was triggered by fresh author intuitions about SRT's cosmological scope, L0-to-scaffold continuity, multi-agent proxy organization, and the role of the unmanifest / background. Those intuitions are **not** treated here as author adjudications. No canonical owner, symbol, Level, HOLD status, scientific-distinctiveness verdict, or social-normative conclusion is changed.
>
> **Purpose:** test whether those intuitions identify a genuinely SRT-specific dependency or only assemble mature neighboring roles into one vocabulary.

---

## 0. Executive verdict

The four intuitions do **not** survive as four independent novelty claims.

Strong mature traditions already pay large parts of each:

```text
Barad / agential realism
-> no pregiven relata
-> world-side constitutive differentiation
-> apparatus / material-discursive reconfiguration
-> iterative materialization / exclusion

Simondon
-> preindividual ontogenesis
-> transduction
-> operation -> structure -> later operation
-> individual + associated milieu

niche construction
-> organisms modify their own and others' selective environments
-> changed selection pressures persist as ecological inheritance

Sterelny / epistemic niche construction
-> material, social and informational environments scaffold cognition / learning
-> developmental environments are actively constructed and culturally inherited

Hutchins / distributed cognition
-> cognitive work can be distributed across persons, artifacts, representations and organized practices
-> no single individual need be the sole cognitive locus

phenomenological / ecological traditions
-> much action is supported by a non-thematized background
-> habit / body sedimentation can organize later action without explicit foreground representation
-> affordances are organism-environment action possibilities, not merely internal objects
```

Therefore the following are **not safe SRT-specific residuals by themselves**:

```text
cross-domain extension;
scaffolding;
environment reshaping future selection;
multi-agent distributed cognition;
institutions / language / tools supporting action;
background support that normally remains unnoticed;
manifest structure later conditioning action.
```

However, the fresh intuitions expose a more precise and potentially important SRT problem:

> current SRT uses the word `background` for at least two ontologically different burdens that must not be collapsed.

Machine-side distinction:

```text
O      = open / pre-manifest condition field;
B_rel  = Selection-relative background side co-generated in an event;
B_sup  = already formed, currently non-foreground, load-bearing support background / scaffold.
```

These are not three names for one thing.

A new architecture-level candidate emerges only if SRT can defend a continuous grammar of the form:

```text
O
-> Selection
-> manifest / B_rel vertical relation
-> retained consequence / reconstitution where paid
-> formation of load-bearing B_sup / scaffold
-> B_sup reshapes later Selection conditions
-> later Selection
```

and then show that this grammar remains structurally constrained rather than metaphorically reused across physical, biological, cognitive, multi-agent and institutional scales.

Current verdict:

```text
local mechanism novelty of each component = NOT ESTABLISHED
architecture-level unification value = LIVE
cross-scale invariant = NOT YET ESTABLISHED
whole-architecture non-substitutability = NOT ESTABLISHED
scientific distinctiveness = NOT ESTABLISHED
Level 2 = HOLD
canonical edit = NO
```

## 1. Pressure trigger — four author intuitions, not yet adjudicated

Fresh author conversation supplied four provisional intuitions:

1. neighboring theories do not make Selection-or-equivalent the cosmological source of a continuous cross-domain dynamics reaching social, civilizational and evolutionary analysis;
2. they do not sufficiently connect a pre-Selection L0 source with later scaffolds such as language, institutions and habits;
3. they do not build the physical intuition forward through multi-agent proxy / collaboration organization;
4. they focus too heavily on what becomes manifest and what precedes manifestation, while under-theorizing the non-manifest support that makes manifestation possible and shapes later Selection.

This audit pressure-tests those intuitions rather than ratifying them.

## 2. First correction — `background` currently hides different relations

### 2.1 Open condition field is not background

Current L0 / Spine meaning already blocks an object warehouse:

```text
non-flat / non-neutral openness
!= completed options
!= hidden object inventory
!= manifest background object.
```

Therefore the pre-manifest condition field should not be casually called `background` merely because it is not manifest.

Use machine-side placeholder:

```text
O = open condition field.
```

No new canonical symbol is proposed.

### 2.2 Selection-relative background is event-relative

The 2026-09-13 author adjudication fixes the explanatory structure:

```text
Selection_S
-> [manifest side / Selection-relative background side]_S.
```

Machine placeholder:

```text
B_rel.
```

`B_rel` is not:

```text
another object;
a list of rejected options;
a global complement;
a stored scaffold;
a social institution;
a durable support structure by definition.
```

It belongs to the event-level vertical relation.

### 2.3 Support-background / scaffold is formed and load-bearing

Q10 and Q19 contain a different burden.

Examples include:

```text
habitual bodily organization;
language;
road / protocol / tool structure;
organizational procedure;
institution;
shared norm;
AI-mediated default path;
other durable background organization.
```

These can become less foregrounded precisely because they reliably carry part of the work of later action / Selection.

Machine placeholder:

```text
B_sup = already formed, currently non-foreground, load-bearing support background.
```

Important guards:

```text
B_sup != B_rel by definition;
B_sup != hidden rejected alternative;
B_sup != merely subjective inattention;
B_sup != necessarily beneficial;
B_sup != necessarily conscious;
B_sup != necessarily social;
B_sup != necessarily one spatial object.
```

A support background may have been produced through a long history of prior selections, interactions and external construction; this audit does **not** assert that every `B_sup` was once one manifest object at the same scale.

---

## 3. Why the distinction matters

If `B_rel` and `B_sup` are collapsed, SRT can silently move between two claims:

```text
Claim A:
Selection makes one relation manifest while another side is relatively backgrounded.

Claim B:
stable language / institution / body schema / tool infrastructure recedes from attention while supporting later action.
```

These are not equivalent.

A theory could pay A without paying B.
A theory could pay B without an SRT-style primitive Selection ontology.

The strongest-neighbor audit must therefore treat the transition from event-relative backgrounding to formed support-background as an **additional research burden**, not as a definitional free move.

## 4. Neighbor pressure on support-background

### 4.1 Phenomenology / embodiment

Merleau-Pontian habit-body style accounts strongly pressure:

```text
past activity sediments into bodily organization;
that organization can remain non-thematic;
it becomes the background for present skilled engagement.
```

This is already very close to Q10's claim that stable background structure can support action precisely because it no longer needs explicit foreground calculation.

Therefore:

```text
non-foreground support of present action
= STRONGLY NEIGHBOR-PAID at phenomenological / embodied level.
```

### 4.2 Ecological psychology / affordances

Gibsonian traditions pressure:

```text
action possibility is relational to organism + environment;
the environment supports / constrains action without first becoming an internal represented object;
behavior can be organized by an affordance landscape.
```

Therefore:

```text
environmental action support / possibility landscape
= STRONGLY NEIGHBOR-PAID.
```

### 4.3 Niche construction

Niche-construction theory directly pays a powerful feedback:

```text
organism activity
-> environmental modification
-> modified selective environment
-> altered selection pressures for self / others / descendants
-> ecological inheritance.
```

This is a strong mature analogue of:

```text
past action / selection
-> formed background condition
-> changed future selection field.
```

Therefore the broad formula

```text
past selection reshapes future selectable conditions
```

cannot carry distinctiveness by itself.

### 4.4 Sterelny / epistemic niche construction

Sterelny explicitly treats tools, informational resources, teaching environments and social learning contexts as constructed epistemic scaffolds.

This strongly pressures:

```text
language / tools / inherited practices support cognition;
constructed environments reduce learning / action burden;
cultural evolution builds developmental scaffolding;
scaffolding can shape later cognitive capacities.
```

Therefore:

```text
human culture creates cognitive scaffolds
= NEIGHBOR-PAID.
```

### 4.5 Hutchins / distributed cognition

Distributed cognition directly pressures the author's third intuition.

It permits cognitive activity to be distributed across:

```text
people;
artifacts;
external representations;
roles;
procedures;
organizational routines;
material environments.
```

No single organism need be the sole processing center.

Therefore:

```text
multi-person / tool-mediated cognitive coordination
= STRONGLY NEIGHBOR-PAID.
```

SRT cannot claim distinctiveness merely by saying that agency / cognition can be distributed or externally scaffolded.

```text

-> retained consequence where paid
-> vertical reconstitution / One formation
```

The possible residual is therefore not:


This is an architecture-level claim.

It is not yet established.

## 9. Machine-only cross-scale invariant candidate CSI

Before any author adjudication, define a pressure bundle rather than a theorem.

A genuine cross-scale SRT invariant would need to preserve at least the following role distinctions:

```text
CSI-1 EVENT ASYMMETRY
A determinate event produces a non-flat manifest / relative-background relation.

CSI-2 RETAINED CONSEQUENCE
Some event consequences can materially alter the conditions of later Selection.

CSI-3 SUPPORT-BACKGROUND FORMATION
Some retained organization can become load-bearing while not needing to remain foregrounded in every later event.

CSI-4 FUTURE-SELECTABILITY EFFECT
That support background changes later accessibility, friction, candidate formation, transition or reconstitution conditions.

CSI-5 NON-IDENTITY OF BACKGROUNDS
Selection-relative background and support-background are not silently identified.

CSI-6 SCALE DISCIPLINE
A claimed physical / biological / cognitive / social realization must independently pay the relevant roles rather than inherit them by metaphor.
```

This bundle is **not** a canonical definition or N&S theorem.

It creates a testable audit target.
