# Audit — new objectified-trace method versus stopped GRG cross-objectification route

## 0. Purpose

Prevent the 2026-09-28 reconstruction direction from being misrepresented as wholly new or used to rescue the stopped GRG fusion-case programme.

## 1. What the 2026-09-23 GRG method already owned

The prior architecture already required:

~~~text
source-native recovery;
objectification declaration;
objectification genealogy;
legitimate re-objectification;
domain-native generative reconstruction;
questions about how prior history changes later boundaries;
questions about whether a relation treated as fixed in one model is generated / dissolved in another;
missing-relation search;
late grammar extraction;
prospective held-out testing;
source absorption / no-gain;
failure preservation.
~~~

It also explicitly rejected:

~~~text
domain object -> GRG object mapping
~~~

as the research engine.

Therefore the following are **not new** in 2026-09-28:

- objectification is revisable;
- objectification genealogy matters;
- mature domain objects may hide or aggregate generative relations;
- later boundaries may be altered by prior generation / history;
- relations treated as fixed in one model may be generated or dissolved in another;
- alternative cuts should be inspected;
- reconstruction should be source-native first;
- held-out testing is required before stronger credit;
- mature source ownership must be absorbed.

## 3. Corrected candidate delta in the new route

The first draft used one cut variable for two different roles. The corrected proposal separates:

~~~text
K_t = system-side endogenous cut / operative distinction;
M_i,t = researcher / instrument / task measurement cut.
~~~

Observation relation:

\[
O_{i,t}=M_{i,t}(G_t,K_t,H_t)+\epsilon_{i,t}.
\]

The inverse target is generally an equivalence class:

\[
\{O_{i,t},M_{i,t}\}
\Rightarrow
[\widehat G_t,\widehat K_t,\widehat H_t]_{\sim}.
\]

The candidate post-stop-loss delta is now only:

~~~text
1. explicit identifiability conditions for separating
   process G, endogenous cut K and measurement cut M;

2. prospective held-out measurement-cut prediction;

3. prospective endogenous-cut formation / change prediction.
~~~

Qualitative cut genealogy or cut dynamics by itself is not a new delta; the old GRG route already owned it.

## 4. Identifiability boundary

Joint process / cut reconstruction is a blind inverse problem and admits reparameterization freedom unless constrained.

Minimum admissible anchor families include:

~~~text
fixed / independently calibrated M with process perturbation;
approximately fixed system with changed M;
multiple non-equivalent M_i sharing one process trajectory;
interventions with known target / timing;
auxiliary / temporal / group structure with a valid identifiability theorem.
~~~

Without an adequate anchor:

~~~text
VERDICT = UNDERIDENTIFIED
~~~

rather than a unique deep-process claim.

## 5. External neighboring fields that pressure the delta

The method must not compare only against SRT's earlier GRG route.

Relevant neighboring baselines include:

### 5.1 Measurement invariance

Putnick & Bornstein (2016), DOI 10.1016/j.dr.2016.06.004, review methods for testing whether the relation between a construct and its measurements is comparable across groups or time.

Pressure:

~~~text
apparent process / construct change
!= measurement-relation change automatically.
~~~

### 5.2 Identifiable latent-variable recovery

Hyvärinen, Sasaki & Turner (2019), PMLR 89:859–868, use auxiliary / temporal information to obtain nonlinear-ICA identifiability under explicit conditions.

Pressure:

~~~text
multi-view latent recovery
requires stated identifiability assumptions;
flexible fit alone is insufficient.
~~~

### 5.3 Category and structural-form learning

Anderson (1991), DOI 10.1037/0033-295X.98.3.409, provides an incremental rational categorization baseline.

Kemp & Tenenbaum (2008), DOI 10.1073/pnas.0802631105, model discovery among qualitatively different structural forms.

Pressure:

~~~text
prospective endogenous K formation
must beat fair category-learning / structure-learning baselines.
~~~

### 5.4 Diffusion relative-constitution baseline

Biroli et al. (2024), DOI 10.1038/s41467-024-54281-3, identify a reverse-diffusion speciation transition in which broad class structure emerges before later sample-level collapse.

Pressure:

~~~text
category / mode commitment inside a supplied state space
can be generated by a fixed-space diffusion model;
therefore such commitment alone is C-R-like, not C-F or primitive L0.
~~~

## 7. Diffusion-specific boundary

The author correction does not identify SRT with diffusion.

Corrected role split:

~~~text
generic SDE dynamics
!= ML diffusion training
!= learned score field
!= reverse generative trajectory.
~~~

Possible use:

~~~text

-> retained score / parameter field
-> later reverse-generation trajectory
~~~

as an implementation analogy for sedimentation / return.

At the same time, reverse diffusion is a fair **relative-constitution baseline** because class / mode commitment can occur within a fixed supplied state space.

Therefore:

~~~text
diffusion is neither excluded from L0/L1-adjacent testing
nor admitted as unrestricted L0->L1 explanation.
~~~
