## 1. Strong mature pressure family — homogeneous neural fields and continuous attractors

### 1.1 Amari 1977 neural-field pattern formation

Primary source:

- Shun-ichi Amari (1977), “Dynamics of Pattern Formation in Lateral-Inhibition Type Neural Fields,” *Biological Cybernetics* 27(2):77–87. DOI `10.1007/BF00337259`.

Source-native result relevant here:

```text
homogeneous lateral-inhibition type neural field
+ fixed mutual connection structure
+ suitable stimulation / field regime
-> localized excitation pattern
-> localized pattern can persist after the eliciting stimulus disappears
```

The source studies pattern formation dynamics in a homogeneous field; a localized excitation of fixed size can be retained persistently after the stimulus vanishes. The architecture does not require synaptic learning / accumulated weight plasticity as the immediate mechanism that creates the persistent bump.

Safe pressure only:

```text
a persistent localized causal state can be generated and maintained
by current recurrent field dynamics
without first appealing to learned historical restructuring
of the connection matrix.
```

Do not infer:

```text
Amari bump = Selection-position
Amari disproves SRT
fixed neural-field connectivity = pre-One ontology
```

### 1.2 Continuous-attractor family

Supporting mature review:

- Mikail Khona & Ila R. Fiete (2022), “Attractor and integrator networks in the brain,” *Nature Reviews Neuroscience* 23:744–766. DOI `10.1038/s41583-022-00642-0`.

The review describes attractor-network mechanisms by which simple units collectively generate persistent activity states, including low-dimensional continuous-attractor dynamics used for working memory, error correction and integration.

A standard CANN family uses translation-invariant recurrent organization so that no single represented value / bump location is hard-coded as the only attractor. Localized bump states form a continuous family of possible persistent states.

This supplies a mature downstream architecture in which:

```text
pre-existing homogeneous / symmetric interaction law
-> spontaneous or input-triggered symmetry breaking
-> localized persistent state
-> later dynamics issue from that current state
```

without requiring that each persistent locus be created by prior plastic rewrite of the recurrent interaction law.

## 2. Candidate X2-A — endogenous bump locus with fixed transition law

The strongest current bounded counterexample candidate is:

```text
initial field / attractor architecture:
  no single bump location is privileged as the unique current locus

current dynamics:
  local excitation / longer-range inhibition or equivalent attractor feedback

perturbation / input:
  triggers symmetry breaking

result:
  one localized bump / attractor state forms
  and persists after the original trigger is removed

underlying transition law / recurrent weights:
  unchanged by the bump-forming history
```

Candidate mapping:

```text
persistent bump / localized attractor state
-> P*_endo candidate

no learned / plastic rewrite of underlying recurrent law
-> candidate ¬S_H* under a strong writeback reading
```

Why this is stronger than the earlier external-controller pressure:

```text
the particular current locus is not simply supplied as a fixed external box;
it forms dynamically from a field that supports multiple possible loci.
```

Why it is still bounded:

```text
the neural field / units / interaction law / system boundary are pre-specified;
therefore this pressures formation of a higher-level locus,
not genesis of every underlying unit from a pre-individual domain.
```

## 3. The counterexample search exposes an unresolved meaning of “sedimentation”

The candidate cannot yet be adjudicated because `S_H*` itself has two materially different readings.

### S-H-WEAK — any persistent post-event asymmetry counts

```text
prior event / trigger
-> current localized asymmetric activity state persists
-> later transitions are conditioned by that state
```

Under this reading, an Amari/CANN bump itself already counts as sedimented foreground/background asymmetry.

Result:

```text
X2-A is NOT P*_endo ∧ ¬S_H*;
it satisfies S_H-WEAK.
```

But the cost is severe generic-dynamics absorption:

```text
sedimentation
≈ persistence of an attractor / localized activity state
```

Then the strengthened claim risks adding no structural burden beyond ordinary attractor formation / persistent-state dynamics. Bowler-style absorption pressure becomes stronger, not weaker.

### S-H-STRONG — historical differentiation must rewrite / carry forward the transition structure beyond mere current occupancy

A stronger reading would require something like:

```text
prior Selection differentiation
-> leaves a retained asymmetry in the conditions / transition geometry
   from which later Selection is generated or reconstituted

AND
that carry-over is not exhausted by saying
"the system is currently occupying one asymmetric state".
```

Under this reading, a fixed-weight bump attractor becomes a serious counterexample candidate:

```text
P*_endo may form and persist
while the underlying transition law is not historically rewritten
by the bump-forming sequence.
```

Result:

```text
X2-A = LIVE candidate for P*_endo ∧ ¬S_H-STRONG
```

But this stronger reading has **not** been author-adjudicated by the current Scope-B ruling.

## 4. Why the distinction cannot be hidden inside “current causal stratification”

The prior prepass already separated:

```text
S_H* = historical sedimentation provenance / carry-over
S_C* = current non-flat causal geometry
```

Amari/CANN pressure makes that separation concrete.

A bump attractor can plainly have:

```text
S_C* = YES
```

because the current activity geometry is non-flat and causally conditions later transitions.

The open issue is whether it also has the **specific historical sedimentation relation** required by strengthened V.

Therefore:

```text
current foreground/background geometry
!= automatically historical sedimentation
```

unless the author explicitly chooses the weak reading.

This matters for Todd as well:

```text
if strengthened V ultimately requires only S_C*,
then its proposed realiser may be identical to ordinary attractor geometry,
and mechanism-level distinctiveness is not earned.
```

## 5. Stronger counterexample target after X2-A

If S-H-STRONG is intended, the cleanest future test is not “remove the bump.” That only destroys the current state.

Instead compare two systems / conditions with matched current locus-level behavior:

```text
Condition A:
P*_endo formed through history-dependent writeback
that changes later transition structure

Condition B:
P*_endo formed through fixed-law attractor dynamics
without such historical rewrite
```

Then ask whether both support the same declared reconstitution / continuation signature.

If yes:

```text
historical sedimentation provenance is not necessary
for that P* continuation signature.
```

If no:

```text
the difference becomes a candidate route toward specifying
what historical sedimentation contributes beyond generic attractor persistence.
```

This remains design logic only, not experiment authorization.

## 6. Secondary pressure family — winnerless / heteroclinic competition

Supporting sources:

- Rabinovich et al. (2001), “Dynamical Encoding by Networks of Competing Neuron Groups: Winnerless Competition,” *Physical Review Letters* 87:068102. DOI `10.1103/PhysRevLett.87.068102`.
- Voit & Meyer-Ortmanns (2023), “Heteroclinic networks for brain dynamics,” *Frontiers in Network Physiology* 3:1276401. DOI `10.3389/fnetp.2023.1276401`.

Fixed heteroclinic network dynamics can produce reproducible sequences of metastable dominant states. This is useful pressure on any claim that foreground/background succession itself requires accumulated learning history.

However, it is weaker than the bump-attractor family for the present Scope-B target because:

```text
winnerless competition naturally supplies transitions / sequences,
but not necessarily one persisting re-identifiable locus P*
from which later Selection repeatedly resumes.
```

Therefore it is retained as secondary pressure, not the current strongest counterexample candidate.
