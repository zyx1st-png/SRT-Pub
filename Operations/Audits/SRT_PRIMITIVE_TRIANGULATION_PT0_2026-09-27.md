# Primitive triangulation PT0 — Whitehead / Simondon / reversible actuality

> **Role:** candidate machine analysis for the current primitive Selection anti-tautology question after the PR #1074 corrective.
>
> **Canonical impact:** NONE.
>
> **Goal:** determine which burdens actually belong to the primitive question and which belong to downstream/domain specialization.

## 1. Canonical constraints recovered before comparison

Current owners jointly require:

~~~text
Selection
= reality under genuine actualised non-neutral differentiation;

determinate actuality
= actualising aspect of Selection;

Selection occurrence
!= retained history
!= durable trace
!= One / Bearer / Agency;

terminal Selection remains genuine;

arbitrary descriptive / modelled change
!= Selection merely because a model shows a transition;

universal physical irreversibility / durable residue
!= primitive Selection criterion;

compatibility with ontic determinism
= OPEN;

non-preclosed
minimally rejects a completed pregiven outcome inventory.
~~~

The current irreversibility owner additionally permits:

- later reversal / cancellation / compensation;
- observationally or functionally equivalent return;
- disappearance of active trace;
- model path dependence to vanish;

without making an earlier genuine occurrence equal to never-occurrence.

Therefore the older universal-strength route:

~~~text
reversible process
-> not genuine Selection
~~~

is no longer controlling.

## 2. PT-RV — deterministic reversible actuality

### Case

~~~text
a real system genuinely changes;
the governing law is deterministic;
the law is time-reversal symmetric / invertible;
the rule is fixed;
no chooser;
no primitive probability;
no value;
no novelty requirement;
no retained-history requirement;
no rule rewrite.
~~~

### Candidate verdict

Under current Selection-totality semantics:

~~~text
law-level reversibility
does NOT exclude genuine Selection.
~~~

The correct separation is:

~~~text
a modelled reversible transition
!= Selection merely because the model changes state;

but

a genuine actual occurrence realized under reversible dynamics
is not disqualified from Selection merely because an inverse trajectory is lawful.
~~~

So PT-RV supports the following candidate answer:

> **Reversibility is orthogonal to primitive Selection admission.**

### Consequence

The primitive “non-role-interchangeability” cannot mean:

- forward time is ontically privileged by every Selection;
- every Selection is dynamically non-invertible;
- every Selection leaves an irreversible residue.

Those stronger readings were already removed by the current irreversibility owner.

If non-role-interchangeability survives, it must concern the occurrence / manifestation relation itself, not a universal temporal arrow.

## 3. PT-RV exposes a sharper anti-tautology problem

Once irreversibility is removed, two very different asymmetries remain possible:

### RV-A — occurrence asymmetry

~~~text
occurred
!=
never occurred.
~~~

This is current P0-03.

But this alone is close to a generic realist truth. It does not yet show why the term **Selection** earns explanatory content over “actual occurrence”.

### RV-B — O0/S0 non-preclosure burden

~~~text
actuality
is not exhausted by a completed pregiven outcome inventory
or a maximally role-interchangeable neutral occurrence structure.
~~~

This is the distinct SRT burden.

Therefore PT-RV suggests:

> **the current anti-tautology problem may not be solved by finding a new event-classification criterion. It may instead reduce to whether the O0/S0 package has non-redundant explanatory / derivational work beyond bare actuality.**

That is a different question.

## 4. PT-WH — Whitehead separates primitive jobs from thicker jobs

Whitehead supplies a rich package:

~~~text
antecedent-world conditioning;
pure potentials / eternal objects;
subjective form / valuation;
initial aim / relevance ordering;
actual occasion unity.
~~~

These structures answer several jobs at once.

The SRT comparison must split them.

### WH-P0 — primitive occurrence / actualisation

SRT does **not** need eternal objects merely to say:

~~~text
a determinate actuality occurs.
~~~

### WH-P1 — why this determination / relevance?

Whitehead's pure potentials and initial aim provide a richer answer to:

~~~text
why these determinations are available / relevant;
why becoming is ordered rather than arbitrary;
how the actual occasion takes up its antecedent world.
~~~

Current SRT primitive ontology does not yet provide an equally rich source-native account.

But this does not automatically defeat SRT, because the canonical L0 burden is thinner: primitive Selection is not required to provide a complete content-level reason for why A rather than B in every domain.

Thus Whitehead pressures **PB1/PB2 specialization**, not necessarily primitive admission.

### WH-P2 — recurrence of “the same determination”

Cross-event recurrence / repeatability should be routed first through:

- invariant relations;
- formed equivalence;
- recurrent objectification;
- Gate / retained organization;
- history.

Do not force a universal / eternal-object solution into primitive Selection merely to explain recurrence.

### Whitehead verdict

~~~text
primitive replacement of all Whitehead jobs = NOT REQUIRED;

job-preservation burden:
- occurrence: SRT has a thin answer;
- relevance/order: SRT thinner / OPEN;
- recurrence: downstream control, OPEN but not primitive;
- experiential/valuation package: outside CURRENT NEXT.
~~~

Whitehead is therefore a pressure source, not yet a depth verdict.

## 5. PT-SI — Simondon is a strong localization / transformation specialization

Simondon's metastability, tension, incompatibility and transduction answer:

~~~text
why individuation becomes possible;
where / when instability resolves;
how local resolution propagates;
how new structure changes later conditions.
~~~

These are powerful generative mechanisms.

The corrected SRT typing is:

~~~text
Simondon metastability/tension
= strong PB2 / GN2-GN3 realization candidate;

not automatically
= primitive PB0/PB1 definition.
~~~

This matters because SRT should remain able to treat genuine actualisation under cases that lack a Simondon-style metastable landscape.

### Simondon neighbor surplus

Current SRT does not yet match Simondon's richness on:

- localization of individuation;
- metastable potential;
- tension / incompatibility as transformation driver;
- retained preindividual potential for continued individuation.

Record that surplus rather than converting it into an SRT win.

## 7. Candidate reformulation of the anti-tautology problem

The original wording asks:

> What distinguishes genuine actualised Selection from merely descriptive / modelled change?

PT0 suggests splitting the answer into two layers.

### Layer AT-1 — occurrence admission

A domain must supply enough evidence that:

- something actually occurred / differentiated;
- event individuation is not solely a convenient analyst segmentation;
- legitimate representation change does not create or erase the occurrence.

This is a methodological / domain-admission burden.

It is not yet the distinctive metaphysical content of SRT.

### Layer AT-2 — primitive non-redundancy

Ask:

> Given genuine actuality, what does the SRT Selection/O0/S0 package add over bare actualism / process occurrence?

Candidate answer:

~~~text
actuality is not ontologically exhausted by:
- a completed pregiven outcome inventory;
- a maximally neutral role-interchangeable occurrence relation;
- a model whose transition graph is treated as the full ontology.
~~~

But this candidate only earns theory value if it yields non-circular downstream consequences or explanatory compression.
