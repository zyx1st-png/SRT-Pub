# Active Selection target depth — what must actually be reconstructed?

## 1. Starting author threshold

Author-accepted minimum direction:

```text
PASSIVE Selection
primarily sustains continued existence / viability
within an achieved selectable organization.

ACTIVE Selection
acts on / reconstructs the organization
that determines later selectability itself.
```

Pass 22 already rejected weak substitutes:

```text
future behavior changes: too weak;
policy weighting changes: too weak by itself;
more energetic action: irrelevant;
creates any new possibility: too strong as universal criterion.
```

The current problem is therefore the **target depth** of Selection.

## 2. Do not turn survival and creation into exclusive motives

The author language names:

```text
PASSIVE = survival
ACTIVE = creation / reconstruction.
```

But machine interpretation must not infer:

```text
survival goal -> PASSIVE only;
creative goal -> ACTIVE only.
```

A One may reconstruct its selectable organization precisely in order to survive.

Therefore:

```text
PASSIVE / ACTIVE
is better pressure-tested by what Selection acts on,
not by the psychological or functional purpose of the act.
```

Possible combined case:

```text
survival pressure
-> ACTIVE reconstruction of future selectability
-> new organization
-> later PASSIVE maintenance of that organization.
```

Thus maintenance and reconstruction can compose rather than exclude one another.

## 3. Machine-only target-depth ladder

This is an audit ladder, not ontology.

### D0 — current state change

```text
Selection changes x_t;
future organization remains structurally the same.
```

Disposition:

```text
ACTIVE threshold: NO.
```

### D1 — execution / weighting change

```text
Selection changes preferences, policy weights, readiness, salience,
or transition probabilities among already organized candidate relations.
```

Disposition:

```text
ACTIVE threshold: NOT AUTOMATIC.
```

Ordinary learning / adaptive control strongly pays this level.

### D2 — constraint / reachability reconfiguration

```text
Selection changes which continuation relations are reachable,
admissible, supported, inhibited or effectively enterable later.
```

Disposition:

```text
ACTIVE pressure: LIVE.
```

But this still needs care: ordinary learning can sometimes change effective reachability.

### D3 — continuation-organization reconstruction

```text
Selection changes the organization by which future continuations
are generated / admitted / suppressed / related for the One.
```

Examples of machine-side structural targets:

```text
continuation criteria;
relation topology;
role / boundary conditions;
option-generation rules;
constraint architecture;
which histories can re-enter which future paths.
```

Disposition:

```text
CURRENT STRONGEST generic ACTIVE target candidate.
```

### D4 — relation-level / multi-position reconstruction

```text
multiple positions change the relation-level organization
that later conditions what each participant can select.
```

Disposition:

```text
ACTIVE at relation level;
JFS candidate when jointly produced;
not automatically higher-order One / Bearer / collective ISP.
```

## 4. Why D1 is insufficient

Suppose fixed candidate set / relation architecture:

```text
{a,b,c}
```

and learning changes:

```text
p(a), p(b), p(c).
```

This can strongly alter behavior without reconstructing what counts as a candidate relation or how future candidates become available.

Therefore:

```text
Delta probability over fixed organization
!= ACTIVE Selection by itself.
```

## 5. Why D3 does not require ex nihilo novelty

ACTIVE Selection need not create a wholly unprecedented option.

It may:

```text
reopen a backgrounded continuation;
close a formerly admissible route;
change boundary conditions;
recombine existing relations;
change the support / suppression architecture;
change which histories are allowed to organize future Selection;
restructure relations among existing possibilities.
```

Thus:

```text
ACTIVE reconstruction
!= absolute novelty requirement.
```

This preserves the author's use of both `creation` and `reconstruction`.

## 6. Relation to One / Bearer

For an admitted One O:

```text
Phi_O
```

is machine-only shorthand for:

> the organization that helps determine how future selectability is generated for O.

Then:

```text
PASSIVE-dominant Selection:
operate under / repair enough of Phi_O for continued O.

ACTIVE Selection:
Selection materially changes Phi_O itself.
```

Bearer is orthogonal:

```text
q -> reconstitution_O
```

can occur with or without ACTIVE reconstruction of `Phi_O`.

## 7. External challenge can trigger Active Selection

Do not require the initiating consequence to be self-caused.

Possible:

```text
external q
-> q is borne by O
-> O's later Selection reconstructs Phi_O
-> future selectability organization changes.
```

This is compatible with Active Selection because the decisive relation is:

```text
Selection acts on Phi_O,
```

not:

```text
O caused the original disturbance.
```

Self-consequence closure is therefore a separate agency-like relation, not a prerequisite for every ACTIVE episode.

## 8. Active survival is coherent

Important case:

```text
current Phi_O cannot sustain continuation under perturbation;
O reconstructs Phi_O;
O survives under a new selectable organization.
```

Then:

```text
survival function: YES
ACTIVE Selection: YES
```

because the organization of later selectability was reconstructed.

Therefore the author terms should be read as modal emphases, not mutually exclusive teleologies.

## 9. Passive maintenance can contain prediction / learning

A One can:

```text
forecast threats;
learn parameter values;
repair damage;
update policies;
change local state;
```

while leaving the deeper continuation-organization largely intact.

Then:

```text
prediction: possible
learning: possible
behavioral activity: high
PASSIVE-dominant mode: still possible.
```

This preserves Pass 21's warning that PASSIVE does not mean inert.

## 10. Counterfactual machine test

To pressure whether a change is merely D1 or reaches D3, ask:

> Holding the current immediate state / candidate menu as similar as possible, does the intervention alter the rule / constraint organization by which later candidates, continuations or exclusions are generated and related?

If only current weighting changes:

```text
ACTIVE claim weakens.
```

If later selectable organization differs even under matched immediate conditions:

```text
ACTIVE pressure strengthens.
```

This is conceptual audit language only; it is not a new experimental authorization and must not revive retired history-localization routes.

## 11. Relation to multi-subject order

The same target-depth distinction applies relationally.

### Passive relational maintenance

```text
participants reproduce existing roles / expectations / constraints
sufficiently for the relation/order to continue.
```

### Active relational reconstruction

```text
participants change the rules / roles / boundaries / relation topology
that determine what can become selectable later.
```

When this is jointly constitutive:

```text
JFS pressure strengthens.
```

But:

```text
relation-level ACTIVE Selection
!= collective subjecthood.
```

## 12. Current verdict

```text
PASSIVE vs ACTIVE as exclusive motive categories: REJECT
survival can use ACTIVE reconstruction: YES
creation can later require PASSIVE maintenance: YES
D0 state change: below ACTIVE threshold
D1 weighting / ordinary learning: insufficient by itself
D2 reachability reconfiguration: live but pressured
D3 continuation-organization reconstruction: current strongest generic target candidate
absolute new possibility required: NO
self-caused initiating consequence required: NO
Bearer required for every cross-layer ACTIVE Selection: NOT ESTABLISHED
cognitive reflection required: NO
canonical edit: NO
new Level: NO
scientific distinctiveness: NOT ESTABLISHED
```

## 13. Next pressure

The next question is now sharper:

> **Can `Phi_O` / continuation-organization be stated entirely in the already accepted vertical-structure language, so that Active Selection becomes a deeper transformation of the same vertical organization rather than a new meta-level object?**

If yes, the architecture can avoid an infinite regress of selectors selecting selection-rules.
