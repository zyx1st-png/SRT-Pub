# Multiscale Selection indexing — field and position need not compete for one causal owner

## 1. False binary to avoid

The preceding correction distinguished:

```text
field-indexed Selection
vs
position-indexed Selection.
```

That distinction is useful, but `vs` must not be read as exclusive.

Because the current ontology already permits:

```text
nested Ones;
overlapping Ones;
multiscale Bearer attribution;
relation-level organization;
```

the same physical / social event may instantiate Selection relations at more than one scale.

Therefore do not require:

```text
exactly one true Selection index.
```

## 2. Non-exclusive indexing

Possible structure:

```text
wider field F undergoes Selection_F
AND
formed One O participates through P^O in Selection_O
AND
relation R among O and other positions may instantiate Selection_R.
```

These are not automatically three separate events.
They can be three typed relations realized by one coupled episode.

## 3. Position indexing requires an additional paid relation

O-position indexing is not granted merely because O is physically present inside F.

Require:

```text
A. O independently pays One / Selection-position standing;
B. P^O's lineage-conditioned vertical organization materially affects
   which reconstruction continuations are manifested / supported / suppressed;
C. that contribution is load-bearing in W2 reconstruction at O or relation level;
D. deleting / substituting the lineage-specific organization changes the selective reconstruction
   under approximately matched wider-field conditions.
```

Machine phrase:

> **lineage-specific selective mediation**

This is an audit relation only.

## 4. No unique-cause requirement

Do not demand:

```text
O alone caused the outcome;
field causes are absent;
external trigger is negligible;
P^O explains 100% of variance.
```

Position-indexed Selection can be genuinely constitutive while wider field / other positions are also necessary.

Thus:

```text
constitutive contribution
!= exclusive cause.
```

## 5. Stronger than generic internal-condition language

Every subsystem state is an internal condition of a larger field.

To avoid trivial indexing, require **typed specificity**:

```text
the contribution of P^O must track O's own lineage-conditioned vertical organization,
not merely generic mass / location / fixed coupling constant.
```

Example machine contrast:

```text
same broader q
+ different current O-lineage histories / vertical organizations
-> systematically different manifestation/background pattern
-> systematically different W2 reconstruction route.
```

This does not prove a metaphysically separate cause.
It shows that O's formed selective organization is a real causal mediator rather than an analyst's arbitrary sub-box.

## 6. Deletion / substitution pressure

Three conceptual manipulations:

### Delete O-position organization

Preserve wider field as far as coherent while removing the lineage-specific organization that makes P^O a formed position.

If reconstruction is unchanged:

```text
O-indexing weakens.
```

If selective differentiation / W2 route changes materially:

```text
O-indexing strengthens.
```

### Substitute another position

Replace P^O with P^B under matched wider conditions.

If the reconstruction tracks the substituted position's vertical history:

```text
position-indexed mediation strengthens.
```

### Preserve O but change external q

If O mediates different q through a coherent lineage-specific selective organization, this supports the claim that P^O is an operative from-where rather than a one-off correlation.

These are conceptual pressure tests, not experimental authorizations.

## 7. Selection indexing can be nested

Possible:

```text
Selection_F
contains / realizes
Selection_O
contains / realizes
Selection_subprocess
```

but do not infer ordinary mereological containment automatically.

Each claimed index must pay its own:

```text
non-equivalent potential relation;
asymmetric actualisation;
manifestation / relative backgrounding;
relevant writeback;
appropriate conditioning organization.
```

## 8. Active Selection at multiple scales

Likewise W2 reconstruction may be multiscale.

```text
O actively reconstructs its continuation organization;
relation AB is jointly reconstructed;
wider institutional / ecological field also changes.
```

Possible simultaneous dispositions:

```text
Active_O = YES
Active_AB = YES
Active_F = YES / case-dependent.
```

No higher level automatically erases lower-level active participation.

## 9. Relation to Bearer non-exclusivity

Bearer geometry already established:

```text
q can be borne at multiple scales
if each scale independently pays q -> later reconstitution_X.
```

Selection indexing now receives the symmetric guard:

```text
one episode can be Selective at multiple scales
if each scale independently pays its from-where / differentiation relation.
```

This yields a useful duality:

```text
from-where can be multiscale;
to-where can be multiscale.
```

## 10. Relation to JFS

In a multi-position episode:

```text
P_A and P_B can each retain position-indexed Selection standing
while jointly constituting relation-level W2 reconstruction.
```

Therefore JFS need not dissolve individual positions into one collective chooser.

Rather:

```text
from-where_A + from-where_B
-> jointly load-bearing relation-level reconstruction
```

with separate A/B One standing preserved.
