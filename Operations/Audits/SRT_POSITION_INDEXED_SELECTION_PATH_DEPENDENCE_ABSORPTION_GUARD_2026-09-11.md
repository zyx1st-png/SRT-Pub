# Position-indexed Selection and path dependence — absorption guard

## 1. Stop the wrong question

The previous audit ended with:

> Can lineage-specific selective mediation be distinguished from ordinary path-dependent causal mediation without simply restating the One definition?

That question risks slipping back into defensive residual hunting.

Current constructive-integration governance instead requires:

```text
if a mature / ordinary dynamics family genuinely pays the SRT-typed relation,
accept it as a realization / implementation candidate;
do not add an ad hoc extra property merely to force distinctiveness.
```

Therefore the problem is not:

```text
How do we exclude path dependence?
```

It is:

```text
Which path-dependent systems pay only generic history dependence,
and which pay the full One / position-indexed Selection / W2 relation?
```

## 2. Generic path dependence remains too weak

Weak shape:

```text
past state H_t
-> changes probability / cost / transition tendency at t+1.
```

This alone does not establish:

```text
an independently admitted One;
a current operative Selection-position;
non-equivalent reconstruction potentials;
manifestation + relative backgrounding through that position;
W2 reconstruction of future selectability organization.
```

So:

```text
history matters
!= full position-indexed Active Selection.
```

## 3. But path-dependent dynamics may realize the full relation

Suppose a system pays:

```text
O1 — One standing:
prior Selection-generated vertical organization
-> lineage-relative reconstitution
-> current P^O_t.

P1 — positioned Selection:
P^O_t materially organizes non-equivalent reconstructive continuations
through asymmetric manifestation / relative backgrounding.

W2 — organizational writeback:
that differentiation changes the vertical relation organization
through which later selectability is generated.
```

Then a path-dependent physical / biological / computational / social mechanism may be the implementation of this relation.

Disposition:

```text
path-dependent realization: ALLOWED
SRT ontology falsified by ordinary mechanism: NO
SRT scientific novelty thereby earned: NO
```

## 4. Typed cycle — the useful distinction

Current machine cycle:

```text
HISTORY / PRIOR VERTICAL ORGANIZATION
        ↓
[O] lineage-relative reconstitution
        ↓
CURRENT SELECTION-POSITION P_t
        ↓
[P] position-indexed asymmetric actualisation
    manifestation + relative backgrounding
        ↓
[W2] organizational writeback
        ↓
FUTURE VERTICAL ORGANIZATION
        ↓
feeds later reconstitution
```

The value of the architecture is the **typed dependency cycle**, not a proprietary dynamical law.

## 5. Three partial-payment cases

### Case PD-1 — history without One

```text
past trajectory biases present transition;
no localized lineage-relative process unit is established.
```

Disposition:

```text
path dependence: YES
One: NO / unestablished
position-indexed Active Selection: NO.
```

### Case PD-2 — One continuation without positioned W2

```text
local lineage is reconstituted;
current P exists;
history preserves continuation;
current response changes state / weights only.
```

Disposition:

```text
One: YES
Passive / W1-dominant Selection: possible
Active W2: not established.
```

### Case PD-3 — full typed cycle

```text
One / P exists;
P selectively differentiates reconstructive continuations;
result changes organization of later selectability;
new organization re-enters later P reconstitution.
```

Disposition:

```text
position-indexed Active Selection: strong candidate
ordinary path-dependent mechanism: valid realization candidate.
```

## 6. Do not resurrect history-localization

The full cycle does not require:

```text
history stored inside O;
a unique memory token;
a provenance register;
a non-ordinary causal carrier.
```

History can remain distributed while the relevant historical difference is load-bearing for the typed reconstitution / Selection relation.

Cycle-1 shuffled-writeback remains retired as a distinctiveness route.

## 7. No novelty from the cycle alone

Mature theories already pay components or even large parts of the cycle:

```text
Simondon: operation -> structure -> operation / transduction;
autonomy / enactivism: history-sensitive self-maintenance and adaptive coupling;
adaptive networks: state <-> topology coevolution;
niche construction: activity modifies later selective conditions;
Luhmann: prior decisions become later decision premises;
learning systems: history changes later policy / accessibility.
```

Therefore:

```text
full typed cycle exists somewhere
-> SRT distinctiveness
```

is invalid.

Current SRT-side contribution remains the proposed cross-level repartition of:

```text
Selection
vertical organization
One
Selection-position
Bearer
Active / Passive mode
JFS
higher-order One / Bearer.
```

## 8. Constructive-integration consequence

Instead of subtracting until a tiny residual remains, future domain work should ask:

```text
Which mature theory pays which edge of the typed cycle?
Which mechanisms instantiate the edge in that domain?
Where do assumptions conflict?
Can several paid mechanisms be composed without identity collapse?
What new explanatory / formal / intervention capacity emerges from the composition?
```

This is consistent with the author's integrative-whole direction.
