# Selection cross-scale invariant — four-scale realization pressure
## Physical / biological / cognitive / social

> **Boundary:** machine-side audit only. No author answer is supplied here. No canonical edit, symbol, theorem, Level assignment, scientific-distinctiveness claim or experiment is authorized.
>
> **Question:** after separating event-relative background from formed support-background, can the same SRT grammar survive across four scales without becoming metaphorical?

---

## 0. Executive verdict

The full strong candidate does **not** currently survive as a literal four-scale invariant.

In particular:

```text
Selection-relative background (B_rel)
!=
formed support-background / scaffold (B_sup)
```

and `B_sup` is not cleanly meaningful as a universal primitive category at the physical / pre-object level.

The strongest current four-scale result is instead a **layered invariant**:

```text
UNIVERSAL / ONTOLOGICAL TRUNK
Selection-generated differential organization
-> formed organization can become load-bearing for later Selection / process

DOMAIN-SPECIFIC REALIZATION
at biological / cognitive / social scales,
that load-bearing formed organization may be realized as
niche, habit, affordance landscape, tool, language, institution,
distributed practice or other scaffold.
```

Therefore the safest current architecture is:

```text
primitive B_rel = event-level / Selection-relative;
B_sup = downstream formed-condition role, not a third primitive side of Selection.
```

This is already compatible with the canonical Spine rule:

```text
later Selection may be conditioned by a formed One / Selection-position;
Selection under formed constraints remains the same primitive kind.
```

Machine verdict:

```text
strong full-scale identity of `background` = FAIL / OVERSTRONG
narrow result-to-condition recurrence = PASS / already neighbor-paid
support-background as post-formation realization class = LIVE
same causal mechanism across all scales = NOT ESTABLISHED
same typed dependency across scales = PARTIAL / PROMISING
architecture-level SRT value = LIVE
whole-architecture non-substitutability = NOT ESTABLISHED
scientific distinctiveness = NOT ESTABLISHED
Level 2 = HOLD
```

## 2. Scale P — physical / pre-object / material formation

### 2.1 Strongest safe source-native case

The safest current repository case is not speculative SRT quantum language.

Use the mature Simondon / transduction comparison and pattern-formation controls:

```text
metastable / relational physical configuration
-> local structuring / transduction
-> produced structure
-> produced structure becomes a condition for later local structuring
-> further propagation / differentiation.
```

The Simondon source card explicitly records:

```text
local resolution produces a structure;
that structure becomes the condition of the next local resolution;
transduction != canonical Selection.
```

This is a strong physical / material result-to-condition architecture.

### 2.2 CSI payment

```text
CSI-1 event asymmetry               = PARTIAL / mechanism-specific
CSI-2 retained consequence          = PAID at produced-structure level
CSI-3 support-background formation  = ONLY IN THIN LOAD-BEARING SENSE
CSI-4 future-condition effect       = PAID
CSI-5 B_rel != B_sup                = REQUIRED TO AVOID CATEGORY ERROR
CSI-6 scale discipline              = PAID if no phenomenological language is imported
```

### 2.3 Critical negative

At this scale, the phrase:

```text
"the support recedes from foreground"
```

has no clean observer-independent meaning by itself.

The physically safe statement is only:

```text
formed structure is not the current generated output,
but remains an operative condition of later process.
```

Therefore:

```text
physical B_sup as literal hidden / unnoticed background = NOT ESTABLISHED
physical formed-condition role = YES
```

This blocks a naive claim that social scaffolding is simply the same object as physical backgrounding at another scale.

## 3. Scale B — biological / ecological niche construction

### 3.1 Source-native chain

Niche-construction theory supplies:

```text
organism activity
-> modification of ecological / social environment
-> changed selective environment / action conditions
-> altered selection pressures for self / others / later generations
-> ecological inheritance.
```

No SRT vocabulary is required for this chain.

### 3.2 CSI payment

```text
CSI-1 event asymmetry               = NOT REQUIRED AS SRT-STYLE B_rel
CSI-2 retained consequence          = STRONGLY PAID
CSI-3 support-background formation  = STRONGLY PAID as constructed niche / inherited environment
CSI-4 future-selectability effect   = STRONGLY PAID
CSI-5 B_rel != B_sup                = YES / necessary
CSI-6 scale discipline              = PAID
```

### 3.3 Consequence

Biology strongly pays:

```text
formed environmental structure
-> future selection condition.
```

But it does **not** require that the environmental scaffold be the same ontological relation as the `B_rel` side of one primitive Selection event.

Therefore the transition:

```text
B_rel -> B_sup
```

cannot be treated as automatic merely because both are called background.

## 4. Scale C — cognitive / embodied / ecological cognition

### 4.1 Source-native chain

Phenomenological / embodied and ecological approaches strongly pay:

```text
past activity / learning
-> habit-body / skill organization;

environment + organism
-> affordance landscape / action possibilities;

stable skill / environmental organization
-> reduced need for explicit foreground calculation;

breakdown / conflict / mismatch
-> previously backgrounded support becomes salient.
```

Sterelny and extended / scaffolded cognition add:

```text
tools / informational structures / learning environments
-> external support for intelligent action and development.
```

### 4.2 CSI payment

```text
CSI-1 event asymmetry               = PARTIAL / not uniquely SRT
CSI-2 retained consequence          = PAID
CSI-3 support-background formation  = STRONGLY PAID
CSI-4 future-selectability effect   = STRONGLY PAID
CSI-5 B_rel != B_sup                = ESSENTIAL
CSI-6 scale discipline              = PAID
```

### 4.3 Strong local result

This is the first scale at which `background support` has a robust native meaning close to Q10:

```text
it is causally / practically load-bearing
while normally not requiring explicit thematic foregrounding.
```

The mismatch-reveal pattern is also strong here:

```text
stable support is often discovered through failure, conflict, removal or novice entry.
```

But these roles are mature-neighbor territory.

## 5. Scale S — social / institutional / distributed-agent organization

### 5.1 Source-native chain

Distributed cognition, cultural scaffolding and institutional analysis already permit:

```text
persons + artifacts + symbolic media + procedures
-> distributed performance;

repeated social practice
-> language / norm / procedure / institution / infrastructure;

formed social structure
-> changes later action cost, visibility, access and coordination;
```

Q10 and Q19 provide SRT-side companion formulations:

```text
past choices sediment into default terrain;
backgrounded order reduces repeated calculation;
writeback changes later visibility / friction;
scaffold can support or substitute for later judgement;
consequence return matters to capacity formation.
```

### 5.2 CSI payment

```text
CSI-1 event asymmetry               = DOMAIN-DEPENDENT / not a universal social primitive
CSI-2 retained consequence          = STRONGLY PAID
CSI-3 support-background formation  = STRONGLY PAID
CSI-4 future-selectability effect   = STRONGLY PAID
CSI-5 B_rel != B_sup                = ESSENTIAL
CSI-6 scale discipline              = REQUIRED
```

### 5.3 Multi-agent distribution

The previous pass's machine decomposition remains useful:

```text
G generation;
F filtering / foregrounding;
X execution;
C consequence-bearing;
W writeback;
R reselection / revision.
```

A social system can distribute these roles across different people, tools, institutions and AI systems.

This is **not** unique because distributed-cognition traditions already distribute cognitive work.

The potentially SRT-relevant addition is narrower:

```text
which position bears consequences;
where writeback returns;
which position retains reselection capacity;
how the distribution changes future selectable terrain.
```

Those relations remain downstream research candidates and must not be projected back into primitive Selection by definition.

## 7. Narrow invariant J* after four-scale pressure

Define a new machine-only compression of what actually survives:

```text
J1 GENERATED ORGANIZATION
   an endogenous process produces a differentiated organization;

J2 RESULT-TO-CONDITION TRANSFORMATION
   some produced organization becomes a condition for later process;

J3 ACCESSIBILITY / TRANSITION RESHAPING
   that condition changes what later transitions are easier, harder,
   reachable, amplifiable, stable or reconstructible;

J4 REUSE / INHERITANCE / RECURRENCE
   the conditioning role can recur, propagate, be inherited or be reused;

J5 SCALE-SPECIFIC EXPRESSION
   physical structure, ecological niche, embodied habit and institution
   need not be one object-kind to instantiate the dependency.
```

`J*` is real but very broad.

It is strongly neighbor-paid and cannot by itself establish SRT distinctiveness.

## 8. Consequence for the SRT architecture

The four-scale pressure supports a **layered-unification interpretation**, not a literal-mechanism identity interpretation.

### 8.1 Universal trunk

Current canonical universal trunk remains:

```text
non-flat openness
-> subjectless Selection
-> event-level manifest / relative-background verticality
-> regenerative vertical reconstitution
-> One.
```

### 8.2 Post-formation conditioning role

Once formed organization exists:

```text
formed One / organization
-> may materially condition later Selection.
```

This role is already canonical-compatible.

### 8.3 Domain realizations

At downstream scales this conditioning role may be realized as:

```text
physical structure / boundary condition;
ecological niche / inherited environmental modification;
embodied habit / affordance landscape;
tool / external memory / representation;
language / norm / institution / infrastructure;
distributed human-AI workflow.
```

These are not universal ontology rungs.

They are possible **realization classes of formed constraints / scaffolds**.

---

## 9. This avoids two opposite errors

### Error A — flatten everything into one literal mechanism

```text
crystal lattice = habit = institution = language = B_sup
```

This is over-unification.

### Error B — abandon cross-domain ontology entirely

```text
every domain is unrelated;
SRT has no transferable structure.
```

This throws away the real result-to-condition dependency that does recur.

The stronger programme is therefore:

> preserve one typed dependency architecture while allowing different mechanisms and realization classes at different scales.

---

## 10. What kind of unification would count as substantive?

A layered ontology earns more than synthesis only if it constrains mappings.

For each domain SRT should eventually answer:

```text
what counts as generated organization?
what exactly is retained?
what makes it load-bearing rather than merely correlated?
what later transition space is changed?
what is the intervention / deletion test?
what stronger SRT term is NOT licensed at this scale?
```

That last question is essential.

A good unifying ontology must prohibit bad mappings as well as permit analogies.

## 11. Candidate deletion / intervention tests by scale

These are machine-only research templates.

### P physical

```text
neutralize / replace the prior formed structure
while preserving generic external forcing;
ask whether later differentiation / propagation changes.
```

### B biological

```text
hold organism genotype / current state as fixed as practicable;
remove or swap inherited niche modification;
ask whether later developmental / ecological selective trajectories change.
```

### C cognitive

```text
remove / perturb the habit, tool, bodily support or affordance structure;
ask whether candidate generation, friction or transition pattern changes;
use mismatch / breakdown as one diagnostic, not the definition.
```

### S social

```text
alter / remove institutional, linguistic, algorithmic or procedural scaffold;
track changes in visibility, option generation, execution cost,
consequence routing and reselection capacity.
```

The tests differ operationally.

The proposed commonality is only the dependency shape.

## 13. Current machine conclusion

The four-scale pass does **not** support the strongest statement:

```text
"the same foreground/background mechanism literally operates from physics to civilization."
```

It supports a weaker but more disciplined statement:

> **SRT may unify scales through a conserved dependency order — generated difference, formation, result-to-condition transformation, later conditioned Selection — while allowing domain-specific mechanisms and downstream scaffold realizations.**

The primitive manifest / relative-background relation remains specific to Selection.

The scaffold / support-background role should presently be treated as downstream formed-condition semantics, not a new primitive.
