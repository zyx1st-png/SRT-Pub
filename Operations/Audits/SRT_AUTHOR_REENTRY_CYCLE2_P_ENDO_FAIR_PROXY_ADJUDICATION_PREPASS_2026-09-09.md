## 1. Current author / canonical constraints on “position”

### 1.1 Canonical L0 position is intentionally broad

Current L0 terminology defines `position` as the finite conditions under which Selection can occur.

This does not by itself require:

```text
bearer continuity
subjecthood
fixed components
fixed function
historical numerical identity
```

Therefore an audit target broader than bearer is licensed.

### 1.2 Author-accepted bearer reconstruction separates FROM-WHERE and TO-WHERE

The 2026-09-07 author-accepted reconstruction distinguishes:

```text
FROM-WHERE:
  where later Selection resumes from
  = reconstituted stratified Selection-position

TO-WHERE:
  where prior consequences close and become historically load-bearing
  = consequence-bearing organization
```

The accepted summary also keeps three relations distinct:

```text
HORIZONTAL:
  function / role topology

VERTICAL:
  stratified Selection-position

DIACHRONIC:
  consequence return / history writeback
```

and explicitly guards:

```text
vertical / stratified Selection-position != bearer by itself
```

Therefore consequence-bearing closure cannot be silently imported as a necessary condition for the machine proxy of Selection-position merely to defeat the attractor rival.

## 2. Candidate exclusion tests

### X1 — “It has no SED-B history writeback, therefore it is not a Selection-position”

Verdict:

```text
INVALID / CIRCULAR
```

Reason:

SED-B is exactly the allegedly necessary relation under audit.

Using absence of SED-B to deny the target `P` would make:

```text
P requires S
therefore no P without S exists
```

true by definition rather than pressure.

### X2 — “It is not a bearer”

Verdict:

```text
INVALID for the current P proxy
```

Reason:

The author record separates Selection-position from full bearer continuity. Bearer adds consequence closure / higher-order continuing organization.

A rival need not pay bearer to pressure the necessity of SED-B for position formation.

### X3 — “Its components and interaction law are pre-specified”

Verdict:

```text
VALID LIMIT, NOT SUFFICIENT EXCLUSION
```

Reason:

Scope B asks whether the **relevant Selection-position** forms endogenously. It does not currently require every underlying unit / law / field boundary to be generated in the same process.

The attractor architecture pays only:

```text
endogenous higher-level locus formation
```

not preindividual genesis of all substrate.

This limits the counterexample's scope but does not erase it.

### X4 — “Its later transitions are deterministic dynamics, not SRT Selection”

Verdict:

```text
REAL PRESSURE, BUT CANNOT BE USED AS A TERM-level veto
```

Reason:

Strongest-neighbor auditing cannot require the rival to adopt SRT ontology before it can count as a rival.

The fair question is functional / causal:

```text
Does the locus serve as the finite from-where relation
from which later alternative-sensitive / competition / update transitions proceed?
```

Pass 2 pays this narrowly through ring-attractor updating and dynamic-field competition / updating.

If the author intends an additional non-terminological property beyond this, it must be named independently.

### X5 — “It lacks consequence return / non-outsourcing”

Verdict:

```text
VALID for bearer / subject-level targets;
NOT currently owned as a Selection-position admission criterion
```

Reason:

The author reconstruction places consequence bearing in the diachronic / TO-WHERE relation and explicitly distinguishes it from vertical position.

Importing it now would silently change the explanandum from:

```text
Selection-position formation
```

to:

```text
bearer formation / continuity
```

which is a different audit.
