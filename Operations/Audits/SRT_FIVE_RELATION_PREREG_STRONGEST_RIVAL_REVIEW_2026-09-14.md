# Five-relation preregistration — strongest-rival review

> Noncanonical pre-execution audit. This review may narrow or reject the preregistered tests. It does not edit canonical theory or promote any claim.

## 0. Verdict

```text
Control A = RETAIN, but only as a structural discrimination test;
Control B = DEMOTE to calibration / sanity check;
architecture distinctiveness test = MISSING;
required addition = cross-domain transfer + glue-cost/deletion test.
```

Reason:

- multi-agent control, externality theory, capability-style opportunity analysis and Active Inference can all model consequence distribution and adaptive response if the relevant variables are supplied;
- meta-learning / structure learning can pay generator revision directly;
- therefore a within-domain performance difference cannot establish SRT architecture surplus.

The fair target is whether the **same typed relation rules** transfer across domains with less ad hoc remapping and whether deleting the typing causes predictable classification loss.

---

## 1. Control A pressure

### Risk A1 — information advantage

If SRT receives explicit consequence-incidence variables while the rival sees only aggregate reward, the comparison is invalid.

**Required fix:** Rival 2 receives exactly the same position-indexed history, costs, constraints and update traces.

### Risk A2 — revision-bandwidth confound

If A-R has more communication or update bandwidth than A-E, better adaptation may reflect capacity, not topology.

**Required fix:** Match total message/update budget, parameter-update count and observation bandwidth. Only the routing target differs.

### Risk A3 — standing inflation

Toy computational agents do not automatically satisfy SRT Bearer semantics.

**Required fix:** In the computational experiment call them `formed positions / consequence-bearing loci` unless a separate P+E gate is operationalized. Do not cite Control A as Bearer evidence.

### Risk A4 — externality theory already predicts the result

Persistent burden externalization can already explain long-run degradation.

**Disposition:** Control A can test whether five-relation typing is useful and portable, not whether externalization is novel.

---

## 2. Control B pressure

### Fatal weakness B1 — built-in answer

If B-P is forbidden to modify the generator and the perturbation is chosen so no fixed candidate family contains an adequate response, B-G is advantaged by construction.

This can validate the distinction:

```text
policy adaptation != generator revision
```

but not SRT-specific explanatory surplus.

### Fatal weakness B2 — mature rival payment

Structure learning, meta-learning, adaptive control, evolutionary search and model-learning Active Inference already contain generator-level adaptation families.

### Revised status

```text
Control B = CALIBRATION TEST ONLY.
```

It remains useful to verify that SRT's `Revision` label is representation-stable across implementations, but a positive result does not count toward non-substitutability.

---

## 3. Strongest single-family pressure

Extended Active Inference / FEP is the strongest coherent single-family control for Strata II–III because it can combine:

```text
nested boundaries / agents;
future policy organization;
learning;
model revision;
active niche modification;
multi-agent coupling;
collective-level descriptions.
```

Therefore no SRT claim may rest merely on:

```text
feedback;
future orientation;
policy revision;
agent-environment co-shaping;
multiscale organization;
collective adaptation.
```

The unresolved SRT candidate is **typed separation**, especially the refusal to equate:

```text
shaping with standing;
standing with bearing;
bearing with control;
control with revision;
aggregate gain with all-position gain.
```

## 4. Required architecture test — Control C

### C1. Goal

Test whether one fixed five-relation mapping protocol transfers across two domains without changing relation semantics.

### C2. Domains

Use at least:

```text
D1 computational multi-agent allocation / coordination;
D2 human-AI or organizational scaffold decision system.
```

### C3. Frozen mapping protocol

Before D2 data are inspected, freeze for each relation:

```text
admission guard;
failure condition;
minimum evidence;
forbidden inference;
layer/type boundary.
```

No new relation may be added during transfer.

### C4. Rival comparison

Compare against:

```text
R-single: strongest coherent single-family model appropriate to both domains;
R-composite: domain-specific mature theories selected independently for D1 and D2.
```

R-composite is allowed to be stronger locally.

### C5. Glue accounting

Record every extra mapping assumption required to connect a domain observation to the theoretical relation.

Use a transparent, non-canonical bookkeeping table:

```text
number of domain-specific bridge assumptions;
number of relation-definition changes;
number of new latent variables introduced only after transfer;
number of exceptions / patched failure cases;
number of predictions/classifications preserved without modification.
```

Do not collapse these into a single scalar unless justified separately.

### C6. Deletion test

Run the same classification twice:

```text
FULL = Generation + Standing + Shaping + Bearing + Revision typing;
DELETED = domain variables preserved but relation-type separations removed / collapsed where the rival permits.
```

Measure whether deletion causes preregistered errors such as:

```text
institution/algorithm shaping -> falsely classified as subject/standing;
aggregate improvement -> lower-position degradation disappears;
policy adaptation -> falsely classified as generator revision;
option-count growth -> falsely classified as endogenous selectability growth.
```

### C7. SRT support condition

Architecture-level support requires all of:

```text
C-S1 frozen relation semantics transfer to D2;
C-S2 at least one preregistered classification error appears under deletion;
C-S3 the error is not removed by a strong rival without adding equivalent typed distinctions;
C-S4 SRT does not require more domain-specific exceptions than the rival composite;
C-S5 the result is structural, not normative preference disguised as ontology.
```

### C8. Demotion condition

Demote the five-relation tool toward synthesis/checklist if:

```text
C-F1 relation meanings must be rewritten across domains;
C-F2 rival single-family model already preserves all relevant distinctions natively;
C-F3 rival composite reproduces the same results with no additional glue beyond ordinary domain mapping;
C-F4 deletion of SRT typing causes no stable classification or prediction loss;
C-F5 the only remaining advantage is rhetorical coherence.
```
