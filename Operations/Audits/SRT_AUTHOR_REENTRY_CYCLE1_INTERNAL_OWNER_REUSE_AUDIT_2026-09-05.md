# Author Re-entry Cycle 1 — internal owner / experiment reuse audit

> **Purpose:** prevent Cycle 1 from claiming as newly earned a reset / writeback discriminator that the repository already paid for before the live author re-entry. This is internal owner subtraction, not a novelty permission gate.

---

## 0. Finding

The broad experimental contrast discovered in Cycle 1 is **not new to the repository**.

`SRT_NEURAL_UNITY_D2_DISCRIMINATOR_DESIGN_2026-08-28.md` already contains a finite-state architecture family with:

```text
V1  external logging only
V2  external controller / history conditions a fresh resettable core
V3  same-unit internal history writeback
V4  rollback of core + internal history while external record remains
```

and explicitly asks whether bearer verdicts change under manipulation of:

```text
location and directionality of consequence writeback
reset / replacement architecture
```

PH-IND05 already distinguishes:

```text
L2-grade historical efficacy
!= bearer-indexed history
```

PH-IND06 already uses:

```text
same-unit consequence return
+ history writeback
+ future-selectability change
+ non-outsourcing / reset pressure
```

AICONSC01 already proposes a reset/copy factorial.

Therefore Cycle 1 must **not** claim that it invented:

```text
external-history versus internal-history comparison;
same-unit history writeback;
rollback / replacement as bearer test;
current-state versus historical-identity discrimination.
```

This is a **reinterpretation / generative explanation of existing machinery**, not a new D2 architecture family.

## 3. Costly Selective Closure experiment — valuable but only partial reuse

The committed CSC experiment is stronger than a mere proposal. It has reproducible code, fixed results, and a common-state probe.

Its clean manipulation is:

```text
real-stake:
energy depletion terminates the token's reward-bearing run

resettable:
energy depletion cheaply restores the token to full energy
```

The common-state probe evaluates frozen policies on one shared bank of identical observation inputs and finds a large real-versus-resettable policy difference.

This establishes, inside that toy domain:

```text
different consequence / reset history
-> durable policy difference
-> difference visible on identical probe inputs
```

That is useful evidence that training history becomes realized in the learned policy.

However CSC does **not** already implement the full Cycle-1 `M-side versus One-side` factorial:

- `Env.reset()` clears episode state;
- no independent persistent multiplicity-side field trace is carried across episodes;
- both real and resettable policies learn internal weights;
- therefore CSC primarily demonstrates history-conditioned policy formation / irreversible-stake effects, not an independent causal localization of history between `多` and `一`.

Cycle 1 may reuse CSC's code style, seed discipline and common-state logic, but must not cite its current result as direct proof of the author ontology.

## 5. Decision

Use option **B** as the cheapest coherence test first:

> a tiny 2 x 2 agent / field model will preserve or reset external field-history and internal agent-history independently, producing a temporal signature for history location.

This toy model can establish logical / causal separability only.

It cannot by itself establish:

```text
SRT ontology is true;
Bearer identity is solved;
Level-2 scientific distinctiveness is earned;
neighbor theories cannot reproduce the result.
```

If the toy separation fails even in principle, the stronger Cycle-1 history-location architecture should be narrowed before any owner edit.
