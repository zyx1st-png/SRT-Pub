## 3. Source-neutral audit split

To avoid protecting SRT by vocabulary, distinguish two machine-side roles.

### R1 — parameter retuning inside a fixed differentiation field

A system pays `R1*` when history changes quantities such as:

```text
weights
thresholds
gains
attractor depth
choice bias
transition probability
```

while the operative dimensions, relation types, comparison structure and basic field of possible differentiation remain fixed.

This can strongly alter future behavior without reconstituting the field itself.

### R2 — reconstitution of the differentiation field

A system provisionally pays `R2*` when history changes the organization that determines which distinctions and relations are dynamically available for later vertical differentiation.

A source-neutral `R2*` candidate should involve at least one of:

```text
F1 DIFFERENTIABILITY CHANGE
   a previously unavailable distinction becomes dynamically available,
   or a previously available distinction ceases to function as an independent
   direction of later differentiation;

F2 RELATIONAL / COMPARISON REORGANIZATION
   the effective relation or comparison graph changes in kind or adjacency,
   not merely in scalar strength along an otherwise fixed graph;

F3 MANIFESTATION-BASIS CHANGE
   the dimensions / relations through which foreground-background generation
   can occur are reorganized, rather than only changing which old option wins;

F4 RECONSTITUTION CONSEQUENCE
   under a locked later probe, the system now generates a different class of
   possible competitive / manifest-background organizations because of the
   prior history.
```

`R2*` is audit notation only.

It is **not** a canonical definition of `前对象场`.
