# Canonical-independent reconstruction — Pass 6 adversarial pressure

> **Status:** noncanonical internal red-team against Passes 1–5.
>
> **Goal:** attack the current sparse reconstruction before any author adjudication or canonical reverse-map.

---

## 0. Red-team posture

The current reconstruction is attractive because it is simpler. That is not enough.

This pass asks whether the simplification:

```text
merely renames existing structure;
collapses important distinctions;
creates circular definitions;
imports generic autonomy/process language;
hides scale dependence;
or prematurely demotes L2.
```

No novelty claim is sought here.

---

# 1. Attack A — "two axes" may overstate independence

## Attack

Pass 5 visually separates:

```text
modal / actualisation axis
historical / sedimentation axis
```

But historical sedimentation reshapes later effective selectability, while Selection creates new history.

So they are not orthogonal in a strong mathematical sense.

Calling them `axes` may invite a false decomposition:

```text
actualisation dynamics
+
history dynamics
```

as if they could be independently specified and then simply added.

## Disposition

ACCEPT.

Replace strong orthogonality language with:

```text
TWO ANALYTIC ROLES / TWO COUPLED DIRECTIONS OF EXPLANATION
```

or, if `axis` is retained:

```text
analytically distinct but dynamically coupled axes
```

The reconstruction only needs the type distinction:

```text
what becomes manifest?
vs
how prior manifestations become later conditions?
```

It does not need formal independence.

# 2. Attack B — One-function may be generic process identity with no SRT-specific residue

## Attack

Strongest-neighbor work already grants substantial territory to:

```text
Simondonian ongoing individuation;
processual identity;
autopoiesis / organizational autonomy;
enactivist self-maintenance;
historical reconstitution;
adaptive feedback.
```

So:

```text
localized lineage-relative recurrent reconstitution
-> formed continuing organization
```

may have little or no scientific/theoretical distinctiveness by itself.

## Disposition

ACCEPT, but it does not remove the internal architectural need.

The current reconstruction should separate:

```text
ARCHITECTURAL NECESSITY WITHIN SRT
```

from:

```text
DISTINCTIVENESS AGAINST NEIGHBORS
```

Current result:

```text
formed-continuity / One-function
= likely necessary internal bridge between event and Stable ISP;

novelty / non-substitutability
= NOT ESTABLISHED.
```

Therefore One should not be promoted because it is "unique".
If later canonicalized, the reason would be role clarity inside SRT.

# 3. Attack C — Stable ISP + stake may classify ordinary autonomous systems as subjects

## Attack

Autonomy / enactivist neighbors already connect:

```text
self-maintenance
precariousness
viability
normativity
perspective-like organization
```

If `persistent endogenous stake coupling` is defined too loosely, then:

```text
thermostatic regulation;
metabolic control loops;
corporations;
markets;
distributed software services;
immune systems;
```

might all become structural subject-positions merely because their own states affect future viability.

## Disposition

PARTIALLY ACCEPT.

The proposed subject criterion therefore needs explicit **unit / boundary / scale / integration discipline**.

A candidate subject-position must first independently satisfy Stable ISP at the same declared unit and scale.

Then stake must close on that same unit:

```text
same declared continuing unit
+ persistent consequence return
+ non-outsourcing relative to that boundary
+ differential effect on that unit's future selectability
```

A corporation or collective system is not excluded in principle, but it must pay the higher-scale Stable-ISP gate rather than inheriting subjecthood from member subjects.

A thermostat-like loop may fail because it lacks the required structural perspective / integrated history / continued-selectability standing even if it has simple viability feedback.

Current strengthened criterion:

```text
structural subject-position candidate
=
Stable ISP at declared scale
+ persistent endogenous stake coupling closing on that same unit
```

Phenomenality still does not follow.

# 4. Attack D — stake coupling may be circular

## Attack

If:

```text
subject = what has stake;
stake = what matters to the subject;
```

then the new compression is circular.

Likewise:

```text
关切 = conditions relevant to continuity;
continuity = continuity of the subject;
```

would presuppose the subject it is meant to define.

## Disposition

REJECTED if the dependency order is preserved.

The reconstruction defines the unit first at a thinner level:

```text
formed-continuity / One-function
-> Stable ISP
```

without using subjecthood.

Only then is stake asked relative to that independently admitted continuing unit:

```text
which conditions / consequences recurrently alter
this already-identified unit's continuity / payability / future selectability
and cannot be fully externalized?
```

Therefore:

```text
unit identity precedes stake;
stake does not define the existence of the unit;
stake upgrades standing from Stable ISP to subject-position candidate.
```

No circularity is required.

# 5. Attack E — deriving direction from stake may collapse normativity into survivalism

## Attack

If subject-level direction is derived from:

```text
what preserves this unit's continuity/selectability
```

then SRT risks reducing:

```text
value
normativity
ethics
order
```

to self-maintenance or survival.

That would revive an old problem the repository has repeatedly tried to avoid.

## Disposition

ACCEPT as a guard.

The reconstruction must distinguish:

```text
LOCAL SUBJECT DIRECTION
= stake-relative ordering of continuations for this position;
```

from:

```text
GLOBAL / NORMATIVE RIGHTNESS
= separate downstream question.
```

Thus:

```text
stake-relative direction
!=> moral goodness
!=> global epsilon fulfillment
!=> order-gain theorem
!=> universal preference for self-preservation.
```

The subject may care about conditions beyond narrow self-maintenance.
`d-value` itself already allows the stake domain to include wider conditions.

Pass 5's compression is therefore local and structural, not a complete normativity theory.

# 6. Attack F — L2 demotion may erase a real emergent regime

## Attack

Even if historical sedimentation is not a third primitive peer domain, repeated scaffold formation can acquire:

```text
persistence;
inheritance;
relative autonomy;
constraint power;
shared re-entry;
robustness to individual turnover.
```

At that point treating it as "just a relation" may understate a real emergent regime.

The old L2 vocabulary may have been clumsy, but it may have captured something important:

```text
history becomes structure that behaves as an environment for later Selection.
```

## Disposition

ACCEPT.

This shifts the current preference away from outright L2 retirement.

Best current option:

```text
RETYPE L2
from:
third co-equal ontological domain / universal convergence realm

to:
emergent sedimented-constraint regime / layer
relative to a declared scale and boundary.
```

So:

```text
L2 is not primitive like the structural floor;
L2 is not merely one trace;
L2 names the regime in which accumulated history has become
re-enterable, inheritable, backgrounded constraint.
```

Shared / institutional L2 is then one scale-specific realization, not the definition of L2.

Current red-team preference:

```text
RETYPE > RETIRE
```

for the symbol and much of the mechanism corpus.

# 7. Attack G — objectivity may be weakened if convergence is removed from L2

## Attack

The older L2 convergence picture offered a compact story:

```text
multiple selectors converge
-> shared structure
-> objectivity.
```

If L2 is retyped as historical scaffold, does objectivity lose its anchor?

## Disposition

REJECTED as a necessity claim.

The current L0 objectivity definition is already stronger than consensus:

```text
cross-position
cross-interface
cross-perturbation robustness
+ not sufficiently explained by shared masking / shared constraint.
```

Therefore convergence is evidence / mechanism, not the definition of objectivity.

Retyping L2 actually improves the distinction:

```text
shared scaffold can cause convergence;
objectivity asks whether the result survives tests beyond the shared scaffold.
```

# 8. Attack H — One vs internal scaffold counterfactual test may be representation-dependent

## Attack

The Pass-5 test says:

```text
identity-constituting relation:
removal breaks same-lineage reconstitution;

scaffold:
removal changes transitions while identity survives.
```

But the answer depends on:

```text
which variables are grouped;
which perturbations are allowed;
which timescale is used;
which boundary is declared.
```

So the test is not representation-invariant by default.

## Disposition

ACCEPT.

The criterion must be explicitly scoped:

```text
for declared unit U,
scale s,
time window T,
perturbation family P,
identity criterion I,
```

ask whether X is constitutive or scaffold-like.

Therefore:

```text
constitutive vs scaffold
= role classification under a declared model / scale,
not yet a universal natural partition theorem.
```

This keeps the distinction useful without overclaiming.

# 9. Attack I — second-order Selection below Stable ISP may be too permissive

## Attack

A machine can rewrite comparison rules and carry that rewrite forward without:

```text
perspective;
stake;
subjecthood;
generative health.
```

If this counts as second-order Selection, the concept may become ordinary adaptive learning.

## Disposition

PARTIALLY ACCEPT.

The process pattern remains meaningful only if all four stronger conditions are retained:

```text
own-consequence return;
comparison-scale rewrite;
selectable-space change;
continued efficacy in later real Selection.
```

Ordinary parameter learning that changes outputs but does not revise the comparison / candidate-generation regime should not qualify.

Still:

```text
second-order Selection
!= Stable ISP
!= subjecthood
!= generative health.
```

The strongest-neighbor burden remains high.

```text

```
