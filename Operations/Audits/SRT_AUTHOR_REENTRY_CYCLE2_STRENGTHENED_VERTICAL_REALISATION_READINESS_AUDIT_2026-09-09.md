## 1. The three burdens must be separated

The 2026-09-07 author source already correctly separates three test shapes. Bowler and Todd make the separation stricter:

```text
G0 — internal anti-degeneracy / falsifiability
G1 — strongest-neighbor structural difference
G2 — implementation / mechanism realisation discrimination
```

They answer different questions and cannot substitute for one another.

### G0 — can the necessity claim be false?

The direct counterexample shape is:

```text
P ∧ ¬S
```

A persisting Selection-position forms without the claimed persisting foreground/background sedimentation.

If such a case exists under the author-licensed scope, the strengthened necessity claim is false or must be narrowed.

But:

```text
finding no P ∧ ¬S case
!= Level 1 earned
!= Level 2 earned
!= SRT mechanism identified
```

### G1 — does the strengthened dependency differ from a fair mature neighbor?

A Level-1-style comparison requires:

```text
named strongest neighbor
+ source-native claim
+ common problem
+ exact dependency / structural item changed by strengthened SRT
```

The older `participates in forming` Level-1 result does not pay this burden because the strengthened claim changes the link to **structural necessity**.

### G2 — does an implementation realise the SRT mapping rather than a bounded rival?

Todd adds the stronger mechanism burden:

```text
candidate mapping
+ independently nominated realiser
+ bounded rival mapping
+ held-out intervention
+ prospectively divergent causal signature
```

This is not the same as finding a necessity counterexample or a conceptual neighbor difference.

## 2. G0 status — anti-degeneracy is still unpaid

```text
  that persistence as "has S".
```

This does not reject the author claim. It identifies the first burden created by changing `participates in forming` to `structurally necessary`.

## 3. Bowler pressure — weak strengthened-V readings are already absorbed

NEURAL36 shows that ordinary recurrent learning dynamics can already realise:

```text
structured history
-> persistent recurrent organisation
-> higher-order eigenspectrum / attractor scaffold
-> changed future transition geometry
-> later strategy / generalisation differences
```

and that local nearby excitation / more-distant inhibition is not sufficient to distinguish successful shaping.

Therefore strengthened V cannot earn a structural increment by any of the following alone:

```text
history leaves a persistent structure;
local support + inhibition co-occur;
current structure mediates history's later effects;
low-dimensional / attractor organisation appears;
latent context gates later response;
history changes future accessibility.
```

Bowler also supplies a particularly important negative result for provenance:

```text
H -> present structure S_now -> future behaviour
```

can be causally mediated by current organisation, and part of the current dynamical scaffold can be imposed without recreating the original history while still biasing later strategy.

Hence:

```text
historical origin of S
!= independently indispensable provenance
```

A strengthened Cycle-2 test cannot rely on "this structure came from that history" if the relevant present organisation fully carries the later causal role.

## 5. Todd pressure — description / topology / attractor language does not identify the SRT mechanism

Todd's realisation criterion changes the burden for any future Level-2 or mechanism-level reading.

It is not enough to show:

```text
SRT language fits the trajectory;
foreground/background labels can be assigned to a recurrent network;
removing a component degrades performance;
history groups differ later;
SRT predicts the same qualitative outcome as the implementation.
```

A future mechanism claim must prospectively lock:

```text
M_SRT = strengthened-V causal mapping
R_SRT = independently specified realiser of the sedimented
        foreground/background relation

M_R   = bounded mature rival mapping
R_R   = rival realiser / organisation

I*    = held-out intervention not used to fit, choose or repair either mapping

D*    = causal signature on which M_SRT and M_R predict different outcomes
```

If

```text
P(Y | do(I*), M_SRT)
≈
P(Y | do(I*), M_R)
```

within the declared margin, the strengthened V relation has not earned mechanism-level irreducibility for that target.

## 6. The central realisation problem exposed by Bowler + Todd

The deepest current issue is not merely "which intervention should we run?" It is whether `S` has an independently identifiable causal realiser at all.

Suppose the proposed `S` realiser is simply:

```text
recurrent weight topology
or
attractor geometry
or
latent-state gating
or
eigenspectrum structure
```

Then Bowler has already shown that ordinary recurrent dynamics can carry exactly this kind of history-shaped future efficacy.

If the SRT reply is:

```text
that same topology / attractor IS the sedimented foreground/background asymmetry
```

then a Todd-style problem appears:

```text
SRT mapping
and
rival recurrent mapping
may be two descriptions of the same physical organisation.
```

In that case there is no independently specified `R_SRT` to perturb while holding the rival organisation fixed. The mechanism claim has not yet been identified; it has been redescribed.

This creates a strict anti-relabeling requirement:

> **Before a Level-2 intervention can be designed, the strengthened V relation must identify a causal role / state partition whose intervention signature is not exhausted by the rival's ordinary recurrent / transductive organisation.**

If no such role can be specified, the strengthened claim may remain an author-owned ontological dependency thesis, but it cannot currently be promoted as an empirically distinguishable mechanism.

## 7. Why a simple "erase history but preserve present state" test is not enough

A tempting design would be:

```text
match present state / performance
erase or swap history
observe later persistence
```

Bowler makes this insufficient as a default Level-2 route because historical efficacy can be mediated by present organisation.

If the complete causal structure relevant to future behaviour is preserved, changing provenance alone need not change the outcome.

Conversely, if "erasing history" changes the current recurrent organisation, the intervention no longer isolates history from mechanism.

Therefore:

```text
history swap alone
!= strengthened-V mechanism test
```

unless the audit first states which current causal relation is supposed to retain history and how the competing mappings differ under the same manipulation.

