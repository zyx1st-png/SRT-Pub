# GRG-R1 cross-realization / source-fidelity audit — Pass 1

## 0. Trigger

The programme now has two target-blind results that must be held together:

~~~text
O1 spectral formation = PASS
history class -> reproducible current recurrent spectral imprint

O3 one-time spectral causal mediation = NULL
history-associated spectral scaffold -> one-time transplant
-> no preregistered improvement in later source-domain learning
~~~

Therefore the old phrase retained organization re-entry is too compressed if it allows a detectable retained marker, a maintained dynamical scaffold, a causal mediator and a prospective transfer relation to be treated as one burden.

## 1. Cross-realization comparison

### 1.1 Toy RNN evidence

The toy system establishes:

~~~text
retained history marker != causal mediator by default
~~~

Structured and Direct histories leave a highly reproducible recurrent eigenspectrum difference, but the frozen one-time S-history spectral transplant does not outperform D-history spectral transplant or intact naive recipients under the O3 primary criterion.

Therefore the history-associated spectrum is a valid marker of prior organization in this system, but it is not admitted as GRG-R1 causal O under the tested realization.

### 1.2 Bowler source-native causal pattern

Bowler et al. support:

~~~text
structured experience
-> recurrent operator / eigenspectrum organization
-> characteristic dynamical regime
-> altered later learning strategy
~~~

The public source code adds an important fidelity detail. The source-native seed_weights_run.py does not merely transplant shaping-associated eigenvalues once. It seeds leading shaping-associated eigenvalues, trains an early block, re-imposes the scaffold, trains another block, re-imposes again, and only later allows training to proceed without repeated reset.

This means the strongest causal object in that workflow may be better described as a maintained / repeatedly stabilized spectral regime during early learning, not as a static spectral signature by itself.

The source also links this operator organization to low-dimensional trajectories, fixed/slow points and switching dynamical motifs.

Therefore raw eigenvalue marker != maintained dynamical scaffold must remain open rather than silently equated.

### 1.3 Simondon pressure

The Simondon full close-read contributes:

~~~text
operation -> formed structure -> structure becomes a condition of later operation
~~~

A structure that merely records prior operation but does not enter later operation does not pay the full operation-structure recurrence burden.

Thus Simondon pressures GRG-R1 toward causal / generative re-entry, not mere historical detectability.

### 1.4 Synergetics pressure

The current GRG programme uses synergetics as a distributed source-family pressure through order parameters, slaving and circular macro-micro organization.

The relevant lesson is methodological:

~~~text
low-dimensional descriptor != order parameter automatically
~~~

An order parameter earns its role through its dynamical relation to component evolution. Therefore PCA axes, decoder dimensions and spectral labels cannot inherit order-parameter standing merely because they compress the system.

Repository source depth for synergetics is still weaker than for Bowler and Simondon, so no stronger source-specific claim is frozen here.

## 2. Verdict: GRG-R1 is over-compressed at research level

~~~text
VERDICT = SPLIT THE RESEARCH BURDEN
~~~

Do not change canonical ontology and do not create four new ontology modules. For GRG programme work only, separate four burdens that the original GRG-R1 wording had partially conflated.

### R1a — retained imprint

Question:

~~~text
Does prior operation / history leave a reproducibly identifiable current difference?
~~~

Examples include recurrent spectral signature, persistent parameter difference, or history-decodable structural trace.

Burden:

~~~text
formation + retention
~~~

Not sufficient for causal re-entry.

### R1b — maintained scaffold

Question:

~~~text
Is the retained organization dynamically present / maintained during the later process in which it is claimed to matter?
~~~

Possible realizations include stabilized recurrent regime, sustained / recurrent order parameter, attractor / transition scaffold, or maintained coupling structure.

Burden:

~~~text
retention + dynamical participation
~~~

A one-time marker that becomes irrelevant can pass R1a and fail R1b.

### R1c — causal re-entry

Question:

~~~text
Does independent intervention on the maintained organization
change later transition / accessibility / coordination conditions?
~~~

This is the minimum causal core closest to the original phrase retained-organization re-entry.

Burden:

~~~text
formation -> maintained organization -> intervention-sensitive later process
~~~

R1c cannot be inferred from R1a.

### R1d — prospective transfer / re-use

Question:

~~~text
Does an already-admitted R1c organization constrain a genuinely new,
predeclared later context without being selected or defined from that target?
~~~

This is a stronger transfer burden. It is not part of the minimum causal definition of R1c. O4 belongs here.

## 3. Revised GRG-R1 research core

The programme should now read:

~~~text
R1a retained imprint = diagnostic / insufficient
R1b maintained scaffold = candidate generative organization
R1c causal re-entry = minimum GRG-R1 causal core
R1d prospective transfer = stronger downstream transfer burden
~~~

Compactly:

~~~text
prior operation
-> identifiable imprint
-> maintained organization
-> causal re-entry
-> optional prospective reuse / transfer
~~~

The arrows are research-burden dependencies, not claims that every real system must contain four separable objects.

## 4. What the two toy results now mean

v0.1 decoder O:

~~~text
information-bearing / decodable activity structure failed causal withdrawal.
Disposition: R1a-like informational marker at best; not R1c.
~~~

spectral O1/O3 family:

~~~text
history-associated recurrent spectral imprint = R1a PASS
maintained scaffold = not established by the one-time transplant protocol
causal re-entry = O3 NULL under one-time transplant
prospective transfer = not authorized
~~~

This prevents O1-SPECTRAL-PASS from carrying more weight than it earned.

## 5. Bowler source-fidelity revision

Do not summarize Bowler as eigenvalues cause strategy without qualification.

Safer source-fidelity reading:

~~~text
structured history
-> recurrent operator differences
-> shaping-associated spectral scaffold can be experimentally imposed
   and repeatedly maintained during early learning
-> later learning is biased toward the shaped regime
-> shaped networks also exhibit distinct low-dimensional / attractor-like dynamics
~~~

Open causal-object question:

~~~text
raw eigenvalue values?
maintained spectral regime?
eigenvector/eigenspace embedding?
fixed-point / limit-cycle organization?
joint operator + activity dynamics?
~~~

The current repository does not need to answer that by definition.

## 6. Consequence for GRG transfer method

Future GRG extraction must explicitly state which R1 burden is being claimed.

Forbidden shortcut:

~~~text
source shows a persistent marker
-> call it retained organization
-> infer causal re-entry
-> infer transfer
~~~

Required route:

~~~text
R1a evidence != R1b evidence != R1c evidence != R1d evidence
~~~

A source may pay several burdens at once, but each must be evidenced.

## 7. Is GRG-R1 itself defeated?

No. The strongest current update is narrower:

~~~text
GRG-R1 as a causal generative relation survives,
but its old wording was too permissive about what counts as retained organization.
~~~

The toy nulls are productive because they force the programme to exclude mere decodability and mere history markers.

If repeated work shows that R1c always reduces to domain-specific mechanisms with no transferable research constraint, GRG-R1 should later be retired as a cross-domain grammar candidate. That failure condition remains live.

## 8. Immediate programme recommendation

Do not run another toy RNN variant yet.

Next source work should answer two questions before any experiment:

1. In Bowler, what minimal causal object is actually manipulated across the full early-training intervention: eigenvalue values, a maintained spectral regime, or broader dynamical organization?
2. In one mature self-organization source, what makes an order parameter causal / slaving rather than merely descriptive?

Only after those two source-fidelity questions are paid should a new R1b/R1c realization be selected.
