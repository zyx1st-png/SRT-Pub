# One reconstitution graph scaffold — machine pressure only

## 1. Purpose

The current workline needs to distinguish:

```text
many local vertical centers in one global pattern
```

from:

```text
multiple continuing One-lineages.
```

A spatial partition, stable component list or numerical-identity token would beg the question.

This file therefore introduces a machine-side relational scaffold only.

## 2. Nodes are not pre-given Ones

At each time `t`, suppose analysis identifies local vertical organizations:

```text
v_i(t)
```

A node means only:

> a local non-flat organization participating in Selection at that time / grain.

It does **not** mean:

```text
v_i(t) is already a One;
v_i(t) is a Bearer;
v_i(t) is a subject;
v_i(t) has strict token identity.
```

## 3. Reconstitution edge

Define only for audit reasoning:

```text
R[v_i(t) -> v_j(t+1)]
```

when the prior organization `v_i(t)` materially participates in Selection-mediated regeneration / transformation of `v_j(t+1)`.

This must be stronger than:

```text
similarity;
occupying the same location;
playing the same functional role;
sharing a common external template;
generic causal influence.
```

It expresses the current lineage relation under pressure.

## 4. One-lineage as a path, not a static node

A minimal machine picture:

```text
v_a(t0)
   ↓ R
v_b(t1)
   ↓ R
v_c(t2)
   ↓ R
...
```

The candidate One is not any node by itself.

It is the continuing local vertical process-unit carried by the actual reconstitution path.

This preserves:

```text
snapshot change: allowed;
component replacement: allowed;
position movement: allowed;
major transformation: allowed.
```

## 5. Center multiplicity versus One multiplicity

### One global pattern with many centers

```text
F_t contains peaks A, B, C
```

but later regeneration is governed only at whole-pattern level:

```text
Pattern_t -> Pattern_(t+1)
```

while peak identity is interchangeable / re-spaced / regenerated without separate lineage-sensitive R edges.

Then:

```text
center multiplicity: YES
multiple One-lineages: NOT ESTABLISHED.
```

### Multiple lineage candidates

If instead:

```text
A_t -> A_(t+1)
B_t -> B_(t+1)
```

through distinct lineage-sensitive reconstitution relations, then multiple-One pressure is stronger even if A and B remain coupled through the wider field.

## 6. Non-lockstep is a useful pressure, not a full criterion

A practical probe is whether candidate paths can diverge:

```text
A transforms / dissolves / branches
while
B continues differently.
```

If no admissible history can make their continuation relations diverge because every change is only a global-pattern change, then A/B may be parts / phases / roles of one larger lineage.

But:

```text
non-lockstep continuation
!= sufficient theorem of One identity.
```

It is only a source-neutral pressure against hidden global-unity assumptions.

## 7. Branching

The scaffold permits:

```text
        v_a(t)
        /    \
       R      R
      /        \
v_b(t+1)     v_c(t+1)
```

Meaning:

```text
one predecessor organization materially participates in two later lineage branches.
```

Do not force one branch to be the unique same One.

This preserves the existing rule:

```text
continuation relation
!= strict numerical identity.
```

## 8. Merging

The scaffold also permits:

```text
v_a(t)      v_b(t)
   \          /
    R        R
      \      /
      v_c(t+1)
```

Possible readings remain open:

```text
merger into a new higher-order One;
termination of two prior lineages plus new lineage;
continuation of both into one successor in a non-numerical sense;
other domain-specific interpretation.
```

The scaffold does not solve this metaphysics.

Its purpose is to keep merger visible instead of hiding it behind a static boundary.

## 9. Nested lineages

A local One candidate can itself participate in a higher-order vertical lineage:

```text
A_t -> A_(t+1)
B_t -> B_(t+1)

while

R_AB(t) -> R_AB(t+1)
```

Thus:

```text
lower-level One continuation
and
higher-order relation-level One continuation
```

can coexist.

No scale automatically cancels the other.

## 10. Bearer adds a different edge family

Do not encode Bearer by R alone.

A stronger machine relation would be something like:

```text
Q[Selection consequence at t -> organization that bears it]
```

plus:

```text
Q-bearing consequence
-> materially alters the later R reconstitution of the relevant position.
```

Therefore:

```text
R-path
= One / continuation pressure

Q-to-R coupling
= Bearer / return-reconstitution pressure.
```

No new canonical symbols are proposed; `R` and `Q` are local audit labels only.

## 11. Multiplicity result

The graph view suggests a cleaner statement:

> **Multiple Ones do not require a pre-given plurality of bounded entities. They require the Selection-reconstituted field to sustain more than one contemporaneous lineage-sensitive reconstitution path.**

This does not define what creates those paths; it only states the multiplicity burden without pre-objectifying the answer.

## 12. Relation to `多`

The author's pre-Bearer statement can now be represented without turning `多` into a set of completed Ones:

```text
before stable One / Bearer admission:
historical changes are distributed in the wider field / 多;

within that field:
local vertical episodes occur;

some episodes acquire repeated R-relations;

more than one R-path can emerge;

only later can own-history / consequence closure strengthen a path toward Bearer.
```

Thus:

```text
多
!= list of pre-given Ones
```

but can still generate multiple Ones.

## 13. What would falsify the multiple-One reading in a concrete case

For a proposed pair A/B, pressure the following:

```text
1. Are A and B only labels for two current peaks / roles?
2. Does prior A specifically participate in later A-like reconstitution beyond whole-pattern regeneration?
3. Same for B?
4. Can their continuation paths diverge under an admissible perturbation / history?
5. If one disappears and another fills the same role, is that role continuation or lineage continuation?
6. Are apparent A/B paths actually generated by a single higher-order path with interchangeable internal positions?
```

Failure at 2/3 strongly weakens One-lineage interpretation.

Failure at 4 pressures multiplicity but is not by itself decisive.
