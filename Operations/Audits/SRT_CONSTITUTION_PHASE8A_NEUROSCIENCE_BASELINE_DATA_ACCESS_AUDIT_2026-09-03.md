# Phase 8A neuroscience strongest-baseline and data-access audit

## Matched present neural state / different relational history

> **Result**: Phase 8A is complete。The strongest-baseline verdict is **Case B**；SRT currently improves routing and experimental discipline but has not yet established a new domain-content increment。For the exact Phase-8 charter，`DATA-ACCESS-0 = NO-GO` because no accessible dataset or authorized collaborator route satisfies the required relation-history，PRE-relation and rich current-state variables together。
>
> **Consequence**: Phase 8B，protocol lock，preregistration and confirmatory execution are not authorized。This is an adverse but valid deep-well result，not a request to weaken the question after seeing the evidence landscape。

---

## 0. Audit question and decision contract

This audit separates two gates：

1. **increment gate** — does SRT add a bounded domain distinction beyond the strongest ordinary neuroscience baseline？
2. **access gate** — is there an exact，ethically usable dataset or collaborator route for the chartered test？

The governance verdicts are applied literally：

```text
Case A: baseline already provides the gain -> stop the SRT increment claim
Case B: SRT improves routing / reframing but not content -> translation or process contribution only
Case C: SRT yields a new bounded distinction / question with domain consequences -> proceed to test
```

The access gate is independent。A public dataset that supports an adjacent question does not satisfy the exact charter merely because it is convenient。

Evidence was checked against the repository packet and current primary-source / repository records on 2026-09-03。Search discovery alone is not treated as data access。

---

## 1. Exact target that must survive

The charter asks whether a preregistered relation-history term `H` adds subject/session-aware held-out prediction of future **relation identity** after rich controls：

```text
Base:
R_future ~ X + E + C + G + PRE_relation + anatomy + tau

History:
R_future ~ X + E + C + G + PRE_relation + anatomy + tau + H
```

An exact dataset therefore needs，within one declared timescale and system：

| Requirement | Minimum usable content |
|---|---|
| bearer / system | human participant under clinically indicated intracranial monitoring |
| relation object | identifiable cell，ensemble or regional pair whose future relation can be scored |
| PRE relation | pre-history coupling or compatibility for the same relation candidates |
| history contrast | controlled `H+ / H-` joint，relation-specific，consequence-bearing history |
| component controls | current / recent activity，component exposure or excitability，cue / item identity |
| common-driver controls | phase，power，regional event rate，arousal or declared available proxies |
| common future opportunity | the same probe，retrieval or coordination opportunity for competing relations |
| outcome | relation identity / probability，not generic activation，power or task accuracy alone |
| evaluation | participant/session-aware held-out comparison without pair-count pseudo-replication |

Failure to supply PRE relation or a relation-specific history contrast changes the question rather than merely reducing power。

## 2. Strongest ordinary-neuroscience baseline

### 2.1 What the baseline already owns

The verified primary packet already establishes a broad ordinary-neuroscience family：

| Baseline family | Primary pressure | What it already explains |
|---|---|---|
| experience-specific replay | Ji & Wilson 2007，DOI `10.1038/nn1825` | experience can alter later coordinated replay across hippocampus and cortex |
| preconfiguration plus learned inter-regional coactivation | Miyawaki & Mizuseki 2022，DOI `10.1038/s41467-022-28929-x` | local ensembles can pre-exist while cross-region coactivation develops after conditioning |
| memory-age / experience reorganization | Abbaspoor et al. 2026，DOI `10.1038/s41593-026-02357-2` | content-specific assembly interactions can reorganize and stabilize with experience |
| activity-silent / connection-structure accounts | Panichello et al. 2024，DOI `10.1038/s41586-024-08139-9`；Barbosa et al. 2020，DOI `10.1038/s41593-020-0644-4` | current mean firing need not exhaust a latent memory-bearing neural state |
| selection-history probe | Duncan et al. 2023，DOI `10.1038/s41467-023-40405-8` | a common neutral ping can expose a history-conditioned priority state |
| metaplasticity / hidden component state | Hamada et al. 2009，DOI `10.1113/jphysiol.2009.179101` | prior activity can change a later plastic response despite no change in the protocol's measured baseline output |
| human associative coactivity | [Kunz et al. 2024](https://www.nature.com/articles/s41593-023-01550-x) | object- and place-specific cells coactivate around hippocampal ripples as object-location learning develops |

Together these sources already own the generic result：

```text
history can change later neural coordination，reactivation or response
even when the history is not continuously explicit in mean firing
```

Therefore `history matters`，`relations change with learning`，`current firing is incomplete` and `a neutral probe can reveal latent history` are not SRT-specific increments。

### 2.2 Strongest baseline model classes

Before any later reopening，the ordinary comparison must include at least：

```text
component exposure and excitability history
synaptic / engram plasticity
latent-state and population-dynamical state
replay / reinstatement / systems consolidation
metaplasticity
fixed anatomy and electrode coverage
oscillatory opportunity windows and common drivers
relational-memory / conjunctive representation
rich predictive history models
```

These are explanations，not straw baselines。A history coefficient surviving current mean firing alone would not distinguish the charter from them。

### 2.3 Increment verdict

```text
strongest-baseline verdict = Case B
```

The surviving contribution is procedural and translational：the Constitution forces the study to declare the bearer，cut，objectification，consequence attribution，PRE relation，relation identity and failure rules together。That discipline exposes why many apparently supportive studies test only generic history dependence or a hidden component state。

What is **not yet established** is a Case-C content distinction with an accessible empirical contrast that ordinary relational-memory，latent-state，engram or metaplasticity models do not already own。

This verdict does not say that Case C is impossible。It says the present audit cannot claim it before a sharper baseline differential and an executable object exist。

## 3. Candidate-data audit

### 3.1 Closest paradigm: Kunz et al. 2024

[Kunz et al. 2024](https://www.nature.com/articles/s41593-023-01550-x) recorded intracranial EEG in 30 participants and additional single-neuron activity in 20 participants during repeated object-location learning and retrieval。The task contains identifiable object/place relations，behavioral improvement and ripple-locked pair coactivity；it is the closest located paradigm to the charter。

However，the source's data-availability statement says that figure-recreation data and code are public while raw participant data require a reasonable request，a data agreement and privacy conditions。No granted access or collaborator authorization is recorded in this repository。

It also does not supply the charter's predeclared `H+ / H-` manipulation with exposure-matched alternative relations。Early/late or before/after-memory-formation contrasts are scientifically valuable，but they do not by themselves isolate relation-specific history from learning stage and component-history change。

```text
paradigm fit = high
current raw-data access = not granted
exact H contrast = incomplete
verdict = candidate collaborator route，not executable access
```

### 3.2 Public candidate matrix

| Candidate | Publicly evidenced contents | Useful for | Exact blocker | Verdict |
|---|---|---|---|---|
| [Kyzar et al. 2024 / DANDI 000469](https://www.nature.com/articles/s41597-024-02943-8) | 1,809 human MTL/MFC neurons across 41 sessions / 21 participants；screening plus Sternberg working memory；spikes，waveforms，stimuli，behavior，electrode locations and demographics in NWB；DANDI DOI `10.48324/dandi.000469/0.231213.2047` | single-unit pipeline，content-selective cells，current-state and probe controls | no learned relation-specific `H+ / H-`；no PRE relation for the same candidate pair；task tests item maintenance / membership | feasibility / negative-control benchmark only |
| [Cimbalnik et al. 2022](https://www.nature.com/articles/s41597-021-01099-z) | human sEEG，behavior，gaze and pupil signals from ten participants；four memory tasks include paired-associate learning；BIDS / EBRAINS record | pair-task event parsing，macro-relation measures，arousal and gaze controls | no single-unit identity；no pre-learning pair coupling；word pairs do not provide the required exposure-matched competing relation histories | adjacent feasibility dataset only |
| [Chandravadia et al. 2020](https://www.nature.com/articles/s41597-020-0415-9) | 1,863 human MTL neurons from 59 participants；NWB spikes，stimuli and behavior；public code | NWB processing，item-history baselines，old/new recognition | item repetition is not relation-specific history；no PRE pair relation or common future pair opportunity | negative-control / tooling only |
| [Faraut et al. 2018](https://www.nature.com/articles/sdata201810) | 1,576 human amygdala / hippocampal neurons，65 sessions / 42 participants；new/old image recognition，behavior and waveforms | item novelty / familiarity baselines | no pair identity，PRE pair relation or controlled joint history | negative-control only |

The public datasets are valuable，but combining their strengths across different participants and tasks would not manufacture the missing within-system contrast。

### 3.3 License，ethics and access boundary

- the public data descriptors are open-access publications；their dataset repositories and individual records remain the controlling source for data licenses and access terms；
- DANDI supports CC-BY-4.0 or CC0-1.0 records，but the exact dandiset metadata must be captured in an execution manifest rather than inferred from platform policy；
- Cimbalnik et al. report local IRB approval and informed consent；reuse remains subject to the EBRAINS record and any repository conditions；
- Kunz raw data are not public and require agreement-based access；publication of summary / figure data does not authorize reanalysis of the raw recordings；
- clinical electrode coverage is not randomized by the study and must remain a fixed-anatomy / missingness constraint。

No download or participant-level inspection was performed in this audit because no candidate passed the design-variable gate。

## 4. Access verdict

No located candidate supplies all of：

```text
human intracranial single-unit + LFP
PRE relation for the same candidates
controlled exposure-matched H+ / H- relation history
common future probe / retrieval opportunity
rich present component and common-driver controls
participant/session-aware relation-identity outcome
current public access or granted collaborator authorization
```

Therefore：

```text
DATA-ACCESS-0 = NO-GO for the exact charter
Phase 8B = not authorized
Phase 8C protocol lock / preregistration = prohibited
Phase 8D confirmatory execution = prohibited
```

This is not a claim that no qualifying data exist anywhere。It is the bounded result of the repository and primary data-source audit as of 2026-09-03。
