### 2.1 Same-event compression

Land:

```text

```

as constitutive readings of one primitive Selection event, not three successive events.

This does not delete downstream selectable-space effects. It removes only the false temporal / ontological ladder among the three readings.

### 2.2 Finite positionality

Land as an existing K constraint on primitive Selection:

```text

```

Do not create a universal `Position` node from this.

Keep distinct:

```text
L0 finite positionality
!= formed Selection-position
!= post-One relational Position
!= subject-position.
```

### 2.3 Regenerative recurrence

At cross-owner level, use **role recurrence**, not token identity:

```text
organization_t
-> conditions later Selection_(t+1)
-> Selection_(t+1) generates organization_(t+1)
-> organization_(t+1) can again carry the relevant conditioning role.
```

Do not infer:

```text

same spatial position;
strict lineage identity;
organizational closure;
autopoiesis;
formal N&S One criterion.
```

The existing local One owner remains the current detailed semantic owner until its later bounded landing. Any tension between its `lineage-relative` wording and the new cross-owner routing is explicit cleanup debt, not silently harmonized here.

### 2.4 Universal formation stop

Land:

```text
universal formation route terminates at One / Selection-position.
```

This means Bearer is not the next universal existence stage. It does **not** delete the current P+E Bearer route.

### 2.5 Selection under formed constraints

Land a thin no-second-primitive crosswalk in prose:

> Selection occurring under the constraints of a formed One / Selection-position remains the same primitive kind of Selection; this spine introduces no second universal operation.

Do **not** introduce `Selection_O` as a new formal symbol in this PR.

### 2.6 Bearer / Concern non-nesting

Preserve the exact current typed Bearer routing:

```text
formed One / Selection-position + P + E -> Bearer.
```

Keep P and E semantics unchanged.

Remove any visual or inferential suggestion that:

```text
Bearer => Concern universally;
Concern => Bearer universally;
Bearer -> Concern -> Agency is a universal ladder.
```

Both directions remain OPEN unless separately established.
