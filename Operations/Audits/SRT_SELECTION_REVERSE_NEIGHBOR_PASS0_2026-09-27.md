# Reverse-neighbor Pass R0 — first derivability / Facing-diagnostic matrix

> **Role:** first bounded reverse-pressure audit after the 2026-09-27 author direction.
>
> **Question:** can SRT reconstruct each of the existing seven Pass-B neighbors as a bounded special case under explicit added assumptions, and does Facing discipline provide genuine diagnostic surplus rather than retrospective relabeling?
>
> **Verdict strength:** preliminary. D3 is assigned only where the pressure point is independently documented strongly enough for this pass. No D4 claim is made.

## 0. Scale

~~~text
D0 = REDESCRIPTION
D1 = TYPED EMBEDDING
D2 = DERIVATIONAL RECONSTRUCTION
D3 = DIAGNOSTIC SURPLUS
D4 = PROSPECTIVE LEVERAGE
~~~

A D2/D3 result is not a superiority verdict.

## 1. Whitehead — D2 strong / D3 candidate, not yet landed

### Reconstruction

A Whitehead-like local architecture can be reconstructed by adding strong assumptions to the SRT kernel:

~~~text
primitive actualising generativity
+ prior actuality enters later becoming
+ each becoming forms an event-like unity
+ event-unity is experiential / feeling-like
+ subjective form includes valuation / self-determination
+ pure potentials / eternal objects are available
-> Whiteheadian actual occasion / concrescence family.
~~~

The first three burdens overlap strongly with current SRT routing. The experiential, valuation/final-causal and eternal-object commitments are not derived by SRT and must remain visible additions.

### Facing pressure

Candidate diagnosis:

~~~text
actual occasion
appears to combine in one primitive unit:
- actualisation;
- formed unity;
- historical uptake;
- experiential character;
- valuation / final-causal self-determination.
~~~

SRT separates these burdens more aggressively.

Independent pressure exists around at least two points:

1. Whitehead's actual occasions are atomically event-like while continuity is achieved rather than simply given; the relation between atomic occasions and continuity is an explicit interpretive difficulty in secondary literature.
2. Whitehead's ontology generalizes experiential / feeling language to all actual occasions, producing the well-known panexperientialist commitment.

These support a D3 **candidate**, but this pass does not yet show that the problems are caused specifically by Facing mixture.

### External anchors

- Stanford Encyclopedia of Philosophy, “Alfred North Whitehead”.
- Internet Encyclopedia of Philosophy, “Whitehead”.
- Existing repository: Cycle-3 / FRR Whitehead close reading.

### Disposition

~~~text
D2 = PASS
D3 = CANDIDATE / needs tighter causal diagnosis
D4 = NO
~~~

## 2. Barad — D1 strong / D2 partial / D3 not established

### Reconstruction

A bounded agential-cut-like structure can be embedded as:

~~~text
non-pregiven relata
+ constitutive current cut
+ manifestation / relative backgrounding
+ formed apparatus / practice stabilizing what counts as object / agency
-> local agential-cut-like configuration.
~~~

This reconstructs much of the object-boundary burden already judged SOURCE_ABSORBED in Pass B.

But Barad's full ethico-onto-epistemological package, agency language and material-discursive commitments are not derivable from current SRT without importing most of the theory.

### Facing pressure

Useful question:

~~~text
what is:
- primitive non-preclosure,
- current determination,
- retained apparatus / practice,
- ethical / epistemic consequence?
~~~

This is a real typing benefit.

However this pass does **not** yet have strong enough source-native evidence that Barad's recognized problems are specifically produced by failure to separate these facings.

### Disposition

~~~text
D1 = PASS
D2 = PARTIAL
D3 = NOT ESTABLISHED
D4 = NO
~~~

This is an important negative result: broad compatibility is not enough to claim depth.

## 3. Simondon — D2 strong / D3 candidate

### Reconstruction

Simondonian transduction is a natural strong-case generativity example:

~~~text
non-preclosed generative situation
+ domain-specific metastable tensions / potentials
+ local operation
+ operation produces new structure
+ new structure alters conditions for later operation
-> transductive restructuring.
~~~

This maps closely onto the repository's existing S3 working distinction:

~~~text
operation
-> new structure
-> changed local conditions / boundary / admissible relations
-> propagated restructuring.
~~~

### Facing pressure

The important separation is:

~~~text
preindividual
!= primitive O0 automatically;

metastable potential structure
may already be a domain / formed geometry;

transduction
= powerful model of G-A2 / G-A3 generative transformation,
not primitive Selection definition.
~~~

SRT therefore can use Simondon as a strong-case route toward subtraction without making the preindividual field itself primitive.

### Disposition

~~~text
D2 = PASS
D3 = CANDIDATE
D4 = NO
~~~

The candidate D3 burden is whether a single “preindividual” vocabulary carries both primitive non-preclosure and already structured metastable conditions. Source-native verification remains required before hardening this as a criticism.

## 4. Husserl — D2 domain-limited / NO D3

### Reconstruction

Sedimentation/reactivation is cleanly reconstructible at a formed meaning-history level:

~~~text
prior formation
-> retained / sedimented effective structure
-> present meaning / objectification
-> reactivation of genesis
-> revised / renewed access.
~~~

This is almost a paradigm case of L2-to-L1 reconstruction.

### Facing result

The important result is **not a criticism**.

Husserlian sedimentation/reactivation is already operating in an intentional / meaning-bearing domain. Facing simply blocks a bad SRT inference:

~~~text
excellent L2-to-L1 reconstruction
!= primitive generativity account.
~~~

No diagnostic surplus is established because the neighbor is already correctly scoped for its own project.

### Disposition

~~~text
D2 = PASS / DOMAIN-LIMITED
D3 = NO GAIN
D4 = NO
~~~

This is a healthy reverse-test result.

## 5. Organizational closure / function — D2 strong / D3 strong candidate

### Reconstruction

A closure-of-constraints special case can be reconstructed as:

~~~text
formed recurrent organization
+ constraints that modulate processes
+ constraints mutually depend on and maintain one another
+ a component's role contributes to maintenance of that closure
-> organizational function / intrinsic purposive role.
~~~

This strongly supports the repository's formed-level constitutive “为了” while leaving primitive Selection non-teleological.

### Facing pressure

Facing v0.2 requires declared:

~~~text
unit;
boundary;
grain;
equivalence;
timescale;
retained structure.
~~~

This directly meets a documented criticism of organizational-function accounts: constraint sets and closure relations may be sensitive to investigator redescription. Cusimano & Sterner (2020) argue that apparently simple systems such as candle flames can realize closure under richer decompositions, challenging objectivity claims.

Thus the problem can be restated precisely:

> a formed L2 decomposition of constraints / boundaries may be treated as intrinsic before the cut / grain that generates that decomposition has been independently disciplined.

This is the clearest D3 candidate in Pass R0.

### External anchors

- Montévil & Mossio (2015), Biological organisation as closure of constraints, J Theor Biol 372:179–191, DOI 10.1016/j.jtbi.2015.02.029.
- Cusimano & Sterner (2020), The Objectivity of Organizational Functions, Acta Biotheor 68:253–269, DOI 10.1007/s10441-019-09365-9.

### Disposition

~~~text
D2 = PASS
D3 = PASS-CANDIDATE / strong
D4 = NO
~~~

## 6. Evolutionary transitions in individuality — D2 strong / D3 candidate

### Reconstruction

A domain-specific higher-order-One candidate can be reconstructed through:

~~~text
multiple lower-level formed units
+ cooperation
+ increasing interdependence
+ coordination / division of labour
+ suppression / reorganization of internal conflict
+ higher-order recurrent conditioning
-> evolutionary higher-order individuality candidate.
~~~

The ETI literature itself treats mutual dependence and low within-group conflict as central criteria.

### Facing pressure

The key question is unit / level individuation:

> Is group-level selection already presupposed in the explanation of how the group becomes a genuine evolutionary individual?

A documented ETI pressure exists here. Social-niche-construction work has criticized explanations that invoke collective-level selection products to explain how the collective level became a level of selection in the first place.

Facing translates the pressure as:

~~~text
L2 group / fitness partition
must not silently back-define
the earlier formation of the higher-order unit / from-where.
~~~

This closely parallels the repository's existing anti-circularity guard for One / branch-merge admission.

## 10. Common-core subtraction pressure

Across the seven cases, the recurring structure is not “new object”.

More stable common pressure:

~~~text
there is a determinate cut / actuality / organization;
some differences become load-bearing;
formed structure can alter later conditions;
different theories thicken this with:
  experience,
  apparatus,
  metastability,
  meaning-history,
  function,
  evolutionary individuality,
  identity / continuity.
~~~

After stripping those domain thickenings, two residues remain worth testing:

~~~text
R-A:
actuality establishes a non-role-interchangeable differentiation
rather than merely receiving a description;

R-B:
some actual differentiations reorganize what later differences can matter.
~~~

R-B is generative novelty / transformation and is clearly downstream-capable.

R-A is the true primitive anti-tautology residue and remains OPEN.

## 11. Universal-metalanguage audit
