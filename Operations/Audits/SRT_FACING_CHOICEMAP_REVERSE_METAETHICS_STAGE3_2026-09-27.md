# ChoiceMap FACE-REC stage 3 — reverse metaethics / missing-middle reconstruction

## 0. New author input

The author selected the pre-object branch and added historical provenance:

> **“B 。十多年前的感觉里L1facing 的好坏的感觉来自于L0facing的原初选择，在L1facing会变为道德价值bearer expection等，反向推元道德也是srt想要去追寻的东西。”**

Preserved interpretation:

```text
pre-object better/worse sense = YES;

historical author intuition:
L1-facing better/worse directional sense
derives from / is grounded in L0-facing primitive Selection;

formed L1-facing organization may differentiate that burden into
moral-value-related organization, Bearer-related exposure,
Expectation-related direction and other structures;

SRT long-horizon target includes reverse reconstruction of metaethics.
```

No stronger identity is assumed.

## 1. Apparent tension with 2026-09-14, and the narrow reconciliation

The 2026-09-14 author adjudication explicitly rejected:

```text
minimum L0 = primitive moral direction;
minimum L0 = universal good;
primitive Selection = value-bestowing act.
```

It simultaneously retained:

```text
primitive directionality
is more basic than fixed-position better / worse;

the relation between primitive non-neutrality
and later evaluative direction remains a reconstruction problem;

the deepest candidate ground is Selection as ontic generation.
```

Therefore the current author input can remain consistent with that adjudication only under the following distinction:

```text
L0 as GENERATIVE SOURCE of later directional polarity
!=
L0 containing PRE-ENCODED MORAL CONTENT.
```

This is the controlling reconciliation candidate.

## 2. Missing-middle hypothesis

The current source records already contain:

```text
primitive non-flat generativity / directionality
   [L0-facing burden]

and

formed-position-relative better / worse,
generative expectation,
Bearer / exposure,
Concern / d,
indexed normativity,
moral routing
   [formed downstream burdens].
```

What had remained under-specified is the bridge between them.

Author candidate:

```text
L0-facing primitive Selection / non-flat generativity
    ->
L1-facing pre-object directional polarity
    experienced / enacted as "getting better / getting worse"
    before explicit object / option / reason formation
    ->
formed differentiation of that polarity into distinct organizations:
    - structural generative Expectation;
    - Bearer-relative exposure / "for whom" structure;
    - Concern / stake-weighting / value organization;
    - later explicit moral judgment, reason, norm, obligation, etc.
    ->
L2-facing language / symbols / norms / institutions / explicit choice traces.
```

This is a research hypothesis, not a canonical dependency theorem.

## 3. Critical non-collapse: Bearer, Expectation and value are not the same thing

The author's phrase "会变为道德价值 bearer expectation等" must not be flattened into identity.

Current owners require:

```text
Bearer
!= moral standing;
!= Concern;
!= Expectation;
!= value.

Expectation
!= moral legitimacy;
!= explicit prediction only;
!= primitive L0 content.

Concern / d
!= direction source;
!= moral-standing admission.

moral value
!= reward;
!= valence;
!= preference strength.
```

Safer machine parse:

```text
one upstream directional burden
may become DIFFERENTIATED / TYPED
through several formed L1-facing organizations,
rather than literally "turning into one identical variable".
```

## 4. Why this is stronger than the current post-Selection-only wording

The 2026-09-14 post-Selection normativity record correctly blocks:

```text
Selection occurs -> therefore ought.
```

But it begins explicit normative comparison after formed consequence-bearing relations exist.

The present author intuition adds a deeper developmental / reconstructive question:

```text
why can formed positions have directional comparison at all?

what pre-object L1 organization lets a position feel / enact
"better / worse" before reasons and explicit moral objects are formed?

how is that organization historically / structurally grounded
in primitive non-flat generativity without importing morality into L0?
```

Thus the new route does not replace post-Selection normative gates.
It tries to explain the **source lineage of directional capacity** that later gates type and constrain.

## 5. Reverse-metaethics research programme candidate

Forward hypothesis:

```text
L0-facing primitive non-flat Selection
-> latent L1-facing directional polarity
-> formed L1 differentiation
   {Expectation, exposure/Bearer, Concern/value, agency-relevant organization, ...}
-> explicit L2 reasons / moral concepts / norms / judgments / institutions.
```

Reverse method:

```text
controlled perturbation of L2 moral / evaluative expression
-> reconstruct latent L1 directional transformation
-> separate:
   cultural rule,
   explicit reason,
   reward / aversion,
   habit / script,
   stable preference,
   Bearer-relative exposure,
   Expectation,
   Concern / stake,
   generative recut
-> search for cross-context invariants in directional generation
-> subtract formed / historical content
-> constrain the thinnest L0-facing source burden compatible with the data.
```

ChoiceMap is a candidate instrument for the first half of this reverse path.

## 6. Metaethical target is not "find the hidden moral rule"

The target should not be:

```text
recover one universal proposition:
"X is Good".
```

A more SRT-consistent target is:

```text
reconstruct how evaluative direction becomes possible
before explicit moral objects and reasons,
how that direction is typed by formed positions / relations,
and which parts survive subtraction of
language, culture, option-space and explicit rule.
```

This makes the programme closer to a **genesis of normativity** than to ordinary normative ranking.

## 7. Strongest current machine hypothesis

Current machine candidate:

```text
primitive Selection does not contain "good";

primitive Selection supplies irreducible non-flat generativity;

when a formed position participates in that generativity,
the non-flatness can be internally enacted / registered
as a pre-object directional polarity;

that polarity is subsequently differentiated
by exposure, expectation, concern, history and relation
into typed forms of value and normativity.
```

Compactly:

```text
L0 source without moral content
-> L1 directional polarity without explicit object
-> typed formed value / normative structures
-> L2 explicit morality.
```

This is the current best reconciliation candidate, not an author-adjudicated theorem.

## 8. What would falsify / narrow this route

The route should be narrowed or abandoned if, under controlled reconstruction:

1. better/worse judgments are fully explained by explicit learned rules / reward / valence / preference after fair controls;
2. no pre-object directional signal survives removal or perturbation of explicit candidate objects;
3. reconstructed L1 direction does not generalize across representational changes;
4. Bearer / Expectation / Concern distinctions add no independent explanatory or predictive constraint;
5. the supposed L0-facing residual is only a re-description of already formed L1 dynamics;
6. the route requires putting moral content, goal, preferred endpoint or continuation preference back into minimum L0.

## 10. Next author gate

The next author decision should separate three possible meanings of the L1 "better / worse" polarity:

```text
A. FELT READOUT
   a felt registration of alignment / misalignment with deeper generative direction;

B. GENERATIVE BIAS
   the polarity actively changes what becomes salient, comparable, selectable
   and therefore helps generate the next object / cut;

C. BOTH, coupled:
   the process that generates the next cut and the sense of better / worse
   are two facings of one ongoing L1 generative event.
```

The author may reject this trichotomy.
