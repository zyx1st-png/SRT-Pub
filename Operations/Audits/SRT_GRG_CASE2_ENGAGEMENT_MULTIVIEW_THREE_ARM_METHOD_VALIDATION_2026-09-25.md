# GRG case2 — multiview three-arm method validation

> **Purpose:** execute the bounded non-blind method test authorized after the HP-B / GRG follow-up adjudication.
>
> **Case:** existing engagement / recommender-system case2 only.
>
> **Boundary:** no new domain, no new source acquisition, no BCTB T2, no GRG v0.4, no canonical edit. This is a **method-organization test**, not a prospective scientific prediction test.

---

## 0. Three-arm design

The comparison uses the already-inspected case2 source family.

~~~text
Arm A
= current 09-23 GRG / frozen case2 decomposition.

Arm B
= reconstruction-first / grammar-late multiview method.

Arm C
= existing no-GRG ordinary causal / measurement / systems-analysis ablation.
~~~

Important contamination guard:

~~~text
same model/project already knows the case and prior results;
therefore this test CANNOT establish blind predictive superiority.
~~~

Allowed question:

> Does Arm B organize the existing source material in a materially different or more useful way than both A and C?

# Part I — Arm B multiview reconstruction

## 1. Source-native object before SRT / GRG re-description

The mature source family does not contain one single natural object called “engagement”.

It contains operational objects such as:

- candidate / eligible item;
- shown item / exposure;
- response probability;
- click / watch / dwell / conversion / revisit;
- ranking score;
- reward;
- user / model state;
- long-term value;
- satisfaction;
- stakeholder / ecosystem objective.

“Engagement” becomes a usable optimization object only after some of these are selected, weighted, aggregated and given an optimization role.

This is source-real and already established by case2.

---

## 2. Objectification audit

The engagement object depends on several cuts.

### Cut O1 — observability

~~~text
candidate
-> exposed
-> observable response opportunity.
~~~

The recommendation policy partly determines which behavior can become observable.

### Cut O2 — event

~~~text
continuous user activity
-> click / watch / dwell / conversion / revisit event.
~~~

### Cut O3 — metric

~~~text
events
-> weighted / normalized / aggregated engagement score.
~~~

### Cut O4 — horizon

~~~text
immediate interaction
vs
session / revisit / long-term user state.
~~~

### Cut O5 — bearer / stakeholder analogue at the source level

~~~text
single user
vs
cohort
vs
provider
vs
platform / ecosystem.
~~~

No SRT Bearer identity is inferred from this source-side grain distinction.

### Objectification result

“Engagement” is a stabilized operational cut, not a primitive target-domain entity.

This is useful for method clarity but is already substantially source-owned through metric construction, surrogate analysis and multi-stakeholder work.

---

## 3. L2-facing reconstruction — retained organization

Ask what retained organization makes later engagement measurement / optimization reproducible.

Source-native answers include:

- logged interaction histories;
- trained model parameters;
- learned embeddings / value functions;
- ranking and candidate-generation policies;
- reward / objective definitions;
- objective weights;
- business / product conventions;
- exposure distributions produced by prior policies;
- user-state estimates;
- platform / stakeholder constraints.

These are not all the same kind of history.

But together they form retained organization that shapes later recommendation and measurement.

Compact source-native loop:

~~~text
prior interactions + prior policy + retained model/objective
-> later recommendation conditions.
~~~

No GRG-specific target-domain mechanism is required to state this.

---

## 4. L1-facing reconstruction — determinate current formations

At a declared moment / grain, determinate formations include:

- a slate is produced;
- an item is exposed;
- a response occurs or does not occur;
- an interaction event is logged;
- a metric / reward value is assigned;
- an update is made to user / model state.

The important L1-side lesson is that these should not be collapsed:

~~~text
exposure
!= propensity
!= realized interaction
!= metric attribution
!= later state change.
~~~

Again this exactly survives the original case2 tests and is strongly source-owned.

---

## 5. L0-facing reconstruction — what can become observable / selectable

Before treating the observed event as given, ask what made it reachable.

Source-native structures include:

- candidate-generation eligibility;
- retrieval constraints;
- ranking policy;
- exposure propensity;
- slate composition;
- position / presentation;
- user context;
- model state;
- exploration / off-policy structure;
- content / stakeholder availability.

This gives the strongest multiview insight in the case:

> **the system does not merely predict engagement among neutral pre-given observations; its retained policy and model help constitute which future interactions can become observable at all.**

Compact:

~~~text
retained policy / model / objective
-> reachable exposure structure
-> current interaction opportunities.
~~~

This is a useful L0-facing reading.

But causal recommendation / exposure-bias / feedback-loop research already owns the same operational burden without L0 vocabulary.

---

## 6. Recursive re-entry

The three views integrate cleanly:

~~~text
L2-facing:
retained policy / model / history / objective

-> shapes

L0-facing:
candidate reachability / exposure propensity / feasible slate

-> actualises as

L1-facing:
shown item / interaction / metric / state update

-> writes back into

L2-facing:
logs / parameters / policy / reward estimates

-> reshapes later

L0-facing reachability.
~~~

This is a coherent single generative loop.

It is more compact than treating E0-E5 / P1-P6 as many separate probes.

But compactness alone is not scientific increment.

---

## 7. Friction / reconstruction audit

Source-native strain points include:

- exposure bias;
- distribution shift;
- short-term / long-term mismatch;
- reward misspecification;
- engagement / satisfaction divergence;
- feedback-loop amplification;
- stakeholder conflict;
- ecosystem externality.

A GRG / SRT-side analysis may treat these as places where a stabilized objectification becomes difficult to maintain or requires recutting.

However:

~~~text
source-native mismatch / tradeoff / bias
!= canonical Psi_f established.
~~~

No target-domain gain is earned by relabeling these as Ontological Friction.

---

## 8. Recut test

Possible legitimate recuts:

~~~text
item -> slate;
interaction -> trajectory;
short-term engagement -> long-term experience;
user -> multi-stakeholder ecosystem;
observed response -> policy-conditioned observation process;
fixed metric -> revisable objective construction.
~~~

The multiview method makes one recut especially explicit:

> move from “engagement as observed target” to “the policy-conditioned generative process that produces what engagement can be observed and optimized”.

This is methodologically useful.

The no-GRG control already recovers almost the same move through opportunity / exposure + dynamic-system effect + objective construction.

---

## 9. Grammar-late test

After the reconstruction, one may abstract a recurrent relation:

~~~text
retained observation / optimization structure
-> constrains later reachability
-> produces determinate events / measurements
-> writes back into retained structure
-> changes later reachability.
~~~

This relation is **not admitted as a new grammar candidate** here.

Reason:

- it is generic enough to resemble ordinary policy-feedback / adaptive-system dynamics;
- the source family already contains it;
- Arm C recovers it without GRG vocabulary.

Therefore:

~~~text
late grammar candidate = NONE
nontrivial residual = NONE ESTABLISHED.
~~~

This is exactly the kind of outcome the grammar-late correction must permit.

# Part II — three-arm comparison

## 10. Shared ordinal rubric

Scale:

~~~text
0 = weak / absent
1 = useful but partial / mainly reorganizational
2 = strong for this case
~~~

For vocabulary overhead `V`, higher is better:

~~~text
0 = high avoidable overhead
1 = moderate
2 = low.
~~~

Dimensions:

~~~text
F = source fidelity
H = hidden-assumption / objectification exposure
R = relation / dependency recovery
I = intervention / failure discrimination
U = genuinely new unresolved residual
C = explanatory compression
V = low vocabulary overhead
X = cross-view integration that materially reorganizes the case
~~~

### Scores

| Dimension | Arm A current GRG | Arm B multiview / grammar-late | Arm C no-GRG |
|---|---:|---:|---:|
| F source fidelity | 2 | 2 | 2 |
| H hidden assumptions / cuts | 2 | 2 | 2 |
| R dependency recovery | 2 | 2 | 2 |
| I intervention / failure discrimination | 2 | 2 | 2 |
| U new residual | 0 | 0 | 0 |
| C explanatory compression | 1 | 2 | 2 |
| V low vocabulary overhead | 0 | 1 | 2 |
| X cross-view integration / reorganization | 1 | 2 | 1 |

These scores are machine judgments in a contaminated post hoc method test, not objective measurements.

---

## 11. What B improves over A

Arm B improves the internal organization of the GRG analysis in three ways.

### B>A1 — fewer probe fragments

Instead of E0-E5 + T1-T6 + P1-P6 as partly overlapping lists, B compresses the case into:

~~~text
retained organization
-> reachability / pre-object conditions
-> determinate event / metric
-> writeback
-> later reachability.
~~~

### B>A2 — objectification becomes explanandum

Arm B more clearly asks:

> how was “engagement” itself constructed as the object worth optimizing?

rather than using the metric cut mainly as one probe among several.

### B>A3 — grammar does not receive presumptive priority

The method successfully terminates with:

~~~text
NO grammar candidate.
~~~

That is an architectural improvement because the method can now succeed by reconstructing the process without inventing a reusable grammar.

---

## 12. What B does NOT improve over C

Arm C already recovers:

- opportunity / exposure;
- response probability;
- realized interaction;
- metric construction;
- dynamic feedback;
- downstream proxy alignment;
- aggregation / grain dependence.

Therefore B does not currently add:

- a new target-domain variable;
- a new mechanism;
- a new intervention;
- a new failure prediction;
- a new negative control;
- a new source-side residual.

The L0/L1/L2 organization changes **how the analysis is seen**, not what the mature source requires us to believe about recommender systems.


The negative scientific result is useful.

It validates a narrower architecture claim:

> **The 09-25 redesign can improve how GRG organizes its own inquiry without requiring that GRG outperform ordinary mature systems analysis in every target.**

More specifically:

~~~text
reconstruction-first = RETAIN
grammar-late = RETAIN
multiview = RETAIN AS OPTIONAL ORGANIZING METHOD
~~~
