# Facing reconstruction Pass A — FRH-1: One / Selection-position / formed Orientation

> **Role:** second target in the v0.2 bounded Facing reconstruction pass.
>
> **Boundary:** HP-B is read-only. This audit does not edit One Formation, Expectation typing, HP-B, or any canonical owner.

## 0. Question

Test whether the recent compression:

~~~text
One         = diachronic reading
Position    = current operative reading
Orientation = prospective / future-facing reading
~~~

really names three independent constructs.

Canonical control already fixes One and Selection-position. The only materially open item here is the recently coined `formed Orientation`.

## 1. Source typing

~~~text
K1 = One Formation §2: One = formed process-unity carried by a relatively separable Selection-mediated reconstitution path.
K2 = One Formation §3 / Spine §6.2: Selection-position_t = time-local operative from-where of an already formed One.
K3 = One Formation §3: One and Selection-position name distinct ontological aspects of the same formed process-unity.
K4 = Spine §6.3: Selection affecting later selectability != formed-position anticipation automatically.
A0/A1 = author-accepted reconstruction direction: Position formation makes transformation non-arbitrary; formed Orientation was proposed as Position's future-facing expression.
A0-P = 2026-09-20 Expectation typing: B structural generative expectation does not require C / formed locus; C is anticipatory realization from a formed locus.
READ-ONLY HP-B = current Position / Gate carries a future-facing asymmetry; HP-B explicitly routes this through the 09-20 B/C expectation typing.
~~~

## 2. One and Selection-position — no new merge theorem needed

The canonical owner already says:

~~~text
formed-continuation aspect -> One
operative aspect at t      -> Selection-position_t
~~~

Thus the dialogue compression:

~~~text
One      = diachronic / across-reconstitution reading
Position = current operative reading
~~~

is useful explanatory prose but adds no new ontological relation.

Disposition:

~~~text
One = KEEP (canonical burden)
Selection-position = KEEP (canonical burden)
One = Position = REJECT as identity equation
"two readings / aspects of the same formed process" = SOURCE_ABSORBED(K)
~~~

## 3. FACE-L0

Neither One nor Selection-position is the primitive L0 source.

~~~text
primitive Selection / O0
= open / non-preclosed generativity;

One
= formed recurrent organization;

Selection-position
= current operative aspect of that formed organization.
~~~

A future-facing asymmetry of a formed Position therefore cannot be used to define primitive orientation / Oriented Openness.

## 4. FACE-L1

Selection-position is already the L1-side formed operative locality of an admitted One.

If `formed Orientation` merely means:

~~~text
from this Position, not all later continuations / transformations are structurally equivalent
~~~

then it adds no new current entity. It is a description of the directional burden carried by the formed organization participating from this Position.

## 5. FACE-L2 / future-shaping burden

The 2026-09-20 Expectation owner already supplies a broader burden:

~~~text
B — structural generative expectation
= an actually formed generative relation has immanent direction:
  possible continuations / transformations preserve, realize, weaken, substitute, hollow out or destroy the relation differently.
~~~

B does **not** require a formed locus.

Therefore, when the relevant formed relation is a One / Selection-position organization:

~~~text
Position-indexed future-facing asymmetry
= a special case / indexed realization of B-level structural generative direction.
~~~

No new term is required to say this.

## 6. Why this is not automatically C-level anticipation

C in the Expectation typing is stronger:

~~~text
C — anticipatory realization
= enough formed organization exists that generative direction is inherited, embodied, enacted, regulated by, or explicitly modeled from somewhere.
~~~

Spine §6.3 independently guards:

~~~text
Selection affecting later selectability
!= formed-position anticipation automatically.
~~~

Therefore:

~~~text
future-facing asymmetry of Position
-/-> anticipation automatically;

Position-indexed B-direction
-> may be thickened into C where separate anticipatory organization is paid.
~~~

This is exactly where v0.1 over-compressed Expectation into Position / Orientation.

## 7. HP-B read-only cross-check

HP-B says:

~~~text
The current Position / Gate carries a future-facing asymmetry.
09-20 B / C0 / C1 expectation typing = preserved.
~~~

and its hook says:

~~~text
future-facing organization = candidate minimal expectation burden.
~~~

These statements do not require a separate `formed Orientation` ontology noun. They are already expressible as structural generative expectation carried by a current formed organization.

No HP-B wording is changed by this audit.

## 8. Collision pressure

Retaining `formed Orientation` as a stable term would create avoidable collisions with:

- `Oriented Openness` / O0, which is primitive and not formed-position direction;
- `pre-object generative orientation` in the cognition programme, which is a broader research object and will be tested later;
- structural generative Expectation B;
- anticipatory realization C.

This is precisely the kind of noun multiplication the current pass is meant to remove.

## 9. Verdict

~~~text
FRH-1 RESULT

One = KEEP
Selection-position = KEEP

One / Selection-position relation
= already canonical as distinct aspects of the same formed process-unity;
  no new unification theorem needed.

formed Orientation as independent term-of-art
= NOT RETAINED.

Disposition:
MERGE_CANDIDATE -> RETIRE_CANDIDATE.

Route its burden as:
Selection-position / formed organization
+ structural generative Expectation B
= Position-indexed prospective asymmetry.

C-level anticipation
= remains a stronger downstream realization;
  NOT automatic.
~~~

Allowed remaining use:

`orientation` may remain ordinary explanatory prose when qualified by its owner context. Do not harden `formed Orientation` as a new SRT construct.

## 10. What remains OPEN

- whether the cognition programme's broader `pre-object generative orientation` is fully reducible to a bundle of existing formed burdens;
- exact conditions for C-level anticipation;
- One-level perspective sufficiency;
- Bearer / phenomenality routes (HP-B frozen / read-only);
- exact branch / merge identity.

## 11. Pass consequence

After FRH-0 and FRH-1, two recent candidate nouns have been removed:

~~~text
L0-facing continuity -> explanatory / question shorthand only;
formed Orientation   -> ordinary prose / Position-indexed Expectation-B reading only.
~~~

The next internal target should therefore focus on continuity / persistence / recurrence / Stable ISP / generative reselectability without carrying either noun forward.
