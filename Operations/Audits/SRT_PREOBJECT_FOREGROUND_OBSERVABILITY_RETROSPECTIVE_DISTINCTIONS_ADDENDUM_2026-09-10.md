## 1. IRR-B: model-complete state vs ontologically complete pre-Selection state

Historical IRR-B retains the anti-magic discipline:

```text
genuine Selection leaves causally effective residue somewhere in the complete present state / enlarged environment;
no hidden history may be invoked beyond a genuinely complete present causal state merely to force different futures.
```

But two uses of `complete state` must remain distinct:

```text
MODEL-COMPLETE STATE
= complete relative to a declared scientific representation / intervention algebra.

ONTOLOGICALLY COMPLETE PRE-SELECTION STATE
= the stronger claim that reality before Selection is exhaustively objectifiable
  as a finished state vector.
```

MOBJ-A/MOBJ2-B do not reverse IRR-B. They only block the inference that the first sense automatically licenses the second.

Disposition:

```text

complete-state language as model-relative: RETAIN / CLARIFY
complete-state language as L0 ontological exhaustion: NOT LICENSED
IRR-B Level-1 historical verdict: DO NOT REVERSE

```

## 2. Ontological admission vs empirical proxy admission

Historical Level-2 routing often used a structure like:

```text
first identify an event as a Selection candidate by a non-circular admission surface;
then test a downstream SRT-sensitive consequence.
```

That remains sound if `identify` means an operational proxy classification. It becomes a category error if it is read as requiring an observer to stand before manifestation and directly observe pre-Selection ontology as though it were already a determinate manifest variable.

Keep separate:

```text
ONTOLOGICAL ADMISSION
= what Selection is / why objectifiable determinacy is downstream.

EMPIRICAL PROXY ADMISSION
= what post-Selection foreground/readout pattern licenses a bounded test.
```

Therefore:

```text
need for non-circular empirical proxy: RETAIN
requirement to directly observe pre-Selection ontology: REJECT AS CATEGORY ERROR
physical-trigger blocker: REFRAME, not automatically solved
Level 2: still requires a prospective downstream discriminator / intervention consequence
```

```text

PRE-OBJECT ONTOLOGICAL DISTINCTIVENESS
```
