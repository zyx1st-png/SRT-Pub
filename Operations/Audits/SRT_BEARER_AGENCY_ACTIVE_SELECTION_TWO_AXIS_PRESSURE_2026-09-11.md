# Bearer -> agency and active/passive Selection — two-axis pressure

## 1. Accepted starting points

Author-accepted Bearer direction:

```text
Bearer
= an already-admitted One for which a consequence q,
  regardless of source,
  becomes history-bearing for later reconstitution of the same One-lineage
  and changes that One's future selectability.
```

Author-accepted active/passive direction:

```text
PASSIVE Selection
= survival / maintenance within an achieved selectable organization;

ACTIVE Selection
= creation / reconstruction;

minimum ACTIVE threshold
= Selection acts on / reconstructs the organization that determines later selectability itself.
```

Important author/source guard:

```text
active construction does not imply a pre-existing cognitive agent at every layer.
```

Therefore the current workline must not identify:

```text
Agency = ACTIVE Selection
```

by definition.

## 2. Why a one-dimensional ladder is misleading

Tempting but unsafe:

```text
One -> Bearer -> Agency -> ACTIVE Selection.
```

This conflates two different questions.

### Unit / closure question

```text
What continuing One bears which consequences?
Does its own Selection participate in a source-return closure?
```

### Selection-mode question

```text
Does Selection mainly preserve an achieved selectable organization,
or does it reconstruct the organization that determines later selectability?
```

The first is about **who / what is in a consequence loop**.
The second is about **what level of organization Selection acts on**.

## 3. Axis U — unit / closure standing

Machine-side dependency:

```text
ONE
lineage-relative continuation recursion

-> BEARER
consequence-to-reconstitution closure from any source

-> SELF-CONSEQUENCE / AGENT-LIKE CLOSURE candidate
Selection through O's operative position
-> q
-> q becomes constitutive of later reconstitution of O.
```

The last step is stronger because:

```text
who causes
and
who bears
```

converge on the same independently admitted One-lineage.

Working label only:

```text
thin agency / self-consequence closure candidate
```

No subjecthood or consciousness follows.

## 4. Axis M — Selection mode

Independent machine-side mode axis:

```text
PASSIVE MODE
Selection operates primarily within / for continuation of an achieved selectable organization.

ACTIVE MODE
Selection recursively acts on the organization that determines later selectability itself.
```

Active/passive is not:

```text
low activity / high activity;
no agency / agency;
external / internal;
unconscious / conscious.
```

## 5. Cross-product, not ladder

The two axes generate at least four conceptually distinct cells.

### U1/M1 — Bearer + predominantly passive Selection

```text
O bears consequences;
possibly acts and learns;
returned consequences mainly support repair / continued viability
inside an achieved selectable organization.
```

Candidate examples include strong homeostatic / adaptive maintenance regimes.

This may be agent-like without crossing the author's ACTIVE Selection threshold.

### U2/M1 — self-consequence closure + passive Selection

```text
Selection_O -> q -> later O reconstitution;
```

but q-driven change mainly preserves the current organization of future selectability.

This is a strong candidate for **minimal / maintenance agency** if the author later chooses that term.

It is not ACTIVE Selection merely because the system acts and learns from its own consequences.

### U1/M2 — Active Selection without established self-consequence agency closure

Conceptually possible if a subjectless / distributed Selection process reconstructs later selectability without first paying a same-One self-consequence loop.

This possibility is licensed only at the level of an open cross-layer interpretation:

```text
pre-subject Selection can actively construct non-flat selectability;
```

but the exact application of the later PASSIVE/ACTIVE modal distinction to pre-One / pre-Bearer layers remains scope-sensitive.

Therefore:

```text
ACTIVE Selection -> Agency
```

is not licensed as a universal implication.

### U2/M2 — self-consequence closure + Active Selection

Strong combined architecture:

```text
O selects from P_t
-> consequence / intervention q
-> q changes the organization Phi_O that determines later selectability
-> P_(t+1) is reconstituted under changed Phi_O
-> O must continue from a reconstructed future-selectability organization.
```

Machine-side working label:

```text
active agency / creative agency candidate.
```

This is stronger than generic learning because the target is not merely current state or policy weighting; the organization of later selectability is itself reconstructed.

## 6. Self-consequence closure is not enough for ACTIVE Selection

Negative control:

```text
agent action
-> error signal
-> parameter correction
-> same basic selectable organization retained
-> improved continuation / homeostasis.
```

This may pay:

```text
self-consequence closure: YES
Bearer: YES
thin agency pressure: YES
ACTIVE Selection threshold: NOT AUTOMATIC.
```

The author's threshold remains:

```text
Selection acts on / reconstructs
what determines later selectability itself.
```

Therefore:

```text
learning from consequences
!= ACTIVE Selection by definition.
```

## 7. ACTIVE Selection is not enough for full agency

Opposite negative control:

A distributed / subjectless process may reconstruct the conditions under which later differentiations become selectable without an independently admitted One whose own Selection consequences close back on it.

Then:

```text
selectability reconstruction: possible
self-consequence agency closure: not established.
```

This preserves the author's pre-subject guard and prevents agency from being smuggled into L0.

## 8. Relation to older PH-IND04 selector-position

PH-IND04 uses a thicker bridge-level `selector-position`:

```text
same-bearer history
+ path-sensitive modulation
+ changed future selectability
-> selector-position candidate.
```

Current #931 uses a thinner **ontological Selection-position** upstream of Bearer:

```text
One's time-local operative non-flat locus from which later Selection can continue.
```

Therefore keep:

```text
ontological Selection-position
!= PH-IND04 thicker history-conditioned selector-position.
```

The latter can be treated as a downstream agency / subject-side thickening, not as the definition of the upstream One-position.

## 9. Candidate genetic architecture after the split

Do not use one universal ladder.

Use a dependency graph:

```text
FIELD / MULTIPLICITY
-> Selection
-> vertical organization
-> One
-> ontological Selection-position

One + consequence-to-reconstitution closure
-> Bearer

Bearer + self-consequence closure
-> thin agency candidate

SEPARATE MODE AXIS:
Selection on achieved organization
-> PASSIVE maintenance mode

Selection on organization-of-later-selectability itself
-> ACTIVE reconstruction mode
```

These relations can intersect:

```text
thin agency + PASSIVE mode
-> maintenance agency candidate;

thin agency + ACTIVE mode
-> active / creative agency candidate.
```

## 10. Consequence for JFS

Joint Future-Selectability Reconstruction should not require a collective Bearer or collective agency in advance.

Possible:

```text
multiple Ones / Bearers / agents
-> positioned Selections jointly reconstruct relation-level selectable organization
-> JFS
```

Whether relation-level organization is itself:

```text
One;
Bearer;
agent;
collective ISP
```

must be separately paid at that scale.
