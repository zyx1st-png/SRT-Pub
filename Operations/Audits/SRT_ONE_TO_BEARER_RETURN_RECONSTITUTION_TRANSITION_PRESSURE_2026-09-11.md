# One -> Bearer transition pressure — continuation recursion versus consequence-bearing recursion

## 0. Correction note

The first machine draft of this file over-strengthened Bearer onset by requiring the relevant consequence to be generated by Selection from the same One.

That is too narrow.

A Bearer can bear consequences originating from:

```text
its own Selection;
another One;
environmental change;
a relation-level process;
a social / institutional structure;
or another external source.
```

The inherited bearer owner asks **where consequences close and whose future selectable organization is altered**, not only who caused them.

Therefore the corrected minimum distinguishes:

```text
GENERAL BEARING:
consequence -> lineage-coupled return / history-bearing reconstitution change

SELF-CONSEQUENCE / AGENCY CLOSURE:
Selection from O -> consequence -> return to O's later reconstitution
```

The second is a stronger subtype, not the minimum Bearer gate.

## 1. Starting constraint

Current accepted One direction:

```text
Selection-generated vertical result
-> becomes later Selection condition
-> later Selection reconstitutes a successor operative vertical locus
-> lineage-relative result-to-condition recursion
-> One.
```

Earlier author ruling on Bearer:

```text
before Bearer:
Selection sedimentation -> 多

transition:
historical traces begin to sediment in 一

then:
一 -> Bearer.
```

The transition problem is therefore not whether history exists. History already matters before Bearer.

The problem is:

> **What relation changes when consequences become borne as history of this continuing One rather than remaining only distributed conditions in the wider field?**

## 2. One-level recursion is not enough

A One may continue because wider-field history repeatedly helps regenerate the same local vertical lineage.

Machine shape:

```text
H_field(t)
-> helps reconstitute P^A_(t+1)
-> later Selection can proceed from P^A_(t+1)
```

where `P^A` is the time-local operative locus of One A.

This can establish continuation without establishing that a particular consequence has become A-indexed history.

Therefore:

```text
lineage continuation
!= consequence bearing.
```

## 3. Corrected candidate transition: consequence-to-lineage closure

Let:

```text
O_A   = an already-formed thin One
P^A_t = its current operative Selection-position
q_t   = a consequence relevant to A, from any source
```

The Bearer transition candidate begins when:

```text
q_t
-> materially alters the organization responsible for reconstituting P^A_(t+1)
-> the altered reconstitution changes A's later selectability
-> q_t therefore becomes part of A-indexed history in a causal / relational sense.
```

This is stronger than:

```text
q_t merely contacts A;
q_t produces a transient signal;
q_t is stored somewhere;
q_t correlates with A's future state;
q_t changes the environment while A resumes unchanged.
```

The live minimum relation is:

> **a consequence becomes load-bearing in regenerating the later operative locus of the same continuing One-lineage.**

Its causal origin is a separate question.

## 4. `from-where` / `to-where` after the correction

Current bearer architecture can now be placed directly downstream of One:

```text
ONE
= continuation recursion of a localized vertical lineage

FROM-WHERE
= P^A_t, the time-local operative locus from which A can later Select

TO-WHERE
= the continuing organization whose later operative locus is altered by q_t.
```

For general bearing, `q_t` need not originate from `FROM-WHERE_A`.

Bearer onset becomes plausible when:

```text
q_t
-> closes strongly enough on O_A
-> alters reconstitution of P^A_(t+1)
-> changes A's later future-selectability organization.
```

A stronger self-consequence loop exists when:

```text
Selection from P^A_t
-> q^A_t
-> q^A_t returns to alter reconstitution of P^A_(t+1).
```

Important guard:

```text
bearing closure
!= spatial co-location
!= internal storage
!= numerical-identity token.
```

The relevant organization can be distributed and environmentally scaffolded.

## 5. Do not resurrect history localization

The transition is not:

```text
history was in 多
-> history moves physically into 一.
```

That would revive the retired history-localization route.

Use instead:

```text
distributed historical differences remain possible;

some consequences acquire an A-indexed causal role:
they become specifically load-bearing
for how A's next Selection-position is reconstituted.
```

Thus:

```text
where history is stored
!= decisive

which lineage's later reconstitution that consequence becomes constitutive for
= decisive relation.
```

## 6. Corrected machine-side transition roles

For pressure only, distinguish:

### B-RET — consequence-return relevance

```text
q_t materially alters the organization that participates in reconstituting P^A_(t+1).
```

This blocks mere external impact or transient contact.

### B-WRITE — history-bearing future-selectability writeback

```text
the consequence-induced alteration changes A's later selectable organization / future selectability
in a history-dependent way.
```

This blocks narrow reversible feedback as a sufficient condition.

Minimum machine candidate:

```text
B-RET + B-WRITE
-> Bearer-onset pressure bundle.
```

### B-SRC — optional stronger source relation

```text
q_t was generated by Selection issuing through P^A_t.
```

If B-SRC is added to B-RET + B-WRITE, the result is a stronger **self-consequence / agency closure** candidate:

```text
A Selects
-> consequence
-> A must continue from a position altered by that consequence.
```

B-SRC is **not** required for generic bearing.

These are not canonical variables and not a necessary-and-sufficient theorem.

## 7. Feedback is not automatically bearing

Critical negative control:

```text
controller output
-> environment changes
-> sensor input changes
-> next controller output.
```

This establishes a feedback loop, not automatically a Bearer.

The existing consciousness-side patch already treats a thermostat as having local feedback while usually lacking strong history-bearing future-selectability rewrite.

Therefore:

```text
feedback return
!= consequence return sufficient for bearing.
```

A stronger bearer candidate requires that the consequence alter the continuing organization / history from which the later Selection-position is reconstituted.

An adaptive controller may pressure this boundary. The present file does not protect SRT by declaring such systems non-bearers by fiat.

## 8. External consequences can be borne

A consequence need not be self-generated.

Examples in principle:

```text
predator injures organism;
market shock constrains institution;
other agent breaks trust;
environmental event removes a capability;
social recognition creates a durable commitment.
```

If the consequence becomes history-bearing for later reconstitution of the affected One's operative position, the event can support Bearer standing even though the One did not cause it.

Therefore:

```text
who causes
!= who bears.
```

## 9. External scaffolding does not defeat Bearer by itself

A Bearer need not internalize every relevant consequence.

Possible shape:

```text
q_t is stored / propagated by environment or social structure
-> that externally carried consequence later alters organization reconstituting A's position
-> A's later selectability changes.
```

External scaffolding is compatible with bearing if the consequence-return relation remains lineage-coupled.

So:

```text
internal vs external
is not the Bearer boundary.
```

The stronger question remains:

> **whose later operative lineage is nontrivially reconstituted by the consequence?**

## 10. Non-outsourcing as a pressure test, not a primitive

Suppose A is exposed to q, but all relevant cost / damage / correction / historical burden is absorbed elsewhere while A can be restored unchanged.

Then:

```text
contact / causal involvement: YES
One continuation: possibly YES
strong Bearer standing for q: weakened / not established.
```

Non-outsourcing therefore remains a useful adversarial test:

> If the relevant consequence can be fully rerouted away while the alleged bearer resumes the same selectable organization without historical change, what exactly is being borne by that One?

This is a pressure test, not a canonical definition.

## 11. Bearer onset and Bearer stability should be separated

By analogy with One onset versus stability:

```text
Bearer onset candidate
= first genuine consequence-to-reconstitution coupling in which q becomes constitutive of the same One-lineage's later position reconstitution;

Bearer stability / depth
= how repeatedly, robustly, temporally deeply and non-outsourcably this consequence-bearing closure persists across perturbation and change.
```

This preserves graduality without requiring an arbitrary scalar threshold.

It also permits:

```text
thin / weak Bearer candidates
without equating them with subjectivity or phenomenality.
```

## 12. One versus Bearer — corrected compact distinction

```text
ONE
past vertical result
-> later Selection condition
-> lineage-relative reconstitution
-> renewed operative Selection locus.

BEARER
consequence q from any source
-> becomes history-bearing change for that One
-> alters reconstitution of that same lineage's later operative locus
-> changes that One's future selectability.
```

Compactly:

```text
One
= continuation recursion

Bearer
= continuation recursion
+
consequence-to-reconstitution / own-history recursion.
```

Stronger agency subtype:

```text
One Selects
-> q
-> q returns to same One's later reconstitution.
```

## 13. Why Bearer is not just 'more stable One'

A One can be highly stable because environmental dynamics repeatedly regenerate it while consequential events do not become load-bearing for its later reconstitution.

Conversely, a less stable lineage can already begin to bear consequences if a consequence materially shapes the way its next operative position is rebuilt.

Therefore:

```text
One stability axis
!= Bearer axis.
```

Bearing is a new relation, not merely a higher score on continuation robustness.

## 14. Multi-One consequence

For two Ones A and B:

```text
A may cause q that B bears;
B may cause q that A bears;
A may cause q and A itself may bear it;
q may alter both A and B;
q may alter a relation-level One AB.
```

Thus:

```text
causal source
and
Bearer attribution
must be typed separately.
```

Do not infer collective Bearer / collective ISP automatically.

## 15. Relation to cognitive One

Once a Bearer exists, cognitive One can become a powerful route for explicit consequence attribution:

```text
this happened because of / to me/us/this unit
-> memory / model / norm / responsibility routing
-> later Selection weighting
-> stronger own-history coupling.
```

But cognition is not required for the thin Bearer transition candidate.

The earlier author ruling still blocks using cognitive One to explain the first Bearer bootstrap.

## 16. Current verdict

```text
One -> Bearer transition
= NOT mere additional persistence
= NOT history moving spatially into One
= NOT generic feedback
= NOT limited to self-caused consequences

live minimum candidate:
a consequence from any source becomes lineage-conditionally load-bearing
for reconstitution of a continuing One's later operative locus
and thereby changes its future selectability.

stronger self-consequence / agency closure:
Selection from O -> q -> q alters O's later reconstitution.

One = Bearer: NO
Bearer = subject / experiencer: NO
internal storage required: NO
history-localization route reopened: NO
strict numerical identity solved: NO
canonical edit: NO
new Level: NO
scientific distinctiveness: NOT ESTABLISHED
```

## 17. Next pressure

The next internal pressure should distinguish:

```text
A. persistent One with little consequence-to-reconstitution closure;
B. ordinary reversible feedback;
C. adaptive controller with retained self-modification;
D. living cell / precarious autonomous unit;
E. resettable / consequence-outsourcing agent;
F. socially scaffolded agent;
G. externally inflicted consequence that becomes history of the affected One.
```

A second live issue is scale attribution:

> **If nested / overlapping Ones coexist, can the same consequence be borne at multiple scales, or must Bearer attribution be exclusive?**

The current One ontology gives no reason to assume exclusivity in advance.
