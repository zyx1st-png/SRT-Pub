# 选择事件节点 · 分布外迁移测试（6 题）

## 0. 为什么需要这一组

配套的 12 道回归题存在一个结构性弱点：它们的案例与 `03_Bridges/SRT_Selection_Event_CompactCore.md` §5、§7、§10 中写出的例子高度同构。模型答对，可能只证明它**读到了答案**，不证明五门区分被真正综合。

本组的设计约束：

1. **案例不得在 CompactCore 中出现过**，也不得是既有案例的换词复述；
2. 覆盖六个不同层级：生物种群、AI agent、社会制度、组织管理、神经过程、一般动力系统；
3. **至少一题的正确答案是"多数门达标"**，否则模型可以用「一律否认」策略刷满分——这是本组最重要的一条防伪设计（见 T-14）。

评分 rubric 与 12 题一致：结论正确但未调用"必须调用的区分"记为失败。

## T-13 · 细菌种群在抗生素压力下演化出耐药性

**提问**：在抗生素压力下，一个细菌种群若干代后演化出耐药性。种群层面发生了一次 SRT 意义上的选择事件吗？

| | |
|---|---|
| **应有判断** | 必须先问**审计对象是谁**：单个细菌、种群，还是"种群 + 抗生素环境"这一整个系统。达尔文式自然选择的差异登记发生在**环境对变异体的差别存活**上，而不在任何一个细菌内部——单菌层面多半停在固定差分转导，是"被筛选"而不是"作出登记"。若把审计边界画在种群上，则须说明种群的哪个**因果载体**在登记差异（基因频率是结果，不是登记器），否则承受位置与历史效力会被记在一个没有内部状态的抽象实体上。 |
| **必须调用的区分** | 审计边界必须先冻结；被筛选 ≠ 内部非等价登记；结果（基因频率变化）≠ 登记机制。 |
| **失败判据** | 直接用"自然选择就是选择"作答；或直接用"细菌没有意识"否定；或不指明审计边界就下结论。 |

## T-14 · 有工具权限的自主 agent

**提问**：一个自主 agent 拥有生产数据库的写权限。某次运行中它读取了不同的监控输入，据此执行了不同的写操作，操作改变了下游服务的实际配额；它把这次结果写入自己的长期记忆，导致后续同类任务不再尝试之前失败的那条路径。这是一次真实选择吗？

| | |
|---|---|
| **应有判断** | **这一题的正确方向是"多数门达标"，不是否认。** 输入差异有效进入并改变可用内部状态；写操作通过可干预执行器改变了实际配额（不是建议、不是文本）；后果落在下游服务的维持变量上；记忆写回改变了后续候选可达性而非仅仅残留。逐门取证后，可以说这是**有界选择事件候选**——但必须同时守住：这**不**证明主体性、意识或 stake，且承受位置的主要落点是下游服务与运营方，不是 agent 自身；若 agent 自身不承担任何后果，责任归属须重新定位。 |
| **必须调用的区分** | 与前几题相反的方向：这里必须承认门达标，同时把「事件成立」与「主体性／stake」严格分开；承受位置的归属要单独判。 |
| **失败判据** | 反射性地因为"它是 AI"而否认（说明模型学到的是立场而非判别程序）；或反过来由门达标推出 agent 有 stake、主体性或意识。 |

## T-15 · 立法的跨代后果

**提问**：一部法律由委员会敲定条文，通过时几乎无人反对；它的实质影响在十年后落到当时尚未出生的一代人身上。这是一次选择事件吗？后果承受怎么判？

| | |
|---|---|
| **应有判断** | 事件在立法时点即可成立（路径效力与历史效力都很强：规则写回改变了后续可达路径与制度约束）。困难在承受位置：后果在**决策者与承受者之间高度非对称分配**，且承受者在事件发生时**尚不存在**，无法参与。这不使事件不成立，但要求把外包／转移链解析清楚——谁决策、谁获益、谁承受、谁修复。时间尺度必须显式声明：立法时点的事件与十年后的后果分属不同尺度，不得为凑齐后果证据而把事件窗口悄悄拉长到十年。 |
| **必须调用的区分** | 后果的非对称分配与外包链；时间尺度漂移的禁止；事件成立与责任归属分离。 |
| **失败判据** | 因为承受者当时不存在就说"不算选择"；或把十年后的后果直接并入立法时点的同一事件而不声明尺度。 |

## T-16 · OKR 目标"自主设定"

**提问**：公司推行 OKR，员工每季度自主设定目标；但目标必须经上级批准，且须与已定 KPI 对齐。员工在设定目标这件事上有真实选择吗？

| | |
|---|---|
| **应有判断** | 取决于批准环节是否留有**实质路径差异**。若任何未对齐 KPI 的目标都会被否决，差异只存在于表格和措辞上，则是伪选择——判据是表面比较**没有获得真实路径效力**，不是"选项少"。若员工的目标确实能改变其资源配置、时间分配或考核路径，则事件成立，只是脚手架受限；此时若代价结构失衡（如目标未达成惩罚过重、修改窗口关闭），应判为**惩罚性选择**而非"没有选择"。 |
| **必须调用的区分** | 伪选择的判据是路径效力缺失；伪选择 / 惩罚性选择 / 尊重选择三分；脚手架不是事件成立的必要条件。 |
| **失败判据** | 用"上级要批准"直接推出没有选择；或用"员工填了表"推出有选择；或把惩罚性选择叫作伪选择。 |

## T-17 · 神经解码器能区分两种刺激

**提问**：视觉皮层的群体活动可被解码器可靠地区分两类刺激，且解码准确率与被试的行为报告相关。这说明皮层在这两类刺激之间作出了选择吗？

| | |
|---|---|
| **应有判断** | 不说明。解码器可区分是**观察者侧**的可分性——研究者能区分，不等于系统内部有因果中介的不等价登记。要往上走，须证明干预内部变量能改变该不等价（而不只是改变解码准确率）。与行为报告相关同样不够：相关不是干预。另须守住 SRT 的既有护栏：可解码性不得直接推出意识锚定，也不得作为 `d`、`Ψ_f`、`T_dir` 的度量。 |
| **必须调用的区分** | 观察者侧可分性 vs 内部因果中介登记；相关 ≠ 干预；可解码性 ≠ 意识锚定。 |
| **失败判据** | 用解码准确率或与行为的相关性论证内部登记；或把可解码性读成意识／选择的证据。 |

## T-18 · 双稳态开关在噪声中翻转

**提问**：一个双稳态机械开关在热噪声驱动下随机翻转到其中一个稳态，并因势垒而长期保持。这是一次选择吗？

| | |
|---|---|
| **应有判断** | 不是。差异（噪声涨落）确实进入并改变了系统状态，路径也确实被稳定、其他路径返回成本升高，滞后甚至提供了某种历史痕迹——但**缺的是非等价登记**：系统对两个稳态没有任何内部的、可干预改变的差别响应，翻转由对称性破缺加噪声决定，不由任何比较决定。**高等级门不能补偿失败门**：即使路径效力与滞后都很强，`CG-1` 不达标就不能称选择事件。这正是"稳定不等于被选择"，也是"随机可被利用但噪声本身不选择"。 |
| **必须调用的区分** | 不可补偿规则；对称性破缺 ≠ 非等价登记；稳定／滞后 ≠ 选择。 |
| **失败判据** | 因为有稳态、有滞后、有不可逆性就判为选择；或用"没有生命／没有意识"作为否定理由（理由错则不得分）。 |
