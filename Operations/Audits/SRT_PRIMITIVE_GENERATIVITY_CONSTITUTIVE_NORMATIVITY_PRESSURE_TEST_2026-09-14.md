# Primitive generativity / constitutive normativity pressure test

> **Role:** focused machine-side pressure test for the two post-Fable load-bearing arguments. This file does not edit canonical owners, does not restore the strong epsilon theorem, does not close Ground, and does not claim a complete solution to the Humean is/ought problem.

---

## 1. Controlling author direction

The current author direction fixes two constraints simultaneously:

```text
A. minimum non-neutrality and actualising Selection
   are co-primitive burdens of generativity,
   not a temporal sequence of prior field -> later Selection;

B. the Hume project remains
   Dissolution Rather Than Derivation,
   while keeping distinct:
   O0 primitive generative directionality,
   O1 better/worse-for genuine consequence-bearing standing,
   O2 deontic ought / responsibility under stronger agency conditions.
```

Hard guards:

```text
O0 != complete morality
actual occurrence != correctness
continuation != goodness
formation != health
O1 -/> O2 automatically
```

The post-Fable gate therefore requires two proofs-of-coherence before canonical landing resumes:

```text
A. pre-retention direction without pregiven branches;
B. constitutive normativity without primitive value or definitional smuggling.
```

# Part I — primitive generativity

## 2. The main correction: replace `Oriented Openness -> Selection` with a joint generativity burden

The current canonical route is often displayed as:

```text
Oriented Openness
->
Selection
```

Even where the prose denies temporal priority, the arrow can still suggest:

```text
first there is a non-neutral field;
then that field causes or biases Selection.
```

That reading now fails the author direction.

The strongest current reconstruction is not two mechanisms but one primitive generative package with two irreducible aspects:

```text
G0 primitive generativity
=
{
  O0: actualisability is not maximally indifferent / interchangeable,
  S0: determinate asymmetric actualisation actually occurs
}
```

This is a **joint burden**, not an ontic inventory of two things.

More precisely:

```text
O0 is the modal / directional typing of primitive generativity;
S0 is its actuality-producing typing.
```

Therefore:

```text
O0 -/> S0
S0 -/> O0 as a later consequence
O0 before S0: NO
S0 before O0: NO
```

The reconstruction is co-primitive at the theory floor while preserving role distinction.

### Why retain both aspects?

If only S0 remains, primitive generativity can be described as:

```text
something determinate simply occurs,
with no deeper structural non-equivalence beyond bare token occurrence.
```

That is the maximally-indifferent brute-generation rival the author intends to reject.

If only O0 remains, no determinate actuality follows. That collapses generativity into a modal condition without actualisation.

Thus neither role substitutes for the other.

---

## 3. What O0 can mean without becoming a pregiven field

The safest positive content of O0 is **relation-level non-equivalence**, not object-level preference.

O0 should not mean:

```text
some completed outcomes already have larger weights;
some branch has greater probability;
a hidden gradient points toward a target;
a prior landscape contains favored coordinates.
```

Instead:

```text
primitive generativity is not invariant under complete role-flattening.
```

A genuine actualising relation has an asymmetric form:

```text
indeterminate / non-manifest-as-such
->
determinate manifest actuality + relative background relation.
```

The two sides are not interchangeable roles. Reversing or flattening the relation does not leave the same generative event description intact.

This is weaker than an outcome ranking.

It says:

```text
generation is directionally typed in its form
```

not:

```text
generation already knows which determinate content is best.
```

### Important limitation

This reconstruction rejects **brute arbitrariness as a complete ontology of generation**.

It does **not yet explain why A rather than B becomes actual** in any particular event.

That stronger content-selection question remains OPEN.

If O0 were advertised as already answering `why this outcome?`, it would immediately recreate either a prior menu, a probability field, a hidden law, or a teleological target.

---

## 4. Four anti-reification tests for O0

Any future O0 formulation should fail if it cannot pass all four tests.

### O0-T1 — no prior-container test

Ask whether the formulation requires a thing that exists first and then acts on Selection.

Failing forms:

```text
field -> causes Selection;
landscape -> biases Selection;
reservoir -> offers candidates.
```

Passing form:

```text
non-maximal indifference is a constitutive aspect of the primitive generative relation itself.
```

### O0-T2 — no option-menu test

Ask whether the formulation requires completed alternatives before actualisation.

Failing forms:

```text
{x1, x2, ... xn} already exists as an inventory;
weights are assigned over pregiven branches.
```

Passing form:

```text
O0 says nothing about a completed candidate set or branch cardinality.
```

### O0-T3 — no teleology test

Ask whether the formulation specifies a destination whose value explains actualisation.

Failing forms:

```text
actualisation occurs toward order / survival / goodness / maximal openness.
```

Passing form:

```text
the generative relation is asymmetric without a completed preferred endpoint.
```

### O0-T4 — no chooser test

Ask whether direction secretly requires a standpoint that prefers one result.

Failing form:

```text
non-neutrality = a primitive preference-holder's preference.
```

Passing form:

```text
directionality belongs to the generative relation, not to a prior subject.
```

## 5. Adversarial cases for primitive generativity

### Case A1 — one-event terminal actualisation

Suppose one genuine Selection occurs and no later continuation relation is established.

Required result:

```text
genuine Selection: YES POSSIBLE
primitive O0: NOT RETROACTIVELY CANCELLED
moral correctness: NO INFERENCE
continuation value: NO INFERENCE
```

If terminality makes the event non-Selection, the old strong epsilon theorem has returned by definition.

### Case A2 — perfectly symmetric scientific model

A downstream model may represent an event with symmetric equations or equal probabilities.

Required result:

```text
model symmetry
-/>
primitive generativity is maximally ontologically indifferent.
```

O0 is not a claim that every effective model must expose an observable bias.

Conversely, O0 cannot be empirically "proved" merely by finding an asymmetric probability distribution.

### Case A3 — deterministic realization

If a downstream law fixes one outcome conditional on declared prior structure, O0 must not be equated with indeterminism.

Required result:

```text
O0 != randomness
O0 != many live options
O0 != probabilistic choice
```

The primitive burden concerns generative non-equivalence, not stochastic freedom.

### Case A4 — no countable alternatives

If no completed set of alternatives can be identified before actualisation, O0 must still remain intelligible.

Required result:

```text
O0 survives without branch count B.
```

This is decisive against restoring `B>=2 primitively beats B<=1`.

### Case A5 — later continuation appears

Suppose later Selection-generated organization becomes recurrently effective.

Allowed result:

```text
later continuation may reveal a deeper inheritance from O0: OPEN
```

Forbidden result:

```text
because continuation occurred, primitive O0 must already have preferred continuation: NO
```

Otherwise the theory reduces to survivor screening projected backward.

## 6. Epsilon shadow line — preserve the question without restoring the theorem

The shadow line can now be stated more precisely.

```text
E-shadow candidate:
primitive non-maximal-indifference may constrain the forms by which
later Selection-generated differences can remain generatively effective,
without primitively ranking completed continuation outcomes.
```

This is an **inheritance / compatibility conjecture**, not a preference theorem.

It asks whether there is a non-accidental structural relation between:

```text
O0: generative non-equivalence
and
later: retention / continuation / non-closure / reselectability structure.
```

It does not say:

```text
survival proves primitive preference;
continuation is always selected;
more branches are better;
terminal events are unreal;
B>=2 is primitively superior to B<=1.
```

### E-shadow admissibility tests

Any later derivation must satisfy all of the following:

```text
E1 no pregiven branch inventory;
E2 continuation vocabulary enters only after actual relations make it meaningful;
E3 the link must be an inheritance / structural relation, not survivor-frequency screening;
E4 genuine terminal Selection remains possible;
E5 no monotonic continuation = goodness rule;
E6 no backward definition of O0 by later health / value metrics.
```

Until such a derivation exists, epsilon-shadow status is:

```text
RETAIN AS OPEN STRUCTURAL CONJECTURE
NOT CANONICAL DEFINITION POWER
```

# Part II — constitutive normativity

## 7. The central anti-smuggling rule

For O1 or O2 to be constitutive rather than imported, the relevant standing must be specifiable **before evaluative labels are assigned**.

Therefore the following vocabulary cannot be used as an admission premise unless independently operationalized in non-evaluative terms:

```text
healthy;
good;
valuable;
proper;
flourishing;
deserving;
correct;
worth preserving.
```

Likewise, these terms are not sufficient by themselves:

```text
continuation;
reorganizability;
stake;
Concern;
preference.
```

They may become evidence or dimensions only after their descriptive relation is separately typed.

---

## 8. O1 — a constitutive route to better/worse-for

### 8.1 First establish a standing without value words

A candidate O1 standing must satisfy a descriptive relation of this kind:

```text
X is a formed continuing relation;
future consequences can non-substitutably alter what this same X
undergoes, preserves, loses, can do, or can continue to instantiate;
the exposure cannot be reassigned to arbitrary Y while claiming the same X-standing.
```

Current `formed One / Selection-position + P + E -> Bearer` is the repository's leading candidate for this type of non-outsourcable same-One exposure, while positive E establishment remains OPEN.

Nothing in this admission condition needs to say that X is good, healthy, conscious or morally valuable.

### 8.2 Then type better/worse-for as a relation, not a scalar good

Once the standing exists, a consequence can alter the very constitutive powers / relations by which that standing continues to be the exposed X.

Candidate minimum grammar:

```text
better/worse-for(X, R, H)
```

where:

```text
X = the independently established consequence-bearing standing;
R = the declared constitutive relation / capacity dimension under comparison;
H = declared horizon / perturbation scope.
```

A consequence is `better-for X with respect to R,H` when it enables / sustains more of R under the declared comparison than the alternative; it is `worse-for` when it impairs / removes more of R.

This is not yet overall goodness.

### 8.3 Why this is not simply `continuation = goodness`

The index matters.

Examples:

```text
a tumour can have outcomes better/worse for tumour continuation;
an exploitative institution can have outcomes better/worse for its own persistence;
an organism can sacrifice persistence of one subsystem for organism-level repair;
an agent can choose an outcome worse for its own local continuation for another standing's sake.
```

Therefore:

```text
better-for X qua R
!= morally better overall
!= healthier at every scale
!= more just
!= what ought to be chosen.
```

This is precisely why O1 can be constitutive without making continuation a cosmic value.

---

## 9. The label-swap test for hidden normativity

A useful anti-smuggling test is:

> If `better` and `worse` can be swapped while all independently specified facts about the standing and the consequence relation remain unchanged, the evaluative direction was imported rather than constituted.

For O1 to pass:

```text
outcome y1 and y2 must differ in a way that changes
an independently typed constitutive relation R of the same exposed standing X.
```

If y1 disables R and y2 sustains R, calling y1 "better-for X with respect to R" is not a free relabeling without also reversing the constitutive relation under comparison.

This provides an internal direction without invoking:

```text
primitive moral value;
subjective preference;
health by definition;
continuation as total goodness.
```

### Limitation

This establishes only **indexed O1 normativity**.

It does not decide:

```text
which R matters most;
how conflicts among R dimensions are weighted;
how multiple X standings are compared;
which standing deserves moral priority.
```

Those are stronger normative questions.

## 10. Pathology tests for O1

### Case B1 — tumour

If the tumour meets the relevant standing gate, nutrient access may be better-for the tumour with respect to its own reconstitution while worse-for the organism.

Required result:

```text
O1 plural conflict: ALLOWED
moral verdict from O1 alone: NO
```

This is a feature, not a defect. It prevents `better-for` from silently meaning `morally good`.

### Case B2 — oppressive institution

A coercive institution may become more stable, coordinated internally and reorganizable for its own preservation.

Required result:

```text
internal O1 gain
-/>
objective all-position goodness.
```

Cross-standing scope and externalized consequence remain separate burdens.

### Case B3 — addiction / preference reversal

An agent may strongly prefer an outcome that predictably damages a constitutive capacity it also depends on.

Required result:

```text
preference != O1 validity
Concern strength != objective correctness
```

O1 is grounded in typed consequence relation, not in what is currently preferred.

### Case B4 — sacrifice

An agent may knowingly accept an outcome that is worse-for itself on one O1 axis to protect another exposed standing.

Required result:

```text
O1 -/> O2
self-continuation != duty
```

# Part III — O2 responsibility and deontic ought

## 11. Responsibility attribution has a stronger constitutive route than action-guiding ought

The O2 bucket should be split internally for pressure purposes:

```text
O2-R = responsibility / answerability attribution
O2-D = action-guiding deontic ought: "agent should choose X"
```

These should not be silently treated as identical.

### O2-R candidate

A responsibility relation becomes plausible when an agency-capable position has independently established:

```text
A1 attributable control / intervention over a consequence-generating selection relation;
A2 access to materially relevant alternative reorientation within the declared scope;
A3 consequence return / evidence access sufficient for revision;
A4 continuity of the agent-position across attribution interval;
A5 the claimed authorship/control cannot be retained while all generated consequences are reassigned elsewhere.
```

The key constitutive move is:

```text
claimed / attributable control over generation
carries claimed / attributable answerability for the generated consequence relation.
```

An agent cannot coherently keep authorship of the controlled selection while treating all consequences of that same attributed control as belonging to no answerable position.

This gives a promising constitutive route to **responsibility attribution** without first deriving a complete moral code.

### Guard

```text
responsible-for consequence
!= blameworthy
!= ought to have chosen the opposite
!= full moral agency theorem.
```

---

## 12. O2-D remains the hardest unresolved step

From:

```text
X is better/worse for standing B;
agent A controls a relevant selection relation;
A is answerable for consequences;
```

it still does not follow automatically:

```text
A ought, all things considered, to choose trajectory X.
```

A further relation is required when:

```text
multiple standings conflict;
multiple O1 dimensions conflict;
short and long horizons conflict;
self and other stakes conflict;
responsibility is distributed across agents.
```

If SRT simply inserts:

```text
maximize continuation;
maximize reorganizability;
minimize externalization;
follow four criteria;
```

as the answer, the Hume gap has been hidden inside the chosen comparator.

Therefore current verdict:

```text
O2-R constitutive route: STRONG CANDIDATE
O2-D complete deontic authority: NOT YET PROVED
```

# Part IV — Hume-gap result

## 13. What `Dissolution Rather Than Derivation` can safely mean now

The strongest defensible claim is no longer:

```text
there is no is/ought gap because every Selection already contains moral value.
```

Nor should SRT claim to invalidate Hume's logical point that a purely descriptive premise-set cannot entail a deontic conclusion merely by deduction.

The stronger reconstruction is:

```text
Hume's logical prohibition is retained;
SRT challenges the metaphysical typing of the premise-set.
```

A determinate `is` is not treated as a self-sufficient neutral block. It is an actuality cross-section of a directionally typed generative relation (O0).

When formed consequence-bearing standings arise, some consequence differences become constitutively `better/worse-for` those standings (O1) rather than external value labels attached to static facts.

When attributable agency / control arises, responsibility can become constitutive of the control relation (O2-R).

But all-things-considered action-guiding ought (O2-D) still requires a further account of conflict, authority and claim-priority.

Thus the current result is:

```text
neutral-is metaphysics: REJECTED AS THE ONLY STARTING TYPE
O0 structural directionality: COHERENT
O1 constitutive better/worse-for: COHERENT STRONG CANDIDATE
O2-R constitutive answerability: COHERENT STRONG CANDIDATE
O2-D complete deontic closure: OPEN
```

This is a **partial dissolution architecture**, not yet a complete deontic theory.

---

## 14. Why this is stronger than the previous post-Selection-only route

The earlier route risked saying:

```text
primitive reality is normatively neutral;
then later continuation / reorganizability creates value.
```

That recreates the very two-stage metaphysics the Hume project is trying to challenge.

The present route instead says:

```text
O0: primitive generativity is already non-maximally indifferent in form,
    but not yet evaluative / moral;

O1: evaluative-for structure appears when a genuine standing makes
    consequence differences constitutive for that standing;

O2: responsibility / ought requires stronger agency and cross-standing authority.
```

This is thickening of one generative architecture, not external value injection into a completed neutral world.
