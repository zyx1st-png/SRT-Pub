## 2. Mature rival 1 — latent-cause / state-structure learning

### 2.1 Gershman, Norman & Niv (2015)

Their structure-learning problem is explicitly **not** ordinary value update over a fixed supplied state space.

Source-native problem:

```text
when a surprising experience occurs,
should it be absorbed into a familiar category / state,
or should a new latent cause / state be postulated?
```

They describe reinforcement learning as depending on a state representation whose structure is generally **not supplied to the brain**. The learner must discover an appropriate state representation from interaction with the environment; latent-cause inference is proposed as one framework for this state discovery.

Reference:

- Gershman, S. J., Norman, K. A. & Niv, Y. (2015). *Discovering latent causes in reinforcement learning*. Current Opinion in Behavioral Sciences 5:43-50. DOI `10.1016/j.cobeha.2015.07.007`.

Machine-side payment:

```text
F1 differentiability / state-availability change: STRONG
F2 grouping / partition reorganization: STRONG
F3 manifestation basis: PARTIAL
F4 future consequence: STRONG
```

Reason:

```text
experience can change which observations are treated as belonging to the same state,
and whether an additional latent state is created at all.
```

This already undercuts any claim that mature reinforcement learning always assumes a permanently fixed candidate/state partition.

### 2.2 Wilson, Takahashi, Schoenbaum & Niv / task-state line

The broader task-state literature makes the same pressure explicit: effective learning depends on how the agent represents the current task state, and state representation itself is learned / inferred rather than always given.

This does not establish an ontology prior to objects, but it pays a large fraction of the functional claim:

```text
history changes what later counts as the operative state / context for learning.
```

## 3. Mature rival 2 — representation learning changes the feature basis

### 3.1 Radulescu, Shin & Niv (2021)

The review's central question is not only:

```text
what should be learned?
```

but:

```text
how do we learn which features of experience are worth learning about?
```

The review emphasizes that attention and memory constrain representations toward goal-relevant features and that the representations themselves are inferred from experience with each task.

Reference:

- Radulescu, A., Shin, Y. S. & Niv, Y. (2021). *Human Representation Learning*. Annual Review of Neuroscience 44:253-273. DOI `10.1146/annurev-neuro-092920-120559`.

Machine-side payment:

```text
F1 effective differentiability change: STRONG
F2 comparison organization: MODERATE / STRONG
F3 basis change: STRONG
F4 later consequence: STRONG
```

The relevant pressure is that learning can change **which features become behaviorally and computationally operative**, not only the value assigned to already fixed options.

### 3.2 Category learning and dimensional modulation

Category learning can stretch representations along category-relevant dimensions and shrink them along irrelevant dimensions; related human imaging work reports corresponding changes in visual cortical representations.

Reference:

- Folstein, J. R., Gauthier, I. & Palmeri, T. J. (2015). *Category Learning Stretches Neural Representations in Visual Cortex*. Current Directions in Psychological Science 24(1):17-23. DOI `10.1177/0963721414550707`.

This is stronger than scalar choice-weight adjustment:

```text
same physical stimulus space
-> learned task structure
-> different effective discriminability geometry
```

Therefore an R2* criterion based only on relevant-dimension gain/loss is already neighbor-paid.

## 4. Mature rival 3 — conceptual / relational reorganization

Mack, Love & Preston (2016) study how the same objects can be reorganized under changing conceptual goals. Successful learning in different classification tasks requires attention to different features; hippocampal object representations reorganize with the changing conceptual structure.

Reference:

- Mack, M. L., Love, B. C. & Preston, A. R. (2016). *Dynamic updating of hippocampal object representations reflects new conceptual knowledge*. PNAS 113(46):13203-13208. DOI `10.1073/pnas.1614048113`.

Pressure paid:

```text
F2 relational organization change: STRONG
F3 effective basis change: STRONG
F4 later organization consequence: STRONG
```

This source still begins with already identifiable stimuli / objects, so it does not pay the author's **pre-object** placement. But it blocks the weaker claim that ordinary cognitive learning can only reweight a fixed representation while leaving relational organization unchanged.

## 5. Mature rival 4 — neural manifold and dynamical reorganization

### 5.1 Gurnani & Cayco-Gajic (2023)

Their review emphasizes that task learning can reshape:

```text
neural manifold geometry
representation dimensionality
orthogonal task-relevant dimensions
dynamic modes
attractor landscape
```

Reference:

- Gurnani, H. & Cayco-Gajic, N. A. (2023). *Signatures of task learning in neural representations*. Current Opinion in Neurobiology 83:102759. DOI `10.1016/j.conb.2023.102759`.

This matters because the realization-side consequence of learning need not be representable as one scalar weight vector. The effective geometry and dynamical flow structure can reorganize.

### 5.2 2026 primate PFC geometry result

A recent primate study tracks learning of a novel XOR structure across sessions. Early PFC activity is high-dimensional and randomly mixed; with learning, population activity becomes lower-dimensional and task-relevant structure emerges. When new stimulus combinations are introduced, representations reorganize so new and familiar conditions align along a shared axis.

Reference:

- *Learning shapes neural geometry in the primate prefrontal cortex*. Nature Neuroscience (2026). DOI / metadata to be logged separately if this source enters Pipeline 1; here it is used only as a current source-native pressure anchor.

Machine-side payment:

```text
F1 dimensional / discriminability change: STRONG
F2 geometry reorganization: STRONG
F3 basis / axis change: STRONG
F4 later generalization consequence: STRONG
```

Again, this is not an ontological proof. It shows that mature neuroscience already treats learning as changing representational geometry and dynamical organization rather than merely adjusting one visible choice weight.

## 7. What the composite still presupposes

```text

an observation or sensor interface
an input domain
an objective / relevance signal / task
an inference or learning architecture
already available physical variables or representational substrate
```

Representation learning can discover effective features from lower-level inputs, but a computational architecture, input stream and learning objective / prior remain specified.

This is a genuine scope difference.

```text

```

At present it is primarily an ontological-placement difference.
