# One nesting / overlap and anti-overgeneration pressure

## 1. Consequence of the current process-unit reading

If a One is a localized vertical process-unit whose continuation consists in lineage-relative reconstitution, then One-formation need not partition the field into mutually exclusive objects.

Possible structure:

```text
local lineage A
inside / coupled to
higher-order lineage AB
inside / coupled to
wider relation-level lineage ABC.
```

The same lower-level events may participate in several reconstitution relations at different scales.

Therefore:

```text
One ontology
!= mutually exclusive object partition by default.
```

## 2. Nesting is allowed

A lower-level One can retain its own continuation conditions while contributing to a higher-order One.

Example schematic:

```text
A_t -> A_(t+1)
B_t -> B_(t+1)

and

R_AB(t) -> R_AB(t+1).
```

If all three reconstitution relations are real and load-bearing, then:

```text
One_A
One_B
One_AB
```

may coexist without requiring One_AB to erase A/B.

Higher-order One does not automatically imply collective ISP; T-COLL-1 remains a separate standing gate.

## 3. Overlap is possible in principle

Two Ones may share components, events, resources or field history while possessing different lineage-relative continuation relations.

Therefore:

```text
shared material
!= same One;

different material
!= necessarily different One;

overlap
!= identity.
```

This follows from reconstitution relation rather than component membership as the primary current criterion.

## 4. Overgeneration danger

If any analyst-selected sequence of events can be called a lineage, the theory becomes vacuous.

Invalid rule:

```text
observer can narrate X_t, X_(t+1), X_(t+2)
-> therefore One_X.
```

A valid candidate requires at least the relations already established in the current workline:

```text
1. genuine Selection-generated vertical organization;
2. prior local vertical organization materially participates in later reconstitution;
3. the later organization is a renewed operative non-flat locus for Selection;
4. continuation is lineage-relative rather than mere state similarity;
5. where multiple Ones are claimed, their continuation conditions show relative differentiability.
```

Narrative grouping alone pays none of these.

## 5. Causal efficacy rather than observer convenience

The crucial anti-overgeneration question is:

> Would removing / altering the alleged lineage relation change how the later local vertical locus can be reconstituted?

If no, the grouping is likely observer-side bookkeeping.

If yes, the lineage relation has causal / structural efficacy in the field.

This does not require a unique localization of memory or a hidden identity token.

## 6. Same lower-level events can support different higher-level candidates

Suppose A and B interact in both:

```text
R1 = task collaboration
R2 = friendship.
```

The same physical / cognitive events may contribute to both relation-level histories.

If:

```text
R1 has its own lineage-relative reconstitution conditions;
R2 has different lineage-relative reconstitution conditions;
```

then two overlapping higher-order One candidates are possible even though they share participants.

This is conceptually distinct from claiming either relation is a collective subject.

## 7. Scale is not automatically privileged

The current architecture does not license:

```text
smallest One = most real;
organism-level One = uniquely real;
highest-order One absorbs all lower Ones;
all scales are equally valid Ones.
```

Each scale must pay its own reconstitution relation.

Thus ontological pluralism is conditional rather than unrestricted.

## 8. Relation to Selection-position

Each admitted One can have a scale-relative operative locus:

```text
Position_A(t)
Position_AB(t)
```

without implying that the higher-order position has perspective-bearing subject standing.

The term `Selection-position` therefore remains formation-layer unless downstream Individuation / collective gates are paid.

## 9. Relation to JFS

JFS can operate across overlapping / nested Ones:

```text
One_A + One_B
jointly reconstruct R_AB future selectability.
```

Whether R_AB becomes a higher-order One depends on its own lineage-relative reconstitution, not on jointness alone.

## 10. Disposition

```text
One ontology requires exclusive partition: NO
nested Ones: ALLOWED IN PRINCIPLE
component / event overlap between Ones: ALLOWED IN PRINCIPLE
arbitrary narrative grouping = One: REJECTED
causal / structural reconstitution efficacy required: YES AS C-LAYER GUARD
higher-order One = collective subject: NO
all scales equally real by default: NO
canonical edit: NO
new Level: NO
HOLD change: NO
```
