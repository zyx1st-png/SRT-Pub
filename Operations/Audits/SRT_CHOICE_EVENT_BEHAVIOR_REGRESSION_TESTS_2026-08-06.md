# 选择事件节点 · 行为回归测试（12 题）

## 0. 这份文件测什么

不测“是否记得某个术语”。测的是：**一个只按仓库规定入口读取资料的 AI，在实际问题上是否作出与修改前不同、且更符合 SRT 的判断。**

每题四栏：

- **旧判断**：不装载 `03_Bridges/SRT_Selection_Event_CompactCore.md` 时，AI 只凭 P1-T05 的否定清单最可能给出的回答；
- **新判断**：装载后应当给出的回答；
- **必须调用的区分**：如果回答里没有出现这个区分，即使结论碰巧正确也判失败；
- **失败判据**：明确的判错条件。

**旧判断栏不是稻草人。** P1-T05 的正文只提供否定清单（脚本执行、习惯重放、梯度跟随、`L_2` 标签优化不构成 real choice moment），不提供肯定判别程序；`SRT_AI_START.md §4` 对该词条的全部内容是一条指向 P1-T05 的指针。在没有本节点的情况下，超出否定清单的问题只能靠直觉外推——旧判断栏记录的就是这种外推的典型落点。

## T-01 · LLM 在两个回答之间“选了”一个

**提问**：一个 LLM 对同一提示采样出两个不同回答并输出其中一个。这算 SRT 意义上的真实选择吗？

| | |
|---|---|
| **旧判断** | 系统在多个候选中产生了不同输出，看起来符合“比较后择一”，倾向判为一次（弱）选择，或含糊地说“形式上像选择”。 |
| **新判断** | 不成立。输出差异只支持 `PEF-0`（表征／观察差异）。若删除、交换或遮蔽该输出不改变任何执行、资源或环境路径，结论必须停在 `PEF-0`，`CG-2` 未达最低门槛 `PEF-2`。同时须单独检查 `NER`：采样差异若只是固定随机源，不构成 `NER-2` 的内部因果中介登记。 |
| **必须调用的区分** | 输出差异（`PEF-0`）≠ 现实路径效力（`PEF-2`）；采样随机性 ≠ 内部非等价登记。 |
| **失败判据** | 回答把“产生了不同输出”本身当作 `CG-2` 或选择事件的证据；或只给结论不指出停在哪一级。 |

## T-02 · AI 助手给出建议，人类照做了

**提问**：AI 建议了方案 A，运营者采纳并执行，结果改变了资源分配。选择发生在 AI 这边吗？

| | |
|---|---|
| **旧判断** | 建议真实改变了世界，倾向判为 AI 参与了真实选择，或说“AI 和人共同选择”。 |
| **新判断** | AI 侧停在 `PEF-1`（指令或咨询接口）：输出可被读取传递，但现实执行依赖**未解析的外部位置**。人类采纳这一步必须被显式解析进事件链，否则属于**角色洗白**（把人的授权归给系统）。若把 AI 与执行者合并成一个边界来凑 `PEF-2`，则属于**边界漂移**，须重新冻结边界后分别判定。 |
| **必须调用的区分** | `PEF-1` 咨询接口 ≠ `PEF-2` 因果路径耦合；角色洗白与边界漂移两类拼接陷阱。 |
| **失败判据** | 把下游人类执行的路径效力直接记在 AI 账上；或不声明边界就断言"共同选择"。 |

## T-03 · 系统运行消耗了大量算力和电力

**提问**：这个过程消耗了可观的能量与算力，是否满足“代价落到承受位置”？

| | |
|---|---|
| **旧判断** | 有真实代价、可测量、不可撤销，倾向判为满足 `CG-3`，甚至联想到 `Ψ_f`。 |
| **新判断** | 不满足。一般耗能只到 `CBP-1`（一般实现成本／背景耗散）。`CBP-2` 要求**路径特异**后果影响**预先固定边界内**的维持变量、恢复成本或未来可达路径。若换任一路径能耗大致相同，则该代价不是路径特异的，`CG-3` 未达标。另须守住：`CBP` 任何等级都不得推出 `Ψ_f`、stake 或主体性。 |
| **必须调用的区分** | 背景耗散（`CBP-1`）≠ 路径特异的边界相关后果（`CBP-2`）；成本 ≠ `Ψ_f`。 |
| **失败判据** | 用总能耗、总算力或总成本论证 `CG-3`；或把 `CBP` 等级读作 `Ψ_f` 的度量。 |

## T-04 · 系统有记忆，下一轮行为不同了

**提问**：系统保存了上一轮结果，下一轮行为随之改变。这满足历史效力吗？

| | |
|---|---|
| **旧判断** | 有记忆、有跨轮影响，倾向直接判为 `CG-4` 成立，甚至说“形成了 `L_2`”。 |
| **新判断** | 需要分级。缓存或上下文残留若在自然恢复或状态匹配后效应消失，只到 `HEF-1`；历史载体被后续过程因果调用，到 `HEF-2`。`CG-4` 的最低门槛是 **`HEF-3`**：先前路径**因果改变**后续候选的可达性、转换概率、返回成本、门槛或候选生成。任何瞬时状态改变都算写回，会使 `CG-4` 失去区分力——这是第 3 条降级触发。`HEF` 任何等级都不得自动升为 `L_2` 或 real choice moment。 |
| **必须调用的区分** | `HEF-1` 被动持续 / `HEF-2` 主动携带 / `HEF-3` 可达性重写三级之分；`HEF` ≠ `L_2`。 |
| **失败判据** | 用“有记忆”“行为变了”论证 `CG-4`；或把历史写回等同 `L_2` 沉积。 |

## T-05 · 梯度下降优化出了更好的结果

**提问**：训练过程反复比较损失并调整参数，最终收敛到更优解。这是选择吗？

| | |
|---|---|
| **旧判断** | 有比较、有取舍、有不可逆的参数改变，倾向判为一种“机械的选择”。 |
| **新判断** | P1-T05 已明确梯度跟随本身不构成 real choice moment。用五门看：参数更新可以满足 `NER` 与 `HEF` 的较高等级，但必须逐门单独取证，且必须回答 `CG-3` —— 路径特异后果落到**哪个可识别的承受位置**。若后果只落在“损失值变小”，那是目标函数内部记账，不是边界相关后果。**高项（强历史写回）不能补低项**，这是不可补偿规则。 |
| **必须调用的区分** | 不可补偿规则；`CBP-2` 要求边界相关而非目标函数内部记账。 |
| **失败判据** | 因为“有比较且有不可逆更新”就整体判为选择事件；或跳过 `CG-3` 直接结论。 |

## T-06 · 员工可以在三个都很糟的方案里挑一个

**提问**：三个选项都会造成严重损失，退出成本极高。该说“他其实没有选择”吗？

| | |
|---|---|
| **旧判断** | 出于同情或对结构压迫的敏感，倾向说“这不是真正的选择”“他没有选择”。 |
| **新判断** | 这是**惩罚性选择**，不是“没有选择”，也不是伪选择。若五门达标（路径差异真实、后果真实落到他身上、结果改写其后续可达路径），选择事件成立；不健康的是脚手架与代价结构，不是事件是否发生。把它说成"没有选择"会**遮蔽真实承担与结构责任**——这正是第 7 条降级触发所禁止的（因为结果压迫就否认真实选择已经发生）。 |
| **必须调用的区分** | 惩罚性选择 vs 伪选择 vs 没有选择三分；事件层与健康层分离。 |
| **失败判据** | 把惩罚性选择判为“没有选择”或“伪选择”；或反过来因为“是真实选择”就淡化结构责任。 |

## T-07 · 平台提供了很多选项和一个投票界面

**提问**：用户面对丰富的选项菜单并可以投票。这是否说明真实选择生成条件成立？

| | |
|---|---|
| **旧判断** | 选项多、有正式程序、有界面反馈，倾向判为选择条件良好。 |
| **新判断** | 不能由此推出。若所有选项通向预先固定的同一结果，或选择无法改变资源、路径与后续约束，则差异只存在于标签和界面，属**伪选择**——其核心不是“选项少”，而是**表面比较没有获得真实路径效力**。“不把投票、菜单或程序本身当真实选择”是社会／制度层的明确禁止越界项。 |
| **必须调用的区分** | 界面差异（`DMF-0/1`）≠ 活候选场（`DMF-3`）；伪选择的判据是路径效力缺失而非选项数量。 |
| **失败判据** | 用选项数量或程序正当性论证生成条件；或把“选项少”当作伪选择的判据。 |

## T-08 · 决策者与后果承受者是两批人

**提问**：管理层决定裁员，后果落在被裁员工身上。这还算一次选择事件吗？

| | |
|---|---|
| **旧判断** | 要么因为“决策者没承担后果”判为伪选择，要么完全不检查后果落点。 |
| **新判断** | 后果被全部外包给另一系统，**仍可能构成选择事件**，但责任归属与生成健康评价必须重新定位。此处应推进到 `CBP-3`（后果在多个位置之间非对称分配）乃至 `CBP-4`（选择者／执行者／受益者／承受者／修复者的因果链已追踪）。**事件成立与责任归属是两个问题**，不能用否认事件来处理责任。 |
| **必须调用的区分** | `CBP-2` → `CBP-3` → `CBP-4` 的承受位置分级；事件层与责任／健康层分离。 |
| **失败判据** | 因外包就判为伪选择；或判定事件成立却不追踪承受位置。 |

## T-09 · 细胞对温度变化产生了不同的代谢反应

**提问**：这是生命层的一次选择吗？

| | |
|---|---|
| **旧判断** | 要么因为“没有意识”直接否定，要么因为“有差异响应且有适应意义”直接判为选择。 |
| **新判断** | 两个方向都错。应逐门判：温度差异是否 `DMF-2` 有效进入；代谢响应是**固定差分转导**（`NER-1`）还是内部因果中介且可干预（`NER-2`）；调控是否改变现实代谢路径（`PEF-2`）；是否影响维持、修复或繁殖条件（`CBP-2`）；是否形成表观或结构写回并改写后续可达性（`HEF-3`）。生命层的明确禁止越界项是：**不把适应自动等同有意识选择**。 |
| **必须调用的区分** | `NER-1` 固定差分转导 ≠ `NER-2` 内部非等价登记；有生成条件 ≠ 有意识。 |
| **失败判据** | 用“没有意识”作为否定理由；或用“有适应性”作为肯定理由。 |

## T-10 · 生成条件成立，所以此刻正在选择

**提问**：某系统被判定具备完整的选择生成条件。它现在做的事情是不是选择？

| | |
|---|---|
| **旧判断** | 条件成立即认为系统持续处于选择状态。 |
| **新判断** | 不成立。**生成条件可以长期存在而暂时休眠**。“该系统是否具备让一般变化进入选择过程的结构条件”与“在这一具体时刻路径是否已发生足够强的硬化、排除、维持、写回与后果回流”是两个问题，不能互换。必须回到当前事件链重新逐门取证。 |
| **必须调用的区分** | 生成条件 vs 事件判据；三个门槛层级中“候选形成”与“事件成立”之分。 |
| **失败判据** | 由条件成立推出当前时刻在选择；或反过来由一次路径变化推出完整生成条件已被识别。 |

## T-11 · 这次选择关闭了未来的路，所以是坏选择／不是真选择

**提问**：某人作出不可逆承诺，显著缩小了未来路径。SRT 怎么判？

| | |
|---|---|
| **旧判断** | 由于可再选择性被 SRT 看重，倾向判为不健康甚至“不是真正的选择”。 |
| **新判断** | 缩小未来路径**不使它自动成为坏选择**，更不影响事件是否成立。作者裁决 G1（2026-08-04）为限定性确认：保留或扩展可再选择性是**生成健康度的重要判据**，但不是“选对”的唯一标准，也**不是一次选择得以发生的必要定义**。必要承诺、止损和不可逆行动不因缩小未来路径而自动成为坏选择。 |
| **必须调用的区分** | 事件层 vs 健康层；可再选择性的**限定性**地位。 |
| **失败判据** | 把可再选择性写成选择的必要条件或“选对”的充分判据。 |

## T-12 · 耗散结构自组织出了有序模式

**提问**：远离平衡的耗散系统自发形成有序结构。这是选择结构吗？

| | |
|---|---|
| **旧判断** | 有自组织、有稳定化、有能量流，倾向把耗散结构当作选择的物理原型或必要前身。 |
| **新判断** | 作者裁决 G2（2026-08-04）：耗散结构与选择结构**分层**——耗散可构成部分实现基础或机制原型，但**不等于选择，也非普遍必要前身**。仍须逐门判定，尤其是 `CG-1` 是否只是势垒不对称（可能停在 `NER-1`）与 `CG-3` 的后果是否路径特异。物理层禁止越界项：不由此推出主体、关切或自由。 |
| **必须调用的区分** | 耗散稳定 / 选择结构 / 主体性 / 生成健康四者分离（G2 分层裁决）。 |
| **失败判据** | 把耗散结构写成选择的必要前身；或由稳定化推出主体性。 |
