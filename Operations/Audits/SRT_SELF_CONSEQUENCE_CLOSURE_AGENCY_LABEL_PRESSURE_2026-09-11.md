# Self-consequence closure — pressure before assigning an agency label

## 1. Why a new primitive is not yet needed

The current architecture already distinguishes:

```text
One
-> Bearer
-> self-consequence closure candidate
```

without needing to decide immediately whether the last relation is `Agency` by definition.

Working relation:

```text
SC(O):
Selection through O's operative position P_t
-> consequence q
-> q becomes history-bearing for O
-> q changes later reconstitution of P_(t+1).
```

This is stronger than generic Bearer because:

```text
source of q
and
Bearer of q
```

converge on the same independently admitted One-lineage.

But the label `agency` remains under pressure.

## 2. Why generic action-feedback is too weak

Weak loop:

```text
output
-> environment change
-> sensor input
-> new output.
```

This can occur in ordinary control without durable history-bearing rewrite.

Therefore:

```text
action-feedback != SC(O).
```

SC requires:

```text
q materially alters the organization from which the same One later continues Selection.
```

## 3. Why SC is still not automatically full agency

Even when SC is paid, mature agency theory pressures further dimensions such as:

```text
self-defined individuality;
interactional asymmetry / modulation of coupling;
normativity / adaptivity;
spatiotemporal organization.
```

Current SRT should not absorb those into `SC` by vocabulary alone.

Thus safe status:

```text
SC = agent-like / thin-agency candidate relation
!= full theory of agency.
```

## 4. Case pressure

### A. ordinary thermostat

```text
output affects room;
room affects sensor;
next output changes;
no durable history-bearing rewrite of selectable organization.
```

Disposition:

```text
feedback: YES
SC: usually NO / not established
agency: not inferred.
```

### B. adaptive controller

```text
action
-> outcome
-> retained adaptation / controller reconfiguration
-> later action-selection organization differs because that outcome occurred.
```

Disposition:

```text
Bearer pressure: possible
SC: possible / live
thin-agency label: plausible but not forced
ACTIVE Selection: separate question.
```

### C. living cell / autonomous organism

Mature autonomy / enactivist accounts already strongly pay:

```text
individuality;
adaptive coupling;
activity consequences feeding back into organization;
continued self-maintenance.
```

Disposition:

```text
SC: strongly plausible realization family
agency: neighbor-paid in mature theory
SRT novelty: not inferred.
```

### D. resettable executor

```text
action causes external q;
q / cost closes elsewhere;
executor restored without q-conditioned later reconstitution.
```

Disposition:

```text
causal efficacy: YES
SC: NO / weakened
agency standing under current typed relation: weakened.
```

### E. reinforcement-learning agent

```text
action
-> reward / error
-> parameter update
-> later policy changes.
```

Possible:

```text
SC: YES if the same admitted One bears the update as its history.
```

But:

```text
SC != ACTIVE Selection automatically.
```

Ordinary credit assignment / policy reweighting may remain within an achieved selectable organization.

### F. niche-construction / active organism

```text
O acts
-> modifies environment / relation field
-> altered environment returns as later condition of O
-> O's future selectability changes.
```

Possible:

```text
SC: YES
ACTIVE Selection: possible where the organization determining future selectability is reconstructed.
```

This is strongly neighbor-paid and not an SRT-local novelty claim.

### G. subjectless / distributed selectable-space reconstruction

A pre-subject process can, under current author direction, actively construct non-flat selectable organization without a paid same-One SC loop.

Disposition:

```text
active selectability construction: possible
SC / agency: not established.
```

This is a key negative control against `ACTIVE Selection = agency`.

## 5. Three layers now preferable to one agency word

Until further author adjudication, use:

```text
B — generic bearing:
q from any source -> later reconstitution of O.

SC — self-consequence closure:
Selection_O -> q -> later reconstitution of O.

AS — Active Selection mode:
Selection acts on / reconstructs the organization determining later selectability.
```

Then distinguish:

```text
B without SC:
One bears consequences but those consequences need not originate from its own Selection.

SC without AS:
One's own Selection consequences change its later organization,
but mainly inside / for preservation of an achieved selectable organization.

AS without SC:
selectability can be reconstructed without an established same-One self-consequence loop.

SC + AS:
strong active-agency candidate:
One's own Selection consequences participate in reconstructing
its organization of future selectability.
```

## 6. Passive agency becomes coherent

This split yields an important non-obvious case:

```text
SC = YES
ACTIVE mode = NO
```

The system can act, bear its own consequences, learn, repair and regulate while its dominant ontological function remains preservation of an achieved One / selectable organization.

Machine label:

```text
maintenance agency / passive-agency candidate.
```

This does not mean behavioral inactivity.

## 7. Active agency becomes a conjunction, not a stage

Strong candidate:

```text
SC(O)
+
ACTIVE Selection on Phi_O
```

where machine-only `Phi_O` means:

> the organization whose current state helps determine what can become selectable for O later.

Then:

```text
Selection_O
-> consequence / intervention
-> Delta Phi_O
-> later Selection proceeds under reconstructed selectability organization.
```

This is stronger than:

```text
state update;
policy weighting;
ordinary error correction;
behavioral adaptation alone.
```

But no unique implementation is implied.

## 8. Relation to subjecthood

Do not import stake or phenomenality into thin agency.

Keep:

```text
SC / agency-like closure
!= subject-position
!= concern domain
!= experiencer.
```

The existing non-jump owner remains useful precisely because a strong historical controller can exist without a licensed subjecthood inference.

## 9. Current verdict

```text
new Agency primitive required: NO
self-consequence closure as typed relation: RETAIN
self-consequence closure = full agency theorem: NO
self-consequence closure = thin / agent-like candidate: LIVE
feedback = SC: NO
RL update = ACTIVE Selection: NO
SC + PASSIVE mode: COHERENT
SC + ACTIVE mode: STRONG active-agency candidate
ACTIVE Selection = agency: NO
subjectless active construction: remains possible / scope-sensitive
subjecthood or phenomenality inferred: NO
canonical edit: NO
new Level: NO
scientific distinctiveness: NOT ESTABLISHED
```

## 10. Next pressure

The next issue should not be `is SC agency?` in the abstract.

A more productive question is:

> **When SC is already present, what exactly must be reconstructed for the transition from maintenance/passive agency to active/creative agency — current state, policy, boundary, continuation criteria, relation-level constraints, or the organization that generates future selectability?**

That question directly reuses the author's accepted ACTIVE Selection threshold and can be pressure-tested without adding a new primitive.
