# Osako et al. 2026 — framework routing and owner-subtraction audit

> **Role**: route the supplied Osako et al. primary paper into the active Neuroscience Reconstruction Framework and test whether it earns any new SRT theoretical or scientific increment after internal-owner and generic-dynamics subtraction.
>
> **Source boundary**: source-side claims are limited to the user-supplied *Nature Neuroscience* paper. SRT mappings below are repository-side analysis.
>
> **No promotion by adjacency**: conceptual fit with One/Bearer/Selection-position language is not evidence for those SRT constructs.

---

## 1. Source result in one bounded statement

The source supports a task-specific neural architecture in which:

```text
stimulus representation can be reused across epochs / context
+
memory-maintenance computation can be reused across different contents
+
functional subpopulations can contribute selectively to those computations
+
module interaction can matter for RNN task performance
+
training history can bias the geometry of the reusable representation
```

The source does **not** establish:

```text
natural bearer identity
One formation
history ownership
same-unit consequence closure
primitive Selection
subjecthood / phenomenality
```

## 3. Internal owner subtraction

### 3.1 NEURAL18 / Posani subtraction

Existing NEURAL18 already owns the critical guard:

```text
decodability / representational geometry
!= causal use
!= behavioral anchoring
!= consciousness / subjecthood
```

Osako adds a useful complementary pressure:

```text
functional clustering can become more visible
under a task demanding flexible input-output mapping
```

but this does not reverse NEURAL18. The joint reading is:

```text
high separability without clean clustering: possible
cleaner functional clustering in some task / region regimes: also possible

therefore:
clustered vs distributed organization is task / region / scale sensitive
and neither side by itself establishes anchoring or bearer identity
```

Disposition:

```text
new decodability theorem: NO
new anchoring criterion: NO
new cluster->bearer rule: NO
objectification guard strengthened: YES
```

### 3.2 Cycle 1 subtraction

Cycle 1 already retired the tested route in which state-encoded history and stable writeback are treated as an independent SRT-specific Bearer-genesis discriminator after ordinary recurrent-learning absorption.

Osako raises the ordinary baseline further:

```text
training history
-> current coding geometry
-> reusable computation / later behavior
```

is reproduced inside ordinary RNN learning.

Therefore the following are not recoverable as Cycle-1 novelty from this source:

```text
history changes present neural state
history changes later behavior
history shapes reusable representation
recurrent organization preserves task-relevant memory
```

The only Cycle-1-relevant residual remains the already-recorded genetic question about whether same-unit consequence bearing participates in Bearer formation. Osako does not test that residual.

Disposition:

```text
Cycle-1 retired history-localization Level-2 route: REMAINS RETIRED
Cycle-1 Level-1 genetic reinterpretation: UNCHANGED
new scientific discriminator: NO
```

### 3.3 Cycle 2 subtraction

Cycle 2 retains a narrow ontology/dependency ordering around primitive subjectless Selection, foreground/background differentiation and later Selection-position / One formation.

Osako demonstrates mature scientific mechanisms for:

reusable computation
modular interaction

Therefore:

```text
reusable functional module
!= primitive bearerless Selection
!= emerging Selection-position
!= ontological One
```

Disposition:

```text
Cycle-2 Level-1 dependency consolidation: UNCHANGED
Cycle-2 Level-2: HOLD
ordinary modular-recurrent neighbor pressure: STRENGTHENED
```

## 4. Strongest generic-baseline pressure

For the questions this source actually touches, the strongest immediate scientific baseline is not a special SRT mechanism but ordinary learned recurrent computation with task-dependent population geometry and reusable modular structure.

The source itself demonstrates this baseline by showing that data-constrained RNNs can:

```text
reproduce relevant neural dynamics
show module-specific perturbation effects
show inter-module dependency
reproduce training-history bias in coding geometry
```

Accordingly, any future SRT neuroscience claim involving:

```text
history-shaped neural geometry
reusable computation
functional modularity
cluster specialization
```

must first survive this ordinary recurrent-network baseline before being considered for Level 2.

---

## 5. What the paper usefully forbids SRT from saying

The paper creates strong negative controls against several shortcuts:

```text
same content -> same bearer
same computation -> same bearer
same functional cluster -> same One
repeated use -> history ownership
history-shaped geometry -> Selection sedimentation
behavioral relevance -> consequence ownership
cluster-specific RNN lesion -> animal bearer mechanism
```

These forbidden equivalences are a real gain even though they are not a new positive SRT mechanism.

---

## 6. Surviving theory question after subtraction

The best surviving SRT-facing question is not whether reusable modules exist. They do.

It is:

> When content, instantaneous state, and even implementation membership can vary while a computation remains reusable, what additional relation would justify counting later operations as belonging to the same continuing historical bearer / Selection-position rather than merely to the same functional computation class?

This is a legitimate N1/N2/N6 question generator.

It is **not yet** a Level-1 increment earned from Osako, because existing Cycle 1/2 and bearer owners already contain much of the burden.

---

## 7. Level-2 consequence test

Current source does not supply a prospective disagreement of the form:

```text
ordinary reusable recurrent computation predicts X
SRT bearer / One relation independently predicts Y
```

No matched manipulation in the paper separates:

```text
same reusable computation
same current neural geometry / performance capacity
but different consequence ownership / bearer relation
```

Therefore no Level-2 route is earned here.

A future route, if ever proposed, must first specify a non-circular bearer / consequence relation and then show a prospective difference beyond ordinary network state, learning history, task geometry and modular recurrence. Do not build a toy merely to manufacture this difference.
