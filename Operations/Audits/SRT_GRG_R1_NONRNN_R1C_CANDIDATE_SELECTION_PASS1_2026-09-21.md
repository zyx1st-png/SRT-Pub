# GRG-R1 non-RNN R1c candidate-selection audit — Pass 1

## 0. Gate entering this pass

~~~text
R1a retained imprint = diagnostic / insufficient
R1b maintained scaffold = candidate generative organization
R1c causal re-entry = minimum causal core
R1d prospective transfer = stronger downstream burden

toy decoder route = not R1c
toy spectral route = R1a PASS / R1c NULL
new RNN spectral tuning = STOP
O4 = BLOCKED
new experiment = HOLD
~~~

The task is not to pick a theory winner. It is to select one bounded, genuinely different domain realization for the next source/protocol feasibility pass.

## 1. Candidate requirements

A candidate must satisfy all:

1. non-RNN / genuinely different realization;
2. source-native R1b maintained organization already identifiable;
3. source-native R1c perturbation / intervention route exists;
4. maintenance provenance can be typed;
5. GRG burden split changes the pre-result control design;
6. no R1d / transfer target needed;
7. candidate can fail without redefining GRG-R1.

## 2. Candidate family considered

### HKB human bimanual coordination dynamics

Source-native structure:

~~~text
component limb dynamics
-> relative-phase coordination
-> externally varied control parameter changes stability
-> mechanical perturbation
-> relaxation / transition dynamics
~~~

The domain includes both theoretical and empirical perturbation work.

### Other self-organization families

Physical order-parameter systems and generic coupled-oscillator models remain available as later realization families.

They are not rejected.

They are not selected in this pass because the present goal is specifically to move beyond another purely formal/model realization while retaining a tractable, source-native perturbation interface.

This is an execution-routing decision, not a novelty or superiority ranking.

## 3. Candidate decision

~~~text
NEXT REALIZATION CANDIDATE = HKB / BIMANUAL COORDINATION DYNAMICS
~~~

Selection is bounded to protocol/access feasibility.

No experiment is authorized by this verdict.

## 4. Why HKB satisfies the gate

### Different realization

PASS.

It is a human behavioral / neuromuscular coordination paradigm rather than a trained recurrent network.

### R1b source-native organization

PASS for candidate routing.

Relative phase is explicitly proposed as a collective/order parameter and has stable coordinative regimes.

### R1c perturbation route

PASS for candidate routing.

Mechanical perturbation followed by relative-phase relaxation is an existing source-native measurement strategy.

### Maintenance provenance

PASS / MIXED.

The coordinated relation is maintained by the coupled organismic system under externally imposed pacing/instruction conditions. The experiment perturbs but does not continuously clamp relative phase.

### GRG-added pre-result distinction

PASS.

The R1 burden split forces the future design to separate:

~~~text
component state
control parameter
maintained coordination O
perturbation operator
relaxation / transition consequence
~~~

This prevents cycling frequency, relative phase and perturbation from being collapsed into one generic "order" variable.

## 5. Key new pressure on GRG-R1

HKB removes historical sedimentation from the center of the problem.

The relevant chain is:

~~~text
ongoing coupling
-> maintained relational organization
-> perturbation
-> later relaxation / transition
~~~

Therefore the minimum R1c grammar should not require a stored historical trace.

A better programme reading is:

~~~text
formation may be historical OR continuously regenerated;
what matters for R1c is that O is maintained during the relevant process
and re-enters / constrains later transitions.
~~~

This is a research-level refinement, not a canonical edit.

## 6. Future protocol must pay a stronger causal guard

Mechanical perturbation acts on physical components, not on a metaphysically isolated macro variable.

Therefore a future protocol must distinguish:

~~~text
generic component displacement
vs
coordination-specific perturbation of relative phase
~~~

and must track component amplitudes / frequencies so that a relaxation effect is not automatically attributed to the collective variable.

The existing Post frequency/amplitude work is directly relevant to this control burden.
