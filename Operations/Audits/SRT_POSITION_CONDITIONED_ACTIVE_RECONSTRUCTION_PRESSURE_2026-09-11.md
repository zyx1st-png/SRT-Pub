# Position-conditioned W2 reconstruction — when is structural change Active Selection from a formed One?

## 1. Author-owned starting correction

The author has explicitly corrected an observer-first framing:

```text
participant / first-person active Selection
-> constitutes / maintains selectable relation or order
-> third-person observable stability is downstream readout.
```

Here `first-person` is licensed only in the thin sense:

> **position-indexed endogenous participation in Selection from within a formed selective centre, not verbal introspection or consciousness.**

The present audit asks how to state that participation for W2-level reconstruction.

## 2. Structural change is not automatically O-indexed Active Selection

Suppose wider field condition `q` changes a formed One O.

Weak shape:

```text
q
-> V_O changes
-> later selectability differs.
```

Even if the change reaches W2 depth, this only shows:

```text
vertical organization changed.
```

It does **not** yet show:

```text
O actively Selected the reconstruction from its formed position.
```

Therefore:

```text
W2 structural change
!= O-indexed Active Selection by itself.
```

## 3. Current machine candidate — position-conditioned W2 efficacy

For a formed One O with operative Selection-position `P^O_t`, an O-indexed Active episode requires at least:

```text
1. O is independently admitted as a continuing One;
2. P^O_t is the current operative non-flat locus of O;
3. a reconstruction pressure / opportunity presents non-equivalent continuation relations;
4. Selection through P^O_t materially participates in which relations are manifested,
   supported, suppressed, reopened or excluded;
5. that Selection-mediated differentiation is load-bearing in W2-level reconstruction;
6. later Selection proceeds under the reconstructed vertical organization.
```

Machine phrase:

> **position-conditioned W2 reconstruction**

or shorter:

> **from-where efficacy**

Both are audit labels only, not primitives.

## 4. What `from-where efficacy` does not mean

Do not identify it with:

```text
internal cause;
spatially internal processing;
conscious intention;
self-model;
verbal choice;
central controller;
causal isolation;
self-caused initiating disturbance.
```

The Selection-position may be materially distributed and environmentally scaffolded.

The trigger may be external.

The burden is:

```text
the formed position is causally load-bearing in how reconstruction is selectively organized.
```

## 5. Four-way pressure

### F0 — imposed rewrite

```text
external q
-> directly replaces / deforms V_O
-> O's current position makes no material difference to which W2 organization results.
```

Disposition:

```text
structural change: YES
bearing: possible if q becomes O-history
O-indexed Active Selection: NOT ESTABLISHED.
```

### F1 — structurally channelled but non-selective response

```text
q
-> existing material / dynamical constraints channel one response
-> V_O changes
```

Current position matters causally, but no stronger Selection-mediated manifestation / relative-background relation has yet been shown.

Disposition:

```text
position-conditioned dynamics: YES
O-indexed Active Selection: PRESSURED / not automatic.
```

This is an important anti-overgeneration guard against calling every adaptive material an active selector.

### F2 — position-mediated W2 reconstruction

```text
q / opportunity
-> non-equivalent reconstruction continuations are available at O's current position
-> Selection through P^O_t differentially manifests / supports some continuations
   and relatively backgrounds / suppresses others
-> the resulting differentiation reconstructs the organization of later selectability
-> O continues from the changed vertical organization.
```

Disposition:

```text
O-indexed Active Selection: STRONG MACHINE CANDIDATE.
```

No conscious intention is required.

### F3 — self-consequence + position-mediated W2

```text
Selection through P^O_t
-> q
-> q returns to O
-> P^O / O-history mediates a W2 reconstruction
-> later selectability organization changes.
```

Disposition:

```text
self-consequence closure: YES candidate
O-indexed Active Selection: YES candidate
combined active-agency-like closure: STRONGER candidate.
```

Still not subjecthood or phenomenality.

## 6. Why F1/F2 is the hard boundary

A purely mechanistic critic can always say:

```text
P_t is just part of current causal state;
q + P_t -> V_(t+1).
```

SRT should not respond by denying ordinary dynamics.

The current ontology-side distinction is instead typed:

```text
F1:
current structure channels change;

F2:
the formed Selection-position participates in a Selection relation
that differentially organizes non-equivalent reconstruction continuations,
and this differentiation is constitutive of the later W2 organization.
```

This is an explanatory / dependency distinction, not a claim that F2 violates physical causality.

Scientific distinctiveness remains unestablished.

## 7. Counterfactual pressure — no hidden observer

Machine-side test:

Keep wider field pressure `q` approximately matched while varying the current lineage-conditioned Selection-position organization.

Ask:

> Would the W2 reconstruction differ because the from-where differs, not merely because a detached observer labels the outcome differently?

If changing `P^O_t` while preserving the broader perturbation changes which continuation relations are supported / suppressed and which W2 organization emerges, then:

```text
from-where efficacy pressure strengthens.
```

This is not a new experiment authorization and not an operational Level claim.

## 8. Relation to first-person author correction

The first-person correction can now be read structurally:

```text
first-person / position-indexed
!= introspection;

first-person / position-indexed
= later order is constituted through Selection from formed positions
  whose own vertical organization is load-bearing in the selective reconstruction.
```

Thus third-person stable order remains:

```text
readout / evidence
```

rather than the ontological source of the positioned Selection.

## 9. Bearer is neither necessary nor sufficient for the broadest Active ontology

### Bearer not sufficient

A Bearer can carry q into its history while only undergoing W1 / maintenance-level update.

```text
Bearer: YES
Active W2: NO.
```

### Bearer not universally necessary for all constitutive Selection

Pre-subject Selection may actively construct verticality before Bearer formation.

Therefore:

```text
Active selectable-space construction
-> Bearer
```

is not a universal implication.

But for **formed-One O-indexed Active Selection**, One / P standing is required by definition of the indexed claim.

## 10. Relation to self-consequence closure

Self-consequence closure answers:

```text
who caused q and who later bears q?
```

Position-conditioned W2 answers:

```text
from which formed position is the organizational reconstruction selectively constituted?
```

They can combine but neither entails the other.

This yields:

```text
Bearer + F2
= active response to a borne external consequence;

SC + F2
= self-consequence active reconstruction;

F2 without SC
= active reconstruction triggered by external / relation-level conditions;

SC without F2
= maintenance / passive-agency-like closure.
```

## 11. Relation to JFS

At relation level, let A and B be formed positions.

```text
P_A + P_B
-> positioned Selections
-> jointly load-bearing in W2 reconstruction of V_AB
```

This gives a sharper JFS candidate:

> **multiple from-wheres are jointly constitutive of the relation-level reconstruction that changes their later selectability.**

Still:

```text
JFS != collective One
JFS != collective Bearer
JFS != collective ISP.
```

This is machine-side compression, not canonical ontology.

## 13. Edge cases

### Rock deformed by pressure

```text
structural change: YES
formed One under current SRT gate: case-dependent
position-mediated selective W2: not established by deformation alone.
```

### Adaptive material

If current structure changes its response / future reachability under stress:

```text
W2-like dynamics: possible
F1 vs F2: live pressure
```

Do not deny Active Selection merely because substrate is non-biological; do not grant it merely because material adapts.

### Organism under external injury

```text
external q can be borne;
organism's formed position can selectively reorganize repair / behavior / future continuation organization;
F2 possible;
self-caused q not required.
```

### Institution under external law

```text
law simply replaces rules with no institution-mediated selective reconstitution:
F0/F1-like.

institutional positions interpret / select / reorganize roles, rules and continuation conditions:
F2-like pressure.
```

No collective subjecthood follows.
