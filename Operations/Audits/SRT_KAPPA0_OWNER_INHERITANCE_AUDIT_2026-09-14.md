> **Role:** determine what burden `κ₀` can still carry after the author accepted a thinner pre-object L0 whose minimum non-flatness is only `non-maximal-indifference`. This is a noncanonical owner audit. It does not edit `T-L0-Kappa0`, MA-1/MA-2, the symbol table, d-value owners, Ψ_f owners, or any canonical file.

---

## 1. Controlling boundary

Current accepted minimum:

```text
Oriented Openness
= umbrella for:
  non-nothing
  non-total-closure / non-exhaustion
  non-maximal-indifference

none of these derives primitive actualisation.
```

The independent review further narrows non-maximal-indifference to a second-order burden:

```text
maximal structural interchangeability is false,
without yet positing pregiven relata, coordinates, metric, manifold,
gradient, ranking, probability distribution, or value map.
```

Therefore the audit question is not whether κ₀ must be deleted. It is:

```text
Which κ₀ roles remain legitimate as stronger formal / realization burdens,
and which roles can no longer define the minimum pre-object ontology?
```

# 4. Role-by-role disposition

## K1 — universal primordial Riemann-curvature lower bound

Current shape:

```text
exists κ₀ > 0 : R(L0) >= κ₀
```

Disposition: **ROUTE / DEMOTE FROM MINIMUM-DEFINITION AUTHORITY**.

Reason:

The thinner L0 intentionally refuses to specify completed coordinates, manifold structure, metric, or geometry at the minimum pre-object level. A universal Riemannian identity therefore carries substantially more structure than the accepted minimum.

This does not prove the geometric model false. It means the inference:

```text
non-maximal-indifference
therefore
universal Riemannian curvature κ₀
```

is not licensed.

Strongest safe current reading:

```text
where a declared geometric realization of pre-object non-flatness is used,
κ₀ > 0 may encode a nonzero structural-asymmetry floor.
```

A future owner decision would be required to retain κ₀ as universal ontology rather than formal realization.

---

## K2 — geometric witness of non-flatness

Disposition: **KEEP AS STRONGER REALIZATION CANDIDATE**.

This is the κ₀ role most compatible with the new minimum.

Safe relation:

```text
κ₀ > 0
may witness / realize
non-maximal-indifference
within a declared geometric representation.
```

Unsafe relation:

```text
non-maximal-indifference
iff
κ₀ > 0 universally.
```

The witness relation is one-way unless future work establishes representation-independence.

---

## K3 — direction / bias field for Selection

Disposition: **KEEP ONLY AS REALIZATION-LEVEL STRUCTURE; NARROW UNIVERSAL LANGUAGE**.

A geometric model may use κ₀ to express unequal realization costs / trajectories.

But the minimum L0 must not say:

```text
pre-object reality already contains determinate directions / paths / regions
before a stronger representation has supplied those relata.
```

Thus phrases such as:

```text
κ₀ provides directionality bias for all selection operators
```

need future owner calibration.

Safer:

```text
κ₀ encodes non-equivalence among realization directions in models
where such directions are formally defined.
```

This preserves formal utility without back-defining the pre-object minimum.

## K5 — κ(t) initial condition / anti-total-closure floor

Current role:

```text

```

Disposition: **SPLIT**.

Two different burdens are currently combined:

```text
(a) history-dependent geometric state evolution
(b) metaphysical non-closure / non-exhaustion
```

The new L0 accepts (b) independently at the minimum modal level. Therefore κ₀ is no longer required as the definition of non-closure.

Possible retained role:

```text

κ₀ may provide a positive floor for that model's curvature variable.
```

Not licensed:

```text
without κ₀, metaphysical non-closure itself disappears.
```

`T-L0-NonStatic` should therefore be considered a future `L0^rel / formal realization` routing target rather than the unique metaphysical ground of openness.
