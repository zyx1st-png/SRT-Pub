## 2. Source-native mature pressure

### 2.1 Khona & Fiete 2022 — attractor / integrator networks

Source:

- Mikail Khona & Ila R. Fiete (2022), “Attractor and integrator networks in the brain,” *Nature Reviews Neuroscience* 23:744–766. DOI `10.1038/s41583-022-00642-0`.

Source-native mature role family:

```text
simple / forgetful units
-> collective persistent activity states
-> working memory
-> error correction
-> noisy-cue integration
-> low-dimensional continuous-attractor dynamics
```

This matters for P4 because attractor dynamics are defined partly by return / correction toward the attractor manifold after perturbation rather than exact microstate preservation.

### 2.2 Ring-attractor / head-direction family

Supporting mature literature describes:

```text
recurrent ring architecture
-> localized persistent bump
-> bump remains in the absence of current sensory input
-> self-motion / velocity input updates bump location
-> current bump acts as the internal reference from which the next update proceeds
```

Relevant examples:

- Khona & Fiete 2022 review above;
- 2024 *Nature Neuroscience* work on maintaining and updating continuous variables with small neural populations;
- broader head-direction / ring-attractor reviews.

The important audit property is not biological realism. It is that the currently formed locus is not merely passively present: later state transitions are computed **relative to its current position on the manifold**.

### 2.3 Dynamic Field Theory — self-sustaining peaks as decisions / working-memory loci

Mature DFT literature uses local excitation + lateral inhibition to form localized activation peaks that can:

```text
represent a selected feature / item
persist without the initiating input
suppress competing inputs
update toward another item under subsequent input
move autonomously between stable states
```

Some DFT implementations add Hebbian learning. Those are **not** admissible for the clean `not S_H*(SED-B)` candidate unless the learning layer is disabled / excluded during the audited interval.

The relevant fixed-dynamics result is narrower:

```text
current recurrent field dynamics can maintain a localized selected state
and mediate later competition / update transitions relative to it.
```

## 4. P2 — endogenous locus formation

Audit question:

> Is the particular locus supplied as the only fixed location by the modeller, or can one among multiple equivalent loci form dynamically?

Result:

```text
PASS at audit-proxy level
```

Reason:

A translation-invariant / ring attractor can support a continuum of equivalent bump locations. The architecture hard-codes the **space of possible loci**, but not one unique realized locus. Symmetry breaking, noise, initial conditions or non-unique transient input can select the current bump.

Therefore:

```text
pre-specified manifold / law
!= pre-specified realized locus
```

This is sufficient for the deliberately weak `P*_endo` audit criterion.

Important limit:

```text
underlying neurons / field boundary / interaction law remain pre-specified
```

So this is endogenous formation of a **higher-level locus**, not preindividual genesis of every underlying unit.

## 5. P3 — recurrent causal origin

This was the main unpaid condition in Pass 1.

Audit question:

> Do later transition / competition / update events repeatedly issue relative to the formed locus, or is the bump only a static memory mark?

### 5.1 Ring-attractor result

A ring attractor does more than retain orientation:

```text
current bump location
+ angular-velocity / self-motion input
-> next bump location
```

The next state transition depends on the present localized state. Repeated updates proceed relative to the current bump rather than being recomputed from a stateless external lookup.

### 5.2 Dynamic-field result

In fixed-dynamics DFT regimes, a self-sustaining peak can:

```text
stabilize one selected item
suppress incompatible / competing inputs
remain open to later update
transition to a different stable state under continued / changed input
```

This is closer to the audit's “selection-like / competition / update” requirement than passive persistence alone.

Result:

```text
PASS — NARROW at audit-proxy level
```

Why only narrow:

- the relevant transitions are state updates / competition dynamics;
- calling them full SRT `Selection` would beg the question;
- the audit requires only a rival-admitting selection-like causal role.

Thus P3 is paid for the machine proxy, not for canonical SRT identity.

## 6. P4 — re-identification

Audit question:

> Can the locus be re-identified after noise / perturbation / component variation by its causal role rather than exact microstate identity?

Attractor models are explicitly used for error correction and persistent low-dimensional state maintenance. The relevant identity is not exact neuron-by-neuron microstate equality but return / continuation on the same attractor manifold or functionally equivalent localized state.

For the audit proxy:

```text
perturb state off the manifold / bump center
-> recurrent dynamics restore or continue a localized attractor state
-> later update rule again operates relative to that state
```

Result:

```text
PASS — NARROW at audit-proxy level
```

Guard:

This does not establish numerical identity, bearer continuity or historical identity. It pays only causal-role re-identification within the locked attractor model.
