# Facing reconstruction Pass A — FRH-0: L0-facing continuity reduction test

> **Role:** first target in the v0.2 bounded Facing reconstruction pass.
>
> **Boundary:** machine audit only. No canonical owner is edited. Exact Selection anti-tautology, One identity, branch / merge attribution and formed Orientation remain OPEN.

## 0. Question

Test the corrective hypothesis:

~~~text
"L0-facing continuity"
?=
O0 non-preclosure
+ Selection-mediated recurrent reconstitution / One-side historical efficacy
+ formed Selection-position / operative locality.
~~~

The purpose is subtractive: retain a distinct term only if this decomposition leaves a real residual burden.

## 1. Source typing

~~~text
K1 = Spine §2: O0 = Selection reality is not exhausted by completed actuality and is not fully preclosed.
K2 = Spine §2.1: Selection occurrence != retained historical efficacy != sedimentation != generative inheritance; terminal Selection remains genuine.
K3 = Spine §4: history = prior Selection remaining materially effective in later Selection conditions where established.
K4 = Spine §5 / One Formation §2: One requires recurrent Selection-mediated reconstitution; ordinary path dependence is insufficient.
K5 = One Formation §3 / Spine §6.2: Selection-position is the time-local operative from-where of an already formed One.
A0-Q = author intuition: the source of L0-facing continuity feels like primitive Selection.
A1 = earlier machine compression: renewed genuine generativity through Position transformation.
A0-P/A1 corrective = primitive Selection is source of renewed generativity; recurrent history / One supplies localization / continuation burden.
~~~

## 2. FACE-L0

Canonical burden already present:

~~~text
O0
= no determinate actuality exhausts Selection reality;
= no already-given outcome structure fully precloses generation.
~~~

This pays the part of the candidate that said:

~~~text
the next determination is not exhausted by retained L1/L2 structure;
generation is not merely execution of a completed geometry.
~~~

Important negative result:

~~~text
O0 by itself
!= continuation;
!= persistence;
!= One;
!= requirement that another Selection occurs.
~~~

Terminal Selection remains compatible with O0. Therefore the L0-facing part contributes **renewed / non-preclosed generativity when Selection occurs**, not cross-time continuity.

## 3. FACE-L1

At primitive strength:

~~~text
S0 / L1-facing
= current actualised differentiation / manifestation / relative backgrounding.
~~~

For an already formed One:

~~~text
Selection-position_t
= current operative aspect through which the formed recurrent organization participates in current Selection.
~~~

Selection-position does not itself create the cross-time continuation relation. It localizes the current participation of a One whose formation / recurrent reconstitution is already paid elsewhere.

Therefore the candidate's 'from this Position' burden is absorbed by existing Selection-position semantics, but Selection-position is **not** an independent continuity mechanism.

## 4. FACE-L2

The cross-Selection burden lies here:

~~~text
prior Selection-generated organization
-> remains materially effective in later Selection conditions
-> later Selection regenerates renewed vertical organization
-> renewed organization can again carry the conditioning role
-> recurrent non-equivalent reconstitution
-> relative continuation separability / One candidate.
~~~

This pays the candidate's claims that:

- later generation is not an arbitrary reset;
- the next generative episode belongs to a formed recurrent process rather than only sharing similarity;
- prior actualisation matters without becoming the primitive source of Selection.

Thus the One-side continuity burden is not supplied by primitive Selection occurrence. It is supplied by retained efficacy + Selection-mediated reconstitution.

## 6. Residual search

Potential residuals were tested:

### R-A — 'continuity through transformation'

This does not add a separate burden. One Formation already allows snapshot change, component replacement and non-equivalent reconstitution. Continuity is carried by the reconstitution relation, not state invariance.

### R-B — 'renewed openness after each actualisation'

This is O0 applied to later Selection. It does not require a distinct cross-time entity.

### R-C — 'this Position remains genuinely generative'

This decomposes into:

~~~text
this formed process / continuation = One;
current operative locality = Selection-position;
genuine non-preclosed generativity when Selection occurs = primitive Selection / O0.
~~~

No additional independent burden was found.

## 7. Verdict

~~~text
FRH-0 = PASS AS REDUCTION

"L0-facing continuity" as independent ontology noun
= NOT RETAINED.

Disposition:
MERGE_CANDIDATE -> RETIRE_CANDIDATE as term-of-art.

Allowed remaining use:
question / explanatory shorthand only, when explicitly unpacked into
O0 + One-side recurrent reconstitution + Selection-position.

primitive Selection
= source of renewed genuine generativity;
!= sufficient source of this-One continuity.
~~~

## 8. What remains OPEN after the reduction

This reduction does **not** solve:

- the exact criterion separating genuine Selection from merely descriptive / modelled change;
- formal necessary-and-sufficient One admission;
- exact unit / boundary;
- strict numerical identity;
- branch / merge attribution;
- whether `formed Orientation` deserves a distinct role beyond Selection-position + anticipation typing.

These are genuine owner/open problems. They must not be relabeled as residual 'L0-facing continuity'.
