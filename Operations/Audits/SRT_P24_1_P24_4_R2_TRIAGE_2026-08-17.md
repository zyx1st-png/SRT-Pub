# P24-1 / P24-4 Bounded-R2 Triage

> **Verdict:** neither P24-1 nor P24-4 currently supplies a Selection-level D2 prediction against a bounded R2 family. Both remain useful operational signatures, but neither should proceed as an SRT-superiority experiment without a new prospective incompatible prediction.

## 1. P24-1 — non-monotonic friction

### SRT shell

```text
restructuring / new path formation
-> early friction or volatility rises
-> competition / transition
-> later friction falls if a new scaffold stabilizes
```

### Frozen rival: R2-ARL

Allow a bounded adaptive representation learner with:

- fixed network / state dimension;
- frozen optimizer family;
- finite replay / memory window;
- preregistered learning-rate schedule;
- representation update under prediction / task error;
- no architecture growth after holdout begins.

R2-ARL prospectively permits:

```text
distribution / rule shift
-> transient prediction error and gradient conflict rise
-> representation / policy instability
-> later error and switching cost fall after adaptation
```

This already predicts the qualitative P24-1 curve.

### Verdict

```text
non-monotonic friction
!= D2
```

To reopen P24-1, SRT would need a preregistered quantitative feature that R2-ARL excludes: e.g. a bound, ordering, cross-condition invariance or intervention asymmetry derived independently from SRT rather than fitted after observing the curve.

No such feature is currently present in Core 24.

## 2. P24-4 — framework alters visibility / admissibility before belief report

### SRT shell

```text
framework / historical constraint changes
-> option visibility / admissibility / friction changes
-> explicit belief report may change later or not at all
```

### Frozen rival: R2-HRG

Allow a bounded history-conditioned representation / gating model with:

- fixed feature extractor family;
- history-conditioned salience / gating weights;
- fixed candidate-generator architecture;
- preregistered context inputs;
- held-out evaluation on option generation, latency and action accessibility.

R2-HRG prospectively predicts:

```text
history / context changes gating
-> different features or options enter the effective field
-> action latency / admissibility changes
-> explicit verbal report may lag the upstream representation change
```

This covers the current P24-4 observables without a Selection primitive.

### Verdict

```text
pre-belief field shaping
!= D2
```

To reopen P24-4, SRT must specify an intervention on historical constraint or position for which the frozen R2-HRG predicts no / opposite change while SRT predicts a directional change.

No such incompatible forecast is currently stated.

## 3. Combined P24-1 + P24-4 does not rescue discrimination

A tempting combination is:

```text
framework shift
-> field reorganizes before report
-> friction spikes
-> new background scaffold forms
```

But a bounded representation learner with history-conditioned gating predicts exactly that combined sequence.

Adding more co-occurring signatures does not create D2 when all signatures are consequences of the same allowed R2 adaptation machinery.

## 4. Cross-position and floor-challenge controls still help only as falsification hygiene

Cross-position / cross-interface perturbations can expose shared occlusion and prevent false claims of objectivity. Floor challenge can reveal hidden hysteresis.

These are valuable controls, but R2 families can also predict position-conditioned cost and challenge-induced reconfiguration.

Therefore they improve **measurement validity**, not current SRT-specificity.

## 5. Selection-near P24 result after RC-A

The three closest current candidates now have the same status:

```text
P24-1: operationally meaningful / R2-absorbable / no D2
P24-3: operationally meaningful / R2-absorbable / no D2
P24-4: operationally meaningful / R2-absorbable / no D2
```

Downstream P24-2 / P24-5 / P24-6 may still be worthwhile domain tests, but RC-A prevents using them to repair this primitive Selection-level gap.

## 6. Consequence for Core 24

The file `Core/SRT_Core_24_Discriminating_Predictions.md` currently says a useful prediction must state where SRT expects a different structure from neighboring theories.

Under that file's own rule, the present P24-1 / 3 / 4 formulations have not yet earned the label **discriminating** against bounded R2 rivals.

This does not mean the observations are useless or false. It means their epistemic role is closer to:

than to established discriminating predictions.
