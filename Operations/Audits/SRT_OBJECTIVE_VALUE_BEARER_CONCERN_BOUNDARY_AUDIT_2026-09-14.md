# Objective value / Bearer / Concern boundary audit

> **Role:** machine-side pressure test of where SRT can legitimately move from structural comparison to normative authority after the author relocated value away from primitive L0. This file does not define moral standing, does not modify Bearer / Concern / d / agency owners, does not establish a complete ethics, and does not authorize canonical writeback.

---

## 1. Controlling author direction

Accepted reconstruction:

```text
minimum L0
= no primitive value content

primitive Selection
= actuality-producing differentiation, not ought

post-Selection relational consequences
-> consequence return / correction topology
-> reorganizability / lock-in differences
-> scoped structural comparison
-> stronger normativity only where additional standing is paid
```

The four order-gain criteria survive only as a scoped downstream comparator:

```text
可延续 / 可协调 / 不外包 / 可再选择
```

The present audit asks:

```text
When is such a comparison merely structural?
When is it "better / worse for" something?
When does it gain normative authority?
What do Bearer, Concern / d, and agency each add?
```

# 3. N0 — purely structural consequence facts

Many claims remain objective in an ordinary structural sense without any Bearer theorem.

Examples:

```text
trajectory X eliminates later transition classes;
trajectory Y preserves more correction channels;
process A exports measurable load to process B;
a governance rule blocks feedback from affected nodes;
a system cannot revise its own candidate-generation boundary under returned error.
```

These claims can be true or false relative to a declared model / scale / horizon.

They require:

```text
identified processes / positions;
consequence topology;
time horizon;
comparison variables;
```

They do **not** require:

```text
Bearer;
Concern;
subjecthood;
consciousness;
agency.
```

Therefore SRT should keep a category:

```text
structural evaluability
```

that is upstream of normative standing.

### Guard

```text
more reorganizable structurally
!= morally better automatically.
```

A highly adaptive exploitative system can be structurally reorganizable.

---

# 4. N1 — affected-position comparison without typed Bearer

The `不外包` criterion can often detect consequence displacement before a full Bearer result exists.

For example, a model may establish:

```text
local process A gains
while costs accumulate in process B
and B has no effective feedback route into A's correction loop.
```

This is stronger than a local-performance fact.

But it still does not establish:

```text
B is a current SRT Bearer;
B has Concern;
B is a subject;
B has moral standing;
A is morally responsible.
```

Thus:

```text
externalization topology
!= moral patienthood theorem.
```

This distinction protects the four-criterion comparator from depending on unresolved Bearer admission while preventing operational externality measures from silently becoming moral verdicts.

---

# 5. N2 — from affected process to "for whom": the Bearer problem

A stronger normative claim has the grammar:

```text
this outcome is better / worse for this continuing entity;
this consequence genuinely exposes this same entity;
the cost cannot simply be reassigned while preserving the same standing relation.
```

Current canonical architecture already contains the closest typed structure:

```text
formed One / Selection-position + P + E -> Bearer
```

where `E` is same-One prospective exposure and includes a non-outsourcing consistency test.

This is highly relevant because normative stake requires more than causal impact.

Compare:

```text
causal impact:
X changes Y

stake-like exposure:
what happens can alter what this continuing One itself
undergoes / preserves / loses / can continue to do,
and the exposure is not freely reassignable while claiming the same relation.
```

The second is much closer to the grammar of `for whom`.

### Machine finding

Current Bearer architecture is the strongest available candidate for the **minimum non-outsourcable stake standing**.

However it cannot yet be declared the universal moral-standing threshold because:

```text
positive independently applicable E establishment remains OPEN;
P + E is routing / reconstruction strength, not universal cross-domain N&S theorem;
Bearer <-> Concern remains OPEN;
Bearer <-> subject / cognition / phenomenality remains OPEN.
```

Therefore safest current status:

```text
Bearer
= candidate bridge from structural consequence to genuine same-One exposure,
not yet a complete moral-patient theorem.
```

# 6. Why Concern / d should not define the admission floor for being affected

Current `d` owner defines bare `d` as a scalar summary of stake-coupled concern / irreversible-risk sensitivity and explicitly separates capacity from genuine stake coupling.

This adds important information:

```text
which dimensions are effectively coupled to this system's stake structure;
how strongly changes enter its utility / concern organization;
which consequences actually return into its later selection conditions.
```

But if Concern / d is required before an entity can count as normatively affected, SRT risks collapsing:

```text
being exposed to loss
into
already representing / weighting / integrating that loss as Concern.
```

Those are not obviously identical.

A current Bearer can, in principle, be prospectively exposed even if a mature concern representation is not established.

Current spine already blocks:

```text
Bearer -> Concern
Concern -> Bearer.
```

Therefore machine recommendation:

```text
Concern / d
should NOT be the admission criterion for all normative standing.
```

Instead it is better typed as a **stake-organization / weighting layer**:

```text
Bearer-like exposure asks:
who / what can genuinely undergo the consequence?

Concern / d asks:
which dimensions of consequence are differentially integrated
into this formed system's stake / utility organization?
```

This preserves current owner separation.

---

# 7. Concern adds endogenous valuation, not objective validity by itself

Concern matters because two consequences can have different significance for the same formed process.

But:

```text
this system strongly cares about X
```

cannot by itself imply:

```text
X is objectively good.
```

Otherwise SRT collapses value into preference / optimization target.

Thus Concern / d can contribute:

```text
endogenous stake weighting;
which consequences are non-negligible to the process;
where risk / loss / preservation differentials enter its own organization.
```

But objective normativity requires additional cross-position / cross-time / consequence-accounting tests.

Therefore:

```text
Concern
!= value validity

d magnitude
!= moral worth

d expansion
!= order gain
```

The last guard is already consistent with current d-value owner practice.

# 8. N3 — moral patient / moral agent must be separated

The strongest conceptual correction is to split two questions:

```text
Q-patient:
can this entity be genuinely exposed / harmed / benefited in a non-outsourcable sense?

Q-agent:
can this entity be held responsible for revising / choosing / bearing duties
under consequence-sensitive comparison?
```

These need not have the same gate.

Machine recommendation:

```text
Bearer-like standing is relevant to Q-patient;
agency is relevant to Q-agent.
```

Thus:

```text
no agency
-/> no normative standing
```

and:

```text
Bearer
-/> responsibility automatically.
```

This preserves the generative spine's current refusal to infer agency from Bearer or Concern.

### Consequence

A future SRT ethics should distinguish at least:

```text
normative recipient / patient-side standing
from
responsibility / duty-bearing agency.
```

No final terminology is adopted here.

# 9. N4 — inter-Bearer comparison: where the four criteria become genuinely normative

The four criteria gain stronger normative force once the comparison scope contains genuinely exposed positions / Bearers.

Then they can ask:

```text
可延续:
does the trajectory destroy the enabling conditions of exposed positions / relations?

可协调:
can multiple exposed positions continue to coexist / co-organize without one being erased as the hidden cost of another?

不外包:
does local benefit depend on pushing consequence onto exposed positions whose return channel is blocked?

可再选择:
can returned consequences revise the rules / boundaries / candidate generation that produced the harm or lock-in?
```

This is much stronger than a generic system-health test.

But it still does not produce a total ordering.

Trade-offs remain possible:

```text
more continuation but less coordination;
more local revisability but greater externalization;
more short-horizon protection but less long-horizon reselectability.
```

Therefore the natural mathematical form is likely:

```text
partial order / dominance / constraint-satisfaction relation
```

not a single universal scalar objective.

No formalism is adopted here.

# 10. Objective value as scope-indexed robustness, not view-from-nowhere

SRT needs an objectivity notion compatible with finite positionality.

Two bad extremes:

```text
A. God-view objectivism:
one complete ranking from nowhere.

B. preference relativism:
whatever a position prefers is valid for that position.
```

A stronger middle route is available.

Let a comparison declare a scope:

```text
Omega = {
  positions / candidate Bearers considered,
  scale,
  time horizon,
  interfaces,
  consequence-return channels,
  perturbation / uncertainty range
}
```

Then compare trajectories `X` and `Y` under the four axes.

A candidate notion of objectivity is:

```text
X has stronger objective comparative support than Y
when the X > Y relation remains robust
as the accounting scope is admissibly expanded,
hidden consequence channels are restored,
and omitted affected positions are incorporated,
without relying on systematic consequence externalization or irreversible lock-in.
```

This is **scope-indexed robustness under perspective / consequence-account expansion**.

It does not require a view from nowhere.

It does require that the comparison survive attempts to expose what the current position left out.

---

# 11. Why scope expansion is stronger than simple consensus

Do not define objectivity as:

```text
more observers agree.
```

Agreement can be produced by shared blindness, coercion, common L2 lock-in, or excluded affected positions.

The stronger test is:

```text
what happens to the comparison when previously omitted consequence-bearing positions,
horizons, and interfaces are made relevant to the accounting?
```

A trajectory whose apparent superiority depends on excluding affected positions is fragile under scope expansion.

A trajectory whose superiority survives broader consequence accounting has stronger SRT-objective support.

This gives objectivity a directional test without a cosmic fixed optimum.

---

# 12. Scope expansion must itself be bounded

A serious problem appears immediately:

```text
why not include every conceivable position / future / scale forever?
```

That would recreate a God-view demand and make comparison impossible.

Therefore scope expansion must be **admissible and consequence-linked**.

Candidate admission rule:

```text
include a position / horizon / interface when the compared trajectory
can make a material consequence difference to it,
or when that position's consequence can return to the compared system / relation.
```

This is a causal / exposure relevance rule, not arbitrary universal inclusion.

But exact admission conditions remain OPEN.

---

# 13. Relation to non-outsourcing

`不外包` now appears as the key guard preventing fake objectivity.

A local ranking may look excellent because it omits the positions carrying its costs.

Hence:

```text
objective comparison
requires active search for displaced consequence,
not merely aggregation over already visible participants.
```

However do not infer:

```text
all costs must be equalized;
no external effects are allowed;
all positions get veto power;
Pareto improvement is required.
```

The core burden is **accountability of consequence routing**, not universal equality.

---

# 14. Relation to reorganizability

Reorganizability supplies the correction side of objectivity.

A comparison process is stronger when:

```text
newly returned consequences can modify
its own inclusion rules,
boundaries,
weights,
candidate generation,
and repair options.
```

Thus SRT-objectivity is not merely broader accounting once.

It is potentially **self-correcting comparative architecture**.

This yields a promising distinction:

```text
static objectivity:
current comparison includes many positions

vs

generative objectivity:
comparison architecture can change when excluded consequences return.
```

The second is more aligned with the accepted post-Selection normativity direction.

---

# 15. Relation to Hume's is/ought problem

This audit still does not prove a logical derivation of `ought` from `is`.

Instead it identifies a different SRT route:

```text
once real relations create non-outsourcable exposure,
consequence return,
conflict among affected positions,
and revisability of the structures that generate those consequences,
there are objective differences in how the relation treats its own affected field.
```

The theory then proposes that these differences are normatively relevant.

That proposal remains a substantive commitment, not a logical tautology.

Therefore safest statement:

```text
SRT relocates the normativity problem from primitive cosmic value
to the structure of consequence-bearing relations;
it does not yet derive all oughts from bare facts.
```

Current machine-preferred stack:

```text

causal / successor / retention / feedback topology

N1 — structural evaluability
continuation / coordination / externalization / reorganizability
within declared scope

N2 — exposure / stake standing

"for whom can this genuinely go better / worse?"

Concern / d organizes which consequence dimensions
enter the formed system's endogenous stake structure

N4 — inter-standing normative comparison
four-criterion, scope-indexed, consequence-accounting comparison
across relevant exposed positions

who can be expected to read, revise, choose, answer for,
or deliberately externalize consequences
```

Important:

```text
N0 -/> N2 automatically
N2 -/> N3 automatically
N3 -/> N4 validity automatically
N2/N3 -/> N5 automatically
```

This is a dependency proposal, not a canonical ladder.
