# GRG distributed-neighbor extraction — Pass 1

> Role: Phase D first extraction pass after the generative-expectation second adjudication.
>
> This is not a strongest-neighbor tournament, novelty audit, Level verdict or canonical rewrite. The unit of comparison is a GRG relation / burden. A mature neighbor is useful when it pays part of that burden, exposes a missing distinction, or forces GRG to change.

## 0. Method lock

For each source family, record:

1. source-native claim;
2. generative burden paid;
3. source-specific commitments that must not be flattened;
4. provisional GRG mapping;
5. mismatch with current GRG;
6. what GRG must change if the source is correct;
7. bounded transfer candidate;
8. failure condition.

Evidence depth:

~~~
A = repository primary/full close-read or equivalent source-native record
B = strong repository reconstruction with traceable sources
C = provisional family-level extraction; primary close-read still owed
D = analogy only; do not use to freeze grammar
~~~

No whole-theory winner is selected.

## 2. Whitehead — process / concrescence / valuation

Evidence depth: B.

### Source-native claim
Whiteheadian process philosophy treats actual occasions as concrete becoming: concrescence integrates inherited data into a new actuality, with subjective form / valuation internal to the occasion; completed actuality becomes available to later occasions.

### Burden paid
- G1: actuality is a real process of determination rather than static state description.
- G3: completed actuality has later causal availability.
- partial G4: creative advance is serially conditioned.

### Commitments not to flatten
Whitehead's actual occasion is already a strong concrete unit and is tied to experiential / valuational language. GRG must not translate concrescence directly into primitive Selection or use Whitehead to erase SRT's separate One / Bearer / experiencer gates.

### GRG mismatch / revision
G1 cannot mean merely “one outcome differs from another”. It must name differential operative efficacy. G3 must specify what aspect of a prior actualisation remains causally available.

### Transfer candidate
Use Whitehead as pressure when freezing a neutral relation of prior actualisation becoming later condition, but keep unit-formation assumptions explicit.

### Failure condition
If a mapping requires every GRG actualisation to be an already unified experiential occasion, the transfer fails.

## 3. Simondon — individuation / transduction / operation-structure recurrence

Evidence depth: A.

Primary repository anchor:
Materials/2026/SRC_2026_06_11_Philosophy_Simondon_Individuation_UMinnesota.md

### Source-native claim
Individuation begins from preindividual / metastable disparity rather than a finished individual. Transduction propagates local structuration so that a formed region becomes a condition for further formation. The full close-read additionally establishes an operation <-> structure architecture, individual-milieu co-genesis, modulation, and problem-dimension restructuring.

### Burden paid
- G0 pressure: do not presuppose finished individuals or a completed option menu.
- G3: local result can alter later conditions.
- G4: operation -> structure -> later operation.
- G5: individuation produces individual + milieu rather than starting with the individual.
- G8: invention can reorganize the dimension in which a problem is resolved.
- G10: formation and later re-entry can cross levels without a second substance.

### Commitments not to flatten
Transduction != Selection. Preindividual != L0. Metastability != generic possibility. Simondon's crystal / fire examples are crucial negative controls: propagation, recurrence and self-maintenance do not establish position, bearer, perspective or consciousness.

### GRG mismatch / revision
Current G3 and G4 must stay separate:
- retained efficacy = a prior difference remains conditionally effective;
- recurrent organization = retained organization re-enters in a role that itself recurs.

G5 must add negative controls against treating every attractor / self-maintaining propagation as a formed local generative locus.

### Transfer candidate
Freeze a relation in which organization produced by prior interaction becomes an independently perturbable condition on later transition structure.

### Failure condition
If “operation -> structure -> operation” is only relabeled as GRG with no new admission / withdrawal test, the mapping is scholarship, not GRG gain.

## 4. Barad — intra-action / agential cut / constitutive exclusion

Evidence depth: B.

### Source-native claim
Agential realism rejects independently pregiven relata as the universal starting point. Phenomena / intra-actions enact boundaries and determinate separability; agential cuts generate exclusions and an exteriority-within-phenomena. Human agency is not required.

### Burden paid
- G1: determinate differentiation can be constitutive rather than passive readout.
- G2: operative distinction is coupled to exclusion / boundary enactment.
- objectification interface: measurement / apparatus cannot always be treated as neutral access to already fixed relata.

### Commitments not to flatten
Agential cut != Selection. Barad's mattering / apparatus / intra-action vocabulary has its own ontological commitments and should not be reduced to “winner versus loser”.

### GRG mismatch / revision
G2 is currently too compressed. Split its research burden:

~~~
G2a articulation / boundary enactment;
G2b excluded, supporting or background relations;
G2c whether and how that non-foreground organization remains operative later.
~~~

Barad strongly pays G2a and part of G2b. G2c requires separate source / domain evidence.

### Transfer candidate
In a domain experiment, distinguish a change caused by merely reading a fixed boundary from a change caused by the process that constitutes the boundary / effective units.

### Failure condition
If GRG claims a persisting “background” without a domain-native variable, perturbation or later consequence, the G2c mapping fails.

## 5. Enactivism / autonomy / adaptivity — positioned regulation

Evidence depth: B for repository mature-neighbor record; source-specific full close-read should be refreshed before any stronger claim.

### Source-native claim
Autonomy traditions explain self-producing / self-maintaining organization. Enactive adaptivity adds regulation relative to viability conditions: interactions are not merely externally scored but can matter relative to maintaining an autonomous organization.

### Burden paid
- G5 pressure: a relatively separable organization can maintain its own organization.
- G6: a formed organization supplies an operative, viability-conditioned from-where.
- G7c-C0: present organization can be anticipatorily regulated without requiring explicit symbolic future modelling.
- indexed normativity pressure: sense / value can arise relative to organizational viability rather than from a detached observer's reward label.

### Commitments not to flatten
Autopoiesis / adaptivity != all Selection. Viability != moral good. Self-maintenance != One / Bearer / subject automatically.

### GRG mismatch / revision
The B+C adjudication requires G7 to distinguish structural expectation from its realization. Enactivism is especially relevant to C0, not evidence that C0 is primitive B.

### Transfer candidate
Ask whether a system with the same instantaneous state transitions but different organization-relative viability coupling should count as having the same G6/G7c relation.

### Failure condition
If GRG cannot distinguish adaptive regulation from generic negative feedback, the mapping is too broad.

## 6. Participatory sense-making — interaction-level organization

Evidence depth: B.

### Source-native claim
Participatory sense-making allows the interaction process between autonomous agents to acquire its own organization and to enable / constrain the participants' sense-making, while participant autonomy is not thereby erased.

### Burden paid
- G9: relation-level organization can become causally relevant for participants.
- G10 pressure: a higher-order interaction organization can re-enter participant-level dynamics.

### Commitments not to flatten
Interaction autonomy != collective subject. Joint sense-making != fusion of agents. The theory begins with already autonomous participants and therefore does not by itself explain primitive pre-position generation.

### GRG mismatch / revision
G9 needs two independent tests:
1. interaction organization is identifiable beyond a list of simultaneous individual states;
2. perturbing that organization changes participant transition / accessibility while participant identity is preserved enough for the contrast.

### Transfer candidate
Use dyadic coordination as a clean higher-order re-entry case before making claims about social wholes.

### Failure condition
If the interaction-level variable is defined only from the same behavioral effect used to prove its efficacy, the relation is circular.

## 7. Synergetics / self-organization — order parameter and circular constraint

Evidence depth: C in this package; primary-source close-read is owed before theory-specific hardening.

### Source-family claim
Synergetics models systems in which interacting components can generate macroscopic order parameters and, once formed, those order parameters constrain / coordinate component dynamics through a slaving relation often described as circular causality.

### Burden paid
- G4: recurrent macro organization.
- G10: a formed higher-order organization can become a later condition on component dynamics.
- anti-reduction: macro efficacy need not require a mysterious extra substance.

### Commitments not to flatten
Order parameters are formal, system-specific constructs. “Slaving” is not universal domination, agency or normativity. A macro variable's predictive usefulness does not automatically establish an ontological One.

### GRG mismatch / revision
G10 must require a formation mechanism plus a withdrawal / intervention test, not just correlation across scales.

### Transfer candidate
Compare component dynamics under matched local capacities with the relevant order parameter / coordination organization intact versus disrupted.

### Failure condition
If all macro effects disappear once the full microstate is represented and no organization-sensitive intervention difference remains at the declared grain, do not claim an additional G10 relation.

## 8. Niche construction — reconstruction of later selectability

Evidence depth: B from existing repository integration work; stronger domain claims require source-specific evidence.

### Source-native claim
Organisms can modify environments in ways that alter later selection pressures and inherited developmental / ecological conditions for themselves or others.

### Burden paid
- G3: prior activity can persist in the later environment.
- G8: later selection conditions can be reconstructed by prior activity.
- G9: effects can propagate across multiple positions / lineages without implying a collective subject.

### Commitments not to flatten
Evolutionary selection != SRT Selection. Environmental modification need not involve foresight, cognition or explicit anticipation.

### GRG mismatch / revision
G8 must not require C1 or conscious future-directed intervention. “Reconstructive” names the target of change — the organization governing later selectability — not the agent's explicit intention.

### Transfer candidate
Separate state adaptation under a fixed environment from intervention that changes the environment / constraint structure governing later transitions.

### Failure condition
If every ordinary environmental side-effect is counted as G8 without identifying a changed later selection / accessibility relation, G8 becomes tautological.

## 9. Anticipatory / predictive families — C1, not basal B

Evidence depth: B for repository integration routing; source-family extraction remains distributed across Active Inference / predictive processing / Rosen-style anticipatory systems.

### Source-native burden
These families provide explicit or functional machinery in which present organization depends on expected / modeled later states, policies or outcomes.

### Burden paid
- G7c-C1: model-mediated anticipation.
- sometimes G8: policy / action can alter later reachable conditions.

### Commitments not to flatten
Bayesian prediction, internal generative models or Rosen-style anticipatory modelling are not L0 ontology and are not required for all generative expectation.

### GRG mismatch / revision
C1 must remain downstream of B and distinct from C0. Otherwise GRG would incorrectly make explicit future modelling necessary for normativity.

### Transfer candidate
Use matched cases with / without an explicit future model while retaining organization-relative regulation to test C0/C1 separation.

### Failure condition
If B can only be operationalized by importing a predictive model, the B+C adjudication has collapsed back into C1.

## 10. Forced revisions to the provisional grammar

Pass 1 does not replace G0-G11, but it forces the following research-level revisions:

~~~
R1 — G1:
"differential actualisation" must require perturbable operative efficacy,
not descriptive non-equivalence or unequal outcome.

R2 — G2:
split articulation/boundary, excluded/background organization,
and later operative status.

R3 — G3/G4:
keep retained efficacy separate from recurrent role organization.

R4 — G5:
add negative controls from crystal / fire / attractor / generic self-maintenance.

R5 — G6/G9:
require operative-position and interaction-organization tests;
indexing / coordination alone are insufficient.

R6 — G7:
split G7a exposure, G7b structural expectation B,
G7c C0/C1 anticipatory realization, G7d indexed normative comparison.

R7 — G8:
reconstruction need not be cognitive or foresighted;

R8 — G10:
require formation + independent identification + withdrawal / perturbation effect.
~~~

G0 remains OPEN in Pass 1: anti-pregivenness is well pressured, but “open remainder” still needs a sharper non-modal-warehouse formulation and source distribution.

G11 is DEFERRED rather than filled with weak analogy. Civilizational / scientific reflexive learning needs its own source-native extraction.

## 11. First relation worth freezing for transfer

The best first cross-source candidate is not “Selection” in general.

Provisional neutral relation:

### GRG-R1 — retained-organization re-entry

~~~
A relation among components / participants produces an identifiable organization O.

O remains identifiable at the declared grain after the immediate formation event.

Holding relevant component capacities as fixed as the domain permits,
perturbing / removing O changes later transition, accessibility,
support, inhibition or coordination relations.

When O is withdrawn, the predicted organization-sensitive effect
disappears or changes in the predeclared direction.
~~~

Why this relation:

- Simondon contributes operation -> structure -> later operation;
- synergetics contributes component interaction -> order parameter -> component constraint;
- the GRG anti-reduction red-team requires exactly a formation + later-condition bridge;
- it is thin enough to test without assuming One, Bearer, normativity or consciousness.

Non-identities:

~~~
GRG-R1 != generic path dependence
GRG-R1 != mere correlation
GRG-R1 != One automatically
GRG-R1 != downward extra force
GRG-R1 != universal Selection definition
~~~
