# Facing reconstruction Pass A — attractor / field / reachability geometry

> **Role:** sixth internal target cluster in the v0.2 bounded Facing reconstruction pass.
>
> **Boundary:** preserves the author's field intuition while testing whether `field`, `attractor` or `reachability geometry` must be independent ontology terms. The frozen cognition package is not edited.

## 0. Author intuition to preserve

Direct correction:

> 「我觉得重点不是先后，而是整体吸引子场如何形成，接续上一次会话中l0 facing 的问题」

The author was not asserting a literal physical field. The live intuition is whole-organization formation before / beneath explicit objectification.

## 1. The word 'field' had carried three burdens

Recent files use field for at least:

~~~text
A. primitive / L0-facing nonclosure;
B. mature cognitive whole-organization;
C. modeled effective reachability / compatibility geometry.
~~~

Facing reconstruction requires these to be separated.

## 2. FACE-L0 — no independent field object is needed

The primitive burden is already owned by:

~~~text
O0
= Selection reality is not exhausted by completed determinate actuality
  and is not fully preclosed by an already-given outcome structure.
~~~

Therefore:

~~~text
L0-facing field
!= hidden substance;
!= completed possibility geometry;
!= universal manifold;
!= extra thing added beside Selection.
~~~

The author's L0-facing field intuition can be preserved as a **question**:

> what remains generatively non-preclosed relative to the current formed organization?

but O0 already owns the primitive answer burden.

Disposition:

~~~text
field-as-primitive-ontology = RETIRE_CANDIDATE / NOT RETAINED;
O0 = KEEP.
~~~

## 3. Mature whole-field — useful system-level description

At cognition / formed-system strength, the repository already identifies contributors such as:

- recurrent history / retained organization;
- current Selection-position / operative locality where formed;
- structural generative Expectation;
- body-world coupling;
- formed Gate / constraint organization;
- skills, habits, objects and rules;
- current context and perturbation;
- support / maintenance relations.

These can jointly produce one current organization of:

~~~text
compatibility / incompatibility
relevance
competition
nesting
transition bias
foreground / background
action readiness
re-entry priority.
~~~

This justifies `whole field` as a domain-level systems shorthand.

But:

~~~text
whole field
!= extra substance over its contributing organization;
!= primitive Selection;
!= Bearer;
!= consciousness.
~~~

Disposition:

~~~text
whole field = KEEP as explanatory / systems-level aggregate organization;
not a new ontology node.
~~~

## 4. Reachability geometry — model / consequence level

The strongest neutral machine synthesis had been:

> field = effective geometry of differential future reachability.

Facing reconstruction narrows this.

Equivalence, neighborhood, boundary, transition, accessibility and perturbation stability are **formed/modelable relations**.

Thus:

~~~text
reachability geometry
= one useful model / readout of the current formed organization;
= often L2-heavy because retained constraints and history shape it;
= may include current L1 configuration / context;
!= universal L0 ontology.
~~~

The H1/H2/H3 reclassification already showed that changed reachability geometry can be a consequence of:

~~~text
distributed parameter change
-> latent / representational reorganization
-> effective geometry change.
~~~

So geometry reconstruction is a level of organization / consequence, not automatically a distinct mechanism.

Disposition:

~~~text
reachability geometry = KEEP as model family / readout;
RETYPE away from L0 root.
~~~

## 5. Attractor — dynamical property, not root noun

Attractor language may be useful when a domain model exhibits:

- basins;
- metastable dwell regions;
- switching;
- hysteresis;
- preferred trajectories;
- path dependence.

But no one attractor formalism is required for whole-field organization.

Therefore:

~~~text
attractor
= possible dynamical property / realization of a formed system;
!= L0 field;
!= primitive direction;
!= universal explanation of objectification.
~~~

Disposition:

~~~text
attractor = KEEP as domain/model term;
attractor-field as root ontology = RETIRE_CANDIDATE.
~~~

## 6. What remains of 'pre-object generative orientation'?

The cognition programme used `pre-object generative orientation` as a neutral root phrase.

After FRH-0 / FRH-1 / targets 3–5, its burden can now be unpacked as:

~~~text
primitive nonclosure / genuine generation
  -> O0 / Selection;

current formed locality
  -> One / Selection-position where paid;

prospective non-equivalence
  -> structural generative Expectation B;

retained shaping
  -> L2 history / constraints / Gates / skills / objects / rules;

current organism-world relevance
  -> body-world / context / domain mechanisms;

current whole-system coordination
  -> domain-level field / constraint organization;

new local determination
  -> Selection / L1 actualisation / objectification.
~~~

This strongly suggests that `pre-object generative orientation` is a **research umbrella**, not an additional ontology object.

Disposition:

~~~text
pre-object generative orientation
= KEEP as cognition-programme umbrella / question label;
= NOT a new primitive term;
= should be unpacked by typed owners when making theory claims.
~~~

## 7. The magnetic-field analogy survives, but only as analogy

The author's magnetic-field analogy remains useful for one point:

> explicit local objects need not be the primary units from which current whole-system direction is assembled.

It should not imply:

~~~text
a literal invisible substance;
a complete vector field over pregiven coordinates;
a fixed space existing before Selection.
~~~

A safer reading is:

> whole formed organization can exhibit distributed directional structure before that structure is compressed into explicit local objects.

## 10. Consequence for earlier field questions

Earlier questions such as:

~~~text
how does the L0-facing field form?
~~~

should now be split into:

~~~text
1. primitive question:
   why is Selection reality non-preclosed? -> O0 / primitive ontology;

2. formed-system question:
   how do retained constraints, position, expectation, embodiment and current context
   become one coordinated organization? -> cognition / systems science;

3. objectification question:
   how do local cuts stabilize within that organization? -> bridge/property/object route;

4. recursion question:
   how do those cuts later reshape formed conditions without exhausting O0? -> L2 writeback + later Selection.
~~~

This decomposition removes the need for one overloaded 'field formation' mechanism.
