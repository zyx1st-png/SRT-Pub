# Phase 6 — Core 21A/21B -> Constitution v1 coverage map

> **性质**：只读映射。本文不修改任何 P0/P1 claim level，也不把 Constitution probe 反向改写成 formal axiom/theorem。
>
> **问题**：Constitution v1 出现后，`P0/P1` 到底是 Constitution 的地基、Constitution 的推论，还是对 Constitution 暴露问题的一组更强理论回答？
>
> **结论先行**：当前最稳定的读法是第三种。

---

## 1. Two orthogonal ladders, not one vertical chain

旧架构容易被读成：

```text
L0
-> P0
-> P1
-> Constitution / interpretation
-> domain
```

新架构应改读为：

```text
Constitution v1
= reader-side explanatory-burden framework

orthogonal to

Core21 claim ladder
= one formal/metaphysical theory package's internal hardness structure
```

因此：

```text
P0 primitive
!=
Constitution primitive

P1 theorem
!=
Constitution theorem
```

P0/P1 可以继续在**当前 SRT formal-core package 内**表示“primitive / internally constitutive”。它们不因此成为 reader 必须先接受的 constitutional floor。

## 2. Constitution `(1) ARTICULATION` vs P0-01 / P0-04

### Constitution question

```text
这个 One 从哪里来？
这个答案又把什么当成给定？
```

### P0-01 answer candidate

```text
primitive Selection actualisation
-> determinate L1 distinction
```

P0-01 is therefore a **strong SRT answer to one provenance burden**。

But `(1)` can be run on P0-01 itself：

```text
Why take Selection actualisation as primitive?
What does this answer leave given?
```

AM-A explicitly answers by declaring the actualisation kernel a current primitive stopping point。

### Role relation

```text
Constitution (1)
-> opens provenance burden

P0-01
-> one current SRT primitive answer / declared stopping point
```

not：

```text
P0-01
-> proves Constitution (1)
```

### P0-04

Well-formed operator/state-space is a **formal admission rule** for making model claims。It is downstream objectification：a domain/formal model must declare an object it can operate on。

Thus P0-04 is not the source of `(1)`；it is one formal response after the reader has already chosen a unit / representation。

## 3. Constitution `(2) STILL-THIS` vs P0-02 / P1-T06

### Constitution question

```text
Why do we re-identify this as still the same under change?
Perturb the current basis and find its failure range.
```

### P0-02

P0-02 only separates：

```text
actual occurrence
!=
anchoring persistence
!=
Stable ISP
```

This supports the need for the question but does not define a universal re-identification criterion。

### P1-T06

Stable ISP has **four** conditions：

```text
iterative
perspective-bearing
history-bearing
continued-selectable
```

`bearing the downstream consequences of what it selected` is part of the fourth `continued-selectable` condition, not a fifth independent condition。ST-A also requires recurrent reconstitution across a declared perturbation range。

This is clearly related to `(2)` but must not be collapsed into it：

```text
successful re-identification
!=
Stable ISP standing
```

and independently the Constitution freeze preserves：

```text
re-identifiability
does not entail
bearerhood
```

### Role relation

P1-T06 is best read as a **formal-core result-state criterion for the model class SRT calls Stable ISP**。It is not a Constitution answer to identity in general, and current repository routing does not license reading it as universal bearer admission。

## 4. Constitution `(3) OWN-HISTORY` vs P0-03 / P1-T02 / P1-T06

### Constitution question

```text
Why does this past count as this candidate's own history?
```

### P0-03

Minimal irreversible-trace claim：if an anchored selection leaves history, later reversal cannot make it never have occurred。

This aligns with the thin guard：

```text
state restoration
!=
history erased
```

But P0-03 does not by itself answer：

```text
whose history is it?
```

### P1-T02

Ontological time as accumulated irreversible trace is a stronger temporal theory；it does not establish own-history attribution or same bearer。

### P1-T06

History-bearing is one condition of Stable ISP。That makes P1-T06 a stronger theory package about a declared process class；it does not erase Constitution `(3)`'s independent attribution burden and does not by itself settle same-bearer numerical identity across arbitrary branching cases。

### Role relation

```text
P0-03
-> historical facticity / non-erasure floor

P1-T02
-> stronger theory of time/history depth

P1-T06
-> stronger Stable-ISP history-bearing package

Constitution (3)
-> attribution question none of the above may silently skip
```

## 6. Constitution `(5)` consequence attribution vs Core21

### Constitution question

```text
Why is this effect counted as landing here?
Re-cut and re-run the attribution.
```

### Core21 status

There is **no dedicated P0/P1 consequence-attribution rule** in 21A/21B。

P1-T06 uses consequence-bearing language inside its fourth continued-selectability condition, but it assumes a declared process and its consequence relation；it does not provide a unique rule for where effects count as landing under alternative boundary/grain/timescale cuts。

This is consistent with later sigma-attribution audits that distinguish provenance / endogeneity / dependence / control and find no automatic unique attribution rule。

### Role relation

Constitution `(5)` exposes a real methodological burden that Core21 largely **uses but does not independently solve**。

Therefore：

```text
P1-T06 consequence-bearing language
cannot back-define
Constitution consequence attribution
```

and neither direction should be over-read：

```text
(5) success
!= Stable ISP proved

Stable ISP standing
!= same-bearer numerical identity universally proved
```

## 11. The central Phase 6 role correction

The clean architecture is：

```text
Constitution asks
-> Core21 proposes a formal/metaphysical answer
-> domain work tests/realizes the answer
```

not：

```text
Core21 says
-> therefore Constitution must accept
```

and not：

```text
Constitution asks
-> therefore Core21 answer is false
```

The Constitution changes the **burden of admission and explanation**, not the truth value of every existing Core21 claim by fiat。

## 12. P1-T06 correction after owner retrieval

An earlier Pass-1 reading treated P1-T06 as the highest-pressure candidate for a C-class bearer-admission review。Owner retrieval does **not** support that escalation。

### Retrieved separation

The active bearer routing explicitly keeps：

```text
Persistent Process
!=
Bearer
```

and routes the burdens separately：

```text
bearer admission
-> PH-IND02 / bearer owners

continued selectability / Stable ISP
-> P1-T06 / individuation owners
```

The processual-bearer bridge likewise states that its continuity diagnostics do not modify P1-T06 and are not sufficient for same-bearer numerical identity in arbitrary branching/fission cases。

### Current adjudication

Therefore there is **no current C21-1 author gate** merely because P1-T06 conjoins four Stable-ISP conditions。Core is allowed to build stronger conjunctions; the Constitution anti-collapse rule only prevents those conjunctions from being smuggled back into Constitution-level bearer admission without an independent owner relation。

Current safe reading：

```text
P1-T06
= formal-core result-state criterion
  for the model class Stable ISP

P1-T06
!= universal bearer-admission theorem
```

### Reopen condition

Reopen P1-T06 only if a concrete active surface is found that says or functionally entails：

```text
Stable ISP standing
=> bearer admission / same-bearer numerical identity
```

Absent that named conflict, no substantive reopen is warranted。
