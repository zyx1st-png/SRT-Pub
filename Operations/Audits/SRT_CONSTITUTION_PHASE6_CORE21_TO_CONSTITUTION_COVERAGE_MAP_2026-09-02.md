# Phase 6 — Core 21A/21B -> Constitution v1 coverage map

> **性质**：只读映射。本文不修改任何 P0/P1 claim level，也不把 Constitution probe 反向改写成 formal axiom/theorem。
>
> **问题**：Constitution v1 出现后，`P0/P1` 到底是 Constitution 的地基、Constitution 的推论，还是对 Constitution 暴露问题的一组更强理论回答？
>
> **结论先行**：当前最稳定的读法是第三种。

---

## 1. Two orthogonal ladders, not one vertical chain

旧架构容易被读成：

```text
L0
-> P0
-> P1
-> Constitution / interpretation
-> domain
```

新架构应改读为：

```text
Constitution v1
= reader-side explanatory-burden framework

orthogonal to

Core21 claim ladder
= one formal/metaphysical theory package's internal hardness structure
```

因此：

```text
P0 primitive
!=
Constitution primitive

P1 theorem
!=
Constitution theorem
```

P0/P1 可以继续在**当前 SRT formal-core package 内**表示“primitive / internally constitutive”。它们不因此成为 reader 必须先接受的 constitutional floor。

## 2. Constitution `(1) ARTICULATION` vs P0-01 / P0-04

### Constitution question

```text
这个 One 从哪里来？
这个答案又把什么当成给定？
```

### P0-01 answer candidate

```text
primitive Selection actualisation
-> determinate L1 distinction
```

P0-01 is therefore a **strong SRT answer to one provenance burden**。

But `(1)` can be run on P0-01 itself：

```text
Why take Selection actualisation as primitive?
What does this answer leave given?
```

AM-A explicitly answers by declaring the actualisation kernel a current primitive stopping point。

### Role relation

```text
Constitution (1)
-> opens provenance burden

P0-01
-> one current SRT primitive answer / declared stopping point
```

not：

```text
P0-01
-> proves Constitution (1)
```

### P0-04

Well-formed operator/state-space is a **formal admission rule** for making model claims。It is downstream objectification：a domain/formal model must declare an object it can operate on。

Thus P0-04 is not the source of `(1)`；it is one formal response after the reader has already chosen a unit / representation。

## 3. Constitution `(2) STILL-THIS` vs P0-02 / P1-T06

### Constitution question

```text
Why do we re-identify this as still the same under change?
Perturb the current basis and find its failure range.
```

### P0-02

P0-02 only separates：

```text
actual occurrence
!=
anchoring persistence
!=
Stable ISP
```

This supports the need for the question but does not define a universal re-identification criterion。

### P1-T06

Stable ISP gives a much stronger package：

```text
iterative
perspective-bearing
history-bearing
continued-selectable
```

and ST-A requires recurrent reconstitution across a declared perturbation range。

This is clearly related to `(2)` but must not be collapsed into it：

```text
re-identifiability
!=
Stable ISP / bearer admission
```

The Constitution freeze explicitly preserves：

```text
bearerhood does not derive from our re-identification cut
```

### Role relation

P1-T06 is therefore best read as a **stronger formal/theory candidate for a specific class of persistent perspective-bearing processes**, not the Constitution answer to identity in general。

## 4. Constitution `(3) OWN-HISTORY` vs P0-03 / P1-T02 / P1-T06

### Constitution question

```text
Why does this past count as this candidate's own history?
```

### P0-03

Minimal irreversible-trace claim：if an anchored selection leaves history, later reversal cannot make it never have occurred。

This aligns with the thin guard：

```text
state restoration
!=
history erased
```

But P0-03 does not by itself answer：

```text
whose history is it?
```

### P1-T02

Ontological time as accumulated irreversible trace is a stronger temporal theory；it does not establish own-history attribution or same bearer。

### P1-T06

History-bearing is one condition of Stable ISP, but Constitution `(3)` deliberately keeps historical attribution independent of full bearer admission。

### Role relation

```text
P0-03
-> historical facticity / non-erasure floor

P1-T02
-> stronger theory of time/history depth

P1-T06
-> stronger history-bearing process package

Constitution (3)
-> attribution question none of the above may silently skip
```

## 5. Constitution `(4)` vs P0-02 / P1-T03 / 21C B13

### Constitution question

```text
Why are precisely these differences/directions/paths currently processable?
```

### P1-T03 is the clearest stronger answer family

```text
sedimented L2
-> downward constraint on later selection dynamics
```

This directly realizes the author-origin burden：formed history reshapes later multiplicity。

But P1-T03 is not Constitution itself because：

- it uses `L2` as a specific SRT theory vocabulary；
- its equation requires a state representation and `C_L2` term；
- domain mechanisms remain unspecified；
- Constitution `(4)` can be run in a domain without first accepting L2 ontology。

### 21C P2/P3-B13

Generative reselectability / candidate-generation rewrite is a stronger downstream health/generative package。It is explicitly not P1 and not `(4)` admission criterion。

### Role relation

```text
Constitution (4)
-> reader-side field-formation burden

P1-T03
-> current SRT constitutive answer family: sedimented constraint

21C B13
-> stronger downstream generative-health/reselection interpretation
```

## 6. Constitution `(5)` consequence attribution vs Core21

### Constitution question

```text
Why is this effect counted as landing here?
Re-cut and re-run the attribution.
```

### Core21 status

There is **no dedicated P0/P1 consequence-attribution rule** in 21A/21B。

P1-T06 uses：

```text
bearing downstream consequences
history writeback
continued selectability
```

but it assumes a declared process and its consequence relation；it does not provide a unique rule for where effects count as landing under alternative boundary/grain/timescale cuts。

This is consistent with later sigma-attribution audits that distinguish provenance / endogeneity / dependence / control and find no automatic unique attribution rule。

### Role relation

Constitution `(5)` exposes a real methodological burden that Core21 largely **uses but does not independently solve**。

Therefore：

```text
P1-T06 consequence bearing
cannot back-define
Constitution consequence attribution
```

and `(5)` success still does not prove P1-T06 stable bearerhood。

## 7. Constitution `(6)` evaluative re-run vs Core21

### Constitution question

```text
Why is this direction judged better?
Perturb the basis and re-run the judgment.
```

### 21A/21B status

No P0/P1 theorem provides a universal semantic/value ranking。

Relevant history：

- epsilon is managed as a structural postulate / domain floor outside 21A/21B semantic ranking；
- former P1-T07 unconditional anti-closure theorem was demoted；
- stronger generative-reselectability / order-gain criteria live downstream in P2/P3/L1 normative theory；
- `T_dir` is an operational proxy, not a good-direction criterion。

### Role relation

This is an important **non-coverage result**：

```text
Core21 P0/P1
does not close
Constitution (6)
```

That is a healthy boundary, not a missing theorem that must be filled immediately。

## 8. P1-T01 / P1-T04 are adjacent, not Constitution owners

### P1-T01 causality as L2 projection

Adjacent to `(5)` but distinct：

```text
causal relation inside a model
!=
where a consequence is attributed under a declared cut
```

Use after the attribution/model cut is declared；do not treat as consequence-attribution theorem。

### P1-T04 minimal information creation

Adjacent to `(1)/(4)`：Selection creates a determinate distinction unavailable as an L1 fact before selection。

This is a stronger Selection-first theory claim；it does not replace provenance or field-formation probes。

## 9. Former P1-T05 / T07 are positive examples for the new architecture

### T05

Demoted because an anti-script agency guard had been mistaken for a constitutive theorem of Selection。

This is exactly the kind of type confusion Constitution v1 is designed to expose：

```text
one downstream agency distinction
!=
Selection occurrence criterion
```

### T07

Demoted because irreversibility alone did not prove a universal anti-closure direction without neutral dynamics / stability semantics / absorption proof。

Again：

```text
stronger normative/generative conclusion
!=
constitutive consequence merely because it fits SRT vocabulary
```

Both demotions should be treated as precedents for future Phase 6 hardening。

## 11. The central Phase 6 role correction

The clean architecture is：

```text
Constitution asks
-> Core21 proposes a formal/metaphysical answer
-> domain work tests/realizes the answer
```

not：

```text
Core21 says
-> therefore Constitution must accept
```

and not：

```text
Constitution asks
-> therefore Core21 answer is false
```

The Constitution changes the **burden of admission and explanation**, not the truth value of every existing Core21 claim by fiat。

## 12. Highest-pressure current item: P1-T06 Stable ISP

P1-T06 is the one P1 item most likely to be misread as a Constitution-level bearer theorem because it combines：

```text
same process
perspective
history
continued selectability
consequence bearing
```

The new Constitution deliberately distributed these burdens and froze non-entailments between them。

### Current safe reading

```text
P1-T06
= formal-core result-state criterion for the model class SRT calls Stable ISP
```

not：

```text
P1-T06
= Constitution has established the universal essence of bearerhood
```

### Future author gate C21-1

Later C-class review should decide：

```text
A. keep P1-T06 as P1 internal formal-core definition/theorem,
   but explicitly condition it on independently declared bearer/history/consequence relations;

B. reclassify Stable ISP admission itself to P2 conceptual bridge,
   keeping only a thinner P1 persistence/history result;

C. split definition/result-state criterion from any theorem-level existence or sufficiency claim.
```

This is a real theory/claim-hardness decision and should not be made inside the read-only audit。
