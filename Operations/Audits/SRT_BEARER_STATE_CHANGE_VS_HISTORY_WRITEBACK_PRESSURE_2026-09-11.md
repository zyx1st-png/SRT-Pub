# Bearer pressure — state change versus history-bearing writeback

## 1. Core distinction

A consequence q can affect a One without yet becoming that One's history.

Weak shape:

```text
q
-> current state of O changes
-> q is removed / decays
-> O's later operative Selection-position is reconstituted by the same organization as before.
```

This is **state perturbation**.

Stronger shape:

```text
q
-> retained change in organization / constraint / relation relevant to O
-> later P^O is reconstituted from q-altered conditions
-> O's future selectability differs because q occurred.
```

This is **history-bearing writeback** and supports Bearer standing for q.

Therefore:

```text
being affected
!= bearing.
```

## 2. Relation to author-confirmed SED-B

The author-confirmed SED-B ruling already rejects:

```text
persistent current asymmetry
=
historical sedimentation.
```

SED-B requires history-conditioned change in later transition / reconstitution conditions.

The Bearer transition inherits the same anti-degeneracy discipline but adds a new attribution burden:

```text
One-level / field-side historical writeback:
prior history changes later reconstitution conditions in the field;

Bearer-level writeback:
q becomes specifically constitutive of later reconstitution of an already-admitted One-lineage.
```

Thus Bearer does not introduce `history matters` as a new ingredient. It introduces **One-indexed consequence writeback**.

## 3. Current-state input is too weak

Suppose q only changes the current input / state seen by O:

```text
q_t
-> x_t changes
-> controller / process reacts
-> later x returns
-> no retained change in how P^O is generated.
```

This is compatible with ordinary responsive dynamics.

No Bearer conclusion follows from:

```text
q changes current state;
q changes current output;
q changes immediate probability.
```

The stronger question is:

> **Did q change the conditions from which the One's later operative Selection-position is rebuilt?**

## 4. Permanent scar is not required

Do not over-strengthen history-bearing writeback into:

```text
q must permanently alter O forever.
```

A consequence can be borne if it enters one or more later reconstitution cycles as a real historical condition, even if later repair / adaptation / forgetting reduces or removes its effect.

Possible shape:

```text
q
-> P_(t+1) is reconstituted differently
-> repair / adaptation occurs
-> P_(t+k) approaches prior organization.
```

The repair itself belongs to the subsequent history.

Thus:

```text
bearing
!= permanent damage.
```

## 5. Exact restoration / reset remains a pressure case

If after q the candidate One can be restored by replacing / resetting it such that:

```text
its later operative organization is indistinguishable from a q-never-happened continuation
and q's cost/history closes elsewhere,
```

then strong q-bearing by that candidate One weakens.

This is not because exact restoration is metaphysically impossible by definition.

It is because the proposed Bearer relation specifically requires q to become history-bearing for the continuing One-lineage.

Copy / reset identity remains separately open.

## 6. Event-specific bearing versus Bearer standing

A useful distinction:

```text
bearing(q, O)
= q becomes history-bearing for O's later reconstitution.

Bearer standing of O
= O has an established capacity / organization in which consequential history
  can become One-indexed and alter its later operative reconstitution.
```

One q may be enough to mark **Bearer onset** in a thin sense if it genuinely enters later reconstitution.

But Bearer depth / stability remains graded:

```text
how many classes of consequence;
how robustly;
how long;
how non-outsourcably;
at how many reconstitution scales.
```

No scalar threshold is authorized.

## 7. Not every event experienced by a Bearer is strongly borne

Even an established Bearer can receive inputs that leave no durable historical effect.

Therefore:

```text
O is a Bearer
```

does not imply:

```text
every q contacting O becomes strong own-history.
```

This avoids overgeneration.

Bearer standing is an architectural capacity / recurring relation; q-level bearing is event-specific.

## 8. Positive, negative and neutral-looking consequences

History-bearing writeback is not limited to harm.

Examples:

```text
injury;
learning;
resource acquisition;
trust gain / loss;
commitment;
repair;
role change;
new affordance;
constraint removal;
constraint creation.
```

The sign of q is secondary to whether q changes later reconstitution / future selectability.

## 9. Externally caused q fits naturally

An external event can be strongly borne:

```text
external q
-> retained q-conditioned change
-> later P^O reconstitution changes
-> O must continue from q-altered selectable organization.
```

This reinforces:

```text
who causes
!= who bears.
```

## 10. Self-generated q is a stronger loop, not the minimum

If q originated from O's own Selection:

```text
P^O_t
-> Selection_O
-> q_O
-> q_O changes later reconstitution of P^O_(t+1)
```

then O realizes a stronger self-consequence / agency closure.

But generic Bearer does not require this source match.

## 11. Matched-history conceptual pressure

Machine-side test only:

Compare two cases with similar current observable state where possible:

```text
H1:
O reached current state after consequence q
and q left retained reconstitution-relevant change.

H0:
O reached a similar current state without q-history
or with q-history externally washed out.
```

If future P^O reconstitution differs because of H1/H0 history, this supports history-bearing writeback.

This is conceptual pressure only; it is not a new Level-2 experiment authorization and must not revive the retired shuffled-writeback programme.

## 12. Why this still does not establish scientific novelty

Mature learning, autonomy, plasticity, trauma, developmental, institutional and control frameworks already model history-dependent future change.

Therefore SRT cannot claim novelty from:

```text
past event changes future behavior;
learning persists;
constraints adapt;
organism repairs;
institution updates rules.
```

The current SRT-side contribution remains a repartition:

```text
One continuation
!= consequence bearing

state perturbation
!= One-indexed historical writeback

Bearer
!= subject / experiencer.
```

## 13. Compact transition

```text
ONE O
↓
q affects O
↓
[branch]

q only changes current state
-> perturbation / response
-> no q-level Bearer inference

q changes later reconstitution conditions of O
-> q becomes O-indexed history
-> Bearer-onset support
```

## 14. Verdict

```text
being affected = bearing: NO
current feedback = history-bearing writeback: NO
permanent scar required: NO
explicit memory required: NO
q-source must be O: NO
q must alter later reconstitution / future selectability: LIVE MINIMUM CANDIDATE
One-level SED-B = Bearer-level writeback: NO / attribution differs
Bearer standing = every q strongly borne: NO
canonical edit: NO
new Level: NO
scientific distinctiveness: NOT ESTABLISHED
```

## 15. Next pressure

The next live issue is the **attribution step**:

> **When q alters a nested / overlapping hierarchy of Ones, what makes its retained effect One-indexed at each scale rather than merely a global field change that happens to correlate with several continuations?**

The next pass should use fixed pre-q One lineages and differential reconstitution dependence, not physical history location.
