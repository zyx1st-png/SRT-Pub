# Post-Selection directionality relocation map

> **Role:** machine-side mapping pass after the author accepted option C: minimum pre-object L0 does not primitively privilege continuation / non-self-erasure. This audit asks where continuation, closure, anti-closure, reselectability and stronger value-direction burdens first become semantically legitimate, and which current owners can inherit them without recreating a primitive value field.
>
> **Hard guard:** this file does not canonically move `ε_pg`, change `T_dir`, redefine One, promote generative health, or settle normativity. It maps dependency order and owner pressure only.

---

## 1. Controlling author direction

Accepted direction:

```text
pre-object L0 minimum
= non-nothing
+ non-exhaustion
+ non-maximal-indifference

but NOT:
continuation-preserving is already better
non-self-erasure is already preferred
order / value is already embedded as content
```

Stronger direction must be reconstructed only after primitive Selection and sufficient downstream relation structure exist.

The central question is therefore not:

```text
where do we move the old epsilon primitive?
```

but:

```text
what distinct downstream burdens were historically compressed into epsilon,
and at what earliest layer does each burden become meaningful?
```

# 2. Main result — directionality decomposes into a ladder, not one relocated primitive

The strongest coherent reconstruction is:

```text
D0  modal non-indifference
D1  event asymmetry
D2  successor / retention asymmetry
D3  reconstitution / One continuation
D4  continued-selectability standing
D5  generative reselectability / reorganizability
D6  situated normative comparison / value readability
```

These are not equivalent.

The old `ε_pg` bundle partly collapsed D0, D2, D5 and D6 into one L0 seed. The accepted author direction requires that collapse to be undone.

# 4. D1 — primitive Selection / event asymmetry

## Burden

Primitive Selection produces:

```text
A becomes determinate manifest actuality
+
A*_(S) is relatively backgrounded
```

This provides event-level asymmetry / primitive verticalization.

Current One owner already distinguishes one-shot event-level verticalization from continuing One, history or formed locality.

### What D1 adds

```text
actual occurrence;
manifest / relative-background differentiation;
ontic non-erasure of genuine occurrence.
```

### What D1 still does not add

```text
A will continue;
A* remains a future reservoir;
a successor is available;
a retained relation exists;
closure / anti-closure is already meaningful;
continuation is good;
```

### Key result

A single Selection event is too early for the historical strong epsilon burden.

The proposition:

```text
this event occurred
```

is categorically different from:

```text
this realization preserves later selectability / continuation.
```

### Verdict

```text
D1 event asymmetry: YES
D1 continuation-favouring direction: NO
```

# 5. D2 — earliest legitimate continuation / closure typing

## Core claim

The earliest point at which `continuation` / `closure` can become meaningful is **after an actual event, once some later relation to successor conditions is independently available**.

Minimum form:

```text
Selection_t occurs
-> consequence / retained difference materially affects later conditions
-> later Selection remains possible, constrained, blocked, redirected, or otherwise different
```

This does not yet require a formed One.

It requires at least a declared relation over:

```text
post-event condition;
later admissibility / successor relation;
retained or returning consequence;
time / step horizon or equivalent ordering;
what counts as blocked / still available.
```

### D2a — successor availability

In a declared model one may ask:

```text
after realization r,
is any later Selection relation still admissible?
```

This is the first legitimate home for an operational `B >= 2 / B <= 1`-style readout.

But `B` must mean:

```text
successor relations in the declared model after actualisation
```

not:

```text
pregiven branches already stored in primordial L0.
```

### D2b — retention / writeback

Stronger:

```text
prior Selection makes a later-effective difference to later Selection conditions.
```

This is already compatible with the One owner's history / writeback typing, which says retained history can alter later Selection conditions without by itself constituting One.

### Important non-identity

```text
successor availability
!= retained history;
retained history
!= One;
```

A model may have successor availability with no meaningful retained history, and retained consequences may be distributed without forming a relatively separable One.

### Verdict

```text
earliest legitimate closure / continuation comparison: D2
requires formed One: NO
universal ontology theorem at D2: NO
formal / scoped relation: YES
```

# 6. D3 — Selection-mediated vertical reconstitution / One

Current One owner provides a stronger relation:

```text
Selection-generated vertical organization_t
-> materially enters later Selection conditions
-> later Selection regenerates vertical organization_(t+1)
-> renewed organization can again condition later Selection
-> relatively separable reconstitution path
-> One
```

At D3, `continuation` is no longer merely successor availability. It becomes **formation-relative continuation**:

```text
is a relatively separable process-unity being reconstituted through Selection-mediated history?
```

This is a genuine stronger direction but remains non-normative.

A One can form in a pathological, externally harmful, rigid, exploitative, or eventually self-terminating way. Formation is not health or value.

Therefore:

```text
One formation
!= anti-closure value
!= good continuation
!= generative health
```

### Verdict

```text
D3 owns process-unity continuation semantics: YES
D3 owns normativity: NO
```

# 8. D5 — generative reselectability / reorganizability

Current B13 and OPEN-TENSIONS already contain the strongest existing home for the **anti-closure distinction work** without making it primitive.

Current distinction:

```text
formed process
-> identifiable organization

structurally stable ISP
-> recurrently reconstituted same perspective/history-bearing organization
-> continued selectability

generatively healthy ISP
-> consequence return can revise
   comparison rules,
   boundaries,
   candidate-generation / reopening conditions
-> generative reselectability
```

This is qualitatively different from mere survival.

A rigid process may remain stable and continue selecting while progressively locking its own comparison rules and future relation-space. D5 asks whether consequences can return strongly enough to revise the very structures that determine later selection.

This is a much better match for the historically important anti-self-erasure intuition than a primitive L0 branch-count bias.

### Why D5 is the strongest current candidate

It pays the relevant burdens explicitly:

```text
there is a process to be affected;
there are consequences;
consequences can return;
there are comparison rules / boundaries / generation conditions;
those structures can or cannot be revised.
```

No pregiven future tree is required.

### But D5 is not automatically morality

Generative reselectability is currently P2/P3 generative-health structure.

It does not by itself establish:

```text
moral goodness;
justice;
non-outsourcing;
cross-position coordination;
Bearer status;
global value;
objective ranking of all outcomes.
```

### Verdict

```text
D5 strongest current home for anti-lock-in / anti-closure burden: YES
D5 = complete normativity: NO
```
