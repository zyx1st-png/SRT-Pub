# IRR-B global causal residue — internal role pressure pass 1

> **Role:** determine exactly what the author's IRR-B ruling changes inside the current architecture before any physics promotion. The pass may weaken or narrow IRR-B. It must not turn the ruling into a hidden canonical rewrite.

## 1. Author-confirmed candidate entering this pass

```text
every genuine Selection
-> leaves an unavoidable causally effective residue
   somewhere in the complete present state / enlarged environment

therefore:
local restoration may occur
but exact restoration of the complete causally relevant state is impossible.
```

Explicit author boundary:

```text
NOT IRR-C:
complete present causal state may be exactly identical
while history outside that state independently changes the future.
```

The candidate therefore remains state-complete rather than history-extra-causal.

---

## 2. P0-03 is currently weaker than IRR-B

Current `P0-03` says, minimally:

```text
once a Selection is anchored into L1 and leaves history in L2,
it cannot be treated as never having occurred;
any reversal is a new Selection event with its own trace.
```

This guarantees historical asymmetry. It does **not yet state**, in its minimal wording:

```text
every genuine Selection leaves a permanently non-zero causally effective
residue in the complete later physical / causal state;

or

exact global recurrence / exact global inversion is impossible for every
process that instantiates primitive actualisation.
```

Therefore IRR-B is not a paraphrase of current P0-03. It is a stronger author-owned candidate that would require explicit architectural adjudication before canonical promotion.

---

## 3. P0-02 occurrence / persistence boundary must survive

Current P0-02 distinguishes:

```text
manifest actuality
!= anchoring persistence
!= stable object / stable ISP
```

IRR-B must not silently collapse these into:

```text
actual occurrence
-> durable object-level persistence
```

A globally distributed causal residue can be much thinner than a persistent object, memory token, stable L2 scaffold, bearer or subject.

Safe candidate reading:

```text
genuine Selection
-> complete present reality is not exactly the pre-Selection complete reality

but the differentiating residue may be:
- dispersed;
- delocalized;
- below ordinary object persistence;
- encoded in correlations / controller / environment / changed constraints;
- not attributable to one mature bearer.
```

Therefore retain:

```text
global causal non-identity
!= local persistence
!= L2 scaffold
!= Bearer
```

### Pressure

If IRR-B requires a forever identifiable local record, it contradicts the P0-02 separation and is too strong.

If it requires only that the **complete causally relevant state** cannot be exactly restored, P0-02 can remain intact.

---

## 4. Cycle-1 non-Markov guard remains binding

Cycle 1 explicitly rejected:

```text
complete current causal state identical
+ history differs
-> future must differ
```

when the phrase `complete current causal state` genuinely includes every causally effective historical residue.

IRR-B is compatible with that ruling only because it denies the antecedent after genuine Selection:

```text
if history is causally relevant,
its effect must be represented somewhere in the complete current causal state.
```

Therefore IRR-B must not be defended by saying:

```text
the states are physically / causally identical,
but Reality remembers anyway.
```

That would be IRR-C by another name.

## 5. PHR-A compatibility test

The 2026-08-11 physical-realisation author ruling selected `PHR-A — Interpretation-Plural Realisation Audit`.

PHR-A already contains an important negative control:

```text
reversible premeasurement:
system-apparatus correlation may form
and later be quantum-erased / uncomputed;
therefore candidate differentiation alone does not establish an
irreversible realisation event.
```

Its bounded event chain also required a historical difference that is not exactly cancelled at the declared level.

This means IRR-B does not invent the distinction:

```text
reversible correlation / premeasurement
!= genuine physical realisation candidate
```

It **does** strengthen its theoretical placement:

```text
PHR-A before IRR-B:
non-cancellability = one P3/P4 event-audit condition.

IRR-B candidate:
non-global-cancellability = author-owned consequence of genuine Selection itself.
```

That is a genuine architectural change in direction, even if no new mechanism has yet been supplied.

## 6. Everett / interpretation-plural pressure

PHR-A currently allows:

```text
collapse-family:
exclusive outcome anchoring candidate

Everett:
branch-relative record / fact formation candidate

RQM / frame-relative:
relation-indexed fact formation candidate
```

IRR-B makes the Everett case sharper.

Under globally unitary evolution:

```text
U : |Psi_0> -> |Psi_1>
```

is mathematically invertible by:

```text
U^dagger : |Psi_1> -> |Psi_0>.
```

Therefore an Everett / fully unitary physical translation can remain compatible with IRR-B only by one of three routes:

```text
E1.
The intermediate globally reversible correlation is not yet genuine Selection.

E2.
A genuine branch-relative Selection occurs only once a physically relevant
residue has escaped exact global controllable inversion, even though the
fundamental formal dynamics remains unitary.

E3.
IRR-B eventually requires a stronger non-unitary / non-invertible physical
implementation in at least some genuine Selection regimes.
```

No route is author-selected here.

### Important governance consequence

IRR-B therefore puts real pressure on the breadth of PHR-A's interpretation-plural compatibility. It cannot yet be written as though nothing changed.

## 7. The boundary-drift problem

IRR-B can become empirically empty if every apparent reversal is answered by enlarging the system boundary after the fact:

```text
qubit restored?
-> residue is in ancilla

ancilla restored?
-> residue is in controller

controller restored?
-> residue is in environment

local environment restored?
-> residue is elsewhere in universe
```

This is not automatically wrong, but it becomes a degenerative defense unless the relevant complete-state boundary is prospectively declared.

Therefore any future IRR-B test must freeze:

```text
1. what degrees of freedom count as the complete causal state for the test;
2. what transformations are allowed as reversal;
3. what independent evidence licenses calling the intermediate process genuine Selection;
4. what residual variable is predicted to remain;
5. what observation would count as exact-enough restoration to weaken IRR-B.
```

Without this, `residue somewhere` is unfalsifiable.

## 8. Circularity risk

A fatal shortcut would be:

```text
Definition:
Selection = whatever cannot be globally reversed.

Test:
Selection cannot be globally reversed.
```

That is empty.

IRR-B can earn Level 2 only if genuine Selection is admitted by criteria that do **not** already contain the target no-global-reversal result.

Existing PHR-A cannot simply be reused unchanged because its event chain already contains historical non-cancellability.

Therefore a future test needs an **independent preclassification surface**, for example some bounded conjunction of:

```text
- non-equivalent candidates;
- outcome-indexed physical registration;
- intervention-sensitive downstream path efficacy;
- declared event boundary;
```

with global irreversibility held out as the result under test rather than an admission condition.

Whether such a surface is sufficient is currently OPEN.
