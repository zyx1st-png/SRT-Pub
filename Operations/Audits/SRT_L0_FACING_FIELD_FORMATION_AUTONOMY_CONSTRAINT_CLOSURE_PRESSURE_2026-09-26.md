
## 2. Strong neighbor B — closure of constraints

This is especially important for the current L0-facing problem because it addresses not merely "self-maintenance" but the organization of constraints themselves.

### Source-native structure

The organizational account distinguishes:
- processes: ongoing transformations under open nonequilibrium conditions;
- constraints: relatively conserved structures that channel / reduce degrees of freedom of those processes at a relevant timescale.

Biological organization obtains when constraints realize closure:

~~~text
constraint A contributes to production / maintenance of B;
B contributes to C;
...
the network of constraints collectively maintains
the conditions for its own continued existence.
~~~

This directly pays much of the burden behind current SRT working language:

~~~text
glue
constraint
gating
stability
whole > sum
future possibility organization.
~~~

### Direct pressure on gate geometry

Current SRT gate geometry tracks:

~~~text
equivalence
boundary
neighborhood
transition / reachability
perturbation stability.
~~~

Constraint-closure theory already explains how:
- local structures restrict process degrees of freedom;
- constraints jointly maintain one another;
- organization produces system-level stability;
- system boundaries can be marked through organizational closure.

Therefore:

~~~text
gate geometry alone
!= explanation of field formation.
~~~

At best, gate geometry may be:
- a geometric / relational description of the effective constraint organization;
- an operational readout of what the constraint network makes reachable / equivalent / stable.

The causal formation burden still requires an account of how those constraints arise, couple and remain mutually sustained.

This is an important anti-reification correction.

### Source-native pressure

Active inference can supply:
- statistical system boundaries;
- nested self-assembly of local blankets into larger global systems;
- generative models;
- preferred states / priors;
- perception-action loops;
- self-maintaining / allostatic regulation;
- future-sensitive policy selection.

Kirchhoff et al. explicitly describe collectives of Markov blankets self-assembling into a global system with its own Markov blanket.

This directly pressures:

> how can "many" become one statistically bounded global system?

### Guard

Do not equate:

~~~text
Markov blanket
= One
= Bearer
= subject
= L0-facing field.
~~~

A statistical partition does not by itself settle:
- process-lineage continuation;
- same-unit consequence ownership;
- phenomenality;
- intrinsic system boundary in every interpretation.

There are also serious critiques that FEP / Markov-blanket formalism can redescribe rather than fully explain perception / action and self-organization.

Therefore active inference is a strong comparator, not a final answer.

## 5. Main synthesis — field as derived reachability geometry, not extra substance

The strongest current machine synthesis is:

> **The L0-facing "field" should not be introduced as one more entity. Treat it provisionally as the effective geometry of differential future reachability generated by the whole current organization.**

In other words:

~~~text
distributed processes
+ mutually sustained constraints
+ metastable coordination
+ retained history
+ current operative position
+ structural Expectation
+ body-world coupling
+ current perturbation
-> effective L0-facing reachability geometry.
~~~

That geometry can be described through:
- which differences are equivalent;
- which distinctions remain load-bearing;
- which boundaries are effective;
- which neighborhoods cohere;
- which transitions are easier / harder / blocked;
- which perturbations preserve / reopen the organization;
- which local cuts can stabilize as objects / relations / actions.

### Why this helps

It avoids:

~~~text
field = hidden L0 substance
field = central controller
field = one fixed attractor
field = complete pre-existing possibility inventory.
~~~

It also clarifies the magnetic-field analogy.

The analogy is not:

~~~text
an invisible thing exists first
then objects are inserted into it.
~~~

A safer reading is:

~~~text
the whole organization induces a structured pattern
of differential continuation / reachability;

local explicit objects are stabilized determinations
within that pattern;

retained determinations modify the organization
and therefore reshape the next reachability pattern.
~~~

~~~text
of the evolving reachability geometry
~~~

~~~text

= attractor.
~~~

This preserves the author's intuition without prematurely choosing a fixed-point / energy-landscape formalism.

## 11. Next valid move

Do not expand to another ten-neighbor literature sweep yet.

Focus on the bridge:

~~~text
same continuing organization
+ consequence / history
-> what exactly changes in the whole field?
~~~

Pressure-test three alternatives:

### A — local-memory account

History changes only local values / weights / memories.

If sufficient, no stronger field reconstruction is needed.

### B — latent-state / model-update account

History updates a predictive / latent model that changes global inference.

If sufficient, SRT field language may be translation-only.

### C — geometry-reconstruction account

History changes:
- equivalence relations;
- boundaries;
- neighborhoods;
- transition reachability;
- stability / recutting conditions

across multiple local readouts.

Only C motivates the stronger gate/reachability reconstruction burden.

A future empirical design should discriminate A / B / C before invoking SRT-specific ontology.
