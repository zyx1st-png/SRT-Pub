# L0 canonical semantic-diff draft — pre-object minimum reconstruction

> **Role:** bounded semantic-diff draft only. This file does not edit `Core_Law/SRT_L0_Metaphysics.md`. It identifies the smallest current semantic change set implied by the 2026-09-14 author adjudications and separates that set from independent owner questions that still require their own audit.
>
> **Hard guard:** no canonical wording below is adopted merely because it appears in this draft. `κ₀`, `ε_pg`, `L0^abs`, real-cost universality, irreversibility, finite positionality, and downstream L1/L2 structures retain their current canonical status until an explicitly authorized owner edit occurs.

## 1. Controlling author direction

Current accepted reconstruction direction:

```text
pre-object minimum
= Oriented Openness as an umbrella for three distinct burdens:
  (1) non-nothing
  (2) non-total-closure
  (3) non-maximal-indifference

none of (1)-(3) derives determinate actuality
```

Stronger inherited constructions do not automatically define this minimum merely because they historically occupied L0.

# 3. Executive semantic verdict

The current L0 owner is **not structurally wrong**. Its post-#957/#959 core already contains most of the needed guards. The problem is narrower but important:

1. the newest `Oriented Openness` grammar is thin and anti-object-first;
2. §2 still preserves older positive `潜在域` language that can be read as a pre-existing absolute One / container;
3. some inherited stronger constructions (`颗粒性`, `κ₀`, `ε`, option/branch language) still sit close enough to the minimum layer that they can be mistaken for its definition;
4. the slogan `Selection precedes existence` still needs an explicit scope guard so that real pre-object modal reality is not accidentally denied;
5. `潜在 / 显现 / 稳定` are presently narrated as three states of one process, but the reconstructed burden structure is better treated as modal admissibility / actual occurrence / downstream retained standing, not three symmetric ontic containers.

Therefore the likely future canonical change is **surgical**, concentrated in Quick Reference, §1 modal wording, §2, part of §3, and the minimum-term entries in §6. Most of §1 irreversibility, §5 consciousness prohibitions, and downstream boundary guards can remain.

# 5. §一 — 选择先于存在

## I-1 — “存在不是一个背景” and occurrence / persistence split

Disposition: **KEEP**, with one scope precision.

The EX-A split between:

```text
actual occurrence
anchoring persistence
Stable ISP
```

is still useful and should remain.

However sentences that can be read as `nothing whatsoever is real before Selection` should be narrowed.

Candidate scope guard:

```text
没有任何确定对象、确定状态或确定事件在 primitive Selection 之前就已经以完成的显现实在性存在。
这不等于 pre-object actualisability 是绝对虚无。
```

This preserves Selection-first ontology while preventing `Selection precedes all reality` from becoming an unintended claim.

## I-2 — no prior chooser

Disposition: **KEEP**.

The following burden survives directly:

```text
Selection is process/event grammar, not the action of a pre-existing chooser.
```

The current exclusion of prior selector / subject / completed object menu / One remains aligned with the author adjudication.

## I-3 — finite positionality

Disposition: **KEEP + NARROW**.

Keep:

```text
every genuine Selection is finite-position-indexed;
finite positionality != formed One / perspective / Bearer / subject.
```

Do not yet canonically assert:

```text
position is fully reducible to relation-indexicality.
```

The current reconstruction strongly disfavors a pregiven coordinate-container reading, but the exact irreducible burden of positionality remains separately OPEN.

## I-4 — irreversibility / ontic non-erasure

Disposition: **KEEP, SEPARATE FROM ORIENTED OPENNESS**.

The distinction:

```text
actual occurrence
!= durable persistence
!= localized memory
!= recurrent historical efficacy
```

remains important.

But irreversibility should not be silently treated as one of the three minimum modal burdens. It is a distinct actual-event / history burden after genuine Selection occurs.

## I-5 — Oriented Openness paragraph

Disposition: **REWRITE CANDIDATE**.

Current good guards should remain:

```text
not earlier entity
not temporal predecessor-event
not completed option menu
not probability distribution
not goal field
not second generative mechanism
```

But the positive minimum should be decomposed explicitly:

```text
Oriented Openness is a routing name, not a fourth object.

minimum burden A: pre-object actualisability is not absolute nothing;
minimum burden B: no current determination has total-closure authority;
minimum burden C: actualisability is not maximally indifferent.

A, B and C are not presumed mutually derivable.
None of them is primitive actualisation.
```

## I-6 — current “第一命题”

Disposition: **REWRITE CANDIDATE**.

Keep:

```text
Selection = actual differentiation
= manifestation / relative backgrounding
= primitive verticality as same-event structural reading
```

Add the accepted A/A* guard:

```text
A* != pregiven B
A* != completed option inventory
A* != automatically proven future-generative field
```

Retain the hard separation between actual occurrence and downstream persistence / memory / recurrent efficacy.

`κ₀` / `ε` / irreversibility should no longer appear in this first proposition as if they jointly define the minimum modal floor; their stronger inheritance remains separately auditable.

# 6. §二 — “现实具有三种状态，而不是三种物质”

This is the **highest-priority semantic repair zone**.

## II-1 — section title and “three states” grammar

Disposition: **REINTERPRET / NARROW**.

The useful burden is that potentiality, manifestation, and stability must not be collapsed.

The risky burden is that they sound like three symmetric pre-existing ontic regions or state-containers.

Candidate future direction:

```text
pre-object actualisability
!= determinate manifestation
!= downstream retained / stabilized standing
```

Possible future section title:

```text
潜在、显现与稳定承担不同本体负担，不是三个容器
```

No final title is adopted here.

## II-2 — “潜在域是尚未被选择的可能性场”

Disposition: **REWRITE CANDIDATE**.

Problem: `域 / 场` still invites a container reading even with the post-#959 option-menu guard.

Candidate minimum replacement:

```text
“潜在”在最低层不命名一个装有未实现对象的区域；
它命名尚未获得确定显现实在性的 pre-object actualisability。
```

Keep the distinction from absolute nothing and from manifest actuality.

## II-3 — “潜在域是绝对的、不可分割的”

Disposition: **DELETE-CANDIDATE IN CURRENT POSITIVE FORM / REINTERPRET AS PRE-PARTITIONALITY**.

Unsafe reading:

```text
there exists one absolute indivisible primordial latent thing.
```

Author-accepted safer burden:

```text
prior to primitive Selection, objectified partition into independently individuated One / Many / domains is not yet licensed.
```

Thus `不可分割` should, if retained at all, mean:

```text
not-yet-legitimately-partitioned
```

not:

```text
one huge indivisible substance.
```

## II-4 — “景观共享不发生在潜在域层面” / time-space sharing

Disposition: **HOLD — OWNER AUDIT / LIKELY ROUTE DOWNSTREAM**.

This paragraph includes post-Selection spacetime / shared-constraint claims that are stronger than the minimum pre-object burden. They need not be deleted, but they should not be used to define pre-object L0.

## II-5 — “内在颗粒性”

Disposition: **ROUTE / DEMOTE FROM MINIMUM**.

The minimum burden needed at L0 is only:

```text
maximal indifference / complete flatness = false.
```

`颗粒性` is a stronger interpretation and easily objectifies pre-object reality as if it already contained primitive units.

Therefore future wording should say, in effect:

```text
“颗粒性” is one historical/stronger interpretation of non-flatness;
it must not be read as pre-existing granular objects or as the complete definition of Oriented Openness.
```

## II-6 — κ₀ formal note

Disposition: **HOLD — OWNER AUDIT; KEEP AS STRONGER REALIZATION CANDIDATE**.

Current AM-A guard is valuable and should remain:

```text
κ₀ constrains realization;
κ₀ does not derive first actualisation.
```

But the future L0 owner should not imply:

```text
pre-object reality literally is universally Riemannian with κ₀.
```

Bounded `κ₀` owner audit must decide whether the strongest safe role is:

```text
geometric witness / formal realization of non-flatness
```

rather than universal ontological identity.

## II-7 — post-actualisation self-bootstrapping

Disposition: **KEEP + ROUTE DOWNSTREAM**.

The core distinction is good:

```text
primitive actualisation first;
constraint thickening / co-evolution later.
```

But “造更多颗粒” should eventually be checked for objectifying metaphor if `颗粒性` itself is routed away from the minimum.

## II-8 — “为什么必须承认潜在域？因为否则无法解释真正新颖性”

Disposition: **DELETE-CANDIDATE AS CURRENT ARGUMENT**.

Reason:

```text
novelty -> therefore a latent domain exists
```

is not established by the current author adjudication and makes `潜在域` sound like a positive source-container from which novelty comes.

The minimum burden can be defended without this inference:

```text
pre-object actualisability is not absolute nothing;
later determinate B need not pre-exist as completed B;
Selection actualises under real constraints without a completed option inventory.
```

## II-9 — “潜在域永远大于任何已经显现的东西；它是选择的来源”

Disposition: **REWRITE / PARTIAL DELETE-CANDIDATE**.

Keep only the non-closure burden:

```text
no finite/current determination exhausts pre-object actualisability.
```

Do not retain, without further argument:

```text
潜在域 is a larger object;
潜在域 is the actuality-producing source of Selection.
```

The actuality-producing role remains primitive Selection.

## II-10 — 显现域

Disposition: **KEEP + REINTERPRET AS REGISTER, NOT CONTAINER**.

Keep:

```text
determinate event actuality can be transient;
manifest occurrence != durable persistence.
```

Prefer future wording such as `manifest actuality / manifest register` over imagery of a separate spatial domain if the domain-language audit confirms that change.

## II-11 — 稳定域

Disposition: **KEEP AS DOWNSTREAM BURDEN + ROUTE**.

Keep the history/sedimentation intuition, but do not imply that all stable structure is simply the third coordinate-like region of the same L0/L1/L2 space.

Formation of reusable constraints, Stable ISP, One, Bearer and stronger standings remain governed by their own downstream owners.

## II-12 — current “第二命题”

Disposition: **REWRITE CANDIDATE**.

Candidate conceptual content:

```text
pre-object actualisability,
determinate manifest occurrence,
and downstream retained/stabilized constraint
must remain distinct.

They are not three substances or three containers.
```

Do not yet assert a universal exhaustive three-stage ontology beyond what current owners independently support.

# 8. §四 — 选择有代价

Disposition: **HOLD — SEPARATE OWNER AUDIT**.

This pass does not adjudicate the strong universal claim:

```text
any Selection occurrence, maintenance and transformation require real cost.
```

Two reasons:

1. occurrence, persistence and transformation have already been separated elsewhere;
2. the new minimum L0 author adjudication did not independently derive or reaffirm a universal `cost` theorem from Oriented Openness or Selection.

Therefore:

```text
real cost != automatically derived from non-flatness
real cost != automatically part of Oriented Openness
```

No deletion is authorized here. The section should remain unchanged until a bounded `Ψ_f / cost / primitive occurrence` audit decides whether primitive occurrence itself universally carries cost or whether some cost claims belong to realization / persistence / transformation layers.
