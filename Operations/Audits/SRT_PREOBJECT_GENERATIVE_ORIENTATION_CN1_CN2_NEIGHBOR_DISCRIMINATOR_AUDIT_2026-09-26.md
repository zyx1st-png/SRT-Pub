# CN-1 / CN-2 audit — pre-object generative orientation of cognition

> Role: machine research audit retained as supporting provenance; it no longer owns CURRENT NEXT after the 2026-09-26 convergence freeze.
>
> Boundary: this file does not adjudicate SRT ontology, does not modify canonical owners, and does not claim scientific distinctiveness. Its original temporal-priority framing is superseded in-place by the author's later same-day correction recorded in `01_Source_Intuition/SRT_AUTHOR_ADJUDICATION_L0_FACING_ATTRACTOR_FIELD_FORMATION_CORRECTION_2026-09-26.md`.

## 0. Executive verdict — corrected after author adjudication

The first machine pass correctly found that many mature theories already support organization before explicit articulation, but it framed the root problem too narrowly as:

~~~text
object-first
vs
orientation-first
~~~

The author corrected this.

The root problem is now:

> **How is the whole L0-facing attractor / generative field formed, unified, maintained, normalized and recursively reshaped?**

Therefore the earlier candidate:

~~~text
change in objectifiability / partition structure
~~~

is retained only as one downstream consequence / discriminator of field formation.

The mature-neighbor findings remain useful, but they must now be re-read through a field-formation matrix:

~~~text
FORMATION
UNITY
DIRECTION
NORMALIZATION
POSITION / BEARER INDEXING
PERSISTENCE / GLUE
NONCLOSURE
OBJECTIFICATION
RECURSION
~~~

The strongest immediate burden is not novelty.

It is to determine how each comparator constructs and maintains its global organization and whether the SRT-facing synthesis adds a coherent burden beyond those mechanisms.

CN-3 remains HOLD until that architecture is clearer.

## 1. Controlling author question preserved

The controlling source asks whether cognition is fundamentally better described as:

~~~text
pre-object generative orientation
-> objectification
-> explicit objects / rules
-> retention
-> recursive reshaping
~~~

rather than:

~~~text
explicit objects / rules
-> relations
-> global attractor / direction.
~~~

This audit does not reject that direction.

It asks whether existing cognitive science already carries most of the burden.

## 2. CN-1 neighbor map

### N1 — Skilled Intentionality / field of relevant affordances

Core source family:
- Bruineberg & Rietveld (2014), Self-organization, free energy minimization, and optimal grip on a field of affordances, Frontiers in Human Neuroscience 8:599. DOI: 10.3389/fnhum.2014.00599.
- The Oxford Handbook of 4E Cognition chapter Ecological-Enactive Cognition as engaging with a field of relevant affordances: The Skilled Intentionality Framework (2018), DOI: 10.1093/oxfordhb/9780198735410.013.3.
- Bruineberg, Kiverstein & Rietveld (2018), The anticipating brain is not a scientist, Synthese 195:2417–2444. DOI: 10.1007/s11229-016-1239-1.

Source-native burden:
- selective engagement with multiple affordances simultaneously;
- field of relevant affordances;
- action readiness;
- skill / concern relative solicitation;
- metastable attunement;
- organism-environment coupling;
- learned history embodied in anticipatory dynamics rather than necessarily explicit knowledge structures.

#### SAME / OVERLAP

Strong overlap with:
- global relevance / direction before explicit deliberation;
- expectation-sensitive organization;
- body-world coupling;
- selective openness;
- a field-like organization that determines what stands out;
- history-dependent shaping of later engagement.

The ecological-enactive interpretation is especially important because it explicitly argues that generative-model dynamics need not be understood as internalized representational knowledge structures. It describes internal organization as coupled affordance-related states of action-readiness that shape salience.

#### RESIDUAL / OPEN

Not yet shown to be outside SIF:
- the stronger claim that pre-object organization changes which distinctions can become stable objects, rather than which already available affordances become salient;
- a general objectification mechanism spanning perception, conceptualization and theory-formation;
- SRT-specific Selection / Bearer / gate-geometry reconstruction.

Current disposition:

~~~text
broad pre-object orientation = heavily absorbed
objectification-space burden = OPEN
SRT gain = NOT ESTABLISHED
~~~

### N2 — Affordance Competition Hypothesis

Core source:
- Cisek (2007), Cortical mechanisms of action selection: the affordance competition hypothesis, Philosophical Transactions of the Royal Society B 362:1585–1599. DOI: 10.1098/rstb.2007.2054.

Source-native burden:
- rejects the simple serial picture in which the brain first constructs a complete representation of the world, then decides, then prepares an action;
- multiple currently possible actions can be specified in parallel and compete under contextual / goal constraints.

#### SAME / OVERLAP

This directly absorbs a major action-domain version of:

~~~text
global practical organization
before
fully explicit object -> decision -> action sequence
~~~

#### RESIDUAL / OPEN

It is primarily an action-selection architecture.

It does not by itself establish:
- how perceptual / conceptual object boundaries are generated;
- cross-domain objectification;
- recursive re-cutting of the units over which action competition is defined.

Current disposition:

~~~text
action-domain anti-object-serialism = SOURCE-OWNED
general objectification burden = OPEN
~~~

### N3 — Gestalt / global precedence / scene gist

Representative sources:
- Navon (1977), Forest before trees: The precedence of global features in visual perception, Cognitive Psychology 9:353–383. DOI: 10.1016/0010-0285(77)90012-3.
- Oliva & Torralba (2006), Building the gist of a scene: the role of global image features in recognition, Progress in Brain Research 155:23–36. DOI: 10.1016/S0079-6123(06)55002-2.

Source-native burden:
- global organization can influence / precede local analysis;
- scene gist can be represented using scene-centered global image features without first invoking object segmentation or grouping.

#### SAME / OVERLAP

Very strong visual-domain evidence against the claim that explicit local objects must always be constructed first.

Scene gist is especially close because the formal representation is scene-centered rather than object-centered.

#### RESIDUAL / OPEN

The effect can be explained by global image statistics.

Therefore it does not establish:
- a general cognitive generative orientation;
- Bearer-relative organization;
- a mechanism that changes objectifiability rather than extracting global structure from sensory input.

Current disposition:

~~~text
visual whole-before-object = SOURCE-OWNED
general pre-object ontology = NOT ESTABLISHED
~~~

### N4 — Predictive coding / predictive processing / ecological-enactive FEP

Representative sources:
- Rao & Ballard (1999), Predictive coding in the visual cortex, Nature Neuroscience 2:79–87. DOI: 10.1038/4580.
- Bruineberg, Kiverstein & Rietveld (2018), DOI: 10.1007/s11229-016-1239-1.

Important correction:

The programme must not define predictive processing as uniformly object-model-first.

Rao-Ballard provides hierarchical prediction without requiring fully identified objects at each level.

More strongly, ecological-enactive interpretations of FEP explicitly reject the idea that the generative model must represent the environment as it is; they instead treat it as embodied anticipatory organization steering interaction.

#### SAME / OVERLAP

Predictive families can already provide:
- expectation before final object resolution;
- top-down shaping of lower-level processing;
- continuous prediction-error dynamics;
- history-sensitive anticipatory organization.

#### RESIDUAL / OPEN

The useful pressure question is no longer:

> does prediction presuppose object-like representation?

That is too broad.

The better question is:

> Does the comparator assume a sufficiently fixed latent / hypothesis space, while the proposed generative orientation changes the partitioning or state space from which stable objects are formed?

This remains OPEN and model-specific.

### N5 — Metastable coordination dynamics

Core source:
- Tognoli & Kelso (2014), The Metastable Brain, Neuron 81:35–48. DOI: 10.1016/j.neuron.2013.12.022.

Source-native burden:
- transient self-assembly;
- simultaneous integration and segregation;
- flexible switching;
- continuous spatiotemporal coordination rather than a fixed sequence of isolated representations.

#### SAME / OVERLAP

Strong overlap with:
- continuous organization;
- transient global coordination;
- non-fixed attractor dynamics;
- flexible reconfiguration.

#### RESIDUAL / OPEN

Metastability is a dynamical architecture, not by itself a theory of:
- object boundary formation;
- what makes a distinction load-bearing;
- why one partition becomes the explicit cognitive unit.

Therefore:

~~~text
continuous dynamics = absorbed
objectification criterion = OPEN
~~~

### N6 — Event Segmentation Theory

Core sources:
- Zacks et al. (2007), Event perception: a mind-brain perspective, Psychological Bulletin 133:273–293. DOI: 10.1037/0033-2909.133.2.273.
- Nolden et al. (2024), Prediction error and event segmentation in episodic memory, Neuroscience & Biobehavioral Reviews 157:105533. DOI: 10.1016/j.neubiorev.2024.105533.

Source-native burden:
- ongoing experience is continuous;
- perceptual systems continuously predict what happens next;
- transient prediction errors contribute to perceived event boundaries;
- segmentation regulates attention and memory;
- meaningful discrete event units emerge from ongoing processing.

#### SAME / OVERLAP

This is a direct strong neighbor to:

~~~text
continuous orientation / prediction
-> local boundary formation
-> explicit discrete unit
-> memory consequences
~~~

It therefore strongly pressures any claim that continuous field -> discrete objectification is itself distinctive.

#### RESIDUAL / OPEN

Possible remaining distinction:

~~~text
event segmentation
often explains where a boundary is inserted
within an ongoing predictive stream;

current SRT intuition may be stronger:
the prior organization may determine
which dimensions / distinctions are available
to become stable objects at all.
~~~

But this stronger reading is not yet author-adjudicated as the controlling residual.

### N7 — latent-cause / structure learning

Representative sources:
- Gershman, Blei & Niv (2010), Context, learning, and extinction, Psychological Review 117:197–209. DOI: 10.1037/a0017808.
- Gershman & Niv (2010), Learning latent structure: carving nature at its joints, Current Opinion in Neurobiology 20:251–256. DOI: 10.1016/j.conb.2010.02.008.
- Gershman, Norman & Niv (2015), Discovering latent causes in reinforcement learning, Current Opinion in Behavioral Sciences 5:43–50.
- Lu et al. (2024), Reconciling shared versus context-specific information in a neural network model of latent causes, Scientific Reports 14:16782.

Source-native burden:
- state representation need not be given in advance;
- learners infer latent causes / contexts;
- experience is partitioned into states or causes according to inferred structure;
- generalization boundaries can themselves be learned.

#### SAME / OVERLAP

This is the strongest direct threat to the current CN-3 toy-world idea.

A participant can:
- learn transition regularities before labels;
- infer hidden states;
- detect anomalies;
- later map labels onto already learned latent structure;

without requiring a distinct SRT pre-object mechanism.

Therefore:

~~~text
unlabeled relational learning
+
anomaly detection
+
later discrete category formation
~~~

is not sufficient.

#### RESIDUAL / OPEN

A stronger test must distinguish:

~~~text
learning hidden states / latent causes
within an inferred model
~~~

from:

~~~text
changing the organization / partition space
that determines what can count as a stable state or object.
~~~

Whether this distinction is coherent and empirically separable remains OPEN.

### N8 — continuous relational geometry / cognitive maps / conceptual spaces

Representative sources:
- Gärdenfors (2000), Conceptual Spaces: The Geometry of Thought, MIT Press.
- Gärdenfors (2025), The Geometry and Dynamics of Meaning, Topics in Cognitive Science 17:34–56. DOI: 10.1111/tops.12767.
- Whittington et al. (2020), The Tolman-Eichenbaum Machine, Cell 183:1249–1263.e23. DOI: 10.1016/j.cell.2020.10.024.

Source-native burden:
- cognition can use continuous / geometric structure;
- concepts can correspond to regions in a geometry;
- relational structure can support generalization across spatial and nonspatial tasks;
- object / label identity need not be the primitive basis of all structure.

#### SAME / OVERLAP

This absorbs:
- continuous geometry before symbolic object;
- relational / metric structure before explicit naming;
- later concept boundaries carved from continuous spaces.

#### RESIDUAL / OPEN

Potential pressure point:

Conceptual-space and cognitive-map approaches typically still specify:
- dimensions;
- latent variables;
- relational structure;
- learning rules.

The current intuition may be asking a deeper question about how the operative dimensions / equivalence relations themselves become selected and normalized.

That is a candidate burden, not an established difference.

### N9 — statistical learning

Core source:
- Saffran, Aslin & Newport (1996), Statistical learning by 8-month-old infants, Science 274:1926–1928. DOI: 10.1126/science.274.5294.1926.

Source-native burden:
- infants can use transition statistics to segment continuous speech after brief exposure;
- explicit rule instruction is unnecessary.

### Consequence

~~~text
structure before explanation
~~~

and

~~~text
segmentation before explicit rule report
~~~

are both heavily source-owned.

This means preformal-coherence tasks remain useful as assays but cannot carry the root claim.

### N10 — object individuation in infancy

Representative source:
- Xu & Carey (1996), Infants’ Metaphysics: The Case of Numerical Identity, Cognitive Psychology 30:111–153. DOI: 10.1006/cogp.1996.0005.

Important terminological warning:

Their Object-first Hypothesis is not the same as the current programme’s object-first family.

The infant literature shows that object individuation can exist before rich kind concepts or naming.

Therefore:

~~~text
no explicit name / category
!= no object representation
~~~

This is a critical anti-overreach guard for CN-3.

## 3. CN-1 synthesis

### What is already strongly occupied

The following broad claims are not viable as SRT-specific residuals:

~~~text
global organization can precede explicit object recognition;
action-readiness can precede deliberative object judgment;
continuous dynamics can precede discrete cognitive states;
prediction can precede final object resolution;
unlabeled statistical structure can be learned;
experience can be segmented into latent states / events;
continuous geometry can support later concepts;
object identity can exist without explicit naming.
~~~

### Current strongest candidate burden

The most promising remaining question is narrower:

> Does prior generative organization merely weight / predict / select among states in an already usable representational space, or can it alter the operative partition / equivalence structure that determines which distinctions become stable objects, events or states?

Working diagnostic phrase only:

~~~text
change in objectifiability / partition structure
~~~

Do not harden this as a new SRT term without lexical and author review.

Replace:

M0 object-first

with at least these comparator families:

| Family | What is fixed? | What can change? | Already explains |
|---|---|---|---|
| C0 fixed object / discrete-state models | object/state vocabulary | weights, values, relations | learning over pre-given units |
| C1 global perceptual organization | local features | grouping / whole configuration | Gestalt, scene gist |
| C2 affordance / action-readiness | body-environment possibilities | relevance, solicitation, action competition | field of affordances, skilled action |
| C3 predictive / generative models | model-dependent latent space | posterior / precision / prediction | top-down anticipation, context effects |
| C4 structure learning / event segmentation | observation stream | latent causes, boundaries, states | discovered state representations |

| C6 current pre-object proposal | OPEN | possibly the partition / objectifiability structure itself | not yet independently established |

CN-2 must compare C6 against C1–C5, not only C0.

## 5. Revised discriminator requirements

A future experiment should not count as discriminating merely because:

- behavior precedes verbal explanation;
- global context affects local judgment;
- participants learn before labels;
- continuous dynamics fit better than a simple object graph;
- categories emerge after transition learning;
- action readiness shifts with goals or concerns.

Each of these already has strong non-SRT explanations.

A stronger candidate test would need to show at least one of the following under preregistered model comparison.

### D1 — partition-space change

Hold local inputs and learned transition statistics as constant as practical.

Manipulate a global / embodied / expectation condition.

Test whether participants change:
- which dimensions are treated as equivalent;
- where category / event / object boundaries are formed;
- what counts as a stable unit for transfer.

Critical burden:

> can fixed-latent-space predictive, latent-cause and continuous-state models explain the same result without changing their representational basis?

### D2 — recutting rather than reweighting

After an initial partition has stabilized, change the broader orientation while preserving local evidence.

Look for:
- reopening of previous boundaries;
- reorganization of similarity structure;
- transfer across old boundaries;
- emergence of a new partition not captured by simple value / salience reweighting.

### D3 — recursive history

After explicit object / rule learning, remove explicit labels and test whether:
- pre-explicit similarity;
- transition expectation;
- spontaneous segmentation;
- action readiness

remain changed.

This must be compared against ordinary latent-cause updating and memory consolidation, not merely against a no-learning control.

### D4 — same explicit knowledge, different operative cut

Match explicit recall / rule knowledge across groups.

Manipulate a consequence / concern / action-readiness history.

Ask whether the same nominal knowledge produces different spontaneous objectification / segmentation.

Strong caution:
Skilled Intentionality already predicts concern- and skill-relative differences, so this is not SRT-specific without a sharper residual.

## 6. Consequence for CN-3 toy-world design

The current toy-world idea remains promising but is under-discriminating as written.

Original weak signature:

~~~text
learn transitions before labels
-> detect anomaly
-> later categories appear
~~~

can be explained by statistical learning, latent causes, cognitive maps, event segmentation and continuous latent-state models.

### Required CN-3 upgrade before preregistration

The toy world should include:

1. identical local symbol set across conditions;
2. matched exposure and transition statistics where possible;
3. an independent manipulation of global orientation / consequence / task geometry;
4. spontaneous pre-label partition probes;
5. post-label recutting / transfer probes;
6. explicit model comparison including at minimum:
   - discrete-state baseline;
   - latent-cause / structure-learning baseline;
   - continuous latent-state / manifold baseline;
   - affordance/action-readiness interpretation where relevant;
7. a preregistered absorption rule:

~~~text
if C1-C5 explain the key effect without the extra C6 burden,
SRT incremental gain = ZERO for this experiment.
~~~

CN-3 should not freeze until the C6 burden is author-adjudicated.

## 7. Author adjudication required before hardening

This audit reaches a substantive fork.

### Q1 — weak reading

Is the intended root claim only:

> cognition has global / continuous / anticipatory organization before explicit objects and rules?

If yes:

~~~text
mature-neighbor absorption = VERY HIGH
SRT-specific gain = likely narrow or zero
~~~

The programme can still be useful as synthesis, but should not search for a forced residual.

### Q2 — stronger reading

Is the intended claim:

> the prior organization does not merely weight or predict over already available units; it helps constitute the operative distinctions / equivalences / partitions from which objects become formable?

If yes:

~~~text
this is the leading residual candidate
but it requires formal clarification and direct comparison
with structure learning, event segmentation,
conceptual spaces and ecological-enactive cognition.
~~~

### Q3 — SRT-specific components

Should Bearer / structural Expectation / Selection / gate geometry enter the first neutral cognitive discriminator?

Current machine recommendation:

~~~text
NO for the first neutral test.
~~~

Reason:
adding them now risks making the comparator impossible to falsify and conflating the neutral cognitive phenomenon with SRT interpretation.

Preferred sequencing:

~~~text
neutral partition / objectification burden
-> empirical discriminator
-> only then test whether SRT-specific typing adds explanatory gain.
~~~

This recommendation is M-level analysis, not author adjudication.
