
```text

```

## 4. Neighbor C — phenomenological horizon / foreground-background structure

Classical phenomenology already distinguishes focal awareness from marginal / horizonal awareness and treats experienced objects as given within wider horizons and enabling background conditions.

A current Stanford Encyclopedia of Philosophy overview states that phenomenology analyzes attention as including focal and marginal or horizonal awareness, and that experience opens onto wider implicit horizons and enabling conditions.

Reference used for this pass:

- Stanford Encyclopedia of Philosophy, `Phenomenology`: https://plato.stanford.edu/entries/phenomenology/

The repository's own L0 philosophy bridge already guards the key scope distinction:

```text
Husserlian horizon
= horizon / margin of already manifested conscious experience;

SRT L0
= proposed source-condition for manifestation itself,
  not merely the fringe of an already manifested object.
```

### Payment

Phenomenology strongly pays:

```text
focal object != exhaustive experiential field;
what is thematic is surrounded by a non-thematic horizon;
background conditions shape how an object can appear.
```

### Residual pressure

Phenomenology therefore prevents SRT from claiming that foreground/background itself is novel.

The possible SRT difference is the **ontological relocation**:

```text
foreground/background is not only a structure of conscious appearance;
subjectless Selection is allowed before consciousness / bearer;
L0 is not merely the horizon of an already constituted subject-object correlation.
```

That difference remains architectural, not a newly demonstrated mechanism.

## 5. Neighbor D — predictive-state / computational-mechanics reconstruction

A stronger state-space opponent should not be caricatured as a warehouse of hidden physical objects.

### 5.1 Predictive State Representations

Littman, Sutton & Singh, `Predictive Representations of State` (NeurIPS 2001), represent dynamical-system state using multi-step action-conditional predictions of future observations rather than requiring a privileged hidden-state ontology. They show a linear predictive representation can exist with no more predictions than states in a minimal POMDP model.

Primary public source:

- https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf

### 5.2 Computational mechanics

Shalizi & Crutchfield's computational mechanics constructs causal states as predictive equivalence classes of histories and argues that the resulting epsilon-machine is a minimal representation consistent with accurate prediction.

Reference:

- Shalizi & Crutchfield, `Computational Mechanics: Pattern and Prediction, Structure and Simplicity`, Journal of Statistical Physics 104 (2001); arXiv preprint: https://arxiv.org/abs/cond-mat/9907176

### Payment

These frameworks strongly pressure any argument of the form:

```text
state-space model must begin from hidden finished objects;
therefore any state representation is automatically object-first ontology.
```

That argument fails.

A state can be operationally / relationally reconstructed from predictive regularities in observation histories.

### But a new boundary appears

Predictive-state approaches still require a declared observational / intervention interface:

```text
observations;
actions / tests where applicable;
history equivalence;
predictive distributions.
```

MOBJ-A can therefore ask a prior constitutive question without denying predictive closure:

> **What makes something count as one determinate observation / action / test / distinction in the first place?**

A predictive state may be fully sufficient for future observable prediction while remaining downstream of the manifest interface from which that state was reconstructed.

This does **not** prove that predictive-state formalisms are ontologically incomplete. It establishes only that predictive completeness and the constitution of the observation alphabet are different burdens.

## 7. What survives the composite subtraction?

The surviving SRT candidate is no longer a slogan-level novelty claim. It is an explicit **dependency organization**:

```text
minimal non-objectified non-neutrality
-> subjectless Selection
-> simultaneous manifestation + relative backgrounding
-> the manifest side becomes objectifiable at that level
-> the background side is not deleted and can remain a condition for later Selection
-> repeated Selection may sediment / reconstitute a Selection-position
-> bearer / cognition are later continuity / attribution structures.
```

The strongest current SRT claim is therefore:

> **Manifestation is not an unexplained floor. Objecthood is a downstream role in a Selection-first dependency architecture.**

This survives as an author-owned theory organization.

What is **not** yet established is that no Barad+Simondon+horizon+predictive-state composite can reproduce an ontologically equivalent organization.

## 8. Anti-redundancy / non-substitutability test

The correct replacement test is now:

```text
Replace:
L0 + Selection + manifestation

with:
constitutive cut + preindividual dynamics + horizon/background + predictive state.
```

Ask what is lost.

### If nothing is lost

If the composite preserves all of the following without importing SRT's labels:

```text
what counts as pre-object rather than hidden object;
why determinate observability is downstream;
foreground/background co-determination;
continued causal relevance of background;
from-where / Selection-position reconstitution;
late emergence of bearer/cognitive attribution;
```

then MOBJ-A remains a coherent SRT organization but does not earn comparative non-substitutability.

### If something is lost

A serious residual must identify a relation such as:

```text
one and the same constitutive event
simultaneously establishes:
- what is manifest / objectifiable now;
- what is relatively backgrounded now;

while the non-manifest side remains structurally available to shape later constitution,
so that repeated differentiated manifestation can form a non-flat later from-where.
```

The burden is to show that this relation is not already paid by the composite in source-native terms.

That proof has **not** been completed here.
