## 2. Why B + C alone was incomplete

A minimal B+C reading can be stated as:

```text
higher-order organization
+ consequences close on it
+ functions may change inside it
```

That is a good anti-functionalism guard, but it leaves two hidden assumptions:

1. **Why does later Selection repeatedly resume from this organization rather than merely occur somewhere inside the same analyst-drawn container?**
2. **What internally differentiates a living Selection-position from a flat collection of mutually coupled functional roles?**

The 2026-09-07 vertical / three-dimensional strengthening directly pressures both questions.

---

## 3. Why vertical structure alone remains incomplete

The reverse collapse is still unsafe:

```text
persisting foreground/background asymmetry
-> same bearer
```

A system can maintain a stable priority hierarchy, attractor landscape, active/inactive split or gating structure without thereby showing:

```text
same-unit consequence return;
history ownership;
non-outsourcing;
bearer continuity;
subjecthood;
phenomenality.
```

Thus vertical structure is author-confirmed as part of the bearer-continuity burden only **in conjunction with** historical consequence bearing and reconstitution. It remains insufficient by itself.

## 4. Three-relation decomposition

### Horizontal — functional topology

```text
which roles interact;
which function is implemented where;
which components are recruited / dropped / migrated;
which modules cooperate, compete or substitute.
```

Osako-style reusable computation lives primarily here.

### Vertical / stratified — Selection-position topology

```text
what is foregrounded / manifested relative to what is backgrounded;
which alternatives remain relatively suppressed / latent;
how repeated two-sided Selection sedimentation produces a non-flat position
from which later Selection can resume.
```

This is not anatomical verticality. It is a stratified relation of selective standing.

### Diachronic — consequence/history closure

```text
where consequences return;
which continuing organization is altered by them;
where repair / cost / liability / history remain non-outsourcably effective;
how those consequences alter later selectability.
```
