# Functional continuity / bearer continuity × vertical-structure cross-pressure

> **Question:** after the author selected `FC-B + FC-C`, does the 2026-09-07 author-strengthened「立体结构」change the meaning of bearer continuity, or only supply an upstream condition on stable Selection-position?
>
> **Verdict of this pass:** the cross-read is **substantive and necessary**, but it does not yet authorize a new bearer criterion. The cleanest current reconstruction is a **three-relation decomposition**—horizontal functional organization, vertical/stratified Selection-position organization, and diachronic consequence closure—while preserving `selection-position != bearer` until further author adjudication.

## 2. Why B + C alone is incomplete

A minimal B+C reading can be stated as:

```text
higher-order organization
+ consequences close on it
+ functions may change inside it
```

That is a good anti-functionalism guard, but it leaves two hidden assumptions:

1. **Why does later Selection repeatedly resume from this organization rather than merely occur somewhere inside the same analyst-drawn container?**
2. **What internally differentiates a living Selection-position from a flat collection of mutually coupled functional roles?**

The 2026-09-07 vertical / three-dimensional strengthening directly pressures both questions.

It says the stable position cannot be generated by horizontal co-location or coupling alone. A persisting selection-position requires a sedimented asymmetry between what is relatively foregrounded / manifested and what is relatively backgrounded / latent.

Therefore B+C should not be read as a merely higher-level container theory.

---

## 3. Why the vertical structure alone is also incomplete

The reverse collapse is equally unsafe:

```text
persisting foreground/background asymmetry
-> same bearer
```

This fails existing owner discipline.

A system can maintain a stable priority hierarchy, attractor landscape, active-set / inactive-set split or gating structure without thereby showing:

```text
same-unit consequence return;
history ownership;
non-outsourcing;
bearer continuity;
subjecthood;
phenomenality.
```

Thus the vertical relation is currently strongest as a **Selection-position formation / maintenance constraint**, not a bearer identity theorem.

---

## 4. Three-relation decomposition — current best C-level reconstruction

The combined material suggests distinguishing three relations that had been at risk of collapse.

### 4.1 Horizontal relation — functional topology

```text
which roles / processes interact with which;
which function is implemented where;
which components are recruited / dropped / migrated;
which modules cooperate, compete or substitute.
```

Osako-style reusable computation lives primarily here.

Properties may change while a higher-order bearer continues.

### 4.2 Vertical / stratified relation — Selection-position topology

```text
what is foregrounded / manifested relative to what is backgrounded;
which alternatives remain relatively suppressed / latent;
how repeated two-sided Selection sedimentation produces a non-flat position
from which later Selection can resume.
```

This is not anatomical verticality. It is a **stratified relation of selective standing**.

The contents of foreground/background may change. The candidate continuity therefore should not be prematurely identified with a fixed ranking.

### 4.3 Diachronic relation — consequence/history closure

```text
where consequences return;
which continuing organization is altered by them;
where repair / cost / liability / history remain non-outsourcably effective;
how those consequences alter later selectability.
```

This is the PH-IND02 / PH-IND06 burden.

## 5. Candidate integrated architecture

The most coherent current machine synthesis is:

```text
Selection event
-> manifestation / relative backgrounding

repeated events
-> sedimented vertical / stratified asymmetry
-> persisting Selection-position

within / around that position:
functional roles may horizontally migrate, split, disappear or be recruited

if consequences of those operations
recurrently return to / alter / constrain
one higher-order continuing organization
and later Selection continues from the reconstituted position,
then that organization is a stronger bearer candidate.
```

A more compressed statement:

> **Bearer continuity is not continuity of one function. A candidate bearer is a higher-order consequence-bearing organization that keeps reconstituting a stratified Selection-position while its concrete functions and components may change.**

Status:

```text
AI synthesis / C
NOT author-confirmed as a full sentence
NOT a canonical definition
NOT a necessary-and-sufficient theorem
```

## 6. What becomes clearer about “same bearer”

The cross-read improves the replacement / re-instantiation question.

### Same-bearer candidate

```text
function migrates / implementation changes
BUT
prior consequences remain internally load-bearing for the continuing organization
AND
those consequences participate in reconstituting the stratified position
from which later Selection proceeds.
```

### Mere functional re-instantiation candidate

```text
same function / same performance is restored
BUT
old consequences do not need to be borne by the new instance as part of its own
reconstitution; the functional position can be instantiated again from outside.
```

This sharpens the **question**, but does not solve perfect copying.

If a perfect copy reproduces:

```text
all current functional organization
+ all current vertical / stratified structure
+ all current causal state
```

then PH-IND05's branching / consequence-separability problem remains. The present pass must not manufacture a hidden token-provenance variable.

```text

+
```

with Simondon as formation pressure and functionalism as a useful but weaker anti-collapse comparator.

A final strongest-neighbor selection still requires a source-native pass under current governance.

## 9. Anti-degeneracy problem is now more visible

The combined architecture creates one sharper risk.

If “vertical structure” means only:

```text
some state variables have larger weights / activations / access probabilities
than others over time
```

then ordinary recurrent learning, attention, gating, attractor dynamics or control hierarchy can absorb it.

If “consequence closure” means only:

```text
past events are encoded in current state
```

Cycle-1 ordinary-learning absorption returns.

Therefore any future Level-1/2 route must avoid both reductions simultaneously.

A valid future discriminator would need to show that the **unit / identity / consequence-attribution structure** changes when:

```text
horizontal functional realization is held flexible,
vertical selective stratification is present,
and consequence closure is manipulated or re-routed,
```

in a way not exhausted by generic recurrent state encoding or ordinary autonomous control.

No such discriminator is claimed here.
