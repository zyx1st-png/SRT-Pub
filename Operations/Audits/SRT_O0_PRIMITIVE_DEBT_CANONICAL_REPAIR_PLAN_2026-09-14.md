# O0 primitive-debt canonical repair plan

> **Scope:** bounded planning only. This file does not edit canonical owners and does not authorize canonical landing.

## 0. Controlling author result

The accepted upstream structure is:

```text
G0 primitive generativity
=
co-primitive {
  O0 non-maximal indifference,
  S0 actualising Selection
}
```

Hard guards:

```text
O0 before S0: NO;
S0 before O0: NO;
O0 causes S0: NO;
S0 produces O0: NO;
orientation != goal / value / probability / continuation preference;
openness != possibility container / branch inventory;
finite positionality != evaluative standpoint;
O0 does not answer why A rather than B;
old strong epsilon does not define O0;
O0 != morality.
```

The repair target is therefore not to invent new content, but to remove older proof-load that contradicts or back-defines this structure.


The current `开放但不平坦` section already contains much of the right negative boundary and should be the semantic center of the repair rather than being replaced wholesale.

## 1.2 Rewrite

The later section currently re-objectifies the primitive layer through language such as:

```text
潜在域是尚未被选择的可能性场;
潜在域是绝对的、不可分割的;
潜在域具有内在颗粒性;

```

Future repair should replace this primitive-container reading with a mode / relation reading:

```text
potentiality / latent language
= shorthand for what is not exhausted by completed determinate actuality;
!= an independently existing warehouse of formed possibilities;
!= a thing temporally prior to Selection.
```

Recommended semantic move:

```text
primitive reality = G0 generativity;
"potential / latent" = a modal read of generativity not exhausted by actualised determination;
Selection = the actualising differentiation face of the same primitive generativity.
```

Do not introduce a new term merely to rename the old field.

## 1.3 Retype

`intrinsic granularity / κ0` should no longer define minimum O0.

Future owner wording should type them as:

```text
stronger formal / realization commitments or candidate implementations
of non-flat generativity,
whose exact necessity / independence / inheritance remains owner-level OPEN.
```

This repair does **not** itself delete `κ0`, deny all anisotropic formal models, or settle the `κ0` dependency graph.

## 1.4 Remove proof-load

Remove any implication of:

```text
possibility field -> Selection;
intrinsic granularity -> first actualisation;
κ0 -> sufficient ground of Selection;
latent-domain object -> ontological thing prior to generativity.
```

## 1.5 Keep OPEN

```text

how ε_pg should survive as a symbol after strong epsilon is removed;
how primitive non-flatness inherits into later recurrent-position continuation asymmetry;
formal representation of openness without an option inventory.
```

```text

non-self-erasure preference is primitive;
```

These loads must be removed from primitive O0.

```text

   = non-maximally-indifferent generativity / irreducible non-flat role-structure;

   = no longer licensed to encode B>=2 > B<=1 at primitive level;
   exact future status requires a separate symbol / dependency audit.
```


That identification has not been author-established.

must lose canonical primitive theorem status.

Likewise:


must not remain as the definition of primitive non-neutrality unless a later bounded audit independently re-establishes it under a new non-continuation meaning.

## 2.4 `MA-2` warning

That sentence must be removed or replaced.

```text
A contentless structural asymmetry may be admissible at L0;

probability ordering, value ordering or preferred outcome class.
```

## 3.4 Preserve read-back discipline




## 4.2 Rewrite the reference semantics

Current text assumes:

```text

every Selection has an order-direction;
T_dir=0 means the direction/value exists but is hidden.
```

This can no longer carry canonical proof-load.

Recommended future definition:

```text
T_dir(D_ref)
= degree to which an independently established directional reference D_ref
  is available to the relevant formed system / position
  for self-readback and effective reorientation.
```

Key direction:

```text

T_dir measures access to D_ref;
T_dir does not prove D_ref exists;
T_dir does not prove D_ref is good;
T_dir does not prove D_ref is universal.
```

Possible `D_ref` sources may later include:

```text

relation-relative O2-C constraint;
a domain-specific declared task direction;
a bridge-level empirical / phenomenological direction.
```

No one source is primitive merely because T_dir can read it.

when a relevant `D_ref` or O1/O2 standing has independently been established.
