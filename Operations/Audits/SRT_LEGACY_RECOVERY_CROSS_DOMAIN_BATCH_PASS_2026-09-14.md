### Standing

The batch contains many old claims about:

```text

```

After current One / Collective subtraction, none supplies a new universal admission rule for Standing.

```text

```

Exact old-One expansion versus new higher-order One, exact unit, scale, strict identity and branch / merge identity remain OPEN.

### Shaping

This is where the batch has the strongest reusable implementation material.

Old `Agential Material` / nested-controller language carries the burden:

```text
higher-scale organization need not micromanage lower-scale detail;
it may alter constraints / target landscape / interface conditions;
lower-scale competent processes may locally realize the detail.
```

Safe current typing:

```text
higher-order constraint
-> changes lower-scale selectability / costs / accessibility / interface conditions
-> lower-scale Selection realizes local detail
= cross-scale delegated Shaping candidate.
```

This is **not** a sixth relation and does not mean:

```text
higher scale causes primitive Selection;
lower-scale unit loses Standing;
constraint delegation = Bearer;
constraint delegation = Revision automatically;
local competence = agency / consciousness automatically.
```

Current B13 multi-level notes, scale bridges and Collective Selection already pay much of this burden. Its value here is therefore bridge-level organization / implementation, not core novelty.

### Bearing

Legacy AI / mortality material repeatedly claims that computation gains meaning only when error threatens the system's own survival or continued existence.

The recoverable thin burden is:

```text
stronger bearing requires consequences to matter to the continuing unit itself,
not merely to an external maintainer or model.
```

But current Bearer routing already generalizes this as:

```text
formed One / Selection-position + P prospective self-indexing
+ E same-One prospective exposure
-> Bearer.
```

Therefore:

```text
metabolic vulnerability = Bearer necessary condition    NOT RECOVERED;
mortality = consciousness necessary condition           NOT RECOVERED;
biological death risk = universal meaning condition     NOT RECOVERED.
```

The legacy material is lineage / intuition support for prospective exposure, not a new Bearing relation.

### Revision

Prediction-error feedback, Transformer weight / attention updates, institutional change, parameter change and changed energy landscapes appear throughout the batch.

They must stay typed conservatively:

```text
changed weight / cost / accessibility / salience / path preference
= Shaping unless more is established;

consequence-sensitive change to the process's own
comparison rules / boundaries / candidate-generation or reopening conditions
= Revision candidate under B13.
```

Thus old `reparameterization`, learning or feedback language does not by itself add a Revision burden.
