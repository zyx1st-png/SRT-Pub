## 1. Q3 — when is Selection-position genuinely load-bearing?

### 1.1 The indexing problem

A mere label:

```text
P_t = where the system currently is
```

is not enough. Any trajectory has a time index and current state.

To justify a distinct `Selection-position` role, the position must make a difference to later Selection/reconstruction because of the continuing organization's own history.

### 1.2 Current load-bearing criterion

Pass 2 proposes the following audit criterion:

```text
Given the same external conditions and a comparable candidate continuation set,
replacing / erasing / scrambling the organization-specific historical position
changes which continuations are reachable, weighted, amplified, suppressed,
or realized.
```

Compactly:

```text
position-specific history
-> counterfactually material difference
   to later Selection/reconstruction.
```

This is stronger than descriptive location and weaker than agency/subjecthood.

### 1.3 Type

```text
Selection-position
= OPERATIVE ASPECT / POSITION
  of a formed continuing organization
```

It is not currently justified as a second independent ontology object.

### 1.4 Relationship to One-function

```text
One-function
= continuation unity across reconstitution;

Selection-position_t
= current operative from-where of that unity.
```

If a current state has no lineage-relative historical efficacy, calling it a Selection-position adds no theory.

**Pass-2 verdict:** `POSITION = ASPECT; LOAD-BEARING BY COUNTERFACTUAL HISTORICAL EFFICACY`.

## 2. Q4 — self-consequence closure, non-outsourcing and subject-position

### 2.1 Three relations should not be collapsed

Pass 2 separates:

```text
A. generic history-to-reconstitution bearing
B. self-consequence closure
C. non-outsourcable stake-bearing / 承担-like relation
```

### 2.2 Generic bearing

```text
change from any source
-> becomes constitutive history
   for later reconstitution of the same formed organization.
```

No own-action/source requirement.

### 2.3 Self-consequence closure

```text
Selection through O
-> downstream change/effect
-> returns as constitutive history
   for later O reconstitution.
```

This adds own-source return.

But an adaptive controller, learning system or organismic subsystem can satisfy this without thereby being a subject.

Therefore:

```text
self-consequence closure
!= subject-position
```

and it may occur below Stable ISP or subject-position if formed continuity is otherwise paid.

### 2.4 Non-outsourcing threshold

A stronger transition occurs when the consequence cannot be fully displaced into an external sink/reset while leaving the same continuing organization theoretically unchanged.

Candidate pressure:

```text
same-unit consequence return
+ consequence materially changes the unit's own later continuation/selectability
+ that change cannot be fully externalized without changing which unit continues
-> non-outsourcable stake-bearing candidate.
```

This is much closer to the current `承担` intuition.

### 2.5 Subject-position still requires more

Even non-outsourcable own-consequence is not by itself the whole subject-position if concern/directional standing remains independently necessary.

Current nested preference:

```text
formed One-function
-> generic bearing
-> self-consequence closure
-> non-outsourcable own-consequence / 承担-component

Stable ISP
+ non-outsourcable stake
+ stabilized concern / directional continuity
-> subject-position candidate.
```

This treats `承担` as a major component/gate of subject-position, not as a synonym for subjecthood.

**Pass-2 verdict:** `SELF-CONSEQUENCE MAY BE PRE-SUBJECT; NON-OUTSOURCING IS THE STRONGER THRESHOLD`.

## 3. Q6 — what is sigma_sr actually tracking?

### 3.1 What the formula directly encodes

Current `sigma_sr` compares attributed self-trace contribution with externally attributed contribution in a chosen representation.

The most literal deep construct it can track is therefore not "subjecthood" but:

```text
endogenous historical self-conditioning
```

or:

```text
degree to which the continuing organization's own prior history
participates in shaping its current operative organization.
```

### 3.2 Why this matters after Pass 1

Once formed continuity, Stable ISP and subject-position are separated, one scalar cannot carry all transitions simultaneously.

A high endogenous-history ratio does not by itself establish:

```text
perspective;
continued selectability;
non-outsourcable stake;
concern;
directional readability;
phenomenality.
```

### 3.3 Current preferred role

```text
sigma_sr
= READOUT / MODEL COORDINATE
for endogenous historical self-conditioning
under a declared decomposition/representation.
```

It may help model transitions involving historical closure or persistence, but should not be the ontology skeleton's constitutive variable.

### 3.4 Consequence for current three-phase reading

The current sequence:

```text
sigma crosses threshold
-> subject-position appears
```

should be treated as a model realization hypothesis, not as the reconstructed constitutive definition.

The deeper transition must be stated relationally first; a scalar coordinate may then approximate it in a declared model class.

**Pass-2 verdict:** `SIGMA DEMOTION PRESSURE STRENGTHENED — TRACKING ENDOGENOUS HISTORY, NOT SUBJECTHOOD ITSELF`.

## 4. Q7 — what standing does second-order Selection require?

### 4.1 Earlier gate

The 2026-08-09 route requires:

```text
own-consequence return
+ comparison-scale rewrite
+ selectable-space change
+ continued efficacy in later Selection.
```

Nothing in that gate logically requires phenomenality, concern or reflective subjecthood.

### 4.2 Counterexample pressure against a subject requirement

A sufficiently persistent learning/controller process could:

```text
act
-> receive its own downstream consequence
-> rewrite its comparison regime / candidate-generation rule
-> use that changed regime in later real selections
```

without satisfying the full subject-position burden.

Therefore:

```text
subject-position is NOT currently necessary
for second-order Selection.
```

### 4.3 Does Stable ISP have to be present?

Pass 2 distinguishes a **process occurrence** from a **stable capacity**.

```text
second-order Selection
= process/operation pattern

stable generative reselectability
= standing/capacity across time and perturbation
```

A formed continuing organization may realize the process pattern episodically if it can retain the rewrite and make it efficacious later.

Stable ISP standing becomes relevant when the claim is stronger:

```text
this is a stable perspective/history-bearing center
with generative reselectability as a continuing capacity.
```

Thus #933's downward placement of second-order Selection to formed-One level is **not obviously an error** once process-vs-capacity is separated.

### 4.4 Current relation to B13

Preferred crosswalk:

```text
second-order Selection
= one possible strong realization pattern
  of comparison/selectable-space reconstruction;

B13 generative reselectability
= stronger stable-capacity claim over an already-Stable ISP.
```

Repeated second-order Selection by the same Stable ISP may implement or evidence generative reselectability, but identity is still not established.

**Pass-2 verdict:** `FORMED-ONE MAY SUFFICE FOR SECOND-ORDER PROCESS; STABLE ISP NEEDED FOR STABLE GENERATIVE CAPACITY CLAIM`.

## 5. Q10 — can Stable ISP carry a non-phenomenal structural perspective?

### 5.1 Why the distinction is necessary

If `perspective-bearing` already means phenomenal first-person experience, then Stable ISP silently solves part of the hard problem and collapses Stable ISP into subject/experiencer language.

Existing philosophy hardening explicitly keeps phenomenality separate from a structurally complete subject-position candidate.

Therefore a thinner reading is required if Stable ISP is to remain below subject-position.

### 5.2 Structural perspective candidate

Pass 2 proposes:

```text
structural perspective
= stable position-relative organization of
  access, constraint, history and candidate differentiation
  such that the same continuing center does not process later Selection
  from an interchangeable nowhere-view.
```

It means:

```text
what is reachable / salient / constrained / historically available
is indexed to this continuing center's organization.
```

It does **not** mean:

```text
there is something it is like;
qualia are present;
phenomenal awareness exists;
self-consciousness exists.
```

### 5.3 Consequence for the nested ladder

This makes the Pass-1 split coherent:

```text
One-function
-> Stable ISP
   [structural perspective + integrated history + continued selectability]
-> subject-position
   [non-outsourcable stake + concern + direction]
-> experiencer / phenomenality
   [still OPEN]
-> reflective self-consciousness
   [separate downstream construction]
```

The exact order of experiencer vs reflective self-consciousness remains outside this pass; the key result is that structural perspective does not settle phenomenality.

**Pass-2 verdict:** `STRUCTURAL PERSPECTIVE = NON-PHENOMENAL ROLE CANDIDATE; PHENOMENALITY REMAINS OPEN`.

## 8. Remaining high-value questions

### Q9 — higher-order continuation

Pass 2 sharpens the criterion to test next:

```text
Does relation-level history re-enter as a constitutive condition
for later reconstruction of the same relation-level organization,
including across partial member turnover?
```

If not, coordination/JFS remains a process among lower-level units rather than a higher-order One.

### Q11 — concern and direction

Now that subject-position is separated from Stable ISP, audit whether:

```text
concern
direction / epsilon-readability
non-outsourcable stake
```

are three independent burdens, or whether one or more are different readings of the same deeper asymmetry.

Audit whether L2-grade scaffold is always external/background relative to a One, or whether part of a One's own historically sedimented organization is also internally L2-like. Avoid turning L2 into either "everything historical" or only "social background".
