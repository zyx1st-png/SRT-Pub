# Part I — `Core_Law/SRT_Irreversibility.md`

## 2. Prelanding verdict

```text
OWNER STATUS: RECONSTRUCTION REQUIRED
PRIMARY PROBLEM: P0-03 ontic non-equivalence is repeatedly inflated into durable-trace / residue / universal-history claims
NEW AUTHOR ADJUDICATION REQUIRED: NO, not yet
```

The file contains useful distinctions, but its current master framing is no longer compatible with Selection-totality.

### BLOCKER IRR-1 — authority inflation

Current text repeatedly speaks of `L_0 irreversibility` as an already fixed primitive property whose L1 consequences are being expanded.

Current L0 does not license that strength. It explicitly leaves:

```text
kappa0 / epsilon_pg / irreversibility inheritance into stronger realizations
```

OPEN, while P0-03 licenses only ontic non-equivalence to never-occurrence.

Required retype:

```text
primitive / P0 floor:
  occurred != never-occurred

stronger irreversible-history claim:
  requires retained efficacy / declared lineage / declared transition model
```

### BLOCKER IRR-2 — absorbing-state existence is over-universalized

Current `Def-IRR-1` claims that for any ISP the Selection space contains an absorbing-state structure, with `A_t = empty` as canonical case.

What is actually licensed without extra model premises is narrower:

```text
if a realized history reaches a state from which that same history has no Selection continuation,
that terminated history does not itself license its own later continuation.
```

This is not equivalent to:

```text
every ISP state space contains a natural absorbing set
```

or:

```text
all terminality is globally absorbing under every external/reset relation.
```

Absorbing sets beyond the same-history cessation remainder must be declared-model properties.

### BLOCKER IRR-3 — `no consequence can return to zero` is too strong

Current `Def-IRR-3` states that no operator can return historical consequences to zero.

Selection-totality only requires:

```text
later change cannot retroactively make the earlier occurrence identical to never-occurrence.
```

It does **not** require:

```text
every earlier Selection retains a nonzero later causal residue;
every consequence remains locally readable;
future state cannot become observationally / functionally equivalent under a declared model;
compensation cannot neutralize a downstream effect.
```

The file must distinguish:

```text
retroactive erasure of occurrence: NO

later neutralization / decay / overwrite / functional equivalence: POSSIBLE unless separately excluded

durable historical efficacy: only where established
```

### BLOCKER IRR-4 — learning / trauma trace permanence

Current T-IRR-1 says, in effect:

```text
learned fact always remains as nonzero trace contribution;
forgotten Selection still leaves a structural trace;
trauma pressure is permanently sedimented;
healthy learning must show nonzero trace norm and monotonic Psi_f payment.
```

These claims collapse occurrence into durable trace and exceed the current owner architecture.

Required retype:

- learning irreversibility may be a declared model/domain hypothesis;
- forgetting != time reversal can be retained;
- exact durable trace, permanent trauma residue, monotonic `Psi_f` accumulation and necessary behavioral signature require independent domain/model evidence;
- clinical healing must not be ontologically forced to preserve a permanently active local trace.

### BLOCKER IRR-5 — `Psi_f` arrow is not a universal L0 projection

The file currently presents a universal `Psi_f` time arrow as a direct projection of L0 irreversibility, including non-thermodynamic systems.

Required boundary:

```text
Psi_f owner meaning remains independent;
a model may define path-dependent / non-refundable cost,
but P0-03 alone does not prove universal monotonic Psi_f accumulation.
```

### BLOCKER IRR-6 — epsilon_pg / nu_block branch still carries old inheritance burden

The later operator section still treats `epsilon_pg > 0` as an L0 scalar seed and uses it in a conditional positive `nu_block` construction.

This branch may survive only as a declared pathology/formal model candidate if its variables are independently admitted. It must not imply:

```text
epsilon_pg supplies primitive anti-closure direction;
epsilon_pg positivity is inherited from Selection-totality;
nu_block positivity is a primitive consequence;
```

Any use involving direction/readability must obey `_SRT_T_DIR_CANONICAL.md` direction-source discipline.

### BLOCKER IRR-7 — suffering/non-conservation claims exceed the owner

Current T-IRR-4 derives strong claims such as unavoidable structural suffering and hidden mismatch conservation from `L_0 irreversibility`.

These should be demoted to declared suffering/pathology model candidates or routed to the suffering owner. P0-03 does not by itself establish a conserved mismatch stock or a universal anti-minimization theorem.

# Part II — `Core_Law/SRT_Occlusion_Dynamics.md`

## 4. Prelanding verdict

```text
OWNER STATUS: RECONSTRUCTION REQUIRED
PRIMARY PROBLEM: old subject/direction/health/normativity gates are encoded as a universal d-threshold ontology
NEW AUTHOR ADJUDICATION REQUIRED: NO, not yet
```

Occlusion contains a useful distinction between finite-view limitation and self-reinforcing lock-in, but its current admission and evaluative structure is too strong.

### BLOCKER OCC-1 — stale L0 authority claim

The file says current L0 explicitly promises a term-table theory in which every finite position necessarily has occlusion and can self-lock.

Current L0 instead says:

```text
finite positionality
!= formed Selection-position
!= Bearer
!= subject-position
!= consciousness
```

Primitive finite positionality therefore cannot by itself establish perspectival blind spots, denial, gap perception or pathological lock-in.

Required retype:

```text
finite primitive positionality
-/-> occlusion dynamics

occlusion dynamics
requires a separately established formed / perspective-bearing organization
plus the functions invoked by the declared model
```

### BLOCKER OCC-2 — sigma threshold cannot be universal admission gate

The file still uses:

```text
sigma >= sigma_sr^sub
```

as the structural entry criterion for embodied subject/occlusion.

D3-A has already established:

```text
sigma_sr = model-local / replaceable P2 coordinate
sigma_sub = P3/P4 model coordinate
exact subject-position sufficiency = OPEN
```

Therefore sigma may remain in a declared occlusion model, but not as universal ontology admission.

### BLOCKER OCC-3 — d cannot be the universal occlusion order parameter

Current three-regime architecture treats bare `d` and `d_c` as if they universally determine:

```text
healthy narrow position
active occlusion
locked occlusion
```

Current d owner instead defines a stake-coupled summary with strict proxy/admission rules. A d-threshold occlusion model may remain, but only after a declared stake-coupled realization and calibration.

Required retype:

```text
three-regime / two-threshold architecture
= P2/P3 model candidate unless stronger evidence independently establishes it

d_c / d_narrow
= model coordinates, not natural universal boundaries
```

### BLOCKER OCC-4 — direction readability is inherited illegally

Current T-OCC-1 uses `epsilon direction readable / unreadable` to distinguish healthy, A and B phases.

This violates current direction-source discipline unless a direction has been independently typed and declared.

Required replacement:

```text
if a declared direction signal exists:
  T_dir may track access / readability / reorientation

without a declared direction:
  T_dir is not admitted / undefined
```

No `epsilon_pg`, bare epsilon, B-count, d-value or primitive Selection may supply the direction by inheritance.

### BLOCKER OCC-5 — health cannot be inferred from d or T_dir

Current language repeatedly equates the high/open regime with health and the low/locked regime with pathology.

Current canonical boundary requires:

```text
T_dir > 0 -/> generative health
more options -/> good
continuation -/> good
low friction -/> good
```

If the term `healthy` is retained, the file must declare the independent health/viability/relation-integrity criterion being used. Otherwise the neutral structural labels should be used.

### BLOCKER OCC-6 — responsibility is over-inferred

The A-phase section says direct responsibility follows because perceptual capacity is intact; B-phase language reduces responsibility structurally.

Responsibility requires separately admitted Agency / O2-A answerability conditions. Occlusion phase alone cannot establish moral responsibility or excuse.

### BLOCKER OCC-7 — `evil` cannot be canonically defined here

Current §10 defines evil by an iff conjunction of:

```text
B-phase lock
+ burden externalization
+ active diffusion
```

and calls the resulting judgment objective.

Under the current normativity architecture:

```text
primitive Selection = nonnormative
O1 / O2-C / O2-A require typed gates
O2-M = OPEN
```

Therefore the `evil` section may survive only as a scoped ethical/political bridge proposal or structural harm taxonomy. It cannot function as a universal canonical moral definition owned by Occlusion Dynamics.

### BLOCKER OCC-8 — unilateral-return impossibility is too strong

`B -> A requires external intervention` may be a useful declared-model result when the transition kernel proves internal channels unavailable.

It is not a universal theorem merely from low d, high sigma, or irreversibility. The file must separate:

```text
model-level lock / no-internal-exit result
```

from:

```text
universal ontological impossibility of endogenous return
```

### BLOCKER OCC-9 — AI / collective categorical claims are not licensed

Current text categorically says AI is outside occlusion because it lacks embodied position / epsilon direction / internal stakes, while collective B-phase is treated as available.

Those are domain-admission questions. The owner should provide typed criteria and leave particular AI, organism, institution or collective classification to domain bridges.
