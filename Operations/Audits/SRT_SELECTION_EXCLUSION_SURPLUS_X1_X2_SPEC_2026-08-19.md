# Selection Exclusion-Surplus Audit — X1 Causality / X2 Information

> **Purpose**: continue the exclusion-consequence class explicitly left open by the corrected C1-C6 + X0 audit. Test two already-canonical P1 ordering surfaces without adding theory: X1 causality and X2 information readout.
>
> **Hard boundary**: governance-only derivation audit. No canonical file, theorem, symbol, equation, Selection Grammar, primitive alphabet, bridge, or empirical claim is changed or authorized.

---

## 0. Why this pass exists

The corrected derivational-surplus duel established:

```text
C1-C6 additive surplus = not established
X0 no-prior-chooser = primitive-linked on SRT side
V2 comparison at X0 = Outcome C / primitive-role isomorphism
exclusion consequence class = open
```

The same canonical corpus already contains two additional ordering claims:

- P1-T01: horizontal causality is a projected structure inside `L_2`, **not an ontological primitive prior to Selection**;
- P1-T04: a Selection event creates a determinate distinction not previously available as an `L_1` fact; in this restricted sense **Selection is upstream of information readout**.

This pass asks whether the **negative ordering portions** of those P1 claims are genuinely regenerated by P0-01 under target suspension.

It does **not** ask whether the full P1 theorems are reducible to P0-01.

## 2. Frozen target split

### X1-N — causality negative ordering target

Test only:

```text
an ontologically instantiated causal structure
cannot be required as a primitive ontological predecessor of Selection
```

Do **not** count as primitive consequences:

```text
C_H(A -> B) = P(B | A, L2)
all causality is an L2 projection
any specific causal mechanism
```

Those are additional P1 / domain-level content.

**Scope condition**: X1-N concerns causality proposed as an ontologically real structure / relation inside the ontology. A purely metalogical notation or an external descriptive ordering that is not being asserted as ontologically prior is outside this target.

### X2-N — information-readout negative ordering target

Test only:

```text
a readout of a determinate manifest fact
cannot be ontologically prior to the primitive event by which that fact becomes determinate
```

Do **not** count as primitive consequences:

- Shannon entropy identities;
- global information creation measures;
- information thermodynamics;
- any quantitative information proxy;
- every possible philosophical use of the word information.

X2-N is restricted to **readout / transmission / measurement of a determinate manifest distinction**.

## 6. Rival adjudication

Use four outcomes only:

- **SRT primitive-link fails** — target requires extra SRT premise;
- **Outcome C / role-isomorphic** — SRT primitive-link passes, but V2-PAR already preserves the same primitive-role ordering without amendment;
- **candidate exclusion surplus** — SRT primitive-link passes and frozen V2-PAR needs a genuinely new substantive ordering premise to match it;
- **unresolved** — the comparison turns on an ambiguity not fixed by the frozen target or rival.

A candidate exclusion surplus is **not** D2 and does not prove SRT true. It only shows a derivational asymmetry within the frozen conceptual comparison.
