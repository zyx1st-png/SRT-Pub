# Selection Exclusion-Surplus Audit — X1 Causality / X2 Information

> **Purpose**: continue the exclusion-consequence class left open by corrected C1-C6 + X0, testing two already-canonical ordering surfaces without adding theory.
>
> **Hard boundary**: governance-only derivation audit. No canonical file, theorem, symbol, equation, Selection Grammar, primitive alphabet, bridge, or empirical claim is changed or authorized.

## 0. Final-review correction

The pre-review execution provisionally classified X1 as a `candidate exclusion surplus`. Independent final review found that classification unsound for two independent reasons:

1. **rival preemption**: frozen V2-PAR is not merely primitive actualisation; it is **pre-objective** actualisation from non-objectified potential, so a prior **ontologically instantiated** causal relation with determinate relata already violates the frozen rival's no-pre-given-object/state-space constraint;
2. **background fairness**: on a fallback reading where causality is a pre-objective propensity/disposition rather than an instantiated relation with determinate relata, SRT can exclude it only by using the one-sided P0-01 range/exhaustiveness biconditional. That cannot count as rival-specific surplus when the compared rival is denied the mirror premise by freeze.

The corrected audit therefore treats X1 as **Outcome C on the primary instantiated-relation reading**, with the fallback pre-objective-propensity reading classified as **invalid surplus under background fairness**. No positive exclusion surplus survives.

#### X1 scope resolution

The phrase `ontologically instantiated causal relation` is now split rather than left ambiguous:

- **X1-I (instantiated-relation reading)**: the relation has ontologically instantiated/determinate relata. A prior X1-I relation therefore imports determinate ontology before primitive pre-objective actualisation.
- **X1-P (pre-objective-propensity reading)**: a causal propensity/disposition is posited inside non-objectified potential without determinate relata.

These readings must be adjudicated separately.

### 3.2 Background fairness adjudication

The merged duel freeze contains two constraints that can pull in opposite directions for exclusion targets:

```text
A claimed SRT surplus is invalid if SRT receives an extra target-bearing premise withheld from V2-PAR.
```

and:

```text
V2-PAR may not acquire a range biconditional unless already frozen.
```

For this X1/X2 audit, the local adjudication is:

> **A one-sided range/exhaustiveness biconditional may remain part of canonical SRT-P, but its mere absence from frozen V2-PAR cannot by itself be scored as derivational surplus when that biconditional is the target-bearing difference.**

This preserves the rival freeze without turning an intentionally withheld premise into an automatic SRT victory.

Therefore X1-P cannot become a valid surplus merely because SRT-P has the range biconditional and V2-PAR does not.

### 3.3 Definition-echo guard

If a target is defined as `x is ontologically instantiated`, then applying the unrestricted SRT schema

```text

-> x falls under P0-01 existence ordering
-> x is not prior to Selection
```

is a legitimate SRT-side substitution instance, but not by itself evidence of **Selection-specific rival surplus**. Rival discrimination must survive independently of the target stipulation and fairness rule.
