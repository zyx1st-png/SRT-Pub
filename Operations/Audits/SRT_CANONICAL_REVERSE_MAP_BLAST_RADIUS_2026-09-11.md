# 2. Sigma-specific blast radius

## 2.1 Why sigma requires its own sub-pass

The repository does not only use sigma as a numeric threshold. It uses the threshold name to carry **ontology labels**.

Current surfaces include:

```text
Core_Law/SRT_Individuation.md
Core_Law/SRT_L1_Formalism.md
Core_Law/SRT_L1_Hardening_Notes.md
_SRT_SYMBOL_TABLE.md
Core/SRT_OPEN_TENSIONS.md
Governance/SRT_CLAIM_MODE_AUDIT.md
```

Therefore a semantic re-assignment of `sigma_sub` is not a local rename.

## 2.2 Current type problem

The same family currently carries at least three jobs:

```text
1. historical/writeback balance coordinate;
2. threshold coordinate in a model class;
3. label for a claimed natural ontology transition.
```

The 2026-08-29 truth-up already weakened job 3:

```text
sigma_sr
= conventional / replaceable model-local historical-writeback proxy
!= automatically representation-invariant natural quantity
```

D3 further breaks the old assumption that one threshold can own both Stable-ISP entry and subject entry.

## 2.3 Landing rule

A future sigma PR must distinguish:

```text
FORMAL OBJECT:
sigma_sr and its model equations

MODEL THRESHOLD:
a coordinate such as sigma_sr^{sub}

ONTOLOGY EVENT:
Stable-ISP entry / subject-position entry / self-consciousness transition
```

No future owner should infer the third from the second without a separately paid relation.

## 2.4 Claim-mode surfaces

`Governance/SRT_CLAIM_MODE_AUDIT.md` currently marks concrete threshold values as P3/P4 while retaining structural phase claims at higher interpretive levels.

If D3 landing changes the phase ontology itself, the claim-mode ledger must be checked so it does not preserve an obsolete structural claim merely because the numerical values were already marked low-confidence.

# 8. Reverse-map review questions

Before any C-class landing, reviewers should answer:

1. Does the proposed One owner add only D4a, or does it silently import D4b/D4c?
2. Can a concrete process satisfy all P1-T06 conditions while failing at least one of S1/S2/S3? If not, the D3 split needs stronger explanation.
3. Is P1 consequence-bearing best typed as self-consequence closure, a weaker neighbor, or a partially overlapping condition?
4. Which ontology event, if any, does `sigma_sr^{sub}` track after the split?
5. Can an L2 regime exist without shareability? Give a concrete internal/single-unit case before deleting the shareability gate.
6. Is the L2 agency layer universal or specifically social/institutional? What non-social counterexample tests the universal claim?
7. Is canonical d defined only after subject admission, or should d be broadened to any declared continuing unit? The latter requires a fresh author decision.
8. Which downstream AI and collective claims actually depend on the old Stable-ISP = subject identity rather than merely using similar vocabulary?
