# R1 first canonical landing — standing de-coupling scope

## 0. Decision boundary

This package is a **C-risk canonical edit** under `Governance/SRT_EDIT_PROTOCOL.md` because it changes the interpretation boundary of P1-T06.

The author has already authorized the current execution plan and has already adjudicated the controlling R1 distinctions in the 2026-09-11 author source. This landing therefore implements only already-adjudicated negative/typing constraints and does not invent a new ontology gate.

## 1. Why the first landing is narrower than the full R1 reconstruction

PR #938 establishes the current noncanonical reconstruction spine:

```text
pre-object difference
-> subjectless Selection
-> manifestation / relative backgrounding
-> active verticalization
-> recurrent localized vertical organization
-> One / Selection-position
```

But PR #937/#938 also leaves the final canonical owner of `One` open. B13 is the strongest existing host/crosswalk, not an automatically authorized final owner.

Therefore this first landing does **not** canonize a complete One definition. It first removes a narrower contradiction: P1-T06 currently reads as though Stable ISP owns the first appearance of perspective and is tightly coupled to subject entry.

## 2. Exact canonical change allowed in this package

The package may change P1-T06 only to state that:

```text
Stable ISP
= a strong recurrent standing package
  for a perspective-bearing, history-bearing,
  continued-selectable process.
```

and that:

```text
P1-T06 standing
!= definition of Selection
!= generation law for upstream formed positional organization
!= first appearance of perspective
!= Bearer admission
!= subject-position proof
!= phenomenality proof.
```

The existing `perspective-bearing`, `history-bearing`, recurrent-reconstitution and continued-selectability conditions are retained as P1-T06 standing conditions. Their interpretation is narrowed so they do not back-define the upstream ontology.

`bearing downstream consequences` in P1-T06 is typed only as consequence return / coupling to the same history-bearing process. It must not be read as establishing the later `Bearer` concept, `承担`, non-outsourcable stake, or subjecthood.

## 3. Formation / history boundary

This landing may record the negative inference guard:

```text
recurrent historical reconstitution / writeback
is relevant to continuity / standing,
but does not by itself generate active verticality,
One / Selection-position, Bearer, or subjecthood.
```

This is a boundary statement, not a new positive One theorem.
