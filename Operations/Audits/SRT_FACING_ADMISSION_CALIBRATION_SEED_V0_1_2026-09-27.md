# Facing Admission Test v0.1 — calibration seed

> This is a producing-model calibration seed, NOT a gold set and NOT independent validation.
> Labels below are hypotheses to be blind-rerun by another session/model before any method promotion.

## 0. Calibration goals

Test whether v0.1 can reliably distinguish:

~~~text
hidden != L0;
generative != L0;
history != L2 unless later-effective;
bridge != uncertainty;
philosophical burden facing != formal realization facing;
same named construct can change facing when explanandum / cut changes.
~~~

## 2. Detailed pressure notes

### C1 — O0 open burden

Target cut: determinate manifestation / admitted object-state inventory.

~~~text
Q1 presupposed cut: NO as complete ontology;
Q2 cut genesis: YES / source burden concerns non-preclosure relative to determination;
Q6 removal: burden survives removal of current completed inventory;
Q9 back-import: must exclude chooser, option menu, value, history.
~~~

Seed verdict: FACE-L0-CANDIDATE / HIGH.

Revision trigger: downgrade if O0 is made dependent on a pregiven complete state or option inventory.

### C2 — S0 actualising Selection

Target cut: actual determinate event/manifestation at declared level.

~~~text
Q3 actual determination: YES;
Q7 same-event aspect: YES — O0/S0 are co-primitive analytic burdens, not temporal mechanisms.
~~~

Seed verdict: FACE-L1 / HIGH.

Important: this does not mean primitive Selection as a whole is a downstream formed object.

### C3 — retained historical efficacy

~~~text
Q4 retained efficacy: YES by target definition.
~~~

Seed verdict: FACE-L2 / HIGH.

Negative control: terminal Selection with no later-effective consequence is not L2 merely because it occurred in the past.

### C4 — Selection-position

Target explanandum: current formed operative from-where, not its full developmental lineage.

~~~text
Q1 presupposed cut: formed position already exists;
Q3 current operative organization: YES;
Q4 historical conditions: may contribute but are not identical to current role.
~~~

Seed verdict: FACE-L1 / MEDIUM.

Revision trigger: if the target is instead the recurrent reconstitution of Position across time, retype as FACE-L1<->L2-BRIDGE or MIXED.

### C5 — Gate

Target explanandum: currently available stable coarse-graining geometry.

~~~text
Q3 current operative organization: YES;
Q4 prior stabilization may matter but belongs to a different question.
~~~

Seed verdict: FACE-L1 / MEDIUM.

Revision trigger: a study of Gate sedimentation / historical stabilization should be retyped toward L1<->L2.

### C6 — ChoiceMap latent directional generator

~~~text
hidden: YES;
nonconscious: possible;
generative: YES;
formed subject-internal operative organization: YES.
~~~

Seed verdict: FACE-L1 / HIGH.

This case is a deliberate trap against hidden = L0.

### C7 — Barad agential cut

Target explanandum: constitutive enactment of determinate separability.

~~~text
Q2 cut genesis: YES;
Q5 bridge: YES;
Q6 removal of already-determinate relata: explanatory role remains;
Q7 relation culminates in determinate manifestation.
~~~

Seed verdict: FACE-L0<->L1-BRIDGE / MEDIUM.

Formal/source caveat: do not infer that every Baradian construct shares this facing.

### C8 — Simondon transduction

Target explanandum: individuation process generating structured individual + associated milieu.

~~~text
Q2 cut / dimension genesis: YES;
Q5 bridge: YES;
Q6 burden survives removal of finished individual;
formed structure emerges through the process.
~~~

Seed verdict: FACE-L0<->L1-BRIDGE / MEDIUM.

Do not equate metastable model variables themselves with primitive L0.

### C9 — actualized occasion as later datum

Target explanandum: objective/superjective role of prior actuality in later occasions.

~~~text
Q4 retained later-effective role: YES.
~~~

Seed verdict: FACE-L2 / HIGH.

Changing target to concrescence/self-determination would require a new admission record and may produce L1 or bridge status.

### C10 — active-inference generative model

Target cut: declared hidden-state, observation, action/policy variables.

~~~text
Q1 presupposed cut: YES;
Q3 operative organization: YES;
Q6 remove state/observation/policy ontology: model no longer has the same explanatory object.
~~~

Seed verdict: FACE-L1 / HIGH.

Even a hierarchical/nonparametric version must be retested rather than automatically upgraded.

### C11 — learned prior / habit

Target explanandum: prior learned organization continuing to shape later inference/action.

~~~text
Q4 retained later-effective role: YES.
~~~

Seed verdict: FACE-L2 / HIGH.

If the item is only stored but does not later constrain anything, L2 fails.

### C12 — archived ChoiceMap transcript

Target explanandum: text as stored record only.

~~~text
explicit: YES;
past: YES;
later-effective ontic role: NOT ESTABLISHED;
epistemic reconstruction use: possible but distinct.
~~~

Seed verdict: FACE-UNDETERMINED / HIGH for the refusal to call it ontic L2.

This is a deliberate test of the guard: explicit / recorded / historical does not automatically equal L2.
