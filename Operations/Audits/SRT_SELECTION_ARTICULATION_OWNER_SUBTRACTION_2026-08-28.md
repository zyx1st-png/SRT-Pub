# Selection / Articulation — Initial Owner Subtraction Audit (2026-08-28)

> **Boundary:** repository-internal subtraction only. This audit does not establish external novelty and does not authorize canonical change.

## 0. Result

The 2026-08-28 workline should **not** claim novelty for either of the following by itself:

```text
selection history can generate a stable selector / subject position
stable object identity requires differentiation + constraint + invariance + re-identifiability
```

Both already have explicit owners.

The candidate residual increment is narrower and more upstream:

> **Primitive Selection may need to be read as prior to determinate individuation itself: not selection among already individuated alternatives, but the actualisation in which effective distinctions / boundaries / relations / unities become determinate enough for later object, bearer, or selector individuation to operate.**

That claim remains a P1/P2 candidate interpretation of P0-01 pending canonical and external audit.

---

## 1. P0 owner already carries the non-menu kernel

`Core/SRT_Core_21_Minimal_Axioms.md P0-01` already states:

```text
non-objectified potential
under real constraints
acquires a determinate manifest distinction
```

and explicitly blocks:

```text
menu of completed latent objects
```

Therefore `determinate articulation` must first be tested as a clarification of P0-01, not a new primitive.

Residual question:

> Does `determinate manifest distinction` already entail the weaker claim that one/many/boundary/relation are not primitive at the operative grain, or would that be an additional P1/P2 consequence?

---

## 2. `SRT_Individuation.md` already owns selector / subject-position formation

`Core_Law/SRT_Individuation.md` explicitly defines its role as:

```text
主体位从无主语选择中凝结
```

and already supplies a dynamics in which later selection parameters contain both historical writeback and external contribution:

```text
theta_t = theta_t^trace + theta_t^ext
```

Its P1-candidate claim tracks transition from subjectless / unfolding selection toward a stable perspective-bearing position through self-reference and historical writeback.

Therefore the new workline must not create a parallel theorem such as:

```text
Selection -> Position -> Selector
```

as if position formation were previously ownerless.

### Residual increment

The upstream unresolved question is instead:

> **Before the subject-position dynamics in `SRT_Individuation.md` begin, what exactly has primitive Selection already made determinate?**

The articulation proposal answers provisionally:

```text
effective difference / boundary / relation / unity at an operative grain
```

This is upstream of the existing self-reference phase-transition model.

---

## 3. PH-IND04 already owns object-side re-identifiable unity

PH-IND04 Stage O already gives the thin objectification grammar:

```text
differentiation
-> constraint
-> individuation
-> stabilized invariance
-> re-identifiability
```

and asks:

```text
What makes this a re-identifiable unit across a declared family of transformations?
```

Therefore the shorthand:

```text
Object = still this
```

is useful exposition but not a new object theory by itself.

### Residual increment

The present workline can still ask a prior question not answered by PH-IND04 Stage O:

> **How does the differentiation / grain on which an objectification grammar operates become determinate in the first place?**

The articulation proposal is potentially upstream of PH-IND04 rather than a replacement for it.

---

## 4. PH-IND02 already owns boundary formation and bearer escalation

PH-IND02 already separates:

```text
selective stabilization
-> candidate closure
-> candidate boundary
```

from the stronger bearer audit:

```text
same-unit consequence return
+ history-bearing writeback
+ future-selectability change

-> stronger bearer candidate
```

Therefore the new workline must not identify primitive articulation with closure or bearerhood.

Residual relation:

```text
primitive articulation
< possible precursor to >
selective stabilization / closure
< additional historical conditions >
bearer candidate
```

The exact entailment is not yet established.

## 5. PH-MEM01 already owns history attribution pressure

PH-MEM01 asks why distributed subpersonal changes count as the history / capability of `this same continuing unit` and preserves:

```text
subsystem causal contribution
!= bearer ownership
```

Therefore `historical belonging`, `ownership`, or `one history` should not be coined as new owners in the articulation workline.

The stronger contribution, if any, is architectural:

> the same Selection-first floor may explain why later history attribution problems only arise after a determinate articulation has made candidate units addressable.

---

## 6. Processual Bearer bridge already pressures pre-declared grains

The Processual Bearer / Constraint bridge already states that formal boundary calculations require a declared unit / variable / grain and cannot, by themselves, establish why that grain is ontologically correct.

It also preserves:

```text
perspective / task can select a grain
+
reality constrains which cuts remain stable
```

The present workline goes one step more upstream only if it can defend:

> the possibility of a declared grain is itself downstream of primitive determinate articulation, rather than merely a methodological choice made by an already individuated analyst.

This requires external novelty audit and cannot be promoted from internal fit alone.

## 8. Recommended next audit

Do not spend the next pass on subject-position mechanics; the repository already has an owner.

The next pass should target only the residual candidate:

```text
Does Selection precede determinate individuation of one / many / boundary / relation?
```

External comparison should prioritize theories that also place individuation before relata:

- Simondon;
- Barad / agential cut;
- Whitehead / process individuation;
- Peirce habit / continuity;
- relational ontology;
- enactivist / autonomy individuation;
- category / structural accounts of individuation where relevant.

The audit question must be package-level:

> Is SRT merely renaming pre-individual differentiation, or does its primitive actualisation + irreversible history + downstream selector/bearer non-jump architecture impose a distinct dependency structure?

Until that audit is complete, recommended status remains:

```text
clarification / hardening candidate
not established novel ontology
```
