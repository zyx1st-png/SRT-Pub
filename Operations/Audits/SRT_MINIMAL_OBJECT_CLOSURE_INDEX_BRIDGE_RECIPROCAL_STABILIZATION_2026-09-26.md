# Minimal object closure — thin index × bridge-network reciprocal stabilization

> Goal: identify the weakest closure operation by which several actively formed relational properties become one richer object without assuming a rich object token at the start.

## 0. Correction to the naive order

Do NOT use a universal sequence:

~~~text
relation
-> property
-> first objecthood of any kind
~~~

Object-index research supports a thinner architecture:

~~~text
thin individuation / 'this one'
can precede
rich property / kind identification
~~~

Representative sources:
- Leslie, Xu, Tremoulet & Scholl 1998, DOI 10.1016/S1364-6613(97)01113-3.
- Croteau, Cheries & Xu 2026, DOI 10.1037/rev0000527.

Therefore current terminology:

~~~text
I-thin
= minimal tracked locus / 'this one'

B_k
= actively formed reusable bridge / relational property

O-rich
= richer object closure integrating multiple B_k around a continuing I-thin
~~~

---

## 1. Two initially independent achievements

### Achievement A — thin index

The system can track:

~~~text
'this current locus'
-> 'still this locus'
~~~

through some spatiotemporal continuation / common fate / correspondence cues.

The index need not encode rich properties.

### Achievement B — reusable bridge

The system can learn:

~~~text
under condition family C
action / transformation family A
-> stable relation R
~~~

for example graspability.

The bridge need not by itself specify a unique enduring individual.

Thus:

~~~text
thin index
!= property bridge
~~~

and neither alone equals rich objecthood.

---

## 2. Why simple feature binding is not enough

Existing object-file / binding work already shows that distributed features can be bound to an indexed object representation.

Representative pressure:
- Hommel 2004, *Event files: feature binding in and across perception and action*, Trends in Cognitive Sciences 8(11):494–500. DOI 10.1016/j.tics.2004.08.007.
- Robertson 2003, *Binding, spatial attention and perceptual awareness*, Nature Reviews Neuroscience 4:93–102.
- Leslie et al. 1998, object index architecture.

So the current route cannot claim novelty from:

~~~text
index
+ feature binding
-> object representation
~~~

The stronger question is generative:

> **When do independently formed sensorimotor bridges become mutually dependent enough that one continuing locus becomes the best reusable compression for their joint recurrence?**

---

## 3. Closure candidate C1 — co-reinstantiation

Suppose:

~~~text
B1 = grasp bridge
B2 = view-change bridge
B3 = common-motion bridge
B4 = resistance / weight bridge
~~~

Across episodes, these bridges repeatedly reactivate around the same thin index I.

First condition:

~~~text
P(B1,B2,B3,B4 | I)
is substantially more structured than
independent P(Bk)
~~~

No specific probability formalism is licensed yet.

The conceptual burden is simply:

> knowing the continuing locus helps predict which bridge family will reappear.

---

## 4. Closure candidate C2 — reciprocal re-identification

One-way binding is still too weak.

Require reciprocity:

~~~text
index I
-> predicts bridge set {Bk}

and

bridge pattern {Bk}
-> helps recover / re-identify index I
after ambiguity, interruption or transformation
~~~

Example:

After brief occlusion, the reappearance of a familiar grasp / shape / resistance relation helps the system treat the new sensory state as continuation of the same locus.

This is consistent with work showing that both spatiotemporal and feature information can contribute to object correspondence rather than a purely feature-blind tracking rule.

Representative source:
- Moore et al. / object correspondence line summarized in 2019 work, PMID 31214971.

Working term:

> **reciprocal stabilization**.

---

## 5. Closure candidate C3 — joint perturbation response

A stronger object candidate exists when perturbing the continuing locus changes several bridges coherently.

Example:

~~~text
rotate locus
-> visual bridge changes predictably
-> grasp bridge updates
-> resistance expectation remains / changes predictably
-> common-motion relation is preserved
~~~

Compare a false conjunction:

~~~text
visual pattern from one locus
+ grasp relation from another
~~~

If joint perturbation breaks the false bundle but preserves the true bundle, object closure gains causal structure.

---

## 6. Closure candidate C4 — boundary economy

An object boundary becomes useful when one boundary decision simplifies several relations at once.

Working criterion:

~~~text
changes within boundary
-> can be treated as transformations of same continuing locus

changes crossing boundary
-> require new index / bridge reassignment
~~~

The boundary earns status if it improves:
- prediction;
- action coordination;
- bridge reuse;
- recovery after occlusion;
- error localization.

Thus boundary is not assumed as a primitive contour.
It is a control / compression achievement.

---

## 7. Closure candidate C5 — re-entry

Rich objecthood requires more than continuous online tracking.

After:
- occlusion;
- release;
- attention shift;
- temporary loss;

the system should be able to restore the bridge cluster without relearning it from zero.

~~~text
I-thin lost / weakened
+ partial bridge evidence returns
-> bridge cluster reinstates
-> same-object candidate recovers
~~~

This makes the object an historical infrastructure, not only a current percept.

---

## 8. Minimal reciprocal-closure package

Current machine proposal:

A richer object candidate requires at least:

~~~text
RC1 thin continuing index
+
RC2 multiple reusable bridge relations
+
RC3 co-reinstantiation
+
RC4 reciprocal index <-> bridge recovery
+
RC5 joint perturbation coherence
+
RC6 useful boundary
+
RC7 re-entry after interruption
~~~

Then:

> **rich object closure = reciprocal stabilization between a continuing index and a reusable bridge network.**

This is machine wording only.

---

## 9. Why this is stronger than 'bundle of properties'

A classical bundle picture risks:

~~~text
red + round + hard + graspable
= object
~~~

The current route requires dynamic dependence:

~~~text
properties / bridges
must co-transform, reappear, correct and support re-identification together
~~~

So:

> objecthood lies less in static co-possession of features and more in the stable organization of how multiple relations change together.

This is closer to the author's active-bridge intuition.

---

## 10. Why this is stronger than a thin object index

A thin index answers:

> which one?

A richer object closure answers additionally:

> what family of transformations, actions and consequences belongs together around this continuing locus?

Thus:

~~~text
I-thin
= continuity handle

O-rich
= continuity handle
  + actively formed relational infrastructure
  + reciprocal re-identification
  + predictive / control closure
~~~

---

## 11. Revised author-intuition reading

The author's phrase:

> 状态之间获得了一个统一的标签。我们称之为状态的属性。随着属性的稳定，状态逐渐变成了一种对象。

should currently be protected as a generative intuition about **rich objectification**, not hardened into the universal claim that no thin object index can precede property formation.

Safer machine reconstruction:

~~~text
active relation formation
<-> thin selective individuation
-> reusable properties / bridges
-> reciprocal bridge-index stabilization
-> rich objectification
~~~

The bidirectional arrow matters.

---

## 12. Gate consequence

This gives Gate a possible recursive hierarchy:

~~~text
micro bridge formation
-> property-level relation

thin index
+ multiple properties
-> object-level closure Gate

object-level closure
-> constrains later micro bridge formation / action gating
~~~

Therefore:

> **a higher-level Gate may be the stabilized closure produced by lower-level bridges, while simultaneously becoming a constraint on future lower-level bridge use and formation.**

This is a candidate multiscale interpretation, not yet formalized.

---

## 13. Whole-field consequence

If many objects / properties / action relations are recursively closed in this way, then the whole cognitive field is not merely a collection of object nodes.

It contains:
- currently active thin indices;
- mature bridge networks;
- latent reusable relations;
- cross-object action relations;
- higher-order goals / constraints;
- unresolved bridge conflicts;
- bridge-formation opportunities.

Thus the field can remain pre-object generative even though mature objects participate in it.

---

## 14. Content -> control revisited

A conscious target can now be modeled as activating a rich closure rather than a single token.

~~~text
'pick up cup'
-> select / stabilize cup index
-> reinstate relevant bridge cluster
-> suppress irrelevant bridge families
-> orient grasp / reach / feedback pathways
-> distributed execution
~~~

This provides a more concrete bridge from object content to multilevel Gate operation.

---

## 15. Failure conditions

The reciprocal-closure model should be rejected or split if:

### F1
A thin index plus static feature binding predicts all relevant object continuity / action effects; reciprocal bridge structure adds no payoff.

### F2
Bridge clusters do not help re-identify a locus after ambiguity / interruption.

### F3
Joint perturbation does not produce coherent multi-bridge updating.

### F4
Boundary formation adds no compression / control advantage.

### F5
Object-level closure does not alter later property learning / action selection.

### F6
The model merely renames object files / event files without a distinct active-formation or recursive-control burden.

## 17. Next question

The next pressure point is no longer 'when is there an object?' in isolation.

Use:

> **What makes a reciprocal closure become sufficiently stable that the generative relations disappear from view and the object is experienced as simply given?**

This routes directly back to:
- gate transparency;
- object givenness;
- L2 sedimentation;
- friction when the closure fails;
- gate-objectification when hidden relations re-enter foreground.
