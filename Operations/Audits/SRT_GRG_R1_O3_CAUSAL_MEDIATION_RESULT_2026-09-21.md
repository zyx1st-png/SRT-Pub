## 1. Frozen causal question

The protocol asked whether a recurrent spectral scaffold generated by Structured history would causally improve later learning on the same source-domain base task when transplanted into otherwise naive recipients.

Arms:

~~~text
I0 = intact naive recipient
IS = S-history spectral scaffold
ID = D-history spectral scaffold
~~~

Primary contrasts:

~~~text
C_SD = AUC_IS - AUC_ID
C_S0 = AUC_IS - AUC_I0
~~~

O3-PASS required both median contrasts >= 0.03 and both bootstrap 95% confidence intervals of the mean entirely above zero.

## 2. Primary result

| quantity | result |
|---|---:|
| median C_SD | 0.001575 |
| median C_S0 | 0.002794 |
| mean C_SD | -0.000030 |
| mean C_S0 | 0.004394 |
| bootstrap 95% CI mean C_SD | [-0.003182, 0.003168] |
| bootstrap 95% CI mean C_S0 | [-0.000015, 0.008896] |
| mean AUC I0 | 0.970442 |
| mean AUC IS | 0.974836 |
| mean AUC ID | 0.974866 |

The preregistered conjunction clearly fails.

Structured-history spectral seeding did not produce a reproducible learning advantage over Direct-history spectral seeding, and its small average advantage over intact naive recipients did not survive the preregistered bootstrap criterion.

This O3 result now establishes a separate negative result:

~~~text

~~~

Therefore:

~~~text

~~~

This is a substantive programme constraint.

## 4. What is rejected

For this toy RNN and this frozen source-native-style intervention:

~~~text
top-four averaged history-associated recurrent eigenspectrum scaffold
-> sufficient causal mediator of improved later base-task learning
~~~

is NOT SUPPORTED.

Do not use the prior O1 result to promote the spectral scaffold to GRG-R1 O.

## 5. What is not rejected

Do not infer:

~~~text

Bowler et al.'s source-native eigenspectrum intervention is false;
GRG-R1 is universally false;
retained organization never re-enters later generation;
all dynamical scaffolds reduce to description.
~~~

The null is local to this toy realization and intervention contract.

## 6. Source-fidelity limitation

The public Bowler seed_weights_run.py does more than a one-time transplant.

Its source-native procedure:

~~~text
inserts shaping-associated eigenvalues before training
and repeatedly resets those leading eigenvalues during early training blocks
before later training proceeds without reset.
~~~

The present frozen O3 protocol used a one-time pre-training transplant.

This difference is a real source-fidelity limitation, but it does NOT invalidate or rescue the current null.

It was known only as part of the broader source pattern before execution but was not included in the frozen v0.1 O3 intervention contract.

Any repeated-reset test must therefore be a new visible source-fidelity protocol, not a reinterpretation of this run.
