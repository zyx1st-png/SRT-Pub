# R4-pre · Q01–Q10 Source-Intuition Derivational Mining (2026-08-28)

> **Scope:** read-only source-intuition mining. The book drafts are companion exposition, not definition owners. This record extracts possible missing derivational edges and performs first-pass owner subtraction. It does not promote a book sentence into P0/P1/P2.
>
> **Question:** Which intuitions in Q01–Q10 remain useful after subtracting current canonical/L2/individuation owners, specifically because they expose a missing, overclaimed, or poorly typed arrow in the Selection-first architecture?

---

## 0. Executive result

The strongest Q01–Q10 increment is **not** a new primitive vocabulary.

Most of the later historical machinery is already owned by the L2 architecture:

```text
historical path accumulation
hysteresis
hardening
low-friction compatible re-traversal
foreground -> background scaffold
re-entry / backgrounding
```

The residual value of the book lies instead in four seams:

```text
A. primitive actualisation
   != historical three-step formation / retention

B. independent reality / physical individuality
   != public readable object identity / objectification

C. world-historical facticity
   != history actually borne by one candidate unit

D. excluded alternatives
   -> ?
   -> later structural residue
```

These seams should guide R1C/R2A/R2C/R2-CORE before any new formal object is invented.

## 3. Card R4-Q01 — Givenness is a downstream effect, not an ontology

### Source intuition

Q01 distinguishes:

```text
independent reality
!= public readable identity
!= givenness / “of course it is there” background feeling
```

and explicitly refuses to make independent reality the chapter’s target.

Its three-step compression is:

```text
objectification
-> categorization / public identity
-> defaulting / backgrounding
```

### Owner subtraction

L2/backgrounding owners already explain how stable structures recede into default conditions.

### Residual

Keep the three-level distinction as an anti-confusion guard:

```text
ontic persistence / individuality
!= public scientific object identity
!= phenomenology of givenness
```

This is especially important for R2A. A physical individual cannot be defined merely by the fact that a scientific community has stabilized a public measurement object.

### Disposition

`USEFUL ROUTING GUARD / NOT A NEW THEORY CONSTRUCT`.

## 4. Card R4-Q02 — Objectification has two different burdens

### Source intuition

Q02 says objectification is not an error; it is the operation by which continuous or relational process is cut into manipulable units.

The chapter repeatedly stresses:

```text
object is not necessarily primitive
process / relation can overflow the slice
no boundary -> no graspable cognition
```

### Pressure

Q02 moves between two different claims:

1. **epistemic/public objectification:** how a process becomes a tractable, nameable, measurable working unit;
2. **ontic individuation:** how a physical/processual unity exists and remains reidentifiable independently of a particular observer’s description.

These cannot share one proof burden.

### Residual for R2-DOWN-O

Ask separately:

```text
What makes a cut scientifically/publicly useful?
!=
What makes a process one physical individual?
```

A future physical-individuation account must survive different measurement conventions and finite positions; otherwise SRT collapses objecthood into observer-side segmentation.

### Disposition

`HIGH-VALUE TYPE SPLIT / R2-DOWN-O INPUT`.

### Disposition

`OWNER-SUBTRACTED / RETAIN AS FORMALIZATION GUARD`.

## 7. Card R4-Q04b/Q05 — Three-step engine belongs to historical formation, not primitive occurrence

### Source intuition

Q04b asks how “this one” becomes a stable reality and gives:

```text
排开
-> 定形
-> 写入
```

It describes `写入` as leaving a trace that changes later distributions, and says all three are required for a `这一个` to “真正成形并留住”.

Q05 then uses the same engine to explain why Selection is prior to chooser/menu.

### Canonical pressure

AM-A is thinner:

```text
non-objectified potential
under real constraints
-> determinate manifest distinction
```

P0-02 explicitly separates event actuality from anchoring persistence.

Therefore:

```text
primitive Selection occurrence
!=
full historical formation / retained unity
```

### Rebase consequence

The three-step engine should be audited as a candidate description of:

```text
historically effective selection structure
or
stable object/terrain formation
```

not silently treated as the minimum P0-01 occurrence criterion.

### Derivational question

```text
AM-A determinate occurrence
+
what additional admission conditions?
-> minimal write-in / historically effective selection
```

This is an R1C / R2-CORE edge question.

### Disposition

`HIGH-VALUE SCOPE REPAIR / DERIVATIONAL-SPINE INPUT`.

## 8. Card R4-Q06 — Excluded-branch residue is a bridge candidate, not primitive fruitfulness yet

### Source intuition

Q06 distinguishes three residual modes:

```text
shadow          = evaluative-reference residue
tension         = structural-force residue
later friction  = turnaround / future-path cost
```

and explicitly says non-human terrain may lack `shadow` while retaining structural tension / later friction.

### Owner subtraction

General path dependence, hysteresis, structural constraint and future-friction effects already have large prior-art and L2 coverage.

### Residual

The potentially sharper claim is not “history matters”. It is:

> holding the realized endpoint fixed, does the **identity/structure of what was excluded** leave a differentiable later residue, and can the predicted residue mode dissociate by terrain type?

### Attribution guard

This is currently source intuition / middle-level bridge content.

AM-A does not itself derive:

```text
excluded-alternative-specific persistent differential
```

and existing primitive-surplus audits already show primitive Selection does not regenerate irreversible trace/writeback by itself.

### Disposition

`POTENTIALLY INTERESTING MIDDLE-LEVEL TARGET / A0 BRIDGE REQUIRED / NO P0 CREDIT`.

## 9. Card R4-Q07 — Minimal write-in, anchoring and backgrounding should not be collapsed

### Source intuition

Q07 explicitly distinguishes:

```text
minimal write-in
!= anchoring
```

and decomposes deeper anchoring into:

```text

-> re-entry
```

with an explicit caution that this is not a necessary-and-sufficient checklist.

### Owner subtraction

L2 owner already contains a trace/closure/scaffold ladder and backgrounding mechanism.

### Residual

The book contributes a useful type discipline:

```text
record exists
!= record constrains later selection
!= record becomes default background
```

This should be used to audit `history-bearing` and `L2-grade` claims, not registered as a parallel anchoring theory.

### Disposition

`MOSTLY OWNER-ABSORBED / RETAIN AS TYPE GUARD`.

## 10. Card R4-Q08 — Split world-historical facticity from borne history

### Source intuition

Q08’s central image is:

```text
rollback / reversal
-> A'
not A
```

because an anchored event changes later terrain.

### Pressure from current bearer work

A perfect restoration of one subsystem can erase that subsystem’s internal memory/state while the wider world still contains consequences of the event.

Therefore two questions must be separated:

```text
Did the event remain part of world history?
!=
Does this candidate continuing unit still bear that history?
```

### Proposed type split

```text
world-historical facticity
= event cannot be made globally never-to-have-occurred once consequences have propagated

borne history
= consequence remains dynamically carried by the declared candidate unit and alters its own later selection conditions
```

The second is unit/boundary/reset sensitive; the first is not automatically evidence of bearer continuity.

### Relevance

This directly supports R2-DOWN-B and clarifies why rollback examples can be conceptually useful without automatically producing D2.

### Disposition

`HIGH-VALUE BEARER TYPE SPLIT / R2C INPUT`.

### Residual

```text
!= morally good
```


### Disposition

`OWNER-ABSORBED / KEEP AS ANTI-INFLATION GUARD`.

### Source intuition

```text
-> friction allocation

```


The distinction can help prevent a category collapse:

```text

```

But no new order primitive or scalar is warranted by the book alone.

### Disposition

`MOSTLY OWNER-ABSORBED / POSSIBLE L2 SCOPE CLARIFICATION ONLY`.
