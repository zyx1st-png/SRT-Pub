## 1. Q9 — what makes a relation-level organization a higher-order One?

### 1.1 Coordination is too weak

The following are insufficient:

```text
multiple Ones act together;
shared environment;
shared L2 scaffold;
mutual prediction;
repeated interaction;
JFS-like joint reconstruction;
member-level policies become correlated.
```

These can all occur while the only persisting units remain the lower-level members.

### 1.2 Reapply the One-function at the higher scale

Pass 1 identified the formed-continuity function as:

```text
localized lineage-relative continuity
of Selection-mediated historical reconstitution.
```

At relation level, the same logic should apply without inventing a new criterion.

Higher-order continuation candidate requires at least:

```text
1. relation-level localization:
   there is a bounded interactional/organizational unit whose continuation
   is not identical to any one member;

2. relation-generated history:
   interaction among members produces a history belonging to the relation-level organization;

3. relation-level writeback:
   that history changes how the relation is reconstructed later;

4. counterfactual efficacy:
   erasing the relation-level historical organization while preserving member states
   changes later coordination / reachability / continuation;

5. turnover tolerance:
   at least some member replacement can occur while the relation-level continuation remains recognizable,
   if the declared domain allows turnover.
```

### 1.3 Minimal criterion

Compactly:

```text
relation-level result
-> relation-level historical condition
-> later reconstitution of the same relation-level organization
```

This is the scale-lifted analogue of One-formation.

### 1.4 JFS relation

```text
JFS / joint reconstruction
= possible process contributing to relation-level formation;

higher-order One
= formed relation-level continuation standing.
```

Therefore:

```text
JFS != higher-order One;
JFS may participate in higher-order One-formation.
```

### 1.5 Collective ISP remains downstream

A higher-order One still does not establish:

```text
structural perspective;
integrated history as a selection center;
continued selectability;
non-outsourcable collective stake;
collective concern;
collective phenomenality.
```

Those remain separately paid standing questions.

**Pass-3 verdict:** `HIGHER-ORDER ONE = SCALE-LIFTED FORMED-CONTINUITY GATE; JFS = PROCESS, NOT STANDING`.

## 2. Q11 — are 承担, 关切 and 方向 the same deeper asymmetry?

### 2.1 Current L0 vocabulary assigns different jobs

The current L0 text gives three distinct functions.

```text
承担:
selection consequences cannot be fully externalized;
selector and consequence are structurally bound.

关切:
some conditions are endogenously incorporated as differential conditions
of the position's continuity, payability and later selectable space.

方向 / epsilon-readability:
non-equivalent continuations are not structurally neutral;
continuations preserving further selectability differ from self-erasing ones.
```

### 2.2 Why immediate unification would lose information

Each answers a different question:

```text
承担 -> WHO PAYS / WHERE CONSEQUENCES CLOSE?
关切 -> WHAT CONDITIONS MATTER TO THIS POSITION?
方向 -> HOW ARE CONTINUATIONS NON-NEUTRALLY DISTINGUISHED?
```

A system can in principle exhibit one without fully paying the others.

Examples of pressure cases:

```text
own-consequence return without stabilized concern;
endogenous concern-like weighting without robust non-outsourcing;
formal survival-direction bias without a formed subject-position.
```

### 2.3 Coupling hypothesis

Although not identical, subject-position may require their coupling:

```text
non-outsourcable consequence closure
+ endogenous incorporation of continuity-relevant conditions
+ local readability of continuation vs self-erasure
-> stake-bearing directed subject-position candidate.
```

This can be summarized as a deeper family resemblance:

```text
position-relative endogenous non-neutrality
```

but that phrase is not yet a new primitive or theorem.

### 2.4 Concern should not be reduced to emotion

The current theory pressure remains:

```text
concern
= structural relevance / endogenous inclusion,
not affective feeling by definition.
```

Phenomenal or emotional concern remains downstream/domain-specific.

### 2.5 Direction should not be reduced to concern

`epsilon`-style direction supplies a formal asymmetry; concern supplies which conditions have been written into the position's own continuity structure.

Thus:

```text
direction can be a domain-floor asymmetry;
concern is position-relative endogenous inscription;
```

and they should not be aliases.

**Pass-3 verdict:** `THREE DISTINCT ROLES, COUPLED AT SUBJECT-POSITION; NO MERGE YET`.

## 3. Q12 — is L2 internal or external to a One?

### 3.1 Reject the external-only reading

If L2-grade structure means sedimented, re-enterable, inheritable background constraint, there is no reason in principle it must always sit outside the continuing organization whose history helped form it.

A One can carry internally sedimented historical organization that functions as background constraint for its own later Selection.

Likewise, an institution/environment can carry sedimented scaffold external to a given One.

Therefore:

```text
internal vs external
is relative to the declared unit/boundary/cut.
```

### 3.2 Reject the everything-historical reading

Pass 1 already separated:

```text
generic trace/writeback
!= L2-grade scaffold.
```

Not every historical residue is L2-grade.

Current minimum L2-grade pressure remains:

```text
history becomes sufficiently stable / re-enterable / inheritable / backgrounded
that it constrains later Selection as an already-formed scaffold.
```

### 3.3 Scale-relative L2 candidate

Pass 3 prefers treating L2-grade organization as boundary-relative:

```text
L2^B-like role
= sedimented historical scaffold relative to declared boundary/unit B.
```

This notation is audit-only; no new canonical symbol is proposed.

For a given One O:

```text
internal scaffold:
history sedimented into O's own continuing organization;

external scaffold:
history sedimented in environmental / social / institutional structures
that condition O from outside its declared boundary;

shared scaffold:
sedimented structure jointly maintained across multiple Ones.
```

### 3.4 Consequence for One/L2 relation

The architecture should not be:

```text
One
-> later enters L2
```

nor:

```text
L2
-> only exists outside One.
```

Better:

```text
historical writeback
-> localized sedimentation may become part of One's internal organization;
-> distributed sedimentation may become environmental/shared scaffold;
-> both can constrain later Selection.
```

### 3.5 Consequence for current L2 ontology

The current `L0 / L1 / L2` notation may be conflating:

```text
ontological stage;
historical storage role;
constraint field;
scale-relative shared scaffold.
```

Pass 3 does not abolish L2, but strengthens `REWRITE/RETYPE` pressure:

```text
retain sedimented-constraint insight;
drop any implication that all history is one global third domain;
make boundary/scale relativity explicit if the concept survives.
```

**Pass-3 verdict:** `L2-GRADE SCAFFOLD = BOUNDARY/SCALE-RELATIVE; MAY BE INTERNAL, EXTERNAL OR SHARED`.

## 6. New pressure created by Pass 3

Three issues now become central before author adjudication.

### Q13 — must Stable ISP be downstream of One?

The current graph assumes:

```text
formed continuity
before
stable structural perspective.
```

This seems plausible but should be attacked with edge cases where perspective-like organization appears without clear lineage-localized One formation.

### Q14 — does subject-position require all three of 承担 / 关切 / direction?

Current T-IND says yes in effect, but canonical-independent pressure should test minimality:

```text
Can non-outsourcable stake itself generate concern?
Can concern + stake imply local direction without separate epsilon-readability?
Or are all three irreducible gates?
```

### Q15 — should L2 remain a top-level L-number at all?

If L2 is a boundary-relative sedimented scaffold rather than a universal third ontological domain, audit whether the `L0/L1/L2` tier notation itself carries outdated stage metaphysics.

This question is now unavoidable but remains OPEN.
