# Selection Irreducibility Rival Test — Pass 1

> **Role**: executed non-canonical audit record under `Governance/SRT_GOV_SUB01_Subtractive_Audit_Protocol_v0_1.md`.
>
> **Scope**: test whether the primitive role currently carried by `selection` in `P0-01 / AM-A` is removable or reconstructable under declared refit budgets.
>
> **Hard boundary**: this record does **not** modify `P0-01`, `P0-04`, `P1-T05`, or any canonical definition. It does not prove selection fundamental, and it does not prove selection unreal. It assigns only target- and refit-budget-relative GOV-SUB01 residue judgments.

---

## 0. Executive verdict

**Pass-1 overall residue: `R4 compensated / unresolved`.**

The test produces three different results that must not be collapsed:

1. **`K=0`**: the current architecture literally depends on `selection`; deletion causes immediate loss in the P0 grammar and several downstream constitutive statements. This establishes implementation dependence only.
2. **limited `K`**: much of the downstream work can be reconstructed from a frozen non-selection vocabulary—historical asymmetry, reachable-set change, bearer-specific consequence return, and much of the real-choice/script distinction—but the primitive actualisation role cannot yet be counted as removed without a serious hidden-reparameterization risk.
3. **broad `K`**: a substantially different process/causal model can reproduce most currently operationalized downstream targets. This demonstrates substantial representational substitutability. It does **not** establish that the underlying actualisation role is absent, because the competing model may simply redescribe the role and because no external counterfactual/interventional divergence has yet been executed.

Therefore this pass supports neither of the two overclaims:

```text
P0 primitive status -> selection is proven ontologically irreducible     [NOT LICENSED]

broad-K reconstruction -> selection is merely a word and can be deleted [NOT LICENSED]
```

The next discriminating burden moves to **rival-model divergence**, especially `E_int` / `E_cf`, rather than another vocabulary-level reformulation.

## 1. Governing audit tuple

Following GOV-SUB01 §2:

\[
\mathcal A=\langle M,x,Y,C,E,H,P,K,\tau\rangle
\]

### 1.1 Current model `M_SRT`

Minimal tested fragment:

```text
non-objectified potential
-> primitive actualisation / determinate manifestation (P0-01 / AM-A)
-> manifest L1 event
-> irreversible trace / historical asymmetry (P0-03)
-> sedimented constraint on later transitions (L2 / P1-T03)
-> real-choice distinction where selected outcome constrains future selection space (P1-T05)
-> bearer- and history-sensitive continuation in stable ISP cases (P1-T06)
```

`\hat G_\theta` is treated exactly as current canonical does: a formal role-carrier, not a prior chooser or a mechanism that independently explains the primitive transition.

### 1.2 Candidate `x`

Delete both:

- the word / label `selection`; and
- the **primitive role** by which non-objectified potential acquires determinate manifest distinction.

Deleting only the label is insufficient and counts at most as rhetorical or representational substitution.

### 1.3 Locked targets `Y`

| Target | Preserved question |
|---|---|
| `Y1 Manifest actuality` | Can the model distinguish determinate occurrence from a merely described or latent alternative without assuming completed pre-given objects? |
| `Y2 Historical asymmetry` | Can it preserve irreversible trace, matched-endpoint history difference, and future constraint from prior path? |
| `Y3 Real-choice discrimination` | Can it distinguish a live event that changes future reachability from script replay / habit / gradient following without merely renaming the distinction? |
| `Y4 Bearer-specific consequence` | Can it preserve who bears path-specific cost, repair burden, or future-option loss, including anti-outsourcing bookkeeping? |
| `Y5 Differential leverage` | Does retaining `selection` change a counterfactual, intervention, or externally judgeable prediction relative to the rival vocabulary? |

### 1.4 Context `C`

- bearer: generic bounded system; bearer changes are treated as perturbations, not silently pooled;
- scale/grain: event -> short historical chain -> later reachable set;
- boundary: fixed before each comparison;
- history: path identity retained even when endpoints are matched;
- measurement regime: conceptual/structural audit only; no new empirical dataset is introduced;
- domain: cross-domain core fragment, with no physics/neuroscience/AI bridge allowed to back-define P0;
- normative authority: only bearer attribution is audited; no rights/legitimacy conclusion is licensed;
- horizon: immediate event plus delayed future-reachability effects.

### 1.5 Evaluation vector `E`

Primary:

- `E_int` intervention effectiveness / difference;
- `E_cf` counterfactual discrimination;
- `E_mech` mechanism identifiability / causal specificity;
- `E_norm` bearer/stake attribution.

Secondary:

- `E_phen` only as a preservation question for internally borne vs externally re-described event position; no phenomenal necessity claim is tested;
- `E_pred` only where a rival prediction can be stated;
- `E_orient` is recorded but not used to rescue theoretical indispensability.

### 1.6 Threshold `tau`

No scalar aggregate is used. A target counts as lost only when a declared target distinction cannot be reconstructed without:

1. target laundering;
2. bearer relocation;
3. hidden reparameterization; or
4. introducing a new primitive that performs the deleted selection role under another name.

## 2. Frozen reduced rival vocabulary

The limited-K rival may use only the following structural resources:

1. asymmetric constraint;
2. reachable-set restriction / transformation;
3. history dependence;
4. irreversible writeback;
5. cost / payability accounting;
6. bearer-specific consequence return;
7. ordinary state / process transition relations needed to compose 1–6.

### 2.1 Explicitly forbidden aliases

The rival may not introduce an unexplained primitive named or functionally defined as:

- choice;
- selection;
- decision;
- actualisation;
- chooser / selector;
- resolution operator;
- state-collapse primitive;
- manifestation operator;
- any black-box `F`, `R`, `A`, or kernel whose only specified job is “make one possibility determinate” while leaving that job unexplained.

A named transition relation is allowed only when its input/output conditions and causal role are independently specified. A black box that simply carries the full deleted role is a GOV-SUB01 §7.4 hidden reparameterization failure.

### 2.2 Role-conservation ledger

Every reconstruction must say where each role went:

| Role originally carried in SRT grammar | Rival must identify |
|---|---|
| determinate manifestation | what changes from non-determinate to determinate, without a renamed primitive |
| non-equivalent registration | which bounded state/process mediates the difference |
| path efficacy | which intervention changes actual continuation |
| consequence bearing | where path-specific burden returns |
| irreversible history | what preserves path identity / prevents “never happened” erasure |
| future reachability | how the prior path changes later admissible transitions / costs |

If the six roles are simply redistributed across renamed functions, only **label-level dispensability** has been shown.

## 3. `K = 0` — literal deletion

### 3.1 Operation

Remove `selection` and its primitive actualisation role. No compensating redefinition, new transition primitive, or reformulation of P0 is allowed.

### 3.2 Immediate losses

- `P0-01` no longer has a constitutive admission rule for determinate manifest actuality.
- `P0-03` loses the thing whose trace is called an irreversible selection trace, although generic historical irreversibility can still be stated descriptively.
- `P1-T04` loses its upstream distinction between a newly determinate fact and downstream information readout.
- `P1-T05` loses the current positive noun around which “real choice moment” is contrasted with script/habit/gradient following.
- `P1-T01/T02/T03` can still be rewritten as causal/history/constraint claims, but no longer retain their current derivational wording from selection dynamics.

### 3.3 Verdict

For the **current implementation**:

```text
K=0 -> robust immediate grammar loss.
```

Budget-relative classification: **`N1 current target-relative indispensable`** for `Y1` and the present canonical grammar.

**Guard**: this is not the overall residue. GOV-SUB01 §3 explicitly states that `K=0` answers only whether the present implementation literally depends on `x`.

## 4. limited `K` — frozen structural reconstruction

### 4.1 Allowed reconstruction

The rival may recompose the seven allowed structural resources but may not add a new primitive actualisation operator.

A minimal rival skeleton is:

```text
historically conditioned process state
+ asymmetric admissibility constraints
-> multiple materially available continuations are not equivalent
-> one continuation occurs through an ordinary specified transition channel
-> the outcome writes to persistent state / environment
-> cost and consequence are assigned to a fixed bearer position
-> the writeback changes later reachability / transition cost
```

This skeleton is deliberately non-SRT. It does not say that “selection” caused the transition.

### 4.2 Target results

#### `Y2 Historical asymmetry` — largely reconstructed

History dependence + irreversible writeback + later reachable-set change are sufficient to preserve:

- matched-endpoint path differences;
- “cannot treat the event as never having occurred” at the record/constraint level;
- delayed differences in transition costs or admissibility.

`selection` is therefore **implementation-substitutable for this target** unless a stronger SRT-only counterfactual is demonstrated.

Target-level residue: `R2` / `R3` depending on whether the comparison is implementation or target scoped.

#### `Y4 Bearer-specific consequence` — reconstructed

A rival can explicitly track:

- actor;
- executor;
- beneficiary;
- cost bearer;
- repair bearer;
- state on which future-option loss lands.

No current result shows that the word or primitive `selection` is necessary for this bookkeeping.

Target-level residue: **`R2 implementation substitutable`**.

#### `Y3 Real-choice discrimination` — provisionally reconstructable, but unresolved

Using live non-equivalent continuations + internal mediation + path efficacy + bearer consequence + future-reachability rewrite, the rival can reproduce much of the distinction currently used to separate a bounded selection-event candidate from mere output difference, script replay, or gradient following.

However, this reconstruction largely mirrors the existing `CG-0..CG-4` audit surface. `Core/SRT_OPEN_TENSIONS.md §14` already records that no executed test has shown a counterfactual/interventional gain over ordinary causal transition, constraint, and path dependence.

Therefore the correct result is **not** “selection removed.” It is:

> downstream event classification is substantially reconstructable; discriminating gain remains unexecuted.

Target-level residue: **`R4 compensated / unresolved`**.

#### `Y1 Manifest actuality` — unresolved due hidden-reparameterization risk

The rival can say “an ordinary transition yields a determinate event.” But two readings must be separated:

1. **weak reading**: the model begins with an already objectified state space and reports which state obtains. This reconstructs an event description but does not preserve SRT's pre-objectification / AM-A target.
2. **strong reading**: the model includes a primitive transition by which non-objectified potential becomes determinate. If this primitive is merely renamed “resolution,” “determinacy,” or an unspecified kernel, the deletion has failed by hidden reparameterization.

No independently specified limited-K mechanism in the frozen rival vocabulary currently closes this gap without one of those two moves.

Target-level residue: **`R4 compensated / unresolved`**, not `N1`: the audit has found a live burden, but has not shown that no alternative role decomposition can ever carry it.

#### `Y5 Differential leverage` — not demonstrated

No new intervention, counterfactual, or empirical result was executed in this pass that differs solely because one model retains the selection primitive.

Target-level residue: **`R4 compensated / unresolved`**.

### 4.3 limited-K verdict

The pass rejects both simplistic readings:

```text
"Most downstream roles can be reconstructed" -> selection is dispensable simpliciter.  [INVALID]

"Primitive actualisation remains hard to rewrite" -> selection is proven irreducible. [INVALID]
```

The supported result is:

> much of selection's downstream role is decomposable into ordinary structural relations; the primitive actualisation remainder is currently unresolved because rival reconstruction either changes the target or risks carrying the same primitive under another name.

## 5. broad `K` — substantially different rival model

### 5.1 Rival family admitted

Broad K may use a substantially different process ontology / state-transition / structural-causal architecture, provided it:

- states its primitives explicitly;
- does not define success by reproducing SRT vocabulary;
- preserves the locked targets without moving bearer or horizon;
- exposes where determinacy, writeback, and reachable-set change enter;
- does not hide the full deleted role inside an unexplained operator.

### 5.2 Result

For `Y2`, `Y3` (as an operational event classifier), and `Y4`, broad rival families can in principle reproduce almost all currently specified behavior using ordinary causal-history machinery.

For `Y1`, broad K can replace SRT's metaphysical starting point with a different ontology in which determinate states/events are primitive or in which a complete state-transition space is assumed. That is **representational/theoretical replacement**, but it is not a successful preservation of the exact SRT pre-objectification target; preserving that exact target would risk target circularity because the target is itself partly defined by the SRT primitive commitment.

This exposes an important limit of the audit:

> a metaphysical starting point cannot be declared empirically necessary merely because a rival that rejects the starting point does not preserve the starting point's own vocabulary.

The deciding burden must therefore move to `Y5`: externally judgeable differences in intervention, counterfactual, prediction, or bounded explanatory constraint.

### 5.3 broad-K verdict

- downstream structural roles: substantial **`R2 implementation substitutability`**;
- primitive actualisation role: **not adjudicated** by vocabulary replacement alone;
- overall: **`R4 compensated / unresolved`** pending differential leverage.

No `N2` is licensed because cross-context survival has not been demonstrated against strong rivals.

## 6. Failure-check ledger

### 6.1 Measurement blindness

A pure task-accuracy or endpoint metric would miss most of the declared target. Not used.

### 6.2 Short-horizon masking

The audit explicitly retains delayed future-reachability and repair-cost windows.

### 6.3 Redundancy / degeneracy

History, writeback, consequence return, and reachability can compensate for one another in event classification. This is a main reason the overall residue remains `R4`.

### 6.4 Hidden reparameterization

**Detected as the central failure risk.** Any rival that solves `Y1` by introducing an unexplained “determinacy/resolution/manifestation” primitive has not removed the role.

### 6.5 Target laundering

**Detected as the mirror-image risk.** A rival that assumes a pre-given object/state space may describe determinate events while dropping SRT's pre-objectification burden. That may be a legitimate alternative ontology, but it does not count as preserving `Y1` unchanged.

### 6.6 Scale collapse

Not adjudicated in Pass 1. No cross-scale irreducibility claim is licensed.

### 6.7 Bearer relocation

Prevented by fixed bearer bookkeeping in `Y4`.

### 6.8 Ethical asymmetry

No live-system protection or rights decision is involved.
