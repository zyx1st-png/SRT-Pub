# Generative normativity semantic-owner prototype — pressure test

> **Role:** adversarial test of the noncanonical semantic-owner prototype. No canonical edits are authorized.

---

## 1. Executive verdict

The prototype survives as a useful architecture, but only after one decisive limitation is made explicit:

```text
relation integrity
!=
relation legitimacy.
```

O2-C can establish constitutive consistency conditions for a relation **if that relation is to remain of a declared type**.

O2-C cannot by itself establish:

```text
that the relation ought to exist;
that the relation ought to continue;
that its declared type is morally legitimate;
that one position may never be subordinated / terminated / transformed;
that a consistently typed domination relation is morally acceptable.
```

This is not a failure of O2-C. It is the boundary that prevents O2-C from silently becoming O2-M.

---

# 2. Strongest objection — the honest tyrant / shmagency problem

Consider a relation Q that previously claims:

```text
X and Y are co-generative participants.
```

Suppose X recurrently displaces Y's effective source-role.

Participant-status consistency says Q must either:

```text
repair Y's real participation;
or
retype the relation honestly.
```

Now let X answer:

```text
"Fine. This is not co-generation. I openly define Q as domination.
Y is subordinate and does not co-author the relation."
```

The structural contradiction disappears.

Therefore:

```text
O2-C cannot prove domination morally wrong merely from relation-type consistency.
```

This is the strongest anti-overclaim result of the pressure test.

### Consequence

Generative non-usurpation cannot yet be a universal categorical moral law.

It remains:

```text
1. a structural diagnostic of generative substitution;
2. a constitutive norm where participation is part of the relation type;
3. a possible input to stronger moral standing / conflict adjudication downstream.
```

---

# 3. Add a new hard distinction — integrity vs legitimacy

Use:

```text
R-integrity
= does the actual generative organization still instantiate the relation type it claims / enacts?

R-legitimacy
= should this relation type exist / continue / govern these positions under the relevant moral / political / stake conditions?
```

Then:

```text
O2-C primarily owns R-integrity;
O2-M is required for full R-legitimacy where genuine conflict / moral standing enters.
```

O2-A may assign answerability for transforming, misrepresenting, or maintaining the relation, but answerability itself does not settle legitimacy.

---

# 4. Is O2-C merely semantic word-policing?

Potential objection:

```text
"If O2-C only says 'call the relation what it really is', it is linguistically trivial."
```

Answer:

The prototype is nontrivial only if relation type is **ontologically enacted**, not nominal.

For example, a co-generative relation requires real causal / selective organization in which each attributed participant materially enters the relation's future constitution.

If Y's role disappears, the ontology of the relation has changed regardless of language.

Thus O2-C tracks:

```text
real role-structure -> relation-type identity
```

not merely vocabulary.

However, the pressure test confirms:

```text
ontological retyping is descriptive necessity;
"therefore the new relation is morally wrong" does not follow automatically.
```

---

# 5. O1 lexical risk — `better/worse-for` can overstate welfare

The phrase:

```text
better / worse for X
```

can be misread as welfare, moral interest, or Bearer standing.

Safer owner language should be:

```text
generatively stronger / weaker for X with respect to R,H
```

or explicitly:

```text
G-better / G-worse relative to (X,R,H)
```

until Bearer / Concern / moral-standing burdens are separately paid.

Therefore:

```text
O1 structural evaluability
!= welfare theorem.
```

This guard is required before canonical landing.

---

# 6. One / Stable ISP / identity pressure

The prototype indexes a formed position X across a horizon H.

Potential circularity:

```text
how can a transition be better / worse for the same X
if sameness / continuation has not been established?
```

Required correction:

- for event-local or short relation-local comparison, One / Selection-position may be sufficient if no strong diachronic identity claim is made;
- where the comparator says the **same X** persists across a declared interval / perturbation range, the relevant continuity / Stable-ISP / lineage burden must be independently paid;
- O1 must not create identity by needing an evaluation target.

Thus:

```text
O1 inherits identity / continuity;
O1 does not define identity / continuity.
```

# 7. Bearer / Concern pressure

Current spine keeps:

```text
formed One / Selection-position + P + E -> Bearer
```

and explicitly blocks automatic One->Bearer->Concern->Agency ladders.

The prototype is compatible only if:

```text
O1 / O2-C structural relation
can occur without claiming Bearer / moral stake;

but
moral patienthood / suffering / non-outsourcable stake claims
must route through the relevant stronger owners.
```

Example:

A tumour may have a structurally describable local generative strengthening relation without thereby acquiring complete moral standing.

Therefore:

```text
G-better-for
!= morally-better-for.
```

This is a necessary guard, not an embarrassment.


Later O0 repair may supply a weaker primitive directionality relation, but it must not predetermine O1/O2-C content.

# 11. T_dir pressure

Current `T_dir` contains two layers:

```text
useful operational core:
self-readability + reorientation of a direction signal;

old metaphysical layer:
value is always embedded in Selection / every Selection carries order direction.
```

The prototype is compatible with the first and conflicts with the second.

Future safe routing:

```text
independent O1 / O2-C typed direction relation
-> D_ref
-> T_dir asks whether the formed system can read / use D_ref for reorientation.
```

Not:

```text
T_dir
-> proves value direction exists.
```

Thus the prototype can eventually provide one family of downstream `D_ref`, but it must not make T_dir its owner.

The current anti-optimization interface strongly agrees that:

```text

capacity != normative coupling;
non-substitutability matters.
```

But it currently grounds normativity in:

```text
concern-weighted non-substitutability.
```

The new prototype is broader and earlier:

```text
participant-status / generative-role non-substitution
can be structurally typed before complete Concern standing.
```

Therefore:

```text
generative non-substitution
!= d-value non-substitutability;
!= concern non-substitutability;
```

They may later interact, but must not be merged.

# 13. Ethics / Agency pressure

Existing Ethics_Agency guardrails are mostly compatible:

```text
responsibility requires selectable agency;
causal role != responsibility;
high d != agency;
choice window / knowledge / consequence return / revision matter.
```

But old bridge prose also contains overstrong claims such as absolute responsibility and inherited normativity-from-order language.

The new routing should be:

```text
O2-C establishes relation-level constitutive integrity;
O2-A asks who can be answerable for relation-transforming Selection;
O2-M asks whether / why the relation or action is morally justified overall.
```

This prevents responsibility from being used as the foundation of normativity.

# 14. Hard cases

## 14.1 Honest domination

A domination relation may be internally type-consistent.

Result:

```text
O2-C pass possible;
O2-M legitimacy still OPEN.
```

## 14.2 Parental formation

A child may not yet have the same generative role as a mature adult.

Correct typing can permit temporary asymmetry.

But if the relationship claims to be developmental / formative, then whether it systematically prevents the future emergence of the attributed mature generative role becomes a legitimate O2-C / O1 question.

Still:

```text
no automatic universal parenting rule.
```

## 14.3 Medical guardianship / incapacity

Delegated or substituted decision-making can be correctly typed and necessary.

O2-C does not forbid it.

Questions of stake, restoration, consent, harm and legitimacy route downstream.

## 14.4 Irreversible commitment

A genuine commitment can reduce future alternatives while constituting a new formed position / relation.

Therefore:

```text
option loss != G-worse automatically.
```

## 14.5 Self-sacrifice / self-termination

A formed agent may author a transition that reduces or ends its own future generativity.

This does not retroactively invalidate the Selection event.

O1 may register a loss on one generative dimension; O2-M cannot automatically forbid it.

## 14.6 Predatory but coherent system

A predatory institution can be highly persistent, coordinated and internally generative.

The prototype correctly refuses:

```text
more local generativity = more moral good.
```

Its moral diagnosis still requires cross-position standing / stake / legitimacy work.

# 15. Partial-order dominance pressure

The limited dominance rule survives, but only under strict conditions.

It applies when:

```text
same declared task / relation objective;
same admitted comparison scope;
no real tradeoff hidden by omitted positions / horizons;
no higher-order independently established loss;
at least one dimension strictly improves.
```

It fails when the parties disagree about:

```text
the task itself;
which positions count;
which horizon counts;
which relation type should exist;
which loss is morally weightier.
```

Thus N5 is genuinely useful but narrow.

---

# 16. Hume-gap pressure

The prototype supports three increasingly strong statements:

### H1 — descriptive retyping

```text
a relation either does or does not instantiate its claimed generative type.
```

Strong and non-normative.

### H2 — constitutive normativity

```text
if the relation is to remain of type tau,
it must satisfy tau's constitutive generative roles or be retyped.
```

Strong candidate for O2-C.

### H3 — categorical moral normativity

```text
therefore tau ought to exist / continue
or domination ought never occur.
```

NOT ESTABLISHED.

Therefore current Hume status must be stated precisely:

```text
SRT has a strong candidate for type-theoretic / constitutive normativity;
it has not yet dissolved the categorical moral is/ought gap in full.
```

This is a more precise version of:

```text
partial constitutive dissolution: strengthened;
complete deontic closure: OPEN.
```
