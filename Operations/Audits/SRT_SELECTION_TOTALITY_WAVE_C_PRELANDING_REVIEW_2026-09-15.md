## Owner 1 — Claim Ladder §0A

### Blocking residual A — obsolete Class A enumeration

Current §0A still lists `κ₀`, `ε_pg` and the irreversibility floor as bare-L0 Class A members and still describes structured potentiality as a primitive inventory-like object.

This conflicts with the landed Selection-totality architecture. `κ₀` and `ε_pg` may remain formal / stronger-realization candidates, but their inheritance from primitive non-flatness is OPEN and they cannot define O0 by default.

### Blocking residual B — primitive option-count ordering

Current §0A states that `ε_pg` induces a primitive two-class ordering `B >= 2` over `B <= 1` and explicitly protects this as Class A.

This conflicts with the landed hard guard:

```text
B >= 2 primitively preferred over B <= 1: NO;
continuation preference at O0: NO;
terminal Selection defective: NO.
```

### Required retyping

Gate 0 remains a governance type / admission boundary. It must not become a second metaphysics owner.

Its role after Wave C should be:

```text
primitive / L0-side claims may carry only contentless structural burdens already licensed by the current L0 / Spine owners;
global notation does not create primitive authority;
formal anisotropies, priors, probability measures, entropy, κ0, ε_pg, option-count rankings and reachability orderings require independent typing / derivation;

```

Suggested current Class A examples are only already-landed contentless burdens such as:

- non-maximal indifference / minimum non-flatness;
- openness not exhausted or fully preclosed by completed determinate actuality;
- finite positional indexing without a prior formed operator / subject.

Gate 0 should explicitly say that the examples are routing summaries of current L0 / Spine commitments, not independent ontology definitions.

## Owner 2 — T_dir canonical

### Blocking residual C — primitive value / order smuggling

Current §§1–2 still state:

```text
value is embedded in Selection itself;
every Selection points toward order;
nihilism mistakes hidden value for absence;
```

This is no longer compatible with Selection-totality. Primitive Selection is generative but normatively contentless.

### Blocking residual D — T_dir lacks an independently typed direction source

Current `Def-T-1` defines T_dir as readability of the system's own `order direction`, allowing the direction to be silently inherited from primitive Selection.

Wave C must require a declared downstream direction / relation before T_dir is admitted.

Correct routing:

```text
T_dir
= self-readability / reorientation capacity relative to an independently typed, declared direction signal.
```

A direction may come from a formed positional / relational constraint, an explicit agent objective, a domain bridge or a declared model gradient. T_dir does not itself create or validate that direction.

Important typing rule:

```text
no declared direction -> T_dir not admitted / undefined for that claim;
declared direction present but unreadable -> T_dir may be 0;
T_dir > 0 -> direction is self-readable / usable for reorientation under the declared model;
T_dir > 0 -/-> good / legitimate / generatively healthy / morally correct.
```

### Blocking residual E — proto-gradient / Part II backflow

Part II is already described as bridge / theory-clarifying, but §§11–18 repeatedly use `proto-gradient`, `expected L0`, `maximum order`, `value attractor` and `universal criterion` language as if it supplied a universal value direction.

These sections may remain as historical / bridge development, but they need local authority guards so connector retrieval cannot restore a primitive direction claim.

At minimum the following sections require a local Selection-totality scope marker or bounded rewrite:

- §11 value generation;
- §12 internal value / proto-gradient;
- §13 value induction;
- §14 expected L0 / symmetry perception;
- §15 value attractors / maximum order;
- §16 rise vs degeneration;
- §17 penetrative vs absorbed Psi_f;
- §18 T_dir development paths.

The local guard should state that:

```text
these are downstream / bridge hypotheses about formed systems and relations;
proto-gradient is not a primitive universal direction source;
"order", "higher", "healthy", "degenerate" and "value" require independently declared criteria;
no section may back-define primitive Selection, O0, legitimacy or O2-M.
```

### Blocking residual F — d / Psi_f / ii conditions overstate universality

Current §4 treats d, Psi_f and ii as universal necessary mechanisms for T_dir.

Wave C should retype them as current operational / bridge implementation hypotheses unless an independent canonical owner already proves necessity.

In particular:


must not be presented as primitive or universal Selection laws. The current v0 operational role may remain.
