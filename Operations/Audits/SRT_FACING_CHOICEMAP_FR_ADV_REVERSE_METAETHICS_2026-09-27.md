# ChoiceMap / reverse-metaethics FACE-REC — FR-ADV pass 1

## 0. Target under pressure

Author-accepted preformal reconstruction:

```text
L2-facing explicit traces
-> inverse reconstruction of latent L1 directional-generative process;

L1 directional sense
and
L1 recutting / candidate-generation
= two facings of one event;

underlying event need not be phenomenal;

mismatch / friction can foreground an otherwise transparent direction;

direction is:
- historically inherited;
- pre-object relative to the current cut;
- continuously operative;
- recursively revisable;

historical source intuition:
L0-facing primitive Selection
-> source-line of L1 directional-generative polarity
-> formed differentiation into Expectation / exposure / Concern-value / moral structures;

ChoiceMap
= candidate reverse-identification instrument.
```

The FR-ADV question is not whether this is intuitively coherent.

It is:

> after strongest source-return and mature-neighbor subtraction, what burden remains that changes dependency order, objectification, measurement or intervention?

The current reconstruction is not isolated from the author's earlier source line.

```text
pre-object generative orientation
-> mismatch / fit changes before explicit reason
-> later objectification of violated relation
-> explicit explanation / recut;
```

```text

```

Current package obeys this.

The accepted scale-separated reconstruction also obeys this.

## 4. ADV-4 — reparameterization pressure

This is the strongest current danger.

The whole proposal may collapse into:

```text
latent state / policy / value landscape
+ history
+ prediction error / mismatch
+ adaptive updating
+ conscious access when globally relevant.
```

If so, SRT has only renamed a familiar architecture.

To avoid reparameterization, the reconstruction must require something that a fixed-state-space latent-value model does not already pay.

Candidate non-reparameterization burden:

```text
the latent process must be allowed to change:
- what the objects are;
- what the comparison dimensions are;
- what counts as a candidate;
- what the relevant scale is;
- what the problem itself is;

and those recuts must be constrained prospectively,
not only fit after observing the author's response.
```

This is stronger than:

```text
same candidate space + updated weights.
```

But modern model-based, hierarchical, nonparametric or structure-learning accounts can also change representations.

Therefore even "recutting" is not yet unique.

The sharper burden must become:

> Can the reverse reconstruction predict **which level of representation must be revised** before the explicit recut appears, and can it outperform a fair structure-learning / latent-state rival?

Until then:

```text
NON-REPARAMETERIZATION = NOT ESTABLISHED.
```

## 5. ADV-5 — dependency-order change

### Provisional result: YES, conceptually; empirical gain unproven

The strongest surviving change is a dependency-order correction.

Object-first / value-after architecture:

```text
objects / candidates
-> evaluation
-> choice
-> update.
```

Current author route:

```text
historically formed directional-generative organization
-> helps determine distinctions / comparisons / candidates
-> objectification
-> explicit evaluation / reason / choice
-> retained consequence
-> reconstruction of later directional organization.
```

This changes what must be measured.

The primary datum becomes:

```text
transformation of the offered representational cut
```

rather than:

```text
choice among offered options.
```

That is a real methodological difference.

However mature ecological / enactive / structure-learning approaches may accept similar ordering.

Therefore:

```text
dependency-order change = ESTABLISHED WITHIN THE SRT/ChoiceMap METHOD;
scientific distinctiveness = NOT ESTABLISHED.
```


Reconstructed object:

```text
offered grammar / cut
-> acceptance / rejection / merge / split / root-return / breakout

```

Therefore:

```text

becomes downstream evidence;

becomes primary reconstruction evidence.
```

This is a genuine objectification change even if no SRT-specific scientific residual is established.

## 8. ADV-8 — reverse-metaethics pressure

The reverse-metaethics route is most vulnerable to an is/ought shortcut.

Blocked:

```text

-> therefore it is morally correct.
```

Blocked:

```text
what feels better
-> what is morally better.
```

Blocked:

```text
cross-person invariant
-> universal moral truth automatically.
```

The defensible research target is narrower:

> reconstruct the genesis and differentiation of evaluative direction before explicit moral objects, then separately test what additional relations license normative authority.

Therefore the programme can investigate:

```text
genesis of evaluative direction
```

without claiming:

```text
complete moral truth derivation.
```

Current disposition:

```text
REVERSE METAETHICS = RETAIN AS RESEARCH PROGRAMME
FULL METAETHICAL SOLUTION = NOT ESTABLISHED.
```

## 11. What would count as real gain

At least one of the following must be achieved prospectively.

### G1 — recut prediction

Before seeing the explicit correction, predict whether the subject will:
- accept the current cut;
- reject a dimension;
- change level;
- merge / split objects;
- root-return;
- generate a new comparison scale.

### G2 — representation invariance

Infer a directional-generative relation from one L2 realization and predict recuts under a materially different language / representation / object inventory.

### G3 — model exclusion

Show that a fair:
- stable-preference;
- reward/value;
- latent-state;
- active-inference;
- enactive/affordance;
- structure-learning

model cannot match the same cross-perturbation transformations at equal or lower burden.

### G4 — direction / content dissociation

Manipulate explicit moral/value content while preserving inferred directional organization, or vice versa, and prospectively predict which recuts remain invariant.

### G5 — developmental / historical reconstruction

Predict how a known history-changing intervention alters later pre-object directional organization without merely refitting a new preference vector after the fact.

Absent such gain:

```text
ChoiceMap FACE-REC disposition
= useful reconstruction discipline / self-study tool,
not distinct explanatory science.
```
