# Author Re-entry Cycle 1 — history-in-One admission and Bearer-genesis audit

> **Question:** can `当历史痕迹沉积在一时，变为 Bearer` be given a non-circular causal reading, and does that reading force any change in the direction of existing bearer tests?
>
> **Boundary:** this audit does not define Bearer canonically. It pressures existing owner logic using the live author relation and records the minimum remaining author burden.

---

## 0. Live author relation

The author has stated:

```text
before Bearer:
Selection sedimentation is in 多

transition:
historical traces sediment in 一

then:
一 becomes Bearer
```

The key burden is therefore not whether history exists, but **how history attribution / localization itself becomes constitutive of a continuing One**.

---

## 1. Existing owners already block the weakest answers

### 1.1 Internal location is not enough

PH-IND02 already blocks:

```text
analyst draws a box
-> all events inside the box belong to one bearer
```

and explicitly keeps:

```text
copied state
replayed trace
externally archived history
replaceable instance
```

from automatically establishing same-bearer temporal closure.

Therefore Cycle 1 cannot define:

```text
history sediments in One
=
there exists an internal memory variable
```

### 1.2 Causal efficacy is necessary but not enough by itself

PH-IND02 and PH-IND06 already require that history change later organization / selectability and use reset / replacement / non-outsourcing pressure.

But a portable policy table can causally change later Selection after being copied into a fresh machine. Thus:

```text
internal + causally active
!= automatically historically owned by this One
```

### 1.3 Persistence is not enough

PH-IND06 already blocks:

```text
Persistent Process = Bearer
```

A storm, service, institution, checkpoint-restored controller or distributed workflow may persist while relevant costs/history close elsewhere.

### 1.4 History-bearing is weaker than history-constituted

The Processual Bearer bridge already distinguishes:

```text
history-bearing:
earlier outcomes leave traces constraining later candidates

history-constituted:
the candidate's current organization is itself a generative product
of earlier historical stages
```

This distinction is the nearest existing internal neighbor to the new live author relation.

It still does not solve numerical identity.

---

## 2. Circularity in the old `theta_trace / theta_ext` individuation picture

`Core_Law/SRT_Individuation.md` currently decomposes a selection pattern's parameters as:

```text
theta_t = theta_t^trace + theta_t^ext
```

and treats `theta_t^trace` as the component written by the pattern's **own prior outputs**.

This is useful once a pattern / candidate unit is already sufficiently stable to support attribution.

But as a genesis theory it faces a circularity:

> Before Bearer formation, by what non-circular rule can a trace already be classified as `P's own trace` rather than part of the wider multiplicity?

Therefore Cycle 1 pressures the role of the old self-reference ratio:

```text
unsafe genesis reading:
theta_trace/theta_ext ratio creates the first Bearer by definition

safer candidate reading:
after / during sufficient One-localization of history,
theta_trace/theta_ext can serve as one model-local readout of an already-emerging
history-attribution asymmetry
```

This does **not** invalidate the existing model. It changes the direction of explanation under pressure.

The scalar should not be used to solve the attribution problem it presupposes.

---

## 3. Four adversarial cases for `沉积在一`

The purpose is to find the earliest case that deserves the phrase without using Bearer in the premise.

### Case S0 — internal but inert storage

```text
one robot contains a log file of its past actions
but the log never changes its future Selection or maintenance
```

Verdict candidate:

```text
storage inside One
!= Selection sedimentation in One
```

### Case S1 — portable causal memory

```text
a policy / memory token inside candidate A changes A's later Selection;
the token can be copied into fresh candidate B and reproduces the same measured policy
```

This establishes:

```text
causal memory inside a declared unit
```

but not automatically:

```text
A's historical ownership transferred to B
A = B
```

Open pressure:

> Is A already a weak Bearer simply because history causally sediments in A, even though the same causal state is portable?

### Case S2 — same-line adaptive writeback

```text
Selection / consequence involving candidate A
-> durably changes A
-> the changed A performs later Selection
-> repeated writeback progressively stabilizes A's selection-position / boundary
```

This is stronger because the trace is not merely housed inside A; it participates in **reconstituting the continuing organization from which later Selection proceeds**.

### Case S3 — history-constituted reconstitution under turnover

```text
material / component realization changes substantially
but a history-generated organization continues to regenerate the selection-position,
consequence pathway, and later selectability of the evolving One
```

This is the strongest non-phenomenal candidate for:

```text
history sediments in One
```

without requiring snapshot identity.

It still does not prove strict numerical identity under copying/fission.

---

## 4. C candidate — non-circular causal reading of `沉积在一`

A bounded candidate interpretation is:

> **Historical traces sediment in a One when prior Selection/consequence traces do not merely reside within a declared unit, but causally participate in the recurrent reconstitution of the selection-position / boundary through which that unit's later Selection continues.**

Compactly:

```text
trace persists
+
trace alters later Selection
+
trace contributes to reconstituting the continuing One / selection-position
-> strong candidate for history-in-One sedimentation
```

The third clause is the key increment over portable memory.

This is `C`, not author-owned wording.

### Guard

Do not silently replace `reconstituting the continuing One` with:

```text
self-maintenance alone
autopoiesis alone
internal memory alone
same current state
non-outsourcing alone
re-identifiability alone
```

Those are pressure dimensions / realizations, not automatic identities.

---

## 5. R4 — genetic reading reverses the direction of the old bearer audit

Existing bearer hardening usually has this operational order:

```text
1. declare candidate unit
2. test boundary / consequence return
3. test history writeback
4. evaluate bearer status
```

The live Cycle-1 relation suggests a stronger **genetic** question:

```text
1. begin without a stable Bearer
2. allow Selection consequences to sediment in the wider multiplicity
3. manipulate whether historical writeback repeatedly converges on the same emerging One
4. ask whether a stable selection-position / boundary / continued Selection emerges
```

This is not merely a semantic reversal.

It changes the intervention target from:

```text
POST-FORMATION:
does this already-declared unit retain its history?
```

to:

```text
FORMATION-TIME:
does routing historical efficacy repeatedly into the same emerging One
cause / accelerate / stabilize Bearer formation relative to distributing
comparable historical efficacy across 多?
```

That is the clearest downstream consequence of the new genetic reading not already paid by the fixed-core D2 audit.

---

## 6. Formation-time discriminator candidate

Hold as closely as possible:

```text
total Selection count
total historical trace magnitude
total memory / plasticity capacity
environmental statistics
initial component architecture
resource budget
```

Vary only the **routing consistency / localization of historical efficacy**.

### Distributed-history condition `D`

```text
Selection consequences are retained,
but writeback is dispersed / shuffled across 多;
no one emerging unit repeatedly receives a coherent historical line.
```

### One-localizing condition `O`

```text
comparable Selection consequences are repeatedly routed back into
one evolving candidate organization;
that writeback changes later Selection and contributes to reconstituting
that same selection-position / boundary.
```

Candidate Cycle-1 prediction:

```text
O > D
```

on a **vector** of formation observables such as:

```text
cross-time selection-position continuity
boundary reconstitution after perturbation
history-conditioned reselection
same-line correction / repair
persistence of candidate-unit-specific transition biases
resistance to writeback shuffling
```

Do not reduce this to one maturity scalar.

---

## 7. Failure logic

The genetic reading weakens if:

```text
A. distributed / shuffled history produces the same stable unit formation
   as same-line localized history after matched total trace;

B. internal portable memory is sufficient for every claimed Bearer consequence,
   with no remaining role for recurrent reconstitution / history attribution;

C. the `O > D` result is fully explained by ordinary memory bandwidth,
   recurrent connectivity, autonomy, or optimization without any independent
   history-attribution distinction;

D. `history sediments in One` can only be detected after declaring in advance
   which unit counts as the Bearer.
```

Failure should narrow the genetic claim, not generate a new metaphysical variable.

## 9. One remaining author adjudication

The main unresolved author question is now narrow:

> Does `历史痕迹沉积在一` require that the trace help **reconstitute / maintain the One from which later Selection continues**, or is any causally active history stored inside an ontological One already sufficient for that One to count as Bearer?

The answer separates:

```text
S1 portable causal memory
from
S2/S3 history-constituted continuing One
```

and determines whether the formation-time discriminator is genuinely licensed by the author relation or only an AI strengthening.
