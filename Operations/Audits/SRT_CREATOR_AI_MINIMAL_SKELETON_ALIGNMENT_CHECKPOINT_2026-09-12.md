# Part I — internal deletion pressure

## 4. Can manifestation, backgrounding and verticality be deleted as separate nodes?

### Test

Remove them as separate stages while preserving Selection as actual differentiation.

### Result

No essential explanatory content is lost if they remain typed as distinct **readings** of the same event:

```text
Selection = process reading;
manifestation / backgrounding = polar reading;
primitive verticality = structural reading.
```

### Verdict

```text
SEPARATE TEMPORAL NODES = unnecessary / misleading.
DISTINCT ANALYTICAL READINGS = retain.
```

This is one of the strongest compressions in the checkpoint.

## 5. Can pre-object Difference be deleted entirely?

### Crude deletion

```text
absolute featureless neutrality
-> Selection somehow occurs
```

### Pressure

This creates an unexplained jump from a condition in which no continuation is more or less admissible than any other to a selective event with direction / asymmetry.

### Counterpressure

Keeping a pre-existing `Difference` as an actual distinction risks smuggling completed alternatives into the pre-object level.

### Current balance

Retain only:

```text
non-equivalence / directional openness
without separately identifiable alternatives.
```

### Verdict

```text
actual pre-Selection distinction = reject for now;
absolute featureless neutrality = reject for now;
minimal oriented openness = retain as admission condition candidate.
```

## 7. Can One be defined as persistence or recurrence alone?

### Counterexamples

```text
stable crystal / mountain:
long duration, but no obvious recurrent self-reconstitution requirement.

externally reprinted pattern:
repeated similarity, but current pattern contributes nothing to later generation.

vortex / flame:
current organization plausibly conditions later organization, but with heavy environmental dependence.

cell:
strong endogenous contribution to later reconstitution while exchanging matter / energy.
```

### Result

The useful discriminator is not duration or similarity but:

```text
current lineage organization makes a non-trivial endogenous contribution
to later lineage-relative reconstitution.
```

### Verdict

```text
persistence alone = insufficient;
recurrence alone = insufficient;
full autonomy / closure = too strong;
non-trivial endogenous reconstitutive contribution = current best admission pressure.
```
