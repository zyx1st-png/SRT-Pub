## §1 Universal formation route

Disposition: **MAJOR RETYPE**.

Current `modal condition -> primitive generative operation -> formed result` should no longer be the master ontology picture.

Replace master reading with:

```text
Selection reality
├─ modal/open aspect;
├─ actualising event-cut;
└─ recurrent Selection-mediated organization -> One.
```

Retain:

```text
one-shot Selection != One;
role recurrence != token identity;
One formation requires Selection-mediated recurrent conditioning;
universal One admission does not imply Bearer / subject / agency.
```

Reword `universal formation route stops at One` as:

```text
One is the first universal formed recurrent Selection-organization owned by this formation route;
stronger standing/bearing/agency remain separately gated.
```

This prevents `stops at One` from sounding like reality itself stops there.

## New governance guard — facet before kind

Disposition: **ADD**.

```text
Before adding a new ontological noun:
1. state the distinct structural burden;
2. ask whether it is a mode / organization / relation of Selection;
3. create a new ontic kind only if the mode reading fails under explicit argument.
```

This is a default burden rule, not a proof that no other ontic kind can ever exist.

## Acceptance tests for eventual Spine patch

A patch FAILS if it:

- says `everything is Selection` without typed structural burdens;
- collapses Selection event into One / Bearer / Agency;
- turns all downstream concepts into mandatory temporal stages;
- makes Ghost Operator primitive;
- equates actual occurrence with value / legitimacy;
- closes O2-M;
- weakens P+E Bearer gate;
- erases the occurrence / persistence / Stable-ISP boundary.

A patch PASSES only if it makes the ontology more unified while preserving more, not fewer, explicit gates.
