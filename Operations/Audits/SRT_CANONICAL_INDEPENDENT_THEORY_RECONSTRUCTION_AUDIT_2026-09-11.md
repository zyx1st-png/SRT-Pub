# Canonical-independent theory reconstruction audit — 2026-09-11

> **Role:** reconstruct the minimum current SRT theory architecture before asking how it fits current canonical owners.
>
> **Noncanonical status:** this file is an active audit, not a definition source and not a canonical rewrite.
>
> **Author direction:** theory-first / reconstruction-first / canonical-lagging. Current canonical is evidence and historical authority, not the prior truth constraint for this audit.

## 0. What this audit is trying to prevent

Two opposite failure modes are prohibited.

### Failure A — canonical conservatism

```text
new reconstruction
-> ask only whether it conflicts with current canonical
-> preserve old owner wording by default
-> theory becomes an exercise in compatibility maintenance
```

This can freeze historical path dependence into theory.

### Failure B — novelty overwrite

```text
new author intuition
-> assume newer = truer
-> overwrite canonical immediately
-> lose hard-won distinctions / evidence / formal discipline
```

This destroys continuity and allows conceptual churn.

The audit therefore uses:

```text
reconstruct independently first;
compare historically second;
edit canonical only after author adjudication third.
```

## 4. Preliminary minimum architecture

The current best provisional architecture is intentionally sparse:

```text
minimum non-neutral structural floor
-> subjectless Selection / actualisation
-> manifestation with relative backgrounding
-> historical result-to-condition recursion
-> localized continuing organization
   [One-candidate / continuation aspect]
-> operative from-where
   [Selection-position candidate / operative aspect]

then separate downstream questions:

A. bearing / self-consequence / non-outsourcing relations;
B. stable perspective-bearing standing;
C. stronger generative self-revision;
D. higher-scale / collective formation.
```

This is **not** yet a theorem ladder. In particular:

```text
bearing is not automatically a new object;
Selection-position is not automatically a new standing;
Stable ISP / subject-position may be one standing;
second-order / Active / generative reselectability may be type-different descriptions of related deeper revision phenomena;
collective formation is not required to pass through generative reselectability first.
```

## 5. Candidate ontology-node test

Before any term becomes a canonical node, ask all five:

1. Does it identify a distinct object/standing rather than a relation/aspect/readout?
2. Is its admission condition non-redundant with an existing deeper node?
3. Would removing the term collapse an explanatory distinction that cannot be recovered compositionally?
4. Does it survive strongest-neighbor translation without becoming generic feedback/process language?
5. If added, which older terms become aliases, subtypes, projections or historical labels?

Failure of (1) or (2) strongly favors keeping the term as relation/aspect/proxy rather than ontology node.
