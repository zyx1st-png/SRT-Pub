# Whole-field composition from transparent closures

> Goal: derive a whole-field architecture from lower-level Gate formation / closure without introducing 'field' as an independent primitive or merely repeating the word Gate at every scale.

## 0. Starting point

We now have a lower-level candidate cycle:

~~~text
active bridge formation
-> reusable relational property
-> thin index × bridge reciprocal closure
-> object-level closure
-> transparency / givenness
-> mature closure constrains later lower processing
~~~

The whole-field question is:

> **How do many such closures jointly determine the system's current geometry of what can form / matter / be acted on next?**

---

## 1. Field is not the sum of object nodes

Reject:

~~~text
field
= list of all currently represented objects
~~~

because many field constraints are:
- pre-object;
- action-relative;
- body-state dependent;
- habitual;
- contextual;
- temporal;
- cross-object;
- currently latent but rapidly callable.

Therefore the field must include relations among closures and constraints on their joint use.

---

## 2. Minimal composition relation — shared downstream dependence

Two closures matter to the same current field when they are not independent for ongoing generation.

First composition condition:

~~~text
C_i and C_j
share downstream variables / resources / effectors / state estimates
such that activating or changing one alters
the realizability or meaning of the other
~~~

Examples:
- two action options compete for one hand;
- balance state changes which reaching affordances are usable;
- current social context changes which object-actions are appropriate;
- one task rule suppresses another learned mapping.

This creates actual interaction rather than mere coexistence.

---

## 3. Composition relation CR2 — compatibility / incompatibility

A whole field needs a current relation over:

~~~text
which closures can co-stabilize
which are mutually exclusive
which one subsumes another
which must wait
which can be ignored
~~~

Working interpretation:

> **field geometry is partly a compatibility topology over currently available closures and bridge families.**

This gives a non-metaphorical meaning to 'attractor field':

some combinations are dynamically easy to co-realize;
others are unstable or mutually blocking.

---

## 4. Composition relation CR3 — nested control

Closures can be nested.

Example:

~~~text
'cup' object closure
is nested inside
'make tea' activity closure
which is nested inside
'prepare breakfast' task set
~~~

Higher closure does not micromanage every lower bridge.

It constrains which lower closures are relevant and how they are sequenced.

This recovers the conscious-action result:

~~~text
coarse high-level target
-> lower Gate configuration
-> distributed execution
~~~

without introducing a central executive.

---

## 5. Composition relation CR4 — competition for control

Some closures cannot dominate downstream control simultaneously.

Examples:
- approach vs avoid;
- continue habit vs deliberate override;
- grasp one object vs another;
- read word vs inspect font;
- maintain conversation vs respond to threat.

Thus:

~~~text
field
includes current control competition
not merely stored structure.
~~~

Affordance competition and cognitive-control accounts are strong mature neighbors here.

---

## 6. Composition relation CR5 — common perturbation response

Multiple closures can become one coordinated field when one perturbation reorganizes several at once.

Example:

~~~text
unexpected alarm
-> object relevance changes
-> action affordances change
-> attention changes
-> posture changes
-> ongoing task closure weakens
~~~

This is stronger than saying many representations changed in parallel.

It indicates a shared higher-order constraint affecting the current compatibility topology.

Neural metastability / large-scale coordination are mature implementation neighbors for this burden.

---

## 7. Composition relation CR6 — shared prospective direction

Structural Expectation / current goal can bias several closures together.

Example:

~~~text
'drink water'
-> cup closure becomes action-relevant
-> route-to-cup relation strengthens
-> irrelevant objects recede
-> hand configuration / posture options shift
~~~

The field therefore has direction because closures are not equally weighted for the current prospective continuation.

Important:

~~~text
direction
!= conscious goal only
~~~

Embodied / enacted Expectation may supply direction without explicit representation.

---

## 8. Composition relation CR7 — history-dependent priority

Transparent closures differ in how easily they re-enter.

History changes:
- activation threshold;
- habitual dominance;
- transition cost;
- expected success;
- conflict sensitivity;
- repair speed.

Thus whole-field geometry is history-conditioned.

Current state cannot be characterized only by the explicit objects presently foregrounded.

---

## 9. Candidate whole-field representation

Do NOT harden as a canonical equation.

Working graph-like picture:

~~~text
nodes
= active / latent closures, bridge families, thin indices, goals / constraints

edges
= compatibility, inhibition, nesting, transition, shared-resource,
  mutual prediction, common perturbation and re-entry relations

current weights
= history + body state + context + Expectation + relevance + friction
~~~

The field is then:

> **the current organization of how these closures can jointly stabilize, compete, transform and recruit one another.**

This is closer to a dynamic constraint network than a static map.

---

## 10. Why this counts as 'whole' without a central controller

Whole-field unity need not mean every local process synchronizes.

Use the existing distinction:

~~~text
coordination unity
!= continuation unity
!= bearer unity
~~~

For the neutral cognition programme, 'whole' means:

> local changes propagate through enough shared compatibility / constraint relations that the system has one current organization of mutual possibilities rather than disconnected mini-fields.

This is compatible with metastable integration / segregation.

---

## 11. Field formation is recursive

Lower closures compose the field:

~~~text
bridges
-> properties
-> objects / skills / habits
-> current compatibility topology
~~~

But the field also changes lower formation:

~~~text
current compatibility topology
-> which differences are sampled
-> which bridge attempts are worth making
-> which errors matter
-> which objects become foreground
~~~

So:

> **field and local Gate formation are recursively co-constituting at different analytic scales.**

Do not interpret this as temporal simultaneity in every implementation.

---

## 12. Link to author's active-field intuition

The author's original field intuition can now be reconstructed without a primitive field object:

~~~text
active bridge formation
-> transparent closures
-> closures constrain one another
-> current compatibility / reachability topology
-> behavior / objectification
-> consequences
-> bridge revision / reprioritization
-> new topology
~~~

Thus:

> **the field is the current global pattern of mutually conditioned Gate use and Gate-formability.**

This is machine wording, not canonical.

---

## 13. Link to multilevel conscious control

A conscious target need not command all lower processes.

It can alter the field by:
- stabilizing one high-level closure;
- changing compatibility weights;
- suppressing competing closures;
- increasing persistence of a goal-related cluster;
- reopening a conflicting Gate when friction becomes foreground.

Then behavior changes because the whole compatibility topology has changed.

This makes:

~~~text
conscious target
-> field reconfiguration
-> distributed behavior
~~~

more precise than:

~~~text
conscious target
-> direct action command.
~~~

---

## 14. Link to Levin analogy

The architecture analogy is now cleaner.

Levin-style developmental bioelectric control:

~~~text
distributed local states
<-> network-level constraints
-> coordinated morphology
~~~

Current cognition candidate:

~~~text
distributed transparent closures
<-> whole compatibility topology
-> coordinated perception / action
~~~

No mechanism identity is implied.

---

## 15. Strong mature-neighbor pressure

This architecture is heavily pressured by:
- Skilled Intentionality / field of relevant affordances;
- metastable coordination dynamics;
- hierarchical active inference;
- task-set / cognitive-control architectures;
- affordance competition;
- constraint-closure / organizational autonomy.

Therefore the scientific increment cannot be:

~~~text
many distributed processes form one context-sensitive whole
~~~

That is mature-neighbor paid.

Potential SRT value remains in typed integration of:
- active Gate genesis;
- objectification / transparency;
- history-conditioned future selectability;
- gate-objectification / revision;
- L0/L1/L2 recursion;
- bearer-indexed consequence return where relevant.

Novelty remains OPEN.

---

## 16. Nontrivial composition test

Field language earns explanatory status only if joint composition predicts something not available from isolated closures.

Minimum tests:

### CT1 cross-closure prediction
Knowing the state of one closure cluster predicts changes in another.

### CT2 intervention propagation
Perturbing one high-level constraint changes multiple lower closures coherently.

### CT3 conflict geometry
Mutually incompatible closures produce structured competition rather than independent errors.

### CT4 nested compression
Higher-level closure reduces control complexity without encoding lower details.

### CT5 recursive learning
Whole-field state changes which new bridges are learned / retained.

If these fail:

~~~text
whole field
= decorative summary
~~~

rather than an explanatory level.

---

## 17. Current whole-field candidate

Strongest neutral machine formulation:

> **The whole cognitive field is the dynamically maintained compatibility, competition, nesting and transition structure among active and latent Gate closures, together with the conditions governing which new bridges can form and which existing closures can be revised.**

Shorter:

> **field = current organization of mutual Gate-possibility.**

Important:

~~~text
field
!= extra substance
!= literal electromagnetic field
!= complete latent state inventory
!= conscious workspace
!= one neural synchrony measure
~~~

Earlier:

~~~text

~~~

~~~text

~~~

Now:

~~~text

~~~

So the field is no longer only descriptive.
It has a candidate construction route.

## 19. Current next

The next question should not immediately be another external experiment.

First ask:

> **What is the smallest formal operator that can represent (a) active bridge formation, (b) closure, and (c) cross-closure compatibility without collapsing all three into generic 'constraint'?**

That is the first point where formalization may now be worth attempting.
