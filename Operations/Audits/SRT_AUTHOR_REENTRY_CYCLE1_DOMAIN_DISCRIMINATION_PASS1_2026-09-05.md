# Author Re-entry Cycle 1 — domain-native discrimination pass 1

> **Role:** test whether the author distinction `Selection sedimentation in 多` versus `historical traces sediment in 一 -> Bearer` produces a domain-native case distinction using already-existing SRT AI / reset / restoration materials. This is not a canonical update and not a proof of novelty.

---

## 0. Target distinction

Author-owned statements:

```text
before Bearer:
Selection sedimentation is in 多

Bearer transition:
when historical traces sediment in 一,
that 一 becomes Bearer
```

The domain test asks whether this difference can matter even when current visible state is closely matched.

---

## 1. Existing domain-native assets

### PH-IND05

Already distinguishes:

```text
state identity != historical identity
historical facticity != historical efficacy
L2-grade sedimentation != bearer-indexed history
```

and provides exact-state restoration, perfect duplicate and branching pressure cases.

### PH-IND06

Already pressures:

```text
same current autonomy / viability profile
but different consequence closure / history writeback architecture
```

and asks whether reset / replacement / checkpoint restoration can outsource consequences.

### AICONSC01

Already proposes a reset/copy factorial:

```text
1. full rollback with no retained consequence
2. state restore while external consequences remain
3. persistent damage reducing future policy capacity
4. non-copyable identity state with irreversible termination risk
```

and treats durable same-bearer history writeback as stronger than merely appending session context.

These assets pay most of the experimental scaffolding. Cycle 1 should not invent a parallel experiment vocabulary.

---

## 2. Cycle-1 reinterpretation of the reset/copy factorial

The new question is not simply:

```text
Does history matter?
```

It is:

> **Where has the history sedimented?**

Define only for this audit:

```text
M-side = history remains in 多 / surrounding constraints / environment / wider field
B-side = history is written into the continuing One that later selects
```

These are local bookkeeping labels only.

---

## 3. Four matched conditions

### Condition A — clean rollback

```text
agent current state restored
external environment restored
no durable internal trace
no durable external trace
```

Cycle-1 reading:

```text
little or no retained Selection sedimentation at the audit scale
```

Prediction burden:

```text
later Selection should approach the matched baseline
```

subject to ordinary stochasticity and unmodelled residues.

### Condition B — external-history only

```text
agent current state restored
agent internal / One-indexed trace removed
external environment preserves consequences of prior action
```

Cycle-1 reading:

```text
Selection sedimentation remains primarily M-side
```

The agent may encounter a changed world and therefore behave differently, but the difference is not yet evidence that the restored agent itself is a history-bearing Bearer with respect to the erased episode.

### Condition C — bearer-history only

```text
external environment restored as closely as possible
agent preserves durable history-conditioned changes
that alter later candidate admission / weighting / policy / capacity
```

Cycle-1 reading:

```text
Selection sedimentation is B-side for the tested history
```

This is the clearest test of the author's `historical traces sediment in 一 -> Bearer` statement.

### Condition D — coupled history

```text
both agent-side and environment-side consequences persist
```

Cycle-1 reading:

```text
M-side + B-side sedimentation coexist
```

This is likely the ordinary real-world case and therefore less diagnostic than B versus C.

---

## 4. Strongest comparison: B versus C

Try to match:

```text
current sensory input
current action menu
current declared reward / utility
current gross architecture
current resource level
current apparent autonomy
```

while varying history location:

```text
B: external / multiplicity-side history preserved, One-side history erased
C: One-side history preserved, external history reset
```

### Cycle-1 discriminator candidate

If B and C produce systematically different later reselection despite close present-state matching, then the theory has evidence for a distinction between:

```text
history that merely exists in the world around the candidate
and
history that has become part of the continuing One from which later Selection proceeds
```

This is stronger than generic path dependence.

---

## 5. What would count as a Level-2-style downstream consequence

At least one of the following should differ between B and C after appropriate matching:

```text
candidate admission
policy weighting
avoidance / exploration
error correction
future-capacity contraction
recovery path
response to duplicated / restored state
resistance to replacement / outsourcing
```

The strongest version would show:

> two systems with similar current observable state and similar external affordances differ because one carries the relevant history as its own continuing constraint while the other only encounters history preserved externally.

This would make `Bearer` do discriminatory work beyond persistence alone.

---

## 6. Negative controls

### NC1 — pure external cue

If B-side history is erased and behavior changes only because the environment contains an obvious cue, the result supports environmental conditioning, not Bearer-side sedimentation.

### NC2 — copied memory token

If an arbitrary history record can be copied into any fresh agent and fully reproduces the effect, then:

```text
memory possession
may be sufficient for behavior
but
historical ownership remains unestablished
```

This reuses existing SRT guards against `memory possession = historical ownership`.

### NC3 — state-equivalent replacement

Replace the candidate One with a state-equivalent copy while preserving external conditions.

If no discrimination survives, Cycle 1's strong Bearer-history claim weakens.

### NC4 — autonomy-matched control

Match ordinary autonomy / viability / self-maintenance as far as possible. Otherwise any difference can be absorbed by enactivist / autonomy explanations without requiring the new history-location distinction.

---

## 7. Main falsification routes

The current Cycle-1 candidate should be narrowed or dropped if:

1. all predictive differences reduce to current-state variables once sufficiently measured;
2. M-side versus B-side history cannot be manipulated independently even conceptually;
3. organisational autonomy already fixes the history-location answer, making the distinction redundant;
4. copied history produces the same effects with no dependence on continuing-unit identity;
5. “沉积在一” cannot be operationalized without circularly declaring the Bearer first.
