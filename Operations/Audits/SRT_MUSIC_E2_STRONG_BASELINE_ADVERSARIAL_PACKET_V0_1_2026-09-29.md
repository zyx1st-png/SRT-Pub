# Music E2 strong-baseline adversarial packet v0.1

> **Role:** paper-only red-team packet under the existing cognition CURRENT NEXT.
>
> **Goal:** try to eliminate the apparent music residual **before** any experiment, preregistration or SRT-specific interpretation.
>
> **Non-goal:** prove SRT, establish a new invariant, reopen HP-B, admit Bearer, or expand into language / action / Aha synthesis.

## 0. Prior target — inherited from the 2026-09-26 cognition programme

The target is **not** discovered from music.

The pre-existing cognition programme already asks:

> Can one inferred whole-system geometry / orientation transformation explain coordinated changes across multiple local objectification / grouping / transition probes better than strong local-update and latent-state models?

Music is only a bounded test surface for that prior E2 burden.

Local operational shorthand:

~~~text
E2-M target
= one context-level continuation / orientation organization
  that predicts multiple held-out music probes jointly.

candidate probes
= tension trajectory
+ completion / unfinishedness
+ boundary / grouping
+ next-event expectation
+ later reinterpretation where applicable.
~~~

This is a neutral model burden, not an SRT ontology claim.

## 1. Adversarial rule

The default outcome is **absorption**, not residual.

For each case:

1. identify the strongest source-native comparator family;
2. grant it the explanatory job it already owns;
3. ask whether the case still discriminates anything after that grant;
4. reject any residual produced only by weaker baselines, vague labels or extra model flexibility;
5. require a residual to affect **multiple probes or transfer conditions**, not one rating scale alone.

Allowed dispositions:

~~~text
ABSORBED
= strong comparator already owns the scoped job;

UNDERDETERMINED
= current paper design cannot separate candidate organizations;

E2-DESIGN-CANDIDATE
= a design remains worth specifying because it may separate
  strong baselines, but no residual is yet established;

E4-PRECURSOR
= the useful discriminator concerns later recutting / reinterpretation,
  not E2 predictive geometry;

PHEN-CONTROL
= useful for structural-registration vs phenomenal vs explicit dissociation,
  but not an E2 geometry discriminator.
~~~

No disposition in this packet authorizes an experiment.

### SB-1 Tonal tension / attraction / closure

Primary families:
- Lerdahl / Krumhansl tonal tension and attraction;
- Bharucha melodic anchoring;
- Larson musical forces;
- Narmour implication-realization / closure;
- Huron ITPRA;
- Farbood temporal tension model;
- TenseMusic;
- cadence-specific closure / expectancy models.

### SB-2 Statistical / Bayesian expectation

Primary families:
- IDyOM;
- Temperley-style Bayesian tonal / key models;
- n-gram / transition models;
- strong latent-state / structure-learning sequence models.

### SB-3 Event / boundary models

Primary family:
- Event Segmentation Theory / event-model updating;
- music phrase-boundary prediction / tracking models.

### SB-4 Relational identity controls

Primary family:
- relative pitch / interval / contour accounts.

### SB-5 Implicit-registration controls

Primary family:
- MMN / ERAN / preattentive regularity detection.

## 3. What would count as an E2 residual?

A case does **not** count merely because:

- listeners report tension;
- the same chord feels different in context;
- a deceptive cadence surprises;
- a phrase boundary is detected;
- transposed melodies preserve identity;
- an implicit neural mismatch differs from explicit report.

These are already mature-neighbor territory.

A paper-level E2 residual is worth preserving only if the proposed manipulation plausibly requires:

~~~text
one context-level organization
to predict a coordinated pattern across >= 2 distinct probes
or across a held-out transfer condition,
after strong source-native baselines are paid.
~~~

Stronger future empirical burden, if ever authorized:

~~~text
shared frozen organization
must improve held-out joint prediction / transfer
without relying only on greater parameter count
or post-hoc relabeling.
~~~

## 4. ADV-1 — same target chord / different harmonic background

### Manipulation

Keep the local target chord or target tone physically identical.

Change only the preceding organization:
- tonal centre;
- harmonic path;
- phrase position;
- metric placement where controllable.

### Why it initially looks attractive

~~~text
same local object
+ different background
-> different tension / stability / completion.
~~~

This appears to support background-relative rather than object-only organization.

### Strongest comparator attack

SB-1 and SB-2 already predict context-sensitive tonal function.

Expected comparator jobs:
- tonal hierarchy / attraction;
- key inference;
- local harmonic expectancy;
- learned transition probability;
- phrase-position effects.

### Kill criterion

~~~text
if strong tonal + Bayesian / statistical models
predict the full cross-condition pattern,
ADV-1 = ABSORBED.
~~~

### What would remain interesting

Not "the target differs by context."

Only a residual such as:

> one inferred context organization predicts **tension + completion + boundary / next-event expectation together**, while strong specialized baselines leave systematic cross-probe error.

### Current paper verdict

~~~text
default = ABSORBED / STRONG NEGATIVE CONTROL
E2 residual = NOT YET SHOWN
~~~

## 5. ADV-2 — same terminal object / different path

### Manipulation

Construct sequences that end on the same terminal note / chord but arrive through different trajectories:

~~~text
Path A:
stable -> terminal

Path B:
tension -> suspension / delay -> terminal
~~~

Keep the terminal object identical.

### Strongest comparator attack

SB-1:
- temporal tension models;
- musical-force / implication-realization accounts;
- ITPRA;
- tonal-tension surface / attraction accounts.

TenseMusic / Farbood-type path-sensitive features are especially important because endpoint identity alone is not their explanatory unit.

### Kill criterion

If path-dependent phenomenal trajectory is already predicted by these models:

~~~text
same terminal object != same episode
= source-owned result
-> ADV-2 ABSORBED.
~~~

### Potential E2 residual

Only if one frozen context organization predicts:
- continuous tension trajectory;
- completion point;
- expected continuation;
- later grouping / memory boundary;

and the improvement is not reducible to adding those outputs separately.

### Current paper verdict

~~~text
UNDERDETERMINED
high risk of full source absorption
~~~

## 6. ADV-3 — predictability x unfinishedness 2x2

### Target matrix

~~~text
A high predictability + high completion
B high predictability + high unfinishedness
C low predictability  + high completion
D low predictability  + high unfinishedness
~~~

This is the packet's **highest-value E2 discriminator**.

### Strongest comparator attack

Condition B is **not** automatically a residual.

Strong attacks:
- tonal attraction may make the continuation highly directional while unresolved;
- implication-realization may distinguish implication from closure;
- ITPRA explicitly separates tension and prediction responses;
- cadence models may predict both certainty and incompletion;
- IDyOM / Temperley may separate statistical probability from tonal function.

### Paper requirement before stimuli are built

A valid B condition must be constructible where:

~~~text
next-event predictability is high
AND
strong tonal-tension / attraction / closure baselines still predict
a specific unfinishedness profile.
~~~

Then the question becomes whether anything remains **after** those predictions are paid.

### Kill criterion

If unfinishedness is fully predicted by the strongest closure / attraction families:

~~~text
prospective-dependence residual
= NO LOCAL COMPARATIVE INCREMENT.
~~~

### Design condition for a future E2 residual

A future residual would become interesting only if:

- completion / unfinishedness can be orthogonalized from the strongest tonal / statistical predictions;
- the same residual also predicts a second probe such as phrase boundary, continuation choice or later recutting.

### Current paper verdict

~~~text
E2-DESIGN-CANDIDATE
design worth further paper specification only;
paper residual = NOT ESTABLISHED.
~~~

## 7. ADV-4 — resolution vs interruption with matched stopping

### Manipulation

Create pairs where the external stream stops at closely matched physical endpoints but differs in organization:

~~~text
resolution:
open relation discharged before silence;

interruption:
stream stops while a strong continuation remains open.
~~~

### Strongest comparator attack

SB-1 + SB-3:
- cadence / closure models;
- event segmentation;
- phrase-boundary prediction;
- expectation / tension dynamics.

### Kill criterion

If completion ratings, boundary judgments and memory grouping are jointly explained by cadence closure + event segmentation:

~~~text
ADV-4 = ABSORBED.
~~~

### Potential residual

Only if a shared inferred organization predicts a cross-probe pattern that the best closure + segmentation combination misses.

### Current paper verdict

~~~text
UNDERDETERMINED
good future stimulus family
but no residual entitlement.
~~~

## 8. ADV-5 — deceptive continuation and reinterpretation

### Manipulation

Use a strong pre-cadential expectation followed by:
- expected resolution;
- deceptive continuation;
- deceptive continuation followed by recovery / reinterpretation.

### Primary question

Does the useful signal live in:

~~~text
E2:
pre-event predictive organization;

or

E4:
later event changes what the earlier sequence counts as?
~~~

### Strongest comparator attack

- Huron ITPRA / expectation response;
- implication-realization;
- tonal tension;
- event-model update;
- Bayesian / statistical surprise.

### Kill criterion

If the only effect is surprise / prediction error followed by ordinary state update:

~~~text
not an E4 recutting discriminator.
~~~

### Potential value

If later input changes:
- prior grouping;
- perceived phrase boundary;
- interpretation of an earlier tone / chord;
- future continuation rules;

then classify as **E4-PRECURSOR**, not E2 success.

### Current paper verdict

~~~text
E4-PRECURSOR
remove from E2 positive-count logic.
~~~

## 9. ADV-6 — familiarity: schematic vs veridical expectation

### Manipulation

Compare the same structural passage under:
- unfamiliar exposure;
- repeated familiarization;
- highly familiar exact sequence where feasible.

### Strongest comparator attack

Huron already separates schematic and veridical expectations.

IDyOM / learning models also make familiarity-sensitive predictions.

PH-QUAL PC-8 creates an internal pressure question, but this packet does not adjudicate it.

### Kill criterion

If familiarity effects on prediction and tension are fully paid by schematic + veridical expectation models:

~~~text
ADV-6 = ABSORBED.
~~~

### Residual worth retaining

Only if automatization / exact predictability dissociates systematically from a stable phenomenal completion/tension organization **after** those models are paid, and this predicts another probe.

### Current paper verdict

~~~text
PHEN-CONTROL / PH-QUAL PRESSURE
not primary E2 discriminator.
~~~

## 10. ADV-7 — transposition / preserved contour

### Manipulation

Change absolute pitches while preserving relational contour / interval structure where appropriate.

### Strongest comparator attack

SB-4 relative-pitch / contour accounts directly own much of this phenomenon.

### Kill criterion

Immediate:

~~~text
preserved melodic identity under transposition
= EXPECTED SOURCE ABSORPTION.
~~~

### Why retain it

As a **sanity control**:

> if the music route starts treating this result alone as evidence for E2 generative geometry, the route is overclaiming.

### Current paper verdict

~~~text
ABSORBED / NEGATIVE CONTROL
~~~

## 11. ADV-8 — implicit registration vs phenomenal foreground vs explicit objectification

### Manipulation family

Seek three separable conditions:

~~~text
A implicit regularity / violation response
  + no reliable phenomenal report;

B reliable phenomenal tension / change report
  + weak explicit music-theory objectification;

C explicit structural judgment / objectification.
~~~

### Strongest comparator attack

SB-5 MMN / ERAN and attention literature already establish that regularity detection need not imply awareness.

Explicit report literature can also explain later judgment.

### Kill criterion

Do not count:
- MMN as phenomenal evidence;
- explicit report as occurrence-time evidence;
- stage separation by itself as E2 geometry evidence.

### Value

This case protects the route's typing:

~~~text
structural registration
!= foreground_phen
!= foreground_obj.
~~~

### Current paper verdict

~~~text
PHEN-CONTROL
important guard;
not E2 positive evidence.
~~~

## 13. What survives this paper-only red team?

At v0.1, **no empirical SRT residual is established**.

The only candidate worth hardening further before any experiment is:

~~~text
ADV-3:
can predictability and unfinishedness be cleanly orthogonalized
after strongest tonal-attraction / closure / statistical baselines,
with the residual also predicting at least one independent probe?
~~~

Secondary candidates:

~~~text
ADV-2 / ADV-4
= stimulus-construction support;

ADV-5
= E4 precursor only;

ADV-1 / ADV-7
= source-absorption controls;

ADV-6 / ADV-8
= phenomenology / typing controls.
~~~

## 14. Gate to a future E2 prereg candidate

Do **not** draft a preregistration merely because this packet exists.

A future E2 prereg candidate requires all of:

1. one primary case selected in advance;
2. strongest comparator set frozen before stimuli are tuned;
3. operational definitions for predictability, unfinishedness and completion that do not circularly use the outcome ratings they are meant to predict;
4. at least two independent dependent-variable families;
5. explicit complexity control / held-out evaluation plan;
6. a source-owned prediction table for every named strong comparator;
7. a failure rule that permits full source absorption;
8. no HP-B / Bearer / primitive Selection interpretation in the primary endpoint;
9. independent FR-ADV before experiment authorization, per the cognition programme.

Until those are satisfied:

~~~text
experiment = NO
preregistration = NO
E3 = NO
E4 execution = NO
SRT-specific increment claim = NO
~~~
