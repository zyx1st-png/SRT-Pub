# Gate bridge -> property -> object formation — scientific / formal crosswalk

> Boundary: machine analysis only. The author intuition is preserved separately. This audit tests whether the intuition can be made precise without collapsing into ordinary invariant representation / categorization.

## 0. Executive result

The author intuition is scientifically plausible as an integration architecture, but its components are strongly neighbor-paid.

Current strongest neutral translation:

~~~text
state variation
-> learned / maintained transformation relations
-> invariants / stable equivalence structure
-> reusable property-like compression
-> coherent object representation / objectification
~~~

This is close to mature work on:
- invariant object representation;
- categorization as equivalence clustering;
- relational category learning;
- structural alignment / relational invariants;
- object identity across transformations.

Therefore novelty cannot rest on 'stable relation produces property/object' alone.

---

## 1. Recent categorization pressure

Barrett & Miller (2026), Nature Reviews Neuroscience, argue that categorization is not merely a late stage after perception; equivalence clustering occurs throughout signal processing.

Pressure on the current intuition:

~~~text
grouping different states / inputs into adaptive equivalence clusters
= mature-neighbor paid
~~~

This strongly supports the plausibility of the author's emphasis on stable sameness before explicit object labels, but does not establish SRT-specific Gate.

---

## 2. Invariant object representation pressure

Halvagal & Zenke (2023), Nature Neuroscience, show a computational route by which sensory systems can learn object representations invariant across changes such as size, orientation and context.

Pressure:

~~~text
different sensory states
-> invariant object representation
= mature-neighbor paid
~~~

Useful distinction:

An invariant representation may describe the result.
The current author intuition asks whether a stabilizing gate / relation-building process is a general upstream architecture for producing those invariants.

That upstream claim remains open.

---

## 3. Relational category pressure

Relational-category research shows that categories can be defined by relations rather than intrinsic surface features, and that discovering higher-order invariant relations supports transfer to novel exemplars.

Representative anchors:
- Goldwater et al. 2018, DOI 10.1037/xge0000387;
- Corral & Jones 2014, DOI 10.1016/j.cognition.2014.04.007;
- Jung & Hummel 2015, DOI 10.1111/cogs.12199.

This supports:

~~~text
property / category structure
need not be intrinsic to a pre-given object;
relations can become the stable reusable structure.
~~~

But mature relational learning does not imply:
- all intrinsic properties reduce to relations;
- all objecthood is cognitive construction;
- Gate is the unique mechanism.

---

## 4. Formal family A — invariant under transformation

Let states be s in S and admissible transformations be t in T.

A property candidate can be represented as an invariant:

~~~text
phi(s) = phi(t(s))
for a declared family of transformations t
~~~

Examples:
- same object under rotation;
- same functional role under position change;
- same affordance under several sensory realizations.

This gives a precise version of the author's '统一标签':

> the label is not primary; it names a relation that remains invariant across changes.

Important:

Not every property is expected to be perfectly invariant. Approximate / probabilistic invariance is more realistic.

---

## 5. Formal family B — equivalence / quotient

If a relation R is sufficiently stable, states can be grouped:

~~~text
s_i ~ s_j
when their differences can be ignored for the current continuation problem.
~~~

Then a property or proto-object may correspond to an equivalence class / quotient at a declared grain.

However, do not assume exact mathematical equivalence.

Real cognitive relations may be:
- asymmetric;
- context-dependent;
- graded;
- non-transitive;
- history-sensitive.

Therefore a graph / manifold / category-like representation may be safer than a strict equivalence relation.

---

## 6. Formal family C — object as a stable transformation orbit / relational closure

A strong candidate formalization is:

~~~text
many state manifestations
+ recurrent transformations between them
+ stable invariants
+ recoverability / predictive continuity
-> one object candidate
~~~

Machine working metaphor:

> **Object = a local knot / closure in a transformation network.**

The object is not any one instantaneous state.

It is the relatively stable organization that allows many changing states to be treated as manifestations of one continuing thing.

This fits the author's intuition better than:

~~~text
object first
-> properties attached later.
~~~

---

## 7. Revised Gate roles

The current programme should distinguish at least three analytic gate roles.

### G1 — pass / suppress

Which live transition is permitted or weighted?

### G2 — bind / stabilize

Which different states are linked into a repeatable transformation relation?

### G3 — coarse-grain / objectify

Which stable relations are compressed into reusable invariants, boundaries and object structure?

These are analytic roles, not three anatomical modules.

Possible recursive relation:

~~~text
G1 repeated selection / transition
-> G2 stable relation formation
-> G3 reusable coarse-grained object/property structure

and later:

G3 object/property structure
-> biases future G1 transitions.
~~~

This is structurally compatible with L1/L2 writeback without making them temporal containers.

---

## 8. Major connection to content -> control

The current action programme asks:

> How does a conscious target move from accessible content to control-effective structuring bias?

The present intuition offers a concrete answer candidate:

~~~text
mature object / target
= compressed access point into a pre-existing network
  of stabilized perceptual, causal, affordance and action relations

foreground the object / target
-> reactivate / weight that relational network
-> many lower gates change together
-> distributed execution becomes possible
~~~

Thus the word / image 'cup' need not contain the motor programme.

It may function as an address into a learned relational control structure.

This is a stronger mechanistic candidate than 'the target sends an abstract command'.

Still, it is strongly compatible with schema, predictive-processing, affordance and hierarchical-control accounts.

---

## 9. Property formation may precede object closure

The author's ordering:

~~~text
stable bridge
-> property
-> object
~~~

should be preserved as a genetic / generative possibility, not a universal chronological rule.

Candidate interpretation:

> local invariants can become reusable before the system has a stable closed object boundary.

Examples in principle:
- 'moves together';
- 'supports weight';
- 'graspable';
- 'same contour under transformation';

may become stable regularities before a rich object concept is formed.

This is testable in development, perceptual learning and novel-object learning.

---

## 10. What remains specifically open

The strongest unresolved burden is not whether invariance / relational categories exist.

It is:

> **Does one common gate-stabilization principle link transition control, property formation, objectification and later action control, or are we merely using the same word 'gate' for several distinct mature mechanisms?**

This is the central anti-unification test.

Failure condition:

~~~text
if pass/suppress gating, invariant learning, relational categorization
and object identity require unrelated mechanisms with no shared operator-level structure,
then 'Gate' is only an umbrella metaphor.
~~~

Success condition:

~~~text
if the same abstract operation can be defined as
'stabilize distinctions / transformations so some differences
remain load-bearing and others become safely compressible',
and this operation supports multiple domains without triviality,
then Gate may earn a deeper architecture role.
~~~

Before further experiment design:

2. define the weakest nontrivial Gate kernel that can cover pass, bind and coarse-grain without becoming 'any constraint';
3. test the cup/content-to-control example under that kernel;
4. only then decide whether Gate should remain one concept or split into typed families.
