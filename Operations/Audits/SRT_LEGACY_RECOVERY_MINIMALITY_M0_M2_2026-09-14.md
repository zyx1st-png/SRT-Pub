---

## 1. M0 — five static relation types only

### Strength

Very minimal. Avoids identity inflation and keeps the tool easy to route.

### Failure

M0 can say:

```text
X shapes O;
Y has Standing.
```

but does not itself ask when repeated X-O coupling changes the **standing topology**.

It therefore under-types cases where:

```text
external support becomes constitutive;
a constitutive component remains non-independent;
a higher-order One forms;
a higher-order One dissolves while lower-scale units persist.
```

These are not merely changes in performance or Shaping strength.

Verdict:

```text
M0 = too static for multiscale formation.
```

---

## 2. M1 — add Standing <-> Shaping transition grammar

M1 adds no new relation type.

It only adds a mandatory question when cross-scale / scaffold-boundary dynamics are relevant:

```text
Does this structure remain external Shaping,
or has recurrent coupling become constitutive to a declared vertical-reconstitution path?
```

and the reverse:

```text
Has a formerly higher-order reconstitution dependence dissolved
while a lower-scale reconstitution path remains viable / becomes relatively separable?
```

### Classification gain

M1 cleanly separates:

```text
supportive scaffold;
substitutive scaffold;
constitutive non-independent component;
higher-order Standing;
de-nesting / decomposition.
```

### Identity guard

M1 does not need to close:

```text
same-One expansion;
strict numerical identity;
branch / merge identity;
exact boundary.
```

It only claims participation in Standing formation or loss / reorganization of a declared higher-order path.

### Fit with author-approved five-relation tool

Strong.

The author already approved a typed recursive network rather than five linear stages. M1 makes one missing recursion explicit without adding ontology.

Verdict:

```text
M1 = RECOMMENDED machine minimum.
```

## 3. M2 — put effective objecthood inside the minimum tool

T-SO has real explanatory value:

```text
One / Standing
-> stable scale-relative interface
-> operational black-boxability
-> low-cost re-identification
-> effective objecthood.
```

It helps explain why object-based sciences can work downstream of an anti-object-first ontology.

However, making T-SO part of the **minimum universal research tool** creates three problems.

### Problem 1 — not every domain needs objectification

A formed process can be studied as a process / relation without becoming a stable object token for the target model.

### Problem 2 — model-side objectification can occur without One

A scientist may bundle variables into a useful object token without establishing independent ontic Standing.

### Problem 3 — P07 already owns the physical bridge family

The missing work is a post-#970 crosswalk, not a universal new research relation.

Therefore objecthood should remain:

```text
important downstream interface bridge,
not part of the minimum five-relation grammar itself.
```

Verdict:

```text
M2 = over-engineered as minimum tool.
T-SO = retain as separate high-priority crosswalk.
```
