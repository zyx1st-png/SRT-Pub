# 1. Q16 — Structural subject-position can likely be compressed to Stable ISP + persistent endogenous stake coupling

## 1.1 What Stable ISP already pays

The current Stable ISP standing already includes:

```text
formed continuity of the same selection center
+ iterative exposure to currently effective non-equivalent candidates
+ structural perspective
+ integrated history/writeback
+ continued selectability
```

So several candidate extra subject gates are already paid:

```text
active temporal continuity;
position-relative differentiation;
current responsiveness to alternatives;
historical integration;
ability to continue under later Selection.
```

The remaining distinctive subject burden is not generic activity or continuity.
It is whether some consequences / conditions become **the unit's own non-outsourcable stake**.

## 1.2 Persistent endogenous stake coupling

A one-shot cost should not be enough.

Current stronger definition candidate:

```text
persistent endogenous stake coupling
=
a recurrent relation in which some conditions / consequences
are differentially incorporated into the same Stable ISP's
continuity, payability and later selectability,
and cannot be fully externalized without changing the unit's own future standing.
```

This already contains the two faces identified in Pass 4:

```text
承担 face:
consequence cannot be fully outsourced;

关切 face:
conditions acquire differential endogenous relevance.
```

And because Stable ISP already supplies a structural perspective over non-equivalent candidates, the stake relation induces a local directional ordering over continuations.

## 1.3 Current sufficiency preference

For **structural subject-position**, current machine preference is:

```text
Stable ISP
+ persistent endogenous stake coupling
=> subject-position candidate
```

No additional independent `direction` primitive is currently required.
No additional sigma threshold is currently required.
No reflective self-model is required.
No phenomenality theorem is implied.

This is a structural subjecthood criterion only.

Therefore:

```text
subject-position
!= experiencer / phenomenality
!= self-consciousness
```

## 1.4 Remaining caution

This sufficiency claim is not yet author-adjudicated.

A future pressure test should ask whether a sufficiently sophisticated artificial / distributed controller could satisfy:

```text
Stable ISP + persistent endogenous stake coupling
```

while still intuitively failing subject-position.

If yes, another gate is missing.
If no, the compressed criterion gains strength.

Current verdict:

```text
Q16: PROVISIONAL YES for structural subject-position.
```

# 2. Q17 — One organization and internal scaffold differ by constitutive role, not by location

## 2.1 The problem

If a One is historically constituted and also contains sedimented internal history, then both appear "inside" the same continuing organization.

So spatial/internal location cannot distinguish:

```text
identity-constituting organization
vs
internal sedimented scaffold.
```

## 2.2 Counterfactual constitutivity test

Current preferred distinction:

### Identity-constituting organization

A relation/component is identity-constituting at a declared scale and interval when perturbing or removing it changes whether later organization still counts as the **same lineage-relative continuing unit**.

Compactly:

```text
remove / disrupt X
-> same-unit reconstitution fails or lineage attribution changes
```

### Internal sedimented scaffold

A relation/component is scaffold-like when it:

```text
biases
constrains
lowers/raises re-entry cost
changes reachability / weighting
backgrounds some pathways
```

while the same continuing unit can still be identified across a declared perturbation range.

Compactly:

```text
remove / alter S
-> transition landscape changes
but same-unit standing can remain
```

## 2.3 Not an absolute partition

The same historical structure may shift role across scale or perturbation magnitude.

A scaffold can become constitutive if enough of the continuing identity depends on it.
A formerly constitutive component can become replaceable if the organization develops redundant reconstitution routes.

Therefore the distinction is:

```text
functional / counterfactual
not material / spatial
```

## 2.4 Consequence for One / L2 relation

This allows a clean nested relation:

```text
One-function
= organization whose constitutive relations support same-lineage reconstitution;

internal historical scaffold
= sedimented constraints carried by or within that One
  that shape later Selection without automatically defining its identity.
```

So:

```text
internal scaffold != One
but may participate in One maintenance;

One history != all internal scaffold;

L2-like sedimentation need not be external or collective.
```

Current verdict:

```text
Q17: boundary = counterfactual constitutivity for same-lineage reconstitution.
```

# 3. Q18 — Time, objectivity and social convergence survive L2 retyping better when separated

The strongest reason not to preserve L2 as a bundled top-level domain is that the major claims routed through it can be reconstructed independently.

## 3.1 Time

Current deep intuition can be retained without L2 ontology:

```text
time
= measure / ordering of irreversible historical depth
  produced by non-reversible Selection events and their traces.
```

This needs:

```text
irreversibility
+ ordered historical accumulation
```

but does not need:

```text
one universal L2 domain.
```

So current phraseology such as:

```text
"time is an information pheromone in the stable L2 domain"
```

is likely **REWRITE / metaphor-demotion** material.

The stronger surviving claim is simply:

```text
irreversible Selection generates historical depth;
time measures / orders that depth.
```

## 3.2 Objectivity

Current L0 wording already defines objectivity through robustness across positions/interfaces/perturbations rather than by a pre-given L2 realm.

This can survive as:

```text
objectivity candidate
= a manifest / reconstructed structure that remains robust
  across sufficiently independent positions, interfaces and perturbations,
  and is not explained merely by one shared masking constraint.
```

Shared sedimented scaffold can help produce objectivity-like convergence,
but:

```text
shared scaffold != objectivity by definition.
```

Thus objectivity no longer needs to be defined as "entry into L2".

## 3.3 Social convergence

Social convergence becomes a scale-specific sedimentation process:

```text
many positioned selections
+ interaction / coordination
+ repeated writeback
+ shared re-entry / inheritance
-> shared sedimented scaffold
```

Examples:

```text
language conventions
institutions
legal norms
scientific standards
technical protocols
```

These are not one new ontology domain.
They are higher-scale realizations of historical scaffold formation.

## 3.4 Institution

An institution is currently better typed as:

```text
shared / externalized sedimented constraint scaffold
with durable re-entry, role inheritance and enforcement pathways
```

rather than:

```text
institution = L2 object
```

This preserves most useful social-theory content while reducing ontology burden.

## 3.5 Q18 verdict

```text
time -> historical-depth relation
objectivity -> cross-position robustness relation
social convergence -> multi-agent sedimentation process
institution -> durable shared scaffold realization
```

All four can survive a major L2 retype.

Therefore the existing package:

```text
L2 = time + objectivity + convergence + institution + memory + scaffold
```

is not theoretically necessary.

# 4. Q19 — The three-level symmetry is likely historically useful but ontologically misleading

## 4.1 Why the symmetry is suspicious

Current labels visually suggest:

```text
L0
L1
L2
```

are three comparable ontological levels or domains.

But current reconstruction types them differently.

```text
L0
= modal / pre-object structural condition;

L1
= determinate manifest actuality / event result;

L2 (strongest surviving role)
= cross-temporal sedimented historical scaffold / constraint structure.
```

The third is not obviously the same kind of entity as the first two.

## 4.2 Two orthogonal axes

Current strongest architecture is therefore not a three-rung ladder but two coupled axes.

### Axis A — modal / actualisation axis

```text
potential / selectability field
        ↓ Selection
manifest determination / actuality
```

Historical labels:

```text
L0 -> L1
```

### Axis B — historical / sedimentation axis

```text
manifest event
-> trace / writeback
-> repeated reinforcement / re-entry
-> sedimented scaffold / background constraint
```

This axis acts across repeated actualisation cycles.

## 4.3 Where One appears

A formed continuing organization does not sit "after L2".

It emerges when historical writeback is localized such that later Selection repeatedly reconstitutes the same lineage-relative organization.

So One-function is produced by coupling the two axes:

```text
repeated Selection / manifestation
x
localized historical writeback
-> formed-continuity / One-function
```

## 4.4 Where Stable ISP and subject appear

Then stronger standing gates operate on that formed continuity:

```text
formed-continuity / One-function
+ structural perspective
+ integrated history
+ continued selectability
-> Stable ISP

Stable ISP
+ persistent endogenous stake coupling
-> subject-position candidate
```

Again, neither requires a universal third ontological domain.

## 4.5 Where collective structure appears

At higher scale:

```text
multiple formed organizations
+ coordination
+ shared writeback / sedimentation
-> shared scaffold

if relation-level history reconstitutes the same relation-level organization
-> higher-order formed-continuity candidate
```

So collective formation also follows the same two-axis grammar.

## 4.6 Current naming preference

Current machine preference:

```text
DO NOT preserve L0/L1/L2 symmetry merely for historical elegance.
```

Possible later mappings:

```text
L0 — likely retained because it names the modal / pre-object floor;
L1 — may remain as manifest-slice shorthand, though the symbol need not carry a peer-domain ontology;
L2 — strongest candidate for RETYPE / DEMOTE from peer domain to historical scaffold label.
```

The audit does **not** yet recommend deleting L2 notation.

But it now rejects this as the default deep architecture:

```text
L0 -> L1 -> L2
```

Current preferred deep architecture:

```text
                MODAL / ACTUALISATION AXIS
potential ---------------------------------> manifest
                         Selection

                            |
                            | trace / writeback
                            v

                HISTORICAL / SEDIMENTATION AXIS
manifest event -> history -> re-entry -> scaffold
                            |
                            +-> localized recursive reconstitution -> One-function
```

This is a major architecture rebase candidate.
