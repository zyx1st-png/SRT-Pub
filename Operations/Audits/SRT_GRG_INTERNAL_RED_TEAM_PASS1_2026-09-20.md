# GRG internal red-team — Pass 1

> Role: adversarial pressure test of the noncanonical GRG programme.
>
> This audit does not change the author's source record and does not authorize canonical edits. Where it proposes a meaning refinement, that refinement remains machine analysis pending author second adjudication.

## 0. Executive verdict

The GRG programme survives the first internal pressure pass, but four relations require tightening.

Pass-1 disposition:

- Selection as “non-flat generative change”: RETAIN + NARROW.
- generative causal continuity: RETAIN + SPLIT dependency depth from physical micro-scale.
- objects / laws as objectified slices: RETAIN + ADD world-resistance / invariance gate.
- generative expectation → normativity: RETAIN DIRECTION + REDEFINE “expectation” to block prediction-to-ought collapse.
- “more order / persistence / options = better”: WITHDRAW as any generic implication.
- canonical landing: HOLD.
- next work: author review of the normativity refinement, then distributed-neighbor extraction.

## 1. RT-1 — anti-tautology

### Threat

If Selection is defined as any non-flat change, the theory may become extensionally universal by stipulation:

something changed → effects were unequal → therefore Selection occurred.

That would make Selection a relabeling of change rather than a discriminating research concept.

### Minimum nontrivial burden

For the GRG programme, an event should not count as a useful domain-level realization of Selection merely because one state differs from another.

A nontrivial mapping should show at least:

1. relational efficacy becomes non-equivalent in a specified domain-native sense;
2. the operative change is coupled to a change in background / support / exclusion / accessibility / constraint;
3. removing or altering that coupling changes target formation or later generative conditions;
4. the result cannot be fully stated as a fixed-unit state transition with no change to relevant generative organization.

This does not redefine primitive canonical Selection. It is a programme-level admission test for domain mapping.

### Strong counterexample class

A passive variable whose numerical value changes under a fixed externally supplied update rule, while unit identity, candidate structure, boundary, accessibility and later transition organization remain fixed, may be change without paying the stronger GRG burden.

### Disposition

Selection = non-flat generative change: RETAIN + NARROW.

Recommended programme wording:

“non-flat” must mean more than unequal outcome. It requires differential operative efficacy that is constitutive of, or materially changes, later generative organization.

## 2. RT-2 — anti-reduction

### Threat

“Go deeper into vertical generation” can silently become:

micro-level = real;
macro-level = approximate;
therefore complete explanation reduces downward.

That would reproduce the object-first reductionism the programme is trying to reopen.

### Required distinction

Generative depth != spatial smallness != physical micro-scale.

Generative depth tracks dependency questions such as:

what makes this unit / boundary / causal capacity / scale operative?

A higher-order organization may be downstream in formation yet upstream as a condition for later participant-level generation.

Therefore the admissible cycle is:

distributed relations → formed higher-order organization → higher-order organization materially changes later participant conditions.

### Non-mystical higher-order efficacy test

A higher-order organization earns real generative status only if:

- it is independently identified rather than named from the effect;
- perturbing / removing its organization changes later lower-level or participant-level transition structure;
- the effect cannot be reduced to an unchanged list of independent component rules without encoding the higher-order organization somewhere in the causal state;
- no new substance or extra force is required.

### Disposition

Generative causal continuity: RETAIN.

“Vertical” = dependency depth: RETAIN.

“Lower level is more real”: WITHDRAW.

Cross-scale recursion should be treated as formation plus later constraint re-entry, not one-way upward emergence.

## 3. RT-3 — anti-relativism / anti-anti-realism

### Threat

If every object, variable and law is a coarse-grained / normalized / categorized slice, the programme can appear to imply:

all facts depend on our slicing;
there is no reality independent of representation;
any failed model can be rescued by choosing another position or scale.

That would make GRG anti-realist and difficult to falsify.

### Required three-way distinction

Objectification dependence:
our usable scientific objects require declared or backgrounded unit / boundary / grain / equivalence decisions.

World resistance:
those decisions are not free to produce arbitrary success; perturbation, mismatch, independent measurement and failed intervention can defeat them.

Cross-position objectivity:
a structure earns stronger objective standing when it survives controlled changes of position, interface, representation and perturbation without being explained by shared occlusion.

### Reopening criterion

An objectification should be reopened when sustained mismatch cannot be absorbed without ad hoc patching, or when changing position / interface / scale systematically changes the supposed invariant in ways the model cannot explain.

### Failure guard

“another scale / another position” may not be used as an automatic rescue.

A GRG mapping must state in advance which changes of scale / position preserve the claimed relation and which defeat it.

### Disposition

Objects / laws as finite objectifications: RETAIN.

Objects / laws as arbitrary constructions: REJECT.

Cross-position / cross-interface robustness + world-resistance gate: REQUIRED.

## 4. RT-4 — anti-teleology and normativity

### Threat A — prediction-to-ought collapse

The author says:

“generative relational grammar提供的生成的预期便是normativity。”

If “预期” means ordinary empirical prediction, then:

GRG predicts X will happen → X ought to happen

is invalid.

A domination structure, tumor, addiction loop or brittle institution can be highly predictable.

Therefore statistical / descriptive expectation cannot by itself be normativity.

### Threat B — persistence-to-good collapse

If generative expectation means “what keeps this structure going”, then normativity collapses into self-maintenance:

what persists better = better.

This was already rejected in the 2026-09-14 author adjudication.

### Proposed refinement — machine analysis pending author adjudication

The strongest interpretation of the author's statement is not statistical expectation but **immanent generative expectation**.

Provisional distinction:

1. descriptive expectation:
   what is likely to happen under current dynamics.

2. structural generative expectation:
   what continuation / transformation is implied by the constitutive generative relation if that relation is to remain the same typed relation.

3. indexed normative expectation:
   once a formed position / relation is admitted as a generative participant, actual trajectories can be compared by whether they preserve, enlarge, weaken, substitute, hollow out or contradict the participant's constitutive generative role under a declared scope.

4. moral legitimacy:
   whether the relation itself ought to exist / continue, and how conflicts among real positions should be resolved.

Only 2 → 3 supplies the current GRG normativity route.

1 does not entail 3.

3 does not automatically entail 4.

### Why this fits existing SRT routing

This refinement is compatible with the existing O1 / O2-C architecture:

- O1 asks indexed G-stronger / G-weaker comparisons;
- O2-C asks what must hold if a relation is to continue instantiating its declared / enacted constitutive type;
- O2-A adds agency / answerability burdens;
- O2-M retains genuine moral conflict / legitimacy as OPEN.

Thus “generative expectation” can be read as the bridge between generative grammar and constitutive normative direction without deriving complete morality from occurrence.

### Key anti-teleology guard

The expected relation must be inherited from an actually formed generative organization, not projected backward as a cosmic final goal.

Therefore:

generative expectation != predetermined endpoint.

It is local / indexed / historically formed unless a stronger whole-position relation is independently established.

### Disposition

Generative expectation → normativity: RETAIN DIRECTION.

Meaning of “expectation”: REDEFINE / TYPE.

Statistical prediction → normativity: REJECT.

Persistence → normativity: REJECT.

Cosmic endpoint / maximum order: REJECT.

Full moral legitimacy: REMAINS OPEN.

## 5. Cross-cutting challenge — grammar or meta-language?

### Threat

GRG may turn into a vocabulary for redescribing every theory rather than an explanatory structure.

### Admission requirement

A GRG relation earns retention only if it does at least two of the following:

- removes an ambiguity between domain concepts;
- predicts a missing control / failure mode;
- explains why a domain-level law changes when the unit / boundary / scale changes;
- enables bounded transfer into a new domain before result inspection;
- forces SRT itself to narrow or split a concept.

Pure crosswalk is useful scholarship but not yet GRG explanatory gain.

## 7. Strongest unresolved issue after Pass 1

The central issue is now not whether normativity comes from generativity in the broad sense.

The sharper issue is:

What exactly is a generative expectation, and what makes it normative rather than merely predictive?

Current best machine answer:

a generative expectation is a typed constraint implied by an actually formed generative relation on what counts as continuation / transformation of that relation; normativity enters when trajectories are compared relative to the generative standing of formed participants / relations.

This answer is coherent with current SRT but is not yet author-adjudicated.

## 8. Required author second adjudication

Before hardening the normativity interface, ask the author to accept, reject or modify this distinction:

descriptive prediction

In particular, determine whether the author intended “预期” as:

Current recommendation from this audit: B is the minimum ontology-level reading; C is a downstream formed-position realization; A alone is insufficient.
