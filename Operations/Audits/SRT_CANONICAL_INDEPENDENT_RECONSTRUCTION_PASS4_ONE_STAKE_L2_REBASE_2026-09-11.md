# 1. Q13 — Stable ISP presupposes formed continuity, but One need not be a separate final node

## 1.1 Structural reading

The current Stable ISP result-state criterion already says, in substance:

```text
same process / same selection center
+ recurrent historical reconstitution
+ perspective-bearing organization
+ history-bearing writeback
+ continued selectability
```

The first two items already presuppose a thinner function:

```text
localized lineage-relative continuity
through recurrent historical reconstitution
```

That is exactly the function recent reconstruction has been calling:

```text
formed continuing organization
One-function
```

Therefore the canonical-independent dependency is currently best read as:

```text
Stable ISP
=> formed-continuity / One-function already paid
```

but not conversely:

```text
formed-continuity / One-function
!=> Stable ISP
```

A flame-like, metabolic, regulatory, learning or organizational process may have enough lineage-relative reconstitution to count as a formed continuing organization while lacking Stable-ISP-level perspective/history integration/continued selectability under the stronger standing gate.

## 1.2 Compression consequence

This means Q13 should not be framed as:

```text
Do we need a new ontology level called One before Stable ISP?
```

The better question is:

```text
Does SRT need an explicit name for the formed-continuity substructure
that every Stable ISP already presupposes but many non-ISP organizations may also possess?
```

Current answer:

```text
FUNCTION: YES, strongly indicated.
SEPARATE CANONICAL NODE: NOT YET REQUIRED.
NAME "One": AUTHOR / CANONICAL MAPPING OPEN.
```

This is an important simplification pressure.

The ontology can acknowledge a real intermediate function without automatically multiplying final canonical nodes.

## 1.3 Current preferred relation

```text
isolated Selection events
-> localized lineage-relative reconstitution
-> formed-continuity / One-function
-> Stable ISP only when stronger standing conditions are also paid
```

So `One` currently behaves more like:

```text
necessary structural prerequisite / substanding function
```

than a guaranteed independent rung in the final canonical ladder.

# 2. Q14 — 承担 and 关切 are two faces of endogenous stake coupling; direction is likely not a third coequal subject primitive

## 2.1 Current canonical burden split

Current materials distribute three burdens across subject-entry language:

```text
承担
= own consequence cannot be fully externalized;
  consequence structurally returns into the same continuing process.

关切
= some conditions are endogenously and differentially incorporated
  into that position's continuity / payability / later selectable space.

direction
= continuations are not structurally neutral;
  some preserve or expand continuation/selectability better than others.
```

These three are related but not type-identical.

## 2.2 A deeper candidate: endogenous stake coupling

The current d-value owner already treats `d` as a summary of:

```text
stake-coupled concern / irreversible-risk sensitivity
```

This suggests a deeper relation beneath the apparent triple gate:

```text
ENDOGENOUS STAKE COUPLING
```

Working reconstruction:

```text
A condition / consequence belongs to a position's endogenous stake domain
iff changes in that condition cannot be treated as merely external bookkeeping,
because they differentially alter that same continuing process's
continuity, payability, reachable futures or continued selectability.
```

This relation has two natural faces.

### Consequence-facing face

```text
承担 / non-outsourcing
= what happens after Selection cannot be fully exported away from the same unit.
```

### Condition-facing face

```text
关切 / concern
= some conditions count differently because their variation changes
  the same unit's continuity / selectable future.
```

These are therefore not obviously three separate ontological primitives.

Current compression preference:

```text
承担 + 关切
= two relational faces of endogenous stake coupling
```

not identity of words, but a deeper shared structure.

## 2.3 Where direction fits

`direction` must be split into two levels.

### Pre-subject structural direction

At the thinner Selection/L0 level, non-neutrality and non-self-erasure asymmetry may exist without subjecthood, concern or stake.

Therefore:

```text
structural direction
!=> subject-position
```

and direction cannot be made a subject-exclusive primitive.

### Position-relative direction readability

Once a Stable ISP has:

```text
structural perspective
+ endogenous stake coupling
```

its possible continuations are no longer equivalent relative to its own continuity/selectability.

That yields a local ordering/readability:

```text
some continuations preserve / expand stake-bearing continuity more than others;
some damage / close it more than others.
```

Current reconstruction pressure therefore favors:

```text
direction at subject-entry level
= induced local ordering / readability of stake-relative continuations
```

rather than an additional third primitive that must be independently paid beside `承担` and `关切`.

## 2.4 Provisional subject-position compression

Current preferred minimal subject formula becomes:

```text
subject-position candidate
=
Stable ISP
+ endogenous stake coupling
```

where:

```text
endogenous stake coupling
has consequence-facing non-outsourcing (`承担`)
and condition-facing differential relevance (`关切`);

position-relative direction
is induced/read from the non-neutral effect of continuations
on that stake-bearing process.
```

This is a major simplification candidate.

It does **not** claim:

```text
L0 epsilon is reducible to subject stake;
all direction is derived from concern;
all concern is phenomenality;
stake coupling proves experiencer status;
d-value by itself proves subjecthood.
```

Phenomenality remains OPEN.

## 2.5 Pressure on current T-IND-2

If the above compression survives review, then current subject-entry wording may be over-factorized as:

```text
承担
+ 关切
+ epsilon-direction readability
```

when a thinner reconstruction might be:

```text
Stable ISP
+ endogenous stake coupling
-> position-relative directional differentiation becomes readable
```

This is a **REWRITE pressure**, not a current canonical decision.

# 3. Q15 — L2 currently contains two different architectures

## 3.1 The older convergence-domain architecture

Older / glossary lineage defines L2 roughly as:

```text
multiple selectors' stable intersection / convergence
-> shared structure
-> objective / social / institutional stability
```

This reading is inherently:

```text
multi-selector
shared
convergence-oriented
```

and often treats:

```text
personal L2 < group L2 < human L2
```

as nested convergence domains.

## 3.2 The later sedimentation / scaffold architecture

The current L2 dynamics owner also uses L2 for:

```text
historical trace
hysteresis
writeback
closure
low-friction re-entry
scaffold formation
backgrounding
inheritability
constraint on later Selection
```

and explicitly distinguishes:

```text
trace
-> closure
-> L2-grade closure
-> background scaffold
```

This later reading does not require multi-selector convergence.

A single continuing organization can possess internal sedimented history that constrains its later selections.

Therefore current `L2` carries at least two different types:

```text
A. shared convergence structure
B. historical sedimented scaffold / constraint structure
```

These are related but not identical.

## 3.3 Type diagnosis

The canonical-independent audit currently judges this as a likely historical bundling error:

```text
shared convergence
is one possible realization / scale of sedimented constraint,
not the definition of historical sedimentation itself.
```

A more general architecture is:

```text
generic trace / writeback
-> repeated selective reinforcement / sedimentation
-> re-enterable, inheritable, backgrounded constraint scaffold
```

This scaffold can be:

```text
internal to one formed organization;
external/environmental relative to that organization;
shared across multiple organizations;
institutional / social;
relation-level / collective.
```

So `internal vs collective` is not the defining axis.

The defining axis is:

```text
mere history record
vs
history that has become reusable background constraint.
```

## 3.4 Should L2 remain a top-level L-number?

Current provisional answer:

```text
AS A FUNDAMENTAL CO-EQUAL ONTOLOGICAL DOMAIN: DOUBTFUL.
AS A LEGACY / CONVENIENT LABEL FOR SEDIMENTED CONSTRAINT STRUCTURE: POSSIBLY.
```

Reason:

`L0` and `L1` answer two different modal/actuality questions:

```text
L0 — what remains potential / selectable under the structural floor?
L1 — what has become determinate / manifest in a Selection event?
```

But the strongest current `L2` reading answers a different kind of question:

```text
what historical structure has sedimented enough to constrain later Selection?
```

That is not obviously a third peer domain.

It may instead be a cross-temporal structural relation / layer generated by repeated Selection and writeback.

So the cleaner architecture may be:

```text
L0  modal / latent condition
Selection
L1  manifest actuality

history/writeback across selections
-> sedimented scaffold / constraint structure
```

rather than:

```text
L0 -> L1 -> L2
```

as a universal chronological or ontological ladder.

## 3.5 A possible retype without losing useful L2 work

The audit does **not** recommend deleting the L2 research corpus.

Instead later canonical mapping could choose among:

```text
OPTION A — RETYPE
Keep the symbol `L2`, but explicitly define it as a boundary/scale-relative
sedimented constraint layer, not a third co-equal ontological domain.

OPTION B — DEMOTE / ALIAS
Retire top-level `L2` ontology status and keep `L2` as legacy shorthand
for historical scaffold / sedimented constraint structures.

OPTION C — SPLIT
Use one term for generic sedimented scaffold and reserve `L2`
for the special shared/convergence realization.
```

Current machine preference:

```text
A or B > C
```

because C risks preserving the old conflation under two partially overlapping terms.

No naming decision is made in this pass.

## 3.6 Consequences if L2 is retyped

Several current expressions would need later review, for example:

```text
time as L2 pheromone / accumulation;
L2 as universal convergence domain;
L2 as automatically shared/objective;
personal L2 < group L2 < human L2 as a single ontological nesting;
L2 closure as necessary wording for all historical integration;
```

Some may survive as bridge metaphors or scale-specific realizations.
They should not automatically survive as core ontology merely because they are historically canonical.

    │       ↓

    │   [structural perspective + integrated history + continued selectability]
    │       ↓
    │   subject-position candidate

    │       ├── condition-facing: 关切 / differential endogenous relevance
