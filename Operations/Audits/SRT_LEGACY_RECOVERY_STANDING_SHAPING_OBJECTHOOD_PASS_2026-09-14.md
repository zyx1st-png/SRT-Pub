## 2. Recovered burden A — Shaping can become constitutive to Standing

### 2.1 Legacy intuition

Several old examples converge on the same structural question:

```text
sensory-substitution / tool incorporation;
external scaffold acting as an operational exoskeleton;
maternal structure functioning as a prior support for a forming unit;
cell-cell coupling yielding higher-order coordination;
loss of coupling dissolving the higher-order organization;
gradual de-nesting / differentiation of a dependent unit.
```

The old language often expressed this through `theta expansion`, nested operators or external `L2`. Those formulations are not retained.

The load-bearing remainder is:

> **A structure can begin as an external condition of a process and, through recurrent load-bearing coupling, become part of the dependency by which a new or expanded formed process-unity is reconstituted.**

The reverse can also occur:

> **A component previously nested in a higher-order organization can cease to depend on that higher-order reconstitution and acquire / recover a relatively separable reconstitution path.**

### 2.2 Current-owner translation

Current One semantics already supplies the crucial guard:

```text
One formation requires a relatively separable Selection-mediated vertical reconstitution path;
relative separability is generated rather than presupposed;
identity, exact boundary, branch / merge and same-material persistence remain OPEN.
```

Therefore the legacy question should **not** be translated as:

```text
"when does tool X literally become the same self?"
```

The safer machine formulation is:

```text
Given a formed process O and shaping structure S:

Case 1 — external Shaping:
S materially changes later selectability / cost / reachability,
but O's relevant vertical-reconstitution path does not require S as a constitutive relation.

Case 2 — higher-order formation:
recurrent O-S coupling supports a new relatively separable vertical-reconstitution path O*.
O and S need not thereby lose all lower-level standing.

Case 3 — constitutive incorporation candidate:
S becomes persistently load-bearing inside the reconstitution path used to track a declared standing.
Whether this is "the same One expanded" or "a new higher-order One" remains an identity/boundary question and is OPEN.

Case 4 — de-nesting / boundary contraction:
a higher-order reconstitution path breaks or ceases to be load-bearing,
while a lower-scale path remains / becomes independently reconstitutable.
```

### 2.3 Why this is not already ordinary scaffold theory

`Q19` already distinguishes:

```text
support -> substitution -> atrophy -> lock-in,
with capability sedimentation, payable exit and consequence return as tests.
```

But those are primarily **capacity / generative-health** questions.

They do not by themselves determine ontological Standing.

A scaffold may:

```text
improve performance without entering Standing;
degrade endogenous capability without entering Standing;
become operationally indispensable without becoming a separate Bearer;
participate in a new higher-order One while remaining non-Bearer itself.
```

Thus:

```text
scaffold dependence != constitutive incorporation automatically.
```

### 2.4 Collective Selection partial precedent

`SRT_Collective_Selection.md` already carries a local precedent:

```text
an institution may function as an organ of a collective ISP
without the institution itself becoming the collective ISP.
```

This is important because it already blocks:

```text
causal / organizational importance -> independent Standing.
```

What is missing is a generic cross-owner rule for how Shaping structures can become constitutive relations inside a new formed Standing without themselves automatically acquiring One/Bearer status.

### 2.5 Guards

Do not infer:

```text
frequent use -> incorporation;
dependence -> incorporation;
correlation -> incorporation;
information flow -> incorporation;
performance loss on removal -> incorporation;
incorporation -> Bearer;
incorporation -> subject;
incorporation -> moral standing;
collective formation -> lower-standing erasure.
```

## 4. Recovered burden B — One formation does not yet explain effective objecthood

### 4.1 The old black-boxing intuition

Legacy materials repeatedly used a black-box / compression idea:

```text
micro / formation detail is filtered;
a stable macro symbol or interface becomes available;
the result can be reused without replaying all formation history.
```

The old files often mixed this with consciousness, L1 projection or `Ghost` semantics. Those claims are not retained.

The recoverable burden is simply:

> **Formation and downstream usability are different problems. A process can become a One, yet a further condition is needed before other processes can reliably treat it as a stable operational unit.**

### 4.2 Current P07 already contains an object bridge

`Physics/patches/SRT_Phys_P07_Closure_Ontology_of_Physical_Objects_v0_1.md` already asks:

```text
How does a fact become an object?
```

and proposes:

```text
record bundling
-> boundary stabilization
-> low-cost re-identification
-> physical object.
```

Its strongest safe insight is:

```text
objectivity / object-likeness increases when a structure can be re-identified
across instruments, positions and declared temporal slices with low marginal burden.
```

It also explicitly allows fuzzy / graded objects and treats object boundaries as stable permeability profiles rather than primitive lines.

### 4.3 Why P07 is not yet integrated with post-#970 One

P07 is an April bridge built on the older closure-record architecture.

It does not answer the post-#970 question:

```text
What is the relation between a Selection-mediated vertically reconstituted One
and a re-identifiable effective object?
```

Therefore the live gap is **not objecthood from scratch**.

It is the crosswalk:

```text
current One formation
-> interface / readout stabilization
-> scale-relative re-identifiability
-> effective objecthood.
```

### 4.4 Critical distinction — One != object

The crosswalk must preserve at least two classes:

```text
MODEL / OBSERVER-SIDE OBJECTIFICATION
A domain model groups relations into one operational token.
This can be useful without establishing independent One standing.

FORMED EFFECTIVE OBJECTHOOD
A formed process has One standing,
and at a declared scale / interface it also supports stable,
low-cost re-identification and downstream reuse.
```

Therefore:

```text
objectification != One;
One != automatically effective objecthood;
effective objecthood != primitive substance.
```

### 4.5 Candidate machine bridge

A cautious machine-only bridge is:

```text
Selection-mediated vertical reconstitution
-> formed One / Standing
-> stable interface / boundary profile under a declared perturbation and readout range
-> downstream interaction no longer requires replaying the whole formation history
-> low-cost re-identification / reuse
-> effective objecthood at that scale.
```

Call the middle property **operational black-boxability** only as an audit label.

It means:

```text
formation history remains ontically relevant,
but is not required as an explicit state variable for every target-scale downstream interaction.
```

It does **not** mean:

```text
history has been erased;
internal dynamics do not matter;
the object is absolutely opaque;
the object is a fundamental substance.
```

## 6. Ordinary causation after object formation

Legacy materials repeatedly say that ordinary `A -> B` causation is not the same explanatory task as primitive generation.

Current reconstruction can now state the distinction more carefully:

```text
VERTICAL GENERATION
why / how a determinate manifestation and formed Standing obtain at all.

HORIZONTAL / OBJECT-LEVEL CAUSAL MODEL
how already formed effective units constrain each other's later states / reachability
inside a declared domain representation.
```

This does not imply that every scientific causal model is merely illusion.

Instead:

> Object-level causation can be an effective, scale-valid description once the participating units have sufficient standing / interface stability for the domain model.

This is a bridge claim, not a replacement theory of causation.

## 11. Proposed noncanonical transition grammar

The current five-relation minimum tool remains:

```text

Standing
Shaping
Bearing
Revision
```

The legacy pass suggests adding **transition questions**, not new relation types:

```text
T-GS  Generation -> Standing
      already owned by One formation.

T-SH  Standing/history -> Shaping
      already owned by retained history / L2 scaffold.

T-SS  Shaping -> Standing
      LIVE: incorporation / higher-order formation under recurrent constitutive coupling.

T-DS  Standing -> de-nesting / changed Standing
      LIVE: loss or reorganization of higher-order reconstitution dependence.

T-SO  Standing -> effective objecthood
      LIVE bridge: stable interface + re-identifiability + operational black-boxability.

T-BR  Bearing / consequence return -> Revision -> Shaping
      already represented by B13 / consequence-sensitive revisability.
```

This keeps the ontology thin while making the research grammar dynamic.
