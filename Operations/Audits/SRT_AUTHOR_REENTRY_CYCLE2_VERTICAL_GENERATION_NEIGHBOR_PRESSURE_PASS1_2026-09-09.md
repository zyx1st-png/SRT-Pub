## 1. Source-neutral candidate criterion for active vertical generation

To avoid circularity, use a deliberately broad audit criterion.

A system provisionally pays `VG*` when all four roles are present:

```text
V1 DIFFERENTIAL PRODUCTION
   the system actively produces a non-flat relation among candidate
   continuations rather than merely reading a pre-existing ranking;

V2 MANIFEST / BACKGROUND CO-GENERATION
   enhancement / realization of one relational direction is dynamically
   coupled to relative suppression / backgrounding of alternatives;

V3 REGENERATION
   after perturbation, replacement of the currently dominant content,
   or context change, the non-flat relation is generated again rather
   than only preserving one fixed winner;

V4 TRANSITION CONSEQUENCE
   the generated vertical relation changes which later transitions are
   accessible, amplified, suppressed or selected under a locked probe family.
```

`VG*` is audit notation only.

It does not presuppose SED-B and does not require a bearer.

## 2. Can ordinary attractor / competitive dynamics pay `VG*`?

### 2.1 Simple persistent bump

A fixed bump that merely remains active can pay:

```text
L = YES
current asymmetry = YES
```

but does not automatically pay:

```text
V1-V4
```

Persistence alone is insufficient.

### 2.2 Dynamic field / competitive selection architectures

A stronger mature rival family includes recurrent fields with:

```text
local excitation
+ broader inhibition
+ competition among candidate peaks
+ winner replacement / updating under changed input
```

Such systems can plausibly pay:

```text
V1 differential production
V2 enhancement + suppression
V3 regeneration after winner/context change
V4 transition consequence
```

Therefore the new author clarification does **not yet defeat** generic dynamical rivals.

It changes the strongest-neighbor target from:

```text
persistent attractor state
```

to:

```text
active competitive field that repeatedly generates a foreground/background
relation among possible continuations.
```

This is a stronger and fairer rival.

## 3. Where the real residual may now lie

If an ordinary dynamic field pays `VG*`, SRT cannot claim distinctiveness from:

```text
active competition
winner selection
lateral inhibition
recurrent foreground/background production
```

alone.

The remaining strengthened residual would have to involve how:

```text
active vertical generation
and
historical sedimentation / writeback
```

are coupled across repeated Selection events.

Candidate residual shape:

```text
VG_t
-> Selection_t differentiation
-> SH_t retained writeback
-> SH_t changes conditions for VG_(t+1)
-> later vertical generation is history-shaped
```

This is stronger than either:

```text
static attractor persistence
```

or:

```text
history-independent recurrent competition
```

But it is also close to adaptive / plastic recurrent dynamics, so strongest-neighbor pressure remains substantial.


This expectation is not an author ruling.
