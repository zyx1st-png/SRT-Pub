## 1. Why thinning is now justified as a review question

Spine is read very early in the canonical route:

~~~text
CANONICAL_REGISTRY §C
-> Generative Ontology Spine
-> compatible local owners
~~~

It is also repeatedly included in core/context bundles and theory retrieval.

Therefore repeated local-owner explanation carried inside Spine has unusually high recurring retrieval cost.

The repository already states that canonical files should be short, stable and low-ambiguity, while long files carry expansion, derivation and historical sediment.

The issue is not that 560 lines proves a formal governance violation. No separate hard line-count theorem is established here.

The structural issue is:

~~~text
cross-owner routing owner
+
repeated local-owner exposition
+
OPEN list
+
citation / owner navigation
=
high recurring retrieval load
~~~

Desired result:

> preserve all cross-owner semantic burden while reducing local-owner duplication.

## 2. Three allowed thinning actions

### KEEP-IN-SPINE

Content is itself cross-owner canonical routing, non-identity, admission guard or OPEN boundary.

It must remain substantively readable in Spine.

### COMPRESS

Content belongs in Spine, but current wording repeats explanation that can be shortened without changing semantics.

Compression must preserve all positive and negative inference guards.

### MOVE-TO-OWNER / POINTER-ONLY

A detailed local owner already carries the burden.

Spine should retain only:
- cross-owner placement;
- essential non-identity / anti-jump rule;
- exact owner pointer;
- any OPEN gate needed to prevent reverse inference.

This action does not delete theory. It removes duplicate exposition from the cross-owner spine.

## 11. Acceptance tests for a future semantic diff

A thinning FAILS if it:
- removes a cross-owner non-identity;
- converts a local-owner pointer into loss of a gate;
- weakens P+E;
- drops positive-E OPEN status;
- turns Stable ISP into source of One;
- restores Selection occurrence -> retained-history implication;
- removes genuine-Selection anti-tautology OPEN;
- merges O1 / O2-C / O2-A / O2-M;
- lets a formal L0/L1/L2 owner back-define the metaphysical crosswalk;
- uses line count as reason to delete unresolved theory;
- removes the only route to accepted/continued historical analysis recovered in #1044/#1046.

A thinning PASSES only if:

~~~text
all current cross-owner inference permissions remain unchanged
+
local-owner detail becomes easier to reach
+
no OPEN is silently closed
+
Spine becomes materially shorter / easier to load
~~~
