# One onset versus graded stability — pressure pass

## 1. Why a scalar threshold is probably the wrong first move

The author has already ruled:

```text
Selection can be bearerless;
stable / history-bearing organization emerges gradually;
"稳定是渐进的层次。"
```

Therefore the present work should not invent an arbitrary scalar threshold such as:

```text
reconstitution strength > x
-> One;
else not One.
```

A cleaner decomposition is:

```text
One onset
= qualitative relation;

One stability
= graded property of the continuing relation.
```

## 2. One-shot event remains below the onset gate

A single Selection event can generate:

```text
manifestation + relative backgrounding;
local vertical organization;
irreversible historical difference.
```

But if no later localized vertical organization is reconstituted relative to that event's vertical history, then:

```text
Selection event: YES
verticalization: YES
One onset: NOT ESTABLISHED.
```

## 3. Minimal onset candidate

Machine-side minimum:

```text
V_t
= local Selection-generated vertical organization;

V_t materially participates in reconstituting V_(t+1)
relative to the same local lineage;

V_(t+1) functions as an operative non-flat locus
from which later Selection can proceed.
```

Then:

```text
minimal One onset: CANDIDATE YES.
```

This does not require long duration, strong robustness, Bearer ownership, cognition or perspective.

Compact relation:

```text
vertical event
-> lineage-relative reconstitution
-> renewed operative locus
= minimal One-onset candidate.
```

## 4. Why ordinary causation is insufficient

Do not weaken the relation to:

```text
state_t causes state_(t+1).
```

The successor must reinstantiate / reconstruct the relevant **vertical selective locus** rather than merely be any later causal effect.

Thus:

```text
ordinary state transition
!= One onset.
```

The live relation is:

```text
prior local vertical organization
-> contributes to regeneration of a later local vertical organization
-> later organization can again condition Selection.
```

## 5. Stability is then graded

Once the onset relation exists, stability can vary along several noncanonical dimensions:

```text
recurrence depth;
perturbation tolerance;
range of component / state replacement compatible with continuation;
strength / specificity of lineage-conditional reconstitution;
resilience of the operative locus;
ability to preserve continuation while actively reconstructing future selectability.
```

No single scalar is authorized.

This matches the author's gradual-stability ruling better than a binary persistence gate.

## 6. Short-lived One is allowed

A One can form and then quickly dissolve.

Therefore:

```text
short duration
!= no One;

failure to persist indefinitely
!= failure of One formation.
```

The important distinction is:

```text
one-shot actuality
vs
at least one genuine lineage-relative reconstitution into a renewed operative locus.
```

This preserves the occurrence / persistence distinction without making permanence part of ontology.

## 7. Relation to Selection-position

At the onset moment:

```text
One
= the localized vertical process has entered a continuation relation;

Selection-position
= the renewed time-local non-flat locus through which that continuing process can participate in later Selection.
```

Thus One formation and Selection-position reconstitution remain tightly coupled but conceptually distinct.

## 8. Relation to Bearer

Bearer remains stronger:

```text
minimal One onset:
lineage-relative regeneration of operative vertical locus;

Bearer:
Selection consequences return to / become own-history of the organization
that must reconstitute the later locus.
```

Therefore a weak / newly formed One may exist before Bearer-level closure.

## 9. Relation to multiple Ones

Multiple-One onset requires multiple local lineage-relative reconstitutions whose continuation conditions are relatively differentiable.

Stability of each lineage may differ:

```text
A = weak / short-lived One;
B = highly stable One;
C = emerging / branching One.
```

No global uniform stability threshold is assumed.

## 10. Disposition

```text
One formation requires indefinite persistence: NO
One formation requires high stability: NO
One onset as first lineage-relative reconstitution into renewed operative locus: STRENGTHENED CANDIDATE
One stability as graded: AUTHOR-COMPATIBLE / STRENGTHENED
single stability scalar: NOT AUTHORIZED
Bearer closure at One onset: NO
canonical edit: NO
new Level: NO
HOLD change: NO
```
