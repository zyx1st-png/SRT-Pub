# SRT minimum unifying tool — latent-burden mining pass

> **Boundary:** machine-side noncanonical reconstruction audit. It mines burdens already distributed across SRT's source intuition, book architecture, current owners, bridge hypotheses and operational audit grammar. It does not create a new primitive, restore superseded Real Choice Moment claims, edit canonical owners, assign novelty, raise a Level, or close HOLD.
>

## 0. Executive result

The mining pass finds a real omission risk, but not a warrant to thicken the universal spine immediately.

The post-2026-09-13 canonical spine correctly protects the minimum ontology:

```text
non-flat openness
-> finite-position-indexed subjectless Selection
   = actual differentiation
   = manifestation / relative backgrounding
-> Selection-mediated vertical reconstitution
-> One.
```

However, older and parallel SRT work repeatedly analyzes a different question that is only thinly visible in this route:

> **not only what becomes actual, but how an actual differentiation changes what can become selectable next, for which formed position, at what burden, through which retained structure, and whether the conditions of selection themselves can later be revised.**

This is not one missing ontology node. It is a **typed analysis grammar** distributed across several layers.

Machine conclusion:

```text
missing universal node = NOT FOUND
latent cross-version analysis grammar = FOUND
local novelty of its components = MOSTLY NOT SAFE
architecture-level residual candidate = LIVE
```

The strongest live residual is no longer `world-side two-sided actualisation` by itself. It is a layered relation among:

```text
actuality generation
relative backgrounding
future-selectability transformation
position-indexed consequence / burden routing
formed-condition / scaffold feedback
generative revision of selection conditions.
```

Not every line is primitive or universal. The point is the typed continuity and the guards between them.

## 1. Method — mine first, compare second

This pass does not search only for novelty-shaped fragments. It first asks what SRT itself repeatedly needs.

Evidence strata are kept separate:

```text
A. current canonical owner burden;
B. author/source-intuition recurrence;
C. book architecture / companion exposition;
D. old formal or bridge machinery;
E. operations/audit grammar;
F. neighbor pressure.
```

A candidate survives mining only if it appears as a repeated explanatory dependency, not merely an old equation or discarded term.

A candidate survives neighbor pressure only if source-native neighbors do not already pay the same burden at the relevant scope.

## 2. The first hidden distinction — occurrence, later efficacy, scaffold and reselection are not one thing

Older SRT prose often compressed `写入` into the Selection event. The strongest archived formulation said, in effect:

```text
without downstream terrain change,
what looks like Selection is only simulation / preference / rehearsal.
```

The current L0 correctly thinned this because it overcollapsed several strengths.

Current canonical minimum instead fixes:

```text
actual occurrence
-> cannot later become ontologically equivalent to never having occurred

but

irreversible ontic update
!= durable persistence
!= localized memory
!= anchoring
!= recurrent historical efficacy.
```

The apparent conflict is best decomposed rather than choosing one side wholesale.

### Machine-only effect ladder

Do not treat the following labels as new symbols or canonical stages.

```text
E0 occurrence non-erasure
   the event occurred; later loss does not make it never-have-occurred.

E1 later-condition effect
   some retained consequence changes conditions of a later process / Selection.

E2 localized recurrent efficacy
   retained organization can re-enter later Selection in a load-bearing way;
   vertical reconstitution can support One formation.

E3 scaffold/background condition
   accumulated history becomes inheritable / shareable / backgrounded enough
   to pre-shape later candidate access, friction, visibility or default paths.

E4 generative reselectability
   consequence return can revise comparison rules, boundaries,
   or candidate-generation conditions themselves.
```

This ladder reconciles the thin current spine with the old Selection-dynamics intuition without smuggling persistence into every primitive Selection.

Current placements:

```text
E0 = current L0 minimum;
E1 = allowed where retained consequence exists;
E2 = One-formation / vertical recurrence territory;
E3 = L2 scaffold family, not L0;
E4 = B13 generative-health / stronger downstream territory.
```

This decomposition is a genuine recovery result.

## 5. Latent burden C — consequence routing is not generic feedback

### 5.1 Repository recurrence

The old SEA apparatus made `X` — the consequence-bearing location — an independent field rather than assuming that the executor, chooser and bearer coincide.

Current `SRT_Collective_Selection.md` goes further:

```text
M_ij(t)
= degree to which consequences of P_j's Selection
  return to P_i's future selection capacity.
```

This is structurally important because one event can separate:

```text
candidate generator;
filter / comparator;
formal authorizer;
executor;
beneficiary;
loss / risk bearer;
repairer;
history / writeback location.
```

At higher levels, the same Selection-shaped social event can therefore alter one position's future selectability while another position receives the benefit or authority.

### 5.2 Source-neutral statement

Candidate burden:

> When formed positions exist, a generative account should type **where consequences land and whose later selection capacity they change**, rather than representing all feedback as returning to the same system boundary by default.

This is downstream of primitive Selection and cannot define L0.

### 5.3 Neighbor pressure

Many domains contain local analogues:

```text

control and distributed systems;
niche construction affecting constructor and other species;
distributed cognition and sociotechnical systems;
responsibility / accountability traditions.
```

But Barad + Simondon do not by themselves supply the full SRT-style explicit decomposition of selection-role location plus future-selectability routing.

Machine disposition:

```text
position-indexed consequence-to-selectability routing
= LIVE SRT TOOL CANDIDATE
= NOT YET SHOWN LOCALLY NON-SUBSTITUTABLE
= strongest current downstream residual candidate.
```

The reason it remains live is not that nobody has studied externalities or distributed agency. The live question is whether SRT's exact coupling


Not all seven questions apply at every scale. That is part of the typing discipline.
