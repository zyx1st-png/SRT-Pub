# Post-RC-A Selection-Level D2 Candidate Ranking

> **Question**: after demoting former P1-T05 out of the Selection core, which existing SRT prediction has the best chance of yielding a genuinely **Selection-level** prospective difference against a bounded ordinary rival?
>
> **Verdict**: `NO CURRENT P24 CANDIDATE IS D2-READY`. The best near-term workline is **P24-3 L2 hardening / floor challenge**, not because it is currently SRT-specific, but because it has the cleanest measurable structure and the lowest theory cost. P24-1 is second. P24-4 is third. P24-2/5/6 are downstream and should not carry primitive-Selection proof burden.

---

## 1. RC-A changes the admissible target

Before RC-A, Selection irreducibility work repeatedly borrowed the former `Real Choice Moment` / anti-script boundary.

That route is closed.

The Selection-level discrimination target must now satisfy:

```text
no appeal to:
Choice essence
subjecthood
phenomenality
moral standing
mere felt freedom
```

and must instead produce at least:

```text
frozen bounded rival
+ prospective intervention / counterfactual
+ observable prediction difference
+ explicit SRT failure condition
```

A classification difference or richer vocabulary remains D0/D1 only.

---

## 2. Rival tiers

Use the post-A4 rival hierarchy.

### R0 — fixed script / mapping

Useful negative control, too weak for a strong D2 claim.

### R1 — bounded adaptive rival

Allows declared memory, hysteresis, policy update, ordinary reinforcement / control.

### R2 — bounded generative / representation-update rival

Allows a preregistered generative / meta-learning / representation-update family with frozen architecture, calibration data, state variables and complexity/revision cost.

### R∞ — unrestricted causal-history reconstruction

Arbitrary history-dependent functions / latent expansion. Useful only for translation / absorption stress; invalid as the final empirical judge because it cannot be forced to make a wrong prediction.

A credible SRT differential should eventually survive the relevant R2, not only R0.

---

## 3. Ranking criteria

Each P24 candidate is scored qualitatively on seven dimensions:

1. **Selection proximity** — how directly it concerns Selection / L2 rather than downstream agency, normativity or phenomenality;
2. **positive measurable variable**;
3. **independent intervention**;
4. **bounded R2 comparability**;
5. **prospective D2 potential**;
6. **failure clarity**;
7. **theory / experiment cost**.

The ranking asks where to spend the next experiment-design effort, not which claim is “most true.”

## 5. Rank 1 — P24-3 L2 hardening / floor challenge

### Current core shell

Existing P24-3 requires:

```text
local compatible-path cost down
+ global constraint up
+ hysteresis under perturbation
```

The 2026-08-17 continuous-convergence work adds a useful fourth diagnostic without changing the core definition:

```text
compatibility failure
-> previously background scaffold re-enters active regulation
```

A richer measurable shell is therefore:

```text
formation:
compatible cost down
+ re-entry reliability up
+ switching cost / global constraint up
+ foreground regulation demand down

challenge:
controlled mismatch
-> friction / error / regulation demand rises
-> old-path hysteresis appears
-> refresh, revision, bypass or replacement

re-stabilization:
new compatible cost falls
+ new hysteresis / backgrounding emerges
```

### Why rank 1

- It stays close to Selection history and `L2`.
- Existing `rho(p,t) / rho*`, `Psi_f`, accessibility and hysteresis machinery already provide handles.
- It does not require subjecthood, d-value or phenomenality.
- It supports direct perturbation and longitudinal measurement.
- It has clear failure modes.

### Why it is not D2-ready

Ordinary rivals can predict the same pattern:

- habit / reinforcement learning;
- attractor dynamics;
- predictive control;
- state-space adaptation;
- hysteretic dynamical systems;
- representation learning.

Therefore the four-signature pattern is **an operationalization / calibration target**, not evidence of SRT superiority.

## 6. Rank 2 — P24-1 non-monotonic friction

### Prediction shell

```text
new restructuring
-> early friction / volatility rises
-> transition / competition
-> later friction falls if a new scaffold hardens
```

### Strength

It is prospective and measurable. A fixed-frame optimization condition can be compared with a restructuring condition.

### Main weakness

A bounded R2 rival can readily predict non-monotonic loss, uncertainty, competition, exploration cost, representational instability, or phase-transition-like dynamics.

Therefore:

```text
non-monotonicity alone
!= SRT differential
```

P24-1 becomes more useful as a **time-course component inside P24-3 floor formation / floor challenge**, rather than as a standalone flagship discriminator.

## 7. Rank 3 — P24-4 framework / visibility effects

### Prediction shell

A framework can change:

```text
what differences become salient
what options enter the candidate field
what is admissible / costly
before explicit belief report changes
```

### Strength

This aligns with existing perceptual-learning and social invitation-gating bridges and can be tested while holding nominal facts / rewards fixed.

### Main weakness

Predictive processing, representation learning, affordance theory, attention models, social cognition and learned gating can all represent upstream field shaping.

The effect therefore cannot carry Selection irreducibility without a much stronger frozen rival.

Best use:

> auxiliary measure of **what part of the field changed** during a P24-3 scaffold revision.

## 8. Why P24-2 should not carry primitive Selection proof load

P24-2 asks whether `d-value` predicts non-substitutability beyond reward / preference.

This remains valuable, but RC-A plus the current layering discipline make its role clearer:

```text
Selection core
-> broader than stake-bearing subject / bearer systems
```

`d` belongs to a thicker concern / stake architecture. Even a successful P24-2 experiment would primarily support the d / embodied-value bridge, not prove primitive Selection irreducibility.

It can later become an **independent downstream convergence test**, which is scientifically useful precisely because it no longer needs to carry P0 proof burden.

## 9. Why P24-6 is now explicitly an agency workline

P24-6 concerns AI competence without binding `Psi_f` / stake-coupled `d`, consequence return and fragile agency.

After RC-A this is not a Selection discriminator.

Use it to test:

```text
capacity != stake
selection-bearing computation != stronger agency standing
```

Do not use it to infer:

```text
AI without stake has no Selection
```

This clarification removes a major source of circularity from future AI-consciousness / agency work.

## 10. Cross-position floor / objectivity finding: useful control, not new flagship

The recent audit established:

```text
shared L2 backgrounding
!= cross-position objectivity
```

and:

```text
one position's floor can be another position's wall
```

This creates a valuable **control structure** for P24-3:

### Position manipulation

Hold the nominal scaffold fixed while varying independently motivated:

- history;
- role;
- resource access;
- consequence exposure;
- interface;
- entry / exit rights.

Measure position-specific:

- compatible cost;
- switching / exit cost;
- alternative visibility;
- perturbation recovery;
- ability to revise the scaffold.

### Shared-occlusion control

Change representation / interface / measurement route and test whether the apparent stability survives.

This improves objectivity discipline but remains compatible with ordinary social / ecological / learning models. It is therefore an **anti-false-positive control**, not a D2 result.

## 11. Strongest near-term experiment class

The best next experiment-design target is a **matched scaffold / controlled floor-challenge study**.

### Minimum structure

Freeze before preregistration:

```text
S = scaffold / learned path
R2 = bounded rival family
Z = measured pre-challenge state vector
I = controlled mismatch / perturbation
O = future friction / accessibility / hysteresis trajectory
```

Use at least two conditions:

1. **compatible continuation** — current scaffold remains adequate;
2. **floor challenge** — a targeted relation that the scaffold relies on becomes invalid.

Measure prospectively:

```text
local execution cost
switching cost
alternative accessibility
hysteresis
recovery / revision time
foreground regulation proxy where available
future reachability after restabilization
```

### Required R2 discipline

The rival must freeze:

- state variables;
- memory window;
- update rule / architecture family;
- calibration data;
- permitted model-selection / complexity budget;
- out-of-sample forecast.

No post-result latent expansion.

## 13. Failed shortcut — history matching

A tempting route is:

> match current observable state / performance, vary the formation history, and show different later friction.

This is useful for showing **history matters**, but it is not automatically SRT-specific. An R2 rival with memory / latent history state can predict the same difference.

Therefore the valid question is not:

```text
same visible state + different history -> different future?
```

but:

```text
under a preregistered R2 state representation and update family,
does SRT require a future difference that R2 prospectively excludes?
```

This prevents “the rival forgot a variable” from masquerading as ontology.

## 14. Current scientific disposition

### Do now

1. Treat P24-3 as the **calibration / operational hardening** priority.
2. Fold P24-1 time-course measures into its formation/challenge/re-stabilization sequence.
3. Use P24-4 as an auxiliary field-change measure where relevant.
4. Add cross-position / shared-occlusion controls when the domain has multiple bearers or interfaces.
5. Freeze an R2 model family before any claim of differential prediction.

### Do not do now

- do not invent a new Selection variable;
- do not return to `Live Choice`;
- do not use d-value / moral / AI-agency results as primitive Selection proof;
- do not call the P24-3 signature D2;
- do not use R∞ as the empirical judge;
- do not widen the rival after seeing the result.

## 15. Stop rule

Stop here because:

1. RC-A has removed agency contamination from the Selection target;
2. all current P24 candidates were ranked against a bounded-rival requirement;
3. P24-3 is the strongest **near-term operationalization** candidate but not D2-ready;
4. P24-1 and P24-4 are best treated as components / auxiliary readouts rather than separate flagship claims;
5. P24-2/5/6 are downstream and no longer carry primitive proof load;
6. no existing prediction currently provides `O_SRT != O_R2` under a frozen R2 family;
7. the next legitimate work is to specify one bounded P24-3 floor-challenge model duel, not to add another concept.

**Final disposition:** `P24-3 CALIBRATION FIRST / NO CURRENT SELECTION-LEVEL D2 / NEXT = FROZEN-R2 FLOOR-CHALLENGE DUEL SPEC`.
