# GRG-R1 productive-adequacy / O-criterion revision — Pass 1

## 0. Trigger

The first bounded transfer pilot returned PILOT-NULL.

Failed mapping:

~~~text
highly context-decodable hidden-state subspace
-> retained causal organization O
-> organization-specific later transfer effect
~~~

The response is not to tune the decoder or relax the pass threshold.

New question:

What must count as retained organization O before a future target is inspected?

## 1. Core correction

v0.1 paid an information criterion:

~~~text
O carries information about context.
~~~

GRG-R1 needs a stronger generative criterion:

~~~text
O was formed by prior process;
O is retained in current organization;
O mediates / constrains subsequent process;
O can be independently perturbed as organization rather than only read out;
only then may O be tested for later re-entry on a new target.
~~~

Therefore:

~~~text
information-bearing structure != retained generative organization by default.
~~~

## 2. Distributed source pressure

### Simondon

The repository full close-read pays:

~~~text
operation
-> structure
-> later operation
~~~

and transduction in which local formed structure becomes a condition for further formation.

GRG consequence:

A candidate O cannot be admitted merely because an analyst can classify it. It must occupy the middle term as structure produced by prior operation and entering later operation.

Simondon does not provide the domain-native RNN identifier.

### Synergetics

Haken's synergetics supplies the relevant source-family pressure through order parameters and the slaving principle: low-dimensional organization matters only insofar as it is dynamically linked to component evolution.

GRG consequence:

A low-dimensional variable is not enough by itself. Do not equate PCA / decoder axes with an order parameter.

At this stage synergetics remains a distributed pressure source rather than a full repository close-read owner.

### Bowler et al. 2026

Bowler supplies the strongest current domain-native realization:

~~~text
structured shaping
-> persistent recurrent-weight organization
-> characteristic dominant eigenspectrum / dynamical motifs
-> altered later learning strategy.
~~~

The public source code in heyslab/StructuredExperience_NatNeuro_2026, seed_weights_run.py, confirms the intervention logic:

~~~text
1. load recurrent weights from shaping-trained RNNs;
2. eigendecompose the recurrent matrix;
3. take the mean of the leading four shaping-associated eigenvalues;
4. insert those eigenvalues into an otherwise unshaped network's recurrent matrix;
5. during early training, repeatedly reset the leading eigenvalues to that scaffold;
6. later training proceeds without the repeated reset.
~~~

This is stronger than decoding because the candidate structure is embedded in the recurrent operator, retained independently of a target decoder, manipulable, and shown to bias later learning.

It remains ordinary recurrent-learning science rather than SRT-specific evidence.

## 3. Revised pre-target O admission gate

A future GRG-R1 pilot should not call something O unless it pays all three pre-target gates.

### O1 — formation

The organization must be demonstrably generated / reorganized by an antecedent process or history.

Acceptable evidence:

- pre/post structural difference;
- controlled history contrast;
- known formation intervention.

Not sufficient:

- analyst-selected component;
- arbitrary PCA / decoder axis;
- static variable with no formation account.

### O2 — retained operator / transition structure

O must be identifiable in a current organization that can condition later transition dynamics.

Preferred evidence:

- recurrent operator / connectivity structure;
- local Jacobian / dominant dynamical mode;
- stable constraint / coupling structure;
- independently measurable order parameter with a specified component relation.

Not sufficient by itself:

- decoding accuracy;
- representational similarity;
- correlation;
- transient activation pattern.

### O3 — target-blind causal mediation

Before a new transfer target is inspected, manipulating O must change a source-native current dynamical or learning property in the predicted direction.

Stronger forms:

~~~text
transplant O -> induces / biases the corresponding dynamical regime;
attenuate O -> weakens that regime;
matched generic perturbation -> does not produce the same directional effect.
~~~

This is the gate that converts O from an informative descriptor into a candidate causal retained organization.

## 4. Re-entry is a fourth, later gate

Only after O1-O3 are frozen should a new target be exposed.

### O4 — prospective re-entry

~~~text
Does the already-admitted O alter later transition / accessibility /
support / inhibition / coordination on a target not used to identify,
select or validate O?
~~~

This preserves GRG-R1 while preventing target outcomes from defining the structure that supposedly explains them.

## 5. Why v0.1 failed under the revised gate

The v0.1 decoder-defined O paid:

~~~text
O1: weak / indirect
O2: no
O3: no
O4: tested and null
~~~

It was target-blind, which was good, but it entered O4 without first paying operator-level retention and source-domain mediation.

The null therefore narrows the programme method:

Decoder-first O admission is too weak.

## 6. Candidate v0.2 O family

Strongest current candidate:

~~~text
operator-embedded dynamical scaffold
~~~

Working realization family:

~~~text
training / interaction history
-> recurrent operator change
-> retained spectral / Jacobian / attractor organization
-> source-domain causal mediation
-> prospective new-target re-entry.
~~~

In RNNs, dominant recurrent eigenmode / eigenspectrum structure is a candidate implementation family.

No fixed k, eigenvalue statistic or threshold is authorized by this audit.

Bowler's four-eigenvalue intervention is a source-native example, not a universal GRG number.

## 7. Generic-damage control must also be revised

v0.1 matched intervention displacement magnitude, but the noise arm caused much larger functional damage.

Therefore:

~~~text
equal hidden-state displacement norm
!= equal functional damage.
~~~

A future pilot should pre-target-match controls on a source-domain competence surface as well as perturbation size.

Candidate control contract:

~~~text
targeted O perturbation
vs
structure-randomized / spectral-control perturbation

matched before target on:
- perturbation rank / parameter distance;
- base-task competence loss within a fixed tolerance;
- gross activity norm / stability;
- intervention timing.
~~~

The target outcome must not be used for matching.

## 8. v0.2 authorization status

~~~text
new v0.2 target run: NOT AUTHORIZED YET
~~~

The v0.1 target has already been inspected and the revised O criterion was generated after the null.

A new transfer test therefore requires:

- a new visible preregistration;
- a new target surface not used to formulate the O rule;
- an O admitted only by O1-O3;
- pre-target functional-damage controls.

Using the same target to tune O would destroy the transfer claim.

## 9. Next bounded task

Do a target-blind O-feasibility pass only.

Question:

Can an operator-embedded dynamical scaffold satisfying O1-O3 be identified and causally manipulated on a source-domain / base-task surface before any new transfer target is chosen?

Preferred route:

1. use Bowler's public eigenspectrum intervention as the source-native positive control;
2. state which parts are already paid by ordinary recurrent dynamics;
3. build a minimal base-only GRG O-admission protocol;
4. require a negative control where decodable but non-mediating structure is rejected;
5. only if O1-O3 pass, freeze a genuinely new target and v0.2 preregistration.
