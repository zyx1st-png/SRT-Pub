# One -> Bearer transition — internal red-team

## 1. Candidate under pressure

Current machine candidate:

```text
ONE
prior Selection-generated vertical result
-> later Selection condition
-> lineage-relative reconstitution
-> renewed operative Selection-position.

BEARER
Selection from that operative position
-> consequence q
-> q becomes history-bearing input to the organization reconstituting
   the same lineage's later operative position
-> future selectability of that lineage changes.
```

The extra Bearer relation is therefore **source-specific consequence return**, not mere persistence or generic historical dependence.

## 2. Case A — externally regenerated persistent pattern

Shape:

```text
a local vertical pattern repeatedly regenerates
because wider-field dynamics preserve / recreate its lineage;
its own local outputs do not materially alter how that lineage is later regenerated.
```

Disposition:

```text
One candidate: YES / possible
Bearer: NOT ESTABLISHED
```

Reason:

```text
continuation recursion is paid;
source-specific consequence return is not.
```

This case is important because it proves Bearer cannot be defined as `more stable One`.

## 3. Case B — ordinary thermostat-like feedback

Shape:

```text
controller output
-> room state changes
-> sensor reading changes
-> controller updates output.
```

The existing PH-CONSC03 patch already treats a thermostat as having local feedback while usually lacking strong history-bearing future-selectability rewrite.

Pressure result:

```text
B-SRC: often YES
B-RET: weak / current-state feedback YES
B-WRITE: usually weak, reversible or absent
strong Bearer: NOT ESTABLISHED FROM FEEDBACK ALONE.
```

Therefore:

```text
feedback signal
!= history-bearing consequence return.
```

A thermostat is not excluded by name. If an adaptive controller acquires durable self-modification that changes its later selectable organization, the case must be re-opened rather than definitionally rejected.

## 4. Case C — adaptive controller with retained self-modification

Shape:

```text
selection / action
-> outcome
-> outcome changes internal or externally scaffolded control organization
-> later selectable policies / transitions change
-> changed organization persists into later operation.
```

Disposition:

```text
Bearer pressure: LIVE / potentially paid.
```

This is intentional.

If SRT's Bearer relation is substrate-neutral, it cannot reserve bearing to biology after a non-biological system pays the same source-return-writeback role.

Therefore the current route is not:

```text
machine -> not Bearer.
```

It is:

```text
pay the relation or do not pay the relation.
```

Scientific distinctiveness is not inferred.

## 5. Case D — living cell / precarious autonomous unit

Mature autonomy / enactivist material already supplies strong pressure through:

```text
self-production;
precarious organization;
viability-sensitive regulation;
consequences of action feeding back into the organism's capacity to continue acting.
```

Disposition:

```text
strong Bearer candidate: YES at the architecture-pressure level;
SRT-local novelty: NO from this fact alone;
phenomenality: OPEN.
```

The useful SRT role is not to deny this neighbor payment but to place the cell-level relation in the same One -> Bearer dependency architecture.

## 6. Case E — resettable / consequence-outsourcing agent

Shape:

```text
agent selects and causes important external effects;
errors / damage / costs are absorbed by environment, operator or replacement instance;
agent can be reset to the same selectable organization without carrying those consequences forward.
```

Disposition:

```text
external causal impact: YES
Selection / execution: possibly YES
One continuation: architecture-dependent
strong Bearer: weakened / NOT ESTABLISHED.
```

Reason:

> large effects do not establish bearing when the alleged bearer need not incorporate their history into its own later reconstitution.

This preserves the non-outsourcing pressure without defining Bearer as biological vulnerability.

## 7. Case F — socially / externally scaffolded history

Shape:

```text
A selects / acts
-> consequence is stored or propagated externally
   (records, commitments, legal relations, social memory, environmental modification)
-> those external structures later modify how A's operative position is reconstituted
-> A's future selectability changes.
```

Disposition:

```text
external carrier: compatible with Bearer
if the consequence remains lineage-conditionally load-bearing for A's later reconstitution.
```

Therefore:

```text
own-history
!= history physically inside the unit.
```

A consequence can be 'A's history' in the relevant causal sense while materially distributed outside A, provided its later re-entry is specifically constitutive of A's continuation / Selection-position reconstruction.

## 8. Case G — memory loss with persistent consequences

A useful conceptual stress case:

```text
an organism or agent does not explicitly remember an event;
physical / social / learned consequences of the event nevertheless alter its later selectable organization.
```

Disposition:

```text
explicit recollection: NOT REQUIRED
history-bearing consequence: still possible.
```

Thus:

```text
own-history
!= conscious memory.
```

This keeps Bearer upstream of cognitive One where appropriate.

## 9. Case H — copied history without borne consequence

Suppose a new system receives a perfect data copy of A's recorded history but did not stand in the source-return relation through which those consequences altered A's continuing organization.

Then:

```text
history content similarity: YES
source-specific consequence bearing: NOT AUTOMATIC.
```

This blocks:

```text
possessing the record of a consequence
=
bearing the consequence.
```

It does not solve strict numerical identity or copying metaphysics.

## 10. The transition is relational, not locational

Red-team result:

```text
One history may be distributed;
Bearer history may also be distributed;
```

so physical storage location cannot define the transition.

The stronger distinction is:

```text
ONE:
which prior vertical relations are causally constitutive of reconstituting this lineage?

BEARER:
which consequences generated from this lineage's own operative Selection
become causally constitutive of reconstituting this lineage's later operative position?
```

The second relation adds **source-indexed return**.

## 11. Counterfactual pressure test

Machine-side conceptual test only:

Hold the wider environment / general continuation support approximately fixed and compare:

```text
R1:
q^A_t is allowed to alter the organization that reconstitutes P^A_(t+1)

R0:
q^A_t is rerouted / washed out / externally absorbed
while other continuation-support conditions are matched as far as possible.
```

If:

```text
P^A_(t+1) / future selectability differs materially between R1 and R0,
```

this supports a source-return relation.

If not, the claim that q was 'borne by A' weakens.

This is not a new experimental authorization and must not revive the retired shuffled-writeback route as a Level-2 programme.

## 12. Why this does not collapse into credit assignment by default

Ordinary credit assignment asks which past actions / states should receive update signal for task performance.

The current Bearer question is different in scope:

```text
which continuing One's operative organization
is actually changed by the consequences of Selections issuing from it,
so that the One must later continue from the altered organization?
```

A reinforcement-learning implementation may realize this relation. If it does, that is implementation / neighbor payment, not a reason to deny the relation.

Therefore:

```text
Bearer relation != unique algorithm;
credit assignment may be one implementation family.
```

## 13. Consequence does not mean only damage / cost

Do not overread `bearing` as punishment.

Relevant consequence can include:

```text
repair;
resource gain / loss;
commitment;
learning;
constraint creation;
new affordance;
reputation;
structural transformation;
irreversible opportunity change.
```

The defining pressure is whether the consequence changes later reconstitution / selectability of the same lineage, not whether it is negative.

## 14. Bearer onset versus Bearer depth

Red-team supports preserving the same logical split used for One:

```text
Bearer onset
= first genuine source-specific consequence-return relation that becomes load-bearing for reconstitution of the same lineage's later operative position;

Bearer depth / stability
= degree, recurrence, robustness, non-outsourcability and temporal reach of that closure.
```

No scalar threshold is authorized.

## 15. Current compact result

```text
One:
RESULT_A -> later CONDITION_A -> renewed P_A

Bearer:
P_A -> Selection_A -> CONSEQUENCE_A
                     ↓
            alters reconstitution of later P_A
```

The Bearer transition is therefore a **closure across two directions**:

```text
past organization -> future position
and
current position -> consequence -> future position.
```

The second direction is the new burden.

## 16. Verdict

```text
persistent pattern test: PASS / distinguishes One from Bearer
thermostat feedback test: PASS provisionally / feedback alone insufficient
adaptive controller: LIVE Bearer pressure / no biology monopoly
living cell: strong neighbor-paid Bearer candidate
resettable outsourced agent: strong negative control
external scaffolding: compatible with Bearer
explicit memory: not required
copied history content: not sufficient
history localization: not revived
credit assignment: possible implementation, not definition
Bearer = subjectivity: NO
canonical edit: NO
new Level: NO
scientific distinctiveness: NOT ESTABLISHED
```

## 17. Next live question

The strongest remaining machine-side pressure is no longer `does consequence return?` in the generic sense.

It is:

> **When does source-specific consequence return become sufficiently integrated with lineage reconstitution that we should say the One itself bears the consequence, rather than merely being one node in a wider causal loop?**

This should be pressured through unit attribution / closure and non-outsourcing without introducing a hidden numerical-identity token.
