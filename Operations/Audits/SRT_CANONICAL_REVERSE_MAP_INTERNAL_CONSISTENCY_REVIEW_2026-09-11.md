# 2. Material omission — `T_dir` intersects D3 S3

## 2.1 D3 S3 from #936

The author-adjudicated D3 live split keeps a separate candidate burden:

```text

```

Its function is to block the inference:

```text
stake exists
-> therefore the unit can read and use stake-relevant differences in its own Selection regulation
```

D3 does **not** establish a completed S3 formalism.

## 2.2 Current `T_dir` role

`_SRT_T_DIR_CANONICAL.md` currently defines a governance-canonical v0 operational proxy:

```text
T_dir
= readability of the system's current selection direction to itself
  × ability for that direction signal to enter reorientation / recalibration
```

This is structurally close to S3.

However, current T_dir also states:

```text
d = 0 -> T_dir = 0
T_dir > 0 -> d > 0 + real Psi_f pressure + integration capacity
```

while current canonical d is subject-conditioned.

## 2.3 Hidden circularity if S3 is silently identified with T_dir

If future landing were to write:

```text
S3 = T_dir > 0
```

and use S3 to establish subject-position, the current dependency chain would become:

```text
subject-position requires S3
S3 identified with T_dir
a current T_dir gate requires d > 0
current d uses subject utility / subject closure
therefore subject-position is presupposed inside a gate used to establish subject-position
```

That is circular.

### Current disposition

```text
S3 = T_dir: IDENTITY NOT ESTABLISHED
T_dir as direct subject-admission gate: NOT CURRENTLY SAFE
T_dir as downstream operational proxy for already-admitted subject-level regulative readability: LIVE CANDIDATE
```

A later author decision could instead revise the d/T_dir dependency, but #936 did not authorize that.

## 2.4 Reverse-map addition

`_SRT_T_DIR_CANONICAL.md` must therefore be added to the D3 / subject-transition blast radius.

Likely future treatment:

```text
T_dir core operational role: RETAIN
S3 relation: OPEN / crosswalk required
current d > 0 prerequisite if T_dir is used upstream of subjecthood: REWRITE / guard
old order-direction metaphysical prose: separate existing debt; not automatically part of D3 landing
```

Do not broaden the next landing PR into a full T_dir rewrite unless the S3 crosswalk requires it.
