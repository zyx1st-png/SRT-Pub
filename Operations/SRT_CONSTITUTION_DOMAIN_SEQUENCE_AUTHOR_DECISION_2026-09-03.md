## 3. Neuroscience reopening rule

The first Neuroscience result remains fixed as a historical/evidence record:

```text
strongest-baseline verdict = Case B
exact-charter DATA-ACCESS-0 = NO-GO
confirmatory execution = not started
Phase 9 disposition = translation-only + scope-limited
```

“Not permanently frozen” means that future work may reopen Neuroscience in one of three ways:

### N-R1 — exact-charter access reopening

A qualifying public dataset or documented collaborator / clinical route supplies the original PRE-relation, relation-history, common-probe and rich present-state requirements.

Then the existing charter may continue into its next gated phase without rewriting the original Phase-8A verdict.

### N-R2 — stronger differential reopening

New domain evidence, a materially stronger rival comparison, or a newly identified measurable contrast creates a sharper Case-C candidate **for the same underlying relational-history problem**.

This requires a visible addendum / versioned successor stating:

```text
what changed since the first audit
why the old Case-B verdict remains historically correct
what new discriminator now exists
what new falsifier / withdrawal condition applies
```

### N-R3 — successor-question reopening

A different but genuinely stronger neuroscience question may later be opened if it cannot be answered by silently weakening the old question to fit convenient data.

It requires a new author-visible charter and may not inherit a positive result, novelty credit or evidence standing from the first pass.

### Reopening prohibitions

```text
deleting or rewriting the first adverse result
calling a weaker dataset an execution of the old exact charter
changing outcome / timescale / system after seeing convenient data while preserving the old question label
using Epistemology or Consciousness results as neuroscience evidence
running a large parallel neuroscience programme merely because reopening is allowed
```

The default remains sequential focus on the active Epistemology well. Reopening is conditional and bounded, not permanent parallel authorization.
