# W1 / W2 writeback audit labels

> **Role**: owner of the `W1` / `W2` retrospective writeback-depth labels used in
> machine audits. These are **classification and checking tools**, not ontology
> primitives: nothing here defines Selection, One, Selection-position, Bearer or
> any canonical object, and no canonical surface may be derived from a W1/W2
> assignment.
>
> **Claim status**: `claim_mode: machine`, `canonical: false`. A W1 or W2 label is
> an audit reading of a described mechanism, never a theory claim about it.

## Why this file exists — the 一进一出 it pays

Until 2026-09-13 the only live surface defining these labels was `STATUS.md §14`,
a dashboard whose own §20 states it is routing / programme state and **not a
definition authority**. The typology therefore had no owner while the dashboard
acted as one.

`01_Source_Intuition/SRT_AUTHOR_ADJUDICATION_OPEN_REGISTER_OWNERSHIP_2026-09-13.md` §A3,
recorded in `Operations/Audits/SRT_OPEN_REGISTER_OWNERSHIP_ADJUDICATION_2026-09-13.md`,
adjudicated that W1/W2 leave `STATUS.md` without being promoted into Spine
canonical, and land here as a noncanonical machine/audit taxonomy owner.

`Governance/README.md` 治理比例原则 4 —「导航一进一出」— requires a new entry to
merge, retire or repurpose an old one. **The entry retired here is `STATUS.md
§14`'s de-facto ownership of the typology**: that section now carries a pointer
to this file and no longer defines the labels. This file is the 一进; that
retirement is the 一出. `STATUS.md` is therefore recorded above as the labels'
**historical source, not a runtime dependency**: a file that has just taken
ownership away from the dashboard must not then depend on it.

## The labels

```text
W1 configuration writeback
= change under broadly preserved later-selectability organization.

W2 organizational writeback
= change in relations that generate, admit, suppress, reach,
bound or reconstitute later continuations.
```

## Representation-invariance guard

```text
W1/W2 follow causal / organizational role,
not whether a model calls the variable state / parameter / weight / structure.
```

A model's vocabulary — "state", "parameter", "weight", "structure" — does not fix
the label. The organizational role does.

## Hard limits

```text
W2 != Bearer
W2 does not decide Bearer by itself;
a W1/W2 assignment establishes no Selection-position, One, standing,
subjecthood or claim level;
these labels are retrospective audit readings, not admission gates.
```

## OPEN

Carried here from `STATUS.md §OPEN register` (item S17) by the 2026-09-13
ownership adjudication, unchanged and **not closed**:

```text
formal / empirical representation-invariant W1/W2 criteria = OPEN
```

The guard above states that the labels *should* follow causal / organizational
role rather than model vocabulary. What remains open is a criterion that makes
that representation-invariance formally or empirically checkable, rather than a
reading applied case by case.
