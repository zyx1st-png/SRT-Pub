# Part B — Def-IRR reconstruction

## 5. Def-IRR-1 — absorbing regime

Delete the universal theorem form:

```text
for any ISP, the Selection space contains an absorbing-state structure
```

Replace with a declared-model definition:

```text
A set A_dagger is absorbing only relative to a declared transition relation/kernel,
environment, lineage identity criterion, reset policy and horizon,
when exit from A_dagger is excluded under those declared conditions.
```

Keep the narrow constitutive remainder:

```text
if the same realized history reaches a state with no continuation available to that history,
that history does not itself generate a later continuation from that terminated state.
```

Hard guard:

```text
same-history cessation
!= proof that no external reset / new event / new lineage / reconstruction can occur
```

`A_t = empty` may be used only after the model states what `A_t`, continuity and lineage identity mean.

---

## 6. Def-IRR-2 — occurrence asymmetry vs historical efficacy

Replace the current universal future-constraint wording with a two-level distinction.

Required core:

```text
Occurrence asymmetry:
  an actual past Selection cannot later become ontically identical to never-occurrence.

Historical efficacy:
  when effects of that Selection remain materially effective in later Selection conditions,
  the later process is historically constrained by it.
```

Explicitly state:

```text
Selection occurrence -/> retained later constraint
Selection occurrence -/> readable trace
Selection occurrence -/> durable local memory
```

Parametric time may order events without proving durable ontological memory.

---

## 7. Def-IRR-3 — no retroactive erasure, not universal residue

Replace:

```text
no operation can return historical consequences to zero
```

with:

```text
no later Selection retroactively makes an earlier occurred Selection equal to never-occurrence.
```

Then separate possible downstream outcomes:

```text
later causal effect may decay;
active burden may be compensated;
local trace may disappear;
a model may return to an observationally/functionally equivalent state;
path dependence may remain or vanish depending on declared dynamics.
```

None of these possibilities erase the past occurrence itself.
