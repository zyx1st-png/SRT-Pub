# Selection → vertical structure → One / Selection-position — lineage reconstruction

> **Role:** provisional C-layer reconstruction after author convergence on the direction that `One` can correspond to vertical structure. This file organizes the dependency without changing canonical definitions, assigning a new Level, or claiming scientific distinctiveness.

## 1. Root problem

The current workline has converged on two author-controlled constraints:

```text
Selection
-> actively constructs / maintains / anticipates a non-flat selectable space;

One
<-> vertical structure
(author correspondence direction; exact relation still requires reconstruction).
```

The main burden is to avoid two collapses at once:

```text
all verticalization = One
```

and

```text
One must pre-exist Selection in order for Selection to have a position.
```

The candidate solution is a bootstrap plus recursion architecture.

## 2. Bootstrap — Selection before One

Primitive Selection does not require a pre-existing chooser, One, Bearer, or Selection-position.

Working shape:

```text
minimum non-neutrality / pre-object difference
-> subjectless Selection
-> manifestation + relative backgrounding
-> event-level verticalization.
```

At this stage:

```text
verticality: YES
ontological One: NOT YET REQUIRED
Selection-position: NOT YET REQUIRED
Bearer: NOT YET REQUIRED
subject: NOT YET REQUIRED.
```

This preserves the occurrence / persistence boundary: a determinate event can be actual without already being a persistent object or stable ISP.

## 3. Three vertical states — routing labels only

The reconstruction distinguishes three analytic states without creating new canonical levels:

```text
V-EVENT
one Selection creates a local non-flat manifest/background relation;

V-REENTRY
earlier vertical organization materially re-enters later Selection conditions;

V-LINEAGE
later vertical organization is Selection-mediated reconstitution of an already-established vertical history rather than an unrelated new occurrence or externally regenerated look-alike.
```

The transition of interest is:

```text
V-EVENT
-> V-REENTRY
-> V-LINEAGE.
```

These labels are audit aids, not ontology primitives.

## 4. Candidate One relation

The strongest current machine reconstruction is:

> **Ontological One is a Selection-generated vertical organization whose prior vertical history continues to participate in later Selection-mediated reconstitution, so later changes are indexed to that continuing lineage rather than treated as independent events.**

Compact shorthand:

```text
One ~= lineage-indexed vertical organization
```

This shorthand is deliberately weaker than strict numerical identity and stronger than recurrence, similarity, path dependence, or durable structure.

### 4.1 Logical direction

Current candidate:

```text
One
=> vertical organization
```

but not:

```text
vertical organization
=> One.
```

The additional diachronic burden is lineage-indexed reconstitution.

## 5. Why this is not circular

Bad circular form:

```text
One
-> Selection from a position
-> vertical structure
-> One.
```

Candidate non-circular form:

```text
BOOTSTRAP
minimum non-neutrality
-> subjectless Selection
-> verticalization

GENESIS
repeated Selection + historical re-entry
-> vertical organization
-> lineage-indexed reconstitution
-> One / Selection-position

RECURSION
formed One / Selection-position
-> later Selection proceeds from that position
-> later Selection can maintain or reconstruct vertical organization.
```

The first Selection therefore does not borrow a completed One from the future.

## 6. One / Selection-position as two faces of one structure

The current synthesis does not require two separate formation mechanisms.

```text
lineage-indexed vertical organization
             /                 \
            /                   \
 continuation reading       operative reading
        One                Selection-position
```

Working distinction:

```text
One:
what is continuing?

Selection-position:
from where can later Selection continue?
```

This is a C-layer repartition, not an authorized canonical identity statement.

## 7. Bearer remains downstream and distinct

Existing bearer reconstruction provides a useful separation:

```text
One / Selection-position problem:
why can later Selection continue from here?

Bearer problem:
where do consequences return,
and do those consequences alter how the later here is reconstituted?
```

Candidate chain:

```text
lineage-indexed vertical organization
-> One / Selection-position

+

consequence return to the relevant organization
-> borne history materially changes next-position reconstitution
-> stronger Bearer candidate.
```

Therefore:

```text
One != Bearer automatically
Selection-position != Bearer automatically.
```

## 8. Continuation is not invariance, autonomy, or an attractor

The current reconstruction explicitly rejects these substitutions:

```text
continuation
!= same snapshot
!= same components
!= same function
!= stable attractor
!= path dependence alone
!= self-maintenance alone
!= analyst-drawn boundary persistence
!= pure internal causation.
```

A One may undergo major internal change and still continue if the prior vertical lineage participates in the later reconstitution.

A One may also depend strongly on external support, recognition, legal structures, caregivers, environments, or other participants. The necessary distinction is not internal versus external cause but:

```text
continuation
vs
replacement / independent regeneration.
```

## 9. Lineage-relative boundary

The earlier phrase `endogenous continuation boundary` is too strong and is retired in this reconstruction.

Use instead:

```text
lineage-relative continuation boundary
```

Meaning:

> The relevant difference is whether a change can still be constituted as a Selection-mediated reconstitution of this prior vertical lineage, versus dissolution, replacement, or branching of that lineage.

This boundary can be materially supported by internal and external processes together.

## 10. Center / edge reconstruction

The center–edge / lateral-inhibition intuition can now be restated without literal neural mechanism import:

```text
Selection
-> some continuations become more re-enterable / supportable
-> incompatible continuations become relatively backgrounded / suppressed
-> repeated Selection differentiates continuation-compatible from lineage-breaking directions
-> a lineage-relative continuation boundary can emerge.
```

Important guards:

```text
background != annihilation;
relative suppression != winner-take-all;
center != a pre-existing entity;
edge != non-being;
neural lateral inhibition != universal ontological implementation.
```

## 11. Active / passive Selection through the vertical object

Once a One / Selection-position exists, the existing active/passive author distinction can be organized around the same vertical structure:

```text
PASSIVE orientation:
Selection operates mainly within an achieved vertical continuation organization and preserves current One viability / survival.

ACTIVE orientation:
Selection acts on the organization determining later selectability itself — including what continuations remain enterable, how boundaries can be revised, and which backgrounded possibilities can be reopened.
```

Thus identity need not mean resistance to change. A stronger candidate is:

```text
identity
= lineage-preserving reconstitution through change
```

without making generative reselectability a necessary condition of every One.

## 12. Cognitive One — recursive support, not universal prerequisite

Earlier author material says cognitive One can serve and participate in determining ontological One. The current bootstrap shows why that cannot safely be universalized into:

```text
all ontological One
= prior cognitive One sediment.
```

Current reconciled reading:

```text
pre-cognitive / subjectless route:
Selection can generate vertical organization and ontological One without prior cognition.

post-cognitive route:
cognitive objectification / boundary marking / naming / recognition / anticipation
can enter later Selection conditions,
preserve or route lineage information,
and thereby materially participate in ontological One continuation or reconstruction.
```

This is a reconciliation proposal, not a silent rewrite of the earlier author sentence.

## 13. Multi-position extension

For already-formed Ones / Selection-positions `A` and `B`:

```text
Selection_A + Selection_B
-> relation-level vertical organization V_AB.
```

If participant Selection can jointly maintain / modify / reopen the future selectable conditions organized by `V_AB`, this supports the current JFS candidate:

```text
JFS
= joint reconstruction of relation-level future selectability.
```

But:

```text
JFS
!= higher-order One automatically.
```

A higher-order One requires the additional lineage burden:

```text
V_AB(t)
materially participates in Selection-mediated reconstitution of V_AB(t+1)
so later changes become changes of the same relational lineage.
```

Therefore JFS and One-formation are orthogonal dimensions that can reinforce one another without logical entailment.

## 14. Higher-order One versus collective ISP

Current routing:

```text
relation-level vertical organization
-> joint active reconstruction where applicable
-> multi-subject order

+

relation-level lineage-indexed reconstitution
-> higher-order ontological One candidate

+

separate P1-T06 / T-COLL-1 perspective, history, consequence and continued-selectability standing conditions
-> collective ISP where the existing owner admits it.
```

Do not use relation-level One formation to bypass T-COLL-1.

## 15. Cross-layer Selection invariant — candidate integration with route A

The working cross-layer identity remains operation-level rather than mechanism-level:

> **Selection makes non-equivalent potential relations undergo asymmetric actualisation, co-generating relative manifestation and background while leaving effective historical difference that conditions later Selection.**

Across layers, what changes is not necessarily the minimum operation but the conditioning organization:

```text
pre-One:
minimum non-neutrality conditions Selection;

post-One:
lineage-indexed vertical position conditions Selection;

multi-position:
relation-level vertical organization additionally conditions participant Selection.
```

This gives a bootstrap plus recursion rather than a family-resemblance-only reading.
