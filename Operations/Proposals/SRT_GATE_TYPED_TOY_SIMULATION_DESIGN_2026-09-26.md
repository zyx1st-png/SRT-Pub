# Typed Gate toy simulation — pre-experimental discriminator design

> Purpose: build the smallest simulation in which Formation -> Closure -> Composition can be tested without presupposing object labels in the learner, while comparing against strong mature alternative models. This is a design only; no execution is authorized by this file.

## 0. Core question

> **Can an actively learned bridge architecture produce reusable relational properties, richer object closure and cross-closure field effects that are not exhausted by a fair action-conditioned latent-state / object-file model?**

The simulation is not intended to prove SRT.

It is intended to decide whether the current Gate architecture has any nontrivial modeling payoff at all.

Zero incremental gain is an allowed and important result.

---

## 1. Environment — physical loci exist, object labels do not

The environment may contain persistent physical sources for simulation control.

The learner is NOT given:
- source identity;
- object label;
- property label;
- graspability flag;
- category;
- global state inventory.

Each physical source can generate changing local observations under:
- viewpoint / orientation;
- distance;
- partial occlusion;
- contact;
- movement;
- hand / effector configuration.

The simulator knows the ground truth only for evaluation.

---

## 2. Minimal sensorimotor variables

At each step the learner receives only a bounded observation tuple such as:

~~~text
visual local descriptors
+ proprioceptive / hand configuration
+ contact / resistance feedback if contact occurs
+ current action / perturbation
+ immediate next observation
~~~

Actions:
- approach;
- retreat;
- rotate viewpoint / source;
- open / close effector;
- apply force;
- lift;
- release.

No action is named 'grasp'.

---

## 3. Ground-truth relational affordance

Define grasp success relationally in the simulator.

Example hidden rule family:

~~~text
success depends jointly on:
source extent / orientation
+ effector aperture
+ contact alignment
+ force / friction conditions
~~~

So:

~~~text
same source
can be graspable in one body configuration
and not graspable in another.
~~~

This prevents 'graspable' from being a fixed intrinsic feature.

---

## 4. Training regimes — active vs matched exposure

### R-ACTIVE

The learner chooses perturbations / actions and therefore influences which transitions it experiences.

### R-YOKED

A passive learner receives the same sensory sequence generated by an active learner but does not control the action that produced it.

### R-RANDOM

Actions are sampled without information-seeking or task-sensitive selection.

The active-formation claim predicts that:

~~~text
active control of transition sampling
can change bridge quality
even under matched observation exposure.
~~~

Important:

This effect is already mature-neighbor plausible; it is not by itself an SRT-specific prediction.

---

## 5. Model family B0 — static feature baseline

Input:
- current observation;
- current body configuration;

Output:
- action success / next label / candidate action score.

No explicit action-conditioned transition structure.

This is a weak baseline and cannot carry the main verdict.

---

## 6. Model family B1 — strong action-conditioned latent-state / world model

Input:
- observation history;
- action history;
- body state;

Learn:
- latent state z_t;
- action-conditioned transition p(z_t+1 | z_t, a_t);
- observation decoder;
- policy / outcome predictor.

B1 is allowed to learn:
- continuous latent geometry;
- context;
- memory;
- nonlinear dynamics;
- history dependence.

This is a strong absorber of bridge language.

Critical rule:

> **If B1 reproduces all bridge / closure / field predictions with equal or better compression, transfer and intervention performance, Gate adds zero modeling increment.**

---

## 7. Model family B2 — object-file / slot + action transition baseline

B2 is allowed:
- thin persistent slots / indices;
- feature binding;
- action-conditioned updating;
- occlusion tracking;
- learned properties;
- slot re-identification.

This is the strongest direct absorber of the object-closure proposal.

Critical rule:

> If B2 explains reciprocal index–bridge stabilization and re-entry without any additional Gate structure, object-closure language is translation only.

---

## 8. Model family G — typed Gate candidate

G is explicitly factorized into:

~~~text
Form
-> learns reusable action-conditioned bridges

Close
-> learns reciprocal support between thin index and bridge cluster

Compose
-> learns compatibility / competition / nesting among closures
~~~

G is not allowed a hidden oracle object ID.

G may maintain local latent variables if learned from interaction.

The point is not 'no latent representation'.

The point is whether the typed factorization yields nontrivial prediction / control / transfer advantages or clearer intervention structure.

---

## 9. Phase S1 — bridge / property test

Train on only a subset of:
- viewpoints;
- effector apertures;
- approach directions;
- friction levels.

Held-out test:
- novel combinations;
- novel viewpoint-action pairings;
- same visual source with changed body capability;
- same body capability with changed source geometry.

Metrics:

### S1-M1 transfer
Success prediction on held-out relational combinations.

### S1-M2 prospective control
Can the model choose an action before full execution using learned relation?

### S1-M3 perturbation envelope
Does it know when the learned relation should fail?

### S1-M4 counterfactual ablation
Does removing the learned bridge change later candidate selection?

Property-candidate criterion:

~~~text
reusable across trajectories
+ prospective
+ perturbation-bounded
+ future-effective
~~~

---

## 10. Phase S2 — thin index / rich closure test

Add multiple bridge families around persistent physical loci:
- grasp / release;
- viewpoint transformation;
- common motion;
- resistance / weight;
- occlusion / reappearance.

Still do not give learner object identity.

Tests:

### S2-M1 co-reinstantiation
Does partial evidence recover multiple bridge expectations?

### S2-M2 reverse recovery
Can bridge pattern help recover the correct thin index after ambiguity?

### S2-M3 joint perturbation
Does one source perturbation update several bridge predictions coherently?

### S2-M4 re-entry
Can the system recover a closure after interruption without relearning?

### S2-M5 compression
Does one closure representation reduce description / prediction cost versus independent bridges?

---

## 11. Phase S3 — transparency / givenness proxy

Do NOT claim phenomenological givenness from a simulation.

Use functional proxies only:
- fewer online inference steps;
- faster closure reinstatement;
- reduced prediction error under ordinary perturbation;
- lower recomputation cost;
- direct action readiness from partial cue.

Transparency proxy:

~~~text
mature closure
requires less online reconstruction
while preserving successful control.
~~~

Failure / anomaly should increase:
- bridge-specific error;
- recomputation;
- exploratory action;
- closure revision.

---

## 12. Phase S4 — whole-field composition test

Introduce at least two closures sharing resources.

Example:

~~~text
closure C_water
= locate / grasp / lift source A

closure C_tool
= locate / manipulate source B

shared resource
= one effector / limited attention / incompatible posture
~~~

Add high-level goals that change which closure matters.

Tests:

### S4-M1 structured competition
Can the model predict which closure suppresses / delays another?

### S4-M2 goal propagation
Does a high-level target change several lower bridge priorities coherently?

### S4-M3 common perturbation
Does a body-state / context perturbation reorganize multiple closures at once?

### S4-M4 nested compression
Can a higher task closure guide lower behavior without encoding all microsteps?

### S4-M5 recursive learning
Does current whole-field configuration change what new bridges are sampled / retained?

S4-M5 is the strongest current discriminator.

---

## 13. Local future-selectability measurement

For each model and phase, define a bounded probe family Q_t of candidate next actions / transitions.

Estimate:

~~~text
A_t(q)
= local model-derived availability / preference / support for q
~~~

Then compare before / after learning or intervention:

~~~text
Delta_A(q)
= A_after(q) - A_before(q)
~~~

No canonical interpretation is licensed.

The only question is:

> did the learned structure actually change later selectability?

---

## 14. Critical matched comparisons

### Test T1 — active control vs matched sensory exposure

R-ACTIVE vs R-YOKED with identical observation stream.

Question:
does control of the transition matter beyond data volume?

### Test T2 — bridge factorization vs strong world model

G vs B1.

Question:
does typed bridge structure improve transfer / intervention / compression?

### Test T3 — reciprocal closure vs strong object-file baseline

G vs B2.

Question:
does explicit bridge-index reciprocity add measurable work?

### Test T4 — field composition vs independent closure policies

Full G vs version where closures do not interact except through final action arbitration.

Question:
does whole-field topology predict cross-closure propagation / recursive learning?

---

## 15. Strong stop-loss / zero-gain rules

### Z1
If B1 matches G on S1–S4, Gate is a translation / factorization, not a scientific increment.

### Z2
If B2 matches reciprocal closure / re-entry, object-level Gate adds no independent mechanism.

### Z3
If R-ACTIVE and R-YOKED match after controlling action labels / efference information, active formation is narrower than proposed.

### Z4
If Compose adds no held-out prediction or intervention propagation, whole-field language is decorative.

### Z5
If Delta_A can be fully predicted from ordinary policy probabilities with no additional explanatory gain, future-selectability language is bookkeeping only.

### Z6
If a single end-to-end latent model compresses the full process better without losing intervention clarity, retain SRT language only as interpretation.

---

## 16. Positive result must be stronger than model fit

A positive Gate result should require a package:

~~~text
held-out transfer
+ intervention localization
+ recursive learning prediction
+ cross-level compression
+ failure-mode specificity
~~~

Not merely:

~~~text
lower loss on one benchmark.
~~~

---

## 17. What this simulation can and cannot establish

Can test:
- whether typed Form / Close / Compose is coherent;
- whether active transition control changes learned structure;
- whether property-like relations can be learned without labels;
- whether reciprocal closure has modeling payoff;
- whether cross-closure topology changes later learning / action.

Cannot establish:
- primitive Selection;
- L0 ontology;
- consciousness;
- qualia;
- Bearer necessity;
- real neural implementation;
- metaphysical novelty.

---

## 18. Current recommendation

Do not yet preregister a human experiment.

First implement this toy simulation as a falsification tool for the typed architecture.

Preferred execution order:

~~~text
S1 bridge/property
-> S2 closure
-> S4 composition
-> only then S3 transparency proxy if needed
~~~

Reason:

S3 is mostly a consequence of successful closure and can become cosmetic if tested too early.
