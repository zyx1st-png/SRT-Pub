**一条术语护栏（先立后用）**：`AQ-2` 的「无中生有」在本 programme 内一律读作 **非预成**（non-preformation）——不是从预先完成的候选菜单中挑选，也不是字面的从虚无中无约束创生。P0-01 的「在真实约束下」与 PC-A（potential non-exhaustion / non-preformation）已经拥有这个边界。任何 workline 若允许对手通过打败「字面无中生有」获胜，按 target laundering 作废。

## 1. 偏移诊断（结论，证据从略）

当前 rebase（#860 家族）相对作者纲领有三处偏移：

1. **目标替换**：Articulation Packet §15 的「D-A pending audit」（待审计的推荐）被 Master Plan §0 写成了默认结论（"更可能是依赖传播与减法程序"）；Stage B/C（减法与外审）被当成了整个纲领，Stage D/E 不在完成条件内。
2. **问题类型错位**：AQ-1 至 AQ-6 是**建构问题**（一是怎么出现的），现行 gate 全部服务于**归属问题**（我们关于一的说法新不新）。Topic Protocol 的 lexicographic 排序使「不新」自动等于「无价值」，而 AQ-6 的「通过清晰化解决」的价值恰恰不依赖新颖性。
3. **一个无主问题**：AQ-3（一的出现伴随着什么）在现行 R2 全家（R2-DOWN-O / R2-DOWN-B / R2-UP-NAT / R2-UP-PHEN / R2-CORE）中没有任何 workline 认领。`SRT_SELECTION_ARTICULATION_OWNER_SUBTRACTION_2026-08-28.md §1` 结尾已经写出了这个残余问题（「确定显明区分」是否已蕴含 one/many/boundary/relation 在操作粒度上非原初），但 Owner Matrix 中无对应行。

同时确认三样**必须保留**的东西（它们在保护作者方向，不是偏移）：

- G2/G3 + P0-04：非菜单读法为 P0 默认；不许把「一的出现」偷换成「有个先在者在生」。
- 承重者预审计 §2.1 的三个非法删除靶（WRONG-1/2/3）与 target-laundering 作废规则。
- G8 / HP-B-B：`B_s != B_p`；不许用承重者结果直接推现象性——这保护的是「通过清晰化解决」而不是「通过混淆解决」。

## 3. 建构 worklines（W1–W5，与 AQ 逐条对应）

以下 workline 均为 read-only / documentation-first；任何 owner 编辑仍走 Freeze / Edit Protocol / B1 预算，本文件不预授权。

### W1 — 一之出现（owner：AQ-1 + AQ-2）

**主问题**：

> P0-01 的「非对象化潜能，在真实约束下，获得确定的显明区分」，是否已经在措辞层面蕴含：one / many / boundary / relation 在操作粒度上不是原初给定，而是随显明区分一同变得确定？若已蕴含，写出蕴含论证；若未蕴含，写出缺失的那一步是 P1 定理、P2 解释还是新负担。

这正是 owner subtraction §1 结尾的无主残余问题，本 workline 将其正式认领。

**输入**：`Core/SRT_Core_21_Minimal_Axioms.md` P0-01/AM-A、`Core_Law/SRT_L0_Metaphysics.md`、PC-A 裁决、Articulation Packet §4.1–4.2。

**允许结局**：

```text
ENTAILED       已蕴含；产出蕴含论证 + P1/P2 解释层落点建议
ADDITIONAL     未蕴含；缺失步骤被类型化（定理 / 解释 / 桥 / 新负担）
UNRESOLVED     写明卡在哪一步
```

**护栏**：不注册新原初；不把 `articulation` 升格为 canonical 术语；「无中生有」按 §0 术语护栏读。W1 的问法与 G6 的关系见 A2。

### W2 — 一之伴随（owner：AQ-3）

**主问题**：

> 一次原初显明发生时，**同一个事件里**还有什么被一并固定？候选清单：有效区分的集合、边界、关系、粒度、什么算一什么算多、以及**被排开者**的地位。

**关键挂靠**：承重者预审计的 **T2（被排开者继续施力：阴影 / 张力 / 后续摩擦三模式 + 场景选择子集的解离预测）就是 AQ-3 的经验面**——「一的出现伴随着什么」的第一个可检验答案是「伴随着被排开者以三种可分离模式继续受力」。T2 因此从「§13 原初有用性的候选证据」重新挂靠为「W2 的执行目标」，其 A0 天花板（NOT-R-ATTRIBUTABLE / 中层包目标）照录不改——**挂靠变了，纪律没变**。

**允许结局**：伴随清单（每项标注：owner 已有 / P1-P2 候选 / 开放）+ T2 执行的冻结规格。

### W3 — 一之动力学（owner：AQ-4）

**主任务**：把 `SRT_SELECTION_FIRST_DERIVATIONAL_SPINE_TRIAGE_2026-08-28.md §8` 的重述从「可接受的退路」升格为**正面章程**，并写成带类型的承诺表：

> Selection-first 固定本体地板与顺序；历史不对称、持存、个体化、承重者准入、主体形成各需**额外的、有类型的结构承诺**，每根柱子（P0-03、Stable ISP 判据、P2/P3 桥假设……）显式记账：它立在哪、凭什么、与原初者是共同准入还是派生。

C2/C3b/C4 的否定结果在此**不是失败，而是承诺表的输入**：它们指明哪些箭头不是免费的。产出物 = spine triage §7 那张「每个箭头标注 primitive co-admission / constitutive theorem / canonical interpretation / bridge hypothesis / source intuition / genuinely missing」的完整表。

### W4 — 多种一的划分（owner：AQ-5）

**主命题（整体评估，不再三线分跑）**：

> 同一个生成机制（历史条件化的再选择 / historically conditioned reselection）生成三种互不可推的一——「还是这个」（对象之一）、「从这里继续」（位置/承重之一）、「for me」（现象之一）——并且每一对之间的不可推关系可被显式陈述。

**评估方式**：作为**一个** N2（dependency-architecture residual）候选进入 Gate 2，问题是「有无现成理论用同一机制同时给出这三种一并说明其互不可推」，而不是三条线各自问「这一种一我们新吗」。R2-DOWN-O、R2-DOWN-B、R2-UP-PHEN 降为 W4 的三个组件审计，其既有护栏（G11 no-bootstrap、Unit-Binding Gate、HP-B-B）逐条继承。

**σ 的位置**：#863 的三探针结论（换坐标读数变 / 归属规则缺失 / 来源份额≠控制份额）在 W4 内消化——σ 定位为四条件的**指示灯**候选而非划分**判据**；划分判据回到各个一自己的准入条件。这与已批准的 S+R 姿态相容，并为 B1-1 的修改幅度提供上界。

### W5 — 一之清晰化解题（owner：AQ-6）

**主任务**：建一张**问题变换表**——每个传统问题一行：

```text
传统问题            | 它实际在问哪种一        | 清晰化后问题变成什么
--------------------+------------------------+---------------------------------
意识难题            | for me 之一            | 「from here → for me 缺哪座桥」（保持开放，但被定位）
人格同一/裂变       | 还是这个 vs 从这里继续  | 两种一被混问；分开后各自可答或各自开放
意识统一性          | for me 之一的边界      | ……
心物问题            | 对象之一 vs 现象之一    | ……
自由意志（既有 index）| 从这里继续之一的动力学  | ……
```

**成功判据**：`CLARIFY-A`（见 A4）——问题被**变换**（可提出 / 可形式化 / 可判定为无意义），不要求被解决，更不要求新颖。R2-UP-PHEN 的问法由「还需要加什么」改为「意识难题在问哪种一、缺的桥的两端各是什么」；有界 no-go 仍是允许结局，但必须携带（1）结构资源穷举清单、（2）明确蕴含目标、（3）反转条件「若 X 成立则本 no-go 失效」，否则不得记为成功结局。
