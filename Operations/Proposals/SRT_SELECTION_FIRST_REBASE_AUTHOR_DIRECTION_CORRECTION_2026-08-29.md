# Selection-First Rebase — 作者方向修正案：裁决记录

> **Status:** 作者已于 2026-08-29 裁决：原修正案提出的“在既有 subtraction / novelty / A0 框架内增加 W1–W5”的纠偏仍然不够彻底。当前 programme 正式改为 **constructive-first / philosophy-first**。
>
> 新的执行 authority：
>
> `Operations/Proposals/SRT_SELECTION_FIRST_CONSTRUCTIVE_ONTOLOGY_REBASE_MASTER_PLAN_2026-08-29.md`

---

## 1. 作者最终方向

作者明确：

> 当前重构防守味过重，缺少主动构建性。SRT 的目标不是寻找细分领域的最小新异性后发论文，而是构建统一的本体论。因此顺序应当改为：**先做加法，再做减法；加法先完成哲学上的构建，不急于形式化，也不把新颖性审计作为思考许可。**

这条裁决取代本文件旧版 A1–A7 / W1–W5 的逐项 author-decision pending 结构。

---

## 2. 为什么旧版修正仍然不够

旧版虽然发现当前 programme 从构建偏向了 subtraction，但它仍然把 constructive workline 装在以下旧逻辑里：

```text
A0 derivability
owner subtraction
T2 execution priority
N2 residual
Gate 2 novelty
CLARIFY-A publication routing
```

这仍然是“审计框架里的建构”。

作者裁决后的新原则是：

```text
constructive philosophy first
-> internal architecture second
-> owner/prior-art subtraction third
-> canonical hardening fourth
-> formalization fifth
-> D2/D3 sixth
-> publication/venue last
```

---

## 4. 旧版问题的重新路由

旧版 AQ-1 至 AQ-6 不删除，而被吸收进新的统一 Constructive Ontology Pass：

```text
AQ-1/AQ-2 -> potentiality -> actuality -> One
AQ-3      -> distinction / boundary / relation / exclusion co-determination
AQ-4      -> history / recurrence / object / bearer / subject dynamics
AQ-5      -> still-this / from-here / for-me 等 unity burdens
AQ-6      -> problem-transformation table + phenomenality positive bridge search
```

旧版“W1 一个结果直接决定 D-A/B/C”作废。P0 是否需要修改只能在哲学草稿、内部 dependency map 与 subtraction pass 完成后由作者裁决。

旧版“T2 first”作废。T2 保留为未来可能的局部经验/结构测试，但不再组织本体论重构顺序。

旧版“W4 作为 N2 候选先进入 Gate 2”作废。多种 One 的统一生成关系先作为哲学候选完整展开，之后再做 prior-art / novelty QA。
