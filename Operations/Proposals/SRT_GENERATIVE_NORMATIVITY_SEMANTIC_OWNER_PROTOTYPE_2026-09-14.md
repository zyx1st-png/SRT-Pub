# Prototype semantic owner — generative normativity / constitutive relation

> **Status:** noncanonical semantic-owner prototype. It does not define current SRT canon, add an ontology layer, assign a P-level, or authorize canonical edits.

---

## 0. Intended owner scope

This proposed owner would carry only the semantic relations needed to distinguish:

```text
position-relative better / worse;
cross-position generative relation quality;
participant-status consistency;
generative substitution / objectification;
constitutive ought at the relation-integrity level;
partial-order dominance;
O2-C / O2-A / O2-M routing.
```

It would **not** redefine:

```text
Selection;
L0;
One / Selection-position;
Stable ISP;
Bearer;
Concern / d;
Agency;
Responsibility;
collective ISP;
T_dir;
moral standing;
full ethics.
```

---

# 1. Admission objects are independently typed

Normative language may enter only after the relevant structural objects are independently specified.

For any comparison, declare at minimum:

```text
X = the formed position / relation being indexed;
R = the independently described generative relation or capacity under comparison;
H = the horizon / perturbation / scope over which the comparison is made;
T = the transition or trajectory being evaluated.
```

Do not use as admission predicates:

```text
good;
bad;
healthy;
valuable;
proper;
flourishing;
just;
legitimate;
deserving.
```

These may be downstream interpretations, not premises that manufacture the result.

---

# 2. O1a — indexed position-relative better / worse

Prototype relation:

```text
T_a >=_(X,R,H) T_b
```

means only:

> under the declared horizon / perturbation class H, transition `T_a` leaves the independently specified relation or capacity `R` of formed position `X` no less realizable / effective than `T_b` does.

Strict improvement requires a declared dimension on which `T_a` is stronger while no contrary change is hidden inside the same declared comparator.

This relation is **indexed and partial**.

It does not mean:

```text
T_a is morally better overall;
X deserves preservation;
X should survive forever;
R is the only thing that matters;
all R dimensions can be scalarized;
more options = better;
more persistence = better.
```

### Candidate R families

Depending on which upstream owner has independently paid the burden, `R` may include:

```text
formed participation in Selection;
recurrent continued-selectability;
consequence-sensitive re-entry;
rule / boundary / candidate-generation revisability;
relation-level contribution to a higher-order formed process.
```

No R family is universal by default.

---

# 3. O1b — cross-position relation typing

For a relation `Q` among formed positions `X_1 ... X_n`, comparison must track how each position actually enters the future conditions of the relation.

Do not reduce relation quality to:

```text
sum of local generativity;
option count;
persistence sum;
preference satisfaction;
size;
power;
majority;
friction minimum.
```

A relation can be locally strengthening for one participant while generatively substituting another.

Thus cross-position comparison remains multi-indexed unless a genuine higher-order position has independently formed.

---

# 4. Whole-position gate

An observer-declared aggregate does not acquire an evaluative standpoint merely because it contains several positions.

Whole-relative comparison is admitted only after independent formation routing establishes a real higher-order generative position / relation.

At minimum, the whole claim must not be reducible to:

```text
shared label;
common institution;
majority;
spatial containment;
common goal statement;
external observer aggregation.
```

Where a higher-order One / collective recurrent standing is independently established, `better / worse for H` becomes meaningful.

But:

```text
better-for H
-/> H is sovereign over members.
```

Nested evaluation creates a conflict problem, not an automatic hierarchy.

---

# 5. Participant-status consistency

Prototype structural rule:

```text
If relation Q independently types Y as a load-bearing generative participant,
then Y's own Selection must materially enter the future constitution / revision of Q
in the role attributed to Y.
```

If another position `X` recurrently becomes the effective source of Y's future relation-state while Y's own Selection no longer materially enters Q, then at least one of the following must occur:

```text
Q is repaired so Y again performs the attributed participant role;
or
Q is retyped so Y is no longer falsely described as performing that role.
```

This is **participant-status consistency**.

It is structural before it is moral.

---

# 6. Generative substitution / objectification

Prototype diagnostic:

```text
Generative substitution occurs when X recurrently displaces Y's effective source-role
in a relation that still counts Y as a generative participant.
```

A stronger SRT anti-objectification candidate is:

```text
Y is generatively objectified in Q
when Q preserves Y's participant label
while treating Y's future relation-state as something effectively generated elsewhere.
```

Guards:

```text
asymmetry != substitution automatically;
delegation != substitution automatically;
formation / education != substitution automatically;
emergency coordination != substitution automatically;
causal influence != substitution automatically;
substitution != complete moral wrongness automatically.
```

The decisive question is whether the relation's stated participant role remains structurally true.

---

# 7. Actualisation closure != generative closure

Every Selection creates determinacy and thereby closes some unrealized alternatives.

Call this:

```text
actualisation closure.
```

It is not a pathology.

A different phenomenon is:

```text
generative closure
= a transition restructures a relation so that an admitted formed position
  can no longer materially participate in generating / revising the future relation
  in the role the relation still attributes to it.
```

Therefore:

```text
irreversibility != generative closure;
commitment != generative closure;
termination != generative closure automatically;
option reduction != generative closure.
```

---

# 8. O2-C — constitutive ought / relation-integrity norm

Prototype form:

```text
Ought_C(Q, tau)
```

where `tau` is an independently specified relation type.

Meaning:

> if Q is to continue instantiating relation type `tau`, its future transformations must remain compatible with the constitutive roles that make Q an instance of `tau`, or Q must be retyped.

For a relation type that constitutively includes Y as a generative participant:

```text
Q ought not preserve the claim "Y is a generative participant"
while recurrently eliminating Y's effective generative role.
```

This is a **conditional / constitutive ought**, not an all-things-considered moral command.

Its force is ontological-semantic:

```text
violate the constitutive relation -> cease to instantiate the claimed relation type
unless the relation is repaired / retyped.
```

### Anti-triviality guard

O2-C must not become mere word-policing.

The relation type must be independently instantiated by real generative organization, not merely asserted by a label.

Thus:

```text
nominal claim alone -/> O2-C burden;
real enacted relation type + claimed continuation of that type -> O2-C burden.
```

---

# 9. Limited partial-order dominance

Where two feasible transitions `T_a` and `T_b` pursue the same declared task / relation objective, and:

```text
1. T_a is no worse than T_b for every admitted constitutive position / relation
   under the declared comparison scope;
2. T_a is strictly better on at least one declared dimension;
3. T_a reduces unnecessary generative substitution for at least one admitted participant;
4. no independently established higher-order position / relation is worse under T_a;
```

then:

```text
T_a may be preferred to T_b under that declared scope.
```

This is a dominance rule, not a universal scalar optimization rule.

If genuine tradeoffs remain:

```text
STOP.
```

No hidden weighting function may be invented.

---

# 10. O2-A routing — answerability / responsibility

This prototype does not define responsibility.

It only routes relation-transforming Selection toward a stronger agency gate.

O2-A requires separate establishment of conditions such as:

```text
attributable participation / control;
accessible reorientation or alternatives;
relevant relation-state access / knowledge;
capacity for inhibition / revision;
consequence return;
repair / answerability pathway;
absence or degree of external scripting / blockage.
```

Thus:

```text
causal contribution != responsibility;
Selection-position != responsibility-bearing agent;
O2-C violation != culpability automatically.
```

---

# 11. O2-M routing — genuine moral conflict

O2-M remains OPEN.

This prototype does not decide what to do where:

```text
X improves and Y worsens;
member and whole conflict;
short and long horizons conflict;
several non-substitutable positions / relations conflict;
no transition dominates across the declared scope.
```

Forbidden shortcuts:

```text
largest scale wins;
majority wins;
maximum generativity wins;
maximum persistence wins;
maximum d wins;
minimum friction wins;
maximum option count wins;
whole always wins;
individual always wins.
```

# 12. Relation to Bearer / Concern / moral standing

This prototype intentionally stops before moral-standing closure.

```text
O1 / O2-C structural relation
-/> Bearer automatically;
-/> Concern automatically;
-/> rights automatically;
-/> suffering automatically;
-/> moral patienthood automatically.
```

Bearer / Concern can become load-bearing downstream when the question changes from:

```text
is this generative relation structurally coherent?
```

to:

```text
whose stake / suffering / concern carries moral weight in a genuine conflict?
```

# 13. Hume status under this prototype

The prototype supports only a bounded thesis:

```text
some evaluative relations (O1)
and some constitutive oughts (O2-C)
can arise from correctly typed generative relations
without first adding a free-standing moral predicate to a completed neutral fact block.
```

It does not show:

```text
all facts are moral;
all Selection is correct;
all generativity is good;
all constitutive oughts are moral oughts;
all conflicts are resolvable from ontology alone.
```

Status:

```text
partial constitutive dissolution: candidate strengthened
complete Hume closure: NO
```
