# Generative Expectation adequacy charter v0.1

## 0. Scope

Bounded schema-pressure pass.

Use EXISTING repository evidence only.

No new domain source is required.

No canonical normativity owner is edited.

## 1. Frozen author constraint

~~~text
B + C = ASYMMETRIC / LAYERED

B =
structural generative expectation:
an actually formed generative relation carries a directional burden
on what counts as preservation / realization / weakening /
substitution / hollowing / destruction of the typed relation.

C =
formed-locus anticipatory realization.

C0 =
embodied / enacted anticipation.

C1 =
model-mediated anticipation used by a formed position
in current organization.

statistical / predictive expectation alone =
NOT A NORMATIVE SOURCE.
~~~

## 3. Frozen two-axis candidate

### Axis S — expectation source / provenance

Candidate source descriptors:

~~~text
S-MAT
S-TECH
S-LEGAL
S-ORG
S-NORM
S-BIO
~~~

These answer:

> What formed relation / institution / material organization pays the directional burden?

They do NOT answer who anticipates.

### Axis L — expectation locus / mode

Candidate modes:

~~~text
B-STRUCTURAL
= relation-level structural generative expectation;
  no anticipating subject/model required.

C0-ENACTED
= a formed locus embodies / enacts continuation sensitivity.

C1-MODEL
= a formed locus uses an explicit or functional model of later states
  in current organization.

OBS-MODEL
= external analyst / researcher / evaluator prediction or objective;
  NOT a generative-normativity source by itself.
~~~

This candidate schema is frozen before row-by-row reclassification.

## 4. Admission test for B

B is admitted only if all are stated:

~~~text
1. typed formed generative relation R;
2. declared position / scale / grain;
3. relation-native continuation / transformation burden;
4. at least one relation-relevant mismatch / failure condition;
5. the burden is not merely "what usually happens."
~~~

A high-probability transition alone fails B.

## 5. Admission test for C0 / C1

C0 requires evidence that a formed locus is currently regulated by conditions of possible continuation.

C1 additionally requires:

~~~text
a model / representation / functional forecasting structure
is used by the formed locus
to organize present action / selection.
~~~

An external scientific model does not pay C1.

## 6. Indexed normative-comparison gate

G-stronger / G-weaker requires:

~~~text
typed relation / locus
+ comparison dimension
+ position / scale
+ horizon where relevant
+ actual trajectory / alternative
+ explicit statement of what is strengthened / weakened.
~~~

Without the index:

~~~text
"better"
"worse"
"should"
"failure"
~~~

must remain analytically qualified.

## 7. Moral-legitimacy guard

The pass must preserve:

~~~text
relation-reproductive strength
!=
moral legitimacy

institutional stability
!=
justice

whole-level persistence
!=
participant-level good
~~~

A domination structure may have strong B relative to its own reproduction.

That does not establish:

- legitimacy;
- participant benefit;
- moral priority;
- all-things-considered ought.

## 11. Immutable guards

Do not:

- redefine B after inspecting rows;
- classify external analyst prediction as C1;
- use E-MIXED to avoid explicit layer decomposition;
- turn legal obligation into moral legitimacy;
- turn biological viability into universal good;
- turn model prediction error into generative normativity by itself;
- aggregate multiple positions into one moral score.

## 12. Expected framework question

The pass should answer:

> Can GRG distinguish where a generative expectation comes from, from where/how it is anticipated, and from who is evaluating it?

If not, the normativity route remains under-specified.
