## 二、核心理论框架：四类生成条件与双路径机制汇合

五轮研究将 `R5-01A` 最初的 Q-A / Q-B / Q-C 三问深化为**四种互相关联、非线性阶梯的生成条件**：

1. **支付条件（Payment conditions）**：组织是否拥有使新探测、比对或重构活动得以发生的容量与余度（如 S2 中的有效拥挤率 $\Gamma_{\text{eff}}$、背景化减负、外部负载卸载）；
2. **区分条件（Distinction conditions）**：外部或跨位置差异能否穿透感知死区与现有等价类盲区，转化为系统内部可操作的非对称梯度或竞争比对（如竞争归一化 $\lambda_\pm$、`C2` 物理微扰差分 $\hat g_i$ 与死区阈值 $\epsilon_s$）；
3. **关系条件（Relational conditions）**：已形成的能力能否通过真实耦合接口（$K_{AB} = g_{AB}w_A w_B$）实际作用于其他过程或共同整体——**具备局部恢复的探测能力（$p_A\uparrow$），并不自动意味着具备通过现有关系重构整体的现实条件**；
4. **再生产条件（Reproduction conditions）**：当前生成结果（前景成功、职责特化、历史沉积）究竟是**再生产**还是**侵蚀**上述三类条件，以及在原有职责承接位失效后，系统能否完成**职责再分配与重新承接**。

> **阶段核心命题（非 canonical 候选）**：*一个整体的形成，不仅改变各局部能够做什么，还会改变各局部必须做什么、可以不再做什么（生成性退隐与职责转承），以及在原有生成职责失效后，谁能够重新承担这些职责。秩序的生成性不仅取决于它创造了什么，还取决于它如何对待使自己得以形成的生成条件。*

## 三、路径 A 校准成果：S1 / S2 精确模型、完整 5D 谱与成功反噬反例

全部精确数值来自 [`results_calibrated.json`](../../Experiments/r5_01a_stage1_mechanisms/results_calibrated.json)，由 [`run_all_verifications.py`](../../Experiments/r5_01a_stage1_mechanisms/run_all_verifications.py) 确定性复现。

### 3.1 竞争归一化局部灵敏度校准（`divisive_normalization`）
对于 $u_1 = \frac{A}{\varepsilon+\alpha A+\beta B},\; u_2 = \frac{B}{\varepsilon+\alpha B+\beta A}$，在对称点 $A=B=x$ 处（$D=\varepsilon+(\alpha+\beta)x$）：
$$\lambda_+ = \frac{\varepsilon}{D^2},\qquad \lambda_- = \frac{\varepsilon+2\beta x}{D^2},\qquad \frac{\partial\lambda_-}{\partial\beta} = \frac{2x^2(\alpha-\beta)}{D^3}.$$
- 在 $\alpha=1.0, \varepsilon=0.2, x=1.0$ 下，绝对差模灵敏度 $\lambda_-$ 在 $\beta=\alpha=1.0$ 处达到峰值 `0.454545`（$\partial\lambda_-/\partial\beta=0$），随后在 $\beta>1$ 下降（如 $\beta=3.85$ 时 $\lambda_+=0.007842, \lambda_-=0.309774$）；但**相对比值 $\lambda_-/\lambda_+ = 1+2\beta x/\varepsilon$ 保持单调递增**（`1.0 → 41.0`）。因此不能把“提高竞争 $\beta$”笼统等同于“单调锐化当前区分”。

### 3.2 Model S1（严格 2+1 复制子单纯形）：方程预设吸收面的警示
在严格守恒单纯形 $w_1+w_2+p=1$ 上，复制子方程 $\dot w_k = w_k(f_k-\bar f),\; \dot p = p(f_p-\bar f)$ 使面 $w_2=0$ 与 $p=0$ 成为**代数硬编码不变吸收面**。即使从充裕初态 $(w_1,w_2,p)=(0.6,0.2,0.2)$ 出发，Phase 1（$T_1=40$）结束时 $w_2$ 与 $p$ 仍分别指数塌缩至 $5.53\times 10^{-23}$ 与 $6.05\times 10^{-29}$，Phase 2 切换后通道 1 误差被钉死在 `2.2622 rad`。**结论**：复制子/乘性 Hebbian 模型的边界不可恢复性高度混杂方程代数预设，不能直接充当“组织内生丧失”的证明。

### 3.3 Model S2（非吸收变容量 5D 系统）：精确方程、完整 5D 谱与折叠分岔认证
去掉一切预设零点（$\nu_w = 0.01 > 0,\; \nu_p = 0.015 > 0$），完整 5 维自治系统定义于 $(w_1, w_2, p, \theta_1, \theta_2)$（固定外部相位 $\Delta\phi_1=0, \Delta\phi_2=\pi$）：
$$\Phi_k = \frac{1+\cos(\Delta\phi_k-\theta_k)}{2},\qquad A=w_1\Phi_1,\quad B=w_2\Phi_2,\qquad u_1=\frac{A}{\varepsilon+\alpha A+\beta B},\quad u_2=\frac{B}{\varepsilon+\alpha B+\beta A},$$
$$W_{\text{al}} = A+B,\qquad C(W_{\text{al}}) = C_0 + \lambda\frac{W_{\text{al}}}{K_s + W_{\text{al}}},\qquad L_{\text{fg}} = \sum_{k=1}^2 w_k(1-\kappa_{\text{auto}}\Phi_k^2),\qquad \Gamma_{\text{eff}} = \mu_p + \chi\frac{L_{\text{fg}}}{C},$$
$$h(p)=h_{\max}\frac{p}{p+K_h},\qquad b_k=-\sin(\Delta\phi_k-\theta_k)\sin h(p),\qquad m_{\text{sig}} = m_0 + \kappa_b(b_1^2+b_2^2),$$
$$\dot w_k = \nu_w + \eta_w u_k\Phi_k - \mu_w w_k - \gamma_{\text{cap}}\frac{w_k(w_1+w_2+p)}{C},\qquad \dot p = \nu_p + \frac{a_p m_{\text{sig}} p^2}{K_p^2+p^2} - \Gamma_{\text{eff}} p,\qquad \dot\theta_k = -\eta_\theta b_k.$$

### 4.1 严格模型设定（无偷渡 $\sin\psi$、对称规则、明确不可辨识条件）
- **局部不可辨识条件与代码初始设置区分（严格限定，`P2-01`）**：设 $\phi_A(t)=\phi_{\text{bg}}(t)+\frac{1}{2}\Delta_{\text{env}},\; \phi_B(t)=\phi_{\text{bg}}(t)-\frac{1}{2}\Delta_{\text{env}}+\text{bias}_B$。**理论命题**层面，仅当公共背景 $\phi_{\text{bg}}(t)$ 独立于 $\Delta_{\text{env}}$ 且在 $\mathbb{S}^1$ 上呈平稳均匀分布（且局部无法快于漂移主动调制源）时，单点观测满足 $I(\phi_A(\cdot);\Delta_{\text{env}})=0$；若背景具有可学习规律，局部可部分辨识。**代码计算设置**层面，因公共背景 $\phi_{\text{bg}}(t)$ 在共享接口差值 $\psi_{AB}=(\phi_A-\theta_A)-(\phi_B-\theta_B)$ 中严格代数抵消，主脚本为便于确定性对比而设初值 `phi_bg = 0.0` 并加漂移噪声，须将二者明确区分。
- **纯操作化方向差分**：共享接口只输出偶函数标量 $U_{AB} = g_{AB}w_A w_B\frac{1+\cos\psi_{AB}}{2}$；局部仅通过对自身 $\theta_i$ 施加 $\pm h_i$ 微扰读取差分并受感知死区 $\epsilon_s=0.012$ 截断：
  $$\hat g_A^{\text{raw}} = \frac{U_{AB}(\theta_A+h_A,\theta_B)-U_{AB}(\theta_A-h_A,\theta_B)}{2} = \frac{K_{AB}}{2}\sin\psi_{AB}\sin h_A,\qquad K_{AB}=g_{AB}w_A w_B.$$

### 4.3 “局部能力恢复但整体无法重构”的状态条件解析判据（回应校准项 4 与 `P2-02`）

$$\boxed{S_{\max}(w_A,w_B,\psi) \equiv \frac{g_{AB}w_A w_B}{2}|\sin\psi|\max_{0\le h\le h_{\max}}|\sin h| \le \epsilon_s,}$$
系统仅靠提高本地探测能力 $p_A$（哪怕 $p_A\to\infty$）就**严格无法通过现有接口产生非零方向更新信号**（$\hat g_A \equiv 0$）。在 T3d 终态（$w_A=0.1224, w_B=0.68, \psi=2.95, h_{\max}=0.50$）中，$S_{\max} = 0.00608 \le 0.012$，精确解释了为何 $p_A$ 升至 `1.8140` 仍无法修复现有接口（`err=2.9500, U=0.0012`）；而在 T3b 中，卸载最低谷处 $S_{\max} \approx 0.0212 > 0.012$，故去分化成功接通整体修复。**边界声明（`P2-02`）**：该判据仅刻画“当前接口状态下的不可驱动性”，不外推为系统丧失一切未来路径（例如接入新接口、引入外部中介桥接或改变外部相干条件仍可能重新打开恢复通道）。
