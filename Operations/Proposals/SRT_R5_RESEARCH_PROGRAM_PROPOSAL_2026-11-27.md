## 一、R5 总定位：从“理论骨架重构”转向“核心生成机制发现”

随着 `R4`（`#1159`–`#1167`）全部合并收口，SRT 已完成从早期直觉整理、历史材料归并到全仓 canonical 一致性重构的阶段任务。`R5` 不再执行 R4.1 式全仓治理或概念扩张，也不以“证明 SRT 整体正确”为研究目标，而是确立单一核心使命：

> **统一研究母题**：**生成能力的生成（The Genesis of Generative Capacity）**
> **核心目标**：从 SRT 自身提出的机制问题出发，发现并检验少数真正具有生成力、可推导新认识、且经得起反例与实证检验的核心生成机制，同时保持两条既有资产线（存量构造性论文发表、《从存在到秩序》思想深化）独立并行推进。

四条硬执行纪律：
1. **机制发现优先，不“为赢竞争对手而选题”**，但在主张成熟期按主张类型严格支付数学、因果、反例或竞争性判别义务；
2. **绝不将全部机制候选塞进同一个最小模型**，避免造出“什么都能演示却什么都验证不清”的复杂玩具；
3. **不预设最终数学工具**（`HCLR01` 李括号、网络动力学、可生存性分析均作局部候选工具，服从问题而非绑架问题）；
4. **禁止无明确机制产出的概念扩张与术语增殖**，暂不新增正式理论术语，也不回写 canonical。

### 1.1 历史研究资产利用原则（R5 常规研究方法）

本原则作为 **R5 的常规研究方法** 随具体科学问题运行，**不作为独立的前置工程阶段**：

1. **承继存量，不从零起步**：R5 充分利用仓库已有历史材料卡、SourceCard、PatchNote、Bridge、IntegrationHook、GRG 研究成果、作者早期笔记及历史计算实验，而不是从零开展机制研究。
2. **问题驱动的有界检索**：每项核心机制研究开始时，围绕具体科学问题进行有界的历史资产检索与外部文献研究，主动寻找能够支持、深化、修正或挑战当前理论的机制、数学方法、实证证据及反例。
3. **重估 R4 新框架下的搁置价值**：尤其关注过去因研究阶段、理论结构或局部竞争增量不足而暂时搁置，但在 R4 重构后的新理论框架下可能重新具有研究价值的内容。
4. **以理论与模型产出为目标，不启工程治理**：历史资产的检索与利用以产生新理论认识、数学构造与实验设计为目标，**不另起全量材料审计、重新评级或大规模前置治理整理任务**。
5. **双向防偏与硬边界**：不因材料非 canonical 或曾被 parked 而忽略其研究价值，也不将历史结论直接视为现行理论结论；始终保持既有 `HOLD`、25 项封存验证材料（`validation_holdout`）及冻结科学包的边界不变。

## 二、R5 三项递进研究入口（结构化拆分，不强行同模型实现）

以下编号（`R5-01 / R5-02 / R5-03`）为**提案级建议工作结构**，非已获授权的仓库执行任务；三者构成递进关联的研究入口，而非现实系统必经的线性演化阶梯。

### 2.1 `R5-01`（第一理论与机制入口）：组织—比对共同生成
- **为何作为第一入口**：直接贯通 SRT 的存在（新位置与新接口）、价值（新比对尺度与机会成本定义域）与方向（新选择条件）三条递归轴，确保 R5 从第一天起围绕核心生成理论生长，而非退回孤立的局部技巧研究。
- **核心研究问题**：新的组织与生成关系如何创造原先不存在的差异作用效力、新的比对维度、新的价值关系与实际作用接口？
- **推进收束要求（防概念空转）**：不在纯哲学层面无限延展，尽快将问题压缩至可形式化与因果干预检验的最小形态：
  - 核心因果判据：当差异变量 $z$ 在旧组织条件 $G_0$ 下**已有定义**时，检验 $E_{G_0}(z_1,z_2)=0$ 而在新组织条件 $G_1$ 下 $E_{G_1}(z_1,z_2)\neq 0$，配合五步排伪检验（干预差异 / 撤除新组织 / 干预内部路由 / 检验历史生成 / 切断双向回写）；**严禁将尚未成立的关系对象或新比对维度定义域直接等同于零因果效力**（定义域尚未成立的情形须以新关系闭合出可定义、可干预的新关系对象/接口本身为刻画与检验目标，而非硬套既有变量的 $E_{G_0}=0$）；
  - 核心对照骨架：**`A / B / C / D / D₀` 五组对照**（其中 `D₀` 保持同等参数与更新预算及通信带宽，但切断组织重构与比对条件之间的双向条件改写，排除自由度混淆；按主张层次撤回：`D` 与 `D₀` 无差异时**仅撤回对应的双向回写贡献主张**，不自动否定新效力、新接口或新比对维度的生成）；
  - 严守非增益与去窄化纪律：不把“提升组织延续能力”写进比对生成定义，不把非可加约束瓶颈或慢变历史槽预设为唯一参照来源，正面容纳破坏性、排斥性与寄生性比对生成；
  - **暂定首项研究建议（`R5-01A`：组织—比对共同生成的最小机制辨识，须在 PR #1169 合并后获作者授权启动）**：原则上优先从组织—比对共同生成切入，重点开展**最小研究对象确定、成熟机制同目标对照、数学构造与低成本计算验证**；不直接实现包含全部候选机制的复杂模型，也不再开展大规模前置工程治理。按 §1.1 常规研究方法，优先检索并利用以下已有历史资产：**协同学与循环因果、GRG 跨尺度因果再进入、Learnable Novelty、Performative Prediction、个体化、生态位构建、组织生成与历史依赖可达性**。

### 2.2 `R5-02`（优先数学与计算研究切口）：过渡条件生成
- **定位与资产衔接**：与 `R5-01` **拆分为独立最小模型**，不强塞进同一个原型。它最直接衔接仓库既有计算资产（`Experiments/anchoring_tiny_mdp_confirmatory`、`03_Bridges/SRT_History_Conditioned_Lie_Reachability_Bridge_v0_1.md`）与 `HEF-4` 历史依赖可达性。
- **核心研究问题**：当原有组织条件 $G_0$ 失配、目标结构 $G_1$ 已具备现实条件但直接切换会破坏维持连续性时，系统如何利用历史形成的条件或新生成关系，创造原本不存在的过渡可行路径？
- **防过界边界**：
  - 临时过渡承载结构 $T$（双轨重叠、跨尺度托举等）仅作为重点研究通路之一，**不预设为一切重构的普遍必要条件**（保留连续变形、局部替换、暂时休眠、原结构直接转化等路径）；
  - 正面对照**现代动态可生存性理论**（含动态约束与时变可行区域）及**软件动态重构**，聚焦“原先不存在现成过渡结构时，系统如何内生生成承担过渡职责的新关系”。

### 2.3 `R5-03`（后续深化入口）：生成能力自身的重构与锁死诊断
- **启动前提**：依据 `R5-01` 与 `R5-02` 的具体建模与反常结果推进，不提前铺开。
- **核心研究内容**：
  1. **前背景递归与协议构成性重构**：前景如何在什么条件下反向获得改写底层背景与共同协议的能力；
  2. **四类重构失败机制分离**：区分（a）失配未识别、（b）`U5` 选择机制自我豁免、（c）极效剪枝致无替代结构、（d）底盘耗竭致过渡不可支付；不将简并底盘、摩擦支付通道、反向杠杆与失配回流预先写成普遍充要条件；
  3. **定向实验底物探针（升级版人机共同生成）**：严避 Bastani et al. (2025, *PNAS*) 已充分覆盖的“普通 AI 辅助 vs 引导式 AI 教育成绩”范式，聚焦检测**撤除 AI 支架后人类是否内生形成原先不具备的新比对维度，以及依赖结构重组后能否继续生成其他新能力**。

## 三、按研究主张性质分层的科学验证标准

`R5` 废除“所有研究一刀切套用同一证明门槛”的做法，按实际主张性质匹配验证义务与撤回条件：

| 主张类型 | 必须支付的验证标准 | 明确失败 / 撤回条件 |
|---|---|---|
| **存在性主张**（某种生成机制可在指定条件下发生） | 构造性数学或可复现计算存在性证明（锁定随机种子与全部参数） | 无法在不作弊/不硬编码目标结果的条件下复现 |
| **机制与因果主张（新效力 / 新接口 / 新比对维度层）**（新关系真实产生新效力、新接口或新比对维度） | 独立因果干预、撤除新组织与阻断内部路由消融、等自由度单向对照、反例检验（$E_{G_0}=0\to E_{G_1}\neq 0$ 仅适用于变量已有定义的情形；定义域尚未成立的关系对象创生另按闭合接口刻画） | 撤除新组织或阻断内部路由后效应不消失，或完全由等自由度基线/自由度增加解释时，撤回对应的新效力、新接口或新比对维度主张 |
| **双向回写贡献主张（互构增量层）**（组织重构与比对条件间的双向回写带来额外增益或超加性效应） | 等预算、等通信带宽切断双向回写的结构消融（如 `D vs D₀`）与对应干预对照 | **`D` 与 `D₀` 无实质差异时，只能撤回对应的双向回写贡献主张，不自动否定新效力、新接口或新比对维度的生成** |
| **必要性 / 普遍性主张**（某结构为新能力形成的必要条件） | 跨配置反例排查与替代路径测试 | 出现不依赖该结构的反例时，立即降格为“一类实现通路” |
| **跨尺度迁移主张**（条件性组织律可跨底物迁移） | 至少两个异质底物上的独立验证（不靠事后调参） | 跨底物失效时收缩启用条件，不以类比充当规律 |
| **竞争性解释增量主张**（SRT 相对特定成熟邻域具额外解释/预测力） | 冻结强竞争基线，完成前瞻性反事实/干预分歧（`D2 / D3`） | 若强竞争基线在同资源与同干预下等价吸收全部结果，诚实记录局部无竞争增量 |
| **哲学与统一性主张**（本体论综合与概念贯通） | 概念一致性、反循环审计与解释力比较（不冒充经验科学证明） | 暴露内部逻辑矛盾或循环定义时须修订 |
