## 0. 核心突破与本轮关键校准摘要

本轮 `R3-05` 从“历史为什么能够参与现实的生成（而不只是已发生事件的记录）”与“时间究竟是什么”两大根问题切入，沿 `R3-04` 确立的存在—秩序主轴打通了时间、历史、信任与遗忘四项关系，并完整承接原议程全部硬审查债：

1. **时间作为秩序的关系度量（作者核心方向候选）**：提出时间不是生成之前预设的本体容器，而是多单元生成变化之间形成的**秩序关系度量与对比标尺**，统一涵盖 **横向（多单元变化对比标尺）** 与 **纵向（同一组织从一种秩序向另一种秩序维持、发展与重构的展开尺度）**，并探索时间标尺作为脚手架的双向生成参与功能（定位为本体论研究候选，不升级为已证普遍物理时间理论）；
2. **历史作为当下持续生成效力与前背景五种去向**：确立历史不是过去隔空遥控现在，而是先前 `Selection` 在当下保持的实际生成效力（不以已形成垂直组织或 `One` 为普遍必要前提，兼容 [`Spine §4 / §11`](../../Core_Law/SRT_Generative_Ontology_Spine.md#L205-L240)）；在组织化语境中，历史承接先前比对工作、支撑新秩序，但在与变化后生成条件产生持续失配且阻碍必要重新比对与选择时构成向固化势阱滑落的重要诊断线索（继承 `R3-04 P2-04` 边界）；同步保留并拓展 `B3-a` 为五种可能交叠的条件性前背景去向；
3. **信任重估与历史调用调整（严格区分背景化与遗忘）**：在保持 [`Spine §11`](../../Core_Law/SRT_Generative_Ontology_Spine.md#L449-L466) `L2` 普遍定义不变的前提下，区分历史沉积、路径倾向与信任分配（适用模型中严格分离非负 $\rho\ge 0$、有符号 $\Delta w_{\text{trust}}\in\mathbb R$ 与跨主体 $W_{\text{social}}$）；明确**背景化不必然削弱历史效力，反而可能通过脚手架强化背景约束**，严格区分退出显现、退出调用与退出实际生成作用，将历史效力调整四分与原主动遗忘二式统一归位。

## 1. `R3-05` 阶段性收敛候选（六维骨架主轴）

### 一、时间作为秩序的关系度量：横向/纵向统一、三项校准与七项接口（承接硬债 1）

1. **时间本体论研究候选（不升级为已证明的普遍物理时间理论）**：
   - 在作者确认的本体论研究方向下，时间不预先设定为独立于生成过程之外的全局容器，而被探索为**多单元生成变化之间形成的秩序关系度量与多单位对比标尺**——它同时承担两类用途（非两种独立时间）：
     - **横向度量**：不同生成单元或子过程之间通过参照比对建立相对变化尺度、快慢与节律；
     - **纵向度量**：同一生成组织从一种秩序维持、发展或重构为另一种秩序所经历的变化展开跨度（依托横向关系尺度获得相对度量）。
   - **度量脚手架的双向生成参与（候选命题，具体成立条件 `OPEN`）**：与 `R3-04` 脚手架双重功能及跨尺度递归一致，时间标尺既可以从已有生成秩序中建立（把相对稳定的变化过程放到背景作参照），也可能在形成共同脚手架（物理耦合同步、生命节律协调、公共时间制度）之后反向参与跨单元协作与新秩序生成——度量不一定只是被动描述，也可能在脚手架化后成为参与生成的组织条件。
2. **三项强制防误读校准**：
   - **校准 1（时间度量 $\neq$ 秩序高低或健康打分，且非普遍物理时钟）**：时间度量的是秩序变化与跨单元对比的相对展开尺度，绝不等于“时间越长秩序越高或越健康”（僵化锁定可持续极久）；同时严守 [`P1-T02`](../../Core/SRT_Core_21b_Constitutive_Theorems.md#L71-L90) 与 `D01 v0.2` 边界——目标依赖的“到达某秩序所需步数（如击中时间 $E[N]$）”或声明模型内的局部积分 $t_{\text{onto}}$ 均不构成普遍物理时钟，原初 `Selection` 目前亦无统一计数单位；
   - **校准 2（守住孤立实际化的不可逆底线，兼容终端 `Selection`）**：即使在尚无多单位对比标尺的孤立原初实际化中（尚未建立持续长度、快慢或完整时间度量），**发生非等价性（已发生 $\neq$ 未发生，[`P1-T02`](../../Core/SRT_Core_21b_Constitutive_Theorems.md#L57-L68) P1 底线）依然成立**；同时须区分**发生不可逆性**与**局部生成依赖次序**（一次不可逆发生不自动与另一次发生建立先后次序）；
   - **校准 3（区分纯数量比对、构成性约束与非对称生成依赖，`P2-02` 校准）**：纯变化次数比例本身是时间反演对称的，而具体实际化事件间的非对称生成依赖关系（$A$ 的实际化成为 $B$ 的条件、$B$ 改变 $C$ 的条件而 $C$ 未参与 $A$）已带有局部方向性；但须严格区分**两种组织间的相互/构成性约束（不一定构成时间先后）**、**具体实际化事件间的局部非对称生成依赖（局部次序研究候选，不直接升级为偏序）**、**满足传递性与无环等条件后的严格偏序（条件保持 `OPEN`）**，且已建立偏序仍不自动给出时间度量、物理因果律或热力学/宇宙学时间箭头。
3. **七项时间接口精确分离与 `R4` 符号表修订边界（完整承接原议程 `A4a` 硬债）**：

| 时间接口 | 定位与职责边界 | 与现行规范及 `R4` 修订的关系 |
|---|---|---|
| **1. 实际化非等价** | 不依赖观察者的发生事实（已发生 $\neq$ 未发生） | 保留 [`P1-T02`](../../Core/SRT_Core_21b_Constitutive_Theorems.md#L57-L68) P1 底线；不要求留痕或时间度量 |
| **2. 生成关系次序候选** | 多个具体实际化事件间的局部非对称生成依赖关系（仅作建立局部次序的研究候选，区别于组织间构成性/双向约束） | 形成严格偏序所需的传递性、无环等具体条件保持 `OPEN`；不预设无依赖事件间全局同时性，不自动给出时间度量或物理因果律 |
| **3. $\tau_{\text{ontic}}$** | 条件性的物择相对变化步比候选 | 承接 `Q04`；保留 `D01 v0.2` 非普遍时钟边界，无原初统一计数单位 |
| **4. `P1-T02` $t_{\text{onto}}$** | 声明了历史留存与算子归属的模型局部积分度量 | **登记 `R4` 任务**：收窄 `_SRT_SYMBOL_TABLE.md` 中过宽的 `Ontological Time` 译名，明标其模型限定范围 |
| **5. $t_{\text{exp}}$（体验时间）** | 具身认知位置对连续生成变化、持续与窗口的组织 | 承接 `Q04` 与 `R3-03` 时间窗口；**校准：错误、预期、记忆、注意与关切是重要调节因素，而非体验时间成立的唯一或必要来源** |
| **6. 数学参数 $t$** | 动力学方程中的数学排序与索引工具 | 承接 [`Philosophy/SRT_Causality_Time.md §二`](../../Philosophy/SRT_Causality_Time.md#L92-L122)，无本体论承诺，不与公共时间混同 |
| **7. 公共时间** | 跨位置共享的参照度量与社会协作脚手架（如钟表、历法） | 属于跨主体 `L2` 脚手架，兼具认识比对与协作组织双功能 |

### 二、历史的当下生成效力、`L1 / L2` 视角、快慢尺度协作与前背景五种去向（承接硬债 `B3-a`）

1. **历史为何参与现实生成（兼守 [`Spine §4 / §11`](../../Core_Law/SRT_Generative_Ontology_Spine.md#L205-L240) 普遍边界）**：
   - 历史不是“过去存在在另一时空里隔空作用于现在”，而是**先前 `Selection` 在当下仍然保持的实际生成效力**；
   - **未成体兼容性护栏**：**历史效力不以已经形成垂直组织或 `One` 为普遍必要前提**——尚未成体的局部 `Selection` 同样可能在满足条件时留下影响后续选择条件的实际效力（完整保留 `Spine §4 / §11` 普遍定义，并兼容无历史留存的终端 `Selection`）；
   - **已成组织与脚手架中的双面效应（`P2-03` 校准，继承 `R3-04 P2-04` 边界）**：在形成垂直组织与脚手架的系统中，历史留存的不只是过去选择的结果，也包括“选择方式”本身，并**承接了部分先前比对工作**（降低重复比对负担、支撑新秩序）；须避免表述过绝对——**生成条件变化而既有脚手架继续参与生成，不自动构成不健康固化**（已有脚手架仍可能有效，未必需要重做全部比对），只有当**既有脚手架与变化后的生成条件产生持续失配、且阻碍了必要的重新比对与选择**时，才构成向固化势阱滑落的重要条件性诊断线索（具体非循环判据继承 `R3-04 P2-04` 继续保持 `OPEN`）。
2. **`L1 / L2` 视角分工与快慢时间尺度垂直协作**：
   - `L1`（当下实际形成的结构）与 `L2`（先前选择通过当下结构或留存条件对后续生成的持续效力）是同一现实或组织上的不同认识视角（与 `One` / `R3-04 Bearer` 秩序视角候选并行）；历史效力可以完全融入当前存在结构，**路径依赖、滞回与返回点记忆是检验历史效力的重要手段，而非 `L2` 成立的普遍必要条件**；
   - **快慢时间尺度的双向垂直协作**：在跨尺度系统中，相对缓慢的生成关系可充当快速变化过程的背景条件，而持续的快速选择与协作亦可能逐渐改写缓慢背景（如物理结构调整 vs 局部运动、发育适应 vs 瞬时生理响应、长期信任/习惯 vs 当下注意、语言制度 vs 个体行为）；明标**垂直结构 $\neq$ 快慢尺度**，快慢差异仅为重要实现关系之一。
3. **整个前背景生成关系的历史与五种交叠条件性去向（完整承接 `B3-a`）**：
   - 历史不是前景单方面的历史，而是**整个前背景生成关系的历史**；保留原议程 `B3-a`（阴影 / 张力 / 后续摩擦）并补全为五种**可能交叠的条件性分析去向（不构成互斥分类，亦非必经阶段；例如张力与后续摩擦可为同一未协调关系在不同条件下的表现）**：

| 背景去向（条件性、可交叠） | 生成意义与边界 |
|---|---|
| **1. 构成性退隐** | 局部显现退隐为支撑当前前景与更高尺度整体秩序的协作条件（承接 `R3-02`） |
| **2. 阴影（`B3-a`）** | 退入相对背景、隐性框定后续可达空间并保持潜在再显现条件（`阴影 != 平行实体`） |
| **3. 张力（`B3-a`）** | 尚未被当前组织协调消化的差异持续施加失配压力 |
| **4. 后续摩擦（`B3-a`）** | 未协调关系在后续选择或条件变动中浮现为实际阻力或修正信号 |
| **5. 终止或消散** | 不再具有可建立的后续生成效力（守住终端 `Selection`，不预设历史永不消失或万物留痕） |

### 三、适用模型下的 `L2` 痕迹—信任三分与历史调用调整（承接原议程 `A4b` 与主动遗忘硬债）

1. **跨尺度三层区分与 `Q09` 信任本义**：
   - 跨尺度上严格区分：① **历史沉积**（先前选择留下仍有效的生成条件，广泛存在）、② **路径倾向**（既有条件使某些方向更易发生，广泛存在）、③ **信任分配**（承接作者 `Q09` 原话：“基于变化的秩序趋势，将其分配到事物表征的过程”——具备趋势评估与重分配能力的系统根据生成趋势重新组织既有关系在当下选择中的条件化权重，**无需删除既有记忆即可下调其有效地位**）。不在现阶段把“信任”拟人化推广至一切物理尺度，低尺度是否存在同功能非拟人机制保持开放。
2. **适用模型下的三分离（严守 [`Spine §11`](../../Core_Law/SRT_Generative_Ontology_Spine.md#L449-L466) 与 [`Core_12b`](../../Core/SRT_Core_12b_Ontology_L2.md#L76-L92) 边界，含 `P2-04` 精度校准）**：
   - 保持 `Spine §11` 对 `L2` 的普遍定义不变，且尊重 [`Core_12b Def-PathTrace`](../../Core/SRT_Core_12b_Ontology_L2.md#L76-L92) 中 $\rho$ 的特定映射与门控前提（非 `L2` 普遍本体原语）；
   - **仅在声明了保留历史、信任重估与跨主体关系的适用模型中**，正式裁定分离以下三个独立接口（不写成所有 `L2` 必然具有的三部分），并**严格区分信任调节权重 $w_{\text{trust}}$ 与其有符号变化量 $\Delta w_{\text{trust}}$**：
     1. **非负痕迹密度 $\rho(p,t)\ge 0$**：保留 `Def-PathTrace` 的 $\rho\ge 0$ 非负性与正向沉积 $\Delta\rho^+\ge 0$ 性质（$\rho$ 本身可在满足相应衰减条件与无持续补充沉积时自然衰减，不要求随时间单调增长，严禁负号污染 `Def-PathTrace` 单调性）；
     2. **个体信任调节权重 $w_{\text{trust}}^{(i)}$ 及其有符号变化量 $\Delta w_{\text{trust}}^{(i)}\in\mathbb R$**：记录基于秩序趋势的信任权重调节与正负更新量，使系统能够将“历史留存深度（$\rho$）”与“信任调节地位（$w_{\text{trust}}$）”分离；**明确护栏**：正向重估（$\Delta w_{\text{trust}}>0$）不意味着最终信任权重一定为正，权重正负亦不自动等同于系统当下必然采纳该路径（具体权重—采纳映射关系在各声明模型中保持开放）；
     3. **跨主体关系权重接口 $W_{\text{social}}$（暂不固定数学形式，暂不入符号表）**：在社会与制度层分离高 $\rho$ 路径惯性/强制约束与可经跨位置校准修订的公共信任分配。
3. **背景化非必遗忘、历史效力及调用关系的四种调整方式与主动遗忘二式（`P2-04` 条件性边界校准）**：
   - **关键纠偏**：**背景化不必然削弱历史效力，反而可能通过脚手架（如语言、习惯、制度）更稳定地强化背景约束**；因此必须严格区分 **① 退出当下显现（不在前景）**、**② 退出主动调用** 与 **③ 退出实际生成作用（效力真正减弱或解除）**；
   - 将相关过程定位为 **历史效力及调用关系的四种调整分析候选**（不预设共享同一具体底层机制，哪些属严格意义的遗忘、哪些属新组织形式继续分域研究；严守 `P1-T02` 发生不可逆性——后续调整均属新生成，不能使已发生事件变为从未发生）：
     1. **自然衰减**：历史痕迹及其效力随停止重复遍历而逐渐减弱（对应原**主动遗忘式一**：在 `Def-PathTrace` 特定模型下，需满足相应衰减条件、足够时间跨度且无持续补充沉积时，停止遍历方能使 $\rho$ 按指数衰减回 $\rho^*$ 以下）；
     2. **退出显现与前背景重排**：历史退出当下前景显现或显式比对（须独立核查其究竟转入了更稳固的脚手架背景约束，还是同时退出了实际调用）；
     3. **信任重估**：历史仍可被召回，但借有符号 $\Delta w_{\text{trust}}$ 调节 $w_{\text{trust}}$ 以改变其在当前选择中的权重地位；
     4. **结构解固**：承载历史的组织条件被重新构造，使此前受限路径重新可达（对应原**主动遗忘式二**：低摩擦重巩固窗口解固属于**待验证的条件性机制候选**，进入窗口并不自动保证结构成功解固）。
   - **独立检验原则**：**历史痕迹下降、信任权重降低、实际约束解除与路径重新开放四者彼此不等同，须在后续模型与实证中分别检验**。
   - **跨时间存在—秩序闭环**：历史沉积（维持先前效力）与信任重估 / 结构解固（重构既有历史效力）共同构成 `R3-04`“存在与秩序一体”在跨时间维度上的展开。
