# X4c P-INST freeze — precedent / stare decisis inheritance

## 0. Freeze

~~~text
relation = X4c inherited reconstructed condition
candidate provenance = P-INST
target domain = common-law precedent / stare decisis
target system = prior judicial decisions conditioning later adjudication
date = 2026-09-21
base commit = a2da464e5de8893d20ac7860b4cc72b0f564ad2b
dedicated target-source inspection before freeze = NO
~~~

Known generic background that cannot be erased:

- prior court decisions can function as precedent;
- some precedent is binding and some is persuasive;
- stare decisis concerns following prior decisions.

No decisive legal source has been inspected for this attempt.

## 1. Core discrimination

This attempt tests whether institutional inheritance can be separated from mere informational persistence.

Frozen contrast:

~~~text
same prior decision / legal reasoning remains available as information

but

binding institutional authority differs.
~~~

Candidate near-control:

~~~text
binding precedent
vs
persuasive / nonbinding precedent
~~~

If the same informational content is available in both cases but only the binding relation constrains successor adjudication, that is pressure for P-INST rather than P-INFO.

## 2. Frozen X4c topology

~~~text
prior adjudication A
-> reconstructs legal decision field F
-> institutional precedent relation C persists
-> successor court / judge enters under F
   without having made the original adjudication
-> F changes which later legal moves require following,
   distinguishing, overruling or otherwise special justification
~~~

## 3. Admission burdens

Require all:

1. prior adjudication materially changes a later decision field;
2. the later court is a successor participant rather than the original decision maker;
3. institutional authority, not mere availability of text, carries the constraint;
4. later legal possibilities / burdens differ because of the inherited institutional field;
5. the mapping survives comparison with persuasive / nonbinding authority.

## 4. P-INST test

Candidate:

~~~text
P-INST =
institutional authority / rule scaffold is sufficient
to transmit the reconstructed field into successor adjudication.
~~~

Evidence sought after freeze:

- hierarchy / jurisdiction rules that determine binding force;
- source-native distinction between binding and persuasive authority;
- recognized options such as follow / distinguish / overrule;
- evidence that later courts inherit the burden without re-enacting the original decision.

## 5. Negative controls

### NC-1 — information without binding force

~~~text
same / similar legal reasoning remains accessible
but is only persuasive
-> information persists
-> P-INST inheritance burden should be weaker or absent.
~~~

### NC-2 — current rule only

~~~text
a current procedural rule tells a court what to do
without a prior decision reconstructing the later field
-> may pay X3b
-> does not automatically pay X4c.
~~~

### NC-3 — historical citation only

~~~text
later court cites an old case
but citation has no source-native authority / option-shaping consequence
-> not X4c by citation alone.
~~~

## 6. X3b / X4c separation

### X3b

~~~text
current institutional expectation:
courts should apply the operative hierarchy / precedent rule.
~~~

### X4c

~~~text
prior decisions accumulated under that institution
become inherited constraints / affordances for successor adjudication.
~~~

If the target collapses completely to the current rule "follow binding precedent", X4c should fail or narrow.

## 7. Possible outcomes

### P-INST PASS

If binding institutional status itself makes the difference while informational access is held conceptually constant.

### P-MIXED

If written informational content + institutional authority are jointly indispensable and neither can be treated as merely support.

### X4c FAIL / NARROW

If there is no distinct successor inherited-field burden beyond current X3b operation.

## 8. Maturity consequence

This is a provenance stress test.

~~~text
X4c remains M3 regardless of a local P-INST result.
M4 is not opened.
~~~

## 9. No normative shortcut

A precedent being institutionally binding does not establish:

- moral correctness;
- justice;
- democratic legitimacy;
- political desirability.

This test concerns inheritance topology only.
