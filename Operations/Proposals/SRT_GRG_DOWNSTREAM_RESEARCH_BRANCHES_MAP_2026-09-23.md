# GRG Downstream Research Branches Map — 2026-09-23

## 0. Purpose

This file parks the accepted but currently non-core downstream GRG analysis so later sessions can drill down without forcing it into the experimental Grammar Card.

Primary current route remains:

`FRR -> Grammar Card refinement -> more fusion cases -> cross-card reconciliation`.

The branches below are **candidate follow-on programmes**, not current mandatory execution order.

## 1. Admission rule for reopening a branch

Reopen a downstream branch when at least one of the following occurs:

- a fusion case makes the concept load-bearing;
- the Grammar Card repeatedly exposes the same unresolved relation;
- an existing canonical / source-intuition tension requires the branch;
- a source-native mechanism provides enough structure for a bounded comparison;
- the author explicitly selects the branch for development.

Do not reopen a branch merely because it is philosophically interesting.

## 2. Branch map

### B1 — Selection anti-tautology / event individuation

Core questions:

- what independently licenses actuality?
- how is an event individuated?
- what is relational non-neutrality?
- what survives representation change?
- how are deterministic transitions handled?
- what counts as empirical warrant for terminal Selection?

Desired output:

- bounded Selection audit;
- negative controls;
- relation to canonical OPEN without premature closure.

### B2 — Neutrality maps / proxy / reach

Core questions:

- when is an equivalence safe?
- how is neutrality position-indexed?
- how does a distinction lose / regain reach?
- how is latent reconstructive reach evidenced?
- when is compression source-native vs analyst-imposed?

Desired output:

- source-native operationalizations across multiple fusion cases;
- clearer relation among proxy, reach and equivalence.

### B3 — Scaffold / cage / generative debt

Desired output:

- no static moral labeling.

## 3. Cross-branch invariants to preserve

Across all branches:

`source-native first, GRG second`.

`same role != same mechanism`.

`same mechanism != same ontology`.

`position != perspective automatically`.

`perspective != Bearer automatically`.

`Bearer != self automatically`.

`self != agency automatically`.

`agency-like organization != consciousness automatically`.

`generative efficiency != moral rightness`.

`control power != generative health`.

`conflict absence != healthy alignment automatically`.

## 4. Relationship to the Grammar Card

The downstream branch map is a **hypothesis reservoir**.

It should influence the Card only when repeated fusion-case evidence shows that a field is needed.

The Card should not pre-load all downstream concepts.

If a later fusion case requires one of these branches, the preferred sequence is:

`source-native case -> identify missing Card burden -> open bounded branch -> derive minimal field -> cross-card reconciliation -> decide whether Card changes`.
