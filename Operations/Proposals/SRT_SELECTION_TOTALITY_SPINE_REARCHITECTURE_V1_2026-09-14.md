# Proposal — Selection-totality spine rearchitecture v1

## 0. Core change

The current architecture should no longer be read primarily as a ladder of different ontic items.

Candidate governing sentence:

> **Selection is not one event-type inside reality. Selection is reality in its generative mode; the named SRT layers are distinguishable structural organizations, relations and cuts of Selection.**

This is Selection-monist and Selection-nonflat.

## 1. Resolve the word `Selection`

A central ambiguity now matters:

```text
Selection-totality
!= one-shot Selection-event.
```

Use two reading levels without introducing a new ontic kind:

```text
Selection reality / Selection process
= the whole generative mode;

actualising Selection event
= a determinate event-cut in which a manifest difference is instituted.
```

The event is a mode / cut of Selection reality, not an external product or a separate substance.

This distinction prevents the thesis `everything is Selection` from implying that every object is one instantaneous choice-event.

## 2. Re-read G0

Retain the previous author gate but strengthen its ontology:

```text
primitive Selection reality
has at least two inseparable analytic faces:

O0-side = openness / non-maximal indifference;
S0-side = actualising differentiation.
```

So:

```text
co-primitive burdens: YES;
co-primitive ontic mechanisms: NO.
```

`Oriented Openness` is not upstream of Selection; it is Selection read modally before a completed actuality exhausts the relation.

## 3. Re-read existence

Replace the factory/product intuition:

```text
Selection -> existence
```

with the stronger ontological identity-at-aspect:

```text
Selection-as-actual
= manifest existence.
```

Safe wording:

> Existence is Selection under determinate actuality.

This does not erase the occurrence / persistence / Stable-ISP distinctions.

## 4. Re-read potentiality

Avoid:

```text
first there is a latent warehouse;
then Selection operates on it.
```

Candidate:

```text
potentiality
= Selection's non-exhausted / not-yet-determinate openness aspect.
```

Potentiality is real as a modal aspect, but not an inventory of preformed objects external to Selection.

## 5. Re-read L0 / L1 / L2

Candidate analytical typing:

```text
L0
= Selection under open / not-fully-preclosed generativity;

L1
= Selection under determinate manifestation / actuality;

L2
= Selection under retained historical efficacy,
  where prior actualisation materially constrains later Selection.
```

These are not three substances and not necessarily three chronological containers.

Current formal domain semantics must be audited before landing this wording canonically.

## 6. Re-read history

```text
history
= prior Selection still selecting indirectly,
  by remaining materially effective in current Selection conditions.
```

More precisely:

```text
prior Selection
-> retained difference / constraint
-> later Selection condition.
```

Do not infer durable history from every event.

## 7. Re-read One

One is not something added to Selection.

Candidate:

```text
One
= Selection acquiring relatively separable recurrent self-conditioning.
```

Current One owner gives the detailed admission burden:

```text
prior Selection-generated organization
materially enters later Selection;
later Selection renews organization;
the conditioning role recurs;
formed locality / relative continuation separability emerges.
```

`One != Selection event` remains true because recurrent self-conditioning adds a real structural burden.

## 8. Re-read Selection-position

```text
Selection-position
= formed Selection localized as an operative `from-where` in a current Selection.
```

It is Selection's positional organization, not an independently existing selector.

## 9. Re-read Stable ISP

```text
Stable ISP
= Selection organization with stronger recurrent standing:
  perspective-bearing + history-bearing + same-center recurrent reconstitution
  + continued selectability over declared range.
```

This remains a stronger gate and does not become synonymous with One.

## 10. Re-read Bearer

```text
Bearer
= Selection organization under prospective self-exposure:
  formed One / Selection-position + P + E.
```

Bearer is not a new material and not automatic for Selection reality generally.

## 11. Re-read Agency

Candidate deep definition direction:

```text
Agency
= Selection participating in the rewriting of conditions of future Selection,
  through a formed organization meeting stronger control / revision / attribution gates.
```

This is stronger than merely changing the world: the relevant Selection can enter the production / revision of the constraints through which later Selection proceeds.

## 12. Re-read normativity

The strongest result of this reconstruction:

```text
normativity
= Selection becoming reflexively constrained by the Selection-conditions
  that formed / relational Selection itself creates or rewrites.
```

This does not mean:

```text
Selection occurrence = good;
Selection occurrence = ought;
all Selection ought to continue.
```

Instead:

```text
formed Selection-position
-> O1 indexed generative stronger/weaker;

relation-transforming Selection
-> O2-C constitutive constraints on relation integrity;

agency-qualified relation-transforming Selection
-> O2-A answerability;

cross-position all-things-considered adjudication
-> O2-M remains OPEN.
```

Compact thesis:

> **Selection is the source-condition of normativity because Selection can come to shape the conditions of Selection itself.**

## 13. The spine becomes a branching mode map

Candidate top-level map:

```text
Selection reality
│
├─ modal openness / non-flatness
│
├─ actualisation / manifestation
│
├─ retained efficacy / history
│
├─ recurrent self-conditioning / One
│      └─ formed operative locality / Selection-position
│
├─ stronger recurrent standing / Stable ISP
│
├─ prospective self-exposure / Bearer
│
├─ reflexive condition-rewriting / Agency
│
└─ Selection constraining Selection
       ├─ O1 indexed comparison
       ├─ O2-C constitutive ought
       └─ O2-A answerability
```

This is **not** one compulsory temporal ladder. Branches require separate gates.

## 14. New canonical discipline — facet before kind

Before creating or retaining an ontological noun, ask:

```text
Does this concept require a genuinely new ontic kind?
OR
Is it a distinct structural facet / organization / relation of Selection?
```

Default under current author direction:

```text
prefer facet / organization / relation typing;
new ontic kind requires independent proof burden.
```

This is the governance expression of anti-objectification.
