# Neural Unity / Bearer D2 Discriminator Design — 2026-08-28

> **Status / boundary:** spec-stage P3/P4 proposal. No empirical support is claimed. This file does not define consciousness or bearerhood and does not modify IIT, GNWT, bodily-self, or SRT canonical claims. Its sole purpose is to identify prospective contrasts capable of paying the scientific-distinctiveness burden of the residual bearer architecture after novelty subtraction.

---

## 0. Why this proposal exists

Two rounds of novelty subtraction eliminate weak tests.

Do **not** spend a new workline merely showing that:

```text
self-related stimuli differ from other-related stimuli
body ownership can be manipulated
agency and ownership dissociate
interoception contributes to selfhood
autonomous systems regulate viability
copying creates identity problems
global access differs from local processing
```

All are established neighboring territory.

The target must instead isolate a contrast that follows from SRT's remaining candidate discriminator:

```text
bearer-relevant unity
=
where consequences close as same-unit history
+ where that history rewrites later selectability
+ where cost cannot be harmlessly outsourced / reset
```

The two highest-value worklines are:

1. **D2-IIT:** causal-complex boundary versus consequence-bearing boundary;
2. **D2-ACCESS:** global-access / reportability unity versus bearer-indexed consequence unity.

A third clinical/phenomenological line is retained only as triangulation, not as primary D2.

---

## 1. D2-IIT — Causal complex versus consequence-bearing unit

### 1.1 Rival freeze

**IIT-side bounded rival claim:** at a declared model grain, the candidate conscious substrate is identified through maximal intrinsic irreducible cause-effect power / exclusion; the winning complex has definite borders and grain.

**SRT-side bounded claim:** a bearer boundary is not fixed by causal irreducibility alone. A stronger bearer candidate requires same-unit consequence return, history-bearing writeback, non-outsourcing pressure and future-selectability change.

The contrast is not:

```text
IIT has boundaries; SRT has boundaries
```

but:

```text
Boundary_IIT = maximal intrinsic causal irreducibility

Boundary_SRT-B = consequence/history closure under non-outsourcing audit
```

### 1.2 Core D2 question

> **Can a finite dynamical model be constructed in which the maximally irreducible causal complex remains fixed while the SRT bearer verdict or bearer boundary changes under a manipulation of consequence closure / historical writeback?**

If yes:

```text
O_IIT invariant
while
O_SRT changes
```

which is a genuine D2 candidate.

If no coherent model can do this without necessarily changing IIT's complex, the proposed SRT distinction weakens.

### 1.3 Minimal architecture family

Use small deterministic / probabilistic Boolean or finite-state networks to keep exhaustive causal analysis feasible.

Declare modules:

```text
C = recurrent causal core
M = persistent history / damage state
A = action / output interface
E = external consequence channel
```

Construct matched variants.

#### Variant V0 — isolated causal core

```text
C <-> C
C -> A -> E
```

Consequences do not return to the internal system.

Expected:

```text
strong causal unity possible
weak bearer evidence
```

#### Variant V1 — external logging only

```text
C <-> C
C -> A -> E -> M
```

`M` records failure but does not causally alter later `C` selection.

Expected SRT:

```text
history fact / log
!= bearer writeback
```

#### Variant V2 — replaceable external controller update

```text
C -> A -> E -> M_external
M_external -> future input to a freshly reset / replaceable C
```

Behavior can become history-sensitive while the candidate `C` itself does not bear the previous cost.

Expected SRT:

```text
policy adaptation
!= same-unit bearing
```

#### Variant V3 — same-unit writeback

```text
C <-> C
C -> A -> E
E -> M_internal
M_internal <-> C
```

Failure modifies an internal state that persists and changes later reachable transitions of the same continuing organization.

Expected SRT:

```text
stronger bearer candidate
```

#### Variant V4 — rollback control

Run V3, then restore `C + M_internal` from a pre-consequence checkpoint while retaining an external record of the event.

Expected SRT:

```text
external historical fact
!= current same-bearer retained consequence
```

This overlaps AICONSC01 conceptually, but here the purpose is specifically to compare the **boundary verdict** with an IIT complex calculation, not to infer AI consciousness.

### 1.4 Required model matching

The workline is invalid if variants trivially differ on everything.

Match as far as possible:

```text
node count
state alphabets
base recurrent topology of C
input/output capacity
task performance before manipulation
average activity / transition entropy
external sensory statistics
```

Manipulate primarily:

```text
location and directionality of consequence writeback
reset / replacement architecture
```

### 1.5 Observables

IIT-side or IIT-inspired bounded observable:

```text
identified maximal complex / borders / grain
system integrated-information readout where computationally feasible
```

SRT-side declared observables:

```text
same-unit consequence retention
prospective writeback-ablation effect
future transition / reachability change
rollback sensitivity
counterfactual consequence separability
```

Do not use one metric as the definition of SRT bearerhood. This is a discrimination matrix.

### 1.6 Pass / fail logic

**D2-positive candidate:**

```text
IIT complex / border remains matched or invariant across a declared pair
AND
SRT bearer audit changes prospectively under consequence-closure manipulation
AND
the change predicts later behavior / reachability beyond generic state-memory covariates
```

**NO-GO / translation-only:**

```text
every bearer manipulation necessarily changes the IIT complex in the same direction
OR
SRT verdict reduces to ordinary causal integration / recurrent memory
OR
SRT difference disappears when generic state persistence is controlled
```

### 1.7 Why this is the highest-priority workline

It directly tests the claim:

```text
causal whole != bearer whole
```

against a theory that already has a sophisticated border / grain criterion. A successful contrast would be much more informative than showing that GNWT, bodily-self or interoception measures correlate with self-related processing.

## 2. D2-ACCESS — Global access versus bearer-indexed consequence unity

### 2.1 Rival freeze

**Workspace-side bounded construct:** conscious access is associated with broad availability / broadcasting of selected information for memory, planning, evaluation, report and action.

**SRT residual claim:** global availability does not by itself determine where consequences are borne as same-unit history.

### 2.2 Core question

> **Can content be matched on conscious access / reportability while differing in bearer-indexed consequence ownership, and does that difference produce a distinctive persistent writeback profile after controlling for arousal, valence, salience and generic reinforcement?**

### 2.3 Human experimental skeleton

Use fully suprathreshold, reportable contents so conscious access is not the manipulated factor.

Candidate factorial:

```text
Access: held high / matched
Outcome sensory magnitude: matched
Valence: matched as closely as feasible
Agency / controllability: crossed or measured
Consequence recipient: self vs other / external unit
Persistence: transient vs history-writing consequence
```

A possible paradigm uses a dyadic or avatar-mediated choice task in which the same visible outcome occurs, while the consequence is experimentally assigned to:

```text
A. participant's own later effort / resource / task capacity
B. matched other-agent / avatar resource
C. external neutral counter with no continuing owner
```

All outcomes remain equally visible and reportable.

### 2.4 Candidate dependent variables

Do not use `self > other` activation as the target result.

Primary target is **post-consequence deformation of the same participant's later selection policy**, for example:

```text
change in later transition preference
avoidance generalization
switching cost
memory weighting
counterfactual option valuation
interoceptive / affective coupling
persistence across context change
```

with pre-registered mediation tests separating:

```text
generic salience
reward prediction error
arousal
explicit instruction
social concern
from
same-bearer consequence writeback candidate
```

### 2.5 Strong negative controls

1. **Observed-other consequence:** same sensory/affective observation, consequence borne by another.
2. **Symbolic-self consequence:** screen says `your loss` but nothing about the participant's future task changes.
3. **Generic reward consequence:** equal monetary / score loss without altering future task capacity.
4. **Agency-matched condition:** outcome is self-borne but not self-caused, separating bearing from agency.
5. **Agency-without-bearing condition:** participant causes a matched outcome borne elsewhere, separating agency from bearing.

These controls are essential because bodily-self / agency literature already shows that ownership, agency and self-location can dissociate.

### 2.6 Interpretation boundary

A positive effect would **not** prove bearerhood or consciousness.

It would support only the narrower claim that:

```text
access / reportability
and
same-unit consequence-linked historical deformation
are separable experimental dimensions
```

### 2.7 Failure condition

If all effects are fully explained by standard reinforcement learning, self-reference, salience, arousal, valence, agency or social valuation under matched controls, the SRT-specific workline is D2-negative / translation-only.

## 3. BODILY-SELF triangulation — not primary novelty test

The literature already distinguishes:

```text
body ownership
self-location
first-person perspective
sense of agency
```

and shows partially distinct neural substrates / manipulability.

Therefore SRT should not present those dissociations as predictions.

The useful role is triangulation:

> Which existing bodily-self measures best track the SRT `from-here` / bearer-indexing candidate, and which clearly do not?

### Candidate synthesis matrix

| Construct | SRT relation to test |
|---|---|
| body ownership | candidate self-attribution readout, not bearer identity |
| self-location | spatial index, not consequence ownership |
| first-person perspective | perspectival orientation, not phenomenality proof |
| agency | action-source experience, can dissociate from bearing |
| interoception | biological bearer-indexing channel candidate |
| depersonalization / dissociation | possible disruption of bearer-indexing / phenomenal ownership relation |

A 2025 meta-analysis of bodily self-consciousness and a 2026 systematic review of interoception in dissociation make this a timely empirical bridge, but not a safe originality claim.

## 4. Clinical candidate matrix

Use only after mechanistic hypotheses are specified.

### Depersonalization / dissociation

Candidate question:

```text
ordinary sensory access remains
while felt ownership / presence / interoceptive trust changes
```

Potentially useful for:

```text
access != ownership / for-me
```

but not by itself for bearer numerical identity.

### Alien hand / agency disorders

Potential:

```text
body ownership != agency
```

already established; use as calibration only.

### Anosognosia / somatoparaphrenia

Potential:

```text
physical body continuity != explicit ownership attribution
```

again calibration, not SRT novelty.

### Split brain

Potential:

```text
one organism
with contested access / phenomenal / subject unity
```

best used to test whether SRT's bearer branching diagnostic can make a distinct prediction beyond behavioral access disconnection.

## 5. Revised manuscript Figure / theory matrix

The Collection paper should map theories by the unity they operationalize.

```text
IIT
-> intrinsic causal / exclusion unity

GNWT
-> access / broadcast unity

RPT
-> recurrent perceptual-content formation

bodily-self / Damasio
-> organismic / interoceptive indexing and subjectivity

enactivism
-> autonomous / viability-centred self-individuation

SRT candidate
-> typed distinction between object, bearer, selector/subject and experiencer,
   with bearer audited by consequence closure / non-outsourcing
```

The claim is **not** that these theories are wrong or incomplete in one common way.

The claim to test is:

> different theories may successfully identify different forms of `one`, while disagreement becomes confused when those unities are treated as interchangeable answers to the same consciousness question.

```text
strongest rival

```

## 7. Terminal dispositions

Each workline must end in one of:

```text
D2-positive local contrast
D2-negative / rival-equivalent
spec-stage NO-GO
```

Do not keep a failed contrast alive by changing datasets or relabeling variables after outcome inspection.

Under PD-A, only independently motivated, prospectively frozen D2 worklines count toward architecture-level empirical fruitfulness.

---

## 8. Bottom line

The strongest next test is no longer `does the brain integrate?` or `does self-related information differ?`.

It is:

> **Can the unit that is causally most integrated, globally accessible, bodily owned, or phenomenally unified come apart from the unit on which consequences close as a non-outsourcable history that rewrites future selection?**

If the answer is prospectively and reproducibly yes, SRT gains a real middle-level discriminator. If the answer is no across mature matched tests, bearer/non-outsourcing should be narrowed from a distinctive construct to a translation of existing autonomy, identity or causal-integration structure.
