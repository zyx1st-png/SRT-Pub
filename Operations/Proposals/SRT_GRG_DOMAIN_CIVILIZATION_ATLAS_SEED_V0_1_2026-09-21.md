# GRG Domain + Civilization Atlas — seed v0.1

## 0. Purpose

This is a navigation and work-routing surface.

It does not claim that every listed domain already has a GRG realization.

The atlas records:

- existing repository assets;
- framework maturity;
- active relation candidates;
- calibration state;
- civilizational relevance;
- next bounded framework action.

## 1. Maturity labels

~~~text
A0 = no active GRG/domain surface
A1 = inherited assets only
A2 = domain reconstruction surface exists
A3 = relation records / GRG mapping begun
A4 = calibrated by evidence / adverse result
A5 = cross-domain transfer contribution earned
~~~

These are programme maturity labels, not truth or ontology Levels.

## 4. First civilizational case queue

The first cases should pressure the schema, not prove GRG.

### CIV-001 — common-pool resource governance

Why useful:

- identifiable participants;
- local rules;
- resource regeneration;
- free-riding / externality;
- institutional revision;
- long-run success and failure variation.

Primary neighbor ownership must begin with Ostrom-style institutional analysis rather than GRG vocabulary.

### CIV-002 — Montreal Protocol / ozone governance

Why useful:

- science -> institutional expectation -> coordinated intervention -> measurable environmental consequence;
- cross-national coordination;
- technological substitution;
- delayed system response.

Guard:

Do not treat one policy success as universal governance proof.

### CIV-003 — antibiotic use and resistance

Why useful:

- local benefit / population-level generative cost;
- feedback across biological and institutional scales;
- short-horizon versus long-horizon expectation conflict.

Guard:

Separate biological mechanism from policy / incentive architecture.

### CIV-004 — standardized technical protocols / internet interoperability

Why useful:

- externalized expectations;
- coordination through shared constraints;
- generativity through standardization;
- tension between openness and lock-in.

Guard:

technical persistence != social legitimacy.

### CIV-005 — scientific peer correction / replication

Why useful:

- objectification;
- distributed criticism;
- anomaly;
- institutional memory;
- self-revising grammar learning.

Guard:

idealized science != actual scientific institutions.

### CIV-006 — historical urban infrastructure lock-in

Why useful:

- early path formation;
- durable material constraint;
- later option shaping;
- maintenance cost;
- redesign difficulty.

Guard:

path dependence alone != GRG-R1c.
