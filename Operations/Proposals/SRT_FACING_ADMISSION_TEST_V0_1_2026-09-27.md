# Facing Admission Test v0.1

> Role: noncanonical operational test for assigning a construct-level explanatory burden to L0-facing, L1-facing, L2-facing, or an explicit bridge/mixed status before cross-theory comparison.
>
> Boundary: this test does not create three substances, does not replace canonical L0/L1/L2 owners, and does not make facing assignments permanent properties of concepts.

## 0. Core principle

Facing assignment is not: what layer does this thing essentially belong to?

It is:

~~~text
Relative to the declared explanandum and cut,
what explanatory burden is this construct carrying?
~~~

Every verdict is indexed to construct + target explanandum + declared cut + explanatory level/scale + source context.

## 1. Non-reification rule

~~~text
L0-facing / L1-facing / L2-facing
= analytic / execution views;
!= three substances;
!= three universally sequential temporal stages.
~~~

Primitive Selection may be read under co-primitive analytic burdens:

~~~text
L0-facing = non-preclosed / open generative burden;
L1-facing = actualised determinate differentiation / manifestation.
~~~

Do not silently convert this into a temporal ladder in which an L0 thing later becomes an L1 thing.

## 2. Step 0 — declare the target cut

No facing verdict is admissible until the current cut is declared.

Record at minimum:

~~~text
UNIT: what counts as one operative entity / event?
BOUNDARY: what is inside / outside the unit?
GRAIN: what distinctions are ignored or retained?
EQUIVALENCE: what counts as the same state / object / role?
STATE / CANDIDATE SPACE: what variables, possibilities, actions or outcomes are already admitted?
COMPARISON RULE: what makes two states / candidates comparable?
TIMESCALE: over what interval can formation / retention be identified?
OBSERVER / ACCESS RELATION: what counts as available evidence or manifestation?
~~~

If these cannot yet be declared, use FACE-UNDETERMINED rather than guessing.

## 3. Two-axis record — burden vs realization

Every test must distinguish:

~~~text
A. EXPLANATORY BURDEN FACING
B. FORMAL / MODEL REALIZATION FACING
~~~

A theory may carry an L0-facing philosophical burden while using an L1-facing formal model with declared state variables. Conversely, latent or hidden variables do not thereby become L0-facing.

Hard guards:

~~~text
formal latent != L0-facing automatically;
observable != L1-facing automatically;
mathematical state space != proof that the source theory is object-first;
pre-object vocabulary != proof of L0-facing admission.
~~~

## 4. Admission questions

### Q1 — presupposed-cut test

Does the construct require the current unit / boundary / variables / candidate space / comparison rule to be already determinate in order to be defined?

YES gives strong pressure against L0-only admission and usually routes toward L1, L2, bridge or mixed.

### Q2 — cut-genesis test

Is the construct itself trying to explain how those determinate units / boundaries / variables / candidates / comparison relations become determinate?

YES supports FACE-L0-CANDIDATE or FACE-L0<->L1-BRIDGE, but is not sufficient by itself.

### Q3 — actual-determination test

Does the construct describe the currently manifest / actualised / operative organization under the declared cut?

YES supports FACE-L1. A construct may still be dynamic, hidden, latent, generative or nonconscious and remain L1-facing.

### Q4 — retained-efficacy test

Does a prior achieved differentiation / organization remain materially effective in conditions of later Selection?

YES supports FACE-L2.

Hard guard:

~~~text
mere record / description / archive
!= L2-facing retained efficacy
unless later-effective role is established.
~~~

### Q5 — bridge test

Is the construct's main explanatory role the transition / constitution relation between facings?

Examples include pre-object burden -> determinate manifestation, formed organization -> retained historical constraint, or retained trace -> reconstruction of earlier generation.

If YES, prefer an explicit bridge label rather than forcing a single facing.

### Q6 — removal test

Remove in thought the currently admitted object inventory, state coordinates, candidate menu, comparison scale, boundary and observer-ready output.

Ask whether the construct retains the same explanatory burden.

~~~text
NO -> strong L1/L2 pressure;
YES because it still names the burden by which those distinctions become determinate -> L0-facing pressure;
PARTLY -> bridge / mixed.
~~~

Removal survival is not by itself proof of primitive L0.

### Q7 — same-event aspect test

Is the apparent L0/L1 difference merely two analytic readings of the same constitutive event rather than two successive mechanisms?

If YES, record a dual/aspect relation and do not invent temporal precedence.

### Q8 — formalism trap test

Is an L0-facing source burden being downgraded only because the theory uses a state-space formalization? If yes, separate source burden from model realization.

Inverse check: is a formal latent space being upgraded to L0 merely because it is hidden, probabilistic or high-dimensional? If yes, reject the upgrade.

### Q9 — back-import test

Does the proposed L0-facing interpretation silently import already formed L1/L2 content?

Common forbidden back-imports include:

~~~text
subject / chooser;
completed option menu;
fixed value function;
moral good;
goal / preferred endpoint;
formed attractor;
retained history;
Bearer;
Expectation;
Concern;
phenomenality.
~~~

If YES, L0 admission fails or must be narrowed.

### Q10 — falsifier for the facing assignment

Every verdict must state what new source evidence would change it.

No falsifier -> facing-assignment confidence cannot exceed LOW.

## 5. Allowed verdicts

~~~text
FACE-L0-CANDIDATE
FACE-L1
FACE-L2
FACE-L0<->L1-BRIDGE
FACE-L1<->L2-BRIDGE
FACE-MIXED
FACE-UNDETERMINED
~~~

Bridge is not uncertainty:

~~~text
BRIDGE = the explanatory relation itself crosses facings;
UNDETERMINED = evidence is insufficient to type the relation.
~~~

## 6. Minimum admission criteria

### FACE-L0-CANDIDATE

Require all:

~~~text
1. target cut declared;
2. construct does not simply depend on the cut as already complete, OR explicitly makes cut genesis part of its explanandum;
3. removal test leaves a genuine explanatory burden;
4. no forbidden L1/L2 back-import is required;
5. source support exists;
6. falsifier stated.
~~~

### FACE-L1

Require that the construct identifies current actualised / manifest / operative organization under a declared cut.

### FACE-L2

Require that prior achieved differentiation / organization remains materially effective later.

### BRIDGE

Use bridge when forcing a single label would destroy the explanatory role.

## 7. Comparison admission rule

Before any comparative verdict such as ABSORBED / SOURCE-PAID / EQUIVALENT / NO-GAIN / REPLACED / DISTINCTIVE, record both sides:

~~~text
SRT construct facing:
neighbor construct facing:
comparison type:
  SAME-FACING
  BRIDGE
  INVALID-CROSS-FACING
~~~

Default admissible comparisons:

~~~text
L0 <-> L0
L1 <-> L1
L2 <-> L2
~~~

Cross-facing comparison is admissible only if the bridge / derivation relation itself is the target.

## 8. Fast decision tree

~~~text
START
 |
 |-- target cut declared?
 |      NO -> UNDETERMINED
 |      YES
 |
 |-- construct mainly requires already-determinate cut?
 |      YES
 |       |-- current operative organization? -> L1
 |       |-- prior organization later-effective? -> L2
 |       `-- relation between them? -> L1<->L2 BRIDGE
 |
 `-- construct makes determinacy / cut genesis itself explanandum?
         NO -> likely L1/L2; inspect again
         YES
          |-- names constitutive transition into determinate manifestation?
          |       YES -> L0<->L1 BRIDGE
          `-- burden survives removal of current cut without formed-content back-import?
                  YES -> L0 CANDIDATE
                  NO/PARTIAL -> BRIDGE / MIXED
~~~

## 9. Confidence

~~~text
HIGH = source-native role explicit and multiple tests converge;
MEDIUM = source-native role supported but bridge / cut dependence remains interpretive;
LOW = assignment depends on sparse or secondary evidence.
~~~

Confidence concerns the facing assignment, not the truth of the theory.

## 10. Calibration requirement before promotion

v0.1 must not be promoted into Facing v0.3/v0.4 until:

~~~text
1. calibration seed executed on mixed internal + external constructs;
2. at least one independent model/session reruns assignments without seeing seed labels first;
3. disagreements classified as definition ambiguity / cut mismatch / source ambiguity / genuine bridge;
4. criteria revised if disagreement is systematic;
5. no canonical owner edit is made merely from calibration.
~~~
