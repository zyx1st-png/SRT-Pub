## 2. Prospective-memory assay — strongest surviving version

~~~text

~~~

Method guards:

1. chance must be defined against the participant’s actual induced base rates, not a uniform category distribution;
2. probe questions themselves are retrieval cues, so include a no-probe or weak-probe control;
3. separate confidence / fluency / arousal from directional structure;
4. naturalistic self-reports can be exploratory only because the forgotten target is not independently known.

Strongest surviving test:

> Does pre-recall cross-probe structure predict which specific target will later be recovered, beyond personal base rates, cue familiarity, confidence, arousal and a strong latent-state / prospective-memory comparator?

A positive result still does not establish SRT.

## 4. False-candidate test — highest-value discriminator candidate

Compare:

~~~text

versus

with matched self-judged completion
~~~

Match as closely as possible:

- confidence;
- familiarity;
- subjective “this is it”;
- self-judged completion;
- response latency.

Then test release using outcomes not reducible to confidence:

- spontaneous re-intrusion;
- later target recovery;
- implicit target accessibility;

- downstream action selection.

Candidate discriminating pattern:

> A false candidate can match confidence and self-judged completion yet fail to produce the same durable release / writeback profile as the true target.

Adverse result:

> If a false candidate matched on subjective completion produces the same release profile, this explanatory job is absorbed by mature goal / metacognitive accounts.
