# SRT Selection-First Unified Ontology — Phase II Internal Dependency Map v0.1

> **Scope:** Phase II internal architecture only. This file asks “SRT itself currently owns what, and which constructive arrows still need commitments?” It does **not** run external prior-art subtraction, novelty classification, rival duels, D2 design, or canonical edits.
>
> **Input:** Constructive Ontology Draft v0.2. The draft is a research map; this file types its nodes and arrows against current repository owners.
>
> **Status vocabulary:**
>
> ```text
> OWNED                   current SRT owner already carries the relevant role
> CONSTRUCTIVE-CANDIDATE  Phase I positive addition; no current owner yet
> ADDITIONAL-COMMITMENT   current architecture needs a separately admitted premise/condition
> INTERPRETIVE-BRIDGE     a coherent SRT reading, but not a constitutive derivation
> OPEN-GAP                exact relation is not currently owned/derived
> CONTRADICTION           conflicts with current owner/author decision
> ```
>
> `OWNED` never means “derivable from P0-01 alone”. Maturity/claim level is recorded separately.

# 2. Edge ledger

```text
STATUS: OWNED

OWNER: P0-01 AM-A
```

Owned content:

```text
non-objectified potential
```

Important: this is a primitive stopping point, not a derivation from a prior chooser or completed menu.

## U02 — determinate actuality → local One

```text
STATUS: CONSTRUCTIVE-CANDIDATE + OPEN-GAP
```

P0-01 owns **determinate distinction**, but current owners do not yet state that every determinate distinction thereby establishes a local unity condition satisfying the v0.2 `One` burden.

Split the question:

```text
actuality -> distinction        OWNED

distinction -> effective boundary ?
distinction -> operative grain ?
boundary + grain -> local One ?
```

The latter three are Phase II construction questions, not novelty questions.

**Do not** solve U02 by inserting a new primitive `Unity` beside Selection.

---

## U03 — local One / distinction → minimal negative determination E0

```text
STATUS: INTERPRETIVE-BRIDGE
```

Candidate argument:

```text
determinate this
-> a meaningful outside / not-this is fixed minimally
```

This looks close to conceptual entailment, but the current P0 owner does not separately define an ontology of unrealized alternatives. Therefore E0 may be developed as an interpretation of determinacy; E1/E2 must not be smuggled into it.

## U04 — E0 / actuality → retained difference

```text
STATUS: ADDITIONAL-COMMITMENT / OPEN-GAP
```

This is the first major missing bridge.

Current owner fact:

```text
P0-01 primitive actualisation
-/-> durable trace / L2 writeback
```

P0-03 instead supplies a conditional floor:

```text
IF selection is anchored into L1
AND leaves history in L2
THEN it cannot be treated as never having occurred
```

Therefore v0.2 `Retention Bridge` should remain explicit:

> Some actualisations alter or become recoverable within later constraint structure.

Whether this is already fully paid for by P0-03 + L2, or needs a cleaner middle-level principle, is a real architecture decision.

---

## U05 — retained difference → historical conditioning

```text
STATUS: OWNED AT FULL-SRT MIDDLE LEVEL
ATTRIBUTION: NOT P0-01-ALONE
```

L2 / historical machinery already supports traces constraining later selection. R2-CORE C2/C3b specifically blocks re-crediting this whole result to primitive Selection.

No new theory owner is needed merely to say “history can condition later selection”; the constructive increment is to place that owned mechanism in the unified ontology.

## U08 — history/writeback → borne history / bearer admission (`from here`)

```text
STATUS: OPEN-GAP / MIDDLE-LEVEL ROLE OWNED
```

This is the second major missing bridge.

Existing sigma architecture requires a distinction like:

```text
theta^trace = written by P's own prior outputs
!=
theta^ext
```

That tells us what role is needed, but not what makes `P's own` non-circularly well formed.

Therefore:

```text
sigma names/tracks a role
!=
sigma proves same-unit bearer admission
```

v0.2 positive target:

> borne history = historical consequences constitutively indexed to the identity of one continuing unit, without requiring causal self-sufficiency.

This target is compatible with external support, shared memory, environmental coupling and material dependence.

So this is not a single free derivation. Treat Stable ISP as an additional structured package layered above bearer admission unless a later compression proof shows redundancy.

## U13 — bearer + future asymmetry → stake

```text
STATUS: PARTLY OWNED / ADDITIONAL-COMMITMENT
```

The d owner canonically anchors stake-coupled concern / irreversible-risk sensitivity. It also requires consequence return, identity continuity and future selection capacity for proxies to approximate d.

What is **not yet automatically owned** is the derivation:

```text
bearer exists
-> stake necessarily exists
```

A bearer may need an additional viability/continued-selectability asymmetry before a genuine stake exists.

Thus v0.2 should keep:

```text
bearer + asymmetric consequences for continuation
-> stake candidate
```

rather than `bearer -> stake` simpliciter.

# 4. The deepest current gaps — ranked by architectural upstreamness, not novelty

This ranking is **not** publication priority.

### G1 — local One burden

```text
determinate manifest distinction
-> ?
local unity / boundary / grain
```

Why first: it is the earliest constructive addition after P0 and controls how all later individuation language is interpreted.

### G2 — Retention Bridge

```text
actuality
-> ?
retained difference
```

Why second: without it the ontology never becomes historical; P0-03 currently supplies a conditional floor rather than a complete generative explanation.

### G3 — Object reidentification

```text
historical recurrence
-> ?
still this
```

Why third: objecthood should be positively generated before bearer is defined as “more than object”.

### G4 — Bearer same-unit / borne-history admission

```text
history/writeback
-> ?
from here
```

Why fourth: this is the lower domain-of-definition burden presupposed by sigma and subject-position models.

### G5 — Phenomenal architecture

```text
from here / selection from here
<-> ?
for me
```

Why fifth: it is not less important; it is downstream of distinctions that help state the burden without conflation. But Phase I must continue exploring it in parallel rather than waiting for G1-G4 to be “solved”.

# 5. Phase II action rule

The next constructive work should **not** be one PR per gap plus one novelty audit per PR.

Instead build a bounded **Constructive Commitments Charter** with one row per G1-G5:

```text
candidate claim
why needed in unified ontology
minimal additional commitment
what it must NOT presuppose
what existing owner it connects
what would count as philosophical failure
```

Only after this charter is coherent should Phase III ask which pieces are already present in adjacent traditions, whether the architecture is genuinely distinct, or whether some pieces reduce to translation.

# 6. Phase II v0.1 conclusion

The Selection-first rebase should no longer be described as trying to prove:

```text
Selection alone
-> history
-> object
-> bearer
-> subject
-> consciousness
```

The more accurate unified architecture is:

> **Selection fixes the ontological floor of determinate actualisation. SRT then requires a typed set of additional commitments and already-owned middle-level structures to explain historical retention, reidentification, borne-history unity, subject-position, value, agency and phenomenality. The unification claim lives in the explicit dependency architecture and common generative grammar—not in pretending every layer is a theorem of one primitive.**

This is the positive target for the next pass.
