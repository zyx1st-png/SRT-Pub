# Author Re-entry Cycle 1 — Multiplicity / Selection / One-formation

> **Role**: first live-use working packet for the 2026-09-05 author-reentry programme. It tests the new `K/A/B/C/D` discipline on one foundational formation problem while beginning actual theory formation.
>

It records current constraints, already-recorded author material, recovered historical routes, AI-only decomposition, and unresolved questions so the author can re-enter before neighbor pressure and second adjudication.

## 0. Why this is the first calibration case

The current programme requires at least one foundational cycle involving:

```text
multiplicity / Selection / One-formation
```

This axis is useful because one part is already constrained by a current canonical owner while the broader relation is genuinely open:

```text
world-side determinate manifest actuality
-> K constraint already exists

Selection <-> broader One-formation
-> exact relation remains D
```

The first test is therefore simple but non-trivial:

> Can the reconstruction keep `K` and `D` on the same ontology axis without flattening the canonical constraint into an open candidate or turning the open relation into a hidden conclusion?

This calibration does **not** test the Level 0/1/2 gate yet. That gate requires a named strongest neighbor and a bounded author-owned SRT response, neither of which exists at this stage.

---

## 1. Cycle question

The broad question is:

> **How do multiplicity, Selection, and broader One-formation relate, and which parts of that relation belong to determination, manifestation, stabilization, re-identification, objectification, or later persistence?**

This deliberately avoids the shortcut:

```text
One-formation = Selection
```

and also avoids treating `One-formation` as if its meaning were already settled.

## 2. K — current canonical constraints

These are retrieval-aid summaries only. If any wording here diverges from the canonical owner, `Core_Law/SRT_L0_Metaphysics.md` controls.

### K1 — determinate manifest actuality is downstream of Selection

Current L0 `§一「选择先于存在」` / `第一命题（EX-A／Gate 0 合并口径）` requires:

```text
For world-side determinate manifest actuality,
Selection precedes / produces the actuality.
```

Therefore the ordinary candidate

```text
determinate manifest actuality exists first,
then Selection acts on it
```

is not open under the current owner unless that owner is explicitly reopened.

### K2 — Selection does not require a pre-existing selector / bearer

Current L0 `§一「选择不需要选择者」` states that Selection is a subjectless process and selector-patterns are downstream condensations rather than prerequisites.

Therefore Cycle 1 may ask how a bearer or One later emerges, but it may not silently rebuild Selection as the act of an already formed One.

### K3 — actual occurrence, persistence, anchoring and Stable ISP are not identical

The current L0 first proposition distinguishes:

```text
actual occurrence
!= persistent anchoring
!= Stable ISP
```

Therefore a theory of One-formation must not silently import persistence or subject-position into the minimum condition for determinate actuality.

### K4 — later order/convergence must not be smuggled into the formation event

Current L0 does not contain `Order / 秩序` as native content. `selection tends to order` is licensed only as an L1 read-back under the current owner.

This is a side guard for Cycle 1: if stabilization, persistence or convergence becomes relevant to One-formation, it must be argued rather than imported through the old order-drive wording.

## 4. B — recovered historical / superseded / non-current SRT routes

These items are useful because they expose earlier compressions. They are not current authority merely because they exist in the repository.

### B1 — earlier “two Ones” formulation

The earlier author formulation distinguished an externally objectified One from an embodied, self-maintaining, selection-capable One. The later author question about the generation and mutual relation of many and One prevents this from being read as a final two-species ontology.

### B2 — historical “pure potential -> determination” staging

`Core_Law/SRT_Selection_Argument.md` contains a historical staging in which a “pure potential domain” is described before determinate existence. This can inform the question of what precedes a One, but it must not be promoted directly into a current multiplicity ontology.

In particular:

```text
potentiality
!= automatically a plurality of already individuated alternatives
```

That distinction is one of Cycle 1's central burdens.

### B3 — older source work mixed several senses of “Selection precedes existence”

The 2026-07 ChoiceMap resynchronization trace explored multiple readings, including generation, maintenance, manifestation and scaffold readings. Later canonical work narrowed the current L0 requirement for this cycle to determinate manifest actuality, while persistence remains later.

This history is useful because it shows exactly which compression Cycle 1 must avoid:

```text
generation
manifestation
maintenance / persistence
scaffold / support
```

may be related, but they are not automatically one event.

### B4 — exclusion / foreground formation is a recurring historical pressure

Book/source material on exclusion repeatedly asks why formation of a foreground suppresses other becomings and why suppressed possibilities can retain residual effects on later trajectories.

This provides historical pressure toward a relation among:

```text
formation of a One
exclusion / backgrounding
residual unrealized possibilities
future processability
```

but it does not yet prove that exclusion is a necessary condition of every One-formation.

## 5. C — AI-only problem decomposition for author pressure

Everything in this section is an AI working organization. None of it is author-owned unless explicitly adopted later.

### C1 — “multiplicity” may hide several non-equivalent objects

Before asking how many become one, distinguish at least these candidate senses:

```text
M1  unindividuated potential differentiation
    differences / tendencies may be possible without already being separate Ones

M2  articulated plurality
    multiple candidates already have enough identity to count as distinguishable alternatives

M3  position-relative option field
    alternatives exist as live differences relative to a system / position / probe

M4  retrospective plurality
    after one outcome forms, the rejected or unrealized field is reconstructed as “what else could have happened”
```

A theory that says “Selection chooses one from many” changes radically depending on which `many` it presupposes.

### C2 — Selection may stand in different relations to distinction

At least three candidate relations should be kept separate for author adjudication:

```text
S1  Selection chooses among already articulated alternatives.
S2  Selection is part of what makes a distinction determinate enough to count as alternatives at all.
S3  Selection both determines a foreground and recursively changes what later alternatives can become articulated.
```

`S1/S2/S3` are not claims. They are contrastive pressure cases.

### C3 — “One-formation” may be a compressed family rather than one event

A provisional decomposition is:

```text
F1  determination / event-level actuality
F2  boundary or unit formation
F3  stabilization / persistence
F4  re-identifiability across change
F5  public or cognitive objectification
F6  bearer-like self-continuation / own-history
```

Current K only directly closes part of `F1`. Cycle 1 must determine whether some of `F2-F6` belong to broader One-formation, are downstream consequences, or name different problem families.

### C4 — the relation may be networked rather than a ladder

Do not assume:

```text
multiplicity -> Selection -> One -> persistence -> bearer
```

as a generation ladder.

A competing organization is recursive:

```text
prior formation / sedimentation
-> shapes what differences are currently processable
-> Selection / determination
-> changes foreground, exclusions and constraints
-> alters later processability
-> enables or blocks new Ones
```

This is only a working topology. It must not be canonicalized by diagrammatic convenience.

## 6. D — unresolved relations exposed by the bootstrap

The current unresolved field is at least:

1. **What is “many” before One?** Does pre-One multiplicity contain distinguishable candidates, only differential potential, or neither?
2. **Does Selection presuppose articulated alternatives?** If not, what is the minimum structure required for determination without smuggling in pre-existing Ones?
3. **Is determinate actuality already a One?** Or is it only an event from which a more stable unit may later form?
4. **What role does boundary play?** Is a boundary constitutive of One-formation, a later observer cut, or sometimes both at different layers?
5. **Where does persistence enter?** Is persistence part of becoming One, or only of remaining / being re-identifiable as this One?
6. **How do external objectification and self-continuation relate?** Are they different formation modes, different relations to one formation, or only partially overlapping cases?
7. **Is exclusion constitutive?** Does every formation of a foreground One necessarily suppress alternatives, and in what sense can unrealized possibilities retain causal / structural relevance?
8. **Can One alter the future many?** Does a formed One merely persist, or does its history change what later distinctions and candidates can become processable?

None of these questions is answered by the existence of this list.

## 8. First live author-reentry prompts

These prompts are the next conversation surface. They are deliberately phrased before mature-neighbor comparison so the first author pass is not reverse-engineered from a preferred literature match.

### Q1 — before Selection, what is genuinely there?

When you say “多”, is your intuition closer to:

```text
already distinguishable alternatives;
not-yet-individuated differences / tendencies;
a potential field in which “many” is only retrospectively readable;
or something else?
```

### Q2 — what does Selection do to difference?

Is Selection fundamentally:

```text
choosing one of already formed differences;
making a difference determinate;
drawing / stabilizing a boundary;
or a broader process in which these separate only downstream?
```

### Q3 — what is the minimum “One” beyond determinate actuality?

If one event has become determinate, is that already a One in the ontology-relevant sense? If not, what additional relation is minimally required: boundary, persistence, re-identifiability, consequence continuity, something else?

### Q4 — is persistence inside formation or after formation?

Does a One become a One only when it can continue, or can a transient determinate One exist and then fail to persist?

### Q5 — revisit the earlier “two Ones” without restoring a taxonomy

Is an externally objectified One and a self-continuing / embodied One:

```text
the same formation seen through two relations;
two stages of one process;
two genuinely different formation modes;
or an old distinction that should now be abandoned?
```

### Q6 — how do One and many feed back into each other?

When the author question is “多和一的生成及相互关系”, does the important relation run only:

```text
many -> Selection -> One
```

or also:

```text
formed One + accumulated history
-> changes which differences can later become live / processable
-> changes the next many
```

The answer should come from author intuition first; repository and neighbor material can then pressure it.
