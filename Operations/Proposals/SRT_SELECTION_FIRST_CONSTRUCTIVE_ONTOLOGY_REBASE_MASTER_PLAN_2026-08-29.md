# Constructive Ontology Rebase Master Plan — superseded programme pointer

This plan performed an important correction from `subtract first` to `construct first`, but it still assumed the final programme would move:

```text
constructive philosophy
-> internal architecture
-> subtraction
-> hardening
-> formalization
-> D2/D3
```

The author has since made a deeper identity decision:

```text
SRT Constitution
= bearer-involved perspective framework

Domain research
= formalization / evidence / proof / testing layer
```

Therefore this file is no longer active programme authority.

Durable lessons retained:

- construction should not be permission-gated by novelty;
- philosophy should not be forced to orbit an early equation;
- subtraction is quality control rather than idea engine;
- previous audits remain reusable;
- candidate != canonical;
- actuality/persistence/object/bearer/subject/phenomenality distinctions remain valuable pressure guards.

What changes:

- Constitution itself does not proceed to formalization;
- proof/formalization happens in domain research;
- author dialogue and reader-entry operations replace a large constructive-ontology document as the convergence mechanism;
- one domain deep well precedes breadth;
- Neighbor Map occurs after author convergence, not as permission gate;
- Core/Core_Law are role-audited before any mass rewrite.
