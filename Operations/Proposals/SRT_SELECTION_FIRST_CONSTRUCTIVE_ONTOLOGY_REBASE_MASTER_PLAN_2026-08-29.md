# SRT Selection-First Constructive Ontology Rebase — Master Plan

> **Author decision (2026-08-29):** 当前 Selection-first 重构的防守、减法、归属与新颖性审计已经过重，造成研究 programme 从“构建统一的本体论”偏移为“寻找最小剩余原创点”。作者明确改定研究顺序：**先做哲学上的加法，再做减法；加法阶段先不形式化，不以前置新颖性为许可条件。**
>
> **Boundary:** 本文件是 non-canonical programme authority。它不直接修改 P0/P1/P2 owner，不注册新符号，不把任何哲学候选自动提升为 canonical theorem。它改变的是**研究顺序、执行许可与成功判据**。
>
> **Programme precedence:** 在本轮 Constructive Ontology Pass 期间，本文件对 `SRT_SELECTION_FIRST_ARCHITECTURE_REBASE_MASTER_PLAN_2026-08-28.md` 中的 subtraction-first/default-posture、Track-A-first、R2-CORE-first、topic/novelty-first 执行顺序构成**阶段性覆盖（execution overlay）**。旧 Master Plan、Owner Matrix、A0、Freeze/Edit、HP-B-B、G11 等资产继续有效，但退居第二遍质量控制，不再作为第一遍哲学生成的前置许可。

---

## 0. Programme 的重新定位

SRT 当前任务不是：

```text
找到一个尚未被别人占据的细分 residual
-> 证明 novelty
-> 做 D2
-> 找 venue
```

而是：

> **以 Selection 为本体论地板，正面构造一个能够连续解释 actuality、one/many、boundary、relation、history、object、bearer、subject、value、agency 与 consciousness 的统一世界图景。**

因此研究评价单位从“单个 claim 是否新”改为：

```text
统一生成架构是否清楚
各层是否有明确的生成/依赖关系
哪些桥是自由哲学候选、哪些是已拥有结构、哪些最终需要新增承诺
整个 ontology 是否能把传统上分裂的问题放进同一图景
```

新颖性、可形式化性与经验区分仍然重要，但它们是**后续检验**，不是 ontology 生成的前置许可证。

## 1. 新的总顺序：ADD -> ORGANIZE -> SUBTRACT -> HARDEN -> FORMALIZE -> TEST

```text
Phase I    CONSTRUCTIVE PHILOSOPHY / 哲学加法
           ↓
Phase II   INTERNAL ARCHITECTURE / 内部架构整理
           ↓
Phase III  SUBTRACTION & COMPARISON / owner + prior-art 减法
           ↓
Phase IV   CONCEPT HARDENING / 概念与 canonical 边界硬化
           ↓
Phase V    FORMALIZATION / 必要的局部形式化
           ↓
Phase VI   EMPIRICAL DISCRIMINATION / 经验与 D2/D3
```

### 顺序纪律

- Phase I 不因“别人可能讲过”停止。
- Phase I 不因“目前无法从 P0 严格推出”停止。
- Phase I 不因“还没有 scalar / equation / threshold”停止。
- Phase I 不创建 canonical theorem，不制造符号权威，不把候选写成已经证明。
- Phase II 之后才逐根标记哪些关系是 owned / candidate / additional commitment / open gap。
- Phase III 才运行强 owner subtraction、adjacent-theory subtraction、novelty classification。
- Phase V 只形式化已经在哲学与概念层稳定的关系。
- Phase VI 不反向决定 Phase I 应该允许思考什么。

## 2. Phase I 的最小治理：允许大胆构建，但防止偷渡

Phase I 只保留四条硬护栏。

### C-G1 — candidate != canonical

任何新关系默认标记为：

```text
constructive candidate
```

而不是：

```text
P0 / P1 / P2 established
```

### C-G2 — no prior chooser / no completed menu

继续保留非菜单与非先在 chooser 纪律：

```text
Selection != picking from completed objects
Selection != act of an already-complete selector
```

“无中生有”只作 **non-preformation** 理解：确定者不是在选择前已经完成的对象。

### C-G3 — non-jump discipline

哲学加法可以提出桥，但不得静默把桥当成同一：

```text
actuality != persistence
object != bearer
bearer != subject
subject-position != phenomenality
```

特别保留：

```text
B_s != B_p
B_s -> B_p ?
```

但是 `?` 表示**开放的建构任务**，不是“禁止继续思考”。

### C-G4 — no premature symbolization

Phase I 默认：

```text
no new scalar
no new threshold
no new order parameter
no new equation merely to make a philosophical relation look rigorous
```

若某一关系必须靠公式才能被理解，先写自然语言结构，再另行授权形式化 probe。

## 3. Phase I 的唯一主产物：Constructive Ontology Draft

建立一份统一哲学草稿，而不是拆成五个彼此防守的 audit。

建议文件：

```text
Operations/Proposals/SRT_SELECTION_FIRST_CONSTRUCTIVE_ONTOLOGY_DRAFT_2026-08-29.md
```

它必须是一幅**完整世界图景**，至少连续回答以下 11 个问题。

### C1 — 未定如何成为确定：potentiality -> actuality

核心问题：

> 在没有预成对象菜单的前提下，一次 Selection 发生，究竟意味着什么获得了确定现实性？

第一遍先写哲学图景，不先问 P0 是否已经严格 entail 全部内容。

目标叙事：

```text
non-objectified potential
under real constraints
-> determinate manifestation / actuality
```

### C2 — “一”如何出现：actuality -> One

核心问题：

> 一个确定显现出现时，“什么算一个”是否也在同一事件中被确定？

候选共同确定项：

```text
this / not-this distinction
one / many
boundary
relation
operative grain
identity condition of the manifestation
```

这里的目标是正面理解：**One 不是 pre-given token，而是 determinacy 的一个结构面。**

### C3 — 排除的本体地位：One -> exclusion structure

核心问题：

> 确定 A 是否不仅意味着 A 实现，也意味着 alternatives 被结构性排开？这些被排开者在后续世界中是否仍有不同形式的效力？

第一遍允许提出：

```text
actualized structure
+
excluded structure
```

但不急于把 shadow / tension / friction 写成已证明 theorem，也不把 T2 当成第一优先经验任务。

### C4 — 一次事件如何变成历史：actuality -> historical conditioning

核心问题：

> 为什么过去发生过的 Selection 会改变后续 Selection 的条件，而不是世界每次从零开始？

候选哲学桥：

```text
Selection
-> leaves a difference
-> difference can condition later Selection
-> later Selection occurs in a world already shaped by prior actualisation
```

这一层是历史、路径依赖、习惯、L2 等结构的哲学母问题。

### C5 — 对象如何出现：history -> “still this”

核心问题：

> 什么使一个结构在变化中仍被再次取得为“还是这个”？

候选理解：

```text
historically conditioned recurrence
+ reselectability / reidentifiability
+ stabilized differentiation
-> object-side unity: still this
```

对象首先是 ontology 中的一种 unity burden，不等于 bearer。

### C6 — Matter 的位置：stable objectification regime

核心问题：

> “物”是否可理解为统一 Selection-generated reality 中某类高稳定、可公共重识别、可跨主体 objectify 的 regime，而不是与 mind 并列的第二 substance？

Phase I 只构建统一图景，不立即承诺一个物理学还原公式。

### C7 — Bearer 如何出现：object/history -> “from here”

核心问题：

> “还是这个”什么时候进一步变成“后果从这里返回、历史从这里继续、未来从这里展开”？

候选生成图景：

```text
history
+
consequences recursively condition the continuation of the same process
-> a locus of continued consequence-bearing
-> bearer-side unity: from here
```

这里先构建正面含义。same-unit attribution、reset/replacement、non-outsourcing、active-inference rival 留给 Phase III 做压力测试。

### C8 — Subject-position 如何出现：from here -> selection from here

核心问题：

> 一个承重位置什么时候不只承受后果，而开始参与塑造“哪些未来对它可选、可行、可继续”？

候选图景：

```text
from-here continuation
+
history-conditioned future selectability
+
selection increasingly conditioned by that position
-> subject-position / perspective-bearing selection
```

这一步不得自动等同 phenomenality。

### C9 — Phenomenality 的积极建构任务：from here -> for me ?

Canonical guard 继续保持：

```text
from here !-> for me established
```

但 Constructive Philosophy 必须积极追问：

> **什么额外结构，可能使“世界从这里继续”转化为“世界对这里显现 / for me”？**

允许并行提出多个候选解释，不要求第一遍选定答案。例如：

```text
irreducible position-indexed manifestation
non-transferable consequence field
world-for-this-continuation
integrated availability of distinctions only from one continuation position
```

这些只作为 constructive candidates；任何一个都必须允许后续被否定。

### C10 — Value / stake / agency 如何从同一 ontology 长出

至少研究三条候选链：

```text
bearer + asymmetric future continuation
-> stake

stake + selectable alternatives
-> value / valence structure

subject-position + generative reselectability
-> agency / freedom burden
```

此阶段不重定义 canonical `d`，而是明确 `d` 应该在统一 ontology 中回答什么问题。

### C11 — 多尺度与 collective

核心问题：

> 如果 One、history、bearer 都是生成出来的，那么 higher-order unit / collective 是否也是相同 ontology 在不同 grain 上的再发生？什么时候多个局部 continuation 被组织成一个更高阶 “from here”？

这里允许连接现有 Collective Selection，但不先假定 individual trace == collective trace。

```text

   ↓
Selection / determinate actualisation

   ↓

   ↓

   ↓

   ↓

   ↓

   ↓
position-conditioned / generative selection
   ↓
subject-position
   ↓
```

旁支：


**重要：这张图是研究地图，不是 derivation theorem。** Phase II 才给每根箭头定类型。

## 5. Phase II — Internal Architecture Pass：先整理自己，再审别人

Phase I 草稿完成后，逐根箭头做内部分类，但仍不先跑 external novelty。

每个节点/箭头只标以下状态：

```text
OWNED                  当前 canonical / active owner 已有
CONSTRUCTIVE-CANDIDATE  本轮新增哲学候选
ADDITIONAL-COMMITMENT   需要额外结构承诺才能成立
INTERPRETIVE-BRIDGE     解释性连接，不是假装 theorem
OPEN-GAP                还不知道
CONTRADICTION           与已落地 owner 冲突，需要作者裁决
```

同时形成两张表。

### A. Unified Ontology Dependency Map

回答：

```text
哪一层依赖哪一层？
哪些 unity 是互不可推的？
哪些结构只是不同 grain 的重现？
哪些问题其实过去被混在一起？
```

### B. Problem Transformation Table

至少覆盖：

```text
存在 / becoming
one-many
object identity
personal identity / fission
life / autonomy
mind-matter
subjectivity
consciousness unity
hard problem
free will
value / normativity
collective identity
```

成功标准不是“都解决”，而是：

> 传统问题被重新定位到统一 ontology 的明确节点/箭头，知道到底缺哪一步。

## 6. Phase III — 减法恢复，但角色改变

只有在 Constructive Ontology Draft 与 Dependency Map 完成后，才恢复现有强审计资产。

### III-A owner subtraction

使用：

```text
bounded retrieval
owner matrix
#866 / derivational spine
existing P0/P1/P2/P3 owners
```

目的：

> 防止重复造轮子、发现冲突、识别真正需要新增承诺的位置。

**不是目的：**把所有 partly-owned 候选都判成研究无价值。

### III-B adjacent-theory subtraction

使用现有 comparison owner，按**整条架构与关键桥**比较，而不是逐概念寻找“谁先说过”。

比较单位优先级：

```text
unified dependency architecture
> constitutive bridge
> isolated vocabulary / motif
```

### III-C novelty classification

只有在需要形成 publication claim 时才运行 N0-N3。

规则：

```text
N0 blocks originality claim
N0 does NOT delete the ontology node from SRT merely because it is not new
```

Topic Discovery Protocol 在 Phase I/II 暂停作为研究生成入口；到 Phase III 后恢复为 manuscript/topic QA。

### III-D strong rival / D2

只对已经完成哲学定位、owner 定型、值得经验化的局部桥运行。

禁止：

```text
为了容易做实验而倒过来重写 ontology
```

## 8. Phase V — Formalization：从成熟关系中挑，不从符号开始想

形式化必须满足：

1. 哲学关系已经在 Phase I 稳定；
2. Phase II 明确它在统一 ontology 中的位置；
3. Phase III 知道它不是重复/错误归属；
4. 形式化真的增加精度、可推导性或可检验性。

优先形式化对象可以包括：

```text
actualisation -> historical conditioning 的最小条件
object reidentification / reselectability
bearer same-unit attribution
position-conditioned selectability
multi-grain unit formation
phenomenal bridge 的失败条件（若能给）
```

不优先：为了“显得统一”而给每一层造一个 scalar。

### sigma 的当前角色

现有 `sigma_sr` 路线继续按已批准 S+R：

```text
R = model-local historical/writeback proxy truth-up
S = provenance/endogeneity/dependence/control 的研究分拆
```

它不得重新成为统一 ontology 的总准入判据。

## 13. Phase I 完成定义

Constructive Philosophy Phase 只有满足以下条件才算完成：

- [ ] 有一份从 potentiality 到 phenomenality/value 的连续 ontology 草稿；

- [ ] actuality -> history 有至少一个明确候选桥；

- [ ] matter / life / mind / consciousness 能放入同一生成图中，而不是四套平行 ontology；
- [ ] value / agency / collective 至少有统一 ontology 中的路由；
- [ ] 传统问题变换表完成初稿；
- [ ] 没有因为 novelty、D2 或形式化困难而删掉核心哲学问题；
- [ ] 所有新增内容仍明确是 non-canonical constructive candidate。

完成前，不重新进入 broad subtraction programme。

## 14. 成功与失败标准

### 成功不等于

```text
每个节点都有原创性
每根箭头都能从 P0 演绎
每个概念都有数学公式
每个问题都有实验
马上形成新论文
```

### 成功首先等于

> **SRT 拥有一幅内部连贯、层级清楚、可继续被攻击与硬化的统一本体论地图。**

### 真正的失败条件

Phase I/II 后如果出现：

```text
核心层级彼此无法放进同一 ontology
关键箭头只能靠循环定义维持
object/bearer/subject/phenomenality 只能靠同义改写串联
Selection 对整个生成图没有任何不可替代的组织作用
统一图景需要彼此冲突的底层前提
```

才构成值得整体重构甚至退回的结构性失败。

“某个思想别人讲过”不是本体论失败。

## 15. 当前 programme 的一句话原则

> **SRT 当前不是在寻找“尚未被别人占据的最小原创残余”，而是在尝试构造一个以 Selection 为本体论地板、能够连续解释 actuality、object、history、bearer、subject、value 与 consciousness 的统一世界图景。新颖性、可形式化性和经验区分是对这个图景的后续检验，而不是生成这个图景的前置许可。**

从本文件生效起：

```text
construction = engine
subtraction = quality control
formalization = precision tool
D2 = empirical pressure test
publication = downstream expression
```

而不再倒置。
