# Primitive Selection anti-tautology — strong-case subtraction + reverse-neighbor method

> **Role:** noncanonical execution method inside the existing primitive Selection anti-tautology CURRENT NEXT.
>
> **Not a new programme:** this method refines the route to the existing question. It does not replace canonical Selection, Facing v0.2, GRG v0.3, or the Pass-B neighbor record.

## 1. Why the route changes

The direct primitive question risks two opposite failures:

~~~text
too narrow:
import history / persistence / probability / value / rule rewrite into primitive Selection;

too broad:
Selection = any actuality,
then add no nontrivial explanatory structure.
~~~

The corrected route starts from strong generative cases, where the generative burden is easier to individuate, and subtracts downstream structure.

At the same time it runs a reverse-neighbor test. If SRT is more than a universal translation layer, it should reconstruct at least some mature neighbors from a thinner architecture and locate their pressure points without inventing them after the fact.

## 2. Axis A — strong-case generativity ladder for research only

This is an **epistemic search ladder**, not an ontic hierarchy.

~~~text
G-A0 actual state / event change
= something differs / occurs.

G-A1 generatively consequential difference
= the difference becomes load-bearing for later generation;
  "difference becomes difference-making".

G-A2 generative transformation
= the organization producing later Selection is reorganized;
  intervention grammar changes.

G-A3 higher-order generative formation
= a new load-bearing distinction / comparison dimension / organization forms,
  changing what later differences can matter.
~~~

Hard guards:

~~~text
G-A0..A3 != primitive Selection levels;
higher number != more real;
terminal Selection remains possible;
random novelty != G-A1 automatically;
attractor change != G-A2 automatically;
new visible object != G-A3 automatically.
~~~

## 3. Axis A subtraction route

For each strong case ask, in order:

1. Is novelty merely observer surprise? If yes, remove it.
2. Is the burden only persistence / memory? If yes, route to history/L2.
3. Is the burden only parameter or state change under fixed intervention grammar? If yes, not G-A2.
4. Is the burden only a new representation with no changed later generative role? If yes, not G-A3.
5. Can the case remain generative when rule-rewrite, long-term retention and new-dimension formation are removed?
6. What minimum actualising / relational non-flatness remains?
7. Does that remainder add anything over bare actuality / becoming?

The final question is the primitive anti-tautology edge. Do not answer it early.

## 4. Axis B — reverse-neighbor derivability ladder

Use the following dispositions.

### D0 — REDESCRIPTION

The neighbor can be paraphrased in SRT words.

This has almost no evidential value.

### D1 — TYPED EMBEDDING

The neighbor's characteristic commitments can be located across declared facings / owners without silently identifying them.

Required output:

- what is primitive-facing;
- what is current determination / L1-facing;
- what is retained / formed / L2-facing;
- what remains outside SRT's current commitments.

### D2 — DERIVATIONAL RECONSTRUCTION

SRT plus a **small, explicit, independently motivated assumption set** yields the neighbor's characteristic architecture.

Required:

~~~text
SRT kernel
+ A_neighbor
-> neighbor characteristic structure
~~~

The added assumptions must be visible. If they reconstruct almost the entire neighbor by hand, D2 fails.

### D3 — DIAGNOSTIC SURPLUS

The reconstruction independently locates a recognized pressure point as one of:

- facing mixture;
- hidden / unstable unit;
- hidden boundary or grain;
- pre-given geometry or inventory;
- untyped history / persistence burden;
- continuity / identity conflation;
- formed function back-imported into primitive generativity;
- descriptive equivalence mistaken for generative equivalence.

The pressure point must be source-native or independently documented. SRT may not manufacture a criticism for the purpose of winning the comparison.

### D4 — PROSPECTIVE LEVERAGE

The diagnosis yields at least one new:

- discriminating case;
- intervention;
- counterexample;
- exclusion condition;
- measurable structural difference;
- reconstruction route.

D4 is not required in this first pass.

## 5. Seven bounded reverse cases

Do not add an eighth family in Pass R0.

### R1 Whitehead

Target:

~~~text
Creativity / concrescence / actual occasion / transition.
~~~

Test whether a Whitehead-like architecture can be reconstructed as:

~~~text
primitive actualising generativity
+ recurrent incorporation of prior actuality
+ formed event-unity
+ extra Whitehead assumptions concerning feeling / valuation / self-determination
-> actual occasion / concrescence family.
~~~

Facing question:

> Does the actual occasion bundle primitive actualisation, formed unity, experiential character and valuation/final-causal roles that SRT types separately?

Do not call this a defect unless source-native scholarship establishes the relevant pressure.

### R2 Barad

Target:

~~~text
intra-action / agential cut / constitutive objectification.
~~~

Candidate reconstruction:

~~~text
non-pregiven relata
+ current constitutive cut / manifestation-backgrounding
+ apparatus / retained objectification conditions
-> bounded agential-cut-like case.
~~~

Facing question:

> Which part is primitive non-preclosure, which part is current determination, and which part is the formed apparatus / practice that stabilizes the cut?

Do not equate Barad's full ethico-onto-epistemology with SRT.

### R3 Simondon

Target:

~~~text
preindividual / metastability / transduction / operation-structure-operation.
~~~

Candidate reconstruction:

~~~text
non-preclosed generativity
+ domain-specific metastable potentials / tensions
+ local generative transformation
+ structure becoming later condition
-> transductive restructuring family.
~~~

Facing question:

> Is the preindividual being asked to carry a primitive burden, a formed metastable geometry, or both?

Preserve:

~~~text
preindividual != O0;
transduction != primitive Selection definition.
~~~

### R4 Husserl

Target:

~~~text
sedimentation / reactivation / meaning-history.
~~~

Candidate reconstruction:

~~~text
retained effective formation
+ present objectification / meaning organization
+ reopening of retained genesis
-> sedimentation/reactivation family.
~~~

Facing question:

> Does the account primarily explain L2-to-L1 reactivation within an already formed intentional / meaning-bearing domain rather than primitive generativity?

This may be a clean domain specialization rather than a problem. Do not force D3.

### R5 organizational closure / function

Target:

~~~text
mutually dependent constraints / self-maintenance / intrinsic function.
~~~

Candidate reconstruction:

~~~text
formed recurrent organization
+ mutually maintaining constraints
+ role contribution to continued organization
-> organizational-function special case.
~~~

Facing question:

> Are the chosen constraints, unit, boundary, grain and timescale independently grounded, or can a redescriber manufacture closure?

This directly interfaces with Facing v0.2's declaration-of-cut discipline.

### R6 evolutionary transitions in individuality

Target:

~~~text
cooperative group -> integrated higher-order individual.
~~~

Candidate reconstruction:

~~~text
multiple formed units
+ increasing interdependence
+ coordination / conflict reorganization
+ recurrent higher-order conditioning
-> domain-specific higher-order-One candidate.
~~~

Facing question:

> Is the higher-order unit independently individuated, or is group-level selection / fitness organization already being used to define the level whose emergence it is meant to explain?

Keep ETI criteria domain-specific; do not promote them to universal One admission.

### R7 Parfit / fission

Target:

~~~text
branching continuity without unique numerical identity.
~~~

Candidate reconstruction:

~~~text
strong retained / psychological / causal continuity relation
+ symmetric branching
-> continuity survives while unique identity fails.
~~~

Facing question:

> Which continuity burden is L2/history-like, and which identity burden remains separately OPEN?

Expected result may be only D1/D2 because Parfit itself already supplies the key diagnosis. If so record INHERIT / NO SRT DIAGNOSTIC SURPLUS.

## 6. Reverse-pass falsification conditions

The deeper-than hypothesis weakens if any of these dominate:

~~~text
1. neighbor reconstruction requires importing most of the neighbor as A_neighbor;
2. SRT terms only relabel already-present source-native distinctions;
3. claimed facing diagnosis is not a real pressure in the source literature;
4. SRT cannot explain why one facing split is privileged over another;
5. every neighbor can be "derived" only because Selection is defined broadly enough to absorb anything;
6. no D3 result appears across the bounded seven-family pass.
~~~

A result of D0/D1 across all seven is evidence for **universal-metalanguage risk**, not depth.

## 7. Positive evidence pattern

The strongest acceptable first-pass result is not “7/7 derived”.

A healthier pattern would be mixed:

~~~text
some D2/D3:
SRT reconstruction has real compression / diagnostic value;

some D1:
neighbor is mappable but not derived;

some NO-GAIN:
neighbor already contains the same distinction;

some FAIL:
SRT lacks enough structure to reconstruct it.
~~~

Mixed results are preferred over forced universality.

## 8. Relation to primitive anti-tautology

The reverse-neighbor pass feeds the primitive question in two ways.

### 8.1 Common-core subtraction

Across successful reconstructions, identify which burdens recur even after removing:

- domain ontology;
- subject / experience;
- history;
- function;
- individuality;
- identity;
- explicit state-space geometry.

Candidate residue is then pressure-tested against bare actuality.

### 8.2 Overbreadth control

If the same thin SRT language derives mutually incompatible neighbors with no added constraints, it is too weak.

Therefore:

~~~text
reconstructive breadth
must be paid by explicit specialization assumptions
and discriminating failure boundaries.
~~~
