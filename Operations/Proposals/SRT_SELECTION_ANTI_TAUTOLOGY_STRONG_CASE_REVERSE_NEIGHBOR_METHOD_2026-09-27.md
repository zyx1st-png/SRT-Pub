# Primitive Selection anti-tautology — strong-case subtraction + reverse-neighbor method v0.2

> **2026-09-29 governance correction:** local source ownership blocks the scoped SRT diagnostic / novelty claim; it does not by itself delete the SRT-side relation. The primitive anti-tautology STOP remains unchanged.

> **Role:** noncanonical execution method inside the existing primitive Selection anti-tautology CURRENT NEXT.
>
> **Corrective basis:** independent review of draft PR #1074 plus the overlapping #1073 Whitehead/Simondon burden-replacement draft.
>
> **Not a new programme:** this method refines the route to the existing question. It does not replace canonical Selection, Facing v0.2, GRG v0.3, or the completed Facing Pass-B neighbor record.

## 1. Why the route changes

The direct primitive question risks two opposite failures:

~~~text
too narrow:
import history / persistence / probability / value / novelty / rule rewrite
into primitive Selection;

too broad:
Selection = any actuality,
then add no nontrivial explanatory structure.
~~~

The corrected route therefore uses two coupled tracks:

~~~text
Track GN:
strong generative cases
-> subtract downstream/thickened burdens
-> approach the primitive residue;

Track RN:
reverse-neighbor comparison
-> ask whether SRT merely redescribes,
   reconstructs with small assumptions,
   preserves explanatory jobs,
   or produces prospective leverage.
~~~

Selection-totality / option A remains an ontological horizon under test, not a classifier that must exclude some real changes merely to remain informative.

## 2. Track GN — strong-case generativity ladder for research only

This is an **epistemic search ladder**, not an ontic hierarchy.

~~~text
GN0 actual change / occurrence
= something genuinely differs / occurs.

GN1 generatively consequential difference
= the difference becomes load-bearing for later generation;
  "difference becomes difference-making".

GN2 generative transformation
= the organization producing later Selection is reorganized;
  intervention grammar changes.

GN3 higher-order generative formation
= a new load-bearing distinction / comparison dimension / organization forms,
  changing what later differences can matter.
~~~

Hard guards:

~~~text
GN0..GN3 != primitive Selection levels;
higher number != more real;
terminal Selection remains possible;
random novelty != GN1 automatically;
attractor change != GN2 automatically;
new visible object != GN3 automatically.
~~~

## 3. Track GN — subtraction route

For each strong case ask, in order:

1. Is novelty merely observer surprise? If yes, remove it.
2. Is the burden only persistence / memory? If yes, route to retained-history / formed organization.
3. Is the burden only parameter or state change under fixed intervention grammar? If yes, not GN2.
4. Is the burden only a new representation with no changed later generative role? If yes, not GN3.
5. Can genuine actualisation remain when rule-rewrite, long-term retention and new-dimension formation are removed?
6. What minimum actualising / relational non-flatness remains?
7. Does that remainder add anything over bare actuality / becoming?

The final question is the primitive anti-tautology edge. Do not answer it early.

## 4. Primitive burden split

Do not force one primitive term to answer three different questions.

~~~text
PB0 — actuality / anti-redescription burden
genuine actuality
!= analyst-declared transition.

PB1 — non-arbitrariness / non-preclosure burden
actuality is not exhausted by traversal of a completed pregiven inventory,
but "it happened" is also not yet an explanation.

PB2 — domain localization burden
why this concrete transformation occurs here, now, in this way.
~~~

Current CURRENT NEXT primarily owns **PB0 + PB1**.

PB2 may be answered by declared downstream/domain realizations:

~~~text
physical dynamics;
metastability / tension;
biological constraints;
Gate / learned organization;
institutional structure;
or another source-native mechanism.
~~~

A PB2 mechanism must not be back-imported as the universal definition of primitive Selection.

## 5. Track RN — four-axis reverse-neighbor test

Do **not** compress the result into one winner-style score. Record four partly independent axes.

### RN-R — reconstruction strength

~~~text
RN-R0 REDESCRIPTION
= neighbor can be paraphrased in SRT vocabulary.

RN-R1 TYPED EMBEDDING
= characteristic commitments can be located across declared facings/owners
  without silent identity.

RN-R2 BOUNDED DERIVATIONAL RECONSTRUCTION
= SRT kernel + a small explicit independently motivated assumption set
  yields the neighbor's characteristic architecture.
~~~

Every RN-R2 claim requires an **assumption ledger**:

- added assumption;
- independent motivation;
- whether it is already the neighbor's distinctive content;
- whether removing it collapses the reconstruction.

If most of the neighbor is imported as assumptions, downgrade to RN-R1.

### RN-F — Facing diagnosis

~~~text
RN-F0 = no diagnostic gain;

RN-F1 = a documented pressure point can be cleanly typed
        as a facing/cut/grain/history/identity problem;

RN-F2 = diagnostic surplus beyond the existing criticism.
~~~

RN-F2 requires at least one of:

- a remedy not already supplied by the criticism;
- a prospective diagnosis recorded before literature lookup and later confirmed;
- a single independently motivated diagnostic structure that unifies pressure points from multiple otherwise independent traditions.

If the critic already states substantially the same diagnosis, record:

~~~text
INHERIT / NO LOCAL SRT DIAGNOSTIC INCREMENT
~~~

rather than RN-F2.

### RN-J — explanatory-job preservation

For every element SRT proposes to remove/demote, ask:

> What explanatory job did this element perform for the neighbor, and can SRT still perform that job without silently re-importing it?

Possible outcomes:

~~~text
RN-J PASS
RN-J PARTIAL
RN-J OPEN
RN-J FAIL
NEIGHBOR-SURPLUS
~~~

"Thinner" without RN-J success is not evidence of being deeper.

### RN-P — prospective leverage

The strongest target is a new:

- discriminating case;
- intervention;
- counterexample;
- exclusion condition;
- measurable structural difference;
- reconstruction route.

RN-P is not required for the first bounded pass.

## 6. Neighbor-surplus symmetry rule

Every comparison must include:

~~~text
what SRT reconstructs;
what the neighbor already owns;
what the neighbor explains more richly than current SRT;
what remains OPEN on both sides.
~~~

Bidirectional reconstructibility by itself establishes compatibility / translatability, not depth.

## 7. Blind-step rule

Post-hoc diagnosis after reading criticism is weak evidence.

For any **new** reverse-neighbor target after this corrective:

1. freeze the source-native structure to be examined;
2. write the SRT/Facing diagnosis **before** reading targeted criticism of that exact pressure point;
3. timestamp / commit the diagnosis;
4. only then inspect the criticism literature;
5. score:
   - confirmed,
   - partially confirmed,
   - already-owned,
   - contradicted,
   - not discussed.

The existing seven-family pass is grandfathered as post-hoc / weak evidence. Do not retroactively label it blind.

## 9. Corrected initial pressure map

### RN-WH Whitehead

Primary primitive pressure:

~~~text
pure potentials / determinacy;
antecedent-world uptake;
valuation / initial aim;
actual occasion unity.
~~~

Do not presume:

~~~text
eternal objects = L2 back-import.
~~~

Safer question:

> Does Whitehead require a sufficiently pregiven pure-potential structure for determinate actualisation, and if so does that exceed SRT's non-preclosure commitment?

Job-preservation split:

~~~text
determinacy of one event
!=
cross-event recurrence / "same determination again".
~~~

The recurrence problem is a downstream invariance / stabilization control and must not define primitive Selection.

HP-B weak-experience questions remain frozen and are not part of the present CURRENT NEXT.

### RN-SI Simondon

Treat metastability / tension / transduction as a powerful **domain-thickened generative realization** unless shown otherwise.

Do not presume:

~~~text
preindividual = L2 landscape;
SRT "borrows" Simondon tension.
~~~

Safer questions:

- Is metastability a domain realization of PB2 rather than a universal primitive?
- Can SRT's PB0/PB1 survive subtraction of metastable geometry?
- Which Simondonian explanatory jobs remain richer than current SRT?

### RN-OC organizational closure

The investigator-redescription / closure-objectivity problem is **already owned by the criticism literature**.

Therefore:

~~~text
RN-F1 = INHERIT;
RN-F2 = NOT YET;
~~~

unless SRT adds a non-arbitrary cut priority, remedy, prospective discrimination, or cross-tradition unification not already contained in that literature.

### RN-ET ETI

The circularity / origin-of-level pressure is also already explicitly addressed in the literature, including social-niche-construction alternatives.

Therefore:

~~~text
RN-F1 = INHERIT;
RN-F2 = NOT YET.
~~~

ETI remains valuable as a domain test of One formation, but cannot presently serve as an SRT diagnostic victory.

### RN-HU / RN-PA controls

Retain as NO-LOCAL-COMPARATIVE-INCREMENT controls where the neighbor already owns the distinction; retain the source-owned relation as a convergence coordinate under U-mode.

## 10. Primitive triangulation before broader reverse-neighbor deepening

The immediate next bounded analysis should use three cases:

~~~text
PT-WH — Whitehead:
what work do pure potentials / relevance / initial aim perform,
and which of those jobs belong to PB0/PB1 versus downstream recurrence?

PT-SI — Simondon:
what work do metastability / tension perform,
and are they PB2 specialization rather than primitive PB0/PB1?

PT-RV — real deterministic reversible transition:
no chooser;
no probability;
no value;
no novelty requirement;
no history requirement;
no rule rewrite;
genuine reversible dynamics / actual change.
~~~

PT-RV is the first pressure case for option A + the primitive residue.

It asks:

> If the change is genuine and reversible, is it still Selection? If yes, what non-role-interchangeable structure is present that is not merely an oriented description? If no, what extra criterion excludes it without importing irreversibility, probability, value or history?

Do not prematurely tie PT-RV to any particular interpretation of physics. Use it first as a conceptual collapse test; physical interpretation becomes a later domain question if needed.

## 11. Cross-tradition diagnostic-unification hypothesis

A potentially important RN-F2 route is:

> **formed partition / organization is allowed to back-define the conditions of its own formation.**

Candidate appearances:

- Whitehead pure-potential structure;
- Simondon metastable/preindividual modelling;
- organizational closure decomposition;
- ETI higher-level unit/fitness partition.

This is **not yet a result**.

To count as RN-F2 it must survive:

1. source-native fidelity in each case;
2. job-preservation analysis;
3. a demonstration that the same abstract error structure is present rather than merely similar wording;
4. at least one prospective blind-step confirmation in a new target.

## 12. Falsification / stop conditions

The deeper-than hypothesis weakens if:

- reconstruction requires importing most of the neighbor;
- RN-J repeatedly fails;
- SRT only restates critiques already in the literature;
- Facing declares cuts but supplies no reason one cut has more world-facing standing than another;
- mutually incompatible neighbors are "derived" with no specialization cost;
- reversible genuine change forces an ad hoc exclusion criterion;
- the cross-tradition unification dissolves under source-native scrutiny.

If SRT can only say "this too is Selection", record universal-metalanguage risk.
