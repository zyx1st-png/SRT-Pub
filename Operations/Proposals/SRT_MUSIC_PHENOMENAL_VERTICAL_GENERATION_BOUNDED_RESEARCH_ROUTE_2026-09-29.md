## 1. Core neutral research question

> Can a context-dependent continuation / reachability organization explain coordinated changes in musical tension, completion, segmentation, phenomenal report and later recutting better than strong local-update and latent-state / representation baselines?

**2026-10-08 current-comparator qualification:** The music-specific question above retains its historical shorthand, but it must not be read as a literal win over all H2 models. For the CURRENT NEXT empirical E2 comparison, the controlling later author Option A source (`01_Source_Intuition/SRT_AUTHOR_ADJUDICATION_CN2_NAMED_MODEL_FAIR_COMPARISON_2026-10-08.md`) requires **named, capable models under matched information/resource budgets and held-out predictive gain**; compression is secondary only with comparable prediction. Causal intervention and recursive-recutting gates remain E3/E4. The music companion does not inherit new experiment authorization.

A second, stronger question is:

> When a musical change is processed, under what conditions does it remain implicit structural registration, become phenomenal foregrounding, or become explicit objectification?

Neither question presupposes SRT truth.

## 3. Three target surfaces

### 3.1 Structural registration

Candidate measures:
- MMN / ERAN / other mismatch responses;
- implicit boundary tracking;
- response priming;
- neural tracking of phrase structure.

Purpose:
- establish processing without assuming awareness.

### 3.2 Phenomenal foreground

Candidate continuous reports:
- tension;
- pull / direction;
- completion;
- unfinishedness;
- suspension;
- surprise;
- interruption;
- “something changed”.

Purpose:
- obtain a first-person trace without requiring music-theory vocabulary.

### 3.3 Explicit objectification

Candidate reports:
- note / chord identification;
- key-change judgment;
- phrase-boundary judgment;
- explicit error detection;
- rule statement.

Purpose:
- separate foreground_phen from foreground_obj.

## 5. Manipulation family A — same local target, different background

Hold the target note / chord / acoustic event as constant as possible.

Manipulate preceding:
- tonal context;
- harmonic progression;
- rhythmic grouping;
- phrase history;
- learned familiarity.

Prediction target:

~~~text
same local target
+ different prior organization
-> different phenomenal / segmentation / continuation profile.
~~~

Strong baseline:
- local acoustic model;
- n-gram / transition model;
- **IDyOM** / statistical-learning expectation model;
- **Temperley-style Bayesian tonal / key inference** model where tonal context is load-bearing;
- Narmour / Schellenberg implication-realization family where melodic continuation is load-bearing;
- latent-state sequence / structure-learning model.

Do not use the generic label "predictive music model" as a substitute for these named stronger comparators.

Failure:
- target-object + strong baseline fully explains all held-out effects.

## 6. Manipulation family B — different local objects, preserved relation

Use:
- transposition;
- contour-preserving changes;
- interval-structure preservation where appropriate.

Target:

~~~text
absolute objects change
while relational trajectory is preserved.
~~~

This is not a novelty claim; relative-pitch / contour research already owns much of the phenomenon.

Use it to dissociate:
- object identity;
- relational organization;
- phenomenal trajectory.

## 7. Manipulation family C — predictability x unfinishedness

Target factorial design:

~~~text
A high predictability + high completion
B high predictability + high unfinishedness
C low predictability + high completion
D low predictability + high unfinishedness
~~~

Primary question:

> Can completion / unfinishedness be manipulated after matching **strong music-theoretic and statistical baselines**, not only surprisal / entropy?

Required baseline families include, where appropriate:

- Lerdahl / Krumhansl tonal-tension and attraction structure;
- Bharucha melodic anchoring / tonal-stability relations;
- Larson musical-force predictions;
- Narmour implication-realization / closure;
- Huron ITPRA, including tension and schematic vs veridical expectation;
- Farbood temporal tension model;
- TenseMusic feature-based tension prediction;
- cadence-specific closure / expectancy models;
- IDyOM and Bayesian / statistical tonal models.

Condition B — high predictability + high unfinishedness — is only informative if these stronger tonal-attraction / closure models do **not** already explain it.

If the stronger baselines absorb the effect:
- record NO LOCAL COMPARATIVE INCREMENT for the scoped completion claim;
- narrow or retire prospective-dependence language as an additional explanatory construct.

If a residual survives:
- test whether it predicts later segmentation / continuation / recutting under held-out conditions.

## 8. Manipulation family D — resolution vs interruption vs reinterpretation

Construct matched endpoint families where possible:

~~~text
resolution:
open relation discharged compatibly;

interruption:
stream ends while prior organization remains unresolved;

reinterpretation / recutting:
later event changes prior grouping / boundary / relation.
~~~

Measure:
- completion report;
- tension trajectory;
- boundary judgment;
- memory grouping;
- later expectation;
- recategorization / resegmentation.

Key discriminator:

~~~text
same physical stopping
-/-> same phenomenal / organizational endpoint.
~~~

## 9. Manipulation family E — implicit registration vs phenomenal report vs explicit objectification

Aim for at least three condition classes:

~~~text
implicit regularity detection
+ no reliable phenomenal report;

phenomenal deformation report
+ weak / absent explicit music-theory objectification;

explicit structural objectification.
~~~

This is the cleanest route for testing:

~~~text
structural registration
!= foreground_phen
!= foreground_obj.
~~~

## 10. E2 / E3 / E4 mapping

### E2 — predictive geometry

Question:

> Does one inferred context-level continuation organization improve held-out prediction of multiple local probes: tension, completion, next-event expectation, grouping and boundary judgment?

Success requires:
- held-out prediction;
- comparison against strong H1 local updates;
- comparison against H2 latent-state / representation models.

### E3 — causal geometry

Question:

> Does a targeted intervention on context reorganize multiple downstream probes together in a way predicted by the inferred organization?

Examples:
- alter one harmonic relation;
- move a phrase boundary cue;
- change one transition while preserving local acoustics;
- manipulate familiarity / learned context.

### E4 — recursive reconstitution

Question:

> Does one event change what later counts as a unit, boundary, stable continuation or completion?

This is the strongest current neutral target.

Possible readouts:
- later phrase segmentation;
- reinterpretation of earlier notes;
- changed category / grouping;
- changed future expectation;
- changed explicit objectification.

Positive E4:
- does not prove primitive Selection;
- does not prove phenomenality mechanism;
- does not establish unrestricted cut genesis.

## 12. Bearer-facing question

Only after the neutral cognition relation is operationalized:

> Is “unfinishedness” merely a model state, or does the relevant continuing system remain non-transferably exposed to how the open continuation resolves and then carry the consequence into its next operative position?

This is a bridge question, not the first experimental assumption.

Do not infer:
- Bearer from completion report;
- phenomenality from Bearer;
- same-bearer consequence closure from neural continuity alone.

### 12.1 Music is not the priority Bearer-admission domain

The canonical Bearer gate concerns what this formed One / Selection-position may itself undergo, retain or lose through P + E. In passive music listening, "exposure to how a cadence resolves" risks becoming too thin and collapsing E into ordinary next-state change.

Therefore:

~~~text
music
= primary phenomenal-foreground / completion laboratory;

action with real consequence
= preferred first domain for Bearer-facing non-outsourcable consequence tests.
~~~

Music may later supply a matched phenomenal-side comparison, but it should not carry the first Bearer-admission burden.

### 12.2 K recutting != Position reconstitution

Record the HP-B pressure without editing the frozen hook:

| Relation | Working meaning in this route | Can occur without the other? |
|---|---|---|
| `K` recutting | change in operative grouping / boundary / distinction / representation | yes |
| same-Bearer Position reconstitution | change in the Bearer's current operative from-where / feasible continuation under the frozen HP-B candidate | yes in principle |
| ordinary local state update | change that does not independently alter the relevant cut or same-Bearer operative position | yes |

Consequences:

- within-geometry tension can remain phenomenally foregrounded without `K` recutting;
- if such a case also lacks any independently defensible Position reconstitution, it is **pressure on** the HP-B minimal-topology candidate;
- if every ordinary tension fluctuation is called Position reconstitution merely because reachability changed, the HP-B discriminator risks collapsing into ordinary state update.

## 13.1 PH-QUAL automation / familiarity pressure — record only

PH-QUAL PC-8 predicts that successful automatization should reduce the need for strong task-specific qualitative compression, with policy failure recruiting it again.

Music creates a useful pressure case because:
- schematic tonal expectation can remain strong after extensive exposure;
- veridical familiarity can make the next event highly predictable;
- a familiar deceptive or tension-bearing relation may still retain a qualitative pull / tension profile.

Therefore:

~~~text
automation
!= automatic disappearance of all musical tension / qualitative force.
~~~

This does not refute PC-8 by itself. It requires distinguishing:
- automation of a task policy / control burden;
- schematic tonal attraction;
- veridical familiarity;
- residual phenomenal tension.

Possible clarification for later adjudication:

> "unresolved" in PC-2 may need to mean **a dependence not yet discharged / fulfilled**, not merely probabilistic uncertainty.

## 16. Failure conditions

Downgrade this route if any of the following survives strong controls:

1. local acoustic + predictive baselines explain all key effects;
2. completion / unfinishedness cannot be separated from surprisal / entropy / learned cadence probability;
3. phenomenal reports add no stable held-out structure beyond response bias / explicit judgment;
4. same-terminal-state path manipulations produce no reliable phenomenal or later-organizational difference;
5. implicit / phenomenal / explicit stages cannot be dissociated;
6. recutting claims reduce to ordinary state updates without a stronger multi-probe consequence;
7. Bearer-facing language adds no independently testable distinction;
8. any attempted farther invariant requires changing its meaning separately in every domain;
9. high-predictability / high-unfinishedness effects are fully explained by tonal-tension / attraction / anchoring / closure models;
10. a claimed farther SRT gain is absorbed by a stronger cross-domain predictive-processing or event-segmentation comparator.

A failure here narrows this route, not the entire SRT architecture.
