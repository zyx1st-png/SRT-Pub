# SRT Selection-First Constructive Commitments Charter v0.1

> **Purpose:** 为统一 ontology 的五个最深缺口写出“最小正面承诺”。这里不问 novelty，不形式化，不声称 canonical；只问：若 SRT 想把整幅世界图连起来，最少还必须允许什么成立？
>
> **Rule:** 每一条 commitment 都必须同时写出：
>
> ```text
> Positive commitment
> Why needed
> Must NOT presuppose
> Connects to
> Philosophical failure condition
> ```
>
> 这些 commitment 是作者未来 Stage-D / owner hardening 的候选输入，不是自动新增 P0/P1。

---

# G1 — Local One Commitment

## Gap

```text
determinate manifest distinction
-> ?
local One / effective boundary / operative grain
```

P0-01 已经拥有 `determinate manifest distinction`，但当前 ontology 还没有明确说：为什么“确定”足以交付一个局部 unity，而不是只有一个无单位化的差异事实。

## Minimal positive commitment candidate — C-ONE

> **C-ONE:** 一个 determinate manifestation 若真正是确定的，则它必须在某个 operative grain 上实现一个有效闭合的差异边界；这个边界使“此确定”可以与未被该边界包含的现实区分开。`local One` 就是这种**局部确定闭合**，不是预先存在的 object。

### Why needed

没有 C-ONE：

```text
Selection -> determinate distinction
```

仍然不能回答：

```text
什么使这一次确定成为一个可指称的局部发生？
什么使后续可以谈“它的”历史？
```

对象、bearer、collective 等所有 later unity 都会失去最薄的前身。

### Must NOT presuppose

C-ONE 不能预设：

```text
pre-given object
pre-given subject / observer
completed option menu
cross-temporal identity
public recognition
full relation network
many as already-counted units
```

特别是：

```text
local One != persistent object
```

### Connects to

```text
P0-01 determinate manifest distinction
-> C-ONE local determinacy
-> C5 object reidentification later
```

### Philosophical failure condition

C-ONE 失败，如果可以给出一种融贯的“完全 determinate manifestation”，却不存在任何有效边界、grain 或局部 unity，而且仍能无循环地解释后续的 same/different、history attribution 与 objecthood。

如果这种反例成立，则 `One` 不能从 determinacy 展开，必须被重新定位。

# G2 — Retention Commitment

## Gap

```text
actuality
-> ?
retained difference
-> historical conditioning
```

P0-02/P0-03 已经明确阻止：

```text
occurrence = persistence
```

所以统一 ontology 必须正面说出“什么时候一次发生真的进入未来”。

## Minimal positive commitment candidate — C-RET

> **C-RET:** 至少某些 determinate actualisations 能改变、留下或重构后续 Selection 所面对的有效约束/可达性，使先前发生所产生的差异可以在未来再次具有因果或结构效力。

C-RET 不要求每次 Selection 都 durable writeback；它只允许“历史性”作为一种真实的后续关系成立。

### Why needed

没有 C-RET，SRT 永远停留在：

```text
一个事件
另一个事件
另一个事件
```

而无法得到：

```text
habit
path dependence
learning
L2 sedimentation
object persistence
bearer history
value accumulation
```

P0-03 的 conditional irreversibility 也会失去更正面的生成位置。

### Must NOT presuppose

C-RET 不能预设：

```text
every occurrence leaves durable memory
pre-existing memory substrate as explanation of all history
stable object already exists
bearer already exists
L2 = universal store
```

### Connects to

```text
P0-01 actuality
P0-02 occurrence/persistence separation
P0-03 conditional irreversible trace floor
L2 sedimentation
```

### Philosophical failure condition

C-RET 失败，如果“过去改变未来”完全只能通过一个与 Selection 无关、且已经预装全部 identity/history 的独立 substrate 解释，并且 Selection-event 本身对后续条件没有任何可保留的结构差异。

这不会自动击倒 P0-01，但会使 Selection-first 无法承担历史 ontology 的上游角色。

# G3 — Object Reidentification Commitment

## Gap

```text
retained / recurrent structure
-> ?
still this
```

历史重复、相似与稳定都不自动等于“同一个对象”。

## Minimal positive commitment candidate — C-OBJ

> **C-OBJ:** 一个 local unity 成为 object unity，当存在一个不依赖特定观察者任意指定的 transformation-tolerant continuity rule，使其在一组允许变化中仍可被后续现实过程恢复为同一结构，而越过某些变化则必须算作新的 unity。

核心不是“看起来一样”，而是：

```text
same-under-allowed-transformation
!= merely similar
```

### Why needed

没有 C-OBJ：

```text
history
-> recurring patterns
```

仍然不能推出：

```text
this same object/process persists
```

那么物、生命、bearer、个人同一等问题都会把 reidentification 当作隐含前提。

### Must NOT presuppose

C-OBJ 不能预设：

```text
observer recognition
name / label continuity
memory report
bearer consequence closure
subject perspective
phenomenality
```

也不能把“同一个”定义成“我们决定把它算作同一个”。

### Connects to

```text
C-ONE local unity
+
C-RET retained difference
-> C-OBJ still-this
-> matter / organism / bearer routes
```

### Philosophical failure condition

C-OBJ 失败，如果不存在任何非循环的 transformation tolerance：

```text
要知道哪些变化保持 identity
必须先知道它是同一个对象；
要知道它是同一个对象
又必须先知道哪些变化保持 identity。
```

若这个循环无法通过结构/历史关系打破，则 SRT 不能宣称正面解释 object individuation，只能保留工具性 reidentification。

# G4 — Bearer / Borne-History Commitment

## Gap

```text
history / writeback
-> ?
from here
```

这是 sigma / subject-position architecture 的真正下地基问题：什么使 `own prior output` 中的 `own` 成立？

## Minimal positive commitment candidate — C-BEAR

> **C-BEAR:** 一个持续 unit 成为 bearer，当至少一部分历史差异与后果对该 unit 的未来继续具有**构成性归属**：这些后果改变的不是任意附近状态，而是“这个 unit 如何继续成为这个 unit、还能如何继续选择/维持”。若把同一后果任意重索引到另一个 unit 而声称 bearer fact 完全不变，就已经改变了原来的归属事实。

这不是绝对内生性，而是 identity-indexed consequence relation。

### Why needed

没有 C-BEAR，仓库可以有：

```text
memory
feedback
adaptation
control
history dependence
```

却仍然无法回答：

```text
这些是谁的 history？
后果落回哪里？
为什么这个过程而不是旁边那个过程承担？
```

于是 `theta^trace` 的 `P's own` 永远只是 notation。

### Must NOT presuppose

C-BEAR 不能预设：

```text
causal closure
energetic self-sufficiency
no external scaffolding
no shared memory
sigma threshold
Stable ISP
subjecthood
consciousness
```

因此：

```text
non-outsourcing != independence from environment
```

### Connects to

```text
C-OBJ / C-RET
-> borne history / same-unit admission
-> Stable ISP
-> Individuation sigma domain
-> subject-position
```

### Philosophical failure condition

C-BEAR 失败，有两种主要方式：

1. **same-unit collapse**：任何 attempt to define the continuing unit 都依赖它已经拥有的 history，而 history attribution 又依赖先知道 same unit，形成不可打破循环；
2. **arbitrary reassignment**：所谓 borne-history 与普通 causal influence 没有任何结构差别，history 可以任意搬到另一个 controller/unit 而所有 bearer facts 不变。

任一成立，则 bearer 必须降格为便利描述，不能承担本体 unity。

# G5 — Phenomenal Commitment Fork

## Gap

```text
from here / selection from here
<-> ?
for me
```

这是唯一不应过早压成一条 single commitment 的缺口。Phase I v0.2 已经显示：如果现在强行指定“额外功能结构 X 就产生体验”，会重新进入防守式伪闭合。

因此 G5 先采用 **fork charter**，而不是单一定理候选。

## Common minimum — C-PHEN-0

> **C-PHEN-0:** 如果 phenomenal `for me` 是真实 ontology burden，它就不能仅靠把 `phenomenal` 这个词写进 bearer、perspective、integration、report 或 self-reference 的定义而被消解。任何正面路线必须说明 `givenness / presentation`、位置索引、统一与 qualitative differentiation 如何与 Selection-first architecture 发生关系。

这不是一个“phenomenality exists” primitive；它只是防止循环解释。

---

## Fork A — C-PHEN-A: Late Constitutive Bridge

> 某种已经形成的 bearer/subject-position organization 需要额外构成关系，才能使 position-indexed structure 成为 position-indexed manifestation。

### Must explain

```text
why structure is presented
why presentation is for this position
why there is qualitative differentiation
why unity is phenomenal rather than merely computational
```

### Failure

如果所谓 extra relation 只是在 bearer 结构后面加一句“and therefore experience”，没有独立内容，则失败。

---

## Fork B — C-PHEN-B: Manifestness Deepening

> Primitive actualisation 的 `manifest` 不是 primitive consciousness，但可能含有一个非体验性的 manifestness aspect；在 bearer/subject-position 中，这个 aspect 被稳定地位置化、递归化或统一化，最终转化为成熟 `for me`。

### Must NOT presuppose

```text
manifest = conscious
all Selection events have qualia
panpsychism by vocabulary
```

### Failure

如果 `manifestness` 无法与 phenomenality 区分，只是把 experience 换名提前到 C1，则路线失败。

---

## Fork C — C-PHEN-C: Dual-Aspect Achievement

> 某类 Selection/bearer organisation 达成时，公共因果/结构面与第一位置 phenomenal 面是同一成就的两个 aspect；一个不必逻辑推出另一个，但二者受同一构成条件约束。

### Must explain

```text
why two aspects belong to one event/unit
what constrains aspect co-occurrence
why this is more than a label
```

### Failure

如果任何结构都可以任意被宣布“另有 phenomenal aspect”，且没有 exclusion/failure condition，则路线退化为不可约束的 dual-aspect 命名。

# 6. Five commitments as a positive ontology spine

如果暂时不问 claim level，五个缺口现在可以写成：

```text
P0-01 determinate actualisation
        |
        | C-ONE ?
        v
local determinate unity
        |
        | C-RET ?
        v
historically retained difference
        |
        | C-OBJ ?
        v
object unity: still this
        |
        | C-BEAR ?
        v
bearer unity: from here
        |
        +--> existing Stable ISP / subject-position architecture
        |
        | C-PHEN-A/B/C ?
        v
phenomenal unity: for me
```

重要的是：

> **这不是把五条 commitment 宣布成五个新公理。它只是第一次把统一 ontology 真正需要支付的哲学账单正面列出来。**

有些 commitment 可能最终被现有 owner 吸收；有些可能成为 P1/P2；有些可能被证明多余；有些可能失败。Phase III subtraction 的任务是帮助判断这些命运，而不是决定 Phase I 是否有资格提出它们。

---

# 7. Author-side decision questions after the charter

下一轮作者裁决不应问“哪条最 novel”，而只问：

1. `C-ONE` 是否抓住了“一如何出现”的真正直觉？还是 One 比 boundary/grain 更原初/更晚？
2. `C-RET` 是否足够说明 Selection 如何进入 history，还是需要更强的“Selection 改写可选择性”命题？
3. `C-OBJ` 的 transformation-tolerant continuity 是否是 object 的正确正面定义方向？
4. `C-BEAR` 的 identity-indexed consequence relation 是否抓住 “from here”，还是 bearer 还需要更原初的 self-maintenance / stake？
5. phenomenality 三叉：A/B/C 哪些应保留？是否还有第四条路线？

只有这五个哲学问题得到作者方向性裁决后，才值得开始 Phase III 外部 subtraction。
