# Prototype semantic owner v2 — generative normativity / constitutive relation

> **Status:** noncanonical v2 prototype after adversarial pressure test. It is not a current definition source and authorizes no canonical edit.

---

## 0. Role

This proposed owner is a **semantic relation surface**, not a new ontological stage.

It would own only:

```text
indexed generative comparison;
cross-position relation typing;
participant-status consistency;
generative substitution / objectification;
relation integrity;
O2-C constitutive ought;
limited partial-order dominance;
O2-C / O2-A / O2-M routing.
```

It would not redefine Selection, One, Stable ISP, Bearer, Concern/d, Agency, collective ISP, T_dir, moral standing, rights or full ethics.

---

# 1. Two distinctions govern everything

## 1.1 Structural evaluation vs moral evaluation

Use explicit generative-indexed language:

```text
G-stronger / G-weaker for (X,R,H)
```

rather than unqualified `better / worse for X` whenever moral standing has not been independently established.

Thus:

```text
G-stronger-for X
!= welfare-better-for X
!= morally better overall.
```

## 1.2 Relation integrity vs relation legitimacy

```text
R-integrity
= whether the actual generative organization still instantiates its declared / enacted relation type.

R-legitimacy
= whether that relation type ought to exist, continue, govern, or override competing positions / relations.
```

Routing:

```text
O2-C primarily owns R-integrity;
O2-M is required for full R-legitimacy in genuine moral conflict.
```

An internally coherent domination relation can pass an R-integrity test and still remain morally illegitimate.

---

# 2. Admission discipline

For every O1 / O2-C claim declare:

```text
X = formed position / relation under evaluation;
R = independently specified generative relation / capacity;
H = horizon / perturbation / scope;
T = transition / trajectory;
Q = relation among positions, when relevant;
tau = independently instantiated relation type, when O2-C is invoked.
```

Do not smuggle the conclusion through admission terms such as:

```text
good, bad, healthy, just, legitimate, proper, flourishing, deserving.
```

Identity / continuity must also be inherited rather than assumed:

```text
O1 inherits One / lineage / Stable-ISP burdens where the claim needs them;
O1 does not create the same-X relation by requiring an evaluation target.
```

---

# 3. O1a — indexed local generative comparison

Prototype relation:

```text
T_a >=_G(X,R,H) T_b
```

means:

> under declared scope H, `T_a` leaves independently specified generative relation / capacity R of X no less realizable or effective than `T_b`.

Possible R families, only after upstream payment:

```text
formed participation in Selection;
continued-selectability;
consequence-sensitive re-entry;
rule / boundary / candidate-generation revisability;
contribution to an independently formed higher-order relation.
```

No R family is universal by default.

Guards:

```text
persistence alone != G-stronger;
option count alone != G-stronger;
irreversibility alone != G-weaker;
termination alone != morally wrong;
local G-strength != wider-scope good.
```

---

# 4. O1b — cross-position relation typing

For relation Q among formed positions, track how each attributed participant actually enters Q's future constitution.

Do not scalarize by default:

```text
sum of local G-strength;
size;
activity;
persistence;
power;
majority;
preference satisfaction;
minimum friction.
```

A transition may be:

```text
G-stronger for X;
G-weaker for Y;
ambiguous for Q;
```

without contradiction.

That is a genuine conflict state, not a cue to invent a universal weighting rule.

---

# 5. Whole-position routing

Whole-relative evaluation is admitted only after independent higher-order formation is established.

```text
observer grouping / majority / institution / state / spatial containment
-/> whole-position.
```

Where H is independently established:

```text
G-stronger / G-weaker for H
```

is meaningful.

But:

```text
H formation != H sovereignty;
G-stronger-for H -/> justified sacrifice of X automatically.
```

Whole formation is ontology; whole priority is normativity and remains separately gated.

---

# 6. Participant-status consistency

If Q independently instantiates a relation type tau in which Y is a load-bearing generative participant, then Y's own Selection must materially enter Q's future constitution / revision in the role tau attributes to Y.

If X recurrently displaces that role, then:

```text
repair Q so Y again performs the attributed role;
or
retype Q honestly.
```

This is a constitutive consistency condition.

It does **not** imply:

```text
Q must continue forever;
Y must always remain a participant;
the new relation after retyping is morally legitimate.
```

---

# 7. Generative substitution / objectification

Diagnostic:

```text
Generative substitution occurs when X recurrently displaces Y's effective source-role
in a relation that still counts Y as performing that generative role.
```

Generative objectification candidate:

```text
Q treats Y as a participant in description / organization
while Y's future relation-state is effectively generated elsewhere.
```

This is stronger than representational objectification but weaker than a complete moral wrongness theorem.

Guards:

```text
asymmetry != substitution automatically;
delegation != substitution automatically;
parental / formative guidance != substitution automatically;
guardianship != substitution automatically;
emergency coordination != substitution automatically;
causal influence != substitution automatically;
substitution != culpability automatically.
```

---

# 8. Actualisation closure vs generative closure

```text
actualisation closure
= Selection makes actuality determinate and thereby excludes unrealized alternatives.
```

This is normal.

```text
generative closure
= a transition removes an attributed formed position's effective participation in the future relation
  while the relation continues to count that position as performing the same generative role.
```

Therefore:

```text
commitment != generative closure automatically;
irreversibility != generative closure automatically;
option reduction != generative closure automatically;
termination != generative closure automatically.
```

---

# 9. O2-C — conditional constitutive ought

Prototype:

```text
Ought_C(Q,tau)
```

means:

> if Q is to continue instantiating relation type tau, its transformations must remain compatible with the constitutive generative roles of tau, or Q must be retyped.

This is not a categorical command that tau itself must exist.

Formally in prose:

```text
maintain Q as tau
-> preserve tau's constitutive role-structure or retype Q.
```

### Anti-triviality

Tau must be independently instantiated by real organization.

```text
nominal label alone -/> O2-C;
real enacted relation type + continuation as that type -> O2-C burden.
```

### Hard limit

An honestly typed domination relation may avoid contradiction here.

That does not establish its moral legitimacy.

---

# 10. Limited partial-order dominance

Under the **same declared task / relation objective / admitted scope**, if:

```text
T_a is no worse than T_b on every admitted constitutive dimension;
T_a is strictly stronger on at least one;
T_a reduces unnecessary generative substitution for at least one participant;
no independently established higher-order position / relation is worse under T_a;
```

then:

```text
T_a may be preferred to T_b within that scope.
```

This is a narrow actionable rule.

It does not apply when there is genuine disagreement about:

```text
the task;
the relation type;
who / what counts;
the horizon;
the moral weight of competing losses.
```

Where genuine tradeoff remains:

```text
STOP.
```

---

# 11. O2-A — responsibility routing

O2-A is downstream of O2-C.

Potential responsibility requires stronger establishment of:

```text
attributable relation-transforming participation / control;
accessible alternatives / reorientation;
relevant knowledge / relation-state access;
inhibition / revision capacity;
consequence return;
repair / answerability pathway;
degree of external scripting / blockage.
```

Therefore:

```text
causal contribution != responsibility;
Selection-position != agent automatically;
O2-C failure != culpability automatically.
```

The agency / responsibility owner must decide sufficiency.

---

# 12. O2-M — legitimacy and genuine moral conflict

O2-M remains OPEN.

It owns questions such as:

```text
should this relation type exist / continue?
whose stake carries moral weight?
when may one real position constrain / terminate another?
what happens when member / whole / horizon comparisons conflict?
what justifies rights, sacrifice, coercion or tragic choice?
```

Forbidden shortcuts:

```text
largest scale wins;
majority wins;
maximum generativity wins;
maximum continuation wins;
maximum d wins;
minimum friction wins;
maximum option count wins;
whole always wins;
individual always wins.
```

---

# 13. Bearer / Concern boundary

This owner does not create moral standing.

```text
G-comparison / O2-C
-/> Bearer;
-/> Concern;
-/> suffering;
-/> rights;
-/> moral patienthood.
```

Bearer / Concern become relevant when the problem moves from relation integrity to stake-bearing conflict / moral legitimacy.

Thus:

```text
structural non-substitution
!= concern-weighted non-substitutability.
```

---

# 14. T_dir boundary

O1 / O2-C may later provide independently typed direction references.

Safe dependency:

```text
independent typed direction D_ref
-> T_dir measures self-readability / usable reorientation with respect to D_ref.
```

Unsafe dependency:

```text
T_dir
-> proves value direction exists.
```

This owner therefore does not inherit the old universal value-hiddenness metaphysics.

---

# 15. Epsilon independence

This owner must remain independent of the old strong epsilon theorem.

```text
O1 / O2-C
must not be derived from
"B>=2 is primitively preferred over B<=1".
```

Any future O0-to-O1 inheritance must use the separately reconstructed primitive-generativity route and cannot back-define O1 through continuation preference.
