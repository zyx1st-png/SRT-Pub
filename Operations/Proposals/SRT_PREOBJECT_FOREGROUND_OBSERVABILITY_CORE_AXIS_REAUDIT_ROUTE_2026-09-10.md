# Re-audit route — pre-object field / foreground observability as the candidate core axis

> **Purpose:** turn the retrospective finding into a disciplined next sequence without silently converting the author's priority judgement into a theorem or a Level verdict.

## 1. Root question

```text
Can a complete third-person objectifiable state-space be ontologically prior to,
or fully equivalent to, the pre-object field from which Selection produces
foreground / background determination?
```

Equivalent practical formulation:

> **Does a rival merely predict the manifest result, or does it also explain the constitution of what can count as a determinate observable without presupposing that determinate state-space?**

## 2. Three claims that must not be merged

### PO-1 — foreground-bounded direct observability

```text
A direct observation is already on the manifest / foreground side
of a Selection relation.

The background is not co-manifest as background in that same event.
```

Current status:

```text
AUTHOR-SUPPORTED / SOURCE-CONTINUOUS
strongest-neighbor pressure at exact wording: NOT COMPLETE
```

### PO-2 — no pregiven complete object inventory

```text
The pre-object field is not ontologically equivalent to a warehouse
of already individuated hidden objects / options / state variables.
```

Current status:

```text
STRONGLY SOURCE-CONTINUOUS with Q03 and selection-realism paper
not yet re-audited as the controlling strongest-neighbor claim
```

### PO-3 — no fully equivalent third-person state-space ontology

```text
Even an enlarged predictive state-space cannot be ontologically equivalent
to the pre-object field if the state-space representation presupposes
exactly the determinate distinctions whose genesis Selection is meant to explain.
```

Current status:

```text
LIVE STRONG CANDIDATE
NOT YET AUTHOR-CONFIRMED AS A THEOREM
NOT YET STRONGEST-NEIGHBOR PAID
```

PO-1 does not automatically imply PO-3.

## 3. Strongest-neighbor sequence

### Pass A — Barad first

Questions:

```text
Does agential realism also make observable / determinate relata downstream
of constitutive intra-action / agential cut?

If yes, does SRT add anything structurally non-substitutable through
foreground/background Selection, historical sedimentation, or Position?

Can Barad's apparatus / cut relation already pay PO-1 / PO-2?
```

Why first:

Barad directly addresses measurement, objectification, determinate separability and non-pregiven relata. Generic control theory does not.

### Pass B — Simondon second

Questions:

```text
Does preindividual transduction already pay the non-object inventory point?
Does it also address the observation relation, or mainly individuation?
Does SRT's manifest/background relation change the dependency structure?
```

### Pass C — Whitehead / process actualisation

Questions:

```text
Does concrescence already block a pregiven finished state inventory?
Is the observable/manifest relation structurally comparable or not?
```

### Pass D — state-space reduction advocate

The strongest reduction argument should be allowed:

```text
construct an arbitrarily rich latent state Z_t
and treat every apparent background condition as part of Z_t.
```

Then ask whether this is:

```text
mere predictive representation
or
ontologically non-question-begging equivalence.
```

No victory is allowed by definition. The SRT side must specify exactly what relation is lost if the latent-state replacement is accepted.

## 4. Counterexample discipline

The core claim must survive at least these cases:

```text
C1 — ordinary partially observable dynamical system
hidden state exists but is fully determinate before measurement;
this should NOT count as sufficient SRT support.

C2 — perfect simulator
third-person model predicts every future foreground outcome;
SRT must explain why predictive success does or does not settle ontology.

C3 — Baradian constitutive measurement
boundaries / relata arise through cut;
if this pays the same relation, SRT distinctiveness must narrow.

C4 — Simondonian preindividual field
individual not given in advance;
if this pays PO-2 but not PO-1, the exact split matters.

C5 — retrospective tomography
multiple later probes reconstruct a high-fidelity model of the earlier field;
this must be distinguished from same-event direct co-manifest access.
```

## 5. What a positive result would need

A positive structural result cannot be:

```text
we cannot measure everything;
there are hidden variables;
models are imperfect;
observers have limited information.
```

It would need a source-neutral statement such as:

```text
objectifiable state distinctions are themselves downstream products
of a constitutive differential operation;
therefore treating those distinctions as a complete prior state-space
changes the explanatory order rather than merely improving measurement.
```

Even then, comparison with Barad / Simondon is mandatory.
