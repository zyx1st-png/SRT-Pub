# E2–E4 multi-probe recutting design — whole-field test candidate

> Purpose: produce a first bounded experimental design that tests whether one history / consequence manipulation induces a common whole-system recutting geometry across multiple local cognitive probes.
>
> Status: design candidate only. Not preregistered, not authorized for execution, not evidence for SRT ontology.

---

## 0. Why the old toy-world design is insufficient

The old design emphasized:

~~~text
learn transitions before labels
-> detect anomalies
-> later acquire categories.
~~~

That is strongly absorbable by:
- statistical learning;
- latent-cause learning;
- representation learning;
- event segmentation;
- cognitive-map / manifold models.

The stronger target is:

> **Does one history / consequence manipulation produce a common reorganization of equivalence, boundary, transition and action structure that generalizes across different probes?**

This is a whole-field question rather than a single-task learning question.

---

## 1. Mature-neighbor guard

Current neuroscience already supports:
- task-tailored representational geometry;
- context-dependent orthogonal / low-dimensional manifolds;
- learning-driven dimensionality changes;
- conceptual reorganization of object representations;
- history-dependent state-space and category-structure learning.

Representative anchors:
- Mack, Love & Preston (2016), PNAS, DOI 10.1073/pnas.1614048113.
- Radulescu, Shin & Niv (2021), Annual Review of Neuroscience, DOI 10.1146/annurev-neuro-092920-120559.
- Gurnani & Cayco-Gajic (2023), Current Opinion in Neurobiology, DOI 10.1016/j.conb.2023.102759.
- Flesch et al. (2022), Neuron, DOI 10.1016/j.neuron.2022.01.005.
- Wójcik et al. (2026), Nature Neuroscience, DOI 10.1038/s41593-026-02333-w.

Therefore:

~~~text
representational geometry changes with learning
!= whole-field evidence by itself.
~~~

---

## 2. Core design idea

Use a novel multidimensional stimulus world with:
- identical local stimuli across conditions;
- matched exposure;
- matched marginal transition frequencies where feasible;
- sparse or delayed explicit labeling;
- experimentally manipulable consequence / concern structure.

The same stimulus set should admit multiple possible partitions.

Example stimulus dimensions:

~~~text
shape
surface pattern
motion tendency
sound token
spatial relation
~~~

No dimension should be intrinsically designated as the "correct category."

---

## 3. Two matched consequence worlds

Participants encounter the same local objects / events under two consequence structures.

### World A

Successful continuation / reward depends on relational structure A.

Example:
- similarity along shape × motion predicts safe continuation;
- surface pattern is largely irrelevant.

### World B

Same stimuli and exposure statistics, but consequence closure is reorganized.

Example:
- surface pattern × spatial relation now predicts continuation;
- shape similarity becomes weakly useful or irrelevant.

Important:

~~~text
same item set
similar local frequencies
different consequence topology
~~~

The manipulation is not merely a verbal rule instruction.

Participants should acquire the consequence structure through interaction.

---

## 4. Multi-probe test battery

After learning, probe the same learned world through different tasks.

### P1 — similarity geometry

Rapid pairwise similarity / arrangement task.

Question:
which items are spontaneously treated as near / far?

### P2 — grouping / equivalence

Forced grouping without category labels.

Question:
which differences are flattened into equivalence classes?

### P3 — boundary / morph probe

Use interpolated / ambiguous stimuli.

Question:
where does the participant place a categorical / event boundary?

### P4 — transition expectation

Show partial sequences and ask likely continuation.

Question:
which transitions are treated as reachable / natural?

### P5 — anomaly / surprise

Insert matched violations.

Question:
which deviations count as structural mismatch?

### P6 — action / affordance transfer

Present novel combinations and require an action with no direct training history.

Question:
does learned field structure transfer to novel local objectifications?

### P7 — optional perceptual foregrounding

Brief or noisy presentation.

Question:
which features / groupings become foregrounded under degraded input?

---

## 5. E2 criterion — predictive shared geometry

Fit a shared geometry from only a subset of probes.

For example:

~~~text
train geometry on:
P1 similarity
+ P2 grouping
+ P4 transitions

predict held-out:
P3 boundary
+ P5 anomaly
+ P6 transfer
~~~

Candidate geometry representations:
- learned Mahalanobis metric;
- low-dimensional embedding;
- graph / diffusion geometry;
- context-conditioned transition kernel;
- manifold with learned local neighborhoods.

E2 PASS requires:

> a common geometry predicts held-out local outcomes better than strong probe-specific local models.

This only establishes predictive organizational value.

---

## 6. H1 baseline — independent local-update family

Allow strong local models:
- feature-specific weights;
- task-specific thresholds;
- probe-specific logistic / nonlinear models;
- independent value functions;
- local transition-frequency models.

Do not cripple H1 artificially.

H1 wins if independent local updates predict held-out outcomes as well as the shared geometry.

If so:

~~~text
whole-field compression adds no value.
~~~

---

## 7. H2 baseline — strong latent-state / generative-model family

This is the critical comparator.

Allow:
- latent contexts;
- latent-cause inference;
- flexible feature representation;
- mixture models;
- learned task state;
- representation learning;
- context-conditioned RL;
- low-dimensional latent embeddings.

H2 must be allowed to change state partitions and representation basis.

Do not define H2 as fixed-state prediction.

### H2 absorption rule

If a strong latent / generative model:
- predicts all probes;
- captures context switches;
- generalizes to novel combinations;
- explains recursion after revaluation;

with no extra field-level variable / operator needed, then:

~~~text
whole-field language = translation / visualization layer
increment = ZERO.
~~~

---

## 8. E3 criterion — causal geometry reorganization

After initial learning, intervene on the consequence structure while holding local stimuli fixed.

Preferred intervention:

### outcome / consequence revaluation

Do not teach a new category label.

Instead change:
- what outcome matters;
- which action leads to continuation;
- which relation produces loss / gain;
- which consequence must be avoided.

Then test whether the same participant shows a coordinated change across P1–P7.

Required causal shape:

~~~text
consequence intervention
-> inferred geometry shift
-> coordinated multi-probe recutting
~~~

Use mediation / model comparison:

~~~text
intervention
-> geometry change
-> held-out probe change
~~~

versus:

~~~text
intervention
-> independent local probe updates.
~~~

E3 requires prospective prediction of the direction of multiple probe changes.

---

## 9. E4 criterion — recursive field reconstitution

E4 adds history writeback.

After E3 revaluation:

1. allow new local objectifications / learned labels / explicit rules to stabilize;
2. remove or neutralize those explicit cues where possible;
3. retest spontaneous similarity / grouping / transition / transfer;
4. introduce a second perturbation.

Target pattern:

~~~text
initial field organization
-> local objectification / action
-> consequence
-> shared geometry reorganization
-> new local objectification
-> second shared geometry reorganization.
~~~

E4 PASS requires:
- history-dependent field change;
- cross-probe common structure;
- held-out prediction;
- recursive re-entry.

This still does not establish SRT primitive Selection.

---

## 10. Stronger "same explicit knowledge" control

A key design improvement is to match explicit report.

Before multi-probe testing, measure:
- rule recall;
- stimulus familiarity;
- confidence;
- explicit category report;
- transition knowledge.

Where possible, select / weight participants or trials so groups are matched on explicit knowledge.

Then ask:

> can the same explicit knowledge support different spontaneous multi-probe geometry because consequence history differs?

This directly tests the author's concern that explicit objects / rules do not exhaust the operative whole.

But a positive result is still compatible with latent-state / habit / affordance models.

---

## 11. Whole-field criterion

Do not use "whole field" merely because several measures change.

Require all four:

### W1 — common structure

One shared geometry explains multiple probe families.

### W2 — transfer

Geometry fitted on some probes predicts unseen probes / novel stimuli.

### W3 — intervention

Changing consequence structure predictably changes the shared geometry.

### W4 — recursion

The geometry change becomes history and alters the next round of objectification / transition.

Only W1+W2+W3+W4 supports a strong neutral whole-field interpretation.

---

## 12. Optional neural extension

Behavior should be first.

If later neural data are added:
- fMRI RSA / representational geometry;
- EEG/MEG population dynamics;
- intracranial or animal population geometry where available.

Do not require neural data to establish the behavioral programme.

Neural success would require cross-level convergence:

~~~text
behavioral recutting geometry
<-> neural population geometry
~~~

with preregistered mapping.

A neural geometry effect by itself is E1, not E3/E4.

---

## 13. Formal comparison sketch

Let:
- x = local stimulus features;
- c = consequence context;
- h = participant history;
- p = probe type.

### H1 family

~~~text
y_p = f_p(x, c, h; theta_p)
~~~

Each probe has its own parameters.

### H2 family

~~~text
z = infer_latent(x, c, h)
y_p = g_p(z)
~~~

Shared latent state / model.

### H3 shared-geometry description

~~~text
Phi_geom = Geometry(c, h)
d_G(x_i, x_j)
T_G(x_i -> x_j)

y_p = readout_p(Phi_geom, x)
~~~

The empirical question is not whether H3 can be written.

It is whether:
- Phi_geom learned from some probes predicts other probes;
- Phi_geom responds coherently to intervention;
- Phi_geom mediates recursive reorganization;
- and H3 supplies gain beyond a strong H2.

---

## 14. Primary stop-loss

Downgrade whole-field interpretation if any of the following occurs:

### S1
Probe changes are independent and no shared geometry generalizes across tasks.

### S2
A strong H2 latent-state model fully predicts all cross-probe effects.

### S3
Geometry fits descriptively but does not predict held-out objectification.

### S4
Consequence revaluation changes explicit reports but not spontaneous geometry.

### S5
Geometry shifts after intervention but does not mediate later transfer / recutting.

### S6
The effect disappears after controlling task demand / attention / response strategy.

### S7
Only one probe family shows the effect.

### S8
E4 recursion is absent; explicit object learning does not alter later spontaneous field structure.

## 15. SRT mapping — strictly downstream

Only after neutral results:

~~~text
shared history-sensitive geometry
-> possible gate-geometry mapping

consequence-indexed revaluation
-> possible Bearer / concern mapping

history writeback
-> possible L2 retained-efficacy mapping

next-round recutting
-> possible later L0-facing field-reconstitution mapping
~~~

Do not infer:
- primitive Selection;
- L0 ontology;
- consciousness;
- Bearer necessity;
- scientific distinctiveness.
