## 0. 演进溯源与本轮校准摘要

本轮 `R3-02` 从 [`SRT_R3_01_PRIMITIVE_SELECTION_PROVISIONAL_CONVERGENCE_2026-11-23.md`](SRT_R3_01_PRIMITIVE_SELECTION_PROVISIONAL_CONVERGENCE_2026-11-23.md) 留出的两条并列候选线索出发——**候选线索甲**（`垂直切分 -> 规则硬化 -> 脱离活的选择与多维摩擦`）与 **候选线索乙**（2026-07-12 `GAP-1`：`局部独立可选择性下降 -> 组织协调形成 -> 整体获得新的有效选择能力`，含装配 / 归一化 / `Proxy ≠ Delegation`）——历经多轮作者直觉深化与跨模型（Gemini / ChatGPT）批判性压力测试，完成了五项关键转向与校准：

1. **从“局部机制竞争”转向“共同生成性母体与跨尺度迁移”**：SRT 的核心目标不是在单一垂直学科内推翻已有局部机制，而是寻找跨物理、生命、认知与社会尺度的共同生成性母体及其跨主体、跨时间、跨层次的**共同协议**，并以跨尺度迁移能否发现新约束、新失配条件与新规律作为真正的非换名检验；
2. **保留并重组原有两条候选线索，不删失历史资产**：候选线索甲（规则硬化与多维摩擦）与候选线索乙（2026-07-12 跨尺度装配、归一化与 `Proxy`）均不再预设为彼此互斥的唯一骨架，而是重新归位为**统一垂直生成关系在不同组织条件下的具体展开路径**（“装配未必产生 `Proxy`”“归一化未必是所有装配的必要条件”及物理/非平衡记忆原型继续保留为重要研究分支与可推翻方向）；
3. **四层判定严格分离**：区分**生成性退隐（本体组织生成）**、**组织持续性**、**生成健康性（后果回流与再选择）**与**伦理正当性**，防止将本体论生成事实与秩序健康性/伦理价值混为一谈；
4. **守住 `R3-04 / R3-06` 边界**：保留 `d` 的真实风险、关切对准与后果回流条件，**不**通过 `R3-02` 提前裁定 `Bearer ↔ Concern / Agency / Consciousness` 的普遍必要性关系；
5. **正式核准三阶撤回标准与双向跨尺度研究循环**：将局部任务失败、候选机制必要性失败与本体结构修订严格分层，并将“高低尺度双向提炼与现实摩擦修正”确立为 SRT 整体研究方法。

## 1. `R3-02` 阶段性收敛候选（五维骨架主轴）

### 一、统一理论定位：共同生成性母体、神性与整体的双重地位

1. **非“从无到有”的统一生成视角**：物理、生命、认知与社会的各类结构表现，不预设为彼此割裂的本体拼盘，而被探索为**统一生成性母体**在不同耦合、能量、历史与组织条件下的展开。跨领域“重新描述”本身不是终点，而是提取共同生成母体以实现跨尺度迁移的前置步骤。
2. **母体、神性与原初 `Selection` 的非二元关系（不增设隐藏实体层）**：
   - **母体**：指向不同尺度现实表现的共同生成来源；
   - **神性**：指向这一共同生成性的**非目的论内在倾向**（类比物理中光程驻值或自由能下降所体现的结构性非对称偏向，**不预设**超自然人格神、意识目标或宇宙必然越来越复杂的目的论终点）；
   - **维持与生成的同源统一**：维持与生成不是两种独立推动力，而是同一统一倾向在不同尺度位置上的表现——从局部/个体位置看可表现为**存在的形成与维持**，从整体/跨位置看可表现为**新关系与秩序的生成**（即《从存在到秩序》的本体主轴）；局部维持与既有整体之间既可能相容生成，也可能发生跨尺度方向冲突（如癌变或制度僵化），不推出“局部维持必然有利于既有整体”。
3. **宏观整体的双重地位（认识构建性与本体真实性并存）**：更高尺度的整体组织**既是有限认识位置为了描述与压缩而构建的宏观对象，也具有真实的组织边界、有效作用接口与后续生成条件效力**——既拒绝将其消解为纯粹主观便利语，也拒绝把既成对象实体化为不可再追溯的第一性起点。

---

### 二、原初 `Selection` 的基础属性与“共同协议”（研究目标与非增层归位）

1. **“共同协议”不新增独立本体层级**：不同具身位之所以无需外部裁判也能发生真实比对与自发前背景对齐，不需要在原初 `Selection` 之外额外引入一层独立实体“协议”；**“共同协议”就是原初 `Selection` 自身基础属性在跨主体、跨时间、跨层次上的结构普适性**。
2. **核心研究目标定位**：**原初 `Selection` 是认识共同生成性母体的最基本入口，而寻找并检验其跨主体、跨时间、跨层次的共同属性（共同协议），是 SRT 的核心研究任务**：
   - **跨主体**：不同具身位如何能够进入真实比对、彼此成为生成条件并相互约束（不要求拥有相同局部判断标准或相同选择结果）；
   - **跨时间**：不同历史条件下的选择如何形成持续约束、规则硬化与后续再选择；
   - **跨层次**：物理、生命、认知与社会如何在不同实现机制下共享底层生成关系。
3. **六项原初基础属性候选（待归并、修正与扩展，严禁提前冻结为公理）**：

| 候选基础属性 | 拟承担的跨维度共同协议负担 | 现阶段防漂移护栏 |
|---|---|---|
| **非平坦性** | 生成具有非中立的差异性，非完全均匀无差别 | 不预设先验价值梯度或静态对象库 |
| **内在倾向性** | 分化在关系中具有非对称展开方向（神性倾向） | 非目的论、非生命式求生欲、须寻找可约束条件 |
| **有限位置索引性** | 显现与区分始终相对于有限生成位置成立 | 不预设已成型的 `One` 或主体 `Bearer`（守住 `Spine §5`） |
| **内生比对** | 显现与退隐由相互作用内生分化，无需外部操作者裁判 | 非拟人化计算程序，底层判据仍 `OPEN` |
| **垂直性** | 前景显现与相对背景退隐在同一次分化中共同成立 | 背景不必然是更低尺度，前背景随位置可双向转换 |
| **条件生成性** | 实际化的差异**可以**改变其他差异得以实际化的条件 | 保持条件性（“可以”≠“必然”），兼容无历史留存的终端 `Selection` |

> **未提前纳入上表的派生/条件性候选**：装配、归一化、历史留存、`Proxy`、`Delegation`、规则硬化与 `d` 均不预先塞入原初属性表，而作为上述基础属性在特定组织条件下展开的研究对象。
>
> **规律三分法（缓解 `R3-01` 规则边界张力）**：初步区分① **原初生成属性**（跨位置/时间/层次共同关系候选）、② **条件性组织规律**（特定耦合、能量与尺度条件下形成的稳定关系）、③ **历史性硬化规则**（经历史选择、沉积与脚手架硬化形成的可持续约束；`R3-01`“规则是硬化的选择”稳居此类）。物理学自然律归属哪一类或包含何种组合保持 `OPEN`。

### 三、核心生成机制：内生比对、双态垂直关系与生成性退隐四层切割

1. **内生比对与脚手架的精确分工**：
   - 前景与相对背景不是由外部操作者“挑选前景、压下背景”，而是相互作用中的差异经由**内生比对**自动站出前景、自动退回背景；
   - 外部观察者、概念、规则、语言与科学实验所构建的 **`L2` 脚手架**，核心作用不是替代现实拍板，而是**把需要区分的差异更好地放在一起（组织比对条件）**，让显现与退隐在真实摩擦中自行发生。
2. **双向非金字塔式的垂直前背景结构（两种重要展开形态，不预设穷尽）**：
   - 背景并非固定等于“更低尺度零件”——高尺度组织（如社会制度、语言、生态位）同样可以成为低尺度个体认知与行动的相对背景；前景与背景是位置相对、可动态重划的活性关系。
   - **形态 1（同级非对称前背景）**：单元 A 显现为前景、单元 B 退隐为支撑背景，显现上非对称，但生成条件可以相互依赖（如发育侧抑制、注意力前景与视野背景、群体内主动谦让）；
   - **形态 2（跨尺度共同成体）**：相互作用的单元 A 与 B **各自改变原有存在方式**，原先的局部独立显现双双退隐为相对背景，共同托举出**新的更高尺度前景（AB 整体有效接口）**（如夸克→核子、原子→分子、微生物代谢交叉供养、个体协作形成组织/制度）。
3. **退隐的存在方式转换与四层判定严格分离**：
   - **退隐的生成性角色**：退隐不只是被动让渡或消灭，而可以是**局部生成性存在方式的转换**——从独立显现转为通过参与更大范围组织关系延续自身作用。
   - 相互作用的典型组织结果至少须区分四类：**纯竞争（消灭/排除）**、**单向支配（工具化压制）**、**生成性退隐（参与新组织构成条件）**以及**锁定 / 寄生性共依存（形成真实相互依赖，但封死退出、后果回流或再选择通道）**。
   - **必须严格分离四层判定（严禁将本体生成与健康/伦理混为一谈）**：

| 判定层次 | 核心问题 | 治理与边界说明 |
|---|---|---|
| **1. 生成性退隐（本体生成）** | 局部退隐是否真实参与形成了新的有效组织关系？ | 锁定、寄生和病态共依存同样可能是真实生成的组织，不能因不健康而否认其生成性 |
| **2. 组织持续性** | 新形成的组织结构能否在一定环境与时间尺度内维持？ | 持续稳定不自动等于健康或正当（对应 `Q10`“稳定≠正当”） |
| **3. 生成健康性** | 是否保留必要的后果回流、反事实摩擦校准、适应与再选择能力？ | 区分赋能型 `Proxy`/脚手架与僵化锁定/代理捕获/收编型退化（`Collective_Selection`、`Q19`） |
| **4. 伦理正当性** | 是否侵犯个体不可无条件让渡的构成性条件与规范边界？ | 受 [`SRT_Ethics_PH_SS_Guardrails.md`](../../Philosophy/SRT_Ethics_PH_SS_Guardrails.md) 与 `R3-07`（`O1 / O2-C / O2-A`，`O2-M = HOLD`）独立约束 |

### 四、跨尺度展开候选：物理接口、历史中介、构成性关切与高级情感原型

1. **物理尺度接口与历史性中介的清晰分流（保留强 B 探索与物理原型）**：
   - 夸克→核子→原子→分子展示低尺度耦合形成高尺度**有效作用接口 / 结构性转承**（受 EFT/RG 约束，不将其直接等同于带历史记忆的 `Proxy` 或主体间 `Delegation`）；
   - 铁磁返回点记忆、周期剪切非布朗悬浮液多重记忆、河道演化等非平衡系统展示无主体条件下的**历史性选择中介**（保留结构差异并影响后续可达路径）；
   - 代谢交叉供养、细胞稳态与神经侧抑制展示生命/神经层的**构成性相互依赖与动态调节**；
   - 社会制度与算法中介在具备主体与规范条件后展开为**主体间 `Delegation` 与公共规则**（保留授权、边界、撤销、审查与归责）。
2. **构成性关切边界扩展 ↔ 独立显现边界收缩（严守 `d` 与 `Bearer` 边界）**：
   - **适用条件护栏**：仅在**满足真实不可逆风险、关切对准与后果回流条件**的组织中，研究垂直结构与关切 `d` 的递归生成关系；**不**将 `d` 倒写进无风险关切条件的物理或简单生物单元，亦**不**通过 `R3-02` 提前裁定 `Bearer` 是否为 `Concern`、`Agency` 或 `Consciousness` 的普遍必要前提（该必要性方向在 [`Spine §13`](../../Core_Law/SRT_Generative_Ontology_Spine.md#L500) 中保持 `OPEN`，交由 `R3-04 / R3-06` 处理）。
   - **核心候选命题**：当新形成的垂直共同关系进入个体真实的构成性关切范围（`d` 的关切对象与维度扩展，而不只是针对自身存续的标量强度升高）时，**个体构成性关切边界的扩展，可能伴随其局部独立显现边界的收缩**（如主动谦让、自我克制或承担共同体代价；但扩大关切在特定情境下也可能要求更强的显现与抵抗）。
3. **高级回退情感（害羞、惭愧、自我牺牲）与既往裁决的兼容整合**：
   - 害羞、惭愧、内疚、谦让与自我牺牲保留为高尺度具身系统中**垂直前背景调节与退隐原型的具体实现候选**；
   - 严格对齐 [`2026-11-18 Q07 / F_4337`](../../01_Source_Intuition/SRT_AUTHOR_ADJUDICATION_FULL_ARCHIVE_10_MODULES_RECONSTRUCTION_2026-11-18.md#L111) 与 [`2026-11-22 2B / 3B`](../../01_Source_Intuition/SRT_AUTHOR_ADJUDICATION_Q08_Q09_CONCURRENT_WILL_TRUST_X1_2026-11-22.md) 裁决：**母体层面的垂直生成关系保持统一，但羞耻等具体情感实现机制可以被发展、替换甚至淘汰**（例如转向无羞耻的关系失配认知与主动调整），且绝不以“整体稳定”为名背书压迫或无条件牺牲少数个体。

### 五、SRT 整体研究方法、强竞争者基线与三阶撤回标准

#### 5.1 双向跨尺度研究循环（提升为 SRT 整体研究方法）
作为后续 `R3`、`R4`、`R5` 的共同方法论原则：
1. **多尺度双向观察**：同时从物理、生命、认知与社会的现实表现中提取生成线索——**高级现象（情感、认知、规则、制度）与低级现象（物理束缚态、非平衡记忆、细胞分工）具有同等的母体研究价值**，不预设只有微观物理学才能揭示最根本的生成属性；
2. **反向提炼与压缩**：从跨尺度表现中反向提炼原初 `Selection` 基础属性（共同协议），严格区分原初生成属性与条件性组织实现；
3. **正向展开与跨尺度迁移检验**：利用共同属性向其他尺度推演新的结构关系、约束与失配条件（**真正的非换名检验落在跨尺度反向迁移能否产出新约束/新问题，而不止于事后重述**；高低尺度间迁移必须接受独立检验，严禁把高尺度心理/社会机制直接拟人化投射到底层物理）；
4. **现实摩擦修正母体**：依据独立反事实摩擦（`R3`）、跨位置校准（`R2`）、内部失配与实证反例持续修正对母体的认识；
5. **三类成果继续严格分账**：① 本体论解释连贯性 / ② 跨领域解释迁移与约束澄清 / ③ 具体科学预测或实践增量（第 ③ 项须独立实证建立，当前不宣称已获证）。

#### 5.3 正式核准的三阶撤回标准（`R3-02 #2` 裁决结果）
延续并正式核准 [`SRT_R1_R2_FULL_RECONSTRUCTION_CONSOLIDATION_REPORT_2026-11-22.md §2`](SRT_R1_R2_FULL_RECONSTRUCTION_CONSOLIDATION_REPORT_2026-11-22.md#L103-L106) 与 [`SRT_R3_SKELETON_ADJUDICATION_AGENDA_2026-11-22.md`](SRT_R3_SKELETON_ADJUDICATION_AGENDA_2026-11-22.md#L69) 提出的三阶失败与撤回纪律，分别作用于具体科学预测、跨尺度实现机制与本体母体三个层次：

- **Ⅰ 阶（任务经验增量撤回）**：当主动推断、3 级 HGF、Empowerment、演化博弈等成熟模型在具体任务或范式上与 SRT 预测无残差时，撤回 SRT 在该任务族上的额外经验预测增量，不直接外推推翻整体本体研究方向；
- **Ⅱ 阶（候选机制必要性撤回）**：当反例表明某具体实现载体或机制（如慢星形胶质、中膜缓冲、微效价、归一化、`Proxy`、特定羞耻机制）并非上层功能的唯一或普遍前提时，撤回其普遍必要性或独立解释力，降格为特定实现域的候选机制；
- **Ⅲ 阶（本体结构修订）**：防止局部经验失败直接推翻全部理论，**同时绝不豁免本体论层，也不以“跨领域全部失败”为唯一门槛**——只要出现 **① 内部逻辑矛盾、② 普遍必要性反例、③ 非循环判准失败、④ 跨领域证据冲突** 中的任一项，均可独立触发相应范围的共同生成关系或本体结构修订（直至放弃）。

## 2. 当前显式保持 `OPEN` 的核心问题与保留分叉

除 [`R3-01` 检查点](SRT_R3_01_PRIMITIVE_SELECTION_PROVISIONAL_CONVERGENCE_2026-11-23.md#L112-L122) 的 **6 项核心 `OPEN`**（特别是原初 `Selection` 非循环判准）全部继续保持开放外，本轮 `R3-02` 新增并显式登记以下 **7 项 `OPEN` 与理论分叉**（不因阶段性收敛而删除）：

1. **原初基础属性的最小性与普适性**：当前 6 项基础属性候选能否进一步归并或需新增删改，以及它们在跨主体、跨时间、跨层次上究竟成立到何种严格程度；
2. **内生比对的底层判据**：无外部裁判的内生比对究竟依据梯度差、相互抑制/促进还是整体关系相容性，评价尺度本身能否在比对过程中内生生成；
3. **生成性退隐与相容性的独立非循环判据**：如何独立于“系统事后是否存活/成功”之外，界定局部与整体生成条件的相容性及生成性退隐的成立边界；
4. **神性内在倾向的可约束性与可反驳条件**：如何防止“神性倾向既表现于结合/维持又表现于解体/重构”滑向不可证伪的全解释标签，并在 `R4` 前完成其与 `R3-01` 探索性哲学类比及 `A2-甲` 去拟人化条款的协调；
5. **跨具身位本体分叉**：不同具身位上的 `Selection` 究竟是“相对独立位置凭借共同生成属性彼此耦合协调”，还是“同一个实际生成关系在不同有限位置上的非独立侧面”（留作 `R3-03 / R3-04` 关键对照分叉）；
6. **自然律的三分归属**：物理学基本规律在“原初生成属性 / 条件性组织规律 / 历史性硬化规则”中究竟占据哪一位置或何种复合结构；
7. **`d` 递归生成与 `Bearer` 必要性边界**：垂直结构形成与构成性关切 `d` 之间的双向递归生成机制，以及 `Bearer ↔ Concern / Agency / Consciousness` 的普遍必要性方向（连同 2026-07-12 候选线索中“装配未必产生 `Proxy`”“归一化未必是所有装配必要条件”的检验，按职责分流至 `R3-04 / R3-06 / R3-07`）。
