## 4. M4-E0 absorption-before-execution gate

After freeze, inspect mature target-domain practice.

Record:

~~~text

target field already owns equivalent control? =
target field already owns same failure expectation? =
repository-local target work already owns it? =

~~~

Verdict:

### ABSORBED

If mature practice already owns the same design and no independent replication rationale exists:

~~~text
M4 = NO / ABSORBED
STOP before duplicate execution.
~~~

### DESIGN-CANDIDATE

If the frozen GRG design is not already owned:

~~~text
M4-DESIGN-CANDIDATE
~~~

This is not full M4 yet.

## 5. Execution gate

Only for a non-absorbed design candidate.

Freeze:

- exact unit;
- sample / source;
- intervention;
- controls;
- metric;
- threshold / comparison;
- adverse-result rule;
- semantic-failure rule.

Do not inspect target outcome first.

## 6. Final verdict classes

~~~text
M4-ABSORBED
M4-INVALID
M4-SEMANTIC-FAIL
M4-NULL
M4-PASS
~~~

M4-PASS requires a genuine target-domain gain that survives source-native comparison.

## 7. M4-PASS does not imply

~~~text

~~~

## 8. Writeback

Every M4 attempt must update:

- Relation Library;
- Framework / Atlas if method changed;
- STATUS;
- handoff;

Absorption is a valid learning result.
