# GRG Cross-Objectification Reconstruction Record — Template v0.1

> Use this record **before or alongside** a GTS when the correct generative cut / transformation is still being discovered.
>
> It does not replace GTS v0.2.
>
> It does not require one-to-one domain-object / GRG-object mapping.

## 1. Source-native reconstruction

Write this section so that a competent domain reader can understand it without GRG vocabulary.

~~~text

~~~

For every load-bearing source claim / relation, retain a locator:

~~~text

  passage / equation / figure / dataset field / protocol step

analyst inference:
  NONE / DECLARED
~~~

A GRG-neutral paraphrase without a locator remains analyst inference, not source-native evidence.

Do not yet ask which GRG construct each item "is".

## 4. Domain-native generative reconstruction

Use source-native or neutral relation language.

### Selection terminology guard

When the source uses `selection`, `choice`, `filtering`, `actualization` or similar language, inherit `SRT_AI_START.md §1.1`:

~~~text
source-native selection / choice / filtering
!= SRT Selection by word or role alone.
~~~

Do not let this first-contact reconstruction surface silently import the ordinary pre-given-menu meaning into SRT Selection.

Every load-bearing reconstructed relation below must point back to the source locator recorded in §1 or be marked `ANALYST_INFERENCE`.

~~~text
initially present differences / conditions:
relations that make some differences consequential:
relations that suppress / buffer / localize / amplify consequence:
actual transformations:
what becomes newly possible / impossible / constrained:
what prior organization enters later process:
what current transformation changes in later conditions:

~~~

Only fill what the source warrants.

## 16. Anti-self-sealing close

If a candidate failed and was revised:

~~~text
failed candidate version:
failure preserved at:
new candidate version:
new freeze required before independent test?:
  YES
~~~

Never rewrite a failed candidate and count the same case as independent support for the revision.

A target that caused or informed the failure / revision is permanently non-held-out for that revised candidate.
