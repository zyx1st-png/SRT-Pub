## 11. Framework v0.1 exit gate

Before a deep well opens, verify:

```text
[ ] Given-Ones inventory exists
[ ] all six Constitution operations have domain-native translations
[ ] objectification map exists
[ ] bearer / position roles are separated
[ ] Material Re-entry Pass is complete or blockers are explicit
[ ] inherited SRT assets are rerouted
[ ] stable problem families exist
[ ] mature neighbors are mapped without novelty gating
[ ] candidate well has a parent family
[ ] deep-well question is narrower than the framework
```

If several boxes fail, do not compensate by making the deep-well charter longer.
