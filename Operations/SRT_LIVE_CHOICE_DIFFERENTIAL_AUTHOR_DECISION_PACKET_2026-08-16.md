# Live Choice Differential — A4 Rival Identifiability + Author Decision Packet

> **Purpose**: A1–A3 have removed the easy routes. This packet identifies the first remaining decision that cannot be made by audit discipline alone: **what positive structure, if any, should SRT choose to place behind the word `live` in P1-T05 for future P3/P4 discrimination work?**
>
> **No canonical edit is proposed here.** The decision selects a research direction and proof burden. Any later canonical amendment would require a separate author gate and Claim-Ladder review.

---

## 0. Why an author decision is now genuinely required

A1 showed that much of selection's downstream structural work can be reconstructed in non-selection vocabulary while formal residue remains `UNASSIGNED`.

Pass 1.5 showed:

```text
CG full pass != P1-T05 real choice
```

because a deterministic scripted transaction can pass the five operational gates while P1-T05 still blocks promotion from script execution to real choice.

A2 then returned:

```text
NO-D2
```

across software, E. coli, and institutional cases: current SRT did not make a different counterfactual/intervention prediction from a strong ordinary causal-history description.

A3 returned:

```text
NO-GO FOR EMPIRICAL EXECUTION AT THE CORE REAL-CHOICE LEVEL
```

because no existing candidate supplied a positive, prospective, outcome-independent, rival-discriminating `live` variable.

At this point the remaining question is no longer a missing checker, missing case, missing threshold, or missing literature citation. It is architectural:

> **Which positive burden should SRT deliberately choose to develop, if any, as the P3 bridge behind `live choice`?**

That choice changes what future failure would mean and therefore requires author ownership.

## 1. A4 correction: `R_CH` is not itself a fair empirical rival

### 1.1 What A2's `R_CH` was good for

A2 froze a generic causal-history schema with arbitrary functions for:

```text
state
internal mediation
policy / transition rule
history / memory
cost / bearer state
environment
policy update
future reachability
```

This was useful as an **absorption test**:

> can ordinary causal-history vocabulary carry the currently observed roles without a primitive `selection` variable?

For A1/A2 subtraction pressure, yes.

### 1.2 Why it cannot be the final D2 competitor

If `M/A/F/U/G/C/Reach` remain unrestricted function classes, a finite new observation can almost always be absorbed by:

- a richer state variable;
- a wider generative support;
- an updated policy rule;
- a latent history term;
- a new nonlinear interaction.

That is not a strong scientific rival. It is a near-universal representational container.

Therefore the following demand is too strong in the wrong way:

```text
SRT must produce an outcome that no arbitrary causal-history function could represent.
```

A universal-enough dynamical language is not falsifiable by finite behavior merely because it is expressive.

### 1.3 Correct division of labor

From A4 onward:

```text
R_CH = representational absorption / translation stress test
```

but:

```text
D2 competitor = named or explicitly bounded model family
              + frozen state variables
              + frozen update class
              + calibration data
              + complexity / revision cost
              + out-of-sample prediction
```

A future rival may be an adaptive controller, model-based RL family, generative/meta-learning family, active-inference-style model, or another specific class. The exact external theory can be chosen later per domain. What matters now is that the competitor must be **constrained enough to make a prospective prediction**.

### 1.4 Rival tiers

Use this hierarchy:

| Rival tier | Capacity | Valid use |
|---|---|---|
| `R0 fixed` | fixed script / mapping / state machine | weak negative control only |
| `R1 adaptive` | declared memory + hysteresis + parameter/policy update family | meaningful basic rival |
| `R2 generative` | declared generative / meta-learning / representation-update class with frozen calibration | strongest normal D2 rival |
| `R∞ universal` | arbitrary history-dependent functions / unrestricted latent expansion | translation stress only; **not** an empirical D2 judge |

A credible SRT differential should eventually survive at least a relevant `R2` competitor. Beating only `R0` is not enough.

## 2. What the repository already says about the positive direction

Several existing records constrain the option space without deciding it.

### 2.1 P1-T05 gives the negative boundary

Real choice requires a live anchoring event whose selected result constrains future selection space, while script execution, habit replay, gradient following, and L2-label optimization are insufficient by themselves.

What it does **not** currently specify is the positive operational property that separates `live` from a sufficiently adaptive non-live process.

### 2.2 Choice-generation work allows non-enumerated candidate spaces

`SRT_Choice_Generation_Conditions` explicitly allows continuous / non-enumerated possibility spaces and says a difference may become effective only during process unfolding. It also distinguishes:

```text
candidate formation
process unfolding
event standing
```

So SRT is already protected against reducing choice to a pre-given menu.

### 2.3 PH-DIFF01 puts problem-space upstream of option-space

PH-DIFF01 distinguishes four local levels:

```text
outcome selection within fixed menu
option-space generation / revision
problem-space constitution / revision
rule-generative revision of how problems/options are produced
```

and warns that selection must not merely realize a preformed copy.

### 2.4 ST-A / B13 gives a downstream stronger notion

Generative reselectability means consequence return can revise:

```text
comparison rules
boundaries
candidate-generation conditions
```

but B13 explicitly says this stronger property is **not necessary for every individual selection event**. Therefore it cannot simply be imported into P1-T05 as the definition of live choice.

### 2.5 The source-intuition record is asymmetric

The 2026-07-09 ChoiceMap trace contains author-confirmed choices that emphasize:

- `B3 + B5`: **comparability + future reselectability**;
- `I1 + I2 + I3`: monopolization of manifestation, allocation, and comparison scale as upstream choice poverty;
- `J1 + J2 + J3 + J6`: de-occlusion, redistribution, **rebuilding the comparison scale**, and escaping the choice cage.

Notably, in that J-round the explicit option:

```text
J4 = generate new options
```

was **not** selected.

This does not prohibit candidate generation. It does mean that making “novel option generation” the positive essence of live choice would be a real theoretical pivot rather than a straightforward continuation of the strongest author-confirmed source intuition.

## 3. Three admissible author options

The options below are deliberately non-overlapping at the level of **research center of gravity**. They can later interact, but A4 requires choosing which one bears the primary proof burden.

---

# Option LC-A — Comparison-Space Reconstitution

## A.1 Core idea

Develop `live` primarily as the capacity for a currently effective difference to **reconstitute the comparison relation / scale by which candidate differences become non-equivalent**, rather than merely executing or updating within an already adequate comparison frame.

Working P3 sentence:

> A live-choice candidate is an event in which the operative comparison structure is itself endogenously reconstituted in response to a currently effective mismatch, and that reconstitution changes which differences become action-guiding in a later novel probe.

This does **not** mean every preference update is real choice.

## A.2 Five-output contract

### `L*_A`

**Comparison-reconstitution event**: a predeclared comparison basis cannot order / adequately separate the focal conflict, and the system forms a new comparison relation or dimension that is measurable before the downstream transfer outcome.

### `I_L_A`

Introduce a conflict that is underdetermined by the frozen comparison basis while keeping the immediate action menu and basic resource budget fixed. The manipulation must not externally supply the new comparison metric.

### `R_frozen_A`

A calibrated `R2` rival with explicit representation / value / meta-update class. Its allowed feature construction and objective-update family are frozen before the focal event.

### `O_future_A`

A novel probe whose outcome depends on whether the newly formed comparison dimension transfers:

```text
SRT bridge prediction:
condition with genuine comparison reconstitution
-> stronger preregistered transfer along the new dimension
than a matched script / fixed-frame condition

after rival state matching / calibration.
```

### `F_SRT_A`

Downgrade/withdraw the bridge if:

- the frozen R2 rival predicts the same transfer out of sample;
- the putative new comparison dimension is measurable only after the outcome;
- an externally supplied feature/metric explains the effect;
- no transfer survives a new task where immediate output and reward history are controlled.

## A.3 Strengths

- strongest continuity with author-confirmed `B3`, `I3`, `J3` source intuition;
- directly attacks the “fixed comparison frame” form of scriptedness;
- does not require literal new action options;
- fits PH-DIFF01's problem/scale-generation pressure;
- can fail cleanly against representation-learning / meta-learning rivals.

## A.4 Main risk

A sufficiently good representation-learning or preference-learning model may absorb the entire effect.

If that happens, LC-A may still be useful as a cognitive/agency bridge, but it will not earn a core D2.

## A.5 Theoretical cost

Low-to-medium. It extends an existing author-confirmed intuition but requires a new positive P3 bridge relation between `live` and comparison-space reconstitution.

---

# Option LC-B — Candidate/Problem-Support Expansion

## B.1 Core idea

Develop `live` primarily as the capacity to produce a viable continuation or problem/candidate formulation outside the preregistered support of a frozen generative rival.

Working P3 sentence:

> A live-choice candidate is an event that expands the effective continuation/problem support beyond what a calibrated pre-event generative model assigns non-negligible support, with the new path subsequently entering the same system's history and future reachability.

## B.2 Five-output contract

### `L*_B`

**Support-expansion event**:

```text
candidate/path q
such that
P_R2(q | Z_pre) <= epsilon_R
```

under a rival support distribution calibrated before the focal window, while `q` is generated and used without external injection of the candidate itself.

### `I_L_B`

Present a perturbation for which the current explicit menu/support is inadequate, while preventing external insertion of the focal candidate/path.

### `R_frozen_B`

A calibrated generative/meta-learning `R2` family with:

- frozen architecture/model family;
- held-out calibration;
- preregistered probability floor `epsilon_R`;
- complexity penalty;
- no post-hoc support widening without a new testable prediction.

### `O_future_B`

Prospective prediction:

```text
P(out-of-rival-support viable continuation | live condition)
>
P(out-of-rival-support viable continuation | script/control)
```

plus durable reuse/transfer of the new continuation in a later probe.

### `F_SRT_B`

Downgrade/withdraw if:

- calibrated R2 support already covers the “novel” continuation;
- support expansion disappears under stronger held-out calibration;
- external prompts/tools supplied the candidate;
- novelty has no later historical/reachability effect;
- a rival with independently justified wider support predicts the data without special accommodation.

## B.3 Strengths

- easiest route to a sharp probability prediction;
- naturally produces a prospective D2 contract;
- connects to anti-preformation / problem-space generation;
- experimentally cleaner than phenomenality or `T_dir`.

## B.4 Main risk

**Model misspecification can masquerade as ontology.**

“Rival assigned low probability” may mean only that the rival was too narrow. A universal/open-support generator also makes literal “out of support” rare or meaningless.

## B.5 Theoretical cost

Medium-to-high. It makes candidate/problem generation much more central to live choice than current P1-T05 does and is less directly aligned with the strongest author-confirmed ChoiceMap choices, where `J4 generate new options` was not selected.

---

# Option LC-C — Do Not Positively Operationalize P1-T05 Yet

## C.1 Core idea

Keep P1-T05 as a constitutive **negative / boundary theorem**:

```text
script / habit / gradient / L2 automation are not sufficient
```

but do **not** force a new positive `live` variable into it now.

Move near-term scientific discrimination to better-developed downstream candidates such as:

- `P24-2` d-value / concern-weighted non-substitutability;
- `P24-3` L2 hardening: local cost down + global constraint up + hysteresis;
- `P24-6` stake / future-selectability / consequence-return architectures;
- other bridges with independently measurable variables.

Under LC-C, real-choice operationalization remains an open theory problem rather than the next empirical bottleneck.

## C.2 Five-output contract

No core `L*` is declared.

Instead the contract becomes:

```text
L*         = NOT YET LICENSED
I_L        = NOT YET LICENSED
R_frozen   = selected per downstream P24 claim
O_future   = downstream prediction, not P1-T05 proxy
F_SRT      = failure of that P3/P4 bridge only
```

## C.3 Strengths

- maximally faithful to claim discipline after A1–A3;
- avoids inventing a “live essence” merely because an experiment needs one;
- lets SRT seek empirical traction where variables are already more mature;
- preserves P1-T05 without pretending it is already a lab law.

## C.4 Main risk

The central notion of “real choice” remains scientifically underdetermined for longer.

Critics can reasonably say:

> SRT can exclude scripts verbally but has not yet told us what positive measurable event replaces them.

If downstream P24 work succeeds while P1-T05 remains open, the theory may gradually shift from a core real-choice science toward a broader selection-centered process framework.

## C.5 Theoretical cost

Low immediate cost, high strategic consequence. It explicitly deprioritizes the most central-looking discriminator rather than forcing premature closure.

## 4. Option not offered: consequence-driven self-reconstitution as the definition of live choice

A tempting fourth option would define live choice by:

```text
same-bearer consequence return
-> revision of comparison rules / boundaries / candidate-generation conditions
```

A4 does **not** offer this as a peer option because B13 already assigns it to **generative reselectability / generative health** and explicitly says that stronger property is not necessary for every individual selection event.

Promoting it to P1-T05 now would silently reverse ST-A's author decision.

It remains available as a downstream modifier or experimental factor under LC-A/B/C.

## 6. Audit recommendation before author choice

### 6.1 If the goal is maximum fidelity to the existing SRT intuition

Prefer **LC-A**.

The strongest already author-confirmed source trail repeatedly emphasizes:

```text
comparability
rebuilding scales
removing monopoly over what can count as a relevant difference
future reselectability
```

rather than simple option count or novelty.

### 6.2 If the goal is quickest route to a quantitative D2 attempt

Prefer **LC-B**.

It is easier to turn into a probability / support prediction, but it carries the greatest risk that success only demonstrates a misspecified rival.

### 6.3 If the goal is strictest claim discipline after three negative gates

Prefer **LC-C**.

This is the most conservative scientific decision: do not manufacture a positive essence of live choice just to satisfy the experimental program. Move empirical resources to P24 candidates whose measurements are more mature and keep real-choice positivity open.

### 6.4 Audit preference

**A4's methodological preference is `LC-C > LC-A > LC-B` for the next immediate workline.**

Reason:

1. A1–A3 have all returned pressure/negative results rather than a surviving positive core discriminator;
2. LC-B is too easy to confuse with rival underfitting;
3. LC-A is theoretically coherent and source-faithful but still heavily absorbable by representation/meta-learning rivals;
4. SRT already has several downstream discriminating predictions that can be hardened without pretending P1-T05 itself has been operationalized.

This is a methodological recommendation only. It cannot decide the author-level question of what SRT should ultimately mean by `live`.

## 7. Author decision requested

Choose one research route:

### `LC-A` — Comparison-Space Reconstitution

> Keep real choice central and develop a positive P3 bridge around endogenous rebuilding of the comparison frame/scale.

### `LC-B` — Candidate/Problem-Support Expansion

> Keep real choice central and develop the cleanest quantitative D2 route around expansion beyond a frozen generative rival's preregistered support.

### `LC-C` — Defer Positive Core Operationalization

> Keep P1-T05 as a constitutive exclusion boundary for now; move empirical discrimination to P24-2 / P24-3 / P24-6 and revisit a positive live-choice bridge only when an independent discriminator emerges.

### Optional author rewrite

Reject A/B/C and state the positive structure that, in your view, makes a choice **live** rather than scripted/adaptive while not defining it by its later outcome.

## 8. What happens after the decision

### If LC-A

Build one P3 comparison-space discriminator spec; no canonical edit. Freeze one R2 representation/meta-learning rival and one prospective transfer prediction.

### If LC-B

Build one P3 support-expansion discriminator spec; no canonical edit. Freeze generative rival family, calibration set, `epsilon_R`, complexity penalty, and out-of-sample transfer test.

### If LC-C

Close the core real-choice empirical workline as `deferred / positive discriminator absent`; select one of P24-2, P24-3, P24-6 for the next differential-hardening package. A separate audit should rank those three by current measurability and rival distinctiveness before experimental execution.

No route licenses P0/P1 promotion or a formal selection residue.

## 9. Stop rule

This workline stops at the author gate because:

1. generic `R_CH` has been correctly demoted from empirical rival to translation stress test;
2. a valid future D2 rival must be constrained and pre-calibrated;
3. the remaining live-choice directions have been compressed to three architecturally distinct routes;
4. their tradeoff is no longer resolvable by evidence already in the repository;
5. choosing among them changes SRT's future explanatory center of gravity.

**Author intervention is required before further live-choice work proceeds.**
