# GRG Position / Horizon Conflict Ledger v0.1

## 0. Purpose

This ledger prevents a civilizational analysis from collapsing heterogeneous consequences into one aggregate outcome.

It asks:

~~~text
same relation / intervention
-> consequence for which position?
-> at which horizon?
-> through which evidence?
-> is there an actual directional conflict,
   or only a reason to keep positions separate?
~~~

It is not:

- a moral score;
- a political ranking;
- a utility aggregator;
- a new canonical relation;
- evidence that every multi-position system contains a conflict.

## 1. Required distinctions

Every social / institutional / civilizational record should distinguish where applicable:

~~~text
immediate beneficiary position
delayed affected position
local consequence
distributed consequence
short horizon
long horizon
externalized cost
reversibility
correction / revision capacity
evidence for actual directional divergence
~~~

Three statuses must not be conflated:

~~~text
POSITION/HORIZON SENSITIVE
= aggregation could hide a relevant difference.

DIVERGENCE EVIDENCED
= the source set supports consequences that pull in different
  directions across positions or horizons.

DIVERGENCE NOT ESTABLISHED
= separate positions/horizons are analytically relevant,
  but the current source set does not establish opposed consequences.
~~~

## 3. Strongest current divergence case

AMR is the clearest current example because the source-native record already pays both sides of the horizon split:

~~~text
immediate therapeutic benefit
can coexist with
later population-level loss of treatment effectiveness.
~~~

The GRG contribution is not the medical mechanism.

It is the requirement that both positions / horizons remain present in the generative-expectation analysis.

## 4. Cases that must not be overread

### Road capacity

The current target sources pay:

~~~text
immediate capacity effect
!=
post-adaptation demand / congestion state
~~~

They do not, in the GRG source package alone, establish a specific distributive conflict among residents, drivers, land users or other groups.

Therefore:

~~~text
time-horizon divergence = evidenced
distributional conflict = open
~~~

### Nepal irrigation

Tail-end water availability makes position sensitivity source-native.

But:

~~~text
position-sensitive metric
!=
evidence that upstream and downstream consequences are directionally opposed
~~~

### AI authorization

Different affected positions are conceptually available.

The M4-01 security audit does not independently establish their normative conflict.

## 5. Aggregation guard

Forbidden shortcut:

~~~text
aggregate performance improves
-> all relevant positions improve
~~~

Also forbidden:

~~~text
one position is harmed
-> whole relation is therefore morally illegitimate
~~~

Both require explicit evidence and normative premises.

## 6. Relation-library boundary

Position / horizon indexing can apply to many different GRG relations:

- X3b operative expectation regimes;
- X4b reconstructed-field feedback;
- future R1-family social realizations;
- other civilizational relations.

Therefore this ledger currently treats position / horizon divergence as a cross-cutting analysis burden rather than a standalone generative relation.

## 6.1 CIV-006 lesson

CIV-006 shows why PH must stay separate from relation identity.

~~~text
X4c inheritance can be strongly paid
while
fine-grained distributive conflict remains open.
~~~

The same record can therefore support:

- strong relation admission;
- strong horizon divergence;
- only partial position-conflict evidence.

This separation is intentional.

## 7. Next development

Next additions should prioritize cases where the source itself measures multiple positions or horizons.

Useful future pressure classes:

- commons / allocation systems with upstream-downstream measures;
- environmental externalities with present-future distribution;
- infrastructure lock-in with reversible / irreversible option loss;
- organizational systems with aggregate success but subgroup exclusion;
- technology systems with operator benefit and downstream externalized cost.

Do not add a row solely because a conflict is rhetorically plausible.
