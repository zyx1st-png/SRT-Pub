## 2. What the matrix shows

### Shared grammar without shared mechanism

X3b recurs through:

- technical compatibility;
- treaty/legal implementation;
- commons rules-in-use;
- network-policy enforcement;
- AI tool authorization.

The carriers are not equivalent.

### Recursive field feedback without biological monopoly

X4b recurs through:

- antimicrobial selective environments;
- performative ML distributions;
- road-capacity travel-cost/accessibility fields.

The source-native fields differ.

### Negative controls remain visible

The matrix explicitly includes:

~~~text
formal structure without operative coupling
environment reconstruction without paid recursive feedback
RNN imprint without specific causal re-entry
~~~

Therefore the matrix is not a positive-example catalog.

## 3. Evidence asymmetry

Rows are not equally evidenced.

Do not infer:

~~~text
same matrix row format
-> same causal certainty
~~~

Each row remains owned by its source record / audit.

## 5. Framework use

The matrix should be used to ask:

- where the same burden survives mechanism change;
- where a weaker relation is mistaken for a stronger one;
- where an expectation becomes operative;
- how a current action reconstructs a later conditioning field;
- where consequence differs by position / horizon;
- where mature target theory fully absorbs GRG.

## 6. Next expansion rule

Do not add a row merely because a case sounds similar.

A new row requires:

- source-native record;
- evidence declaration;
- admission burden;
- negative-control relation;
- mechanism-owner declaration;
- M-status or explicit pre-M status.

## 7. Canonical boundary

This matrix does not define ontology.

It is a programme comparison surface.
