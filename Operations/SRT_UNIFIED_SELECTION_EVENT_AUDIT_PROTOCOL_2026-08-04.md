# 统一选择事件审计协议 v1

> **角色说明**：本文件把 T-D 的 CG-0 至 CG-4 与四套既有操作协议压缩为一条统一事件链。它用于判定一个过程究竟停留在观察者侧差异、固定差分响应、建议输出、一般成本或记忆痕迹，还是支持具有路径效力、后果承载和历史效力的 bounded Selection-event candidate。
>
> **不是定义源 / RC-A override**：本文件不是 canonical。former P1-T05 Real Choice Moment 已由 RC-A 撤出 P1；本协议不恢复或改写它，也不把 CG/SEA 当作 Selection ontology。script / habit / gradient / `L_2` automation 与任何 CG/SEA failure 都不能推出 `no Selection`。本协议不提供统一数值阈值，也不是 agency、subjecthood、consciousness、freedom、moral responsibility、L₂ 或 generative health 的判据。
>
> **核心纪律**：五项不能相加平均。任何一项未达到最低门槛，都不能由其他项的高等级补偿；任何一项的证据若来自不同事件、不同边界或不同时间尺度，也不能拼接成“完整 bounded event candidate”。

---

## 0. 总问题与一句话判据

统一审计回答：

> 同一条可追踪事件链中，差异是否进入系统的有效作用范围，是否被内部非等价登记，是否通过可干预通道改变现实路径，是否产生落到可识别位置的边界相关后果，以及该结果是否通过因果载体重塑后续可达路径或转换成本？

只有当以下五道门在同一事件、同一组预先固定边界和相容时间尺度上闭合，才允许使用“**有界选择事件候选**”：

1. **CG-0 差异显现**：差异不只是观察者命名，而是有效进入系统可作用通道；
2. **CG-1 非等价登记**：系统内部介质因果中介相对不等价；
3. **CG-2 路径效力**：登记结果通过执行、资源或环境通道改变现实路径；
4. **CG-3 后果承载**：目标路径产生可归因、边界相关的后果并落到可识别位置；
5. **CG-4 历史效力**：结果通过可干预载体改变未来可达性、转换概率、返回成本、门槛或规则。

默认最低门槛为：

| 条件 | 最低统一门槛 | 允许结论 |
|---|---:|---|
| CG-0 | DMF-2 | 差异有效进入系统作用范围 |
| CG-1 | NER-2 | 内部非等价登记候选 |
| CG-2 | PEF-2 | 现实路径效力候选 |
| CG-3 | CBP-2 | 边界相关后果候选 |
| CG-4 | HEF-3 | 未来可达性／成本重写候选 |

这只是**审计默认门槛**，不是跨所有领域的 Selection 必要充分定理。某领域若需要更强门槛，必须在测试前说明；不得在结果出现后降低门槛。

## 1. 为什么需要统一协议

四套独立协议已经分别阻止：

- 输出差异冒充内部比较；
- 建议、投票或工具调用文本冒充现实路径改变；
- 一般耗能或外部影响冒充后果承载；
- 缓存、日志、迟滞或参数变化冒充历史写回。

但独立协议仍可能产生新的风险：

1. **事件拼接**：NER 证据来自一次实验，PEF 来自另一次执行，CBP 来自第三个尺度，HEF 来自长期环境变化，却被拼成一个事件；
2. **边界漂移**：比较时只算模型，执行时把工具纳入，承受时把用户纳入，写回时再把仓库纳入；
3. **时间尺度漂移**：瞬时登记、小时级执行、年度制度后果被直接拼接；
4. **角色洗白**：人的授权被归给 AI，AI 的建议被当作执行，外部用户损失被说成 AI 自身 stake；
5. **重复计数**：同一状态变化同时被记为 NER、PEF、CBP 和 HEF，而没有独立干预证据；
6. **高项补低项**：因为存在强历史写回，就忽略当前没有足够的差异或内部登记证据；
7. **复杂性偏见**：复杂系统只要有记忆、反馈和资源消耗，就被默认判为完整事件候选。

统一协议的主要贡献不是增加第五套术语，而是建立：

> **同一事件链、同一边界台账、逐门干预、不可补偿的最低审计门槛。**

## 2. 审计对象必须先冻结

任何统一审计开始前，必须冻结以下十二项。

### 2.1 事件单元

明确事件的开始和结束：

- 哪个差异进入时开始；
- 哪个路径结果、后果或写回完成时结束；
- 是否审计单步、一个回合、一个决策周期、一个制度程序或跨代过程；
- 哪些前史仅是背景，哪些属于事件内部。

禁止在审计失败后扩大事件窗口，把后续偶然结果纳入以补足 HEF 或 CBP。

### 2.2 系统边界

必须至少画出：

- 核心处理器／比较器；
- 传感或输入通道；
- 执行器、资源池和环境接口；
- 人类操作者、机构或平台；
- 后果承受位置；
- 历史载体与写回位置；
- 不属于系统但与其因果耦合的外部位置。

允许嵌套审计多个边界，但每个边界必须单独判定，不能把不同边界的最高等级合并。

### 2.3 候选差异

预先写明：

- 差异是什么；
- 差异是否连续、离散、未枚举或关系性；
- 哪些属性是目标差异，哪些是混杂；
- 没有差异或差异被屏蔽时的匹配基线；
- 候选是否现实可进入，还是只存在于界面、文本或观察者想象中。

### 2.4 内部登记介质

预先指认可能承担 NER 的：

- 权重；
- 阈值；
- 资源预算；
- 增益、抑制或竞争状态；
- 内部记忆；
- 授权状态；
- 当前维持压力；
- 制度权限或投票计数。

无法指认内部介质时，不得超过 NER-1。

### 2.5 路径耦合通道

预先指认：

- 执行器；
- 工具／API；
- 肌肉或行为接口；
- 资源路由；
- 预算、权限、队列或调度；
- 环境改写通道；
- 使路径继续、停止或失去资源的维持机制。

### 2.6 后果承受位置

必须分开：

- 谁授权；
- 谁执行；
- 谁受益；
- 谁承担损失、风险、义务或修复成本；
- 谁负责补偿或恢复；
- 结果写回哪里。

### 2.7 历史载体

预先指认可能承担 HEF 的：

- 持久状态；
- 参数、阈值或资源配置；
- 记忆与数据库；
- 结构损伤、习惯或制度先例；
- 仓库提交、规则文本和权限设置；
- 系统—环境闭环中的已修改结构。

### 2.8 时间尺度

至少分别说明：

- 输入与登记窗口；
- 路径执行窗口；
- 后果显现和恢复窗口；
- 历史写回与未来效力窗口；
- 自然恢复、缓存清空或状态洗脱时间。

### 2.9 匹配基线

至少选择一个最强普通解释：

- 固定映射；
- 查找表或脚本；
- 随机路由；
- 共同外部驱动；
- 单路径控制；
- 一般成本／可靠性模型；
- 缓存、疲劳或普通迟滞；
- 观察者事后分类。

### 2.10 干预集合

至少预注册：

- 差异屏蔽／交换；
- 内部介质干预；
- 执行耦合切断；
- 保护、缓冲或负担路由改变；
- 历史载体重置、迁移或替换。

### 2.11 目标结论等级

明确本次只想判定：

- 差异响应；
- 内部登记；
- 路径有效过程；
- 有界选择事件候选；
- 闭环选择结构候选。

不得先用弱实验，再在结论中升级为强事件主张。

### 2.12 非主张

每份报告必须写明不能由本审计推出：

- Selection 的 P0 定义或不存在；
- agency / subjecthood；
- consciousness / 第一人称体验；
- 不可转移 stake；
- freedom；
- moral / legal responsibility；
- L₂；
- generative health；
- SRT 相对普通理论的独立机制优势。

## 3. CG-0：差异显现的最小操作化

CG-0 不是“研究者能列出两个选项”，也不是“输入在物理上不完全相同”。它问：

> 目标差异是否越过预先固定边界，进入一个能够影响系统后续登记或候选路径的有效通道？

本文件为统一审计引入临时证据梯 `DMF`（Difference Manifestation）。它只服务于 operations 层，不是 canonical 符号。

### 3.1 DMF 五级证据梯

| 等级 | 名称 | 最低证据 | 允许表述 | 禁止升级 |
|---|---|---|---|---|
| DMF-0 | 观察者枚举差异 | 研究者能命名、区分或事后分组 | “存在描述差异” | 不得称差异进入系统 |
| DMF-1 | 边界到达差异 | 差异物理或信息上到达输入边界 | “差异到达接口” | 不得称有效显现 |
| DMF-2 | 有效通道准入 | 屏蔽、交换或改变差异会改变系统可用内部状态或候选通道 | “CG-0 操作候选” | 不得称已比较或建立事件候选 |
| DMF-3 | 活候选显现 | 差异对应多个现实可进入的继续路径或连续分岔场，而非界面标签 | “活候选场候选” | 不得称路径已重分配 |
| DMF-4 | 候选场可塑 | 历史、反馈或资源状态改变哪些差异能够成为活候选 | “候选场调制接口” | 仍需 NER、PEF、CBP、HEF |

### 3.2 DMF-0 与 DMF-1

以下只支持 DMF-0/1：

- 研究者在结果后把轨迹分成 A/B；
- 菜单显示两个按钮，但两个按钮进入同一后端；
- 两段文本不同，但系统未读取相关位置；
- 环境存在多个物理状态，但系统边界没有耦合通道；
- 输入到达传感器，却被阈值、掩码或预处理完全抹平。

### 3.3 DMF-2：CG-0 最低门槛

DMF-2 要求：

- 目标差异通过一个可定位通道进入系统；
- 在保持非目标属性近似不变时，改变、屏蔽或交换该差异，会改变至少一个可供后续登记使用的内部状态、资源通道或候选入口；
- 该改变不是测量装置、研究者标签或共同外部驱动造成；
- 系统边界在结果前已固定。

DMF-2 不要求两个清楚命名的选项，也不要求系统意识到差异。连续场中的局部偏差、未枚举的路径分岔或过程中新出现的差异均可满足。

### 3.4 DMF-3：活候选显现

若要主张存在“候选路径”而非仅输入差异，必须证明：

- 至少两个现实继续路径在目标时间点仍可进入，或存在可干预的连续分岔场；
- 替代路径具有执行、资源或维持条件；
- 候选不是研究者事后虚构；
- 屏蔽一个差异不会只是改变标签，而会改变后续可进入路径集合。

DMF-3 仍不说明系统如何比较，也不说明哪条路径获得效力。

### 3.5 DMF-4：候选场可塑

DMF-4 用于记录：

- 过去结果改变哪些差异可见；
- 资源、边界或风险状态改变候选生成；
- 环境反馈开放或封闭新的差异通道；
- 制度规则改变什么议题可以进入决策；
- AI 工具权限改变哪些行动成为现实候选。

DMF-4 只是通向 NER/HEF 的接口，不自动构成完整事件候选。

### 3.6 CG-0 核心测试

1. **差异屏蔽测试**：屏蔽目标差异后，系统可用状态是否变化；
2. **属性交换测试**：交换标签与真实属性，响应跟随哪一项；
3. **通道消融测试**：移除输入通道是否消除后续登记候选；
4. **候选可达性测试**：界面选项是否对应现实可执行路径；
5. **连续分岔探针**：不要求离散标签，直接扰动连续状态并测量可进入路径；
6. **候选场历史测试**：重置历史或权限后，哪些差异可进入是否改变。

## 4. 五门统一链

统一事件链以同一组追踪变量表示：

| 角色 | 记录符号（仅报告字段） | 问题 |
|---|---|---|
| 目标差异 | `Δ` | 什么差异进入系统？ |
| 登记介质 | `M` | 哪个内部状态非等价登记差异？ |
| 路径通道 | `A` | 登记如何进入执行、资源或环境路径？ |
| 承受位置 | `X` | 后果落到哪里？ |
| 历史载体 | `H` | 结果如何进入未来路径组织？ |

目标链为：

> `Δ → M → A → X → H → 下一轮候选／阈值／路径`

这些字母只是报告占位符，不是 SRT 新公式或 canonical 符号；该链是 **SEA audit chain**，不是每次 Selection occurrence 的必要本体链。

### 4.1 Gate 0 · 差异是否有效显现？

最低问题：

- 差异是否超过 DMF-0/1；
- 改变差异是否改变系统可用通道；
- 候选是否现实可达；
- 差异是否只存在于观察者侧。

失败时：统一结论不得超过“外部可区分过程”。

### 4.2 Gate 1 · 是否形成内部非等价登记？

调用 NER 协议：

- NER-1 只支持固定差分转导；
- NER-2 是统一审计最低 CG-1 门槛；
- NER-3 支持关系性比较；
- NER-4 只表示通往路径／历史写回的接口。

必须给出 `M` 的定向干预；只看到不同输出不得超过 NER-1。

### 4.3 Gate 2 · 登记是否改变现实路径？

调用 PEF 协议：

- PEF-0/1 只支持输出、建议、命令或咨询接口；
- PEF-2 是统一审计最低 CG-2 门槛；
- PEF-3 支持替代路径相对重分配；
- PEF-4 支持反馈依赖闭环路径组织。

必须给出 `A` 的切断、替换或资源路由干预；执行成功字符串不等于环境状态改变。

### 4.4 Gate 3 · 路径是否产生边界相关后果？

调用 CBP 协议：

- CBP-0/1 只支持外部效应或一般实现成本；
- CBP-2 是统一审计最低 CG-3 门槛；
- CBP-3 支持位置特异承受；
- CBP-4 支持选择者—执行者—受益者—承受者—修复者—写回位置链解析。

必须给出 `X` 与维持、恢复、风险或未来路径的关系；普通电力、时间和算力消耗不得直接升级。

### 4.5 Gate 4 · 结果是否获得历史效力？

调用 HEF 协议：

- HEF-0/1 只支持记录、缓存或被动持续状态；
- HEF-2 支持主动历史携带；
- HEF-3 是统一审计最低 CG-4 门槛；
- HEF-4 支持规则／边界／继承写回候选。

必须给出 `H` 的重置、迁移、替换或消融结果，并证明未来可达性、转换成本或候选结构发生变化。CG-4 的这一要求只属于本 audit，不能上提为 Selection occurrence 的必要定义。

## 5. 不可补偿原则

统一审计禁止总分制。

### 5.1 为什么不能求和

以下组合均不能成为 SEA-3 bounded Selection-event candidate：

- NER-3 + PEF-0 + CBP-1 + HEF-3；
- DMF-3 + NER-1 + PEF-4 + CBP-2 + HEF-3；
- DMF-2 + NER-2 + PEF-2 + CBP-1 + HEF-4；
- DMF-2 + NER-2 + PEF-2 + CBP-2 + HEF-2。

原因分别是：

- 有比较但没有现实路径；
- 有闭环控制但没有当前内部登记证据；
- 有长期规则变化但没有边界相关承受；
- 有后果和记忆，但未达到本协议要求的未来路径重写门槛。

### 5.2 最弱环原则

统一报告必须列出五项中的最低等级。默认判断：

> event-candidate audit strength 受最低未通过门限制，而不是由最高等级决定。

但“最弱环”不是机械取数字最小值，因为各梯含义不同。审计者必须说明哪一门阻断了哪一种 **audit conclusion**；不得把该阻断升级为 `no Selection`。

## 6. 同一事件链原则

五项证据必须通过可追踪链相连。

### 6.1 必须回答的连接问题

1. 进入系统的 `Δ` 是否正是 `M` 所登记的差异？
2. 被干预的 `M` 是否正是驱动 `A` 的介质？
3. `A` 改变的是否正是产生 `X` 后果的目标路径？
4. `X` 的结果是否通过 `H` 进入下一轮路径组织？
5. `H` 改变的未来候选是否仍属于同一边界与相关尺度？

任一连接没有证据，只能报告分段候选，不能报告完整 SEA-3 event candidate。

### 6.2 链接证据等级

| 链接 | 最低证据 |
|---|---|
| `Δ → M` | 差异干预改变内部相对登记 |
| `M → A` | 介质或耦合干预改变现实路径 |
| `A → X` | 路径干预改变边界相关后果 |
| `X → H` | 后果／结果进入可定位历史载体 |
| `H → future` | 载体干预改变未来可达性或成本 |

只证明每个变量存在，不等于证明链路成立。

## 7. 嵌套边界审计

复杂系统尤其是 AI、机构和生命系统，必须至少比较两个边界。

### 7.1 边界报告格式

| 边界 | 包含 | 排除 | 主要结论 |
|---|---|---|---|
| B₁ | 核心处理器／模型 | 人、执行器、环境 | 核心内部能证明什么 |
| B₂ | 处理器 + 执行器／工具 | 授权者、受影响者 | 技术系统能证明什么 |
| B₃ | 人机／组织—技术整体 | 更广社会与生态 | 社会技术事件能证明什么 |

不得把 B₃ 的人类授权、制度权限和仓库写回反投给 B₁ 的模型。

### 7.2 边界升级规则

扩大边界可以改变判定，但必须同时承担：

- 新边界中的内部登记证据；
- 新执行通道的因果责任；
- 新承受位置和外包链；
- 新历史载体；
- 更强的普通理论基线。

不能只在某一门失败时临时扩大边界。

### 7.3 AI 专项角色表

AI 案例至少分开：

- 模型输出生成位置；
- 系统提示、编排器和策略门；
- 人类授权位置；
- 工具执行器／API；
- 平台权限；
- 环境对象；
- 用户、维护者和受影响者；
- 持久记忆、数据库、仓库或日志。

特别禁止：

- 把人的批准称为模型自己的 agency；
- 把工具执行器的动作称为纯模型动作；
- 把用户或公共后果称为 AI 自身承受；
- 把外部数据库或仓库持久化直接称为模型获得自我连续性；
- 把平台权限和安全策略隐去后宣称 AI 自主行动。

## 8. 统一判定类别

以下类别仅用于 operations 报告，不是本体等级，也不是 Selection subtype。

### SEA-0 · 未建立有效差异

典型情况：

- 只有观察者枚举；
- 候选路径并不现实存在；
- 差异未进入系统通道；
- 边界和事件单元无法冻结。

结论：**不是可审计的 SEA event-candidate process。** 该结论不等于 `no Selection`。

### SEA-1 · 差分响应／咨询过程

至少有 DMF-2，但 NER、PEF 或后续门仍停在弱等级。

典型情况：

- 固定分类；
- 模型产生不同建议；
- 委员会形成意见但无执行；
- 工具调用文本未落地。

结论：**存在差异响应或行动接口，但未建立 SEA-3 event candidate。** 不得升级为 `no Selection`。

### SEA-2 · 路径有效过程候选

通常至少达到：

- DMF-2；
- NER-2；
- PEF-2；

但 CBP 或 HEF 未达到统一门槛。

结论：**存在内部登记并改变现实路径，但尚未建立本协议要求的完整事件后果与历史效力。**

### SEA-3 · 有界选择事件候选

默认需要：

- DMF-2；
- NER-2；
- PEF-2；
- CBP-2；
- HEF-3；
- 五段链路属于同一事件；
- 边界、尺度和角色归属一致；
- 最强普通解释未完全替代该链。

结论只能写作：

> 在边界 B、时间尺度 τ 与基线 K 下，该过程支持一个 bounded Selection-event candidate。

不得省略“有界”“候选”和适用范围。

### SEA-4 · 组织化／闭环选择结构候选

在 SEA-3 基础上，还需要较强结构证据，例如：

- DMF-3/4 的活候选场；
- NER-3 的关系性比较；
- PEF-3/4 的替代路径重分配或闭环重组；
- CBP-3/4 的位置分配或外包链；
- HEF-4 的规则／边界写回；
- 后果回流改变下一轮差异显现、登记或路径组织。

不要求所有项都达到 4，但必须存在至少一个经干预验证的跨门反馈回路。

SEA-4 仍不等于 L₂、agency、subjecthood、consciousness、freedom、moral responsibility 或 generative health。

## 9. 统一测试序列

建议按以下顺序执行，防止后项证据倒投前项。

### Phase A · 负对照与边界冻结

1. 定义事件和嵌套边界；
2. 注册候选差异与现实路径；
3. 建立无差异、固定脚本和无执行基线；
4. 画出授权、执行、承受和写回角色图。

### Phase B · CG-0 / DMF

1. 屏蔽目标差异；
2. 交换标签和真实属性；
3. 消融输入通道；
4. 检查候选路径是否现实可达；
5. 给出 DMF 等级。

### Phase C · NER

1. 指认内部介质；
2. 做介质干预／消融；
3. 检查相对响应而非全局幅度；
4. 改变候选集合或共享资源；
5. 给出 NER 等级。

### Phase D · PEF

1. 分离输出、接口接受、执行和环境完成；
2. 切断执行器／资源耦合；
3. 置换工具、执行器或路由；
4. 检查替代路径可用性；
5. 做固定策略和共同驱动基线；
6. 给出 PEF 等级。

### Phase E · CBP

1. 比较目标路径与匹配路径的后果；
2. 指认边界相关变量；
3. 做保护／缓冲干预；
4. 做负担路由或位置交换；
5. 追踪选择者、执行者、受益者、承受者、修复者和写回位置；
6. 给出 CBP 等级。

### Phase F · HEF

1. 区分日志、缓存、状态残留和主动记忆；
2. 重置、洗脱或遮蔽历史载体；
3. 做反事实重放；
4. 测量未来可达性、转换概率和返回成本；
5. 检查规则／边界是否改变；
6. 给出 HEF 等级。

### Phase G · 链接与撤回测试

1. 逐一检查 `Δ → M → A → X → H → future`；
2. 替换其中一个环节，观察后续链是否按预测断裂；
3. 比较普通模型是否已充分解释；
4. 列出最弱门和最大盲区；
5. 给出 SEA 类别；
6. 写明可击退该 audit conclusion 的新证据。

## 10. 普通理论基线

统一协议不是通过重新命名现象获得贡献。每个案例至少比较：

- 感知／信号检测理论；
- 控制论；
- 动力系统与迟滞；
- 决策或强化学习模型；
- 可靠性与风险分析；
- 成本会计与制度执行理论；
- 计算机系统中的权限、事务和状态机模型。

### 10.1 允许的 SRT 增益表述

允许：

> 统一协议提供一条跨域审计链，要求差异显现、内部登记、现实路径、后果承载和历史写回在同一事件与边界上闭合，并阻止这些现象相互替代。

### 10.2 暂不允许的表述

不允许：

> SRT 已证明存在一个普通理论无法解释的统一选择机制。

只有在统一协议产生普通模型未能预测、而跨门干预能够预测的差异后，才可讨论独立机制增益。

## 11. 常见统一假阳性

| 假阳性 | 被误判为何 | 正确处理 |
|---|---|---|
| 界面有多个按钮 | 活候选路径 | 检查后端是否不同，做 DMF-3 |
| 模型 logits 不同 | 内部比较 | 先做 NER 介质干预 |
| 模型给出工具调用 | 路径已改变 | 检查执行器、权限和环境完成 |
| API 返回 success | 环境状态已改变 | 独立读取目标环境状态 |
| 系统耗电 | 后果承载 | 至多 CBP-1 |
| 用户受损 | AI 自身 stake | 记录外部承受者，禁止角色洗白 |
| 有上下文窗口 | 历史效力 | 至多 HEF-1/2，测试未来可达性 |
| 参数更新 | HEF-3/4 | 检查路径组织是否改变 |
| 固定脚本完成动作 | SEA-3 event candidate 已建立 | 做冻结策略／替代路径测试；失败只能降级 SEA，不得推出 no Selection |
| 仓库产生 commit | 模型自我写回 | 区分模型、工具运行时、仓库和人机系统 |
| 投票形成决议 | 制度路径已改变 | 检查预算、权限和执行 |
| 长期损伤 | 目标事件历史效力 | 先证明它属于目标路径和同一事件 |
| 高复杂度闭环 | 主体性 | 主体性需要独立证据 |

## 12. 降级与失败条件

出现以下任一情况，统一 **audit conclusion** 必须降级：

1. 事件窗口在结果后扩大；
2. 系统边界在不同门之间移动而未分别报告；
3. 候选路径只存在于界面或观察者叙述；
4. DMF 只达到 0/1；
5. NER 没有内部介质干预；
6. PEF 只有输出、命令或未验证执行；
7. CBP 只有一般成本；
8. HEF 只有日志、缓存或短时残留；
9. 五项来自不同事件却被拼接；
10. 人类授权被归给 AI；
11. 工具执行被归给模型；
12. 外部承受者被说成系统自身 stake；
13. 仓库、数据库或环境写回被说成模型参数或自我连续性；
14. 同一变量变化被重复计入多个门而无独立干预；
15. 只报告成功路径，不报告现实替代路径；
16. 不控制固定脚本或共同外部驱动；
17. 不报告恢复窗口和状态清空；
18. 普通理论已充分解释，却宣称 SRT 机制独有；
19. 通过扩大“选择”“系统”“后果”或“历史”含义免疫反例；
20. SEA-3/4 被直接升级为 agency、subjecthood、consciousness、freedom、moral responsibility、L₂ 或 generative health；
21. SEA failure 或 script / habit / gradient / automation 被直接升级为 `no Selection`。

### 12.1 失败类型

- **测量修正**：边界、指标、基线或干预不足；
- **范围压力**：某领域需要更强门槛或不同时间尺度；
- **链路失败**：某两个门之间没有因果连接；
- **事件审计失败**：至少一项最低门槛无法满足；
- **机制失败**：统一链成立，但普通理论完全充分，SRT 只保留审计语言作用。

## 15. 本协议当前理论地位

当前允许的最强结论是：

> SRT 已获得一套统一、不可补偿、边界敏感的 **P2/P3 bounded Selection-event audit**，能够把差异显现、内部非等价登记、现实路径效力、后果承载和历史效力连接为同一可失败事件链。

当前仍未证明：

- 该链是自然界一切 Selection 的必要充分条件；
- 各领域存在统一数值阈值；
- SRT 比控制论、动力系统、决策理论、可靠性工程或制度理论提供了独立因果机制；
- 通过 SEA-3/4 的系统具有 agency、subjecthood、consciousness、freedom 或 moral status；
- SEA-4 自动达到 L₂；
- bounded Selection-event candidate 必然生成健康；
- SEA failure、script、habit、gradient 或 automation 意味着没有 Selection。

下一步不是继续扩张术语，而是：

1. 用明确阴性、边界和较强正候选反复执行统一协议；
2. 检查不同审计者是否获得稳定结论；
3. 比较普通理论是否已充分解释；
4. 识别哪些门具有真正增量预测；
5. 只在案例支持后考虑回写 T-D、论文或书稿。

## 16. 最终操作性结论

> **在本 P2/P3 audit surface 内，SEA-3 event candidate 不能由任何单一现象代理。差异、内部登记、路径效力、后果承载和历史写回必须在同一事件、同一边界台账和相容时间尺度上通过独立干预连接；任何缺门、边界漂移或角色洗白都必须阻止 SEA-3 主张。该操作性门槛不定义 Selection ontology，也不把 history / trace / constraint 写成每次 Selection occurrence 的必要链。**
