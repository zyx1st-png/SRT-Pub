# Book Defensive-Tone Audit · 2026-06-14

## Scope

本审计针对 `01_Source_Intuition/BOOK/Drafts_26Q/` 下的章节草稿，评估各章「答辩体」结构的浓度，并判断 PR #476（Q09 v22→v23「正面显影重排」）所确立的改法能否、以及在多大程度上向其他章节平移。

本审计**不**修改理论、**不**评判 SRT 是否正确、**不**改动 canonical 锚点、**不**直接重写章节正文。它只产出分级与改造建议，供后续逐章决策。

起因：PR #476 把 Q09 主声部从「反误读/答辩」改为「正面显影」——跨域显影提为正文主路、两个对手节压成「两条边界」、护栏归并去重。用户追问该方向是否正确、是否增强可读性、前面章节是否需要同样调整。

## 核心发现：答辩段有两类，改法不同

| | 归约型「X 不就是 Y 吗 / 你只是重新定义了词」 | 先发权型「X 早就说过了吗 / 某某学者」 |
|---|---|---|
| 功能 | 挡住把新概念塌缩成旧机制 | 给本书在学术谱系里定位 |
| Q09 处理的是 | ✅ 正是这种（因果历史/权力 → 「两条边界」） | Q09 里没有这种 |
| 能否照搬 Q09 | 能：压并、降级为「边界」、细节入注 | 慎：降到章末注＝把学术站位撤出正文 |

**结论：Q09 的成功只验证了「归约型可降级」。** 先发权型答辩（休谟/佛教/莱布尼茨/过程哲学/海德格尔/能力方法/西蒙…）几乎每章出现一次，是本书的思想定位签名。是否一并正面化，是一个**全局学术姿态决定**，应先拍板，不应逐章随手改。倾向建议：先发权型留正文（只瘦身），仅对归约型做 Q09 式降级。

## 可读性判断（基于 Q09 已改 diff）

净增强（宏观叙事层）：先遇概念、后遇争议，认知负荷下降；具体跨域实例比抽象反驳更有说服力。

两处局部回退（micro，需在后续每章盯住）：
1. §2 结尾可能提前说出 §3 的答案，削弱「揭示感」（Q14 风险最高）。
2. 合并对手节会抬高局部概念密度。

净值为正，但说明「正面化」不是免费的，会牺牲悬念张力、抬高局部密度。

## 建议执行顺序

1. 先拍全局决定：先发权型答辩留正文（瘦身）还是降为章末注。倾向：留正文。
2. 试点从 Q11 开始（同构、低风险、且能顺带检验先发权瘦身规则），稳定后再上 Tier A 的 Q14/Q16。
3. 每章盯住「§2 预支 §3」失败模式，Q14 最危险。
