# 作者裁决包：初心的 L₀／L₁ 分层

## 作者裁决记录（2026-08-12）

作者选择：**B-A — strict layering**。

当前 canonical 口径固定为：

- SRT 不承认一个独立的 L₀「初心前身」，也不把 `ε_pg` 重新命名、别名化或登记为该前身；
- `ε_pg` 只保留其既有的无内容最小非中立性角色；
- 「初心 / Shoshin」从 L₁ 开始：可作为 P2 处境化解释回读，或 P5 现象学命名；
- `argmin`、`∇F`、长时域和全局收敛公式只可作为声明适用域的 P3/P4 bridge／operational proxy，不能定义 L₀；
- 本裁决不处理 `κ_0 / ε_pg` 的依赖或独立关系；Gate C 的「全局最优」与无限时域范围后来由 C-A 独立关闭。

这是当前理论的准入裁决，不是“任何可能的形而上前身都绝不可能存在”的证明。未来若要重开，必须有新的作者裁决，并对新对象执行独立性、删去差异、准入类型和下游漂移检验。

## 1. 本次只处理的连接

```text
L₀ 的无内容结构不对称（ε_pg）
→ 有限 L₁ 位置可把其处境化显现回读为初心
```

检验目标不是证明初心内容来自 L₀，而是判断这个箭头应当被读成：恒等／定理推出、独立前身，还是处境化回读。裁决只处理这一条，不推进 Gate C、闭包边界、主体、意识或 `κ_0 / ε_pg` 依赖。

## 2. 地板构建报告

### 2.1 负担标注

| 判断句 | 标签 | 负担结论 |
|---|---|---|
| `ε_pg` 是 L₀ 的无内容最小非中立性公设 | **A** | 已有 canonical 承诺；不是 Shoshin 内容 |
| 初心是有限位置对处境化方向的解释／体验命名 | **D** | 可在 L₁/P2 与 P5 使用；依赖位置、历史、具身与解释语境；具体经验效度须另立 F 证据 |
| `ε_pg` 分析地推出 Shoshin 的语义或体验内容 | **S** | 连接未建立；两端对象类型不同 |
| 另设一个无内容 L₀「初心前身」 | **O** | 删除后没有损失：余项就是既有 `ε_pg` 加 L₁ 回读规则；不予准入 |
| `argmin ∫Fdt` 或 `-∇F` 定义初心 | **C** | 只在声明状态空间、泛函、可行域、时间域与测量映射的 P3/P4 条件模型内成立 |

### 2.2 裸句测试

删除「基础方向场」「初心盆地」「归处」等比喻后，可保留的裸句是：

> L₀ 承载 `ε_pg` 这一无内容结构不对称。一个有限 L₁ 位置可以在具体选择、历史与后果回流中，把这种不对称的显现结果解释或体验为初心。该回读不构成恒等式、定理推导或一个额外 L₀ 对象。

裸句完整，不依赖隐喻承重。

### 2.3 连接检验

从 `ε_pg` 到 Shoshin 至少还需要：

1. 一个有限且具身的位置；
2. 可比较的处境化候选与历史约束；
3. 后果回流与可支付性条件；
4. 把结构差异解释为方向的 L₁ 语义框架；
5. 若谈体验，还要有报告或现象学接口。

这些中介不是 `ε_pg` 的定义内容。因此 `ε_pg → Shoshin content` 不是分析连接，也不是当前 P0/P1 定理。

### 2.4 反例施压

1. **无主体结构**：一个系统可具有非中性的转移结构，却没有第一人称体验或「初心」解释。
2. **多重回读**：同一结构不对称在不同有限位置可被读成不同局部方向，说明语义内容不由 `ε_pg` 单独固定。
3. **同一体验、不同模型**：相近的开放／回归体验可由不同梯度、控制目标或生理机制拟合，说明单一 `∇F` 不是定义。
4. **变分不适定**：未声明测度、可行域、时间范围和目标泛函时，`argmin`／无限时域积分没有唯一对象；这同时说明 Gate C 不能被 B-A 偷渡解决。
5. **删去测试**：删掉“独立前身”后，`ε_pg` 的全部既有结构角色与 L₁ 回读均可保留，没有理论差异丢失。

### 2.5 判决

**分层边界：绿。强派生关系：红。**

```text
ε_pg [L₀, contentless]
-- situated L₁/P2 read-back --> Shoshin
```

这个箭头是解释关系，不是同一、因果起源证明、定理蕴含或新对象准入。B-A 因而比“薄前身”更诚实：后者严格执行后只剩 `ε_pg` 加一个命名许可，删除许可不损失任何结构内容，却持续制造反向定义风险。
