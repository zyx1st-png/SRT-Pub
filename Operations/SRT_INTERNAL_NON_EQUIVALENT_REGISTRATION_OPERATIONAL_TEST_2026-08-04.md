# 内部非等价登记：操作化测试协议 v1

> **RC-A active-use override（2026-08-18）**：本文中早于 RC-A 的 `Real Choice Moment / real choice / live choice` 只保留为历史或 downstream agency / revision 语汇，不再是 P1 Selection criterion。CG/SEA 最多给出 P2/P3 bounded Selection-event candidate；通过不证明 agency，失败也不得推出 `no Selection`。script / habit / gradient / `L_2` automation 本身既不证明更强 agency，也不能反推“没有 Selection”。更强 agency / consequence-sensitive revision 另走 `03_Bridges/SRT_Agency_Automation_Guard_2026-08-17.md`。

> **角色说明**：本文件把 T-B 的“比较门槛”和 T-D 的 CG-1“非等价登记”压缩为可干预、可失败、可与固定映射比较的操作协议。它不是 canonical、定义源、公理、统一指标或经验验证结论。
>
> **核心问题**：怎样区分“研究者看见了两个不同结果”，与“被研究系统内部确实对差异进行了非等价登记”？
>
> **最低结论纪律**：本协议最多支持“内部非等价登记候选”或“关系性比较登记候选”。它不能单独证明选择事件、主体性、关切、意识、自由、道德责任或生成健康。

---

## 0. 一句话判据

只有当一个预先固定边界内的内部变量、阈值、资源分配或状态结构，**因候选差异而产生相对响应不等价，并且对该内部结构的干预能够可预测地改变这种相对不等价**，才有理由从“观察到不同输出”升级为“内部非等价登记候选”。

若还要进一步使用 T-B 的“比较关系”，则必须追加：

> 对同一候选的响应会因另一候选、竞争背景、资源约束或关系结构的变化而改变，而不是每个输入分别通过互不相关的固定通道得到不同输出。

压缩为两道门：

1. **内部介入门**：差异响应必须被系统内部结构因果中介；
2. **关系依赖门**：比较主张必须显示候选之间的关系实际改变内部响应或资源配置。

---

## 1. 为什么“不同输出”远远不够

下列现象都可能表现出 A 与 B 的不同结果，却不自动构成内部比较：

- 研究者用不同标签描述同一过程；
- 两个输入经过固定传感通道产生不同输出；
- 一个硬编码阈值把连续输入切成两类；
- 软件排序器按固定权重输出不同分数；
- 两条化学路径具有不同速率常数；
- 噪声导致单次结果不同；
- 外部环境替系统完成筛选，而系统内部没有可识别登记；
- 最终输出不同，但中间状态、资源分配和后续响应完全相同。

这些现象可以证明差异、因果不对称或固定判别，却不必证明：

- 系统在当前过程中形成了比较关系；
- 内部权重或阈值实际参与了差异登记；
- 候选路径是“活的”；
- 当前发生了新的选择。

因此本协议不采用“有差异／无差异”的二元判法，而采用五级证据梯。

---

## 2. 五级证据梯

| 等级 | 名称 | 最低证据 | 允许表述 | 禁止升级 |
|---|---|---|---|---|
| NER-0 | 观察者侧差异 | 研究者能区分输入、轨迹或输出 | “外部可区分” | 不得说系统内部登记 |
| NER-1 | 固定差分转导 | 系统以稳定固定映射对 A/B 产生不同响应 | “结构上非中性／固定判别” | 不得说当前形成比较或新选择 |
| NER-2 | 内部非等价登记 | 内部权重、阈值、资源或状态因果中介相对响应；干预可改变不等价 | “CG-1 操作候选” | 不得直接说路径已选择 |
| NER-3 | 关系性比较登记 | 对 A 的内部响应依赖 B、候选集合或竞争背景；存在关系／上下文效应 | “T-B 比较候选” | 不得直接说 real choice moment |
| NER-4 | 写回接口 | 登记或比较进一步改变后续可达路径、成本、阈值或规则 | “进入 CG-2/CG-4 接口” | 仍需 CG-2、CG-3、CG-4 完整审计 |

### 2.1 NER-0 · 观察者侧差异

典型情形：

- 研究者把两个轨迹命名为 A、B；
- 两个输出在统计上不同；
- 观察尺度改变后出现分组；
- 事后根据结果把样本分成“成功／失败”。

若无法指出系统内部哪个变量对差异作出响应，结论必须停在 NER-0。

### 2.2 NER-1 · 固定差分转导

系统可能拥有固定的：

- 受体特异性；
- 速率常数；
- 传感器灵敏度；
- 硬编码阈值；
- 分类权重；
- 查找表或规则链。

它们说明系统不是完全等价响应，但还不能证明当前存在活的比较过程。

NER-1 的理论位置是：

> 它可以成为最低非中立性的**结构前提**或弱实现，却不足以单独建立 T-B 意义上的比较关系，也不足以证明当前出现新的选择候选。

### 2.3 NER-2 · 内部非等价登记

NER-2 要求相对差异被系统内部状态因果中介。可接受的内部介质包括：

- 权重；
- 阈值；
- 资源预算；
- 增益；
- 抑制强度；
- 通道占用；
- 内部记忆；
- 当前维持压力；
- 历史形成的响应状态。

关键不是内部变量“存在”，而是：

> 对该变量进行有方向的干预，会使 A 与 B 的**相对响应差**可预测地扩大、缩小、消失或反转。

若干预只改变所有响应的总体幅度，而不改变相对不等价，则不足以证明该变量承担差异加权。

### 2.4 NER-3 · 关系性比较登记

NER-3 进一步要求候选并非各自独立经过固定通道，而是彼此或通过共享资源发生关系。

典型证据：

- A 保持不变时，B 的出现、消失或强度改变会改变系统对 A 的响应；
- 候选集合改变会改变相对排序、资源分配或阈值；
- 同一输入在不同资源状态、风险状态或历史背景下获得不同相对权重；
- 抑制、竞争、机会成本或共享预算使候选关系进入系统内部动力学。

NER-3 不要求系统显式表征“选项”，也不要求意识。它只要求：

> 至少一个候选的内部登记依赖其他候选或共同约束，而不是孤立映射。

### 2.5 NER-4 · 写回接口

若 NER-2/3 的结果进一步：

- 改变后续阈值；
- 改变未来候选可达性；
- 改变资源配置；
- 改变返回成本；
- 沉积为记忆、结构或规则；

则进入 NER-4。

NER-4 只是 CG-2／CG-4 的接口证据，不自动构成选择事件。还必须检查路径效力、后果承受位置和历史效力的尺度。

## 3. 测试前必须固定的六项

任何测试开始前，必须预先写明：

1. **系统边界**：哪些部件、环境通道和反馈回路算作被测系统；
2. **候选差异**：A 与 B 在什么属性上不同，哪些属性是无关混杂；
3. **内部介质**：计划测量或干预的权重、阈值、资源、状态或通道；
4. **响应指标**：内部响应与最终输出分别测什么；
5. **相关时间尺度**：瞬时转导、当前过程、跨试次更新还是长期写回；
6. **最低判定等级**：本实验只测试 NER-1、NER-2、NER-3 还是 NER-4。

禁止在看到结果后移动系统边界，把原本的外部筛选器临时纳入“系统内部”，以挽救内部登记主张。

### 3.1 “内部”不是什么意思

“内部”不要求：

- 位于几何中心；
- 不可观察；
- 是神经表征；
- 是显式符号；
- 是有意识状态。

“内部”只要求：

> 该变量位于预先固定的系统边界内，接受候选差异的因果影响，并中介系统后续响应。

若使用扩展系统边界，必须在测试前说明环境部件如何与系统双向耦合，不能只因为结论需要就把外部设施纳入系统。

## 4. 核心测试组

### Test 1 · 匹配差异基线

目的：排除 A/B 的无关物理强度、呈现时间、数据规模或测量尺度差异。

操作：

- 匹配所有非目标属性；
- 重复测量响应分布，而不是依赖单次结果；
- 预先指定目标差异和响应指标；
- 记录效应大小和不确定性。

判定：

- 无稳定差异 → 停在 NER-0；
- 有稳定差异 → 至多进入 NER-1，继续测试内部介质。

### Test 2 · 标签／交换测试

目的：区分系统响应的真实因果属性与研究者标签。

操作：

- 在保持因果属性不变时交换外部标签、位置、显示顺序或编码名称；
- 在保持标签不变时交换真正的因果属性；
- 对软件系统，明确标签字符串本身是否进入模型输入；若进入，它就不是“纯标签”。

判定：

- 响应只跟随研究者标签，且标签未进入因果通道 → 观察者分类嫌疑；
- 响应跟随预先指定的因果属性 → 支持系统判别，但仍只到 NER-1。

### Test 3 · 内部状态交互测试

目的：判断相对响应是否由系统内部状态中介。

最小设计：

- 因素一：候选 A 与 B；
- 因素二：内部状态 1 与状态 2，例如不同阈值、资源预算、历史状态或权重配置；
- 同时测量中间内部响应和最终输出。

关键判据：

> 不只看 A 与 B 是否不同，而看 A/B 的相对差是否随内部状态改变。

若只有稳定的 A/B 主效应，而内部状态只使所有响应共同升高或降低，更接近固定差分转导。

若内部状态使 A/B 相对差可预测地扩大、缩小或反转，则支持 NER-2。

### Test 4 · 内部介质干预／消融测试

目的：从相关性升级为因果中介。

操作方式包括：

- 调整阈值；
- 钳制资源预算；
- 改变增益或抑制；
- 移除候选中介通道；
- 重置记忆或历史状态；
- 在不改变输入的情况下替换内部权重。

通过条件：

- 干预方向事先规定；
- 相对差异按预测改变；
- 中介消融后不等价显著减弱或消失；
- 替代通道和一般性能下降得到控制。

失败条件：

- 干预只造成全局损伤或总体输出下降；
- 任意内部变量变化都能事后解释结果；
- 相对差异没有稳定变化；
- 中介变量只与输出相关而没有因果作用。

Test 3 与 Test 4 共同通过，才建议标记 NER-2。

### Test 5 · 候选关系／竞争背景测试

目的：区分独立固定映射与关系性比较。

操作：

- 保持 A 完全相同；
- 改变 B 是否存在、B 的强度、候选集合大小或共享资源压力；
- 检查系统对 A 的内部响应、相对权重、阈值或资源分配是否改变；
- 控制单纯总输入量、能量叠加和感知遮挡。

通过条件：

> A 的登记因 B 或共同约束而发生可重复、可干预的相对变化。

这可以表现为竞争、侧抑制、机会成本、共享预算、相对排序或上下文依赖。

若 A 的响应始终只由 A 自身决定，B 的变化没有关系性作用，则最多是 NER-2，不足以建立 NER-3。

### Test 6 · 冻结映射／重放测试

目的：识别脚本执行和固定传递函数。

操作：

- 冻结或重置可疑内部状态；
- 对相同输入序列反复重放；
- 比较固定映射模型与状态介导模型的预测；
- 检查历史、候选集合和资源背景是否提供额外预测力。

判定：

- 固定映射即可完整复现响应，状态和关系变量没有额外增益 → NER-1；
- 状态变量提供可重复的干预预测增益 → NER-2；
- 候选关系变量进一步提供增益 → NER-3。

### Test 7 · 写回扩展测试

目的：只在需要连接 CG-2／CG-4 时使用。

操作：

- 测试本轮登记是否改变下一轮阈值、资源、候选可达性或转换成本；
- 与短暂残留、缓存、疲劳和普通迟滞作对照；
- 检查改变是否与先前差异方向相关，而非随机漂移。

通过 Test 7 可以标记 NER-4，但仍不能跳过 CG-2、CG-3、CG-4 的独立审计。

## 5. 最小决策树

### Gate A · 是否只有观察者差异？

- 无内部响应指标；
- 只比较最终输出；
- 分类规则在结果出来后才确定。

若是：**NER-0**。

### Gate B · 是否只是固定转导？

- A/B 差异稳定存在；
- 冻结状态重放即可完整解释；
- 内部状态干预不改变相对差异。

若是：**NER-1**。

### Gate C · 是否有内部因果中介？

- 内部状态与候选差异存在交互；
- 定向干预改变相对差异；
- 消融中介削弱相对不等价。

若是：**NER-2**。

### Gate D · 是否有候选关系依赖？

- A 不变时，B 或候选集合改变 A 的内部登记；
- 关系效应不是总输入量或遮挡造成；
- 共享资源／抑制／机会成本可被干预。

若是：**NER-3**。

### Gate E · 是否改变后续路径？

- 登记结果改变下一轮阈值、成本、规则或候选可达性；
- 改变超出短暂残留与普通缓存。

若是：**NER-4**，随后转入 CG-2 至 CG-4 审计。

## 6. 三个重点领域的最小模板

### 6.1 物理／化学系统

#### 候选模型类

受有限资源和内部组成约束的竞争反应／自催化网络。

可测试内部介质：

- 催化组分比例；
- 抑制产物；
- 可用资源池；
- 内部边界状态；
- 历史形成的组成差异。

关键测试：

1. 钳制资源或组成，观察两条路径的相对通量是否改变；
2. 保持路径 A 的输入不变，引入或移除路径 B，观察 A 是否出现关系性变化；
3. 与固定速率常数模型、普通分岔模型和吸引子模型比较预测。

降级规则：

- 不同反应速率本身只支持 NER-1；
- 内部组成干预改变相对响应可支持 NER-2；
- 竞争路径对彼此登记产生关系性影响可支持 NER-3；
- 即使达到 NER-3，也不得直接称为主体选择或 real choice moment。

### 6.2 生命系统

#### 候选模型类

具有识别、竞争、抑制、资源配置和记忆变化的免疫或调控网络。

可测试内部介质：

- 受体／克隆组成；
- 抑制网络；
- 资源预算；
- 当前维持压力；
- 先前暴露形成的状态。

关键测试：

1. 匹配刺激强度，比较内部响应而非只看最终表型；
2. 干预抑制或资源通道，检查相对响应是否按预测改变；
3. 保持刺激 A 不变，改变竞争刺激 B，检查 A 的内部登记是否变化；
4. 与固定受体特异性、单次阈值开关和无写回调控作反例对照。

降级规则：

- 固定受体特异性只支持 NER-1；
- 状态和资源介导支持 NER-2；
- 网络竞争／上下文效应支持 NER-3；
- 适应、记忆或 NER-4 不得自动升级为关切、意识或第一人称承受。

### 6.3 AI／技术系统

#### 候选模型类

具有持续内部状态、在线更新、有限资源预算和环境行动接口的代理系统。

可测试内部介质：

- 记忆状态；
- 策略权重；
- 风险／成本阈值；
- 计算或工具预算；
- 当前任务和历史约束。

关键测试：

1. 将输入候选保持不变，定向修改内部记忆或成本权重；
2. 检查候选相对排序、工具分配或行动概率是否按预测改变；
3. 保持候选 A 不变，改变候选 B 或预算，检查 A 的相对登记；
4. 重置状态并重放，区分固定分类、无状态采样与状态介导选择候选；
5. 与静态分类器、beam search、固定排序器和无状态语言模型调用作反例对照。

降级规则：

- 不同 logits、分数或输出概率本身只支持 NER-1；
- 内部记忆／成本干预改变相对排序可支持 NER-2；
- 候选集合或共享预算改变相对登记可支持 NER-3；
- 在线更新或环境写回可进入 NER-4；
- 所有等级都不得自动推出不可转移 stake、主体性、意识、自由或道德地位。

---

## 7. 主体与制度层的快速迁移

主体和制度层通常更容易观察到比较，但仍须防止自我报告和程序外观替代路径效力。

### 主体层

NER-2 候选证据：

- 在刺激不变时，资源、风险、承诺或关切状态改变相对权重；
- 干预注意、信息或可承受成本后，相对响应可预测变化。

NER-3 候选证据：

- 同一选项的意义因替代路径、机会成本或关系背景改变；
- 比较不是事后口头解释，而能预测行动准备和资源配置。

### 制度层

NER-2 候选证据：

- 规则、预算或权力配置实际中介方案的非等价权重；
- 改变这些内部制度变量会改变相对资源流向。

NER-3 候选证据：

- 方案 A 的制度登记因方案 B、议程结构或共享预算而改变；
- 不是单纯统计不同意见，而是制度内部产生关系性资源与路径效应。

即使 NER-3 成立，仍须独立检查参与者是否有 CG-2 路径效力，以及后果落到谁。

---

## 8. 模型比较纪律

本协议不能只靠对同一数据作更丰富的 SRT 叙述。至少应比较三类模型：

1. **固定映射基线**：响应只由当前输入决定；
2. **状态介导模型**：响应由输入与内部状态共同决定；
3. **关系比较模型**：响应还取决于其他候选、共享资源或候选集合。

最低要求：

- 在未用于拟合的数据上比较预测；
- 以干预结果而非相关拟合为主要裁决；
- 更复杂模型必须提供额外可检验预测；
- 若关系比较模型没有超出状态介导模型的预测增益，不得标记 NER-3；
- 若状态介导模型没有超出固定映射的增益，不得标记 NER-2。

### 8.1 SRT 的当前增益应怎样表述

在没有发现新可测变量前，允许的表述是：

> 本协议提供一套区分观察者差异、固定判别、内部登记、关系比较与写回接口的跨域审计阶梯。

不允许的表述是：

> SRT 已经发现普通控制论、动力学或机器学习理论无法描述的新机制。

只有当 NER-2／NER-3 指标在干预预测、错误分类率或跨情境泛化上稳定优于最强基线，才可申请更强的机制增益主张。

---

## 9. 常见假阳性

| 假阳性 | 为什么不够 | 应怎样处理 |
|---|---|---|
| 输出不同 | 可能只是固定映射或噪声 | 测内部状态并做干预 |
| 有多个候选 | 候选可能只存在于研究者枚举 | 做候选关系测试 |
| 有注意或资源变化 | 可能是全局增益变化 | 检查相对差而非总幅度 |
| 有抑制 | 抑制可以是固定回路 | 检查状态与候选关系依赖 |
| 有记忆 | 可能只是缓存或状态残留 | 另做 NER-4／CG-4 测试 |
| 有优化目标 | 目标可能完全外部指定 | 区分系统内部中介与外部评分 |
| 有概率排序 | 排序可由固定参数直接产生 | 做状态干预与竞争背景测试 |
| 有不可逆性 | 不可逆不等于比较 | 回到 NER-2/3 门槛 |
| 有耗散 | 耗能不等于内部登记 | 证明耗散变量进入相对权重机制 |
| 有自我报告 | 报告可能是事后叙事 | 检查行为、资源和中间状态预测 |

## 10. 失败与降级条件

出现以下任一情况，主张必须降级：

1. **边界后移**：在看到结果后才把外部筛选器纳入系统；
2. **指标后选**：只报告产生差异的内部变量；
3. **标签泄漏**：模型或实验装置直接读取研究者分类标签；
4. **混杂不匹配**：A/B 在强度、时长、资源或可见性上未控制；
5. **全局损伤误判**：干预降低全部响应，却被解释为差异加权消失；
6. **相关性冒充中介**：内部变量与输出相关，但干预不改变相对差异；
7. **候选虚构**：B 只存在于研究者的反事实描述中，从未进入系统作用范围；
8. **固定映射足够**：冻结状态模型已完整预测全部结果；
9. **关系模型无增益**：候选集合变量不能改善预测或干预解释；
10. **噪声冒充反转**：相对排序变化不可重复或只由随机波动产生；
11. **写回偷换**：短暂残留、缓存或疲劳被直接称为历史写回；
12. **层级偷换**：NER-2/3 被直接升级为主体、关切或意识；
13. **事件偷换**：内部登记被直接当作选择事件完成；
14. **健康偷换**：因为登记导致开放或封闭，就把健康评价塞回登记定义；
15. **普通理论足够**：协议没有提供超出最强领域模型的可区分预测，却声称独立机制增益。

### 10.1 三种修正分类

若测试失败，必须先分类：

- **修正**：测量表达有局部问题，负载主张不变；
- **压力**：需要增加独立可测的范围条件；
- **失败**：内部介入门或关系依赖门系统性无法满足，相关 T-B 强表述应撤回或降级。

不得通过不断扩大“系统内部”或降低“比较”的门槛来免疫反例。

## 11. 报告模板

每个案例至少填写：

| 字段 | 内容 |
|---|---|
| 系统边界 | 预先固定的部件、环境接口和反馈回路 |
| 候选 A/B | 目标差异与已控制混杂 |
| 内部介质 | 权重、阈值、资源、状态、记忆或通道 |
| 内部响应指标 | 不只记录最终输出 |
| Test 1/2 | 基线与标签交换结果 |
| Test 3/4 | 状态交互与中介干预结果 |
| Test 5 | 候选关系／竞争背景结果 |
| Test 6 | 固定映射重放结果 |
| Test 7 | 写回扩展结果（可选） |
| 最强基线 | 固定映射、控制模型、动力学、RL 等 |
| 判定等级 | NER-0 至 NER-4 |
| 失败条件 | 哪些条件仍未排除 |
| 非主张 | 不允许推出的主体性、选择事件或健康结论 |

推荐结论句式：

> 在预先固定的系统边界和时间尺度上，内部介质 X 的定向干预改变了 A/B 的相对响应，因此支持 NER-2；候选 B 的变化进一步改变了对 A 的登记，因此支持 NER-3。该结果尚未证明 CG-2 至 CG-4、real choice moment、主体性或意识。

## 12. 本协议对 T-B / T-D 的具体约束

### 12.1 对 T-B

今后使用“比较”时，至少要说明：

- 是 NER-1 的固定判别，还是 NER-2 的内部登记；
- 是否达到 NER-3 的候选关系依赖；
- 活的候选路径怎样进入系统；
- 比较尺度由什么内部约束生成；
- 哪个干预结果能击退观察者事后分类。

在物理、生命和 AI 层，若没有 NER-2 证据，不应把“不同响应”直接称为比较；若没有 NER-3 证据，不应使用关系性比较的强读法。

### 12.2 对 T-D

CG-1 的跨域使用应分成：

- **结构非中性前提**：NER-1；
- **操作性内部登记候选**：NER-2；
- **比较关系候选**：NER-3。

这样可避免两个相反错误：

1. 把任何固定受体或阈值都升级为当前选择；
2. 把比较限定为必须有意识、语言或显式表征。

CG-1 仍不是选择事件的充分条件。只有进入 CG-2、CG-3、CG-4，才可继续讨论路径效力、后果承载和历史效力。
