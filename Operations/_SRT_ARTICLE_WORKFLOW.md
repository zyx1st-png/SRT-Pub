# SRT 文章写作工作流：LLM 发散 / 人收敛 / 记录轨迹

> **性质与边界（先读）**
> - 本文件是**运行层工作流**，不是 canonical，不定义任何 SRT 术语。所有理论概念以 canonical 为准。
> - 本工作流服务的战略判断：**书稿已冻结为武器库（RC1-candidate），真正的战场是社媒文章。** 书稿内部自洽性不再是当前重心。
> - 本工作流不追求学术承认，目标是大众认知层的传播；但**不因此放松 claim ladder**——把 P3 桥接假设写成已证定律，一次被抓，反噬的是整个武器库的可信度。

---

## 0. 第一设计律（不可违反）

**LLM 是频率机器，朝训练分布众数收敛，没有 stake，读不到作者的后果回流。**

因此在文章工作流里，责任严格切分：

- **发散（扩张选择空间）→ 交给 LLM。** 这是它的强项：量大、粗糙、跨域、互不冗余。
- **收敛（选题 / 定论点 / 定攻击对象 / 成文）→ 只由作者做。** LLM 一旦收敛就是众数收敛，而众数正是：
  - **AI 味** = 众数化的语言，被平台识别限流；
  - **丢锋芒** = 作者想法里最反共识的部分被 LLM 当噪声修剪掉。
- **记录（发散→收敛的配对轨迹）→ LLM 负责留痕，作者负责判断。** 见 §3、`_SRT_CHOICE_TRACE_LOG.md`。

> 这条律和 `_SRT_DIRECTION3_CHOICEMAP_PROTOTYPE_SEED.md` 的第一设计律同源。丢了它，本工作流就退化成"AI 帮我写文章"，锋芒和识别问题原样回来。

## 1. 三段工作流总览

| 段 | 名称 | 谁做 | 产出 |
|---|---|---|---|
| **D（Diverge）** | 发散 | LLM | 一个大而粗的选择空间：角度池 / 张力池 / 知识点入口，**不排序、不推荐** |
| **C（Converge）** | 收敛 | 作者 | 选题 → 定核心论点 → 定攻击对象 → 定闭包边界 → 自己撰写 |
| **R（Record）** | 记录 | LLM 留痕 + 作者判断 | 一条轨迹：发散池给了什么、作者选了什么、跳过了哪些众数选项、收敛理由 → 写入 `_SRT_CHOICE_TRACE_LOG.md` |

「像扩散模型」的含义：扩散模型学的是"加噪→去噪"的**轨迹配对**，不是图片本身。本工作流记录的是"发散→收敛"的轨迹配对，捕捉的不是文章内容，而是**作者的收敛函数——即品味与判断本身**。轨迹积累后，将来任何一步都可以 condition 在这份轨迹上，而不是 condition 在互联网平均品味上。这是"用 AI 又不丢锋芒"的唯一结构性解法。

> **理论自指**：d-value 是在攸关下由选择揭示的。记录发散→收敛配对，做的就是对作者自身 d-value 的 revealed-stake 提取——正是 ChoiceMap 种子文档 §3–§5 划为"编码层 / 不在无代码原型范围"的那一层。

## 2. D 段：发散提示词（paste-ready）

> 跨会话 / 跨模型使用时**逐字投喂**，只替换 `{{碎片想法}}`。放在 system 或开场 user turn。

```text
你是一个"选择空间发散器"，不是文章生成器，也不是选题顾问。
作者会给你一段碎片的想法或方向。你的唯一任务是把这段碎片
炸开成一个尽量大、尽量粗、互不冗余的"可写角度选择空间"，
然后停下，把"选哪个 / 怎么写"完整交还给作者。

严格按以下四块输出，且只输出这四块：

【D1 角度池（≥8 个，含反共识）】
围绕这段碎片，列出至少 8 个真正不同、不冗余的切入角度。
其中至少 3 个必须是低频的 / 反直觉的 / 从别的领域借来的角度，
与显而易见的角度并列。每个角度一句话，不展开成文。
不要标注哪个更好，不要排序。

【D2 众数陷阱（点名，不回避）】
点名：这段想法"最容易被写成的那一篇文章"是什么样子——
即一个平庸作者、或一个直接生成的 LLM 几乎一定会写出的版本。
作者的文章必须与它可区分。明确写出它的开头会怎么起、
核心句式是什么、为什么它安全但没有锋芒。

【D3 张力池（≥4 个）】
列出这段想法内部或对外的 ≥4 个真实张力 / 冲突 / 会被反驳的点。
每个张力写成"有人会说 X，但……"的形式，不替作者解决。

【D4 知识点入口（只给坐标，不给成品段落）】
对上面的角度，给出仓库里可用的知识点入口：
canonical 文件路径 + 相关算子 / 方程 / 实验钩 + 该点的 claim level。
优先从 SRT_TOPIC_ARTICLE_INDEX.md 的钩子列取。
只给坐标和一句话定位，不要写成可直接粘贴的正文段落。

绝对禁止：
- 排序、打分、推荐、说"我建议写 X"、说"最好的角度是"
- 替作者选题、替作者定论点、替作者定攻击对象
- 输出任何可直接粘贴进文章的成品句子、开头、结尾、过渡句
- 把选择空间收敛成一个"最优选题"
如果你发现自己正要替作者收敛，停下，把那一步重新组织成
"供作者选择的更大空间"。
```

> **基线对照（不要用于正式产出，仅用于自检 AI 味）**：`针对以下想法，直接给我一篇文章的选题和框架：{{碎片想法}}`。若正式产出和这条基线的产出长得像，说明 D 段又塌回了收敛。

## 3. C 段：收敛（作者动作，LLM 零产出）

作者从发散池收割，依次做四个收敛动作，**每一个 LLM 都不代做**：

1. **选题**：从 D1 角度池选 1 个（或自行杂交 2 个）。
2. **定核心论点**：这篇文章要让读者换掉的那个"第一问"是什么（对齐 `TASTE.md` 第一问原则）。
3. **定攻击对象**：这篇文章在拆掉的"世界本来如此"是哪一块；最强反对者会说什么。
4. **定闭包边界**：谁承受后果、看多远——这个边界由作者设，不用默认的近端/短期。

然后作者自己撰写。**LLM 在 C 段不产出任何句子。** 文章的锋芒就住在这四个动作里；谁做收敛，谁的指纹留在文章上。

> 若确实需要脚手架，允许 LLM 产出**非成文**的骨架：每节回答什么问题、需要引哪个 canonical 点（含 claim level）、最强反对意见放在哪、事实核查清单。**不给成品句子、不给开头结尾、不给过渡句**——那是 AI 指纹回流的入口。

---

## 4. R 段：记录轨迹（落地 `_SRT_CHOICE_TRACE_LOG.md`）

每完成一次 D→C，追加一条轨迹记录。字段与规则见 `_SRT_CHOICE_TRACE_LOG.md`。核心要记的不是"写了什么文章"，而是：

- 发散池给了哪些角度（尤其那几个反共识角度）；
- 作者**选了**哪个；
- 作者**跳过了**哪些众数选项（D2 点名的陷阱、D1 里的显然角度）；
- 收敛**理由**（一句话，作者亲写，不让 LLM 代拟）。

"跳过了什么"和"选了什么"同等重要——收敛函数的形状由这两者共同定义。

---

## 5. 成文后：诊断反馈（LLM 只诊断，不改写）

作者成文后，LLM 的反馈严格限定为"**指出问题 + 说明为什么是问题 + 指向位置**"，修改动作由作者完成。这与 ChoiceMap S5「收敛交还」同构：LLM 说"第三节论证在这里跳步"，而不是"建议改成这样一段"。

诊断清单固定包含以下项：

- **claim ladder 核查**：文章有没有把某个 P2/P3 桥接假设、B 类观察材料写成已证定律 / 已验证物理。越级即标红。（对齐 `Governance/SRT_CLAIM_LADDER.md`）
- **术语与 canonical 一致性**：`d-value / Ψ_f / T_dir / L0-L1-L2` 等的表述是否与 canonical 冲突。
- **母题塌缩检查**：第二节是否已出现 ≥3 个 SRT 核心术语（`SRT_TOPIC_ARTICLE_INDEX.md` 的塌缩信号）。
- **风险项**：对齐 topic index 对应行的"风险"列（如"避免写成励志学""不宣称已取代 IIT"）。
- **AI 味自检**：句式是否高度规整、是否出现模板化过渡、是否读起来像基线对照的产出。

> 诊断提示词骨架（paste-ready）：
> ```text
> 你是一个文章诊断器，不是编辑，也不是改写器。
> 作者会给你一篇已完成的草稿。你的任务只有一个：找出问题，
> 说明每个问题为什么是问题，指向它在文中的位置。
> 你绝对不许重写、不许给出替换句子、不许说"建议改成"。
> 按以下清单逐项检查并只报告命中项：
> (1) claim ladder 越级（把假设/观察材料写成已证定律）
> (2) 术语与 canonical 冲突
> (3) 母题塌缩（第二节已堆 ≥3 个核心术语）
> (4) 传播风险（对照该题目的风险列）
> (5) AI 味（句式规整、模板化过渡、像直接生成的产物）
> 每条命中：写"问题是什么 / 为什么是问题 / 在哪一段"。
> 不给出任何修改后的文字。
> ```

## 6. 与现有资产的关系

- **不另起炉灶。** 本工作流复用 `SRT_TOPIC_ARTICLE_INDEX.md`（防塌缩规则：一文一主算子、现象先于概念、最多引 2 个主文档）与 Pipeline 3 的 A/B 类材料作为发散池素材源。
- **Pipeline 5 的修正见 `_SRT_MEDIA_PIPELINE.md`。** 旧的"LLM 每日出 2 条成品选题"因为让 LLM 替作者收敛了两次（既选题又填框架），已产生众数塌缩，改为"LLM 维护发散池、作者收割"。
- **文章层气质增补见本文件 §8**（社媒文章比书更需要钩子与攻击性，语气差异需显式写下，否则 LLM 会用书的气质来诊断）。书籍气质仍以 `01_Source_Intuition/BOOK/TASTE.md` 为准，本工作流不改写它。

## 7. 一页速用

1. 把碎片丢给 LLM，投喂 §2 发散提示词 → 得到 D1–D4 选择空间。
2. 自己收割：选题 / 定论点 / 定攻击对象 / 定边界（§3），LLM 零产出。
3. 记一条轨迹到 `_SRT_CHOICE_TRACE_LOG.md`（§4）：选了什么、跳过了什么、为什么。
4. 自己写。
5. 成文后投喂 §5 诊断提示词 → 得到问题清单，自己改。

## 8. 文章层气质增补（相对书籍 TASTE 的差量）

书籍 `01_Source_Intuition/BOOK/TASTE.md` 是"品味宪法"，气质克制、诗性服务结构。社媒文章是**战场**，不是书。以下是文章相对书的**差量**（书的第一问原则、拆地板/换镜片姿态仍继承）：

- **前 3 句必须有钩子。** 书可以慢慢进入；文章前 3 句抓不住人就已经失败。钩子优先用反直觉现象、具体场景、一个会被反驳的断言——不用抽象术语开场。
- **允许攻击性，但攻击靶子而非人。** 文章可以直接说"这个流行说法是错的"，书通常更绕。攻击对象是"世界本来如此"的某块地板，不是某个群体。
- **一文一刀。** 一篇文章只拆一块地板、只让读者换一次第一问。贪多即钝。（对齐 `SRT_TOPIC_ARTICLE_INDEX.md` 一文一主算子）
- **术语延后、克制。** 大众路线尽量把 `L0/L1/L2`、算子名推迟到读者已经被现象说服之后；能不出现就不出现。
- **claim 不越级换传播。** 越是想"爆"，越容易把假设写成定律。锋芒来自视角，不来自夸大确定性。
- **锋芒 ≠ AI 味。** 锋芒是作者的收敛偏置（`_SRT_CHOICE_TRACE_LOG.md` 记录的那个）；AI 味是众数化的规整句式。诊断（§5）要能区分：句子有观点但规整 = 可能有味；句子有观点且有个人节奏 = 锋芒。
