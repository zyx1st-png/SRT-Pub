# SRT 文章写作工作流：LLM 发散 / 人收敛 / 记录轨迹

> **性质与边界（先读）**
> - 本文件是**运行层工作流**，不是 canonical，不定义任何 SRT 术语。所有理论概念以 canonical 为准。
> - 本工作流服务的战略判断：**书稿已冻结为武器库（RC1-candidate），真正的战场是社媒文章。** 书稿内部自洽性不再是当前重心。
> - 本工作流不追求学术承认，目标是大众认知层的传播；但**不因此放松 claim ladder**——把 P3 桥接假设写成已证定律，一次被抓，反噬的是整个武器库的可信度。

> **v2 变更（2026-07-03，由一次完整 dogfeed 回写）**：v1 的发散是**一次性平铺**（角度池/知识点入口），实测中退化成"搬运仓库内容"，且直接跳到写作手法层。v2 修正六处：①发散改为**分层递归**，层序锁死 `思路结构 → 理论内容 → 写作手法`（手法最后）；②发散**前**新增「命题锻造」闸——先把主张锻死再生成结构；③理论内容层强制 canonical 核对（防幻觉）；④新增「一文一刀：折入 vs 另开」决策；⑤明确「校准稿」例外；⑥轨迹台账记录**被剪枝的分支与事后讨还**。

---

## 0. 第一设计律（不可违反）

**LLM 在默认成文任务中容易向高频表达、稳妥结构和平均判断收敛；它没有 stake，读不到作者的后果回流。**

因此在文章工作流里，责任严格切分：

- **发散（扩张选择空间）→ 交给 LLM。** 强项：量大、粗糙、跨域、互不冗余。
- **收敛（锻命题 / 选结构 / 定论点 / 定攻击对象 / 成文）→ 只由作者做。** LLM 一旦收敛就倾向众数收敛，而众数化正是：
  - **AI 味** = 众数化的语言，更容易被读者识别为模板文、带来低停留 / 低互动，以及平台分发上的风险；
  - **丢锋芒** = 作者想法里最反共识的部分被 LLM 当噪声修剪掉。
- **记录（发散→收敛的配对轨迹）→ LLM 负责留痕，作者负责判断。** 见 §7、`_SRT_CHOICE_TRACE_LOG.md`。

> 这条律和 `90_Backstage/Incubation/_SRT_DIRECTION3_CHOICEMAP_PROTOTYPE_SEED.md` 的第一设计律同源。丢了它，本工作流就退化成"AI 帮我写文章"，锋芒和识别问题原样回来。

## 1. 总览：一个锻造闸 + 分层降落 + 记录

| 步 | 名称 | 谁做 | 产出 |
|---|---|---|---|
| **0** | **命题锻造**（§2） | 作者主导，LLM 当压力测试器 | 一个被最强反对者压过、锻死的核心主张 |
| **D** | **分层递归发散**（§3–§4） | LLM 逐层给离散选项 | 决策树：层1 结构 → 层2 理论 → 层3 手法，每层坍缩后条件化下一层 |
| **C** | **收敛**（§5） | 作者 | 每层选一个；定论点/攻击对象/闭包边界；自己撰写 |
| **R** | **记录**（§7） | LLM 留痕 + 作者判断 | 一条轨迹：树给了什么、选了什么、**剪掉了什么**、为什么 |
| — | **诊断**（§8） | LLM 只报问题 | 成文后的问题清单，作者自己改 |

「像扩散模型」的含义：扩散模型学的是"加噪→去噪"的**轨迹配对**，不是图片本身。本工作流记录的是"发散→收敛"的轨迹配对，捕捉的不是文章内容，而是**作者的收敛函数——即品味与判断本身**。轨迹积累后，将来任何一步都可以 condition 在这份轨迹上，而不是 condition 在互联网平均品味上。这是"用 AI 又不丢锋芒"的唯一结构性解法。

> **理论自指**：d-value 是在攸关下由选择揭示的。记录发散→收敛配对，做的就是对作者自身 d-value 的 revealed-stake 提取——正是 ChoiceMap 种子文档 §3–§5 划为"编码层 / 不在无代码原型范围"的那一层。

## 2. 步 0 · 命题锻造（发散**之前**的闸）

> **实测教训**：跳过这一步直接选结构，等于在裂缝上盖楼。作者一句"先评审思路，别按错误方向推进选择"，就是在补这个闸。**命题没锻死，选哪个结构都白搭。**

作者先给出一个还没锻死的核心主张（哪怕一句话）。LLM 当**压力测试器**，把会塌的地方找出来、每处收敛成"作者必须先拍板的一个决定"，然后停。作者拍板，主张锻死，才进 §3。

**命题锻造 prompt（paste-ready）：**

```text
你是一个命题压力测试器，不是拥护者，也不是共同作者。
作者会给你一个还没锻死的核心主张。你的任务不是帮他论证，
而是像最强反对者一样，把这个主张会塌的地方找出来，
每一处都收敛成"作者必须先拍板的一个决定"。
按以下逐条检查，只报命中：
(1) 它是"不是X而是Y"的对撞，还是"不只是X"的增补？
    （对撞极易被懂行的人一句话打穿；先逼作者选定这一点）
(2) 核心概念是不是只给某个常识换了名（循环/同义反复）？
    多出来的增量，一句话能说清吗？说不清=没有硬核。
(3) 招牌证据能不能被对手的现成框架直接吸收？
    （能吸收 = 没证倒任何人，只是重新描述）
(4) 命题内部有没有两个方向被焊在一句里而没分清？
    （歧义若在命题正中心，会被后面每一层放大）
(5) 读者到底是谁？这决定 (1)-(4) 哪些是生死线、哪些可忽略。
每条命中：写"问题 / 为什么致命 / 作者要拍板的那个决定是什么"。
不替作者拍板，不给结论，不夸奖，不安慰。
```

作者对命中项逐条拍板 → LLM 把答复收敛成一段**锻死命题**（含：主张一句话、它**不主张**什么/边界、承重的几根柱、目标读者）回给作者确认。确认后锁定。

## 3. 步 D · 分层递归发散（层序不可颠倒）

> **实测教训（两处）**：v1 让 LLM 一次性平铺"角度池 + 知识点入口"，结果是**把仓库内容搬出来**，没有选择价值；而且直接从**写作手法**（侦探/家谱…）起手。作者纠正：要的是**结构性框架的选择**，而且层序是——

**层序律（硬性）：**

1. **层1 · 思路的结构性框架** —— 论证如何运动（归谬到残差 / 发生学建构 / 分层揭示 / 缺口驱动 / 不变量抽取 …）。**先定这个。**
2. **层2 · 理论内容** —— 在选定结构下，调用哪些 SRT 机件、多深、每件 claim level（见 §4）。
3. **层3 · 写作手法** —— 侦探 / 慢镜头 / 思想实验 / 直陈 …。**最后才轮到。手法是戏服，能套在任何结构上。**

**绝不从层3 起手。** 手法先行，正是 v1 一头扎进侦探故事、绕了几轮才发现地基搭错的原因。

**递归协议：** 每一层给 3–4 个**离散、互斥、边界清楚**的选项（是结构性承诺，**不是仓库摘抄**）；给完即停，等作者收敛；作者选定后，**只生成与该选择相容的下一层**，把不相容分支明确划掉。逐层坍缩，直到骨架闭合。

**分层递归发散 prompt（paste-ready）：**

```text
你是一个"分层选择空间生成器"，不是文章生成器，也不是资料搬运工。
命题已由作者锻死（见命题锻造步）。你的任务是把"怎么把这个命题写成文章"
炸开成一个可逐层坍缩的决策树：每一层给一组离散、互斥、边界清楚的选项，
作者选一个，你用他的选择条件化下一层，直到骨架闭合。

层序（不可颠倒）：
  层1 = 思路的结构性框架（论证如何运动）
  层2 = 理论内容（调用哪些 SRT 机件、多深、每件 claim level）
  层3 = 写作手法（侦探/慢镜头/思想实验/直陈…）
绝不从层3（手法）起手。手法是最后一层。

每一层：
- 给 3–4 个真正互斥、边界清楚的选项。每个是一个结构性承诺，
  不是"仓库里有什么"的摘抄；选项由仓库内容 + 世界知识合成。
- 每个选项标：核心动作 / 说服力从哪来 / 下游代价。
- 给完就停，等作者选。不排序、不推荐
  （可中性陈述兼容性、代价这类结构事实）。
- 作者选定后，只生成与该选择相容的下一层选项，
  明确划掉因此死掉的分支。

严禁：从手法层起手；把"检索结果"当选项摆出来（那是搬运，不是发散）；
排序/推荐/替作者选；一次把多层塞给作者。
进入层2（理论内容）时，每引一个 SRT 机件必须核对 canonical；
拿不准就标 NEEDS_RETRIEVAL，绝不编造文件路径 / 方程 / claim level。
```

> **自检**：若某一层的"选项"其实是"仓库里关于 X 的几段话"，你在搬运不在发散。真选项之间必须互斥、且各自把下一层导向不同的文章。

## 4. 层2 展开 · 理论内容与防幻觉

层2 是"调用哪些理论机件"。**实测教训**：这一层最容易编造 canonical 坐标，也最藏红利——本轮正是在这层核对时，发现 `d ≡ ‖∂U/∂S‖`（对不可逆风险的敏感度）把"要紧"和"撤不回"两个缺口**焊成了一个**，命题因此变硬。

规则：

- **先核对，再落笔。** 每引一个机件（算子 / 方程 / 实验钩 / claim），核对 canonical 源；拿不准标 `NEEDS_RETRIEVAL`，作者或 LLM 检索后再用。**宁可少给，不许编造。**
- **标 claim level。** P0/P1 定理、P2/P3 桥接假设、B 类观察材料、domain/companion 展开——各是什么级别，写清。文章里不得越级（见 §8 诊断）。
- **公式不裸抛。** 面向半技术读者时，canonical 公式最多进脚注；正文用白话读法（如 d → "对不可逆风险的敏感度 / 攸关"）。它是理论定义，不是实测量。
- **给懂行读者的"雷"要提前拆。** 若命题会碰到读者熟悉的成熟结果（如朗道尔原理之于"信息不可撤回"），在这一层就查好 canonical 的处理方式并标好 claim 红线（"定位它，不是驳倒它"）。

## 5. 步 C · 收敛（作者动作，LLM 零成文产出）

每一层的选择都是作者的收敛动作，LLM 不代做。骨架闭合后，作者还需定：

1. **核心论点**：要让读者换掉的那个"第一问"（对齐 `TASTE.md` 第一问原则）。
2. **攻击对象**：拆掉的"世界本来如此"是哪一块；最强反对者会说什么。
3. **闭包边界**：谁承受后果、看多远——由作者设，不用默认的近端/短期。

然后作者自己撰写。**LLM 在 C 段零成文产出——不产出任何可直接进入文章的句子。**

**允许的非成文脚手架**：每节回答什么问题、引哪个 canonical 点（含 claim level）、最强反对意见放在哪、事实核查清单。**不给成品句子、开头、结尾、过渡句**——那是 AI 指纹回流的入口。

> **校准稿例外（明确）**：作者可显式要求 LLM "写一篇我看感觉"。此时 LLM **可以**写整篇，但：(a) 这是**知情地越过**零成文律，只为校准方向；(b) 产出**一次性、可抛**，标注"校准稿，非成品"；(c) 真正要发的那篇由作者**亲手重写**，不得直接拿校准稿发布。校准稿是探针，不是产品；它的价值在于让作者说出"差在哪"，而不是省掉撰写。

## 6. 一文一刀：折入 vs 另开（新增·实测教训）

写作途中常冒出**真的、更完整**的新东西（本轮：作者发现"信息只讲了收敛，缺发散那一半"）。**完整是锋利的敌人。** 别在一篇里同时买锋利和完整。收到新substance时，作者二选一：

- **折入（克制版）**：只把能让**这一刀更利**的那点补进来，砍掉被它撑大的暗假设，守住单一刀锋与既定 claim 边界。（本轮：信息仍=选择的锚点，但砍掉"锚定只会变窄"，承认锚点能关也能开。）
- **另开（最大版）**：新东西其实是**另一篇、甚至更大的重写**，spin off 成新种子，别塞进当前文。（本轮：信息=发散·选择·收敛整条弧，是重写"信息"的种子，单独开。）

判据一句：**当前这一刀会因为它更利，还是会因为它散？** 更利→折入；会散→另开。

## 7. 步 R · 记录轨迹（落地 `_SRT_CHOICE_TRACE_LOG.md`）

每完成一次锻造→分层降落，追加一条轨迹。字段与规则见台账文件。核心记的不是"写了什么文章"，而是收敛函数的形状：

- 每一层的选项全集（尤其反共识/被划掉的分支）；
- 作者在每层**选了**哪个；
- 作者**剪掉了**哪些（含为了"一文一刀"而 park 的洞）；
- 收敛**理由**（一句话，作者亲写，不让 LLM 代拟）。

> **v2 新增·剪枝与讨还**：本轮作者先为锋利剪掉洞1/2/5，随后判断力**讨还**了其中一个（发散半边）。这种"先砍到一把刀、再回来讨还完整性"的模式，是收敛函数最强的信号之一，必须记（台账 `skipped_mode` + `note`：标出被剪的、以及是否被事后讨还）。

"剪掉了什么/后来又要回什么"和"选了什么"同等重要。

## 8. 成文后：诊断反馈（LLM 只诊断，不改写）

作者成文后，LLM 的反馈严格限定为"**指出问题 + 说明为什么是问题 + 指向位置**"，修改动作由作者完成。这与 ChoiceMap S5「收敛交还」同构：LLM 说"第三节论证在这里跳步"，而不是"建议改成这样一段"。

诊断清单固定包含：

- **claim ladder 核查**：有没有把 P2/P3 桥接假设、B 类观察材料写成已证定律 / 已验证物理。越级即标红。（对齐 `Governance/SRT_CLAIM_LADDER.md`）
- **术语与 canonical 一致性**：`d-value / Ψ_f / T_dir / L0-L1-L2` 等表述是否与 canonical 冲突。
- **懂行读者的雷**：碰到成熟结果（朗道尔、香农、IIT…）时，是否守住"定位它、不驳倒它"的 claim 红线。
- **母题塌缩检查**：某节是否已堆 ≥3 个 SRT 核心术语（`SRT_TOPIC_ARTICLE_INDEX.md` 塌缩信号）。
- **风险项**：对齐 topic index 对应行的"风险"列（如"避免写成励志学""不宣称已取代 IIT"）。
- **AI 味自检**：句式是否高度规整、模板化过渡、读起来像"直接生成的产物"。

> 诊断提示词骨架（paste-ready）：
> ```text
> 你是一个文章诊断器，不是编辑，也不是改写器。
> 作者给你一篇已完成的草稿。你的任务只有一个：找出问题，
> 说明每个问题为什么是问题，指向它在文中的位置。
> 你绝对不许重写、不许给替换句子、不许说"建议改成"。
> 逐项检查并只报命中：
> (1) claim ladder 越级（把假设/观察材料写成已证定律）
> (2) 术语与 canonical 冲突
> (3) 懂行读者的雷（把成熟结果写成被驳倒，而非被定位）
> (4) 母题塌缩（某节已堆 ≥3 个核心术语）
> (5) 传播风险（对照该题目的风险列）
> (6) AI 味（句式规整、模板化过渡、像直接生成的产物）
> 每条命中：写"问题是什么 / 为什么是问题 / 在哪一段"。
> 不给出任何修改后的文字。
> ```

## 10. 一页速用

1. **锻命题**：把还没定的主张丢给 LLM，投喂 §2 压力测试 prompt → 逐条拍板 → LLM 收敛成锻死命题，你确认。
2. **分层降落**：投喂 §3 分层发散 prompt。按 `层1 结构 → 层2 理论 → 层3 手法` 逐层选；每层 LLM 给离散互斥选项、你选一个、它条件化下一层。层2 核对 canonical（§4）。
3. **收敛成骨架**：定论点/攻击对象/闭包边界（§5）。需要就要非成文脚手架；需要"看感觉"就要一份标注"校准稿"的可抛样稿。
4. **途中冒出新东西**：用 §6 判"折入还是另开"，别让文章变散。
5. **自己写。**
6. **诊断**：成文后投喂 §8 诊断 prompt → 问题清单，自己改。
7. **记轨迹**：§7，把每层选了什么/剪了什么/为什么，写进 `_SRT_CHOICE_TRACE_LOG.md`。

## 11. 文章层气质增补（相对书籍 TASTE 的差量）

书籍 `01_Source_Intuition/BOOK/TASTE.md` 是"品味宪法"，气质克制、诗性服务结构。社媒文章是**战场**，不是书。以下是文章相对书的**差量**（书的第一问原则、拆地板/换镜片姿态仍继承）：

- **前 3 句必须有钩子。** 书可以慢慢进入；文章前 3 句抓不住人就已失败。钩子优先用反直觉现象、具体场景、一个会被反驳的断言——不用抽象术语开场。
- **允许攻击性，但攻击靶子而非人。** 攻击对象是"世界本来如此"的某块地板，不是某个群体。
- **一文一刀。** 一篇只拆一块地板、只让读者换一次第一问。贪多即钝。（对齐 §6 与 `SRT_TOPIC_ARTICLE_INDEX.md` 一文一主算子）
- **术语延后、克制。** 尽量把 `L0/L1/L2`、算子名、公式推迟到读者已被现象说服之后；能不出现就不出现。
- **claim 不越级换传播。** 越想"爆"，越容易把假设写成定律。锋芒来自视角，不来自夸大确定性。
- **锋芒 ≠ AI 味。** 锋芒是作者的收敛偏置（`_SRT_CHOICE_TRACE_LOG.md` 记录的那个）；AI 味是众数化的规整句式。诊断（§8）要能区分：有观点但规整 = 可能有味；有观点且有个人节奏 = 锋芒。
