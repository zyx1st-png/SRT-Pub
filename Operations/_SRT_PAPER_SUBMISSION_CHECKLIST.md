### Hard gate before any new submission

- [ ] 核验当前状态：accepted / production / proof / DOI / online publication；
- [ ] 取得原期刊可保存的撤回或终止出版确认；
- [ ] 核验版权、许可和重复投稿边界；
- [ ] 在上述三项完成前，不向其他期刊提交。

### Transfer preparation

- [ ] 选择一个主目标期刊和至少一个备选期刊；
- [ ] 优先评估无需高额 APC、允许订阅出版或具有现实减免路径的期刊；
- [ ] 核对 article type、scope、字数、图表、参考文献、匿名、数据与伦理声明；
- [ ] 生成新期刊专用 cover letter，不沿用 Frontiers portal wording；
- [ ] 完成新投稿包的一致性检查；
- [ ] 新投稿后记录稿号与真实阶段。

### Status wording guard

- 未核验公开出版和 DOI 前，不写作 `published` 或 `in press`；
- 因费用终止原路径不等于学术拒稿；
- 原路径未终止前，不得同时投稿。

## Global publication hygiene

- [ ] 每篇稿件只有一个真实 current status；
- [ ] 私有邮件、账单、个人信息和 portal 链接不进入公开仓库；
- [ ] 仓库中的 cover letter、submission fields、状态页和主稿互相一致；
- [ ] 任何转投均先终止原期刊流程；
- [ ] 任何外审、接受、proof、DOI 或出版变化都同步到 `STATUS.md` 和相应 Issue；
- [ ] 材料融合不自动授权论文正文改写。
