# SRT 投稿与出版流程检查清单

> 当前事实状态只看 `STATUS.md` 与 `Operations/SRT_WORKLINE_AUTHOR_PRIORITIES_2026-08-05.md`。本文件只列操作门、核验动作和完成条件。

## Lane A — Frontiers 原出版路径终止与转投

- 稿件：`papers/ontological_friction/paper_ontological_friction_frontiers_submission.md`
- 执行卡：Issue #740

### 原路径终止硬门

- [ ] 核验 accepted / production / proof / DOI / online publication 的真实状态；
- [ ] 取得可保存的撤回或终止出版确认；
- [ ] 核验版权、许可和重复投稿边界；
- [ ] 上述三项完成前，不向其他期刊提交。

### 新投稿准备

- [ ] 选择一个主目标期刊和至少一个备选；
- [ ] 核验订阅出版、APC、减免、scope、article type、字数与匿名规则；
- [ ] 按新期刊生成 cover letter、metadata 和格式包；
- [ ] 做主稿／图表／补充材料／声明的一致性检查；
- [ ] 新投稿后记录稿号和真实阶段。

### 措辞护栏

- 未核验 DOI 或公开出版前，不写 `published` / `in press`；
- 因费用终止路径不写成学术拒稿；
- 原路径未终止前不重复投稿。

## Global publication hygiene

- [ ] 每篇稿件只有一个状态源；
- [ ] 私有邮件、账单、个人信息和 portal 链接不进入公开仓库；
- [ ] cover letter、submission fields、主稿和公开状态互相一致；
- [ ] 任何转投先终止原期刊流程；
- [ ] 外审、接受、proof、DOI 或出版变化同步 `STATUS.md` 与相应 Issue；
- [ ] 材料融合不自动授权论文正文改写。
