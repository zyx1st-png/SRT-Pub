# CG-2 路径效力：操作化测试协议 v1

> **角色说明**：本文件把 T-D 的 CG-2“非等价差异能够形成路径效力”压缩为可预注册、可解耦、可替换、可干预、可失败的操作协议。它不是 canonical、选择事件定义、自由意志判据、统一控制理论或经验验证结论。
>
> **核心问题**：怎样区分“系统产生了不同分数、标签、建议、排序或输出”，与“该差异真正进入资源、动作、边界或环境通道，使现实路径的发生概率、持续条件、替代路径状态或返回成本发生改变”？
>
> **最低结论纪律**：本协议最多支持“路径耦合候选”“CG-2 路径效力候选”“替代路径排除／稳定候选”或“闭环路径组织候选”。这些结论都不能单独证明完整选择事件、后果承载、历史写回、主体性、意识、自由、责任或生成健康。

---

## 0. 一句话判据

只有当内部非等价登记、比较结果或控制信号通过一个可定位、可干预的执行／资源／环境通道，**可重复地改变至少一条现实路径的发生概率、资源占用、持续条件、进入门槛或替代路径可用性**，才有理由从“不同输出／建议”升级为“CG-2 路径效力候选”。

若还要主张较强的“选择性再组织”，必须追加：

> 对耦合通道、资源路由、执行器或替代路径的干预，能够可预测地削弱、消除、反转或转移路径差异；并且差异不能由固定脚本、共同外部驱动或事后观察者分类充分解释。

压缩为四道门：

1. **耦合门**：登记或比较结果必须进入现实执行、资源或环境通道，而不是停留在显示、日志或建议层；
2. **反事实效力门**：改变或切断该通道会改变实际路径，而不只是改变内部分数；
3. **替代路径门**：若主张选择性再组织，必须说明其他路径如何被压低、延迟、排除、保留或提高成本；
4. **当前过程门**：必须排除完全由固定脚本、预设单一路径或共同外部驱动造成的表面方向性。

## 1. 为什么“输出不同”“做了动作”仍然不够

下列现象都可能表现出方向、排序或动作，却不自动满足 CG-2：

- 分类器输出 A 而不是 B；
- 模型 logits、置信度或 reward 分数不同；
- 推荐系统把一个项目排在前面；
- 会议完成表决，但预算、权限和执行安排未改变；
- 系统打印命令或调用接口，但执行器被禁用；
- 工具调用返回成功字符串，但环境状态没有改变；
- 程序按预先固定脚本依次执行步骤；
- 单一路径反射或机械联锁产生稳定输出；
- 外部操作者查看建议后自行行动，但系统内部没有执行耦合；
- 资源分配发生变化，但与候选差异无关；
- 观察者事后把一条已经发生的轨迹称为“被选择路径”；
- 一个局部变量变化，但系统实际转移、行动或环境结果不变；
- 多个候选只存在于界面或文本中，现实上始终只有一条可执行通道；
- 行为不同完全由输入强度、位置、时序或隐藏控制器决定。

这些现象可以证明：

- 系统具有不同输出；
- 存在表示、分类、建议或控制信号；
- 某个执行动作被触发；
- 过程具有方向性；

但不必证明：

- 比较结果真正改变了现实路径；
- 替代路径曾经是活的并被重新组织；
- 当前过程发生了新的路径选择；
- 后果落到了承受位置；
- 结果获得了历史效力；
- 系统具有主体性、意识或自由。

因此本协议采用五级证据梯，而不是“有动作／无动作”的二元判法。

## 2. 五级证据梯

| 等级 | 名称 | 最低证据 | 允许表述 | 禁止升级 |
|---|---|---|---|---|
| PEF-0 | 表征／观察差异 | 标签、分数、排序、建议或观察轨迹不同 | “存在输出差异／方向表征” | 不得称路径效力 |
| PEF-1 | 指令或咨询接口 | 输出可被读取、传递或显示，但现实执行依赖未解析的外部位置 | “存在行动建议／控制信号” | 不得称 CG-2 已成立 |
| PEF-2 | 因果路径耦合 | 信号通过可干预执行器、资源路由或环境接口改变实际转移、动作概率或资源配置 | “CG-2 路径效力候选” | 不得自动称选择事件 |
| PEF-3 | 替代路径重分配 | 至少一条路径被稳定／实现，其他路径的可用性、概率、延迟、资源或进入成本相对改变 | “选择性路径再组织候选” | 不得推出后果承载或历史写回 |
| PEF-4 | 闭环路径组织 | 系统在反馈与扰动下持续使用比较结果重配路径，而非一次性输出或固定脚本 | “闭环路径组织候选” | 不得自动推出主体性、自由或生成健康 |

### 2.1 PEF-0 · 表征／观察差异

典型情形：

- 分类标签不同；
- 分数、排名、概率或可视化不同；
- 研究者识别到不同轨迹；
- 系统内部记录了“推荐 A”；
- 制度文件写入一个决议名称。

若删除、交换或遮蔽该输出不改变任何执行、资源或环境路径，结论必须停在 PEF-0。

### 2.2 PEF-1 · 指令或咨询接口

典型情形：

- 系统生成操作建议，由人决定是否执行；
- 控制器发出指令，但执行器状态未知；
- 委员会形成意见，但没有预算或授权；
- 模型选择工具名称，但工具层可能拒绝、模拟或不执行；
- 规划器输出路线，但行动系统不读取规划结果。

PEF-1 比纯表征多出一个潜在行动接口，但路径效力仍可能全部位于外部主体或未建模执行器中。

要升级到 PEF-2，必须证明：

- 信号与执行／资源通道之间存在可识别耦合；
- 干预信号或耦合通道会改变实际路径；
- 变化不是共同外部驱动造成。

### 2.3 PEF-2 · 因果路径耦合

PEF-2 要求内部登记、比较或控制结果通过一个因果通道进入现实路径。

可接受的通道包括：

- 执行器、肌肉、运动控制或行为接口；
- 反应通量、催化资源或边界通道；
- 预算、权限、席位、人员或时间配置；
- 工具调用、数据库写入、交易接口或环境 API；
- 抑制、门控、路由、队列或调度机制；
- 共享资源池与竞争分配；
- 使某条路径能够继续或停止的维持机制。

关键不是通道“存在”，而是：

> 对信号、耦合、执行器或资源路由进行定向干预，会使实际路径的发生、持续或资源占用按预注册方向改变。

若干预只改变分数或显示，而实际行动、资源和环境转移不变，则仍是 PEF-0/1。

### 2.4 PEF-3 · 替代路径重分配

PEF-3 进一步要求路径效力具有相对性，而不只是触发某个孤立动作。

至少应识别：

- 哪条路径获得实现、稳定、持续或资源；
- 哪些路径被压低、延迟、排除或失去资源；
- 候选集合或共享约束改变时，路径分配如何变化；
- 返回、切换或重新进入其他路径的成本是否变化；
- 替代路径是真实可执行的，还是只存在于研究者描述中。

PEF-3 的关键证据是：

> 在保持主要输入和总体资源近似可比时，改变比较结果、资源路由或候选关系，会重分配现实路径，而不是只改变最终标签。

### 2.5 PEF-4 · 闭环路径组织

PEF-4 要求路径效力进入系统—环境闭环：

- 执行结果被系统读取；
- 环境反馈改变下一步路径分配；
- 系统在扰动、失败或资源变化下重新组织路径；
- 不是一次性的命令—动作链；
- 不是完全冻结策略对不同输入的固定映射；
- 路径组织对耦合和反馈干预表现出可预测依赖。

PEF-4 可以是复杂选择过程的强接口，但仍不能替代 CG-3 和 CG-4：

- 闭环控制可能没有可识别后果承受位置；
- 闭环适应可能只存在短时状态依赖；
- 稳定控制不等于 real choice moment；
- 高性能闭环不等于主体性或生成健康。

## 3. 测试前必须固定的九项

任何 CG-2 测试开始前，必须预先写明：

1. **被测边界**：比较器、控制器、执行器、资源池、环境接口分别是否属于系统；
2. **候选路径**：至少哪些现实转移、动作或资源配置被视为候选；
3. **登记／信号变量**：哪个内部状态、排序、阈值、投票或控制信号被认为驱动路径；
4. **执行／资源通道**：信号如何进入动作、资源、边界或环境；
5. **路径指标**：发生概率、通量、资源占用、持续时间、延迟、进入成本或替代路径状态测什么；
6. **匹配基线**：与固定脚本、随机路由、共同外部驱动、无信号或冻结策略中的哪一个比较；
7. **替代路径真实性**：候选路径在测试时是否可进入、可执行并具有资源条件；
8. **时间尺度**：单步执行、一个回合、反馈周期还是长期运行；
9. **最低判定等级**：本测试只测试 PEF-1、PEF-2、PEF-3 还是 PEF-4。

禁止在看到结果后移动边界：

- 系统建议没有被执行时，把人类操作者临时纳入系统；
- AI 工具调用失败时，把接口返回字符串当作环境改变；
- 制度决议没有落地时，把未来可能执行的部门算入当前路径；
- 只有一条物理通道时，事后虚构未进入系统的替代路径；
- 当外部控制器决定实际行动时，把功劳归于内部分类器。

### 3.1 “现实路径”不是什么意思

“现实路径”不要求：

- 宏观可见动作；
- 有意识决定；
- 永久不可逆；
- 显式选项菜单；
- 价值或偏好表征；
- 人类级行动能力。

它只要求：

> 在预先固定的尺度上，系统的状态转移、资源流、动作执行、边界通量或环境关系真正因该比较／控制结果而改变。

### 3.2 层级与接口纪律

同一过程可以包含：

- 表征层；
- 控制层；
- 执行层；
- 资源层；
- 环境层；
- 后果层；
- 写回层。

必须逐层报告：

- 信号在哪里产生；
- 路径在哪里改变；
- 耦合在哪里可能中断；
- 后果落到哪里；
- 历史写回发生在哪里。

不得因为上层界面显示“已选择”，就跳过下层执行验证；也不得因为底层执行器动作，就自动声称上层主体作出了选择。

## 4. 核心测试组

### Test 1 · 输出—路径分离基线

目的：确认研究者测量的是实际路径，而不是输出标签或内部分数。

操作：

- 同时记录内部输出和外部路径指标；
- 比较输出变化但执行通道冻结的条件；
- 比较执行变化但输出显示保持不变的条件；
- 预先指定何种状态转移算作路径发生；
- 报告输出—路径一致率以及不一致案例。

判定：

- 只有输出差异 → PEF-0；
- 输出可传递但路径未验证 → PEF-1；
- 输出变化稳定预测并因果改变路径 → 继续 PEF-2 测试。

### Test 2 · 标签／建议交换测试

目的：排除研究者标签、界面顺序或建议文本本身造成的误判。

操作：

- 在保持内部因果信号不变时交换显示标签；
- 在保持显示不变时交换真正控制信号；
- 对 AI 系统，说明文本字符串是否真的进入工具或环境接口；
- 对制度系统，区分决议名称与法律／预算效果；
- 对物理系统，区分测量标记与实际控制变量。

若路径只跟随真实控制变量而不跟随观察者标签，支持进一步测试；若路径只在研究者分类中不同，则停在 PEF-0。

### Test 3 · 耦合解断测试

目的：证明内部登记／控制结果通过特定通道改变路径。

操作：

- 切断比较器与执行器之间的连接；
- 将真实控制信号替换为常数、噪声或随机路由；
- 保持内部输出正常产生；
- 检查实际路径差异是否消失、减弱或随机化；
- 控制切断操作造成的一般系统损伤。

通过条件：

- 内部输出仍存在；
- 耦合切断后路径差异显著下降；
- 恢复耦合后路径差异恢复；
- 不是整个系统停止运行导致的假阳性。

这是 PEF-2 的核心测试之一。

### Test 4 · 执行器／资源路由干预

目的：定位路径效力的现实实现位置。

操作方式包括：

- 替换、屏蔽或强化执行器；
- 调整预算、资源池、带宽、队列优先级或权限；
- 改变门控、抑制或路由参数；
- 在不改变比较信号的情况下交换资源分配；
- 对工具系统分别验证调用、执行和环境提交。

通过条件：

- 路径结果按执行器或资源干预方向改变；
- 内部输出可以保持相近；
- 能区分“决定信号”与“实现能力”；
- 路径效力不是由未观测外部位置独立完成。

### Test 5 · 反事实路径替换

目的：证明目标路径不是唯一物理通道或固定脚本的必然结果。

操作：

- 提供功能可比的替代路径；
- 保持任务目标和主要输入尽量匹配；
- 改变比较结果或资源路由；
- 检查系统是否实际转入不同路径；
- 测量替代路径进入、持续和退出条件。

若替代路径从未具备执行条件，就不能用其缺席证明排除效力。

### Test 6 · 替代路径排除／稳定测试

目的：从“触发某动作”升级为“重分配候选路径”。

操作：

- 同时追踪被实现路径和至少一个替代路径；
- 测量概率、通量、资源、延迟、门槛与返回成本；
- 改变共享资源或候选集合；
- 测试目标路径增强是否对应替代路径减弱；
- 区分真实排除与测量不到、暂未采样或界面隐藏。

通过条件：

> 比较／控制信号不只提高目标路径输出，还通过资源、门控或执行机制改变其他路径的现实可用性或相对进入条件。

这支持 PEF-3。

### Test 7 · 固定脚本／冻结策略重放

目的：区分当前路径重组与既定程序执行。

操作：

- 冻结权重、规则、状态和候选集合；
- 重放相同输入与扰动序列；
- 比较固定脚本模型、状态控制模型和候选关系模型；
- 检查路径结果是否完全由预设查找表解释；
- 检查当前比较信号是否提供额外干预预测力。

判定：

- 固定脚本完整解释全部路径 → 至多 PEF-1，或仅说明既往选择的执行痕迹；
- 当前内部状态与比较信号因果改变路径 → 支持 PEF-2；
- 候选关系和资源竞争进一步改变路径分布 → 支持 PEF-3。

固定策略可以执行真实动作，但“动作真实”与“当前发生新选择”必须分开。

### Test 8 · 共同外部驱动控制

目的：排除内部信号与路径只是共同受第三变量驱动。

操作：

- 测量可能同时驱动输出和路径的外部变量；
- 在外部驱动保持不变时干预内部信号；
- 在内部信号保持不变时干预外部驱动；
- 使用时间顺序、负对照和中介分析；
- 检查隐藏控制器、人工审批或后台规则。

若内部输出不具有独立因果效力，结论应降至 PEF-0/1。

### Test 9 · 闭环反馈与扰动测试

目的：判断路径效力是否进入持续的系统—环境组织。

操作：

- 对执行结果施加失败、延迟、噪声或资源扰动；
- 检查系统是否读取结果并重配路径；
- 切断反馈通道；
- 比较开环脚本与闭环控制模型；
- 检查反馈是否只改变总活动量，还是改变相对路径组织。

通过条件：

- 反馈切断后路径重组能力下降；
- 恢复反馈后能力恢复；
- 系统能在候选或资源改变时调整路径；
- 变化不能由固定输入—输出函数充分解释。

这支持 PEF-4，但不自动支持 CG-3 或 CG-4。

### Test 10 · 环境提交与完成性测试

目的：防止“命令已发出”被误作“现实路径已实现”。

对技术／制度系统尤其需要区分：

1. 输出生成；
2. 指令发送；
3. 接口接受；
4. 执行开始；
5. 环境状态改变；
6. 结果被确认；
7. 失败补偿或回滚。

允许的结论必须与实际完成层级一致：

- 只到 1 → PEF-0；
- 到 2/3 → PEF-1；
- 到 4/5 且因果耦合成立 → PEF-2；
- 同时重配替代路径 → PEF-3；
- 按反馈持续重组 → PEF-4。

### Test 11 · CBP 接口测试

目的：明确路径效力与后果承载的分工。

PEF-2/3 建立后，必须另行询问：

- 路径改变是否产生边界相关后果；
- 后果落到哪个位置；
- 是否只是无关环境变化；
- 是否存在外包或转移；
- 是否满足 CBP-2 以上。

有路径效力但无已识别后果承载，仍不能建立完整选择事件。

### Test 12 · HEF 接口测试

目的：明确当前路径效力与历史写回的分工。

PEF-2/3 建立后，必须另行询问：

- 结果是否只在当前回合有效；
- 是否改变后续可达性、转换概率或返回成本；
- 历史载体能否定位和干预；
- 是否达到 HEF-3 以上。

当前动作真实发生，不等于结果已经获得历史效力。

## 5. 最小决策树

### Gate A · 是否只有表征差异？

- 只记录标签、分数、概率、建议或投票；
- 没有实际路径指标；
- 删除输出不改变任何执行或资源状态。

若是：**PEF-0**。

### Gate B · 是否只有咨询／指令接口？

- 输出可能被读取；
- 实际执行位置未纳入或未验证；
- 人类、后台规则或外部控制器可以独立决定路径。

若是：**PEF-1**。

### Gate C · 是否存在因果路径耦合？

- 信号进入可识别执行器、资源或环境通道；
- 耦合切断使实际路径差异消失或减弱；
- 共同外部驱动得到控制；
- 环境状态或资源配置真实改变。

若是：**PEF-2，CG-2 操作候选**。

### Gate D · 是否重分配了替代路径？

- 不只目标路径增强；
- 替代路径的概率、资源、延迟、门槛、可用性或返回成本相对改变；
- 替代路径在测试时真实可进入；
- 路由干预可反转或转移路径分配。

若是：**PEF-3**。

### Gate E · 是否形成闭环路径组织？

- 系统读取执行结果；
- 在扰动和资源变化下重新组织路径；
- 反馈切断会削弱该能力；
- 固定脚本不能完整解释。

若是：**PEF-4**。

无论达到哪一级，都必须继续独立审计 CG-3 与 CG-4；路径效力不能独自建立 real choice moment。

## 6. 五域最小模板

### 6.1 物理／化学系统

#### 候选路径

- 竞争反应通量；
- 边界通道；
- 自催化路线；
- 资源池分配；
- 局部结构的形成与维持路径。

可测试通道：

- 催化、抑制和门控变量；
- 资源浓度与流量；
- 边界通透性；
- 竞争反应的共享底物；
- 反馈产物。

关键测试：

1. 区分研究者测得不同速率与内部信号对通量的因果控制；
2. 切断或替换耦合变量，观察路径通量是否改变；
3. 提供真实竞争路径，检查资源是否被重分配；
4. 与固定速率常数、单一吸引子和共同外部驱动比较；
5. 不把任何分岔或不可逆反应直接称为新选择。

降级规则：

- 不同反应结果只到 PEF-0；
- 固定通道输出可到 PEF-1；
- 可干预内部耦合改变通量可到 PEF-2；
- 竞争资源使替代路径重分配可到 PEF-3；
- 即使 PEF-4 成立，也不得推出生命、主体或意识。

### 6.2 生命系统

#### 候选路径

- 代谢路线；
- 免疫反应与克隆资源；
- 细胞命运或修复路线；
- 行为动作与资源配置；
- 组织层的维持和补偿路径。

关键测试：

1. 匹配刺激强度，区分固定受体转导与路径重组；
2. 干预抑制、增益、资源或执行通道；
3. 同时追踪目标路径和替代路径；
4. 检查行为或资源变化是否真实完成；
5. 与反射、固定程序、一般稳态控制和发育脚本比较。

降级规则：

- 固定反射可产生真实动作，但不自动证明当前新选择；
- 内部状态改变执行概率可支持 PEF-2；
- 候选竞争和资源重配可支持 PEF-3；
- 闭环适应可支持 PEF-4；
- 所有等级都不能单独推出第一人称关切或意识。

### 6.3 主体／行动系统

#### 候选路径

- 可实际执行的行动；
- 资源与时间配置；
- 承诺、退出和修复路线；
- 信息搜索与工具使用；
- 社会互动中的回应路径。

关键测试：

1. 区分口头偏好、自我报告与实际行动；
2. 检查行动能力、资源和外部许可；
3. 观察比较结果是否改变行为准备和执行；
4. 区分强制、操纵、脚本化顺从与真实路径效力；
5. 不把结果不健康或不可逆反推为“没有真实动作”。

主体层可以有独立的体验、意图和理由证据，但这些证据不能替代实际路径效力测试。

### 6.4 社会／制度系统

#### 候选路径

- 法案、政策、预算和项目；
- 人员、席位和权限分配；
- 组织流程、采购和执行路线；
- 申诉、退出和补偿通道；
- 影响不同群体的制度路径。

关键测试：

1. 区分咨询、表决、决议、授权、预算、执行与环境落地；
2. 检查决议是否真正改变资源和权限；
3. 追踪被采纳路径和被排除路径；
4. 检查幕后审批、行政阻断和象征性程序；
5. 区分组织总体路径与参与者个人路径效力；
6. 另行使用 CBP 追踪谁承担后果。

降级规则：

- 意见征集或投票结果只到 PEF-0/1；
- 预算与权限因果改变执行可到 PEF-2；
- 替代方案失去资源或进入门槛提高可到 PEF-3；
- 制度按反馈持续重配可到 PEF-4；
- 路径效力不自动等于公平、合法或生成健康。

### 6.5 AI／技术系统

#### 必须分开的层级

- logits、分数和文本输出；
- 规划器与工具选择；
- 调用协议与权限；
- 工具实际执行；
- 环境提交与确认；
- 用户、平台或外部系统的后续行动。

关键测试：

1. logits、排序或 beam search 本身通常只到 PEF-0；
2. 生成工具调用文本但未执行通常只到 PEF-1；
3. 工具调用真实改变数据库、文件、设备或环境，可测试 PEF-2；
4. 资源预算、候选集合或工具竞争改变实际路径分配，可测试 PEF-3；
5. 代理读取执行结果并在扰动下重规划，可测试 PEF-4；
6. 人类最终决定是否执行时，必须区分 AI 咨询效力与人类行动效力；
7. 用户受损、平台收益或硬件负担必须转入 CBP，不得说成 AI 自身 stake；
8. 记忆、参数更新或日志必须转入 HEF，不得仅凭持续状态声称历史写回。

所有等级都不得自动推出 AI 主体性、意识、自由、道德地位或不可转移 stake。

## 7. 与相邻概念的分工

### 7.1 路径效力不等于内部比较

NER-2/3 回答系统内部是否形成非等价登记或关系性比较；PEF-2/3 回答这种登记是否进入现实路径。

可能出现：

- NER 成立但 PEF 不成立：系统完成分类或比较，却没有执行通道；
- PEF 成立但 NER 不成立：固定脚本或外部控制直接驱动动作；
- 二者都成立：比较结果真实改变路径，但仍需 CG-3/4。

### 7.2 路径效力不等于后果承载

PEF 识别路径改变，CBP 识别后果落点。

- 工具调用可以真实执行但没有重要边界后果；
- 物理通量可以改变但只有背景耗散；
- 制度路径可以落地但代价全部外包；
- 行动真实发生但尚未识别承受位置。

因此 PEF-2/3 不能替代 CBP-2/3。

### 7.3 路径效力不等于历史写回

真实动作可以只在当前回合有效。HEF-3 还要求结果改变后续可达性、转换概率、返回成本或规则。

- 一次工具调用 ≠ 长期记忆；
- 一次预算执行 ≠ 制度先例；
- 一次反应通量 ≠ L₂ 写回；
- 一次行为选择 ≠ 身份或习惯硬化。

### 7.4 路径效力不等于自由

PEF 只检验现实路径是否被内部比较／控制结果改变。自由还可能涉及：

- 强制与操纵；
- 信息和能力；
- 反事实控制；
- 主体性与理由；
- 可退出性和责任。

固定策略也可以具有路径效力；路径效力本身不判定自由。

### 7.5 路径效力不等于生成健康

一条路径可以被真实实现，同时：

- 压低未来选择空间；
- 外包严重成本；
- 形成自我封闭；
- 缺乏修复和退出；
- 对其他承受者构成压迫。

生成健康必须在事件识别后独立评价。

## 8. 模型比较纪律

本协议不能只靠更丰富的 SRT 叙述。至少比较四类模型：

1. **表征模型**：只预测标签、分数、建议或投票；
2. **固定执行模型**：输出通过固定脚本触发动作；
3. **因果耦合模型**：内部信号与执行／资源变量共同预测实际路径；
4. **关系路径模型**：候选集合、共享资源、反馈和替代路径状态进一步解释路径重分配。

最低要求：

- 使用未用于拟合的新输入、干预或环境扰动；
- 以耦合解断、执行器替换和路径替换为主要裁决；
- 复杂模型必须提供额外可检验预测；
- 若因果耦合模型无额外预测增益，不得标记 PEF-2；
- 若替代路径变量无额外增益，不得标记 PEF-3；
- 若闭环反馈无额外增益，不得标记 PEF-4；
- 不得以模型拟合优度代替现实路径干预。

### 8.1 SRT 当前允许的增益表述

允许：

> 本协议提供一套区分表征差异、咨询接口、因果路径耦合、替代路径重分配和闭环路径组织的跨域审计阶梯。

不允许：

> SRT 已经证明任何动作或控制过程都属于选择，或已经发现普通控制论、决策理论和强化学习无法描述的统一路径机制。

只有当 PEF 指标对实际路径、错误分类、干预结果或跨情境泛化提供稳定增益，才可申请更强机制主张。

## 9. 常见假阳性

| 假阳性 | 为什么不够 | 应怎样处理 |
|---|---|---|
| 分类输出不同 | 可能只在表征层 | 同时测实际路径并做耦合解断 |
| logits 或概率不同 | 不证明环境动作 | 验证执行器与环境提交 |
| 推荐被展示 | 用户可能完全不采纳 | 区分咨询效力与执行效力 |
| 工具调用字符串 | 可能未执行或被模拟 | 做完成性测试 |
| 有动作 | 可能是固定反射或脚本 | 做冻结策略和替代路径测试 |
| 有资源变化 | 可能由共同外部驱动 | 做内部信号独立干预 |
| 有投票 | 预算和权限可能不变 | 追踪授权、资源与执行 |
| 有路径依赖 | 可能属于 HEF 而非当前 PEF | 分开当前执行与历史写回 |
| 有抑制 | 可能是固定回路 | 检查当前比较与候选关系依赖 |
| 有多条界面选项 | 现实可能只有一条可执行路径 | 预注册替代路径真实性 |
| 目标路径增强 | 不证明其他路径被重组 | 同时追踪替代路径 |
| 反馈存在 | 反馈可能只调节总增益 | 检查相对路径分配 |
| 人类按建议行动 | 行动效力可能属于人类 | 明确系统边界和控制权 |
| AI 改变文件 | 不证明 AI 有 stake | 转入 CBP 与主体性审计 |
| 行动持续重复 | 不证明历史写回 | 转入 HEF 测试 |

## 10. 失败与降级条件

出现以下任一情况，主张必须降级：

1. **边界后移**：结果出现后才把操作者、执行器或环境纳入系统；
2. **输出偷换**：只记录标签、概率或建议，却声称路径改变；
3. **接口偷换**：命令发送或 API 接受被写成执行完成；
4. **环境未变**：工具或动作没有改变预注册环境状态；
5. **耦合不可定位**：无法指出信号进入执行／资源通道的位置；
6. **解断无效**：切断耦合后路径差异仍完整存在；
7. **共同驱动**：输出和路径都由第三变量造成；
8. **全局损伤误判**：执行器干预只是让整个系统停止；
9. **替代路径虚构**：其他候选只存在于研究者叙述或界面；
10. **固定脚本足够**：查找表或预设程序完整解释路径；
11. **既往选择偷换**：过去固化的规则执行被称为当前新选择；
12. **单路径泛化**：唯一通道的自动运行被写成比较性再组织；
13. **局部输出泛化**：局部变量变化未进入系统级路径；
14. **目标路径单报**：只报告目标增强，不追踪替代路径；
15. **总量混杂**：候选效应其实来自输入量或资源总量变化；
16. **反馈假阳性**：反馈只改变总活动而不改变路径组织；
17. **人机归属偷换**：人类决定和执行被归为 AI 路径效力；
18. **制度象征偷换**：决议文本或咨询程序被当作预算／权力落地；
19. **事件偷换**：PEF-2/3 被直接称为 real choice moment；
20. **后果偷换**：路径改变被直接等同 CBP 后果承载；
21. **历史偷换**：重复动作被直接等同 HEF 历史写回；
22. **主体性偷换**：闭环控制被直接升级为意识、自由或道德地位；
23. **健康偷换**：高效执行被直接判为生成健康；
24. **普通理论足够**：协议没有超出控制、因果中介、组织执行或 RL 模型的可区分预测，却声称独立机制增益。

### 10.1 三种修正分类

若测试失败，必须分类：

- **修正**：路径指标、边界、执行确认或基线存在局部缺陷；
- **压力**：需要增加候选真实性、共同驱动、层级接口或反馈范围条件；
- **失败**：内部信号无法因果改变现实路径，相关 CG-2 强表述必须撤回或降级。

不得通过把任何输出、动作、控制或环境变化都定义为“路径效力”来免疫反例。

## 11. 标准报告模板

每个案例至少填写：

| 字段 | 内容 |
|---|---|
| 系统边界 | 比较器、控制器、执行器、资源池和环境接口 |
| 候选路径 | 真实可执行的转移、动作或配置 |
| 登记／信号变量 | 驱动路径的内部状态或结果 |
| 执行／资源通道 | 信号如何进入现实路径 |
| 路径指标 | 概率、通量、资源、延迟、门槛、持续或环境状态 |
| 匹配基线 | 表征、固定脚本、随机路由、共同驱动或冻结策略 |
| 替代路径真实性 | 进入条件、资源和可执行性 |
| Test 1/2 | 输出分离与标签交换 |
| Test 3/4 | 耦合解断与执行／资源干预 |
| Test 5/6 | 反事实替换与替代路径重分配 |
| Test 7/8 | 固定脚本与共同外部驱动控制 |
| Test 9/10 | 闭环反馈与环境完成性 |
| CBP 接口 | 后果是否达到 CBP-2 以上 |
| HEF 接口 | 历史效力是否达到 HEF-3 以上 |
| 最强基线 | 控制、执行、组织、决策、RL 或动力学模型 |
| 判定等级 | PEF-0 至 PEF-4 |
| 未排除混杂 | 外部操作者、隐藏控制器、脚本、总量或接口失败 |
| 非主张 | 不允许推出的事件、主体性、自由、责任或健康结论 |

推荐结论句式：

> 在预先固定的系统边界上，内部信号 X 通过执行／资源通道 M 改变了现实路径 A 的发生概率；切断 M 后路径差异消失，恢复 M 后差异恢复，因此支持 PEF-2。候选 B 的可用性、资源和进入延迟也随路由干预发生相对变化，因此支持 PEF-3。该结果尚未证明 CBP-2、HEF-3、real choice moment、主体性、自由或生成健康。

## 12. 本协议对 T-D 与相邻协议的具体约束

### 12.1 对 T-D CG-2

今后使用“路径效力”时，至少要说明：

- 是 PEF-0 的输出差异、PEF-1 的咨询接口，还是 PEF-2 的现实路径耦合；
- 信号如何进入执行、资源或环境通道；
- 哪个耦合解断或执行器干预证明因果效力；
- 哪些替代路径在测试时真实可进入；
- 目标路径增强是否伴随替代路径重分配；
- 固定脚本和共同外部驱动如何被排除；
- 实际完成停在哪个层级。

CG-2 的最低操作候选是 PEF-2，而不是 PEF-0 或 PEF-1。较强的选择性再组织主张至少需要 PEF-3。

### 12.2 与 NER 协议

NER-2/3 建立内部非等价登记与关系性比较；PEF-2/3 建立现实路径效力。

建议联合报告：

- `NER-0/1 + PEF-2`：路径由固定判别或脚本驱动，当前比较主张弱；
- `NER-2/3 + PEF-0/1`：内部比较存在，但尚未进入现实路径；
- `NER-2/3 + PEF-2/3`：比较结果真实改变路径，可继续 CG-3/4；
- 任一组合都不能单独建立主体性或完整事件。

### 12.3 与 CBP 协议

PEF 回答“路径是否改变”，CBP 回答“后果落到哪里”。

- PEF-2/3 不自动支持 CBP-2；
- CBP-2/3 也不能反向证明路径由内部比较生成；
- 选择事件候选需要两者在同一边界和时间尺度上对齐。

### 12.4 与 HEF 协议

PEF 回答当前现实路径，HEF 回答结果对下一轮的效力。

- PEF-4 的闭环反馈仍可能只在短时状态内；
- HEF-2 的主动记忆也可能只改变当前响应而未执行；
- 只有路径效力与未来可达性重写分别通过，才可讨论更强写回链。

### 12.5 与 T-B 和 T-E

T-B 的比较／选择性再组织若进入路径层，至少应达到 PEF-2；若使用“排除、稳定或路径重组”的强读法，应检查 PEF-3。

T-E 中耗散、吸引子、迟滞或非平衡流可以实现执行和资源通道，但不能仅凭方向性或能耗直接满足 PEF-2。必须证明其与内部非等价登记之间存在可干预耦合。
