# 作者裁决包：`global optimum` 的作用域与四义拆分

## 0. 当前状态

> **作者裁决（2026-08-12）**：选择 **C-A — bounded plurality／严格拆义**。Gate C 已关闭并完成 canonical、domain mirror 与治理路由回写。本文件是非 canonical 的裁决／地板记录；当前规则以 `Governance/SRT_CLAIM_LADDER.md §0A`、`_SRT_SYMBOL_TABLE.md` Usage Rule 18 与 `_SRT_D_VALUE_CANONICAL.md §5b` 为准。

C-A 不承认位置无关、宇宙尺度、带语义／评价内容的 `global optimum` 为当前正面理论对象；具名有限模型内的技术性全局最优仍可使用，但必须声明算子／位置、可达或可行域、比较规则、时域与约束。regulative horizon 与 closure／model attractor 分别保持为不可到达的方向语言和有限动力学对象，不得互相代换。

本轮只审计：

```text
一次选择所整合的关切范围扩大（d expansion）
→ 该选择必然更接近同一个、位置无关的 global optimum
```

`Ψ_f → 0` 在 Core 与 Spirituality 之间的正负价倒置不并入本裁决。它会改变灵性命题的含义，须在 Gate C 作用域落地后另开 **CΨ** 作者门。

## 1. 旧提案需要先修正的一点

`Operations/Proposals/SRT_CONSISTENCY_DECISION_PACKET_2026-08-11.md §C.2` 曾用 `\Omega(\hat{G}_\theta)` 表示「可达最优」。该写法不能进入 canonical：`_SRT_SYMBOL_TABLE.md` 已把 `Ω` 固定为 **Ontological Consistency**，把 `Ω_mis` 固定为 **Ontological Mismatch Index**。复用 `Ω` 会制造新的符号冲突。

若采用有界最优读法，当前无需注册新符号；形式出现时直接写齐索引：

\[
x^*_{\theta,\tau,K,J}
\in
\arg\min_{x\in \mathcal R_{\theta,\tau,K}}
J_{\theta,\tau,K}(x),
\]

其中至少声明有限算子／位置 `θ`、可达域 `\mathcal R`、时间范围 `τ`、约束 `K` 与比较泛函或偏序 `J`。若这些对象没有给出，就只能说「扩大比较范围」或「避免已知局部陷阱」，不能说「最优」。

## 2. 地板构建报告

### 2.1 负担标注

| 判断句 | 标签 | 负担结论 |
|---|---|---|
| `d` 描述一次选择所整合的关切范围，而不是主体的固定属性 | **D** | 已有 canonical 边界；因此 `d↑` 不是自动发生的宇宙尺度单调过程 |
| 扩大关切范围会改变被纳入的变量、后果回流和可比较候选 | **D / C** | 在声明具体选择域时成立 |
| `d↑` 必然使选择靠近同一个 universe-wide optimum | **S** | 当前无推导；缺目标、聚合、闭包、时域和存在／唯一性条件 |
| 有限算子在声明可达域与比较规则后可定义 reachable optimum | **C** | 只在具名模型内条件成立；不是 L₀ 对象，也不是跨域通用量 |
| regulative horizon 是不可到达的方向性约束 | **D** | 可作为 L₁/P2 回读或 P5／praxis 语言；不得充当公式中的终态 |
| 有限约束下的 attractor 是某动力学模型的稳定／亚稳结构 | **C** | P3/P4；吸引子、最优与生成健康三者不自动等同 |
| 另立 universe-wide semantic optimum | **A / O** | Gate 0 禁止把它放成 bare L₀ primitive；若坚持，只能作为新增的 L₁+ 作者级形而上承诺，并独立承担定义与一致性负担 |

### 2.2 裸句测试

删除「初心」「归处」「最高秩序」「景观终点」等比喻后，当前可站立的最强裸句是：

> 在一个具名有限位置中，扩大一次选择所整合的关切范围，可能暴露原先被外包的后果或被遮蔽的可达路径。只有在可达域、比较规则、时间范围和可支付约束都已声明时，才可以比较两个候选何者在该模型内更优。这个比较不产生位置无关的宇宙级终点。

### 2.3 连接检验

从 `d expansion` 到唯一 global optimum，至少缺少：

1. **目标对象**：到底最小化 `Ψ_f`、总自由能、外包代价，还是最大化持续选择、身份连续、选项多样性；
2. **聚合规则**：不同主体、尺度与不可通约 stake 如何合并；
3. **闭包边界**：谁被计入，谁的再选择算数，未来主体与无申诉者如何进入；
4. **时间范围**：短期成本与长期可再选择冲突时按哪个窗口比较；
5. **可达域**：有限 `θ`、历史、预算和不可逆写回允许哪些路径；
6. **存在／唯一性条件**：即使目标和域已给出，最优解也可能不存在、非唯一或随景观迁移；
7. **测量接口**：哪些观察量能区分「更宽关切」与符号性、占有式或效率式假扩张。

这些都不包含在 `d` 的定义内，所以强箭头不是分析连接，也不是当前 P0/P1 定理。

### 2.4 反例施压

1. **Pareto 反例**：扩大关切后出现多个不可通约 stake，只形成 Pareto 前沿，不形成唯一标量最优。
2. **可支付性反例**：纳入更多后果使候选超出预算，`d` 的名义扩张反而破坏 continued-selectability。
3. **时域反转**：同一路径在短窗降低负担、长窗制造锁定；改变 `τ` 即改变排序。
4. **外包反例**：总量改善可通过牺牲没有反馈通道的位置实现；聚合最小不自动满足「不外包」。
5. **迁移景观反例**：选择本身会改写后续可达域，固定终点不存在，或最优随历史移动。
6. **计数反例**：「维持最大数量的选择过程」可被大量低 stake、可替换过程刷高，不能单独代表稳定身份、生成健康或规范正当性。

### 2.5 判决

**术语拆分：绿。具名有界最优：黄。`d↑ ⇒` 同一宇宙级最优：红。**

可保留的窄连接是：

```text
具名有限位置中的关切范围变化
+ 声明可达域／比较规则／时域／可支付与不外包约束
→ 条件性的 reachable comparison 或 reachable optimum
```

它是 P2/P3 条件接口，不是 L₀ 方向、跨域定理或宇宙终点。

## 3. 作者选项

### C-A — bounded plurality／严格拆义（推荐）

采用以下 repo-wide 规则：

1. **universe-wide global optimum** 不再作为当前理论中的正面对象。历史、引用或高承诺神学段落若保留，必须标成未建立／开放读法，不得承重 canonical 推导。
2. **reachable optimum** 只在有限位置、可达域、比较规则、时间范围与约束均已声明时使用；不注册 `\Omega(\hat{G}_\theta)`，避免与 canonical `Ω` 冲突。
3. **regulative horizon** 明确为不可到达的 L₁/P2 或 P5 方向语言，不作为公式终态或现实已达状态。
4. **closure／model attractor** 只描述具名有限动力学；不得因其稳定、低摩擦或可达就称为最优、善或生成健康。
5. `_SRT_D_VALUE_CANONICAL.md §5b` 撤回 `d↑ ⇒ local optimum → global optimum` 的强箭头，改写为有边界的比较能力与反遮蔽命题。
6. 「热寂不是 SRT 的最优」改写为更低负担的判断：**没有持续选择、stake 与后续可再选择的终止态，不能凭低成本被读成生成健康**。该判断无需承诺存在全局最优。
7. domain／bridge 中的强式按各自角色降为有界模型、规约性语言或明确的高承诺未决命题；普通数学／工程语境中的“全局最优”不机械替换。

**收益**：与 Gate 0、B-A、`d` 的事件属性、`Ψ_f > 0 and payable` 及 ST-A 双轴一致；不新增本体对象或符号。

**代价**：`Spirit_04` 的「全善 = 全局自由能最小」、`Spirit_05` 的 global convergence wording 以及若干领域段落会失去当前的肯定语气；需要逐条区分神学高承诺、P3 模型和普通优化用语。

### C-B — 新增 L₁+ universe-wide optimum 承诺

保留一个 universe-wide optimum，但明确把它设为**新的作者级形而上／规范承诺**，而不是从 `ε_pg`、Shoshin、`d` 或 `Ψ_f` 推出的对象，也不是 bare L₀ primitive。

落地前必须先补齐：

1. 承载对象是世界状态、实现历史还是所有选择过程的轨迹；
2. 跨主体、跨尺度、跨时间的聚合或偏序规则；
3. 可支付、可协调、不外包、可再选择四判据之间冲突时的裁决规则；
4. 存在性、唯一性及非静态／非热寂条件；
5. 与有限算子只能接触局部可达域之间的 epistemic bridge；
6. 与 Gate 0 的分层说明：它只能是 L₁+ 的内容性承诺，不可反向写入 L₀；
7. 可失败条件，或明确承认其只是不可证成的 worldview postulate。

**收益**：保留 SRT 当前最强的宇宙方向论和神学表达。

**代价**：这是新增承重对象，不是措辞修复；若不给出上述结构，C-B 就等同于继续混用，不能落盘。即使给出，也不能再写成 `d↑` 的定理后果。

### 不提供的选项：维持现状

当前同一术语同时指宇宙终点、有限可达最优、规约性方向和动力学吸引子；同一个 `Ψ_f →0` 又在 Core 中表示退化、在 Spirituality 中表示完美。保持混用不是一个可审计的 canonical 选项。

## 4. 本裁决明确不处理

- **CΨ**：是否把 Spirituality 的绝对 `Ψ_f → 0` 改为超额／防御性／跨算子摩擦趋零；
- `κ_0 / ε_pg` dependency graph；
- 书稿、论文、视频与历史输出的自动回写；
- 普通优化问题中技术性的 global optimum 用法；
- 任何新符号的准入。
