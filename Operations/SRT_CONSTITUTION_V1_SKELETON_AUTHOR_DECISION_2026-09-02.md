## 3. `(5)`：consequence-attribution / recutting probe（标题暂缓）

### 3.1 Perspective

从你已经说某个具体发生产生了影响，并且已经把这份影响算在某个对象、系统、位置或过程上的地方看。

### 3.2 悬置的默认

只要效果已经被观察到，或者某处出现了反馈，我们就已经知道这份影响应当算作落在了哪里。

### 3.3 读者动作

找出一个你当前已经说“这份影响落在这里”的具体发生或观察结果。

第一步：

> **你是把什么当成一个整体、在多长的跨度里看，才使“它落在这里”这句话成立？**

把当前实际使用的切法说出来。不要先要求它属于一份预先给定的技术分类。

在这次切法下，继续追踪：哪些后来的条件、约束或状态正在被算作因这次发生而改变。

不要因为某个位置是行动来源、被测量对象、反馈出现的位置或受益位置，就自动把它当作这份影响的归算落点。

第二步：

尽可能保持同一经验发生、事件链或观测材料作为锚点，但换一种整体划法或观察跨度，再重新追踪这份影响。

观察：

- 原来的归算在哪些重新切分下仍然保持；
- 在哪些切分下发生分拆、合并或移动；
- 是否有原先被算在同一位置的变化，在新切法下需要分开；
- 是否有原来的 effect description 在新切法下已经无法一一对应。

如果 effect description 本身必须改变，把这种改变保留为 probe result；不要为了维持“同一个 q”强行制造跨尺度同一性。

### 3.4 变得可见

```text
causal source
!=
observation site
!=
feedback site
!=
consequence attribution
```

“影响落在这里”不再享有解释豁免；它对当前切法的依赖，以及在重新切分下保持、分拆、合并或移动的方式，成为可继续追问的问题。

### 3.5 Boundary

本条不问：

- 后果**应该**回到谁；
- 谁应该承担、负责或修复；
- 什么结构更健康、更公平或更正当。

因此它不是 `non-outsourcing / order-gain` criterion。

本条也不预设存在一个与所有切法、尺度和时间跨度无关的唯一“最终落点”。归算随切法改变，不推出后果是虚构的或分析者可以任意创造现实；不同切法仍受实际发生、因果关系、持续改变、可重复观察和领域证据约束。

反过来：

```text
cross-cut stable
!=
ontologically final
```

某个 attribution 在本次多种切法下保持稳定，不推出它是唯一可能归算，不推出已经找到最终本体边界，也不推出 same bearer / own-history。

```text
successful consequence attribution
does not entail
bearerhood / subjecthood / agency / phenomenality
```

### 3.6 与 `(1)` 的独立性：回溯 != 重跑

把“这份后果落在 X”本身当成一个 One，确实可以运行 `(1)`：追问这份 attribution 从哪里来、预设了什么。

但 `(1)` 只要求暴露 provenance / hidden givens；它不要求在另一种切法下重新执行 attribution。

`(5)` 的独立输出是重新切分后的行为：

```text
one landing -> split
several attributed effects -> merge
landing at X -> moves to X+Y / Y
same empirical occurrence -> no longer one-to-one effect description
```

因此：

```text
provenance of an attribution
!=
behavior of that attribution under recutting
```

### 3.7 不结清作者原始“后果落回哪里？”

作者原始 identity burden 中的：

> **“后果落回哪里？”**

是更强的 substantive question。

`(5)` 只处理它的方法论前厅：先取消“我们已经知道后果落在哪里”的 attribution exemption。

因此：

```text
(5) consequence-attribution probe
!=
final answer to where consequences actually return / close
```

后者仍可能需要 Q12、bearer、same-unit consequence return、domain evidence 与更强理论 owner 支付。

### 3.8 stronger-bearer package guard

PH-IND02 / PH-IND06 等 owner 中已有更强组合：

```text
same-unit consequence return
+ history writeback
+ future-selectability
+ boundary continuity
+ non-outsourcing
```

Constitution 可以给其中若干基础问题提供彼此分离的 reader-side analogues，但不得把这些 analogues 重新合取成 Constitution-level bearer admission。

### 3.9 Full Neighbor Map 结果

本轮 bounded comparison 的最强邻居来自 actual causation / causal modeling、causal abstraction、multiscale modeling、causal emergence 与 causal perspectivalism。

它们已经成熟支付：causal attribution / variable choice / causal grain / scale dependence 不是 SRT 的新发现。

Full Neighbor Map 未产生：

```text
mature neighbor
-> reader operation fails
```

因此 `(5)` 的 Constitution contribution 只保留为 reader-side `declare current attribution -> recut -> re-run` 路径，不声称拥有 causal-model novelty。

## 4. `(6)`：evaluative re-run probe（标题暂缓）

### 4.1 Perspective

从你已经把两个走向，或一个过程的前后变化，称为“更好 / 更坏、进步 / 倒退、走对了 / 走错了”的地方看。

### 4.2 悬置的默认

只要你已经有办法把一个走向放在另一个前面，这个判断本身就不再需要说明。

### 4.3 读者动作

找出一个你当前已经作出的具体“更好 / 更坏”判断。

第一步：

> **现在是什么，使你把这一边放在另一边前面？**

说出你当前实际依赖的根据，不要先给这种根据分类。

如果当前说不出一个可以单独拿出来的根据，把：

> **“目前未分离出可单独扰动的判断依据。”**

作为合法结果保留。

这不推出该判断没有根据、非理性、错误或应当放弃。

第二步：

尽量保持原来的具体情形不变，暂时不让这个根据决定判断，然后再判断一次。

观察：

- 原判断仍然保持；
- 原判断暂时失去依据；
- 原判断发生反转。

如果重新判断时，原来的比较方式本身已经无法继续维持，也把这种变化作为结果保留；不要强迫重新得到一个总的“谁更好”。

### 4.4 变得可见

```text
change
!=
improvement

goal attainment
!=
direction settled

successful optimization
!=
better simpliciter
```

以及：一个“更好 / 更坏”的判断可能依赖当前未被显出的判断根据。

`(1)` 可以暴露这份判断从哪里来；本条进一步要求读者**真的暂时拿掉这个根据，再做一次判断**。

因此：

```text
judgment provenance
!=
judgment behavior under perturbation of its basis
```

### 4.5 双向 null guard

```text
当前说不出可扰动依据
does not entail
判断无根据 / 非理性 / 应当放弃

判断在扰动后改变
does not entail
原判断错误

判断在扰动后保持
does not entail
该判断已经被证成
```

简写：

```text
fragile != false
stable != true
```

### 4.6 Boundary

本条不给出 universal criterion of good direction。

它不把：

```text
可延续 / 可协调 / 不外包 / 可再选择
```

或：

```text
自耗 / 外包 / 锁死
```

写成 Constitution checklist。

本条不定义 `epsilon / T_dir / d-value`，不解决：

- 谁的 re-selection 算数；
- 什么尺度算数；
- 什么最终是真正的“好”。

ranking/evaluation 对依据的依赖不推出 relativism；某个判断对本次扰动保持稳定，也不推出 moral truth 或 ontological finality。

### 4.7 Core 24 owner subtraction

`Core/SRT_Core_24_Normativity_Anti_Optimization_Interface.md` 已有明确 downstream owner：scalar collapse、incommensurability、`d-value` non-substitutability 等属于 Core-tier bridge hardening；该文件自身 `canonical: false`，不是 Constitution 定义源。

因此若 reader re-run 暴露“单一尺度无法继续承载多个关切”，Constitution 只登记 comparison frame 失效；`scalar collapse / incommensurability -> d` 的理论解释回到 Core 24 owner。

抽掉 Core 24 的 anti-scalar payload 后，本条仍保持一个非空 reader operation：

```text
identify current evaluative basis
-> temporarily stop letting it decide
-> re-run the judgment
-> record retain / lose-basis / reverse
```

这个操作普通、成熟，不形成 novelty claim；但普通方法不是 Constitution admission 的 permission gate。

### 4.8 Full Neighbor Map 结果

bounded comparison 的主要 coordinates：

- sensitivity / robustness analysis：`realization + contrast / operational homology`；
- Dewey means–ends inquiry：`resonance + pressure / shared constraint`；
- Sen / capability informational basis：`pressure + resonance / shared constraint`；
- reflective equilibrium：`realization + contrast / operational homology`；
- value pluralism / incommensurability：`pressure + contrast / shared constraint`。

这些传统阻断任何“重新评价依据”“判断可修订”“不可通约”等 novelty claim，但没有使 reader-side re-run operation 失效。

## 8. v1 skeleton 总护栏

### 8.1 analytic probes，不是自然模块

```text
six analytic probes
!=
six ontic modules
!=
claim of completeness
```

这延续 `GOV-CONST01 §16.2` 的既有纪律：analytic cut 不自动成为自然本体分块。

### 8.2 编号不是生成阶梯

```text
(1) -> (2) -> (3) -> (4) -> (5) -> (6)
```

只可作为阅读导航，不表示本体生成顺序、必要前置或蕴含链。

例如：

```text
successful re-identification
!= bearerhood

successful consequence attribution
!= bearer admission

stable evaluative re-run
!= normative truth
```

### 8.3 六条自反可用

Constitution 不享有 God-view exemption。六条都可以反过来用于：

- 研究者自己的 objectification；
- 当前理论使用的 unit / cut / attribution；
- Constitution 自己的条目切分；
- 作者/读者当前使用的评价判断。

但 self-application 不意味着无限递归；按各条 Boundary 在足以暴露当前 givens / dependencies 后停止。

### 8.4 objectification / participation / reflexivity 是横贯纪律，不是第七条

Blueprint 已把 `WHO IS IN THE PHENOMENON? / OBJECTIFICATION / SRT RE-ENTRY` 设计为整个 domain workflow 的方法结构，并保留 ontological situatedness 与 participatory methodology 的 separation gate。

因此当前不新增 `(7) OBJECTIFICATION` 或 `(7) PARTICIPATION`。六条在使用时均受以下 meta-discipline 约束：

```text
reader/researcher is also situated
formalization/objectification has a declared cut
bearer participation is not replaced merely by a modeled bearer variable
position-indexed access != general epistemic privilege
```
