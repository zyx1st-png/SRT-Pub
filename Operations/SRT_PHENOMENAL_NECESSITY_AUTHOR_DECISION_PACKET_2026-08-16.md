# 作者裁决包：HP-B Phenomenal Necessity

## 作者裁决记录（2026-08-16）

作者选择：**HP-B-B — phenomenal necessity remains open**。

本裁决采纳 `Operations/Proposals/SRT_PH_IND04_OWNER_HARDENING_DECISION_PACKET_2026-08-15.md` 中的 HP-B-B，而不是 HP-B-A。

核心裁决：

```text
perspective-center individuation
!= phenomenal necessity

structural bearing (B_s)
!= phenomenal bearing (B_p)

B_s -> B_p
is not currently a proven theorem.
```

因此，SRT 当前可以正面主张的，是 bearer / consequence-return / stake / historical writeback / continued selectability 所构成的 subject-position architecture；不能仅凭这些结构就把 phenomenal presence 写成已证明结果。

## 1. 对硬问题路线的影响

SRT 保留两项已有成果：

1. **view-from-nowhere guard**：第三人称科学描述不是世界之外的无位置全景，第一人称／第三人称访问差异不能自动升级为第二种本体；
2. **HP-A perspective-center individuation**：SRT 已有一套较强的 bearer、boundary、stake、history、continuity 与 consequence-return 架构，用于回答“哪个持续单元在承担后果”。

但以下链条继续开放：

```text
Structural Bearing
->? Indexical For-P
->? Phenomenal For-me
->? Qualitative Character
```

这意味着 SRT 对硬问题的当前状态应写成：

```text
partial dissolution of a view-from-nowhere pseudo-gap
+
open constitutive bridge for phenomenal necessity
```

而不是：

```text
SRT has solved the hard problem
or
philosophical zombies are formally impossible in SRT
```

## 2. Z6 / SRT-zombie 的处置

PH-CONSC04 的 Z6 继续作为 decisive pressure case：

> 一个系统若满足当前全部 structural bearing / Stable-ISP-compatible subject-position 条件，但显式删除 phenomenality，是否形成内部矛盾？

在本裁决下，答案是：**尚未证明形成矛盾。**

因此不得通过把 phenomenal presence 预先塞进 `bearing` 定义来关闭 Z6。未来若要把 `B_s -> B_p` 提升为更强命题，必须提供非循环的构成论证或其他独立关闭路径。

## 3. Owner landing

本裁决要求 `Philosophy/SRT_HardProblem_Epistemology.md`：

- 文件级 `claim_mode` 从单一 `dissolution` 改为 `mixed`；
- 把 §3 从“完整消解论证”改为分层处理框架；
- 把原 §3.2 “承担即第一人称读数（反哲学僵尸）”降为构成性候选；
- 明写 `B_s != B_p` 与 `B_s -> B_p` 未闭合；
- 保留 view-from-nowhere / re-objectification guard，但不得把它们写成 phenomenal necessity 已解决；
- 感受质特定性公式只在 phenomenality 已独立成立的条件下作为结构锚定候选读取。

`Core/SRT_OPEN_TENSIONS.md` 已经与本裁决一致，因此不需要为了形式对称重复写同一开放项。

## 4. 不改变的内容

本裁决不：

- demote `P1-T06`；
- 否认 Stable ISP、bearer formation、stake、same-bearer consequence return 或 history writeback 的理论价值；
- 把 subject-position 降为纯约定；
- 推出 AI、动物、植物或任何具体系统有／无意识；
- 把 phenomenality 改写成经验神经科学已经直接测得的 SRT variable；
- 新增 canonical symbol。

## 5. 未来重新加固的门

只有出现以下任一情况，才重开更强的 phenomenal-necessity promotion：

1. 给出非循环论证，证明 `B_s + no B_p` 在 SRT 自身架构中矛盾；
2. 出现独立理论或经验约束，能把 `Structural Bearing -> Indexical For-P -> Phenomenal For-me` 的至少一个问号转成可审计的强连接；
3. 作者明确重新裁决 HP-B。

在此之前，HP-B-B 是当前 owner 口径。
