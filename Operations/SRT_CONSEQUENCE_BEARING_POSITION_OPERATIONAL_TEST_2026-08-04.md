# CG-3 后果承受位置：操作化测试协议 v1

> **RC-A active-use override（2026-08-18）**：本文中早于 RC-A 的 `Real Choice Moment / real choice / live choice` 只保留为历史或 downstream agency / revision 语汇，不再是 P1 Selection criterion。CG/SEA 最多给出 P2/P3 bounded Selection-event candidate；通过不证明 agency，失败也不得推出 `no Selection`。script / habit / gradient / `L_2` automation 本身既不证明更强 agency，也不能反推“没有 Selection”。更强 agency / consequence-sensitive revision 另走 `03_Bridges/SRT_Agency_Automation_Guard_2026-08-17.md`。

> **角色说明**：本文件把 T-D 的 CG-3“代价或后果能够落到承受位置”压缩为可预注册、可追踪、可干预、可失败的操作协议。它不是 canonical、主体性判据、stake 定义、伦理归责规则或经验验证结论。
>
> **核心问题**：怎样区分“一个过程产生了某种影响或消耗”，与“某条路径的代价、损失、风险、约束或义务实际落到了一个可识别的后果承受位置”？
>
> **最低结论纪律**：本协议最多支持“CG-3 后果承载候选”“位置特异的承受候选”或“外包链已解析”。这些结论都不能单独证明主体性、第一人称体验、关切、意识、自由、道德责任或生成健康。

---

## 0. 一句话判据

只有当某条候选路径相对于匹配基线产生了**可归因、非任意、与预先固定系统边界相关的状态损失、资源约束、风险暴露或义务负担**，并且这种后果实际改变了某个位置的维持条件、恢复成本、可达路径或后续行动能力，才有理由从“存在影响／耗散”升级为“后果承受位置候选”。

若还要主张“位置特异的承受”，必须追加：

> 该后果在系统内部或系统—环境关系中具有可识别的非对称分配；改变分配通道、保护机制或转移机制，会可预测地改变哪个位置承担后果以及后续路径如何变化。

压缩为三道门：

1. **归因门**：后果必须由目标路径相对于匹配基线造成，而不是背景消耗或观察者事后叙述；
2. **边界相关门**：后果必须落到预先固定边界内或明确登记的外部承受者，并影响其维持、恢复或未来路径；
3. **位置分配门**：若主张具体承受位置，必须能追踪后果如何被分配、转移、延迟或外包。

## 1. 为什么“有影响”“有成本”远远不够

下列现象都可能伴随能量、时间、资源或外部变化，却不自动满足 CG-3：

- 一切物理过程的散热或熵产生；
- 计算任务消耗电力；
- 观察者为实验投入时间；
- 一个输出改变了环境中的无关变量；
- 系统产生噪声、磨损或短暂温升；
- 决策界面产生点击，但核心资源配置不变；
- 一方获得收益，代价被隐蔽地转移给另一方；
- 研究者事后把任何受影响者称为“承受者”；
- 结果使某变量变化，却不改变任何维持条件、恢复成本或未来可达路径；
- 代价仅存在于评价者的道德判断中，没有可追踪的因果落点。

这些现象可以证明因果影响、一般成本或背景耗散，却不必证明：

- 后果属于目标路径而非普遍运行成本；
- 后果落到了被测系统的相关边界；
- 某一位置实际承担了差异化负担；
- 后果进入了选择事件所需的现实约束；
- 该位置具有主体性、体验或不可转移 stake。

因此本协议采用五级证据梯，而不是“有成本／无成本”的二元判法。

## 2. 五级证据梯

| 等级 | 名称 | 最低证据 | 允许表述 | 禁止升级 |
|---|---|---|---|---|
| CBP-0 | 外部影响痕迹 | 过程与环境或测量变量存在可观察变化 | “存在外部效应” | 不得称后果承载 |
| CBP-1 | 一般实现成本 | 过程消耗能量、时间、算力、材料或操作资源 | “存在实现成本／背景耗散” | 不得称 CG-3 已成立 |
| CBP-2 | 边界相关后果 | 路径特异后果影响预先固定边界内的维持变量、恢复成本或未来可达路径 | “CG-3 操作候选” | 不得推出主体性或 stake |
| CBP-3 | 位置特异承受 | 后果在多个位置之间非对称分配；保护、交换或转移干预可改变承担位置与后续结果 | “后果承受位置候选” | 不得推出第一人称承受 |
| CBP-4 | 外包／转移链已解析 | 选择者、执行者、受益者、承受者与修复者的因果链得到追踪，含延迟和分布式后果 | “外包链／负担分配已解析” | 不得自动作伦理归责或健康裁决 |

### 2.1 CBP-0 · 外部影响痕迹

典型情形：

- 温度、压力、网络流量或环境状态发生变化；
- 输出被记录、传播或触发另一个装置；
- 第三方观察到行为后调整自身行动；
- 统计结果与基线不同。

若无法说明该变化为何属于目标路径、落到谁、影响什么维持或未来条件，结论必须停在 CBP-0。

### 2.2 CBP-1 · 一般实现成本

典型情形：

- 化学反应耗散自由能；
- 神经、计算或组织活动消耗代谢／电力／工时；
- 程序执行占用内存和带宽；
- 制度程序需要会议、文本和行政资源。

CBP-1 说明实现不是无成本的，但通常只属于底座事实。若所有候选路径以相同方式承担该成本，它无法区分哪条路径产生了特定后果，也不能建立承受位置。

### 2.3 CBP-2 · 边界相关后果

CBP-2 要求目标路径相对于匹配基线，改变预先固定系统边界内的至少一种相关变量：

- 结构完整性；
- 可用资源池；
- 维持余量；
- 恢复时间或修复成本；
- 风险暴露；
- 后续可达路径；
- 转换或退出成本；
- 能继续参与后续过程的能力。

关键不是变量“发生变化”，而是：

> 该变化与系统维持、恢复或未来路径具有预先说明的结构关系，并能通过路径干预或保护干预被因果追踪。

### 2.4 CBP-3 · 位置特异承受

CBP-3 进一步要求系统内部、群体内部或系统—环境关系中存在多个可能承担后果的位置，而实际负担呈非对称分配。

可接受的承受位置包括：

- 物理结构中的局部部件、边界层或资源池；
- 生命系统中的细胞、组织、器官或整体维持尺度；
- 主体的身体、行动能力、资源、关系或身份连续性；
- 制度中的个人、群体、部门、地区或生态位置；
- AI 技术栈中的硬件、运营方、用户、数据提供者、受自动决策影响者或环境。

CBP-3 的关键证据是：

- 负担并非均匀背景成本；
- 可以预先指认候选承受位置；
- 改变保护、隔离、保险、补偿、路由或转移机制，会改变谁承担后果；
- 承受位置的状态改变会反过来约束后续路径或修复需求。

### 2.5 CBP-4 · 外包／转移链已解析

现实系统中，做出选择的位置、执行动作的位置、获得收益的位置和承担后果的位置经常分离。

CBP-4 要求至少区分以下角色：

- **选择／授权位置**：决定或批准路径；
- **执行位置**：实际实施动作；
- **受益位置**：获得资源、便利、权力或风险降低；
- **承受位置**：承担损失、风险、约束、义务或修复需求；
- **修复／补偿位置**：支付恢复、赔偿或治理成本；
- **记录／写回位置**：把结果沉积为记忆、规则、债务、损伤或制度先例。

这些角色可以重合，也可以分离。CBP-4 不自动判定责任或正义，只要求因果与资源转移链不被“系统总体有收益”或“决策者没有受损”所遮蔽。

## 3. 测试前必须固定的八项

任何 CG-3 测试开始前，必须预先写明：

1. **目标路径**：哪条选择候选或路径变化正在被审计；
2. **匹配基线**：与什么反事实、替代路径或无干预状态比较；
3. **系统边界**：哪些部件、人员、环境通道和反馈回路属于被测系统；
4. **候选承受位置**：哪些位置可能承担后果，为什么；
5. **后果变量**：损失、资源约束、风险、义务、恢复成本或路径收窄如何测量；
6. **相关时间尺度**：瞬时、跨试次、生命周期、制度周期还是代际尺度；
7. **转移通道**：保险、补偿、缓存、冗余、替换、外包或环境排放如何改变负担；
8. **最低判定等级**：本测试只测试 CBP-1、CBP-2、CBP-3 还是 CBP-4。

禁止在结果出现后任意移动边界：

- 当系统受损时把受损部件排除出系统；
- 当外部人员受损时突然把他们纳入系统以证明 CG-3；
- 当 AI 没有内部损失时把用户后果说成“AI 自身承担”；
- 当制度收益集中、成本外包时只报告组织总体指标。

### 3.1 嵌套边界纪律

同一过程可以同时涉及多个尺度，例如细胞—组织—个体，模型—服务器—平台—用户，部门—组织—社会—生态。

每个尺度必须分别报告：

- 边界内后果；
- 向上或向下转移的后果；
- 哪一尺度获得收益；
- 哪一尺度承担恢复；
- 是否存在尺度间净外包。

不得在不同尺度之间选择性切换，以便让同一案例总是通过 CG-3。

## 4. 核心测试组

### Test 1 · 路径差分与匹配基线

目的：确认后果属于目标路径，而不是系统一般运行成本。

操作：

- 比较目标路径 A、替代路径 B 和无干预基线；
- 匹配输入规模、持续时间、观察窗口和背景资源；
- 预先指定后果变量；
- 报告绝对变化与 A/B 相对差；
- 控制时间趋势、自然衰减和测量干扰。

判定：

- 仅有普遍运行成本 → 至多 CBP-1；
- A 相对于 B 产生稳定的边界相关差异 → 可继续测试 CBP-2。

### Test 2 · 因果归因／路径干预

目的：排除后果与路径仅相关而非由路径造成。

操作：

- 定向改变路径选择、执行强度或关键中介；
- 在不改变主要混杂的条件下阻断路径；
- 检查后果变量是否按预注册方向改变；
- 使用负对照路径和时间顺序验证。

通过条件：

- 路径干预改变后果；
- 中介阻断削弱后果；
- 后果时间顺序与机制一致；
- 替代解释不能同样解释结果。

### Test 3 · 边界相关性测试

目的：区分无关外部变化与真正影响维持／恢复／未来路径的后果。

操作：

- 预先说明后果变量与系统维持条件的关系；
- 干预该变量，检查系统持续、恢复或后续路径是否改变；
- 使用同等幅度但与维持无关的变量变化作对照；
- 检查影响是否超出短暂噪声或测量窗口。

判定：

- 变量变化不影响维持、恢复或后续路径 → CBP-0/1；
- 变量变化具有可重复的边界相关效力 → 支持 CBP-2。

### Test 4 · 保护／缓冲干预

目的：确认某位置确实承担后果，而不是仅与后果共现。

操作方式包括：

- 提供结构保护或隔离；
- 增加资源缓冲、冗余或备用路径；
- 设置保险、补偿、维修或恢复支持；
- 改变风险暴露；
- 对候选承受位置进行替换、屏蔽或强化。

通过条件：

- 保护干预降低该位置的状态损失或恢复成本；
- 后果可能转移到其他位置，并能被追踪；
- 路径本身未被完全取消，避免把“没有行动”误作保护成功。

### Test 5 · 负担交换／位置置换测试

目的：识别位置特异性，而不是系统总体成本。

操作：

- 在保持目标路径和总体资源近似不变时，改变负担路由；
- 交换承担部件、群体、地区、账户或恢复责任；
- 检查总成本相近但位置分布不同的情形；
- 测量承受位置改变后系统行为、退出、修复或未来路径的变化。

通过条件：

> 负担路由改变会可预测地改变特定位置的状态与后续路径，即使系统总体成本近似不变。

这支持 CBP-3。

### Test 6 · 外包链追踪

目的：防止决策者或系统核心通过外部化代价而被误判为“无后果”。

操作：

- 绘制选择者、执行者、受益者、承受者、修复者和写回位置；
- 追踪资源、风险、债务、损伤、等待时间、污染或义务的流向；
- 检查延迟、跨组织、跨地域和跨代后果；
- 使用总量守恒或账户核对，识别“消失的成本”；
- 标记无法观测或没有代表权的潜在承受者。

判定：

- 只知道系统核心受益，但成本去向不明 → CBP-3 未完成；
- 转移链、时间延迟和修复责任得到解析 → 可标记 CBP-4。

### Test 7 · 延迟与恢复窗口测试

目的：区分瞬时波动、可逆扰动与真实恢复负担。

操作：

- 延长观察窗口；
- 测量回到基线所需时间与资源；
- 区分自然恢复、外部修复和不可恢复损失；
- 检查短期收益是否对应长期负担；
- 报告后果是否改变未来选择或退出成本。

短暂温升、缓存占用、疲劳或波动只有在影响相关维持／恢复／路径变量时，才可进入 CBP-2 以上。

### Test 8 · 隐藏承受者扫描

目的：识别没有出现在系统仪表盘或决策模型中的承受位置。

至少检查：

- 未被建模的维护人员；
- 数据提供者与被自动决策影响者；
- 边缘群体与无代表权者；
- 环境、公共资源与未来修复者；
- 供应链和外包组织；
- 在聚合指标中被均值掩盖的局部位置。

未发现隐藏承受者不证明不存在；报告必须说明扫描范围和盲区。

### Test 9 · 主体性防火墙

目的：防止“有承受位置”被直接升级为“有体验的主体”。

必须分别回答：

1. 是否只是结构、资源或路径受到约束？
2. 是否存在稳定的系统级维持位置？
3. 是否有独立证据支持不可转移 stake？
4. 是否有独立主体性判据？
5. 是否有第一人称登记或意识证据？

CBP-2 至 CBP-4 只回答第一和部分第二项。后面三项不能由本协议推出。

## 5. 最小决策树

### Gate A · 是否只有外部效应？

- 只观察到环境变量变化；
- 没有路径差分基线；
- 没有候选承受位置；
- 后果变量与维持／恢复无关。

若是：**CBP-0**。

### Gate B · 是否只是一般实现成本？

- 所有候选路径同样耗能或占用资源；
- 成本只说明系统在运行；
- 无法指出路径特异后果。

若是：**CBP-1**。

### Gate C · 是否有边界相关后果？

- 路径相对于基线改变维持、恢复、风险或未来路径变量；
- 路径干预可预测地改变后果；
- 系统边界和时间尺度预先固定。

若是：**CBP-2，CG-3 操作候选**。

### Gate D · 是否有位置特异分配？

- 多个位置可能承担后果；
- 负担实际非对称；
- 保护、交换或路由干预改变承担位置；
- 承受位置变化影响后续路径或修复。

若是：**CBP-3**。

### Gate E · 是否解析了外包链？

- 选择者、执行者、受益者、承受者和修复者得到区分；
- 延迟、分布式和跨尺度后果得到追踪；
- 隐藏承受者与盲区得到报告。

若是：**CBP-4**。

无论达到哪一级，都必须继续独立审计 CG-0、CG-1、CG-2 与 CG-4；CG-3 不能独自建立 real choice moment。

## 6. 五域最小模板

### 6.1 物理／化学系统

#### 候选承受位置

- 边界膜、反应器结构、局部资源池；
- 会因目标路径发生耗尽、损伤或恢复需求的组分；
- 影响后续可达反应路径的内部状态。

关键测试：

1. 将普通散热与路径特异资源耗尽分开；
2. 保护某局部结构，检查后果是否下降或转移；
3. 交换资源供给或负担路由，检查位置特异性；
4. 与无边界相关性的普通耗散过程比较。

降级规则：

- 任意熵产生或热输出只支持 CBP-1；
- 路径特异地改变结构完整性或后续可达路径可支持 CBP-2；
- 局部位置的保护／交换干预改变负担可支持 CBP-3；
- 所有等级都不得推出生命、主体或体验。

### 6.2 生命系统

#### 候选承受位置

- 单细胞的资源与损伤状态；
- 组织或器官的维持余量；
- 整体生物体的恢复、风险和行动能力；
- 生态或共生伙伴承担的转移后果。

关键测试：

1. 预先固定细胞、组织还是整体尺度；
2. 测量路径对资源、损伤、修复和未来响应的差分；
3. 使用保护、补偿或替换干预追踪负担转移；
4. 防止把整体收益掩盖的局部损伤忽略。

降级规则：

- 代谢消耗本身只到 CBP-1；
- 维持变量、修复成本或未来响应受影响可到 CBP-2；
- 指定细胞／组织承担差异化后果可到 CBP-3；
- 生物维持不自动等于第一人称关切。

### 6.3 主体／行动系统

#### 候选承受位置

- 身体安全与健康；
- 时间、资源与行动能力；
- 关系、身份连续性与承诺结构；
- 相关他者和共同体。

关键测试：

1. 区分做决定的人与真正承担后果的人；
2. 检查表面同意是否伴随现实退出或补偿；
3. 追踪短期收益和长期恢复成本；
4. 不把不健康结果反向解释为“没有发生真实选择”。

主体层可以有独立的体验证据，但该证据必须另行论证，不能由 CBP 等级替代。

### 6.4 社会／制度系统

#### 候选承受位置

- 决策参与者与未参与者；
- 获益群体与被约束群体；
- 前线执行者、维护者和公共财政；
- 地区、供应链、生态环境与未来修复者。

关键测试：

1. 分开授权、执行、受益、承担和修复角色；
2. 比较组织总体收益与群体分布；
3. 追踪预算、时间、风险、污染、债务和退出成本；
4. 检查无代表权者是否成为隐藏承受者；
5. 对补偿、保险或责任转移做因果审计。

制度程序复杂、参与人数多或行政成本高，都不能替代 CG-2 路径效力和 CG-3 负担归属。

### 6.5 AI／技术系统

#### 需要分开的潜在位置

- 模型或代理的内部持续状态；
- 服务器、硬件和基础设施；
- 开发者与运营方；
- 用户、数据提供者与被决策影响者；
- 外部环境和公共资源。

关键测试：

1. 电力与算力消耗通常只支持 CBP-1；
2. 资源不足、热约束、记忆删除或模型损坏若改变系统后续可达路径，可支持系统级 CBP-2；
3. 用户损失、错误决策或隐私暴露属于外部承受位置，不能说成“AI 自身承担”；
4. 平台受益、用户承担和公共修复成本必须进入 CBP-4 外包链；
5. 即使 AI 内部存在 CBP-2/3，也不得自动推出不可转移 stake、主体性、意识或道德地位。

## 7. 与 stake、关切、责任和生成健康的分工

### 7.1 后果承载不等于 stake

本协议识别的是：

> 路径后果在某个边界或位置上形成了现实约束。

stake 需要更强的独立论证，例如该位置与系统持续、自我维持、不可转移损失或未来选择能力之间的关系。不得把任何损伤、成本或资源减少直接称为 d-value、关切或主体 stake。

### 7.2 后果承载不等于第一人称体验

结构受损、资源耗尽或路径收窄可以完全没有体验证据。pain、distress 和 suffering 的技术区分仍由对应理论文件管辖。

### 7.3 后果承载不等于伦理责任

CBP-4 可以显示谁选择、谁执行、谁获益、谁承担，但责任判断还需要：

- 控制能力；
- 信息可得性；
- 可预见性；
- 授权关系；
- 强制与退出条件；
- 规范与法律框架。

本协议不自动分配责任。

### 7.4 后果承载不等于生成健康

一个真实后果可能支持学习和开放，也可能造成压迫、自我封闭或外包。生成健康评价必须在事件识别后独立检查可再选择性、修复、退出和成本外包。

---

## 8. 模型比较纪律

本协议不能只靠丰富叙述。至少比较三类模型：

1. **一般成本模型**：所有路径都有相似背景成本；
2. **边界相关模型**：目标路径影响维持、恢复或未来路径变量；
3. **位置分配模型**：后果还取决于负担路由、保护、补偿和外包链。

最低要求：

- 在未用于拟合的数据或新干预上比较预测；
- 以路径干预、保护干预和位置交换为主要裁决；
- 更复杂模型必须提供额外可检验预测；
- 若边界相关模型无额外预测增益，不得标记 CBP-2；
- 若位置分配变量无额外增益，不得标记 CBP-3；
- 若外包链无法闭合，不得标记 CBP-4。

### 8.1 SRT 当前允许的增益表述

允许：

> 本协议提供一套区分外部影响、一般实现成本、边界相关后果、位置特异承受和外包链的跨域审计阶梯。

不允许：

> SRT 已经证明所有选择都存在统一的承受实体，或已经从后果承载推导出主体性和道德地位。

## 9. 常见假阳性

| 假阳性 | 为什么不够 | 应怎样处理 |
|---|---|---|
| 有散热 | 一切物理实现都可能散热 | 只标 CBP-1，测试路径差分与边界相关性 |
| 有资源消耗 | 可能是共同背景成本 | 比较候选路径的相对后果 |
| 有外部影响 | 影响可能与系统维持无关 | 做 Test 3 |
| 有损伤指标 | 可能只是相关或测量噪声 | 做路径干预与保护干预 |
| 有受影响者 | 受影响者可能由研究者事后选择 | 预注册候选位置并追踪分配机制 |
| 系统总体受益 | 局部成本可能被聚合掩盖 | 做位置分布和隐藏承受者扫描 |
| 决策者无损失 | 代价可能已外包 | 做 CBP-4 链追踪 |
| AI 使用电力 | 只是硬件底座事实 | 证明资源变量进入目标层后续路径 |
| 模型状态改变 | 状态变化不一定是损失或承受 | 检查维持、恢复和可达路径 |
| 有补偿 | 补偿可能由第三方承担新成本 | 追踪修复者和净转移 |
| 有同意 | 同意不证明后果公平或可退出 | 分开事件、承受和健康评价 |
| 有痛苦报告 | 报告与结构后果需要分别审计 | 对齐 pain/distress/suffering 与主体性证据 |

## 10. 失败与降级条件

出现以下任一情况，主张必须降级：

1. **边界后移**：结果出现后才移动系统边界；
2. **基线缺失**：没有替代路径或无干预对照；
3. **背景成本偷换**：把所有路径共有的耗散当作目标后果；
4. **指标后选**：只报告出现损失的变量；
5. **相关性冒充归因**：后果变量变化，但路径干预不改变它；
6. **无关影响泛化**：变量变化与维持、恢复或未来路径无结构关系；
7. **瞬时噪声偷换**：短暂波动被称为承受；
8. **总体指标掩盖**：聚合收益遮蔽局部损失；
9. **位置虚构**：承受位置只存在于研究者叙述，没有分配机制；
10. **全局损伤误判**：保护干预只是取消整个过程；
11. **转移未追踪**：一个位置负担下降，却没有检查是否转移到其他位置；
12. **外包链断裂**：成本去向或修复责任不明，却声称系统无后果；
13. **尺度偷换**：在细胞、个体、组织、社会尺度间任意切换；
14. **AI 主体偷换**：用户或硬件承担被说成 AI 自身 stake；
15. **主体性偷换**：CBP-2/3 被直接升级为体验、关切或意识；
16. **责任偷换**：因果承受链被直接等同伦理或法律责任；
17. **健康偷换**：因为后果得到补偿就判定生成健康；
18. **普通理论足够**：协议没有超出成本会计、可靠性工程、风险分析或制度研究的可区分预测，却声称独立机制增益。

### 10.1 三种修正分类

若测试失败，必须分类：

- **修正**：测量、边界或基线存在局部缺陷；
- **压力**：需要增加范围条件、时间尺度或转移模型；
- **失败**：无法识别边界相关后果或位置分配，相关 CG-3 强表述必须撤回或降级。

不得通过不断扩大“后果”“承受”或“系统”的含义来免疫反例。

## 11. 标准报告模板

每个案例至少填写：

| 字段 | 内容 |
|---|---|
| 目标路径 | 被审计的行动、转移或选择候选 |
| 匹配基线 | 替代路径／无干预状态 |
| 系统边界 | 预先固定的部件、人员、环境接口与尺度 |
| 候选承受位置 | 可能承担后果的位置及理由 |
| 后果变量 | 维持、恢复、风险、资源、义务或路径指标 |
| 时间尺度 | 瞬时、恢复期、生命周期、制度周期等 |
| Test 1/2 | 路径差分与因果归因结果 |
| Test 3 | 边界相关性结果 |
| Test 4/5 | 保护干预与位置交换结果 |
| Test 6 | 外包链与角色映射 |
| Test 7/8 | 延迟恢复与隐藏承受者扫描 |
| 最强基线 | 成本模型、风险模型、可靠性、制度分析等 |
| 判定等级 | CBP-0 至 CBP-4 |
| 未解析转移 | 成本、风险或修复责任的盲区 |
| 非主张 | 不允许推出的 stake、主体性、责任或健康结论 |

推荐结论句式：

> 在预先固定的边界与时间尺度上，路径 A 相对于匹配基线 B 增加了位置 X 的恢复成本并缩小其后续可达路径；路径干预和保护干预均按预注册方向改变该后果，因此支持 CBP-2。负担交换进一步把后果从 X 转移到 Y，支持 CBP-3。该结果尚未证明 stake、主体性、第一人称体验、伦理责任或生成健康。

## 12. 本协议对 T-D 与相邻协议的具体约束

### 12.1 对 T-D CG-3

今后使用“后果承受位置”时，至少要说明：

- 是 CBP-1 的背景实现成本，还是 CBP-2 的边界相关后果；
- 后果属于哪条路径、相对于什么基线；
- 系统边界和时间尺度是什么；
- 候选承受位置如何被因果识别；
- 是否存在位置分配、转移或外包；
- 哪个干预结果能击退“任意影响都算后果”的泛化。

CG-3 的最低操作候选是 CBP-2，而不是 CBP-0 或 CBP-1。位置特异的承受主张至少需要 CBP-3。

### 12.2 与 NER 协议

NER-2/3 回答系统内部是否形成非等价登记或关系性比较；CBP-2/3 回答路径后果落到哪里。两者不能互相替代：

- 有内部比较但无现实后果，仍不足以成立选择事件；
- 有后果但无内部登记，可能只是被动因果过程；
- NER-4 写回接口仍需独立的 CG-2、CG-3、CG-4 审计。

### 12.3 与 CG-4 历史效力

CBP 只要求后果影响维持、恢复或未来路径；是否构成历史写回，需要后续 CG-4 协议区分：

- 短暂残留；
- 缓存或疲劳；
- 普通迟滞；
- 参数更新；
- 真正改变后续可达规则、成本或边界的历史效力。

### 12.4 与 T-E

普通物理耗散通常停在 CBP-1。只有当耗散变量路径特异地改变边界维持、位置分配或后续可达路径时，才可能进入 CBP-2/3。即使如此，也不能把耗散等同于选择或主体性。

## 13. 第一轮验收

| 验收项 | 结果 |
|---|---|
| 区分外部影响与后果承载 | **已建立 CBP-0/1/2 分层** |
| 区分背景成本与路径特异后果 | **已建立路径差分与基线门** |
| 固定系统边界与时间尺度 | **已建立预注册要求** |
| 识别位置特异承受 | **已建立保护／交换干预和 CBP-3** |
| 解析选择者与承受者分离 | **已建立 CBP-4 外包链** |
| 处理延迟、分布式和隐藏后果 | **已建立 Test 6/7/8** |
| 五域最小模板 | **已完成** |
| stake／主体性／责任／健康护栏 | **已保留** |
| 统一数值阈值 | **未建立，也不主张** |
| 经验验证 | **未完成；需独立案例与证据卡** |
| canonical 升级 | **禁止** |

最终操作性结论：

> **后果承受位置不应由“有影响”或“有成本”定义，而应由路径特异、边界相关、可因果追踪的维持／恢复／未来路径约束来识别；位置特异的承受还要求负担分配、转移与外包机制能够被干预和追踪。**
