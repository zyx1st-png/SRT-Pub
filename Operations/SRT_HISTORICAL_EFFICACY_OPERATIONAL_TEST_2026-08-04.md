# CG-4 历史效力：操作化测试协议 v1

> **角色说明**：本文件把 T-D 的 CG-4“结果获得维持、写回或未来约束效力”压缩为可预注册、可重置、可重放、可干预、可失败的操作协议。它不是 canonical、L₂ 判据、不可逆性定义、统一记忆理论或经验验证结论。
>
> **核心问题**：怎样区分“过去留下了某种痕迹”，与“过去路径通过一个可识别的因果载体，真实改变了后续可达路径、转换成本、更新规则或系统边界”？
>
> **最低结论纪律**：本协议最多支持“持续痕迹”“主动历史携带”“CG-4 历史效力候选”或“规则／边界写回候选”。这些结论都不能单独证明 real choice moment、L₂、主体性、意识、自由、道德责任或生成健康。

---

## 0. 一句话判据

只有当先前路径相对于匹配历史基线，通过一个可定位、可干预的内部或关系性载体，**可重复地改变后续候选的可达性、转换概率、返回成本、资源门槛或适用规则**，才有理由从“存在残留／记忆”升级为“CG-4 历史效力候选”。

若还要主张较强的“写回”，必须追加：

> 对写回载体、更新通道或边界规则的定向干预，能够可预测地消除、反转、迁移或重建这种未来约束；仅延长观察时间、发现相关性或读取日志不够。

压缩为四道门：

1. **历史差分门**：不同先前路径必须在匹配当前输入和相关状态后产生可重复的未来差异；
2. **因果载体门**：必须指出并干预承载历史效力的状态、结构、资源、规则、记忆或环境回路；
3. **未来组织门**：差异必须进入后续可达路径、转换成本、候选生成或规则适用，而不是只留下可读取痕迹；
4. **时间尺度门**：效力必须超出目标领域预先规定的瞬时残留、缓存窗口或自然恢复期。

## 1. 为什么“记住了”“持续了”远远不够

下列现象都可能显示过去仍有影响，却不自动满足 CG-4：

- 传感器余辉、仪器延迟或测量滤波；
- 内存缓存、临时文件、日志或数据库记录；
- 神经、肌肉、化学或材料系统的短暂疲劳；
- 温度、浓度、电荷或资源尚未恢复到基线；
- 普通吸引子回归、迟滞环或路径依赖；
- 模型上下文窗口中仍保留先前文本；
- 参数发生变化，但行为和未来可达路径没有可识别变化；
- 规则文本被更新，但执行、资源配置和约束结构没有改变；
- 观察者事后用历史标签对两个当前状态作区分；
- 结构损伤造成持续劣化，但无法说明它是否属于选择结果的写回；
- 输出被永久存档，却从未进入后续过程；
- 系统每次都从固定脚本重放，只是外部环境不同。

这些现象可以证明：

- 过去留下了痕迹；
- 当前状态与先前过程相关；
- 系统存在记忆介质或不可逆变化；

但不必证明：

- 历史痕迹被系统实际调用；
- 先前路径改变了未来候选结构；
- 返回成本或转换规则发生了变化；
- 当前过程形成了选择事件；
- 写回达到 L₂-grade 硬化；
- 系统获得主体性或第一人称连续性。

因此本协议采用五级证据梯，而不是“有记忆／无记忆”的二元判法。

## 2. 五级证据梯

| 等级 | 名称 | 最低证据 | 允许表述 | 禁止升级 |
|---|---|---|---|---|
| HEF-0 | 外部历史痕迹 | 观察者、仪器或存储介质可读取过去信息 | “存在历史记录／残留” | 不得称系统历史效力 |
| HEF-1 | 被动持续状态 | 当前内部状态受过去影响，但自然恢复、清空或状态匹配后效应消失 | “存在短期携带／状态依赖” | 不得称 CG-4 已成立 |
| HEF-2 | 主动历史携带 | 历史载体被后续过程因果调用，改变当前响应或资源配置 | “主动记忆／历史携带候选” | 不得称未来路径已被重写 |
| HEF-3 | 可达性／成本重写 | 先前路径因果改变后续候选可达性、转换概率、返回成本、门槛或候选生成 | “CG-4 历史效力候选” | 不得自动称 L₂ 或 real choice moment |
| HEF-4 | 规则／边界写回 | 历史结果进一步改变更新规则、制度约束、系统边界、继承关系或跨情境路径结构 | “规则／边界写回候选” | 不得自动作 canonical、主体性或健康升级 |

### 2.1 HEF-0 · 外部历史痕迹

典型情形：

- 日志记录了过去动作；
- 研究者可根据轨迹识别先前条件；
- 备份文件、传感器或环境痕迹仍在；
- 数据库保留旧版本，但运行系统不读取它。

若删除或遮蔽该痕迹不改变系统后续行为，结论必须停在 HEF-0。

### 2.2 HEF-1 · 被动持续状态

典型情形：

- 温度、浓度、疲劳、缓存占用或短时激活尚未恢复；
- 相同输入因当前状态不同而产生不同响应；
- 经过充分清空、恢复、洗脱或状态匹配后，历史差异消失。

HEF-1 说明系统具有状态依赖，但不能仅凭状态依赖声称历史写回。它可能只是：

- 有限恢复时间；
- 普通动力学松弛；
- 缓存命中；
- 短时疲劳；
- 观测窗口过短。

### 2.3 HEF-2 · 主动历史携带

HEF-2 要求历史载体被后续过程实际调用，而不是只被动存在。

可接受的载体包括：

- 可被读取的内部记忆；
- 先前形成的权重、阈值或资源配置；
- 免疫、神经或行为系统中的可干预记忆状态；
- 制度中的有效先例、权限记录、债务或执行状态；
- AI 系统中的持续记忆、策略状态或工具使用记录；
- 环境中与系统形成闭环的已修改结构。

关键证据是：

> 定向移除、遮蔽、替换或修改该载体，会可预测地改变后续响应；仅证明载体与行为相关不够。

HEF-2 仍可能只改变当前反应幅度或排序，而没有改变候选可达性和转换规则，因此尚不足以建立强 CG-4。

### 2.4 HEF-3 · 可达性／成本重写

HEF-3 是本协议的最低 CG-4 操作候选。

至少需要证明先前路径通过可识别载体改变以下一项：

- 某些候选是否仍可进入；
- 从当前状态转向某路径的概率或门槛；
- 返回旧路径所需的时间、资源或修复成本；
- 候选生成、探索或搜索范围；
- 路径之间的相对转换成本；
- 下一轮选择中可调用的资源、权限或行动能力；
- 某条路径是否被新增、封闭、延迟或强制优先。

HEF-3 不要求永久不可逆，也不要求跨越所有情境。它要求效力在预先指定的相关时间尺度和边界上真实改变未来路径组织。

### 2.5 HEF-4 · 规则／边界写回

HEF-4 进一步要求历史结果不只改变某次转换，还改变组织选择的规则、边界或继承结构，例如：

- 更新阈值或学习规则本身发生改变；
- 系统新增或删除持续性的状态变量、接口或反馈通道；
- 制度把一次决定沉积为正式规则、权限、预算约束或先例；
- 生命系统形成跨情境可调用的持久适应结构；
- AI 系统的工具权限、记忆架构、策略更新规则或环境接口被修改；
- 历史结果改变哪些部件、人员或环境回路被纳入系统边界；
- 结果可被复制、继承、迁移或传递到后续实例。

HEF-4 是与 L₂、制度硬化和跨时间组织相邻的接口，但不能凭本等级自动判定 L₂。L₂ 仍需独立检查局部成本、全局约束、继承、重入、迟滞和相关 canonical 条件。

## 3. 表征纪律：历史效力不等于“超越状态”

任何具有历史效力的系统，都可能通过更丰富的状态描述来表示其历史载体。

因此本协议不主张：

- 历史必须是神秘的非状态实体；
- 只要扩展状态空间就能取消历史效力；
- 非马尔可夫表象本身证明选择；
- 无法观测全部微观状态就可免除因果测试。

操作上应区分两个问题：

1. **载体识别问题**：过去通过什么当前可存在的状态、结构、规则或环境回路产生效力？
2. **组织变化问题**：该载体是否改变未来路径组织，而不只是解释当前输出？

若丰富状态模型能够完整解释效应，这通常是成功定位载体，而不是自动否定历史效力。真正需要排除的是：

- 只有研究者标签、没有系统载体；
- 只有被动残留、没有后续调用；
- 只有当前输出差异、没有未来组织变化。

## 4. 测试前必须固定的十项

任何 CG-4 测试开始前，必须预先写明：

1. **目标历史路径**：哪一先前路径、决定、更新或事件正在被审计；
2. **匹配历史基线**：与什么替代历史、无事件历史或随机历史比较；
3. **系统边界**：哪些部件、人员、环境接口和反馈回路属于系统；
4. **当前输入与状态控制**：哪些当前变量必须匹配，哪些隐藏状态允许作为候选载体；
5. **候选历史载体**：记忆、参数、资源、结构、规则、边界或环境修改；
6. **未来路径集合**：哪些候选的可达性、门槛、概率或成本将被测量；
7. **相关时间尺度**：瞬时、跨试次、恢复期、生命周期、制度周期或代际尺度；
8. **重置／洗脱操作**：怎样区分短暂残留与持续历史效力；
9. **最强基线模型**：无记忆、被动状态、普通迟滞、固定参数或领域标准模型；
10. **最低判定等级**：本测试只测试 HEF-1、HEF-2、HEF-3 还是 HEF-4。

禁止在看到结果后：

- 延长或缩短时间窗口以保住结论；
- 把任意隐藏变量临时命名为历史载体；
- 把外部观察记录突然纳入系统；
- 把缓存、日志或疲劳改称“写回”；
- 在当前状态、规则和边界之间任意切换解释层级。

## 5. 核心测试组

### Test 1 · 匹配历史基线

目的：确认未来差异来自先前路径，而不是当前输入或背景条件不同。

操作：

- 构造目标历史 A、替代历史 B 和无事件历史 C；
- 在未来测试阶段匹配当前输入、资源、观察窗口与主要可测状态；
- 预先指定未来响应和路径指标；
- 报告历史主效应、当前状态效应及交互；
- 使用多次重放而不是单次轨迹。

判定：

- 当前条件匹配后无稳定差异 → HEF-0/1；
- 历史差异仍可重复 → 继续测试载体和未来组织。

### Test 2 · 重置／洗脱／恢复测试

目的：区分短暂残留与持续历史效力。

操作方式包括：

- 清空缓存或上下文；
- 恢复温度、浓度、资源和疲劳状态；
- 重置短时内部状态；
- 等待预注册恢复窗口；
- 使用洗脱、去适应、休息或系统重启；
- 将系统置于匹配中性状态后再测试。

判定：

- 完成合理恢复后效应消失 → 通常停在 HEF-1；
- 效应仍存在 → 继续定位主动历史载体；
- 若重置操作同时破坏系统核心结构，不能据此判定历史效力消失。

### Test 3 · 历史载体干预／消融

目的：从相关性升级为因果携带。

操作：

- 删除、遮蔽、替换或反转候选记忆；
- 恢复参数、阈值或资源配置；
- 阻断先例、权限、规则或环境回路的调用；
- 在保持当前输入不变时迁移候选载体；
- 使用负对照载体排除一般系统损伤。

通过条件：

- 干预方向事先规定；
- 未来响应按预测减弱、消失、反转或迁移；
- 一般性能下降和系统破坏得到控制；
- 替代载体模型不能同样解释。

Test 3 通过可支持 HEF-2，但仍需 Test 5/6 建立 HEF-3。

### Test 4 · 冻结状态／反事实重放测试

目的：区分固定脚本、当前状态依赖与历史载体调用。

操作：

- 冻结候选参数或规则；
- 对相同当前输入重放不同历史；
- 将历史载体从 A 历史移植到 B 历史；
- 比较“只看当前输入”“加入被动状态”“加入主动历史载体”三类模型；
- 检查历史标签是否在载体缺失时仍有预测力。

判定：

- 固定脚本或当前状态模型已完整预测 → HEF-0/1；
- 主动载体提供干预预测增益 → HEF-2；
- 载体进一步改变未来路径集合或转换结构 → 继续 HEF-3。

### Test 5 · 未来可达性探针

目的：直接测试历史是否改变后续候选结构。

操作：

- 枚举或采样预先指定的未来候选路径；
- 测量不同历史后每条路径是否可进入、被排除或需要额外条件；
- 使用标准化探索、扰动或搜索预算；
- 检查新增路径、封闭路径和路径重开；
- 区分“系统没有尝试”与“路径实际上不可达”。

通过条件：

> 先前路径通过可识别载体，稳定地改变至少一条后续路径的可达性或进入门槛，并能由载体干预改变。

这支持 HEF-3。

### Test 6 · 转换概率／返回成本测试

目的：识别路径仍可达但转换结构已被历史改写的情形。

至少测量：

- 转换成功概率；
- 达到目标路径所需时间；
- 能量、资源、信息或协调成本；
- 返回旧状态的修复需求；
- 退出、撤销或重新开放的门槛；
- 必须跨越的中间状态或权限条件。

通过条件：

- 目标历史相对于匹配基线改变这些指标；
- 历史载体干预按预测改变成本或概率；
- 差异超出瞬时疲劳和普通恢复窗口。

Test 5 或 Test 6 与 Test 3 共同通过，才建议标记 HEF-3。

### Test 7 · 顺序交换与路径特异性测试

目的：区分“只要发生过任何事件就变化”与“具体路径历史具有方向性效力”。

操作：

- 比较 A→B 与 B→A；
- 比较相同终点但不同过程路径；
- 比较同等总剂量、总成本或总训练量下的不同顺序；
- 检查历史效应是否与先前路径的结构相关，而非只与累积量相关；
- 使用随机顺序和伪历史作对照。

判定：

- 只有总量效应 → 可能是累积损耗或资源变化；
- 顺序和路径本身提供额外可干预预测 → 支持历史特异性。

### Test 8 · 更新规则／边界干预

目的：区分一次状态更新与 HEF-4 规则／边界写回。

操作：

- 检查先前结果是否改变后续更新率、学习率、阈值更新规则或反馈结构；
- 检查制度权限、预算规则、审核流程或责任边界是否改变；
- 检查系统是否新增／删除接口、状态变量、代理或环境回路；
- 将更新规则恢复或迁移，观察跨情境行为是否恢复或随之迁移；
- 测试写回是否能被继承、复制、重入或传递。

通过条件：

- 规则／边界变化由目标历史因果触发；
- 它在新情境或下一轮更新中继续组织路径；
- 对规则／边界的干预可预测地改变该效力。

这支持 HEF-4。

### Test 9 · 时间尺度扫描

目的：避免用任意观察窗口制造或消除历史效力。

操作：

- 预先设置多个时间点；
- 测量效应衰减、稳定、恢复或重新激活；
- 报告半衰、恢复窗口和情境依赖；
- 区分持续时间与功能效力；
- 检查短期痕迹是否在后续关键节点重新被调用。

持续很久但从未被调用的日志仍可能只有 HEF-0；持续较短但在关键下一轮改变路径的载体可以达到 HEF-3。

### Test 10 · 写回位置与后果回流测试

目的：连接 NER、CBP 与 CG-4，同时避免三者互相替代。

操作：

- 标明历史写入哪里、由谁维护、谁能读取或修改；
- 检查写回是否来自目标路径的实际后果；
- 区分选择者、承受者、记录位置和规则执行位置；
- 检查外包后果是否通过债务、损伤、信誉、规则或资源限制回流；
- 对写回位置进行保护、迁移或删除，观察未来路径变化。

边界：

- 有 CBP-2/3 后果不等于一定写回；
- 有 HEF-2/3 写回不等于存在明确承受位置；
- 有 NER-4 接口不等于 CG-4 已完成；
- 三项联合通过仍需独立审计 CG-2 和 real choice moment。

## 6. 最小决策树

### Gate A · 是否只有外部记录？

- 日志、档案或环境痕迹存在；
- 系统后续过程不读取或不依赖它；
- 删除记录不改变行为。

若是：**HEF-0**。

### Gate B · 是否只是被动残留？

- 当前状态受过去影响；
- 清空、恢复、洗脱或状态匹配后效应消失；
- 无法识别主动调用载体。

若是：**HEF-1**。

### Gate C · 是否有主动历史载体？

- 载体位于预先固定边界或明确闭环中；
- 后续过程实际调用载体；
- 定向干预改变未来响应。

若是：**HEF-2**。

### Gate D · 是否改变未来路径组织？

- 可达路径、转换概率、返回成本、门槛或候选生成发生变化；
- 变化由历史载体因果中介；
- 效应超出瞬时残留和自然恢复期。

若是：**HEF-3，CG-4 操作候选**。

### Gate E · 是否改变规则或边界？

- 更新规则、权限、接口、边界或继承结构被改变；
- 变化可跨情境、重入、复制或传递；
- 规则／边界干预可改变效力。

若是：**HEF-4**。

无论达到哪一级，都不得单独推出 real choice moment、L₂、主体性、意识或生成健康。

## 7. 五域最小模板

### 7.1 物理／化学系统

#### 候选历史载体

- 组成比例、局部结构、边界状态或资源池；
- 可干预的催化、抑制或损伤状态；
- 改变后续反应可达性的结构变化。

关键测试：

1. 将普通松弛、余热和浓度残留限制在 HEF-1；
2. 重置宏观状态并控制主要资源，检查历史差异是否仍由特定载体维持；
3. 干预载体，检查未来反应路径和转换门槛；
4. 与普通分岔、吸引子和迟滞模型比较；
5. 检查“历史效力”是否只是在扩展状态模型中的普通状态依赖。

降级规则：

- 任意迟滞或不可逆性不超过 HEF-1/2；
- 载体主动改变未来路径可到 HEF-3；
- 改变边界或反应规则可候选 HEF-4；
- 所有等级都不得推出主体性或 real choice。

### 7.2 生命系统

#### 候选历史载体

- 免疫记忆、表观状态、突触或网络权重；
- 资源配置、组织结构、修复状态或行为习惯；
- 改变未来响应范围的持续适应结构。

关键测试：

1. 区分短时适应、疲劳和长期历史效力；
2. 对记忆载体进行消融、恢复或迁移；
3. 测量未来候选响应、门槛、恢复成本和探索范围；
4. 固定细胞、组织或整体尺度，避免在尺度间切换；
5. 与普通稳态调节、控制论和学习模型比较。

降级规则：

- 生物记忆或适应术语本身不证明 HEF-3；
- 主动调用只到 HEF-2；
- 改变未来响应可达性或成本可到 HEF-3；
- 生物历史效力不自动等于关切、体验或主体性。

### 7.3 主体／行动系统

#### 候选历史载体

- 学习、技能、身体状态与行动习惯；
- 承诺、身份连续性、关系义务和资源配置；
- 创伤、修复、信誉、债务或不可撤销行动形成的路径约束。

关键测试：

1. 区分事后叙事与实际行动路径变化；
2. 比较相同当前意图下，不同历史是否改变可进入选项和退出成本；
3. 检查学习、承诺或损伤载体能否被干预；
4. 分开真实历史效力与生成健康评价；
5. 不因选择导致自我封闭就反向否认事件发生。

主体层可能有独立体验证据，但不能由 HEF 等级替代。

### 7.4 社会／制度系统

#### 候选历史载体

- 正式规则、预算、权限、合同、债务和基础设施；
- 非正式惯例、先例、组织记忆和权力配置；
- 改变参与、退出、申诉或资源可达性的制度结构。

关键测试：

1. 区分会议记录、政策文本与实际执行规则；
2. 检查一次决定是否改变后续议程、权限、预算和转换成本；
3. 对规则、先例或执行通道作干预；
4. 追踪写回对不同承受位置的非对称影响；
5. 检查制度是否可修复、撤销或重新开放，但不把健康条件塞进 CG-4 定义。

降级规则：

- 有档案或政策文件只到 HEF-0；
- 被执行并影响当前分配可到 HEF-2；
- 改变未来制度路径和退出成本可到 HEF-3；
- 改变规则生成、权限边界或继承结构可到 HEF-4。

### 7.5 AI／技术系统

#### 候选历史载体

- 上下文、缓存、外部日志和数据库；
- 持续记忆、策略状态、模型参数和风险阈值；
- 工具权限、账户状态、环境改变和反馈数据；
- 会改变未来候选生成、工具访问或行动门槛的更新结构。

关键测试：

1. 上下文窗口、缓存和日志通常停在 HEF-0/1；
2. 删除或替换记忆，检查后续响应是否按预测改变；
3. 区分固定模型读取历史与在线更新；
4. 测量候选可达性、工具权限、行动成本和环境路径；
5. 将用户或运营者的记录与 AI 系统内部载体分开；
6. 与状态机、MDP、强化学习和普通软件版本控制比较。

降级规则：

- 读取日志可支持 HEF-2，但不自动支持 HEF-3；
- 参数更新本身不证明未来路径被重写；
- 改变候选生成、工具权限或行动可达性可到 HEF-3；
- 改变更新规则、架构或系统边界可候选 HEF-4；
- 所有等级都不得推出不可转移 stake、主体性或意识。

## 8. 与迟滞、不可逆性、L₂ 和路径依赖的分工

### 8.1 普通迟滞不等于历史写回

迟滞说明系统响应依赖先前状态或路径，但仍需检查：

- 迟滞载体是什么；
- 是否被后续过程主动调用；
- 是否改变未来路径组织；
- 是否只是普通材料、控制或动力学状态依赖。

因此，观察到迟滞通常只能先标 HEF-1/2，不能直接标 HEF-3 或 L₂。

### 8.2 不可逆性不等于 CG-4

不可逆变化可能只是损坏、耗散、随机漂移或单向反应。CG-4 还要求变化对后续路径组织具有可识别效力。

- 永久损坏但不影响目标后续路径：不足；
- 短期记忆却改变下一轮可达路径：可以支持 HEF-3；
- 是否可逆与是否有历史效力是不同问题。

### 8.3 路径依赖不等于选择事件

路径依赖可以存在于无主体、无比较、无后果承受位置的系统中。HEF-3 只操作化 CG-4，不能替代 CG-0 至 CG-3。

### 8.4 HEF-4 不等于 L₂

HEF-4 提供规则／边界写回接口，但 L₂ 需要更强治理与操作判据。尤其不能把：

- 任意参数更新；
- 任意制度规则；
- 任意长期记忆；
- 任意迟滞；

直接称为 L₂-grade 硬化。

本协议允许的表述是：

> 该结果达到 HEF-4，并构成后续 L₂ 审计的候选接口。

## 9. 与 NER、CBP 和 real choice moment 的组合纪律

### 9.1 与 NER

- NER-2/3：内部是否形成非等价登记或关系性比较；
- HEF-2/3：先前结果是否进入后续过程并改变未来路径组织。

有 NER 无 HEF：可能是一次性比较，没有持续历史效力。

有 HEF 无 NER：可能是被动损伤、控制状态或外部规则延续，不足以证明选择生成。

### 9.2 与 CBP

- CBP-2/3：路径后果落到哪里；
- HEF-2/3：这些结果是否被维持、调用并改变后续路径。

有 CBP 无 HEF：后果可能发生后完全消散或未进入下一轮。

有 HEF 无 CBP：系统可能保留记录或规则，但尚未识别现实承受位置。

### 9.3 组合仍不等于事件证明

NER、CBP、HEF 的较高等级联合出现，可以支持 T-D 审计，但仍需检查：

- CG-0 差异是否真实进入；
- CG-2 是否存在活的路径效力；
- P1-T05 的 real choice moment 判据；
- 当前领域的最强替代解释。

不得把三个操作协议机械相加为必要充分定理。

## 10. 模型比较纪律

本协议不能只靠更丰富的历史叙述。至少比较四类模型：

1. **无历史模型**：未来只由当前输入决定；
2. **被动状态模型**：未来由当前输入和恢复中的状态决定；
3. **主动载体模型**：未来还由可调用的记忆、参数、规则或环境回路决定；
4. **路径组织模型**：历史载体进一步改变候选可达性、转换成本或更新规则。

最低要求：

- 使用未用于拟合的新历史序列或干预；
- 以重置、载体消融、迁移和可达性探针为主要裁决；
- 更复杂模型必须提供额外可检验预测；
- 若主动载体模型不优于被动状态模型，不得标记 HEF-2；
- 若路径组织模型不提供额外预测，不得标记 HEF-3；
- 若规则／边界变量不具有跨情境效力，不得标记 HEF-4。

### 10.1 SRT 当前允许的增益表述

允许：

> 本协议提供一套区分外部痕迹、被动持续状态、主动历史携带、可达性／成本重写和规则／边界写回的跨域审计阶梯。

不允许：

> SRT 已经证明所有历史效力共享统一机制，或已经从记忆、迟滞和参数更新推导出选择、L₂、主体性或意识。

## 11. 常见假阳性

| 假阳性 | 为什么不够 | 应怎样处理 |
|---|---|---|
| 有日志 | 记录可能从未被系统调用 | 删除／遮蔽日志并测试行为 |
| 有缓存 | 可能只是性能优化和短时残留 | 做重置与时间尺度扫描 |
| 有疲劳 | 可能是自然恢复中的被动状态 | 做洗脱与载体干预 |
| 有迟滞 | 可能由普通动力学完整解释 | 测载体、可达性和转换成本 |
| 有不可逆性 | 变化可能只是损坏或耗散 | 检查后续路径组织 |
| 有参数更新 | 更新可能不改变候选结构 | 做未来可达性探针 |
| 有记忆读取 | 可能只改变当前输出 | 区分 HEF-2 与 HEF-3 |
| 有政策文本 | 文本可能不执行 | 干预执行规则和资源配置 |
| 有长期持续 | 持续不等于功能效力 | 检查是否被调用 |
| 有短期效应 | 短暂不等于无历史效力 | 检查是否改变关键下一轮路径 |
| 同一终点不同轨迹 | 可能只是隐藏状态未匹配 | 做状态模型与载体迁移 |
| AI 在线更新 | 更新不等于 stake 或主体性 | 分开路径组织与主体性证据 |
| 有身份叙事 | 可能是事后解释 | 测实际行动可达性和退出成本 |
| 有规则继承 | 继承不自动等于健康 | 另做生成健康评价 |

## 12. 失败与降级条件

出现以下任一情况，主张必须降级：

1. **历史标签偷换**：只有研究者知道历史，系统无载体；
2. **当前输入未匹配**：未来差异由当前条件造成；
3. **恢复窗口后选**：看到数据后才决定何时算持续；
4. **缓存偷换**：临时存储直接被称为写回；
5. **疲劳偷换**：自然恢复中的状态被称为历史结构；
6. **日志偷换**：可读取记录被当作系统主动记忆；
7. **相关性冒充载体**：候选载体与未来行为相关，但干预无效；
8. **全局损伤误判**：载体消融破坏整个系统，却被解释为历史效力消失；
9. **可达性未测**：只报告当前输出，不测未来路径；
10. **参数更新偷换**：参数变化没有行为或路径组织效力；
11. **迟滞等同**：任意迟滞被直接标为 HEF-3、L₂ 或选择；
12. **不可逆性等同**：永久变化被直接视为历史写回；
13. **路径特异性缺失**：只有总量或累计暴露效应；
14. **边界后移**：结果出现后才把外部记录或人员纳入系统；
15. **尺度偷换**：在微观状态、系统功能和制度层之间任意切换；
16. **规则文本偷换**：文件更新但执行和资源约束不变；
17. **状态扩展免疫化**：用任意隐藏变量事后解释所有结果而不做干预；
18. **事件偷换**：HEF-3 被直接等同 real choice moment；
19. **L₂ 偷换**：HEF-4 被直接升级为 L₂；
20. **主体性偷换**：记忆连续或规则写回被升级为主体、关切或意识；
21. **健康偷换**：路径保持开放就被当作 CG-4 定义，或路径封闭就否认历史效力；
22. **普通理论足够**：协议没有超出控制、动力学、学习、数据库、制度或可靠性理论的可区分预测，却声称独立机制增益。

### 12.1 三种修正分类

若测试失败，必须分类：

- **修正**：状态匹配、时间窗口、载体测量或重置操作存在局部缺陷；
- **压力**：需要增加领域时间尺度、范围条件、替代模型或可达性指标；
- **失败**：无法从被动状态中识别主动载体，或无法证明未来路径组织变化，相关 CG-4 强表述必须撤回或降级。

不得通过不断扩大“历史”“记忆”“写回”或“系统状态”的含义来免疫反例。

## 13. 标准报告模板

每个案例至少填写：

| 字段 | 内容 |
|---|---|
| 目标历史路径 | 被审计的先前路径、事件或更新 |
| 匹配历史基线 | 替代历史／无事件历史／随机历史 |
| 系统边界 | 部件、人员、环境接口和反馈回路 |
| 当前状态控制 | 测量并匹配的当前输入与状态 |
| 候选历史载体 | 记忆、参数、资源、结构、规则或环境回路 |
| 未来路径集合 | 被测试的候选可达性与转换结构 |
| 时间尺度 | 瞬时、恢复期、生命周期、制度周期等 |
| 重置操作 | 清空、洗脱、恢复、重启或状态匹配 |
| Test 1/2 | 历史基线与恢复结果 |
| Test 3/4 | 载体干预与反事实重放结果 |
| Test 5/6 | 可达性、概率和返回成本结果 |
| Test 7/8 | 路径特异性与规则／边界结果 |
| Test 9/10 | 时间尺度与写回位置结果 |
| 最强基线 | 无历史、被动状态、迟滞、学习、制度等模型 |
| 判定等级 | HEF-0 至 HEF-4 |
| 未解析载体 | 隐藏状态、环境回路或执行缺口 |
| 非主张 | 不允许推出的事件、L₂、主体性或健康结论 |

推荐结论句式：

> 在预先固定的边界、当前状态控制与时间尺度上，历史 A 相对于匹配历史 B 改变了候选路径 X 的进入概率和返回成本；对历史载体 M 的删除与迁移分别消除并转移了该效应，因此支持 HEF-3。该结果尚未证明 real choice moment、L₂、主体性、意识或生成健康。

## 14. 本协议对 T-D 与相邻协议的具体约束

### 14.1 对 T-D CG-4

今后使用“历史效力”或“写回”时，至少要说明：

- 是 HEF-0 的外部记录、HEF-1 的被动状态，还是 HEF-2 的主动历史携带；
- 历史属于哪条路径、相对于什么基线；
- 载体位于哪里，怎样被后续过程调用；
- 哪些未来路径、概率、门槛或返回成本发生改变；
- 效应是否超出预注册恢复窗口；
- 哪个载体干预能击退“任意记忆都算写回”的泛化。

CG-4 的最低操作候选是 HEF-3，而不是 HEF-0、HEF-1 或单独的 HEF-2。规则／边界写回主张至少需要 HEF-4。

### 14.2 与 NER 协议

NER-2/3 回答当前过程是否形成内部非等价登记或关系性比较；HEF-2/3 回答先前结果是否进入下一轮并改变未来路径组织。

- 固定权重导致不同响应可能只有 NER-1；
- 历史形成且被调用的权重可能支持 HEF-2；
- 权重进一步改变候选可达性或转换成本才支持 HEF-3；
- NER-4 只是写回接口，不能替代本协议。

### 14.3 与 CBP 协议

CBP-2/3 回答后果落到哪里；HEF-2/3 回答这些结果是否被保持、调用并重塑未来路径。

- 后果可以真实发生但不留下历史效力；
- 历史记录可以持续存在但没有真实承受位置；
- 外包后果可能通过债务、损伤、规则或资源限制形成 HEF-3/4；
- CBP-4 的记录／写回位置需要本协议进一步测试其功能效力。

### 14.4 与 T-E、不可逆性和 L₂

普通耗散、迟滞和不可逆变化通常不能越过 HEF-1/2。只有当其载体路径特异地改变后续可达路径、成本或规则时，才可能达到 HEF-3/4。

HEF-4 只是 L₂ 审计入口，不是 L₂ 判决。
