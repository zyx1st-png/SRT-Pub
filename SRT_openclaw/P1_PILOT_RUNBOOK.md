# P1 Pilot Runbook（E1/E2 可执行步骤）

更新时间：2026-03-01
适用：E1(A7), E2(A11)

## 0) 开跑前（T-1天）
1. 确认实验脚本与任务参数冻结（版本号记录）。
2. 准备被试招募表与知情同意文本。
3. 检查数据落盘路径与匿名ID规则。
4. 试跑 2 人次（内部）验证日志完整性。

## 1) 当天执行流程（单场）
- 00:00-00:10 签署同意 + 基线问卷
- 00:10-00:15 任务说明 + 练习 trial
- 00:15-00:35 E1 正式任务（含短休）
- 00:35-00:55 E2 正式任务（含短休）
- 00:55-01:00 主观负担与退出访谈

## 2) 数据落盘与命名
- 主目录：`data/p1_pilot/`
- 文件命名：`{task}_{participant_id}_{session_id}.csv`
- 元数据：同名 `.json` 存参数与设备信息

## 3) 每日收尾
1. 跑 `P1_QC_CHECKLIST.md` 所列检查项。
2. 生成当日 QC 摘要（pass/warn/fail）。
3. 记录异常与处理决定（不可补记数据）。

## 4) 最小样本目标
- E1：先到 N=20 做中期检查；N=40 完成首轮判定。
- E2：先到 N=24 看阈值趋势；N=45 完成首轮判定。

## 5) 中期停/走规则
- 若前 20 例出现系统性设备问题（>15% fail），暂停采集先修流程。
- 若效应方向与假设完全反向且置信区间稳定，允许提前进入“反证总结”。

## 6) 交付
- `pilot_qc_summary.md`
- `pilot_stats_snapshot.ipynb`（或同等报告）
- 与预注册对照的偏差说明（如有）
