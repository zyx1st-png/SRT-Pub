# E1 预注册草案（A7 / 适应度优先）

更新时间：2026-03-01
状态：Draft v1

## 0. 基本信息
- 假设编号：H-A7-MVP
- 关联公理：Ax-Core-A7
- 研究问题：高风险条件下，系统是否优先采取“可行动但较低精度”的策略？
- 类型：行为 + 生理（可选）

## 1. 可证伪陈述
- 主陈述：风险升高将显著提升速度优先倾向（Accuracy-RT 权衡斜率向 RT 侧偏移）。
- 反证条件：高风险条件下持续出现精度优先，且在独立样本中复现。

## 2. 样本与分组
- 样本量目标：N=40（组内设计，pilot）
- 纳入：18-45岁，正常视力或矫正正常
- 排除：急性精神/神经疾病、无法完成任务
- 分组方式：组内双条件（低风险/高风险，顺序平衡）

## 3. 变量定义
- IV：风险条件（低/高）
- DV：
  - 正确率（Accuracy）
  - 反应时（RT）
  - 权衡斜率（Speed-Accuracy tradeoff index）
- 协变量：睡眠时长、咖啡因摄入、基线焦虑评分
- 理论映射：
  - d/Ψ_f 联合 proxy：在高风险下，系统优先保障可行动性

## 4. 协议
- A 基线：练习 20 trial + 基线问卷
- B 任务：
  - 低风险 block（80 trial）
  - 高风险 block（80 trial）
  - 顺序随机或对半平衡
- C 追踪：任务后主观负担评分
- QC：
  - 注意力检查题
  - RT < 150ms 或 > 3SD 剔除规则预先声明

## 5. 统计计划
- 主模型：线性混合模型（Condition -> tradeoff index）
- 次模型：Condition 对 Accuracy/RT 的主效应
- 校正：FDR
- 缺失：按 trial 级别剔除异常，不做插补
- 稳健性：删去高焦虑亚组重复分析

## 6. 结果判定
- 支持：高风险条件下 tradeoff index 显著向速度侧偏移
- 不支持：方向相反或效应接近 0
- 不确定：方向一致但置信区间跨 0

## 7. 伦理与数据
- 风险：低
- 保护：可随时退出，匿名编码
- 隐私：去标识化，最小化采集
