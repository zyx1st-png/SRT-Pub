# E2 预注册草案（A11 / 本体论脆弱性）

更新时间：2026-03-01
状态：Draft v1

## 0. 基本信息
- 假设编号：H-A11-MVP
- 关联公理：Ax-Core-A11
- 研究问题：随负荷提升，系统稳定性是否出现阈值性下降？
- 类型：行为 + 主观生理 proxy

## 1. 可证伪陈述
- 主陈述：负荷从低到高将引发非线性失稳（错误爆发率与恢复时间在高负荷区突增）。
- 反证条件：负荷上升不引发阈值变化，或仅线性微弱变化且不可复现。

## 2. 样本与分组
- 样本量目标：N=45
- 纳入/排除：同 E1
- 分组方式：组内三级负荷（低/中/高）

## 3. 变量定义
- IV：负荷等级（低/中/高）
- DV：
  - 错误爆发率（error burst rate）
  - 恢复时间（recovery latency）
- 协变量：睡眠、情绪基线、任务熟悉度
- proxy：主观负担评分（0-10）

## 4. 协议
- A 基线：练习 + 基线评分
- B 任务：三级负荷任务，每级 60-80 trial，顺序平衡
- C 追踪：每级后负担评分
- QC：
  - 连续漏答阈值剔除
  - 设备或记录异常日志

## 5. 统计计划
- 主模型：分段回归 / GAM 检测阈值点
- 次模型：重复测量 ANOVA（对照）
- 校正：FDR
- 缺失处理：按预设规则剔除缺失段
- 稳健性：按基线能力分层复验

## 6. 结果判定
- 支持：出现稳定可复现的临界负荷点
- 不支持：不存在阈值，仅噪声波动
- 不确定：阈值位置不稳定

## 7. 伦理与数据
- 风险：低到中（认知疲劳）
- 保护：可中途休息/退出
- 隐私：匿名编码
