# 采集重启触发条件清单（Restart Trigger Checklist）

更新时间：2026-03-01

满足以下任一组条件即可重启采集：

## 组A（资源就绪）
- [ ] 可用被试来源已确认（至少可达 N=20）
- [ ] 试验时间窗已确定（连续 3-5 天）
- [ ] 设备/记录路径已自检通过

## 组B（理论驱动）
- [ ] 出现新的可复现反例或冲突证据
- [ ] 对 A7/A11 阈值条款完成更新并需验证

## 组C（协作驱动）
- [ ] 有外部协作者愿意共同执行并复现
- [ ] 预注册平台与代码仓库已准备

重启后第一步：按 `P1_STARTUP_CHECKLIST.md` 执行 T0。
