## 2. The simplest SRT path

SRT can be compressed into one loop:

```text
L0: possible but not yet manifest
  ↓ selected by Ĝθ, with Ψf cost
L1: currently manifest slice
  ↓ repeated and stabilized
L2: norms, habits, patterns, institutions, laws
  ↓ constrains future selection
Ĝθ selects again
```

One-sentence version:

> SRT says that reality is not first a pile of objects, but a process in which possibilities are selected, manifested, and then hardened into constraints.

## 4. What not to overread

SRT has many bridge files. They are useful, but they are not all core claims.

| File type | How to read it |
|---|---|
| `Core_Law/` | closest to canonical foundations |
| `Core/` | core, formal, or bridge-hardening depending on file |
| `AI/`, `Physics/`, `Neuroscience/` | domain interfaces |
| `Annex/` folders | non-canonical comparison / interface material |
| `Operations/` | workflow records, not theory |
| `_SRT_INDEX.md` | machine index, not public essay |
| `_SRT_SYMBOL_TABLE.md` | symbol registry, not introduction |

When in doubt, follow this rule:

> A bridge file explains how SRT connects to another field; it does not automatically become SRT's foundation.

## 6. Minimal caution for public readers

SRT is not claiming:

- everything is merely subjective;
- consciousness magically creates the universe;
- every attractor is conscious;
- entropy production equals consciousness;
- AI role stability equals moral patienthood;
- physics has already been replaced by SRT.

SRT's stronger and safer claim is:

> What becomes real for a system depends on how possibilities are selected, paid for, anchored, and stabilized across time.
