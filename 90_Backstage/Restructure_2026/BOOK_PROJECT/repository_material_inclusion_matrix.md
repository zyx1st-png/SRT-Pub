# 《从存在到秩序》仓库内容纳入矩阵

> 目的：把仓库中已有材料与《从存在到秩序》的写作范围建立关系。
>
> 本文件不决定理论真伪，也不替代章节大纲。它只回答一个写作工程问题：仓库已有材料哪些应进入本书主线，哪些只作为影子，哪些应留给 formal / bridge / EC / public layer，哪些应暂时排除。
>
> 重要原则：本书不能只是仓库已有内容的重排。仓库本身仍有未闭合、未充分发展、未经过 founder pass 的部分。因此，本矩阵同时保留“待发展空间”，用于标记：某些章节从全书结构上必须存在，但仓库材料尚不足，需要在正式写作时继续生成、补证或重构。

---

## 0. 四类纳入方式

| 类别 | 含义 | 写作处理 |
|---|---|---|
| A. 主线纳入 | 必须进入《从存在到秩序》正文主干 | 用哲学书语言重写，不照搬 canonical / notes |
| B. 影子纳入 | 可作为问题意识、隐喻、边界护栏、桥接暗线 | 只轻触，不展开成综述或技术论证 |
| C. 后续层归属 | 不适合进入本书正文，应进入 formal / bridge / EC / public layer | 在本书中最多留一句“后续层展开” |
| D. 暂不纳入 | 会污染本书文体或偏离书本目标 | 不进入本书，只保留在仓库其他区域 |
| E. 待发展空间 | 全书结构需要，但仓库材料尚不足或未闭合 | 保留章节方向；正式写作时补充新论述、新例子、新桥接 |

## 1. L0 / ε_pg / floor replacement 家族

**仓库内容类型**：L0 metaphysics、ε_pg、κ₀、floor replacement、anti-self-erasure、subjectless selection。

**纳入方式**：A 主线纳入。

**进入章节**：

- 第 1 章：现实不是先给定的
- 第 2 章：L0 不是虚无
- 第 3 章：ε_pg：L0 的最小非中立性
- 第 50 章：SRT 可能错在哪里

**正文处理**：

- L0 写成“未对象化的可成为性”，但避免实体化、神秘化、系统私有化。
- ε_pg 写成“L0 的最小非零不对称 / 原初梯度”，但不写成目的、善、物理力或意识。
- floor replacement 写成全书地板替换动作，不写成治理口号。

**不进入正文的部分**：

- ε_pg 的严格符号系统。
- κ₀ / κ(t) 的完整内部形式化。
- 与 P0 claim ladder 的详细治理说明。

**待发展空间**：

- 需要继续补强 ε_pg 与“非自我抹除”的关系：正文可读性已够，但严格层仍需说明它如何依赖不可逆性与接续条件。
- 第 3 章的哲学防御仍可继续发展：幸存者偏差、同义反复、对称性破缺、亚里士多德潜能、fine-tuning 等边界需要保持精细。

## 19. 结论：本书与仓库的关系

《从存在到秩序》不是仓库内容的汇编。

它也不是脱离仓库重新写一本书。

它应当承担三件事：

1. **从仓库中提取已经硬化的 founder intuition 和核心概念。**
2. **把仓库中暂时过技术、过治理、过桥接的内容，转译成哲学书可承重的语义地板。**
3. **为仓库尚未闭合但全书结构必须面对的问题，预留新的写作空间。**

因此，后续写作每章都应同时问四个问题：

```text
这章要回收仓库中哪些内容？
这章要避免被仓库中哪些技术内容污染？
这章需要补充仓库还没有充分发展的什么？
这章写完后，应该让哪些后续 formal / bridge / EC / public 文件回引它？
```

最后一条护栏：

> 不要让仓库决定书的全部形状；也不要让书切断仓库已经积累的硬内容。二者之间要保持可回流关系。
