# Chapter 6 v3 Refinement Notes

> Purpose: record the v2 → v3 refinement suggestions and how they were applied without overwriting the merged v2 chapter directly.

---

## 1. Review diagnosis accepted

The v2 chapter is structurally sound, but the review identified six useful refinements:

1. §6 / §7 scaffold-cage distinction is strong but too clean.
2. §8 L2 examples are too long as a flat list.
3. “关切维度” appears too suddenly in §9.
4. §3 repeats the “至少包含三件事” framework used in chapter 5.
5. §7 uses four short examples that repeat the same function instead of deepening the argument.
6. §9 repeats “稳定不等于正当” too much before arriving at the new contribution: consequence return.

The v3 candidate applies these as a refinement, not a rewrite.

---

## 2. Applied to chapter 6 v3 candidate

### 2.1 §1 deeper phenomenological entrance

V3 expands the “key fails to open the door” scene into a more immersive passage:

> 你站在门口，手里拿着那把一直能开的钥匙。你先以为是自己没对准，又拧一次，再拧一次。门没有开。

Function: gives order-failure visibility more interiority rather than only observer description.

### 2.2 §3 de-templatized the triple framework

V3 replaces the formulaic:

> 秩序至少包含三件事。第一……第二……第三……

with a processual section:

- an anchor must be able to be taken up again;
- it must be shareable across positions;
- it must become background.

Function: preserves 可继承 / 可共享 / 背景化 while reducing the repeated “three-part framework” fatigue from chapters 5–6.

### 2.3 §6 / §7 scaffold-cage complexity

V3 renames §6 to:

> 脚手架与牢笼不是两类物体

and adds:

> 同一个秩序，可能对一部分人是脚手架，对另一部分人是牢笼；在某个阶段是脚手架，在另一个阶段变成牢笼；在某个任务上降低从零开始的成本，在另一个更深层面提高重新选择的成本。

Function: adds social-philosophical thickness and prevents a too-clean binary.

### 2.4 §7 replaces four shallow examples with one deeper institution example

V3 removes the short list:

- addiction loop;
- organizational process;
- social institution;
- AI agent system.

It develops a single institutional example:

- institution begins as a scaffold for uncertainty;
- it matures through procedures, metrics, roles, budgets;
- it becomes cage-like when exceptions can only be treated as non-compliance and feedback is absorbed by old metrics.

Function: makes §7 argumentative instead of illustrative.

### 2.5 §8 L2 examples grouped

V3 groups L2 examples into three clusters:

1. 身体与认知: habits, language, posture, professional training, perceptual format.
2. 制度与技术: family rules, law, standards, platform defaults, monetary metrics, infrastructure.
3. 身份与关系: identity narrative, aesthetics, gaze of others, fixed self-interpretation.

Function: keeps breadth while improving readability.

### 2.6 §9 starts from consequence return

V3 compresses the repeated “稳定不等于正当” principle and moves directly to the new contribution:

> 如果一个秩序确实已经稳定、已经真实、已经很难被绕开，那么判断它是否健康，应当看哪里？

Then uses consequence return and rule-rewriting channels as the main criterion.

### 2.7 §9 softens concern-dimension reference

V3 changes the sudden “关切维度” reference into:

> 后面会展开的关切维度问题

Function: marks it as a future anchor rather than requiring reader familiarity now.
