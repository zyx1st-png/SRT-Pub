## 7. 虚轴类比的进一步可用方向

> 以下不是都要进入正文。建议分为正文可用、后台可用、慎用三类。核心原则：虚轴类比只能帮助读者理解 L0 的非对象本体论地位，不能变成新的数学化 SRT 模型。

### 7.1 坐标系扩展：从实轴到复平面

**可用等级：正文可用，Q03 主用。**

数学中，虚数的意义不是“补充一个奇怪的数”，而是迫使数系从一维实轴扩展为二维复平面。某些在实轴上无解的问题，只有扩展坐标系后才可表达。

对应 SRT：对象 / 虚无二分等于只允许“对象化实轴”。L0 的引入不是在实轴上添加隐藏对象，而是扩展存在论坐标系，让“尚未对象化但真实”的维度可被承认。

可用句：

```text
L0 不是实轴上多出的一个点，而是迫使存在论坐标系从对象实轴扩展为前对象平面的那条虚轴。
```

风险：不要写成“存在真的有一个二维数学平面”。这是类比，不是形式本体论。

### 7.2 不可还原维度：虚轴不在实轴上

**可用等级：正文可用，Q03 / Q04 回扣可用。**

虚数不是实数轴上尚未发现的点。它不能被还原为实轴内部的一项。

对应 SRT：L0 不是对象世界背后的微小对象，也不是更底层的物理粒子。它不在对象化实轴内部，而是对象化实轴得以成立的前对象维度。

可用句：

```text
把 L0 当成隐藏对象，就像在实轴上寻找 i：找不到不是因为它不存在，而是因为你使用的坐标系已经错了。
```

### 7.3 投影：只看实部会丢失虚轴信息

**可用等级：后台可用；正文慎用。**

复数可以投影到实轴，只保留实部。但投影会丢掉虚部信息。两个复数可以有相同实部，却有不同虚部，因而在后续运算中表现完全不同。

对应 SRT：对象化现实像“投影到实轴后的结果”。只看已对象化结果，会误以为两个对象处于同一现实位置；但它们背后的前对象张力、可成为性、未被对象化的残余不同，后续生成路径会不同。

可连接章节：

```text
Q06 排除与阴影
Q07 锚定
Q09 现实厚度
Q11 被选择
```

可用方向：被排除者不是“无”，更像投影时丢失的虚部；它不在实轴显现，却继续改变后续变换。

风险：不要说“阴影 = 虚部”。只能说“投影丢失信息”的形式相似。

### 7.4 乘以 i：不是添加内容，而是发生轴向旋转

**可用等级：后台可用；Q05 慎用。**

在复平面中，乘以 `i` 相当于旋转 90 度。它不是给数增加一个普通量，而是改变其所在方向。

对应 SRT：对象化不是给前对象内容贴标签，而是一次轴向转换：可成为性被旋转 / 转换到对象化实轴上，成为可指认、可重复遭遇、可承重的对象格式。

可连接章节：

```text
Q05 选择不是挑选
```

可用句候选：

```text
对象化不是给 L0 增加一个名字，而是把前对象张力转入对象化坐标的变换。
```

风险：乘以 i 的旋转太数学化，不建议进大众正文；可作为后台理解“选择不是挑选，而是格式转换”的辅助类比。

### 7.5 解域扩张：无解不是问题不存在，而是域太窄

**可用等级：正文可用，Q03 / 强对手回应可用。**

方程 `x^2 + 1 = 0` 在实数域无解，但不是因为问题荒谬，而是实数域太窄；扩展到复数域后，解出现了。

对应 SRT：旧地板问“对象之前是什么”，在“对象 / 虚无”两值域里无解。不是问题错了，而是存在论域太窄。L0 的引入扩展了解域。

可用句：

```text
“对象之前是什么”在对象 / 虚无二值域中无解，不是因为问题无意义，而是因为旧存在论的定义域太窄。
```

风险：不要把 L0 写成“方程的解”，而应写成“扩展定义域后才可表达的位置”。

### 7.6 模长与相位：现实强度不等于实轴显眼程度

**可用等级：后台可用；Q09 慎用。**

复数的大小不能只看实部，还要看模长与相位。同样实部的复数，可能有不同模长与相位，后续动态不同。

对应 SRT：现实厚度不能只看对象化强度、感知强度、共识强度或出现频率。一个东西在实轴上很显眼，不代表它厚；一个东西暂时不显眼，也可能有深层可成为性张力或后续承重潜力。

可连接章节：

```text
Q09 现实厚度
Q14 价值不是偏好
```

可用方向：现实厚度不是“实轴显眼程度”，而是后续承重、支付、再入场的结构结果。

风险：不要引入模长公式，不要把厚度形式化为复数模长。

### 7.7 共轭：同一对象化实部可能携带相反的前对象取向

**可用等级：后台可用；慎用。**

复共轭具有相同实部、相反虚部。形式上，它提示：两个显现可以在对象化层面看起来相同，却携带相反的生成取向。

对应 SRT：两个制度、承诺、工具或 AI 系统在表面功能上相同，但一个扩展再选择，另一个替代再选择。实轴表现相似，虚轴取向相反。

可连接章节：

```text
Q19 脚手架与牢笼
Q24 AI
Q27 理论自反
```

可用方向：脚手架与牢笼可能在表面功能上相同，差别不在实轴功能，而在它们对未来可成为性的取向。

风险：这个类比较精巧，正文中容易显得炫技，建议留后台。

### 7.8 解析延拓：沿着旧域边界继续，抵达新域

**可用等级：后台可用；Q26 / 理论自反可用。**

解析延拓不是随意发明新函数，而是在已有结构约束下把函数扩展到原来定义域之外。

对应 SRT：SRT 不是任意发明 L0，而是沿着旧地板的问题边界——给定感、对象化、虚无 / 仓库二分——被迫延展到前对象域。L0 不是任意加法，而是问题链的延拓。

可连接章节：

```text
Q03 L0 正当性
Q26 可证伪性
Q27 理论自反
```

风险：解析延拓过于技术性，不适合主文，可作为作者后台自检。

### 7.9 虚部不直接可见，但参与运算

**可用等级：正文可用但需短。**

在某些实数结果中，虚部可能不直接出现在最终实值结果里，但中间计算若没有复数会无法完成。

对应 SRT：L0 不以对象形式出现在最后结果中，但对象化、选择、锚定、厚度等过程若没有前对象维度就无法完整说明。

可用句：

```text
L0 不一定作为对象出现在结果里，但它参与了对象能够成为结果的过程。
```
