# Historical Knowledge Reentry｜公开研究入口

这里保存历史笔记研究的**筛选后非 canonical 副本**。它不属于 SRT-Pub 的定义 owner，不改变 canonical、正式研究主线或历史原句。私有档案中的原文、UID、家族哈希、精确来源定位和作者逐字回答没有随本目录公开。

## 进度与目录

- H1 首批：34 条私有原文定位知识条目、17 条分级关系；本目录公开其中 24 条 H1 释义和 3 条作者恢复释义，共 27 条，另有 11 条筛选关系。数量是研究记录数，不是独立理论数。
- H2 队列：64 条 Beacon，8 组各 8 条。B01「记忆与学习」已有作者补全；B02「时间与变化」进行中；B03–B08 待开始。
- [`knowledge_items_public.jsonl`](knowledge_items_public.jsonl)：公开条目，只有释义和证据状态。
- [`relations_public.jsonl`](relations_public.jsonl)：公开关系，显式区分 H 同文支持与 I 候选。
- [`CONCEPTS_AND_BEACON.md`](CONCEPTS_AND_BEACON.md)：历史概念线索与 Beacon 方法。
- [`SRT_COMPARISON_QUESTIONS.md`](SRT_COMPARISON_QUESTIONS.md)：可能关联当前 SRT 的待核问题，不预设差异成立。
- [`MOBILE_CONTINUE.md`](MOBILE_CONTINUE.md)：移动端续谈入口与增量更新步骤。

## 证据标记

- **H**：私有档案里可核对的历史原文。公开版只给经过筛选的**释义**，不把释义冒充引文。
- **A**：作者今天明确回忆的当年意思；不证明旧笔记已写出完整论证。
- **N**：作者今天提出的主张、例子或解释方式。
- **I**：AI 的问题提炼、关系候选或解释。
- **U**：仍未知、未核或无法恢复。

公开编号 `HK…` / `AR-…` 是跨仓库追溯键；对应私有知识条目及 UID 的表只在历史档案私有仓库。公开关系只在其标明的证据范围内成立，词语相似不构成历史演化链。研究时间以来源可见时间为限，不推定首次形成时间。

## 同步边界

私有仓库保存 H1/H2 已整理的工作副本，公开仓库保存人工筛选的释义。两层可以互相索引；任何公开解释都不能反向修改 H。新的作者回答先进入私有 H/A/N/I/U 记录，再决定是否追加公开释义。未经核实的历史联系保持 `I/U`。本目录不上传原始档案、原始 Beacon 文本、私人路径、凭据、财务材料或封存样本。
