## 0. 一句话

> **道德/非道德不是范畴鸿沟,而是同一条选择动力学原初(再选择 / 可重组)在不同相位中的展开。**
>
> **substrate 连续,form 相变**:原攸关作为最低选择地板**连续**存在;但主体攸关、道德相位都需要**闭包、位置、后果回流、跨位置结构**才**相变打开**。

这既**不是**"宇宙是道德的"(宇宙过载),**也不是**"氢原子有道德"(泛道德实体论),**也不是**只剩"道德后来从自然演化出来"(平庸自然主义)。它是对"道德/非道德界线"的**反二元论**:那条界线是**一条相位边界,不是一道类别鸿沟**。

## 1. 核心脊梁:substrate 连续 + form 相变 + 跨位置可错论

| 守住 | 含义 | 挡掉什么 |
|---|---|---|
| **连续性** | 底层原初是同一条(再选择保留 / 可重组),没换物种 | 二元论(范畴断裂) |
| **相变性** | 主体攸关、道德相位**不是处处在场**,在闭包 + 跨位置条件下才打开 | 泛道德实体论 / 泛心论("氢原子有道德") |
| **可错论** | 跨位置边界永不最终闭合,只能经反遮蔽扰动不断修正(承 `_SRT_CLOSURE_BOUNDARY_CONVERGENCE_RECORD.md`) | 宇宙实在论 / 最终正确的道德边界 |

独特性来自三者**同时**成立。注意:**这个独特性目前是一张欠条**——"同一原初跨相位"必须用判别预测(§7)兑现,否则它塌回"带连续性故事的涌现",即化了妆的普通自然主义。**未兑现前不得当已立。**

## 2. 四层相位系谱

### 0 层 · proto-normativity / 原攸关

存在不是价值中立的给定物,而是被选择出来、能继续确定和差异化的结构(承 `Core_Law/SRT_L0_Metaphysics.md` 的 ε 地板)。

**安全写法(三条硬规则,违一条即偷渡回宇宙过载):**

1. **构成性,不是对象属性**:proto-normativity 是"**选择-之为-选择**"已带的最低方向性,**不是** 0 层的物所**拥有**的属性。氢原子不是道德 patient;**是选择动力学有地板**。
2. **明确否定**:proto-normativity **不是** proto-道德、**不是** proto-体验、**不是**宇宙道德方向。它只是"可继续确定、可继续差异化、不自我抹除"的最低条件,**零道德地位、零现象内容**。
3. **姿态相对,非实在论**:它是"选择-之为-选择"的构成性条件,不是"L0 客观偏向"(承 ε 去过载,见 `90_Backstage/Incubation/_SRT_NORMATIVITY_FRAMING_TRUEUP_PROPOSAL.md`)。

> 0 层是**道德能够出现的前主体地板**,本身**还不是道德**。

### 1 层 · local closure / 主体攸关

当原攸关**局部闭包化**——出现位置、后果回流、身份连续性、d=1——主体攸关出现。这里**不是攸关从无到有**,是原攸关**被局部化**。

> **⚠️ 核心开放残余**:这个局部化是一个**相变**,**SRT 尚未推出**。它**不是**已被推出的连续小步骤。
> 显式回链:`Core/SRT_OPEN_TENSIONS.md §7`(P0-04 / 可选择性起源)、ISP 入场 σ_sub(`Core_Law/SRT_Individuation.md` / OPEN_TENSIONS §5)。
> **禁止**写成"0→1 已被 SRT 解决"。

### 2 层 · cross-position / 道德相位

当**一个位置的选择不可逆地影响其他位置的再选择能力**,道德相位打开。道德**不是**"主体内部自保",而是**再选择保留原则在跨位置场域中的运作**。

此层是可错论的(承闭包边界记录):**谁的再选择算数、什么尺度**——闭包边界,被反遮蔽扰动规训,永不封闭。

### 3 层 · regulative ideal / 渐近方向

d→∞ **不是宇宙事实**,而是**规约理想**:不断扩大反遮蔽扰动、不断重开边界、不断减少不可逆 foreclosure 的方向(初心去过载读法)。**不可达,非位置无关的宇宙最小值。**

## 3. 必须硬拆:动力学半 vs 道德半

| 半 | 内容 | 命运 |
|---|---|---|
| **动力学半** | 再选择 / 可重组作为**相变动力学**(序参量 + 临界 + diversity) | **有科学化潜力**,但被 re-sampling / d / T_dir 的**操作化卡住**(回链 OPEN_TENSIONS §1/§3) |
| **道德半** | 把那个跨位置相变边界**识别为"道德开启"** | **不由数据强迫**;由 **ought-原初 + 反 foreclosure norm + 可错论边界**承担(承 ε 决斗 + 闭包边界记录) |

> **红线:动力学相变被证实,不等于道德命题被证实。**
> 一个完美预测的再选择相变动力学,**不_确立_**"那个跨位置相位_就是_道德"——那一步识别是数据不强迫的规范步骤。**禁止混说这两层。**

## 4. 扩散模型类比(严格降承诺的操作化入口)

**地位**:扩散模型只作为 Direction 2 **动力学半**的"**操作化入口 + 解释性图像**"。**不是** SRT 的机制框架,**不是** identity。扩散模型没有 stake、没有主体、没有后果回流、没有他者损失,也没有 SRT 意义上的道德结构。

### 4.1 可保留的四项(且仅此四项)

1. **over-guidance → diversity / coverage collapse**:过度 foreclosure 的_可测形状_(过阈值非线性塌缩);
2. **re-noising ↔ anti-occlusion perturbation**(结构严谨:都是"对过度承诺的状态加噪以重开生成");
3. **re-sampling capacity 作为序参量候选**(仅覆盖 V/R/A/C,见 §6);
4. **option-diversity collapse precedes output failure** 作为反预测(见 §7)。

### 4.2 必须降格为隐喻 / 禁入机制层

- latent space = option-field;
- denoising = choice formation;
- inpainting = appeal(偷换:申诉要"分布外输入",inpainting 只在同模型重采样);
- guidance = true concern(只拟合脚本/假 d,不拟合内生真选择);
- **mode collapse** 这个 GAN 术语(扩散里实为 over-guidance 的 diversity/recall 下降;改用后者)。

### 4.3 无目标分布防火墙(killer 那条)

> **SRT 没有固定目标分布**,所以**不能引入 denoising-toward-truth / data manifold / correct sample 的生成模型框架**。
> 扩散的核心操作(denoising)字面意思是"朝数据流形去噪";去掉数据流形,它没有意义。一旦认真把扩散当_生成模型框架_用,就**偷运回被去过载掉的"位置无关全局最优"**。
> **只留_不依赖目标分布_的过程形状属性(guidance/diversity/re-noising);弃一切依赖目标的部分。**

## 5. X / 外部化防火墙(重点)

> **扩散类比只覆盖自我相关的 re-sampling 动力学,即 V / R / A / C;它对 X——即外部化、他者损失、后果转嫁——构成性失明。X 是 Direction 2 的道德核心,没有扩散对应项**(扩散里没有"另一个位置承受代价")。

**红线:禁止让可测的自我相关半冒充道德的他者相关半。**

含义:RCI 若重解为"re-sampling capacity",可统一 V/R/A/C(自我相关、可测),但**X 不进这个框**。这个统一是靠**丢掉第 5 个、也就是道德上最核心的那个**买来的。**对过程健康更可测,对道德/外部化维度更不完整——必须在文件里始终标注这一点,不得让可测性挤掉道德核心。**

## 6. RCI 重解(prediction candidates,非 validated)

把 RCI 五分量按"选择生成过程中的可重采样容量"重解(**仅 V/R/A/C 有扩散对应;X 无对应,见 §5**):

| 分量 | 重解 | 扩散对应 |
|---|---|---|
| **V** viable latent alternatives | 还保留多少**真实可生成**的替代路径(非名义选项) | diversity / mode coverage |
| **R** restorability | 被关闭的路径能否重新加噪、重采样、恢复 | re-noising 容量 |
| **A** appeal / re-entry | 被排除位置能否重新进入生成过程(**注:需分布外输入,扩散 inpainting 不足**) | (松散)inpainting,**降格** |
| **C** correction | 局部修复并把修复**写回规则**(非表面补丁) | (松散)局部重绘,**降格** |
| **X** externalization | 表面生成质量是否依赖把代价/错误/损失**转嫁到不可见位置** | **无对应(§5 防火墙)** |

> **RCI / re-sampling capacity ≠ canonical d-value**(禁句 §10)。它是一个**序参量_候选_**,回链 d-proxy gate(OPEN_TENSIONS §1)。

## 7. 判别预测(prediction candidates,非 validated predictions)

这些是**候选**,不是已验证预测。判别性**当且仅当**再选择/re-sampling 能被_测出_并从通用压力变量_隔离_(回链 OPEN_TENSIONS §1/§3;否则与所有 tipping-point 理论共享,见 §8)。

1. **reward-health / re-sampling-death dissociation**:一个系统可以高效率、低投诉、低成本,但 option-diversity / re-sampling capacity **已经坍缩**。——**对 RL 判别**(RL 对它 reward-盲)。
2. **option-diversity early warning**:选项空间的可重采样能力下降,**可能先于**结果指标(reward/效率/投诉率/表面稳定性)恶化。——**对普通韧性判别**(韧性把早警读在状态/输出,此处读在生成-option-diversity)。
3. **anti-occlusion perturbation test**:反馈按钮**不等于** RCI 提升;只有能**重开边界、恢复 standing、增加 incumbent burden、改变后续规则**的扰动,才提升再选择容量。——接 `_SRT_CLOSURE_BOUNDARY_CONVERGENCE_RECORD.md §3` 三条件 + 方向三保护核 P3。

**对 FEP 判别**:不同序参量(re-sampling diversity vs surprise / free-energy)。**对社会建构论**:后者非此种定量预测,不直接对撞。

## 8. 第一经验楔子(按测哪一半分域)

**不要把 AI 申诉系统写成第一颗_干净_经验楔子**(真实制度太混淆,隔离不出序参量;临界性是复杂系统通用特征,Scheffer)。

- **第一楔子 · 受控仿真**:用来**隔离 re-sampling 序参量**,测"diversity 先于结果崩塌",干净对照(像 `_SRT_DIRECTION3_L0_PROBE_RESEARCH_SEED.md §6 E1`:人为注入序参量,量 diversity-先于-结果,隔离通用压力变量)。**这是动力学半成科学的唯一干净入口。**
- **第二楔子 · AI 申诉 / 自动化治理系统**:用来承载**道德半、X / 外部化**,以及与 **ChoiceMap / Direction 3** 的连接(外部化在此最鲜活,reward-健康 + re-sampling-死 最有牙齿)。**但只能在动力学半序参量操作化_之后_做。**
