# SRT Philosophy Patch PH-DIFF01: Difference / Individuation / Generative Selectability v0.1

> **Status:** bounded P3 philosophy / pre-objectification / individuation / selection hardening note.  
> **Canonical caution:** this patch does not redefine `L0/L1/L2`, `Ĝθ`, `Psi_f`, `d`, `kappa`, Stable ISP, Real Choice Moment, ontological time, consciousness or the origin of selectability. It records the SRT-relevant pressure that survived a complete close read of Deleuze's *Difference and Repetition*.

---

## 0. Why this patch exists

The main value of Deleuze for SRT is not the generic slogan that "difference precedes identity." The stronger pressure is architectural:

```text
if SRT says selection precedes stable existence,
then the theory must not silently place already-complete
objects, options, subjects, problems or rules before selection.
```

The close read yields a compact generative sequence on the Deleuze side:

```text
differential / problematic multiplicity
-> productive disparity / intensity
-> coupling / individuation
-> spatio-temporal dynamism
-> actual qualities / parts / subjects
-> repetition that regenerates difference
```

SRT must not import this sequence as ontology. Its use is to pressure-test whether SRT's own `L0 -> L1 -> L2` architecture genuinely explains determination or merely redescribes a pre-given menu.

This patch is intentionally distinct from PH-IND03. PH-IND03 already owns the Simondon-specific `Operation -> Structure -> Operation`, transduction, modulation and incompatibility-to-new-dimension bridge. PH-DIFF01 adds a different layer: anti-preformation, problem-space generation, virtual/possible pressure, productive-asymmetry versus payability, deep repetition/stability and an explicit **Image-of-Selection audit**.

---

## 1. Existing SRT position that must be preserved

The current SRT architecture already contains several anti-preformation safeguards:

```text
pre-object field / selection condition
-> manifestation and objectification
-> mathematical / scientific description
```

and explicitly rejects the reversal:

```text
first define a complete object space
-> then claim to have explained how objects become possible.
```

It also keeps these boundaries:

```text
Psi_f = payability burden / ontological friction
not productive difference by definition

Real Choice Moment
!= script execution / habit replay / gradient following / L2-label optimisation

origin of selectability / P0-04 = open
```

PH-DIFF01 therefore hardens interfaces; it does not replace the current canonical definitions.

---

## 2. PH-DIFF01-A — anti-preformation: selectable does not mean already formed

Deleuze's strongest pressure on SRT is the distinction between a generated actual form and a merely unrealised copy of an already-complete form.

For SRT, the safe reading is:

```text
selectability before objectification
!=
a warehouse of fully formed objects waiting to be picked.
```

This matters wherever SRT uses language such as:

```text
latent pattern
possibility
possibilia
select from L0
```

Those phrases must not silently imply:

```text
{finished A, finished B, finished C} already exist as objects
-> Ĝθ merely reveals one.
```

A safer P3 hardening is:

```text
available / conserved generative relations, constraints or selectability
!=
inventory of completed actual forms.
```

### Guard

PH-DIFF01 does **not** rewrite the canonical Conservation of Possibilia claim. It registers a pressure on its interpretation: future hardening must state whether what is conserved/available is best understood as preformed forms, generative relational capacity, or some more precise SRT-native alternative.

---

## 3. PH-DIFF01-B — possible / virtual is an audit distinction, not an SRT identity

Deleuze distinguishes:

```text
possible -> realisation
virtual -> actualisation
```

where the possible commonly resembles the real, while the actual does not resemble the differential relations and singularities it actualises.

For SRT this supplies a diagnostic question:

```text
Does the model explain the generation of determinacy,
or merely add existence to an already specified form?
```

Useful SRT-side pressure:

```text
pre-object selectability
-> determinate manifestation
```

should not be modelled as:

```text
preformed L1 object minus existence
-> same object plus existence.
```

### Strong boundary

```text
Deleuzean virtual != SRT L0
virtual != L0_abs
virtual != proof of SRT pre-objectification
```

Deleuze's virtual is already a philosophically structured differential multiplicity. SRT's own L0 burden and absolute/relative distinctions must be read from SRT sources, not imported from Deleuze.

---

## 4. PH-DIFF01-C — problem-space can be upstream of option-space

The book's problem/solution distinction adds a useful pressure to current choice-generation work.

A menu-level model begins with:

```text
problem P already fixed
+ options {A, B, C} already named
-> choose one answer.
```

A stronger generative audit asks whether the process also changes:

```text
what counts as a problem
what differences become comparable
what options can be generated
what rules delimit the next round.
```

For future P3 work, keep four analytically separate levels:

```text
L1 — outcome selection within a fixed menu
L2 — option-space generation / revision
L3 — problem-space constitution / revision
L4 — rule-generative revision of how problems/options are produced
```

These labels are local to PH-DIFF01. They are **not** a new canonical freedom ladder and do not replace CG-0..CG-4, H3/I5/J5 or the Real Choice Moment criterion.

### Relation to existing selection-event audit

PH-DIFF01 supports one narrow extension of the audit question:

```text
Before asking which option was selected,
ask whether the problem and menu were themselves generated or merely supplied.
```

This does not imply that problem generation is automatically a stronger, healthier or more agentive selection. Stake, consequence return, historical efficacy and reselectability still require their existing SRT gates.

---

## 5. PH-DIFF01-D — actualisation-mechanism audit for `L0 -> L1`

Writing

```text
Ĝθ : L0 -> L1
```

fixes an abstract selection/anchoring interface, but by itself does not yet answer the genetic question:

```text
How do non-objectified differential conditions become a determinate manifestation?
```

A bounded bridge reconstruction for future mechanism work is:

```text
structured selectability
-> effective asymmetry / non-neutrality
-> coupling / individuation dynamics
-> Ĝθ-mediated anchoring under admissible constraints, paying Psi_f
-> determinate L1 manifestation
-> historical writeback
-> reconfigured future selectability
```

This is a **P3 research scaffold, not a canonical equation**.

Its purpose is diagnostic. A proposed implementation should say which step it explains rather than using `selection`, `emergence` or `Ĝθ` as a black box.

### Failure condition

If a model can replace the entire middle of the chain with:

```text
"selection happens"
```

without specifying any asymmetric, coupling, transition or anchoring mechanism, then the model has not yet explained actualisation; it has only named it.

---

## 6. PH-DIFF01-E — productive asymmetry != `Psi_f`

Deleuze's intensity is best treated, for SRT comparison, as a philosophical model of productive disparity or difference of potential:

```text
Delta != 0
-> directional transformation becomes possible.
```

Canonical `Psi_f` has a different role:

```text
Psi_f = payability burden / ontological friction
```

Therefore:

```text
productive asymmetry / gradient
!=
Psi_f
```

and:

```text
Deleuzean intensity
!= physical energy by definition
!= SRT Psi_f
!= SRT d
```

A future SRT mechanism may contain both:

```text
a difference that drives or biases transition
+
a cost/friction that must be paid along the transition.
```

Conflating these would erase an important distinction between **why a direction becomes dynamically live** and **what burden is borne in actualising it**.

---

## 7. PH-DIFF01-F — individuation before selector: crosswalk to PH-IND03, not a P0-04 solution

Deleuze's use of Simondon strengthens a process question already active in PH-IND03:

```text
metastable field
+ disparity / distributed potentials
-> coupling / internal resonance
-> individuation
-> later qualities, parts, species and identifiable individuals.
```

The SRT-side pressure is:

```text
selective asymmetry
-> individuation of a persistent locus
-> historically stabilized selector-position
```

rather than:

```text
fully formed selector
-> selection begins.
```

This can sharpen the slogan "selector as fossil / condensation of selection," but only at P3.

### Guard

```text
individuation before selector
!= origin of selectability solved
```

P0-04 remains open. Deleuze/Simondon offer a grammar for local individuation from already differentiated/problematic conditions; they do not explain why selectability exists at all.

---

## 8. PH-DIFF01-G — metastability pressure: healthy persistence is not terminal equilibrium

Deleuze/Simondon make a useful distinction between:

```text
terminal equilibrium / exhausted difference
```

and:

```text
metastable organization retaining unresolved potential.
```

For SRT this creates a bounded anti-closure pressure:

```text
stable persistence
should not be silently identified with
maximum fixation or minimum future selectability.
```

A generatively healthy organization may need:

```text
coherence
+ retained reselectability
+ repair / reopening capacity
+ non-exhausted differential reserve.
```

### Strong guard

PH-DIFF01 does not define an optimal `kappa*`, does not claim that high `kappa` is bad, and does not alter any canonical phase threshold. It only registers the open mechanism question:

```text
How do stabilization, metastability and reselectability relate in SRT?
```

---

## 9. PH-DIFF01-H — deep repetition pressures static identity models of stability

Deleuze distinguishes bare repetition of apparently identical cases from a deeper repetition in which displacement, variation and difference are constitutive.

The SRT-side bridge is:

```text
persistence
!= literal microstate identity
```

and, more positively:

```text
stable identity candidate
= recurrent reconstitution of a recognizable historical organization
  across changing states and conditions.
```

This fits SRT history/writeback better than a frozen-copy model:

```text
history-supported constraints
-> repeated reconstitution
-> recognizable continuity
```

### Guard

```text
Deleuzean eternal return
!= SRT ontological time
!= L2 recurrence law
```

SRT's ontological time remains tied to irreversible anchoring/history, not to Nietzschean eternal return.

---

## 10. PH-DIFF01-I — problem/solution occlusion as an `L2` pressure

Across the book, stable results can hide their generative conditions:

```text
problem -> solution -> problem becomes less visible
intensity -> quality/extensity -> productive difference is covered
encounter -> stabilized recognition -> forcing difference is neutralized
```

A bounded SRT analogue is:

```text
historical stabilization
can constrain not only which answer is selected
but which differences are legible as problems/options at all.
```

This gives a useful diagnostic for `L2` closure:

```text
current solution structure
mistaken for
the only possible problem structure.
```

### Guard

```text
L2 stabilization != pathology by default
L2 constraint != occlusion by definition
```

The point is to audit whether stabilization preserves routes for correction, re-description and re-opening of the problem space.

---

## 11. PH-DIFF01-J — Image-of-Selection audit

Deleuze's critique of the Image of Thought should be turned back on SRT itself.

The risk is an implicit **Image of Selection**:

```text
see any structured dynamics
-> rename it "selection"
-> write L0 --G--> L1
-> treat the phenomenon as explained.
```

PH-DIFF01 therefore adds a method-level guard:

> A selection claim must specify the concrete difference/non-neutrality, the path efficacy, where consequences fall, and whether/how the result alters later selection conditions. If those cannot be stated, `selection` is functioning as a universal relabel rather than an explanation.

Use existing SRT audit tools for the actual admission decision, especially CG-0..CG-4 and the Real Choice Moment boundary.

### Do not infer

```text
Deleuze uses "selection"
-> SRT Real Choice Moment is present

Deleuzean selective test
= Ĝθ
= d-value
= SRT agency
```

## 15. One-paragraph abstract

A full close read of *Difference and Repetition* yields a bounded P3 hardening package for SRT rather than an ontology import. Its strongest contribution is an anti-preformation pressure: if selection precedes stable existence, SRT must not silently place completed objects, options, problems, rules or selectors before selection. Deleuze's possible/virtual distinction becomes an audit of whether `L0 -> L1` explains determination or merely realises a pre-specified copy; his account of intensity pressures SRT to separate productive asymmetry from canonical `Psi_f` payability; individuation and metastability sharpen the unresolved genetic route from differential conditions to persistent selector-position without closing P0-04; and deep repetition suggests modelling stability as recurrent historical reconstitution rather than microstate identity. The package ends with an Image-of-Selection guard: `selection` must not become a universal label for ordinary dynamics, and concrete SRT claims must still pass the existing difference, path-efficacy, consequence-bearing and historical-writeback tests.
