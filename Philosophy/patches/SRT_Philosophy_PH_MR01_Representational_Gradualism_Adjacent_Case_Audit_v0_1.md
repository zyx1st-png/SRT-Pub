# SRT Philosophy Patch PH-MR01: Representational Gradualism / Adjacent-Case Audit v0.1

> **Status:** P3 philosophy-of-mind / mental-representation hardening patch.  
> **Canonical caution:** this patch does not redefine representation, `d`, `Psi_f`, `L0/L1/L2`, Stable ISP, bearer, subjecthood, phenomenality or the Real Choice Moment. It hardens the existing Mental Representation interface against false binary thresholds and records one SRT-side research hypothesis about history-bearing recursive states.

---

## 0. Source anchor

Peter Schulte's 2026 *Erkenntnis* paper, *Toward a Radical Gradualism About Representation*, argues that traditional attempts to identify a necessary-and-sufficient border between mere sensitivity and genuine representation face a `problem of adjacent cases`.

The source's strongest route is:

```text
representational status should track genuine representational explanatory value
-> proposed threshold C should correspond to a real explanatory tipping point
-> compare the strongest C-negative case with the weakest C-positive case
-> if explanatory practice shows no discontinuity there,
   C is not supported as a natural representational boundary
-> scientific practice instead appears to move gradually toward representational modeling
-> representationality may therefore be a graded property.
```

Schulte's positive proposal ties degree of representationality broadly to sensory information-processing complexity, understood through the number of information-bearing state families and the number/variety of systematic causal relations among them.

The source explicitly leaves the quantitative specification of that complexity and the roles of memory, learning and multisensory integration open.

---

## 1. Why this matters for SRT

Current SRT already contains a non-binary **evidence** architecture for representation:

```text
Sensitivity
-> Specificity
-> Invariance
-> Downstream functionality
```

and the guardrail:

```text
Decode(X | R) > 0
!=
StrongRep(R, X).
```

Schulte adds a different pressure. Even if evidence for a content-bearing state is graded carefully, the underlying property being investigated may itself fail to have a single natural binary onset.

Therefore SRT should distinguish:

```text
E_rep = evidence strength for a representation attribution
```

from:

```text
R_deg = hypothesized degree of representational organization.
```

The first is epistemic. The second is ontological / mechanistic. High or low confidence about `R_deg` must not be confused with `R_deg` itself.

## 2. Main bridge claim A — adjacent-case audit for purported thresholds

### Claim PH-MR01-A

Whenever an SRT bridge proposes a binary threshold `C` for representation-like organization, bearer admission, agency or another thickened status, the threshold should be pressure-tested with adjacent cases before being treated as a natural boundary.

Minimal audit:

```text
choose condition C
-> identify S_minus: maximally developed relevant case with C = 0
-> identify S_plus: minimally developed relevant case with C = 1
-> hold neighboring dimensions as matched as possible
-> compare the relevant explanatory / causal / behavioral / historical change
-> ask whether crossing C produces the discontinuity the theory claims.
```

A compact diagnostic can be written:

```text
C(S_minus) = 0
C(S_plus)  = 1

Delta E = E_target(S_plus) - E_target(S_minus)
```

where `E_target` is the theory-relevant explanatory or mechanistic quantity.

If:

```text
Delta E approximately 0
```

under a well-matched adjacent-case comparison, then `C` is under pressure as a **fundamental natural boundary**.

This is a methodological audit, not a theorem that all natural thresholds are impossible.

## 3. Main bridge claim B — classification threshold is not automatically an ontological boundary

### Claim PH-MR01-B

SRT should preserve:

```text
practical classification threshold
!=
fundamental ontological phase boundary.
```

A research program can define:

```text
R_deg > R_c -> call the system representational for task T
```

or:

```text
B_strength > B_c -> bearer candidate for protocol P
```

without thereby asserting that reality contains a sharp transition exactly at `R_c` or `B_c`.

This matters directly for bearer / subjecthood work. The existence of an operational admission rule is compatible with graded precursor organization.

### Guard

This patch does **not** imply that all SRT structures are continuous or that event actuality is graded.

Keep separate:

```text
graded formation / strength of an organization
!=
graded actuality of a particular history-producing event.
```

No weakening of the Real Choice Moment follows.

## 4. Main bridge claim C — do not identify information-processing complexity with representation

### Claim PH-MR01-C

Schulte's complexity proposal is a useful external pressure model, but SRT should not adopt:

```text
more information-bearing state families
+ more systematic causal relations
=
more representation
```

as a definition.

The modified-rifle case is the critical negative control:

```text
trigger state
+ safety state
-> logical conjunction
-> firing
```

This mechanism is structurally richer than a one-input trigger, but it is not obvious that semantic content attribution becomes more explanatorily necessary merely because one additional causal dependency is present.

SRT should therefore continue to require dimensions already present in the Mental Representation interface, especially:

```text
specificity
+ invariance where relevant
+ downstream consumer use
+ task-relative explanatory gain.
```

Information-processing complexity may be one predictor of representational organization, but it is not admitted here as a sufficient condition.

## 6. Main bridge claim D — history-bearing recursive state is a P3 candidate refinement

### Claim PH-MR01-D

This is an **SRT-side hypothesis generated from the comparison cases**, not a source claim by Schulte.

The desert-ant home-vector case exposes a potentially important distinction between:

```text
static multi-input integration
```

and:

```text
history-bearing recursive updating.
```

Compare:

```text
modified rifle:
Y_t = F(X_t)
```

with a recursive home-vector-like architecture:

```text
H_(t+1) = G(H_t, X_(t+1)).
```

The second architecture contains a state `H_t` that compresses prior interaction history and becomes an input to later processing.

A stronger SRT candidate is:

```text
past selective / interaction history
-> retained relational state H_t
-> H_t changes the weighting / interpretation of present differences
-> present consequence rewrites H_t
-> future accessibility / selectability changes.
```

This suggests a research hypothesis:

> Representational explanatory necessity may increase not merely with the number of internal relations, but when a reusable internal relation becomes historically recursive and counterfactually relevant to later processing.

### Strong caution

Do not promote:

```text
history-bearing state = representation
```

or:

```text
memory = representation
```

without the existing specificity / functionality / consumer-use gates.

Schulte himself only identifies memory as a future research factor and does not derive this SRT hypothesis.

## 7. Representation axis must remain distinct from bearer axis

### Claim PH-MR01-E

The source explicitly brackets phenomenal consciousness. SRT should further preserve:

```text
representation-bearing organization
!= bearer
!= experiencer.
```

A system may have:

```text
stable distal content
+ cross-context reuse
+ recursive historical updating
```

without yet establishing:

```text
same-unit consequence return
+ stake ownership
+ boundary continuity
+ phenomenal for-me-ness.
```

Crosswalk to PH-IND02 / PH-CONSC03:

```text
representation axis:
content-bearing / consumer-usable / historically recursive organization

bearer axis:
consequence return / same-unit writeback / future-selectability change / maintained boundary

phenomenality axis:
open necessity problem
```

These axes may covary but are not identified.

## 8. Formal bridge — adjacent-case audit template

For any candidate threshold `C`:

```text
S_minus = nearest relevant system with C = 0
S_plus  = nearest relevant system with C = 1
```

Define a matched comparison vector:

```text
M = <task, environment, output demand, available cues,
     history depth, consumer structure, control authority>
```

and a target contrast vector:

```text
Q = <representational explanatory gain,
     causal-use gain,
     behavioral generalization gain,
     historical efficacy gain>.
```

A threshold is under pressure when:

```text
C changes discretely
but
Q does not show the corresponding discontinuity
under sufficiently matched M.
```

This is intentionally plural. SRT should not replace one overstrong scalar boundary with a different unearned scalar.

## 9. Operational consequences / future tests

### 9.1 Constancy versus cue-integration comparison

Compare systems matched for task performance where one uses a perceptual-constancy architecture and another uses reliability-weighted cue integration.

Question:

```text
Does representational attribution become more explanatorily indispensable exactly at constancy?
```

Schulte predicts no unique tipping point.

### 9.2 Static integration versus historical recursion

Construct matched systems:

```text
A: current multi-cue integration only
B: same current cues + retained recursively updated state
```

Hold current observables matched where possible and test whether historical state improves:

- cross-context generalization;
- downstream consumer prediction;
- behavior under current-cue ambiguity;
- counterfactual dependence on past interaction history.

If B shows no independent explanatory increment after ordinary current-state controls, the PH-MR01-D history-bearing refinement should be weakened.

### 9.3 Threshold pressure on bearer candidates

For any future operational bearer threshold, compare near-threshold systems on:

```text
same-unit consequence return
history writeback
future-selectability change
boundary continuity.
```

If the underlying dimensions vary smoothly across the proposed cutoff, treat the cutoff as operational unless an independent phase-transition argument exists.

## 12. One-paragraph abstract

Schulte's radical gradualism is most useful to SRT as a threshold-audit method rather than as a ready-made scalar theory of representation. His adjacent-case argument asks whether a proposed necessary-and-sufficient boundary actually coincides with a discontinuity in scientific explanatory practice; simple perceptual constancy, desert-ant path integration and auditory cue integration suggest that representational modeling becomes useful gradually rather than at one privileged mechanism. PH-MR01 imports that audit while keeping SRT's existing representation-evidence ladder intact, separates epistemic evidence strength from ontological degree, rejects information-processing complexity as a sufficient definition, and records a narrower P3 hypothesis that historically recursive reusable states may explain part of the gap between static causal integration and strongly representational organization. Representation, bearer status and phenomenality remain separate axes.
