# SRT Philosophy Patch PH-IND07: Processual Bearer, Active Maintenance, and Cross-Scale Stake Integration v0.1

> **Status:** P3 philosophy / individuation / d-value hardening patch.
>
> **Canonical caution:** this patch does not redefine `bearer`, `selection`, `d`, Stable ISP, subjecthood, consciousness, `L0/L1/L2`, continued selectability, generative reselectability, or numerical identity. It records a bounded owner-side hardening generated by the IPA/TBI guided read and subsequent subtraction against PH-IND02/04/05/06, Processual Bearer Bridge, d-value canonical, Irreversibility, and Individuation.
>
> **Primary correction:** do not treat a bearer as a passive consequence receptacle or as a sequence of time-indexed object tokens. The candidate bearer is processual and actively maintained; cross-scale inclusion requires stake coupling, not mere causal dependence or coordination.

---

## 0. What this patch adds after subtraction

Existing owners already contain:

```text
PH-IND02:
selective stabilization
-> candidate closure
-> consequence return / history writeback / future-selectability / continuity

PH-IND04:
Object != Bearer != Selector != Subject != Experiencer

PH-IND05:

PH-IND06:
Persistent Process != Bearer

history-bearing != history-constituted
continuity diagnostics != numerical-identity theorem
constraint closure / production-side audit != consequence non-outsourcing

d-value canonical:
only stake-coupled directions may enter canonical d / d_stakes
```

PH-IND07 does **not** duplicate those claims. Its retained increment is narrower:

1. **temporal objectification guard** — time-indexed descriptions are projections of one ongoing process, not a sequence of bearer substances;
2. **active-maintenance bearer pressure** — passive trace-bearing or damage accumulation is insufficient for bearer admission;
3. **self-maintenance != self-sufficiency** — proxy-supported maintenance is compatible with bearer continuity;
4. **copying != process bifurcation** — objectified state/history transfer must be separated from genuine bifurcation of an ongoing closure;
5. **cross-scale stake integration** — lower-level self-maintenance enters higher-order bearer organization only when local differences become stake-coupled to higher-order continuation;
6. **non-additivity of d across scale** — higher-order d is not the sum of local d; alignment/conflict/anti-alignment matter;
7. **higher-order bearer open burden** — whether joint stake integration plus joint consequence-history closure adds discrimination beyond coordination/autonomy remains unresolved.

## 1. Temporal objectification guard

### Claim PH-IND07-A — time-indexed bearer descriptions are readouts, not multiple bearers

SRT uses time-indexed notation such as `P(t)`, `A_t`, state vectors, snapshots and historical comparisons. These are indispensable operationally, but must not silently impose a temporal-slice ontology.

Use the following P3 interpretive guard:

```text
P(t)
=
time-indexed state / objectification readout of an ongoing process P

P(t1), P(t2)
!=
commitment to two numerically distinct temporal bearers
```

Ontology / observation distinction:

```text
---------------- ongoing bearer process P ---------------->

          Obj_t1(P)                Obj_t2(P)
```

The safer question is therefore not:

```text
Is B_t1 numerically identical to C_t2?
```

but:

```text
Is the ongoing process persisting,
transforming, bifurcating, fusing,
or terminating at the declared grain?
```

### Guard

This does not solve numerical identity or fission. It only blocks an illicit reversal in which analyst-generated temporal objectification becomes the ontology to be explained.

```text
object re-identification across slices
!= ontological basis of bearer persistence
```

A processual reading instead permits:

```text
ongoing process persistence
-> multiple re-identifiable objectifications
```

## 2. Bearer is not a passive consequence-return location

### Claim PH-IND07-B — passive historical alteration is insufficient

A weak structure such as:

```text
event
-> persistent trace
-> altered later dynamics
```

is too permissive for bearer admission. Material fatigue, erosion, scars, sedimentation, hysteretic materials and ordinary path-dependent objects can satisfy this pattern.

Therefore block:

```text
persistent trace
+
future dynamical alteration
-> bearer
```

by itself.

### Active-maintenance pressure

A stronger bearer candidate should be audited for whether the candidate organization itself participates in generating, maintaining, compensating for, or reconstituting the conditions under which that organization continues.

Candidate audit only:

```text
active self-stabilization / reconstitution
+
same-process consequence incorporation
+
historical reconstitution
+
continued unfolding
-> stronger bearer candidate
```

Native compression:

> **bearer 不是被动承接后果的位置，而是一个持续参与维持自身存在、并必须把后果纳入这种维持过程中的历史过程。**

### Anti-overreach guards

```text
active maintenance != reflective agency
active maintenance != consciousness
active maintenance != subjecthood by itself
self-maintenance != bearer by definition
feedback != bearer proof
homeostasis != bearer proof
```

This is an admission pressure, not a replacement definition.

## 3. Self-maintenance is not self-sufficiency

### Claim PH-IND07-C — maintenance can be externally supported without moving the bearer

A bearer can depend on:

```text
oxygen
nutrition
caregiving
medicine
life support
microbial metabolites
institutional scaffolds
technical proxies
```

Therefore:

```text
self-maintaining
!=
self-sufficient
```

The relevant question is not whether every persistence-enabling condition is internally produced, but where those contributions are integrated into an ongoing organization whose own continuation is at issue.

Native compression:

> **调节可以被代理，承受不能因此被代理掉。**

More explicitly:

```text
proxy contributes maintenance condition
-> condition is incorporated into bearer continuation
!-> proxy becomes bearer
```

Retain:

```text
proxy support != bearer membership
proxy dependence != bearer identity
functional extension != bearer extension
```

This protects severe-support, infant, caregiving, symbiosis and distributed-support cases from an overly autarkic bearer criterion.

## 4. Process topology vocabulary — bridge only

PH-IND07 proposes a thin discrimination vocabulary, not a canonical taxonomy:

```text
Persistence:
one ongoing writable bearer history continues

Transformation:
one writable history changes internal organization / regime

Bifurcation:
one writable bearer history stabilizes into two independently writable histories

Fusion:
two independently writable histories become one irreducibly joint writable history

Termination:
bearer-indexed future writeback permanently ends
```

### Why this is preferable to time-slice identity language

A large change in state, memory, personality, regulation, material composition or internal organization may remain a transformation within one ongoing bearer process.

Therefore:

```text
large state difference
!= bearer replacement
```

The primary discontinuity questions become topology questions about process continuation and closure, not similarity comparisons between static descriptions.

### Guard

```text
transformation != bifurcation != termination
physical split != bearer bifurcation
state restoration != history reversal
```

## 5. Copying is not genuine process bifurcation

### Claim PH-IND07-D — objectified transfer and process branching must be separated

Copying has the generic structure:

```text
ongoing process P
-> objectification / snapshot / representation R
-> instantiate new process Q
```

Even when `R` contains matching state, memory, parameters, self-report and pre-copy historical description, this only establishes transferred or shared historical representation.

Retain:

```text
state copy != process continuation
history representation transfer != bearer-history continuation
shared initialization != shared ongoing bearer
```

Native compression:

> **可复制的是过程的状态、结构和历史表征，而不是过程已经发生着这一事实。**

### Genuine bifurcation

A stronger process-bifurcation candidate requires that one ongoing consequence/history closure itself reorganize into two independently writable closures.

Use PH-IND05's consequence-separability test:

```text
an admissible E1 can alter P1's future / history
without the same consequence closing on P2

and an admissible E2 can alter P2
without the same consequence closing on P1
```

Compactly:

> **one writable consequence-history closure -> two independently writable histories**

### Shared-past guard

```text
shared pre-branch history
!= shared post-branch bearer closure
```

No claim is made here about whether the pre-branch bearer "survives" as one, both, or neither branch in a strict metaphysical numerical-identity sense.

## 6. Cross-scale self-maintenance and d-value

### Claim PH-IND07-E — higher-order inclusion requires stake coupling, not mere coordination

The central cross-scale increment is:

> **local self-maintenance can be incorporated into whole-organism self-maintenance when local differences become stake-coupled to the continuation of the higher-order bearer.**

The relevant structure is not merely:

```text
local process affects whole process
```

but:

```text
local difference
-> changes higher-order irreversible risk / continuation stake
-> recruits whole-level regulation / selection
-> writes into whole history
-> changes whole future selectability
```

Native compression:

> **高阶 bearer 的形成，不只是局部过程被协调，而是局部差异开始以整体的 d-value 被重新赋予 stake。**

A second compression:

> **d-value 是把“局部发生了什么”转换成“这对哪个持续存在过程意味着什么”的跨尺度接口。**

### Canonical routing

This is an interpretation of existing `Def-d-canonical` / `d_stakes` governance, not a new d definition. A lower-level direction contributes to higher-order d only insofar as its consequences are genuinely stake-coupled to the higher-order bearer's irreversible risk / continuation / future selectability.

Block:

```text
local state importance -> whole d
local viability -> whole stake
local D_eff -> whole d
```

without the stake-coupling audit.

## 7. d is non-additive across scales

### Claim PH-IND07-F — do not sum local stakes into a higher-order bearer

Forbidden shortcut:

```text
d_whole = sum_i d_local_i
```

The reason is structural, not merely numerical. Local and whole-level stake directions can:

```text
align
remain neutral
conflict
anti-align
```

Thus higher-order organization requires a mapping / integration relation between scales, not arithmetic aggregation.

### Normal multicellular integration

Normal tissue can exhibit:

```text
local apoptosis
local replication restraint
local specialization
local resource sacrifice
```

while preserving the organism. Therefore the organism-level stake structure can constrain local persistence rather than maximize it.

This is evidence for:

```text
local persistence objective
!= whole-bearer continuation objective
```

and motivates stake reassignment / integration as a cross-scale question.

### Cancer as negative control

Cancer supplies a clean stress test:

```text
local lineage self-maintenance up
whole-organism viability down
```

Candidate P3 interpretation:

> **local self-maintenance stake geometry can decouple from or anti-align with whole-bearer stake geometry.**

Do not reduce this to "local freedom increased"; the stronger discrimination is scale-relative stake conflict plus cost externalization to the organism.

## 8. Constraint role, token replacement, and microbiome

### Claim PH-IND07-G — whole-level stake may attach to a role before a material token

Microbiome / organ cases motivate:

```text
constraint role != constraint token
component substitutability != bearer substitutability
```

A specific microbe token can be replaceable while a metabolic / immune / regulatory role is highly stake-coupled to host continuation.

Therefore:

```text
replaceable local token
!-> irrelevant whole-level stake
```

and:

```text
whole-level functional stake
!-> token becomes bearer identity constituent
```

This supports a graded distinction among causal participation, regulatory incorporation, consequence incorporation and identity incorporation without forcing a new canonical ladder.

## 12. Higher-order bearer open tension

### Tension PH-IND07-T1 — stake integration and higher-order bearer formation

Open question:

> **Can higher-order bearer formation be discriminated by the integration of multiple local self-maintaining stake directions into an irreducible higher-order d / consequence-history closure?**

Subquestions:

```text
T1a stake integration:
When does a local difference become a genuine higher-order stake direction?

T1b stake conflict:
How should local/whole alignment, conflict and anti-alignment be represented without summing d?

T1c higher-order discrimination:
Does joint d + joint consequence-history closure add explanatory or predictive value beyond coordination, autonomy, mutual dependence, shared L2 or functional integration?
```

### Failure conditions

The proposal should be weakened if:

1. all apparent higher-order stake integration reduces to ordinary causal coupling or centralized control;
2. no independent test distinguishes whole-level d from an analyst-defined utility function;
3. local/whole stake conflict cannot be discriminated from ordinary optimization tradeoffs;
4. joint consequence closure adds no predictive value beyond existing collective ISP conditions;
5. the proposal forces additive cross-scale d despite canonical scale-normalization guards.

Until those burdens are met:

```text
higher-order stake integration
=
P3 open tension
!= bearer theorem
!= collective ISP theorem
```

## 15. Retained hooks for future owner synthesis

1. **不同时间截面的主体描述只是对同一持续 bearer process 的对象化，而不是多个先后存在的主体。**
2. **bearer 不是被动承接后果的位置，而是一个持续参与维持自身存在、并必须把后果纳入这种维持过程中的历史过程。**

7. **高阶 bearer 的形成，不只是局部过程被协调，而是局部差异开始以整体的 d-value 被重新赋予 stake。**
8. **d-value 是把“局部发生了什么”转换成“这对哪个持续存在过程意味着什么”的跨尺度接口。**
