## 1. Retained increment A — temporal objectification is not temporal bearer multiplication

PH-MEM01 §3 already states that once entities, relations, rules or schemas are cut out as reusable units, they are objectification-level objects. PH-IND07 adds a **diachronic application** of that guard.

Let `\mathcal{P}` denote one ongoing candidate process. A description such as:

```text
Obj_t1(𝒫)
Obj_t2(𝒫)
```

is an observer-side / operational cut through the same ongoing process. It must not silently be reified as:

```text
bearer B exists at t1
bearer C exists at t2
therefore prove B = C
```

Safe P3 guard:

> **不同时间截面的对象化描述，不应被反向本体化为多个先后存在的 bearer。**

This does **not** prove numerical identity. It blocks one specific category error: constructing temporal bearer plurality from the notation used to observe or model an ongoing process.

### Namespace guard

This patch does **not** use bare `P(t)` because that notation is already occupied elsewhere in the repository. `\mathcal{P}` here is local prose/math shorthand for an ongoing process only; it is not registered as a canonical symbol.

## 2. Retained increment B — copying is not evidence of genuine process bifurcation

PH-IND06 §5.2 already uses the following contrast to test consequence non-outsourcing:

```text
same bearer undergoes costly repair / adaptation
!=
candidate discarded and untouched equivalent copy / checkpoint substituted
```

PH-IND07 keeps the copy case but asks a different question.

### Copy-instantiation

```text
ongoing process 𝒫
-> objectified state / snapshot R
-> R initializes another process 𝒬
```

Matching state, memory, parameters or self-description establishes representational / initialization continuity. It does not by itself show that the ongoing consequence-history closure of `𝒫` bifurcated.

Retain:

```text
state copying
!= evidence of process bifurcation

shared historical representation
!= shared post-copy bearer closure
```

### Bifurcation candidate

For a genuine bearer-bifurcation candidate, reuse PH-IND05's consequence-separability logic. After a putative split into locally named branches `Π₁` and `Π₂`, look for consequences that can be independently written back:

```text
E1 changes the later history / selectability of Π₁
without the same consequence closing on Π₂

and

E2 changes Π₂
without the same consequence closing on Π₁
```

Compact P3 reading:

> **copying duplicates an objectified description; bifurcation requires evidence that one ongoing consequence-history closure has become independently writable along more than one successor process.**

No claim is made about which successor is numerically identical to the pre-branch bearer.

## 3. Active maintenance and external support — guard only, not novelty

The Processual Bearer Bridge already asks whether persistence-enabling constraints are regenerated by the candidate organization and whether that production-side structure adds discrimination beyond existing autopoiesis / persistence / regulation. It explicitly leaves Layer C empty.

Therefore PH-IND07 does **not** claim:

```text
active self-maintenance = bearer
```

The guided-reading discussion only adds a useful anti-misreading of non-outsourcing:

```text
self-maintenance
!= self-sufficiency

external regulation / proxy support
!= bearer membership
```

Native compression:

> **调节可以被代理，承受不能因此被代理掉。**

This means only that non-outsourcing should not be misread as an autarky requirement. Oxygen, nutrition, caregiving, medicine, life support, microbial products or technical support may contribute to the maintenance of a candidate bearer without thereby becoming that bearer.

This is a guard on owner interpretation, not an independent PH-IND07 theorem.

## 4. d-value subtraction — stake coupling is already owned

The first draft proposed:

```text
local difference
-> higher-order irreversible risk
-> whole-level regulation / selection
-> whole-history writeback
-> whole future selectability
```

After subtraction, this is not new. `_SRT_D_VALUE_CANONICAL.md §2b` already fixes the qualitative stake gate:

```text
w_i = R_i · A_i · C_i
```

where, at P2 canonical-interpretation level:

- `R_i`: genuine irreversible risk;
- `A_i`: subject utility gradient aligned to that risk;
- `C_i`: consequence returns to the subject closure / identity continuity / later selection capacity.

Therefore the guided-reading statement

> “d-value 把局部发生了什么转换成这对哪个持续存在过程意味着什么”

is retained only as an explanatory paraphrase of the existing stake gate, not as PH-IND07 novelty.

Likewise, this patch withdraws the first-draft unconditional prohibition:

```text
d_collective != aggregate(d_i)   [unconditional]
```

Canonical §6.1 already defines collective `d` through `\mathcal{F}_{collective}` and individual `d_i` as subspace sections; §6.2 additionally permits named aggregation schemes as empirical approximations under declared landscape conditions. PH-IND07 must not govern those canonical allowances more strictly than the owner does.

## 5. Retained reverse pressure — cancer and the antecedent of the §6.1 subspace reading

The strongest surviving cross-scale result is not “collective d is non-additive”. That is already canonical. The pressure is on a **precondition** of the canonical §6.1 relation:

```text
d_i = D_eff(F_collective | θ_i)
```

This expression reads an individual/local `d_i` as a subspace section of one collective landscape. That is a coherent whole-first description when the local unit is genuinely organized within the higher-order landscape.

### Cancer pressure case

Cancer supplies a negative control in which a local lineage can maintain and expand a persistence organization whose effective stake directions increasingly diverge from organism-level continuation:

```text
local lineage maintenance / replication pressure increases
while
organism-level viability and future selectability decrease
```

The P3 question is therefore not whether local and collective `d` should be summed. It is:

> **When is a local stake landscape still adequately represented as a restriction / slice of the higher-order landscape, and when has it become a partially autonomous, competing landscape whose stake directions can anti-align with the higher-order bearer?**

This does not falsify §6.1. It pressures the adequacy of its antecedent in scale-conflict cases.

### Relation to the unified `R/A/C` gate

The existing §2b.1 gate table distinguishes AI, frozen states and institutions by where one bearer-relative stake gate fails or is redirected. Cancer suggests a different cross-grain case:

```text
local candidate lineage:
R/A/C may be substantial relative to local persistence

higher-order organism:
the same local trajectory can impose adverse consequence / cost
```

Thus the open issue is **grain-relative stake ownership and landscape nesting**, not a fourth numerical value of `w_i`.

This is the only PH-IND07 item that currently exerts reverse pressure on a canonical interpretation owner.
