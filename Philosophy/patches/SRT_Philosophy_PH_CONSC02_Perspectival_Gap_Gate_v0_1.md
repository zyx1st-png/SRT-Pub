# SRT Philosophy Patch PH-CONSC02: Perspectival Gap Gate v0.1

> Status: philosophy-of-mind / epistemology guardrail patch.
> Canonical caution: this patch does not prove that physics or neuroscience has completed the explanation of consciousness. It blocks a specific mistake: generating a metaphysical gap by treating scientific description as if it came from outside the world.

## 1. Why this matters for SRT

SRT already has a hard-problem dissolution file. Rovelli's essay usefully sharpens the epistemic mistake that often creates the problem:

```text
science is imagined as a view from outside the world
  -> experience is treated as something outside that picture
  -> the theorist then demands a derivation from third-person picture to first-person life
  -> the gap was introduced at the start
```

PH-CONSC02 gives SRT a compact guardrail for that move.

---

## 2. Main SRT bridge claim

### Claim PH-CONSC02

The hard problem should not be framed as the task of deriving first-person experience from a complete view-from-nowhere description. There is no such unpositioned description inside SRT.

SRT compression:

```text
scientific description = embodied L2 stabilization by situated operators
first-person experience = the process as borne from within a bearer unit
third-person account = the process as stabilized from another position
perspectival difference != metaphysical gap
```

Positive rule:

```text
Do not turn a difference in access route,
description grain, or embodied position
into evidence for a second substance.
```

## 5. Operational consequences

When SRT evaluates a hard-problem claim, ask:

1. Is the argument assuming a view-from-nowhere scientific picture?
2. Is first-person access being treated as a different substance, or as a different access route?
3. Which part of the gap is language-interface insufficiency, dimensional compression, high-cost approximation, missing mechanism, or real threshold uncertainty?
4. Has the bearer unit been specified?
5. Are `d`, `Psi_f`, boundary, memory, and continuity doing work, or is "experience" floating free of them?
6. Does the argument prove impossibility, or only mark current explanatory incompleteness?

## 8. Residual after the perspectival gate — 2026-08-08 hardening

The perspectival gate is necessary but not sufficient. The following inference is **not** licensed:

```text
all accounts are perspectival
-> subjectivity is merely perspectivality
```

A later close reading found that the remaining problem must distinguish at least:

```text
Selector
!= Bearer
!= Concern Domain
!= Experiencer
```

and must also preserve:

```text
bearing_candidate != phenomenality proof
```

This residual is developed in:

```text
Philosophy/patches/SRT_Philosophy_PH_CONSC03_Subjectivity_Decomposition_Bearer_Concern_v0_1.md
```

PH-CONSC03 also records the main originality pressure: enactivism/autopoiesis already supplies strong accounts of precarious autonomy, adaptivity and intrinsic normativity, while Damasio supplies a major homeostatic-feeling / ownership route. SRT should therefore test whether same-bearer consequence return, non-outsourcing, concern-boundary separation and future-selectability writeback add independent discrimination rather than claiming `bearing` itself as unique.
