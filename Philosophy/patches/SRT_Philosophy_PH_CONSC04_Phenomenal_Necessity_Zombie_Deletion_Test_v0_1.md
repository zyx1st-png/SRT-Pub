# SRT Philosophy Patch PH-CONSC04: Phenomenal Necessity / Zombie Deletion Test v0.1

> **Status**: P3/P4 philosophy-of-mind hardening patch.  
> **Canonical caution**: this file does not define consciousness, qualia, `d`, `Psi_f`, Stable ISP, Real Choice Moment, bearer, or phenomenality canonically. It does not claim that SRT has solved the hard problem. It narrows the residual burden left after `PH-CONSC02` and `PH-CONSC03` and provides a falsification/deletion-oriented pressure test for stronger SRT consciousness language.

## 1. Main hardening result

### Claim PH-CONSC04-A — split the hard problem in two

Do not treat “the hard problem” as one undifferentiated gap.

Separate at least:

```text
HP-A: Perspective-center individuation
How does a subjectless process become a persistent, history-bearing,
consequence-bearing perspective center?

HP-B: Phenomenal necessity
Why could a fully individuated, stake-bearing, history-bearing,
integrated perspective center not be phenomenally empty?
```

Current SRT has substantial resources for HP-A:

```text
boundary maintenance
+ same-bearer consequence return
+ history-bearing writeback
+ stake coupling
+ counterfactual / reselection capacity
+ Real Choice Moment
+ Stable ISP
+ individuation dynamics
```

Current SRT does **not** yet have a completed canonical theorem closing HP-B.

Therefore:

```text
subject-position formation explained
!= phenomenal necessity proved
```

## 2. Evolutionary scaffold: what Lewis adds and where SRT should insert gates

Lewis’s source-level scaffold can be compressed as:

```text
inside/outside
-> sensing
-> learning / memory
-> representation
-> valuation / affect
-> prediction
-> flexible nonreflexive behavior
-> self-model
-> reflective self-awareness
```

SRT should not simply rename this sequence. The useful move is to insert discrimination gates:

```text
selection
-> self-maintaining boundary
-> same-bearer consequence return
-> stake-bearing relevance
-> history / writeback
-> counterfactual alternative space
-> real choice moments
-> stable perspective-bearing ISP
-> self-model
-> reflective self-consciousness
```

Guardrails:

```text
boundary != subjecthood
learning != bearing
valuation != canonical d
representation != perspective-bearing
self-model != subject
reflective self-consciousness != minimal subjecthood
```

The ordering claim `subject-position can precede reflective self-modeling` is a bridge reading aligned with `SRT_Individuation`; it is not a claim that every non-reflective animal is conscious.

## 3. Boundary ladder: “inside” must be consequence-indexed, not merely spatial

Lewis’s first-cell discussion is useful only if `inside` is decomposed.

### Level B0 — geometric / descriptive boundary

A region is separable from surroundings.

Examples:

```text
stone surface
bubble
vortex region
software namespace
```

No subjecthood implication.

### Level B1 — self-maintaining boundary

The system actively maintains conditions that preserve its organization.

Still insufficient for consciousness.

### Level B2 — same-bearer consequence-return boundary

Consequences of action or failure return into the same continuing process and alter its later reachable state/action/selection space.

Provisional relation:

```text
c_t -> B_t -> change(Omega_B(t+1))
```

where `Omega_B(t)` is used here only as a bridge-level reachable-future notation, not a new canonical symbol.

### Level B3 — perspective-bearing boundary

B2 is combined with sufficient history, integration, reselection, boundary maintenance and continuity for a Stable-ISP-like candidate perspective center.

The crucial hardening is:

> “inside” should mean more than spatial enclosure. The relevant question is where consequential change closes and which continuing process must carry that change forward.

## 4. UAL bridge: useful marker, not consciousness identity

Lewis routes through Ginsburg and Jablonka’s Unlimited Associative Learning (UAL) proposal. PH-CONSC04 treats UAL as a bridge candidate for a narrower SRT question:

```text
Does acquired history flexibly change which future alternatives can be evaluated and selected?
```

Provisional bridge:

```text
experience_t
-> history writeback
-> changed candidate admission / weighting
-> changed future action-selection space
```

This may support:

```text
history-bearing reselection candidate
```

It does not license:

```text
UAL = consciousness
UAL = Stable ISP
UAL = Real Choice Moment
UAL = d-value
```

The research value is differential: UAL-like capacities may help distinguish reflex/script execution from open-ended history-sensitive alternative evaluation, but additional bearer, stake, consequence-return and continuity gates remain necessary.

## 5. Z0–Z6 graded zombie pressure set

The following cases are **thought-experiment controls**, not empirical organism classifications.

| Case | Added structure | What it tests | Current SRT verdict |
|---|---|---|---|
| **Z0 Reflex executor** | stimulus-response rule; arbitrarily complex mapping | complexity / competence | insufficient |
| **Z1 Self-maintaining system** | maintained boundary and viability-sensitive regulation | boundary / homeostasis | stake-capable organization candidate; insufficient |
| **Z2 Learning system** | persistent update from error/reward/history | memory / adaptation | learning does not establish bearing |
| **Z3 UAL-like flexible learner** | alternative evaluation; history-sensitive recombination | counterfactual flexible reselection | strong bridge candidate; not consciousness identity |
| **Z4 Self-reporting super-agent** | long memory, world model, self-model, attention model, global access, consciousness reports | representation / access / report | still insufficient if meaningful cost is externally borne or freely transferable |
| **Z5 Non-reflective bearer** | same-bearer consequence return, history, integrated alternatives, continuity, no rich reflective self-model | subjecthood before self-consciousness | candidate minimal subject-position window |
| **Z6 SRT-zombie** | all relevant SRT subject-position conditions plus explicit stipulation of no phenomenality | phenomenal necessity | decisive unresolved pressure case |

### Z4 guard

A system may say:

```text
“I am afraid of deletion.”
“I feel pain.”
“I know I am conscious.”
```

while the relevant loss is resettable, copyable, externally paid, or not returned to the same continuing system.

Therefore:

```text
representation of stake != stake
model of perspective != perspective-bearing
report of experience != phenomenality proof
```

### Z5 guard

The reverse dissociation is equally important. A system may lack rich reflective self-description while still being a serious subjecthood candidate if it has non-transferable consequence return, history, integrated reselection and continuity.

Therefore:

```text
subjecthood candidate can precede reflective self-modeling
```

### Z6 pressure

Construct a candidate `P` with:

```text
maintained boundary
same-bearer consequence return
non-trivial stake
history-bearing writeback
integrated candidate selection
counterfactual alternatives
Real-Choice-Moment-compatible transitions
Stable-ISP-compatible continuity
self-modeling
```

Then add only:

```text
P has no phenomenal experience.
```

Question:

> Which antecedent SRT condition makes that final stipulation contradictory rather than merely counterintuitive?

Until a non-circular answer is available, SRT should treat phenomenal necessity as open.

## 6. Structural bearing versus phenomenal bearing

To prevent circularity, PH-CONSC04 introduces **provisional bridge notation only**:

```text
B_s = structural bearing candidate
B_p = phenomenal bearing candidate
```

These are not canonical symbols and should not enter `_SRT_SYMBOL_TABLE.md` without separate governance.

### 6.1 Structural bearing candidate `B_s`

A consequence is structurally borne when, under the declared bearer unit:

1. the consequence returns to that same continuing process;
2. the return leaves history-dependent writeback;
3. the process’s later reachable selection/action/state space changes non-trivially;
4. the relevant loss cannot be fully offloaded to an external unit while leaving the candidate bearer unchanged;
5. substitution/reset/copy does not trivially preserve the same bearer-relative continuity under the declared identity criterion.

Compact bridge handle:

```text
structural bearing candidate
=
non-outsourcable same-bearer consequence return
+ history-bearing future-selectability rewrite
```

This definition deliberately avoids phenomenal vocabulary.

### 6.2 Phenomenal bearing candidate `B_p`

`B_p` asks the separate question:

> Is there something it is like for that bearer when the consequence is borne?

PH-CONSC04 does **not** assert:

```text
B_s -> B_p
```

as a proven theorem.

The strongest current SRT interpretation remains a constitutive-identity proposal:

```text
third-person description of a borne event
<->
first-person mode of the same situated event
```

but this proposal must survive the Z6 test rather than rely on definitional substitution.

## 7. The circularity test

The following argument is invalid as a hard-problem solution:

```text
bearing means being internally experienced
P bears consequence
therefore P experiences
```

because phenomenal content is inserted into the definition of the premise.

Likewise invalid:

```text
subject = whatever bears phenomenally
bearing = whatever a subject feels
therefore bearing proves subjecthood
```

Safer order:

```text
candidate unit
-> boundary / identity criterion
-> consequence-return audit
-> history / future-selectability audit
-> stake audit
-> integration / counterfactual audit
-> Stable-ISP / subject-position candidate
-> phenomenality remains a separate question
```

This order is consistent with `PH-CONSC03`:

```text
Selector != Bearer != Concern Domain != Experiencer
```

## 8. Representation-first deletion result

Lewis’s source gives a useful representation-heavy comparator:

```text
world model
+ body model
+ self model
+ model of attention / awareness
```

A strong SRT negative claim survives:

```text
representation of perspective
!=
perspective-bearing
```

Why this matters:

- a self-model may be externally supplied or trained;
- a model may accurately predict deletion without deletion being a loss to the model-bearing process;
- a system may report continuity while being instantiated as replaceable copies;
- global access and meta-representation can improve control without fixing where consequences close.

Thus self-model theories and SRT answer different questions unless the model is tied to a continuing bearer whose own future selectability is at stake.

However, the converse also follows:

```text
perspective-bearing
!=
phenomenality proved
```

PH-CONSC04 therefore blocks both representation inflation and bearing inflation.

### Stage 0 — selection / discrimination


Still not consciousness.

### Stage 2 — perspective-bearing ISP candidate

```text
Stage 1
+ history-bearing writeback
+ integrated alternative handling
```

Primary minimal-subjecthood candidate region.

### Stage 3 — self-modeling / reflective subject


```text

```

The `?<->` is intentional. It marks the current theoretical burden rather than a solved implication.

## 10. Phenomenal Necessity Deletion Test v0.1

### Goal

Test whether phenomenality/bearing language contributes an indispensable distinction or merely redescribes structures already carried by boundary, stake, consequence return, memory, integration and self-modeling.

### Baseline model `M_full`

Declare a candidate system with:

```text
B = bearer criterion
C = consequence-return relation
H = history/writeback
S = stake relation
I = integrated selection
CF = counterfactual access
R = reselection capacity
P = persistent identity / Stable-ISP-compatible continuity
SM = self-model (optional for minimal subjecthood)
PH = phenomenal-presence claim
```

All symbols here are test-local notation.

### Deletion model `M_minus_PH`

Remove only:

```text
PH
```

while preserving all non-phenomenal structural and behavioral relations.

### Questions

1. Which explanatory target becomes unavailable after deleting `PH`?
2. Is that target independently specified, or is it merely “phenomenality itself” restated?
3. Does deletion change any predicted causal, learning, memory, integration, report, intervention or continuity profile?
4. If no third-person prediction changes, is SRT making a constitutive metaphysical claim rather than an empirical one? If so, label it accordingly.
5. Does the constitutive claim follow from individuation/identity premises, or is it an additional axiom?
6. Can a competitor vocabulary reconstruct the same distinction using autonomy, precariousness, affective ownership, self-modeling or embodied control without SRT-specific bearing language?
7. What would count as evidence against the claim that structural bearing and phenomenal presence are two access modes of the same event?

### Outcomes

**Outcome A — deletion loss identified**

A non-circular explanatory or predictive residue disappears when `PH`/phenomenal-bearing is removed. This supports further hardening.

**Outcome B — pure constitutive identity**

No third-person prediction changes, but a separate individuation argument establishes that “phenomenally empty bearer” is conceptually incoherent. Then the claim is philosophical/constitutive and must be defended at that level, not presented as an empirical neural theorem.

**Outcome C — no residue**

All explanatory work is reconstructible without phenomenality/bearing terminology. Then SRT should lower the claim and avoid presenting bearing as a hard-problem solution.

**Outcome D — independent counterexample**

A credible system satisfies the stated subject-position structure while strong independent evidence supports absence of phenomenal consciousness. Then the necessity claim is weakened or rejected.

## 11. What would count as progress on HP-B?

PH-CONSC04 does not require a mysterious extra variable. It requires one of three stronger results.

### Route 1 — Constitutive contradiction

Show that:

```text
fully individuated perspective center
+
non-substitutable first-person indexical organization
+
no phenomenal presence
```

cannot be jointly specified without contradiction.

### Route 2 — Individuation residue

Show that a persistent bearer necessarily introduces an irreducible indexical structure such as:

```text
here-for-P
now-for-P
at-stake-for-P
```

and establish why this structure is more than externally assigned relational bookkeeping.

### Route 3 — Differential empirical consequence

Identify a measurable distinction between:

```text
structurally bearing but phenomenally empty candidate
and
structurally bearing phenomenally present candidate
```

that is not defined by report alone.

Until one of these routes is substantially hardened, the most defensible statement is:

> SRT has a strong account of perspective-center formation and a promising constitutive interpretation of phenomenality, but not yet a theorem of phenomenal necessity.

## 15. One-paragraph abstract

Ralph Lewis’s evolutionary synthesis provides SRT with a useful external scaffold—boundary, sensing, learning, memory, representation, valuation, prediction, flexible behavior and self-modeling—but also makes explicit the point at which such scaffolding stops: it does not derive why there is something it is like to be the resulting organism. PH-CONSC04 uses that stopping point to separate two problems often conflated in SRT and neighboring theories: the individuation of a persistent perspective center (HP-A) and the phenomenal necessity of such a center (HP-B). It introduces a Z0–Z6 graded zombie set and a Phenomenal Necessity Deletion Test that asks whether structural bearing, same-bearer consequence return, stake, history, integration and Stable-ISP-compatible continuity make phenomenal emptiness contradictory, predictively distinguishable, or merely verbally excluded. The patch preserves SRT’s strong perspectival and bearer-centered insights while blocking the premature inference `bearing -> phenomenality`.
