## 2. Why this matters for SRT

The source is useful because it supplies a well-formed ordinary mechanism that can mimic several signatures SRT currently studies:

```text
persistent weighting
fixation
slow reallocation
history-conditioned accessibility
switching cost
hysteresis-like persistence
apparent candidate invisibility
```

while preserving a fully shared represented basis.

Its main SRT value is therefore subtractive:

> SRT must not infer basis loss, candidate-generation change, L2 hardening, or Selection-specific dynamics from these signatures until lower-order attention / learning rivals are independently excluded.

At the same time, the source offers a clean calibration distinction between what is represented and what is currently operative.

## 9. Experimental / operational consequences

### 9.1 Representation-vs-operativity assay

Independently measure:

```text
recognition
retrieval
articulation
use when dominant cue is removed
```

and then perturb the candidate dimension while measuring:

```text
valuation
choice probability
reaction time / gaze where appropriate
path or local causal efficacy
```

Behavioral silence should not be classified as basis absence if representation remains demonstrable.

### 9.2 Four-way calibration

Where feasible, construct matched cases:

```text
A = not encoded / absent
B = encoded but negligible online influence
C = encoded and currently operative
D = encoded + operative + later historical writeback
```

This keeps representation, current efficacy and historical efficacy separately measurable.

### 9.3 P24-3 floor challenge with `R_ATT`

A future floor-challenge study should preregister whether the attention rival is allowed:

- latent gain state;
- context modulation;
- bounded additive or multiplicative update;
- attention-dependent learning rate;
- competitive coupling;
- finite history state;
- engagement variation.

Its calibration data, complexity budget, memory window and out-of-sample forecast must be frozen before the challenge.

### 9.4 Same current profile, different history

Matching current measured `w` and `s` across different training histories can test whether those observables form a sufficient state description. A future difference would show omitted state/history, but not SRT-specificity unless the bounded rival's permitted memory architecture was preregistered.

- discrete system-selection architectures could invalidate the smooth weighted-sum form.

## 12. One-paragraph abstract

PH-ATTN01 uses Amornbunchornvej's shared-basis attention model to harden SRT's representation / candidate-field / L2 boundaries without importing a new SRT mechanism. The source shows how persistent disagreement, fixation, slow reallocation and apparent candidate invisibility can arise from relative weighting, total engagement and bounded attention-learning dynamics while representation remains shared. After owner-side subtraction, the retained increment is a diagnostic distinction between representation, weighting, engagement and online operativity plus a source-backed ordinary rival `R_ATT` for P24-3 / P24-4. Reweighting remains distinct from basis or candidate-generator revision, and the source's multiplicative update law, agent assumption and recovery observations are explicitly barred from becoming SRT Selection, bearer, `d`, L2 or history definitions. No D2 claim is made.
