# SRT Philosophy Patch PH-UNC01: Unconscious Involvement / Embodied Belief v0.1

> **Status:** bounded P3 philosophy-of-mind / history / belief / consciousness hardening note.  
> **Canonical caution:** this patch does not redefine `L0/L1/L2`, `d`, `Psi_f`, `T_dir`, `kappa`, Stable ISP, Real Choice Moment, consciousness, embodied position, or stake. It records the bridge pressure that survived a complete close read of Gil Morejón's *The Unconscious of Thought in Leibniz, Spinoza, and Hume* and separates source-backed claims from SRT-side extensions.

---

## 0. Why this patch exists

The book's value for SRT is not the generic claim that unconscious processes exist. Its stronger pressure is architectural:

```text
conscious access
!=
full map of the processes that make thought possible

and

conscious endorsement
!=
sovereign control over the structures that determine later transition and action
```

Across Leibniz, Spinoza and Hume, Morejón reconstructs three different non-conscious structures:

```text
Leibniz -> imperceptible perception below apperceptive threshold
Spinoza -> inadequate ideas / obscure causes / unconscious desire determination
Hume    -> habits that synthesize passages from one idea to another
```

The SRT delta is not to rename these as `L0` or `L2`. The useful pressure is to keep at least four distinctions hard:

```text
non-conscious process != L0
history-conditioned constraint != mere stored memory
conscious report != complete generative cause
repetition != sufficient explanation of belief weight
```

The last distinction is the main SRT-side extension developed here: Hume's repeated conjunction can explain the formation of habitual expectation, but SRT's embodied-position / stake architecture suggests that the **same repeated content can acquire very different governing force depending on where consequences land and what they rewrite**.

## 1. Existing SRT position that must be preserved

The current SRT architecture already contains the following guardrails:

```text
Stable ISP
= persistent perspective center with history-bearing continuity
!= self-consciousness by definition

Real Choice Moment
!= script execution / habit replay / gradient following

L2
!= memory / learned habit / convention by definition

L2 hardening
= reduced local selection cost
+ increased global constraint
+ hysteresis under perturbation

embodied position
= structural location at which consequences can return,
enter anchoring / writeback,
and reconfigure later selection conditions
```

PH-UNC01 must therefore operate as a pressure map and bridge, not a replacement vocabulary.

---

## 2. PH-UNC01-A — thought / consciousness non-identity

Morejón's most stable cross-book claim is:

```text
thought != consciousness
```

but the useful version is stronger than saying that some thoughts are temporarily unnoticed. In the three case studies, non-conscious processes can be **constitutive conditions** of conscious thought:

```text
imperceptible perceptions
-> conscious perceptual integration

inadequate / obscurely involved causes
-> conscious affect and desire

habitual association
-> conscious idea-to-idea passage
```

### SRT bridge

This supports a P3 hardening of the following negative claim:

```text
conscious access to a selection-relevant state
!=
proof that the consciousness layer generated the underlying transition
```

and:

```text
self-consciousness
!=
self-causal transparency
```

A system may describe or monitor its current state without possessing transparent access to the entire historical and embodied process that shaped candidate visibility, salience, friction, expectation, and action readiness.

### Boundary

Do not infer:

```text
unconscious = L0
all preconscious dynamics = L2
consciousness is epiphenomenal
self-report is always confabulatory
```

---

## 3. PH-UNC01-B — sub-threshold structure is not zero structure

Leibnizian petites perceptions supply a bounded threshold pressure:

```text
below conscious integration threshold
!=
nonexistent / causally irrelevant
```

A conscious percept can depend on a multiplicity of sub-threshold differentials that are never individually apperceived.

### SRT bridge

For any future `kappa_c1` or consciousness-threshold exposition, preserve:

```text
threshold crossing
!=
creation ex nihilo from a zero substrate
```

A phase transition can occur on top of already nonzero, structured dynamics. SRT must separately explain what makes the integrated state **bearer-indexed / stake-bearing / subject-relevant**, rather than importing Leibniz's integration structure as a consciousness proof.

### Strong guard

```text
petites perceptions != L0
Leibnizian apperception threshold != kappa_c1
integration threshold != phenomenality proof
```

---

## 4. PH-UNC01-C — conscious equivalence and uncertainty do not establish real openness

Leibniz's rejection of equilibrium indifference and Spinoza's critique of experienced contingency support two negative controls:

```text
conscious equivalence
!=
structural equivalence

subjective uncertainty
!=
structural openness
```

An agent may experience two options as equally weighted while obscure differences already bias the field. Likewise, not knowing what will happen next can reflect inadequate access rather than a genuinely live future branch.

### Relation to Real Choice Moment

This strengthens the **diagnostic discipline** around P1-T05:

```text
felt freedom
felt indecision
introspective unpredictability
```

must not be used as sufficient evidence for a Real Choice Moment.

At the same time, SRT must not follow Spinoza or a deterministic Leibnizian reading into the opposite overreach:

```text
hidden non-equivalence
!=
prior exhaustive determination
```

The bridge therefore protects both sides:

```text
introspective opacity does not prove freedom
but hidden causes do not by themselves disprove structural openness
```

---

## 5. PH-UNC01-D — truth, adequacy and transformation are different axes

The Spinoza chapters support one of the strongest usable distinctions in the book:

```text
epistemic correction
!=
automatic structural rewriting
```

An inadequate idea is partial rather than simply a positive lump of falsity. When a more adequate or true idea appears, the positive determining structure of the prior configuration need not disappear.

For SRT, preserve three analytically distinct layers:

```text
semantic correction
= what proposition is explicitly accepted

causal adequacy
= how much of the relevant generative relation is understood

structural rewriting
= whether later candidate accessibility / cost / salience / response structure actually changes
```

Compact form:

```text
truth
!=
adequacy
!=
transformation
```

### SRT significance

This gives a philosophy bridge for why:

```text
"I know this is wrong"
```

can coexist with persistent history-conditioned selection bias.

A new representation may be added to the system without materially altering the landscape that governs re-entry into old pathways.

### Boundary

Do not identify:

```text
adequacy = SRT agency
Spinoza power = d-value
true idea = high T_dir
inadequate idea = L2 pathology by definition
```

---

## 6. PH-UNC01-E — habit changes transition propensity, not merely stored content

Hume supplies the most direct L2-adjacent bridge.

The important source structure is not:

```text
past -> memory archive
```

but:

```text
repeated conjunction
-> habit
-> altered future idea transition / expectation
```

Morejón explicitly treats habit as a synthetic principle that creates passageways from one idea to another before reflective consciousness registers the relation.

### SRT mapping

| Morejón / Hume | SRT-side bounded interpretation |
|---|---|
| repeated conjunction | history of similar traversals / encounters |
| habit | domain exemplar of history-conditioned transition bias |
| force / vivacity / firmness | idea-level governing efficacy; no identity with SRT scalars |
| automatic transition | low-friction / high-accessibility re-entry candidate |
| correction by contrary habits | history-dependent reselection / landscape rewriting problem |

The safe bridge is:

```text
history can become a condition of future transition
```

not:

```text
Humean habit = L2
```

Current `T-L2-Scaffold` already formalizes a stronger SRT-native mechanism in which successful history can lower compatible future `Psi_f`, amplify accessibility, and eventually background a path as scaffold. Hume contributes philosophical genealogy and a domain exemplar, not a new L2 definition.

---

## 7. PH-UNC01-F — history-conditioned choice is not history-exhausted choice

Morejón's Humean analysis can be misread as proving that all thought is only habit. SRT should instead retain a narrower distinction:

```text
history-conditioned choice
!=
history-exhausted choice
```

Any stable ISP is necessarily history-bearing. Therefore a Real Choice Moment cannot require the absence of habit or inherited constraint.

The relevant question is whether the current live field is fully exhausted by prior scaffold:

```text
L2 constrains A_t
```

does not imply:

```text
L2 fully determines A_t
```

P1-T05 remains the gate for distinguishing a genuinely live anchoring event from script replay or gradient following.

## 8. PH-UNC01-G — belief / fiction requires an embodied-position extension

This is the main **SRT-side increment** produced by the close read and must not be attributed to Morejón.

### 8.1 Hume's source-level result

Hume distinguishes belief from fiction not by semantic content but by **manner of conception**:

```text
same / similar content
+ different force / vivacity / firmness / steadiness
-> different governing influence on action
```

Repeated experience is central to the formation of habitual belief.

### 8.2 SRT residual question

Repeated conjunction alone does not yet explain why the **same proposition or event-class acquires radically different governing weight for different bearers**.

For SRT, ask:

```text
where do the consequences land?
what is at stake for that position?
what is written back into its future selection conditions?
```

### 8.3 Candidate bridge

Let `EP_t` denote an embodied position only as a local shorthand in this patch; it is not a new canonical symbol.

A first bounded schema is:

```text
Encounter_t
x embodied stakes / consequence-bearing position
-> differential writeback
-> altered threshold / accessibility / salience landscape
-> differential governing weight of later representation
```

or more compactly:

```text
belief weight
~ f(repetition, history, stakes, embodied position, consequence)
```

This is a **heuristic P3 bridge**, not a canonical equation.

### 8.4 Belief as reality-guiding uptake

A stronger interpretive candidate is:

```text
propositional assent
!=
embodied belief
```

A representation is belief-like in the relevant SRT sense when it is taken up by a consequence-bearing position as a guide to future world-sensitive prediction and selection.

This helps distinguish a strongly felt fiction from a reality-guiding belief:

```text
bodily affect
!=
belief by itself
```

A horror film can alter heart rate without being admitted into the system's settled expectation that the depicted monster actually structures the surrounding world.

### Failure condition

The embodied-belief extension weakens if stake / consequence-return variables add no discriminating power beyond ordinary associative frequency, recency, reinforcement, and generic affective intensity.

## 9. PH-UNC01-H — correction is historical, not merely propositional

Morejón's Humean conclusion that there is "no outside to habit" yields a useful correction model when combined with SRT writeback:

```text
old habit / scaffold
+ new proposition saying it is wrong
!=
automatic deletion
```

A robust correction generally requires new encounters and new writeback:

```text
new encounter
-> new consequence
-> repeated / sufficiently strong writeback
-> changed accessibility / friction / salience
-> altered future transition
```

This is compatible with the SRT view that the relevant target is not merely represented content but the **future selection landscape**.

### Normative guard

There is no implication that whatever habit survives is justified. Hume's own correction problem includes prejudice: the same machinery that enables practical generalization can generalize irrelevant similarities and suppress relevant differences.

For SRT, this gives a diagnostic question:

```text
which differences actually change the consequences borne by this position?
```

That is not reducible to raw frequency.

## 10. PH-UNC01-I — perspective is differential susceptibility, not just information angle

Leibniz supplies a useful perspective model in terms of differential clarity / obscurity. Spinoza and SRT embodied-position architecture pressure this further.

A future SRT philosophy synthesis should distinguish:

```text
perspective as information access profile
```

from:

```text
perspective as consequence-bearing differential susceptibility
```

A Stable ISP is not merely a system that represents the world from a viewpoint. A stronger candidate is a position for which:

```text
some world differences can enter,
leave history,
alter what matters,
and rewrite future selectability.
```

This is a bridge pressure on the meaning of `perspective-bearing`, not a new P1 definition.

---

## 11. PH-UNC01-J — obscurity and involvement as bridge vocabulary

Morejón's concluding pair is useful if kept non-canonical:

```text
involvement
= non-conscious conditions participate in constituting a conscious mode
without needing to resemble it

obscurity
= those conditions are not thereby rendered transparently accessible
at the conscious level
```

This supplies a vocabulary for avoiding two errors:

```text
unconscious = hidden miniature consciousness
```

and

```text
unconscious = totally unrelated second domain
```

For SRT, `obscure involvement` can be used as descriptive bridge language when discussing how history, bodily conditions, and prior selection constraints participate in current conscious access without being fully represented there.

Do not promote `obscurity` or `involvement` to canonical symbols from this material pass.

## 12. Formal bridge summary

The most useful compact bridge is:

```text
history H_t
+ embodied position EP_t
+ stake / consequence structure S_t
-> history-conditioned accessibility / salience / friction field
-> candidate transition and belief-like governing weight
-> action / selection
-> consequence
-> writeback into H_(t+1), EP_(t+1)
```

with the guards:

```text
Humean repetition != SRT writeback mechanism
force / vivacity != Psi_f
force / vivacity != d-value
embodied position != organism by material definition
belief weight != truth value
conscious report != complete causal explanation
```

This formal bridge is intentionally schematic. It introduces no new owner-level variable.

## 13. Experimental / operational consequences

PH-UNC01 suggests several bounded P4 windows rather than direct empirical predictions from the monograph.

### 13.1 Repetition-only versus embodied-stake model

Compare matched-frequency learning under different consequence-bearing conditions:

```text
MODEL R — repetition-only
belief / transition bias explained by frequency, recency and reinforcement

MODEL E — embodied-stake extension
matched repetition
+ bearer-specific consequence / stake coupling
predicts stronger persistent future-transition bias
```

Failure condition:

```text
if matched history + generic affect explains the full effect,
embodied-stake adds no independent bridge value
```

### 13.2 Semantic correction versus landscape correction

Measure three separable outcomes after an explicit correction:

```text
1. explicit assent changes
2. causal explanation improves
3. automatic choice / salience / avoidance / expectation changes
```

A persistent 1-or-2 without 3 would instantiate the patch's correction distinction without proving any SRT ontology.

### 13.3 Conscious-equivalence control

When subjects explicitly rate alternatives as equal, test whether pre-existing history / bodily stake variables still predict asymmetric transition or choice. This can test:

```text
conscious equivalence != effective equivalence
```

without presupposing metaphysical determinism.

## 16. One-paragraph abstract

PH-UNC01 uses Morejón's full-monograph reconstruction of Leibniz, Spinoza and Hume to harden a non-voluntarist SRT interface without importing their metaphysics. The source supports `thought != consciousness`, sub-threshold constitution, `conscious effect != causal transparency`, `truth != determining efficacy`, and a Humean model in which repeated history changes later transition propensity through habit. SRT's distinct increment is to argue that repetition alone does not explain belief-like governing force: repeated encounters land in embodied positions with different stakes and consequence structures, producing differential writeback into future accessibility, salience and selection. The resulting P3 bridge distinguishes propositional assent from embodied belief, history-conditioned choice from history-exhausted choice, and semantic correction from actual landscape rewriting, while preserving strict guards against `unconscious=L0`, `habit=L2`, `force=Psi_f/d`, consciousness=habit, or Spinozist determinism as SRT.
