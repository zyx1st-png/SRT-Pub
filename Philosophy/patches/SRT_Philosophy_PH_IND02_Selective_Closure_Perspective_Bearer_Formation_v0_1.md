# SRT Philosophy Patch PH-IND02: Selective Closure / Perspective / Bearer Formation v0.1

> **Status:** P3 philosophy-of-mind / individuation bridge and hardening note.  
> **Canonical caution:** this patch does not define individuation, bearer, subjecthood, consciousness, `d`, `Psi_f`, `L0`, Stable ISP, or the Real Choice Moment. It does not modify the canonical claim that selection does not require a prior chooser. It adds a process-level bridge for asking how a temporary selective organization might become a candidate boundary and, under stronger SRT conditions, a continuing bearer.

---

## 0. Why this patch exists

Current SRT already contains the stronger internal thesis that the selector / subject position need not precede selection:

```text
subjectless selection
-> repeated / history-bearing selection pattern
-> condensation into a perspective-bearing position
```

`Core_Law/SRT_Individuation.md` owns that SRT-side theory. `PH-IND01` separately distinguishes individuation from identification:

```text
OBJECT
this one -> still this one -> what this one is

SUBJECT (P3 analogy)
this bearer / from here -> still this bearer -> who I am
```

The Borges source does **not** add a new primitive and does not prove the SRT transition. Its useful increment is narrower:

> It supplies a process vocabulary in which ongoing relational dynamics can undergo `stop / selection`, produce `momentary closures`, establish boundaries, and thereby create a local perspective before any rich self-identification is present.

This patch uses that vocabulary to sharpen the missing middle between generic selective organization and a fully admitted SRT bearer.

---

## 1. Source-backed philosophical structure

Borges's argument, using Developmental Systems Theory, Deleuze/Guattari, Simondon and Bergson, supports the following **author-level philosophical proposal**:

```text
ongoing relational dynamics
-> mutual selectivity / constraint
-> selective stabilization (`stop / selection`)
-> momentary closure
-> boundary / individuated organization
-> system-relative perspective
```

The source also links perspective to contraction-retention in time and uses Prinz's attention theory to describe later selective availability into working memory.

The source does **not** empirically establish that this sequence is necessary or sufficient for biological subjecthood or phenomenal consciousness.

---

## 2. Main bridge claim

### Claim PH-IND02-A — selective closure is a precursor concept, not a bearer definition

A useful P3 route for SRT individuation is:

```text
selective stabilization
-> candidate closure
-> candidate boundary
```

but SRT must not collapse this into:

```text
closure = bearer
```

A temporary closure becomes a stronger bearer candidate only after additional SRT-side questions are answered:

```text
Where do consequences close?
Does history write back into the same continuing unit?
Does the consequence alter that unit's future selectability?
Is the boundary maintained across the relevant time scale?
Can the cost be fully outsourced or reset away?
```

Compact bridge:

```text
momentary closure
+ same-unit consequence return
+ history-bearing writeback
+ future-selectability change
+ boundary continuity
-> stronger bearer candidate
```

This remains a P3 discrimination architecture, not a necessary-and-sufficient theorem.

---

## 3. Boundary formation should be treated as dynamic

### Claim PH-IND02-B — bearer boundaries need not be primitive partitions

The Borges/DST process picture supports a useful caution:

> The relevant unit boundary may itself be an outcome of repeated selective stabilization rather than a boundary that the analyst is entitled to assume at the beginning.

This matters because SRT frequently asks where consequence return and stake close. The safe order is:

```text
candidate selective organization
-> investigate dynamically maintained closure
-> test candidate boundary
-> test consequence-return / history relations
-> only then evaluate bearer / subjecthood status
```

Not:

```text
analyst draws a box
-> all events in the box belong to one bearer
```

### Boundary guard

A dynamically maintained boundary can be physically, biologically, computationally or institutionally realized. The Borges source itself is primarily biological/philosophical and does not establish substrate neutrality; substrate-neutral use is SRT-side extension.

---

## 4. Perspective must be typed before subjectivity claims

### Claim PH-IND02-C — three perspective levels

The source moves too quickly from organization/perspective toward consciousness. SRT should instead distinguish:

```text
PERS-1: system-relative perspective
PERS-2: bearer-relative perspective
PERS-3: phenomenal perspective
```

### PERS-1 — system-relative perspective

A bounded organization has local asymmetries such as:

```text
inside / outside
maintaining / destabilizing
reachable / unreachable
admitted / excluded
```

No phenomenality follows.

### PERS-2 — bearer-relative perspective

Consequences return to the same continuing closure and rewrite that closure's history and future possibilities.

This is stronger than generic system relativity but still does not prove experience.

### PERS-3 — phenomenal perspective

There is actual `for-me-ness` / `what-it-is-like` presence.

Current SRT must keep:

```text
PERS-1 != PERS-2 != PERS-3
```

and align this with `PH-CONSC03`:

```text
Selector
!= Bearer
!= Concern Domain
!= Experiencer
```

### Anti-panpsychism guard

The following inference is blocked:

```text
selection exists everywhere
-> perspective exists everywhere
-> consciousness exists everywhere
```

Even if the first transition is licensed in some broad system-relative sense, the transition to phenomenality remains open.

## 5. Spatial closure and temporal closure

### Claim PH-IND02-D — continuing bearer formation may require temporal closure

Borges/Bergson's contraction-retention language suggests a useful P3 question: a bearer may require not only a spatial or organizational boundary but a cross-time closure in which past consequences remain active in the same continuing unit.

Candidate temporal structure:

```text
selection_t
-> consequence_t
-> retained trace in candidate bearer
-> parameter / boundary change
-> altered reachable space at t+1
-> selection_(t+1)
```

This connects to existing SRT history/writeback language without identifying Bergsonian duration with `L0` or `L2`.

### Temporal-identity guard

```text
mere persistence in time
!= temporal closure
!= bearer continuity
```

A copied state, replayed trace, externally archived history or replaceable instance does not automatically establish that consequences were retained by the same bearer.

```text
CG-0 difference manifestation
-> CG-1 non-equivalent registration
-> CG-2 path efficacy
```

PH-IND02 adds a bounded individuation question between these audit surfaces:

```text
CG-1 / CG-2 repeated selective reorganization
-> can a dynamically maintained closure be identified?
-> does a boundary begin to persist?
-> CG-3: do consequences close on that unit?
-> CG-4: is history written back into that same unit?
```

This is not a new CG stage and does not alter the CG-0..CG-4 framework. It is a cross-reference showing where boundary formation should be audited rather than assumed.

## 7. Attention is a local selective-gating realization, not SRT selection itself

The Borges source uses Prinz's AIR theory to connect attention with working-memory availability.

For SRT the safe use is:

```text
many ongoing processes
-> selective attentional gating
-> working-memory availability
-> possible retention / report / action influence
```

Guardrail:

```text
attention != canonical SRT selection
working-memory access != consciousness proof
reportability != bearer continuity
memory content != historical writeback
```

The useful pressure is to decompose stages that are often collapsed:

```text
bearer-relative occurrence
!= attentional availability
!= working-memory availability
!= memory stabilization
!= reportable self-identification
```

## 8. Relation to PH-IND01

PH-IND01 and PH-IND02 solve different problems.

### PH-IND01

Question:

> Can individuation precede rich identification?

Answer structure:

```text
this one
-> still this one
-> what this one is
```

SRT analogy:

```text
this bearer / from here
-> still this bearer
-> who I am
```

### PH-IND02

Question:

> Before a bearer can be tracked as `this bearer`, what process may establish the candidate closure and boundary on which bearer tests operate?

Answer structure:

```text
selective stabilization
-> momentary closure
-> candidate boundary
-> consequence-return / history tests
-> bearer candidate
```

Thus:

```text
PH-IND02 = formation pressure
PH-IND01 = individuation-vs-identification pressure
```

Neither source proves phenomenality.

## 9. Relation to current SRT individuation theory

`Core_Law/SRT_Individuation.md` remains authoritative for the SRT-side claim that selection does not require a prior chooser and for its current phase-transition / Stable-ISP architecture.

PH-IND02 does not replace its formal or hybrid claims. It contributes three bridge-level questions for future hardening:

1. Can `momentary closure` be operationalized without presupposing the bearer boundary?
2. Which closure properties distinguish a transient organization from a same-bearer consequence loop?
3. Is temporal retention of consequence-bearing history required for the transition from local perspective to continuing bearer position?

Any future synthesis must check these questions against the current `sigma_sr` formalism rather than introducing a parallel individuation theory.

## 10. Consciousness pressure

The source is useful partly because its panpsychist move exposes a failure mode SRT must avoid.

Borges's broad route is:

```text
organization
-> perspective
-> consciousness as degree
```

SRT hardening requires:

```text
organization
-> candidate perspective
-> candidate bearer tests
-> subjecthood tests
-> phenomenality remains separately open
```

This aligns with current consciousness guardrails:

```text
perspectival difference != metaphysical dualism
perspective != subjectivity
bearing_candidate != phenomenality proof
```

The Borges source therefore functions both as convergence and as a negative-control example of an over-fast transition.

## 11. What this patch does not claim

Do not infer from PH-IND02:

```text
all closures are agents
all boundaries are bearers
all bearers are conscious
all perspectives are phenomenal
all selection is attention
all retention is L2
L0 = intensive matter / Bergsonian duration
chaos = consciousness
panpsychism follows from SRT
```

Do not use Borges as empirical evidence that consciousness exists in simple organisms or inorganic matter.
