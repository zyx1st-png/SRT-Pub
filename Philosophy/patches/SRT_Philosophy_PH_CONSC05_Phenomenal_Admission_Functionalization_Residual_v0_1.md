# SRT Philosophy Patch PH-CONSC05: Phenomenal Admission / Functionalization Residual v0.1

> **Status:** P3/P4 philosophy-of-mind hardening patch.  
> **Canonical caution:** this file does not define consciousness, phenomenality, bearer, subjecthood, `d`, `Psi_f`, `T_dir`, Stable ISP or qualia. It extends PH-CONSC03/04 by sharpening the residual question after bearer, indexicality, self-location and history-sensitive ownership have all been specified. It must not be cited as a theorem that phenomenality is reducible, irreducible, physical, non-physical, or already derived.

---

## 0. Why this patch exists

PH-CONSC03 separates:

```text
Selector != Bearer != Concern Domain != Experiencer
```

PH-CONSC04 then separates:

```text
HP-A = perspective-center individuation
HP-B = phenomenal necessity
```

PH-IND04 adds the non-jump ladder:

```text
Object !-> Bearer !-> Selector !-> Subject !-> Experiencer
```

and introduces the pressure:

```text
Structural Bearing
->? Indexical For-P
->? Phenomenal For-me
->? Qualitative Character
```

The present patch asks a narrower question:

> If `For-P` is made maximally strong — bearer-indexed, history-constitutive, self-locating, non-substitutable, action-guiding and future-selectability-changing — what, if anything, is still missing before phenomenal presence is licensed?

This is the **Phenomenal Admission Problem**.

---

## 1. First-person language is overloaded

SRT should distinguish at least two meanings of “first-person”.

### 1.1 Indexical first-person

A system can represent or use information as:

```text
I / here / now / mine / this is happening to me
```

This includes self-location, de-se organization, ownership tagging and action control.

Working label only:

```text
FP_indexical
```

### 1.2 Phenomenal first-person

A stronger claim is:

```text
there is something it is like here at all
```

Working label only:

```text
FP_phenomenal
```

Guard:

```text
FP_indexical != FP_phenomenal proved
```

No canonical symbol is introduced.

---

## 2. Three grades of `For-P`

### F0 — external attribution

An observer can state:

```text
event e damages / benefits system P
```

This is fully third-personal.

### F1 — self-locating / de-se organization

P uses the information as about itself:

```text
this event concerns me / my body / my continuation
```

This may change action even when the equivalent non-indexical information was already represented.

### F2 — bearer-constitutive `For-P`

The event does not merely get tagged as “mine”; it is written into the same continuing bearer and changes what futures remain available to that bearer:

```text
P_t
-> event e_t
-> same-bearer consequence return
-> history writeback
-> Omega_P(t+) differs from Omega_P(t-)
```

This is stronger than self-description. It is compatible with PH-QUAL01's event-local `RDef_B(q_t)` interface and PH-CONSC03's structural bearing work.

### Guard

Even F2 should not be promoted by definition to phenomenality:

```text
strong For-P != For-me proved
```

---

## 3. Four tempting but insufficient bridges

The following relations may be necessary, useful or biologically important. None currently closes HP-B by itself.

### 3.1 De-se / self-location

```text
de-se organization !-> phenomenality
```

A system may use self-locating information for control without thereby proving phenomenal presence.

### 3.2 Non-substitutability

```text
non-resettable / non-transferable history !-> phenomenality
```

Numerical continuity and non-replaceability can establish a stronger bearer without establishing experience.

### 3.3 Participatory bearing

Working idea:

```text
P does not merely represent event e;
e participates in constituting P_(t+1)
```

This is stronger than representation, but constitutive state update can occur in non-phenomenal candidate systems.

Therefore:

```text
participation !-> phenomenality
```

### 3.4 Access asymmetry

Internal and external positions may have different access routes:

```text
internal event != external re-objectification
```

This remains an important anti-view-from-nowhere guard, but epistemic/access asymmetry is not sufficient for phenomenality. Many non-conscious systems have privileged internal state-access relations.

Therefore:

```text
access asymmetry !-> phenomenality
```

## 4. Fully Functionalized Zombie Test `Z*`

PH-CONSC04's Z6 can be strengthened by preserving every current structural enrichment.

Define a test case `Z*` with:

```text
persistent bearer
+ same-bearer consequence return
+ non-trivial stake
+ history writeback
+ changed future selectability
+ counterfactual alternatives
+ Stable-ISP-like continuity
+ de-se / self-location
+ explicit self-model
+ non-substitutability / no trivial rollback
+ participatory state update
+ affective readout
+ global / cross-domain access
+ report capacity
+ NO phenomenal presence
```

Question:

> Is `Z*` formally contradictory under current SRT, or merely intuitively uncomfortable?

If no independently justified condition is lost when the last line is added, HP-B remains open.

### Burden rule

A candidate phenomenal-admission condition is not explanatory merely because `Z*` is defined to lack it. It must add a constraint with independent content, discriminatory consequences, or a non-circular constitutive argument.

## 5. Permutation / bearer-isomorphism test

Let two candidate bearers `P` and `Q` have an isomorphism `phi` preserving all declared third-person structural relations:

```text
history
stakes
self-model
counterfactual structure
bearer continuity
RDef profiles
self-location relations
affective readout
functional organization
```

Ask:

> After all bearer-relative structure is preserved under `phi`, is there any further fact that fails to be preserved and is required for phenomenal presence?

Candidate use:

```text
phenomenal residual candidate
= whatever is not exhausted by the declared bearer-preserving isomorphism
```

This is a test schema, not an assertion that such a residual exists.

### Haecceity guard

Do not confuse phenomenal residual with bare numerical thisness:

```text
P != Q
```

is true for two stones as well. Therefore:

```text
numerical identity / haecceity != for-me-ness
```

unless an additional argument is supplied.

---

## 6. Copy–Branch Test

Suppose one bearer is duplicated at `t0`:

```text
P -> P1 + P2
```

with matched prior history at the branch point. After `t0`, event `e1` affects only `P1`:

```text
e1 -> Omega_P1 changes

e1 -/-> Omega_P2 changes
```

SRT can use this to sharpen bearer individuation and ownership:

```text
why this consequence belongs to P1's future rather than P2's
```

But this still does not answer:

```text
why P1's update is felt
```

Therefore copy/branch arguments are strong HP-A tools and weak HP-B proofs.

---

## 7. Metaphysical-gap dissolution and phenomenal admission are different tasks

A central hardening result is:

```text
No ontological gap
!->
Every structurally suitable bearer is conscious
```

SRT may have a strong argument against the following inference:

```text
first-person description differs from third-person description
therefore two ontological substances are required
```

because both descriptions are situated selections / objectifications rather than one being a view from nowhere.

That **metaphysical-gap dissolution** does not by itself solve the **phenomenal-admission problem**:

> Which systems / events actually instantiate phenomenal presence?

This permits a stable middle position:

```text
first-person and third-person are not two worlds
AND
phenomenal admission remains a substantive open question
```

## 8. Four-question hard-problem map

This patch proposes the following **working decomposition only**. It does not replace PH-CONSC04's canonical patch namespace.

### HP-0 — metaphysical-gap / view-from-nowhere question

Why does descriptive-perspectival difference not automatically imply a second ontology?

SRT has substantial resources here through situated access and external re-objectification.

### HP-A — perspective-center individuation

Which continuing unit bears consequences, history, stakes and future-selectability change?

SRT has substantial resources here through PH-IND01/02/04 and PH-CONSC03.

### HP-B — phenomenal admission / necessity

Which admitted bearers actually instantiate phenomenal presence, and why?

Open.

### HP-C — qualitative character

Given phenomenal presence, why does experience have this organization rather than another?

SRT has the current three-factor anchor plus PH-QUAL01's forward-facing `RDef_B(q)` bridge.

Guard:

```text
solving HP-0 or HP-A != solving HP-B
solving HP-B != solving HP-C
```

---

## 9. Three live routes for HP-B

### Route A — constitutive identity

Strong hypothesis:

```text
complete situated bearing
= phenomenal occurrence viewed internally
```

This is closest to the current strong wording in `SRT_HardProblem_Epistemology §3.2`.

Burden:

- show non-circularly why `Z*` is contradictory;
- do not define “complete bearing” as “bearing that is experienced”;
- distinguish metaphysical identity from empirical detection.

### Route B — additional organizational / physical gate

Hypothesis:

```text
structural bearer package + X -> phenomenal admission
```

where `X` could be a yet-unspecified organizational or physical property.

Burden:

- define `X` independently;
- produce discriminating predictions;
- explain why `X` is not merely another functional correlate.

### Route C — dissolve the metaphysical derivation demand but leave admission open

Claim:

```text
science need not derive first-personality from a fictional view-from-nowhere
```

while retaining:

```text
which systems are phenomenal? = open empirical/constitutive admission problem
```

This is currently the safest high-level SRT stance because it preserves the perspectival critique without declaring Z6/Z* solved by definition.

## 12. Relation to NEURAL24

NEURAL24 supplies a biological realization candidate:

```text
continuous interoceptive / homeostatic readout
-> organism-indexed action relevance
-> bearer-indexed content
```

Its own strongest pressure remains valid:

```text
for-this-bearer relevance
!= what-it-is-like derived
```

Therefore affective or interoceptive indexing may strengthen HP-A and supply empirical candidate gates, but cannot be promoted into HP-B sufficiency without separate evidence.

---

## 13. Failure conditions

PH-CONSC05 should be downgraded or absorbed if one of the following occurs:

1. an existing canonical theorem already gives a non-circular contradiction for `Z*`;
2. `FP_indexical / FP_phenomenal` adds no discrimination beyond PH-CONSC03/04 terminology;
3. the permutation and copy-branch tests reveal no new inferential burden beyond existing Z6;
4. owner hardening resolves HP-B with an explicit author-level constitutive commitment and defends it independently.

Until then, the patch functions as an anti-overclaim and admission-gate scaffold.

---

## 14. Final synthesis

The strongest current SRT-compatible statement is:

> SRT can increasingly explain how a `here` is individuated without presupposing a prior subject, how consequences become the consequences of one continuing bearer, and how those consequences rewrite that bearer's future selectability. It can also reject the inference that first-person / third-person descriptive difference requires two ontologies. But from maximally specified `for-this-bearer` structure to phenomenal `what-it-is-like-for-this-bearer`, no non-circular sufficient bridge is yet established. That remaining burden is the Phenomenal Admission Problem.

Compact guard:

```text
For-P can be structurally deep
without For-me being proved.
```
