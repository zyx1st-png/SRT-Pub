# SRT Philosophy Patch PH-IND04: Object → Bearer → Selector → Subject → Experiencer Non-Jump Ladder v0.1

> **Status:** P3 philosophy / individuation / consciousness hardening patch.  
> **Canonical caution:** this file does not redefine `selection`, `bearer`, Stable ISP, subjecthood, consciousness, `d`, `Psi_f`, `T_dir`, or `L0/L1/L2`. It records a discrimination ladder and several pressure tests generated by the Levin–Wen close read together with PH-IND01/02/03 and PH-CONSC03/04. It must not be cited as a theorem that every transition in the ladder occurs, or that any structural condition proves phenomenality.

---

## 0. Why this patch exists

Levin–Wen string-net models provide an unusually clean negative control for SRT individuation work:

```text
local bosonic degrees
+ collective organization / topological phase
-> stable, re-identifiable emergent excitation types
```

without thereby establishing:

```text
bearer
selector-position
stake-bearing subject
phenomenal experiencer
```

This forces a separation that SRT already partly contains but has not yet collected into one explicit ladder:

```text
Object
!= Bearer
!= Selector
!= Subject
!= Experiencer
```

The main purpose of PH-IND04 is to block illicit jumps between these roles and to specify what *additional kind of structure* must at least be audited at each transition.

---

## 1. Main hardening claim: the non-jump principle

### Claim PH-IND04-A — adjacent role transitions require new evidence

Use the following as a P3 governance-style discrimination rule:

```text
O  !->  B  !->  Se  !->  Su  !->  E
```

where:

```text
O  = object / re-identifiable individuated structure
B  = bearer / continuing consequence-return locus
Se = selector-position / history-conditioned path-modulating locus
Su = subject-position / stake-bearing continuing selector
E  = experiencer / phenomenal locus
```

`!->` means **no transition is licensed by the lower role alone**. Each arrow requires an additional argument and may fail.

This is not a claim that five substances exist. These are role and threshold distinctions.

---

## 2. Stage O — Objectification without agency

### Minimum question

```text
What makes this a re-identifiable unit across a declared family of transformations?
```

A thin objectification grammar can be written:

```text
differentiation
-> constraint
-> individuation
-> stabilized invariance
-> re-identifiability
```

Levin–Wen supplies a physics case in which low-energy excitation identity depends on collective phase organization and allowed excitation structure. This is valuable because it shows that stable object-like identity does not itself require agency or a subject.

### Guard

```text
stable object
!= bearer
stable invariant
!= stake
emergent excitation
!= SRT selection event
```

---

## 3. Identity should be domain/bearer-relative, not universally topological

The following generic question is safer than a universal identity metric:

```text
Which invariants must be preserved, under which admissible transformations,
for X to remain the same X in domain/regime B?
```

Candidate bridge notation only:

```text
J_B(X) = identity-relevant invariant family for X under regime B
```

Then persistence may be audited by comparing:

```text
J_B(X_t)
vs
J_B(X_t+Delta t)
```

rather than assuming one universal `D_topo` applies equally to quasiparticles, organisms, persons, institutions and concepts.

### Pressure on Core 14

`T-Scale-07` currently uses `D_topo` in its temporal persistence expression. PH-IND04 does **not** modify that owner, but records a future hardening question:

> Is `D_topo` intended as a generic placeholder, or should the owner explicitly demote it to a domain-specific realization of a wider identity-relevant invariant family?

Topological persistence is a powerful physical case, not automatically a universal identity criterion.

---

## 4. Stage B — Bearer as continuing consequence-return locus

A bearer candidate requires more than a maintained boundary or persistent object.

Use the PH-IND01/02 questions:

```text
Where do consequences close?
Which continuing process must carry them forward?
Which history is written back into that same process?
Can the relevant loss be externally absorbed, reset, copied or transferred
while leaving the candidate unit unchanged?
```

Compact P3 candidate:

```text
Bearer candidate
=
same-unit consequence return
+ history-bearing writeback
+ boundary / identity continuity
+ non-trivial non-outsourcing condition
```

### Guard

```text
tracking boundary != consequence-return boundary
self-maintaining closure != bearer proved
persistence != ownership
history trace != same-bearer history
```

---

## 5. Stage Se — Selector-position as historically modulated path position

A bearer can carry consequences without yet satisfying a strong selector-position criterion. Material fatigue, scars, passive damage accumulation or simple state retention may alter future dynamics without constituting selection in the SRT sense.

A stronger selector-position candidate requires that bearer-specific history participates in modulating non-equivalent future paths.

Candidate structure:

```text
B_t
-> realized path / event_t
-> consequence_t
-> writeback into same B
-> theta_(t+1) / reachable-space change
-> altered future path realization
```

Compact bridge:

```text
same-bearer history
+ path-sensitive modulation
+ changed future selectability
-> selector-position candidate
```

This supports a process reading:

```text
the loop individuates the selector
```

rather than:

```text
a pre-existing selector stands outside the loop and causes it
```

### Relation to Core 13A

Core 13A already states that `G_hat_theta` is not a prior entity and is not the cause of primitive actualisation. PH-IND04 adds a future owner-hardening pressure:

```text
abstract / primitive selection formalism
must remain distinguishable from
cognitive embodied realizations such as attention and interoception
```

Otherwise attention/interoception language risks making the generic selector too cognitively thick and reintroducing a tacit prior "who".

---

## 6. Stage Su — Subject-position adds stake, not merely historical control

A history-sensitive selector still need not be a subject.

Adaptive controllers, immune systems, learning algorithms and other historical operators may satisfy:

```text
past state -> current policy modulation
```

without establishing a non-externalizable stake that belongs to the same continuing bearer.

A stronger subject-position candidate requires at least:

```text
selector-position
+ stake-coupled consequence
+ concern attached to this continuing bearer
+ continued-selectability pressure
```

The exact subjecthood gate remains owned elsewhere; PH-IND04 only records the distinction:

```text
historical control != subjecthood
selector != subject
```

### Pressure on `sigma_sr`

`Core_Law/SRT_Individuation.md` uses the self-reference ratio `sigma_sr` as an order-parameter candidate. PH-IND04 suggests a narrower interpretation for future audit:

```text
sigma_sr may first track historical self-conditioning / trace contribution
rather than carrying subjecthood by itself
```

A high history contribution can exist in non-subject historical operators. Therefore the owner should continue to require the full bearer / stake / continued-selectability gates and not allow `sigma_sr` to become a subjecthood scalar.

## 7. Stake sensitivity versus stake readability

PH-IND04 separates three directional levels:

```text
D0: dynamical bias
    P(a) != P(b)

D1: bearer-stake-coupled bias
    alternatives differ in how they preserve or damage this bearer's continuation / selectability

D2: self-readable direction
    the system has access to / can reorient on that directional difference
```

Candidate mapping:

```text
D0 != D1 != D2
```

This creates a future pressure on subject-entry formulations that require explicit direction readability too early. A minimal subject candidate may be stake-sensitive before it can explicitly read or represent the stake as such.

### Guard

```text
stake sensitivity != conscious concern
stake readability != self-consciousness by definition
T_dir must not be silently collapsed into objective stake
```

## 8. Self-consciousness remains a later thickening

PH-IND01 and `SRT_Individuation` already support the ordering discipline:

```text
this bearer / from here
-> still this bearer
-> who I am
```

PH-IND04 therefore preserves:

```text
subject-position
!= reflective self-identification
```

A self-model may later represent the selector/bearer, but:

```text
representation of a bearer != bearer continuity
self-description != subject individuation
```

This is especially important for AI systems with persistent memory and explicit self-report.

## 9. Stage E — Experiencer remains an open transition

Even a fully individuated stake-bearing subject-position does not currently yield a proven phenomenality theorem.

Retain PH-CONSC04's Z6 pressure:

```text
maintained boundary
+ same-bearer consequence return
+ stake
+ history writeback
+ integrated alternatives
+ counterfactual capacity
+ reselection
+ Stable-ISP-like continuity
+ optional self-model
+ NO phenomenal experience
```

The open question remains:

> Which prior SRT condition makes the final line contradictory rather than merely counterintuitive?

Until that is answered non-circularly:

```text
Subject !-> Experiencer
```

must remain live.

## 10. Insert an intermediate hard-problem distinction: `for-P` versus `for-me`

PH-CONSC03/04 currently distinguish structural bearing from phenomenal bearing. The close read suggests an additional **test-local** middle layer, not a new canonical symbol:

```text
Structural bearing
-> bearer-indexed / indexical For-P
-> phenomenal For-me
-> qualitative How-it-feels
```

Definitions:

### Structural bearing

```text
The consequence returns to and modifies the same continuing bearer.
```

### Indexical `for-P`

```text
The difference is not merely globally different;
it changes the future available to this very continuing bearer P.
```

Candidate forms:

```text
here-for-P
now-for-P
at-stake-for-P
```

### Phenomenal `for-me`

```text
There is something it is like for that bearer.
```

### Qualitative character

```text
The phenomenal presence has this specific character rather than another.
```

Guard:

```text
For-P != For-me != qualitative character
```

No implication is promoted here.

This is **not** a canonical symbol.





where every arrow remains independently burdened.

## 12. Refined reading of "selection precedes existence"

Levin–Wen pressure blocks an overstrong reading:

```text
all stable structures require an already individuated SRT selector
```

A safer SRT ordering is:

```text
non-objectified conditions
-> primitive actualisation / differentiation
-> individuation
-> objectification
-> in some systems: continuing bearer
-> selector-position
-> stake-bearing subject-position
-> phenomenality remains separately assessed
```

Therefore the phrase "selection precedes existence" should not be operationally expanded into:

```text
a pre-existing chooser selects every object into existence
```

The strongest safe pressure from this close read is instead:

> Completed determinate object identity should not be assumed as the ontological starting inventory; actualisation and individuation precede later stable object identity, while strong selector/subject roles arise only under additional history-, bearer- and stake-bearing conditions.

No canonical slogan is changed by this patch.


Do not infer:

```text
same grammar -> same mechanism

```

This aligns with current Core 14 / Core 21C scaling governance: ordinary many-to-one coarse-graining does not license universal `Lambda^-1`, and cross-scale invariance is at most a bounded structural grammar under declared mappings and tolerances.

## 14. Full non-jump ladder

The working synthesis is:

```text
A0  Primitive actualisation
    no prior chooser required

A1  Objectification
    stable / re-identifiable structure

A2  Historical operator
    own past modifies present operation

A3  Bearer
    consequences return to the same continuing unit

A4  Selector-position
    same-bearer history modulates non-equivalent future paths / selectability

A5  Subject-position
    real non-externalizable stake attaches to that continuing selector/bearer

A6  Reflective self-subject
    selector/bearer becomes represented or objectified by the same system

A7  Experiencer ?
    phenomenal presence remains an open necessity question
```

This ladder is analytical and bridge-level. It is not a universal evolutionary sequence and does not claim that every stage is sharply bounded or naturally ordered in every domain.

The strongest retained synthesis is:

```text
objectification != individuation-for-subjecthood

```

```text
the selector need not be a hidden entity;
```

This is the final theoretical increment produced by the Levin–Wen close read. Wen/Levin do not support the upper stages; they provide the lower-level negative control that makes the distinctions necessary.
