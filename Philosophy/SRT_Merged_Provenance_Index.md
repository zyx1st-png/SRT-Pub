# SRT Merged Provenance Index

> **Role**: This file records where dialogue-hardened bridge/supplement documents have been merged into the canonical corpus. It is not a doctrinal text. It is a navigation and provenance layer.

---

## Why this file exists

As the repo grows, some ideas are first hardened in temporary bridge or supplement documents and only later merged back into canonical main texts.

Without an index, this creates two recurring problems:

1. readers are unsure which file currently carries doctrinal authority
2. old bridge files may continue to look like parallel doctrine even after merge

This index exists to prevent that drift.

---

## Current rule for reading merged material

When a bridge/supplement file has:
- `status: merged_index_v1`
- `claim_mode: archival_index`

then it should be read as:

> **merge provenance / staging history, not current doctrinal center**

Primary doctrinal authority belongs to the canonical target files listed below.
