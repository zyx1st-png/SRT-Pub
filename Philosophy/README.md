# SRT Philosophy — Section Guide

> **Purpose**: This folder translates SRT into philosophical language: ontology, epistemology, phenomenology, ethics, political philosophy, and social theory. It is an **interpretive bridge**, not the canonical source for primitive SRT definitions.

## 1. What this section is for

The Philosophy section should help readers answer four questions:

1. **Ontology** — What does SRT mean by existence, manifestation, and stabilization?
2. **Epistemology** — Why are knowing, experiencing, and describing not the same operation?
3. **Normativity** — How do values, duties, institutions, and responsibility emerge from selection history?
4. **Boundary problems** — How does SRT diagnose paradox, explanatory gaps, relativism, and pluralism?

The section is strongest when it does **not** claim to replace all philosophy. Its job is to show how classic philosophical problems can be re-expressed as selection, anchoring, compression, stabilization, and boundary-cost problems.

## 3. Claim-level discipline

Philosophy files often use words like “axiom,” “theorem,” and “ontology.” In this folder these terms are usually **domain-mapping terms**, not always canonical mathematical definitions.

| Claim type | Meaning in this folder | Editing rule |
|---|---|---|
| P0/P1 | Primitive or canonical SRT definition | Do not define here; link to Core / Core_Law. |
| P2 | Philosophical interpretation of a canonical structure | Keep explicit dependency anchors. |
| P3 | Comparative bridge to existing philosophy | Name what is being mapped and what is not being claimed. |
| P4 | Operational or falsifiable candidate | Include proxy, prediction, and withdrawal condition. |
| P5 | Pedagogical summary or public-facing language | Allowed to be vivid, but must not silently upgrade into P2/P3. |

**Default rule**: when in doubt, weaken a philosophical claim by adding its scope, dependency, and failure condition.

## 4. Core philosophical position

The cleanest summary is:

> SRT is not idealism, physicalism, dualism, or panpsychism in the ordinary sense. It is a **selection-first ontology**: existence becomes determinate only through constrained selection from a latent field into manifest and stabilized structures.

Minimal chain:

```text
L_0 latent possibilities
  --[ embodied selection: G_theta, paying Psi_f ]-->
L_1 manifest experience / event / object
  --[ stabilization, repetition, intersubjective closure ]-->
L_2 norm / language / institution / law / habit
  --[ downward constraint ]-->
future G_theta
```

Philosophical slogan:

> **What can be constructed is the interpretive cut; what cannot be waived is the cost of anchoring.**

## 5. Anti-misreading guardrails

| Misreading | Better SRT reading |
|---|---|
| “SRT says everything is consciousness.” | No. SRT says manifestation depends on selection; consciousness is one high-complexity selection regime, not the only one. |
| “SRT is subjective idealism.” | No. `theta` filters, but `Psi_f` resists. Reality is participatory, not arbitrary. |
| “SRT is just physicalism with new terms.” | No. It treats physical descriptions as powerful `L_2` stabilizations, not as the whole structure of manifestation. |
| “SRT is panpsychism.” | Not directly. Micro-scale selection does not automatically imply macro-conscious subjects. Subjecthood requires further closure, `d-value`, and integration conditions. |
| “SRT dissolves all paradoxes.” | No. It diagnoses many paradoxes as boundary failures; formal paradoxes still need technical treatment inside their own systems. |
| “SRT rejects representation.” | No. It rejects representation as the universal first principle; representation is task-local and may be useful when it lowers selection cost. |

## 6. Current optimization targets

The Philosophy folder should gradually move toward this architecture:

1. **Compact entry first** — short files should lead, long files should serve as archives and derivation layers.
2. **No duplicate canonical definitions** — core terms should be linked, not redefined.
3. **Objection-led hardening** — each major claim should include the strongest objection and what must be withdrawn if the objection succeeds.
4. **Layer separation** — avoid mixing ontology, phenomenology, ethics, neuroscience, and politics without explicit bridge labels.
5. **Public vs academic voice separation** — slogans are useful in public texts; academic files should keep scope and claim levels visible.

## 8. Safe editing protocol

Before adding new philosophy material, classify it:

```text
Is this a core SRT definition?      -> put it in Core / Core_Law, not here.
Is this a philosophical reading?    -> keep it here, mark P2/P3.
Is this an experimental prediction? -> mark P4 and add failure conditions.
Is this a slogan or explanation?    -> mark P5 and prevent claim upgrade.
```

A good Philosophy edit should make SRT **harder to misread**, not merely more impressive.
