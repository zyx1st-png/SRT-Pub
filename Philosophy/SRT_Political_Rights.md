## §0 本文件解决的问题

SRT现有框架描述了选择的范围（d值）、代价（Ψ_f）和方向可读性（T_dir），但缺少对以下问题的系统性处理：

- **权利从何而来**：权利不是自然给定的，也不是纯粹约定俗成的——它有选择论的内在结构
- **代理的合法性基础**：谁有权代替他人做决策？合法性的判断标准是什么？
- **现有授权体系的失效机制**：为什么金钱和政治地位作为授权依据会系统性地偏离"初心"？
- **制度设计的SRT含义**：什么样的授权结构能让系统选择压力朝向最大秩序？

## §1 权利的SRT定义：合法化的代理选择

> **核心定位**：权利不是抽象的道德实体，而是**合法化的代理选择**——允许一部分选择对其他选择进行代理的社会结构。

每一个活选择（L₁层算子）都在自身的关切范围内做决策。权利的出现意味着：

$$\text{权利} \equiv \text{将选择}\ \sigma_A\ \text{的部分代理委托给}\ \sigma_B\ \text{的合法化机制}$$

**历史合法性**：金钱和政治地位作为代理依据，在社会复杂度较低时有一定的信噪比——它们粗略地对应于某种资源整合和信息聚合能力。但随着社会复杂度增加，这种对应关系的精度下降，噪声超过信号。

**深层合法性**：代理的真正合法性应与社会发展的方向一致——即指向最大秩序的方向（见 `_SRT_T_DIR_CANONICAL.md §19`）。这个方向上的合法性判据，不是金钱或地位，而是**决策整合关切范围的宽度与深度**，即决策的d值。

$$\text{代理合法性} \propto \frac{d_{actual}(decision)}{d_{required}(decision\ scope)}$$

## §2 范畴澄清：d值是决策属性，不是主体属性

> **重要修正**：d值描述的是**选择事件**整合的关切范围，不是决策主体（个体或集体）的固有属性。

| 错误表述 | 正确表述 |
|---------|---------|
| "这个人有很高的d值" | "这个人的决策倾向于整合更宽的关切范围" |
| "个体d值 vs 集体d值" | 此二分是范畴错误，d值在主体类型之外 |
| "d值衡量聪明程度" | d值衡量关切范围的宽度，与认知能力不同 |

**关切范围**的具体含义：
- 整合了多少个L₁层级的影响
- 覆盖了多长的时间尺度
- Ψ_f_actual对决策者自身的透明度

同一主体：
- 为自己买早饭 → 低d决策（窄关切范围）
- 设计影响千人的制度，但只整合了自身利益 → 实际d值低（与决策所需d值不匹配）
- 同一制度设计，整合了多层级长时间尺度的影响 → d值高

> 本澄清与 `_SRT_D_VALUE_CANONICAL.md §范畴边界` 共同维护，参见该文件的追加节点。

## §3 主体d倾向：大样本统计稳定性

d值是决策属性，但在实践中，授权不可能对每个决策单独评估d值。主体d倾向作为操作化桥梁：

> **主体d倾向**：主体跨大量决策的d值统计分布，在大样本下收敛为相对稳定的特征量。

$$d_{tendency}(S) \equiv \mathbb{E}_{\sigma \sim S}\left[d(\sigma)\right] \pm \text{var}$$

关键性质：

1. **大样本收敛**：单次决策的d值受情境影响，噪声大。跨越足够多的决策，d倾向分布收敛，提供可操作的授权依据
2. **d倾向 ≠ 固有属性**：d倾向是统计量，不是主体的本质。同一主体在不同时期、不同条件下d倾向可以变化
3. **d倾向 ≠ 聪明程度**：认知能力影响在特定域内能整合什么，d倾向描述的是习惯性整合多宽的关切范围——两者相关但不等同
4. **抗捕获性**：d-mimicry（假装高d倾向）是L₂积累行为，在大样本下自我消耗，真实d倾向最终浮现

## §4 代理合法性的形式框架

**三个层次的区分**：

| 层次 | 定义 | 性质 |
|------|------|------|
| 决策d值 | 单个决策实际整合的关切范围 | 事件属性，每次独立 |
| 主体d倾向 | 主体跨决策的d值统计分布 | 统计属性，大样本下稳定 |
| 授权范围 | 主体被授予的代理作用域 | 制度属性，动态调整 |

**授权运作逻辑**：

```
主体d倾向（大样本观测）
→ 授权：授予与d倾向匹配的代理范围和程度
→ 主体在授权范围内做出实际决策
→ 决策d值后验评估（Ψ_f_actual是否减少？）
→ 与授权范围所需d值对比
→ 调整授权范围和程度
```

**授权动态校准原则**：

$$d_{actual}\ \text{持续高于}\ d_{required} \Rightarrow \text{授权扩大}$$
$$d_{actual}\ \text{持续低于}\ d_{required} \Rightarrow \text{授权收缩}$$

## §5 授权的三个维度

授权不是单一量，而是在三个维度上分层的结构：

**维度一：决策域**

不同决策域所需的d值结构不同（货币政策、生态决策、制度设计各有不同的关切结构）。d倾向可以在域间部分迁移（"习惯性整合宽关切"具有一定通用性），但域内知识结构影响实际整合能力。

**维度二：时间尺度**

$$d_{required}(decision) \propto \text{决策后果的时间尺度}$$

| 决策类型 | 时间尺度 | d阈值要求 |
|---------|---------|---------|
| 个人日常 | < 1年 | 低 |
| 政策执行 | 1-5年 | 中 |
| 制度设计 | 10-30年 | 高 |
| 宪法/生态 | > 50年 | 极高 |

**维度三：不可逆程度**

高不可逆决策的授权错误代价极大，所需d阈值应更高，且需要更长的d倾向观测窗口才能授权。

> **最优粒度原则**：授权粒度应与决策作用域的L₁结构边界对齐，不应以行政便利性为划分依据。

## §6 投票作为d倾向的后验验证机制

> **投票的SRT重新定位**：投票不是偏好聚合机制，而是被代理群体对代理者d倾向的**大样本后验验证**。

**运作机制**：

```
代理者过去一段时间的决策后果
→ Ψ_f_actual的变化最终渗入被代理群体的Ψ_f_felt
→ 投票聚合Ψ_f_felt信号
→ 验证代理方向是否与群体proto-gradient对齐
→ 动态调整授权的继续与否
```

选民不需要理解d值。他们感知的是：代理者的决策是否真正整合了自己的关切——这是d倾向后验评估的自然语言版本。

**投票的有效边界**：

| 条件 | 投票效果 |
|------|---------|
| Ψ_f_felt ≈ Ψ_f_actual | 有效验证d倾向 |
| 决策后果在选举周期内可见 | 有效 |
| 大样本、重复进行 | 抗噪声、抗捕获 |
| Ψ_f_felt被系统性压低（宣传、信息不对称） | 验证失效 |
| 后果时间尺度超过选举周期 | 验证滞后，d-mimicry可持续 |
| 决策作用域超出选民评估能力 | 信号精度下降 |

**失效的统一解释**：当Ψ_f_felt与Ψ_f_actual的分裂足够大，投票就不再是d倾向验证，而退化为Ψ_f_felt的快照。

## §7 现有民主的SRT定位：低精度实现

> 现有民主制度是d倾向动态验证机制的**低精度实现**，不是任意约定，也不是完善体系。

**精度不足的系统性来源**：

现有筛选机制（金钱/选举/地位）的吸引子问题：

```
金钱/选举作为筛选机制
→ 奖励能说服他人"我指向正确方向"的能力（d-mimicry）
→ 这个能力 ≠ 实际高d倾向
→ 系统性地选入低d但高d-mimicry的代理者
→ 整个L₂层积累Ψ_f债务，但Ψ_f_felt被压低
→ 系统表面稳定，隐性债务增长
```

这不是道德问题，是**筛选机制的动力学问题**：吸引子方向错误。

**现有民主 vs SRT框架**：

| 要素 | 现有民主 | SRT框架 |
|------|---------|---------|
| 授权机制 | 选举 | 选举 + 多层d倾向评估 |
| 验证机制 | 下次选举 | 持续后验 + 周期性重校准 |
| 调整粒度 | 全有或全无（当选/落选） | 授权范围和程度可分级调整 |
| 验证信号 | Ψ_f_felt（主观感受） | Ψ_f_actual后验 + Ψ_f_felt |
| 时间覆盖 | 选举周期（4-8年） | 系统性覆盖长时间尺度 |

**历史合法性的继承**：现有体系不是纯噪音，它积累了一些真实的d信号。SRT的处理：

$$\text{历史合法性（金钱/地位）} \to \text{保留为低精度先验}$$
$$\text{d倾向评估} \to \text{作为高精度校正层叠加}$$

## §8 民主的升级路径：验证精度与授权粒度

**升级方向不是推翻民主，而是补上结构性缺失的层**。

**结构性缺口**：长时间尺度决策的验证失效

```
短期决策链：决策 → Ψ_f_actual展开 → 渗入Ψ_f_felt → 选举验证 → 授权调整
（时间尺度4-8年，闭环可工作）

长期决策链：决策 → Ψ_f_actual展开（数十年）→ 选举验证失效
（决策者早已卸任；因果链已模糊；d-mimicry在时间差内无代价）
```

**制度升级含义**：

1. **Ψ_f_actual追踪与授权结构性连接**：长期后果追踪（生态审计、债务可持续性、社会信任测量）应与授权续期直接挂钩，而非仅作建议

2. **时间层级化的授权结构**：不同时间尺度决策需要不同授权周期，较长时间尺度的层级对较短时间尺度有约束权，而非相反

3. **d倾向观测窗口与授权时间尺度匹配**：
   > 授权前的d倾向观测窗口必须与决策后果的时间尺度可比。

   高时间尺度、高不可逆的决策授权，需要至少部分可比时间段的d倾向记录（决策记录，非简历资质）

## §9 三层制度结构

> **状态**：方向稳定，机制细节为开放问题（见§10）

**层级分工**：

| 机构 | SRT功能 |
|------|---------|
| 公检法（法律体系） | L₁结构边界——定义选择空间的刚性约束，防止Ψ_f债务突破不可逆阈值；作为授权来源而非上级 |
| 监督机构（类纪检委） | Ψ_f_actual持续追踪——让长时间尺度的债务在授权调整机制里可见；评估各授权主体的d倾向 |
| 各授权主体 | 在L₁约束内，按d倾向获得分层、分域、分时间尺度的代理权 |

**监督机构的三个结构性特征**（防d倾向退化）：

1. **推理链公开可审计**：每一个追踪决定和授权调整建议必须留下完整的关切范围记录，让全社会成为分布式d验证者

2. **结构性利益隔离**：监督者的Ψ_f结构与被监督对象的Ψ_f结构在制度层面保持独立，防止监管捕获（L₂耦合）

3. **自反性要求**：监督机构自身必须适用它对他人使用的同一套d验证框架；自身决策对自身标准的违反在公开记录中可见

**递归终止逻辑**：

```
监督机构 ← 三个结构性特征（自我约束）
         ← 公检法（L₁硬性边界，全社会可见，递归终止层）
         ← 文明尺度Ψ_f_actual（终极后验，慢但真实）
```

公检法作为终止层的逻辑：其失效是整个社会中可见度最高的Ψ_f穿透型事件，全体社会成员都是其d验证者，无需专门上级监督机构。

**完整结构图**：

```
文明尺度Ψ_f_actual（终极后验）
            ↕
公检法（L₁边界，递归终止层）
            ↕ 授权来源 + 边界约束
监督机构（Ψ_f_actual追踪 + d倾向评估）
  ├── 推理链公开可审计
  ├── 结构性利益隔离
  └── 自反性要求
            ↕ 持续d倾向评估 + 授权校准
各授权主体
  ├── 按域、时间尺度、不可逆程度分层授权
  ├── 大样本d倾向观测
  └── 投票 + 后验验证
```
