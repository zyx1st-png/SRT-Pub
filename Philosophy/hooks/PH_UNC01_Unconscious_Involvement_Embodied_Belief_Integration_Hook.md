## 2. Stable source-backed pressure

The future landing must preserve the distinction between the source's own claims and the SRT extension.

Source-backed pressure:

```text
thought != consciousness
conscious effect != transparent access to causes
true / adequate knowledge != automatic deletion of prior determining structure
repeated experience can form unconscious habits of expectation
habit can pre-structure later conscious passages

```

SRT-side extension:

```text
repetition alone may be insufficient to explain governing belief-weight
because encounters land in differently constituted embodied positions

```

Never attribute the embodied-position extension to Morejón, Hume, Spinoza or Leibniz.

## 3. Target A — Q12 embodied position / stakes

Preferred neighborhood:

```text
consequence return
-> embodied position
-> anchoring / writeback
-> later selection conditions
```

Candidate bounded paragraph:

A repeated signal does not acquire the same practical weight merely because it is repeated the same number of times. What matters is where the consequences land. A proposition, encounter or cue can become deeply governing when it repeatedly returns to a position that must bear its consequences and reorganize later selection around them. In this sense, repetition supplies recurrence while embodied stake supplies differential uptake: the same content can remain weak background for one position and become reality-guiding for another because the histories being rewritten are not the same.

Required guard:

```text
frequency != stakes
bodily arousal != belief
belief strength != d-value
```

Do not land as a new Q12 definition without book-line review.

## 5. Target C — consciousness conditions

Use the Leibniz / Morejón threshold material only as a negative and architectural guard:

```text
sub-threshold != zero

```

Candidate bounded paragraph:

Conscious access can arise from already structured processes that remain individually below access threshold. This supports reading an SRT consciousness threshold as a change in organization over an active substrate rather than as an ex nihilo switch. It does not identify Leibnizian apperception with `kappa_c1`, and it leaves the specifically SRT burden—bearer-indexing, stake, stable closure and phenomenal necessity—untouched.
