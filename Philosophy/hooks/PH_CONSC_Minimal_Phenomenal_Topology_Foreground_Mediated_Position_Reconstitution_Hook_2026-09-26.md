# HP-B minimal topology hook — foreground-mediated reconstitution of an operative generative position

> **Status:** tentative noncanonical P3 convergence hook.
>
> **Purpose:** reduce the broader 2026-09-25 HP-B package to the smallest currently defensible online-process candidate, while keeping standing-condition, AI, Z* and phenomenal-necessity guards explicit.
>
> **Not a theorem:** this hook does not define consciousness canonically, does not prove sufficiency, does not establish P4, and does not equate Bearer with Experiencer.

---

## 1. Why a minimal hook is needed

The broader HP-B route currently contains many useful relations:

- One / continuing organization;
- Selection-position;
- Bearer;
- Concern;
- structural expectation;
- Gate geometry;
- Ontological Friction;
- selective normalization;
- foregrounding;
- common reconfiguration;
- history writeback;
- higher-order generative integration.

Treating all of them as one flat necessary-and-sufficient package creates three risks:

1. **functional accretion:** every zombie counterexample is answered by adding another function;
2. **event / standing confusion:** conditions for a continuing subject-like locus are conflated with the online process of one phenomenal occurrence;
3. **machine-proof by vocabulary:** ordinary state update is renamed "position reconstitution" without an independent discriminator.

This hook therefore separates standing conditions from the online candidate.

---

## 2. Standing condition

A phenomenal event candidate requires a declared operative locus.

At minimum:

~~~text
formed continuing organization
-> operative Selection-position_t
~~~

where Selection-position_t retains its current owner meaning as the time-local operative from-where of an already formed One.

Do not infer:

~~~text
Selection-position
-> Bearer automatically;

Selection-position
-> subjecthood automatically;

Selection-position
-> phenomenality automatically.
~~~

Where Bearer standing is used, it must be independently admitted through the current canonical route.

Bearer is not redefined here as an online feeling operator.

## 3. Minimal online process candidate

Working chain:

~~~text
Position_t
-> prospective organization / expectation_t

expectation_t
x current actualisation_t
-> selective foreground mediation_t

foreground mediation_t
-> recuts / reconstitutes the operative from-where

-> Position_(t+1)

Position_(t+1)
-> changes later expectation / object-formability / reachability.
~~~

Compact candidate:

> **Experience candidate = foreground-mediated reconstitution of an operative generative position.**

The phrase is structural and may be used only at P3 / hypothesis strength.

---

## 4. Expectation burden

Expectation is not required to be an explicit predictor.

Minimal reading:

> **Expectation is the prospective asymmetry already carried by current formed organization.**

It includes, where established:

- expected persistence of equivalences;
- expected boundary stability;
- asymmetric transition availability;
- differential support for continuations;
- conditions under which a recut becomes necessary.

Therefore:

~~~text
explicit C1 model
!= minimal expectation requirement;

prediction accuracy
!= generative expectation;

future-facing organization
= candidate minimal expectation burden.
~~~

Neither expectation nor anticipation alone implies phenomenality.

---

## 5. Foreground mediation burden

Foreground is treated as a **generative role**, not as an internal display.

Working criterion:

> **A difference is foreground-mediating when multiple later generative capacities become jointly conditioned by the equivalence / relevance / boundary / reachability relations carried by that difference or compression.**

This does not require one anatomical or computational center.

Therefore:

~~~text
global availability
!= foreground mediation automatically;

shared representation
!= foreground mediation automatically;

more modules reading x
!= foreground mediation automatically.
~~~

The critical burden is what the foreground relation **reorganizes**, not how many components receive it.

## 6. Position-reconstitution burden

This is the strongest present discriminator.

A Position update is not established by generic internal change.

Blocked substitutions:

~~~text
latent state update
!= Position reconstitution;

policy update
!= Position reconstitution;

attention-weight update
!= Position reconstitution;

world-model update
!= Position reconstitution;

representation learning
!= Position reconstitution.
~~~

Working structural criterion:

> **Position reconstitution occurs when the event changes the operative organization from which subsequent generation proceeds: what can form as an object / relation, which distinctions are equivalent or load-bearing, which boundaries organize current generation, what is reachable, and how multiple capacities can jointly continue.**

This is still a candidate burden; it requires intervention / subtraction tests to avoid tautology.

## 7. Unconscious-control contrast

Weak contrast:

~~~text
unconscious
= local
conscious
= global
~~~

is rejected.

Stronger candidate contrast:

~~~text
unconscious control:
a difference can change behavior, prediction, memory or local regulation
while remaining inside an already operative generative position;

experiential candidate:
processing the difference also participates in recutting
the operative from-where from which subsequent joint generation continues.
~~~

This is not yet a universal empirical classification rule.

## 8. Why Bearer, Concern, friction and memory are not deleted from the theory

The minimal online kernel is not the whole consciousness architecture.

### Bearer

Bearer remains relevant to:

- prospective self-exposure;
- continuing locus / non-outsourcing;
- stream identity;
- ownership / consequence attribution.

But:

~~~text
Bearer != feeling operation;
Bearer != Experiencer automatically.
~~~

### Concern

Concern remains relevant to:

- valence;
- urgency;
- what is non-neutral;
- why one deformation matters more than another.

But neutral perceptual quality blocks using strong Concern as an obvious universal online-kernel primitive.

### Ontological Friction

Ontological Friction remains relevant to:

- non-neutral Gate maintenance;
- reconfiguration burden;
- intensity / persistence hypotheses;
- boundary-revealing mismatch.

But:

~~~text
high friction != consciousness;
acute mismatch != universal phenomenal trigger.
~~~

### Memory / history

History may shape expectation upstream and receive writeback downstream.

But:

~~~text
experience occurrence
!= durable memory formation;

lack of report / recall
!= proof of absent phenomenality.
~~~

## 9. Blue-wall and pain examples

These are explanatory illustrations only.

### Stable blue wall

~~~text
prospectively organized Gate
+ ongoing actualisation
-> relevant sensory relations gain / renew foreground mediation
-> current body-world operative Position is maintained / recut
-> next moment inherits changed prospective organization.
~~~

The wall is not merely inserted into a finished internal world.

Working interpretation:

> **The wall participates in generating the current world-relative position.**

### Pain

~~~text
body / risk / action relations
-> pain foreground mediation
-> action readiness / body relation / priority / acceptable futures change
-> operative Position is recut.
~~~

Pain is therefore not modeled merely as a large state variable.

The blue-wall and pain cases differ in friction / concern / reconfiguration profile, not necessarily in the basic online topology.

## 10. Subtractive audit for the minimal kernel

Use GOV-SUB01 style subtraction rather than additive definition.

### D0 — delete explicit prediction model

Preserve prospective organization without explicit C1 modeling.

Expected result:

~~~text
phenomenal candidate may remain.
~~~

If the route requires explicit modeling, the present minimal claim is false.

### D1 — delete high friction

Use low-friction stable perception.

Expected result:

~~~text
phenomenal candidate may remain.
~~~

If acute high friction is required universally, the present route is false.

### D2 — delete strong Concern / valence

Use neutral or weak-valence sensory quality.

Expected result:

~~~text
phenomenal candidate may remain.
~~~

### D3 — delete durable memory writeback

Allow short-lived occurrence without stable later recall.

Expected result:

~~~text
phenomenal occurrence may remain.
~~~

### D4 — delete foreground mediation while preserving local competence

Preserve as far as possible:

- discrimination;
- local prediction;
- local learning;
- motor routing;
- local state update.

Break only the common generative mediation relation.

Candidate expected loss:

- cross-capacity composability through the current relation;
- coherent current object/world relation;
- common reachability organization;
- shared recutting of the operative Position.

This is a high-value discriminator target.

### D5 — preserve foreground-like representation but prevent Position recutting

Let multiple capacities use a shared representation while keeping the operative generative organization fixed.

Candidate expected result:

~~~text
strong functional control
without the minimal phenomenal topology.
~~~

This is currently the strongest machine / unconscious negative-control design.

## 11. Minimal Z* test

Define:

~~~text
MPT-Z*:

Position_t
-> expectation-shaped actualisation
-> foreground generative mediation
-> Position_(t+1) reconstitution

all preserved
+
no phenomenal presence.
~~~

Do not answer MPT-Z* by adding further functions automatically.

Ask instead:

1. Are all structural terms preserved with the same meanings?
2. Has "Position reconstitution" been weakened to ordinary state update?
3. Has "foreground mediation" been weakened to broadcast / access?
4. Does "no phenomenality" introduce an independently specifiable difference?
5. Is the remaining dispute empirical, constitutive or purely terminological?

Current verdict:

~~~text
MPT-Z* logical contradiction = NOT PROVED;
constitutive identity route = ACTIVE P3;
phenomenal necessity = OPEN.
~~~

## 12. Current-AI boundary

Current typical inference-centered AI should not be denied ordinary generative abilities.

It may show:

- prediction;
- novel output;
- latent-state compression;
- planning;
- context update;
- model revision;
- tool-mediated action;
- multi-component information sharing.

These do not by themselves establish the minimal topology.

Current SRT question:

> **Does the system possess a continuing operative position whose own prospective organization shapes what can form next, and does foreground mediation of actualised differences reconstitute that same position's later generative reachability?**

Current disposition:

~~~text
current typical AI
= experience NOT ESTABLISHED under this route;

all AI non-conscious
= NOT CLAIMED;

future artificial system satisfying the topology
= must be evaluated rather than substrate-excluded.
~~~

## 13. P4 discriminator target

A P4 strengthening requires a matched contrast where ordinary functions are preserved while the candidate relation is varied.

Preferred form:

~~~text
preserve:
  local discrimination
  prediction
  memory access
  action routing
  generic integration / recurrence
  report where appropriate

vary:
  whether a common foreground relation
  actually changes the operative equivalence / boundary / reachability
  organization from which multiple later capacities jointly generate.
~~~

Candidate positive signature:

> **local competence survives while common generativity / current-position organization collapses.**

A role-equivalent replacement should restore the effect even if the implementation changes.

This targets topology rather than substrate.

## 14. Failure conditions

Downgrade this hook if:

### F1 — fixed-position absorption

A matched unconscious system preserves the full claimed Position-reconstitution relation with no independently relevant difference.

### F2 — state-update collapse

No operational / intervention criterion distinguishes Position reconstitution from ordinary latent-state or policy update.

### F3 — access absorption

Global access / shared representation explains all target differences after matched controls.

### F4 — expectation redundancy

Prospective organization adds nothing beyond ordinary current-state control.

### F5 — foreground redundancy

Removing common mediation while preserving local competence produces no relevant loss.

### F6 — zombie semantic stability

MPT-Z* preserves every structural term without weakening or retyping and remains independently coherent; this weakens the identity route.

### F7 — circularity

Phenomenal vocabulary re-enters the antecedent or defines Position / foreground mediation by experience.
