# SAT Acquisition / Resolution-with-Remainder Integration Hook

## 1. Integration payload

This hook carries only the following SAT-derived discriminations into SRT review:

```text
acquisition condition
!=
persistence / maintenance condition

procedural resolution
!=
constitutive absorption

state / policy / objective non-equivalence
!=
constitution-relative continuation non-equivalence

recorded history
!=
borne history
```

The detailed source/synthesis separation is owned by:

`03_Bridges/SRT_SAT_Acquisition_Remainder_Bridge_2026-08-24.md`

---

## 2. Hard guards

Do not land any of the following:

```text
Recognition -> required stage of Selection
Implication -> SRT primitive
Carrying -> universal consciousness threshold
Contested incorporation -> bearer admission
Remainder -> subjecthood / consciousness proof
constitution-non-equivalence -> phenomenality
```

Existing owner separations remain authoritative:

```text
bearer-unit first
Selection event != conscious content != subjecthood != agency
continued selectability -> P1-T06 owner
generative reselectability -> B13 owner
historical-efficacy depth -> existing HEF owner
non-outsourcing -> PH-IND06 audit
```

## 3. Owner A — `Core_Law/SRT_Individuation.md`

Potential compact landing after review:

> The condition that first writes a bearer-relative consequence into the continuing process need not be the condition that later maintains that consequence. Removal or correction of the initiating trigger therefore does not by itself restore the pre-acquisition history state.

and:

> The procedural or automated character of an action does not decide whether its result becomes a stronger bearer-relative historical constraint.

Do **not** introduce SAT terminology into P1-T06 itself.

---

## 4. Owner B — `Philosophy/SRT_Subjecthood_Threshold_Interface.md`

Potential AI/consciousness guard:

```text
successful self-modification / meta-resolution
!=
subjecthood
```

and:

```text
bearer-relative historical acquisition
!=
phenomenality
```

SAT is useful here because a system can revise policies or objectives under a standing higher-order procedure without thereby establishing a participant-level historical remainder. Conversely, successful procedural resolution does not show that no stronger history was acquired.

This is a two-sided anti-overread guard, not an additional S4 threshold item.

---

## 5. Owner C — `PH_IND06_Bearer_Concern_Selectability_Integration_Hook.md`

PH-IND06 asks first:

```text
Can the relevant cost / loss / correction be transferred elsewhere
while the claimed bearer is restored unchanged?
```

SAT-derived follow-up asks only after a candidate bearer survives that audit:

```text
Can successful resolution treat the event as irrelevant
without changing that bearer's constituted relation to its own history?
```

Keep the sequence:

```text
non-outsourcing / same-unit return
-> resolution-with-remainder stress test
-> later selectability / historical-efficacy audit
```

Do not merge them into one bearer criterion.

---

## 6. Owner D — historical-efficacy owners

The SAT language should be tested against, not duplicated alongside, existing SRT HEF distinctions.

Question:

> After matching systems on memory, path dependence, reachability, return cost, candidate generation and rule/boundary/composition writeback, does `resolution with remainder` identify an independently useful difference?

If **no**, reduce the SAT terms to translation-only vocabulary.

If **yes**, retain only as a P3 discrimination unless and until an owner-level operational readout is independently specified.

---

## 7. AI adversarial test bundle

For a named candidate AI bearer, use this order:

1. **unit test** — what exactly is the bearer: model, deployment, memory-bearing agent loop, cluster, human-AI workflow?
2. **reset / outsourcing test** — can relevant loss be deleted, moved or copied while the claimed bearer is restored unchanged?
3. **standing-procedure test** — are policy/objective/meta-objective revisions fully authorized by an unchanged higher-order procedure?
4. **withdrawal test** — if the initiating belief/relation is corrected, which downstream effects remain and in which unit?
5. **historical-efficacy test** — what later reachability, cost, candidate set, rule, boundary or composition actually changed?

This bundle tests bearer-relative historical acquisition. It does not prove S4 subjecthood or phenomenality.

---

## 8. Failure conditions

Do not land the SAT vocabulary into owner files if:

- no independent observation can distinguish `constitution-non-equivalence` from sufficiently rich state/history dependence;
- `resolution with remainder` reduces without loss to current HEF-3 / HEF-4 plus PH-IND06 non-outsourcing;
- the only evidence is self-report, persistent preference, emotion-like output, rollback cost, objective revision or path dependence;
- the concept is used to infer consciousness from historical depth alone.
