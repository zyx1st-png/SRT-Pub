# PH-IND04 Object / Bearer / Selector / Subject / Experiencer Integration Hook

## 1. Integration payload

Retain only the following compact ladder:

```text
Object
!-> Bearer
!-> Selector
!-> Subject
!-> Experiencer
```

Every transition requires new evidence. Structural similarity or persistence alone cannot license a higher role.

---

## 2. Target A — `Core_Law/SRT_Individuation.md`

### Suggested future insertion

Near the transition from subjectless selection to ISP entry, distinguish:

```text
historical operator
-> bearer
-> selector-position
-> subject-position
```

Candidate native prose:

```text
Historical self-conditioning is not yet subjecthood. A pattern may carry its own trace and allow that trace to alter later operation without yet constituting a stake-bearing subject. A stronger transition occurs when consequences return to the same continuing bearer, rewrite that bearer's future selectability, and become non-externalizable stakes of that continuing position. The resulting selector-position and the later subject-position should therefore be audited separately even if they are tightly coupled in biological cases.
```

### `sigma_sr` guard

```text
sigma_sr tracks historical self-conditioning / trace contribution candidate
!= subjecthood scalar
```

Do not remove the existing P1-T06 gates or promote this hook into a new canonical threshold.

