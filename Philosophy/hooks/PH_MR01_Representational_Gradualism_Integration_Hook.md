# PH-MR01 Representational Gradualism Integration Hook

## 1. Target A

```text
Philosophy/Foundations_Annex/10_MentalRepresentation_Interface_Batch.md
```

### Suggested placement

After the existing representation-evidence ladder / protocol-vs-representation discriminant.

### Suggested paragraph

```text
A second distinction concerns the status of the boundary itself. Even if evidence for representation is graded through sensitivity, specificity, invariance and downstream use, it does not follow that representational organization has a single natural binary onset. A proposed threshold should therefore be tested with adjacent cases: compare the strongest relevant case just below the condition with the weakest case just above it and ask whether representational explanation, causal use or generalization actually changes discontinuously there. If the condition changes while the relevant explanatory structure does not, the condition is better treated as an operational classification rule than as an established ontological boundary.
```

### Suggested placement

Near the separation between bearer-unit specification and subjecthood / consciousness thresholds.

### Suggested paragraph

```text
Operational thresholds should not be silently promoted into ontological phase boundaries. When a bearer or subjecthood protocol introduces a cutoff, compare adjacent systems on the underlying dimensions—same-unit consequence return, history writeback, future-selectability change and boundary continuity. If these vary smoothly across the cutoff, the cutoff remains a practical admission rule unless an independent phase-transition argument is available. This does not make event actuality gradual, and it does not collapse representation into bearer status.
```
