# PH-AG05 Embodied Position / Operator Capture Integration Hook

## 1. Agency / subjecthood synthesis

**Target:** `Philosophy/SRT_Philosophy_Agency_Subjecthood_v0_2.md`

Add a bounded distinction near bearer continuity and reselection:

```text
bearer continuity
!=
current self-model invariance
```

Suggested bridge paragraph:

> A continuing bearer need not preserve an invariant self-description. Robust agency may instead require enough continuity for consequence ownership together with enough self-model revisability for consequence-sensitive correction. When revision of a stabilized self/social position is represented as unacceptable bearer-position loss, the position may capture selection-parameter updating and reduce effective future reselection.

Preserve:

```text
same bearer
!= same policy
!= same belief
!= same role
!= same self-description
```

## 2. Subjecthood threshold interface

**Target:** `Philosophy/SRT_Subjecthood_Threshold_Interface.md`

Use PH-AG05 only as a bearer-continuity guardrail:

```text
continuity sufficient for consequence return
must not be silently strengthened into
identity invariance across time
```

Do not use self-model flexibility as a necessary-and-sufficient subjecthood test.

## 3. Social L2 dynamics

**Target:** `Philosophy/SRT_SocTheory_06_L2_Dynamics.md`

Keep two alienation routes distinct:

```text
external structural capture
!=
internalized embodied-position capture
```

Suggested mapping:

```text
social recognition / sanction
-> position hardening
-> internalized revision cost
-> calibration discounting
-> repeated position-preserving selection
-> further L2 stabilization
```

This permits coupled cases without replacing the existing structural alienation theorem.

## 4. Ethics / freedom

**Target:** `Philosophy/SRT_Philosophy_Ethics.md`

Use only as a bridge-level freedom discriminator:

```text
freedom
!= absence of stable identity

candidate robust freedom
~
continuity sufficient for responsibility
+
revisability sufficient for correction
+
future-selectability preservation
```

Do not infer moral legitimacy from flexibility alone. A highly revisable agent can still select badly, irresponsibly, or under manipulation.

## 6. Empirical hook

Candidate experimental contrast:

```text
private low-identity commitment
vs
public identity-linked commitment
vs
identity-linked commitment + bearer-worth / belonging buffer
```

Hold evidence strength approximately fixed and compare:

- belief updating;
- alternative generation;
- information search diversity;
- willingness to switch policy;
- downstream action-space accessibility;
- persistence after external audience removal.

The PH-AG05-specific prediction requires more than generic stubbornness: identity-position threat should explain incremental future-option compression, and buffering bearer continuity without preserving the challenged content should restore some reselection.
