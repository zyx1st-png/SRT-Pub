# HP-B hook — gate geometry, Bearer, ontological friction and phenomenal admission

> **Status:** tentative noncanonical P3/P4 hook authorized by the 2026-09-25 A-6 / A-7 author adjudication.
>
> **Purpose:** formulate a positive, non-circular mechanism candidate for why feeling may arise, while retaining the existing Z6 / HP-B failure rights.
>
> **Not a theorem:** this file does not prove that every qualifying architecture is conscious, does not redefine Bearer as Experiencer, and does not close the hard problem.

---

## 1. Problem

Existing SRT work has separately established candidate burdens for:

- formed One / Selection-position;
- Bearer;
- Concern;
- structural Expectation;
- objectification;
- qualitative geometry;
- phenomenal compression;
- ontological friction Psi_f;
- reselectability / future-selectability;
- zombie deletion pressure.

The missing positive question is:

> **Why should a formed Bearer ever need a felt mode rather than merely unconscious control?**

The present hook proposes that feeling becomes relevant when bearer-level generative maintenance can no longer keep a consequential deformation entirely in the background.

---

## 2. Structural antecedent — no phenomenal vocabulary allowed

The antecedent must be stated without words such as felt, phenomenal, experience, qualia or for-me.

### C1 — independently admitted Bearer

A Bearer must already be independently admitted under the current repository route.

Blocked:

~~~text
Bearer = thing that feels
~~~

### C2 — formed gate geometry

The Bearer is maintained through a formed coarse-graining organization that determines, under declared scope:

- which differences are currently equivalent;
- which boundaries are stable;
- which transitions are locally available;
- which perturbations can be absorbed;
- which relations remain backgrounded.

This is downstream formed organization, not primitive Selection.

### C3 — ontological friction

World-side actualisation imposes canonical ontological friction Psi_f on the formed organization.

The friction is not merely report, pain, effort or prediction error.

### C4 — local payment failure / escalation

The relevant burden cannot be fully absorbed within one local background gate without materially changing broader bearer-level continuation.

This does not require catastrophic failure.

It requires:

~~~text
local resolution
changes or constrains
other relevant resolution spaces.
~~~

### C5 — common resolution dependence

At least two otherwise partly separable gate processes become mutually resolution-dependent:

~~~text
resolution(G_i)
changes feasible resolution(G_j)

and

resolution(G_j)
changes feasible resolution(G_i)
~~~

under the same independently admitted Bearer.

### C6 — structural foreground objectification

The deformation is coarse-grained into a shared, selection-active foreground object / compressed control state.

This objectification is structural:

- report is optional;
- language is optional;
- metacognition is optional;
- explicit self-model is optional.

### C7 — current Selection-position reconfiguration

The foregrounded state directly changes the current operative from-where of the same Bearer:

- candidate priority;
- action readiness;
- memory access;
- concern weighting;
- future selectability;
- later gate reconstruction.

At this point the structural antecedent is complete.

## 3. Candidate bridge principle

### BP-Q1 — bearer-constitutive phenomenal admission candidate

> **When bearer-relevant ontological friction cannot remain locally background-paid and must be compressed into a common foreground object that directly reconfigures the same Bearer's current Selection-position, phenomenal presence is the first-person mode of that bearer-constitutive objectification.**

Important distinction:

~~~text
object shown to an inner observer
!=
object that becomes constitutive of the current bearer-position.
~~~

The proposal is not that another internal subject reads the foreground object.

The proposal is that:

~~~text
the locus bearing the consequence
=
the locus whose current operative position is being recut.
~~~

This identity of affected unit and continuing selection-locus is the candidate source of first-person character.

---

## 4. Why unconscious control remains possible

Unconscious gating remains expected when:

~~~text
ontological friction is locally payable;
local resolution does not force cross-gate common reconfiguration;
the current bearer-position need not be recut;
the deformation can remain an enabling or constraining background cause.
~~~

Therefore:

~~~text
gating != consciousness
Psi_f != consciousness
Bearer != consciousness
integration != consciousness
~~~

The candidate transition is the conjunction, not any one term.

## 5. Why feeling may be useful rather than epiphenomenal

The hook proposes a functional / generative role without reducing feeling to function.

A low-dimensional felt object may permit a high-dimensional bearer-level deformation to become:

- common across otherwise specialized gates;
- immediately selection-active;
- priority-bearing;
- action-guiding;
- memory-writeable;
- available for later reflective objectification.

Examples of the form, not evidence of the theory:

~~~text
many bodily variables
-> pain / hunger / nausea;

many unresolved threat relations
-> anxiety / unease;

many inferential constraints
-> Aha / obviousness;

many sensory relations
-> stable qualitative color / pitch / texture object.
~~~

The qualitative object is therefore a candidate generative interface, not a passive label.

## 7. Relation to common bearer-relative reconfiguration

Working construct:

> **Common bearer-relative reconfiguration** is present when multiple gate deformations cannot be resolved independently because each changes the feasible resolution space of the others, and the consequences close on the same Bearer.

This is narrower than:

- generic synchrony;
- generic connectivity;
- ordinary recurrent processing;
- global broadcast;
- causal integration.

It is still not a consciousness definition.

## 10. Failure conditions

Downgrade / absorb this hook if any of the following occurs.

### F1 — access absorption

Matched global access / report / integration predicts all relevant differences; bearer-relative common reconfiguration adds nothing.

### F2 — bearer irrelevance

The same phenomenal pattern survives when consequence closure / non-outsourcing architecture is varied in a way the hook predicts should matter.

### F3 — friction irrelevance

Qualitative foregrounding is fully explained without any bearer-relevant ontological-friction relation across the declared cases.

### F4 — no common-reconfiguration discriminator

Mutual resolution dependence reduces to ordinary connectivity / recurrent dynamics with no independent prediction.

### F5 — circularity return

Any future formulation reintroduces phenomenal vocabulary into C1-C7.

### F6 — gate-geometry redundancy

The quality predictions are no better than an existing quality-space / representational geometry account after matched controls.
