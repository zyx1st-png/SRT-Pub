# PH-IND05 Occurrence / Trace / L2 / Bearer / Experiencer Integration Hook

## 1. Integration payload

Retain the following compact discrimination chain:

```text
Actual occurrence
!= persistent trace
!= L2 sedimentation
!= bearer-indexed history
!= phenomenal experiencer
```

and the related guards:

```text
state identity != historical identity
spatial separation != bearer individuation criterion
qualitative identity !-> numerical identity
physical localization != bearer localization != phenomenal locus
```

No owner file should be changed merely because the Nilsson essay advances a stronger idealist conclusion.

---

## 2. Target A — `Core/SRT_Core_21_Minimal_Axioms.md`

### Existing strength to preserve

P0-02 already separates event-level actuality from anchoring persistence, and P0-03 already blocks treating reversal as deletion of prior occurrence.

### Suggested future clarification

Add only if owner review finds ambiguity:

```text
Occurrence irreversibility does not require a permanently surviving record of every event. The loss, decay, overwriting or inaccessibility of a trace may remove downstream persistence or efficacy without converting the earlier actualisation into never-having-occurred.
```

### Guard

Do not introduce:

```text
cosmic archive
world memory substrate
realm of mind
eternal record field
```

as a P0 object.

## 4. Target C — `Core/SRT_Core_12b_Ontology_L2.md`

### Preserve the strongest owner sentence

```text
L2 is not an archive.
```

### Suggested future clarification

```text
Occurrence asks what became actual. L2 asks what prior selection continues to do. A past event may remain factive even when its local persistent trace has decayed, whereas L2-grade history requires continuing structural efficacy such as inheritance, re-entry, hysteresis, changed accessibility, changed friction, or scaffold effects.
```

### Guard

```text
historical facticity
!= L2-grade historical efficacy
```

Do not make `L2` a permanent registry of every event-token.

## 5. Target D — `Philosophy/SRT_Causality_Time.md`

### Suggested distinction

Near the parametric-time / ontological-time split, add a three-way typing only if it reduces ambiguity:

```text
parametric ordering
!= occurrence asymmetry
!= reconstructable / sedimented historical constraint
```

Suggested native prose:

```text
The minimum historical direction does not require that every past event remain retrievable as a current record. Selection irreversibility marks the asymmetry between having occurred and never having occurred; surviving traces and L2 sedimentation are stronger downstream structures through which past selections continue to constrain, scaffold or become reconstructable for later processes.
```

### Guard

Do not identify subjective duration, clock time, memory availability and ontological irreversibility.

## 6. Target E — `Core_Law/SRT_Individuation.md`

### Branching / fission pressure

Current individuation machinery is strongest for one history-bearing process becoming and remaining a Stable ISP. Future hardening should add a fission test:

```text
shared pre-branch history
-> two independently continuing closures
```

Audit:

```text
Can B1 and B2 each inherit P's history while no longer being the same bearer as each other?
```

### Test-local diagnostic

Use only at P3:

```text
counterfactual consequence separability
```

Meaning:

```text
an admissible event can change B1's future selectability
without the same consequence closing on B2,
and vice versa
```

Stronger evidence may combine:

```text
independent consequence closure
+ independent history writeback
+ independent future-selectability change
+ maintained closure continuity
```

### Guards

```text
spatial distance != bearer definition
state copy != same bearer
shared memory != same bearer
continuation != strict numerical identity
bearer branching != phenomenality proof
```

## 7. Target F — `Philosophy/SRT_Subjecthood_Threshold_Interface.md`

### Where-question typing

Suggested future insertion:

```text
WHERE-P: physical realization
WHERE-C: causal propagation
WHERE-B: consequence-return / history-writeback closure
WHERE-S: subject-relative indexical position
WHERE-E: phenomenal locus / for-me-ness
```

Core guard:

```text
WHERE-P != WHERE-B != WHERE-E
```

### Why this matters

A system may be spatially distributed yet remain one bearer candidate; two nearby systems may be different bearer candidates; neither fact proves phenomenality.

Keep the existing rule:

```text
bearer-unit first;
S0-S6 second;
moral status last.
```
