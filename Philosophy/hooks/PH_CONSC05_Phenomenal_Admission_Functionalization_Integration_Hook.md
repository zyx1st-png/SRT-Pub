# PH-CONSC05 Phenomenal Admission / Functionalization Integration Hook

## 1. Core payload

Retain the following distinction:

```text
FP_indexical != FP_phenomenal proved
```

and:

```text
Structural Bearing
->? strong For-P
->? Phenomenal For-me
->? Qualitative Character
```

`For-P` may include self-location, same-bearer consequence return, non-substitutability, history writeback and future-selectability change without becoming a phenomenality proof.

## 2. Hard Problem owner target

### Suggested future scope rewrite

Separate two achievements:

```text
A. metaphysical-gap dissolution
   first-person / third-person difference does not imply two ontologies

B. phenomenal admission
   which systems actually instantiate phenomenal presence remains open
```

Suggested concise owner text if HP-B-B is adopted:

```text
SRT rejects a view-from-nowhere derivation demand, but this does not by itself determine which structurally admitted bearers are phenomenal. The residual admission question remains: what independently justified condition distinguishes a maximally specified bearer-relative system from a phenomenally empty counterpart?
```

### Retain

```text
HP-A = perspective-center individuation
HP-B = phenomenal necessity / admission
HP-C = qualitative character
```

The optional `HP-0` label in the patch is only an expository map; do not promote it unless the owner needs it.
