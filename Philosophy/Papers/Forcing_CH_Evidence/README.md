## Evidence discipline

- An `EVD-*` identifier names an evidence obligation, not a source.
- Sources in these dossiers use stable bibliography keys unless a source has entered the repository through the formal `SRC-*` material pipeline.
- `VERIFIED` is a source-level status. Obligation verdicts are separately recorded as `unresolved`, `supported`, `qualified`, `defeated`, or `withdrawn`.
- Exact locations, checked paraphrases, counterevidence, and adjudication rationales are mandatory before an obligation can be upgraded.
- Modern notation may clarify a historical result but does not show that the notation or method was historically available.
- Technical results do not by themselves establish reception, consensus, response roles, evaluation order, institutionalization, C5-op failure, or C2 failure.

No source text is duplicated here. Short excerpts are used only where they fix an interpretive boundary; the source list points to the verified publication or stable access record.
