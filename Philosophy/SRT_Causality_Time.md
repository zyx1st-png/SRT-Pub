# SRT 因果性分层与时间层次

> 本文件解决两个相互关联的哲学精确性问题：
> 1. SRT 包含两种不同性质的"因果"——Ax-F-03 定义的经验因果与 L₀ 层的结构驱动。混淆二者会导致无效问题（"第一推动力是什么"）。
> 2. SRT 的方程使用时间参数 $t$，同时又研究能否从被保留的选择次序中读取时间。区分参数化时间与条件性的本体论时间候选，消解这个表观循环而不预判普遍时间本体论。

---

## 一、因果性的两层结构

### 1.1 水平因果（Horizontal Causality）

Ax-F-03 定义的因果性：

$$\boxed{C_H(A \to B) \equiv P(B \,|\, A,\, L_2)}$$

**性质**：
- 在 L₂ 层**内部**运作——需要 L₂ 积累才存在
- **时序性**：A 在时间上先于 B
- **条件概率性**：因果关系 = L₂ 历史结构下的稳定条件概率
- 这是休谟意义上的因果、科学定律、所有可实验检验的因果关系
- 无 L₂ 则无水平因果（新生儿出生前没有"因果律"的 L₂ 积累，但物理定律在 L₂ 层面早已存在）

**有效问题**（水平层内）：  
"为什么点燃火柴后纸张燃烧？"（L₂ 的燃烧规律给出条件概率）

**无效问题**（错误地用水平逻辑问垂直问题）：  
"L₂ 形成之前，是什么在时间上先于选择事件？"——这把时序因果逻辑投射到了不适用的层次。

### 1.2 垂直因果（Vertical Causality）——结构约束

L₀ 到 L₁ 到 L₂ 之间的关系是**结构构成**（structural constitution），不是时序推动：

$$\boxed{L_0 \;\vDash\; L_1 \;\vDash\; L_2}$$

读法：L₀ 的曲率结构**构成** L₁ 的可能性条件；在显式 retention / writeback 关系成立时，L₁ 中被保留的历史效力可**构成** L₂ 的硬化结构。

**性质**：
- 本体论性的，不是时序性的——L₀ 不"推动"L₁ 在时间上发生，而是使 L₁ 成为结构上的可能
- **落入机制**（而非推动机制）：κ₀ 的曲率使某些选择方向成本更低，选择"落入"那里，不是"被推向"那里——如同水依几何约束流动，而非被"推"
- **不依赖 L₂**：垂直因果在 L₂ 形成之前就有效（这正是第一批选择何以发生的解释）
- **非时序**：问"哪个垂直因果先发生"是范畴错误

**有效问题**（垂直层）：  
"为什么有 L₁ 而非什么都没有？"（κ₀ > 0 的曲率结构使落入某些稳定选择成为结构必然）

### 1.3 两层因果对比表

| | 水平因果 | 垂直因果 |
|---|---|---|
| 运作域 | L₂ 层内部 | L₀→L₁→L₂ 跨层 |
| 性质 | 时序性、条件概率 | 结构性、本体论构成 |
| 先决条件 | 需要 L₂ 存在 | 不依赖 L₂ |
| 机制 | A 推动 B | 结构使 X 成为可能 |
| 符号 | $C_H(A \to B)$ | $L_0 \vDash L_1$ |
| 典型问题 | "A 为什么导致 B？" | "为什么有 L₁ 而非无？" |
| 无效的混用 | "L₂ 之前是什么因果？" | "谁在时间上先推动了 L₀？" |

### 1.4 因果闭合复审与对现有公理的保护（`R3-03-O6` + `R4-C1`）

**Ax-F-03 受保护**：Ax-F-03 定义的水平因果在 L₂ 层内完整有效。它不需要解释原初生成或结构构成条件，因为那是另一种性质的依赖关系。两层因果并存不相矛盾，各在其域。

**因果闭合复审（`R3-03-O6` 哲学域规范口径落地；跨 `Core_Law` / 下游 owner 全仓核查与相关本体边界研究仍保持 `OPEN`）**：SRT 严格区分**合法的物理域内闭合边界**与**未经论证的物理本体穷尽性宣称**。在具体物理模型内，守恒律与物理动力学闭合完全有效，SRT 不引入打断物理因果链的超自然外力；但第三人称物理闭合描述属于特定抽取视角下的 `L_2` 规律（`Q01 / O-Phil-11`），不能反向排除形成后具身系统内高阶组织约束（如注意、价值比对、历史脚手架与跨尺度有效作用接口）作为**同一现实中的结构性/跨层条件**参与后续选择。同时严格区分**双向构成约束**（两个结构互为维持条件，未必构成时间先后）与**局部非对称生成依赖**（事件 $A$ 成为事件 $B$ 的实际化条件而反向不成立）。

**自举问题消解**（与 `Core_12a` 及 `Spine §2` 联动）：为什么不需要“第一推动力”——结构构成是非时序关系，原初非平坦分化与持续组织条件不位于一个先在外部时间容器的起点上。“谁在时间轴上先推动了 `L_0`”是把水平时序因果错误地投射到构成层——在 SRT 框架内属范畴错误。

## 二、时间作为秩序的关系度量与七项时间接口（`PT08 D` + `R3-05` 重构）

### 2.1 核心重构：时间不是外在容器，而是生成秩序的关系度量（`PT08 D`）

在 `R3-05 / R4-C1` 统一生成框架中，SRT 将时间探索为**多单元生成变化之间形成的秩序关系度量与对比标尺**（本体论研究候选，不替代相对论时空或宣称已完成普遍物理时钟推导）。它统一包含两类用途（非两种独立时间）：
1. **横向度量**：不同生成单元或子过程通过参照比对建立相对变化尺度、快慢与节律（与 Rovelli *"Relational Quantum Mechanics"* [1996] / *The Order of Time* [2018] 关系时间思路相容，但不停留在被动关联描述）；
2. **纵向度量**：同一生成组织从一种秩序维持、发展或重构为另一种秩序所经历的变化展开跨度（依托横向关系尺度获得相对度量）；
3. **时间标尺的双向脚手架参与（SRT 核心增量候选，`R3-05-O2` OPEN）**：时间标尺不仅从相对稳定的周期变化中抽象而出，一旦沉淀为公共脚手架（物理耦合同步、生物节律协调、钟表历法制度），还会**反向参与跨单元协作与新秩序生成**。

**三项防误读校准**：
- **时间度量 ≠ 秩序高低或健康打分**：僵化锁定可持续极久；时间长短不代表秩序健康或价值优劣；
- **孤立发生不可逆底线独立成立**：即便尚无多单元对比标尺，孤立实际化的**发生非等价性（已发生 ≠ 未发生，`P0-03 / P1-T02`）**仍然成立，且发生不可逆不自动给出全局偏序或物理时间箭头；
- **非对称依赖 ≠ 自动偏序 ≠ 物理时钟**：须区分纯数量变化比例（时间反演对称）、双向构成约束、局部非对称生成依赖（研究候选）、以及需额外满足传递性与无环条件的严格偏序（对接 Bombelli, Lee, Meyer & Sorkin [1987] *"Space-time as a causal set"* 因果集方案，条件 `R3-05-O1` 保持 `OPEN`）。

### 2.2 七项时间接口精确分离（取代旧“两层时间”粗分；完成 `R3-05-O6` 本文件规范口径落地与旧冲突清理，底层研究问题仍各自保持 `OPEN`）

早期 SRT 仅粗分“参数化时间 $t$”与“本体论时间 $t_{\text{onto}}$”，易引发循环误读（方程用 $t$ 描述变化，又宣称时间由选择生成）。当前严格分离以下 **七项时间接口**：

| 时间接口 | 定位与职责边界 | 与成熟理论及规范符号的关系 |
|---|---|---|
| **1. 实际化非等价** | 不依赖观察者的发生事实（已发生 ≠ 未发生） | `P0-03 / P1-T02` P1 底线；不要求留痕、时钟或度量 |
| **2. 局部非对称生成依赖候选** | 具体实际化事件间的局部条件依赖关系 | 区别于双向构成约束；升级为严格偏序之条件及因果集对接保持 `OPEN` |
| **3. $\tau_{\text{ontic}}$** | 条件性的物择相对变化步比候选（`Q04`） | 关系变化步比，**非**普遍物理时钟；原初 `Selection` 目前无统一计数单位 |
| **4. 模型内 $t_{\text{onto}}$** | 声明历史留存与算子归属后的局部积分度量（`P1-T02`） | 已在 `_SRT_SYMBOL_TABLE.md` 收窄为**模型限定局部历史积分**（如 $t \equiv \int \Psi_f d\tau$ 仅作模型代理），不再冒充普遍本体时间 |
| **5. $t_{\text{exp}}$（体验时间）** | 具身认知位置对连续生成变化、持续与窗口的组织（`Q04`） | **重要校准**：错误、预期、记忆、注意与关切是重要调节因素，但**非**体验时间成立的唯一或必要来源 |
| **6. 数学参数 $t$** | 动力学方程（如 $d\theta/dt$）中的排序索引工具 | 纯数学坐标，**无本体论承诺**，直接消解“方程用 $t$ 是否循环”之表观悖论 |
| **7. 公共时间（`L_2` 脚手架）** | 跨位置共享的参照度量与协作制度（钟表、历法、协议时钟） | 兼具认识比对标尺与社会协作组织双功能 |

### 2.3 空间、四类距离与时空同源开放线索（`R3-CL-O7` 接口）

与时间作为变化秩序的关系度量并行，SRT 将**空间与距离**登记为关系性可达与条件跨度接口，区分四类不可混同的距离：**物理距离**（时空/物理相互作用约束）、**作用距离**（因果干预与耦合传递跨度）、**认知距离**（表征、注意与理解框架间的转换成本）与**生成距离**（从当前组织条件跃迁至另一可行秩序所需的重构跨度）。空间、时间、价值与历史是否共享更深层的共同生成来源，作为哲学研究线索保留（`R3-05-O3 / R3-CL-O7` OPEN），**绝不宣称替代相对论时空结构**。

### 2.4 与水平/垂直因果的联动

- **水平因果**在既有 `L_2` 结构内运作，常规使用数学参数 $t$ 或公共时间度量；
- **垂直构成**是非时序的结构条件关系，不使用参数时间先后；
- **历史效力（`L_2`）与时间度量**各自独立检验：先前选择在当下保留生成效力（`Core_12b`）支撑局部时间读数，但不由裸发生非等价性自动推出普遍时间箭头。

## 三、综合：无效问题类型学

引入两层因果和两层时间之后，以下问题可被识别为**范畴错误**（不是待解问题，而是问题本身有误）：

| 无效问题 | 错误类型 | SRT 处置 |
|---|---|---|
| "L₂ 形成之前，因果律是什么？" | 把水平因果逻辑投射到垂直层 | 垂直层无水平因果，问题不成立 |
| "谁在时间上先推动了 L₀？" | 把参数化时间投射到本体论层 | 垂直因果非时序，"先后"不适用 |
| "为什么 κ₀ 在时间上存在？" | 混用本体论时间和参数化时间 | κ₀ 是结构约束，不在时间轴上"出现" |
| "SRT 方程用了 t，说明时间是基本的" | 把参数化工具误读为本体论主张 | 参数化时间是描述工具，不声称本体论地位 |
