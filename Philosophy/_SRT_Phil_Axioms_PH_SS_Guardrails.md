# _SRT_Phil_Axioms — PH-SS Guardrails Companion

> **Purpose**: Add guardrails to the philosophy-domain axiom layer without rewriting the long legacy `_SRT_Phil_Axioms.md` file.  
> **Status**: Companion bridge file. It does not define P0/P1 primitives.  
> **Use rule**: When reading or editing `_SRT_Phil_Axioms.md`, apply these guardrails first.

---

## 0. Why this companion exists

`_SRT_Phil_Axioms.md` contains older and newer layers of philosophical mapping. Some old language is useful but easy to over-read. This companion file fixes the most dangerous over-readings without erasing the historical content.

Main risks addressed:

```text
L0 as hidden object-world;
selection-before-existence as chronological priority;
all real things having equal reality-strength;
Psi_f as one undifferentiated cost;
stable L2 norms as automatically good;
micro-selection as already consciousness.
```

## 1. Def-Phil-L0-Selectability

**Claim level**: P2/P3 bridge reading.  
**PH-SS addressed**: `PH-SS-01`.  
**Target legacy risk**: `L_0` being read as a hidden world, object inventory, many-worlds ontology, or mystical potentiality sea.

### Definition-like guardrail

> `L_0` should be read, in the philosophy layer, as a **modal field of selectability**: the condition under which differences can become manifest through constrained selection.

### Negative constraints

`L_0` is not, by default:

- a second physical universe;
- a warehouse of fully formed possible objects;
- private imagination;
- a mystical potentiality ocean;
- a many-worlds ontology;
- an already-populated object inventory.

### Safer reading of legacy language

If old passages say “Meinongian Realm,” “Sunyata,” “potentiality,” or “all possibilities,” read them as analogy / philosophical correlate, not as literal object ontology.

### Editing rule

Use:

```text
L0 = condition of possible manifestation / modal field of selectability
```

Avoid:

```text
L0 contains all possible objects as already-existing entities
```

### Withdrawal condition

If a specific SRT file needs object-like `L_0` semantics, it must be owned by Core_Law and explicitly promoted through claim governance. Philosophy files should not smuggle that commitment in by metaphor.

## 2. Def-Phil-Manifestational-Priority

**Claim level**: P2 bridge reading.  
**PH-SS addressed**: `PH-SS-02`.  
**Target legacy risk**: “Existence ≡ Being Selected” being read as a temporal creation claim.

### Definition-like guardrail

> “Selection-before-existence” means **manifestational priority**, not chronological priority.

### Priority typing

| Priority type | SRT status |
|---|---|
| Temporal priority | Avoid unless explicitly modeled. |
| Logical priority | Yes: determinate existence depends on selection conditions. |
| Manifestational priority | Yes: a possible difference becomes manifest through selection. |
| Stabilization priority | Stronger reality requires repeated anchoring and `L_2` closure. |

### Safer reading of Ax-Phil-1 / Ax-Ph1

When `_SRT_Phil_Axioms.md` says:

```text
Existence(X) iff exists G_hat_theta: G_hat_theta[L0] -> X_L1
```

read it as:

```text
Determinate manifestation of X requires a selection / anchoring operation.
```

not as:

```text
A subject existed before all reality and created X in time.
```

### Editing rule

Use:

```text
selection is manifestationally prior to determinate existence
```

Avoid:

```text
selection happens earlier in chronological time than existence
```

### Withdrawal condition

If temporal priority is needed, it must be modeled separately with explicit time parameter, operator status, and domain boundary.

## 3. Def-Phil-Reality-Strength

**Claim level**: P2/P3 bridge reading.  
**PH-SS addressed**: `PH-SS-03`, `PH-SS-12`.  
**Target legacy risk**: dreams, hallucinations, scientific facts, institutions, and physical bodies being flattened into one undifferentiated “selected reality.”

### Definition-like guardrail

> Reality in SRT should be treated as layered by anchoring strength, stabilization, cross-operator alignment, and resistance.

### E1-E4 ladder

| Level | Meaning | Example | Failure mode |
|---|---|---|---|
| **E1 — local manifestation** | selected for one operator under one `theta` | dream, hallucination, private perception | unstable, private, non-repeatable |
| **E2 — stabilized reality** | persists through repetition, memory, action, correction | durable habit, stable object-use | fails to become durable constraint |
| **E3 — cross-operator reality** | alignable across operators, instruments, contexts, interventions | public object, shared fact, robust institution | collapses under independent tests |
| **E4 — canonical physical reality** | multi-scale resistant, repeatable, scientifically stabilized | physical law, measured constant, stable biological body | local model overfit |

### Use rule

`Existence ≡ Being Selected` first licenses E1. Stronger existence claims require E2/E3/E4 tests.

### Editing rule

When a file says “X is real,” specify one of:

```text
E1 local manifestation
E2 stabilized reality
E3 cross-operator reality
E4 canonical physical reality
social L2 reality
normative L2 reality
```

### Withdrawal condition

If no stability, alignment, or resistance test is supplied, restrict the claim to E1 local manifestation.

## 4. Def-Phil-PsiF-Layers

**Claim level**: P2/P4 bridge reading.  
**PH-SS addressed**: `PH-SS-05`.  
**Target legacy risk**: `Psi_f` sliding between metaphysical cost, information geometry, bodily cost, and social normativity without layer labels.

### Definition-like guardrail

> `Psi_f` should be layer-typed in philosophy files whenever the intended meaning is not obvious.

### Layer typing

| Symbol | Layer | Meaning |
|---|---|---|
| `Psi_f^ont` | ontological / manifestational | resistance of a candidate possibility becoming determinate |
| `Psi_f^inf` | information-geometric | model-update, discrimination, Fisher-like cost |
| `Psi_f^emb` | embodied / action | sensorimotor and bodily cost of re-anchoring |
| `Psi_f^norm` | social / normative | resistance of changing habits, institutions, obligations, or identities |

### Fisher metric guardrail

> Fisher information metric may express `Psi_f` on an information-geometric slice; it does not exhaust the whole meaning of ontological friction.

### Operational proxy families

| Proxy | Question |
|---|---|
| Prediction resistance | Does the candidate selection keep generating error under changed descriptions? |
| Intervention resistance | Does the structure resist attempts to alter it by intention, reinterpretation, or local manipulation? |
| Repetition cost | How much cost is required to reproduce the same anchoring across time? |
| Cross-operator alignment cost | How much coordination is required for multiple operators to stabilize the same object or claim? |
| Model-update cost | How much must `theta` or `L_2` reorganize for the selection to remain coherent? |

### Editing rule

Use:

```text
Psi_f^inf in this paragraph means model-update / information-geometric cost.
```

Avoid:

```text
Psi_f means friction in every possible sense at once.
```

### Withdrawal condition

If a passage cannot specify its intended `Psi_f` layer, mark it as analogy / metaphor / placeholder.

## 5. Def-Phil-Normativity-Ladder

**Claim level**: P2/P3 bridge reading.  
**PH-SS addressed**: `PH-SS-06`, `PH-SS-09`, `PH-SS-12`.  
**Target legacy risk**: stable `L_2` being mistaken for moral legitimacy.

### Definition-like guardrail

> `L_2` stabilization explains how norms become real constraints; it does not automatically justify them.

### Normativity ladder

| Type | Meaning | Moral status |
|---|---|---|
| Descriptive norm | a repeated and stabilized pattern | real but not automatically good |
| Functional norm | a pattern that helps a system continue | useful but not sufficient for legitimacy |
| Evaluative norm | a pattern worth protecting or pursuing | requires legitimacy tests |
| Pathological norm | a stable pattern that survives by coercion, occlusion, or friction export | real but ethically suspect |

### Legitimacy tests

A stabilized norm becomes legitimacy-candidate only if it tends to:

1. preserve or expand future selectability;
2. reduce unnecessary `Psi_f` rather than export it to weaker agents;
3. widen cross-subject `d-value` bandwidth;
4. protect subject-generation rather than suppress it;
5. contain correction, exit, or reversibility channels;
6. avoid lethal `L_2` occlusion.

### Editing rule

Use:

```text
This norm is L2-real, but its legitimacy requires separate tests.
```

Avoid:

```text
This norm is stable, therefore it is good.
```

### Withdrawal condition

If legitimacy conditions are absent, keep the claim as descriptive social ontology, not ethics.

## 6. Def-Phil-Subjecthood-Threshold

**Claim level**: P2/P4 bridge reading.  
**PH-SS addressed**: `PH-SS-10`.  
**Target legacy risk**: micro-selection being treated as consciousness or subjecthood.

### Definition-like guardrail

> A selection event is not yet a subject. Consciousness requires high-stake, integrated, boundary-maintaining selection across time.

### Threshold conditions

A selection process becomes a candidate conscious subject only when additional thresholds are met:

| Condition | Why it matters |
|---|---|
| structured `d-value > 0` | existential stake or concern, not mere state transition |
| failure-sensitive update | the system changes when selection fails |
| integrated selection bandwidth | multiple selection channels coordinate as one perspective |
| minimal memory / `L_2` closure | traces stabilize across time |
| boundary maintenance | self-relevant and non-self-relevant perturbations are distinguished |
| counterfactual access | the system can track alternatives |
| cross-time reidentification | continuity is sufficient for a subject-like trajectory |

### Use rule

Micro-selection may be used to discuss continuity, anchoring, or primitive selection, but not automatically consciousness.

### Editing rule

Use:

```text
micro-selection does not entail subjecthood
```

Avoid:

```text
all selected entities have consciousness
```

### Withdrawal condition

If SRT cannot operationalize subject-boundary formation, it should claim to reframe rather than solve the panpsychist combination problem.
