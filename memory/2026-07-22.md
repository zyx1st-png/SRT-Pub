# 2026-07-22

## 不可修复的疲劳与错误选择的沉积

### 作者原话

> 身体不可修复的疲劳来自于，忽略初心后的错误选择的积累。

### 最小解释

这里的“不可修复”不是严格医学判断，而是一种存在论—具身经验描述：休息能够补偿单次消耗，却未必能消除长期背离自身根本方向所形成的路径沉积。

在 SRT 语境中，可暂时压缩为：

- `ε / 初心` 提供主体较深层的存在一致性方向；
- 每一次背离初心的选择，都不仅产生当下代价，还会写回身体、习惯、关系与可选择空间；
- 当错误选择持续积累，疲劳便从“能量不足”转为“维持错误现实结构的长期成本”；
- 因而真正需要修复的可能不只是身体状态，而是不断生成疲劳的选择路径本身。

可进一步凝练为：

> 有些疲劳不是工作太多，而是身体长期替一个已经不再相信的现实付费。

### 理论位置与边界

- 与 `memory/2026-04-18.md` 中“`ε / 初心`”“成功病理学”“痛苦被旧 `L_2` 征用”的链条连续。
- 当前仅作为 source intuition 保存，不进入 canonical，不构成医学因果主张。
- 后续可检验的问题：疲劳是否可被区分为短期可恢复负荷，与由选择—写回—路径固化造成的长期结构性耗损。
