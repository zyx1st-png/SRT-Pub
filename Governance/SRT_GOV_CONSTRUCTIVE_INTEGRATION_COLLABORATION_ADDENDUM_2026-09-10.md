# Governance addendum — constructive integration as the default human-AI theory-building orientation

## 1. Author trigger

The author states:

> **「SRT理论把架构从防御性比较提升成建设性整合。我觉得这是最近几轮对话下来，最有价值的一点。请把这条写到人机协作的核心内容里。方便后续工作流和对话能够从这个角度去考虑。」**

Source of record:
`01_Source_Intuition/SRT_AUTHOR_HUMAN_AI_CONSTRUCTIVE_INTEGRATION_CORE_2026-09-10.md`.

## 2. Core operating rule

For SRT ontology reconstruction, cross-domain theory work and human-AI dialogue, the default theory-building orientation is:

```text
defensive comparison
-> constructive integration
```

This refines, rather than replaces, the 2026-09-05 amendment §4.2.

Default U-mode / O-track sequence:

```text
SRT root question / author direction
-> recover current SRT constraints and source-native mature theories
-> preserve what each theory already explains well
-> place contributions at the explanatory / ontological / domain interface where they are strongest
-> preserve incompatibilities and unresolved tensions explicitly
-> reorganize relations among contributions
-> ask what new explanatory / inferential / formal / intervention / design capacity the composition enables
-> especially test whether it supports joint reconstruction of future selectability
-> enter bounded N-mode only when an actual comparative claim requires it.
```

## 3. Role of comparison

Strongest-neighbor work remains mandatory when a real claim of uniqueness, irreducibility, superiority or extra predictive/intervention consequence is made.

Outside that scope, comparison primarily serves:

```text
source fidelity;
boundary discipline;
anti-relabeling;
anti-overclaim;
incompatibility detection;
routing of mature mechanisms to the right interface.
```

A neighbor can defeat a local novelty claim and still become a valuable component of the constructive integration.

`NEIGHBOR-PAID` is therefore not, by itself, a command to continue residual narrowing.

## 4. What counts as constructive integration

Constructive integration is not theoretical accumulation or vocabulary absorption.

At least one real gain must become inspectable, for example:

```text
an explanatory dependency that was disconnected before composition;
a new checkable question or inference;
a compositional formal relation;
a better intervention choice;
a design capacity that depends on several correctly connected mechanisms.
```

Current author-directed target:

> **共同重构未来可选性的能力 / capacity to jointly reconstruct future selectability.**

This is a research target, not an already earned superiority result.

## 5. Human-AI division

```text
AUTHOR:
owns root question, meaning, direction and substantive adjudication.

AI:
recovers sources and existing SRT owners;
preserves source-native contributions;
identifies interfaces and incompatibilities;
proposes relational compositions;
red-teams circularity, hidden premises and overclaim;
checks whether the proposed whole adds a real capability beyond juxtaposition;
returns unresolved substantive meaning to the author.
```

AI should not optimize every turn for a smaller proprietary residual merely because a neighboring theory pays a local mechanism.

## 6. Runtime and historical discipline

This addendum does not retroactively pretend that earlier #929 passes already followed the rule perfectly.

The #929 sequence itself contains a useful failure-and-correction record:

```text
Pass 17-22:
strongest-neighbor / residual pressure remained dominant in several passes.

Pass 23:
author explicitly redirected the programme toward integrative construction.

Pass 24 onward:
default research mode for the current integration workline is U unless a bounded comparative claim is explicitly opened.
```

The residual-hunt circuit breaker remains valid. Historical adverse results and neighbor payments remain preserved.

## 7. Non-effects

This addendum does not:

```text
establish scientific superiority;
assign a new Level 1 or Level 2;
release HOLD;
make all theories mutually compatible;
make JFS a canonical ontology ladder;
replace source-native theory with SRT labels;
authorize canonical edits.
```
