# Book-to-Canonical Increment Shim

> Purpose: handle theory-bearing increments that have appeared in the current book line without silently promoting book prose into canonical definitions.
>
> This file is a governance shim. It does not define SRT terms. It records what the book has added, where each increment should land if later hardened, what level it can currently be cited at, and what promotion is forbidden.

---

## 0. Core Rule

Book drafts are high-value retrieval context, but they are not definition authority.

When a book sentence appears stronger than the current canonical anchor, read it through this filter:

```text
book force -> candidate increment -> claim-level assignment -> canonical landing zone -> explicit forbidden promotion
```

Do not move directly from:

```text
book force -> canonical theorem
```

This file exists because the current book line has become theoretically productive: it is not merely popularization. It now generates candidate structures that may later harden into canonical notes, bridge supplements, open tensions, or domain tests.

## 2. Minimal Safe Readings

### 2.1 Selection structure

Book reading:

```text
A concrete reality stands up only when some possibilities recede, one shape stabilizes, and the result leaves a trace.
```

Safe canonical reading:

```text
This is a companion / explanatory structure for manifestation and stabilization. It is not a derivation of the first selectable agency from a non-selective ground.
```

Guard:

- Link to P0-04 as an open exposure point when using selector-like language.
- Say "selection structure" or "selection-like convergence" when the domain does not yet support full subject/agency language.

### 2.2 Agency / 能动性

Book reading:

```text
Agency begins when a position does not merely receive consequences, but can carry returned consequences into the next round of selection.
```

Safe canonical reading:

```text
Agency is being framed as a consequence-return capacity after a position already exists. This supports stable-ISP and T_dir hardening, but does not derive the first selector.
```

Guard:

- Do not collapse agency into free will.
- Do not collapse agency into mechanical feedback.
- Require a consequence-bearing, stake-bearing, or concern-bearing position before using agency language strongly.

### 2.3 Friction allocation / externalization

Book reading:

```text
Order does not eliminate friction; it distributes friction. Power decides which friction is visible, payable, returnable, or externalized.
```

Safe canonical reading:

```text
Canonical Ψ_f defines payability burden / ontological impedance. Claims about who pays, whether burden is externalized, and whether return paths are cut belong to L1 / collective / social-pathology projection until separately hardened.
```

Guard:

- Do not write "Ψ_f is conserved" unless a future canonical theorem is added.
- Do not infer that every externalization leaves a measurable residue without specifying position, channel, return path, and proxy.
- Use "friction allocation" as a bridge phrase, not a new canonical definition.

### 2.4 Direction three questions

Book reading:

```text
A direction is structurally suspect when it consumes its own future basis, externalizes consequences to positions that cannot respond, or locks the path against re-selection.
```

Safe canonical reading:

```text
The three questions are a fallibilist structural diagnostic for direction. They are not a final ethics, not a maximization rule, and not a solved closure-boundary.
```

Guard:

- Use them as threshold diagnostics, not moral totalization.
- Preserve response / appeal / correction channels for evaluated positions.
- When other-regarding boundaries matter, link to closure-boundary open tension.

### 2.5 Community as consequence-return network

Book reading:

```text
A community is not a pile of individuals or a big subject; it is a multi-position structure of consequence return, response, and revisability.
```

Safe canonical reading:

```text
This is a collective-selection diagnostic. It helps locate social health/pathology but does not solve aggregation, representation of voiceless positions, or final boundary weighting.
```

Guard:

- No collective will unless separately justified.
- No big-subject ontology.
- No final aggregation rule from book prose.

### 2.6 Falsifiability discipline

Book reading:

```text
SRT must say where it dies; otherwise it becomes a self-sealing interpretive machine.
```

Safe canonical reading:

```text
The book offers public-facing failure-condition candidates. They should be converted into operational variables before being used as lab or domain tests.
```

Guard:

- Failure lists are not victory conditions.
- Cross-domain examples are manifestation / illumination, not proof.
- Competing theories must be allowed to beat SRT on external variables.

## 3. Promotion Queue

If a maintainer later wants to harden these increments, use this sequence:

1. **Register as retrieval support**: add this shim to `_SRT_INDEX.md` and/or `_SRT_AGENT_RETRIEVAL_PROFILE.md` as support, not authority.
2. **Route to open tension**: if the increment touches an unresolved pressure point, update `Core/SRT_OPEN_TENSIONS.md` rather than canonical anchors.
3. **Create bridge note first**: if the increment needs formal development, create a bridge-hardening note before touching frozen files.
4. **Only then consider canonical anchor edits**: edits to `L0`, `d`, `Ψ_f`, `T_dir`, core axioms, or equations require `SRT_CANONICAL_FREEZE.md` and `SRT_EDIT_PROTOCOL.md` high-risk treatment.
