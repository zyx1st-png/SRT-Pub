# Author ruling — Selection-position is ontological/structural; Bearer is cognitively special

> **Routing:** this record captures the author's clarification after the RBH2 fork was restated in intuitive form and after Cycle-2 had been reframed around cross-domain ontological unification. It is controlling for the layer assignment between `Selection-position` and `Bearer` in this workline, but it does not by itself establish a Level verdict or a formal theorem.

## 1. Exact author statement

> **「bearer 是在认知上的特殊性，选择不是随意的，对位置的稳定有承担作用。selection-position 是结构和本体上的特殊性，如果没有 selection-position，系统变为传统反馈系统，可以由外部观测获得完整的动力学。」**

Status:

```text
AUTHOR SOURCE / CONTROLLING CLARIFICATION
```

## 2. Minimum licensed layer separation

The author explicitly places the main structural / ontological specialness on `Selection-position`, not on Bearer as an independently deeper ontological primitive.

Minimum safe reading:

```text
Selection-position:
  structural / ontological specialness;
  the non-arbitrary "from-where" of later Selection;
  candidate site where manifestation/background asymmetry
  becomes organized as a stable selective position.

Bearer:
  primarily cognitive-level specialness / continuity attribution;
  participates in the stability / continuation of the position;
  should not be used to move observer-facing consequence language
  back into primitive ontology.
```

The author sentence does not yet fix a necessary-and-sufficient Bearer definition.

## 3. Selection is not arbitrary

The phrase:

> **「选择不是随意的，对位置的稳定有承担作用」**

licenses at minimum the following pressure target:

```text
Selection
!= arbitrary isolated event;

repeated / continuing Selection
is related to stabilization / continuation of a Selection-position.
```

This file does not decide whether the grammatical subject of “承担作用” should be formalized as:

```text
Selection itself stabilizes Position;
Bearer stabilizes / carries Position;
or
both are recursively coupled.
```

That exact dependency must remain available for later author clarification rather than being silently chosen by AI reconstruction.

## 4. Traditional-feedback contrast — author claim requiring pressure

The author further states:

```text
without Selection-position
-> the system becomes a traditional feedback system
-> complete dynamics can be obtained from external observation
```

This is a strong claim and must be separated into at least two readings before promotion.

### Reading A — third-person dynamical closure

```text
a system lacking Selection-position
can in principle be exhausted, at its declared dynamical level,
by a third-person state / transition / feedback description.
```

This is an ontological / explanatory closure claim.

### Reading B — empirical reconstructibility from outputs

```text
an external observer can actually reconstruct the complete internal dynamics
from measured inputs / outputs.
```

This is a control / observability / system-identification claim and is much stronger.

The author did not yet distinguish these readings explicitly.

## 5. What is not licensed yet

Do not infer:

```text
all ordinary feedback systems are observable;
all feedback-system states can be uniquely reconstructed from outputs;
Selection-position is an unobservable hidden state;
Selection-position adds a new causal force beyond domain dynamics;
predictive incompleteness is required for Selection-position;
Bearer is merely an observer label with no cognitive role;
Bearer is a new L0 primitive;
```

## 6. Immediate route

The next valid machine move is a strongest-neighbor pressure pass on the phrase:

```text
"external observation obtains complete dynamics"
```

using control-theoretic observability / realization results, while preserving the author's deeper distinction between:

```text
third-person dynamical closure
and
Selection-position as structural / ontological from-where.
```

The pressure must also test whether `Selection-position` can be eliminated by simply augmenting the ordinary state vector with a hidden / latent state.
