# Author adjudication — Selection-relative background, vertical recurrence, and One formation

> **Nature:** noncanonical author adjudication. This record does not edit canonical owners, does not open the One owner cycle, does not create a new symbol, Level assignment, N&S theorem, or scientific-distinctiveness claim.
>
> **Controlling purpose:** tighten the current #957 whole-skeleton reconstruction so that `manifestation / relative backgrounding`, `verticality`, and `regenerative recurrence` are not silently re-read through an object-first or generic-process ontology.

---

## 1. Why this adjudication is needed

The current whole-skeleton reconstruction already fixes:

```text
Oriented Openness
-> finite-position-indexed subjectless Selection
= actual differentiation
= manifestation / relative backgrounding
= primitive verticality
--[regenerative recurrence]-->
One
```

and #957 already author-accepted:

```text
Selection-generated organization_t
-> conditions later Selection_(t+1)
-> Selection_(t+1) generates organization_(t+1)
   that can again carry the relevant conditioning role.
```

That direction remains accepted.

The remaining problem is semantic overbreadth:

```text
organization
```

can be read too generically, and

```text
relative backgrounding
```

can be misread as selection among already-objectified alternatives.

This adjudication therefore does not replace #957. It narrows the intended reading.

---

## 2. V1 — Selection generates a vertical relation, not two completed objects

**AUTHOR-ACCEPTED:**

For explanatory purposes, a Selection event may be represented noncanonically as:

```text
Selection_S
-> [A / A*]_S
```

The whole bracketed relation is the relevant event-level vertical organization.

Do **not** read this as:

```text
Selection
-> object A + object A*
```

The notation is explanatory only. `A*` is not introduced as a canonical symbol.

---

## 3. V2 — ontological status of `A*`

**AUTHOR-ACCEPTED:**

`A*` is not another manifest object or completed rival content.

```text
A* != B;
A* != C;
A* != logical complement ¬A;
A* != a set of rejected options;
A* != an observer-added later counterfactual;
A* != a separately existing hidden object.
```

`A*` names, only at explanatory level, the **Selection-relative background side co-generated with the manifestation of A**.

Accordingly:

> the manifest side and its relative background side are two structurally asymmetric readings of one world-side Selection event, not two independently admitted objects.

---

## 4. V3 — no completed option menu is required

**AUTHOR-ACCEPTED:**

The intended order is not:

```text
{A, B, C, ...}
-> Selection chooses A
-> B/C become unchosen.
```

Instead:

```text
non-flat / non-neutral openness
-> Selection
-> [manifest side / Selection-relative background side]
```

The relative background side therefore does not need to exist before Selection as a completed content or enumerated option set.

This preserves the current no-option-menu guard.

---

## 5. V4 — event-level verticality does not establish One

**AUTHOR-ACCEPTED:**

A genuine Selection may generate event-level vertical organization without thereby generating persistence, durable history, or a continuing One.

```text
Selection
-> [A / A*]
```

is compatible with:

```text
no durable recurrence;
no stable locus;
no One;
no Bearer;
no subject-position.
```

Therefore:

```text
event-level verticality != One automatically;
occurrence != persistence;
primitive verticality != historical continuation by definition.
```

---

## 6. V5 — Selection sedimentation is not object sedimentation

**AUTHOR-ACCEPTED:**

When a Selection leaves a later-effective historical consequence, what matters is not the storage of object `A` or object `A*` as such.

The relevant burden is:

> the vertical differentiation produced by prior Selection makes a real, load-bearing difference to the conditions under which later Selection occurs.

Compactly:

```text
prior Selection-generated vertical differentiation
-> changes later Selection conditions
```

This is compatible with history remaining distributed in the wider relational field before Bearer-level own-history is established.

Do not infer:

```text
sedimentation = static structure deposit;
sedimentation = object A preserved;
sedimentation = A* stored as an object;
sedimentation = Bearer own-history automatically.
```

---

## 7. V6 — One requires vertical recurrence, not generic recurrence

**AUTHOR-ACCEPTED semantic tightening of #957:**

The `organization` that matters for One-forming recurrence is not arbitrary organization merely because it persists or influences later process.

The intended minimum is:

```text
Selection-generated vertical organization_t
-> materially conditions later Selection_(t+1)
-> Selection_(t+1) generates renewed vertical organization_(t+1)
-> renewed vertical organization_(t+1)
   can again materially condition further Selection.
```

Therefore:

```text
generic causal recurrence != One automatically;
process persistence != One automatically;
self-maintenance != One automatically;
repeated similarity != One automatically;
ordinary path dependence != One automatically.
```

The recurrence burden is a **Selection-mediated vertical reconstitution burden**.

This does not create a new primitive operation. Selection remains the sole primitive generative operation in the current whole-skeleton reconstruction.

---

## 8. V7 — localization / relative separability are generated, not pre-given

**AUTHOR-ACCEPTED direction:**

One formation must not begin by presupposing a completed local unit, mature boundary, or independently identified locus.

The intended explanatory order is:

```text
repeated Selection-generated vertical differentiation
-> historically non-equivalent reconstitution dependence
-> relative continuation separability
-> formed locality / process-unity
-> One
```

Accordingly:

```text
locality != primitive object boundary;
relative separability != causal isolation;
relative separability != material independence;
relative separability != mature closure;
relative separability != autopoiesis.
```

Formation locality remains a generated relation inside One formation, not an upstream completed object premise.

---

## 9. V8 — lineage is downstream continuity language, not an admission premise

**AUTHOR-ACCEPTED:**

Do not reason:

```text
same lineage
-> therefore One continuation.
```

The intended order is:

```text
Selection-mediated vertical reconstitution path
-> formed One
-> continuation / lineage description becomes available downstream.
```

Therefore:

```text
same token = NOT PRESUPPOSED;
same lineage = NOT PRESUPPOSED;
same material composition = NOT REQUIRED;
same spatial position = NOT REQUIRED;
strict numerical identity = OPEN;
branch / merge identity = OPEN.
```

This strengthens, rather than reverses, the #957 ruling that recurrence is role recurrence rather than token identity.

---

## 10. V9 — post-One Selection remains the same primitive kind

The #957 adjudication remains accepted:

```text
pre-One:
subjectless finite-position-indexed Selection

post-One:
the same primitive Selection
now occurring under conditions partly generated / constrained
by a formed One / Selection-position.
```

No second universal primitive `Selection_O` is introduced.

The new clarification is only that the formed One conditions later Selection through a history of Selection-generated vertical organization / reconstitution, not by becoming a hidden selector standing behind Selection.

---

## 11. `A*` is Selection-relative, not a global complement

**AUTHOR-ACCEPTED guard:**

Do not define:

```text
A* = Universe - A.
```

The background side is indexed to the finite-positioned Selection event:

```text
A*_S
= background-relative-to-A-under-Selection-S.
```

This prevents the relative background from being reified into one static universal object.

Different Selection events may therefore generate different manifest/background organizations without requiring one global completed partition of reality.

---

## 12. Consequence for `多` / Many

**AUTHOR-ACCEPTED direction:**

Before formed One, `多` must not be reduced to a collection of already completed objects:

```text
Many != {object A, object B, object C, ...} by definition.
```

The relevant pre-One picture is a wider open relational field in which multiple Selection events and their consequences may remain distributed, coupled, mutually supportive, mutually constraining, or differentially load-bearing for later Selection.

A formed One arises when a relatively separable Selection-mediated vertical reconstitution path becomes load-bearing enough to count as a formed process-unity at current D4a strength.

No scalar threshold is set here.

