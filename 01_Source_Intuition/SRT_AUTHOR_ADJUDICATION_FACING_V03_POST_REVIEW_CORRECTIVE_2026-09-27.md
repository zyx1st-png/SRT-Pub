## 3. F3 — author-blind-first is mandatory

Accepted:

> the machine must not show its own “object-too-early” / recut candidate before the author's first response.

The author first sees only:

- the source-native domain question;
- the source-native object / variable cut;
- the minimal factual context required to understand the domain;
- blind generative-confrontation questions.

The first author response is preserved before machine recut candidates are revealed.

Only afterward may the machine show its own candidate recuts and compare:

~~~text
independent human-machine convergence;
independent divergence;
machine-only candidate;
author-only candidate.
~~~

The purpose is to reduce machine anchoring of author intuition.

## 4. F1 — protect intuition generation, gate claim promotion

The author-side bias problem is accepted, but not by requiring a falsifier at the moment of raw intuition.

Accepted asymmetry:

~~~text
Stage / phase of intuition generation:
author response may remain intuitive, metaphorical, incomplete, preformal,
and may simply identify that the explanatory direction feels wrong.

Such output = AUTHOR RECUT CANDIDATE / PREFORMAL.
~~~

No prediction or falsifier is required at this generation step.

However, promotion is gated.

Before an author recut may become any of the following:

- a formal domain-reconstruction conclusion;
- a new experiment / preregistered discriminator;
- an SRT / GRG explanatory increment claim;
- a canonical consequence;

the later adversarial stage must identify at least one differentiating consequence, for example:

- different dependency order;
- different object / unit / boundary / grain;
- different failure localization;
- different intervention;
- different prediction;
- different reconstruction requirement;
- or a stated observation / result that would cause the recut to be abandoned or materially narrowed.

If no such consequence survives:

~~~text
interpretive restatement / PREFORMAL_ONLY / NO_GAIN / SOURCE_ABSORBED
~~~

is valid and the recut must not be promoted merely because it originated from the author.

Preserving an intuition as source provenance is distinct from promoting it as a research claim.

## 5. F2 — graded Stage-C / adversarial independence

Accepted with scope control:

~~~text
ordinary exploratory author-led Facing reconstruction
-> same session may perform the adversarial return,
   provided it explicitly argues against the preferred recut;

promotion to:
- a new experiment / preregistration;
- a formal domain-reconstruction claim;
- a strong SRT / GRG increment claim
-> independent session / model context must rerun the adversarial return from source material;

canonical semantic consequence
-> existing independent pre-merge review rules still apply in addition.
~~~

This avoids converting every exploratory dialogue into a governance-heavy multi-agent workflow.

## 6. F4 — no retroactive Mode typing of #1074

The reviewer's request to classify #1074 as source-only vs author-reconstruction mode is **not accepted**.

Reason:

- #1074 predates Facing v0.3;
- it was not a cross-domain Facing reconstruction pass;
- it combined reverse-neighbor work, primitive triangulation, machine analysis and repeated author adjudication under a distinct anti-tautology route.

Therefore do not retroactively force #1074 into later Facing execution classes.

The useful clarification is accepted:

~~~text
future author-led Facing reconstruction
!= automatic reopen of the #1074 anti-tautology STOP.
~~~

A future Facing result may reopen primitive anti-tautology **only if its actual output independently satisfies one of the already-frozen reopen conditions**:

1. a genuinely new author-owned primitive distinction not reducible to already-subtracted burdens;
2. a non-circular downstream derivation that fails under a fair role-matched rival;
3. a prospective intervention / exclusion specific to O0/S0;
4. a representation-invariant world-facing relation not already paid by mature neighboring theories.

Facing method choice itself is not a reopen condition.
