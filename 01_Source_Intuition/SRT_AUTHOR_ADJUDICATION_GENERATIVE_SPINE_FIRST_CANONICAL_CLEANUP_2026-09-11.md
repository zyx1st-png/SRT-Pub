# Author adjudication — canonicalize the new generative spine before old-canonical cleanup

> **Role:** record the author's explicit change in reconstruction priority on 2026-09-11. This source authorizes a bounded canonical generative spine to become the routing standard before the repository continues semantic cleanup of older canonical surfaces. It does not itself settle downstream OPEN gates such as `承担`, concern, agency, subject-position, cognition, consciousness or phenomenality.

## 1. Immediate author direction

The author stated that the next step should be:

> **先压一下新主轴，做成新的 canonical，然后基于这个新主轴去对旧 canonical 进行梳理，去掉错误、过度声明等问题，并进行简洁化，而不是让之前不成熟的 canonical 影响目前理论的研究和进展。**

This changes the execution order from:

```text
old canonical cleanup first
-> infer the surviving architecture
```

to:

```text
compress the author-converged new generative architecture
-> land it as the cross-owner canonical spine
-> audit older canonical / canonical-seeming surfaces against that spine
-> retire errors / overclaim / duplicate authority
-> simplify to one-owner / many-consumer architecture.
```

## 2. What is being authorized

The author authorizes a **thin cross-owner canonical spine** whose job is to fix:

```text
current generative ordering;
formation / standing / bearing layer boundaries;
history-vs-source typing;
position / perspective / anticipation typing;
Bearer onset at the accepted P + E reconstruction strength;
explicit OPEN downstream relations;
anti-circularity rules for sigma / d / T_dir / Stable ISP.
```

The spine is not authorized to become a giant replacement definition file. Local semantic owners should remain local owners where compatible.

## 3. Supersession / cleanup meaning

After the new spine lands:

```text
older canonical status
!= immunity from audit;

older file name / theorem label / claim_mode
!= authority to override the new cross-owner generative order;

local definition ownership may survive
only within the scope compatible with the new spine.
```

Where older material implies a conflicting cross-layer inference, that inference becomes a cleanup target rather than a constraint on current theory development.

Examples of targeted conflict types include:

```text

Stable ISP treated as the formation source of One;

Bearer collapsed into 承担 / concern / subject / experiencer;
reader prose or alignment files presented as independent canonical owners;
duplicate definitions spread across multiple files.
```

## 5. Execution instruction

The authorized order is:

```text
A. land the thin generative ontology spine;
B. make Registry / runtime routing point to it for cross-owner ontology order;
```

This order is intended to prevent immature historical canonical material from dictating current ontology merely because it was canonicalized earlier.
