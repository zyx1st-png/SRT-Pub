# Author Re-entry — physical trigger pluralism, pass 1

## 1. Literal author statement

> SRT不会把物理登记作为最底层的理论推进基础，所以更倾向于C，但是不排除可以形成符合A的准入面，只是不作为重点。

## 2. Author ruling extracted without extension

The author does **not** license physical registration as the bottom-level basis from which SRT's primitive Selection is derived or advanced.

Primary architecture:

```text
SEL-PHYS-C as the governing orientation:
SRT currently does not require one interpretation-neutral physical Selection trigger
as the foundation of primitive Selection.

primitive Selection / actualisation remains ontologically prior in the SRT architecture;
physical domains may supply implementation-specific realization or admission surfaces.
```

At the same time, the author explicitly does **not** forbid an A-like downstream surface:

```text
A-like physical admission surface may be developed
within a declared physical model / interpretation / event boundary
if it proves useful and non-circular.
```

But:

```text
A-like surface
!= bottom-level definition of Selection
!= derivation of primitive actualisation
!= privileged foundation of SRT
!= mandatory research priority
```

## 3. Relation to IRR-B

The author retains the prior IRR-B ruling:

```text
every genuine Selection
-> unavoidable causally effective residue somewhere in the complete causally relevant present state / enlarged environment
-> exact complete-state restoration is impossible.
```

This record does not add a universal physical trigger for determining when genuine Selection has occurred.

Therefore the current architecture is intentionally asymmetric:

```text
ontology-level constraint:
genuine Selection -> global non-cancellability

physical-domain admission:
implementation-specific / interpretation-indexed / still open
```

## 4. Relation to PHR-A

This ruling is continuous with `PHR-A — Interpretation-Plural Realisation Audit`:

```text
one primitive actualisation kernel
+
plural domain realizations / audits
```

It sharpens PHR-A by adding a priority rule:

> Physical registration may test, instantiate, or operationally admit a realization candidate, but it must not be elevated into the metaphysical source of Selection merely because it is experimentally convenient.

## 5. Explicit exclusions

This author ruling does not authorize:

```text
- universal collapse as the physical definition of Selection;
- outcome-indexed registration as a new P0 axiom;
- a claim that every domain must use the same Selection trigger;
- using a successful physical admission test to prove P0 Selection-first ontology;
- abandoning A-like domain tests where scientifically useful;
- treating IRR-B as already empirically established.
```
