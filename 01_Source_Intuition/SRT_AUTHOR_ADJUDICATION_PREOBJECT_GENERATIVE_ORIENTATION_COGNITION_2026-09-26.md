# Author adjudication — cognition begins from pre-object generative orientation, not object-built attractors

> **Role:** root correction of the 2026-09-26 intuition research programme.
>
> **Boundary:** noncanonical research direction. This is not a canonical SRT cognition theorem and not a claim that a literal physical field has been established.

## 0. Direct author correction

> 「我主要关注的是我们所有人的认知，本质上不是先获得对象，然后在对象(知识和规则等）之上建立吸引子和方向。而是先在预期，bearer，原初选择，神性等作用下产生吸引子，一种统一的、连续的、生成性的、归一化的非对象。然后才把一些显性的对象装进去形成连续性的结构。就像先有磁场，然后有磁力线一样。」

This explicitly corrects any research framing of the form:

~~~text
objects / knowledge / rules
-> accumulated relational structure
-> attractor / intuition
~~~

as the primary cognitive architecture.

---

## 1. Controlling direction

The author's current direction is:

~~~text
pre-object generative orientation
comes first at the cognitive-structural level;

explicit objects
are later local foreground formations / stabilizations
within that already-directed organization;

retained objects / knowledge / rules
can later reshape the next pre-object organization,
but they do not exhaust its origin.
~~~

The key inversion is:

~~~text
NOT:
objects -> relations -> attractor -> direction

BUT:
generative orientation -> objectification -> explicit objects
-> retention / sedimentation -> later reshaping of generative orientation.
~~~

---

## 2. "Attractor" is a working analogy, not yet the final formal object

The author uses attractor language to point at:

- prior directionality;
- continuity;
- normalization;
- unified organization;
- selective tendency;
- non-objective structure.

A single fixed-point attractor may be too narrow.

Potential formal families include:

- attractor landscape;
- continuous attractor;
- vector / flow field;
- metastable manifold;
- dynamical constraint geometry;
- gate geometry.

Therefore use:

> **pre-object generative orientation**

as the neutral root phrase.

Use "field" or "attractor geometry" as model candidates, not ontology by fiat.

---

## 3. Multi-level contributors must not be flattened

The author's list includes terms from different theoretical levels.

### Primitive Selection / generativity

Provides the deeper Selection-first / non-preclosed generative condition.

It is not a cognitive representation.

### "Generative divinity" provenance

The 09-24 source uses "神性" as provenance for primitive generativity / nonclosure.

Guard:

~~~text
no agent
no designer
no purpose
no supernatural force
~~~

### Bearer

Provides the formed continuation-position relative to which some differences are consequential / non-neutral.

Bearer is downstream formed organization, not primitive Selection.

### Structural Expectation

Provides directional burden / prepared continuation without requiring an explicit proposition or object-model.

Expectation can therefore participate before reflective objectification.

### Gate / normalization structure

Provides selective coarse-graining:
- which differences remain active;
- which are backgrounded;
- which transitions are easy / hard;
- which distinctions can become foreground.

Together these may shape a continuous, non-objective cognitive orientation.

## 5. Objects are not the bricks from which cognition is first assembled

The author correction rejects the picture:

~~~text
object A
+ object B
+ object C
-> relational graph
-> global cognition.
~~~

Instead:

> explicit objects are local stabilized cuts within an already-directed generative process.

They may later become:
- anchors;
- constraints;
- memory landmarks;
- rules;
- symbolic handles;
- social coordination devices.

But cognition is not exhausted by manipulation of those explicit units.

---

## 6. Magnetic-field analogy — intended content and guard

The intended analogy:

~~~text
field-like directionality / organization first;
explicit lines / local structures later reveal or stabilize aspects of it.
~~~

The analogy should not be taken literally.

Physical magnetic field lines are representational constructions for a field; they are not separate objects inserted into it.

The cognitive point is:

> **the global directional organization is not assembled only after explicit local objects already exist.**

A safer operational analogy may be:

~~~text
continuous field / flow
-> local ridges / basins / trajectories / landmarks
~~~

rather than:

~~~text
objects
-> graph
-> field.
~~~

## 7. Preformal coherence sensitivity becomes a downstream phenotype

The previously defined "preformal coherence sensitivity" remains useful, but no longer as the root construct.

New position:

~~~text
pre-object generative orientation
-> proposal / input perturbs the organization
-> mismatch / fit changes the field before explicit reason is formed
-> early "this is wrong / right" judgment
-> later objectification of the violated relation
-> explicit explanation / recut.
~~~

Therefore:

> early coherence judgment is one possible observable window onto pre-object generative orientation.

It is not the orientation itself.

## 8. L0 / L1 / L2 interpretation

This correction is compatible with the author-adjudicated view that L0 / L1 / L2 are analytic views.

### L0-facing

Ask:

> what pre-object generative orientation makes some distinctions / objects more formable than others?

### L1-facing

Ask:

> what explicit object / distinction becomes foregrounded now?

### L2-facing

Ask:

> what retained objects, rules, histories and stabilizers continue to reshape the next orientation?

Recursive relation:

~~~text
pre-object orientation
-> objectification
-> retention
-> later pre-object orientation.
~~~

The existence of later L2 influence does not imply that the original orientation was built out of prior explicit objects.

---

## 9. Main empirical question

The new research question is stronger than:

> can people judge coherence before explaining it?

It becomes:

> **Can cognition be shown to exhibit structured, directional, integrated organization before explicit object / rule representation, such that later objectification samples, stabilizes or discretizes that prior organization?**

Subquestions:

1. can orientation be detected before object identification?
2. can global direction change object formation without explicit rule access?
3. can structural expectation bias what becomes an object before propositional expectation is available?
4. can the same explicit objects be organized differently by changing pre-object orientation?
5. can explicit object learning later reshape the orientation recursively?
6. are individual differences better explained by properties of the pre-object orientation than by object knowledge alone?

## 10. Strong neighbors

The current direction has important scientific neighbors.

### Skilled Intentionality / field of relevant affordances

Ecological-enactive work describes skilled agents as selectively engaging with a field of relevant affordances, where multiple possibilities solicit action pre-reflectively and are shaped by abilities / concerns.

Strong overlap:
- field-like relevance before explicit deliberation;
- action-readiness;
- concern-relative orientation;
- pre-reflective directedness.

Potential residual:
- SRT's Selection / Bearer / objectification / L0-L1-L2 reconstruction architecture.

### Operative intentionality

Phenomenology and computational-phenomenology work distinguishes pre-reflective bodily / operative intentionality from explicit object-oriented judgment.

Strong overlap:
- directedness before reflective object cognition.

### Metastable coordination dynamics

Neuroscience models show cognition emerging from continuously reorganizing, metastable large-scale coordination rather than from a fixed sequence of isolated object representations.

Strong overlap:
- continuous organization;
- integration + segregation;
- transient coordination.

### Predictive / Bayesian processing

Prediction and prior structure can shape perception before final object interpretation.

Strong overlap:
- prior direction / context shapes object processing.

Difference to test:
- whether prediction models still presuppose a sufficiently objectified model vocabulary that the present hypothesis seeks to go beneath.

### Gestalt / field organization

Gestalt traditions reject atom-first assembly and emphasize organization / whole-structure as primary in perception.

Strong overlap:
- organization precedes decomposition into independent elements.

No novelty claim follows from these overlaps.
