# Author ruling — L0 difference -> Selection -> vertical structure -> stabilized multi-subject order

> **Role:** record the author's clarification after Pass-18 owner reconciliation. This source fixes the minimum forward dependency from L0 difference through Selection and ontological vertical structure into multi-subject order. It is not a canonical edit, not a new Level verdict, and not a ruling that every multi-subject order is a higher-order collective One.

## 1. Exact author statement

> **「L0的差异通过选择获得本体上的垂直结构，这种垂直结构构成了更多差异在更多主体参与下（选择）形成了更稳定的选择从而形成多主体的秩序。」**

Status:

```text
AUTHOR SOURCE / CONTROLLING CLARIFICATION FOR CURRENT #929 WORKLINE
```

## 2. Minimum licensed dependency

The narrowest safe reconstruction is:

```text
L0 difference / non-neutral differentiation
-> Selection
-> ontological vertical structure
-> that vertical structure becomes part of the conditions / organization
   under which further differences are encountered and selected
-> with participation by more subjects / selective centres,
   selections become more mutually stabilized
-> multi-subject order forms.
```

The author therefore does not place multi-subject order at L0 as a primitive goal. Order appears downstream from repeated / distributed Selection operating through already formed vertical structure.

## 3. What "vertical structure" is doing here

This ruling gives vertical structure a stronger forward role than a static foreground/background description.

Minimum safe reading:

```text
vertical structure
!= merely an observer's classification of foreground vs background;
!= merely a stored historical state;

vertical structure
= an ontological asymmetry produced through Selection
  that helps organize the conditions of later Selection.
```

The ruling does not yet authorize one universal mathematical realization of this structure.

## 4. Multi-subject order is formed through stabilized Selection

The new author statement sharpens SP-O:

```text
multi-subject order
is not introduced as an externally imposed global frame;
it forms when more subjects participate in Selection
within / through already generated vertical structures,
and their selections become more stable in relation to one another.
```

Thus the relevant bridge is:

```text
vertical differentiation
-> repeated / distributed selection among multiple centres
-> greater relational stability of Selection
-> multi-subject order.
```

This is stronger than the broad claim that "agents interact and order emerges," but the exact stabilization relation remains open for pressure.

## 5. Relation to collective One / T-COLL-1

This author ruling does **not** say:

```text
multi-subject order = collective One;
every stable multi-subject order = collective ISP;
order formation requires a higher-order subject;
T-COLL-1 standing conditions are the genesis law of order.
```

Therefore the existing owner distinction remains necessary:

```text
multi-subject order can exist without collective-subject standing;
T-COLL-1 applies only if the resulting organization additionally qualifies
as a higher-order history-bearing / perspective-bearing / continued-selectable unit.
```

Whether some multi-subject orders later form a higher-level Selection-position / collective One remains OPEN and requires a separate author or owner ruling.

## 6. Relation to the previous CR-A / CR-B / CR-C machine fork

The Pass-18 owner reconciliation offered three machine-side routes. The present author ruling does not simply choose one of them.

It replaces their framing with a more specific dependency:

```text
AUTHOR-OWNED CORE:
L0 difference
-> Selection
-> ontological vertical structure
-> more differences + more participating subjects / selections
-> more stable Selection
-> multi-subject order.
```

Consequences for the old fork:

```text

CR-B as complete separation between local Selection-position and multi-subject order: TOO WEAK
CR-C conditional collective-One recursion: STILL POSSIBLE, BUT NOT DECIDED HERE
```

The current author-owned point is the vertical-structure-to-stabilized-selection bridge, not collective subject formation as such.

## 7. What remains open

Do not infer without further author ruling or audit:

```text
whether "more stable Selection" means temporal persistence, recurrence,
mutual compatibility, lower conflict, increased closure, or some conjunction;

whether each participating subject must already possess a mature Selection-position;

whether vertical structure is identical across scales;

whether the same mechanism generates individual existence and social order;

whether a sufficiently stable multi-subject order necessarily becomes a collective One;

whether a collective One has its own Selection-position;

any quantitative threshold for stabilization;

any new Level 1 / Level 2 verdict;

any canonical rewrite.
```

```text

interactional autonomy;
collective individuation;
endogenous network / topology formation;
multi-agent coordination and stabilization.
```
