# Author adjudication — cross-level Selection + fresh-session comparison guard

## 1. Trigger

A repository-derived submission-strategy reading characterized CogWAM as another
"history-event-action" implementation that does not require the Selection
primitive. The author clarified that the important issue is not repairing one
quarterly report, but preventing future sessions from repeating the same
cross-level inference error.

## 2. Author statements

> 「我感觉仓库还强调基于L2层面的历史回写，改变后续路径。在SRT应该关注的是跨层级之间的相互影响，比如L0到L1的选择、L1到L2的选择等等。」

> 「重点不是季报。而是避免其他会话出现类似的问题。」

These statements are retained as source intuition / author direction. The
examples `L0 -> L1` and `L1 -> L2` are not by themselves a new canonical
claim that L0/L1/L2 are sequential ontic containers; current analytic-aspect
guards remain in force.

## 3. Controlling clarification

The repository should not allow this inference:

~~~text
neighbor implements
history -> event/state -> later action
therefore
Selection primitive / cross-level SRT burden is unnecessary
~~~

The permitted conclusion is target-scoped:

~~~text
neighbor implements
history -> event/state -> later action
therefore
that downstream explanatory job may be source-owned / locally absorbed
~~~

A stronger subtraction requires the rival to preserve the same target level.

## 4. Level-preserving comparison rule

For rival, novelty, no-gain, subtraction and submission-positioning work:

~~~text
primitive Selection / O0 burden
!= cross-level generative-organization burden
!= formed whole-field / Gate organization
!= retained historical efficacy / writeback
!= event / state / action implementation
~~~

A model that implements one lower/downstream job does not thereby absorb a
higher/upstream job.

Therefore any claim such as:

- "no SRT gain";
- "absorbed by the neighbor";
- "Selection is not needed";
- "ordinary implementation is sufficient";

must name the exact target being compared and establish target preservation at
that same level. Downstream equivalence must not be promoted into upstream
subtraction.

## 5. Current cognition-programme clarification

The 2026-09-10 author-confirmed correction remains controlling:

~~~text
passive-sedimentation reading
= retired as ontological centre

history-conditioned selectability
= retained as downstream consequence

active selectable-space construction
= author-confirmed centre
~~~

For the current pre-object generative-orientation programme:

~~~text
history / consequence writeback
= one bounded route or subtype of recursive reconstitution

recursive cross-level reconstitution
= broader burden

active construction / revision of selectable organization
= controlling centre
~~~

The broader question includes how local relations become stabilized into
higher-level organization, how formed higher-level organization constrains
later local actualisation / objectification, and how results at multiple levels
can recursively reconstruct the organization that conditions later
selectability.

## 6. Boundaries

This adjudication:

- does not reopen the primitive Selection anti-tautology STOP;
- does not establish primitive Selection's scientific indispensability;
- does not establish SRT novelty over mature neighboring theories;
- does not make every cross-level influence an SRT-specific effect;
- does not promote L0/L1/L2 into independent substances or mandatory temporal stages;
- does not modify canonical ontology owners;
- changes retrieval / comparison discipline and current-programme interpretation only.
