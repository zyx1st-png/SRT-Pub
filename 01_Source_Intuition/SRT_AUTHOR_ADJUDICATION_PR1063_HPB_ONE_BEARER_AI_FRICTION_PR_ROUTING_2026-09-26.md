# B-1 — One carries an experiential direction, but One is not experience

## Author decision

The author rejects both of the following simplifications:

~~~text

~~~

and:

~~~text

~~~

> **One is an experiential direction / orientation, not experience itself.**

The author's phrase "任何实体都有弱体验" must be preserved with its immediate qualification:

> **that weak relation should not itself be called "experience"; "experience" is a higher-order description.**

Therefore the current noncanonical interpretation is:

~~~text

BUT

One
!= phenomenal experience
!= consciousness
!= Experiencer automatically.
~~~

This is **not** authorization to write a canonical pan-consciousness thesis.
