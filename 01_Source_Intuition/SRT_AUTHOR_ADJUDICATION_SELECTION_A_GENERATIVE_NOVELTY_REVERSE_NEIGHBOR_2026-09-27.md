# Author adjudication — preserve A as ontological horizon; enter through generative novelty and reverse-neighbor reconstruction

## 1. Trigger

The author clarified the long-standing intuition:

> 「我最初（十多年前）的直觉是A，但是担心包含的太多，反而什么都解释不了。所以考虑是否是有一个过程。先关注新颖的生成性，再考虑本体的生成性。」

After analysis distinguishing ontology from research entry, the author replied:

> 「认同，继续。」

The author then supplied an additional reverse-pressure prompt from independent review:

> 「至今的审计问的都是“SRT 的哪些部分已被邻居覆盖”。如果你是对的，即 SRT 更深、邻居只是它的局部投影，那么反过来问应当成立：
> SRT 能否把每个邻居的立场推导为某个特例，并且用 Facing 纪律准确指出每个邻居的已知困难出在哪里？」

This record accepts the bounded research direction below. It does **not** establish that SRT is deeper than the named neighbors.

## 2. A is retained as ontological horizon, not used as an empirical classifier

Accepted research posture:

~~~text
A / Selection-totality
= retain as the deep ontological horizon / hypothesis;

A
!= an operational rule that must classify some real changes as non-Selection
   merely to make Selection narrower;

primitive Selection
!= generative novelty;
!= generative transformation;
!= emergence.
~~~

The concern that A may become too inclusive is treated as a **fruitfulness / explanatory-structure burden**, not as an automatic reason to reject A.

## 3. Research entry shifts to strong generative cases

Accepted:

~~~text
do not begin by trying to prove that every actual change is primitive Selection;

begin with comparatively strong, reconstructible cases in which:
- a difference becomes difference-making;
- later generative conditions change;
- intervention grammar changes;
- a new load-bearing distinction / dimension forms;
- operation produces structure that alters later operation.
~~~

Then apply subtraction / reduction:

~~~text
strong generative case
-> remove novelty-as-surprise
-> remove persistence
-> remove retained history
-> remove rule-rewrite
-> remove new-dimension burden
-> remove downstream formed organization where possible
-> ask what minimum actualising / non-flat burden remains.
~~~

This is an epistemic route toward the primitive question, not a new ontic ladder.

## 4. Reverse-neighbor pressure is accepted as a real test

Accepted question:

> If SRT is genuinely deeper than a mature neighboring framework, can SRT reconstruct that framework as a bounded special case / projection under explicit added assumptions, and can Facing discipline locate the neighbor's own pressure points without post-hoc redescription?

Hard guard:

~~~text
translation alone = insufficient;
vocabulary overlap = insufficient;
retrospective "SRT can describe it too" = insufficient;
known difficulty explained only after reading the criticism = weak evidence;
superiority / deeper-than verdict = NOT PRESUMED.
~~~

## 5. Required reverse-test escalation

The reverse test should distinguish at least:

~~~text
D0 REDESCRIPTION
= neighbor can be paraphrased in SRT vocabulary.

D1 TYPED EMBEDDING
= neighbor's core claims can be located across declared L0/L1/L2 facings
  without silent back-import.

D2 DERIVATIONAL RECONSTRUCTION
= SRT + a small explicit set of neighbor/domain assumptions
  reconstructs the neighbor's characteristic structure.

D3 DIAGNOSTIC SURPLUS
= the same reconstruction predicts / independently locates a recognized
  pressure point as a facing-mix, hidden cut, missing burden or overextension.

D4 PROSPECTIVE LEVERAGE
= the reconstruction yields a new discriminating consequence,
  intervention, exclusion condition or reconstruction path.
~~~

Only D2 or above may support the phrase “bounded special case / projection”.
Only D3 or above is meaningful evidence for the stronger “SRT may be deeper” hypothesis.
D4 remains the strongest target and is not presumed.

## 6. Failure result is informative

Accepted:

~~~text
if SRT cannot reconstruct a neighbor without ad hoc assumptions:
  DEEPER-THAN HYPOTHESIS WEAKENS;

if SRT reconstructs everything only by broad relabeling:
  UNIVERSAL-METALANGUAGE RISK;

if SRT can reconstruct but cannot localize any pressure point:
  NO DIAGNOSTIC SURPLUS;

if Facing diagnoses a problem that is not source-native / recognized:
  POST-HOC STRAWMAN / FAIL;

if the neighbor already states the same diagnosis:
  INHERIT / NO SRT INCREMENT.
~~~
