## 1. Horizontal / vertical is not a hierarchy distinction

AUTHOR-ACCEPTED direction:

~~~text
horizontal
!= lower level

vertical
!= upper level
!= downward causation by default
!= cross-scale relation by default
~~~

Horizontal inquiry starts after a sufficiently stable objectification has already been admitted. It studies relations among formed units, variables or states while treating their boundaries and admissible differences as sufficiently given for the declared question.

Vertical inquiry goes **under the object cut**. It asks how a difference becomes operative; how some differences acquire reach while others become background; how relations become sticky, recurrent or mutually supporting; how boundaries become effective; how a proxy or foreground becomes stable enough to count as a thing; and how formed organization reshapes later admissibility.

Working compression:

> **Horizontal research asks what happens between formed things; vertical research asks how “things” become possible and remain generatively coherent.**

This is a current source-level direction, not a canonical definition.

Term routing: "vertical inquiry" here is a **research direction**. It does not redefine the existing canonical senses of verticality: `Core_Law/SRT_One_Formation.md` Def-OF-1 (Selection-generated non-flat organization; event-level verticalization), and `Core_Law/SRT_Generative_Ontology_Spine.md` §3 (event-level verticality as a structural reading of every actualising Selection event). Other same-name uses are 2026-09-22 §C–§D (vertical structure as a later closed loop) and GRG v0.3 §4 (vertical research). `vertical` is therefore OVERLOADED_SAME_NAME and must be qualified on reuse.

## 2. Horizontal causality as an effective discretization of deeper generation

The author rejects an ontology in which reality is primitively a list of self-contained objects linked by arrows.

Current direction:

~~~text
underlying generative continuity
-> locally stabilized cuts / objects / relations
-> horizontal causal description among those stabilized cuts
~~~

Accordingly:

> **Horizontal causality is downstream of object formation.**

Typing note: "horizontal" names an **objectified description regime** (causal description among already stabilized cuts). It is not a second kind of world-side causation standing beside Selection. Under the canonical Spine, every actualising Selection event is itself readable as event-level verticality.

No unrepresentability claim is made. GRG v0.3 §4.3 remains in force: a sufficiently rich horizontal model may encode every variable used in a vertical analysis. Any payoff of vertical inquiry must be shown through a discriminator, an intervention or reconstruction, not through a claim that horizontal models cannot represent it.

This does not make horizontal science false. Stable objectifications can be extremely effective for prediction, intervention and explanation.

The stronger claim is only:

~~~text
successful A -> B description
!= proof that A and B are primitive furniture of reality
~~~

“Continuity” here is not yet mathematical continuity or a continuum-field claim. It means that explanatory dependence should not be forced to stop at an object boundary merely because a research representation has cut there.

## 4. Grammar analogy — organization is not another peer object

The author uses language as an explanatory analogy:

~~~text
words alone
!= sentence meaning

parts alone
!= organized whole
~~~

Mature linguistics already treats meaning composition as dependent on syntax / organization. The SRT-side intuition is therefore not “linguistics forgot structure”.

The intuition is:

> **The organization that makes a whole possible is not well represented as merely one more peer object added to the list of parts.**

Grammar is useful as an analogy because it licenses some relations, blocks others, groups differences into equivalences, preserves some distinctions, suppresses others, and produces an organized whole whose future transformations depend on the organization rather than only on isolated constituents.

“Grammar” is therefore a candidate analogy for **non-objectified generative organization**, not an identity claim about linguistic grammar.

## 6. Operator correction — gating is formed organization realizing / carrying a Selection-operator role, not post hoc sorting of formed objects

This is a central author correction.

Rejected picture:

~~~text
pregiven objects / particles / options
-> selector inspects them
-> selector chooses preferred items
-> selected objects move to another set
~~~

Preferred explanatory analogy:

~~~text
ongoing dynamics
-> a gate is opened / closed under a selective relation
-> differential passage / reachability results
-> repeated asymmetric flow accumulates
-> a stable nonequilibrium organization becomes manifest
~~~

The Maxwell-demon valve is the guiding analogy.

The decisive action is not carrying already selected molecules. It is opening / closing a passage so that different trajectories become differently reachable.

Therefore:

> **Selection is closer to the actual opening / closing of generative passage than to selecting an already-formed object from a menu.**

Level typing, second adjudication D-1 (author: 「组织，作为选择算子的actualize」):

~~~text
gating
= a formed organization in which an Ĝ-type Selection role is realized / carried

primitive Selection
!= gating of a pregiven flow / partition / criterion
~~~

The sentence above therefore describes Selection as realized **through a formed gating organization**. It does not describe primitive Selection. At the primitive level, the analogy's "ongoing dynamics", pre-existing passage and sorting criterion would reintroduce what `Core_Law/SRT_L0_Metaphysics.md` §S0 excludes: a pregiven A/B menu, weights, goal or chooser.

Physics note: in Maxwell's setup the gate operation is conditioned on measurement of individual molecules, and the thermodynamic cost lies in information acquisition and erasure (Szilard, Landauer, Bennett). A passive gate with no information coupling (the Smoluchowski trapdoor, the Feynman ratchet) produces no separation at equilibrium. Read accurately, the analogy fits a formed, measurement- or expectation-coupled organization, which is the D-1 level.

Hard guard:

~~~text
Maxwell demon analogy
!= proof of SRT
!= primitive ontology model
!= observing demon required for primitive Selection
!= information thermodynamics identical to SRT
~~~

The analogy is useful specifically for:

~~~text
gating
-> asymmetric reachability
-> repeated biased flow
-> maintained non-equilibrium organization
~~~
