# Author Re-entry — irreversibility / global causal residue PASS1

> **Role:** preserve the author's explicit choice on the IRR-A / IRR-B / IRR-C gate prepared after the post-Cycle-3 HOLD-blocker triage. This file records author content and bounded interpretation only. It does not itself rewrite P0-03, physics, ontological time, or any canonical owner.

## 1. Gate presented to the author

The three options were:

```text
IRR-A:
historical/path fact remains,
but exact complete-state restoration need not leave future causal difference.

IRR-B:
every genuine Selection leaves an unavoidable causally effective residue
somewhere in the complete present state / enlarged environment,
so exact complete-state restoration is impossible.

IRR-C:
even complete identical present states can have different futures
solely because their histories differ.
```

The author selected:

> **B**

## 2. Author-owned content fixed by this answer

The bounded author direction is therefore:

```text
genuine Selection
-> cannot become globally causally traceless

local / subsystem restoration may occur
!=
exact restoration of the complete causally relevant state

if a process appears fully reversed locally,
then the causal residue must remain somewhere in the enlarged present reality
(system / controller / ancilla / environment / record / changed constraint structure)

therefore:
reversal is a new Selection event
and exact global state restoration is not licensed.
```

The intended force is stronger than the minimal historical statement:

```text
"the event occurred and cannot be redescribed as never having occurred"
```

because PASS1 now also licenses a present-state consequence:

> **A genuine Selection must leave some causally effective present residue in the complete relevant state; otherwise the claimed complete restoration would erase the causal difference made by the Selection.**

## 3. Explicit boundary against IRR-C

This answer does **not** license:

```text
complete causally relevant present states can be exactly identical
+
history alone, outside the present state, still changes future dynamics.
```

Cycle 1 already rejected that stronger hidden-history requirement as an unnecessary non-Markovian metaphysical commitment when every causally effective historical residue is included in the complete current state.

Therefore the current author direction is:

```text
history matters through present causal residue / changed present reality
not through an extra history variable acting outside a genuinely complete causal state.
```

## 4. Relation to the earlier creative-Selection adjudication

This PASS1 is compatible with the Cycle-3 author direction:

```text
every genuinely actualising Selection
= local / continuous creative event
```

and sharpens one consequence of that direction:

```text
if Selection genuinely creates determinate actuality,
that creation cannot be globally erased without residue;
a later "reversal" is another creative/actualising event,
not the ontological inverse of the earlier one.
```

This is an author-level continuity claim, not yet a scientific discriminator.
