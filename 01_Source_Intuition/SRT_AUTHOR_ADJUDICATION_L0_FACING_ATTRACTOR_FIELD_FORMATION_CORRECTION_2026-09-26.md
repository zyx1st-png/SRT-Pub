## 3. Current source-level contributors must remain typed, not flattened

The current candidate contributors occupy different roles.

### Primitive Selection / generativity

Provides non-flat actualisation / generative nonclosure.

It is not a cognitive object, explicit predictor, chooser, or already formed gate.

It is needed to avoid explaining the mature field only by a previously completed field.

### Retained vertical organization / history

Prior actualisations can become materially effective in later generative conditions.

This gives the mature field path dependence without making history the primitive source of Selection.

### Bearer / continuing operative position

Where independently established, Bearer gives a continuation-relative locus for consequences to become non-interchangeable historical conditions.

Bearer therefore helps explain why some differences matter for this continuing organization rather than merely occurring in the environment.

Bearer is not primitive Selection and is not automatically consciousness.

### Structural Expectation

Expectation is operative shaping, not merely prediction.

It biases / gates generative passage and changes reachability.

It can therefore bend the whole field toward some continuations without requiring a fully explicit object or proposition.

### Gate geometry / normalization

Gate geometry is the formed coarse-graining / equivalence / boundary / neighborhood / reachability organization through which:
- many differences are flattened;
- some remain active;
- some become load-bearing;
- some transitions become easier, harder or unavailable;
- local objectifications become possible.

It is not identical to Ontological Friction.

### Glue / maintained generative coherence

The field must remain sufficiently coherent across changing local contents.

Current source-level decomposition includes:
- selective permeability;
- support;
- recurrent correction;
- reciprocal constraint;
- compression / equivalence;
- friction-bearing maintenance;
- reconstruction after perturbation.

This is not a fifth substance.

### Body-world / environment coupling

The field is not an internal self-contained cognitive space.

Current coupling changes which differences can matter, which affordances are live, and which continuation pressures are effective.

### Retained L2 organization

Explicit objects, concepts, rules and histories can recursively reshape later L0-facing organization.

This is a feedback contribution, not proof that the field is originally assembled out of explicit objects.

### Generative divinity / nonclosure provenance

The author’s "神性" remains provenance language for inexhaustible generativity / non-preclosure.

Its role here is not:
- supernatural agency;
- designer;
- goal;
- hidden force.

The live burden is whether no achieved objectification / grammar / retained organization exhausts later generativity.
