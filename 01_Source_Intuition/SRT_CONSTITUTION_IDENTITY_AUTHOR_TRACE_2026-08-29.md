# SRT Constitution identity — author source trace (2026-08-29)

> **性质**：本文件只记录本轮作者已经明确表达并反复收敛的研究身份与方法直觉，供后续 Constitution 梳理取材。它不是 canonical theory，不证明任何形而上命题，也不替代现有 Core/Core_Law owner。
>
> **用途**：未来会话在讨论本轮重构时，应先恢复这里的作者方向，再由 AI 发散、作者收敛；不得把本文件当成可自动扩写的新公理表。

## 1. 作者已明确的身份判断

1. SRT 的最高层应重新组织为 **Constitution / 宪法**：它不是公理集合，而是提供一种看世界、切分问题和暴露默认前提的视角。
2. Constitution 的中心是作者直觉的结构化自然语言表达；它**不承担证明任务**。证明、形式化、测量、实验与模型属于具体领域。
3. Constitution 不应尝试形式化。原因不仅是“避免过早承诺”，而是：形式化本身是一种跨 bearer、跨主体、跨时空的公共收敛操作——通过范畴化、粗粒化、归一化、等价化，把不同位置下的发生转换成可共享约束。
4. SRT 要保留的不是一个被第三人称模型表示的 `bearer variable`，而是 **bearer participation**：主体、读者、研究者、生命过程、社会单元等在相关现象中实际参与选择、承担历史与后果、改变未来可达性的事实。
5. 因而 SRT 不是站在外部“研究 bearer”；它要让读者/研究者进入一个 bearer-involved 的观察位置，重新问：什么被当作给定？这个“一”如何形成？谁承担它的历史？后果落回哪里？什么未来因此改变？
6. 传统科学的去位置化、可重复性与形式化并不是错误；它们是强大的公共知识生产方式。SRT 要研究的是：这种“脱产式”对象化如何形成，以及在把结果反过来当成本体起点时遗漏了什么。
7. 自然语言也会对象化；Constitution 选择自然语言不是因为它“纯粹”，而是为了维持**最低必要对象化**，允许 unit、grain、boundary、state space 等在作者尚未裁决前保持开放。
8. Constitution 的效力不来自“无位置的绝对证明”，而来自不同 bearer 能否从自己的位置重新执行这种视角转换，并在领域里获得稳定的解释生产力。

## 2. 外部领域的工作方式

传统领域通常已经给定一个研究对象/“一”。SRT 进入领域时，不先给另一套公式，而先问：

```text
0. WHO IS IN THE PHENOMENON?
谁在参与、承担、产生数据或改变后果？

1. GIVEN ONE
该领域把什么当作已经给定的 unit / object / subject / system？

2. DETACHMENT / OBJECTIFICATION
为了获得公共研究对象，哪些 bearer / position / history 差异被抽掉、归一或粗粒化？

3. SRT RE-ENTRY
把参与者、承担者、历史与位置重新放回后，研究对象怎样改变？

4. REORGANIZATION
哪些传统问题因此被重新组织、连接或消解？

5. NEW PROBLEMS
哪些过去因为去 bearer 化而没有成为问题的问题开始出现？

6. DOMAIN TEST
这些新问题能否由该领域自己的证据、实验、模型、数学与 rival comparison 进行检验？
```

SRT 的“统一”不由 Constitution 宣布完成；它应在多个领域独立执行这套重新提问后，如果反复长出同构结构，再作为结果显现。

## 4. Constitution 条目的预期形状

一条 substantive Constitution thesis 不应只是一个可背诵命题，而应成为 **perspective interface**：

```text
Perspective
从哪里看？

Default suspended
暂时停止把什么当作给定？

Reader-entry operation
读者实际执行什么视角动作？

What becomes visible
执行后什么结构/问题出现？

Boundary
这不意味着什么？
```

因此 Constitution 的传递目标不是要求读者接受一个 position-free result，而是邀请不同 bearer 重新执行一种位置化的视角操作。

## 5. 两个必须分开的主张

本轮对话明确要求不要把下面两件事混写成自动蕴含：

### A. Ontological situatedness

某些现实关系可能构成性地 bearer-indexed / position-indexed；`still this / from here / for me` 是不同的 unity burden。

### B. Participatory methodology

研究者、读者、主体或社会单元作为 bearer 参与知识生产和现象生成，某些研究不能在方法起点就把这种参与删除。

二者之间需要独立的 **epistemic-preservation bridge**：

> 如果某一类现象的 bearer-indexed relation 被提出为可能的构成结构，那么研究方法在判断其作用之前，不应预先系统删除这一结构；否则可能已经改变研究对象。

这不是“所有科学都必须参与式”的主张。

## 6. 反身性与认识论特权边界

- Constitution 自己也是从一个位置写出的；它不享有 God-view exemption。
- 它要求的是 cross-position re-enactability 与 domain-side productive adequacy，而不是作者位置的绝对权威。
- `position-indexed access != general epistemic privilege != infallibility`。
- SRT 不从“某个位置有特殊资料”自动推出“某个身份对全部理论解释拥有最终权威”。

## 7. 形式化的位置

Constitution：

```text
no equation as constitutional authority
no scalar threshold as constitutional authority
no predefined state-space ontology as constitutional floor
minimal objectification
natural-language structural description
```

Domain：

```text
formalization allowed
metrics allowed
models allowed
experiments allowed
statistics allowed
operational definitions allowed
```

但领域形式化应显式说明自己的对象化契约：unit、boundary、grain、equivalence、normalization、history loss、position loss、bearer substitution、consequence attribution、participation。
