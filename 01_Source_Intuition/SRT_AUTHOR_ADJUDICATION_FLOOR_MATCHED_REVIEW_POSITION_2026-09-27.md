# Author adjudication — SRT floor position requires floor-matched review

## 0. Direct author statement

> **“基本上认同，但是还是有种拿别的理论来审的感觉。SRT我认为是地板级别的。如果位置放错了，很可能未来会影响理论的发展。”**

## 1. Author-controlled interpretation

The author accepts the current FR-ADV narrowing in broad terms, but rejects a review posture in which downstream or already-objectified theories are allowed to function as global judges of SRT's floor-level programme.

Current author position:

~~~text
SRT programme position
= floor-level / floor-replacement programme;

therefore
comparison must be matched to the explanatory floor being tested.
~~~

This does **not** mean:

~~~text
SRT is immune to comparison;
SRT is automatically more fundamental;
other theories are merely downstream;
SRT floor status is already proved.
~~~

It means:

~~~text
a comparator may adjudicate only the burden it actually takes as explanandum.
~~~

## 2. Required level separation

Use the existing D1-D4 distinction:

~~~text
D1 LOCAL DYNAMICS
   observed mechanism / transition pattern;

D2 STATE-SPACE / REPRESENTATIONAL CAPTURE
   latent state, attractor, policy, hidden variable,
   topology, generative model, structure learner;

D3 PRE-OBJECT CONSTITUTION
   genesis of objectifiable state / option / boundary / comparison space
   without presupposing a completed object-style state-space as the floor;

D4 OBSERVATION RELATION
   whether observation itself is downstream of constitutive differentiation
   rather than a neutral window onto already-complete objects.
~~~

Author methodological guard:

~~~text
D1 / D2 success
-/-> D3 / D4 absorption.
~~~

## 3. Floor-matched comparison rule

Comparators should be typed before review.

### Class F-DOWNSTREAM

Examples may include theories that explain:
- valence;
- regulation;
- policy selection;
- salience;
- prediction error;
- latent-state dynamics;
- behavioral adaptation;
while taking their operative variables / state spaces as already sufficiently determinate.

Allowed role:

~~~text
pressure SRT's downstream mechanism / realization claims;
subtract local novelty;
supply implementation rivals.
~~~

Not allowed by default:

~~~text
declare SRT floor ontology absorbed.
~~~

### Class F-BRIDGE / FORMATION

Theories that partially address:
- field formation;
- affordance formation;
- individuation;
- structure learning;
- endogenous recutting;
- organism-environment co-constitution.

Allowed role:

~~~text
pressure the transition between formed dynamics and constitutive genesis;
test whether SRT's D3 burden is actually stronger or merely renamed.
~~~

### Class F-FLOOR-MATCHED

Theories / traditions that independently make constitutive differentiation,
manifest-interface genesis, individuation before formed objects,
or observation-after-cut part of their explanandum.

Examples already identified in the repository include:
- Barad on agential cut / determinate separability;
- Simondon on preindividual individuation;
- Whitehead on actuality / concrescence where relevant;
- phenomenological / process accounts that genuinely refuse the completed object-interface as final explanatory floor.

Allowed role:

~~~text
directly pressure SRT at D3 / D4.
~~~

No comparator earns floor-matched status merely by being broad, mature or successful.

## 4. Consequence for #1079

The author's acceptance of FR-ADV should therefore be read as:

~~~text
downstream phenomenon / mechanism overlap = broadly accepted;

but

floor-level absorption
must be adjudicated only by floor-matched comparison.
~~~

The phrase:

~~~text
SOURCE-ABSORBED
~~~

is too coarse when it fails to identify D1 / D2 / D3 / D4.

Future review language must use typed absorption.

## 5. Governance significance

The author explicitly warns that a category error here can distort later theory development.

Therefore:

~~~text
review-floor mismatch
= governance risk
~~~

because repeated downstream comparison can gradually force SRT to reformulate its own root questions in the vocabulary and ontology of its realizations.

Required protection:

~~~text
preserve SRT root explanandum first;
then compare source-native accounts at the same explanatory floor;
then use downstream theories to constrain realization, measurement and prediction.
~~~

## 6. Status

~~~text
floor-level programme position = AUTHOR-AFFIRMED
floor-level truth / superiority = NOT ESTABLISHED
floor-matched review rule = AUTHOR-AFFIRMED
D1/D2 -> D3/D4 promotion = FORBIDDEN
canonical edit = NO
~~~


## 7. Author refinement — comparison must be facing-matched, not merely theory-matched

The author clarified:

> **“我的想法是传统领域也包含了L0 L1 L2 facing的概念，但通常只包含后两个层级的，所以在与传统领域做对比分析最好不做跨层级的对比，否则会得出错误的结论”**

This refines the earlier floor-matched rule.

The governing unit of comparison is not the whole theory but the **specific construct / claim / explanatory burden**.

Current author position:

~~~text
traditional domains may contain constructs that can be read
at L0-facing, L1-facing and L2-facing levels;

however, much mature domain work is concentrated on
formed / manifest / retained organization,
therefore often L1-facing and L2-facing;

so comparison must first type the facing of each compared construct.
~~~

Mandatory rule:

~~~text
L0-facing SRT burden
must not be declared absorbed
by an L1-facing or L2-facing neighbor construct
merely because the downstream observable / formal structure matches.

L1-facing SRT burden
should be compared against L1-facing neighbors.

L2-facing SRT burden
should be compared against L2-facing neighbors.
~~~

Cross-facing comparison is allowed only when the explicit question is a bridge / derivation question, for example:

~~~text
can this L1-facing structure be derived from that L0-facing burden?

can this L2-facing sediment / scaffold
reconstruct the earlier L1-facing generation?

does a neighbor explicitly connect
its constitutive level to its formed / retained levels?
~~~

Cross-facing comparison is **not** valid evidence for:

~~~text
absorption;
novelty subtraction;
equivalence;
replacement;
superiority;
irreducibility;
~~~

unless the bridge itself is what is under test.

## 8. Facing-match matrix

Use this default discipline:

~~~text
SRT L0-facing <-> neighbor L0-facing / constitutive burden
SRT L1-facing <-> neighbor L1-facing / formed generative organization
SRT L2-facing <-> neighbor L2-facing / retained / sedimented / scaffolded organization
~~~

If no same-facing neighbor construct exists:

~~~text
status = NO SAME-FACING COMPARATOR FOUND / OPEN

NOT:
status = SRT SURVIVES BY DEFAULT.
~~~

If only a lower / downstream comparator exists:

~~~text
status = DOWNSTREAM REALIZATION OVERLAP

NOT:
status = FLOOR ABSORPTION.
~~~

## 9. Governance implication

The principal comparison risk is now more precisely:

~~~text
CROSS-FACING CATEGORY ERROR
=
using a valid explanation at one facing
to close a claim located at another facing.
~~~

This error can produce false negative conclusions such as:

~~~text
L1/L2 rival reproduces observable dynamics
-> therefore L0-facing SRT burden is redundant.
~~~

It can also produce false positive conclusions:

~~~text
neighbor lacks an explicit L0-facing vocabulary
-> therefore SRT is distinctive.
~~~

The correct result is instead:

~~~text
same-facing comparison required;
otherwise the relation remains a bridge / mapping question.
~~~

This refinement supersedes any earlier review shorthand that classified whole theories globally as simply "downstream" or "floor-matched".
