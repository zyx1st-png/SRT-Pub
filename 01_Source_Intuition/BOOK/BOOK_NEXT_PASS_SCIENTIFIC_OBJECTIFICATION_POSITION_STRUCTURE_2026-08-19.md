# 下一轮书稿统一优化方向：科学客观化、对象化与生成位置的退场

> **施工性质**：这是下一轮统一优化主轴，不是立即逐段改正文的授权。经本轮评审后，施工落点已重新依据当前正文校正：**Q00–Q03 + Q19/Q20 是主施工面；Q26/Q27 只承担回收与自检。**
>
> **治理说明**：本计划已按 `BOOK_CURRENT_STATUS.md §0.3` 重新打开并核对 Q19、Q20、Q26、Q27 当前正文。Q26 的职责是经验失败条件，不承载新的认识论病理线；Q27 已有完整“理论从脚手架变牢笼”结构，未来只做接缝，不另造平行框架。

## 1. 要补的不是“反科学”，而是科学成功背后的操作结构

当前 Q00 已经钢人化“水平因果”：从稳定对象、变量、指标和数据出发，科学获得了巨大的预测力与技术回报。Q01 也已经明确对象化不是错误。

这里先用**转述**而非逐字引文概括 Q01 §3：

```text
对象化本身不是问题；
危险在于对象化过于成功，以至于人忘记对象只是工作面，
并把这个工作面误认成世界的初始形态。
```

下一轮要把这条线推进一步：

> **科学客观化不是简单“消灭位置”，而是有纪律地管理位置：把观察者差异、测量程序、坐标和校准条件做成可公开、可交换、可重复的操作结构，从而使不同位置能够稳定对齐到同一个公共对象。**

因此：

```text
objectivity != no position

objectivity
~ disciplined position management
+ observer exchangeability
+ cross-procedure recoverability
+ world constraint
```

这里的 `~` 只是书稿施工压缩，不是 canonical 定义。

## 2. 下一轮的三条主线

### 2.1 客观化：位置没有消失，而是被治理到退入背景

科学实践不断压低与目标无关的位置差异：

- 不同观察者尽量可互换；
- 不同实验室尽量可复现；
- 私人经历不应决定结果；
- 单位、坐标、仪器与校准程序可公开；
- 对象在换操作、换角度、换测量方法后仍能被恢复。

最终效果是：生成这个公共对象所需的具体位置条件不再出声，只留下一个稳定、可交换、仿佛“自己就在那里”的工作对象。

这不是揭穿科学，而是解释科学客观性为何如此强。

### 2.2 对象化：不是单纯信息压缩，而是重新组织工作面

下一轮要明确区分：

```text
rich data -> compact representation
```

与：

```text
ongoing process
-> boundary cut
-> variable selection
-> scale / coordinate stabilization
-> measurement interface
-> public identity
-> repeatable object
```

后者不是“同一内容从高清压成低清”，而是在现实约束下重新组织什么可以成为对象、变量和可重复操作面。

因此书稿可以保持一个一般区分：

```text
原位发生
!= 对该发生的外部对象化
!= 关于对象化结果的语言描述
```

这条区分不专属于意识问题。

### 2.3 科学的强项与遮蔽来自同一种成功机制

科学为了可重复的公共结构，会有纪律地让许多内容退到背景：

- 谁在这个位置；
- 对象怎样被切出；
- 为什么选择这些变量；
- 坐标与测量办法从哪里来；
- 这个对象怎样获得公共身份；
- 它对不同 bearer / organism / practice 的具体意义差异。

这些退场换来：

- 跨主体对齐；
- 可交换性；
- 可重复性；
- 模型压缩；
- 因果识别；
- 技术预测。

所以不能把“位置退场”写成科学缺陷。真正需要诊断的是：

> **一个局部极其成功的工作格式，何时因为自身的成功而退入背景，使使用者忘记了它曾经做过切割、标准化与排除。**

这条动力学与 Q19/Q20 比 Q26 更贴合。

## 3. 三类“简化”必须分开

### A. 信息压缩

```text
rich information -> compact representation
```

保留主要差异、删去次要细节。

### B. 对象化重组

```text
process -> object / variable / measurable state
```

建立边界、身份、尺度和工作面。

### C. 位置退场

```text
situated access
-> standardized / exchangeable procedures
-> intersubjectively recoverable public object
```

不是删除位置，而是把位置条件治理到可以背景化。

下一轮真正缺的是 **B + C 的联动**，而不是继续把所有差异都称为“压缩”。

## 4. 主施工面

### Q00 序章：给“水平因果”补一拍客观化机制

现有 Q00 已经充分肯定水平因果的成功。下一轮只需补一拍：

> 它的力量不仅来自研究稳定对象，也来自把测量位置、操作程序和对象身份标准化，使不同人可以在共同工作面上继续推理。

序章不展开认识论史，不堆术语，只留下一个读者直觉：

```text
“客观”不是观察者真的消失，
而是位置差异被成功治理到不再妨碍公共恢复。
```

### Q01 给定性：让“公共可读身份”的位置条件显出来

Q01 已经有“独立实在 / 公共可读身份 / 给定感”三层和“对象化 / 范畴化 / 默认化”三步。

下一轮补的不是第四步，而是把第二层内部的科学实践讲清：一个对象成为公共可读对象，往往需要仪器、校准、操作定义、数学表示和跨实验室恢复。等这些都稳定以后，它们退到背景，只剩“对象在那里”。

这一补充不能削弱独立实在，而应强化：

```text
public readable identity != arbitrary construction
```

### Q02 对象化：核心施工面

Q02 应承担最完整的说明：

```text
objectification
= world-constrained stabilization
  of boundaries, variables, scales and operational surfaces
```

并统一吸收两条现有 hook：

**PH-METH02**：
- 切片不等于任意；
- 跨操作恢复是稳定约束；
- redescription change != target-system path change；
- constitutive measurement != measurement creates physical reality。

**PH-MEM01**：
- objectification 不只是此刻的一刀；
- 历史会改变下一次什么更容易被切出、放在一起或忽略。

本轮新增的接口是：

```text
public object identity
= world-constrained stabilization
+ historical inheritance
+ disciplined position management
```

仍是书稿施工式，不是 canonical 定义。

**PH-MEM01 landing ledger 继续保持 `pending`**：本计划只是正式排入下一轮 Pass 2；只有实际重写 Q02 时才把 hook 的 landing 状态推进，不能把“有计划”误写成“已落地”。

### Q03 前对象场：防止生成论重新偷渡成品对象库

如果理论在解释开始前已经给定：

```text
all objects
+ all variables
+ all boundaries
+ all coordinates
+ all admissible transformations
```

那么最困难的生成问题已经被偷偷做完。

Q03 下一轮应明确：前对象不是幕后藏着更细的一套成品对象，而是把“什么算对象、变量、测量、观察位置”本身也重新放回形成过程。

### Q19 脚手架与牢笼：处理“成功格式何时替代判断”

Q19 当前已经有完整的：

```text
支撑 -> 替代 -> 萎缩 -> 锁死
```

以及能力沉积、离开代价、后果回流三把刀。

下一轮不新增一套病理学，只把科学／理论工作面作为一个**高成功度脚手架案例**接入既有判据：

> 一个工作面只要仍帮助我们生成更好的独立判断，就是脚手架；当它开始替代“哪些差异值得重新打开、哪些边界需要重画”的判断，并且离开代价越来越高时，才进入 Q19 的替代问题。

科学实践本身不能被粗暴归入“牢笼”；这里诊断的是任何成功框架的使用关系。

### Q20 遮蔽：本轮“位置退场”最重要的后半书承重点

Q20 当前最关键的区分是：

```text
位置性有限 != 未建立型 != 锁定型遮蔽
```

这为本轮提供了必要护栏：**有位置、看不到全部，不是病。**

真正的连接点是 Q20 已有的“替代退到背景后，生成判断的尺子本身被改写”。下一轮可以把科学／理论对象化的风险写成同构但受限的情形：

```text
successful standardized work-surface
-> its generating conditions recede
-> local format becomes default
-> excluded dimensions become harder to formulate as questions
```

但只有在出现 Q20 所要求的独立结构证据时，才能称为遮蔽；不能因为一个框架抽象、标准化或忽略位置，就自动把它诊断成病理。

## 5. 次级回收位：Q26 / Q27

### Q26 可证伪性：只做失败条件自检，不承载新病理线

Q26 当前职责是用五类失败条件划定 SRT 的经验边界。下一轮不把“局部成功 -> 全局本体”写成新主体内容。

只需在完成 Q00–Q03 + Q19/Q20 后，用 Q26 回查：

- “位置治理”是否只是无法区分的哲学重述；
- “对象化重组 / 位置退场”是否有任何额外诊断或预测价值；
- 若没有，书稿是否应该收缩相关主张。

因此 Q26 是**失败条件审计位**，不是正文承重点。

### Q27 理论自反：只做接缝，不另造一套三步病理

Q27 已经有：

```text
命名帮助看见
-> 命名替代经验
-> 理论退回背景
```

并有万能钥匙化、批评吸收、正统性压力与自检三问。

下一轮只需要确认“科学客观化／对象化”这条线与 Q27 的既有自反结构接得上：

> 理论危险不在于它简化世界，而在于它忘了自己的适用条件、把局部工作面写成世界唯一格式。

这句话只能作为既有三步的一个应用／接缝，不能再新开 `local success -> forgetting conditions -> global ontology` 平行模型。

## 6. 与意识线的接口：只作压力案例

Jackson–Mary–Nagel 材料适合说明：

```text
complete public description
!= same event from the original bearer-position
```

但不得推出：

```text
therefore consciousness is nonphysical
```

或：

```text
therefore bearer / situated actualisation proves phenomenality
```

意识只是把“位置退场”的问题放大得最清楚，因为研究对象本身包含：

```text
for-this-system
from-this-position
with-this-history
```

phenomenal necessity 继续保持开放。

## 7. 下一轮验收标准

必须做到：

- Q00/Q01/Q02 完全保持“对象化和科学客观性是成就，不是错误”；
- 明确区分信息压缩、对象化重组、位置退场；
- 将客观性写成位置治理与跨程序恢复，不写成主观构造；
- Q03 不把前对象写成隐藏成品对象库；
- Q19 只用既有“脚手架／替代”判据吸收本轮材料，不另造病理；
- Q20 明确“位置性有限不是病”，并只在替代退场、判断通道被改写时讨论遮蔽；
- Q26 只做失败条件审计；
- Q27 只做与既有三步／三病理的接缝；
- consciousness 只作压力案例，不承担 HP-B 证明。

不得出现：

- “科学只是一种主观叙事”；
- “客观世界不存在”；
- “测量创造一切物理存在”；
- “因为观察有位置，所以真理是相对的”；
- “L2 = 科学 = 错误对象化”；
- “第一人称无法对象化，所以必然非物理”；
- “bearer / actualisation 已经解决意识硬问题”；
- “只要抽象或标准化，就构成 Q20 意义上的遮蔽”。
