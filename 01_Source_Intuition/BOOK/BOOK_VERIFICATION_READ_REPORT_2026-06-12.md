# 全书校验读报告（第一轮）

> 依据定梁页 v2.5 清单执行。本报告只记录证据与裁决，不改正文；报告中的"建议修复"均待作者批准后另行施工。动土许可规则：本报告未列出的违例，不得动土。

## 一、签署项（核查通过）

1. **中文引号平衡**：全库逐文件计数，左右引号零不平衡。建议固化为脚本，每轮校验读自动执行。
2. **烫手呼应**：Q05 §3（焊点预埋，一句带过）→ Q12 §1（完整展开）→ Q12 §7（回收）。三处递进、无重句，判定为有效预埋而非重复。
3. **"回来"纪律**：PR-5 修复后各主要部位（Q12、Q13、Q15、Q22、Q23、Q26、Q28、两座幕间桥、三处焊点）按修订范围（后果主语＋折返义豁免）核查通过。全书逐字扫尾留待文字编辑阶段。
4. **Q00 §5 体量**：放大镜纪律显式在场（"症状不是根源""放大镜不是地基"），无硬性违例。结案。
5. **Q23 去环化**：正文零残留；章末注八形式层 M(t) 矩阵与 Q12 对手语态"反馈回路"按裁定保留。

## 二、合章判断（本轮最重决定）：Q01/Q02 不合并，撤回此前怀疑

此前基于章节骨架怀疑 Q01/Q02 与 Q00 重叠过高、建议合并。本轮逐句读毕，**怀疑撤回**，证据如下：

- **Q01 拥有四件 Q00 没有的承重机器**：三层区分（独立实在／公共可读身份／给定感——Q09 中子案例的地基）；三步压缩（对象化→范畴化→默认化——Q27 §2 按章号引用）；科学实在论之墙（§4）；三重测试粗判准（时间／位置／代价——Q07 §2 原文"第一章曾留下一个粗判准……它在这里被接住并充实"）。
- **Q02 拥有四件独立机器**：切片之刀及"用刀找刀"的自反循环（§4——Q26 §1、Q27 §2 的地基）；跨学科有效性之墙（§5 网格坐标）；"因果链跑在切片之后"（Q05 §5 按章号引用）；对过程哲学的"为什么有些流动凝固"之问（驱动 Q07–Q09 的主问题）。
- 与 Q00 的重叠属**承诺—兑付关系**（序章预告、章节交付），非机器重复；两章且各自显式定位于序章之后（Q01 开篇"序章已经指出……"）。
- 合并的代价（全书章号引用重排＋一问一章节奏破坏）远大于收益。

**连带结案**：Q15 的"并入 Q14"选项同时死亡——PR-4 后 Q23 §4 按章号引用第十五章，Q15 拥有宽度定义且 §7 过桥装置经核验完整。全书章数维持现状，合章议题关闭。

## 三、违例与建议修复（待批准）

### V-R1（红）｜Q15 §7 疑似薄 ε 违例
原文："……为它保留了更多可成为性，**也为锚定和最低非中立性提供了更厚的地面**。"——ε 是最薄公设、生成的地板，不接受任何下游事物为它"提供地面"；此句方向颠倒，构成薄 ε 纪律违例（变相加厚）。
**建议修复**（词级）：删"和最低非中立性"，作"也为锚定提供了更厚的地面"；或改"也为生成的持续提供了更厚的保障"。

### Y-R1（黄）｜Q16 §6 归因松动
原文："第四章已经说明……最低非中立性意味着选择发生在主体出现之前。"——"选择先于主体"是第五章的工作，ε 只拒绝归零。建议改"第四、五章已经说明"或将归因移至选择结构。不紧急。

### Y-R2（黄）｜Q24 两处归因松动
"第四章的 ε 要求（真实摩擦）"——ε 不要求摩擦，摩擦是 Ψ_f／写入链的事。建议改为"从 L₀ 层选择写入中产生的真实摩擦（第四、五、八章的链条）"。不紧急。

### G-R1（治理）｜"末拍"条款需要解释性裁决
脚本核查显示 18 章的版面末位元素（章末注前）为装框的操作接口／微型示范／工具箱块；但抽查的全部章节中，**正文声部的最后一段均为转场或本体论断言**（接口块是边栏式附件，且 v6 优化轴显示此为既定排版惯例）。
**裁决建议**：防降格条款的"最后一拍"指正文声部的收束段；装框边栏（接口／示范／工具箱）不计拍点。建议在定梁页补一行解释，否则该条款按字面将误判 18 章。
