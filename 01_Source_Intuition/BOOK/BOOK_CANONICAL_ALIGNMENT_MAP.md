## 3. Editing rule

When a book chapter seems to improve the theory, do not promote the prose sentence directly into canonical definition.

Use this sequence:

```text
book sentence
→ minimal structural claim
→ claim level check
→ canonical/open-tension check
→ bridge/governance note or RFC
→ only then canonical edit if permitted
```

The book may reveal cleaner routes. It does not automatically become the authority for definitions.
