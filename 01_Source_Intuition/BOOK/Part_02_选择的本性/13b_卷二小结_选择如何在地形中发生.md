# 卷二小结：选择如何在地形中发生

这一节不是把卷二术语重新堆给读者，而是把卷二完成的移动压成一条可回看的路：选择从来不是菜单之后才开始，它从地形预先塑造可见性、摩擦、排除、不可逆、支付和健康门槛时就已经发生。下面的链条只承担卷三入口的路标功能，不提前要求读者掌握主体、价值或 d-value。

卷二不是把选择写成更复杂的心理活动。

它把选择从「主体面对选项」的时刻，推回到选项出现以前。

卷一说明选择如何沉积为地形。卷二说明地形如何进入下一次选择。过去选择留下的锚，不只是结果；它们会退到背景，成为摩擦分配、默认通道、接触窗口和预裁剪方式。后来所谓我可以选什么，已经在这些条件中被提前塑形。

因此，选择不是从选项出现之后才开始；选项之前已有地形、坡度、默认通道和预裁剪。选择算子把可成为性压成显现，也就是把某个方向打开为可尝试、可支付、可修复的未来入口。显现制造排除，排除留下阴影，阴影与显现共同使世界不可逆。不可逆带来摩擦，摩擦要求支付，支付形成路径，路径需要判据。只有当后果能够回到一个承重位置，主体与价值才成为下一卷的问题。

卷二与结构理论、路径依赖、具身行动和能动实在论相邻，但它不把选择理解为既有选项中的决策，也不只说结构影响行动。SRT 要追问的是：选项出现之前，地形如何已经预处理可见性、默认通道、排除、不可逆、支付和再选择成本。

这条链条的关键，不在于给「选择」增加新标签，而在于固定一个顺序。

地形先于选项出现。它不选择，却分配什么更容易被看见、被命名、被承担、被尝试。

选择算子不是主体，也不是算法。它命名的是一种成形结构：可成为性怎样穿过接触窗口、关切耦合、承载条件和候选竞争，成为前景。

前景不是单独升起。一个方向获得现实厚度，另一些方向就被压低、延后、提高摩擦或失去承接。阴影不是另一个完整现实，也不是心理残余的总和；它是未被打开者在后续地形中的效力分布。

当前景与阴影共同写回，撤回就不是逆操作。撤回不是 B 回到 A，而是在 B 之后生成一个携带路径痕迹的 A′。修复不是删除历史，而是在已经改变的地形上重新成形。

重新成形之所以不能免费，是因为现实有厚度。一个方向要进入现实、维持现实、切换现实或修复现实，都要穿过本体论摩擦。摩擦不是普通困难；摩擦是再成形必须承接的现实化阻抗。

支付若能被系统整合，就会写回地形，沉积为路径。路径不是静态轨道，而是支付、写回、沉积之后形成的低摩擦通道。可是路径能形成，不等于路径健康。某条路可以靠自耗延续，可以靠外包变顺，也可以靠锁死保持稳定。

所以卷二最后不能停在「路径形成」。它必须提出三判据：可延续、可协调、可再选择。三判据不是完整伦理学，也不是道德标签。它们只是路径作为选择结构继续健康运行的最低检查。

它说明了选择如何在地形中发生：地形预处理可见性，选择算子压出显现，显现制造阴影，前景与阴影共同造成不可逆，本体论摩擦要求支付，反复支付沉积为路径，路径再接受健康判据。

卷二到这里不能再只问「选择如何发生」。

它必须问：谁在承接选择的后果？谁能让阴影回流？谁还能重新打开未来？这些问题把选择结构推向主体与价值。

从卷一生成链来看，三判据还有另一层读法：它们检视的是「一」的扩张是否仍在健康运行。可延续，检查的是「一」的扩张是否靠自耗维持，即消耗承重位置本身来换取表面的延续；可协调，检查的是后果是否真正回到了扩张发生的那个位置，还是已经被外包到别处而使位置失去真实反馈；可再选择，检查的是扩张是否仍然保留了对未来成形的开放性，还是已经以沉积方式封闭了下一次落点的可能。三判据不只是路径健康的外部标准，而是「一」的扩张能否持续作为真实承重结构的最低自检方式。

这个读法只作卷二到卷三的桥接：它说明三判据为什么会把问题推向承重位置、后果回流与在乎；但它不提前替代卷三关于主体、价值与 d-value 的完整展开。
