# 第十四章 价值问题：价值如何被收束出来？

> 价值不是偏好，也不是对象的属性。它更晚、也更深：某个界面先被选择性收束出来，对一个具身位带上微弱的趋避，接上行动入口，再因为某条生成回路无法闭合而变成需要——直到具身位把继续生成的路径锚定在它上面。价值，是这条锚定沉积出来的结构重量。

---

## §1　甜的和苦的

你嗜甜。下午三点，注意力开始涣散，你走到便利店，拿了一块巧克力，撕开，咬下去。甜味扩散的那一瞬间，你得到了你想要的东西。偏好被满足了。

但三个小时后，血糖的波谷把你的精力拖了下来。你需要完成的事被推迟了，因为你的身体进入了一个比吃那块巧克力之前更差的状态。你的偏好被精准地满足了——你想要甜的，你得到了甜的——但你接下来能做什么、能承受什么，因此被削弱了。

反过来看。一周前，你强迫自己在雨里跑了五公里。每一步都不愉快——冷、湿、喘。你的偏好在跑步的全程都在大声抗议。但第二天早上醒来，你的身体以一种不同的方式响应了：更清醒，更有弹性，面对当天的事情时可动用的余裕更多了。那件你从未偏好的事，支撑了你对关切对象的生成能力。

这里不是说所有甜食都侵蚀、所有跑步都支撑。一个糖尿病患者、一个低血糖者、一个受伤的人、一个正在恢复的人，都会让同一个动作进入完全不同的后果结构。这个例子只为了点明一点：**偏好满足和结构后果可以分离。**

把尺度放大。一个人花了十年追求某个职位、某个数字、某所房子。偏好一直指向这些东西。然后他实现了。那一刻，他确实感到满足。但几个月之后，锚定的东西失去了参照，时间结构变空了，接下来怎么选没有方向了。偏好满足了，存在却更脆弱了。

也可以反过来：一段艰难的照护、训练或承诺，在过程里几乎不满足偏好，却可能重配一个人的承重方式、选择能力和关切范围。偏好从未被满足，但关切对象的生成能力反而被加强了。

**偏好满足了，但对关切对象的支撑被侵蚀了。偏好从未被满足，但对关切对象的支撑被加强了。**

这里有两种截然不同的回路。第一种是偏好回路：你想要什么，你得到了，认知登记闭合。第二种是生成回路：某个选择是否让具身位更能维持、扩展、承受它所关切的对象。偏好回路可以闭合，而生成回路正在被侵蚀；偏好回路从未闭合，生成回路却可能被支撑。这条区分会贯穿全章。

上一章建立了在乎：具身位的整个展开方式围绕某事重新组织。在乎不是一个人“决定去在乎”——上一章已表明，它是后果进入选择之后发生的结构性事件，不由意志启动。但在乎也不是纯粹的被动：如果具身位不展开这个在乎的过程，攸关的后果仍然在发生，具身位的承重会被改变，选择能力会受到不可逆的影响。正因如此，具身位不得不围绕攸关之事展开选择。在乎是被迫主动的——被攸关的后果逼迫而展开，不展开就承受结构性损失。

但在乎本身不回答一个更深的问题：**展开之后，具身位对关切对象的生成提供了什么？** 生活可以围绕甜食习惯重组，也可以围绕跑步习惯重组。它们对关切对象生成能力的后果截然相反。

这一章要追问的是价值的**深度**：你在乎的东西，是否在你的具身位上沉积出了不可替代的结构重量？（价值还有宽度——关切牵涉多少条独立赌注轴线，下一章建立；还有方向——支撑还是侵蚀，后续章节建立。这一章先只走深度。）

往下走之前先定位一句：**价值是晚期锚定，不是 L0→L1 直接收束出来的东西。** 选择性收束在 L1 留下的是界面和选择结构；价值要等界面在具身位上继续回流、沉积之后才出现（第二十五章：意识、主体、价值都是 L1 之上的晚期界面，不是 L1 的入口）。所以要正面回答深度，不能从“不可替代性”这个判据开始——那是价值断裂时才显露的结果。要看清价值如何被收束出来，得先回到它在生成过程中更早的样子：一件东西，是怎么一步步从中性的界面，变成有结构重量的。

## §2　从微效价到 affordance：价值不是一开始就在

一件东西开始有价值，并不是因为它本身带着某种静态属性，也不是因为一个已经完成的主体把偏好投射到它上面。更早的情况是：选择性收束先让某个界面从可成为性中显现出来（第五章）；这个界面一旦遇到具体具身位，就不再只是中性的“这个东西”，而开始带上**微效价**——可趋近、需避开、让人安定、令人警觉、能够恢复、可能伤害。微效价不是价值本身，而是价值发生的前信号：它标记的是某个已经显现的界面，对这个具身位不再中性。

但微效价还只是世界对具身位产生的最小倾斜。这个倾斜必须进一步接上行动入口：某物在某个位置上显现为可喝、可坐、可逃、可依靠、可修复、可继续。这个入口——**affordance**——不是对象自身的功能清单，而是具身位、环境、身体能力和代价结构共同收束出来的。一把椅子不是静态地“有可坐性”：对成年人、婴儿、腿伤者、逃跑中的人、疲惫的人，它显现出的入口并不相同。当一个显现界面不只被看见，而且被读作“可用来做什么”，它就从对象界面转成了行动入口。

把正面的链先一口气走完：**选择性收束让界面显现 → 界面对具身位带上微效价 → 微效价接上 affordance，成为可生成入口。** 到这里为止，还都只是“可以”，不是“需要”。价值要再往前一步才发生（下一节）。

这条链要立两道护栏，免得它和前面的概念混读。**微效价不是第四章的最低非中立性。** ε 是对象化之前、L0 拒绝归零的最薄倾向，不指向任何具体对象，也不属于任何具身位；微效价晚得多，出现在 L1 显现界面与一个具身位相遇的地方，是“这个已显现界面，对我如何”的最小读数。**affordance 不是第十一章的预裁剪。** 预裁剪是地形在选择发生之前对整个选项空间做的宏观处理——哪些可成为性能被看见、可达、低摩擦、可支付；affordance 更贴身，是某个已显现界面在这个具身位这里被读成“可用来做什么”的那一下。预裁剪决定哪些入口对你开着，affordance 是你站在入口前它向你显现的那个具体“可继续”。和第五章的“排开—定形—写入”一样：选项不是预先摆好的，affordance 也不是预先贴在对象上的，而是在具体位置中被生成出来。

## §3　缺失如何生成需求

“价值是缺失带来的需求”——这句话是对的，但很容易写软。写软了，它会滑回欲望理论：我缺什么，什么就有价值。那等于把价值重新交还给主观想要。

要写硬，得换两个词的定义。

**缺失不是对象不在场，而是某条生成回路无法按原方式闭合。** 水的价值不在水这个对象静态地“有价值”，而在脱水状态下，身体的生成回路无法继续稳定收敛——体温调节、注意力、判断力一个接一个开始失稳。水成为让这条回路重新闭合的条件。缺水的“缺”，不是少了一个对象，而是一条本来能闭合的回路现在闭合不了。

**需求不是主观想要，而是具身位为了让生成继续，需要某种条件重新进入地形。** 这就是为什么需求和欲望可以分叉：欲望可以指向一个换个场景就消解的缺失感；需求指向的是一条不重新闭合、生成就继续受损的回路。

把尺度放大，这一点更清楚。亲密关系的价值不是“我喜欢这个人”那么简单。大量时间结构、回应预期、身份连续性、对未来的想象，都锚定在这个关系上。关系断裂后，缺失显现为一整套预期无法收敛——不是少了一个人，而是一条条生成回路同时失去了它们闭合所依赖的条件。

这一节和 §1 直接接上。§1 区分了偏好回路（想要—得到—认知登记闭合）和生成回路（某个选择是否让具身位更能维持、扩展、承受它所关切的对象）。缺失与需求，正是生成回路这一侧的语言：缺失是生成回路的开口，需求是它要求被重新闭合。偏好回路可以全部闭合而生成回路正在开口——这正是价值要正面处理的地带。

## §4　价值是对继续生成的锚定

现在可以把这一章最正面的一句话立起来：**价值不是静态对象的属性，而是对继续生成的锚定。**

某物、某关系、某能力、某共同体之所以有价值，是因为具身位把“接下来如何继续”的路径锚定在它上面。当它持续让这条路径能够闭合、恢复、扩展或承重，它就被锚定为有价值；当它失去之后，路径无法按原样收敛，具身位就不得不重组自己。失去它，带走的不只是一个对象，而是一整套让生活能够闭合、继续和展开的收敛结构。

这里必须立一道护栏，否则这句话会被读成它不是的东西。“继续生成的收敛”不是预测加工，不是预测误差最小化。具身位带着的不是一个等待被印证的预测模型，而是一套“接下来还能怎么承重、怎么选、怎么关切”的生成结构。锚定不是“我预测它会在”，而是“我后续的生成已经搭在它上面了”。一个把价值编码为先验偏好、再记录先验被更新的框架，能登记锚定的存在，却很难追问：是什么让这套生成结构必须搭在这里，而不是随机搭在别处？（与主动推断 prior preferences 的近邻对照见章末注。）

由此，价值深度可以正面定义：

> **价值深度，是具身位把继续生成的路径锚定在某物、某关系、某能力或某路径上之后，形成的结构重量。**

这道锚定不是凭空的喜欢，它由三样东西共同构成：**后果回流**——攸关之事的后果真的回到这个位置（第十二章）；**不可逆赌注**——搭上去的路径一旦断裂，不能无损撤回；**关切结构**——这条路径牵着具身位所关切的对象。正是这三者一起，让锚定有了可被称量的结构重量：缺了后果回流，它退回纯粹的偏好；缺了不可逆赌注，它退回可随时替换的功能。

这个定义比“不可替代性”更靠前一步。不可替代性是失去之后才显露的判据——它告诉你锚定有多重，却不解释重量从哪来。“对继续生成的锚定”解释了来源：正因为继续生成的路径搭了上去，失去时才需要非平凡的重组。下一节就从这里转入不可替代性——把它放回它本来的位置：不是价值的定义，而是锚定断裂时显露出来的深度。

---

## §5　不可替代性：锚定断裂时显露的深度

价值深度在锚定里发生，但锚定本身不容易直接观察——你很难从外面看出一条生成路径搭在哪里。能观察的是它**断裂时**的反应。这就是不可替代性的位置：它不是价值的定义，而是锚定被切断时显露出来的深度判据。

一件事对你是否有结构重量，第一问不是你是否偏好它，而是：**如果失去它、阻断它或替换它，你的具身位是否需要非平凡的生成重组？**

这是一个门槛判断：要么失去后具身位支持关切对象选择性生成的结构需要重组，要么不需要。不是“重组有多深”的程度问题，而是“是否发生结构性影响”的存在问题。

不可替代性不是“我很喜欢”。你可以非常喜欢一件可替代的东西——今天这杯咖啡换成另一杯，心情有点变，但生活结构不需要重组。你也可以并不喜欢一件不可替代的东西——照护、训练、承诺、身体康复，过程里充满痛苦，但它一旦被拿走，整个选择地形都需要重组。

不可替代性也不是“价格很高”。一个昂贵的奢侈品可以很容易被另一个等价符号替代；一件廉价但承载了长期关系和承诺的物品，可能不可替代。

更重要的是，不可替代性不是“选项越多越好”。亲密关系、长期训练、语言能力、承诺、职业熟练度，都可能关闭很多选项，但它们并不因此降低价值深度。它们通过关闭某些任意漂移的路径，深化了在关切对象生成结构中的嵌入。一个学会语言的人，不是因为失去了胡乱发声的自由而变穷；他获得了表达和理解的地形。

为了避免不可替代性变成空洞口号，可以用两个测试把它操作化。

**替换测试。** 问：如果把这个对象换成功能上相似的对象，你是否几乎无须重组？如果是，那么你锚定的可能是功能，而不是这个对象本身——换一杯同样有咖啡因的茶、换一个同样能填补空白的人，功能被满足了，生成路径几乎不动。但如果换不了——照护十年的亲人不能用“另一个需要照护的人”替代，共同生活二十年的伴侣不能用“功能相似的伴侣”替代，承载你语言、记忆和身体习惯的地方不能用“生活条件类似的地方”替代——就进入了价值深度。不是因为它们功能特殊，而是因为继续生成的路径已经搭在它们身上。

**恢复测试。** 问：失去之后，是短期痛苦，还是长期结构重配？一次比赛失利、一次购物落空、一次旅行取消可以很痛，但恢复后你不需要重新组织你是谁、如何承重、如何选择。亲人去世、身体能力丧失、语言环境消失、共同体破裂则不同：它们让身份连续性、日常路径、承重方式和未来想象都需要重新组织。

两个测试的分工要说清。**替换测试是第一道筛：它问锚定在不在这个对象上。恢复测试是第二道筛：它问这种锚定有多深——断了要重铺多长的路。** 它们也有相对独立性：一个东西可能功能上可替换却仍牵动漫长恢复，也可能短期痛苦很强但恢复后结构并没有深改。它们不是精密量表，而是两道诊断：先把锚定对象从功能对象中分离出来，再把痛苦强度从结构深度中分离出来。

---

## §6　四种状态：欲望、成瘾、创伤、价值

前一章讲的是：因为后果攸关存在，具身位需要关切来影响选择。水、食物、空气对你有价值，不是因为你偏好它们，而是因为它们深度嵌入了具身位支持关切对象选择性生成的结构——而你自身的存在也是这些关切对象之一。价值深度的根源在这种结构嵌入中，不在偏好的行为观察中。

这个框架可以帮助拆开四种容易混淆的状态。

**欲望。** 欲望的张力可以很强，但张力的来源可能不是攸关对象。你渴望一个假期，得不到会烦躁；但这个张力来自缺失感，不一定来自对你的选择产生结构性影响的东西。换一个路径、换一个场景，缺失感消解了，生活结构不需要重组。欲望是偏好强度的高值，但它和选择的结构支撑之间的连接可能是松散的。

**成瘾。** 成瘾确实和选择产生了结构连接：失去物质或行为后，生活围绕它重组，系统剧烈反应。但成瘾的结构后果是**关切的生成质量下降**——越来越多的选择被一个窄通道劫持，具身位对关切对象的生成性影响被压缩到获取这一种物质或行为上。成瘾有结构深度，但这个深度的方向是锁死：选择空间被窄通道劫持，关切对象不再被更好地生成。

**创伤。** 创伤也有结构深度。它无法被“另一个类似事件”替换，发生之后不能平滑恢复；它会重配警觉、回避、信任和身体反应。但这种不可替代性来自损伤性写入。创伤完全满足不可替代性判据——它确实深度嵌入了具身位；但它**不满足承重性，也不构成成熟价值**，因为它的方向不是支撑生成，而是损伤性重组。用深度和方向两把尺一起说更准：创伤显示的是**负向的价值深度**——深度是真的，方向是负的（方向检验在后续章节完整建立）。正因如此，它需要被承认、修复和重新整合，而不应被简单尊奉为价值。

成瘾和创伤的通道区分只能是分析性的。现实中两者经常交织：成瘾也有仪式、社交场景和自我叙事；创伤也有应激反应、身体记忆和生理锁定。本章关心的不是给它们做临床分类，而是说明：深度嵌入本身不能直接等同于价值。

**价值。** 价值要求我们关注选择的生成机制本身，而不是偏好的表象。某事不可替代，是价值诊断的第一层判据；但不可替代性只说明深度嵌入了生成结构，不自动说明嵌入的方向——成瘾和创伤同样深度嵌入，它们与价值的区别在于方向，而方向检验是后续章节的任务。

这里必须把话说硬：**不可替代性不是完整价值判准，而是价值的第一层判据。** 它说明某物已经深度嵌入具身位的生成结构；至于这种嵌入是在承重、锁死、过载，还是成熟地支撑生成，还需要方向检验。这个不闭合不是漏洞，而是概念分层：先判断什么是深的，再判断深的方向。

这里还需要说清一点：**关切范围的质量不等于关切对象的数量。** 一个全身心投入一种艺术的创作者，关切对象很少，但他对那些对象提供了极深的生成性影响——艺术作为自我体现的本体，通过选择得到了生成。一个为原则牺牲的人，个体存在确实终止了，但他的选择不一定是对价值的否定；他可能是在关切范围内做了局部最优的生成选择，用自身的终止换取关切对象的最大化存在。价值的单位不是个体存在，而是关切对象的选择性生成。这个判断不自动正当化任何具体牺牲——具体牺牲是否正当，还需要后文的宽度、方向和共同体检验。收窄关切范围如果提升了生成质量，就不是病理；成瘾和创伤的问题不是“窄”，而是窄的方向不再服务于生成。

## §7　偏好：价值锚定的晚期登记

到这里可以正面回答偏好的位置了：**偏好不是价值的源头，而是价值锚定浮到认知层面之后的晚期登记。** 价值在生成过程中先发生——某条继续生成的路径锚定在某物上；然后，这个事实才被登记为“我想要它”。偏好忠实地记录了你想要什么，但“想要什么”本身，是更早那件事的晚期简化。

这正是最有影响力的一种价值理论搞反的地方。“价值就是偏好被满足”——经济学叫偏好满足功利主义，日常语言叫“我想要什么什么就对我有价值”，升级版是“理想化偏好”（在充分信息和冷静思考下会想要的）。它在操作上无与伦比：经济学用它量化价值，博弈论用它预测行为。问题不在建模，而在它**从一个已经完成对象化的主体出发**：先有完成的“我”，“我”拥有偏好，偏好投射到世界。但第十三章已表明，主体不是在乎的起点——在乎比主体更早。偏好理论从对象化完成之后才开始思考价值，正如旧图景从对象化完成之后才开始思考存在，是同一种顺序错置。

这种错置在三处暴露。**偏好的来源**：你嗜甜，可能只是糖稀缺环境把“喜欢甜”写进默认通道的预裁剪（第十一章），偏好理论拒绝追问来源，也就放弃了判断偏好本身是否“对”。**偏好满足后的空洞**：偏好可以全部闭合，而选择能力、承重弹性和关切范围仍在萎缩。**偏好作为错位关切的表达**：偏好能忠实记录围绕错误参照点形成的想要。三处指向同一件事：偏好和价值经常重叠，但这种重叠是统计性的，不是逻辑性的——在成瘾、承诺、牺牲、照护、创伤、长期目标这些节点上，两者会分叉，而价值论真正承压的正是这些分叉处。

最强的对手会反击：不可替代性不过是强偏好、长期偏好、二阶偏好的组合，完全可以写进偏好函数。这个反驳必须接住。关键在于：**偏好是本体论关切在心理和行为层面的投影，不是价值本身。** 投影有时与价值方向一致——强烈偏好长期伴侣，投影的是共同生活沉积出的时间结构、身体节奏、身份位置已成为承重所依赖的结构；有时反向——成瘾的强偏好指向锁死，甜食的明确偏好侵蚀承重，创伤后的回避偏好来自损伤性写入。偏好函数还有一个结构性盲区：**它无法表达主体追求的变化。** 一个人在长期照护中变了——不只是偏好排序变了，而是他追求什么、以什么为锚做选择、围绕什么展开，全都位移了。强偏好理论只能说“偏好函数更新了”，却无法追问是什么驱动了更新、为什么新偏好不是随机漂移而是围绕那段照护重新组织的。状态依赖偏好可以把主体状态写进参数，但写进去仍只是参数，不追问参数为什么变。偏好理论记录的是本体论变化的认知论投影：它能说“偏好从 A 变成 B”，不能说“主体的生成结构为什么需要 B 来维持”。

## §8　能力方法已经说过了吗？

还有一个更近的邻居：能力方法。Nussbaum、Sen 等人早就强调，价值不能只看偏好满足，要看人实际能否过一种有尊严、有能力的生活。这个反对比偏好理论更强，因为它已经突破了偏好框架，本章接受其中的压力：一个人实际能做什么、能成为什么，才是更深的价值问题。

但两者追问的层级不同。能力方法主要提供规范和政治哲学框架：哪些能力值得保障，什么样的社会安排更能让人过有尊严的生活。本章追问的是更前一层：为什么某些能力一旦受损，就会让具身位的生成结构发生非平凡重组？为什么失去语言、移动、信任、照护、共同体，不只是少了一个选项，而是改变了一个位置支持关切对象选择性生成的方式？能力方法提供价值政治的规范框架；本章追问价值深度的发生学/动力学起因。两者相邻，不等同——本章没有取代能力方法，反而能为它提供一个更底层的回答：那些能力之所以一旦被剥夺就让整个存在结构重组，是因为它们维持着具身位的关切范围和选择能力，它们的价值扎根在生成机制中。

---

## §9　失去的不只是偏好对象

如果对继续生成的锚定只是一个哲学词，它没有多少力量。但在多个独立领域中，同一种结构同时可见——这些只是显影，不是证明。

在**亲密关系**里，长期共同生活者不是一个可以被等价替换的功能对象。失去之后，改变的不只是情绪强度。共同生活沉积了时间结构、身体节奏、身份位置和未来想象——这些是具身位维持选择能力和关切范围的基础设施。它们被拿走后，关切范围收缩（很多事不再有意义了），选择能力萎缩（不知道下一步怎么选了），存在的连续性被打断。

在**语言**里，母语不是一个可以被第二语言完全替代的工具。第二语言可以打开新的通道，但它不完全替代母语承载的身体反应、童年记忆、亲密称呼、羞耻和安慰的路径。失去语言环境，不只是少了一套表达工具，而是世界的进入方式被改组了。

在**身体能力**里，失去行走、视力、听力，不只是少了一个功能。空间、时间、风险、他人关系和自我理解都需要重排——关切范围被迫重新配置，选择地形被重写。康复训练的意义不只是恢复功能，而是重建一个可以继续承重的关切范围和选择能力。

在**共同体**里，家园、制度、信任网络也具有不可替代性。一个社区被摧毁，损失的不只是建筑和人口，而是人们的关切范围突然失去了承载结构——相互承重的路径、共同记忆、可预期的秩序和未来想象——个体的选择能力因此被孤立地压缩。

这些领域的机制完全不同，但显影的是同一种结构：某物一旦失去，具身位支持关切对象选择性生成的结构被扰动，继续生成的路径必须重铺。不可替代性之所以不是偏好强度，是因为它指向的不是“你多想要”，而是“你的生成结构多依赖它”。

---

## §10　三步检验

**本章操作接口**——遇到任何价值主张时，不要只问“你有多喜欢”，也不要立刻问“这是不是道德上应该保护”。先做三步：

1. **在乎检验**（上一章）：你的生活是否真的围绕这件事重新展开了？
2. **不可替代性检验**（本章）：先做替换测试——换成同功能对象后，你的具身位是否需要重组？再做恢复测试——失去后是短期痛苦还是长期结构重配？
3. **方向检验**（预告，后续章节完整建立）：这种深嵌入是在维持或扩展你的关切范围和选择能力，还是在劫持、冻结或侵蚀它们？

有人说“这份工作对我很有价值”。先看在乎：你的生活确实围绕它重新展开了吗？再看不可替代性：如果被另一份条件相同的工作替代，你的身份结构、时间节奏和关系网络需不需要重组？如果可以平滑迁移，你锚定的是这类工作的功能，不是这份工作本身。如果不能，这份工作对你有深度结构重量——不管你是否“喜欢”它。最后问方向：这份工作的深嵌入是在扩大你的选择能力，还是在把你锁进单一身份？

需要强调：这三步检验是**诊断框架**，不是规范处方。它帮你看清偏好和本体论关切之间的关系，但不替你判断“你应该在乎什么”。不可替代性只是嵌入诊断的第一层——本章建立深度判据，方向和宽度的检验由后续章节完成。之所以必须先建立深度、把方向检验留到后续，是因为方向检验要用到宽度、后果回流和主体沉积概念，而这些概念本身又以深度为前提。这是概念分层的次序，不是论证缺口。

---

## §11　深度还不够

价值不是偏好。偏好是认知论层面的登记——一个已完成主体对已完成选项的排序；价值深度涉及生成层面——某事是否深度嵌入了具身位支持关切对象选择性生成的结构。偏好是对本体论关切的投影，不是直接表达；投影有时准确，有时错位，有时反向。两者可以分离。

把这一章的正面建设串起来：选择性收束让界面显现，界面对具身位带上微效价，微效价接上 affordance 成为可生成入口；当某条生成回路无法按原方式闭合，入口就从“可用”变成“需要”；具身位把继续生成的路径锚定在它上面，沉积出结构重量——这就是价值深度。不可替代性，是这道锚定断裂时显露出来的判据；替换测试和恢复测试把“偏好声称”和“结构依赖”拆开。

但深度必须和方向分开。成瘾、创伤和仇恨身份都可能高度不可替代，但它们劫持、冻结或损伤了选择，而不是支撑选择。不可替代性告诉你某物嵌入了选择结构，不告诉你它是在支撑还是在劫持生成。

普通读者只需记住：价值深度不是喜欢程度，而是失去或替换后，具身位支持关切对象选择性生成的结构是否需要重组。

不可替代性把价值从偏好中拆出来，给了它一个深度判据。但深度还不够。一个价值可以很深，却只牵涉很窄的范围。下一章要先从宽度进入：一个价值牵涉多少条不可通约的真实赌注轴线？要完整地区分承重、锁死、过载和成熟关切，还必须同时追问三件事：它嵌入得有多深，展开到多少真实后果，这些后果回来以后是在支撑这个位置，还是在侵蚀它。

这里先给四个词一个最小抓手。**承重**：深度嵌入并支撑生成。**锁死**：深度嵌入但压缩选择。**过载**：深度过高以至侵蚀位置。**成熟关切**：深度、宽度和方向相互支撑。下一章开始补上宽度，后面再追问方向和成熟。

>
> **一、与 Active Inference「prior preferences」的距离。** §7 攻击的“价值就是偏好被满足”，在当代形式神经科学里有一个更锋利的版本：Parr、Pezzulo 与 Friston 的《Active Inference》（MIT Press, 2022）。在这个框架里，一个系统的目标与价值被编码为生成模型的 **prior preferences**；行为的好坏由期望自由能度量，其中一项是预测结果与偏好状态一致的实用价值。换句话说，价值被形式化为与预置偏好先验的一致程度。这是“价值＝偏好”的强版本，本章与它的关系是近邻对照，不是反驳其工程有效性。本章 §4“对继续生成的锚定”尤其要与它划清：那里的“收敛”取生成论义，不是预测误差最小化——具身位锚定的是“继续生成的路径搭在哪里”，不是“等待被印证的预测”。
>
> 真实共振必须承认：Active Inference 没有把价值写成外部客观属性，而是把价值系在系统维持自身存在的条件上，这比普通偏好满足理论更接近本章。但分叉也必须挑明：prior preferences 把价值冻结成一组先验。它能登记先验被更新，却很难追问：是什么驱动了这次更新？为什么新的先验不是随机漂移，而是围绕某段被承受的后果重新组织？本章的价值深度不是 preferred-outcome 先验，而是时序上更早的结构事实：某物一旦失去或替换，具身位支持关切对象选择性生成的结构是否需要非平凡重组。偏好先验可以记录投影，不能替代结构诊断。（材料卡见 `Materials/2026/SRC_2026_06_11_Philosophy_ActiveInference_FEP_Book_MITPress.md`。）
>
> **二、稳态感受作为“对生命过程的自然评估”（与达马西奥的对照）。** 达马西奥（Antonio Damasio）《Feeling & Knowing》（Pantheon, 2021）从生物学一侧给出同一区分的独立显影：有机体内部化学活动可以作为 ongoing life process 的自然评估，感受在心智与表征之前已经读出损益。这与本章“微效价是 L1 界面上对具身位的最小损益读数”“价值深度不是偏好强度，而是结构损益的读数”方向相邻，也与第十三章把情感定位为后果回流的信号/动力通道相衔接。分叉在于：达马西奥把价值的终极参照主要绑在稳态/存活上；本章把价值深度锚定在关切对象的选择性生成上。稳态感受是价值方向轴在生物学中的显影，不是价值定义。

| 微效价 | L1 显现界面与具身位相遇时出现的最小趋避倾斜。价值的前信号，不是成熟价值；晚于 ε（最低非中立性）。 |
| affordance | 具身位在地形中读出的可生成入口（可喝/可坐/可逃/可继续）。不是对象的静态功能清单；晚于、贴身于第十一章的预裁剪。 |
| 缺失 | 某条生成回路无法按原方式闭合。不是对象不在场，也不是主观欲望。 |
| 需求 | 为了让生成继续，需要某种条件重新进入地形的结构要求。不是“我想要”。 |
| 价值（本章正面定义） | 对继续生成的锚定：把“接下来如何继续”的路径搭在某物/关系/能力/路径上。 |
| 价值深度（本章意义） | 锚定形成的结构重量。门槛判断：失去或替换后该结构是否需要非平凡的重组。是否真正支撑生成，仍需方向检验。 |
| 不可替代性 | 锚定断裂时显露出的深度判据。用替换测试和恢复测试判断。只说明嵌入了选择结构，不自动说明方向。 |
| 偏好 | 价值锚定浮到认知层面的晚期登记。对本体论关切的投影，不是直接表达。 |
| 关切范围 | 不是关切对象的数量，而是对关切对象是否提供了真实的生成性影响。收窄但提升生成质量不是病理。 |
| 方向（预告） | 这种深嵌入是在支撑选择的生成，还是在劫持、冻结或侵蚀选择。后续章节完整建立。 |
| 宽度 | 下一章处理：这种关切牵涉多少条不可通约的真实赌注轴线。 |
