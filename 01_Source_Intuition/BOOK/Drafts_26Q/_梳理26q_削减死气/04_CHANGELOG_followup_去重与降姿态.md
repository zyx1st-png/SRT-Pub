# 梳理 26Q · follow-up CHANGELOG —— 章末注去重 + 留桩标题降姿态

> 承接已合并的 PR #566。本 follow-up 做两件事，顺序按要求：先去重，再降姿态。
> 分支：`claude/26q-dedup-retitle-followup`（基于合并后的 main）。

## 第一步：章末注去重（Q06 / Q07 / Q09）

PR #566 把三处专家防御小节"下沉"为各章末的下沉注，但各章末注里**本就有压缩版镜像注**，造成同一注块内部分内容重叠（见 02 清单第 4 条）。本步消除该重叠。

**机制**：把下沉注的完整内容**按主题折叠回对应的压缩注**，再**删除下沉注**。压缩注（含其精确出处/术语）保留为引子在前，完整展开续于其后；**不重排任何注编号**，故全章 `注X / §N` 交叉引用保持有效。

| 章 | 折叠去向 | 删除 | 受益的既有交叉引用 |
|---|---|---|---|
| Q06 | 原下沉注九（§4 全文）→ 并入**注二**（在 Lewis/可能世界压缩注后续上完整展开） | 注九 | 桩内引用改指"章末注二" |
| Q07 | 原下沉注八按界切两半：因果段→**注一**，功能段→**注二** | 注八 | 注五"注四的退相干"不受影响 |
| Q09 | 原下沉注十切两半：因果历史段（含"可检验性开放问题"句）→**注一**，社会建构论段→**注二** | 注十 | 注九"注二已区分…"仍有效 |

**核对**：脚本逐段比对——原下沉正文段落（Q06:13 / Q07:9 / Q09:6 段）在新文件中**零丢失**；§ 标题数不变（6/6/7）；文中不再有任何下沉注。

## 第二步：正文留桩标题降姿态（"降维反击/降维打击" → "理论边界（专业旁路）"）

把三处正文留桩的 `§` 标题与桩内措辞从带攻击性的"降维反击/降维打击"改为更低姿态的"理论边界（专业旁路）"：

|---|---|---|
| Q06 §4 | 降维打击：为什么逻辑学和反事实推理远远不够？ | 理论边界（专业旁路）：与逻辑学、反事实推理的界限 |
| Q07 §4 | 降维反击：别把"因果"和"功能"当成锚定 | 理论边界（专业旁路）：与"因果"和"功能"的界限 |
| Q09 §5 | 降维反击：这不是"因果论"，也不是"权力论" | 理论边界（专业旁路）：与"因果论""权力论"的界限 |

- 桩内"**本节为面向专业读者的'降维反击'…**"同步改为"**本节是面向专业读者的理论边界（专业旁路）…**"，并把指向更新为合并后的"章末注一/二"。
