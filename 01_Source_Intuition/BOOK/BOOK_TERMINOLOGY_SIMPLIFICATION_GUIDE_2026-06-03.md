> 本文件用于当前 main 的全书总修。它继承 v3 的核心原则：**正文先让读者看见经验结构，术语只作为后来命名；普通读者读懂主线，专业读者仍能追踪理论结构。**

## 1. 总原则

本书当前最大风险已经不再是“读者完全进不去”，而是：

1. 后半部已经明显降噪，前半部部分机制章可能读感偏硬；
2. 连续章节可能形成“入口故事 → 旧地板 → 白话记忆句 → 最强反对者 → 边界 → 章末注”的新模板；
3. 技术术语虽已后置，但元文件、旧注释、旧术语表可能仍保留旧定义；
4. 继续逐章大改会导致理论被过度平滑。

因此，总修阶段的第一原则是：

> **只修阻碍阅读和概念一致性的地方，不把已经有力量的章节继续磨平。**

---

## 2. 术语进入正文的标准顺序

所有核心术语第一次出场，优先使用：

```text
经验状态 → 白话记忆句 → 后置命名 → 必要边界
```

禁止顺序：

```text
术语 → 定义 → 反误读 → 例子
```

正文应尽量让读者先说：“我懂这个状态。”然后才说：“本书把它叫作 X。”

---

## 3. 技术符号管理

以下符号不得作为普通正文推进主词：

```text
L0 / L1 / L2 / ε_pg / θ / Ψ_f / d-value / σ_sr / d_mobile / χ_payable / S_sig / S_str / P24-1 等预测编号
```

标准处理：

1. 正文先用白话说明；
2. 必要时写“专业表达中记作……”；
3. 紧跟一句“普通读者只需要记住……”；
4. 后文尽量使用中文回指；
5. 复杂形式层统一放入章末注或专业读者注。

## 4. d-value 统一治理

### 4.1 最终约定

**d-value 只用于 Q15 的“关切宽度 / 赌注化关切轴线展开”。**

它不用于 Q14 的“不可替代性深度 / 价值深度”。

一句话口令：

> **Q14 讲深度，不用 d-value；Q15 讲宽度，d-value 只在这里后置命名。**

### 4.2 Q14 用词

Q14 正文主词应使用：

- 不可替代性；
- 价值深度；
- 结构重量；
- 替换测试；
- 恢复测试。

禁止写法：

```text
本书把这种不可替代性的重量记作 d-value。
```

推荐写法：

```text
本章不再为这种深度增加新的技术符号。普通读者只需记住：价值深度不是喜欢程度，而是失去或替换后，未来选择空间需要被多深地重组。
```

### 4.3 Q15 用词

Q15 正文主词优先使用：

- 关切宽度；
- 赌注轴线；
- 脆弱性轴线；
- 真实后果能否回来；
- 关切轴线的展开。

推荐首次命名：

```text
专业表达中，本书把这种关切轴线的展开记作 d-value。注意：本书把 d-value 保留给关切宽度；上一章的不可替代性只称为价值深度，不再另设符号。普通读者只需要记住：这里不是在数对象，也不是在算喜欢程度，而是在问多少真实后果能够回来并改变这个位置。
```

### 4.4 后续章节规则

1. 讨论深度：用“不可替代性 / 价值深度 / 结构深度”。
2. 讨论宽度：用“关切宽度 / 赌注轴线展开 / d-value”。
3. 若旧稿、旧术语表、旧注释把 d-value 写成深度或不可替代性重量，按本规则修正。
4. 不新增新符号替代 Q14 的深度概念。

## 6. 章末注与工具箱规则

### 6.1 章末注

后半部 Q18–Q28 的章末注策略总体有效：正文保持白话，专业层放入可跳过区域。

总修时应统一命名为：

```text
章末注（专业读者，可跳过）
```

章末注内容可以包括：

- 形式层对应；
- 外部理论比较；
- 预测编号；
- canonical 源文件追踪；
- 跨领域显影；
- 被正文降级的专业防守。

章末注不应承担正文推进。

### 6.2 工具箱 / 操作接口

不机械统一。

| 章节类型 | 建议 |
|---|---|
| 奠基章 Q03–Q05 | 可使用工具箱。 |
| 机制章 Q06–Q11 | 优先使用“本章一句话”或短操作接口。 |
| 主体/价值章 Q12–Q17 | 少工具箱，多经验收束。 |
| 秩序/苦难/AI 章 Q18–Q25 | 可用操作接口，但不要每章同型。 |
| 理论自检/终章 Q26–Q28 | 可用专业读者注；正文不宜再加工具箱化总结。 |

## 7. 跨领域与实证材料规则

跨领域与实证材料不再被限制为“只能显影”。当材料直接贴住本章判据时，它可以承担三种更强功能：

1. **局部经验支持**：支持某一章的局部结构判断，例如某个机制确实在经验世界中反复出现。
2. **结构锚点**：让读者看见本章概念不是内部自洽词汇，而是能切入现实材料的判断工具。
3. **最小证明压力**：当材料满足本章给出的定义条件时，可以作为该局部命题的正面压力点；例如无意识过程若确实具备“排开、有形、留痕”，就可以支持“选择广于意识”的局部命题。

但这三种功能都不能升级为“整套 SRT 已被证明”。正文使用经验材料时，只服务一个判断，不展开案例史、学科综述或对手谱系。

禁止写法：

```text
物理学 / 生物学 / AI 已经证明了 SRT。
```

也避免写成：

```text
这个案例证明了本书整条理论链。
```

推荐写法：

```text
这个材料直接支持本章的一个局部判断：……
```

```text
它不是整套理论的证明，但它给本章判据施加了经验压力：如果判据成立，我们确实应该在这里看到这种结构。
```

正文进入经验材料时遵守四条纪律：

1. **只贴一个判据**：一个材料只服务本章一个核心判断，不顺手证明相邻章节。
2. **不展开综述**：正文只写必要事实；文献谱系、争议和细节放章末注或不写。
3. **不越级证明**：局部命题可以被支持，全书本体论不能靠单一案例证明。
4. **保留失败可能**：材料若有争议、反例或替代解释，正文应降低因果强度；必要时改为“显示一种结构风险 / 经验压力”，而不是“已经证明”。

尤其注意：Q04、Q05、Q20、Q21、Q24、Q25、Q26、Q28 最容易在“局部支持”和“整套证明”之间滑坡。Q25 的无意识选择结构材料可以强支持“选择广于意识”的局部命题，但不能直接证明 SRT 全书；Q20、Q21 的组织和创伤材料可以支持遮蔽、苦难的结构判据，但不能把复杂社会现象写成单因果。

## 8. 边界与反对者规则

边界不是可删内容。降噪不是去掉边界，而是改变呈现形式。

建议：

- 每章正文只保留最关键的 3–6 条边界；
- 其余边界移到章末注；
- 最强反对者必须贴住本章核心，不写成“这只是换语言”的套话；
- 有些章节可以不叫“最强反对者”，改为“最危险的误读”“必须接住的反问”等。

避免：

- 每章都用“这一章没有说什么”；
- 每章都用“最强反对者”；
- 每章都出现完整理论巡礼；
- 每章都以“不是 X，而是 Y”密集推进。
