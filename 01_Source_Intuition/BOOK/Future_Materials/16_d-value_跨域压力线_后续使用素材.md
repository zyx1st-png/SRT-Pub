# 第 16 章 d-value：跨域压力线后续使用素材

> 这些材料不是第十六章主文本的一部分。它们的用途是为后续更系统的跨域论证保留素材：哲学、物理学、生物学、神经科学、社会科学如何各自把“偏好 / 功能 / 信息处理 / 自我报告”推到边界，并迫使问题转向后果回流、不可逆赌注与承重位置。

---

## 0. 使用原则

这些材料在后续使用时必须遵守三条限制。

第一，它们不是 SRT 的地基。

SRT 的地基仍然是自身第一问题迁移：从“什么存在”转向“什么样的选择结构，使某些可能性能够显现、留下、承重并稳定为存在”。

第二，它们是压力点，不是证明清单。

外部传统和经验研究可以说明旧图景已经在多个领域遇到边界，但不能被写成“SRT 被这些学科证明”。

第三，所有具体事实要后续核验。

涉及人名、年份、实验结果、神经通路、概念归属、公式与文献页码时，后续专章必须回到原始文献或权威综述核验。当前文件只保存写作方向。

## 1. 哲学压力线

### 1.1 Frankfurt：caring 不是 wanting

候选展开：

Harry Frankfurt 在《The Importance of What We Care About》中区分 wanting 与 caring。

wanting 是一阶欲望：我想要 X。

caring 则要求一种认同结构：我不只是想要 X，而是把 X 的命运纳入了我之后会怎样的结构里。

如果 X 受损，我不只是少了一个满足项，而是我的位置被划伤。

可用来压旧图景：偏好强度不足以解释 caring，因为 caring 的核心不是欲望量，而是认同、脆弱性、历史承接与未来连续性。

SRT 可推进处：Frankfurt 从二阶意志和主体认同切入；SRT 可把问题移到更早的后果回流结构：不是先问主体是否认同某欲望，而是问后果是否已经回到承重位置并改写未来选择条件。

### 1.2 Heidegger：Sorge 不是情绪，而是时间结构

候选展开：

Heidegger 的 Sorge 可作为压力点，而不是本章地基。

Sorge 不是一种心理状态，而是 Dasein 的本体论时间结构：已经在、正在、先行于自身。

这可帮助说明 d-value 不能被写成“此刻偏好权重”。

d-value 牵涉过去写入的历史、当前正在承受的后果、以及未来连续性的压力。

可用句式：

SRT 与 Heidegger 相邻处在于：在乎不是情绪强度，而是一个位置被时间性地卷入自身未来的方式。差异在于，SRT 把这一路径落在后果回流与承重位置上，而不是从 Dasein 的存在分析出发。

### 1.3 Kierkegaard：高 d 与低移动能力的分裂

候选展开：

Kierkegaard 关于绝望的描述可用于后续“感到不等于能动”章节。

绝望不是没有重量，而可能是重量过高、移动能力过低。

一个位置知道自身被赌注押入，却无法重新组织自身。

这可以为后续 d_mobile 铺垫：d 是回流重量；d_mobile 是能否移动选择结构。

注意：不宜在第16章展开，容易提前进入第21章。

### 1.4 Nagel：功能描述无法推出“有什么感觉”

候选展开：

Nagel 的蝙蝠论证可作为结构类比。

对系统的信息处理、功能输出和行为描述可以非常细，但仍然不自动推出“是否有某种感觉”。

类比到 d-value：对系统的信息处理和输出行为的完整描述，也不能自动推出后果是否真正回到一个承重位置。

注意：若使用，必须避免把 d-value 直接等同 consciousness。应写作：这是类型差别的压力点，不是意识论证。

## 2. 物理学压力线

### 2.1 可逆 / 不可逆过程

候选展开：

可逆过程可以无损返回初态。

不可逆过程产生历史写入，返回需要外部代价。

d-value 的“后果回流”应更接近不可逆过程，而不是普通信息更新。

可用句式：

信息可以被覆盖；历史改变了势能地形本身。

注意：不可把热力学不可逆性直接证明为 d-value。它只是同构压力：历史可以进入结构，而不是停留在外部记录里。

### 2.2 迟滞 Hysteresis

候选展开：

迟滞说明系统状态取决于路径历史。

外部刺激撤去后，系统不自动回到原点。

这可用于解释高 d 关切为什么难以被“新信息”直接覆盖。

不是因为情绪惰性，而是因为历史已经写入结构，重新移动需要代价。

候选句：

一个位置被后果改写后，不会因为后果消失就自动退回原始状态。历史写入产生迟滞，重新移动需要主动代价。

### 2.3 d_max 双瓶颈

候选材料：

v9 中曾写：

$$d_{\max} = \min\left(\operatorname{rank}_{\text{eff}}(I_F),\; \frac{\Psi_f^{\text{budget}}}{\kappa_0}\right)$$

候选解释：

第一个瓶颈是信息维度：系统能区分多少独立风险方向。

第二个瓶颈是稳定性预算：系统维持自身运行的代谢、动力或摩擦预算上限。

后续用途：可用于 AI / 生物 / 制度比较，说明扩大处理能力只提高信息瓶颈，不自动提高赌注化 d。

注意：此公式若后续使用，必须回到 Core/SRT_Core_22_Equations.md 核验当前 canonical 状态。

## 3. 生物学压力线

### 3.1 自创生 Autopoiesis

候选展开：

Maturana 与 Varela 的自创生理论可作为生命结构压力点。

生命系统持续重新制造自身边界与组成。

对一个活的自创生系统而言，自身续存并不是外加目标；一旦不再维持，就停止作为该系统。

候选句：

有机体无法对自身续存保持 d=0，因为不再在乎自身续存并不是一个中性选择，而是该系统停止作为自身。

注意：这不等于所有生命都有意识，也不等于生命价值自动道德化。

### 3.2 Markov 毯

候选展开：

Markov 毯可作为“后果是否穿过边界进入内态”的操作类比。

发生在毯外但不改变内态的后果，对该系统而言可能接近 d=0。

穿过毯并改写内态的后果，才开始进入 d-value 的回流语义。

候选句：

d-value 度量的不是世界发生了什么，而是哪些后果穿过边界并改变系统之后还能怎样维持自身。

注意：不要把 Markov blanket 直接等同承重位置；只能作为形式或生物学压力点。

### 3.3 Damásio 与躯体标记

候选展开：

Damásio 的躯体标记假说可用于说明计算能力与实际决策承重的差别。

某些患者可以理性列举利弊，却无法完成实际生活决策。

关键缺失不是计算能力，而是身体对选项的承重标记。

候选句：

身体不是理性的噪音，而是后果回流的早期承重结构。

注意：后续需核验具体案例、脑区、结论强度。不得写成“没有躯体标记 = d≈0”的强断言，只能说“显影低赌注化 / 低承重接地”。

## 4. 神经科学压力线

### 4.1 LeDoux：防御反应先于自我报告

候选展开：

LeDoux 的恐惧研究可用于说明身体防御反应不依赖完整意识报告。

卡车逼近时，身体先行重排优先级，而不是先形成“我在乎”的自我报告。

候选句：

d-value 的激活可以先于自我报告；报告不是在乎的来源，而只是某些在乎进入语言后的形态。

注意：不要使用未经核验的毫秒数字。不要把防御反应直接写成意识。

### 4.2 Panksepp：CARE / PANIC-GRIEF 系统

候选展开：

Panksepp 的原始情感系统可作为跨个体关切的生物学压力点。

照护、分离、求助、回应等并非纯粹文化叙事，而有深层神经—生物基础。

候选句：

跨位置攸关不是道德哲学后加的修辞；在许多生命结构里，他者状态已经能回到自身调节系统。

注意：具体通路、脑区、跨物种结论需核验。

### 4.3 Eisenberger / Lieberman：社会痛与身体痛

候选展开：

社会排斥与身体疼痛之间的神经重叠可作为压力点。

它挑战“社会损失不是真损失”的旧图景。

候选句：

关系断裂不是“只是心理上不舒服”。某些社会后果可以使用与身体伤害部分重叠的承重通道。

注意：必须写“部分重叠”“提示”，避免“完全重叠”之类过强表述。

## 5. 社会科学压力线

### 5.1 Charles Taylor：强评价

候选展开：

Taylor 区分弱评价与强评价。

弱评价比较偏好强度。

强评价涉及“什么构成我是什么”的质性判断。

候选句：

偏好排序无法解释为什么某些事物不是“我更喜欢”，而是“没有它，我不再以同样方式成为我”。

SRT 推进处：Taylor 从自我理解和强评价出发；SRT 从后果回流与承重位置出发。

### 5.2 Sen：适应性偏好

候选展开：

Sen 的适应性偏好可作为强压力点。

长期剥夺会改变主体报告出的偏好；人可能不再要求那些长期得不到的东西。

这挑战“偏好满足 = 福利 / 价值”的旧图景。

候选句：

适应性偏好不是 d 增长，而可能是 d 被结构性压低后，位置学会了不再在乎曾经失去的东西。

SRT 推进处：不问我说我想要什么，而问后果真实回来改写了什么，以及这种改写是否压缩了之后还能怎样选择。

## 6. 后续章节或新书可用结构

若后续做一章或一本新书专门处理“各领域如何把 SRT 推到边界”，可考虑如下结构：

1. 哲学：从欲望、意义、时间性、自我报告的边界进入后果回流。
2. 物理：从不可逆性、迟滞、历史写入进入承重结构。
3. 生物：从自创生、边界维持、身体标记进入生命的最低赌注。
4. 神经科学：从防御反应、照护系统、社会痛进入非报告性的回流通道。
5. 社会科学：从强评价、适应性偏好、制度外包进入集体层承重。
6. AI：从高处理能力、低赌注化、无承重位置进入当前系统边界。
7. SRT 收束：这些领域不是证明 SRT，而是共同显示旧图景的同一个缺口。

核心句候选：

这些领域并没有共同说出 SRT。

它们共同逼近一个缺口：偏好、功能、信息处理和自我报告，都无法单独说明后果如何获得抵押。

SRT 从这个缺口处重新开始。
