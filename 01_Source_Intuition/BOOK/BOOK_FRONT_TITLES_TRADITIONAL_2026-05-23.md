# 《从存在到秩序》传统哲学式前台标题层

## 0. 定位

当前 26 问问题链适合作为后台施工骨架，但若原样作为出版目录，容易显得过于内部化或理论推演化。本文提供一层更接近传统哲学书写的前台标题：保持哲学庄重感，同时避免过度口语化与 SRT 内部术语先行。

原则：

```text
后台问题链：保证论证顺序、旧地板崩塌、生成机制推进。
前台标题层：保证出版目录的哲学感、可读性和传统问题对接。
正文写作：从读者场景进入，再逐步逼出后台问题与 SRT 概念。
```

本文件只改变“呈现层”，不改变 26 问的后台顺序。

## 3. 使用规则

### 3.1 出版目录优先使用前台标题

正式目录、书稿部标题、章节标题建议优先使用“传统哲学式标题”。后台问题可在章节卡、写作计划、章节内部提示中保留。

推荐格式：

```text
第九章 现实厚度问题：真实为何具有等级与重量？
```

不推荐正式目录直接写成：

```text
Q9 为什么现实会有厚度？
```

后者适合内部问题链，不适合作为最终出版目录。

### 3.2 正文开头仍从场景进入

传统哲学式标题不意味着正文可以直接进入概念定义。正文仍应遵循 Chapter Card 的读者入口规则：先给读者已经身处其中的具体情境，再让概念作为必要名字出现。

```text
标题：不可逆性问题：撤回为何不能取消历史？
开头：一封邮件被撤回，但读过的人仍然读过了……
随后：撤回不是时间倒转，而是在已经改变的地形上执行新的动作。
```

### 3.3 前台标题不得反向改变后台问题链

前台标题服务于出版呈现；后台仍以 `BOOK_PROBLEM_CHAIN_REWRITE_2026-05-21.md` 的 26 问顺序和逻辑推进为准。

若二者冲突：

```text
逻辑推进、问题顺序、章节使命 → 以 REWRITE 为准。
出版目录、章名、读者导览 → 可采用本文件标题层。
```

### 3.4 避免两种极端

```text
过度大众化：像公众号标题，削弱哲学庄重感。
过度内部化：像 SRT 概念清单，削弱读者进入能力。
```

本文件的目标是第三条路：传统哲学感 + 当代生成论问题意识。
