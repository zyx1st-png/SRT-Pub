# `_SRT_D_VALUE_CANONICAL.md §5b.1b` 建议替换稿

> 目的：软化原 §5b.1b 中“最优解是否位移”的单点判据，避免把真/假 d 扩张写成过窄的适应度函数判断；同时保留四种假 d 扩张分类，明确其中的不等式只是诊断性记号，不新增 d-value 定义。

---

## §5b.1b 真 d 扩张 vs 假 d 扩张（建议替换稿）

**真 d 扩张**：新的后果方向通过真实回流、不可逆赌注、关切对准与承重检验，进入算子的有效选择景观。纳入这些方向后，选择位置的可见路径、代价权重、修复条件、稳定吸引子或最优解发生结构性位移；选择者在相关反事实条件下，会做出不同于只考虑自身局部景观时的选择。

**假 d 扩张**：名义上的关切范围扩大，但对应方向没有真正进入有效选择景观。它可以改变表层行为、身份收益、组织指标或控制结构，却没有让被宣称纳入的他者秩序条件成为选择的有效约束。

以下不等式为**诊断性记号**，用于标记名义关切与真实赌注化回流之间的落差；它们不构成新的 d-value 定义，也不得替代 `Def-d-canonical`、`Def-d-stakes`、`d-vector` 或 `d-gate` 的既有层级。

四种典型形态：

- **占有式**（$d_{apparent} > d_{real}$）：将他者纳入为自身秩序的资源。他者看似进入关切范围，实际只服务于自身秩序扩张。
- **符号式**（$d_{declared} > d_{operative}$）：使用关切的语言，但不支付关切的代价；声明扩大，操作层仍未让后果回流。
- **表演式**（$d_{visible} > d_{structural}$）：在可见场合展示关切以获取社会收益；可见姿态扩大，结构性承重未跟进。
- **效率式**（$d_{nominal} > d_{effective}$）：以关切之名行控制之实，将他者的复杂秩序压缩为单一可管理指标。指标本身不是假扩张；当指标压缩、替代并遮蔽真实后果回流时，才构成效率式假扩张。

**判别标准**：纳入的新方向是否真实改变选择景观，而不是只改变声明、符号收益、可见姿态或代理指标。若新的他者秩序条件能够改变可见路径、代价权重、修复条件、稳定吸引子或最优解，则构成真扩张；若只改变表层行为、身份收益、管理指标或控制结构，则属于假扩张。

**Cross-ref**: `Core_Law/SRT_Selection_Argument.md §7c`（真关切与假关切的完整论证）。

## 对原 §5b.1b 的修改要点

1. 将“最优解位移”从唯一判据改为“选择景观结构性位移”的一个强信号。
2. 将“假扩张不改变适应度函数”改为“没有让他者秩序条件成为选择的有效约束”。
3. 保留占有式、符号式、表演式、效率式四类假扩张。
4. 明确 `$d_{apparent} > d_{real}$` 等符号为诊断性记号，不是新的 canonical 变量。
5. 增加效率式护栏：指标不是问题，指标替代回流才是问题。
