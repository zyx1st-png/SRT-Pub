# 读者辅助件：核心词速查 ＋ 采样阅读路径

> 这两页是给读者随手翻回用的。
> 第一部分帮你在隔了几章后想起一个词是什么意思；
> 第二部分帮你在时间有限时，先尝一口再决定要不要深读。
>
> 提醒：本书每一章都建立在前一章之上。下面的"采样路径"是**取舍**，不是替代——它让你低成本判断这本书是否对你的胃口，真正读懂仍建议按顺序读。

## 第一部分：核心词速查页

下表按词第一次正式出场的章排序。**定义一栏是白话回指，精确含义以该章正文为准。**

| 词 | 首次出场 | 一句话回指 |
|---|---|---|
| 给定感 | 序章 / 一 | 把"已经在那里"当成第一事实的那种感觉；它是效果，不是起点。 |
| 对象化（被切出） | 二 | 对象不是天然单元，而是从连续中被切出来的稳定形。 |
| 可成为性 | 三 | 对象化之前不是虚无，而是"还能成为很多样子"的开放前场。 |
| 最低非中立性（不完全平） | 四 | 起点既不是蓝图，也不是绝对均匀，而是带着一点点不平的坡度。 |
| 选择（排开·有形·留痕） | 五 | 选择不是从菜单里挑一个，而是排开其他可能、定出形态、留下痕迹。 |
| 阴影（被排除者） | 六 | 被排开的东西不会消失，它以阴影和摩擦继续受力。 |
| 锚定 | 七 | 一个显现获得位置、被反复遭遇，从此改变后续地形。 |
| 不可逆 | 八 | 撤回一个结果，不等于回到做选择之前；A′ 不等于 A。 |
| 现实厚度 | 九 | 一个显现被后来多少选择踩过的深度——重不重，不是真不真。 |
| 承重·支付·再入场 | 九 | 厚度的三个来源：被当作条件倚靠／维持它要付代价／成为默认背景。 |
| 秩序（背景化） | 十 | 厚度退入背景、不再被察觉之后，形成的"本来就该这样"的地面。 |
| 被选择（预裁剪） | 十一 | 在你开始选之前，地形已经替你裁过菜单。 |
| 攸关 | 十二 | 后果真的进入了你正在进行的选择，而不只是发生在你身上。 |
| 在乎 | 十三 | 不是情绪音量大，而是你的生活是否真的围绕某事重新展开。 |
| 价值深度（不可替代性） | 十四 | 失去或替换它，未来选择空间要被多深地重组——不是喜欢程度。 |
| 关切宽度（d-value） | 十五 | 你的赌注摊在几条轴线上——深度之外的另一个独立维度。 |
| 主体沉积（选择的化石） | 十六 | 主体不是起点，而是选择历史一层层压出来的位置。 |
| 意识 | 十七 | 选择的晚期凝结物——晚到，但不等于没用。 |
| 自由的地面 | 十八 | 秩序不是自由的反面，而是自由能够发生的地面。 |
| 脚手架与牢笼 | 十九 | 好脚手架最终让你能不靠它站住；坏脚手架留下依赖。 |
| 遮蔽 | 二十 | 不是挡住你的眼睛，而是改写你用来看的方式。 |
| 苦难 | 二十一 | 不是疼痛变大，而是痛苦失去了可修正的方向。 |
| 方向 / 三问 | 二十二 | 一条路健不健康，看三件事：是否自耗、是否外包、是否锁死。 |
| 共同体 | 二十三 | 不是个体相加，而是后果能不能在多个位置之间正确回流。 |
| AI / 地形改写 | 二十四 | AI 不一定在选择，但正在改变人类选择的地形。 |
| 选择广于意识 | 二十五 | 选择不需要先有意识；但不是所有发生都叫选择。 |
| 可证伪 / 死亡条件 | 二十六 | 一个理论必须说得出：什么情况会让它认错。 |
| 理论自反 | 二十七 | 理论最危险的时候，是它开始替你看世界。 |
| 回到生成 | 二十八 | 秩序最好的样子，是给下一次生成留下位置。 |

**三问（来自第二十二章，最实用的随身工具）**

遇到一条路、一个制度、一个工具，问三句：

1. **是否自耗？**——这条路在消耗我未来重新选择的能力吗？
2. **是否外包？**——承受后果的人，能不能把后果推回到做决定的地方？
3. **是否锁死？**——如果条件变了（系统失效、平台崩溃、制度改变），这个位置还重新站得住吗？

## 第二部分：采样阅读路径

> 用于时间有限、还在犹豫的读者。先尝一口，合胃口再回到第一章按顺序读。

### 三章尝鲜（约一次长阅读）

**序章 → 第五章 → 第二十二章**

- **序章**：看这本书到底想移动什么——为什么"稳定不是起点"。
- **第五章（选择不是挑选）**：全书最核心的一次概念翻转，整条生成链的发动机。
- **第二十二章（方向 / 三问）**：把前面的理论收成一个你当天就能用的工具（是否自耗·是否外包·是否锁死）。

读完这三章，你会知道这本书的"提问入口"是不是你想要的。它**不能**让你读懂中间的机制链——那需要顺序阅读。

### 八章主干（理解生成链的最短骨架）

**序章 → 五 → 九 → 十 → 十一 → 十三 → 二十二 → 二十八**

| 站 | 章 | 在主干上的位置 |
|---|---|---|
| 1 | 序章 | 为什么要把第一个问题往前移 |
| 2 | 五（选择不是挑选） | 留下运动的起点：选择如何排开、定形、留痕 |
| 3 | 九（现实厚度） | 留下运动的产物：现实为什么有厚薄轻重 |
| 4 | 十（秩序背景化） | 留下运动的收束：厚度退入背景，成了"本来就该这样"的地面 |
| 5 | 十一（被选择） | 转向回来运动：地形反过来开始选你 |
| 6 | 十三（在乎） | 回来运动落到你身上：后果如何长出"在乎" |
| 7 | 二十二（方向 / 三问） | 把整条链收成方向判据 |
| 8 | 二十八（回到生成） | 全书闭合：秩序如何给下一次生成留位置 |

这条骨架能让你看清"留下 → 回来 → 方向"这条主运动。跳过的章（六至八、十二、十四至二十一、二十三至二十七）补的是机制细节、边界、和苦难／共同体／AI／理论自限等展开——主干读顺了再回去补，会轻松很多。

### 完整顺序读

如果你决定认真读：按致读者的建议，**至少读完前十章再决定是否继续**。前十章（序章到第十章）走完"留下的运动"，是后面一切的承重地基；从第十一章起，书才转向"回来的运动"——你也在这个地形之中。
