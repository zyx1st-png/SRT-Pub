# DiSalle—SRT 对齐与插入地图

> 本文件服务《从存在到秩序》的未来统一优化轮。它不把 DiSalle 写成 SRT 的来源，也不在本轮触发逐篇材料式正文重写。当前书稿治理已经明确：未融合材料收口期间，外部材料先进入桥、卡片和插入地图，正文统一优化后置。

---

## 1. 总定位

DiSalle 对书稿最有价值的不是“相对论支持生成哲学”，而是给出一条非常成熟的中间路线：

```text
对象 / 物理量并非总是预先完成后再被理论描述
但
构成这些对象 / 物理量的规则也不是任意创造
```

它们在测量、操作、变换和理论原则中取得经验身份，同时不断承受世界的约束与失败压力。

书稿可以借此加固一句重要边界：

> **对象化不是被动复制，也不是任意切割；它是在现实约束中被反复稳定出来的可识别结构。**

这句话是未来书稿的 native synthesis，不是 DiSalle 原句。

## 3. Q02：最重要的插入

当前 Q02 已经有很强的主张：对象化不是把世界原样复制进头脑，而是把复杂连续过程切成可处理的对象格式。

它最需要补的不是更多“对象是构造”的材料，而是**反任意性**。

未来正文候选：

> 切片并不意味着任意。真正能留下来的对象边界，往往要经得住换角度、换操作、换测量办法之后的反复恢复。我们当然参与了切割，但世界也一直在回推：有些切法一换手段就散掉，有些关系却在不同操作中一再回来。对象化因此既不是把一件预先完成的东西原样搬进头脑，也不是想怎么切就怎么切；它更像是在约束里把某些差异稳定成可以反复找到的形。

未来注释功能：

- Helmholtz：空间经验与可逆、可组合的刚体变换相关；
- Poincare：某些原则既像定律又参与定义量；
- Einstein：同时性标准不是纯任意约定，而受电动力学结构制约；
- DiSalle：这些历史共同说明 constitutive framework 可以受经验约束和修正。

正文不需要讲完整思想史。

## 4. Q03：前对象场的防实体化用途

未来正文候选：

> 如果一种理论必须先把所有对象、变量和可允许变换都完整列好，才能开始谈生成，那么它其实已经把最困难的问题悄悄做完了。前对象并不是躲在幕后的另一套成品对象，而是提醒我们：连“什么算一个东西、什么算一次测量”这样的边界，也有自己的形成史。

DiSalle 在这里仅作为一个科学哲学平行案例：物理理论并非先获得一个无解释的数学对象，再任意指定它对应现实；理论原则本身参与建立可测量的经验身份。

禁止写：

```text
DiSalle proves pre-object field
spacetime physics discovers L0
mathematical objectification is impossible
```

## 5. Q05：构成性选择的有限用途

书稿可以使用一个白话层区分：

```text
挑选：从已经成形的菜单里取一项
构成：参与决定什么以后才算一个选项
实现：真正改变后续路径并留下后果
```

未来正文候选：

> 有一种更早的“选择”甚至不是从菜单里挑一项，而是参与决定什么以后才有资格成为菜单上的一项。可这仍然不等于凭空创造：能不能被稳定成一个选项，要看它是否经得住反复操作、后果和现实约束。这样的构成，比日常挑选更早，却也比任意命名更硬。

注意：这里的“构成”是书稿层面的解释桥，不修改 canonical selection 定义。

## 6. Q26 / Q27：理论失败与理论牢笼

这是除 Q02 外第二高价值接口。

DiSalle 的 Newton -> SR -> GR 历史提供一种很好的“理论失败”图景：

```text
旧框架成功
-> 向更广经验域外推
-> 新事实使旧框架的构成标准出现系统性张力
-> 重新分析基本概念
-> 新框架恢复旧框架的局部有效性
```

未来正文候选：

> 理论真正危险的时候，不是它曾经有效，而是它忘了自己为什么有效。一个局部框架一旦把自己的适用条件抹掉，就会把“在这里成立”悄悄改写成“世界本来如此”。真正的理论进步未必把旧理论扔掉；更常见的情形，是把它重新放回一个较大的视野里，说明它在哪些条件下仍然正确，又从哪里开始把局部地形误认成了整个世界。

这一段非常适合连接全书“地形 / 背景化 / 牢笼”的主线。

## 7. 可保留的五条方法桥

1. **构成性不等于任意。** 一个标准可以参与形成可测量对象，同时受世界约束。
2. **构成性不等于永恒。** 形成经验的框架也有修正史。
3. **表述变化不等于现实变化。** 换坐标、换语言、换切分不自动构成路径变化。
4. **局部成功不等于全局本体。** 这是 Q27 很强的防牢笼原则。
5. **好理论要解释旧理论为什么曾经有效。** 新框架不是靠宣布更深，而要能回收旧成功。

- “DiSalle 证明选择先于存在”。

## 10. 未来施工优先级

未来统一优化轮建议顺序：

1. **Q02**：吸收“切片不任意 / 跨操作稳定 / 世界回推”——最高价值；
2. **Q26/Q27**：吸收“构成框架的系统失效 / 局部有效误全球化”；
3. **Q03**：补“不要预先定义完对象空间”的防实体化边界；
4. **Q05**：少量吸收“菜单形成早于挑选”，避免术语膨胀；
5. **Q28**：只在收束需要时使用 framework-content 可变的思想，不单独展开。

最终目标不是让读者认识 DiSalle，而是让书稿的两个关键命题更硬：

> **对象并非预先完成，但对象化也并非任意。**
>
> **理论不是因为稳定而错，而是在忘记自身适用条件时变成牢笼。**
