# Jackson–Mary–Nagel：从表征到位置化实际化的 SRT 压力桥

> **用途**：记录 Frank Jackson 访谈、Mary 知识论证与 Nagel 视角问题对 SRT 的结构性启发与压力。本文是比较／桥接材料，不证明 SRT，不升级任何 consciousness、qualia、bearer 或 subjecthood 命题。

## 1. 核心结论

Jackson 后期路线最有价值的地方，不是简单否认 Mary 获得了新东西，而是把 `what-it-is-like` 尽量压入：

```text
world/body state
-> perceptual representation
-> recognitional access to that representation
-> what-it-is-like
```

这一路线很好地打击了把感受质想成“经验内部额外实例化的一团红色性质”的直觉，也提醒 SRT 区分：

```text
represented property
!= property instantiated by the representational vehicle
```

但它同时形成一个强竞争解释：如果 `representation + recognition` 已经足以穷尽体验事实，那么 SRT 的 bearer、stake、consequence return、history writeback 与 reselectability 必须证明自己有额外的区分力，而不能只宣称“结构更多”。

## 2. Mary 应拆成四个不同问题

Mary 思想实验最容易混淆的不是 physical / nonphysical，而是以下四层：

```text
I. Description
   对一个事件的结构知识

II. Access
   系统获得该状态的识别、比较、调用能力

III. Situated Actualisation
   事件第一次在这个 bearer-position 上实际发生，并进入其历史

IV. Phenomenality
   该实际事件是否／为何具有 felt presence
```

SRT 的安全立场是：

```text
description != situated actualisation
```

但当前不得推出：

```text
situated actualisation = phenomenality
```

因此 Mary-out 的变化不必被解释为发现一种新的非物理实体或事实类型。一个更稳的候选读法是：此前只作为对象化知识存在的 red-experience，第一次成为在 Mary 这个具体 bearer-position 上发生的事件，并由此产生新的历史写入、比较能力、识别 basin 与未来可选择结构。

这解释的是 `II -> III` 与 `III -> future structure`，不是 `III -> IV` 的 phenomenal-necessity 证明。

## 3. Jackson 的真正薄弱处：recognition 是否已等于 phenomenality

即使接受：

```text
R = red representation
M(R) = the system recognises that it is representing in R-like manner
```

仍可追问：

```text
why M(R) is phenomenally present
rather than a fully unconscious meta-representation?
```

如果继续增加更高阶 recognition，问题可能只是上移一层。因此 SRT 不应说 Jackson “已经解决 hard problem”，也不应仅以更多功能变量反驳 Jackson。当前最强的约束仍是：

```text
structural bearing != phenomenal bearing proved
```

以及 Z6 删除压力：给足 bearer、stake、consequence return、history writeback、Stable-ISP-compatible continuity 与 reselectability 后，若仍显式删除 phenomenality，SRT 当前尚未证明会产生内部矛盾。

## 4. Nagel 比 Mary 更直接击中 bearer-position

Mary 主要是“相近算子缺少某次实际化”；Nagel 的蝙蝠问题更强，因为 human 与 bat 不只缺一次相同刺激，而是整个具身选择条件不同：

```text
theta_human != theta_bat
```

差异可能包括：

- 感觉通道与分辨率；
- 身体尺度与运动方式；
- 感觉—动作闭环；
- 时间组织；
- 生态位中的机会与威胁；
- 历史写回；
- concern / stake 结构；
- 哪些差异会进入未来选择。

因此，完整的 human-side bat science 仍首先是：

```text
bat process
-> human observation / measurement
-> human objectification
-> human L2 model
```

它不能未经论证直接等同于：

```text
bat-side situated actualisation
```

这里的关键不是“主观信息神秘不可传递”，而是：外部描述本身是另一个位置上的再次选择、划界、标准化与对象化。

## 5. Nagelian point of view 不得直接等同于 SRT bearer

Nagel 的 `point of view` 首先是现象学／认识论位置；SRT bearer 还承担更重的结构条件：

```text
boundary
+ consequence return
+ history writeback
+ continuity
+ stake
+ future-selectability change
```

因此安全关系是：

```text
bearer structure
-> candidate structural basis for a situated point of view

but

bearer != phenomenal point of view by definition
```

否则只是把“有一个视角”改名为“有一个 bearer”，并没有解释 phenomenality。

## 6. SRT 相对 Jackson 的真正竞争点

不能把竞争写成：

```text
Jackson = representation
SRT = representation + more variables
```

成熟功能主义完全可以把 body、history、stake、self-model、action-space 与 future accessibility 全部吸收进更复杂的 functional / representational role。

SRT 若要形成实质增量，必须提出可区分问题，例如：

```text
matched sensory / representational content
+ different bearer history / concern structure
-> does phenomenal geometry shift?
```

```text
matched reportable representation
+ severed / altered consequence-return structure
-> does ownership / for-me attribution shift?
```

```text
matched sensory representation
+ different RDef_B profiles
-> does experienced dissimilarity Delta_ij shift out of sample?
```

成功也只会加强 HP-A / HP-C 邻接桥与 qualia-geometry 预测，不自动关闭 HP-B。

## 7. 一个更干净的 SRT 位置

SRT 在 Jackson–Mary–Nagel 这组问题上的最佳当前位置不是传统反物理主义，也不是宣布功能主义已经闭合，而是同时拒绝两次未经论证的跳跃：

```text
objective description cannot replace situated actualisation
-/-> therefore a second nonphysical ontology exists
```

以及：

```text
complete structural / functional description
-/-> phenomenal presence has therefore been explained
```

可压缩为：

> **第一人称首先不是一种神秘的信息类型，而是一种与具体 bearer-position、历史与后果闭环不可随意剥离的现实发生方式；但这种 situated actualisation 为什么具有 phenomenal presence，仍应作为独立问题保留。**

## 8. 对 Mary 的 SRT 候选改写

第一次经验前：

```text
Mary possesses extremely rich L2 knowledge of red-experience
but lacks her own red-event historical anchor
```

第一次经验发生：

```text
Omega_Mary(t-)
-> q_red borne / incorporated at Mary-position
-> Omega_Mary(t+)
```

之后出现：

- recognitional basin；
- 与其他 qualia 的新比较关系；
- memory / retrieval weighting；
- attention 与 action accessibility 的变化；
- 对未来 red-like events 的可再选择性。

这给 Jackson 的 `recognitional capacity` 一个 SRT 候选解释：识别能力可以部分来自第一次 bearer-indexed actualisation 对未来可选择结构的改写。

仍需保持：

```text
recognitional capacity != proof of phenomenality
reselectability != consciousness proof
actualisation != phenomenality by definition
```
