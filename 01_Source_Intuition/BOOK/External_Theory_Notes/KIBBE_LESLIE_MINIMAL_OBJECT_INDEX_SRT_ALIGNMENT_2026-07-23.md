# Kibbe–Leslie 最小对象索引与 SRT 对齐、插入地图

> 本文件处理一个单一问题：Kibbe 与 Leslie 的“裸索引”模型如何为书稿中的对象化和个体区隔增加认知层承重，同时不把对象表征实验越权写成本体论、主体性或意识证据。

## 1. 总定位

该文最适合承担的不是“证明选择先于存在”，而是一个更窄、更硬的认知架构命题：

> **心智可以先维持“这一个存在”，随后才绑定“它是什么”以及“它具有哪些性质”。**

它为书稿补出的关键分层是：

```text
individuation
!= identification
!= subjectivity
```

- `individuation`：把“这一个”与其他候选区隔并持续追踪；
- `identification`：绑定类别、表面特征与可预测性质；
- `subjectivity`：后果回流到同一具身位，被承重、组织并调用为自身历史。

前三者不能压成一件事。

## 2. 论文的最小结构

### 2.1 裸索引

对象索引是一个可以不携带任何描述内容的心理指针，类似“那个”。它能够在对象被遮挡后继续维持其存在与时空连续性。

### 2.2 可选性质绑定

颜色、形状、类别和物理预期可以随后绑定到索引；这些信息在注意资源不足时可能丢失，而裸索引仍被保留。

### 2.3 关键经验分离

六个月婴儿可能不检测第一件被遮挡对象的形状替换，却会检测该对象完全消失。这一结果建立：

```text
object-existence expectation
can survive
loss of identifying features
```

### 2.4 丰富对象概念是组装结构

文章不否认婴儿具有坚固性、凝聚性等物理知识，但认为这些内容不必成为每一个对象表征的原子性组成。裸索引可以作为丰富对象概念形成的起始核。

## 3. 与书稿概念的精确对齐

| 论文概念 | 书稿邻位 | 可吸收内容 | 不可越权内容 |
|---|---|---|---|
| bare index | Q02 对象化 | 一个可操作、可追踪的“这一个”可以先于丰富内容 | 不证明对象由认知创造 |
| object existence without identity | Q02 / Q05 | 个体化先于识别；菜单与身份不是免费起点 | 不证明物理存在依赖婴儿表征 |
| optional property binding | Q02 范畴化邻位 | 类别与性质可在已切出的个体位置上逐步绑定 | 不等于所有性质都是主观标签 |
| spatiotemporal sticking | Q07 锚定的远邻 | 提供最小连续追踪界面 | 短期追踪不自动构成承重或现实厚度 |
| loss of index | 认知可调用性 | 对象从当前心智工作面消失 | 不等于对象从世界消失 |
| index capacity limit | 认知资源边界 | 对象化工作面受注意与工作记忆限制 | 不构成世界对象数量或本体结构 |

## 4. 对当前“个体性区隔”问题的直接贡献

### 4.1 外部对象区隔：索引闭合

裸索引形成一个追踪位置：

> 这一个，而不是另一个。

它并不要求知道这个对象是什么，也不要求它对系统产生内部攸关。

### 4.2 内部个体区隔：承重闭合

书稿的具身位与主体性要求另一种闭合：

> 后果回到这个位置，被该位置承受、整合，并写入其下一轮选择。

因此可登记两个不同的个体边界：

- **追踪边界**：索引可以持续指向谁；
- **承重边界**：后果由谁承担并写回谁的历史。

### 4.3 三句压缩

本轮形成的最紧凑表达：

> **选择性收束产生“这一个”。**
>
> **对象索引维持“还是这一个”。**
>
> **承重闭合产生“属于这一个”。**

这三句不是同一来源的三条经验结论：第一句属于 SRT 生成哲学，第二句获得本文认知架构支持，第三句属于 SRT 对具身位和主体沉积的扩展。必须显式保留层级。

## 5. 插入路由

### 5.1 Q02《对象化》——主要候选

**推荐形态：章末注或正文一段低体量经验显影。**

候选段：

> 婴儿可以忘记一个被遮住的东西是什么形状，却仍然期待那里有一个东西。心智最先保住的，可能不是一份性质清单，而只是一个持续的“那个”——一个尚未被充分描述、却已经与其他东西区隔开并能够继续追踪的位置。只有随后，颜色、形状、类别和物理预期才逐步绑定到这个位置上。这并不说明对象由心智创造；它说明在认知结构里，“这一个”可以先于“它是什么”。

推荐位置：对象化作为“稳定工作面”的定义之后，范畴化展开之前或章末 object-file 邻位。

施工纪律：

- 不单开“婴儿认知研究”小节；
- 不展开全部遮挡实验；
- 不使用“科学证明 SRT”；
- 不将 `index` 译成 SRT 新 primitive。

### 5.2 Q05《选择不是挑选》——一句回指

候选句：

> 连一个对象的“是什么”，都未必是最早给出的；心智可以先保住“有这一个”，随后才把身份和性质绑定上去。所谓菜单里的现成选项，本身已经是一段对象化历史的晚期结果。

功能：加固“挑选不是选择起点”，但不把索引部署写成全尺度选择的同义词。

### 5.3 Q12《攸关》——负边界

候选章末注句：

> 能持续追踪一个对象，只说明系统保住了“那一个”；只有后果回流并重配这个位置自身的选择和锚定时，才进入“对这个位置攸关”的层级。

功能：防止把对象连续性、注意或工作记忆误写成 stakes。

### 5.4 Q16《主体沉积》——负边界与递进

候选句：

> 裸索引能够维持“还是同一个对象”，却不能产生“这是发生在我身上的”。后者还要求后果反复回到同一个具身位，留下痕迹，围绕关切组织，并被该位置调用为自己的历史。

功能：把 object continuity 与 first-person continuity 分开。

## 6. 防误解边界

1. **认识论／认知架构不等于本体论。** 论文说明对象如何被表征，不说明对象如何在观察者之外存在。
2. **裸索引不等于无结构。** 即使不含描述性属性，索引仍有部署、黏附、重分配和容量等操作结构。
3. **个体化不等于身份。** “有一个”不保证知道“它是什么”。
4. **个体化不等于主体性。** 能追踪对象的系统不因此成为被追踪对象的主体，也不因此自身有意识。
5. **连续追踪不等于锚定厚度。** 工作记忆中的短期维持不能直接替代 Q07 留痕—承重—再入场。
6. **消失于心智不等于消失于世界。** index loss 只能表述为当前认知表征不再维持。
7. **不要从婴儿数据推出结构先于物质。** 该数据最多建立认知内容的分层顺序。

## 7. 对书稿现有术语的修正压力

### 7.1 “对象化”需要区分切出与描述

当前对象化定义强调从过程中截取稳定工作面。本文要求进一步守住：

```text
cutting out a trackable one
can precede
describing what it is
```

因此对象化不应被写成“先识别完整属性，再划定对象”。

### 7.2 “选择性收束”不应吞并所有索引过程

索引部署可能只是认知系统对已经显现对象的追踪操作。除非能够建立排开、定形与改变后续地形的写入门槛，不得把任何注意指向或 FINST 部署都称为完整选择性收束。

### 7.3 “具身位”需要保留后果归属门槛

对象索引是强负对照：一个系统可以大量索引、追踪和绑定性质，却没有任何后果回流到自身承重位置。具身位不能退化为复杂表征节点。

## 8. SRT 对该文的反向分层

论文主要给出：

```text
index
-> optional binding
-> richer object concept
```

SRT 可以把它放进更长但必须标明为理论扩展的链条：

```text
selective convergence
-> minimal individuation interface
-> identity / property binding
-> consequence return
-> bearing closure
-> historical invocation
-> subject sedimentation
```

该长链的价值在于避免两个相反错误：

- 用丰富对象属性解释最小对象性，导致起点过厚；
- 用裸索引解释主体内部性，导致终点过薄。

## 10. 最终定位

> Kibbe–Leslie 的最小对象索引模型不是 SRT 的本体论证据，而是对象化链条上的一个高价值认知显影：对象的最薄心智形式可以只是“那个”，不必先是一份完整属性清单。它帮助 SRT 更精确地区分“这一个”“还是这一个”与“属于这一个”，并阻止对象追踪被误升格为主体内部性。
