# d-value 术语治理补丁

本文件是 `BOOK_TERMINOLOGY_SIMPLIFICATION_GUIDE_2026-06-02.md` 的临时覆盖说明，用于修复 Q14/Q15 之间的 d-value 定义冲突。

## 1. 最终约定

**d-value 只用于 Q15 的“关切宽度 / 赌注化关切轴线展开”。**

它不再用于 Q14 的“不可替代性深度 / 价值深度”。

---

## 2. Q14 的处理

Q14《价值不是偏好》只处理价值的第一层深度问题。

正文主词应使用：

- 不可替代性；
- 价值深度；
- 结构重量；
- 替换测试；
- 恢复测试。

Q14 不再为“不可替代性深度”增加技术符号。

推荐表述：

```text
本章不再为这种深度增加新的技术符号。普通读者只需记住：价值深度不是喜欢程度，而是失去或替换后，未来选择空间需要被多深地重组。
```

禁止表述：

```text
本书把这种不可替代性的重量记作 d-value。
```

---

## 3. Q15 的处理

Q15《关切维度》承载 d-value。

正文主词优先使用：

- 关切宽度；
- 赌注轴线；
- 脆弱性轴线；
- 真实后果能否回来；
- 关切轴线的展开。

技术记号：

```text
d-value = 关切宽度 / 赌注化关切轴线展开
```

推荐首次命名：

```text
专业表达中，本书把这种关切轴线的展开记作 d-value。注意：本书把 d-value 保留给关切宽度；上一章的不可替代性只称为价值深度，不再另设符号。普通读者只需要记住：这里不是在数对象，也不是在算喜欢程度，而是在问多少真实后果能够回来并改变这个位置。
```

---

## 4. 对术语指南 v3 的覆盖

若 `BOOK_TERMINOLOGY_SIMPLIFICATION_GUIDE_2026-06-02.md` 中仍出现：

```text
d-value → 关切深度 / 不可替代性重量
```

应按本补丁覆盖为：

```text
d-value → 关切宽度 / 赌注化关切轴线展开
```

若该指南中仍写：

```text
Q14 主记忆点应是“价值不是偏好”，d-value 后置。
```

应按本补丁理解为：

```text
Q14 主记忆点应是“价值不是偏好 / 不可替代性深度”；Q14 不使用 d-value。d-value 后置并归入 Q15。
```

---

## 5. 后续改稿规则

1. 所有后续章节遇到 d-value 时，默认按 Q15 的关切宽度解释。
2. 若要讨论“深度”，使用“不可替代性”“价值深度”“结构深度”，不要使用 d-value。
3. 若要讨论“宽度”，使用“关切宽度”“赌注轴线展开”，必要时后置 d-value。
4. 若发现旧稿、旧术语表、旧注释中把 d-value 写成深度或不可替代性重量，应按本补丁修正。
5. 不新增新的符号替代 Q14 的深度概念。

---

## 6. 一句话口令

> Q14 讲“深度”，不用 d-value；Q15 讲“宽度”，d-value 只在这里后置命名。
