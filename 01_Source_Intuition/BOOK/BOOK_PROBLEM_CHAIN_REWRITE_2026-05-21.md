# 《从存在到秩序》问题链重写草案

> 用途：本文件不从旧 52 章映射出发，而从“旧地板如何一步步崩塌”出发，重建书稿的认知推进顺序。它是出版主链的候选骨架，不是 canonical 定义。

## 0. 总原则

本书不应先问：

```text
SRT 有哪些概念？
```

而应先问：

```text
读者站在哪些默认地板上，才会把世界误读成静态、碎片化、离散化、对象化、无价值、无方向的东西？
这些地板如何被逐一拆除？
新的生成地板如何被逐步搭建？
```

因此，章节顺序应服从“旧地板崩塌顺序”，而不是 SRT 内部概念顺序。

每章只完成一个核心动作：

```text
让一个默认认知失效
→ 显现一个更深的问题
→ 逼出一个必要生成机制
→ 推向下一处旧地板
```

## 1. 全书四幕结构候选

```text
第一幕：存在地板的崩塌
第二幕：生成机制的显影
第三幕：价值与主体的回流
第四幕：秩序、方向与理论自反
```

四幕不是旧卷的压缩版，而是认知迁移的四个阶段。

## 第一幕：存在地板的崩塌

目标：拆除“现实已经在那里，变化只是对象状态改变”的默认世界观。

### 第 1 问：为什么现实看起来像已经在那里？

旧地板：

```text
现实是先给定的对象集合。
```

读者误认：

```text
我们以为自己只是面对一个已经完成的世界，然后在其中观察、命名、选择和行动。
```

要显现的生成机制：

```text
给定感不是世界的原始属性，而是生成过程退到背景之后留下的稳定效果。
```

可使用的跨学科材料：

- 物理学中的观测、尺度、状态描述问题；
- 现象学对对象显现的分析；
- 神经科学中的感知建构与预测加工材料；
- 复杂系统中宏观稳定态如何遮蔽生成过程。

必要 SRT 概念：

- 给定感；
- 稳定标注；
- 现实厚度的入口。

必须避免的过度宣称：

- 不说世界是主观制造的；
- 不说科学对象不真实；
- 不把生成写成社会建构主义。

最终推进到的下一问题：

```text
如果现实的给定感是生成后的效果，那么对象之前是什么？
```

---

### 第 2 问：为什么变化总被我们切成静止对象？

旧地板：

```text
变化 = 对象在时间中的状态改变。
```

读者误认：

```text
我们以为先有对象，再有变化；变化只是对象属性的更新。
```

要显现的生成机制：

```text
对象是变化被切片、稳定、可重复遭遇后的结果；不是变化的原初承载者。
```

可使用的跨学科材料：

- 芝诺飞矢与静态切片问题；
- 过程哲学；
- 物理学中的状态空间与轨迹描述；
- 生物学中的发育过程与形态生成。

必要 SRT 概念：

- 静态切片；
- 对象化；
- 存在作为稳定标注。

必须避免的过度宣称：

- 不否定对象描述的有效性；
- 不把过程哲学直接等同 SRT；
- 不把变化浪漫化为流动神秘主义。

最终推进到的下一问题：

```text
如果对象不是第一事实，对象之前不能只是虚无，那么它是什么？
```

---

### 第 3 问：如果对象不是第一事实，对象之前是什么？

旧地板：

```text
对象之前要么是无，要么是隐藏对象仓库。
```

读者误认：

```text
只要还没有对象，就只能说什么都没有；或者把对象之前想成尚未发现的对象库存。
```

要显现的生成机制：

```text
对象之前不是虚无，也不是仓库，而是对象化之前的可成为性位置。
```

可使用的跨学科材料：

- 德勒兹虚拟性、Simondon 前个体材料作为相邻压力；
- 发育生物学中的潜势与分化，但只作显影；
- 复杂系统中状态空间未定形区域。

必要 SRT 概念：

- L0；
- 前对象；
- 可成为性。

必须避免的过度宣称：

- 不把 L0 写成物理实体；
- 不把 L0 写成可能性大全；
- 不把 L0 写成主体想象空间；
- 不把 L0 写成神秘本源。

最终推进到的下一问题：

```text
如果 L0 不是虚无，它是否完全中立？
```

---

### 第 4 问：生成为什么不是从虚无开始？

旧地板：

```text
生成要么来自无中生有，要么来自已经给定的蓝图。
```

读者误认：

```text
如果没有对象，就没有任何方向；如果有方向，就说明方向已经预先存在。
```

要显现的生成机制：

```text
生成需要最低非中立性：它拒绝全归零，但不预设目标。
```

可使用的跨学科材料：

- 物理学中的对称性破缺作为显影，不作证明；
- 非平衡系统中稳定结构出现的压力；
- 生物学中非任意存续条件；
- 复杂系统中吸引子、约束与路径形成。

必要 SRT 概念：

- ε_pg；
- 最低非中立性；
- 非归零；
- 反目的论边界。

必须避免的过度宣称：

- 不把 ε_pg 写成善、目的、生命冲动、进步方向或物理力；
- 不说跨学科材料证明了 ε_pg；
- 不把公设伪装成已完成证明。

最终推进到的下一问题：

```text
最低非中立性只能拒绝零，不能决定具体的一；具体形状如何出现？
```

## 第二幕：生成机制的显影

目标：把“选择”从心理挑选中解放出来，显现现实如何通过成形、排除、锚定和秩序获得厚度。

### 第 5 问：选择为什么不是挑选？

旧地板：

```text
选择 = 主体在已有选项之间做决定。
```

读者误认：

```text
选择发生在菜单出现之后；没有主体、偏好和选项，就没有选择。
```

要显现的生成机制：

```text
选择不是从多中拿一，而是让一从未定形中变得可遭遇；它包含排除、定形、写入。
```

可使用的跨学科材料：

- 神经科学中的竞争性抑制；
- 生物选择与细胞分化材料；
- 决策理论作为对照；
- 复杂系统中的路径选择与状态收缩。

必要 SRT 概念：

- 选择；
- 排除；
- 定形；
- 写入；
- 选择者是选择的化石。

必须避免的过度宣称：

- 不把选择等同达尔文选择；
- 不把选择等同主体意志；
- 不把神经机制写成选择本体论的证明。

最终推进到的下一问题：

```text
如果选择让一出现，那么未被成形者去了哪里？
```

---

### 第 6 问：为什么每次成形都伴随排除？

旧地板：

```text
现实出现只是获得一个正面结果；未出现者等于无关或不存在。
```

读者误认：

```text
只要某个结果出现，其他可能性就只是没有发生，不再起作用。
```

要显现的生成机制：

```text
显现必然制造边界，边界必然制造排除；被排除者不是删除，而是以阴影、张力、机会成本和后续摩擦继续作用。
```

可使用的跨学科材料：

- 量子测量/路径信息只作谨慎显影；
- Barad 切割概念作为相邻压力；
- 神经系统中的抑制机制；
- 社会选择中的外部性。

必要 SRT 概念：

- 阴影；
- 排除不是删除；
- 后续摩擦。

必须避免的过度宣称：

- 不写成平行世界；
- 不把阴影道德化；
- 不把排除直接等同压迫。

最终推进到的下一问题：

```text
出现和排除发生之后，为什么世界不能回到选择之前？
```

---

### 第 7 问：为什么撤回不是回到原点？

旧地板：

```text
选择可以撤回，撤回就是回到选择前。
```

读者误认：

```text
只要取消结果，世界就恢复原状。
```

要显现的生成机制：

```text
选择写回地形，改变前景、阴影、选择者和未来开放性的地图；撤回只能成为新的选择。
```

可使用的跨学科材料：

- 热力学不可逆性作为压力点，不作还原；
- 记忆、学习与路径痕迹；
- 社会制度中的历史锁定；
- 生态系统扰动后的新稳定态。

必要 SRT 概念：

- 不可逆；
- A′；
- 历史写回；
- 修复不是删除历史。

必须避免的过度宣称：

- 不把不可逆简化成熵增科普；
- 不写成悲观主义；
- 不把所有修复写成不可能。

最终推进到的下一问题：

```text
如果撤回不是免费回到原点，现实为什么不会免费改变？
```

---

### 第 8 问：为什么出现不等于留下？

旧地板：

```text
出现了，就算进入现实。
```

读者误认：

```text
只要某物发生、被记录、被命名或被感知，它就已经获得现实地位。
```

要显现的生成机制：

```text
发生只是切入；锚定让显现获得留痕、受力和再入场能力。
```

可使用的跨学科材料：

- 记忆与痕迹理论；
- 生物学中的遗传/表观遗传留痕；
- 物理记录与信息稳定；
- 社会制度中的记录、承认、继承。

必要 SRT 概念：

- 锚定；
- 留痕；
- 受力；
- 再入场；
- 现实厚度。

必须避免的过度宣称：

- 不把锚定等同记忆；
- 不把记录等同锚定；
- 不把锚定写成意识活动。

最终推进到的下一问题：

```text
许多留下来的锚如何形成后来选择必须面对的地形？
```

---

### 第 9 问：为什么现实会有厚度？

旧地板：

```text
现实性来自出现强度、感知强度或共识强度。
```

读者误认：

```text
越强烈、越被看见、越被相信，就越真实。
```

要显现的生成机制：

```text
现实厚度来自锚定深度：一个显现能否持续受力、改变后续选择，并作为未来地形再入场。
```

可使用的跨学科材料：

- 科学对象的多位置校准；
- 制度事实的维持成本；
- 生物结构的可继承性；
- 技术系统中的路径依赖。

必要 SRT 概念：

- 现实厚度；
- 承重；
- 再入场；
- 支付。

必须避免的过度宣称：

- 不把现实厚度写成真理充分定义；
- 不把共识写成真实性来源；
- 不把稳定直接等同正当。

最终推进到的下一问题：

```text
当许多锚彼此接续、竞争、共享并退到背景，秩序如何出现？
```

---

### 第 10 问：为什么秩序通常只在失效时显影？

旧地板：

```text
秩序是外部规则、制度或管理结构。
```

读者误认：

```text
秩序只有在被命令、被设计、被制定时才存在。
```

要显现的生成机制：

```text
秩序是过去选择沉积后的摩擦分配；它在正常运作时退到背景，只有失效时才显影。
```

可使用的跨学科材料：

- 语言语法；
- 技术默认设置；
- 制度路径依赖；
- 生态位构建；
- 复杂系统中的吸引盆。

必要 SRT 概念：

- 秩序；
- L2；
- 背景化；
- 摩擦分配；
- 从零开始成本 / 再选择成本。

必须避免的过度宣称：

- 不把秩序等同制度；
- 不把 L2 写成纯负面；
- 不把摩擦写成纯阻力。

最终推进到的下一问题：

```text
如果秩序已经成为背景，人在选择之前是否已经被地形预处理？
```

## 第三幕：价值与主体的回流

目标：从后果回流中推出主体、在乎、价值和意识，而不是从先验主体或主观偏好开始。

### 第 11 问：为什么人在选择之前已经被选择？

旧地板：

```text
自由选择发生在选项出现之后。
```

读者误认：

```text
只要选项摆在面前，选择才真正开始。
```

要显现的生成机制：

```text
L2 作为摩擦分配，在选项出现之前已经改变可见性、接触窗口、默认通道和可支付路径。
```

可使用的跨学科材料：

- 可供性理论；
- 社会结构与 habitus；
- 神经注意与 salience；
- 平台推荐与默认路径。

必要 SRT 概念：

- 地形；
- 预裁剪；
- 默认通道；
- 接触窗口。

必须避免的过度宣称：

- 不写成决定论；
- 不写成社会压迫专章；
- 不把地形拟人化。

最终推进到的下一问题：

```text
如果地形预处理了选择，那么后果到底回到谁那里？
```

---

### 第 12 问：为什么后果必须攸关某个位置？

旧地板：

```text
后果只是事件链中的结果。
```

读者误认：

```text
只要有因果影响，就等于对某个主体有意义。
```

要显现的生成机制：

```text
被影响不等于攸关；后果必须回到一个承重位置，并改变其未来选择条件，才获得主体/价值入口。
```

可使用的跨学科材料：

- 生物体边界与自维持；
- 神经系统中的身体回路；
- 社会责任中的后果归属；
- 复杂适应系统中的反馈位置。

必要 SRT 概念：

- 承重位置；
- 攸关；
- 后果回流。

必须避免的过度宣称：

- 不把所有受影响者都写成主体；
- 不把攸关等同感受；
- 不提前解决 selectability 起源问题。

最终推进到的下一问题：

```text
当后果回到承重位置，在乎和价值如何出现？
```

---

### 第 13 问：为什么在乎不是喜欢？

旧地板：

```text
在乎 = 主观喜欢或情绪强度。
```

读者误认：

```text
越喜欢、越痛、越强烈，就越在乎。
```

要显现的生成机制：

```text
在乎是攸关进入主体经验层后的形态；它意味着后果能够改写一个位置的未来选择结构。
```

可使用的跨学科材料：

- 情绪神经科学；
- attachment / salience 材料；
- 行为经济学偏好反例；
- 社会关系中的不可替代承担。

必要 SRT 概念：

- 在乎；
- 攸关；
- 不可替代承担。

必须避免的过度宣称：

- 不把在乎降级为情绪；
- 不把在乎写成无限承担；
- 不把 AI feedback 直接写成在乎。

最终推进到的下一问题：

```text
如果在乎不是喜欢，那么价值为什么不是偏好？
```

---

### 第 14 问：为什么价值不是偏好？

旧地板：

```text
价值 = 被主体偏好、选择或赋值的东西。
```

读者误认：

```text
我喜欢什么，什么就对我有价值；社会承认什么，什么就有价值。
```

要显现的生成机制：

```text
价值从后果回流开始：某物是否真正改变承重位置的未来选择空间，决定它是否具有结构重量。
```

可使用的跨学科材料：

- 价值理论与偏好理论对照；
- 生物适应价值与生存赌注；
- 神经 reward 与 salience 区分；
- 社会符号价值与真实承重错位。

必要 SRT 概念：

- 价值；
- d-value；
- 赌注化；
- 后果回流。

必须避免的过度宣称：

- 不把 d-value 写成道德价值；
- 不把价值还原为生存；
- 不把价值写成主观偏好强度。

最终推进到的下一问题：

```text
如果价值来自后果回流，那么“我”是什么？
```

---

### 第 15 问：为什么“我”不是源头，而是沉积物？

旧地板：

```text
主体是选择的源头。
```

读者误认：

```text
先有一个我，然后我拥有偏好、做出选择、承担后果。
```

要显现的生成机制：

```text
选择者是选择的化石：后果、路径、回流和历史沉积出一个承重位置，这个位置后来被语法标记为“我”。
```

可使用的跨学科材料：

- 自我模型理论；
- 发展心理学；
- 记忆与身份连续性；
- 社会身份与角色沉积。

必要 SRT 概念：

- 选择者作为位置；
- 主体位；
- 自指率；
- 历史写回。

必须避免的过度宣称：

- 不把主体写成幻觉；
- 不取消责任；
- 不提前把自我意识写成主体的充分条件。

最终推进到的下一问题：

```text
如果主体不是源头，意识又是什么？
```

---

### 第 16 问：为什么意识不是选择的源头？

旧地板：

```text
意识是选择、价值和世界显现的源头。
```

读者误认：

```text
只有被意识到，世界才真正进入现实；有意识才有选择。
```

要显现的生成机制：

```text
意识是某些选择结构在关切、回流、自指、整合和可移动性条件下的迟到凝结物，不是选择的原初源头。
```
