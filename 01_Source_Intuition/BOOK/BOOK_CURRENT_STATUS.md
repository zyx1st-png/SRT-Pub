## 0. 当前总方向：第三类著作升级

当前《从存在到秩序》的施工目标已经从“可读的 SRT 源头书稿”升级为：

> **SRT 的源头哲学主文本 / 第三类著作版本。**

这意味着后续所有章节优化和新写作必须服务于一个中心动作：

> 从“什么存在”转向“什么样的选择结构，使某些可能性能够显现、留下、承重并稳定为存在”。

当前不再以“更生活化、更好懂、更有现代问题感”为第一目标。生活场景、AI、平台、指标、制度、心理困境等只能作为显影剂；真正主梁必须是：

1. 根本哲学问题；
2. 旧图景为什么失效；
3. SRT 概念为什么不得不引入；
4. 强反对者必须回答什么；
5. 本章能否压缩出可签字命题；
6. 下一章为什么必然出现。

新增施工指导文件：

- **第三类改写指南**：`01_Source_Intuition/BOOK/THIRD_TIER_REWRITE_GUIDE.md`
- **第三档厚重补充**：`01_Source_Intuition/BOOK/00_全书章节写作概要_第三档哲学厚重补充.md`
- **治理方向锚点**：`Governance/BOOK_THIRD_TIER_DIRECTION.md`
- **卷二调整指导**：`01_Source_Intuition/BOOK/00_全书章节写作概要_卷二调整指导.md`

压缩护栏：

> 生活入口让问题显影；哲学命题让问题不能逃走。
>
> 现代问题只是症状；真正的第三类写作要逼问使这些症状反复出现的旧地板。
>
> 本书的核心不是“让 SRT 更好懂”，而是让旧图景不能再轻易站住，让 SRT 的第一问题迁移变得不可回避。

## 8. 出版导出规则（Publication Export）

源文件保留完整 YAML front matter，用于仓库状态、版本管理与 AI 协作。

出版稿 / 读者版导出时应自动剥离 YAML front matter，只保留正文 Markdown。注意：`---` 也在正文中用作章节分隔线，请勿使用 `sed '/^---$/,/^---$/d'`（会误删正文分隔线）。

推荐导出方式（只剥离文件开头第一段 YAML front matter）：

```bash
awk 'NR==1 && $0=="---" {skip=1; next}
     skip && $0=="---" {skip=0; next}
     !skip {print}' 原文件.md > 导出文件.md
```

或使用 pandoc：

```bash
pandoc 原文件.md -o 导出文件.pdf  # pandoc 默认不渲染 YAML front matter 为正文
```

正文中的 `optimization_axis`、`based_on`、`references` 等字段不进入读者稿；这些信息留存于源文件 YAML 和 BOOK_VERSION_LOG.md。
