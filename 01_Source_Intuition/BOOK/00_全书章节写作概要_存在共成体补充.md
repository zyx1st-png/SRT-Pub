# 《从存在到秩序》大纲补充：从共同体到存在共成体

> 目的：把作者最新确认的终极野心补入书籍写作蓝图：SRT 不只是要解释“存在如何成为秩序”，也不只是要统一个体与集体价值；它更深地指向一种跨个体、跨集体、跨物种、跨 AI、跨非生命结构与宇宙生成过程的价值共建框架。
>
> 工作原则：本补充文件不替代主大纲，而是作为 founder pass 的结构锚点。后续主大纲修订时，应把这里的内容分流进序章、卷三、卷五、卷六、卷七与收尾章。

---

## 0. 核心命名调整

当前建议采用三层命名：

| 层级 | 推荐命名 | 用途 |
|---|---|---|
| 正式理论名 | **存在共成体** | SRT 的最高本体论—价值论结构 |
| 规范运行名 | **共成秩序** | 指导 AI、制度、生态、社会、教育和共同体的运行系统 |
| 通俗传播名 | **存在共同体** | 面向大众解释时使用 |
| 精确说明名 | **可成为性共同体** | 用于说明其本质结构 |
| 宇宙层表达 | **宇宙共成** | 仅在宇宙目的论/最终章中使用 |

**主定义候选**：

> 存在共成体不是由已经存在的对象组成的共同体，而是不同存在层级在选择、锚定、承重、后果回流与再选择中共同维持和扩展可成为性的生成结构。

**通俗压缩句**：

> 世界不是存在者的集合，而是存在者共同成为的过程。

**价值论压缩句**：

> 价值不是人类赋予世界的标签，而是存在共成体维持和扩展可成为性的方式。

## 1. 对全书总运动的补充

主大纲当前总运动为：

```text
静态存在图景的失效
→ 前对象可成为性 L0
→ 最小非中立性 ε_pg
→ 选择 / 定形 / 写入
→ 锚定 / 承重 / 再入场
→ 秩序 / L2 / 背景化
→ 主体 / 价值 / 痛苦 / 意识 / AI / 共同体
→ 边界、张力与回返
```

建议在后续修订中升级为：

```text
静态存在图景的失效
→ 前对象可成为性 L0
→ 最小非中立性 ε_pg
→ 选择 / 定形 / 写入
→ 锚定 / 承重 / 再入场
→ 秩序 / L2 / 背景化
→ 主体 / 关切 / 价值 / 痛苦 / 意识
→ 个体—集体价值统一
→ 人—生命—生态—AI—非生命结构的价值共建
→ 存在共成体 / 共成秩序
→ 非终点式宇宙目的论
→ 边界、张力与回返：让 SRT 自己不变成新的牢笼
```

**新增总问题**：

> 如果存在是选择、锚定和秩序的结果，那么价值也不能只是主体对对象的评价；价值应被理解为不同存在层级共同维持、扩展和修复可成为性的方式。

## 2. 对全书定位的补充

《从存在到秩序》不应只被定位为：

> 一本解释存在如何生成秩序的哲学书。

更准确的定位应是：

> 一本通过解释存在如何生成秩序，进一步重建个体、集体、生命、生态、AI 与宇宙生成过程之间价值共建方式的基石论述。

更压缩的表述：

> 本书不是从存在走向服从秩序，而是从旧秩序走向可再选择的共成世界。

## 3. 对卷结构的补充建议

### 3.1 序章需要轻量埋钉

序章不应提前展开“存在共成体”，但应埋下终极方向：

> 本书看似从存在开始，实际上最终要回到价值与共同生活。若存在是选择、锚定和秩序的结果，那么个体与集体、人类与生命、文明与 AI、社会与生态之间的冲突，也不能再被理解为已成对象之间的利益冲突。它们更深地表现为：哪些可能性被允许显现，哪些后果能够回流，哪些痛苦能够成为结构输入，哪些秩序仍然服务再选择。

### 3.2 卷三“主体与价值”需要提前承担价值共建

主大纲中的卷三目前聚焦主体、在乎、价值如何沉积。建议新增一条承重任务：

> 卷三不仅要说明主体如何产生价值，也要说明价值为什么不是主体私有物。价值必须通过后果回流、承重、关切维度和再选择能力进入共同地形，才能从偏好变成可共建价值。

### 3.3 卷五“共同秩序”需要从人类共同体升级

主大纲中卷五目前是“从个体秩序到共同秩序”。建议将其终点改为：

> 从人类共同体走向存在共成体。

卷五新增核心问题：

1. 个体价值如何不被集体 L2 吞没？
2. 集体目标如何不只是个体偏好的加总？
3. 人类共同体如何把生命、生态、AI、非生命承重结构纳入价值共建？
4. “共同体”如何避免变成新的总体性牢笼？

### 3.4 卷六“意识、AI、修行”需要加入 AI 的共成位置

AI 不应只被写成工具、代理或潜在主体，而应写成：

> 一种能够改变人类、社会、生命、生态和知识系统 L0 接触窗口的选择结构。

卷六新增判据：

> 好的 AI 不是更会满足偏好，而是更能扩展人、生命、共同体和生态的真实再选择能力。

### 3.5 卷七“边界与张力”必须防止宇宙目的论误读

卷七新增必须处理：

- SRT 不是神学目的论。
- SRT 不是进步主义目的论。
- SRT 不是人类中心主义。
- SRT 不是泛灵论。
- SRT 的宇宙目的论不是预设终点，而是非自我抹除、继续成为、保持开放性的生成方向论。
- SRT 自身不能成为替人完成选择的新 L2 牢笼。
