# 全书概念地图

> 这是一张读者路线图，不是定义词典。
> 它只帮助读者知道自己正走到哪里；每个概念的重量，仍要在章节里慢慢获得。

---

## 1. 全书生成链

```text
L0 → ε_pg → 选择 → 锚定 → L2 → 主体 / 价值 / 共成秩序 / AI
```

这条链说明本书的基本方向：先从对象之前的可成为性出发，看它如何获得最小非中立性，如何经由选择让一出现，经由锚定让一留下，再沉积为后来选择必须面对的 L2 地形。主体、价值、共同体和 AI 问题，都要在这条链之后重新回来。

---

## 2. 卷一生成链

```text
对象之前 → L0 → 最小非中立性 ε_pg → 选择让一出现 → 锚定让一留下 → 秩序成为背景
```

卷一的任务，是拆掉“存在先在那里”的旧地板。它不急着回答意识、AI、价值和共同体，而是先追问：如果对象不是第一事实，对象之前是什么；如果对象之前不是虚无，为什么会有显现；如果显现发生，为什么有些能留下；如果许多留下者彼此继承，秩序如何退到背景。

---

## 3. 卷二机制链

```text
L2 地形 → 可见性 / 摩擦 / 默认通道 / 预裁剪 → 选择算子 → 排除 → 不可逆 → 本体论摩擦 → 可支付性 → 路径
```

卷二从“秩序已经成为背景”之后开始。它要让选择获得机制厚度：人并不在空白世界里选择，选项出现之前已经有可见性差异、摩擦分布、默认通道和预裁剪。选择算子把可成为性定形为显现；排除留下阴影；不可逆让世界获得历史厚度；本体论摩擦说明现实不会免费成形；可支付性决定一条路能否真正持续。

---

## 4. 选择算子结构

```text
接触窗口 → 定形条件 → 显现 / 阴影
```

选择算子不是机器，也不是算法。读者只需要先把它理解为一个动作结构：可成为性通过某个接触窗口进入，被身体、历史、L2、关切、代价和承接条件共同定形，最后形成可遭遇的显现；与此同时，未被定形者并不安静消失，而会以阴影、摩擦、机会成本或未来回流的方式继续改变地形。

---

## 5. 核心术语快照

- **L0**：对象化之前的可成为性。
- **ε_pg**：L0 的最小非中立性。
- **选择**：让一出现。
- **锚定**：让一留下。
- **L2**：多锚继承、共享、背景化后的地形。
- **选择算子**：从可成为性到显现的定形结构。
- **阴影**：未被定形者在后续地形中的效力。
- **本体论摩擦**：现实成形、维持、切换、修复时必须支付的阻力。
- **可支付性**：路径是否有资源、承接、重复维护和代价回流机制。

---

## 6. 如何使用这张地图

读第一遍时，不必记住所有词。只要记住一件事：本书不是从已经完成的对象出发，而是从“对象如何能够成为对象”出发。每当某个术语显得抽象，可以回到这张图，看它在生成链上的位置。
