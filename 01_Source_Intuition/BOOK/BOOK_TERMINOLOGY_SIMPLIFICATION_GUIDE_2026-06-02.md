# 《从存在到秩序》术语降噪规则表 v3

> 本文件用于后续全书改稿：不是删除 SRT 的理论锋利度，而是改变术语进入正文的顺序。
>
> 核心原则：**正文先让读者看见经验结构，术语只作为后来命名；普通读者读懂主线，专业读者仍能追踪理论结构。**

---

## 0. v3 更新说明：三章样板后的规则固化

v1 版本主要解决高风险术语：L0、L1、L2、ε_pg、Ψ_f、d-value、本体论、结构位置等。

v2 版本补入全量核心术语覆盖：具身位、攸关、承重、代理/代付、在乎、价值、自指率、d_mobile、冻结态、felt/actual、L0 接触窗口、遮蔽阶段、苦难等。

v3 版本基于三个样章 PR 固化新规则：

- **PR #314 / Q03**：验证“先懂状态，后知 L0”。
- **PR #316 / Q04**：验证“技术符号降级为专业记号”。
- **PR #315 / Q05**：验证“核心术语保留锋利度，但白话先行”。

v3 的新增重点：

1. 把三章样板跑通的规则写成可复用标准；
2. 明确哪些规则可以推广到全书，哪些不能机械复制；
3. 防止后续全书批量改写时出现“Claude 腔统一全书”；
4. 指定第二批样章优先处理 Q12/Q13/Q14/Q17，而不是直接顺序推进 Q06；
5. 增加“每章只允许一个新核心术语成为读者记忆点”的纪律。

注意：这里的“全量”指**当前书稿核心术语与机制术语**，不包括每章临时出现的普通解释词、外部学术人物名、一次性类比词。后续若某章新增承担理论推进功能的新术语，应补入本表。

## 1. 总目标

本书当前最大的可读性风险不是“术语太多”本身，而是：

1. 很多章节的入口故事很好，普通读者能进入；
2. 但一旦进入概念命名区，术语密度迅速升高；
3. L0、L1、L2、ε_pg、θ、Ψ_f、d-value、σ_sr、d_mobile 等符号容易让读者误以为必须先学习一套系统；
4. “本体论条件”“前对象场”“结构位置”“生成前场”“拓扑学约束”等表达连续出现时，会把正文推向论文语感；
5. 后半部分的理论防守很强，若不分层，普通读者会把它读成专业审稿而非思想书。

本轮修改的目标是：

> 把 SRT 从“读者必须学习的一套术语系统”，改成“读者顺着经验自然走到的一组名字”。

## 2. 三章样板验证出的通用规则

### 2.1 术语三步法

所有核心术语第一次出场，优先使用以下顺序：

```text
经验状态 → 白话记忆句 → 后置命名
```

必要时再加第四步：

```text
必要边界
```

样板：

- Q03：先让读者懂“不是空无、不是隐藏对象、还没成形但足以成形”，再命名“可成为性 / L0”。
- Q04：先让读者懂“起点不是蓝图，也不是完全归零；它只是不完全平”，再给出“最低非中立性 / ε_pg”。
- Q05：先让读者懂“排开、有形、留下痕迹”，再命名“选择结构 / 排除-定形-写入”。

### 2.2 每章只允许一个新核心术语成为读者记忆点

一章可以包含多个旧术语，但只能让一个新术语承担读者记忆压力。

| 章节 | 读者主要记忆点 | 技术词处理 |
|---|---|---|
| Q03 | L0 / 可成为性 | 后置命名，避免神秘化 |
| Q04 | 最低非中立性 | ε_pg 降级为专业记号 |
| Q05 | 选择结构 | 排除/定形/写入先白话化 |

后续章节也应遵守：

- Q12 不要同时强推“攸关、具身位、承重、代理”；主记忆点应是“攸关”，具身位作为必要支撑。
- Q13 主记忆点应是“在乎不是情绪音量”。
- Q14 主记忆点应是“价值不是偏好”，d-value 后置。
- Q17 主记忆点应是“意识是晚来的二阶结构”，σ_sr 等符号后置。

### 2.3 技术符号只做专业记号，不做正文主词

以下符号不得作为普通正文推进主词：

```text
ε_pg / θ / Ψ_f / d-value / σ_sr / d_mobile / P24-1 等预测编号
```

推荐处理：

1. 前文已有白话解释；
2. 符号第一次出现时明确说“专业表达中记作……”；
3. 紧跟一句“普通读者只需要记住……”；
4. 不在同一段落引入第二个符号；
5. 后文尽量使用中文或白话回指。

### 2.4 跨领域材料只能显影，不能证明

跨领域材料的作用是让同一种结构更可见，而不是证明 SRT。

禁止写法：

```text
物理学 / 生物学 / AI 已经证明了 SRT。
```

推荐写法：

```text
这些材料不是证明，而是显影：它们在各自对象化框架内，让同一种结构更容易被看见。
```

尤其注意：Q04、Q05、Q24、Q26 最容易滑向“跨领域材料当证明”。

### 2.5 防误读边界要保留，但不能压过主线

边界不是可删内容。降噪不是去掉边界，而是改变边界的呈现形式。

推荐方式：

- 正文中只保留最关键的 3–6 条；
- 用短列表、短段落或“这一章没有说什么”集中处理；
- 避免每个边界都写成一段答辩。

### 2.6 章末工具箱可用，但不能滥用

三章样板证明，章末“理论工具箱”对奠基章有效。

但不能机械推广到所有章节。

| 章节类型 | 建议 |
|---|---|
| 奠基章 Q03–Q05 | 可以使用工具箱 |
| 机制章 Q06–Q11 | 优先使用“本章一句话”或操作接口 |
| 主体/价值章 Q12–Q18 | 少工具箱，多经验收束 |
| 秩序/苦难/AI 章 Q19–Q25 | 视术语密度而定 |
| 理论自检章 Q26–Q28 | 可以使用“专业读者注” |

### 2.7 警惕 Claude 式平滑

样章改写成功后，后续 Claude 很容易机械复制以下结构：

```text
入口故事 → 白话记忆句 → 后置命名 → 边界 → 工具箱
```

这适合样章，但不能成为全书固定模板。

需要避免：

1. 每章都同一种节奏；
2. 每章都加工具箱；
3. 每章都用“这不是 A，也不是 B”的句式堆边界；
4. 为了顺滑而削弱最强反对者；
5. 为了可读而删掉必要理论张力。

## 3. 总体写作规则

### 3.1 正文推进顺序

优先使用：

```text
经验场景 → 旧图景为什么有力 → 旧图景解释不了什么 → 白话压缩 → 后置命名 → 必要边界
```

避免直接使用：

```text
术语 → 定义 → 反误读 → 理论边界 → 例子
```

### 3.2 第一次出现术语的标准格式

推荐：

```text
先用普通话说清楚这个位置/过程是什么。
再用一句话压缩它。
最后才说：为了后文方便，本书把它叫作 X。
```

### 3.3 禁止的术语使用方式

避免以下写法：

1. 开头三段内直接抛出高压术语；
2. 用符号承担正文推进功能；
3. 用术语替代解释；
4. 每章反复重新定义同一概念；
5. 用跨领域材料证明概念，而不是显影概念；
6. 为了显得专业而保留不必要的希腊字母、英文缩写或理论史标签；
7. 把防误读护栏写成正文主线，导致读者感觉在读答辩稿；
8. 在同一段落连续引入两个以上新术语；
9. 用“真正理解 SRT 才能……”作为隐性守门句式。

### 3.4 保留理论深度的方式

降噪不等于改浅。理论深度应当通过以下方式保留：

1. 保留问题链；
2. 保留关键区分；
3. 保留最强反对者；
4. 保留失败条件；
5. 保留必要边界；
6. 把技术定义、符号化表达和外部理论对照后置。

## 4. 术语四级分类

### A 类：正文主线术语，保留

| 术语 | 正文处理 | 降噪要求 |
|---|---|---|
| 旧图景 / 旧地板 | 保留 | 用“从稳定之后开始说话的习惯”解释 |
| 切片 | 保留 | 用“把连续经验切成可命名、可处理的东西”解释 |
| 给定感 | 保留 | 用“它好像本来就在那里”的直觉解释 |
| 生成 | 保留 | 尽量与“形成、留下痕迹、变成背景”连用 |
| 对象化 | 保留 | 第一次出现时用“被叫出名字、划出边界、可以处理”解释 |
| 选择 | 保留 | 必须区分“挑选”和“生成层面的选择” |
| 地形 | 保留 | 用“你不是在平地上选择，而是在被过去塑造的地面上选择”解释 |
| 锚定 | 保留 | 第一次出现时用“某个结果留下位置，后来不再容易撤回”解释 |
| 阴影 | 保留 | 用“没有显现、但仍然留下张力的可能”解释 |
| 不可逆性 | 保留 | 用“能改变，但不能无痕撤回”解释 |
| 攸关 | 保留 | 用“这件事会不会真的回到某个位置身上”解释 |
| 具身位 | 保留但必须白话先行 | 用“后果会回到这里、被这里承受，并改变下一次选择的具体位置”解释 |
| 承重 | 保留 | 与“承受后果、把后果带入下一次选择”绑定 |
| 代理 / 代付 | 保留 | 用“帮你做事，但可能保留或切断后果回流”解释 |
| 在乎 | 保留 | 用“不是情绪音量，而是后果回来后未来变了”解释 |
| 价值 | 保留 | 用“不可替代的后果重量”解释 |
| 选择者 | 保留但慎用 | 用“选择历史压出来的形状”解释 |
| 脚手架 / 牢笼 | 保留 | 作为后半部分核心隐喻保留 |
| 遮蔽 | 保留 | 用“不是看不见，而是看见的方式已经被提前安排”解释 |
| 疼痛 / 苦难 | 保留 | 必须区分“感受强度”和“选择结构撕裂” |
| 方向 | 保留 | 避免被读成目的论；强调“不是预设终点，而是结构后果” |
| 理论自反 | 保留 | 用“这套理论也要检查自己会不会变成牢笼”解释 |

### B 类：核心理论术语，正文保留但必须白话先行

| 术语 | 正文第一次出现方式 | 注意事项 |
|---|---|---|
| L0 | 先讲“还没成形但不是空无的真实” | 不要直接说“前本体论结构位置” |
| L1 | 先讲“某次成形、某个结果浮出来” | 不要让 L1 变成纯编号 |
| L2 | 先讲“过去的选择退到背景，变成后来者的地面” | 与“背景结构”绑定解释 |

| 最低非中立性 | 保留 | 优先使用中文，不优先使用 ε_pg |
| 选择结构 | 保留 | 先用“排开、有形、留下痕迹”解释 |

## 5. 全量术语覆盖清单

### 5.1 第一幕：前对象与生成起点

| 术语 | 是否进入正文 | 降噪方式 | 普通读者记忆句 |
|---|---|---|---|
| 切片 | 是 | 白话解释 | 我们把连续世界切成一个个可处理的东西。 |
| 给定感 | 是 | 白话解释 | 有些东西看起来像本来就在那儿。 |
| 对象化 | 是 | 白话先行 | 一个东西被划出边界、叫出名字、进入处理流程。 |
| 前对象场 | 是，但慎用 | 优先说“对象之前” | 东西还没成为对象之前，并不是空无。 |
| 可成为性 | 是 | 区别于可能性 | 菜单还没印出来之前的成形余地。 |
| L0 | 是 | 后置命名 | 还没成形但不是空无的位置。 |
| 最低非中立性 | 是 | 中文优先 | 起点不是蓝图，也不是完全归零。 |
| ε_pg | 降级 | 脚注/工具箱 | 最低非中立性的专业记号。 |
| 结构位置 | 少用 | 换成“必须承认的位置” | 如果删掉它，解释链就断了。 |
| 前本体论条件 | 少用 | 换成“对象出现之前的条件” | 对象出现之前，也要有让对象能出现的条件。 |

### 5.2 第二幕：选择、显现、锚定、秩序

| 术语 | 是否进入正文 | 降噪方式 | 普通读者记忆句 |
|---|---|---|---|
| 选择 | 是 | 必须重定义边界 | 选择不只是最后从菜单里挑一个。 |
| 选择结构 | 是 | 白话先行 | 排开、有形、留下痕迹。 |
| 排除 | 是 | 与“排开其他路”绑定 | 有了这个，就必须有不是这个。 |
| 定形 | 是 | 与“有了形”绑定 | 一个方向开始变成可指认的东西。 |
| 写入 | 是 | 与“留下痕迹”绑定 | 发生没有消失，而是改变后来的地形。 |
| 显现 | 是 | 白话解释 | 某个形状浮出来，能被遭遇。 |

## 6. 关键术语降噪模板

### 6.1 L0

不推荐：

```text
L0 是对象化尚未发生的可成为性位置，是前本体论条件。
```

推荐：

```text
在一个东西被叫出名字、划出边界、进入处理流程之前，它并不是空无，也不是一个已经完成的对象。它更像一种还没成形、但已经足以让成形发生的状态。

为了后文方便，本书把这个位置叫作 L0。
```

使用原则：

- 第一次出现时，不要只给定义；
- 不要让 L0 像神秘实体；
- 不要说“L0 里面有某种东西”；
- 可以说“L0 是为了标记那个还没对象化、但不是空无的位置”。

### 6.2 可成为性

推荐：

```text
它不是已经摆好的可能选项，也不是空无。它只是说明：那里有某种还没有定形的差异，足以让后来的成形发生。
```

使用原则：

- 必须区别于“可能性”；
- 可能性像菜单，可成为性是菜单尚未印出来之前的状态；
- 避免把可成为性写成“所有可能性的仓库”。

### 6.3 最低非中立性 / ε_pg

推荐正文：

```text
起点不是一张已经写好的蓝图，但也不是完全平坦的零。它至少有一点点不均匀，使得生成不必从绝对归零中冒出来。本书把这种最小的不均匀叫作“最低非中立性”。
```

推荐脚注 / 工具箱：

```text
专业表达中，本书将“最低非中立性”记作 ε_pg。普通读者只需记住：它不是目的、不是物理力、不是善，也不是进步方向；它只表示起点不是完全归零。
```

使用原则：

- 正文优先写“最低非中立性”；
- ε_pg 第一次出现后，不要频繁回调；
- 所有边界说明压缩为一句：“它只拒绝归零，不规定方向。”

### 6.4 选择结构

推荐：

```text
一个东西真正成形，至少发生了三件事：别的路被排开，它自己有了形，这个结果留下了痕迹。排开、有形、留下痕迹，三者合在一起，本书把它叫作“选择结构”。
```

使用原则：

- 面向普通读者时，先用“排开、有形、留下痕迹”；
- 专业段落再恢复“排除、定形、写入”；
- 避免让读者误解为“万物都有意识”；
- 每次扩展“选择”含义时，都要提醒：“这不是说它有意图或责任。”

### 6.5 具身位

推荐：

```text
一件事发生之后，后果总要回到某个地方。它不是飘在空中的“影响”，而是被某个身体、某段历史、某个生活位置承受，并改变这个位置下一次能够怎么选择。

本书把这个会承受后果、带着后果继续选择的具体位置，叫作“具身位”。
```

使用原则：

- 具身位是第三幕最重要的术语之一，不能遗漏；
- 它不是抽象主体，不是纯视角，也不是心理感受位置；
- 第一次出现必须绑定“后果回来”“被承受”“改变下一次选择”；
- 不要频繁与“主体”混用；
- 旧称“承重位置”只作为脚注说明，正文优先用“具身位”。

### 6.6 攸关 / 在乎 / 价值

推荐关系写法：

```text
有些事只是发生在你旁边，有些事会回来改变你。前者只是相关，后者才攸关。

当这种后果回流在经验中变厚，它就表现为在乎。

当某些后果不能被无损替换，未来的选择空间会因它改变，这时我们才进入价值问题。
```

使用原则：

- 攸关：强调后果是否真的回到某个具身位；
- 在乎：强调后果回流在经验层变厚；
- 价值：强调不可替代承担，不是偏好强度；
- d-value 只在需要技术区分时后置。

### 6.7 自指率 / 自我意识 / 冻结态

推荐正文：

```text
一个人并不是每一次都从零开始选择。过去的选择会写回自己，变成下一次选择的条件。写回得太少，人会碎裂，无法形成连续历史；写回得太死，人会闭合，只能重复自己。

本书把这种“过去选择写回自身”的程度，称为自指率。专业表达中记作 σ_sr。
```

冻结态推荐写法：

```text
有些困境不是“不够在乎”，而是太在乎却动不了。后果非常重，但重新选择的地形已经被堵死。本书把这种状态叫作冻结态。
```

使用原则：

- σ_sr 后置；
- d_mobile 后置；
- 自我意识不要写成意识的神圣高点，而是写成晚来的二阶结构；
- 冻结态要用生活经验进入，不要先给公式。

### 6.8 辅助式 L2 / 替代式 L2 / 硬化

推荐正文：

```text
有些秩序像脚手架：它支撑你，让你能做以前做不到的事。也有些秩序像牢笼：它替你处理关键选择，久而久之让你失去重新选择的能力。

前者可以叫辅助式 L2，后者可以叫替代式 L2。
```

使用原则：

- 先用脚手架/牢笼，再给辅助式/替代式 L2；
- 硬化优先写成“背景变硬”；
- 不要让 L2 术语压过读者对秩序经验的理解。

### 6.9 felt / actual、疼痛 / 苦难

推荐正文：

```text
有些东西让你当下更痛，这是 felt 层面。有些东西没有立刻那么痛，却让真实的选择结构更坏，这是 actual 层面。

疼痛可以是报警铃。苦难的问题不只是铃声有多响，而是火在哪里、为什么一直灭不掉。
```

使用原则：

- felt / actual 必须翻译；
- 疼痛与苦难的区分要用“报警铃/火”或类似经验隐喻；
- 反最小化原则可以压缩成：“关掉报警铃不等于灭火。”

## 9. 章节类型与降噪策略

### 9.1 第一幕：概念奠基章

适用章节：Q00–Q04。

目标：让普通读者进入“世界不是已经完成”的问题。

策略：

1. 入口故事必须强；
2. 不要过早堆术语；
3. L0、可成为性、最低非中立性必须白话先行；
4. 符号全部后置；
5. 避免让读者误以为本书在提出神秘本体。

### 9.2 第二幕：生成机制章

适用章节：Q05–Q11 左右。

目标：让读者理解“对象、选择、稳定、秩序如何形成”。

策略：

1. 保留“选择结构”“锚定”“地形”等核心词；
2. 每个机制都要对应一个生活、身体、制度或技术例子；
3. 不要让排除、定形、写入变成僵硬三分法；
4. 多写“这个机制让什么变得不可撤回”；
5. 少写抽象定义。

### 9.3 第三幕：主体、价值、意识章

适用章节：Q12–Q18 左右。

目标：把理论从宇宙论/存在论拉回人的经验。

策略：

1. 减少本体论术语；
2. 增加承诺、羞耻、爱、损失、责任、记忆、身体经验；
3. “具身位”必须成为本幕核心桥梁，但要白话先行；
4. “价值不是偏好”要优先用不可替代性经验解释；
5. d-value、σ_sr、d_mobile 后置；
6. 意识章避免变成认知科学或泛心论防守稿。

### 9.4 第四幕：秩序、苦难、共同体、AI、方向章

适用章节：Q19–Q25 左右。

目标：把 SRT 转化为读者能用于理解现实的分析框架。

策略：

1. 保留脚手架/牢笼、遮蔽、方向、共同体、AI 地形参与者等强表达；
2. 技术符号弱化；
3. felt/actual、遮蔽 A/B、L0 接触窗口等概念尽量工具箱化；
4. 不要把跨领域材料当证明；
5. 每章只保留一个主反对者；
6. 避免每章都用同一种“这只是换语言”的反驳。

### 9.5 理论自检章

适用章节：Q26–Q28。

目标：保留理论严肃性，同时给普通读者可跳读路径。

策略：

1. 章节开头明确提示：“以下是理论压力测试”；
2. 主线读者可以读白话结论；
3. 专业读者继续读预测、失败条件、理论自反；
4. 拉卡托斯、蒯因、Duhem-Quine 等外部理论史内容尽量脚注化；
5. 六项预测可以保留，但正文先给一张白话总表。

1. **Q12《攸关》**：测试“攸关—具身位—承重”的出场。
2. **Q13《在乎》**：测试“在乎不是情绪音量”的大众表达。
3. **Q14《价值不是偏好》**：测试 d-value 的后置处理。
4. **Q17《意识》**：测试 σ_sr、自我意识等符号和认知术语的降级。

### 10.3 第三批再处理 Q06–Q11

等主体/价值样板成立后，再回头处理 Q06–Q11。

目标是统一第二幕机制语言：

```text
排开 → 阴影

```

### 11.1 Q26 可证伪性

Q26 可以保留较高专业密度，但需要改变读者定位。

```text
如果你只是跟随本书主线，读到这里已经足够。下面这一章更像是本书对自己的压力测试：它要问的不是 SRT 还能解释什么，而是什么情况会让 SRT 必须认错。
```

## 12. 全书统一口径

### 12.1 SRT 的白话总命题

```text
世界不是先完整摆好，然后才发生变化。许多看起来“本来如此”的东西，是在生成中成形、留下痕迹、变成背景之后，才像一个已经完成的世界。
```

### 12.2 对象化的白话口径

```text
一个东西成为对象，不只是被贴上名字，而是获得边界、身份、处理路径和再次被遇见的方式。
```

### 12.3 选择的白话口径

```text
选择不只是最后一刻从菜单里挑一个。更早的选择发生在菜单如何形成、哪些东西能进入视野、什么结果会留下痕迹。
```

### 12.4 具身位的白话口径

```text
后果不是抽象地存在。它总要回到某个具体位置，被那个位置承受，并改变它下一次能够怎么选择。本书把这个位置叫作具身位。
```

### 12.5 价值的白话口径

```text
价值不是偏好强度，而是有些后果回来之后，未来不能再像从前那样继续选择。
```

### 12.6 秩序的白话口径

```text
秩序不是凭空站在那里。它是过去选择留下的痕迹互相加固，最后退到背景里，变成后来者脚下的地面。
```

### 12.7 遮蔽的白话口径

```text
遮蔽不是简单看不见，而是你看见世界的方式，已经被某种结构提前安排好了。
```

### 12.8 方向的白话口径

```text
方向不是预先写好的终点，而是某种秩序在维持、扩展或消耗自身时显出来的结构倾向。
```

## 13. 评估标准

### 13.1 普通读者标准

一个没有哲学训练、但愿意读思想书的读者，应当能够：

1. 读懂本章要反对的旧图景；
2. 读懂本章新提出的问题；
3. 记住一个白话结论；
4. 不因为符号或术语中途退出；
5. 即使跳过脚注，也不影响主线理解。

### 13.2 专业读者标准

一个哲学、理论或跨学科读者，应当能够：

1. 看出术语背后的结构位置；
2. 追踪概念之间的递进；
3. 找到边界声明；
4. 看到最强反对者；
5. 不觉得书被改成鸡汤或泛泛科普。

### 13.3 作者标准

改写后必须满足：

1. 不牺牲 SRT 的核心命题；
2. 不把理论改成心理学鸡汤；
3. 不把哲学问题改成励志表达；
4. 不为了通俗而抹掉最强反对者；
5. 不为了流畅而删除必要边界；
6. 不把三章样板模板机械复制到所有章节。

```text
你现在是《从存在到秩序》的大众化改写编辑。
```
