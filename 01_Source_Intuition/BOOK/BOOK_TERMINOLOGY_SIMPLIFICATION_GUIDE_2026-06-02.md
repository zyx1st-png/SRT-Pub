# 《从存在到秩序》术语降噪规则表

> 本文件用于后续全书改稿：不是删除 SRT 的理论锋利度，而是改变术语进入正文的顺序。
>
> 核心原则：**正文先让读者看见经验结构，术语只作为后来命名；普通读者读懂主线，专业读者仍能追踪理论结构。**

---

## 0. 本轮降噪的目标

本书当前最大的可读性风险不是“术语太多”本身，而是：

1. 许多章节的入口故事很好，普通读者能进入；
2. 但一旦进入概念命名区，术语密度迅速升高；
3. L0、L1、L2、ε_pg、Ψ_f、d-value 等符号容易让读者误以为自己必须先学习一套系统，才能继续阅读；
4. “本体论条件”“前对象场”“结构位置”“生成前场”“拓扑学约束”等表达连续出现时，会把正文推向论文语感；
5. 后半部分的理论防守很强，但若不分层，普通读者会把它读成专业审稿而非思想书。

本轮修改的目标是：

> 把 SRT 从“读者必须学习的一套术语系统”，改成“读者顺着经验自然走到的一组名字”。

---

## 1. 总体写作规则

### 1.1 正文推进顺序

所有核心概念第一次出现时，尽量遵循以下顺序：

```text
经验场景 → 旧图景为什么有力 → 旧图景解释不了什么 → 白话压缩 → 后置命名 → 必要边界
```

不要直接用：

```text
术语 → 定义 → 反误读 → 理论边界 → 例子
```

### 1.2 第一次出现术语的标准格式

推荐格式：

```text
先用普通话说清楚这个位置/过程是什么。
再用一句话压缩它。
最后才说：为了后文方便，本书把它叫作 X。
```

示例：

```text
在一个东西被叫出名字、划出边界、进入处理流程之前，它并不是空无，也不是一个已经完成的对象。它更像一种还没成形、但已经足以让成形发生的状态。

为了后文方便，本书把这个位置叫作 L0。
```

### 1.3 禁止的术语使用方式

避免以下写法：

1. 开头三段内直接抛出高压术语；
2. 用符号承担正文推进功能；
3. 用术语替代解释；
4. 每章反复重新定义同一概念；
5. 用跨领域材料证明概念，而不是显影概念；
6. 为了显得专业而保留不必要的希腊字母、英文缩写或理论史标签；
7. 把防误读护栏写成正文主线，导致读者感觉在读答辩稿。

### 1.4 保留理论深度的方式

降噪不等于改浅。理论深度应当通过以下方式保留：

1. 保留问题链；
2. 保留关键区分；
3. 保留最强反对者；
4. 保留失败条件；
5. 保留必要边界；
6. 但把技术定义、符号化表达和外部理论对照后置。

## 2. 术语四级分类

### A 类：正文主线术语，保留

这些词可以在正文中正常使用，因为它们具有较高的普通语言可理解性，且承担全书主线。

| 术语 | 正文处理 | 降噪要求 |
|---|---|---|
| 生成 | 保留 | 尽量与“形成、留下痕迹、变成背景”连用 |
| 对象化 | 保留 | 第一次出现时用“被叫出名字、划出边界、可以处理”解释 |
| 选择 | 保留 | 必须区分“挑选”和“生成层面的选择” |
| 地形 | 保留 | 尽量用“你不是在平地上选择，而是在被过去塑造的地面上选择”解释 |
| 锚定 | 保留 | 第一次出现时用“某个结果留下位置，后来不再容易撤回”解释 |
| 遮蔽 | 保留 | 用“不是看不见，而是看见的方式已经被提前安排”解释 |
| 方向 | 保留 | 避免被读成目的论；强调“不是预设终点，而是结构后果” |
| 关切 | 保留 | 用“有些后果回来之后，未来不再一样”解释 |
| 脚手架 / 牢笼 | 保留 | 非常适合大众读者，作为后半部分核心隐喻保留 |

### B 类：核心理论术语，正文保留但必须白话先行

这些词是 SRT 的核心，不应删除，但不能作为第一次理解的入口。

| 术语 | 正文第一次出现方式 | 注意事项 |
|---|---|---|
| L0 | 先讲“还没成形但不是空无的真实” | 不要直接说“前本体论结构位置” |
| L1 | 先讲“某次成形、某个结果浮出来” | 不要让 L1 变成纯编号 |
| L2 | 先讲“过去的选择退到背景，变成后来者的地面” | 与“背景结构”绑定解释 |
| 可成为性 | 保留 | 第一次出现时必须区别于“可能性” |
| 最低非中立性 | 保留 | 优先使用中文，不优先使用 ε_pg |
| 选择结构 | 保留 | 先用“排开、有形、留下痕迹”解释 |
| 主体沉积 | 保留但慎用 | 先讲“人不是一开始就完整站在那里” |
| 现实厚度 | 保留 | 用“撤回成本、后果重量、不可轻易归零”解释 |
| 后果回流 | 保留 | 用“做出的事回来改变做事的人”解释 |
| 可再选择性 | 保留 | 用“在关键分叉处还能不能重新选择”解释 |

### C 类：技术符号术语，正文降级

这些词不应成为普通读者的阅读负担。正文可以出现，但必须满足两个条件：

1. 前面已经有充分白话解释；
2. 出现后不要求读者频繁记忆或回调。

| 术语 / 符号 | 推荐处理 | 正文替代表达 |
|---|---|---|
| ε_pg | 放脚注、括号或章末工具箱 | 最低非中立性 / 起点不是完全归零 |
| Ψ_f | 放脚注、图表或理论工具箱 | 选择摩擦 / 改变路径时的阻力 |
| d-value | 放脚注、图表或工具箱 | 不可替代性重量 / 失去后不能等价替换的程度 |
| L₂ 硬化 | 第一次可写“背景变硬” | 旧选择变成后来的默认地面 |
| B 相 / C 相 | 尽量工具箱化 | 遮蔽阶段 / 可见性阶段 |
| P24-1 等预测编号 | 附录或理论章使用 | 第一项预测、第二项预测 |
| 组合签名 | 后置解释 | 多个现象必须一起出现，才算命中 |
| 拓扑学约束 | 附录或专业注 | 改变越深，绕开的成本越高 |

### D 类：专业附录术语，正文尽量不承担主线

这些内容可以保留，以维持理论严肃性，但不应成为畅销版正文主线。

| 内容 | 推荐位置 |
|---|---|
| Duhem-Quine 论点 | Q26 脚注或理论附录 |
| 拉卡托斯研究纲领 | Q26 脚注或理论附录 |
| 波普尔朴素证伪主义细分 | Q26 脚注或理论附录 |
| 库恩范式理论细节 | Q26/Q27 理论注 |
| 与康德先验哲学的完整对照 | 专业附录或章末注 |
| 与德勒兹、怀特海、海德格尔等传统的系统比较 | 专业附录 |
| 形式化预测表 | 附录、工具箱或专业版章节 |

## 3. 关键术语降噪模板

### 3.1 L0

#### 不推荐

```text
L0 是对象化尚未发生的可成为性位置，是前本体论条件。
```

#### 推荐

```text
在一个东西被叫出名字、划出边界、进入处理流程之前，它并不是空无，也不是一个已经完成的对象。它更像一种还没成形、但已经足以让成形发生的状态。

为了后文方便，本书把这个位置叫作 L0。
```

#### 使用原则

- 第一次出现时，不要只给定义；
- 不要让 L0 像神秘实体；
- 不要说“L0 里面有某种东西”；
- 可以说“L0 是为了标记那个还没对象化、但不是空无的位置”。

---

### 3.2 可成为性

#### 不推荐

```text
可成为性是对象化之前的前对象条件。
```

#### 推荐

```text
它不是已经摆好的可能选项，也不是空无。它只是说明：那里有某种还没有定形的差异，足以让后来的成形发生。
```

#### 使用原则

- 必须区别于“可能性”；
- 可能性像菜单，可成为性是菜单尚未印出来之前的状态；
- 避免把可成为性写成“所有可能性的仓库”。

---

### 3.3 最低非中立性 / ε_pg

#### 不推荐

```text
ε_pg 是 L0 内蕴的 primordial gradient。
```

#### 推荐正文

```text
起点不是一张已经写好的蓝图，但也不是完全平坦的零。它至少有一点点不均匀，使得生成不必从绝对归零中冒出来。本书把这种最小的不均匀叫作“最低非中立性”。
```

#### 推荐脚注 / 工具箱

```text
专业表达中，本书将“最低非中立性”记作 ε_pg。ε 表示它极小，pg 来自 primordial gradient。普通读者只需记住：它不是目的、不是物理力、不是善，也不是进步方向；它只表示起点不是完全归零。
```

#### 使用原则

- 正文优先写“最低非中立性”；
- ε_pg 第一次出现后，不要频繁回调；
- 不要让 ε_pg 成为读者必须背诵的符号；
- 所有边界说明压缩为一句：“它只拒绝归零，不规定方向。”

---

### 3.4 L1 / L2

#### L1 推荐写法

```text
某个方向不再只是模糊地可能，而是浮出了一个形。它被排开了其他方向，暂时成了“这个”。这就是本书后面说的 L1：一次成形的结果。
```

#### L2 推荐写法

```text
如果这样的结果没有消失，而是留下痕迹，后来者就必须在它留下的地面上继续行动。久而久之，它不再像一次选择，而像世界本来就这样。这就是本书后面说的 L2：过去选择退到背景之后形成的地形。
```

#### 使用原则

- L1 不要写成抽象层级编号；
- L2 必须和“背景”“地形”“默认条件”“移除成本”绑定；
- 尽量少用裸写“L2”，多写“L2 背景结构”或“已经退到背景的 L2”。

---

### 3.5 选择结构

#### 不推荐

```text
选择结构包含排除、定形、写入。
```

#### 推荐

```text
一个东西真正成形，至少发生了三件事：别的路被排开，它自己有了形，这个结果留下了痕迹。排开、有形、留下痕迹，三者合在一起，本书把它叫作“选择结构”。
```

#### 使用原则

- 面向普通读者时，先用“排开、有形、留下痕迹”；
- 专业段落再恢复“排除、定形、写入”；
- 避免让读者误解为“万物都有意识”；
- 每次扩展“选择”含义时，都要提醒：“这不是说它有意图或责任。”

---

### 3.6 选择摩擦 / Ψ_f

#### 推荐正文

```text
当一个人、一个制度或一个系统要离开旧路时，困难不只是心理上的不愿意，也不只是成本增加。旧路本身已经变成了地形。改变意味着要对抗过去留下的结构阻力。本书把这种阻力叫作“选择摩擦”。
```

#### 推荐脚注 / 工具箱

```text
专业表达中，选择摩擦记作 Ψ_f。普通读者不需要记住符号，只要记住：它指的是改变路径时，过去结构施加的阻力。
```

#### 使用原则

- 正文优先写“选择摩擦”；
- Ψ_f 只在 Q26、理论附录或图表中集中使用；
- 不要在叙事章节中反复出现符号。

---

### 3.7 d-value

#### 推荐正文

```text
有些东西失去了，可以换一个；有些东西失去了，未来的选择空间会被永久改变。这个差别不是偏好强弱，而是不可替代性的重量。
```

#### 推荐脚注 / 工具箱

```text
本书在专业表达中把这种不可替代性的重量记作 d-value。它不是“喜欢程度”，而是某个后果一旦发生或失去，未来选择空间被改变的深度。
```

#### 使用原则

- 正文优先写“不可替代性的重量”；
- d-value 不应在情感、价值、苦难章节中过早出现；
- 只有在需要严肃区分“偏好强度”和“不可替代性深度”时才使用。

## 4. 每章执行检查表

每章改写前，先回答以下问题：

1. 本章普通读者入口是什么？
2. 前 1000 字是否能不依赖专业术语读懂？
3. 本章必须保留的 1–3 个核心术语是什么？
4. 哪些术语只是增加理论气氛，并不增加解释力？
5. 哪些符号可以移到脚注或章末工具箱？
6. 是否有连续三句以上都是抽象定义？如果有，必须打断。
7. 是否有跨领域例子被写成“证明”？如果有，改成“显影”。
8. 最强反对者是否贴住本章核心概念，而不是套话？
9. 章末是否需要“专业读者注”？
10. 删除术语后，论证是否仍然成立？如果成立，优先删术语。

## 5. 章节类型与降噪策略

### 5.1 第一幕：概念奠基章

适用章节：Q00–Q04。

目标：让普通读者进入“世界不是已经完成”的问题。

策略：

1. 入口故事必须强；
2. 不要过早堆术语；
3. L0、可成为性、最低非中立性必须白话先行；
4. 符号全部后置；
5. 避免让读者误以为本书在提出神秘本体。

### 5.2 第二幕：生成机制章

适用章节：Q05–Q11 左右。

目标：让读者理解“对象、选择、稳定、秩序如何形成”。

策略：

1. 保留“选择结构”“锚定”“地形”等核心词；
2. 每个机制都要对应一个生活、身体、制度或技术例子；
3. 不要让排除、定形、写入变成僵硬三分法；
4. 多写“这个机制让什么变得不可撤回”；
5. 少写抽象定义。

### 5.3 第三幕：主体、价值、意识章

适用章节：Q12–Q18 左右。

目标：把理论从宇宙论/存在论拉回人的经验。

策略：

1. 减少本体论术语；
2. 增加承诺、羞耻、爱、损失、责任、记忆、身体经验；
3. “价值不是偏好”要优先用不可替代性经验解释；
4. d-value 后置；
5. 意识章避免变成认知科学或泛心论防守稿。

### 5.4 第四幕：秩序、苦难、共同体、AI、方向章

适用章节：Q19–Q25 左右。

目标：把 SRT 转化为读者能用于理解现实的分析框架。

策略：

1. 保留脚手架/牢笼、遮蔽、方向、共同体、AI 地形参与者等强表达；
2. 技术符号弱化；
3. 不要把跨领域材料当证明；
4. 每章只保留一个主反对者；
5. 避免每章都用同一种“这只是换语言”的反驳。

### 5.5 理论自检章

适用章节：Q26–Q28。

目标：保留理论严肃性，同时给普通读者可跳读路径。

策略：

1. 章节开头明确提示：“以下是理论压力测试”；
2. 主线读者可以读白话结论；
3. 专业读者继续读预测、失败条件、理论自反；
4. 拉卡托斯、蒯因、Duhem-Quine 等外部理论史内容尽量脚注化；
5. 六项预测可以保留，但正文先给一张白话总表。

## 6. 术语降噪替换词库

| 高压表达 | 优先替代表达 |
|---|---|
| 前本体论条件 | 在对象出现之前必须有的条件 |
| 结构位置 | 一个不能删掉的位置 / 一个必须被承认的位置 |
| 对象化操作 | 被叫出名字、划出边界、可以处理 |
| 可重复遭遇性 | 下次还能把它当作同一个东西遇见 |
| 生成前场 | 东西还没成形之前的那一层 |
| 结构不等价 | 起点不是完全平的 / 各个方向不是严格一样 |
| 选择摩擦 | 改变旧路时遇到的阻力 |
| L2 硬化 | 旧选择变成背景 / 地面变硬 |
| 不可替代性 | 失去后不能用别的东西补上的重量 |
| 后果回流 | 做出的事回来改变做事的人 |
| 组合签名 | 几个现象必须一起出现才算命中 |
| 拓扑学约束 | 改变越深，绕开的成本越高 |
| 可证伪性 | 什么情况会让这套理论必须认错 |
| 理论自反 | 这套理论也要检查自己会不会变成牢笼 |
| 主体沉积 | 人是在后果、记忆、责任中慢慢变厚的 |

## 7. 技术符号使用规则

### 7.1 正文符号上限

原则上，每章正文最多只允许一个技术符号承担记忆功能。

示例：

- Q03 可以保留 L0；
- Q04 正文优先保留“最低非中立性”，ε_pg 后置；
- Q05 正文保留“选择结构”，不新增符号；
- Q26 可以集中出现 Ψ_f、d-value 等，但要明确这是理论压力测试章。

### 7.2 符号第一次出现规则

所有符号第一次出现时必须满足：

1. 前文已有白话解释；
2. 符号后紧跟一句“普通读者只需要记住……”；
3. 不在同一段落引入第二个符号；
4. 不用符号结尾，要用白话结尾。

### 7.3 符号复现规则

同一符号再次出现时，至少每隔若干页要用中文提醒一次含义。

示例：

```text
ε_pg，也就是前面说的“起点不是完全归零”……
```

不要写成：

```text
因此 ε_pg 在 L0 中触发后续 L1 的……
```

---

## 8. 章末“理论工具箱”模板

对于术语密度较高章节，可在章末增加如下模块：

```markdown
## 理论工具箱：本章术语怎么记

- **L0**：东西还没成形，但不是空无的位置。
- **可成为性**：不是已经列好的可能性，而是可能性菜单尚未印出来之前的状态。
- **最低非中立性**：起点不是完全归零，但也没有预设方向。
- **ε_pg**：最低非中立性的专业记号；普通读者不需要记住符号。

一句话总结：本章不是说“万物背后有一个神秘东西”，而是说：如果对象不是从绝对虚无中冒出来，就必须承认对象化之前有一个不是对象也不是虚无的位置。
```

工具箱规则：

1. 不超过 300–500 字；
2. 只收本章必要术语；
3. 不扩展新理论；
4. 不做长篇文献对照；
5. 普通读者可以跳过，专业读者可以用来回看。

---

## 9. 三章样板改写优先级

后续批量改写前，先做三章样板。

### 9.1 Q03《前对象场》

目标：测试最抽象概念如何大众化。

重点：

1. L0 不要神秘化；
2. “前对象场”先解释为“还没成形的真实”；
3. 减少“前本体论条件”“结构位置”的连续出现；
4. 保留肿块、歌曲等入口例子；
5. 章末增加理论工具箱。

### 9.2 Q04《最低非中立性》

目标：测试技术符号如何降级。

重点：

1. 正文主词使用“最低非中立性”；
2. ε_pg 移到脚注或工具箱；
3. primordial gradient 不进入正文主线；
4. “公设”先解释成“本书先放下的最小承诺”；
5. 反误读护栏压缩，不要让护栏压过主线。

### 9.3 Q05《选择不是挑选》

目标：测试核心术语如何保留锋利度。

重点：

1. 衣柜例子保留并强化；
2. “排除—定形—写入”先翻译成“排开、有形、留下痕迹”；
3. “选择结构”作为后置命名；
4. 明确“这不是说雪花有意识”；
5. 表格可以保留，但要减少过多技术分类。

## 10. 后半部分特别规则

### 10.1 Q26 可证伪性

Q26 可以保留较高专业密度，但需要改变读者定位。

建议开头加入类似提示：

```text
如果你只是跟随本书主线，读到这里已经足够。下面这一章更像是本书对自己的压力测试：它要问的不是 SRT 还能解释什么，而是什么情况会让 SRT 必须认错。
```

处理原则：

1. 六项预测先给白话总表；
2. 专业细节后置；
3. 外部科学哲学人物脚注化；
4. 每项预测都要说清楚“普通读者该记住什么”；
5. 不要让 Q26 变成专业审稿文。

### 10.2 Q27 理论自反

Q27 的大众潜力很强，因为“理论也可能变成牢笼”本身很好懂。

处理原则：

1. 保留“好用的锤子”入口；
2. 保留“万能钥匙化”“批评吸收”“正统性压力”；
3. L2 等术语后置；
4. 强化普通读者能用的自检问题：
   - 我是否只能用这一套话说话？
   - 我是否把所有反对都解释成对方没懂？
   - 我是否开始用术语替代经验？

## 11. 全书统一口径

以下表达应成为全书大众版的稳定口径。

### 11.1 SRT 的白话总命题

```text
世界不是先完整摆好，然后才发生变化。许多看起来“本来如此”的东西，是在生成中成形、留下痕迹、变成背景之后，才像一个已经完成的世界。
```

### 11.2 对象化的白话口径

```text
一个东西成为对象，不只是被贴上名字，而是获得边界、身份、处理路径和再次被遇见的方式。
```

### 11.3 选择的白话口径

```text
选择不只是最后一刻从菜单里挑一个。更早的选择发生在菜单如何形成、哪些东西能进入视野、什么结果会留下痕迹。
```

### 11.4 价值的白话口径

```text
价值不是偏好强度，而是有些后果回来之后，未来不能再像从前那样继续选择。
```

### 11.5 秩序的白话口径

```text
秩序不是凭空站在那里。它是过去选择留下的痕迹互相加固，最后退到背景里，变成后来者脚下的地面。
```

### 11.6 遮蔽的白话口径

```text
遮蔽不是简单看不见，而是你看见世界的方式，已经被某种结构提前安排好了。
```

### 11.7 方向的白话口径

```text
方向不是预先写好的终点，而是某种秩序在维持、扩展或消耗自身时显出来的结构倾向。
```

## 12. 评估标准

一章完成降噪后，用以下标准判断是否合格。

### 12.1 普通读者标准

一个没有哲学训练、但愿意读思想书的读者，应当能够：

1. 读懂本章要反对的旧图景；
2. 读懂本章新提出的问题；
3. 记住一个白话结论；
4. 不因为符号或术语中途退出；
5. 即使跳过脚注，也不影响主线理解。

### 12.2 专业读者标准

一个哲学、理论或跨学科读者，应当能够：

1. 看出术语背后的结构位置；
2. 追踪概念之间的递进；
3. 找到边界声明；
4. 看到最强反对者；
5. 不觉得书被改成鸡汤或泛泛科普。

### 12.3 作者标准

改写后必须满足：

1. 不牺牲 SRT 的核心命题；
2. 不把理论改成心理学鸡汤；
3. 不把哲学问题改成励志表达；
4. 不为了通俗而抹掉最强反对者；
5. 不为了流畅而删除必要边界。

## 13. 后续执行建议

### 第一轮：只做术语降噪

不改章节结构，不重排问题链，只处理：

1. 术语第一次出现顺序；
2. 技术符号后置；
3. 高压表达替换；
4. 章末工具箱；
5. 开头 1000 字的可读性。

### 第二轮：做三章样板

优先处理：

1. Q03《前对象场》；
2. Q04《最低非中立性》；
3. Q05《选择不是挑选》。

三章样板通过后，再扩展到全书。

### 第三轮：全书术语一致性扫描

扫描词：

```text
L0 / L1 / L2 / ε_pg / Ψ_f / d-value / 本体论 / 前本体论 / 结构位置 / 生成前场 / 选择摩擦 / 不可替代性 / 组合签名 / 拓扑学约束 / 研究纲领 / 可证伪性
```

每次出现都问：

> 这个词是否非出现不可？如果换成白话，损失的是精度，还是只是损失理论气氛？

如果只是损失理论气氛，优先降级。

## 14. 后续改写提示词

逐章改写时可使用以下提示词：

```text
你现在是《从存在到秩序》的大众化改写编辑。

任务：在不削弱核心论证的前提下，降低本章术语门槛。

请对以下章节执行：

1. 保留原有问题链和核心概念。
2. 不删除理论锋利度，但改变术语出现顺序。
3. 正文优先使用普通读者能懂的表达。
4. 专业术语第一次出现前，必须先用生活语言解释。
5. L0、L1、L2、ε_pg、Ψ_f、d-value 等符号不得作为正文推进的主要抓手。
6. 技术符号优先移到脚注、括号、章末“理论工具箱”。
7. 每章开头前 1000 字尽量不出现高压术语。

10. 输出：
   一、术语风险诊断
   二、应降级术语清单
   三、需要保留的核心术语
   四、逐节修改建议
   五、改写后的关键段落示范
   六、是否适合进入全书批量改写
```

## 15. 一句话执行口令
