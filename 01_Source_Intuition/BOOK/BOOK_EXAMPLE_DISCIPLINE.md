# BOOK_EXAMPLE_DISCIPLINE.md

> 每章例子选择的约束规范。目标：让全书读感为“一本本体论书，能解释社会与政治现象”，而非“一本社会/政治哲学书，借用了本体论语言”。

---

## 核心规则

**每个核心概念的首次出现，必须用非社会例子建立本体论骨架；社会/政治/制度例子只作为第二或第三显影层。**

“非社会”指：物理、地质、生物、身体感知、神经/认知、语言习惯（语法级，非制度级）。
“社会”指：货币、法律、央行、国家、城市、平台、算法治理、权力结构、社会建构论、制度设计、政治哲学。

---

## 逐节位约束

### §1 沉浸式开场

| 优先级 | 材料类型 | 示例 |
|--------|---------|------|
| 首选 | 身体/知觉/物理/地质 | 台阶踩空、峡谷与雨痕、走路时的想法 |
| 可用 | 日常人际（个人级，非制度级） | 朋友说的一句话、伤人的话 |
| 避免 | 货币、法律、国家、城市、平台 | — |

§1 是读者的身体入口。身体和物理感知优先。若用人际例子，限于两个人之间的具体场景，不引入制度。

### §3 核心概念定义

**硬规则：核心概念第一次被定义/展开时，第一个具体例子必须是非社会的。**

| 递进 | 材料类型 |
|------|---------|
| 第一例 | 物理/地质/生物 |
| 第二例 | 认知/语言/身体 |
| 第三例（可选） | 社会/制度 |

每个子概念（如“承重”“支付”“再入场”）各自遵守此递进。不能在子概念 A 用了物理例子之后，子概念 B 直接跳到制度例子。

### §4–§5 对手章节

**社会材料可以作为主例。** 因为很多强反驳本来就来自社会建构论、制度经济学、权力理论、功能主义。但：

- 在反驳前后需有一句锚定句，明确：社会领域是本章概念的一种显影，不是概念的来源。
- 反例和类比中，尽量保留至少一个非社会对照（如蝴蝶效应 vs 法律颁布）。

### §6 跨领域显影

**固定排序原则：**

```
物理/地质/生物 → 神经科学/认知 → 语言/文化 → 社会制度
```

社会制度段落放在最后。若某章不需要社会制度段落，不必强加。

每个跨领域段落开头的“在 **X** 里”标记必须清晰。段落之间用空行分隔。

### §7 边界守卫

不做限制。§7 的功能是防误读，社会材料在此处是合适的（“锚定不等于记录”“不可逆不等于宿命论”等）。

### §8 桥接

收尾句尽量用非社会意象。若本章核心例子有物理/地质/生物的主线（如峡谷、河流），§8 应回扣该主线，不要在收尾时突然切换到制度材料。

### 操作接口 & 微型示范

**微型示范可以用社会例子。** 这是读者的应用场景，社会/商业/制度是自然的落地层。但操作接口的三问/四问框架本身应当是中性的（适用于物理和社会），不要让框架本身只对社会场景有意义。

---

## 禁止清单（在概念首次定义的位置）

以下材料不得作为核心概念的**第一个**例子：

- 货币 / 法币 / 央行
- 法律 / 法典 / 判例
- 国家 / 政权 / 主权
- 城市规划 / 交通体系
- 平台 / 算法 / 数字治理
- 权力 / 布尔迪厄 / 资本
- 社会建构论 / 社会契约

这些材料**可以出现在**：§3 的第三例、§4–§5 对手节、§6 最后一段、§8 微型示范。

## 全书气质梯度

| 位置 | 气质 | 主要材料 |
|------|------|---------|
| 第一幕 (Q01–Q04) | 纯本体论 | 知觉、物理、生物、数学结构 |
| 第二幕 (Q05–Q10) | 本体论 + 自然过程显影 | 河流、峡谷、生态、神经、语言习惯；社会例子作为次级显影 |
| 第三幕 (Q11–Q16) | 本体论 → 主体/认知 | 可逐步增加认知、语言、文化材料 |
| 第四幕 (Q17–Q22) | 本体论 → 共同体/制度 | 社会制度材料可升为主例，但每章仍需有非社会锚点 |
| 尾声 (Q23–Q26) | 本体论 → 伦理/方向 | 政治、伦理材料自然密集，但核心概念仍先用结构语言定义 |

**关键转折点：** 社会制度材料从 Q17 开始可作为核心概念的第一例，但前提是该概念本身就是关于社会结构的（如“共同体”“制度”“正当性”）。即便如此，定义框架仍应使用中性的结构语言（摩擦分配、厚度、承重），不能用纯社会学术语（权力、资本、霸权）来定义本体论概念。

## 拟人化纪律

描述非意识过程（河流冲蚀、细胞分化、量子退相干）时：

- 用“路径被写入地形”“方向被排除”，不用“河流选择了左岸”“细胞决定成为肌肉”
- “选择”用于非意识过程时，第五章已正式扩展了这个概念。但后续章节仍应注意：描述具体自然过程时优先用被动/中性句式，减少拟人感。
- “永久”一词在生物语境中须谨慎——表观遗传标记是“长期稳定抑制”而非“永久沉默”。

---

## 科学精度底线

- 地质年代不可混淆（岩层年龄 ≠ 地貌年龄；峡谷切割 ≠ 底层片岩形成）
- 量子退相干只做“提示性类比”，不做“机制等同”
- 神经科学例子用“提示”“让结构更可见”，不用“证明了本章的主张”
- 生物学例子区分“必然发生”和“统计显著的偏向”
