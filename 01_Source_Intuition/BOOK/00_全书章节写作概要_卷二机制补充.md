# 《从存在到秩序》大纲补充：卷二机制厚度

> 目的：在主大纲“卷二：选择的本性”基础上，补充第 7–13 章的机制性写作要求，防止卷二继续沿用卷一的纯本体论散文节奏，也防止过早滑入社会批判、AI 专章或形式层证明。

---

## 0. 卷二新增总任务

主大纲中，卷二任务为：

> 从卷一的生成链，转入“选择如何运作”。这里要把选择从哲学反转变成可继续承重的机制直觉，但仍保持书稿层，不写成 formal layer。

建议补充为：

> 卷二要让“选择”获得机制厚度：不是只说选择不是挑选，而是逐步说明地形、算子、排除、不可逆、摩擦、可支付性、路径如何共同决定某些可成为性进入显现，另一些则被压低、延迟、残留或回返。

卷二总体动作链建议：

```text
L2 作为下一次选择的天气
→ 地形改变选择摩擦
→ 选择算子把可成为性压成显现
→ 排除制造阴影与张力残留
→ 不可逆让世界获得历史厚度
→ 本体论摩擦说明现实不会免费成形
→ 可支付性决定某些路径能否真正进入世界
→ 路径成为后来选择的坡度
```

## 1. 第 7 章补充状态

**当前建议状态**：draft_v3 可作为卷二开篇工作稿。

**新增锚定句**：

- L2 不只是选择的结果。它是下一次选择的天气。
- 地形不是命令。地形是坡度。
- 命令取消选择。坡度改变摩擦。
- 默认不是中性背景。默认就是被预先降阻的现实。
- 筛选发生在选项之间。预裁剪发生在选项之前。
- 再选择不是意志强度问题。再选择是摩擦能否被支付、后果能否被承接、新路径能否被锚定的问题。
- 地形有效时，常常不被看见。它正是因为有效，才退到了背景里。

**未来 revision 注意**：

- AI 段只保留为 pre-pruning 伏笔，不展开卷六问题。
- 生态段只作为存在共成体远端伏笔，不提前变成生态哲学章节。
- 不要把第七章改成完整社会压迫论或自由意志论。
- 第七章的核心承重是：地形如何进入选择发生之前。

## 2. 第 8 章写作补充：选择算子

主大纲已有第 8 章 brief。建议补充：

**本章应接住第 7 章最后一句**：

> 地形之所以能选择人，不是因为它有意志，而是因为它已经进入了那个把可能性压成现实的动作。这个动作需要一个名字：选择算子。

**第 8 章不可只解释术语**。它要回答：

1. 为什么“地形”必须进入选择算子，而不是停留在背景比喻？
2. 为什么选择算子不是主体、机器、算法、意志或物理力？
3. L2、身体、关切、代价、历史、环境如何作为参数改变定形？
4. 为什么显现不是从 L0 取出，而是被定形出来？

**建议动作骨架**：

```text
接触窗口 → 参数化定形 → 显现
```

或：

```text
可成为性被接触 → 被约束 → 被压缩 → 成为可遭遇形状
```

## 3. 第 9–13 章机制深度提醒

### 第 9 章：排除

不要只写“选择也意味着放弃”。要写：

> 被排除者如何以张力、阴影、机会成本、遮蔽、未释放压力的形式改变后续地形。

可隐性接入：心理残留、制度外部化、生态外部性，但不要抢卷四/卷五。

### 第 10 章：不可逆性

不要只写“覆水难收”。要写：

> 撤回为什么不是逆操作，而是在新地形上的再选择。

AI rollback、合同、关系修复可以做压力点，但不要提前变成 AI 技术章。

### 第 11 章：本体论摩擦

不要把 Ψ_f 公式化。要从“现实不会免费成形”进入，说明：

> 摩擦不是结构面对的敌人；摩擦是结构能够成立的条件。

可接身体训练、制度维护、关系修复、学习成本。

### 第 12 章：可支付性 / 路径预算

若主大纲后续需要细化，本章应回答：

> 为什么某些路径形式上可选，却实际上不可支付？

这章可承接第 7 章“再选择需要地面”。

### 第 13 章：路径与回流

卷二收束应回到：

> 当选择、排除、不可逆和摩擦反复发生，路径如何形成？路径如何进入后续主体和价值章节？

这章应把卷二推向卷三：主体不是纯源头，而是路径回流中的承重位置。

## 4. 隐性哲学 / 科学支撑的放置原则

卷二应允许“隐性支撑”，但不在主文堆名字。

| 主题 | 可隐性借用的方向 | 正文写法 |
|---|---|---|
| 地形有效时不可见 | 现象学 / 工具背景性 | 地形有效时，常常不被看见。它正是因为有效，才退到了背景里。 |
| 自我作为地形 | habitus / 习性结构 | 旧路已经被感受为“我”。 |
| 形式自由 vs 实质再选择 | capabilities / 能力进路 | 形式上的自由只说：你可以选。真实的再选择还要问：你有没有能力让那个选择进入世界，并让它留下。 |
| 身体坡度 | 神经与习惯回路 | 反复走过的路会在神经、姿势、注意和反应速度里变得更顺。 |
| 默认通道 | 行为经济学 / 默认效应 | 默认不是中性背景。默认就是被预先降阻的现实。 |
| 预裁剪普遍性 | 生态位构建 | 生物也会通过巢穴、路径、土壤、遮蔽和迁徙路线改变后来生命面对的选择压力。 |
