# Author Re-entry Cycle 1 — fourth live author adjudication

> **性质**：本文件只记录 2026-09-05 Cycle 1 对 `S1 portable causal memory` 与 `S2/S3 history-constituted One` 分叉的作者直接裁决。它不是 canonical ontology owner，不自动修改 L0 / Core / Core_Law。
>
> **记录原则**：作者本轮只回复选项字母 `b`。下文必须保留该回复所对应的原问题语境，不得把记录者的展开自动当成作者新增定义。

## 原分叉

作者被要求在以下两种读法中裁决：

```text
A / S1 portable causal memory

只要历史真实进入这个 One，
并因果性改变这个 One 后面的 Selection，
它就已经开始成为 Bearer。

即使整套记忆 / 参数可以复制给另一个 fresh One，
也不影响原 One 已经是 Bearer。
```

versus

```text
B / S2-S3 history-constituted One

只有当历史不仅改变 Selection，
而且历史参与持续重构、维持那个
“以后仍然从这里继续选择”的 One 本身，
才真正叫“沉积在一”。
```

## 作者回答

> **b**

因此本轮明确作者裁决为：

```text
B / S2-S3 direction selected
```

## 最小作者许可范围

该裁决直接允许将此前作者原话：

> `当历史痕迹沉积在一时，变为Bearer。`

进一步限定为：

```text
仅有 portable causal memory 不足；
“沉积在一”要求更强的 history-constituted relation。
```

换言之，当前作者许可支持：

```text
history changes later Selection
+
history participates in recurrently reconstituting / maintaining
that One from which later Selection continues
```

而不是只支持：

```text
history is stored inside a One
+
history changes later output
```

## 仍不得自动推出

本轮作者裁决没有自动定义：

```text
history-constituted One = canonical Bearer definition
reconstitution = autopoiesis
reconstitution = self-maintenance
reconstitution = numerical identity
reconstitution = non-outsourcing
reconstitution = Stable ISP
reconstitution = consciousness
```

也没有解决 copy / fission / branching 下的 numerical identity。

## 对 Cycle 1 的直接影响

本轮作者裁决使 formation-time discriminator 获得作者许可：

该测试仍是 bridge / proposal-level consequence，不因作者选择 B 自动成为 canonical theorem 或 empirical prediction。
