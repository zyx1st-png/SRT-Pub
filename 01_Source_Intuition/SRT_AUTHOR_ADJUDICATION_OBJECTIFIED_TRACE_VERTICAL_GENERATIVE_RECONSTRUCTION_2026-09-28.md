\[

## D. Vertical generation becomes the main unit of analysis

The preferred research object is not a layer label but an edge:

\[
A\xrightarrow{?}B
\]

For a candidate L1→L2 relation, the edge should be decomposed into at least:

~~~text
source actuality / organization
-> transformation or writeback
-> carrier or distributed retention
-> survival / reconstitution
-> later efficacy
-> change in later generative conditions.
~~~

The critical distinction remains:

~~~text
occurrence
!= retained generative efficacy.
~~~

Therefore a valid L1→L2 account must identify how a present organization becomes later-effective history.

## F. L0→L1 and L1→L2 should not be forced into one formal engine

### F1 — L1→L2

The author accepts diffusion-like models as a plausible family for:


A candidate implementation may model history as changing drift, transition geometry, accessibility, or landscape:

\[

### F2 — L0→L1

Standard diffusion already assumes:

- a state variable;
- a coordinate or representation space;
- admissible trajectories;
- some topology / neighborhood or score geometry.

Therefore it is a poor default for the stronger constitutive question:

> how do the operative distinctions, variables, boundaries, candidate relations or comparison structure become determinate in the first place?

Provisional method rule:

~~~text
do not use an implementation that presupposes the target cut
as if it had explained the genesis of that cut.
~~~

The L0→L1 route should for now be specified by constitutive requirements rather than forced into a single algorithmic family.
