# Author correction — GRG should vertically reconstruct mature domain objectifications

## 0. Role

This record preserves the author's 2026-09-24 correction during the bounded evolution / population-genetics reconstruction.

It is:

- direct author source-intuition provenance;
- noncanonical;
- not a GRG v0.4 owner;
- not a canonical SRT edit;
- not a claim that horizontal science is false or inferior;
- not merge authorization for PR #1039.

## 1. Direct author anchors

### 1.1 Target is not source-domain novelty hunting or term matching

## 2. Faithful direction

**[A0-P]**

The author correction implies:

1. GRG cross-domain work is not primarily a hunt for biological / economic / physical facts that the source discipline has not yet discovered.
2. GRG terms are not a dictionary whose entries must be matched to source-domain objects.
3. Mature source objects, variables and models should first be treated as successful horizontal objectifications that stabilize particular questions, grains and boundaries.
4. GRG's vertical use is to decompose / recut those stabilized objects and reconstruct the generative relations by which differences become manifest, consequential, retained, reorganized, composed and fed back into later generation.
5. The intended output may therefore be a new **vertical organization of already mature source knowledge**, even when every local mechanism remains source-owned.
6. Reach is one possible dimension of that vertical organization. It must not substitute for the wider architecture of differentiation, support, history, actualisation, sedimentation, condition rewriting, composition, scale and re-entry.
7. Component-level source absorption does not by itself settle whether the **integrated vertical reconstruction** is absorbed. The comparison target must be the materially same integrated organization, not merely the presence of each component somewhere in the literature.

## 3. Guard against a new self-sealing route

This correction does not mean any GRG redescription counts as gain.

A vertical reconstruction still has to show, in source-checkable terms, at least one of:

- a previously implicit interface among mature source models;
- a distinction that matters under intervention / counterfactual stress;
- a nontrivial dependency that survives legitimate recuts;
- a useful new integration, diagnostic, failure condition, prediction or research question.

If removing GRG labels leaves only a generic process chain, the reconstruction is redescription only.

If a mature source framework already organizes the same integrated structure in materially the same way, the vertical reconstruction is absorbed.

## 4. Immediate evolution-route consequence

For the current evolution / population-genetics case:

```text
DO NOT ask primarily:
  which biological object is reach / support / Selection / reconstruction?
  which individual GRG distinction is novel to biology?

DO ask:
  what horizontal cuts do population genetics, developmental robustness,
  fitness / epistasis, evolvability / CGV and niche-construction stabilize?

  when those cuts are decomposed, what continuous generative organization
  connects variation formation / retention, manifestation, consequence,
  population realization, sedimentation and later-condition rewriting?

  does that integrated vertical organization add coherence or testable
  structure beyond the mature source frameworks considered together?
```
