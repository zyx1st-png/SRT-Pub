# FRR × SRT 定向陪读：actualization / self-determination / history

## 0. 本轮问题

本轮不做 FRR 全书综述，只核对 Epperson 通信后最承重的四个问题：

1. FRR 是否只有 local/global constraints，还是也有真正的 actualization / novelty？
2. actual occasion 的 “subjective” 面究竟更接近 valuation，还是 local-context / self-determination？
3. actualized event 是否进入后续历史并改变 future contexts？
4. 在这些重叠之后，SRT 的 primitive Selection 还剩什么未被 FRR 竞争语汇重构？

---

## 1. Source-derived：FRR 明确有 actualization，而非纯静态约束

### Chapter 2, printed pp. 88–90（PDF pp. 106–108）

FRR 把 becoming occasion / quantum measurement-in-process 的 **subjective standpoint** 对应为 local Boolean context。潜在 internal relations 在该局部 context 下经逻辑整合与 negative selection，由 pure-state / conceptual-phase 的未协调潜能进入 mixed-state / comparative-phase 的相互排斥且穷尽的 probable outcomes。

该段还把 Whitehead 的 “valuation up / valuation down” 在量子语境中具体化为 probability valuation。

**Source-level结论：**

```text
subjective standpoint / local Boolean context
and
valuation of subjective forms / probable outcomes
are related but distinguishable roles.
```

因此不能把 FRR 的 subjective side 直接压成 SRT 的 stake-bearing valuation。

---

## 2. Source-derived：local context 被当作 actual occasion 的 constitutive self-determination

### Chapter 4, printed pp. 164–165（PDF pp. 179–181）

FRR 明确说 actual occasion 的 local context / subjective standpoint 对 actual occasion 是 **constitutive** 的，并称这种 indexical context 为 “self-determined”。

关键限制也同样明确：

- 这不是经典意义上的 experimenter 任选装置就能穷尽的 “choice”；
- 每一个 quantum actual occasion 有自己的 local context；
- 该 local context 虽非 externally determined，却由它与 dative world 的 internal relatedness 所条件化；
- compatible local Boolean contexts 的 overlap 为这种 local context 提供约束背景。

**比较压力：**

这已经非常接近 SRT 想避免的“先放一个 selector object，再让它选”的反面：FRR 也把 local contextualization 放到 event 自身的构成中，而不是交给一个外在 chooser。

因此：

```text
FRR self-determination
cannot be dismissed as ordinary agent-choice;
SRT cannot claim a difference merely from "no prior chooser".
```

---

## 3. Source-derived：FRR 有清楚的 actualization -> later datum -> global formation

### Chapter 3, printed pp. 133–134（PDF pp. 150–151）

FRR 明确写到：past is closed、future is open；actualized quantum fact 对 logically/temporally subsequent predication 具有 causal efficacy，并把 universe as “enduring structure” 描述为随新 predicative facts 离散增补的 **serial historical evolution of totality**。这一段比单纯的 “subsequent datum” 更直接地支持 FRR 具有 global-history / historical-evolution 结构。

### Chapter 4, printed pp. 165–166（PDF pp. 181–182）

FRR 明确说：actualized occasion 会作为 datum 与 subsequent occasions-in-process 发生 internal relation。但这里的 **subsequent 首先是 logical / mereotopological subsequence，并不必然是 temporal subsequence**；时空意义上的先后被作者视为这一更基础关系的特化。因此，不能把 FRR 的 subsequence 无限定地等同于 SRT 的时间性 L2 / T_dir 结构。

### Interlude, printed pp. 206–209（PDF pp. 220–224）

FRR 将 actual occasion 的两面明确分开：

- subjective aspect：actual occasion 决定 / 实例化自己的 local context，并在其中整合 potential internal relations；
- objective / superjective aspect：一旦 actualized，它成为后续 actual occasions-in-process 的 datum。

进一步，Boolean germ 被描述为 generative structure，会随每个 quantum actual occasion 增长；global 不是预定义完成整体，而是通过 discrete, internally related predicative actualizations 持续形成。

### Chapter 8, printed p. 269（PDF p. 281）

“many become one and are increased by one”的 sheaf-theoretic reading是：

- compatible relational information 被 gluing 成 novel quantum event；
- 新事件加入 totality；
- 新 totality 连同该事件的 compatible local context，对后续 local contexts 施加新的 compatibility constraints；
- 这一过程被明确描述为 ontological process，而不是对 fixed global totality 的 epistemic restructuring。

### Chapter 11 附近（PDF p. 386）

FRR 把 germ 从 event 到 event 的连续 extension 表述为 historical process，并用 sheaf-theoretic section 的连续 functional representation 描述；但该段先在空间拓扑的建模语境中给出这一表达，随后才说可 **analogically transfer** 到量子域。因此这里支持“FRR 有历史/生成连续性的形式资源”，但不能未经额外核对就把空间拓扑中的每一项 historical-process 语义直接等同于量子物理中的时间历史。

**Source-level结论：**

```text
FRR contains:
actualization
-> objective incorporation
-> subsequent datum
-> further contextual constraint
-> historical / global formation.
```

所以旧比较：

```text
SRT has writeback/history; FRR does not
```

应废弃。

## 4. SRT-side reorganization：现在应该比较什么

在 #1031–#1033 后，SRT 当前最重要的分离是：

```text
Selection occurrence
!= {retained historical efficacy / sedimentation / generative inheritance}.
```

而 FRR 也有：

```text
actual occasion-in-process
-> actualized occasion
-> subsequent datum / global augmentation.
```

因此当前真正的比较不是“谁有 history”，而是：

### A. occurrence burden

FRR 的 self-determined local contextualization + germ evaluation + actualization，是否已经重构了 SRT primitive Selection occurrence 的全部作用？

**Status: OPEN.**

当前不能写成 SRT residual，更不能写成 FRR 缺失。

### B. historical efficacy burden

双方都存在 actualized past conditioning later process 的结构。

**Status: strong overlap / candidate reorganization.**

SRT 不应再用一般性 “writeback” 作为相对 FRR 的差异声明。

### C. persistence / revisability / resistance / cost

已核对段落支持“later constraint”，但尚不足以建立 FRR 是否具有：

- 不同 sediment 的持久性强弱；
- revision / undoing 的不对称难度；
- 类似 SRT friction / cost 的量；
- 支撑结构损坏后的历史恢复代价。

**Status: NOT YET ESTABLISHED FROM REVIEWED PASSAGES.**

这仍是可继续陪读的问题，但不能写成 absent。

### D. subjective aim / valuation

FRR 已把 subjective standpoint/local context、probability valuation、self-determination 放在不同但相连的角色中。

**Status: SRT 的旧 “micro-valence vs stake-bearing valuation” 二分不应继续作为首要比较框架。**

更好的问题是 aim / self-determination 是否属于每个 actual occasion 的 constitutive unity，而非 SRT downstream concern。

## 5. 当前最小 comparative question

建议以后给 Epperson 的主问题只保留：

> Does the self-determination of an actual occasion already exhaust what SRT calls primitive Selection occurrence, or does actualization still carry an event-level burden not exhausted by Boolean contextualization, valuation, and local-to-global gluing?

这是一项 **competitor-vocabulary pressure question**，不是 novelty claim。

可能结果应保持对称：

```text
FRR fully reconstructs the burden
-> SRT should inherit / reorganize and narrow its primitive claim;

partial reconstruction
-> identify the exact remaining burden before any residual label;

different category
-> clarify the type mismatch rather than force equivalence;

insufficient evidence
-> remain OPEN.
```
