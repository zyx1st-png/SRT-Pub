## A-3 — meaning of A0-Q1 “从背景进入前景成为对象”

**Decision: A-3(c), with an explicit two-level interpretation.**

The author's phrase “成为对象” must **not** be deleted or silently weakened to generic foregrounding.

The intended structure is:

### A-3.1 Primary / pre-reflective objectification

~~~text
background gate / deformation
-> becomes a phenomenally available object / qualitative formation
~~~

This is the primary sense intended in the author's qualia statement.

It does **not** require explicit conceptual reflection, linguistic naming or metacognition.

Examples may include pain, hunger, color quality or a diffuse “something is wrong”.

Working labels only:

~~~text
phenomenal objectification
pre-reflective objectification
~~~

### A-3.2 Reflective / explicit gate-objectification

A stronger later step is:

~~~text
the gate / expectation / category / deformation itself
-> becomes an explicit object of reflection
-> may become deliberately revisable
~~~

This supports stronger L0-facing freedom.

Therefore keep:

~~~text
phenomenal objectification
!= reflective objectification
~~~

but reject:

~~~text
phenomenality != objectification tout court
~~~

The independent review is correct that the earlier machine rewrite had changed the author's meaning too strongly.

### A-3.3 Canonical wording guard

“foreground”, “manifestation” and “objectification” are overloaded across the repository.

Future patch prose must distinguish:

~~~text
manifest_OF
= canonical One-Formation manifestation / relative-background reading;
  not phenomenal by itself

foreground_obj
= objectification / operative foreground in a formed cut

foreground_phen
= phenomenal candidate / pre-reflective phenomenal objectification
~~~

No canonical symbol is introduced by this distinction.
