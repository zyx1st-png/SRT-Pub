# Dialogue derivation trace — GRG cross-objectification method correction

## 0. Role

This file preserves the derivation path behind the 2026-09-23 method correction.

It is not a theory owner and does not upgrade machine synthesis to author authority.

## 1. Trigger

The evolution / population-genetics fusion discussion exposed a methodological drift:

~~~text
source concept
-> search for GRG counterpart
-> audit whether mapping is allowed
~~~

The author corrected the research aim: GRG is not primarily a cross-domain term/object matching scheme. Current GRG names and future formalisms are themselves objectifications; the research goal is to reorganize domain concepts and formalisms around deeper generative relations, even if no current GRG object has a natural domain counterpart.

Direct quotations are preserved in the companion author record §1.1–§1.2.

## 2. Independent critique pressure

A subsequent independent critique accepted the anti-object-matching correction but raised four main pressures:

1. object mismatch cannot make the method unable to fail;
2. "deep grammar" cannot be treated as a direct God-view layer outside objectification;
3. the GRG lens participates in decomposition, so post-hoc recurrence can be projection;
4. source-native-first must remain a fidelity guard rather than be replaced by a new slogan.

The critique also warned that generic state-transition / feedback restatements can be fully absorbed by mature source models.

These pressures are review inputs, not author wording.

## 3. Assistant synthesis

The assistant then proposed:

~~~text
object-level mismatch:
  not a method failure by itself

grammar-level claim:
  must remain rejectable

gain claim:
  must remain rejectable
~~~

and retyped "deep grammar" as a candidate relation / constraint organization proposed to survive legitimate re-objectification rather than an independently accessed layer.

The assistant also split:

~~~text
DISCOVERY
= grammar formation / revision permitted after source inspection

TEST
= relation burden frozen before decisive held-out inspection
~~~

This synthesis remained machine-level until the author accepted the package direction.

## 4. Author convergence event

After that analysis, the author instructed that the intuition, critique and analysis be consolidated into a revised GRG base architecture and anti-drift package and asked for a new PR.

That event is preserved verbatim in the companion author record §1.3.

Interpretation boundary:

~~~text
package direction:
  AUTHOR ACCEPTED

individual machine clauses / exact wording:
  remain M unless separately adjudicated
~~~

## 5. Implementation consequences

The PR therefore implements:

- GRG working terms / formalisms as revisable objectifications;
- Cross-Objectification Reconstruction before Card mapping;
- DISCOVERY / TEST separation;
- relation-claim freezing rather than vocabulary freezing;
- source-locator requirement for load-bearing reconstructed relations;
- projection / triviality / absorption / re-objectification failure modes;
- failed-version preservation;
- held-out contamination after failure-driven revision;
- Card retyping to late audit / non-identity overlay;
- exact inheritance of v0.3 XG2 mechanism-change burden.

## 6. Non-conclusions

This trace does not establish:
