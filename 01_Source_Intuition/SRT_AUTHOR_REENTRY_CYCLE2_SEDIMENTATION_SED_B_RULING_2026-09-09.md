# Author Re-entry Cycle 2 — sedimentation SED-B ruling

> **Role:** record the author's 2026-09-09 adjudication of the sedimentation fork exposed after the Scope-B endogenous-locus counterexample prepass.
>
> **Boundary:** this is an author-source meaning ruling only. It does not assign Level 1 or Level 2, does not promote the machine `P* / S_H* / S_C*` notation, does not prove a counterexample, and does not edit canonical ontology.

## 1. Question presented to the author

After Scope B fixed the target to endogenously formed / continuously reconstituted Selection-positions, the Amari / continuous-attractor pressure exposed two readings of `sedimentation`:

```text
SED-A — weak persistence reading

any event-triggered asymmetric state that persists
and conditions later transition counts as sedimentation.

Example:
a fixed-law attractor bump persists after input withdrawal;
its current asymmetric occupancy itself counts as sedimentation.
```

versus:

```text
SED-B — history-writeback reading

sedimentation requires prior Selection differentiation
to leave a history-conditioned carry-over that changes
later transition / reconstitution conditions;

mere continued occupancy of one asymmetric current state
is not sufficient by itself.
```

Machine recommendation before the response: **SED-B**.

## 3. Author-licensed minimum reading

For the strengthened Cycle-2 claim, `sedimentation` must now be read as a historical writeback relation rather than mere state persistence.

Safe minimum:

```text
prior Selection differentiation
-> leaves a retained, history-indexed asymmetry
-> that retained asymmetry changes / constrains
   the conditions under which later Selection-position formation,
   reconstitution or continuation occurs.
```

Therefore:

```text
current asymmetry
!= sufficient by itself

persistent attractor occupancy
!= sufficient by itself

one localized bump remaining active
!= sufficient by itself

one event having foreground/background
!= sedimentation-level result
```

The historical carry-over must be load-bearing for later transition / reconstitution conditions.

---

## 4. Important carrier guard

SED-B does **not** mean:

```text
sedimentation = synaptic weight change only
```

or:

```text
sedimentation = one specific physical memory substrate
```

The author ruling fixes the **role**, not the implementation.

A valid later implementation may in principle be carried by:

```text
recurrent topology
transition thresholds
boundary / coupling conditions
persistent relation structure
gating architecture
state-dependent control parameters
field organization
or another history-indexed causal carrier
```

provided that the history-dependent carry-over remains independently detectable and changes later transition / reconstitution conditions beyond merely noting which asymmetric state is occupied at the instant of measurement.

Thus the decisive distinction is:

```text
mere current occupancy
vs
history-conditioned modification of later causal conditions
```

not:

```text
activity state
vs
weight matrix
```

## 5. Relation to the prior machine notation

Using the audit notation only:

```text
S_C* = current non-flat causal geometry
S_H* = historical sedimentation / writeback
```

SED-B fixes that the strengthened historical-sedimentation burden cannot collapse into:

```text
S_H* := S_C*
```

Merely finding a current non-flat geometry does not by itself establish the historical sedimentation relation.

A candidate S_H* now needs at least the stronger shape:

```text
History contrast
+
post-event retained difference
+
future transition / reconstitution difference
+
not exhausted by instantaneous asymmetric occupancy
```

The exact operational criterion remains audit work and is not canonically defined by this source record.

## 6. Immediate consequence for Amari / continuous-attractor pressure

Under SED-A, a persistent bump could be declared to be sedimentation by definition.

Under the author-confirmed SED-B reading, that move is no longer licensed.

Therefore a fixed-law attractor architecture becomes a **live counterexample candidate** if it can establish:

```text
P*_endo:
  a persistent / re-identifiable selection-like locus forms dynamically

AND

not S_H*:
  the bump-forming history does not leave a retained
  history-indexed modification of the later transition /
  reconstitution conditions beyond current occupancy.
```

This does **not** yet mean the counterexample succeeds.

The candidate fails if closer analysis shows that the supposedly fixed-law attractor in fact carries a history-indexed modification relevant to later reconstitution under the locked criterion.
