# SRT Author Adjudication — Relation Transition Grammar

Date: 2026-09-14  
Status: author adjudication / source-intuition authority  
Scope: legacy-recovery synthesis only; no direct canonical rewrite in this file

## 1. Decision

The author ACCEPTS the M1 option from the legacy-recovery minimality comparison.

The five-relation research tool remains unchanged:

```text
Generation
Standing
Shaping
Bearing
Revision
```

No sixth primitive relation is introduced.

What is added is a minimal transition discipline for relations whose role changes across formation history.

The author does NOT accept M0 as sufficient, because a static typing table cannot express how an initially external shaping structure can become constitutively load-bearing in a newly formed standing, or how a higher-order standing can lose integration while lower-scale standing persists.

The author does NOT accept M2 as part of the minimal five-relation tool. Effective objecthood remains an important downstream interface problem, but it is not a universal relation type and should be handled separately as a post-One bridge.

## 2. Accepted transition: Shaping -> Standing-formation participation

An initially external shaping structure is not thereby part of a formed One.

However, where repeated coupling makes that structure materially and recurrently load-bearing in the relevant Selection-mediated vertical reconstitution path, and where the relevant dependence is not freely replaceable by arbitrary surrounding-field history while preserving the same claimed formation path, the structure may be treated as participating in new Standing formation.

Compact author reading:

```text
external Shaping
+
repeated participation in vertical reconstitution
+
load-bearing contribution to renewed formation
+
non-freely-substitutable reconstitution dependence
->
Standing-formation participation candidate
```

This transition does NOT establish that the prior One merely enlarged its old boundary.

The following remain OPEN:

```text
old One boundary expansion
vs
new higher-order One formation

strict numerical identity
exact unit / boundary
branch / merge identity
```

Therefore the safe adjudicated claim is only:

> A structure may cease to function as merely external Shaping and begin to participate constitutively in a newly formed Standing when it becomes recurrently load-bearing in the relevant vertical reconstitution path. The identity relation between earlier and later One-formation remains separately OPEN.

## 3. Accepted reverse transition: de-nesting / lower-standing persistence

The author also accepts the reverse structural possibility.

If a higher-order Standing loses the constitutive reconstitution dependence that supported it, while a lower-scale reconstitution path remains capable of continued relatively separable formation, the lower-scale process may persist as a Standing candidate after higher-order de-integration.

Compact reading:

```text
higher-order Standing
-> constitutive coupling failure
+
lower-scale vertical reconstitution remains viable
->
de-nesting / lower-standing persistence candidate
```

This is NOT automatically:

- emancipation;
- agency;
- subject formation;
- Bearer formation;
- proof that the lower unit is numerically identical to some prior unit;
- a completed branch / merge theory.

It is only a structural Standing transition candidate.

## 4. Boundary with Shaping and Revision

This adjudication does not reopen the existing Shaping / Revision distinction.

Ordinary change in later conditions, weights, costs, accessibility, or path preference can remain Shaping.

Revision remains the stronger consequence-sensitive case in which the process's own comparison rules, boundaries, candidate-generation conditions, or reopening conditions are modified.

Therefore:

```text
Shaping-role change != Revision automatically
Standing-formation participation != Revision automatically
```

A transition can alter constitutive Standing without yet establishing generative reselectability in the B13 sense.

## 5. Effective objecthood is NOT part of the minimal five-relation tool

The author rejects adding `objecthood` or `black-boxability` as a sixth relation.

The legacy material and the existing noncanonical physics P07 patch nevertheless identify a valuable downstream research bridge:

```text
vertical Generation
-> formed One / Standing
-> scale-relative stable interface
-> operational compression / formation-history black-boxing
-> low-cost re-identification
-> effective objecthood
-> ordinary object-level causal modelling
```

This bridge is retained for separate reconstruction.

The following distinctions are mandatory:

```text
model-side objectification != One
One != effective objecthood automatically
effective objecthood != absolute metaphysical objecthood
```

Effective objecthood, if retained, must remain scale-relative, task-relative, and interface-relative.

The next reconstruction question is therefore not "what is an object?" in the abstract, but:

> Under what conditions can a formed One be treated by downstream inquiry as a stable effective object without erasing the generative ontology that produced it?
