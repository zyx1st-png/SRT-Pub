## 2. Minimum L0 ruling

The minimum pre-object L0 does **not** primitively contain the positive directional claim:

```text
continuation-preserving / non-self-erasing structures are better,
more privileged,
more real,
or more selected
than closure / self-erasing structures.
```

At the minimum L0 level, the relevant burden remains only:

```text
actualisability is not maximally indifferent.
```

This burden does not yet identify which realized relation, outcome class, continuation form, or history should be structurally preferred.

Thus:

```text
non-maximal-indifference
!= continuation-favouring direction
!= anti-self-erasure value
!= order
!= normativity.
```

## 3. `ε_pg` minimum witness role

If `ε_pg > 0` is used only to express:

## 4. Stronger epsilon burden is downstream

The historical stronger reading:

```text

is structurally favored over
B <= 1 self-erasing realization
```

must not define the minimum pre-object L0.

The author accepts the relocation principle:

> **Continuation, closure, non-self-erasure, reselectability, and related directionality become ontologically meaningful only after primitive Selection has produced determinate actuality and some stronger retention / relational continuation structure has been established.**

Therefore the stronger directional burden must be reconstructed in a downstream layer where the following notions are independently available:

```text

retained consequence / writeback;
relational availability across events;
continuation / closure distinction;
history-bearing or reconstitution structure where additionally required.
```

This does **not** yet identify one final owner or one universal threshold.

Relocating continuation semantics downstream does not mean:


nor:

```text

```

A weaker post-Selection relation may already permit a scoped continuation / closure comparison before full One formation.

But the following remain distinct:

```text
retention / successor availability
!= One;

One
!= Stable ISP;

Stable ISP
!= generatively healthy process;

continuation / non-self-erasure
!= Bearer / subject / consciousness / morality.
```

Exact owner placement must be earned by the next bounded audit.
