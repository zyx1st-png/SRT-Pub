## 2. Accepted reconstruction

### A — real pre-object modal burden

Before primitive Selection, SRT may retain a real but non-objectified differential / modal openness.

This burden is not licensed as:

```text
an entity;
a substance;
a formed One;
a countable Many;
a field-like container;
a warehouse of unrealised objects;
a completed options set.
```

It names a pre-object actualisability condition only.

### B — minimal positive burden

The pre-object modal burden may carry the following minimum claim:

```text
actualisability is real;
actualisability is open;
actualisability is not maximally neutral / flat.
```

This does not yet specify individuated alternatives, global preference, final aim, probability distribution, completed geometry, or object-level direction.

### C — no actuality-producing substitution

The pre-object modal burden does **not** itself carry the role:

```text
therefore one determinate difference actually obtains.
```

The actuality-producing burden remains with primitive Selection:

```text
pre-object non-flat actualisability
-/> determinate manifest actuality

primitive Selection
-> a determinate difference obtains event efficacy
```

Thus Oriented Openness constrains / qualifies actualisability but does not replace Selection as the actualisation floor.

### D — consequence for `potential field` language

Any inherited `潜在域 / potential field` language must not be read as committing SRT to one prior object-like domain containing already formed unrealised entities or alternatives.

A permitted reconstruction direction is:

```text
potentiality
= non-objectified actualisability / modal openness
```

rather than:

```text
potentiality
= a prior container populated by hidden objects.
```

This adjudication does not yet rename or edit the canonical term.
