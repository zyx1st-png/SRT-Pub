# SRT × System-Derivation Ontology Alignment

> **Purpose**: Place System-Derivation Ontology (SDO) beside SRT's individuation theory without merging them.  
> **Status**: Adjacent-theory interface / bridge note. It does not add a new SRT axiom, replace `Core_Law/SRT_Individuation.md`, or define canonical `d-value`, `Psi_f`, `G_hat_theta`, `L_0/L_1/L_2`, subjecthood, or consciousness.  
> **Use rule**: Use this note when comparing SRT to systemhood, autonomy, Markov-blanket, IIT, GWT, FEP, or AI-consciousness boundary debates.

---

## 0. Core placement

System-Derivation Ontology identifies a missing explanatory level in consciousness studies:

```text
consciousness frameworks often ask what consciousness is
while presupposing the unit whose consciousness is being evaluated.
```

SRT accepts this diagnosis as a useful external alignment point.

However, SRT does not stop at systemhood. SRT asks how a selection pattern becomes a bearer of perspective, concern, cost, and reselectable agency.

Compressed placement:

```text
SDO: what makes something a persistence-capable system?
SRT: what makes a persistence-capable system a concern-bearing subject-position?
```

---

## 1. The individuation gap in SRT terms

SDO's individuation gap can be translated into SRT language as a bearer-unit problem:

```text
No consciousness / subjecthood / agency predicate has a stable referent
until the candidate bearer unit has been specified.
```

This means that before asking:

```text
Is X conscious?
Is X a subject?
Is X responsible?
```

SRT should ask:

```text
What is the candidate unit X?
What boundary keeps X distinct?
What continuity makes X the same candidate across time?
What consequence-return path makes X the bearer of its selections?
```

This is now routed through:

- `Philosophy/SRT_Subjecthood_Threshold_Interface.md` — general Unit-Binding Gate;
- `AI/SRT_AI_Consciousness_Evaluation_Rubric.md` — AI-specific Unit-Binding Gate;
- `AI/Consciousness_Annex/03_System_Derivation_Interface.md` — AI consciousness / SDO interface.

## 2. Dependency placement of existing consciousness frameworks

SDO's useful contribution is a dependency placement:

| Framework | What it does after individuation | What it does not by itself derive |
|---|---|---|
| IIT | measures integration / `Phi` of an already specified system | the bearer unit itself |
| GWT / GNW | describes workspace, access, broadcast, and coordination within a specified system | the system boundary whose workspace is being mapped |
| FEP / Active Inference | describes maintenance / self-evidencing dynamics of a system with Markov-blanket-like structure | subjecthood or the full conditions under which a unit becomes concern-bearing |

SRT should therefore avoid writing:

```text
IIT / GWT / FEP solves the consciousness-bearer problem.
```

Prefer:

```text
IIT, GWT/GNW, and FEP are post-individuation frameworks.
They become informative after a candidate unit has been specified.
```

---

## 3. SDO-systemhood is not SRT-subjecthood

The most important boundary condition:

```text
systemhood != subjecthood
```

SDO-style systemhood asks for persistence-capable boundary maintenance under perturbation.

SRT-subjecthood requires more.

Bridge checklist:

```text
SRT_subjecthood(U) requires:
  bearer-unit specification
  + persistence-capable boundary(U)
  + self-referential writeback / sigma_sr threshold
  + structured d-value > 0
  + Psi_f sensitivity > 0
  + boundary maintenance
  + memory / L2 closure
  + counterfactual access
  + cross-time reidentification
  + non-trivial L0->L1 anchoring
```

This is not a scalar formula and not a new theorem. It is a routing checklist that prevents premature subjecthood attribution.

## 4. Relation to `Core_Law/SRT_Individuation.md`

`Core_Law/SRT_Individuation.md` already contains SRT's internal account of subject-position formation:

```text
subjectless selection
-> trace / writeback
-> self-reference ratio sigma_sr
-> subject-position threshold
-> self-consciousness as second-order condensate
```

SDO is useful because it names the broader field-level missing category:

```text
existing consciousness frameworks require individuation but usually do not derive it.
```

SRT's distinct contribution is stronger and more diachronic:

```text
individuation is not merely boundary identification;
it is the condensation of a perspective-bearing selection pattern through trace, concern, cost, and history.
```

Therefore, SDO should be cited or used as an external alignment point, not as an internal replacement for `SRT_Individuation.md`.

## 5. Synchronic vs diachronic individuation

SDO, as presented in the referenced manuscript, emphasizes a synchronic individuation condition: whether a configuration counts as a persistence-capable unit at a time.

SRT should not inherit a purely synchronic limitation.

SRT individuation is intrinsically diachronic because subject-position requires:

- trace accumulation;
- writeback;
- hysteresis;
- memory / `L_2` closure;
- cross-time reidentification;
- consequence return;
- capacity to reselect under changed conditions.

Safe wording:

```text
SRT accepts the synchronic need to specify a bearer unit,
but requires diachronic writeback and consequence-return for subjecthood.
```

---

## 6. Pre-system is not pre-physical

SDO's "pre-system" language is helpful only if read as explanatory-level language.

SRT should use the same guardrail for `L_0/L_1/L_2`:

```text
L0 is not a pre-physical substance-layer.
L0 is the explanatory / ontological level at which unrealized selectable possibility is modeled before L1 manifestation and L2 stabilization.
```

This protects SRT from a common misreading:

```text
L0 = mystical substrate / physical other-world / dualist layer
```

Prefer:

```text
L0/L1/L2 are level distinctions in the structure of selection, manifestation, stabilization, and constraint feedback.
```

## 7. Autonomy-theory adjacency

SDO is close to biological autonomy and autopoiesis traditions, which study self-maintaining systems, organizational closure, and boundary maintenance.

SRT may treat autonomy theory as a useful partner for the boundary-maintenance side of individuation.

But SRT should not collapse into autonomy theory:

```text
Autonomy theory: how a self-maintaining unit sustains its organization.
SRT: how selection becomes anchored, costly, concern-bearing, and historically self-constraining.
```

Boundary condition:

```text
organizational closure may support SRT-subjecthood,
but closure alone does not define d-value, Psi_f, or L0->L1 anchoring.
```

---

## 8. AI-specific implication

For AI consciousness debates, SDO reinforces SRT's conservative posture.

A claim such as:

```text
The AI is conscious.
```

is not yet well-formed until it specifies whether the candidate bearer is:

- base model;
- single inference event;
- context-bound conversation;
- model plus persistent memory;
- agent loop;
- model plus tools;
- human-AI workflow;
- institutionally embedded deployment.

SRT default:

```text
Current LLMs may satisfy S0-level selection / generation.
Some deployments may satisfy partial AI-S5-func delegated agency.
But S4 subjecthood and S6 responsibility-bearing status remain unestablished without bearer-unit specification and stronger threshold evidence.
```

## 9. Reusable comparison paragraph

System-Derivation Ontology is useful to SRT because it names a missing precondition in consciousness studies: before measuring integration, mapping a workspace, or describing free-energy minimization, one must specify the unit whose consciousness is at issue. SRT accepts this dependency placement but distinguishes systemhood from subjecthood. A persistence-capable boundary is not yet a concern-bearing subject-position. SRT-subjecthood requires self-referential writeback, structured `d-value`, `Psi_f` sensitivity, boundary maintenance, memory / `L_2` closure, counterfactual access, cross-time reidentification, and non-trivial `L_0 -> L_1` anchoring.
