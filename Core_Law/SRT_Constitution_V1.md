# SRT Constitution v1

SRT 的 Constitution 不是一组关于世界的公理，也不要求读者先接受一套形式本体、参数或方程。

它提供六个可以实际执行的视角操作。它们共同做一件事：

> **取消一些已经习惯成自然起点的东西所享有的解释豁免。**

这六条不是六个自然本体模块，不构成六层现实，也不是生成阶梯；它们只是当前 Constitution v1 的六个分析入口。

还有一个贯穿全文的边界：

> **悬置一个判断的给定性，不等于把现实变成任意的。**

发现 identity、history、可处理范围、后果归算或评价判断依赖某种位置、关系或切法，不推出这些东西只是分析者创造的。不同分析仍然受到实际发生、因果与历史关系以及领域证据的约束。

---

## 1. ARTICULATION — 这个“一”从哪里来？

### Perspective

从你已经把某个东西区分、组织并作为一个“一”来使用的地方看。

### 悬置的默认

> 我手里的这个“一”，不需要为自己的来路负责。

### 读者动作

先问：

> **这个“一”从哪里来？**

再问：

> **这个答案又把什么当成已经给定了？**

### 变得可见

当前解释自己的给定起点。

### Boundary

本条不要求无限递归，也不要求找到一个完全无前提的终极基础。

这里指定的是 reader-side 的分析位置；不因此断言被研究的 One 自身具有 perspective、bearerhood 或其他更强性质。

---

## 2. STILL-THIS — 为什么变化以后还是“这个”？

### Perspective

从你已经把不同时间、状态或呈现中的实例继续当作“同一个”的地方看。

### 悬置的默认

> 只要我们还能再次指认、追踪、命名或使用它，“还是这个”就不需要说明自己的条件。

### 读者动作

找出两个你已经当作“同一个”、但状态或呈现并不相同的实例。

先说出：

> **你当前的再识别依赖什么？**

然后改变、移除或扰动其中一个当前依赖的条件。

观察：

> 在哪些变化下，你仍继续把它当作“这个”？  
> 又在哪里，这种再识别开始失效？

### 变得可见

“还是这个”所依赖的关系、能够容纳的变化以及失效位置，不再只是背景。

### Boundary

本条不把我们的 re-identification rule 定义成对象自身的本体身份。

它也不主张 identity 是任意的或由观察者创造的。

冻结的两条非蕴含继续成立：

```text
re-identifiability
does not entail
bearerhood

bearerhood
does not derive from
our re-identification cut
```

因此：

```text
successful re-identification
does not entail
own-history / bearerhood / subjecthood
```

## 3. OWN-HISTORY — 为什么这段过去算“它自己的”？

### Perspective

从你已经把某件过去的发生、后果或改变算作“这个候选自己的历史”的地方看。

### 悬置的默认

> 一旦一件过去已经被写在它名下，“这是它自己的历史”就不再需要说明。

### 读者动作

找出一件你已经算作它自己历史的过去。

问：

> **现在有什么——如果有的话——使你仍把这件过去算作这个候选后来条件、关系或约束的一部分？**

指出你当前实际依赖的关系，再改变、切断或重新安排它。

观察这种历史归属在哪里保持、在哪里开始失去依据。

如果当前找不到可追关系：

> **“当前未找到可追的归属依托。”**

本身就是合法结果。

### 变得可见

```text
发生在过去
!=
后来仍有效
!=
属于这个候选自己的历史
```

开始成为三个不同的问题。

### Boundary

当前没有找到归属依据，只说明这次探针没有找到可追关系；不推出事件没有发生，也不推出它绝不可能属于该候选的历史。

```text
historical facticity
does not entail
current historical efficacy
```

状态后来恢复得相同，也不推出此前历史已经被抹除；反过来，这也不证明此前历史现在仍具有可检测效力。

```text
shared historical inheritance
does not establish
strict same-bearer numerical identity
```

分叉因此仍是开放 pressure point：共同继承同一段历史，不保证后来仍是同一个 bearer；本条不承诺为所有 branching case 给出确定 verdict。

转移、外包、重置或恢复可以用于压力测试历史归属，但不因此成为 bearer 的 Constitution 定义。

## 4. 为什么偏偏是这些方向现在可以被处理？

### Perspective

从某些差异、方向或路径已经实际成为当前比较、行动、推进或分析的一部分，而“为什么偏偏是这些”被当作背景的地方看。

### 悬置的默认

> 当前现实能够拿来比较、行动、推进或分析的范围，可以直接作为起点。

### 读者动作

找出一个当前已经现实可比较、可行动、可推进或可分析的方向。

问：

> **现在是什么，使它成为一个现实可处理的方向？**

指出当前实际依赖的关系或条件，不要先套一份固定门槛清单。

然后改变、移除或重新安排其中一个条件。

观察：

- 哪些原有方向仍然现实可处理；
- 哪些不再如此；
- 哪些只有改变之后才第一次成为现实可处理的方向。

如果当前没有分离出这样的依赖，也把这个结果保留下来。

### 变得可见

```text
后来没有采用
!=
从未成为现实可处理的方向
```

先前形成、沉积或继承下来的结构，是否正在塑造后来什么能够进入现实处理范围，也由此成为可以继续追问的问题。

### Boundary

本条不要求存在一张完整、预先写好的“全部可能菜单”。

现实可处理的东西也不要求是离散、有限、可以逐项枚举的候选；连续的方向、路径、变化范围或维度同样可以接受这一追问。

先前结构能够约束后来哪些方向更容易或更难成为现实可处理的方向：

```text
does not entail
later outcome is already determined
```

当前不能处理，也不推出不存在、绝对不可能或在其他位置与条件下永远不能处理。

```text
processable-range change
does not entail
Selection / agency / bearerhood /
subjecthood / phenomenality
```

现实可处理的方向更多、更开放，也不自动意味着更自由、更健康或更好。

## 5. 为什么这份影响算落在这里？

### Perspective

从你已经说某件发生产生了影响，并已经把这份影响算在某个地方的地方看。

### 悬置的默认

> 只要效果已经被观察到，或者某处出现了反馈，我们就已经知道这份影响落在哪里。

### 读者动作

找出一个你已经说：

> **“这份影响落在这里。”**

的具体发生。

先问：

> **你是把什么当成一个整体、在多长的跨度里看，才使这句话成立？**

把当前实际使用的切法说出来。

然后尽可能保持同一经验发生、事件链或观测材料作为锚点，换一种整体划法或观察跨度，再追一次。

观察原来的归算：

- 是否保持；
- 是否分拆；
- 是否合并；
- 是否移动；
- 原来的 effect description 是否已经无法一一对应。

如果描述本身必须改变，也把这种改变作为结果保留，不强迫维持跨切法的“同一个 q”。

### 变得可见

```text
causal source
!=
observation site
!=
feedback site
!=
consequence attribution
```

### Boundary

归算随切法改变：

```text
does not entail
consequence is fictitious
or reality is arbitrarily created by the analyst
```

不同切法仍受实际发生、因果关系、持续改变、可重复观察和领域证据约束。

反过来：

```text
cross-cut stable
!=
ontologically final
```

跨多种切法保持稳定，也不推出已经发现唯一真实的本体边界、same bearer 或 own-history。

本条不问谁**应该**承担、负责或修复，因此不是 non-outsourcing / order-gain criterion。

成功追踪 consequence attribution 也不推出 bearerhood、subjecthood、agency 或 phenomenality。

最后，本条没有结清作者更强的问题：

> **后果实际落回哪里？**

它只是先取消“我们已经知道答案”的 attribution exemption。

## 6. 为什么你已经说这一边更好？

### Perspective

从你已经把两个走向，或者一个过程的前后变化，称为“更好 / 更坏、进步 / 倒退”的地方看。

### 悬置的默认

> 只要我已经能够把一个走向放在另一个前面，这个判断本身就不需要再说明。

### 读者动作

找出一个具体的“更好 / 更坏”判断。

问：

> **现在是什么，使你把这一边放在另一边前面？**

说出当前实际依赖的根据，不要先给这种根据分类。

如果目前说不出一个可以单独拿出来的根据：

> **“目前未分离出可单独扰动的判断依据。”**

就是合法结果。

然后尽量保持原来的具体情形不变，暂时不让这个根据决定判断，再判断一次。

观察：

- 原判断仍然保持；
- 原判断暂时失去依据；
- 原判断发生反转；
- 或原来的比较方式本身已经无法继续维持。

最后一种同样是结果，不要求重新制造一个总的“谁更好”。

### 变得可见

```text
change
!=
improvement

goal attainment
!=
direction settled

successful optimization
!=
better simpliciter
```

而且：

```text
judgment provenance
!=
judgment behavior
under perturbation of its basis
```

### Boundary

本条不给出 universal criterion of good direction。

它不把任何现有 Core 层方向、order-gain 或 re-selectability 判据写成 Constitution checklist，也不定义 ε、T_dir 或 d-value。

三条 null guard 保持：

```text
当前说不出可扰动依据
does not entail
判断无根据 / 非理性 / 应当放弃

判断在扰动后改变
does not entail
原判断错误

判断在扰动后保持
does not entail
该判断已经被证成
```

简写：

```text
fragile != false
stable != true
```

# 六条共同服从的四条纪律

## 1. 六条不是阶梯

编号只用于导航。

一条成功，不自动推出下一条：

```text
re-identifiability
!=
bearerhood

consequence attribution
!=
bearer admission

evaluative robustness
!=
normative truth
```

## 2. Constitution 可以审计自己

六条都可以反过来应用于研究者、作者、SRT 当前的理论切分以及 Constitution 自身。

但 self-application 不要求无限递归；在足以暴露当前 givens、dependencies 或 cuts 后停止。

## 3. 位置性不是认识论特权

一个位置能够获得特殊信息，不意味着它自动拥有关于所有位置的最终解释权。

同时，承认位置性也不意味着所有位置同样正确。

## 4. Constitution 重新打开问题，Domain 支付答案

当一个问题需要：

- 固定 unit 或 boundary；
- 建立机制；
- 形式化；
- 数学；
- 测量；
- 实验；
- rival comparison；

它就进入 Domain Research。

Constitution 的职责不是提前替领域给出答案，而是防止领域在开始研究以前，已经把最重要的前提当成无需说明的背景。
