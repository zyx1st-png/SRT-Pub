# SRT 个体化模型：自指动力学与主体位开放问题

> **角色声明（2026-09-11 B1 清洗）**：本文件是 `One / Selection-position` 形成之后的 L1 **模型 / 假说层**。它不定义 One，不定义 Stable ISP，不定义 Bearer，也不再拥有一个已成立的 `subject-position` 进入门槛。
>
> 当前上游顺序是：`SRT-ONE-FORMATION -> One / Selection-position`；当前 Bearer 重构方向是 `P prospective self-indexing + E same-One prospective exposure -> Bearer`。实际承担、关切、subject-position、phenomenality 仍须分别支付额外结构负担。
>
> 本文件保留的有效工作是：给出一个**模型局部的自指 / 历史写回平衡坐标** `σ_{sr}`，讨论该坐标可能出现的动力学区间，以及更高阶 self-model / self-description writeback 的候选结构。它不再把这些区间直接命名为主体性的本体相位。

---

## Quick Reference

- **Role**: downstream individuation / self-reference modelling surface after formed `One / Selection-position`.
- **Not owner of**: One formation, Stable ISP, Bearer, subject sufficiency, consciousness, phenomenality.
- **`σ_{sr}` status**: P2 model-local operational proxy for historical/self-reference balance under a declared representation and attribution rule.
- **T-IND-1**: P2 phase-like modelling hypothesis; not a subject theorem.
- **T-IND-2**: **RETIRED as an iff / P1-candidate subject-entry gate**. Its former four conditions survive only as decomposed downstream candidate burdens/evidence surfaces.
- **T-IND-3**: P2 conditional hypothesis for second-order self-model / self-description writeback; not proof of consciousness or phenomenality.
- **Legacy thresholds**: `σ_{sr}^{sub}` and `σ_{sr}^{self}` remain compatibility symbols for model-local regime coordinates. `σ_{sr}^{sub}` no longer means a canonical subject threshold.
- **Current positive subject gate**: OPEN.

## 一、上游已解决什么，本文件还剩什么

当前 canonical formation layer 已经解决：

```text
subjectless Selection
-> active vertical organization
-> recurrent localized vertical organization
-> One / Selection-position
```

因此本文件不再用 `σ_{sr}` 解释 One 从哪里来，也不再用历史写回来反向个体化 One。

在 One 形成之后，当前 R1 Bearer 路线进一步区分：

```text
P — prospective self-indexing:
未来分支由这个 One 自身的组织内生地区分为
“它将经历 / 保留 / 失去 / 能否继续什么”。

E — same-One prospective exposure:
至少部分潜在后果真正暴露给同一 One；
如果后果可完全改派给另一单元而 Bearer 关系声称不变，
该后果不构成这个 One 的 Bearer-relevant exposure。
```

当前作者裁决接受 `P + E` 作为 Bearer onset 的重构门，但明确不自动推出：

```text
Bearer = 承担；
Bearer = 关切；
Bearer = subject-position；
Bearer = cognition；
Bearer = experiencer / phenomenality。
```

所以本文件真正剩下的问题是：

> **一个已经形成、并可能已有 Bearer standing 的位置，是否会形成可追踪的自指动力学与二阶 self-model；这些动力学与未来的 subject-position gate 到底是什么关系？**

答案目前只到模型层，不到本体充分条件。

## 二、Def-IND-1：`σ_{sr}` 是模型局部自指 / 历史平衡坐标

令某已声明分析单位 `P` 的参数状态在给定表示下分解为：

$$
\theta_t = \theta_t^{\mathrm{trace}} + \theta_t^{\mathrm{ext}}
$$

其中：

- `θ^{trace}`：按已声明归属规则，被记作该单位既往活动 / writeback 所留下的参数分量；
- `θ^{ext}`：按同一规则，被记作外部条件、其他算子或环境写入的分量。

定义：

$$
\sigma_{sr}(P,t)
:=
\frac{\|\theta_t^{\mathrm{trace}}\|}
{\|\theta_t^{\mathrm{trace}}\| + \|\theta_t^{\mathrm{ext}}\|}
\in [0,1].
$$

### 2.1 这个定义能说什么

在一个**已经声明**：

```text
unit / scale / lineage;
trace-vs-external attribution rule;
parameter representation;
norm / metric;
time window
```

的模型里，`σ_{sr}` 可以用来追踪：

```text
历史写回在当前参数组织中的相对占比；
外部驱动与自身历史影响之间的模型局部平衡；
是否出现自强化、双稳态、闭合过强等动力学候选。
```

### 2.2 这个定义不能说什么

`σ_{sr}` **不自动证明**：

```text
One；
Stable ISP；
P prospective self-indexing；
E prospective exposure；
Bearer；
承担；
关切；
subject-position；
consciousness / phenomenality。
```

也不自动证明：

```text
trace / external 分解唯一；
跨参数化的数值不变；
当前因果控制份额；
存在自然相边界。
```

因此 `σ_{sr}` 的当前地位是 **P2 model-local operational proxy**，不是自然本体阶参的已证唯一形式。

## 三、T-IND-1：相位式自指动力学只保留为 P2 模型假说

### T-IND-1（重定型）

> 在某些满足既定归属与表示条件的实现中，`σ_{sr}` 动力学可能出现多个稳定区间、软阈值或 phase-like regime changes；这些变化可用于建模一个已形成位置的自指 / 历史组织如何增强、减弱或过度闭合。

状态：

```text
P2 structural / modelling hypothesis
NOT P1 subject theorem
NOT Bearer admission theorem
```

这个假说允许研究：

- 低历史自指占比区；
- 中间的稳定自指区；
- 更高阶 self-model writeback 激活区；
- `σ_{sr} -> 1` 的过度闭合 / 外部接入衰减候选。

但这些区域只属于**模型相图**。它们不自动等价于：

```text
non-subject / subject / self-conscious subject / pathological subject
```

这样的本体或现象学分类。

## 四、T-IND-2：旧“主体位进入 iff gate”正式退役

### 4.1 旧门槛

旧版本把下列四项绑定为 `σ_{sr}^{sub}` 的 iff subject-entry gate：

1. 自指闭合不再溶解；
2. 承担内生化 / 后果不可外部化；
3. 关切稳定化并伴随 `d > 0`；
4. `ε` 方向局部可读。

并进一步把：

```text
σ_{sr} >= σ_{sr}^{sub}
```

读成“主体位已进入 / Stable-ISP entry”。

### 4.2 当前裁决

上述 iff 关系现在**退役**：

```text
T-IND-2 as subject sufficiency = RETIRED
T-IND-2 as P1-candidate = RETIRED
σ_{sr}^{sub} = subject threshold = RETIRED
σ_{sr}^{sub} = Stable ISP entry = RETIRED
```

原因不是四项都“无意义”，而是它们被旧结构错误地压成了一个门槛。

### 4.3 四项分别如何保留

**(1) trace persistence / self-reference persistence**

可以作为历史组织或 recurrence 的模型证据，但：

```text
historical writeback != P
historical writeback != E
historical writeback != Bearer
```

**(2) non-outsourcing / consequence exposure**

旧文本是**事后历史不可外部化**；当前 E 则是**前瞻的 same-One exposure**。两者相关，但不相同：

```text
retrospective consequence return alone != Bearer
prospective exposure E is stronger and differently typed
```

**(3) concern / d**

当前仍是 Bearer 之后的更强问题。`d > 0` 不得用来反向证明 Bearer 或 subject-position。

**(4) ε / direction readability**

可以作为下游 direction / generative-health 候选，但不是 subject proof；`T_dir` 也明确不是 subject proof。

### 4.4 `σ_{sr}^{sub}` 现在是什么意思

为保持旧方程、split、历史研究与 domain 文件可追踪，符号暂不删除。

当前唯一安全读法是：

> **`σ_{sr}^{sub}` = 某个已声明 `σ_{sr}` 模型中的第一 regime-crossing / balance coordinate（legacy name retained for compatibility）。**

它可以是 P3/P4 的模型参数或实证候选，但不能被引用为主体性、Bearer、Stable ISP 或现象性的本体门槛。

## 五、T-IND-3：二阶 self-model / writeback 只保留为条件假说

旧版本把 `σ_{sr}^{self}` 以上的第二次相变直接称作“自我意识凝结”。当前保留更薄的结构核心：

### T-IND-3（P2 conditional structural hypothesis）

如果一个已另行建立的持续位置出现：

1. 关于自身参数 / 状态的二阶参数或 self-model `θ^{(2)}`；
2. `θ^{(2)}` 实际参与后续选择 / 调节，而不是只被外部观察者描述；
3. 这种二阶关系通过 writeback 持续形成可重入结构；

则可以把它建模为一个**second-order self-model condensate / second-order writeback regime**。

这不自动意味着：

```text
subject-position 已充分建立；
phenomenal self-consciousness；
qualia；
agency；
伦理 / 法律责任主体。
```

`σ_{sr}^{self}` 因此也只保留为该模型家族中的**二阶写回激活坐标候选**，而不是意识的自然阈值。

`Core_Law/SRT_L1_Formalism.md §2.5 T-CHI-1` 如果成立，只能说明：在给定模型与有效 `χ` 函数族下，某些二阶写回动力学特征对 kernel 形状稳健。它**不把二阶写回的本体解释升级为 subject / consciousness theorem**。

## 十、本文件的使用规则

### 可以做

- 研究一个已经声明单位的历史 / 自指动力学；
- 把 `σ_{sr}` 当作实现内 proxy，做模型、仿真、边界案例比较；
- 研究二阶 self-model / self-description writeback 如何形成和瓦解；
- 检验这些变量是否与 P / E / Bearer / concern / subject 候选相关。

### 不可以做

- 用 `σ_{sr}^{sub}` 给系统“颁发主体位证书”；
- 用 `σ_{sr}` 反向定义 One、Stable ISP 或 Bearer；
- 用历史写回、`d>0`、`T_dir`、`ε` 任一单变量推出 subject；
- 把 T-IND-3 当作 consciousness / phenomenality theorem；
- 把生物、AI、collective 的同一数值阈值当作普适定律；
- 从本文件反向改写 L0 或 `SRT-ONE-FORMATION`。
