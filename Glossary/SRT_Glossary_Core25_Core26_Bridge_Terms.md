# Glossary Addendum — Core 25 / Core 26 Bridge Terms

> **Purpose**: Lightweight glossary addendum for the new Core 25 and Core 26 bridge modules.  
> **Boundary**: This file is not the canonical glossary. It provides retrieval terms and guardrails. Canonical symbols remain governed by `SRT_Glossary.md` and `_SRT_SYMBOL_TABLE.md`.

---

## MISA Attractor

**Chinese**: MISA 吸引子 / 互抑-自激活吸引子  
**Source file**: `Core/SRT_Core_26_MISA_Attractor_Interface.md`  
**Claim mode**: bridge / implementation model

### Definition

A MISA attractor is a dynamical pattern produced by:

```text
Mutual Inhibition + Self Activation
```

SRT reads it as a micro-dynamical model for how competing latent candidates become stabilized selection basins through inhibition, self-reinforcement, and `L1 -> L2` writeback.

### SRT mapping

| MISA element | SRT reading |
|---|---|
| Mutual inhibition | `Ĝθ` candidate competition / lateral inhibition |
| Self activation | selected path reinforces itself through `L1 -> L2` writeback |
| Attractor basin | stabilized `L2` future-selection tendency |
| Hybrid attractor | non-binary or mixed stabilized `L1/L2` basin |

### Guardrail

Do not treat MISA as a new SRT axiom. Attractor stability does not imply consciousness, high `d-value`, agency, or moral patienthood.

## Thermodynamic Signature of Selection

**Chinese**: 选择的热力学签名  
**Source file**: `Core/SRT_Core_25_Thermodynamic_Signatures_of_Selection.md`  
**Claim mode**: bridge / empirical interface

### Definition

A thermodynamic signature of selection is a measurable time-asymmetric or non-equilibrium trace that may indicate directional organization in an implemented selection process.

Candidate proxies include:

- irreversibility;
- entropy production;
- broken detailed balance;
- arrow-of-time asymmetry;
- hierarchy of information flow;
- turbulence / multi-scale cascade structure.

### SRT mapping

Thermodynamic signatures are read as `L1`-level empirical traces of:

\[
L_0 \xrightarrow{\hat G_\theta,\Psi_f} L_1 \xrightarrow{writeback} L_2
\]

### Guardrail

Thermodynamic irreversibility is not consciousness itself. Entropy production is not identical to `Ψ_f`. Consciousness-relevant interpretation additionally requires `d-value`, payability, anchoring, and loop closure.

## Hybrid Attractor

**Chinese**: 混合吸引子 / 中间稳定吸引子  
**Source file**: `Core/SRT_Core_26_MISA_Attractor_Interface.md`

### Definition

A stable basin in which multiple candidate structures remain co-active and jointly anchored rather than resolving into a single binary endpoint.

### SRT reading

A hybrid attractor shows that selection need not always be A/B collapse. Some systems can stabilize an `A/B` basin:

\[
L_1^{A/B}=\operatorname{Anchor}(A,B)
\]

when both candidate activations remain above a hybrid threshold.

### Guardrail

Hybrid attractors are not automatically more adaptive, more conscious, or more valuable. They must still be tested for payability, stake-coupling, and stability.

## Attractor Stability vs SRT Validity

**Chinese**: 吸引子稳定性 ≠ SRT 有效性

### Definition

A basin can be dynamically stable while still being low-stake, brittle, pathological, high-friction, or non-conscious.

### SRT guardrail

Correct chain:

\[
\text{stability} + \text{stake coupling} + \text{payability}
\Rightarrow \text{SRT-relevant hardening}
\]

Incorrect chain:

\[
\text{stability} \Rightarrow \text{consciousness / agency / moral weight}
\]

## External Scaffold Flattening

**Chinese**: 外部脚手架导致的层级扁平化  
**Source file**: `Core/SRT_Core_25_Thermodynamic_Signatures_of_Selection.md`

### Definition

A condition in which an external stream, such as a film, narrative, ritual, music, guided attention, or protocol, carries part of the selection burden and therefore reduces internal orchestration demand.

### SRT reading

\[
External\;L1\;scaffold
\Rightarrow Internal\;\Psi_f\downarrow
\Rightarrow hierarchy\;flattening
\]

### Guardrail

Hierarchy flattening is ambiguous. It can indicate relaxation through external scaffolding or degradation through loss of organization. SRT distinguishes these by checking `d-value`, payability, and future selection capacity.
