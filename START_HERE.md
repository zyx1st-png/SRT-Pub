# Start Here — SRT Reading Guide

This file is the lightweight human entrypoint for the restructured public repository.

SRT begins from one reversal:

> Reality is not first given and then selected. Reality becomes determinate through constrained selection.

中文：

> 现实不是已经完成的对象清单，而是潜在可能在约束、代价、关切与历史中被选择、显现、锚定并稳定化的过程。

## 3. Reading warning

Do not read SRT in the wrong order.

If you begin with governance, audits, claim-mode controls, or agent protocols, the repository may look like a documentation system rather than a theory.

The intended order is:

> source intuition → formal anchors → bridges → convergence evidence → lab tests → governance → public release

Governance is necessary, but it is not the source of the theory's force.
