# RIKEN Sleep population-size scaling — null-calibration preregistration candidate

> **Status: DRAFT FOR INDEPENDENT REVIEW; NOT FROZEN; NO EXECUTION AUTHORIZED.**
> This document is a prospective plan for **uncomputed null-calibrated endpoints**, written **after** the 2026-10-09 PS-A result was observed. It must never be described as a preregistration of the original positive population-size slope or as an independent biological replication. Following review, freeze its actual code, parameters, dataset/ledger identity, and commit SHA before running or inspecting any null outcome.

## 1. Motivation, question, and provenance

The completed RIKEN Sleep N-scaling holdout (PR #1113) reported positive finite-N slopes in all five eligible animals (median beta_N = 0.06729) but no observed finite-N sign reversal. Its Gate 1 = PS-A authorized **stopping**, followed by a **separately preregistered null-calibration**; it did not authorize an unregistered mechanism search.

**New question:** how much of the observed positive slope of the operational NREM-minus-Wake modularity contrast survives comparison with a null distribution that preserves, graph by graph, population size, edge count, connectedness and the exact degree sequence, while applying a **finite 4E-step topology perturbation** that may retain higher-order structure and start-graph dependence?

The primary target is a **finite-length, start-graph-conditioned, exact-degree/connected topology-perturbation excess slope**, not an equilibrated degree-only null excess, an SRT variable, consciousness measure, or proof of scale-specific ontology. The degree-preserving null does not test whether the original neuron-to-neuron correlations are causal, nor does it preserve the original correlation geometry, spanning-tree membership, spatial distances or triangles. A separate signal-level surrogate will address a different, narrower question.

**Disclosed antecedents and limitations:** this protocol was designed after observing PS-A, using the same five animal lineages and underlying Sleep recordings. Its success would not provide a wholly independent discovery. The earlier subset seed used a string label such as "N100" instead of the preregistered numeric N; this protocol deliberately consumes the **recorded realized subsets** and cannot repair original exact seed-recipe compliance. The Kiyooka session-specific anchor remains ANCHOR-UNRESOLVED. Mouse05 overlaps the Phase 1 lineage.

## 2. Inherited measurements and fixed audit unit

- Data: the **same** eligible six RIKEN Sleep recordings from five animals; mouse04 has two sessions and must contribute only one animal-level curve. No new recordings or outcome-based exclusions.
- Source signal: existing S3 smoothed_spike. State annotations, windows, accepted neuron sets, signal preprocessing and original graph builder remain exactly those of the completed run.
- Original graph builder: binary undirected connected network from an MST backbone plus highest-ranked absolute-correlation edges, target mean degree 16; original graph construction is *not* altered by this proposal.
- Graph-level Q: max of 200 Louvain trials with inherited settings; state-level Q: arithmetic mean over state windows; NREM minus Wake contrast.
- Finite N grid: 100, 150, 225, 340, 510, 765, 1150, 1725, 2600, 3900. FULL is reported descriptively, with no place in any primary finite-N slope.

- Raw data and job/seed/checkpoint ledgers remain in ignored local storage, not Git. Commit only compact aggregate result, code/manifests and checksums.

## 3. Primary null G0: connected, exact-degree-preserving graph rewiring

**Unit of null randomization:** each original selected-subset × state-window graph separately. Preserve its exact labeled node set, number of undirected edges, per-node degree, absence of self loops/multi-edges, and connectedness. Randomize which nodes connect using degree-preserving double-edge swaps; do **not** preserve MST edge identities, community assignments or geometric wiring.

For each source graph, make **10 independently seeded graph-null replicates**, independently starting each from the original labeled graph. The proposed kernel is a **custom reject-and-stay simple connected double-edge swap chain**, **not** a call to NetworkX `connected_double_edge_swap`. For each proposal, select two distinct present undirected edges uniformly, choose an orientation uniformly from the two possible cross-pairings after canonically sorting their endpoints, and either (a) perform the swap if it is simple and leaves the graph connected, or (b) **leave the graph unchanged and count one rejected proposal**. Each replicate stops after **exactly 4 × E total attempted proposals**, whether accepted or rejected (E = original number of edges). The stopping rule must not depend on the number of accepted swaps. The implementation must reject proposals where the two selected edges share an endpoint, so a valid proposal has four distinct endpoints a, b, c, d. For the connectedness test, after applying the tentative swap, run a BFS starting at a and **stop successfully once b, c and d have all been reached**; otherwise reject and restore the original graph. This is equivalent to full connectedness checking after a two-edge swap on a connected input graph: after the two removals, any disconnected component must contain at least one of the four endpoints, so reachability among all four is necessary and sufficient. The NC-0a synthetic tests must compare **the accept/reject decision on every proposal of the separately declared, deterministic kernel-equivalence validation traces** against a full-graph connectedness check and obtain 100% agreement. Long synthetic mixing chains must additionally verify whole-graph connectivity at all five declared checkpoints, as well as degree/edge invariants after every accepted swap. Do not replace this with degree-only validation. This is an explicitly **procedure-defined null ensemble**; **uniform mixing over all connected fixed-degree graphs is not asserted**.

Before freezing, the actual algorithm, graph adjacency representation, proposal probabilities, endpoint ordering, connectivity test and dependency versions must be committed and reviewed. NetworkX 3.6.1 may be used for invariant checks; silently substituting its windowed `connected_double_edge_swap` is prohibited. **Synthetic-only mixing diagnostics** and their **pass/fail rules are declared in §6 before any synthetic diagnostics are run**. Include snapshots at E, 2E, 4E, 8E and **32E** attempts. The 32E endpoint is a **longer-chain reference, not proof of an equilibrium or uniform distribution**. Any failure of the declared synthetic criteria, unreasonable connectivity-check cost, or invalid topology means **NC-0a not passed**; the draft must be changed and reviewed before further testing. Do not tune on biological RIKEN nulls. Mixing remains a limitation even when synthetic checks pass.

At execution each required null graph must pass labeled node, degree sequence, edge count, simplicity and connectivity checks. A missing/invalid required null graph or trial gives **NC-INVALID** (no replacement cherry-picking), and record all kernel attempts, acceptance rates, swaps and diagnostics.

For every rewired graph run the same 200-repeat Louvain/max-Q algorithm and modularity definition as the original analysis. There is no optional choice of a better-looking null. Stable seeds follow the inherited stable_seed hash function with explicit *string* label semantics:

~~~text
stable_seed(20261009, "NC_G0_GRAPH_V1", recording_id,
            "N" + decimal(N), repeat_id, state, window_id, null_repeat)
stable_seed(20261009, "NC_G0_LOUVAIN_V1", recording_id,
            "N" + decimal(N), repeat_id, state, window_id, null_repeat, louvain_repeat)
~~~

Here null_repeat = 0..9 and louvain_repeat = 0..199; all ID encodings, ordering, and graph-to-seed mapping must be documented and fixed in the execution manifest before the first new Q is calculated.

**Important scope:** G0 conditions on observed state-dependent degree sequences. Because the graph builder targets mean degree 16, the N-dependence of D_G0 may arise from differences in state-specific degree heterogeneity plus finite-size/max-Q optimizer behavior, even though mean degree is nearly fixed. G0 calibrates these factors only under the **specified rewiring procedure**; it does not isolate how the graph builder **produced** the sequences, prove mixing to a uniform connected-degree ensemble, or distinguish all finite-size sampling artifacts. The primary outcome is therefore not an SRT-specific mechanism discriminator.

## 4. Primary outcome and Gate NC-1

For a recording s, finite N and selected subset r:

~~~text
D_obs(s,N,r)  = mean_windows Qobs(NREM) - mean_windows Qobs(Wake)
Q_G0(s,N,r,w) = mean_{10 graph-null replicates} maxQ_200(null graph at window w)
D_G0(s,N,r)   = mean_NREM_windows Q_G0 - mean_Wake_windows Q_G0
D_excess(s,N,r) = D_obs(s,N,r) - D_G0(s,N,r)
~~~

**Aggregation order is mandatory and paired:** for each session s and finite N first compute `D_excess(s,N,r) = D_obs(s,N,r) - D_G0(s,N,r)` **within the same selected subset repeat r**, then take `median_r D_excess(s,N,r)` over the ten selected repeats. For mouse04, average its two session medians at each N; the other animals have one session. Fit ordinary least-squares to the resulting animal-level excess curve against `log10(N)` over **exactly the ten finite targets**; this yields `beta_G0_excess`, the **primary** slope.

**Separate diagnostic curves:** independently take `median_r D_obs(s,N,r)` and `median_r D_G0(s,N,r)` within each session, then average mouse04's two sessions and fit finite-N slopes `beta_obs_10` and `beta_G0_10` by the same session→animal→slope steps. The observed ten-repeat slope `beta_obs_10` may differ from the published 100-repeat `beta_N`; report per-animal absolute and signed differences (and percentages only if the published denominator is nonzero).

**Do not assert additivity across medians:** generally `median_r(D_obs - D_G0) != median_r(D_obs) - median_r(D_G0)`. Consequently `beta_G0_excess != beta_obs_10 - beta_G0_10` is **not** an automatic integrity failure. For transparency compute the diagnostic `beta_marginal_difference = beta_obs_10 - beta_G0_10` and the non-additivity gap `beta_G0_excess - beta_marginal_difference` for every animal. Neither diagnostic replaces the paired-median primary estimate or changes the gate. Only the **per-subset identity** `D_obs(s,N,r) - D_G0(s,N,r) = D_excess(s,N,r)` (up to floating-point tolerance), followed by the prescribed paired aggregation, is an algebraic integrity check.

Report for every animal and every N: the **three separately and transparently defined** curves `median_r D_obs`, `median_r D_G0`, and `median_r (D_obs-D_G0)`, plus slopes, Spearman rho, finite-N ranges, per-animal non-additivity gaps, and the independent FULL original reference. Cross-animal report: all five slopes, number positive, median and mean. Descriptive percentile bootstrap: resample five **animals** with replacement 10,000 times using seed 98766; 95% percentile intervals for the **mean and median** of beta_G0_excess. Do not bootstrap windows, null graphs or subsets as biological replicates. Intervals are descriptive with n=5, not a calibrated confirmatory p-value.

**Proposed Gate NC-1 (subject to a further independent methodology review before freeze):**

Define `p = number of animals with beta_G0_excess > 0`; zero slopes count as nonpositive. Compute `R_med = median(beta_G0_excess) / median(beta_obs_10)` **only** when `median(beta_obs_10) > 0` and at least 4/5 `beta_obs_10` slopes are positive; otherwise set R_med = undefined and classify NC-B (selected observed panel does not directionally reproduce PS-A). Report all five `R_i = beta_G0_excess / beta_obs_10` only where the individual denominator is positive; otherwise show undefined, never set it to zero or exclude that animal from p. Also report the unnormalized median and mean slopes (observed, G0 and paired excess), their **median-nonadditivity gaps**, and an explicit statement that `R_med` is an operational **ratio of separately aggregated slopes**, not a mathematically exact fraction of observed Q or a proportion of biological mechanism retained.

- **NC-A-material@0.25 (direction + operational magnitude):** observed-panel reproducibility holds, p >= 4, and R_med >= **0.25**. The 25% retention bar is a **provisional operational materiality convention**, not a known biological threshold, statistical significance threshold or evidence that a quarter of the *biological mechanism* survives. It is selected before inspecting any G0 outcomes; its rationale must be independently reviewed **before freezing**. **Regardless of outcome**, report parallel descriptive retained-magnitude flags for **0.10 and 0.50** using the same observed/excess slopes; these never replace the **sole decision threshold 0.25**.
- **NC-A-directional-only:** observed-panel reproducibility holds and p >= 4, but R_med < 0.25. This means only the *sign* remains in most animals; **do not** describe the residual as substantively surviving.
- **NC-B:** p = 3; **or** the selected observed panel does not reproduce a positive 4/5 trend, or R_med is undefined. No ambiguous discretionary catch-all.
- **NC-C:** observed-panel reproducibility holds and p <= 2.
- **NC-INVALID:** required input provenance, original-graph/Q identity, null topology, algorithmic reproducibility, optimizer trials, or required null replicates fail. No biological classification or post-hoc rescue.

**Monte-Carlo fragility check, predeclared tiered rule:** with 10 G0 replicates, recompute beta_G0_excess from the first five and last five G0 replicates separately in their *fixed assigned index order*. Keep the same beta_obs_10 denominator for each half and calculate p and R_med for each. Report both half-panel slopes and all three classifications, including the full 10-null result. **For an otherwise positive full-panel NC-A result:** if either half fails **directionality** (p < 4), downgrade to **NC-B (MC direction unstable)**; if directionality holds in both halves but either half fails **R_med >= 0.25**, the most positive permitted result is **NC-A-directional-only (MC materiality unstable)**. Only classify **NC-A-material@0.25** if the full result and **both halves** satisfy p >= 4 and R_med >= 0.25. A full-panel NC-C or NC-B cannot be upgraded by halves. No extra null draws may be triggered by the observed result. A larger confirmatory follow-up needs a separate prospective design.

This is a **conditional residual N-dependence classification against G0 only**, not a p-value, proof that the remaining effect is non-artifactual, or a statement about individual D_excess zero crossing. Do not choose a new N range, delete animals, change repeat counts or redefine null-Q based on the result.

## 5. Secondary null T1: within-window independent neuron circular shifts

This null examines whether the measured slope remains when zero-lag cross-neuron coordination is disrupted while preserving each neuron's within-window amplitude distribution and circular temporal structure. It is **secondary and diagnostic**, not another chance to replace a failed NC-A.

On the fixed first 5 of 10 selected subset repeats per recording × finite N, use **5 surrogates** per state-window input. Independently circularly shift **each selected neuron's** S3 sequence within the original state window by an integer offset chosen uniformly from [ceil(L/4), floor(3L/4)] inclusive (L = frames in that window). No cell is shifted as an intact population, no mixing between state windows and no state relabeling. Preserve the selected neuron IDs, window IDs and Wake/NREM status. Recompute correlations, original MST-plus-edges builder, the same 200-repeat Louvain max-Q and paired state contrast.

~~~text
stable_seed(20261009, "NC_T1_SHIFT_V1", recording_id,
            "N" + decimal(N), repeat_id, state, window_id, surrogate_repeat, neuron_id)
stable_seed(20261009, "NC_T1_LOUVAIN_V1", recording_id,
            "N" + decimal(N), repeat_id, state, window_id, surrogate_repeat, louvain_repeat)
~~~

surrogate_repeat = 0..4. Store offsets or their verifiable hashes. Use the same session-median → mouse04 session average → animal-slope pipeline for a T1-adjusted diagnostic, and show the raw observed curve for that **same five-repeat panel**. Compute all five `beta_T1_excess` slopes as observed-minus-surrogate after that paired 5-repeat aggregation, and count strictly positive slopes `p_T1`. Predeclared **secondary descriptive labels only**: `T1-DIRECTIONAL` if p_T1 >= 4; `T1-MIXED` if p_T1 = 3; `T1-NONPOSITIVE` if p_T1 <= 2; `T1-INVALID` for missing/incomplete surrogate or identity artifacts. Additionally flag `T1-OBS-PANEL-MISMATCH` if fewer than four of the five *observed five-repeat* slopes are positive: any T1 direction label under that mismatch is **not** evidence of replication of PS-A. Always report individual slopes and magnitudes irrespective of direction label. None of these labels modifies the primary G0 Gate NC-1, and there is no T1 significance test or post-hoc primary substitution.

Caveats: circular shifting introduces a boundary seam, may not faithfully preserve nonstationary event structure, and cannot by itself identify biological coupling, causal coordination or consciousness. It tests a particular zero-lag surrogate assumption, not all signal-level null hypotheses.

### 6.1 NC-0a synthetic-only quantitative acceptance contract (lock before formal NC-0a)

These are **proposed formal NC-0a criteria** and require independent review and prospective lock before the **16-case prespecified NC-0a run**. They were drafted before formal NC-0a execution, but **not before every informal synthetic calculation**: the R4 reviewer ran a disclosed 4/16-case exploratory check described below, using different chain seeds. That existing exposure must not be concealed or used to retune the acceptance criteria. No real RIKEN null outcomes may be used to revise them.

**Synthetic cases:** at node counts **100, 340, 1150, 3900**, generate one connected graph for each of **four independently defined, purely synthetic families**: (i) connected **ER-like** graph with a seeded random-recursive spanning tree plus independently sampled uniform distinct edges until `8N` total (not exact ER conditional on connectivity); (ii) connected **WS-like** `k=16` ring with `p=0.10` rewiring applied to distances 2–8 while preserving distance-1 cycle edges (not the unconditional WS distribution); (iii) connected **BA-like** degree-proportional attachment with `m=8` and an initial 9-node clique; (iv) **synthetic-correlation-derived MST+top-edges**, matching the *graph-building logic* of the original analysis without using original neural signals. For (iv), generate an `N × 6` matrix of independent pseudorandom standard-normal factor loadings `B` with NumPy `Generator(PCG64(seed))`; the synthetic-only seed is the unsigned big-endian integer of the **first 8 bytes of SHA-256** of ASCII `NC_SYNTH_V1|20261009|factor-mst|N`. This is a new, independent synthetic seed convention, **not** the inherited biological `stable_seed` recipe. Let `C_ij = (B_i · B_j) / sqrt((||B_i||²+1)(||B_j||²+1))` for distinct i,j and `C_ii=1` (a valid correlation matrix for a six-factor signal-plus-unit-noise covariance). Build the **maximum spanning tree using |C_ij|**, tie-breaking by the canonically ordered edge pair, and then add highest-ranked remaining **absolute-correlation** edges until the undirected simple graph has `min(N*(N-1)/2, 8*N)` edges (mean degree 16 where possible). This is a *synthetic analogue*, not a faithful model of Sleep correlations, and leaf count or rejection behavior is **measured**, not assumed. Record all input graph degree histograms, leaf counts, graph hashes, and family-specific seed/generator/dependency versions; for (i)–(iii) use the same SHA-256 first-eight-byte seed derivation with the literal family tokens `er-like`, `ws-like`, `ba-like` in place of `factor-mst`, and Python `random.Random(seed)`; pin Python and NumPy versions before formal NC-0a testing; avoid any source-neuron IDs or observed RIKEN weights.

**Exact synthetic-only seed contract (fully separate from biological `stable_seed`):** concatenate the fields below as **ASCII** with literal `|` separators, take SHA-256, interpret the **first 8 digest bytes as an unsigned big-endian integer**, and use that integer to seed the Python `random.Random` proposal stream; the graph fixture `factor-mst` uses NumPy `Generator(PCG64(seed))`. Set `root = 20261009`, `family ∈ {er-like, ws-like, ba-like, factor-mst}`, `N` in base-10 without leading zeros, and independent chain index `j = 0..7` in base-10. The literal payloads are:

~~~text
graph fixture: NC_SYNTH_V1|20261009|family|N
chain j:       NC_SYNTH_V1|20261009|chain|family|N|j
BFS oracle:    NC_SYNTH_V1|20261009|bfs-identity|family|N
~~~

This seed encoding is implemented in `synthetic_graphs.synthetic_seed` and has explicit unit tests. **Do not** substitute `stable_seed(...)`, reuse another family's/chain's seed, use the reviewer's `random.Random(1000+c)` exploratory seeds, or let scheduler/parallel execution order determine random draws. Persist 16 fixture seeds, all **128 chain seeds** and the 16 separate BFS-oracle seeds with graph fingerprints before formal execution.

Use the fixed root above and **8 independently seeded proposal chains per synthetic graph** (no change to chain count following the informal R4 trial); there are **16 graph cases and 48 prespecified case×metric comparisons**. Each chain is run for **32E attempted proposals**, recording 4E and 32E snapshots from the *same chain*, plus E/2E/8E checkpoints. Synthetic inputs and chain snapshots must remain valid simple connected graphs at every checkpoint. No post-result replacement of a synthetic family or ad-hoc increase to 16/32 chains is authorized by this draft.

**Mixing/stabilization anomaly screen — R3 statistical calibration repair (not a mixing proof):** measure (a) triangle count, (b) degree assortativity and (c) initial-edge overlap `|E_t ∩ E_start| / |E_start|` at the stated checkpoints for **all 16 synthetic graph cases**. For each case×metric, let the **eight independent chains** provide paired differences `d_j = metric_j(4E) − metric_j(32E)` for j=1..8. Compute `mean_d`, sample `sd_d` with denominator seven, and the **paired** statistic `T = |mean_d| / (sd_d/sqrt(8))`. Because 4E/32E snapshots come from the *same* chain, a two-independent-samples SE would ignore pairing.

~~~text
Comparison family: 4 node sizes × 4 synthetic families × 3 metrics = 48.
Nominal familywise alpha: 0.05 (two-sided Bonferroni).
Per-comparison alpha: 0.05 / 48.
Reference distribution: Student t with df=7 for 8 paired chain differences.
Critical t: t_(1 − 0.05/(2×48), 7) = 5.3698626063.
Criterion per comparison: pass screen if T <= 5.3698626063.
If sd_d == 0 and mean_d == 0: T = 0; if sd_d == 0 and mean_d != 0: T = infinity (FAIL).
All 48 comparisons must pass to clear the *anomaly screen*.
~~~

The earlier criterion `|mu_4−mu_32| <= 0.5 × sd_32` is **withdrawn**: even under independent equal-mean draws, it rejects far too frequently. The new criterion is calibrated to **control false rejection from sampling variation approximately** under independent chains and an approximately normal distribution of paired differences; Bonferroni does not require the 48 tests to be independent. With only eight chains, non-normal paired differences, strong temporal dependence, or very low test power may weaken this approximation or permit undetected lack of mixing. **Quantified detection threshold:** `5.3698626063 / sqrt(8) = 1.8985`, so a comparison requires `|mean_d| > 1.8985 × sd_d` to trigger rejection. This is an **observed-SD-dependent critical drift size**, *not* the minimum effect detectable with 80% power or a power analysis; true power varies with noise distribution and effect. Report `5.3698626063 × sd_d / sqrt(8)` in the metric's natural units for **each** of the 48 comparisons, and state that smaller drifts may readily go undetected. The eight-chain count and nominal cutoff remain unchanged. Thus **PASS means only “no detected 4E→32E drift under this screening rule,” never “4E is mixed,” “uniform random graph null,” or “SRT effect independently confirmed.”**

In every case report raw 4E/32E means, eight individual paired differences, sample SD, T, uncorrected and Bonferroni-adjusted two-sided t p-values, the full E/2E/4E/8E/32E diagnostic trajectories, the 48 native-unit critical-drift magnitudes, acceptance/rejection rates, and graph invariants. Mark `MIXING-UNRESOLVED` even after the screen passes: 32E is a long-chain **reference only**, not known stationarity.
