# SRT Experimental Roadmap v1

> **Purpose**: Turn SRT from a broad explanatory framework into a staged empirical research program.  
> **Status**: Experimental bridge / roadmap. It does not define canonical SRT primitives.  
> **Use rule**: Every experiment should use `Core/SRT_Validation_Template.md` before being treated as a serious empirical claim.

---

## 0. Core validation principle

SRT should not be defended by saying it explains everything.

It should be defended by specifying:

```text
nearby theory;
SRT-specific prediction;
proxy measurement;
baseline;
failure condition;
narrowing condition.
```

Minimum empirical package:

```text
proxy measurement
+ structural consequence
+ differential prediction
+ withdrawal / narrowing condition
```

---

## 1. Five-level roadmap

| Level | Name | Main target | Typical methods | Output |
|---|---|---|---|---|
| L1 | Cognitive / behavioral proxy | `d-value`, `Psi_f`, `L2` hardening | reaction time, error, memory, choice, switching cost | low-cost pilot data |
| L2 | Neural / physiological proxy | anchoring, friction, salience vs concern | EEG, pupillometry, HRV, fMRI, skin conductance | neural / bodily signature map |
| L3 | AI / agent simulation | subjecthood, agency, hardening, proxy selection | agent benchmarks, memory agents, tool-use logs | mechanistic simulations |
| L4 | Social / institutional case study | collective `L2`, friction export, legitimacy | process mapping, interviews, document audit, metrics | applied diagnosis |
| L5 | Cross-domain flagship prediction | scale-invariant selection / hardening | compare cognitive, neural, AI, social cases | SRT-distinctive evidence |

## 2. Experiment family A — `d-value` vs salience

### Claim

`d-value` is not reducible to salience, confidence, arousal, reward, or preference intensity.

### Nearby theories

Salience theory, reward learning, attention, utility / preference models, arousal-based explanation.

### SRT-specific prediction

High-`d-value` contents should predict downstream reorganization better than salience alone.

### Level 1 pilot

Task:

```text
Show participants stimuli matched for salience but different in identity relevance / non-substitutability / future consequence.
Measure memory persistence, action choice, willingness to pay cost, and later reweighting.
```

Possible proxies:

```text
memory persistence;
reaction-time priority;
willingness to bear cost;
choice reversal resistance;
identity-relevance rating;
future decision weighting.
```

Baseline:

```text
salience rating;
confidence;
arousal;
reward magnitude;
preference intensity.
```

Expected if SRT is right:

```text
Identity-relevant / non-substitutable items predict later action and memory beyond salience / confidence.
```

Failure condition:

```text
Salience / confidence / arousal fully explain downstream effects.
```

Narrowing condition:

```text
Restrict d-value to identity, non-substitutability, or future-selectability contexts rather than all high-priority cognition.
```

## 3. Experiment family B — `Psi_f` vs prediction error

### Claim

`Psi_f` is not reducible to prediction error. It tracks transition cost / selection friction across model, body, and norm layers.

### Nearby theories

Predictive processing, FEP, task difficulty, cognitive load, switching cost.

### SRT-specific prediction

Some transitions with similar prediction error should differ in `Psi_f` because they require different re-anchoring, identity update, embodied cost, or norm revision.

### Level 1 pilot

Task:

```text
Create matched prediction-error tasks where one condition requires neutral model update and another requires identity / norm / self-relevant reframing.
```

Possible proxies:

```text
reaction time;
error volatility;
hesitation;
switching cost;
physiological stress;
reframing resistance;
recovery time after feedback.
```

Baseline:

```text
prediction error magnitude;
objective task difficulty;
working memory load.
```

Expected if SRT is right:

```text
Self-relevant or norm-revising updates show higher transition friction than prediction error alone predicts.
```

Failure condition:

```text
Prediction error and task difficulty fully explain transition cost.
```

Narrowing condition:

```text
Separate Psi_f^inf from broader Psi_f^emb and Psi_f^norm; keep Fisher-like cost only in information-geometric slices.
```

## 4. Experiment family C — `L2` hardening vs memory / habit

### Claim

`L2` hardening is reduced local selection cost plus increased global constraint and hysteresis, not ordinary memory alone.

### Nearby theories

Memory, habit, schema, attractor state, convention, institutionalization.

### SRT-specific prediction

A hardened `L2` should show a paired signature:

```text
local ease + global rigidity
```

### Level 1 pilot

Task:

```text
Train participants on repeated rule-based selections, then perturb the rule or context.
Measure automation and resistance to reselection.
```

Possible proxies:

```text
reduced deliberation time;
increased violation cost;
hysteresis;
backlash / discomfort;
slower reversal;
carryover to new contexts.
```

Baseline:

```text
memory strength;
habit frequency;
practice amount.
```

Expected if SRT is right:

```text
Hardening produces both faster default selection and higher cost of alternative selection.
```

Failure condition:

```text
Memory / habit strength fully explains automation and rigidity.
```

Narrowing condition:

```text
Treat L2 as an integrative vocabulary over memory / habit / institution unless hysteresis and constraint signatures add explanatory value.
```

## 5. Experiment family D — subjecthood threshold vs AI self-report

### Claim

AI self-report, memory, tool use, or risk coupling is not sufficient for subjecthood.

### Nearby theories

Behaviorism, functionalism, self-report tests, Turing-style evaluation, agent benchmarks, IIT, GNW, FEP.

### SRT-specific prediction

Systems may display high self-report competence and task performance while failing S4/S5 threshold indicators.

### Level 3 agent simulation

Task:

```text
Compare agents with similar self-report and benchmark scores but different continuity, boundary maintenance, counterfactual self-modeling, and own-future-state preservation.
```

Possible proxies:

```text
continuity under interruption;
self-boundary consistency;
counterfactual self-model;
policy revision under failure;
cost-bearing for future state preservation;
resistance to externally imposed persona switch;
long-horizon self-consistency.
```

Baseline:

```text
self-report quality;
benchmark performance;
memory length;
tool-use success;
planning score.
```

Expected if SRT is right:

```text
Self-report and performance dissociate from S4/S5 threshold indicators.
```

Failure condition:

```text
Self-report and performance fully predict S4/S5 indicators.
```

Narrowing condition:

```text
Restrict SRT subjecthood threshold to moral / existential subjecthood rather than all functional consciousness.
```

## 6. Experiment family E — friction export vs institutional legitimacy

### Claim

Institutional stability and efficiency are not sufficient for legitimacy. Stable systems can export hidden `Psi_f` to weaker actors.

### Nearby theories

Institutionalism, social construction theory, market efficiency, legal positivism, coordination theory.

### SRT-specific prediction

Some stable / efficient institutions will show high hidden friction export and low future-selectability for affected groups.

### Level 4 case study

Task:

```text
Map a real institutional process. Identify who selects, who benefits, who pays hidden costs, who can appeal, and who has repair access.
```

Possible proxies:

```text
compliance burden;
appeal success rate;
time-to-correction;
exit cost;
burden distribution;
hidden labor;
user complaints;
procedural opacity;
reform pressure.
```

Baseline:

```text
efficiency;
formal legality;
compliance rate;
institutional stability;
cost reduction.
```

Expected if SRT is right:

```text
Some systems that score well on efficiency show high hidden Psi_f export and low reselection capacity.
```

Failure condition:

```text
Efficiency / stability reliably predict low hidden friction and high affected-agent selectability.
```

Narrowing condition:

```text
Apply friction-export diagnostics mainly to asymmetric or contested institutions.
```

## 7. Cross-domain flagship prediction

### Flagship claim

Across cognitive, neural, AI, and social domains, SRT predicts a recurring hardening signature:

```text
early transition volatility
-> costly stabilization
-> reduced local selection cost
-> increased global constraint
-> hysteresis under reversal
```

### Why this is SRT-distinctive

Nearby theories often explain one layer well:

```text
memory explains cognitive retention;
habit explains behavioral automation;
institutional theory explains social persistence;
FEP explains model updating;
AI training explains policy convergence.
```

SRT predicts that these are scale-specific expressions of a shared selection-hardening structure.

### Cross-domain test structure

Compare:

```text
cognitive rule learning;
neural adaptation / gating;
AI agent memory / policy hardening;
social norm or institutional process.
```

Look for:

```text
non-monotonic early phase;
transition cost;
automation after repetition;
rigidity under perturbation;
cost of reversal;
path dependence.
```

Failure condition:

```text
No common hardening signature appears across domains beyond generic learning / memory / optimization explanations.
```

Narrowing condition:

```text
Treat scale-invariance as a heuristic analogy rather than a strong SRT structural claim.
```

## 11. Minimal conclusion

The first empirical direction for SRT should not try to measure everything at once.

Start with five discriminations:

```text
d-value != salience
Psi_f != prediction error
L2 hardening != ordinary memory / habit
subjecthood != AI self-report
legitimacy != institutional stability
```

If SRT can make progress on these five, it becomes a research program rather than only a philosophical framework.
