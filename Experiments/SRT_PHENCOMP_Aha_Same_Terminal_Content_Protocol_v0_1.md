# Phenomenal Compression P4 Protocol v0.1 — Same Terminal Content, Different Formation Path

> **Decision first:** this is a **parked / pre-pilot design**, not an active execution queue item and not a preregistration. It exists to test whether the dialogue-generated phenomenal-compression hypothesis can survive a clean ordinary-rival audit before any larger consciousness claim is attempted.
>
> The protocol is intentionally narrow. It does not attempt to prove phenomenality, define qualia, measure canonical `d` or `Psi_f`, or identify Aha with Selection.

---

## 0. Single question

Hold terminal perceptual content as constant as practicable while varying how that content is reached.

Ask:

> **Does independently measured pre-to-post candidate-space deformation add held-out predictive value for Aha transition phenomenology beyond terminal content, confidence, processing fluency, arousal/pleasantness, attention and item difficulty?**

The target is an HP-C / qualitative-character bridge only.

```text
same terminal content
+
different formation path
-> different candidate-space deformation?
-> different transition phenomenology?
```

The experiment does **not** test:

```text
deformation -> consciousness
attractor -> phenomenality
bearing -> experiencer
```

---

## 1. Claim package

### 1.1 P4 claim under test

A task-specific qualitative episode may sometimes covary with a transient compression / reshaping of an unresolved candidate field, such that the immediate next-selection landscape becomes more directional.

The stronger dialogue-generated bridge remains explicitly open:

```text
bearing-indexed directional non-neutrality
-> ?
lived directional non-neutrality
```

This protocol tests only whether measurable transition geometry adds explanatory / predictive structure to the **character and strength of Aha phenomenology**.

### 1.2 Nearby theories / ordinary rivals

At minimum, the result must compete against:

```text
R0 terminal representation / correctness
R1 confidence / certainty
R2 processing fluency / response time
R3 arousal / pleasantness / reward-like evaluation
R4 attention / salience
R5 item / task difficulty
R6 generic mismatch / prediction-error-style update pressure where operationally available
```

No SRT-specific increment is claimed if these rivals absorb the effect under a fair information budget.

### 1.3 Claim level discipline

```text
positive result -> bounded P4 support for an HP-C bridge
null result     -> narrow / weaken phenomenal-compression D-track
negative result -> possible retirement of the proposed incremental mechanism
```

No outcome upgrades HP-B phenomenal necessity.

---

## 2. Experimental object

Use ambiguous / Mooney-style images for which a stable physical stimulus can become a coherent recognized object.

Core reason:

```text
external image can remain stable
while
internal organization / accessibility changes strongly
```

The terminal content should be a recognizable object identity, e.g. `DOG`, but **the protocol does not depend on DOG specifically**.

### 2.1 Anti-carryover rule

The same participant should not experience the same ambiguous item in more than one formation condition before the primary endpoint, because one-shot disambiguation can permanently alter later perception.

Therefore use item-by-participant counterbalancing:

```text
participant i, item j -> exactly one formation condition

across participants:
each item appears in all conditions
```

A Latin-square / balanced assignment is preferred.

---

## 3. Formation conditions

All conditions must end in the same intended recognized object class, with correctness verified.

### Condition A — Direct reveal

The solution is supplied with minimal search demand, for example by a clear canonical image / explicit solution cue followed by the ambiguous image.

Target profile:

```text
low unresolved search
low self-generated restructuring demand
same final recognized content
```

### Condition B — Gradual disambiguation

Information is increased progressively through a preregistered cue sequence until recognition occurs.

Target profile:

```text
distributed / gradual reduction of ambiguity
same final recognized content
```

### Condition C — Unhinted self-generated recognition

The ambiguous image is presented without solution cue; the participant searches until recognition or timeout and reports the transition.

Target profile:

```text
maximum opportunity for self-generated Aha
same final recognized content when solved
```

### 3.1 Important limitation

Condition C cannot guarantee an Aha on every trial. Therefore:

- formation condition is the manipulation;
- Aha phenomenology is measured continuously, not defined by condition membership;
- confirmatory analyses must not silently discard low-Aha successful C trials;
- unsuccessful / incorrect trials are retained for predefined secondary analyses rather than post-hoc deletion.

---

## 4. Measurement architecture

The central methodological requirement is that deformation measures are **not constructed from the same phenomenology ratings they are supposed to predict**.

Use three stages:

```text
PRE -> TRANSITION -> POST
```

### 4.1 PRE — unresolved candidate field

Candidate measures must be as non-intrusive as possible because repeated explicit guessing can itself alter insight.

Candidate families:

```text
candidate diversity / number of live interpretations
candidate switching / revision rate
uncertainty / response-distribution entropy proxy
search duration
```

#### Measurement-feasibility gate

Before the confirmatory pilot, compare at least two PRE measurement methods, e.g.:

```text
M1 sparse candidate probes at fixed preregistered times
M2 low-intrusion continuous confidence / candidate-presence reporting
```

Do **not** use retrospective reconstruction of “what I was thinking before Aha” as the sole PRE measure.

If the PRE measurement itself materially changes Aha incidence / timing relative to a no-probe control, the protocol is not yet interpretable.

### 4.2 TRANSITION — phenomenology

Measure separately:

```text
suddenness
rightness / obviousness
relief
pleasantness
confidence / certainty
arousal
optional urgency / pull
```

Do not collapse these into one Aha scalar before the main analysis.

### 4.3 POST — independently observable landscape change

Primary candidate families:

```text
alternative suppression
switching cost to a plausible competing interpretation
old-interpretation / ambiguity recoverability
attention allocation to newly diagnostic features
transfer to related ambiguous stimuli
```

Secondary / delayed outcomes:

```text
memory weighting
24h / multi-day recognition persistence
reopening cost
```

The v0.1 primary claim should not depend on delayed memory.

---

## 5. No new canonical deformation scalar

This protocol deliberately does **not** introduce a new SRT symbol or a single “compression score”.

The primary deformation evidence is a preregistered multivariate feature set spanning PRE and POST:

```text
candidate concentration / diversity change
switching change
alternative suppression
recoverability / switching cost
```

A later scalar is allowed only as an empirical summary after reliability and out-of-sample value are established. It must not be identified with `Psi_f`, `d`, `RDef_B`, valence or consciousness.

---

## 6. Primary predictions

### P4-AHA-1 — formation-path effect

After terminal content is matched, formation paths should differ in transition phenomenology and independently measured candidate-space change.

Expected ordering is a **candidate**, not a required theorem:

```text
self-generated Aha
> gradual disambiguation
> direct reveal
```

for suddenness / local closure and some deformation measures.

A different ordering does not automatically falsify the theory; the central test is continuous deformation-to-phenomenology prediction.

### P4-AHA-2 — incremental prediction

The preregistered deformation feature set should improve held-out prediction of one or more transition-phenomenology dimensions beyond ordinary rivals.

The strongest expected targets are:

```text
suddenness
rightness / obviousness
relief
```

Confidence and pleasantness are explicit competitors, not proxies for the target mechanism.

### P4-AHA-3 — dissociation discipline

The protocol must permit:

```text
restructuring / deformation without strong Aha
and
strong Aha-like report without large measured deformation
```

These are empirical dissociations to explain, not cases to redefine away.

---

## 7. Primary analysis discipline

### 7.1 Unit structure

Use participant- and item-aware analysis because both subjects and ambiguous images vary substantially.

Minimum analysis family:

```text
mixed-effects model and/or hierarchical predictive model
with participant + item structure
```

### 7.2 Nested rival comparison

Pre-freeze nested models before looking at the confirmatory data.

```text
M0: terminal content / item + task difficulty + RT
M1: M0 + confidence + arousal + pleasantness + attention / salience proxies
M2: M1 + preregistered deformation feature set
```

Where a prediction-error / mismatch proxy is available, include it in M1 rather than granting it less information than M2.

### 7.3 Information-budget fairness

If flexible machine-learning models are used:

- use the same train/test splits;
- match feature-access rules as closely as possible;
- match tuning budget / regularization procedure;
- compare held-out performance, not training fit;
- report uncertainty of the incremental gain.

A more flexible M2 defeating a deliberately weak rival does not count as D-track evidence.

### 7.4 Primary criterion

The P4 D-track survives only if deformation features add reproducible held-out predictive value beyond the frozen ordinary-rival model.

No fixed effect-size threshold is frozen in v0.1; it must be set only after feasibility data establish measurement reliability and plausible variance.

---

## 8. Falsification / narrowing conditions

### F1 — vivid Aha without measurable deformation

If strong suddenness / rightness / relief repeatedly occurs without detectable PRE->POST change in candidate accessibility, switching, suppression or recoverability, the compression interpretation weakens.

### F2 — strong deformation without phenomenology

If strong candidate-space deformation repeatedly occurs under matched access / attention / report opportunity with stable absence of Aha phenomenology, deformation is not sufficient for Aha experience.

This result is compatible with the existing guard:

```text
attractor / deformation !-> phenomenality
```

but weakens any strong constitutive HP-C reading.

### F3 — ordinary-variable absorption

If confidence, fluency / RT, arousal, pleasantness, attention / salience, task difficulty and available mismatch variables fully absorb the deformation effect under a fair information budget, the SRT-specific D-track fails.

Retain only O-track descriptive organization if useful.

### F4 — terminal-content confound

If the three conditions cannot be made comparable in final recognized content / correctness / item difficulty, the central same-terminal-content inference is not identified.

### F5 — measurement reactivity

If PRE candidate probing materially creates, suppresses or delays Aha relative to a no-probe control, the current protocol is **UNINTERPRETABLE** until the measurement method is redesigned.

---

## 9. STOP rules before confirmatory execution

Do not run a powered confirmatory study until all of the following pass:

```text
STOP-0 Measurement gate:
PRE measurement has acceptable reliability without large Aha reactivity.

STOP-1 Terminal-content gate:
conditions can achieve comparable correct terminal recognition.

STOP-2 Condition-density gate:
self-generated recognition yields enough successful trials without extreme post-selection.

STOP-3 Proxy gate:
at least one PRE and one POST deformation measure show usable within-person / between-item variance and test-retest or split-half stability where appropriate.

STOP-4 Rival gate:
a bounded literature / model audit confirms that the proposed M2 test is not merely a renamed confidence / fluency / attention test.
```

Failure of a STOP gate means **redesign / park**, not “collect more data until significant”.

## 10. Interpretation matrix

| Result | Admissible interpretation | Forbidden interpretation |
|---|---|---|
| M2 adds robust held-out prediction | candidate-space deformation contributes to Aha qualitative-character prediction | deformation causes consciousness |
| deformation effect fully absorbed by rivals | D-track fails / narrow to ordinary fluency-confidence-attention account | SRT secretly still explains it |
| strong deformation, weak Aha | deformation is not sufficient; preserve dissociation | participants “must have had unconscious qualia” |
| strong Aha, weak deformation | compression model weakened or measurement inadequate; discriminate prospectively | redefine deformation post hoc |
| direct reveal ~= self-generated Aha after controls | self-generation / transition-path hypothesis weakened | terminal content alone proves qualia theory |

## 11. Stage structure

### Stage 0 — bounded rival + measurement audit

Goal:

- choose minimally reactive PRE proxy;
- freeze ordinary rivals;
- verify condition feasibility;
- define primary outcome(s).

Output:

```text
GO -> Stage 1 pilot
REDESIGN -> revise protocol
STOP -> park D-track
```

### Stage 1 — low-cost behavioral pilot

No neural measurement required.

Primary goals:

```text
reliability
condition separability
candidate-space measurement viability
rival-model comparison feasibility
```

Stage 1 is not confirmatory evidence for phenomenality.

### Stage 2 — confirmatory behavioral replication

Only after Stage 1 freezes:

```text
sample-size logic
primary outcomes
model comparison
exclusion rules
STOP / failure criteria
```

### Stage 3 — optional neural / physiological extension

Only if behavioral D-track survives.

Possible additions:

```text
EEG / MEG transition timing

fMRI representational-change replication
```

Neural correlates do not replace the behavioral rival test.

## 12. Relation to automation prediction

The dialogue-generated hook also predicts that successful automatization may reduce strong task-specific qualitative recruitment and policy failure may recruit it again.

That is **not part of the primary v0.1 Aha experiment**.

If the same-terminal-content protocol survives, a separate Stage-2/Stage-3 experiment may test:

```text
novel unresolved task
-> practice / automatization
-> surprise rule change
```

while distinguishing task-specific qualitative prominence from total consciousness.

Do not add this manipulation to the first pilot.
