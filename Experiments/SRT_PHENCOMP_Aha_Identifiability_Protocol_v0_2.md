# Phenomenal Compression P4 Protocol v0.2 — Identifiability Before Execution

> **Decision first:** this protocol is **PARKED / PRE-PILOT**. It is not an active execution item, not a preregistration and not authorization to recruit participants.
>
> v0.2 preserves the useful skeleton of v0.1 — matched terminal object identity, different formation paths, PRE / TRANSITION / POST separation, ordinary-rival comparison — but withdraws the stronger claim that the original design had already identified “same terminal content.” Terminal representational equivalence must be measured rather than assumed.

---

## 0. What changed from v0.1

The method review exposed four identification debts:

```text
PRE measurement can alter the slope it is meant to estimate;
clock-time PRE measures can absorb RT / time-to-transition;
object-label identity does not establish terminal-state equivalence;
rival models can be unfairly feature-poor relative to deformation models.
```

v0.2 therefore makes four structural changes:

1. **Condition A becomes a benchmark, not a core PRE-deformation arm.**
2. **Conditions B and C form the primary PRE→POST comparison.**
3. **terminal object identity is matched; terminal representational equivalence is an empirical GO gate.**
4. **Stage 0 becomes an identifiability audit, not merely a feasibility / literature audit.**

A fifth correction is conceptual:

```text
absence of Aha-specific phenomenology
!= absence of phenomenality
```

Therefore this human Aha protocol does **not** output direct empirical evidence for or against the PH-CONSC04 “phenomenally empty architecture” question.

---

## 1. Single bounded question

Primary question:

> **Among trials that reach the same intended object identity, and only after terminal-state differences are measured and controlled / bounded, do independently measured candidate-space deformation features add held-out predictive value for Aha suddenness beyond equally rich ordinary rivals?**

The target is an HP-C / qualitative-character bridge.

This protocol does not test:

```text
deformation -> consciousness
bearing -> experiencer
absence of Aha -> phenomenal emptiness
attractor -> phenomenality
pressure trajectory = Psi_f
```

---

## 2. Experimental logic

### 2.1 Core comparison: B vs C

The primary inferential comparison is:

```text
B — gradual externally supported disambiguation
C — unhinted self-generated recognition
```

Both conditions contain a genuine unresolved interval in which a PRE candidate field can in principle be measured before recognition.

### 2.2 Benchmark only: A

Condition A remains useful as a low-search benchmark:

```text
A — direct verbal/category reveal
```

But A is **excluded from the primary PRE→POST deformation regression** because its pre-reveal state is not measurement-equivalent to the unresolved search field in B/C.

A may contribute to:

- terminal-state benchmarking;
- transition-phenomenology benchmarking;
- descriptive checks on how much endogenous search matters.

It must not be used to manufacture a three-point PRE ordering.

### 2.3 No clear-image reveal before the primary endpoint

The v0.1 example `clear canonical image -> ambiguous image` is withdrawn.

Before the primary endpoint, Condition A should use a preregistered **verbal / category-level cue** while keeping the ambiguous visual stimulus physically unchanged as far as practicable.

Reason:

```text
clear-image exposure
-> visual priming / one-shot perceptual learning / target-template exposure
-> terminal-state confound in the same direction as the Becker RC measure
```

A clear image may be shown only after all primary transition and terminal-state measures that would be contaminated by that exposure are complete.

---

## 3. Formation conditions

### Condition A — direct verbal reveal benchmark

Example:

```text
ambiguous image remains on screen
+
brief preregistered category / solution label
```

Target profile:

```text
minimal endogenous search
same intended terminal object identity
no pre-endpoint clear-image exposure
```

A does not enter the core PRE-deformation model.

### Condition B — gradual disambiguation

Use a fixed, item-specific, preregistered cue schedule.

Rules:

- cue content and cue timing are fixed before data collection;
- there is no adaptive branching based on the participant's guesses;
- recognition can terminate the cue sequence;
- cumulative cue dose at recognition is recorded;
- cue dose is treated as an ordinary explanatory variable / sensitivity factor, not hidden inside deformation.

Because cue count is partly determined by recognition time, it is not a clean exogenous quantity. Any B-vs-C interpretation must report sensitivity to cue dose and time-to-recognition.

### Condition C — unhinted self-generated recognition

Present the ambiguous image without solution cues until recognition or timeout.

Condition membership does not define Aha. Suddenness and other transition phenomenology are measured continuously.

### 3.1 Anti-carryover rule

Each participant-item pair appears in only one formation condition before the primary endpoint.

Across participants, items are counterbalanced across conditions.

One-shot perceptual learning is therefore contained within a participant-item trajectory rather than allowed to contaminate another condition for that same participant-item pair.

---

## 4. Terminal state: identity matched, equivalence measured

### 4.1 Replace the old assumption

Do not write:

```text
same DOG label -> same terminal representation
```

Use:

```text
same intended object identity
+
independent terminal-state battery
-> test whether terminal states are equivalent enough for the planned inference
```

Becker-style evidence already motivates this caution: post-solution representations can vary in the degree to which they resemble clear-object representations, and that variation can track insight strength.

### 4.2 Terminal-state battery

The same battery must be administered across A/B/C after recognition and before any clear-image exposure that would contaminate it.

Candidate components:

1. **near-neighbor forced choice** — target vs plausible lure classes;
2. **generalization probe** — recognition of a preregistered transformed / degraded derivative not previously shown;
3. **target-lure similarity profile** — after the primary endpoint, rate similarity to a clear target and matched lures;
4. **recognition latency / stability on a held-out variant** — treated as part of terminal characterization, not as proof of representational identity.

No single component is privileged in v0.2. Stage 0 must select and reliability-test a bounded battery.

### 4.3 Terminal-equivalence GO rule

Before confirmatory execution, freeze local equivalence bounds for the selected terminal-state measures.

Test-local placeholders:

```text
TERM_SESOI_k = smallest terminal-state difference judged materially relevant
```

These are not SRT variables or canonical symbols.

GO requires either:

- equivalence within the frozen bounds on the primary terminal-state measures; or
- a predeclared analysis that conditions on measured terminal-state differences and narrows the claim accordingly.

If neither is possible:

```text
STOP: the “matched terminal state” inference is not identified.
```

Correct object labels alone do not satisfy this gate.

---

## 5. PRE candidate field: claim-preserving measurement

### 5.1 Core PRE scope

Confirmatory PRE candidate-field inference is restricted to B/C.

Condition A has no assumed measurement-equivalent unresolved PRE field and is not included in the primary PRE correlation / prediction analysis.

### 5.2 Temporal anchor

Primary PRE predictors must be **stimulus-onset locked** or otherwise externally scheduled.

They must not be defined by back-locking to the participant's reported Aha time.

Preferred structure:

```text
externally defined onset windows
T0-T1, T1-T2, ...
```

Recognition / Aha time is modeled separately as an event-time / RT variable.

Transition-locked plots are allowed only as secondary descriptive analyses and cannot supply the confirmatory predictor that is supposed to predict transition phenomenology.

### 5.3 Search duration is a rival, not deformation

Remove search duration / RT from the candidate-space deformation feature family.

Keep:

```text
RT / time-to-recognition -> ordinary-rival block
```

Candidate-space deformation must add information beyond how long search lasted.

### 5.4 PRE measurement families

Use distinct names to avoid collision with model labels.

#### PM-A — content-sensitive sparse candidate probe (preferred)

A probe must retain information about **which interpretations are live**, not only how confident the participant feels.

Possible implementations:

- one externally scheduled candidate report per trial;
- a preregistered candidate/lure set derived from independent norming plus `other / none`;
- sparse open-ended candidate report with blinded semantic coding.

A useful low-reactivity design is a staggered single-probe scheme in which different trials are probed at different externally assigned onset times rather than repeatedly interrogating every trial.

#### PM-B — confidence / candidate-presence trajectory (diagnostic fallback)

A low-intrusion confidence-like signal may be measured for feasibility and rival modeling.

But:

```text
confidence-only PRE
!= candidate-space deformation evidence
```

If Stage 0 finds that only PM-B is reliable and nonreactive, the claim changes.

Allowed downgrade:

> confidence dynamics predicts Aha transition phenomenology beyond confidence level.

Forbidden rescue:

> call confidence dynamics “candidate-space deformation” and retain the original D-track claim.

PRE proxy selection is therefore **claim-altering**, not merely a feasibility decision.

---

## 6. Probe reactivity: test mean and slope effects

### 6.1 Mean reactivity is insufficient

A no-probe comparison can test whether probing changes:

- Aha / recognition incidence;
- recognition timing;
- mean suddenness.

But it cannot by itself test whether probing changes the **deformation→phenomenology slope**, because the no-probe arm has no PRE deformation measure.

### 6.2 Probe-density diagnostic

Stage 0B must include at least two probed densities / schedules with the same construct target, for example:

```text
low-density sparse probe
vs
higher-density diagnostic probe
```

plus a no-probe benchmark when useful.

The critical diagnostic is whether:

```text
beta(candidate-space measure -> primary phenomenology)
```

changes materially with probe density / schedule.

If the slope is probe-dependent beyond a frozen tolerance:

```text
REDESIGN: the measurement is constitutively reactive for the target inference.
```

Probe-density manipulation is a preferred low-cost test, not the only logically possible reactivity test.

---

## 7. TRANSITION phenomenology

### 7.1 Single confirmatory primary outcome

Primary outcome:

```text
suddenness
```

Reason: it is closest to the transition claim and less definitionally entangled with confidence or pleasantness than several alternatives.

### 7.2 Secondary outcomes

Confirmatory secondary family:

```text
rightness / obviousness
relief
```

Use a preregistered multiplicity correction, e.g. Holm across the secondary family.

### 7.3 Exploratory / control outcomes

```text
pleasantness
confidence / certainty
arousal
urgency / pull
```

These can function as rivals, controls or exploratory outcomes but cannot be promoted post hoc to rescue a failed primary result.

### 7.4 PH_MR01 guard

```text
subjective suddenness
!= demonstrated neural discontinuity
!= ontological phase transition
```

---

## 8. POST deformation measures

POST measures must be independent of the phenomenology ratings they are used to predict.

Candidate families:

- suppression of the strongest plausible alternative;
- cost of switching to / entertaining a plausible competitor;
- ambiguity recoverability;
- attention to newly diagnostic features;
- transfer / generalization to held-out related ambiguous stimuli.

Delayed memory and long-horizon reopening remain secondary extensions and are not required for the first behavioral test.

Stage 0 must freeze **one primary deformation endpoint** or a fully prespecified multivariate summary before any confirmatory GO.

Local placeholder:

```text
D_PRIMARY
```

This is a test-local label only. It is not `RDef_B`, `Psi_f`, `d`, valence or consciousness.

---

## 9. Rival-model fairness

### 9.1 Separate measurement names from model names

Use:

```text
PM-* = PRE measurement methods
RM-* = rival / nested predictive models
```

### 9.2 Core model family for B/C

Illustrative structure to freeze after Stage 0:

```text
RM0:
item / participant structure
+ condition B/C
+ RT / time-to-recognition
+ item difficulty
+ cue dose where applicable
+ measured terminal-state battery

RM1:
RM0
+ confidence / certainty
+ arousal / pleasantness
+ attention / salience proxies
+ available mismatch / prediction-error-style proxies

RM2:
RM1
+ preregistered content-sensitive candidate-space deformation features
```

A positive D-track requires RM2 to improve held-out prediction of the primary outcome beyond RM1.

### 9.3 Same-function-form parity

Fairness is not only equal train/test splits or equal tuning budget.

If RM2 receives a temporal transform such as:

```text
slope
variance
within-trial delta
change magnitude
switching rate
trajectory curvature
```

then RM1 must, where the rival signal supports it, receive the **same function class** applied to confidence, arousal, attention, RT-derived or other rival trajectories.

Do not compare:

```text
rich deformation time series
vs
one scalar confidence
```

and call the resulting gain SRT-specific.

### 9.4 Equal modeling opportunity

Where flexible models are used:

- same train/test partitions;
- same hyperparameter / tuning budget;
- same regularization-selection procedure;
- same leakage rules;
- participant/item-aware splits where appropriate;
- held-out performance with uncertainty intervals.

A more expressive feature representation or model class must not be granted only to RM2.

---

## 10. Effect-size and equivalence discipline

v0.2 remains formal V4 / pre-V5 because numeric thresholds are not yet frozen.

However, a future GO is forbidden until Stage 0 freezes three local decision scales from independent literature, norming or feasibility data not reused as confirmatory evidence:

```text
TERM_SESOI  terminal-state material-equivalence bound(s)
DEF_SESOI   smallest meaningful deformation effect / equivalence bound
PRED_SESOI  smallest held-out predictive increment worth retaining D-track
```

These are local protocol placeholders, not theory symbols.

### 10.1 Positive criterion

A confirmatory positive result requires held-out incremental prediction at or above the frozen `PRED_SESOI`, with uncertainty compatible with the strengthening claim.

### 10.2 Null / narrowing criterion

Use an equivalence / ROPE / TOST-style branch appropriate to the chosen metric so that a practically negligible effect can be affirmatively identified rather than described only as “non-significant.”

Examples:

```text
candidate deformation equivalent to negligible range despite vivid Aha
-> F1-style pressure

RM2 increment equivalent to < PRED_SESOI
-> ordinary-rival absorption / D-track narrowing
```

The exact statistical implementation is frozen only after the endpoint and metric are fixed.

---

## 11. Falsification / narrowing conditions

### F1 — vivid Aha-specific phenomenology without meaningful deformation

If high suddenness repeatedly occurs while the primary deformation endpoint is equivalent to a preregistered negligible range, the compression interpretation weakens.

### F2 — strong deformation with weak / absent Aha-specific phenomenology

If strong candidate-space deformation occurs while Aha-specific transition phenomenology is weak / absent under a validated report instrument, then:

```text
deformation is not sufficient for Aha qualitative character
```

This protocol must **not** infer:

```text
weak / absent Aha report
-> absence of phenomenality
-> direct PH-CONSC04 zombie evidence
```

Human participants may remain richly conscious of the stimulus, uncertainty, effort and other contents while lacking a strong Aha transition.

PH-CONSC04 remains a **theory-level conceptual pressure** on the owner hook, not an empirical output of this human Aha task.

Aha-report sensitivity should nevertheless be checked using validated scales and positive-control trials / participants so that measurement floor is not confused with absence of Aha-specific phenomenology.

### F3 — ordinary-rival absorption

If RM2's held-out gain over a feature-parity RM1 is equivalent to less than `PRED_SESOI`, the SRT-specific D-track fails / narrows.

### F4 — terminal-state nonequivalence

If B/C terminal states are not equivalent within frozen bounds and measured differences cannot be adequately conditioned without changing the claim, the core formation-path inference is not identified.

### F5 — measurement reactivity

If PRE probing materially changes either:

- Aha incidence / timing; or
- the candidate-space→suddenness slope,

beyond frozen tolerances, the current measurement method is not confirmatory-ready.

### F6 — claim-preserving proxy failure

If no reliable nonreactive content-sensitive PRE proxy survives and only confidence-like PM-B survives, candidate-space D-track is downgraded / parked rather than relabeled.

## 12. Interpretation matrix

| Result | Admissible interpretation | Forbidden interpretation |
|---|---|---|
| RM2 > RM1 by frozen meaningful increment, terminal gate passes | bounded support that candidate-space deformation adds predictive structure to Aha suddenness | deformation causes consciousness |
| RM2 gain equivalent to negligible range | D-track narrows toward ordinary confidence / fluency / attention accounts | “SRT still explains it secretly” |
| strong deformation + weak Aha | deformation not sufficient for Aha-specific qualitative character | phenomenally empty human / zombie evidence |
| strong Aha + negligible deformation | compression model weakens or measurement fails; adjudicate by preregistered reliability rules | redefine deformation after seeing data |
| terminal-state gate fails | formation-path claim not identified | label identity is “close enough” by assertion |
| only confidence-like PRE survives | downgrade to confidence-dynamics claim | call confidence dynamics candidate-space deformation |

No participant recruitment.

Output:

```text
DESK-GO -> eligible for separately authorized Stage 0B
REDESIGN -> revise protocol
STOP -> park D-track
```

### Stage 0B — micro-feasibility / norming

Requires explicit later authorization; it is not authorized by this PR.

Goals:

- terminal-battery reliability and discriminability;
- candidate/lure norming for PM-A;
- probe-density mean- and slope-reactivity test;
- B/C recognition density and timing;
- cue-dose behavior;
- report-scale sensitivity / positive controls;
- preliminary variance needed to freeze decision bounds without using confirmatory data.

Stage 0B is measurement engineering, not evidence for phenomenality.

### Stage 1 — low-cost behavioral pilot

Only after Stage 0A/0B gates pass.

Goal: test whether the entire analysis pipeline can run without severe leakage, terminal-state imbalance or proxy collapse.

Stage 1 is still not confirmatory evidence for HP-B.

### Stage 2 — confirmatory behavioral replication

Only after Stage 1 freezes:

- sample-size / precision logic;
- all SESOI / equivalence bounds;
- primary endpoint and secondary correction;
- PM-A implementation;
- terminal-state gate;
- RM0/RM1/RM2 feature sets and transforms;
- held-out evaluation scheme;
- failure / narrowing rules.

### Stage 3 — optional neural / physiological extension

Only if the behavioral D-track survives.

Possible additions:

```text
EEG / MEG transition timing
pupillometry / autonomic controls
fMRI representational-change replication
```

Neural measurement does not repair a failed behavioral identification strategy.
