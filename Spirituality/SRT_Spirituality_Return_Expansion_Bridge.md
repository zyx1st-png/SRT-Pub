## 1. Why this bridge exists

新建的 Spirituality 双线已经形成了一个清楚的主轴：

- canonical line：`SRT_Spirituality_Selection_Pathology_and_Return.md`
- companion line：`SRT_Spirituality_How_We_Lose_Ourselves_and_Return.md`

但仓库中仍有一批先前分散写入其他文档的内容，与这条新主轴高度同构：

1. `Philosophy/SRT_SocTheory_06_L2_Dynamics.md`
2. `Spirituality/SRT_Spirit_07_Meditation_Neuro.md`
3. `Spirituality/SRT_Spirit_09_Praxis.md`

这些材料若直接无差别并入双线正文，会带来两个风险：
- A 线（canonical spirituality）过胖、失焦
- B 线（companion exposition）被旧 praxis 细节淹没

因此本 bridge 只做一件事：

> **把可迁移内容按“最适合加入 A 线 / 最适合加入 B 线 / 暂不建议重搬”三类整理出来，为后续精准回写提供桥。**

## 2. Most valuable source cluster: `SRT_SocTheory_06_L2_Dynamics.md`

这份文件虽属社会理论，但其中已经沉积了一整簇与新 spirituality 轴高度同构的内容。

### 2.1 Necessary Chaos / Floor–Direction / Protective Closure cluster

最有价值的现成材料在：
- `§5.4 Integration Note (2026-04-18): Necessary Chaos, Floor/Direction, and L2 Pathology`

其已成熟的关键命题包括：

- 必要混沌不是单纯打碎，而是**地板与方向重新分离**
- 保护性封闭不只是拖延定型，而是**保护 `L_0` 入口继续存活**
- `L_2` 的病理不是提供稳定，而是把稳定本身抬升为最高价值
- 空心感必须区分：
  - **病理空心感**：空心 → 恐惧 → 抱紧旧地板 → 麻痹 → 更深空心
  - **苏醒性空心感**：空心 → 旧地板失效 → 悬置危机 → 开放 → 新地板重建
- 选择开始死亡的最早社会信号，是：
  - 痛苦、空心感、异样都被过快翻译回现成模板

- 为什么很多“成熟解释”其实是在过快封口

## 3. Hollow Subject cluster: modern L2-dominant environments

`SRT_SocTheory_06_L2_Dynamics.md` 中另一簇极适合迁移的内容是：

- `VII. L2主导环境与L0→L1选择能力衰退`

这是新双线当前尚未真正吸收、但与其高度吻合的一组核心材料。

### 3.1 Existing mature concepts in the source file

该簇已给出：

- `Selection Capacity (SC_{L_0→L_1})` 的正式定义
- 现代城市/制度环境并非纯 `L_2`，但其主导选择比例严重偏向 `L_2`
- 亲近自然的冲动可被重读为：
  - **L0→L1 接触缺口的调节信号**
- 有效接触由：
  - **剂量 × 纯度** 决定
- 两阶段衰退模型：
  - **阶段一：校准漂移**（可逆）
  - **阶段二：结构固化**（难逆）
- `空心主体 (Hollow Subject)` 的正式定义与阶段分层

### 3.2 Why this cluster matters for the new spirituality axis

新双线已经提出：
- 空心感 = 主体位缺失
- 现代生活中人越来越像在维持一个自己
- ready-made floors 导致真正参与减少

但它们还缺一层更硬的环境机制说明：

> **为什么现代环境本身会系统性削弱主体从 `L_0` 向 `L_1` 的生成性接触。**

`Hollow Subject` 这一簇正好补上这一层。

### 3.3 A-line merge value

A 线可吸入的重点是：

- hollow subject 的正式定义
- 比例失衡：现代环境的主导问题不是纯 `L_2`，而是 `L_0→L_1` 接触比例太低
- 两阶段衰退模型
- 自然亲近冲动作为缺口信号

### 3.4 B-line merge value

B 线可转成生活化表达：

- 为什么很多人到了自然里反而无聊、慌、坐不住
- 为什么旅游不一定真的修复你
- 为什么现代生活下会出现“功能完整，但越来越空”
- 为什么越来越多情感响应只对点赞、排名、评价等 `L_2` 事件有反应

### 3.5 Proposed merge points

**Into A line**:
- new subsection candidate: `§3.5 L2-dominant environments and hollow-subject formation`

**Into B line**:
- `§2 现代生活为什么特别容易让人把自己活丢`
- `§6 有些轻，是终于不用再拧着自己；有些轻，只是先麻一下`
- `§11 最后：不是马上成为新的人，而是慢慢把自己救回来`

## 4. Praxis cluster: lived return, relationship, work, community, dark night

- Dark Night 不是退步，而是：
  - **旧 `L_2` 在溶解，新 `L_2` 尚未形成**
- 其正常性与过渡性
- 应对原则：
  - 减少强度
  - 增加支持
  - 身体照顾
  - 不把过渡误判为失败

#### A-line value
A 线只适合吸收：
- Dark Night 的结构定义
- 其作为“旧 `L_2` dissolving / new `L_2` not yet formed”的过渡状态

B 线非常适合吸收：
- 为什么有时不是你变糟，而是在过渡
- 为什么这时不是越用力越好
- 为什么支持、身体照顾和减量很重要

### 4.2 Integration into life cluster

`Praxis.md` 中和 B 线高度匹配的，还有：

- 关系中的修行

这一簇非常适合强化 B 线的一个潜在短板：

这和新双线中“托住而不代替”的支持定义高度互补。
