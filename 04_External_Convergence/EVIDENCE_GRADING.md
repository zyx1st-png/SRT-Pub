# Evidence Grading

External convergence grades how independent findings support, operationalize, constrain, or pressure SRT constructs. Even E5 is not proof.

| Level | Name | Meaning |
|---|---|---|
| E0 | loose analogy | Interesting resemblance only; no support claim. |
| E1 | conceptual resonance | Similar intuition or vocabulary, but no variable mapping. |
| E2 | structural convergence | Similar structure, such as selection-cost-stabilization. |
| E3 | operational proxy | Can help measure or approximate an SRT construct under stated conditions. |
| E4 | differential support | Supports a prediction that distinguishes SRT from simpler alternatives. |
| E5 | strong corroboration | Strong support with alternatives partly excluded; rare and used cautiously. |

## Support Types

- structural convergence
- operational proxy
- formal constraint
- differential support
- falsification pressure
- contradiction / pressure case

## Required Guardrails

- Every E3-E5 entry must name alternative explanations.
- Every E4-E5 entry must name what would weaken it.
- Every field should eventually include pressure or contradiction entries.
- A bridge file is not automatically an evidence card.
- A proxy must state its scope and failure conditions.
