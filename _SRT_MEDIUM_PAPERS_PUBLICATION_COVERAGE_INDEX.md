# SRT Medium Coverage Index: Papers / Publication / Articles

> **Purpose**: This file processes papers, publication drafts, submission materials, article drafts, and working-note medium-priority candidates from the deep-navigation coverage audit. It is a navigation / coverage file, not a canonical theory source.

> **Scope**: This M5 batch handles paper versions and publication support. It prevents publication drafts from polluting canonical navigation while still making them discoverable.

---

## 0. Use Rule

Use this file when a coverage audit flags files under `papers/` or paper-like article drafts as unreferenced.

This file does **not** mean every listed draft should be read for ordinary theory questions. For theory answers, start with canonical anchors and routes. Use paper files when the task is manuscript preparation, reviewer response, publication history, article development, or version comparison.
