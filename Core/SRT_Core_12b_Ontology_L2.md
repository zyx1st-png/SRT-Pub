# Part A: Recursive Historical Generation & Formal `L_2` Mechanisms

## 0. 历史的递归生成架构（`R3-05 / R3-08 / R4-B2` 正面核心主轴）

历史不是“过去存在在另一时空里隔空遥控现在”，而是**先前 `Selection` 在当下仍然保持的实际生成效力**（兼容 `Core_Law/SRT_Generative_Ontology_Spine.md §3, §7` 与 `Core/SRT_Core_21b_Constitutive_Theorems.md P1-T03`）。它既是先前选择的结果，也是后续选择的构成条件，并可在特定组织条件下参与形成新的选择方式与比对维度。

### 0.1 历史怎样形成：发生、痕迹、留存、持续效力与前背景五去向

1. **四层形成链与未成体兼容性**：
   - **发生（Occurrence，`P1-T02` 底线）**：确定实际化已发生即不可被后续过程擦除为“从未发生”；允许无后续留存的终端 `Selection`，不预设万物必留痕。
   - **痕迹（Trace）**：在存在显式保留或写回机制的模型中，先前选择留下可被后续过程读取或承载的结构差异。
   - **留存（Retention / Closure）**：留存结构跨事件维持，并开始系统性改变后续相容路径的摩擦、权重或可达条件。
   - **持续生成效力（Continuing Efficacy / `L_2`）**：先前选择通过当下结构或留存条件持续条件化后续生成方向、生成关系、可达空间与比对准则（**不以已形成垂直组织或 `One` 为普遍必要前提**，兼容局部非 `One` 历史效力）。
2. **`L_1 / L_2` 双视角与快慢尺度非等同**：
   - `L_1`（当下实际形成的结构）与 `L_2`（先前选择通过当下结构对后续生成的持续效力）是同一现实或组织上的不同认识视角；路径依赖、滞回与返回点记忆是检验历史效力的重要手段，但**不是 `L_2` 成立的普遍必要条件**。
   - 快慢时间尺度垂直协作（缓慢背景条件化快速选择，持续快速选择逐步改写缓慢背景）是重要实现机制，但**垂直结构 $\neq$ 快慢尺度**。
3. **整个前背景生成关系的历史与五种交叠去向（`B3-a` 完整拓展，非互斥、非必经阶梯）**：

| 背景去向（条件性、可交叠） | 历史生成意义与防混同边界 |
|---|---|
| **1. 构成性退隐** | 局部显现退隐为支撑当前前景与更高尺度整体秩序的协作条件（`R3-02`） |
| **2. 阴影（`B3-a`）** | 退入相对背景、隐性框定后续可达空间并保留潜在再显现条件（`阴影 != 平行实体`） |
| **3. 张力（`B3-a`）** | 尚未被当前组织协调消化的差异持续施加失配压力 |
| **4. 后续摩擦（`B3-a`）** | 未协调关系在后续选择或条件变动中浮现为实际阻力、代价或修正信号 |
| **5. 终止或消散** | 不再具有可建立的后续生成效力（守住终端 `Selection`，不预设历史永不消失） |

### 0.2 历史怎样被调用：`R3-05` 跨尺度三层区分与 $\rho / w_{\text{trust}} / W_{\text{social}}$ 三分接口

1. **跨尺度三层区分（拒绝泛拟人化）**：
   - **历史沉积**：先前选择留下仍有效的生成条件（跨尺度广泛存在）；
   - **路径倾向**：既有条件使某些方向更易发生（跨尺度广泛存在）；
   - **信任分配（`Q09` 本义）**：具备趋势评估与重分配能力的系统，“基于变化的秩序趋势，将其分配到事物表征的过程”——通过调整既有关系在当下选择中的条件化权重，**无需删除既有记忆即可下调或重配其有效地位**（不把“信任”拟人化推广至一切物理尺度，低尺度是否存在同功能非拟人机制保持 `OPEN`）。
2. **适用模型下的三分离接口（严守 `Spine §3, §7` 普遍边界，仅在声明保留历史、信任重估与跨主体关系的适用模型中启用）**：
   - **非负痕迹密度 $\rho(p,t) \ge 0$**：保留 `T-L2-Scaffold` / `Def-PathTrace` 的非负性与正向沉积 $\Delta\rho^+(p,t) \ge 0$（自然衰减靠衰减项 $\lambda_d$，**严禁将负号直接写入 $\rho$ 污染 `Def-PathTrace` 单调性**）；

### 0.3 历史怎样支撑新生成：背景化非遗忘、脚手架生成盈余与认知生成三分

1. **V 层正面暂时背景化（背景化 $\neq$ 遗忘）**：背景化**不必然**削弱历史效力，反而常通过脚手架（语言语法、数学符号、习惯、公共时间与制度）稳定强化背景支撑，替当前系统承接大量重复比对工作。由此产生的**生成盈余（generative surplus）**，使有限位置得以将稀缺的比对与注意资源投向更高尺度的新关系与新秩序，而不是从零重做每一次比对。
2. **历史与认知的三种正面生成过程（`R3-08`，连接 `Core_21c P2/P3-B15` 五类变化刻度）**：
   - **① 历史关系复用**（对应刻度 1–2）：借助概念、习惯与符号锚点快速调用既有耦合（解释认知与组织效率）；
   - **② 历史关系重构**（对应刻度 2–4）：通过改写高构成深度检索锚点、比对入口、主动扰动或信任重估（$\Delta w_{\text{trust}}$）重组既有历史网络（解释框架调整与结构洞察）；
   - **③ 新比对能力生成**（对应刻度 4–5）：不同生成关系发生构成性耦合（如习得新数学图式或跨位置协作协议），使系统获得此前不具备的区分与组织能力，反向改变参与者自身生成条件（对应 `(A, B) → (A', B', C)`）。
   - **边界**：上述三过程与构成深度剖面保留为自然语言分析接口（暂缓立符 `q`，守住 `07-23/24` 撞车记号禁运）；具体神经/计算实现留待 `R4-C / R5`。

### 0.3a 异质历史载体、三位置分离与历史的双重生成空间（`R4-C5-C / D4` 深化）

综合 `R4-C1..C5`（社会制度与公共时间脚手架、跨尺度物理—生命历史、AI 七层异质载体、神经再生成记忆与发育式冗余剪枝），本节将 `L_2` 历史效力升级为统一跨尺度理论框架——**历史不只是“过去的结果被静态保存”，而是过去的生成如何经由异质载体成为当下及未来生成的有效条件**：

1. **五类历史职责与异质载体统一接口**：跨越生物记忆、遗传/表观遗传印迹、AI 训练数据/模型权重/运行时状态/上下文/外部记忆/工具反馈、语言文化、公共时间脚手架与社会制度，历史效力统一承担五类职责：**① 条件承载（维持后续生成边界）、② 路径偏置（调节相对可达性与摩擦地形）、③ 检索与重构锚定（提供再生成与重新比对入口）、④ 反馈写回（将后果转译为结构更新）、⑤ 跨情境迁移（将局部经验转为跨位置可复用脚手架）**。不把单一物理或生物架构预设为 `L_2` 的唯一载体。
2. **生成位置 / 留存载体 / 生效组织三位置分离**：在复杂与跨主体系统中，一项历史结构**产生于交互组织 `X`、留存于物理或符号载体 `Y`、最终实际改写组织 `Z` 的后续生成条件**，三者不必重合。由此确立硬边界：**“存于载体 $\neq$ 参与特定组织后续生成”**（例如将框架写入外部持久记忆或档案，不自动等于某一认知或人工智能组织已形成跨情境生效的新能力，须在目标生效组织层面独立核验）。
3. **历史的双重生成作用（超越单纯惯性与遮蔽）**：历史不仅压缩、锁定与遮蔽既有生成空间（病理面见 `§0.5` 与 `Core_Law/SRT_Occlusion_Dynamics.md`），更通过以下机制**主动创造此前不存在的生成空间**：
   - **再生成记忆（Regenerative memory）**：记忆不是静态档案提取，而是在当下比对条件与历史痕迹耦合中重新生成有效工作结构；
   - **发育式冗余剪枝（Developmental pruning）**：通过有选择地缩减早期冗余连接与无序自由度，反而雕琢出更高精度、低内耗的新比对与行动能力；
   - **脚手架与公共时间回流**：语言、数学符号、制度协议与共享时间脚手架（`Philosophy/SRT_Causality_Time.md`）使跨位置、跨代际的高阶协同与原本不可能的新能力组合获得现实生成条件。

### 0.4 历史怎样被重构：历史效力与调用调整四式及主动遗忘二式

为避免把“不在前景”误当“失去效力”，须严格三分：**① 退出当下显现（不在前景）** $\neq$ **② 退出主动调用** $\neq$ **③ 退出实际生成作用（效力真正减弱或解除）**。在严守 `P1-T02` 发生不可逆底线（一切后续调整均属新生成，绝不能使已发生事件变为从未发生）的前提下，将相关过程归为四种可交叠分析候选：

| 调整方式 | 机制要点与边界 | 与既有模型 / 主动遗忘二式的接口 |
|---|---|---|
| **1. 自然衰减** | 停止重复遍历后，历史痕迹及其效力随时间逐渐减弱 | **主动遗忘式一**：在 `Def-PathTrace` 模型中，需满足相应衰减条件（$\lambda_d > 0$）、足够时间跨度且无持续补充沉积时，$\rho$ 方衰减至 $\rho^*$ 以下 |
| **2. 退出显现与前背景重排** | 历史退出当下前景或显式比对 | 须独立核查究竟转入了更稳固的背景脚手架，还是同时退出了主动调用与实际约束 |
| **3. 信任重估** | 历史痕迹仍可召回（$\rho$ 未清零），但借有符号 $\Delta w_{\text{trust}}$ 调整其在当下选择中的权重地位 | 对接 `0.2` 三分离接口，无需擦除记忆即可解除旧路径对当下决策的主导 |
| **4. 结构解固** | 承载历史的组织条件、检索锚点或协议被重构，使受限路径重新可达 | **主动遗忘式二**：低摩擦重巩固窗口解固属**待验证条件候选**，进入窗口不自动保证解固成功；对接 `Core_21c B15` 刻度 4–5 |

- **独立检验原则**：**历史痕迹下降（$\rho\downarrow$）、信任权重降低（$w_{\text{trust}}\downarrow$）、实际约束解除与路径重新开放**四者彼此不等同，须在模型与经验研究中分别检验。

### 0.5 历史怎样成为病理：遮蔽四分、六种前背景失配与 `U5` 绝对化

1. **条件变化与脚手架延续的去绝对化校准（`R3-05 P2-03`）**：生成条件变化而既有脚手架继续参与生成，**不自动**构成不健康固化（既有脚手架仍可能有效）。只有当**既有脚手架与变化后的生成条件产生持续失配，且阻碍了必要的重新比对与再选择**时，才构成向固化势阱滑落的重要条件性诊断线索（非循环判据继续保持 `OPEN`）。
2. **给定感去病理化与遮蔽四分（`R3-08 P2-03`，不将 `U5` 垄断设为一切遮蔽的必要门槛）**：

| 状态 | 理论定位与防混同边界 |
|---|---|
| **1. 给定感** | 对象化 → 范畴化 → 默认化使已形成认知接口快速直呈前景的正面表现（本身非病理） |
| **2. 有限性遮蔽** | 任何有限位置与表征无法穷尽全部生成关系的结构性有限（非病理，非 `U5`） |
| **3. 病理性遮蔽** | 重要生成关系与现实后果受到持续、难以纠正的排斥（可先于 `U5` 全局垄断发生） |

3. **`U5` 绝对化的深层诊断（`R3-08`）**：`U5` 不等于静态停滞、规则不变或缺乏互动；高度固化的系统完全可以保持**高频局部创新、策略微调与活跃双向反馈**，却把一切新关系与新资源都导向维护一套退出有效再比对的核心组织方式（由此解释高持续性、高局部生成效率与结构病理性的共存）。同时完整对接 `_SRT_D_VALUE_CANONICAL.md §2` 的六种候选前背景失配：**① 遮蔽 / ② 错配 / ③ 固化 / ④ 失权 / ⑤ 断流 / ⑥ 局部劫持**，以及 `R3-08` 持续动态平衡（废弃机械的“关闭 → 触发 → 重开”开关模型，兼容动力学滞回与非线性重构势垒）。

```text
L₂ hardening
= reduced local selection cost
+ increased global constraint
```

**Reading Rule (updated by ST-A, 2026-08-11): formation, stabilisation, and generative health**

## III. L₂ 规范性判据（Normative L₂ Criterion）

> **新增节（2026-03-11；ST-A 降阶说明 2026-08-11）**：本节提出从选择动力学通向 L₂ 规范判断的 P2/P3 桥接方案；结构稳定本身不推出规范正当性。

### Def-L2-Normative: L₂ 规范性判据

定义**选择空间体积**（以 L₁-诱导测度 $\mu_{L_1}$ 替代在无结构 L₀ 上定义体积，避免可测性困难）：
$$S(\hat{G}, t) \equiv \mu_{L_1}\!\left\{\sigma \in L_1 : \hat{G}_{L_2(t)}[\sigma] \text{ 是可行锚定}\right\}$$

> **可测性注记**：原始写法 $\text{Vol}_{L_0}\{\cdots\}$ 要求在无结构潜在域 L₀ 上预设体积测度，但 L₀ 无先验群结构，该量不良定。改用 L₁-诱导测度后，S 表示”当前显现域中可被该 L₂ 成功锚定的态的 L₁-测度比例”，语义更清晰且计算可操作。

**L₂ 规范性分类**：

| 类型 | 判据 | 演化命运 |
|:-----|:-----|:---------|
| **可持续 L₂** | $\dfrac{dS}{dt} \geq 0$ 且 $\dfrac{d\mathcal{F}_{collective}}{dt} \leq 0$ | 演化稳定，在集体算子系统中长期存续；对应 T-Core-02 不动点条件 |
| **自保型 L₂** | $\dfrac{dS}{dt} \geq 0$ 但 $\dfrac{d\mathcal{F}_{collective}}{dt} > 0$ | 短期可存续，集体耦合摩擦中最终被压出 |
| **退化 L₂** | $\dfrac{dS}{dt} < 0$ | 压缩未来选择空间 → 算子走向绝境 → 被淘汰 |

> **T-Core-02 对接边界**：条件（$dS/dt \geq 0 \wedge d\mathcal{F}_{collective}/dt \leq 0$）可作为 T-Core-02 不动点的动力学投影候选。局部不动点或 $\mathcal{F}_{collective}$ 极小只说明模型内稳定性，不证明 continued selectability、generative reselectability 或规范正当性。

**集体景观多样性候选优化目标**（条件模型目标，非单标量 `d` 最大化或伦理正当性定义）：
$$L_2^* = \arg\max_{L_2} \frac{d\, D_{\text{eff}}^{\text{coll}}(t)}{dt} \quad \text{s.t.} \quad \frac{d\mathcal{F}_{collective}}{dt} \leq 0 \;\land\; \text{四判据与非外包检查满足}$$

其中集体景观有效维度容量代理（旧记 $d_{collective}$，严格区别于个体规范风险敏感强度 `d`）定义为集体自由能景观非负且非全零谱（$\lambda_k \ge 0,\; \exists k,\ \lambda_k > 0$；全零谱走 $0/0$ 未定义显式分支）的参与率指数（`Core_22 Eq-Multi-03`）：
$$D_{\text{eff}}^{\text{coll}} \equiv D_{\text{eff}}(\mathcal{F}_{collective}) = \frac{(\sum_k \lambda_k)^2}{\sum_k \lambda_k^2}$$
**注意**：$D_{\text{eff}}^{\text{coll}}$ 是集体景观的无赌注谱容量代理（反映可分辨方向的谱均匀度），**既不等于**个体规范 $d_i$ 的均值 $E_\theta[d]$，**也不单独证明**集体秩序健康——须与 `_SRT_D_VALUE_CANONICAL.md §5b` 秩序增益四判据（可延续 / 可协调 / 不外包 / 可再选择）及成员个体后果回流 $C_i$ 联合审查（防止高局部景观多样性建立在代价外包之上）。

**双层选择压力**：

| 层次 | 选择压力来源 | 淘汰机制 |
|:-----|:-----------|:---------|
| 个体层 | $\Psi_f$ 的累积消耗 | 算子无法支付维持成本 |
| 集体层 | $\mathcal{F}_{collective}$ 景观曲率（Eq-Multi-01/02） | 不指向集体极小的算子被耦合摩擦压出 |

**规范性的内生桥接候选**：维持并扩展相关算子的未来选择条件，可构成评价 L₂ 的一个内部理由；但 ST-A 不把该理由等同于“好”，也不声称选择动力学已经单独跨越事实—价值鸿沟。任何规范结论仍需说明相关主体覆盖、后果回返、规则修订、成本外部化与比较时间窗。

> **是-应当推导的适用边界**：该推导的有效性依赖于 $\mathcal{F}_{collective}$ **完整覆盖所有相关算子**。若某 L₂ 通过将部分算子排出核算范围（如剥削/排斥机制）来实现 $dS/dt \geq 0$，则推导失效——此时 S 的”扩展”建立在对被排除算子的选择空间的压缩之上，不满足内生规范性的完备性前提。形式判据：F_collective 的算子集必须等于实际受该 L₂ 影响的完整算子集。

**Precision Note (2026-04-21): normatively neutral closure / pathological closure / lethal L₂**

Closure is structurally real but **normatively neutral**.
It tells us that a path has formed a scaffold; it does not by itself tell us that the scaffold is good.

**Normatively neutral closure**:
> Closure means "formed," not yet "justified."

**Pathological closure**:
> A closure becomes pathological when it can preserve itself **only by compressing a broader future selectability**. Here the compression is not a mere side-effect; it is part of the sustaining mechanism of the closure itself.

**Lethal L₂**:
> Lethal `L₂` is the stronger case: a pathological closure that has already become **shared, inheritable, and backgrounded as scaffold**.

Compressed form:

> **闭包说明“成形了”，不说明“正当了”。病态闭包是靠压缩更大范围后续可选择性来维持自身的闭包；致命 `L₂` 则是这种病态闭包已经共享化、背景化之后的形态。**

This note should be read together with the existing normative classification table.
A stable structure is not automatically a sustainable structure, and a sustainable local closure is not automatically a healthy collective scaffold.

**Reading Rule (2026-04-21): pathological-closure loop**

Pathological closure should be checked by whether consequences can return to the closure as **effective input**, not merely by whether affected subjects can express burden. Appeal standing has a structural source: recognition as a relevant subject is the lowest prerequisite; consequence-return capacity is the working core; shared interpretive standing is the stronger co-governance layer.

Consequence-return paths are commonly cut in three layers: information fails to arrive; arrived burden is not counted as valid input; counted burden is re-attributed as private failure rather than evidence against the gate. In the strict sense, a burden becomes effective input only when it can alter gate decisions or stabilization parameters; the stronger normative case is that it can also trigger legitimacy review of the gate itself.

Pseudo-openness names the appearance of responsiveness without structural uptake: expression without decision change, parameter tuning without gate-logic change, or gate optimization without exposing the gate's legitimacy. Experientially, the typical sequence is habituation -> loss of appeal sense -> reality-misrecognition. In the full loop, gate-rule rigidity, consequence-return cuts, pseudo-openness, reselection loss, and reality-misrecognition reinforce one another until a contingent gate is lived as inherited background scaffold. This is a hardening-level diagnostic chain; exact thresholds and domain metrics remain open.

### H-L2-Cage-Resolution: L₂ 笼子悖论的桥接性消解候选

$$\text{L}_2 \text{ 的规范有效期} = \int_{t_0}^{t^*} \mathbf{1}[dS/dt \geq 0]\, dt, \quad t^* = \inf\{t : dS/dt < 0\}$$
