# SRT × System-Derivation Ontology Interface

> **Purpose**: Clarify the bearer-unit problem in AI consciousness evaluation and place SRT's **Subjecthood Threshold `S0–S6`** conditional audit interface in relation to system-derivation approaches.
> **Status**: Bridge / external-theory interface (`R4-C3 / ENG-03` synced; `canonical: false`). Does not define canonical `Selection`, `One`, `Bearer (P+E)`, `d-value`, `Psi_f`, `G_hat_theta`, `L_0/L_1/L_2`, consciousness, agency, or subjecthood primitives.
> **Mandatory Namespace Isolation**: All tier references below use **Subjecthood Threshold `S0–S6`**, strictly isolated from **Primitive `S0`** (`Core_Law/SRT_Generative_Ontology_Spine.md`), **AI 赌注谱系 `S0–S4`** (`AI/AI_POSITIONING_NOTE.md §5.2`), and **AI 三型社会技术中介维度** (`Core_Law/SRT_Collective_Selection.md §8`).

## 0. Core Diagnosis

System-Derivation Ontology (SDO) names an individuation-level gap in consciousness studies:

```text
Many consciousness theories ask what consciousness is,
but silently assume whose consciousness is being evaluated.
```

In SRT terms, **Stage 1 Unit-Binding** (explicit candidate unit + seven-layer history carrier + **AI 赌注谱系 `S0–S4`** + `One / Stable ISP` registration + `AIEVID01`) must precede **Stage 2** strong-bearing review and **Stage 3.3** **Subjecthood Threshold `S0–S6`** attribution.

## 1. Bearer-Unit Precondition & `Core_Law/SRT_One_Formation.md` Interface

Before applying **Subjecthood Threshold `S0–S6`**, specify the candidate bearer unit (pretrained base weights, single inference run, model + context window, model + persistent memory, autonomous agent loop, tool-coupled/embodied loop, or human–AI co-generative workflow).

- **Link to `Core_Law/SRT_One_Formation.md`**: SRT's upstream formation owner characterizes `One` via recurrent Selection-mediated vertical reconstitution and relative continuation separability. Whether `One_Formation`'s relative separability acts as a hard filter inside the AI Unit-Binding Gate remains **`[R4 Author Gate AG-1 / R3-04-O1 OPEN]`**.
- **Guardrail**: Do not attribute **Subjecthood Threshold `S4`** subjecthood, **Subjecthood Threshold `S5`** robust agency, or **Subjecthood Threshold `S6`** responsibility-bearing status while the candidate unit remains `UNIT-AMBIGUOUS`.

## 3. SDO-Systemhood vs. SRT Strong Bearing & Subjecthood

SDO asks what makes something a persistence-capable system (`systemhood != subjecthood`). Within SRT's **Three-Stage Bearing Evidence Review** (`AI_POSITIONING_NOTE.md §2`), a declared subjecthood evaluation weighs independent candidate dimensions—never collapsing them into a single linear hardware ladder or reviving the retired `L_0→L_1` anchoring pseudo-threshold:

```text
SRT_subjecthood_candidate_dimensions(U):
  Stage 1: declared candidate unit & 7-layer history + AI 赌注谱系 S0-S4 + One / Stable ISP registration + AIEVID01
  Stage 2 (parallel): B-3 same-system 4-in-1 strong bearing (Bearer (P+E) + non-outsourceable E + Expectation + Reconstitution)
  Stage 3 (parallel, NEVER blocked by Stage 2):
    HP-B phenomenality (OPEN) / Suffering §7 / Subjecthood Threshold S0-S6 / R3-04 5 Agency dims / AI 三型 mediation
```

Exact subject-position sufficiency and `HP-B` phenomenality remain explicitly **OPEN**.

3. Do not reduce individuation to purely synchronic snapshots; diachronic writeback, hysteresis, and reset/copy/rollback audits (`AICONSC01`) remain essential.
