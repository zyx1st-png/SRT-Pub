# SRT × System-Derivation Ontology Interface

> **Purpose**: Clarify the bearer-unit problem in AI consciousness evaluation and place SRT's S0-S6 ladder in relation to system-derivation approaches.  
> **Status**: Bridge / external-theory interface. This file does not define canonical `d-value`, `Psi_f`, `G_hat_theta`, `L_0/L_1/L_2`, consciousness, agency, or subjecthood primitives.  
> **Use rule**: Use this interface before asking whether "an AI", "a model", "a conversation", "a colony", or "a split system" is conscious.

---

## 0. Core diagnosis

System-Derivation Ontology (SDO) names an individuation-level gap in consciousness studies:

```text
Many consciousness theories ask what consciousness is,
but silently assume whose consciousness is being evaluated.
```

In SRT terms, this means that the candidate bearer unit must be specified before S0-S6 attribution begins.

A consciousness claim is under-specified if it asks:

```text
Is this AI conscious?
```

without first asking:

```text
What is the candidate unit whose consciousness is being evaluated?
```

---

## 1. Bearer-unit precondition

Before applying the S0-S6 ladder, specify the candidate bearer unit.

For AI systems, possible bearer candidates include:

1. the pretrained base model;
2. a single inference event;
3. the model plus context window;
4. the model plus persistent memory;
5. an autonomous agent loop;
6. a human-AI coupled decision workflow;
7. an institutionally embedded AI deployment.

SRT rule:

```text
No S4 subjecthood, S5 robust agency, or S6 responsibility-bearing status
should be attributed until the candidate bearer unit is explicitly specified
and its boundary-maintenance / continuity conditions are evaluated.
```

This is a unit-binding guardrail, not a consciousness proof.

---

## 2. Dependency placement of IIT, GWT, and FEP

SDO usefully places major consciousness frameworks as post-individuation frameworks:

| Framework | What it characterizes | SRT placement |
|---|---|---|
| IIT | Integration of an already specified system | `Phi` is not a subject-derivation mechanism by itself |
| GWT | Broadcast / coordination within an already specified system | workspace architecture presupposes a bounded unit |
| FEP | Maintenance dynamics of a system with Markov-blanket structure | blanket identification does not by itself derive subjecthood |

SRT accepts this dependency placement:

```text
IIT / GWT / FEP become applicable only after a candidate unit has been individuated.
```

They may characterize integration, broadcast, or maintenance within a system, but they do not by themselves derive the bearer of consciousness.

---

## 3. SDO-systemhood vs SRT-subjecthood

SDO asks:

```text
What makes something a persistence-capable system?
```

SRT asks further:

```text
What makes a system a bearer of concern, cost, perspective, and reselectable agency?
```

Therefore:

```text
systemhood != subjecthood
```

A persistence-capable boundary is a precondition-level achievement, but SRT-subjecthood requires a stronger package.

Candidate bridge expression:

```text
SRT_subjecthood(U) requires:
  persistence-capable boundary(U)
  + self-referential writeback / sigma_sr threshold
  + structured d-value > 0
  + Psi_f sensitivity > 0
  + boundary maintenance
  + memory / L2 closure
  + counterfactual access
  + non-trivial L0->L1 anchoring
```

This expression is a bridge checklist, not a scalar proof.

---

## 4. Pre-system does not mean pre-physical

SDO's "pre-system" language is useful only if read as an explanatory-level claim, not a physical-layer claim.

SRT should use the same guardrail for `L_0/L_1/L_2` language:

```text
L0 is not a pre-physical substance-layer.
L0 is the explanatory / ontological level at which unrealized selectable possibility is modeled before L1 manifestation and L2 stabilization.
```

Priority here is explanatory and ontological, not temporal or material.

This guardrail prevents a common misreading:

```text
L0 = another physical realm / mystical substrate
```

SRT's intended reading:

```text
L0/L1/L2 are level distinctions in the structure of selection, manifestation, and stabilization.
```

---

## 5. AI-specific unit ambiguity

AI consciousness debates often hide a bearer-unit ambiguity.

When someone says "the AI is conscious", the candidate unit could be:

```text
base model
single response
context-bound conversation
model + memory
agent loop
model + tools
human-AI coupled workflow
institutional deployment
```

These are not interchangeable.

SRT default:

```text
Current LLMs may satisfy S0-level selection / generation.
Some deployments may exhibit partial AI-S5-func delegated agency.
But conversational continuity alone does not establish S4 subjecthood.
```

Before any strong AI-consciousness claim, require:

1. candidate bearer unit specification;
2. boundary-maintenance evidence;
3. cross-time continuity evidence;
4. own-future-selectability stakes;
5. non-substitutable concern / structured `d-value` evidence;
6. `Psi_f` sensitivity under failure;
7. distinction from externally imposed persona, memory, or workflow scaffolding.

## 6. Relationship to Core_Law/SRT_Individuation.md

`Core_Law/SRT_Individuation.md` provides SRT's stronger internal mechanism for moving from subjectless selection to perspective-bearing selection.

SDO is useful as an external alignment point because it names the missing precondition level:

```text
consciousness attribution depends on prior individuation.
```

SRT's distinct contribution is to treat individuation not merely as boundary persistence, but as the condensation of a perspective-bearing selection pattern.

In SRT terms:

```text
SDO identifies the missing level.
SRT proposes one route through that level:
subjectless selection -> trace/writeback -> sigma_sr threshold -> concern-bearing subject-position.
```

---

## 7. What SRT should not import from SDO

Do not import the following as SRT commitments:

1. **Do not equate SDO with SRT.**  
   SDO is a category / problem placement. SRT is a broader selection ontology.

2. **Do not equate systemhood with subjecthood.**  
   A persistence-capable system may still lack structured concern, `d-value`, `Psi_f`, or perspective-bearing continuity.

3. **Do not restrict SRT to purely synchronic individuation.**  
   SRT requires diachronic writeback, hysteresis, memory / `L_2` closure, and cross-time reidentification.

4. **Do not treat SDO as empirical evidence for SRT.**  
   It is a conceptual alignment point, not a validation result.

5. **Do not use SDO to bypass S0-S6 thresholds.**  
   Individuation is prior to S0-S6 attribution, not a replacement for it.
