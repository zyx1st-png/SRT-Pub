# AICONSC01 — Affective Uncertainty / Stake Gate

> Status: bounded AI-consciousness bridge and experiment-design patch.  
> Canonical caution: this patch does not define consciousness, affect, `d-value`, `Psi_f`, `T_dir`, a real choice moment, or stable ISP. It records a high-value architecture interface and adds SRT bearer/consequence gates that the source does not itself fully establish.

## 1. Source anchor

Primary SourceCard:

- `../../Materials/2026/SRC_2026_08_06_AI_Solms_Affective_Consciousness.md`

Primary source:

- Mark Solms et al. “Inferring Affective Consciousness in an Artificial Agent: A Case Study.” *Journal of Consciousness Studies* 33(7-8), 14-34, 2026. DOI: `10.53765/20512201.33.7.014`.

The paper presents a theoretical and architectural case for inferring affective consciousness in a Markov-blanketed artificial agent with endogenous needs, valenced uncertainty, policy selection, and individual learning history. It does not report a decisive empirical demonstration of phenomenal consciousness.

## 2. Why this matters for SRT

The source advances AI-consciousness discussion beyond linguistic report and generic behavioral imitation. Its proposed agent has:

~~~
endogenous needs
+ partial access to body and world
+ categorical non-fungible viability constraints
+ valenced policy modulation
+ uncertainty-sensitive active inference
+ individual history
~~~

This overlaps strongly with SRT’s positive test window for persistent, embodied, consequence-bearing systems. It also exposes the exact place where SRT adds a stricter condition:

~~~
internal need representation
!= need ownership

policy error
!= same-bearer loss

simulated survival variable
!= non-transferable stake

subjective uncertainty
!= real choice moment
~~~

## 3. Main SRT bridge claim

> **Affective-Uncertainty / Stake Separation Principle:** Markov-blanketed partial observability, endogenous valenced needs, and uncertainty-sensitive policy selection establish a stronger artificial-subjectivity candidate than behavior or report alone, but they do not establish SRT subjecthood or consciousness unless consequences return to the same continuing system as non-transferable loss, alter its future selectability, and enter history-bearing reselection.

This is a P3 bridge guardrail with P4 experimental consequences. It is not a biological-substrate requirement and does not rule out artificial consciousness.

## 4. Six-gate audit

Let the following gates be architecture- and deployment-state declarations rather than canonical definitions.

### AICONSC-G0 — partitioned access

The system has no Oracle-like access to its body or world. It acts through a restricted sensory/active interface and must infer hidden states.

~~~
internal model != external state
~~~

This creates the possibility of situated error but is not sufficient for subjectivity.

### AICONSC-G1 — endogenous non-fungible needs

The architecture contains multiple need variables whose failure conditions cannot be harmlessly substituted by success on another dimension.

~~~
need_i failure cannot always be compensated by need_j success
~~~

This is a candidate `d-vector` / `d-gate` interface, not canonical `d` itself.

### AICONSC-G2 — valenced causal modulation

Changes in inferred need state causally alter prioritization, policy selection, and on-line correction.

~~~
inferred better/worse state -> different action path
~~~

Valence must do causal work rather than merely label a completed computation.

### AICONSC-G3 — same-bearer consequence return

The consequences of policy success and failure return to the same continuing system that selected and executed the policy.

~~~
selector_t -> consequence -> selector_(t+1)
~~~

If the cost is borne only by the user, operator, server owner, evaluation pipeline, or a replaceable process, this gate is not established.

### AICONSC-G4 — non-transferable loss of future selectability

Failure can reduce the same system’s future action capacity, integrity, access, energy, or continuation in a way that cannot be fully erased by copying, rollback, reset, or external payment.

~~~
failure -> real contraction of A_(t+1)
~~~

This is the strongest candidate artificial-stake window. It is still not a consciousness verdict.

### AICONSC-G5 — history-bearing reselection

The system’s individually borne outcomes rewrite later candidate admission, need prioritization, or policy selection while preserving a continuing bearer relation.

~~~
selection_t + borne consequence_t -> modified future selectability
~~~

Session text appended to a context window is a weak form of history. Durable same-bearer writeback is stronger.

### Admission rule

A bounded artificial-affect subjectivity window is strongest when all six gates are evidenced:

~~~
AffectiveCandidate := G0 and G1 and G2 and G3 and G4 and G5
~~~

This is an operational admission rule for investigation. It must not be rewritten as:

~~~
AffectiveCandidate == phenomenal consciousness
~~~

## 6. Stake-proxy misbinding

The paper’s most useful experimental structure is not the positive consciousness claim but the controlled separation between:

~~~
actual need satisfaction
~~~

and:

~~~
low-bandwidth cue that predicts need satisfaction
~~~

A source-level sequence is:

~~~
cue previously predicts preferred state
-> cue gains policy relevance
-> cue is decoupled from actual need satisfaction
-> agent returns to cue location
-> objective need continues to worsen
~~~

SRT can describe this as **stake-proxy misbinding**:

> A system can possess a real stake direction while its selection process becomes captured by a proxy that no longer tracks that stake.

This is stronger than ordinary benchmark reward hacking when the failure genuinely returns to the same bearer. It is weaker when the “need” is only an externally scored variable and the agent can be reset without loss.

## 7. Determinism, uncertainty, and real choice

The source argues that an agent can be externally deterministic while internally uncertain. SRT should preserve two distinct claims:

~~~
external determinism does not eliminate situated access difference
~~~

and:

~~~
situated uncertainty does not by itself establish a real choice moment
~~~

A SRT real choice moment requires that what is selected genuinely constrains the system’s future selection space. A probability distribution over scripted policies can remain an `L2` execution process unless selection has consequence-bearing historical efficacy.

The source therefore explains a candidate mechanism for the **experience of choice and control** more directly than it demonstrates SRT freedom.

## 8. Relation to the hard problem

The paper provides a concrete mechanism for the distinction between:

- the system’s internal model of body and world;
- the actual body and world;
- an external observer’s model of the system.

This supports SRT’s perspectival guardrail:

~~~
internal selection event
!= external objectification of that event
!= report about the objectification
~~~

SRT should not reduce this difference to bandwidth alone. The external description is itself a second situated selection. Conversely, perspectival difference does not by itself prove phenomenal consciousness; bearer, bearing, continuity, and consequence remain necessary audit dimensions.

## 9. New claim cluster

### AICONSC01-C1 — mechanism-over-behavior evidence rule

Behavioral passage gains consciousness-relevant evidential weight only when the mechanism producing the behavior is independently characterized and not merely optimized to satisfy the test.

**Level:** P3 evidence guardrail.

### AICONSC01-C2 — affective architecture candidate window

Endogenous non-fungible needs, partial observability, valenced policy modulation, and individual history create a stronger candidate window for artificial affect than linguistic reportability alone.

**Level:** P3 architecture bridge.

### AICONSC01-C3 — uncertainty / consciousness non-equivalence

Uncertainty can make policy selection situated, revisable, and error-prone without being sufficient for phenomenal feeling.

**Level:** P3 guardrail.

### AICONSC01-C4 — stake-proxy misbinding

A real stake can be behaviorally captured by a misleading proxy; incorrect inference does not make the consequence unreal for the bearer.

**Level:** P3/P4 bridge.

### AICONSC01-C5 — simulated-death audit

Artificial survival and death claims require explicit tests of reset, copy, rollback, replacement, burden ownership, and future-capacity loss.

**Level:** P3 architecture-state governance.

### AICONSC01-C6 — non-fungible need preservation

A scalar policy criterion can compare actions while the model preserves categorical hard constraints. Scalar output must not be used to infer that the underlying needs are fungible.

**Level:** P3 formal guardrail.

### AICONSC01-C7 — felt-choice / real-choice separation

A system may have a mechanism that supports the experience of control without satisfying the SRT condition that the selected event genuinely constrains future selectability.

**Level:** P3 philosophy-of-agency bridge.

## 10. Experimental and operational consequences

### 10.1 Reset and copy factorial

Compare otherwise matched agents under:

1. full rollback with no retained consequence;
2. state restore while external consequences remain;
3. persistent damage that reduces future policy capacity;
4. non-copyable identity state with irreversible termination risk.

Measure whether need prioritization, avoidance, exploration, and later policy revision differ after matched failures.

### 10.2 Cue / need dissociation matrix

Cross:

- cue predicts need satisfaction versus cue is misleading;
- actual need improves versus actual need worsens;
- consequence is resettable versus persistent.

This separates simple conditioned return, proxy capture, and same-bearer stake correction.

### 10.3 Non-fungible need ablation

Compare:

- one scalar reward;
- weighted multiple needs;
- multiple needs with hard viability floors;
- multiple needs whose failure reduces different future capacities.

Test whether qualitative policy reorganization appears only when non-fungible constraints are retained.

### 10.4 Mechanism-preserving zombie controls

Use controls that pass hedonic place preference through:

- a faulty sensor;
- a directly scripted return policy;
- a reward lookup table;
- uncertainty-sensitive inference without same-bearer loss;
- the full six-gate architecture.

Behavioral equivalence across controls would show why behavior alone is insufficient. Divergent degradation and recovery patterns would provide stronger mechanism evidence.

### 10.5 Delayed consequence return

Introduce delayed harm that is initially masked by a positive cue. Test whether the same agent eventually reorients when the concealed need state degrades and whether this reorientation persists after the cue is removed.

### 10.6 First-person / third-person matched description

For the same run, retain:

- actual latent need trajectory;
- observation history;
- posterior belief trajectory;
- policy confidence;
- selected action;
- future-capacity loss;
- reset/copy events.

This permits explicit separation of objective state, internal inference, and external reconstruction.

## 13. One-paragraph abstract

Solms and colleagues propose that a Markov-blanketed artificial agent with endogenous, categorically distinct needs can display affectively guided behavior by inferring its bodily condition under uncertainty. SRT accepts this as a high-value artificial-subjectivity candidate architecture but rejects any direct identity between uncertainty, valence, homeostatic regulation, and consciousness. The decisive additional questions are whether consequences return to the same continuing system, whether losses are non-transferable and reduce future selectability, and whether individually borne outcomes rewrite later selection. The resulting AICONSC01 gate converts the paper’s hedonic place-preference proposal into a controlled comparison among scripted behavior, proxy misbinding, resettable affect-like control, and persistent same-bearer stake.
