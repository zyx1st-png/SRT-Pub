# SRT Adjacent-Theory Interface Index

> **Purpose**: This file indexes existing SRT adjacent-theory materials and fixes their interface roles. It does **not** introduce a new theory, does **not** add a P0/P1 theorem, and does **not** replace existing domain files.

> **Use rule**: Use this file when a reader asks whether SRT is “just FEP,” “just IIT/GNW,” “just quantum collapse,” “just multilevel selection,” or “just social constructionism.” The answer should route through interface role, existing file location, and boundary condition.

---

## 0. Core Rule: Interface, Not Identity

SRT does not absorb adjacent theories by identity. It assigns them to different interface roles in the SRT loop:

\[
L_0 \xrightarrow{\hat G_\theta} L_1 \xrightarrow{writeback} L_2 \xrightarrow{constraint} \hat G_{\theta'} \to L_1'
\]

Adjacent theories are useful because they clarify particular segments of this loop:

- **FEP / Active Inference**: local self-maintenance under existing constraints (`L_2 -> L_1`).
- **IIT / PCI**: integration-side structure and clinical readouts of an actualized `L_1` slice.
- **GNW**: global availability / broadcast of selected `L_1` content.
- **Quantum measurement / decoherence**: physical actualization interface (`L_0 -> L_1`).
- **Multilevel selection**: which scale carries selection pressure and where consequences return.
- **Niche construction / language ecology**: how repeated `L_1` action rewrites the future selection environment (`L_1 -> L_2 -> L_1`).
- **Language / social reality theories**: human-social stabilization of `L_2` through meaning, shared intentionality, norms, roles, and institutions.

Compressed rule:

> **Adjacent theories are bridge languages for parts of the SRT loop, not replacements for the SRT core.**

## 2. FEP / Active Inference Interface

### Role

FEP / Active Inference is best placed at the `L_2 -> L_1` side of SRT: it describes how an already organized system updates perception, belief, and action under existing constraints in order to preserve closure.

### Existing locations

- `Philosophy/SRT_FEP_Comparison.md`
- `SRT_Fisher_FEP_Landscape_Interface.md`
- `Neuroscience/SRT_Clin_02_FEP.md`
- `Core/SRT_Core_14_Dynamics_Scaling.md`

### Safe wording

> FEP / Active Inference is a local self-maintenance interface for already organized systems under `L_2` constraints. In SRT terms, it models how an operator updates `L_1` trajectories in order to preserve closure and reduce local predictive burden.

### Boundary

Do not write:

\[
SRT = FEP
\]

Prefer:

\[
FEP \subseteq \text{SRT local self-maintenance interface}
\]

FEP helps model maintenance and prediction under constraint; it does not replace `L_0 -> L_1` selection or the broader `selection precedes existence` thesis.

## 3. IIT / PCI / GNW Consciousness Interface

### Role split

IIT / PCI and GNW should not be collapsed into one consciousness interface.

| Theory | SRT role |
|---|---|
| IIT / PCI | Integration-side structure or clinical complexity readout of `L_1` |
| GNW | Global availability, access, reportability, and broadcast of selected `L_1` content |
| SRT | Selection, anchoring, payability, and stake coupling |

### Existing locations

- `Neuroscience/SRT_Clin_00_IIT_PCI.md`
- `Neuroscience/SRT_Neuro_09_Integ_Eq.md`
- `Neuroscience/SRT_Consciousness_Mechanisms.md`
- `Neuroscience/SRT_Consciousness_Mechanisms_CompactCore.md`
- `AI/SRT_AI_03_Consciousness_Framework.md`

### Safe wording

> IIT / PCI can be used as integration-side or clinical-complexity proxies for `L_1`; GNW can be used as the global-availability and broadcast interface for selected content. Neither replaces SRT's `d-value`, `Ψ_f`, or `Ĝθ`.

### Boundary

- `Φ` is not canonical `d-value`.
- PCI is not the full condition for consciousness in SRT.
- GNW explains access and broadcast, not the full origin of selection from `L_0`.
- High integration or broadcast does not automatically imply stake, payability, or existential concern.

## 5. Multilevel Selection / Niche Construction Interface

### Role

Multilevel selection helps SRT specify **which level carries selection pressure**. Niche construction helps SRT specify how repeated `L_1` actions alter `L_2`, which then reshapes future selection.

### Existing locations

- `papers/ontological_friction/paper_ontological_friction.md`
- `_SRT_D_VALUE_CANONICAL.md`
- `_SRT_PSI_F_CANONICAL.md`
- `Core/SRT_Core_21c_Bridge_Hypotheses.md`
- `Core/SRT_Core_12b_Ontology_L2.md`
- `Philosophy/SRT_SocTheory_05_Language_Eco.md`

### Safe wording

> Multilevel selection is a scale-disambiguation interface for SRT: it forces each selection claim to specify which level bears the consequence and where future-selection capacity is altered. Niche construction is an `L_1 -> L_2 -> L_1` writeback interface: agents reshape the environment that will later reshape them.

### Boundary

Do not use “selection” generically. Always specify:

1. Which operator level is selecting?
2. Which level pays `Ψ_f`?
3. Which level receives consequence writeback?
4. Which future selection capacity is changed?
5. Is the relevant `d` individual, collective, ecological, institutional, or only a capacity proxy?

## 7. Anti-Reduction Quick Answers

### “Is SRT just FEP?”

No. FEP models local self-maintenance under existing constraints. SRT also models `L_0 -> L_1` selection, `Ψ_f` payability, `d-value` stake coupling, and `L_1 -> L_2` sedimentation.

### “Is SRT just IIT or GNW?”

No. IIT / PCI and GNW are consciousness-interface theories. They help describe integration and access of `L_1`, but they do not define selection, payability, or stake.

### “Is SRT just quantum measurement?”

No. Quantum measurement is a physical actualization bridge. SRT treats it as one instance of the broader `L_0 -> L_1` selection problem, not as the master explanation for all domains.

### “Is SRT just multilevel selection?”

No. Multilevel selection disambiguates the level of selection pressure. SRT additionally tracks `Ψ_f`, `d-value`, `Ĝθ`, and `L_2` writeback across domains.

### “Is SRT just social constructionism?”

No. Social constructionism is a theory of human-social `L_2` formation. SRT generalizes selection, anchoring, sedimentation, and constraint feedback beyond the social-linguistic domain.

## 8. Reusable Summary Paragraph

SRT does not absorb adjacent theories by identity. It assigns them to different interface roles: FEP / Active Inference models local self-maintenance under existing constraints (`L_2 -> L_1`); IIT / PCI models integration-side complexity of actualized `L_1`; GNW models global availability and broadcast; quantum measurement theories model physical actualization (`L_0 -> L_1`) under decoherence and environmental selection; multilevel selection specifies which scale bears selection pressure and where consequences return; niche construction and language ecology model how repeated `L_1` actions rewrite `L_2`; and social-reality theories model human-social `L_2` stabilization through shared intentionality, symbols, norms, roles, and institutions. None of these theories replaces SRT's core loop; each supplies a bridge language for one part of it.
