# Explicit ChoiceMap Scaffolding: scope and prior failures

## Fixed boundary

This is a new, independently falsifiable engineering experiment. It does not rescue,
reinterpret, overwrite, or soften any prior result:

- `SR_preC v1`: **NO-GO**;
- Fisher: **lose**;
- four-state classification: **unstable**;
- matched-path stage four: **DESIGN INFEASIBLE**.

Earlier CNN experiments could observe training traces, not selection structure itself.
Their failures do not entail that machine learning can never implement a selection
operator; they show that the tested trace proxies and designs did not establish one.

## New construct

The present experiment does not infer choice from gradients or parameter drift. It
implements candidate generation, comparison, bounded probing, reversibility labels,
commitment timing, and branch memory as visible software mechanisms that can be enabled,
disabled, and ablated.

This is a P4/lab test of a **ChoiceMap engineering scaffold**, not a test of SRT ontology,
not an implementation of the complete SRT selection operator, and not evidence that
“selection precedes existence.” Results may support or weaken only the scoped bridge:
explicitly maintaining decision structure may protect unforeseen future task capacity
under uncertainty and irreversible action.

## Relationship to the existing ChoiceMap seed

`_SRT_DIRECTION3_CHOICEMAP_PROTOTYPE_SEED.md` is a human-facing decision-support proposal
whose first design law gives final convergence back to the user. This experiment instead
tests an autonomous synthetic agent. The shared name marks family resemblance—option
expansion, closure visibility, and reselectability—not identity. The autonomous algorithm
must not be back-projected into the human workflow or promoted to a canonical definition.

## Competitors and value threshold

The primary competitors are:

1. Greedy immediate utility;
2. compute-matched ordinary search;
3. a scalar option-preservation reward;
4. full ChoiceMap.

ChoiceMap has independent research value only if it exceeds the strongest compute-matched
baseline and the option-preservation scalar baseline under matched interaction and model
access budgets. Merely adding more search, information, or conservative delay is a failure.
