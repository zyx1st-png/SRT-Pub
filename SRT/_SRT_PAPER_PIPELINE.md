# SRT 论文孵化流水线（Pipeline 2）

## 目标
将内部理论资产持续提炼为可投稿论文，形成“候选池 → 主稿 → 预投稿包”的闭环。

## 周期
- 每周：候选筛选 + 主稿迭代
- 每两周：投稿就绪评估

## 阶段
1. 候选池构建（3-5题）
2. 成熟度评分（理论完整、证伪性、证据等级、引用密度）
3. 主稿迭代（单篇优先）
4. 预投稿检查（结构、图表、引文、边界声明）
5. 投稿包生成（cover letter + target journal fit）
