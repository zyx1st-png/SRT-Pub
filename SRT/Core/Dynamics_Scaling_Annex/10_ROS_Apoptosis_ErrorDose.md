## 1. 生物学类比的映射

### 1.1 ROS / 自由基 → 错误积累

ROS（活性氧）是正常细胞代谢的副产品：G正常运作也持续产生错误积累——不是外来入侵，是选择活动的内源性副产品。

| 生物学 | SRT映射 |
|---|---|
| ROS / 自由基 | 选择活动产生的错误积累（L0/L1过滤层增厚）|
| 氧化损伤链式反应 | 错误积累的自我强化回路（见文件09）|
| 低剂量ROS = 信号分子 | 低积累张力 = G的选择校准信号 |
| 高剂量ROS = 氧化损伤 | 高积累张力 = 遮蔽过滤，压缩可能性空间 |
| 细胞凋亡 | 局部L2遮蔽子结构的受控瓦解 |

### 1.2 凋亡 → L2子结构受控瓦解

凋亡的精确结构：**细胞**（局部）为**有机体**（整体）的利益而死。

SRT映射：一个具体的信念/图式/行为模式（L2子结构）被溶解，G整体获得更大的可能性空间。

$$\text{死亡的} = \text{局部L2遮蔽子结构} \quad \text{受益的} = G_{\text{整体}}的\ \Omega_{\text{perceived}}$$

凋亡 = 文件09中"去遮蔽重建"路径的**受控形式**：不是防御性封闭，不是横向漂移，而是精确定位并溶解特定遮蔽结构。

## 2. 剂量区分

### 2.1 错误积累的双阈值性质

错误积累不是线性负面的——存在功能区和病理区：

```
错误积累量

低 ──────────── 阈值Θ ──────────── 高
  ↓                                  ↓
选择张力信号                    遮蔽过滤层
（功能性，校准资源）         （病理性，压缩Ω_perceived）
```

低积累区：G感受到选择张力，张力提供方向信息，G通过处理张力校准选择能力。
高积累区：张力超过处理能力，错误在L0/L1过滤层固化，G的可能性空间被系统性截断。

## 3. d值：统一整合带宽定义

### 3.1 d的统一性

d（整合带宽）是单一概念在不同场景中的显现：

| 场景 | d的显现形式 |
|---|---|
| 多G道德场景（文件08）| 整合半径：G能将多少他者G的状态纳入选择计算 |
| 错误剂量场景（本文件）| 可处理张力窗口：G能消化多少错误积累而不崩溃 |

两种显现是同一底层容量——能整合更多他者状态的G，同样能容纳更高剂量的选择张力。

### 3.2 d的训练机制（hormesis）

低剂量错误积累的反复处理**可训练d值**：

$$d_{t+1} = d_t + \Delta d(\text{低剂量暴露频率，整合成功率})$$

类比：低剂量运动产生ROS → 激活抗氧化防御 → 整体氧化应激耐受性提升。

> **注意**：d的提升有上限，且依赖积累量保持在功能区内。高剂量单次暴露可损伤d而非提升d。

## 4. 病理阈值的四因子公式

### 4.1 阈值结构

病理阈值不由d单独决定：

$$\Theta = f\left(d,\ E,\ h_{\text{memory}},\ \vec{\delta},\ \Lambda_{\text{L2}}\right)$$

| 参数 | 含义 | 方向 |
|---|---|---|
| $d$ | 整合带宽 | $\uparrow d$ → $\uparrow \Theta$（更不易崩溃）|
| $E$ | 当前可用能量（睡眠、代谢、注意力资源）| $\uparrow E$ → $\uparrow \Theta$ |
| $h_{\text{memory}}$ | 迟滞记忆变量（张力暴露历史）| 中性存储，方向另行编码 |
| $\vec{\delta}$ | 方向编码：历史暴露的脱敏/敏化效应 | $\delta^+$（脱敏）↑Θ；$\delta^-$（敏化）↓Θ |
| $\Lambda_{\text{L2}}$ | L2硬度复合系数 | $\uparrow \Lambda$ → $\downarrow \Theta$（更易崩溃）|

### 4.2 迟滞的精确定义

**迟滞 = 记忆变量，不是方向变量。**

$h_{\text{memory}}$ 记录历史张力暴露的模式（频率、强度、时序），方向效应由 $\vec{\delta}$ 单独编码：

- 低剂量高频历史 → $\delta^+$（脱敏）→ 阈值提升
- 高剂量单次历史 → $\delta^-$（敏化）→ 阈值下降

混淆记忆和方向会产生错误预测。

### 4.3 L2硬度的复合结构

$$\Lambda_{\text{L2}} = f(\kappa_{\text{连通性}},\ \tau_{\text{时间沉积}},\ \iota_{\text{认同融合度}})$$

| 成分 | 含义 | 对修改的影响 |
|---|---|---|
| $\kappa$ 连通性 | L2子结构间的连接密度 | 决定局部修改的传播范围 |
| $\tau$ 时间沉积 | 结构形成时间与持续时长 | 决定惯性大小（老信念更硬）|
| $\iota$ 认同融合度 | 结构与G自我模型的重叠深度 | 决定情感阻力（修改"我是谁"代价最高）|

三者不可简化为单一维度——高连通性低认同融合度的L2与低连通性高认同融合度的L2，崩溃模式完全不同。

## 5. 与文件09的接口

文件09描述了L2重建的触发机制（跨G张力积累 → 超阈值 → 重建）。
本文件精化了阈值的内部结构：

- 文件09的"L2承载阈值"= 本文件的 $\Theta$
- 文件09的"重建方向"取决于**张力可溯源性**
- 本文件补充：可溯源性还受 $\Lambda_{\text{L2}}$ 影响——L2越硬，张力越难被定位到具体子结构，越倾向防御性封闭

$$\uparrow \Lambda_{\text{L2}} \xrightarrow{} \downarrow \text{张力可溯源性} \xrightarrow{} P(\text{防御性封闭}) \uparrow$$
