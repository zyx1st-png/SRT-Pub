# SRT 运行节奏（Cadence）

- Daily:
  - Pipeline 1 材料融合（先审后入正文）
- Every 3 days:
  - Pipeline 3 情报采集与审核
- Weekly:
  - Pipeline 2 论文候选池与主稿迭代
  - Pipeline 4 文档治理巡检
- Twice weekly:
  - Pipeline 5 双风格内容产出（默认先入发布队列）
- Biweekly:
  - Release Note 更新与质量回顾
