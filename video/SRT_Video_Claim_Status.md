# SRT Video / Public Script Claim Status

> **Role**: guardrail for scripts, cinematic drafts, subtitles, and public-facing explanatory language.
> **Boundary**: video scripts may use compression, contrast, and memorable phrasing, but they do not define SRT primitives and do not outrank canonical files or domain claim-status audits.

---

## 1. Public compression rule

Public scripts may simplify, but every strong public slogan must remain compatible with these constraints:

- selection is constrained by resistance / payability / anchoring / stabilization;
- `d-value` is not attention scope, kindness, spiritual rank, all-knowledge, or infinite love;
- `Ψ_f` is not pain, suffering, energy, prediction error, Fisher metric, or moral guilt;
- AI claims must state architecture state when using `d_AI approx 0` or `Ψ_f` non-binding language;
- God / Ω / divine / liberation language is spirituality-domain mapping, not canonical proof.

---

## 2. High-risk public phrases

| Risk phrase | Video-safe replacement |
|---|---|
| “苦难 ∝ 1/d” | “可作为低-d / narrow-care phenomenological proxy，不是 canonical formula。” |
| “解脱 = d -> infinity” | “解脱语言指向更宽 consequence-bearing 的 regulative direction，不是 finite attainment。” |
| “神 is infinite selection operator” | “神/Ω可作为 total-source / asymptotic mapping，不是 SRT theological proof。” |
| “AI 现在没有意识” | “当前 inference-only / non-history-bearing / non-embodied LLM 部署不满足 SRT stake/subjecthood 条件。” |
| “预测编码自由能是 Ψ_f” | “预测编码自由能可作为神经层 proxy / projection，不定义 canonical `Ψ_f`。” |
| “量子测量就是选择算子” | “量子测量可被 SRT 读作 selection/anchoring interface；不是已证明的物理替代理论。” |
| “意识创造现实” | “确定现实依赖受约束选择、支付、锚定与稳定化；不是意念创造外部世界。” |

---

## 3. Script authoring rule

When writing public scripts:

1. Use strong metaphors in narration only if a nearby sentence prevents literal overread.
2. Prefer “可以读作 / 可被建模为 / public shorthand / proxy / mapping” for formulas involving spirituality, suffering, AI, physics, and morality.
3. Avoid presenting old cinematic lines as current canonical claims unless refreshed against domain claim-status files.
4. If a video draft is older than the relevant claim-status audit, treat it as historical copy needing claim hygiene before publication.

---

## 4. Minimum pre-publication check

Before publishing or translating a script, scan for:

```text
Ψ_f = / Ψ_f -> infinity / pain = / suffering ∝ / d -> infinity / God = / AI has no consciousness / mind creates reality / measurement is selection
```

If present, either add a guardrail sentence or downgrade to proxy / mapping / bridge wording.
