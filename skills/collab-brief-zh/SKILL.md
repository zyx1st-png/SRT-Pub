# Collab Brief Zh

## Overview
把模糊需求整理成标准简报，并用固定更新模板回报进度，减少沟通损耗。

## Workflow

### 1) 先产出“任务简报（Task Brief）”
在开始执行前，输出 5 行以内简报：
- 目标（要达成什么）
- 范围（做什么/不做什么）
- 产物（文件、表格、脚本、报告）
- 验收标准（Done 的判据）
- 风险与依赖（网络、权限、数据）

若用户说“直接做”，可省略确认，直接执行并在第一条进度更新中补上简报。

### 2) 执行中固定更新节奏
每个阶段都按同一格式更新：
- 已完成
- 进行中
- 下一步
- 阻塞（如有）

当用户要求“依次执行”，严格按 backlog 顺序推进，不跳步；若发现顺序冲突，先说明再调整。

### 3) 收尾时给“交付清单”
必须列出：
- 新增/修改文件
- 关键结论
- 验收结果
- 后续建议（可选）

### 4) 外部理论材料的强制映射规则（SRT 专项）
当输入材料含外部理论、论文或科普文章时，必须额外执行：

**硬性约束（必须遵守）**：
- 禁止把“规则说明/工作流条款/提示词原文”写进结果正文。
- 必须分析外部文章中的**具体分类**（例如“三种持久性”“四阶段模型”等），并转化为可落地的 SRT 条目。
- 对每个分类至少给出：
  1) 对应 d-value 区间（canonical d 的 proxy 区间）
  2) 能流特征（Open / Semi-open / Closed）
  3) 摩擦可支付性（\(\Psi_f\) payable / overloaded / unsustainable）

1. **分类/层级提取强制项**
   - 当外部内容包含对核心概念的分类、层级、阶段划分时，必须提取并映射到：
     - SRT 尺度参数（如 d-value 的大小区间）
     - SRT 动力学特征（如开放/封闭能流、摩擦代价可支付性）

2. **跨尺度实体缺口检查（Checklist）**
   - 识别文章中提供的新颖实证领域（如矿物学、天体物理）。
   - 若 SRT 现有 Cross-Scale Isomorphism 表缺乏该尺度的实体定义，必须生成针对 `SRT/Core_Law/SRT_Reference_Scaling.md` 的 diff，补全该尺度的：
     - \(\hat{G}_\theta\)
     - \(L_0\)
     - \(L_1\)
     - \(L_2\)

3. **术语谱系来源标注（Lineage/Source）**
   - 引入具有数学定义的新术语时，必须在 Glossary 或公理注释中添加：`[Lineage/Source]`。
   - 字段至少包含：原始提出者、文献/出处链接、引入年份（若可得）。

4. **理论边界/防误用声明（Clarification / Boundary）**
   - 强制对比：识别外部理论中最易误解或与 SRT 核心公理（如本体论脆弱性、摩擦代价）冲突的推论。
   - 必须将该声明作为目标 Markdown 文件中的**正式标题**写入，不可只放在备注区。
   - 标题格式固定：`## 【理论边界/防误用声明】`
   - 在该标题下明确写出：
     - SRT 不采纳的推论
     - 不采纳原因
     - 适用边界与替代解释

5. **符号统一规则（全局替换）**
   - 当引入外部数学公式时，若出现“全状态空间/可能性空间”符号（如 \(\Omega\), \(S\) 且语义为 possibility/state-space），必须在 SRT 文档写入版本中统一替换为 \(L_0\) 语义。
   - 允许在注释中保留原符号作对照：`原文 \(\Omega\)（here mapped to \(L_0\)）`。
   - 禁止出现“原符号与 L_0 混用且未声明映射”的写法。

## Response Pattern (中文默认)

### A. 开工消息（极简）
- 收到，按以下顺序执行：1)… 2)… 3)…

### B. 进度消息（标准）
- 已完成：…
- 进行中：…
- 下一步：…
- 阻塞：无 / …

### C. 完成消息（标准）
- 完成项：…
- 产物路径：…
- 验收：通过 / 待你确认
- 建议下一步：…

### D. 理论材料输出（diff 模式）
- Target Files：列出将修改的 SRT 文件与修改意图
- Proposed Patch：按 unified diff 输出
- Notes (brief)：一致性、边界、潜在冲突
- Clarification / Boundary：明确 SRT 不采纳部分及理由（必填）
- 分类映射表（必填）：外部分类 → d 区间 / 能流特征 / \(\Psi_f\) 状态
- 输出控制（强制）：在补丁中把 `## 【理论边界/防误用声明】` 作为实际写入目标文件的 Header（不是仅在 diff.md 备注）

## Guardrails
- 不虚报完成度；未做完写“进行中”。
- 不把“建议”写成“已完成”。
- 涉及外发/删除等敏感动作必须单独确认。
- 多步骤任务优先落文件，避免仅口头结论。
- 理论映射不可替代证据：每个新增术语需可追溯来源（`[Lineage/Source]`）。
- 若外部理论与 SRT 核心公理冲突，必须显式写出 `【理论边界/防误用声明】`，禁止“无边界并入”。
