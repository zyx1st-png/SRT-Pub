## 3. Core claims reported by the source

> 本节全部是“会议记录报告了什么”，不是 SRT 结论，也不是已经完成的一手核验。

### 3.1 Qualia can be studied through relational structure

会议前半段提出：isolated labels / verbal reports 不足以承载 qualia 研究，可以改从体验之间的关系结构、相似性结构或更大的关系网络入手，并尝试用数学方式描述这些关系。

材料中的强版本表述包括：

```text
entity-first description may be insufficient;
relations may be more informative than isolated entities;
qualia may be approached through relational organization.
```

会议助手进一步把它概括成“关系优先”“没有实体对象时关系仍可存在”等说法。后两种强表述必须在未来回到原论文/项目文本核验，不能直接归给主讲人或相关学术项目。

### 3.2 Language label != reported similarity structure

会议报告的儿童颜色研究区分了：

```text
颜色命名能力
!=
颜色相似性判断结构
```

记录称三岁儿童颜色命名较差，但通过直接触屏进行颜色相似性判断时，得到较稳定的结构；中日/不同年龄组的颜色相似性结构也被报告为高度接近，而文化情绪差异对基础颜色相似结构影响较小。

若一手研究支持该结果，它对意识研究最重要的意义不是“儿童和成人体验已经被证明相同”，而是：

```text
report vocabulary / naming competence
need not be identical with
relational organization recoverable from behavior.
```

### 3.3 Internal organization vs external behavior

会议对 AI consciousness repeatedly 区分：

```text
external behavior / functional output
!=
internal organization
!=
phenomenal experience automatically
```

主讲路线明显偏向 internal organization：仅凭 AI 表现出某种行为功能不足以确定 consciousness；内部结构/组织方式被视为更关键的研究对象。

材料本身并未给出“何种内部组织足够产生 consciousness”的充分条件。

### 3.4 Counterfactual / joint causation as mechanism tools

会议将反事实框架、联合因果、神经群体作用与 causal emergence 连到一起，意图从单神经元相关性转向受结构约束的联合因果组织，并强调主动刺激/记录、干预和人工芯片测试意识理论的价值。

材料支持的最安全方法论读法是：

```text
correlation-only observation
<
intervention / counterfactual mechanism testing
```

但它不支持把 counterfactual causation 本身升级成 pre-object / primitive ontology。

### 3.5 Information as meaningful difference / structural correspondence

Richard Tong 部分把 information 从 Shannon quantity 拉回 meaning / relation，讨论“产生差异的差异”、赋予形状以及体验结构之间的同构/结构对应。

这一段对 SRT 有启发，但属于高偷渡风险材料，因为任何 primitive use 都会立刻要求回答：

```text
difference for whom / for what?
what system receives or preserves the difference?
what makes the difference consequential?
```

会议没有在 primitive ontology 层解决这些问题。

### 3.6 Anthropomorphism critique is not an ontic disproof

Digital mind 部分有一个较清楚的方法论区分：

```text
why an observer attributes a mental property to a system
!=
whether the system actually has that property.
```

因此，“language causes anthropomorphic attribution”最多解释 judgment formation，不能单凭这一点反推出 system definitely lacks the relevant mental property。

同时会议要求：

```text
attribution strength should track evidence strength;
behavioral evidence should be distinguished from causal-mechanistic evidence.
```

这对未来 AI consciousness / welfare claim discipline 有直接 guardrail 价值。

### 3.7 China–US AI consciousness / moral-status attitudes

后半场报告了一项中美公众调研：中国样本被报告为更愿意向当前/未来 AI 归属 consciousness 和 moral status；两国在极端利益冲突中仍优先保护 biological humans，并在国际合作治理上存在一定共识。

该部分主要属于：

```text
public attribution / social expectation / governance context
```

而不是：

```text
actual consciousness condition
actual Bearer condition
moral truth
```

所以对 SRT 核心 ontology 的直接承重较低。

## 6. SRT relevance

### 6.1 Qualia Structure is a strong external neighbor to existing PH-QUAL01, not a new SRT construct

仓库已有：

```text

```

其中已经使用：

```text
Q_L1 = (E, Delta_ij)
```

来表示 experience items 与 experienced dissimilarity relation，并明确要求从 phenomenal neighborhoods / clustering / deformation 而不是 isolated labels 约束 qualitative character。

因此本次材料不能再创建：

```text
new relational-qualia geometry
new similarity-space primitive
new qualia-structure ladder
```

它真正的新价值是：

> 提供一个明确存在于外部 consciousness research 中的 relation-first / qualia-structure 邻居，未来可以用其正式论文对 PH-QUAL01 做 source fidelity、absorption、contrast 与 pressure test。

### 6.2 Ground relevance: relational characterization does not yet pay actuality

对当前 Ground / primitive Selection 最有价值的问题不是“关系优先是否正确”，而是：

> **如果 strongest relational structuralism 已经可以用 relations 充分刻画一个 experience / object，那么它是否还能解释为什么某个 determinate relational organization 实际化，而不是只描述已经形成的 relational structure？**

可保留为 future strongest-neighbor question：

```text
relational characterization of an already formed structure
?
actualising differentiation that makes this determinate structure operative
```

如果未来一手 Qualia Structure / relational ontology 已经能支付后者，SRT 的 Selection residual 必须缩小；如果不能，则需要精确说明缺的不是“relation”这个词，而是 actuality / determination / manifestation burden。

本材料只**提出该 pressure**，不裁决结果。

### 6.3 Internal organization != SRT perspective

会议偏向 internal organization，但当前 SRT 必须保留更严格的 non-identity：

```text
inside-the-system causal organization
!=
formed One-level endogenous perspective automatically
!=
Bearer
!=
phenomenality.
```

后续若把这条材料用于 AI consciousness，最有价值的不是把“internality”直接映射成 perspective，而是反过来问：

> 什么条件使一个 observer-described internal organization 变成该 formed position 自身在后续 manifestation / backgrounding / selectable-space organization 中 load-bearing 的 endogenous participation？

### 6.4 Counterfactual causal models should remain post-formation unless they pay their prerequisites

会议的 causal-emergence / intervention 路线适合 neuroscience mechanism hardening，但不应无检查下沉到 primitive Ground。

原因是 counterfactual model 通常已经需要某些已形成项目：

```text
variables;
alternative states;
intervention relation;
system boundary;
causal comparison;
often temporal or dependency order.
```

因此未来若有人用 causal emergence “解释 Selection”，必须先证明这些前件没有偷偷预设 formed system / option structure / time，而不是只换名。

### 6.5 “Difference that makes a difference” is useful pressure, not a free primitive

该信息论/意义论表达最值得保留的 SRT 问题是：

```text
when does a difference become generatively consequential?
```

但在 Ground 层使用前必须排除 receiver / bearer / system / code / meaning 的偷渡。

安全路由：

- primitive use = OPEN / pressure only；
- formed-position / history-writeback / later selectability use = potentially relevant；
- no new information primitive is authorized。

### 6.6 Digital-mind attribution discipline is a useful AI guardrail

会议对 anthropomorphism 的处理与 SRT 已有 claim hygiene 兼容：

```text
observed behavior
!=
mental-property attribution
!=
causal mechanism
!=
Bearer / subjecthood / phenomenality proof.
```

同时还应保留另一半：

```text
anthropomorphic route to attribution
!=
proof that the attributed property is absent.
```

这可以成为以后 AI consciousness / welfare 材料审计的双向 guard：既防 over-attribution，也防用“拟人化”作为 ontic dismissal shortcut。

### 6.7 Cross-cultural survey belongs downstream

中美态度差异可在未来进入：

- AI governance；
- social attribution；
- recognition / moral-status interface；
- public-policy framing。

但不应打断当前 Ground 主线，也不应作为 consciousness / Bearer admission evidence。
