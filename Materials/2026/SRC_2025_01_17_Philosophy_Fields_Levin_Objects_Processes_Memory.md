# SourceCard: Fields & Levin — *Thoughts and thinkers*

## 1. One-line summary

Fields 与 Levin 反对把 objects 与 processes 当作互斥本体选项，主张二者是描述 persistence through time 的互补方式；论文同时把可用记忆视为观察变化的必要资源，并把记录性记忆视为更基础的解释功能之派生物。

## 2. Source boundary

这是 peer-reviewed conceptual/formal synthesis。它结合 category theory、standard quantum theory、FEP、active inference 与 multiscale biology，提出广域哲学结论；其中若干形式选择和普遍化前提是论文框架的一部分，不是由一组新实验单独证明。

本卡因此不把下列内容当作 SRT 证据：

```text
FEP applies without qualification to every persistent system
all object/process distinctions should literally be abolished
memory as interpretation proves a specific SRT bearer
multiscale competency proves agency, stake or consciousness
```

## 3. Source-backed claims

### 3.1 Object/process complementarity

论文的中心主张不是简单的“过程优先”，而是 objects 与 processes 可以作为时间持续性的互补描述；把二者设为排他的本体二分，可能遮蔽观察与操控所需的条件。

**Anchor:** abstract；§1 introduction；§6 conclusion。

### 3.2 Observation requires reference memory

论文用 signal/object change detection 等例子说明，观察变化需要区分相对稳定的 reference state 与变化的 pointer state；检测装置和观察者都依赖已实现的结构／记忆资源。

**Anchor:** §2.2 signal and object-change discussion；later observer discussion。

### 3.3 Memory is first interpretive, record second

论文沿用 Levin 的论点，把 memory 首先理解为当下可执行的解释功能；“过去事件的记录”是这种功能的一种派生读法。该主张用于连接观察、时间、历史序列与系统持续。

**Anchor:** abstract；§4–§5 observer and memory discussions。

## 4. SRT comparison

当前 SRT 已分别承载：

```text
ST-A: recurrent historical reconstitution + continued selectability
EX-A: event actuality != anchoring persistence != stable ISP identity
PH-MEM01: retention/transformation/use distinctions
PH-DIFF01 and objectification owners: individuation/process constraints
```

因此该来源没有留下一个需要新 owner node 的独立正向命题。它提供的稳定 guardrail 是：

```text
object description != bearer individuation criterion
process description != sufficient identity criterion
present similarity != shared historical identity
available memory for observation != hidden permanent archive
```

## 5. O-track / D-track verdict

- O-track：有比较与边界加固价值，但核心结构已被 ST-A、EX-A 与 memory/objectification 路线承载。
- D-track：无。论文不检验 SRT，也不提供相对 process ontology、FEP 或普通 dynamical-systems rivals 的 SRT 独有预测。
