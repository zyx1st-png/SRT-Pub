# SourceCard: Friston et al. (2026), active inference and artificial reasoning

## 1. One-line summary

Friston et al. extend active inference from state inference and parameter learning to active structure learning / rule discovery: actions can be selected partly for expected information gain over alternative model structures, with Bayesian Model Reduction (BMR) used to compare models efficiently. The paper also explicitly describes BMR as an offline process proposed for introspection or sleep and reprises a three-ball paradigm previously used for synthetic insight via introspection / sleep. For the current SRT cognition programme, this is an H2 reduction-base upgrade, not SRT support.

## 2. Core source-owned claims

The following remain source-owned.

1. The paper distinguishes uncertainty about latent states, model parameters and model structure, and associates these with inference, learning and model selection respectively.
2. It introduces expected information gain over model structures as an epistemic contribution to action selection.
3. Bayesian Model Reduction is used to evaluate alternative model structures efficiently after evidence accumulates.
4. BMR is described as an offline variational process proposed to occur during introspection or sleep.
5. The worked three-ball paradigm demonstrates active rule discovery under a supplied family of partially observed discrete generative models and is explicitly linked to prior synthetic insight / sleep work.
6. The authors frame reasoning here as optimisation / selection of model structure under a prior model space.
7. The prior model space is constrained using plausible symmetries and structural assumptions; the paper does not claim an unconstrained search over all possible world models.

### Source anchors

- Abstract — structure learning, expected information gain over models, BMR, and the three-ball paradigm previously used for synthetic introspection / sleep.
- Introduction — distinction among hidden states, parameters and structure; offline BMR as proposed for introspection / sleep; active structure learning; prior model-space constraints.
- Results, "The three-ball paradigm" — active data sampling, model comparison and rule selection.
- Discussion / scope statements — the worked agent is stated to know the generative model of the task / puzzle family rather than learning that full model directly from unsegmented sensory input in the same demonstration.

## 3. Evidence / method

This is a peer-reviewed theoretical and computational article with an independently archived preprint (`arXiv:2512.21129`). The paper uses discrete partially observed generative models and simulations; it reports no new empirical human or animal dataset.

The strongest repository-relevant evidence is therefore formal / architectural:

- active inference can extend beyond policy choice to model-structure learning;
- structure discovery can guide epistemic action;
- BMR can operate post-hoc / offline after evidence accumulation;
- sleep / introspection are explicitly named as proposed biological / cognitive contexts for such offline model reduction;
- the demonstrated rule-learning problem remains inside a supplied generative-model architecture and constrained hypothesis space.

## 4. Limits

The source itself supplies the main limit for current comparison.

The demonstration assumes that the agent knows the generative model of the task / puzzle and then reasons over candidate reduced model structures / rules. It does not, in the same demonstration, learn the entire generative model from unsegmented sensory input.

Therefore:

- successful active structure learning does not imply unrestricted constitution of state variables, factors, boundaries or objects;
- the source blocks any weak SRT comparison that treats active inference as fixed-menu policy selection only;
- the supplied-model limitation is not evidence that SRT fills the remaining problem.
