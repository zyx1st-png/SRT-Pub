# SourceCard: Friston et al. (2026), active inference and artificial reasoning

## 1. One-line summary

Friston et al. extend active inference from state inference and parameter learning to active structure learning / rule discovery: actions are selected partly for expected information gain over alternative model structures, with Bayesian Model Reduction used to compare models efficiently. For the current SRT cognition programme, this is a strongest-baseline upgrade, not SRT support: any claim that SRT uniquely "changes the menu" must now survive a fair structure-learning comparator.

## 2. Core source-owned claims

The following remain source-owned.

1. The paper distinguishes uncertainty about latent states, model parameters and model structure, and associates these with inference, learning and model selection respectively.
2. It introduces expected information gain over model structures as an epistemic contribution to action selection.
3. Bayesian Model Reduction is used to evaluate alternative model structures efficiently after evidence accumulates.
4. The worked three-ball paradigm demonstrates active rule discovery under a supplied family of partially observed discrete generative models.
5. The authors explicitly frame reasoning here as optimisation / selection of model structure under a prior model space.
6. The prior model space is constrained using plausible symmetries and structural assumptions; the paper does not claim an unconstrained search over all possible world models.

### Source anchors

- Abstract — structure learning, expected information gain over models, Bayesian Model Reduction.
- Introduction — distinction among hidden states, parameters and structure; active structure learning; prior model-space constraints.
- Methods, "Active inference, learning and selection" — generative model, hidden states, policies and expected free energy.
- Discussion — explicit scope limit: the worked agent is assumed to know the generative model family in which the unknown rule is implemented, rather than learning that full model directly from unsegmented sensory input.

## 3. Evidence / method

This is a peer-reviewed theoretical and computational article. The paper uses discrete partially observed generative models and simulations; it reports no new empirical human or animal dataset.

The strongest repository-relevant evidence is therefore formal / architectural:

- active inference can be extended beyond policy choice to structure learning;
- structure discovery can itself guide epistemic action;
- the demonstrated rule-learning problem is nevertheless posed inside a supplied generative-model architecture and constrained hypothesis space.

## 4. Limits

The source itself provides the most important limit for the current SRT comparison.

The demonstration assumes that the agent already knows the generative model under which the unknown rule is implemented. It does not solve, in the same demonstration, how an agent learns the entire generative model from unsegmented sensory input. The paper also treats rule discovery mainly as discovery of the form of a likelihood mapping to a rule-defining outcome.

Therefore:

- successful active structure learning does not imply unrestricted constitution of state variables, factors, boundaries or objects;
- conversely, the source blocks any weak SRT comparison that treats active inference as fixed-menu policy selection only.
