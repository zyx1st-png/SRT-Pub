# SourceCard: Kibbe & Leslie — Minimal object representations in the infant mind

## 1. One-line summary

Kibbe and Leslie argue that infant cognition can maintain a minimal object representation—a bare object index that preserves “there is this one” and supports continued tracking—without simultaneously preserving a rich description of what the object is; the source therefore supports the cognitive claim that **object individuation can precede identification and descriptive property binding**, while providing no direct evidence that subjecthood, consciousness, stake or consequence-bearing work the same way.

## 4. Source-level claims

The following are source-level cognitive-development claims as captured in the prior full-text close read.

### 4.1 Object existence can remain represented when identifying content is unavailable

The source distinguishes at least two questions:

```text
Is there an object?
What object is it?
```

Infants can preserve an expectation that an occluded object remains present even in conditions where they do not retain or use enough surface-feature information to reidentify the object by shape or appearance.

Safe source-level statement:

> object-existence / individuation information can be retained when richer identifying content is unavailable or lost.

This does not imply that physical objects lack properties or that properties are never represented.

### 4.2 Bare object index as minimal representation candidate

The paper treats an `index` as a minimal pointer-like representation that can be deployed to an object and maintained through occlusion. A bare index need not contain the full descriptive content normally associated with an object concept.

This motivates a separation between:

```text
object individuation / tracking
and
object identification / description
```

### 4.3 Index deployment can precede optional property binding

The mature architecture described in the paper permits an object index to be established first, with property/category information bound later and under additional resource constraints.

Compact source-level sequence:

```text
index deployment
-> optional property/category binding
-> richer object concept / physical expectations
```

The source does not require a complete property description as a prerequisite for representing that an object exists.

### 4.4 Category and surface-feature information can dissociate

The prior close read records cases in which infants can preserve a coarse category distinction while failing to preserve or act on finer surface-feature identity. This reinforces the idea that object representation is layered rather than one scalar “richness” dimension.

Possible layers include:

```text
bare individuation index
category information
surface-feature identity
richer physical expectations
```

### 4.5 Minimal index is not a complete object ontology

The object-index architecture is an operational account of cognitive individuation/tracking. It is not a metaphysical theory of what objects ultimately are, and it does not show that physical objects depend on being indexed by a mind.

## 5. Minimal surviving claims after second-round adjudication

### Surviving claim 1

**Claim:** In infant object cognition, maintaining “this one exists / is still this one” can precede or survive without a rich representation of “what this one is.”

**Epistemic level:** OS / source evidence.

**Status:** admissible as a cognitive-development source claim.

### Surviving claim 2

**Claim:** Object individuation, object identification and subject individuation must not be collapsed into one process.

**Epistemic level:** P3 bridge/guardrail.

**Status:** admissible as an SRT hardening distinction because the source supplies a strong object-level negative control.

### Surviving claim 3

**Claim:** The source creates a useful but explicitly analogical prompt for SRT: if an object can be individuated before it is descriptively identified, then SRT should separately test whether a subject position can be individuated before it is reflectively self-identified.

**Epistemic level:** P3 analogy / theory prompt.

**Status:** not source evidence; route to a philosophy hardening patch.

## 6. Corrected SRT interface

### 6.1 Directly supported interface: “this one” before “what it is”

The strongest source-facing bridge is:

```text
object individuation
can precede
object identification / rich description
```

Useful formulation:

> A cognitive system can preserve a thin “this one” before it preserves or constructs a rich answer to “what is this one?”

This is the material’s actual empirical/theoretical contribution.

### 6.2 Object tracking is not bearing

A bare object index answers something like:

```text
Which one is being tracked?
Is it still the same tracked item?
```

It does not answer:

```text
For whom did the consequence matter?
Where did the consequence return?
Which continuing process had its own future selectability rewritten?
```

Therefore:

```text
tracking continuity
!= bearer continuity

object index
!= Stable ISP

object individuation
!= subject individuation
```

### 6.3 New 2026-08-08 theory prompt: subject individuation before self-identification

Current `Core_Law/SRT_Individuation.md` already distinguishes a subject-position phase from a later transition to reflective self-consciousness. That existing SRT structure creates a disciplined analogy:

```text
OBJECT SIDE
"this one"
-> "still this one"
-> "what this one is"

SUBJECT SIDE (SRT hypothesis)
"from this bearer / from here"
-> "still this bearer across consequences and history"
-> "who I am" / reflective self-model
```

Only the object-side architecture receives direct support from Kibbe–Leslie.

The subject-side sequence is an SRT P3 structural analogy constrained by the existing individuation theory. It must not be presented as an infant-cognition finding.

## 7. What the source corrects in SRT language

### 7.1 Do not make “object” start too thick

An object need not enter cognition as a completed bundle of category, appearance and physical description. A thin trackable individual can be maintained first.

### 7.2 Do not make “subject” start as a self-description

The source does not prove this, but it makes a useful comparison available: SRT should not assume that a subject requires a prior narrative or reflective model of itself any more than object tracking requires a prior complete description of the object.

This remains an SRT inference from the comparison, not a source conclusion.

### 7.3 Do not collapse object continuity into first-person continuity

A system can track many persistent objects without any of those object indices being the locus where consequences are borne. SRT therefore requires a separate same-bearer / history-writeback / consequence-return audit for subjecthood.

## 8. Bidirectional gain card

### New interface

- `object individuation before identification` as a source-backed cognitive distinction;
- thin “this one” versus rich “what it is” representation;
- object tracking continuity as a negative control for subject continuity;
- a new P3 comparison between object individuation and pre-reflective subject-position formation.

### Reverse correction

- The old PR #686 formulation that allowed the source to appear to support `selective convergence -> this one` is rejected.
- The source does not support `bearing closure`, `stake`, subjectivity or consciousness.
- “Object index” must not become an SRT primitive or a proxy for consciousness.
- The object/subject parallel must be labeled analogy, not evidence transfer.

### Strengthened SRT content

- `SRT_Individuation` already places subject-position entry before reflective self-consciousness; Kibbe–Leslie supplies a neighboring cognitive architecture in which individuation likewise precedes richer identification.
- `PH-CONSC03` gains a cleaner negative control: selector/bearer/experiencer cannot be inferred from an ability to maintain object indices.
- self-model theories face a sharper question: does the self-model identify an already individuated bearer, or is the model itself supposed to create the bearer?

### SRT contribution back to the source

SRT adds a distinction the object-index architecture does not need to answer:

```text
tracking boundary
!= consequence-return boundary
```

The first tells us which object remains cognitively available. The second asks which continuing process must carry the consequences into its own future.

### Residual pressure

- Whether a “bare” object index is literally description-free depends on how spatiotemporal and operational structure are classified.
- Looking-time paradigms remain methodologically indirect.
- The object/subject structural analogy may turn out to be shallow if subject individuation requires qualitatively different mechanisms rather than a homologous “thin index before rich model” architecture.
- SRT must not use the analogy as evidence that pre-reflective subjecthood or phenomenal consciousness exists in any specific infant or animal case.

## 9. Adjudication

**A — bounded cognitive-development evidence card + P3 individuation guard/analogy.**

Why A:

1. the source provides a stable, peer-reviewed object-level distinction;
2. the prior overreach is identifiable and removable;
3. the source gives SRT a strong negative control against collapsing object tracking into subjecthood;
4. the new object/subject parallel is useful only when explicitly quarantined as P3 analogy.

Not admitted:

```text
object index proves SRT ontology
object index proves consciousness
individuation-before-identification proves subject-before-self-model
selective convergence is empirically established by this source
bearing closure is empirically established by this source
```
