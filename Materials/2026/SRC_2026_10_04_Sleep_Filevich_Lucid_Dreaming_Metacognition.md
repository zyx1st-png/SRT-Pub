# SourceCard: Filevich et al. (2015), lucid dreaming and metacognition

## 1. Source fact

Compared with a low-lucidity group, participants reporting higher lucid-dreaming ability showed greater frontopolar gray-matter volume. The same BA9/10 regions were recruited during a waking thought-monitoring task, with stronger BOLD increases in the high-lucidity group.

The authors interpret this as shared neural systems between lucid dreaming and metacognitive thought monitoring.

## 2. Boundary

This source supports a mature comparison in which becoming lucid / monitoring one's current mental state is linked to metacognitive systems.

It does not establish:

- a discrete reanchoring mechanism;
- successful dream control;
- Position reconstitution;
- SRT Selection.

Lucidity / metacognition must still be separated from control using the existing Bonamino & Peters guardrail.

## 3. Revival trigger

Use with Bonamino & Peters if a future dream assay tests whether:

    meta-awareness / lucidity recovers
    while stronger frame exit / reframing / reanchoring measures remain dissociable.
