# SourceCard: Rechtschaffen (1978), dream single-mindedness

## 1. Source fact

Rechtschaffen characterizes dreams as "single-minded." The abstract names four manifestations:

- lack of reflective awareness that one is dreaming;
- lack of alternative simultaneous thoughts / images while attending to the main dream content;
- tendency to remain on one thematic track;
- lack of an in-dream set to remember the dream.

## 2. Boundary

This is a direct mature neighbor for the **phenomenological part** of R5 Reading C:

    rich dream content can continue
    while reflective noticing / alternative-frame access is weak

It does not establish an SRT mechanism, primitive Selection loss, Position reconstitution, or the neural cause of the phenomenon.

## 3. Revival trigger

If the current cognition route operationalizes Reading C in dreams, use Rechtschaffen as an ownership comparator for:

- contradiction / anomaly noticing;
- alternative-frame availability;
- thematic / frame persistence.
