## 3. 已稳定的跨文献增量

### 3.1 Evidence provenance

```text
observable indicator
-> target-overlap audit
-> causal grounding
-> bearer audit
-> consequence-return gate
-> candidate stake evidence
```

### 3.2 Cognitive selection and commitment

```text
available continuations
-> knowledge-shaped structural bias
-> enacted reasoning trajectory
-> no final guarantee
-> constitutive commitment
-> responsibility-bearing position
```

必须区分：

```text
bias efficacy != directional readability != stake ownership
support != final guarantee
commitment != truth
retroactive stabilization != retrocausation
```

### 3.3 Bilateral position and context repair

Simonelli 全文支持：

```text
position = assertions + denials + open remainder
```

并要求区分：

```text
strict incompatibility
!= defeasible material clash
!= script-generated false dilemma
```

材料冲突可能通过例外、角色、时间或边界信息得到 repair；但作者同时明确指出：

```text
negative incompatibility != positive committive consequence
```

所以 exclusion 不能单独定义选择。

### 3.4 ChoiceMap 综合管线

```text
expand options
-> reveal installed biases
-> separate assertions / denials / left-open alternatives
-> classify strict / defeasible / script-generated clashes
-> test repair contexts
-> distinguish reducible uncertainty from final-guarantee gap
-> declare bearer, horizon and delay cost
-> record positive consequences and revision conditions
-> preserve reselection
-> return commitment to user
```
