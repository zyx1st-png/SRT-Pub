# SourceCard: Chris Sawyer — *Subtraction*

## 1. 一句话结论

这本书真正可供 SRT 吸收的，不是其中关于压力、空间介质、燃烧、氧气、生命、视觉或超常感知的自然哲学，而是一条经过严格收紧后仍有价值的治理原则：

> **一个理论成分只有在明确目标、尺度、时间窗、扰动集、允许重拟合范围和观测指标后，经受受控删除仍造成不可替代损失，才获得“当前目标下不可删除”的资格；不可删除不等于真实、基础或本体终极。**

因此本书采用分层裁决：

```text
A：减法式必要性审计、解释饱和诊断、开放/边界负荷检查
C：书中未经充分证据支撑的替代物理学、化学、生理学、超常感知和宇宙论断言
```

## 3. 全书结构

本书没有常规章标题，而是以三个大段落和附录推进。

### 3.1 第一运动：从解释饱和到边界与生命（书内 pp. 1–41）

主要路径：

```text
解释仍在运转但不再改变方向
-> refusal / saturation
-> 怀疑 surplus mediation
-> 以 shared constraint 解释部分无沟通趋同
-> reduced interference 与 openness cost
-> 神秘实践作为干扰减少
-> life as maintained exclusion
```

其中最值得保留的图示是书内 p. 26 的四象限：

- total exposure：无缓冲、无延迟、信号等价、调节崩溃；
- reduced interference：表面清晰度提高，但负荷和脆弱性上升；
- regulated permeability：选择性进入、边界维持、延迟与调节、可持续存在；
- institutional insulation：稳定但可能通过形式过滤异常并损失敏感性。

### 3.2 第二运动：从解释制度批评滑向替代自然哲学（书内 pp. 42–179）

前段仍延续有价值的诊断：

- 解释可以增加而 orientation 不再增加；
- 机构会把异常重新分类为边缘问题，以维持程序连续性；
- “统一”“深度”“起源”“终点”可能成为停止继续追问的修辞装置。

但随后文本逐渐提出一整套替代自然哲学，包括：

- 把 pressure 与 “medium of space” 作为广泛原因；
- 以局部 interruption / minus-pressure 解释运动；
- 质疑原子、热、氧气和现代化学的本体表达；
- 以保护、暴露和排除重述燃烧、呼吸、消化、心脏、视觉和运动；
- 讨论第六感、梦、远距报告和所谓减法状态；
- 延伸到惯性、行星形成、彗星和宇宙结构。

这些内容有时被作者标成“不是现代化学的替代”，但正文又持续以事实语气描述机制，因而形成显著的类别漂移。

### 3.3 附录：删除条件、总开放反模型与废弃路线（书内 pp. 181–206）

附录包含：

1. 一组删除句式：术语、解释、框架、假设、原则在撤除后若不改变持续现象，就被移除；
2. 63 条“总开放与边界崩溃”的形式化列表；
3. “Failures and Abandoned Lines”：记录因过度稳定、过度优雅、过度一致或不再产生差异而被放弃的路线。

作者最终明确：

```text
survival after removal
!= truth
!= foundation
!= finality
!= proof that further removal is impossible
```

## 4. 方法纲领的准确重建

### 4.1 Refusal 不是反驳

作者把起点放在一种特殊失败：

```text
论证仍然正确
+ 文献仍然增加
+ 程序仍然运行
+ 但不再改变理解、行动或方向
= explanatory saturation
```

因此 refusal 不是发现某理论为假，而是拒绝继续用同一种加法手势维持解释。

### 4.2 删除标准针对必要性，不直接针对真值

书内明确说：

- 一个主张可以为真，但对当前现象解释仍可删除；
- 一个主张也可能暂时不可删除，却仍未得到正当化；
- 残余不因幸存而获得特权。

这意味着减法检验最多回答：

> 在当前目标和表示方式下，这个成分是否仍承担不可替代工作？

它不能直接回答：

> 这个成分是否真实存在？

### 4.3 作者自己拒绝把 subtraction 稳定成算法

“Failures and Abandoned Lines” 中，作者说把 subtraction 表述成 method 的路线被放弃，因为它开始类似 optimization。

因此全书存在一个重要张力：

```text
书籍描述：subtractive philosophical method
正文自我理解：refusal / orientation / constraint，拒绝稳定成优化程序
附录实际操作：又提供大量可复用删除准则
```

SRT 不能照抄这一不稳定性，而必须把它转写成受控治理协议。

## 5. 最强可保留贡献

### 5.1 解释力与定向增益必须分开

本书区分：

```text
predictive / procedural adequacy
!=
orientational gain
```

一个模型可能持续预测、分类和支持操作，却不再让主体知道该如何站立、行动或重组问题。

SRT 可用这一点审计：新术语是否真的增加可检验差异、干预差异或选择方向，还是只让旧框架继续运转。

### 5.2 共享约束可以在无交流时产生趋同

建筑、制度、实验装置和行为场景中，多个系统可能因为相似边界和成本而独立收敛。

安全结论是：

```text
observed convergence
!= sufficient evidence of communication, shared intention or common inner content
```

但作者经常从“交流并非总是必要”滑向“交流只是后续精炼”。后者不能普遍成立。

### 5.3 开放性不是纯收益

本书对开放性的最好修正是：减少过滤可能增加可见性，同时消耗缓冲、延迟、恢复间隔和信号区分能力。

这支持 SRT 的受限结论：

```text
healthy openness
= permeability + gating + delay + modulation + repair

not:
openness = maximum exposure
```

### 5.4 生命作为 maintained exclusion 是有价值但不充分的桥

书中把生命描述为持续维持选择性边界、排除失控交换并更新限制的过程。

这一描述可与 SRT 的边界、持续性、修复和可再选择性形成 P3 桥，但不能推出：

- 生命只是一种排除；
- 生物与非生物只有程度差异；
- 持续性自动产生价值、主体或 stake。

### 5.5 残余不得因幸存而被神圣化

本书最稳健的自我限制是：

```text
what survives one subtraction cycle
= current residue
not ultimate ground
```

这对 SRT 的 primitive admission 很重要。即使 selection 暂时无法被删除，也只能先标为 unresolved primitive，而不能据此声称已经证明“选择是宇宙最终本体”。

## 6. 减法标准为何必须被 SRT 重写

原始标准：

```text
若删除 X 后现象仍持续，X 不是必要的。
```

至少缺少以下条件。

### 6.1 目标相对性

对预测不必要的成分，可能对解释、干预、主体经验或规范归责必要。

### 6.2 时间窗

短期没有变化，不能证明长期、累积或延迟效应不存在。

### 6.3 测量盲区

观测指标不敏感时，真实损失可能被漏掉。

### 6.4 冗余与代偿

删除一个成分后，其他成分可能接管其功能。此时被删除的是实现，不一定是功能角色。

### 6.5 重拟合预算

若允许删掉变量后任意重写模型，任何成分都可能看起来可删除。

### 6.6 多变量交互

单项删除可能无损，但联合删除会造成崩溃；也可能单项看似必要，实际可由替代组合承担。

### 6.7 伦理与安全非对称

安全护栏、权利保护或罕见故障机制不能因日常输出暂时不变而直接移除。

### 6.8 现象定义可能已保护理论

若“现象仍持续”只按理论原有指标判断，删除实验会循环确认原框架。

## 7. 自然哲学部分的隔离裁决

以下内容不进入 SRT 科学、物理、神经科学或生命定义：

- “压力是剩余的唯一原因”或空间介质作为普遍作用条件；
- 运动主要由局部 minus-pressure 或介质进入解释；
- “没有遇到原子”被用来削弱现代原子理论；
- 氧气在水中不再存在、呼吸主要是排出 remainder、氮气框架等表述；
- 心脏由外部压力压缩而动作、肌肉不产生运动等机制；
- 火不产生热、燃烧主要是移除保护层等自然科学重述；
- 第六感、梦、远距报告或 clairvoyance 的减法机制；
- 行星、彗星和宇宙形成的介质/压力模型。

理由：

1. 这些断言没有达到现代自然科学证据标准；
2. 许多表述与成熟实验和理论存在直接冲突或严重概念错位；
3. 作者的“这不是现代化学替代”限定，不能消除正文事实语气造成的机制主张；
4. 历史概念能够提出被现代框架遮蔽的问题，不代表历史机制因此恢复真实性。

## 9. 对 SRT 最直接的压力测试

### 9.1 Selection deletion test

删除“selection”术语，只保留：

- 非对称约束；
- 可达集变化；
- 历史写入；
- 状态依赖成本；
- 后果回流。

若 SRT 的独特预测和解释没有下降，就必须说明 selection 是否只是这些结构的总称。

### 9.2 L0/L1/L2 joint-removal test

不能只逐层删除。需要检查：

- L2 是否只是历史依赖的别名；
- L1 是否只是常规动力学；
- L0 是否只承担不可检验的剩余空间；
- 三层联合是否提供单层或双层模型无法提供的反事实差异。

### 9.3 Symbol deletion test

对 `d`、`Psi_f`、`T_dir`、`G_hat_theta` 分别检查：

- 删除后哪些方程、实验预测或失败分类消失；
- 是否可由现有变量重参数化；
- 是否只是测量代理或叙事标签；
- 是否在不同尺度保持同一角色。

### 9.4 Phenomenology preservation test

不能只保留行为和系统持续性。删除主体报告、第一人称差异或痛苦结构后，若模型仍被判“无损”，说明目标函数已经排除了需要解释的现象。

## 11. Surviving claims

1. 理论成分的必要性应接受目标明确的删除测试，而不能由术语熟悉度、传统或解释优雅自动获得。
2. 删除后的持续不证明被删除项为假，也不证明残余真实、终极或跨域必要。
3. 解释活动、预测能力和主体定向增益是不同评价维度。
4. 共享约束能够解释部分无交流趋同，但不能普遍取代通信、意图或主体机制。
5. 开放性若缺少过滤、延迟、调节和修复，会从可接近性转化为负荷与边界崩溃。
6. SRT 应特别审计 selection、L0/L1/L2、`d`、`Psi_f`、`T_dir` 是否各自承担不可替代工作。
7. 本书自身展示了减法原则的风险：一个有价值的反膨胀方法，可以在缺少经验守门时扩张成新的总体自然哲学。

## 12. 后续用途

- 每次新增 primitive、symbol、layer 或 bridge 前运行一次轻量 subtractive audit。
- 每次准备将 P3/P4 提升为 P2/P1 时运行完整 audit。
- 对当前 SRT 最优先审计：selection primitive、`Psi_f` 与 Fisher 的关系、`d` 与 stake 的区分、`T_dir` 的不可替代角色、L0/L1/L2 联合必要性。
- 本书不再需要等待全文重评；未来只在正式修订版、同行评议或外部科学论证出现时重新审查其被隔离的实质主张。
