# SourceCard: Chris Sawyer — *Subtraction*

## 1. 一句话结论

该书提出一种减法式哲学方法：不以增加隐藏实体、媒介和形而上学原则来解释现象，而是持续移除假设，观察解释力何时真正下降，以此识别不可删除的结构条件；对 SRT 的价值主要是审计最小核心，而不是为“选择先于存在”提供外部证明。

## 2. 访问与精读状态

- 已核验：作者、题名、出版地/出版社、年份和书籍描述。
- 未获得：目录、章节正文、论证案例、方法步骤、反例和结论。
- 这是一本文献描述级卡，不能称为全书精读。
- 当前仅可把 “disciplined removal” 作为方法候选，不能断言作者如何处理每个领域。

## 3. 摘要明示的研究纲领

1. 评价解释框架时，询问哪些部分可以被移除而不损失解释力。
2. 方法优先消除不必要的实体、中介结构和形而上学原则。
3. 持续减法直到只剩不可缺少的结构条件。
4. 书中涉及沟通、认知、知觉、神秘实践、生命、身份和社会协调。
5. 许多通常归因于隐藏实体或特权解释域的现象，可以通过 shared constraints、environmental coupling 与 structural organization 来理解。
6. 方法资源来自现象学、心灵哲学、科学哲学、系统理论和建筑。
7. 核心目标是通过纪律化移除识别 explanatory necessity，而非理论累积。

## 4. “减法”不能与三个概念混淆

### 4.1 奥卡姆剃刀

奥卡姆原则通常偏好较少实体；减法方法更强调实际测试：移除某项后解释力是否下降。

### 4.2 还原主义

减去隐藏实体不等于把一切还原为微观物理。作者摘要反而保留约束、耦合与组织这些关系结构。

### 4.3 否定神学或空无主义

“通过移除发现必要条件”不等于剩下虚无；剩下的可能是不可替代的结构关系。

## 5. 对 SRT 的核心价值

### 5.1 P0 最小化测试

逐项做删除试验：

| 候选成分 | 删除后要检查什么 |
|---|---|
| 预先给定主体 | 选择是否仍可被定义，还是只剩状态变化？ |
| 意识 | bare selectability 是否仍成立？ |
| 信息 | 差异与可区分性是否还能表述？ |
| 价值 | 非中立方向是否只是物理偏置？ |
| 摩擦 | manifestation 是否仍有有限约束与代价？ |
| 历史 | 稳定对象与不可逆性是否还能成立？ |
| 对象 | selection 是否必须先有可选对象？ |
| 时间 | 变化、承诺和后果回流是否仍有意义？ |

该方法可以暴露 SRT 中哪些成分是 primitive、constitutive consequence、domain bridge、metaphor 或 explanatory convenience。

### 5.2 对 origin of selectability 的帮助与局限

减法可把问题压缩为：

> 在去除主体、目的、意识和既定对象后，哪一最低结构仍能使差异不只是发生，而是限制并改变后续可达差异？

它能澄清问题，但不会自动给出起源机制。若最后仍把 selection 作为不可删除原语，需承认这是 primitive admission，而非 derivation。

### 5.3 防止 SRT 变量膨胀

每引入新符号前问：

1. 删除它是否损失可区分预测？
2. 是否已有变量能够承担其工作？
3. 它是定义、测量代理还是叙事标签？
4. 是否只在一个领域有效？
5. 是否产生新的失败条件？

## 6. 可建立的 SRT Subtractive Audit

### Step 1: Target

明确要解释的现象，例如对象持续性、真实选择、stake、主体方向可读性或病理性闭包。

### Step 2: Candidate inventory

列出当前解释使用的实体、关系、参数和层。

### Step 3: One-at-a-time removal

逐项移除并检查解释覆盖、预测差异、反事实、可操作化与术语冗余。

### Step 4: Joint removal

防止单项似乎必要但实际由多个可替代成分共同承担。

### Step 5: Residue classification

将剩余项标为 logical necessity、model-relative necessity、empirical necessity、current explanatory indispensability 或 unresolved primitive。

## 7. 与 SRT 的潜在张力

1. **SRT 自身可能被减掉。** 若过程哲学、动态系统、active inference 或信息几何在不使用 SRT 术语时解释力不降，SRT 可能只是重新命名。
2. **跨域统一可能依赖过多中介。** L0/L1/L2、`Ĝ_θ`、`Ψ_f`、`d`、`T_dir` 必须各自展示不可替代工作。
3. **“选择”可能不是最小残余。** 更低层残余可能只是非对称约束、历史依赖或状态空间截断；SRT 需解释为何称其为 selection。
4. **减法可能丢失现象学。** 只保留结构组织可能不足以解释第一人称显现。
5. **不可删除性依赖解释目标。** 对工程预测不必要的成分，可能对主体性或规范解释必要。

## 8. SRT 映射表

| 减法概念 | SRT 应用 | 禁止越级 |
|---|---|---|
| remove without explanatory loss | 变量/层级冗余审计 | 被移除即本体不存在 |
| indispensable structure | 当前目标下最小承重条件 | 永恒、跨域的绝对原语 |
| shared constraints | 多系统共同边界结构 | 自动等于 L2 |
| environmental coupling | bearer 与后果回流接口 | 耦合自动产生 stake |
| structural organization | 对象持续和重组接口 | 组织即意识/主体 |
| anti-accumulation | 防止理论膨胀 | 拒绝所有新机制和经验变量 |

## 11. Surviving claims

1. 理论必要性应通过受控移除测试，而非通过术语累积宣告。
2. SRT 的每个核心变量都应展示删除后损失的解释或预测。
3. 结构约束、环境耦合和组织可能替代部分实体化解释。
4. 减法方法能压缩 origin of selectability 的问题，但不能自动解决它。
5. 该书目前是方法候选，不是外部证据。
