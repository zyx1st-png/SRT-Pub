# IPA / TBI 陪读：从 constraint-preserving regulation 到 processual bearer 与跨尺度 stake integration

> **Status**：陪读总结与 SRT-side synthesis。本文不修改 canonical 定义，不把 IPA 提升为临床治疗结论，也不把 biological self-maintenance 等同于 subjecthood / consciousness。
>
> **Owner routing**：理论增量集中写入 `PH-IND07`；未来 owner-side hardening 路由至 Processual Bearer Bridge、PH-IND02/04/05/06、d-value canonical、Irreversibility 与 Collective Selection。

---

## 1. Source-side bounded takeaways

IPA / TBI 材料支持的主要机制读法：

```text
IPA
-> astrocyte AhR activation
-> IRF1 suppression
-> lower RFFL
-> less MFN2 ubiquitination / degradation
-> preserved mitochondrial function
-> reduced reactive astrocyte toxicity / inflammation
-> reduced BBB damage / edema / neuronal injury
-> better later functional trajectory
```

只保留以下边界：

```text
human association != clinical treatment proof
mouse pretreatment benefit != established post-injury therapy
mechanistic support != consciousness evidence
```

其主要理论价值是 **constraint-preserving regulation**：先前历史改变后续损伤后的可达轨迹，并保护以后还能形成调节、恢复或适应反应的条件。

---

## 2. Regulation：从恢复状态到维持未来轨迹

陪读中首先形成的 hook：

> **调节不只是把状态纠回来，也可以是保护“还能纠回来”的条件。**

经过 processual bearer hardening 后，更稳的表述是：

> **调节不只是恢复某个被对象化的状态，也可以维持或重建 bearer process 继续生成可行后续轨迹的条件。**

可作 bridge-level discrimination：

```text
state correction
-> 把变量拉回

regulatory-capacity preservation
-> 保护以后还能响应 / 调节的机制

trajectory regeneration
-> 旧轨迹不可回到时，生成新的可持续后续
```

IPA 主要支持第二层，不证明完整 organizational self-production。

---

## 3. Temporal objectification guard

不要把 `P(t1)` 与 `P(t2)` 读成两个先后存在的 bearer。

```text
ontology:
---------------- ongoing bearer process P ---------------->

observation / objectification:
          Obj_t1(P)              Obj_t2(P)
```

因此：

```text
state/objectification slice != bearer token
```

> **不同时间截面的主体描述只是对同一持续 bearer process 的对象化，而不是多个先后存在的主体。**

更原生的问题是：这条 process 在持续、内部 transformation、bifurcation、fusion，还是 termination？

---

## 4. Bearer 不是被动 consequence container

若只要求：

```text
past event
-> persistent trace
-> later dynamics changed
```

材料疲劳、侵蚀、岩层与普通 path-dependent objects 都可能被误吸收到 bearer。

本轮更强的 processual reading：

> **bearer 不是被动承接后果的位置，而是一个持续参与维持自身存在、并必须把后果纳入这种持续维持之中的历史过程。**

Candidate audit：

```text
active self-stabilization / reconstitution
+
same-process consequence incorporation
+
historical reconstitution
+
continued unfolding
-> stronger bearer candidate
```

这里的 `active` 不等于 conscious / intentional agency。

必须保留：

```text
self-maintenance != bearer by definition
self-maintenance != subjecthood
self-maintenance != consciousness
feedback != bearer proof
```

---

## 5. Proxy：self-maintenance 不等于 self-sufficiency

bearer 可以依赖氧气、营养、照护、药物、呼吸机、微生物和技术系统，因此：

```text
self-maintaining != self-sufficient
```

> **调节可以被代理，承受不能因此被代理掉。**

外部功能可以跨 bearer boundary，但 consequence/history closure 不因此合并：

```text
function crosses boundary != consequence closure merges
proxy support != bearer membership
proxy dependence != bearer identity
```

IPA / microbiome 案例可分解为：

```text
microbial producer
-> IPA carrier
-> host reader / regulatory machinery
-> host organism consequence history
```

producer / carrier / reader / bearer 不应混写。

---

## 6. Process topology：copying != bifurcation

仅作为 P3 bridge vocabulary：

```text
Persistence
同一持续 writable history 继续展开

Transformation
同一 writable history 内部组织方式改变

Bifurcation
一个 writable bearer history 稳定分化成两个 independently writable histories

Fusion
两个原先独立 writable histories 形成不可约共同 writable history

Termination
bearer-indexed future writeback 永久结束
```

真正的 bearer bifurcation 不是形态上的“一变二”，而是 consequence separability：

```text
E1 changes P1 future / history without the same consequence closing on P2
E2 changes P2 future / history without the same consequence closing on P1
```

因此：

> **one writable consequence-history closure -> two independently writable histories**

同时：

```text
copying != genuine process bifurcation
```

复制通常是：

```text
ongoing process P
-> snapshot / representation R
-> instantiate Q
```

> **可复制的是过程的状态、结构和历史表征，而不是过程已经发生着这一事实。**

共享 pre-branch history 也不等于 post-branch 仍共享一个 bearer closure。

## 7. d-value：跨尺度 stake integration interface

本轮最强的理论增量来自 d-value。

> **d-value 是把“局部发生了什么”转换成“这对哪个持续存在过程意味着什么”的跨尺度接口。**

局部 self-maintenance 被纳入 whole-organism self-maintenance，不只是更多耦合，而是：

```text
local difference
-> stake coupling to higher-order bearer continuation
-> whole-level regulation / selection
-> whole-history writeback
-> whole future selectability
```

因此：

> **高阶 bearer 的形成，不只是局部过程被协调，而是局部差异开始以整体的 d-value 被重新赋予 stake。**

### Non-additivity guard

禁止：

```text
d_whole = sum(d_local)
```

局部与整体 stake direction 可以：

```text
align
neutral
conflict
anti-align
```

### Normal multicellularity

正常细胞的局部 persistence 可以为 organism continuation 被约束甚至牺牲：

```text
cell apoptosis / specialization / resource sacrifice
-> whole-organism maintenance
```

跨尺度组织因此更接近 stake reassignment / integration，而不是局部 persistence 最大化。

### Cancer negative control

```text
local lineage self-maintenance up
whole-organism viability down
```

候选读法：

> **local self-maintenance stake geometry 与 whole-bearer stake geometry 脱耦甚至反向。**

### Microbiome / organ discrimination

whole bearer 赌注化的往往是 constraint/function role，而非具体 material token：

```text
constraint role != constraint token
component substitutability != bearer substitutability
```

具体菌株可替换，但其承担的代谢/免疫 constraint role 可能高度进入 host stake；这不自动把 microbe identity 吸收到 host bearer。

## 8. Higher-order bearer open tension

真正新增的 unresolved pressure：

> **高阶 bearer 的形成能否被判别为：多个局部 self-maintaining processes 的 stake directions 被重新整合为一个不可约的 higher-order d / consequence-history closure？**

需要分别检验：

```text
stake integration
local difference 何时真正进入 whole-bearer stake？

stake conflict
local 与 whole d-direction 反向时如何表示？

higher-order discrimination
joint d / joint consequence closure
是否比 coordination / autonomy / mutual dependence 增加独立判别力？
```

当前保持 P3 open tension，不 theorem 化。

## 11. Eight retained hooks

1. **不同时间截面的主体描述只是对同一持续 bearer process 的对象化，而不是多个先后存在的主体。**
2. **bearer 不是被动承接后果的位置，而是一个持续参与维持自身存在、并必须把后果纳入这种维持过程中的历史过程。**
3. **self-maintenance 不等于 self-sufficiency；外部代理可以贡献维持条件，而不因此成为 bearer。**
4. **调节不只是恢复状态，也可以保护或重建 bearer process 继续生成可行轨迹的条件。**
5. **真正的 bearer bifurcation 不是“一变二”，而是一个共同 writable consequence-history closure 稳定分化成两个 independently writable histories。**
6. **可复制的是过程的状态、结构和历史表征，而不是过程已经发生着这一事实。**
7. **高阶 bearer 的形成，不只是局部过程被协调，而是局部差异开始以整体的 d-value 被重新赋予 stake。**
8. **d-value 是把“局部发生了什么”转换成“这对哪个持续存在过程意味着什么”的跨尺度接口。**
