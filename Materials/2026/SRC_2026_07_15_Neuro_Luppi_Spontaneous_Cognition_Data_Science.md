# SourceCard: Luppi et al. — *Unlocking spontaneous cognition in the age of data science*

## 1. 一句话结论

该文主张，自发脑活动不应只被当作任务研究的剩余噪声；数据驱动方法可以从未受显式任务约束的活动中提取与意识状态、生命周期、物种和临床状态相关的信息，从而形成任务范式与自然情境范式之外的第三个研究窗口。

对《从存在到秩序》的最强价值是方法论而非本体论：

```text
实验观察到的认知
already depends on
实验者先规定了什么任务、报告和可见差异
```

但：

```text
spontaneous != uncaused
!= free choice
!= L0
```

## 3. 核心问题

传统认知神经科学主要依赖：

1. **任务范式**：实验者规定刺激、反应、时间和成功标准；
2. **自然情境范式**：观看电影、听故事等，约束较弱但仍由外部材料组织；
3. **自发活动研究**：不提供明确任务，观察内部活动如何自行展开。

作者认为第三类窗口可以借助数据驱动方法产生新的可解释结果，尤其适合：

- 深度改变的意识状态；
- 人类生命周期；
- 跨物种比较；
- 临床与转化研究。

## 4. 方法价值与限制

### 强项

- 把“rest”从缺少任务的消极基线改写为积极研究对象。
- 迫使研究者检查任务设计如何预先塑造可见认知。
- 指向跨尺度、跨物种和意识状态研究的共同数据分析机会。
- 有助于识别任务平均值掩盖的动态、个体性和自发结构。

### 局限

- 无显式任务不等于无环境、身体、历史或内部动力学约束。
- 从自发神经活动解码出的标签，仍可能由研究者事后定义。
- 数据驱动方法可能降低先验束缚，也可能增加事后选择和可解释性风险。
- spontaneous brain activity 与 spontaneous cognition 不是自动同义；神经动态不必对应可报告思维。
- 研究纲领本身不证明意识、自由、主体或生成的本体论。

## 5. 对《从存在到秩序》的具体价值

### 5.1 Q10/Q11：背景秩序与预裁剪

本材料可作为方法论类比：任务范式不仅测量认知，也提前规定什么差异会成为对象、什么响应算成功、什么时间尺度可见。

安全表达方向：

> 当实验者规定问题、按钮和时间窗口时，所观察到的心智已经被问题先切过一刀。

这不是对任务实验的否定，而是提醒：任务研究看到的是认知在特定地形上的运动。

### 5.2 Q17《意识》

可放入专业注，提醒：

- 意识不只存在于报告、判断和受控刺激任务中；
- report-based evidence 不能覆盖所有意识流；
- 自发活动的神经可解码性也不能直接证明体验内容。

### 5.3 Q28《回到生成》

最适合成为理论与实验自反的表达资源：

> 研究工具不仅记录生成，也会先替生成划定什么可以出现、什么可以被看见。

该句仅作候选表达。Q28 应把它用于反思对象化和完成态，而不是展开自发认知学科综述。

## 6. 对 SRT 的新增压力与接口

### 新增接口

- 建立 task-bound / naturalistic / spontaneous 三类证据地形。
- 要求实验设计披露外部约束如何预裁剪候选状态和报告通道。
- 提供研究 `T_dir`、主体连续性或 L2 背景动力时的无显式任务比较窗口。

### 反向修正

- 不得把任务外活动直接写成“更接近真实 L0”。
- 自发活动不自动具有 stake、agency 或 choice-event 地位。
- 若 SRT 的实验只在强任务范式中成立，需要说明其结果是否由任务 scaffold 产生。

### 加固内容

- Q10/Q11 已强调背景化和预裁剪，本材料把这一结构带入实验方法。
- Q28 已把理论本身纳入牢笼风险；本材料提供科学实践案例。

### SRT 可能的反哺

SRT 可把三个范式理解为不同 constraint profiles，而不是“受限／自由”的二分：

```text
task-bound: explicit external gates
naturalistic: structured external flow
spontaneous: reduced explicit task gate, persistent embodied/history constraints
```

可比较同一指标在三种地形中是否保持，并检查实验结论的 scaffold dependence。

### 残余压力

若自发数据的可解释结构完全依赖事后标签和模型选择，所谓“减少预裁剪”可能只是把预裁剪从任务设计移动到分析管线。SRT 不能把数据驱动方法浪漫化为未经选择的现实入口。

## 7. 过度映射守门

```text
spontaneous activity != spontaneous cognition
spontaneous cognition != free choice
no explicit task != no constraint
resting state != L0
decodable state != conscious content
internal dynamics != T_dir
data-driven != theory-free
experimenter reduction != observer removal
```
