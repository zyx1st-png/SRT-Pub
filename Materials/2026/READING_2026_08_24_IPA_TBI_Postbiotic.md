## 1. Layer A — source-backed evidence

### 1.1 Primary-source mechanism

论文报告的主要机制链为：

```text
gut-derived indole-3-propionic acid (IPA)
-> astrocytic AhR activation
-> IRF1 suppression
-> lower RFFL induction
-> reduced RFFL-dependent MFN2 ubiquitination / degradation
-> preserved mitochondrial dynamics / function
-> reduced reactive-astrocyte neurotoxic / chemokine output
-> reduced peripheral immune-cell infiltration
-> reduced edema / tissue injury
-> better neurological trajectory
```

作者还报告 astrocyte-specific `Rffl` deletion 可重现重要的神经保护表型，因此 RFFL/MFN2 不是只凭相关性拼出的中间链。

### 1.2 Human evidence is associative

人类部分支持的是：较低 serum IPA 与更严重脑水肿和更差神经结局相关。

安全写法：

```text
human serum IPA association
!= causal clinical efficacy
```

不能从人类 cohort 直接推出 IPA 治疗有效。

### 1.3 Mouse intervention is strongest as pretreatment / protective-state evidence

小鼠实验中的 IPA 干预提供了损伤后表型改善和机制链证据，但本轮理论使用应优先把它读作**预先形成的生物状态如何改变后来同一扰动后的损伤轨迹**。

因此：

```text
mouse protective / pretreatment result
!= established post-injury human therapy
```

### 1.4 Source-side bounded takeaway

这篇论文最适合作为：

> **先前生物条件改变后续损伤轨迹，并通过维持较慢的线粒体/调节 constraint，降低快速炎症与组织损伤级联。**

它不证明 SRT、bearer、subjecthood、d-value 或 consciousness。

## 2. Regulation：从 state correction 到 regulatory-capacity preservation

本轮最早形成并已保留的 reading hook：

> **调节不只是把状态纠回来，也可以是保护“还能纠回来”的条件。**

更严格的 processual 解释：

```text
state correction
!=
regulatory-capacity preservation
!=
trajectory regeneration
```

- **state correction**：让某个偏离变量回到目标区间；
- **regulatory-capacity preservation**：保护以后还能响应、补偿、恢复的机制条件；
- **trajectory regeneration**：旧路径不可恢复后形成新的可持续后续。

IPA / MFN2 案例主要支持第二层的 biological realization：MFN2/mitochondrial organization 可被读成相对较慢、对更快炎症与损伤动力学施加约束的机制条件。

Guard：

```text
MFN2 != stake
MFN2 != d-value
MFN2 != Selection
constraint-preserving regulation != complete organizational self-production
```

---

## 3. Production / proxy / bearer decomposition

这篇材料提供一个很好的边界拆分：

```text
microbial producer
-> IPA signal / material carrier
-> astrocytic host-side reader
-> host regulatory realization
-> organism-level measured consequence
```

因此必须区分：

```text
producer
!= carrier
!= reader
!= consequence bearer
```

安全的 SRT bridge reading：

> **The source of a persistence-enabling constraint need not coincide with the bearer of its failure.**

以及：

```text
constraint dependence != bearer identity
proxy support != bearer membership
functional extension != bearer extension
```

微生物或其他外部支持可以深度参与宿主 regulation，而不因此自动进入宿主 bearer identity。

---

## 4. Active maintenance：本轮只保留为 owner guard

后续讨论曾把 bearer 进一步压成：

> bearer 不是被动承接后果的位置，而是持续参与维持自身存在、并必须把后果纳入这种维持过程中的历史过程。

owner subtraction 后，这不能作为本轮新理论：Processual Bearer Bridge 已经打开 production-side self-production / regeneration 与 consequence non-outsourcing 的关系，而且明确没有在上一轮 claim Layer C。

本轮只保留一个重要 anti-misreading：

```text
self-maintenance != self-sufficiency
```

所以：

> **调节可以被代理，承受不能因此被代理掉。**

氧气、营养、照护、药物、生命支持、微生物代谢物或技术代理都可以贡献 maintenance condition；这不自动转移 bearer identity。

## 5. Temporal objectification — dialogue-derived P3 hardening

本轮讨论中一个真正存活的理论 hardening 与 IPA 论文并非直接经验关系，而是由 bearer continuity 问题触发。

错误对象化：

```text
t1: B
t2: C
-> ask whether B and C are numerically identical subjects
```

processual guard：

```text
one ongoing process 𝒫
-> Obj_t1(𝒫)
-> Obj_t2(𝒫)
```

因此：

> **不同时间截面的对象化描述，不应被反向本体化为多个先后存在的 bearer。**

PH-MEM01 已经拥有 objectification 一般问题；本轮残余只是从“什么被对象化”延伸到“时间切片如何被本体解释”。

该点不解决 numerical identity。

## 6. Copying vs bifurcation — dialogue-derived P3 hardening

另一个存活增量来自复制 / 分叉压力测试。

复制的一般结构：

```text
ongoing process 𝒫
-> objectified snapshot / representation R
-> R initializes process 𝒬
```

这可以复制：

- state；
- memory；
- parameters；
- historical representation；
- self-description。

但不能仅凭这些推出：

```text
copying = bifurcation of one ongoing bearer process
```

PH-IND06 已经用 copy/checkpoint substitution 测 non-outsourcing；本轮把同一 negative control 用到另一个问题：

> **复制对象化描述，不等于证明一个 ongoing consequence-history closure 本身发生了分叉。**

真正的 bifurcation candidate 仍应回到 PH-IND05 的 consequence-separability：分叉后的两个 successor process 是否形成 independently writable consequence histories。

## 8. Cancer：真正留下的 canonical reverse pressure

本轮关于癌症最初的用途是说明 local self-maintenance 与 whole-organism self-maintenance 可以反向。经过 subtraction，它真正有价值的地方不是“证明 d 不可加”，而是压力测试 canonical §6.1 的前件：

```text
d_i = D_eff(F_collective | theta_i)
```

这个表达把 local `d_i` 读作 higher-order collective landscape 的子空间截面。

正常多细胞组织中，这种 whole-first 读法很自然：局部细胞维护、凋亡、分化、复制限制等都可被整体 continuation 组织。

癌症则提出一个不同形状：

```text
local lineage maintenance / replication pressure ↑
while
whole-organism viability / future selectability ↓
```

因此真正的 P3 问题是：

> **什么时候 local stake landscape 仍然可以充分地表示为 higher-order landscape 的 restriction / slice；什么时候它已经形成一个部分自治、与整体 stake directions 竞争甚至反向的 landscape？**

这是对 §6.1 **antecedent adequacy / scope** 的 reverse pressure，不是 falsification，也不修改 canonical d。
