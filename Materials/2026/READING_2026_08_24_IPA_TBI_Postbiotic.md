# 陪读笔记：IPA / TBI / astrocytic mitochondrial regulation

> **性质**：陪读过程记录，不是 SRT definition authority；理论写回需另做 owner-side novelty subtraction。

## 1. 当前主线

这篇材料的 SRT 价值不主要在“肠脑轴”本身，而在一个清晰的跨层级机制链：

```text
microbial metabolite IPA
-> astrocytic AhR
-> IRF1 / RFFL
-> MFN2 preservation
-> mitochondrial organization / function
-> inflammatory trajectory
-> BBB / neuronal survival
-> later cognitive / behavioural outcome
```

当前可用作 bounded biological realization 的方向包括：历史预置的 constraint 如何改变未来扰动后的响应轨迹、跨时间尺度 regulation、以及 persistence-enabling constraint 的生产边界与 consequence bearer 边界可能不重合。

## 2. 用户标记的高优先级 hook

> **调节不只是把状态纠回来，也可以是保护“还能纠回来”的条件。**

### 当前解释

这句话指向一个比普通 state correction 更强但仍需保持边界的调节读法：

```text
state correction
!= preservation of regulatory capacity
```

MFN2 / mitochondrial organization 在该实验中可被理解为较慢的、对更快炎症动力学施加约束的局部机制条件。IPA 的作用因此不只是让某个瞬时变量回到基线，而可能是在保护一组使后续恢复轨迹仍可达的条件。

### Guard

- 不把 MFN2 本身等同于 stake、d-value 或 Selection。
- 不把该实验直接读成 HEF-3/HEF-4 的测量；目前更安全的是 HEF-compatible biological realization。
- 不把“恢复能力”自动升格为所有生命、Stable ISP 或 subjecthood 的定义条件。

## 3. 当前待继续问题
