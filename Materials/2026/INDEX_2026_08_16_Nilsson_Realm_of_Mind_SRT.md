## Big Crunch pressure

The strongest question is:

```text
if every witness, record, persistent trace and downstream causal remnant disappears,
does "E occurred" become "E never occurred"?
```

Current SRT P0-02/P0-03 strongly pressures a **NO** answer, but this should not be expressed by inventing a permanent world archive.

Recommended distinction:

```text
historical facticity
!= historical efficacy
```

and:

```text
Occurrence asks what became actual.
L2 asks what prior selection continues to do.
```

## Duplicate pressure

The source challenges spatial counting, but its stronger conclusion that physically separated identical systems yield one numerically identical experience-token is not established.

SRT-side P3 diagnostic candidate:

```text
counterfactual consequence separability
```

Stronger bearer-branching evidence:

```text
independent consequence closure
+ independent history writeback
+ independent future-selectability change
+ maintained closure continuity
```

Guard:

```text
two bearers !-> two experiencers proven
```

## Restoration pressure

SRT retains:

```text
same configuration
!= same trajectory / history
```

A restoration is a new occurrence, not cancellation of the path that produced it.
