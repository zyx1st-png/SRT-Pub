# SourceCard: Valerie van Mulukom — *The experiential self state as affective salience*

## 1. 一句话结论

该文提出“双重自我状态”框架：反思性／叙事性自我与体验性自我不是两个固定实体，而是同一意识系统沿加工连续体形成的动态占优构型；体验性自我被描述为由内感受、外感受和情感显著性组织的非命题式“在此作为主体”的状态。

对《从存在到秩序》的核心增量是：

```text
功能分层
!=
两个静态自我模块
```

它可迫使 Q16—Q17 把主体和意识写成可转换、可混合、可退居背景的动态姿态，而不是按固定楼层堆叠。

## 2. 来源状态与证据边界

- 正式发表于 *Neuroscience of Consciousness*，开放获取，DOI 已核验。
- 论文是理论整合框架，没有报告新的实验数据。
- 本卡核验了官方摘要、引言、核心框架、神经网络说明、冥想／自我超越应用和讨论。
- 论文把 default mode network、salience network、内感受和多类神经调质机制用于框架锚定；这些对应关系来自既有文献综合，不是本文独立建立的因果结论。

## 3. 论文的核心区分

### 3.1 反思性自我状态

主要包括：

- 自传记忆与叙事；
- 自我评价、社会自我与时间旅行；
- 命题性、指称性和高层自我相关加工；
- 较强的高层先验和 default mode network 参与。

### 3.2 体验性自我状态

主要包括：

- 当下的身体和情感显著性；
- 非命题式、透视性的“我在这里”；
- 内感受与外感受信号整合；
- 不以叙事自我反思为中心的持续 meta-awareness；
- salience network，尤其 anterior insula 与 anterior cingulate 的候选作用。

### 3.3 动态而非实体化

作者强调两者是相对占优状态，而不是两个轮流控制身体的独立自我。冥想、吸收、敬畏和某些自我超越体验，被用作状态转换的经验窗口。

## 4. 证据与理论强度

### 强项

- 明确反对把 self-as-object 与 self-as-subject 实体化为两个自我。
- 将叙事、自我相关加工、身体显著性和 meta-awareness 放入可比较的状态架构。
- 提供预测加工语言，说明高层自我先验权重降低时，身体和情感信号如何获得更大影响。
- 把冥想和自我超越经验转化为可检验状态，而非异常或神秘例外。

### 局限

- 框架综合性强，但独立区分度和可证伪边界仍需进一步实验。
- salience network、DMN 和神经调质的定位可能存在多对多映射，不能当作单一机制证明。
- “体验性自我”同时承担身体意识、情感显著性和非反思 meta-awareness，概念负担较重。
- 自我超越报告受文化、训练、语言与事后解释影响。

## 5. 对《从存在到秩序》的具体价值

### 5.1 Q16《主体沉积》

Q16 当前把主体写成选择历史、价值锚定、痕迹调用和后果回流沉积出的承重位置。该文可提供一个重要修正：沉积出的主体不是每时每刻以同样方式显现。

适合进入专业注或局部正文的命题：

> 主体沉积出连续性，不意味着主体只有一种稳定的自我姿态。叙事调用可以占据前景，身体与情感的“在此”也可以占据前景；两者都依赖同一段历史，却以不同方式读取和组织它。

### 5.2 Q17《意识》

Q17 当前区分感受性与反身意识。该文最适合作为**反实体化守门**：

```text
感受层 / 反身层的生成与功能区分
!=
两个解剖隔离、轮流值班的模块
```

建议进入方式：

| 位置 | 方式 | 功能 |
|---|---|---|
| Q17 §3 反身意识之后 | 正文短段 | 强调层次是工作分化和依赖次序，不是固定实体 |
| Q16 章末专业注 | 文献对手 | 主体连续性与自我状态变换并存 |
| Q28 理论自反段 | 一句回指 | 分类会把连续状态切成固定对象 |
| 后台材料 | 保留冥想与自我超越细节 | 避免正文扩成 altered-states 综述 |

### 5.3 可用表达资源

> 把意识分层，是为了说明它承担了不同工作，不是说脑中住着两个轮流值班的自我。叙事性的“我”和身体里正在发生的“我”，更可能是同一历史在不同条件下形成的两种占优姿态。

仅作为后续写作资源，不是当前正文补丁。

## 6. 对 SRT 的新增压力

### 新增接口

- 主体连续性与自我状态可变性可以同时成立。
- 反身性降低不自动等于意识或主体性降低。
- 非命题 meta-awareness 提醒 SRT：`T_dir`、反身报告和语言可读性不能被默认为同一层。

### 反向修正

- Q17 的“两层”若被读成静态模块，需要明确动态状态解释。
- `d-value` 不能被等同于 affective salience；salience 只说明某些信号获得优先处理，不说明不可替代赌注和后果归属。
- `T_dir` 不能被等同于 meta-awareness 或冥想中的非反思觉察。

### 加固内容

- Q16 的主体沉积可以解释为什么不同自我状态仍被归到同一持续历史。
- Q17 已区分感受与知道自己在感受，该文提供了连续、混合和相互转换的外部框架。

### SRT 可能的反哺

SRT 可把“状态转换”进一步放入历史和后果结构：不同自我状态是否改变后果被谁承担、哪些痕迹被调用、未来选择通道如何开放？

### 残余压力

若反思／体验状态及其转换能够由 salience、precision weighting、内感受和网络动力学充分解释，SRT 必须说明“主体沉积”和 bearer continuity 提供什么额外可测内容，而不能只做更宏观的叙述。
