## 0. 书目信息与总问题

Kathryn Nave, *A Drive to Survive: The Free Energy Principle and the Meaning of Life*, The MIT Press, 2025. PDF ISBN `9780262381673`。

全书的核心问题不是“FEP 是否能拟合很多生物行为”，而是：

> **FEP / predictive processing 所提供的稳定、预测、误差最小化和 Markov-blanket 语言，究竟只是对某类动力学的有用重述，还是足以解释生命为什么具有自身目的、规范、行动和持续同一性？**

Nave 的最终答案是：FEP 作为近似模型有价值，但不能承担“生命第一原理”的本体论负担。真正关键的是 biological autonomy，尤其是 constraint closure：活动依赖 constraints，而这些 constraints 又必须由它们共同使能的过程持续再生产。

SRT 在本次陪读中的主要关注点则是：

- bearer 如何个体化；
- consequence 如何回流到同一持续过程；
- 历史写入是否只改变状态，还是改变可能空间本身；
- 稳定是状态不变还是跨变化的生成连续；
- object / boundary 是否被 formal model 预先假定；
- production closure 与 consequence non-outsourcing 是否是两个独立维度。

# Introduction — Control Is Not the Goal

## 来源主线

Nave 用英国电力控制中心与 living cell 的对比开场。工程控制系统可以预测扰动、维持目标区间，但系统停止活动后，组成它的硬件并不会马上解体。细胞不同：膜、酶、蛋白等条件必须持续被修复和替换。

因此：

> **Control is the means, not the goal.**

FEP / PP 即使能解释 organism 如何控制输入，也还没有解释：为什么这些控制结果对 organism 自身有意义？为什么失败构成真正的 failure？

## SRT 对照

从一开始就要区分：

```text
successful control
!= intrinsic norm

state correction
!= consequence bearing
```

“谁承担失败”比“有没有反馈控制”更接近 SRT 的 bearer / stake 问题。

# Chapter 1 — Biodynamic Enactivism

## 来源主线

Enactivism 拒绝把 cognition 首先理解成：一个预先给定的 mind 去重建一个预先给定的 world。世界对 agent 的意义从行动、历史、身体、文化和环境关系中展开；affordance / salience 从一开始就是 agent-relative。

Bioenactivism 进一步试图从生命的 precarious self-production 中找到 normativity：糖对于细菌不是抽象物理对象，而是与代谢组织相联系的 opportunity。

一个关键难题是：如果适应性只依赖已经发生过的成功/失败，organism 怎样在不先死一次的情况下把从未见过的 signal 当成 danger？这把 anticipatory / open-ended learning 推到前台。

## 用户标记

> 认知所抽取的结构可以从一开始就是相对于行动者的位置、能力和目标组织起来的，而不必先有一个完全 agent-neutral 的世界模型。

> 个体怎样在不先死一次的情况下知道从未见过的新信号意味着危险？

## SRT 对照

更安全的表述不是“对象的存在依赖具身”，而是：

> **所有被经验、认知、赋义的对象，只能从某种位置和具身关系中显现 / 对象化。**

anticipatory danger 也不能直接证明全局 L0 `epsilon_pg`。它最多是一个强经验显影：

> **非中立性可以先于结果实现。**

# Chapter 2 — Predictive Processing

## 来源主线

Nave 区分最小 predictive covariation 与更强的 inference / representation。一个系统状态与后续输入有规律关系，不等于系统在进行 model-rich prediction。

更关键的是：一旦说“prediction error”，就已经偷偷带入了“什么算 correct matching state”。Error 不是纯 difference。

## 用户标记

> 认知所抽取的结构可以从一开始就是相对于行动者的位置、能力和目标组织起来的，而不必先有一个完全 agent-neutral 的世界模型。

> 系统“正在最小化 prediction error”已经包含解释：某个 matching state 是系统应该趋向的状态。

## 保留 hook

```text
Difference = descriptive
Error = Difference + norm / target
Consequence = who bears what follows from the mismatch?
```

precision weighting 也不能直接等同 SRT value / stake。

# Chapter 3 — The Free Energy Framework

## 来源主线

本章区分 FEP 的“low road”（把 cognition 当 inference）与“high road”（试图从 survival / free energy 得出生命第一原则）。

Variational free energy 的 adequacy 并不等于 truth。Active inference 把 action 纳入 generative cycle：organism 不只更新 model，也改变世界，从而改变以后收到的 evidence。

但几个问题持续存在：

- fixed state space；
- first generative model 从哪里来；
- 相关性 / similarity 为什么就成了 representation；
- generative distribution 如果只是实际 dynamics 的统计描述，它凭什么自己有“错”的可能？

## 用户标记

> description ≠ mechanism ≠ function。

> 不只是 error 需要 norm。model、representation、inference、learning 全都需要 norm……不能从系统“可以被描述为什么”直接推出“系统自己正在为什么而行动”。

## 四个保留 hook

1. agent-relative generative cycle；
2. description ≠ instantiation / mechanism / function；
3. fixed-state-space limitation；
4. normative regress。

后来全书把第一条方法论逐渐扩成：

> **description ≠ redescription ≠ derivation ≠ mechanism ≠ function ≠ ontological grounding。**

# Chapter 4 — One Weird Trick to Stay Alive

## 来源主线

FEP 的 substantive life claim 依赖 steady-state / stationarity。Nave强调 ergodicity 与 biological history 的冲突：

> **An ergodic system forgets its history.**

Ashby homeostat 可以调整 parameter，但这仍不自动产生 agency / teleology。稳定、回到 attractor、调整参数这些结构在非生命系统也很普遍。

## 用户标记

> An ergodic system forgets its history。

> Ashby homeostat 的参数重构说明 structural change / learning 本身不能建立 subject-level agency；还要问 bearer、排除、后果回流与未来空间改变。

> 一个理论要解释主体性，不能靠一个所有稳定物体都有的性质；也不能靠一个最基础生命根本没有的高级机制。

## RC-A guard

本章尤其容易诱发旧式“attractor convergence ≠ SRT Selection”表述，必须避免。

正确边界：

> stability / attractor / script / gradient / automation 本身不足以建立 subjecthood、agency 或 revision standing；**同时也不能由此推出没有 Selection。**

# 中途理论讨论：生命与非生命是程度还是种类？

本次陪读中形成并由用户明确认可的一句：

> **底层性质连续，耦合强度连续；组织形式可以发生非连续相变。**

含义：

- 历史依赖、feedback、稳定、持续、物质流、重构等性质在非生命中也可有低阶实例；
- 不能把 life/nonlife 简化成一个单轴“生命程度”；
- 但一般连续成分在多尺度递归耦合后可以产生新的 organizational phase；
- life boundary 与 subject boundary 不必重合。

可用非生命例子：hysteresis / crystal growth / river erosion / vortex / flame / thermostat 等，分别具有 history、feedback、persistence 或 self-maintenance 的局部结构，但这些成分的耦合方式不同。

# Chapter 5 — Free Energy Minimization beyond the Brain

## 来源主线

Markov blanket 原本是 Bayesian network 中的统计筛分结构。FEP 文献却常把它升级成 organism/environment 的真实边界，并赋予 sensory / active / internal / external causal roles。

Nave 的关键批评不是简单“MB 不真实”，而是：要建立 graph，modeler 必须先决定 variables、grain、atomic nodes。Markov blanket 可以描述已切分 unit 之间的 conditional independence，却不能自己生成 unit。

## 四个高优先级 hook

1. **variable-first problem**：统计关系 / boundary 依赖先行变量化；
2. **statistical boundary ≠ causal / ontological boundary**；
3. **individuation precedes blanket**：`boundary as input ≠ generation of boundary`；
4. **stable boundary ≠ living identity**。

## 用户标记

> 这意味着对象化并不是在已经完成的世界对象上贴标签。它甚至参与决定：哪些连续差异被压成一个 object，哪些差异被保留为 object 之间的关系。如果用我们正在形成的 SRT 链来写，现在可以更完整：最低非中立性 → 具身位置中的差异可读性 → 差异的重要性分配 → 变量化 / 边界化 → 对象化 → L2 科学模型。

> 模型中的对象单位并不是无视角直接从世界掉出来的。

# Chapter 6 — From Markov-Blanketed Steady-State Systems to Sensorimotor Cycles

## 来源主线

一个 generic Markov blanket 不会自动产生 sensorimotor cycle。ESIA 的循环结构实际上由额外的 dynamical equations / variable partition 引入，而不是从 MB conditional independence 本身推出。

Nave进一步指出，任意 coarse-graining / aggregation 可以制造宏观表面关系；如果 model 已经把想解释的 structure 预置在 variable choice、equation 和 boundary 中，formalism 可能只是重新编码。

## 高优先级保留

- **redescription ≠ derivation**；
- coarse-graining can manufacture apparent structure；
- assumption-away problem；
- continuity does not imply arbitrary individuation。

## 用户标记的 7 条

> autonomy 不是“对一些东西关闭、对另一些东西开放”就够了，而是必须 closed to the right things。

> 你以为数学推出了结构，实际上结构可能已经在变量选择、动力学方程和边界设定中被预置进去；数学只是把它重新编码。

> 变量怎么切，不只是决定你看到什么边界；还会决定你看到什么“因果结构”。

> 所以科学对象化不是：世界先给出对象，然后我们测量对象之间关系。更准确地可能是：对象化与关系化共同发生。

> “noise”有时不是现实中缺乏结构，而是该结构不能被当前对象化框架表示。

> 具身不是简单：我的身体是这个袋子里面的东西。更深的可能是：哪些变化以不可替代的方式回流到这个持续历史过程，并改变它未来的可行动空间。

> 把一个整体稳定系统切成 organism / environment 本来就是观察者的人为切分。系统并没有自己说“这里是我，那里是环境”。只是我们发现切完以后，其中一部分似乎特别擅长抵抗另一部分的扰动，于是把前者叫 organism。

## 对象化链更新

> **最低非中立性 → 具身位置中的差异可读性 → 重要性分配 → variable / coarse-graining → object 与 relation 共同确定 → boundary / causal model → L2 scientific structure。**

Guard：这不等于说现实结构是任意 fabricated。

# Chapter 7 — Seeking Closure

## 来源主线

本章区分多种 closure。关键推进是：

```text
causal/statistical dependence
< existential dependence
```

一个 process 影响另一个 process，不等于后者的继续存在依赖前者。

Operational closure / process closure 仍可能被 washing machine、thermostat、Turing machine 等满足。真正 bioenactive 关注的是 precarious self-production：constraints / components 不持续生成就会消失。

## 四个高优先级 hook

1. **causal feedback ≠ existential dependence**；
2. **writeback ≠ constitutive writeback**；
3. `structure -> dynamics` 不够，还要问 `dynamics -> structure`；
4. **maintenance presupposes generation**。

保留句：

> **真正重要的不是反馈闭环，而是维持该反馈闭环的条件本身也被闭环中的历史活动持续生成。**

## 用户标记的 7 条

> 我的活动结果改变了我下一次还能不能继续作为这个 process 存在。

> history write-in 本身还不够；要问写入的是行为状态，还是持续承载过程自身的构成条件。

> 所以具身位不只是：“我从哪里观察。”还是：我是什么样的历史结构，决定同一差异对我成为什么差异。

> 被调节的东西的失败后果最终回到调节者自己的持续条件。

> 生命不是在变化中仍能保持自身，而是必须通过持续变化才能继续成为自身。

> 如果这种再生产历史还进一步改变后续能够生成什么结构、能够承受什么后果、能够选择哪些候选，那么它就从简单 self-production 开始向真正的 history-bearing bearer 靠近。

> 一个过程成为强 bearer 候选，可能不只是因为历史会写回它，而是因为历史性活动持续再生成“这个过程还能继续作为自己承担后果”的条件。

# Chapter 8 — A Theory of Everything, or Just of Every “Thing”?

## 来源主线

Nave转向 process ontology。一个 song / story / organism 可以持续前进而不反复回到同一 state。过程的同一性可以依赖 generative succession，而不是 snapshot similarity。

Lewin 的 `genidentity` 被用来表达：later time-slice 是 prior time-slice 的 generative product。

生物结构还有一个更强特点：material turnover 不只是允许发生，而是持续存在的条件。

## 四个高优先级 hook

1. identity may be genidentity, not snapshot invariance；
2. bearer may be history-constituted, not merely history-bearing；
3. stability despite change ≠ stability because of change；
4. fixed state space is a modeling commitment, not automatically an ontological fact。

## 用户标记的 6 条

> bearer 的同一性可能首先是历史生成关系，而不是属性相似性。

> 机器：可以换零件，但不换也能在那里。生命：不是“允许更换”，而是依赖更换。

> 生物结构的暂时稳定本身依赖持续能量与物质流。

> 稳定身份不是某个 snapshot 的恒定性质，而是跨时段的生成连续性。

> 不要把模型中固定的方程、变量和 phase space 反过来当成真实 organism 的本体定义。

> 模型为了解释而固定的东西，不一定是现实为了存在而固定的东西。

## SRT 压缩

> **真正的持续同一性，未必是“有某个东西一直没变”，而可能是“每一次变化都由前一历史状态生成，并继续承担这条历史留下的后果”。**

这强化 P1-T06 的 `recurrent historical reconstitution`，但不新增 P1 条件。

# Chapter 9 — Seeking Stability with the FEP

## 来源主线

Nave依次检查 allostasis、higher-order stability、species/ensemble stability、path/trajectory-based FEP。

allostasis 说明重要的不是 constancy，而是 context-sensitive coordination。更高阶 invariant 只是把 fixed rule 往上移动，并没有解释 invariant 的来源。

更重要的是 developmental history 会 canalize future dynamics：一些过去可能状态不只是 probability 变低，而是退出当前 organism 的 effective possibility space；新的结构 / 能力也可能在历史中出现。

Nave用 `enablement` 对照 `perturbation` / entailment：环境变化不只破坏稳定，还能打开新的 production / individuation possibilities。

## 用户标记的 6 条

> goal is not constancy, but coordinated variation。

> moving the invariant upward does not explain its origin。

> organism 的活动会 canalize 它自己的 future dynamics，并改变自己的 possibility space。

> SRT 过去说：历史写入会约束下一轮 candidate set。Nave 这里给了非常具体的生物学版本：发展本身会让过去的一些可能性永久退出，并生成新的可能性。所以这里甚至不是 history changes preference over candidates，而是 history changes which candidates exist at all。

> 历史不仅改变系统在既有可能空间中的位置，也可能改写可能空间本身。

> 真正的区别不是生命更随机，而是环境事件可以在 organism 中成为新的组织和行为可能性的 enabling condition，而不必等于 organism 的毁灭。

## 去重后的保留簇

- coordinated variation；
- higher-order regress；
- possibility-space rewriting；
- perturbation / destruction / transformation；
- viability ≠ stability；
- environmental enablement。

SRT 的治理边界：possibility-space rewriting 很适合强化 P2/P3 generative reselectability，但不是每个 Selection 或 Stable ISP 的 P1 必要条件。

# Chapter 10 — Biological Autonomy

## 来源主线

本章进入正面方案。Nave反对把 organism 的 identity 固定在 invariant organization 上，强调 historical reciprocity / open-ended individuation。

她批评 generic process closure 太宽：robot + swingball 也能形成 mutually dependent process cycle。真正的 constraint closure 要把 closure 放到“使 process 成为可能的 constraints 自己如何被生产”这一层。

Constraint 不是额外提供能量，而是限制自由度、channel thermodynamic flow，使宏观 work 成为可能。更重要的是，biological constraint 在短 timescale 上可相对 invariant，在长 timescale 上又会降解、需要再生产。

## 六个高优先级 hook

1. historical reciprocity > mere perturbation；
2. individuation before individual；
3. structure = slow process（timescale-relative）；
4. constraint enables by excluding；
5. constraint closure = no free internal background；
6. continuity of production > invariance of organization。

## 用户标记的 5 条

> machine-style 思维把环境理解成：对稳定组织的扰动。organism 要做的是：抵抗 perturbation。但 processual biology 提出的 enablement 不一样：环境不只是破坏稳定，也会打开新的未来。Nave写得很清楚：changing surroundings can become an expanding well of possibilities for novel production and individuation。

> bearer 可能不是一个先存在再经历历史的东西，而是历史性 individuation 暂时稳定出来的持续承载过程。

> 所谓结构，只是相对于当前观察时间尺度足够慢的过程。

> constraint closure 本身还只是最小组织。但只要有多个时间尺度，一个层面的扰动就可以激活另一个时间尺度的 constraint 来补偿。于是出现 regulation。

> machine：结构稳定，但活动停止也没关系。tornado / dissipative structure：活动和结构相互依赖，但关键 boundary conditions 在系统之外，自己不能维持。organism：多层 constraints 互相依赖、互相生产，并且部分 higher-level constraints 还能调节这些 closure 之间的 transformation。

## 额外保留

> **bearer 的“结构”可能不是历史的容器，而是历史在较慢时间尺度上的沉积形式。**

以及重要的新接口：

```text
Nave / constraint closure:
persistence-enabling constraints cannot all remain free external background

SRT / non-outsourcing:
relevant failure consequence cannot all be exported while candidate bearer is restored unchanged
```

二者可能互补，但不能先合成 theorem。

# Chapter 11 — Constraint Closure as the Basis of Intentionality

## 来源主线

Nave试图解释：怎样区分 norm-compatible movement 与真正 norm-guided action？

一个行为最后符合某个 goal，不代表它是因为那个 norm 才发生。Normative reason 的特点是 `binding but violable`：它可以真的适用，但 agent 仍可能失败。

constraint-closed organism 的特殊性在 Nave 看来是：它必须持续 channel energy into regenerative work，否则构成它的 constraints 会解体。因此某些行为规范具有“存在性的 must”，但 organism 可以失败并死亡。

## 六个高优先级 hook

1. norm-compatible ≠ norm-guided；
2. normativity = binding but violable；
3. objective ≠ eternal；
4. value = historical organization × environmental affordance；
5. constitutive consequence return；
6. endogenous reason-cause。

## 保留句

> **规范不是“不允许偏离”，而是“偏离会由同一持续过程承担构成性后果”。**

> **价值不是东西自带的标签，而是一个历史形成的承载结构与环境可能性之间的关系。**

## Guard

Nave 会进一步把 self-production 写成 biological ultimate norm。SRT 不能直接普遍化：

```text
biological self-production
= useful stake-grounding mechanism in biology
!= universal definition of SRT value / d
!= universal bearer criterion
```

# Chapter 12 — Wrapping Up

## 来源主线

Nave将 PP / FEP 降级为 implementation / approximation：如果 organism 已经有 biological normativity，那么 predictive control、offline simulation、counterfactual cognition 等可以帮助实现和扩展它，但不负责生成规范性的最初来源。

她也解释了为什么 stability 在生命中仍然常见：未来不确定时，保留过去已经证明 viable 的 organization 是一个低风险 heuristic，而不是生命的 ultimate purpose。

最后她提出 `nothing to lose`：即使复制一个很复杂的 predictive-control system，如果它的 failure 对构成它的 parts 没有自身 stake，把它说成 trying / failing 仍可能只是我们的投射。

## 六个高优先级 hook

1. continuity ≠ preservation of organization；
2. implementation ≠ grounding；
3. primitive normativity before cognitive complexity；
4. stability as strategy, not ontology；
5. nothing-to-lose test；
6. strong embodiment = consequence-bearing embodiment。

## 保留句

> **稳定可能不是原始 norm，而是历史上已经证明可行的组织，在不确定未来中形成的二阶保守策略。**

> **continuity is not preservation of form, but inheritance of consequence through transformation。**

SRT 可进一步追问：`nothing to lose` 的 “who loses it?” 是否能由 same-unit consequence-bearing / non-outsourcing 精确化。

# Appendix — What’s the Use of a Concrete Blanket?

## 来源主线

Nave对 Markov-blanket realism 做 steelman。即使接受 causal graph realism、probabilistic reduction 和某种 mathematical realism，仍需先回答：graph 的 units 是什么？

Markov blanket 可以给定 unit 后描述 conditional separation，却没有因此发现一个 principled carving of the world into things。

同时，variable / grain 的 perspective dependence 不推出所有 structure 任意：模型仍可能抓到真实关系。

## 五个高优先级 hook

1. metaphysical conclusions require metaphysical premises；
2. node as input ≠ generation of object；
3. perspectival scale ≠ arbitrary structure；
4. Markov separation ≠ bearer individuation；
5. formal relations cannot replace a theory of units。

## 额外保留

> **统计上能划出内外，不等于找到了承载者；bearer 边界必须进一步由历史后果的回流、持续约束与跨时重构来证明。**

> **对象化具有 perspectival entry，但不是任意 fabrication：具身位置选择可读的尺度与差异，而现实关系反过来约束哪些对象化能够稳定成立。**
