# SourceCard — Synergetics: order parameter, slaving principle and circular causality

## 1. Scope

This card is narrowly scoped to one GRG question:

~~~text
What makes a higher-order / low-dimensional variable causally constraining
rather than merely descriptive?
~~~

It is not a general review of synergetics.

Primary bibliographic anchors:

- Hermann Haken, Synergetics: An Introduction, Springer Series in Synergetics.
- Hermann Haken, Principles of Brain Functioning: A Synergetic Approach to Brain Activity, Behavior and Cognition.
- Open retrospective close-read: Juval Portugali, Synergetics' two foundations and the city, European Physical Journal Special Topics, 2025/2026 volume.

## 2. Source-native architecture

The source family distinguishes:

~~~text
interacting components
-> emergence / selection of an order parameter
-> order parameter organizes / constrains component dynamics
-> components continue to generate / sustain the order parameter
~~~

This is described as the slaving principle plus circular causality.

In the laser paradigm:

~~~text
atoms / microscopic components
-> coherent field amplitude as order parameter
-> field constrains electron / atomic dynamics
-> stimulated emission by atoms sustains the field
~~~

The key point is not that the order parameter is low-dimensional.

The key point is that it occupies an operative role in the equations / dynamics of the components.

## 3. Admission guard

Do not infer:

~~~text
PCA component = order parameter
decoder dimension = order parameter
summary statistic = order parameter
macro correlation = order parameter
stable marker = order parameter
~~~

Compression or predictability alone does not pay the slaving burden.

A candidate order parameter must have a source-native dynamical relation to the component evolution it summarizes.

## 4. Circular causality

The source-native causal organization is reciprocal:

~~~text
parts generate macro organization
and
macro organization constrains parts
~~~

This is not a mysterious extra force.

The macro-variable is a collective variable of the system that enters the effective dynamics of the components.

Therefore synergetics is directly relevant to GRG-R1 cross-scale re-entry pressure.

## 5. Relation to GRG-R1 burden split

### R1a retained imprint

Synergetics does not reduce order-parameter standing to R1a.

A detectable macro signature without dynamical feedback is insufficient.

### R1b maintained scaffold

Strong alignment.

The order parameter is maintained as part of the ongoing collective dynamics rather than existing only as a historical trace.

### R1c causal re-entry

Strong alignment.

The slaving principle explicitly requires the order parameter to constrain component dynamics.

### R1d prospective transfer

Not automatically paid.

Order-parameter causal standing in one regime does not by itself establish transfer to a new unseen context.

## 6. Maintenance provenance

Synergetic order parameters are normally treated as endogenously generated / sustained by the system dynamics.

This creates an important contrast with experimental manipulations that externally clamp or repeatedly reset a macro / operator variable.

Therefore GRG work should record:

~~~text
maintenance mode:
- endogenous self-consistent maintenance
- exogenous experimental clamp
- externally imposed environment / institution
- mixed
~~~

Causal intervention on an exogenously maintained variable can establish causal capacity without proving endogenous self-maintenance.

## 7. Time-scale note

The slaving principle is commonly developed with separation between order-parameter dynamics and faster component / mode dynamics around instability.

This card does not claim a full formal derivation because the primary monographs were not fully close-read in this pass.

Any theorem-level or timescale-specific import requires a dedicated formal source read.

## 8. SRT / GRG use

Safe pressure:

> A higher-order variable earns GRG-R1c relevance only when it is dynamically generated / maintained and demonstrably constrains later component transitions; low-dimensional description alone is insufficient.

Non-identity:

~~~text
synergetic order parameter != SRT One
synergetic order parameter != Bearer
synergetic slaving != moral / political domination
synergetic circular causality != universal GRG theorem
~~~
