# SourceCard: Bryant & Whyte — *A data-driven approach to identifying and evaluating connectivity-based neural correlates of conscious visual perception*

## 1. 一句话结论

该研究重分析 COGITATE Consortium 的 MEG 数据和预注册理论预测，系统比较 246 种功能连接指标，发现基于信号“重心”的一组指标具有较强刺激解码能力；但 GNWT 式延迟点燃模型和 IIT 式同步感觉动力模型都能够重现相关连接模式。

对《从存在到秩序》的核心价值不是支持 IIT 或 GNWT，而是提供一个清晰反例：

```text
同一经验模式
can be fit by
不同理论机制
```

因此，神经相关、解码成功或单一指标优胜，并不自动构成意识理论的唯一解释。

## 2. 来源状态与证据纪律

- 正式发表于 *Neuroscience of Consciousness*，开放获取，DOI 已核验。
- 论文使用 COGITATE 的 MEG 数据和预注册假设，比较大量功能连接测量，并建立神经质量模型。
- 本卡核验了官方摘要、方法概览、主要结果和理论解释；后续若形成 PatchNote，应完整审计 246 指标、交叉验证、区域选择与模型比较细节。
- 论文处理的是 conscious visual perception 的连接相关和理论模型，不直接研究第一人称质感、主体连续性或 SRT 变量。

## 3. 研究设计与主要结果

研究流程可压缩为：

```text
COGITATE MEG dataset
+
pre-registered IIT / GNWT region predictions
-> compare 246 functional-connectivity measures
-> identify top decoding family
-> construct neural-mass models
-> compare simulated and empirical connectivity patterns
```

主要报告：

1. 一组 barycenter-based connectivity measures 在跨区域刺激解码中表现突出；
2. 这些指标可在 IIT 和 GNWT 预测的关键区域中泛化；
3. GNWT 式延迟点燃动力和 IIT 式同步感觉动力都能捕捉观测模式；
4. 数据驱动指标发现提高了测量层性能，但没有简单裁决理论赢家。

## 4. 证据强度与局限

### 强项

- 使用预注册理论预测和公开大型合作数据，减少完全事后选取。
- 系统比较大量指标，而不是只展示一个符合预期的 connectivity measure。
- 将数据驱动发现与显式神经动力模型连接。
- 结果自身暴露理论欠定：不同机制可以拟合同一经验结构。

### 局限

- 从 246 种指标中识别优胜者仍需严格控制多重比较、模型选择和泛化。
- 刺激解码能力不等于意识特异性；指标可能携带刺激、报告或任务信息。
- IIT 与 GNWT 模型能拟合数据，不等于完整理论获得同等支持，只说明当前观测区分力有限。
- neural mass model 的参数化和结构选择可能允许不同理论在较宽范围内适配。
- 连接相关仍不是体验内容的充分解释。

## 5. 对《从存在到秩序》的具体价值

### 5.1 Q17《意识》

可作为专业注中的**经验与理论欠定案例**：

> 神经数据并非没有约束力，但同一个连接模式可能被不同理论机制重建。问题不只是“找到意识相关区域”，还要设计能够让竞争理论给出不同失败结果的干预。

建议进入方式：

| 位置 | 方式 | 功能 |
|---|---|---|
| Q17 章末专业注 | 一段案例 | 防止把神经相关写成体验机制 |
| Neuroscience/SRT_Consciousness_Mechanisms.md | 后台方法材料 | 设计竞争模型和差异化预测 |
| Philosophy/SRT_HardProblem_Epistemology.md | 边界例子 | 映射成功不等于唯一解释 |

### 5.2 Q26《理论如何失败》

该材料非常适合说明：理论失败不只发生在数据与预测相反时，也发生在不同理论都能通过同一测量时。

```text
fit to data
!=
discriminative success
```

### 5.3 Q27/Q28

可用于理论自反：测量指标一旦成为默认地板，会引导所有理论围绕同一可见结构优化；数据驱动发现也可能生成新的“指标牢笼”。正文不需要介绍全部方法，只需保留理论欠定和测量选择的结构。

## 6. 对 SRT 的新增压力与接口

### 新增接口

- 将“理论竞争”从概念比较推进到同数据、同指标、不同机制模型的可执行审计。
- 要求 SRT consciousness claims 提供与 IIT/GNWT/PP 等竞争模型不同的干预或失败模式。
- 提醒 neural proxy 需要检验刺激信息、报告信息和意识特异性。

### 反向修正

- 任何与 SRT 叙事相容的 connectivity pattern 都不能被当作 SRT 独有证据。
- “后果回流”“承重位置”“历史闭合”若不能生成差异化预测，可能只是重新描述已知动力学。
- 数据驱动指标优胜不能反向定义 canonical 变量。

### 加固内容

- SRT 现有 claim ladder 和 bridge/canonical 区分适合处理此类欠定。
- Q17 已承认候选安置而非终解，可将该研究作为保持谦抑的经验锚点。

### SRT 可能的反哺

未来实验应设计 matched-neural-fit 条件，再引入 SRT 候选变量：

```text
same stimulus decoding
+
similar connectivity fit
but different consequence return / history writeback / future reselection
```

如果这些变量不能预测新的跨时间或干预差异，则 SRT bridge 应降级。

### 残余压力

若 IIT、GNWT 或一般动力系统模型在允许合理参数化后能覆盖所有 SRT 候选结果，SRT 必须缩小其经验声称，或提出更具体的失败条件。

## 7. 过度映射守门

```text
functional connectivity != consciousness
stimulus decoding != phenomenal content
barycenter measure != SRT variable
model fit != theory truth
IIT-compatible pattern != IIT proof
GNWT-compatible pattern != GNWT proof
multiple fits != all theories equivalent
neural correlate != generative explanation
```
