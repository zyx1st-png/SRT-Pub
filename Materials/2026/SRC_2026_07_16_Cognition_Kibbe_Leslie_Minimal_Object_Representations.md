# SourceCard: Kibbe & Leslie — *Minimal object representations in the infant mind*

## 1. 一句话结论

该文为 SRT 的对象化与个体区隔提供了一个高价值认知架构接口：**婴儿可以在不保留对象表面特征、类别身份乃至丰富物理性质的情况下，仍以一个裸索引维持“有一个东西在那里”。** 它支持“个体化可以先于描述与识别”的认知层命题，并为“先有这一个，后有它是什么”提供经验承重；但它不证明对象由心智创造，不证明选择先于物理存在，也不把裸索引升级为具身位、主体性或意识。

## 3. 来源明确支持的认知结构

### 3.1 对象存在表征可以弱于对象身份表征

文章区分两个问题：

```text
is there an object?
what object is it?
```

六个月婴儿在顺序遮挡任务中，可能无法检测第一件被遮挡物体的形状替换，却会对本应存在物体的位置变空表现出更长注视。这说明婴儿可以期待“那里有一个对象”，同时不保留足以重新识别该对象的表面特征。

安全结论是：

> object existence can remain represented when identifying content is unavailable or lost

不安全结论是：

> properties are never represented, or physical objects have no properties

### 3.2 裸索引是最小对象表征候选

作者把最小对象表征定义为 `index`：一个指向并持续追踪某个对象的心理指针。裸索引类似思维语言中的裸指示词“那个”，可以包含零描述性信息。

其最小性有两层：

1. 表面特征、类别、功能与物理性质可以选择性绑定到索引上；这些内容逐项丢失时，对象仍可能被表征。
2. 如果索引本身丢失，该对象在认知上不再被维持，其存在表征随之消失。

### 3.3 索引先部署，性质后绑定

图 4 给出的成熟架构包括三条索引部署路径：

- 时空路径：独特时空位置或轨迹触发索引；
- 性质图路径：时空信息不足时，检测新性质可触发新索引；
- 自上而下路径：即使对象未被直接看到，也可因推断其存在而部署索引。

索引部署之后，性质信息才可选择性绑定；绑定需要额外注意资源，而维持裸索引不要求完成性质绑定。

因此作者主张的架构顺序是：

```text
index deployment
-> optional property/category binding
-> richer object concept and physical prediction
```

而不是：

```text
complete property description
-> object existence
```

### 3.4 类别信息有时优先于表面特征

六个月婴儿在资源受限时，可以保留 `HUMAN / NON-HUMAN` 的类别区分，却不一定保留同类别内部的具体外观。图 3 显示：跨类别替换可被检测，而同类别内的特征替换可能不被检测。

这说明对象表征不是单一丰富度轴，而至少包含可分离层：

```text
bare individuation index
category identity
surface-feature identity
richer physical expectations
```

### 3.5 最小索引不等于丰富的 Spelke-object 概念

作者不否认婴儿可能具有坚固性、凝聚性、刚性、边界性等知识，但反对把这些性质视为每次对象表征都必然携带的不可分割内容。婴儿对相同物理违反在不同情景中可能表现不同，提示丰富物理对象概念具有逐步组装与学习的成分。

### 3.6 索引是宽松的，不能等同于完整物体本体

索引不仅可指向三维坚固物体，也可指向二维移动斑块、错觉对象、非牛顿运动对象或作为整体移动的对象集合。对象失去凝聚性后索引可能失效或重分配，但这不意味着索引显式表征“凝聚性”这一性质。

因此，索引更接近一个操作性个体化机制，而不是对对象本质的完整理论。

## 4. SRT 的核心接口

### 4.1 直接加固：个体化可以先于识别与描述

文章为以下认知层顺序提供经验支持：

```text
this one exists as a tracked position
-> what kind of thing it is
-> what properties it has
-> how it should behave
```

这与书稿中的对象化路线相容：对象性最早不必是一个完成的属性包，而可以先表现为一个被切出、维持和继续调用的“这一个”。

可采用的桥级句是：

> 心智最早维持的未必是“红色圆球”或“坚固物体”，而可能只是“那个”；个体区隔先被保住，性质与类别随后才落到这个位置上。

### 4.2 与选择性收束的受限映射

| 文章架构 | SRT 书稿接口 | 边界 |
|---|---|---|
| 索引部署 | 认知层切出一个可追踪的“这一个” | 不是宇宙本体论的第一次选择 |
| 性质未绑定仍维持存在 | 个体化先于描述性对象内容 | 不表示物理性质不存在 |
| 性质／类别后绑定 | 对象身份和范畴在个体位置上逐步沉积 | 不自动等于 L2 硬化 |
| 遮挡后继续追踪 | 最小连续性与可再调用界面 | 工作记忆维持不自动满足完整“写入”门槛 |
| 索引丢失则对象认知消失 | 对象不再处于当前可调用界面 | 不推出对象在观察者之外不存在 |

最稳妥的定位是：

> 裸索引是选择性收束在认知对象化层面的一种候选最小界面，而不是选择动力学全部结构的实证证明。

### 4.3 对象个体化与主体个体化必须分层

裸索引能够回答：

```text
which one?
```

它不能回答：

```text
for whom did the consequence matter?
where did the consequence return?
who bore and integrated it?
```

因此必须区分：

- **对象个体化**：建立并维持“这一个，不是另一个”；
- **主体个体化**：后果持续回到同一具身位，被承重、写回并参与历史调用。

可登记的三段式表达是：

> **选择性收束产生“这一个”；对象索引维持“还是这一个”；承重闭合产生“属于这一个”。**

前两段可由该文提供认知层承重；第三段属于 SRT 的主体性扩展，该文不提供证据。

### 4.4 为“个体区隔”补入两个不同问题

后续书稿与研究中应始终区分：

1. **追踪区隔**：什么机制允许系统持续指向同一个对象？
2. **后果区隔**：什么机制使后果归属于一个不可替代的具身位？

裸索引解决第一问的认知架构版本；具身位、攸关、承重和历史调用处理第二问。两问若混合，就会把对象追踪误写成意识，把第一人称归属降维成注意索引。

## 5. Claim ladder

### `E` — 来源直接支持

- 婴儿能够在不保留可识别表面特征时维持对象存在预期；
- 裸索引模型可以解释对象存在、身份和性质绑定的分层；
- 类别与表面特征在资源受限时具有不同优先级；
- 索引可以包含零描述信息，性质绑定不是对象存在表征的必要条件；
- 丰富物理对象概念不必作为不可分割的初始对象表征。

### `B` — SRT 桥级解释

- 个体化在认知架构中可以先于识别、范畴化和属性描述；
- 对象化可以先切出一个可追踪位置，再让内容沉积到该位置；
- “这一个”与“它是什么”应作为两个层级处理；
- 索引可以作为选择性收束在认知对象化层面的候选最小接口。

### `O` — 未被来源建立的本体论外推

- 对象本身由心智索引创造；
- 没有观察或索引，物理对象就不存在；
- 裸索引证明选择先于物理存在；
- 属性、结构或物质只是语言幻觉。

### `C` — 明确隔离的意识与主体性外推

- 能够索引对象就具有意识；
- 对象索引就是具身位、攸关、在乎或主体；
- 跟踪连续性等于第一人称连续性；
- 工作记忆容量或属性绑定强度可作为意识程度指标。

## 6. 书稿路由

### 6.1 Q02《对象化》：主要落点

未来正文或章末注可用该文说明：对象化的最低认知界面不必先携带完整属性内容；一个裸指示性的“这一个”可以先于“它是什么”。该材料适合放在现有 object-file / 对象追踪邻位，避免另立认知科学综述小节。

候选短句：

> 婴儿可以忘记被遮住的东西长什么样，却仍然期待那里有一个东西。对象化最早保住的，可能不是一份性质清单，而只是一个持续的“那个”。

### 6.2 Q05《选择不是挑选》：次要回指

可用来支持“菜单和对象身份不是免费起点”：认知系统可能先维持一个个体位置，随后才绑定类别与性质。不得把索引部署直接等同于全尺度选择三联。

### 6.3 Q12 / Q16：反向边界

在“具身位”与“主体沉积”处可作为负边界：对象索引提供连续追踪，却没有后果回流、价值锚定、承重轴线或历史调用，因此不能由 objecthood 直接跃迁到 subjecthood。

## 7. 防误解护栏

1. 论文研究的是心智中的对象表征，不是对象本体。
2. “认知上消失”不等于“物理上不存在”。
3. 裸索引无描述内容，不等于对象无性质。
4. 对象持续追踪不等于后果归属或第一人称内部性。
5. 索引容量约三至四个是工作记忆／注意架构约束，不是世界中对象数量的限制。
6. 该文与 SRT 的一致性属于桥级映射，不是 SRT 的经验验证。

## 8. 双向增益

### 新增接口

- `individuation before identification`：个体化先于识别；
- `bare index -> property binding`：对象位置与对象内容分层；
- `tracking boundary / consequence boundary`：追踪区隔与后果区隔分离；
- “这一个 / 还是这一个 / 属于这一个”三层对象—主体桥。

### 反向修正

- 收紧“对象由选择产生”的公共表达，避免被理解为心智索引创造物理对象；
- 收紧“结构先于物质”的认知例证：该文只显示表征顺序，不建立本体优先性；
- 防止把 object file、FINST、注意索引或工作记忆连续性升级成主体性与意识。

### 加固内容

- Q02 对象化不是先接受完整对象再描述，而是先建立可操作工作面；
- Q05 “挑选是最后一帧”可获得认知架构邻证；
- Q12/Q16 的具身位与主体门槛因为有了对象索引负对照而更清晰。

### SRT 反哺

SRT 可把论文主要处理的追踪问题置于更长链条中：

```text
selectional convergence
-> minimal tracked individuation
-> identity / property binding
-> consequence return
-> bearing closure
-> historical invocation
-> subject sedimentation
```

该长链不是论文结论，而是 SRT 对对象表征、个体归属与主体形成的分层重述。

### 残余压力

- 裸索引是否真的包含零描述信息，仍取决于对时空定位与操作结构是否算作“描述”的理论选择；
- 违反预期范式的注视时长需要继续受方法论争论约束；
- 对象索引模型与预测加工、事件分割、关系性对象观如何整合，本文未解决；
- SRT 尚需进一步形式化“追踪连续性”何时升级为选择特异写回，何时只属于短期认知维持。

## 9. 最终裁决

```text
A: bounded cognitive-development and book-objectification bridge
C: direct proof of SRT ontology, subjectivity, or consciousness
```

该材料已经足以进入材料库和书稿外部理论对齐层。它最强的贡献不是证明“现实由选择生成”，而是建立一个更有限但坚实的经验台阶：**在婴儿心智中，“有这一个”可以先于“知道它是什么”。**
