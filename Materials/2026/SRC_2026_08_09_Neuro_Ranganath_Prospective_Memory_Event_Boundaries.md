## 1. One-line summary

Episodic memory is better treated as a reconstructive and prospective control resource than as a photographic archive: event boundaries preferentially recruit hippocampal-memory circuitry, remembered history can bias behavior before a predicted event occurs, and sleep can strengthen that anticipatory use of memory even when explicit report does not show the same gain.

## 2. Verified primary anchors

### 2.1 Event-boundary responses and aging

Reagh et al. (2020), *Aging alters neural activity at event boundaries in the hippocampus and Posterior Medial network*, *Nature Communications* 11, 3980.

- DOI: `10.1038/s41467-020-17713-4`
- 546 cognitively normal participants aged 18–88 watched a short movie during fMRI.
- Hippocampus and posterior-medial-network regions showed increased activity at event boundaries.
- Boundary-evoked responses decreased with age.
- Posterior hippocampal boundary response predicted performance on a separate story-memory measure.

### 2.2 Boundary-specific hippocampal–cortical interaction and later memory

Barnett et al. (2024 issue; published online 2023), *Hippocampal-cortical interactions during event boundaries support retention of complex narrative events*, *Neuron* 112(2), 319–330.e7.

- DOI: `10.1016/j.neuron.2023.10.010`
- Participants encoded and recalled cartoon movies during fMRI.
- Hippocampal–posterior-medial-network functional connectivity at event offset was related to later successful recall.
- Offset connectivity also predicted amount of detail retained after a two-day delay.
- The key result is temporally specific: memory-related hippocampal-cortical interaction is biased toward event boundaries rather than uniformly expressed across the entire episode.

### 2.3 Anticipatory gaze as a no-report memory marker

Schmidig, Yamin, Sharon, Nadu, Nir, Ranganath & Nir (2025), *Anticipatory eye gaze as a marker of memory*, *Communications Psychology* 3, 122.

- DOI: `10.1038/s44271-025-00305-7`
- Five experiments, total `n = 145`.
- Participants repeatedly viewed short clips containing surprising events while eye movements were tracked.
- On repeated viewing, gaze shifted toward the future event location before the event occurred.
- Accumulated gaze proximity could index memory at the single-trial level.
- Anticipatory gaze tracked associative recollection, while pupil dilation showed a different relation closer to familiarity.
- In the nap/wake experiment, anticipatory-gaze memory expression was stronger after sleep, supporting a no-report window onto sleep-related consolidation.

### 2.4 Curiosity and hippocampal learning

Gruber, Gelman & Ranganath (2014), *States of curiosity modulate hippocampus-dependent learning via the dopaminergic circuit*, *Neuron* 84(2), 486–496.

- DOI: `10.1016/j.neuron.2014.08.060`
- High-curiosity states improved memory for target answers and incidental material.
- Curiosity-related memory benefit involved anticipatory midbrain/hippocampal activity and functional coupling.

Gruber & Ranganath (2019), *How Curiosity Enhances Hippocampus-Dependent Memory: The Prediction, Appraisal, Curiosity, and Exploration (PACE) Framework*, *Trends in Cognitive Sciences* 23(12), 1014–1025.

- DOI: `10.1016/j.tics.2019.10.003`
- Review / framework linking prediction, appraisal, curiosity, exploration and memory.

## 3. Core claims of the source packet

### C1. Memory is reconstructive, not photographic

The talk's strongest rhetorical form — "memory is not about the past at all" — should not be imported literally. The safer surviving claim is:

> Episodic remembering is not a literal replay of a stored past scene; retrieval is reconstructive and conditioned by present context, goals and available memory traces.

### C2. Memory circuitry is reused for present interpretation and future-oriented simulation

The relevant empirical program treats episodic memory, imagination, event-model updating and prediction as partially overlapping functions. This does not imply that memory ceases to represent past events; it implies that memory's functional role is broader than archival storage.

### C3. Event boundaries are privileged update/encoding moments

Human observers reliably segment continuous experience into events. Hippocampal and posterior-medial-network activity rises at boundaries, and boundary-specific hippocampal-cortical interaction predicts later retention.

### C4. A remembered past can alter behavior before the future event arrives

In MEGA, the physical movie segment can be replayed while prior exposure differs. On later viewing, gaze moves toward the location of a salient event before that event appears.

This is especially important for SRT because the remembered history is expressed as a prospective behavioral divergence, not only as a verbal statement about the past.

### C5. Sleep can strengthen future-guiding memory expression

The nap/wake experiment shows that a no-report anticipatory measure can reveal sleep-related memory benefit. The result should not be overread as "sleep makes prediction universally improve"; it is a task-specific memory-consolidation result.

### C6. Curiosity links uncertainty/prediction appraisal to active information seeking and memory

Curiosity is a useful adjacent mechanism for SRT because surprise need not terminate in passive mismatch. Under some conditions it recruits exploration and improves later memory. Curiosity, however, is not canonical `d`, `Psi_f`, or `T_dir`.

## 5. Limits

1. Event-boundary activation is not a proof that the brain stores complete episodes only at boundaries.
2. Boundary salience can correlate with perceptual or narrative change; boundary-specific memory claims require appropriate controls.
3. MEGA demonstrates history-sensitive anticipatory gaze, but the published paradigm does not by itself causally identify the neural carrier of that memory effect.
4. A repeated-viewing effect is not automatically an SRT real-choice event.
5. Anticipatory gaze can operationalize active historical use, but it does not by itself establish `L2`-grade hardening.
6. Sleep-related benefit is paradigm-specific and should not be generalized to every memory or predictive process.
7. Curiosity is not equivalent to prediction error, reward, salience, `d-value`, `Psi_f` or `T_dir`.
8. The Alzheimer's biomarker proposal in the talk remains a prospective application rather than a validated clinical diagnostic claim in this packet.
