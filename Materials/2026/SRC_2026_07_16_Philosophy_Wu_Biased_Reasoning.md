# SourceCard: Wayne Wu — *Being Biased and Knowing How to Reason*

## 1. 一句话结论

该文把推理从“由规则自动推出结论的认知反射”改写为一种行动：由于任何实际推理都面对多种可继续的思考路径，知识通过 bias 解除行动欠决定性，使某条思考轨迹被实际执行；“知道如何推理”因此是知识与思考能力结合后形成的可行动结构。

## 3. 摘要明示的论证结构

1. 推理是一种 action，而不是 reflex。
2. 推理面临 action underdetermination：在一个认知状态下，可进行的下一步思考不止一个。
3. 欠决定性不仅出现在归纳，也出现在演绎。
4. 因而实际推理若要发生，必须带有 bias；没有选择性偏置，认知能力不会落实为一条具体推理行动。
5. 这种 bias 不是任意歪曲，而由 agent 的知识塑造。
6. Boghossian 所说的 “taking” 可被重述为 biased reasoning：主体把某些内容当作理由、前提或推理许可。
7. 经验研究显示 belief 会偏置 attention，为哲学模型提供心理学支持。
8. 知识与思考能力的整合结构构成一种 knowing how to reason。

## 4. 最关键的概念区分

### 4.1 Bias 不是错误的同义词

日常语境常把 bias 理解为认知缺陷。本文的结构性用法更接近：

> 在多个可执行路径之间，使行动实际沿某一方向展开的选择性约束。

因此需要区分：

- **constitutive bias**：任何有限推理行动都需要的路径选择；
- **epistemically good bias**：由相关知识适当约束；
- **epistemically bad bias**：由无关、错误或僵化结构驱动；
- **opaque bias**：主体无法读取其方向来源；
- **revisable bias**：新证据可触发重定向。

### 4.2 Action underdetermination 不等于逻辑不确定

即使演绎关系客观确定，实际主体仍需决定：

- 调用哪条规则；
- 检索哪一知识；
- 注意哪个特征；
- 以什么顺序展开；
- 何时停止；
- 把结论用于什么行动。

所以“结论在逻辑上蕴含”并不自动说明有限主体如何完成推理。

### 4.3 Knowledge-how 不只是命题库存

知道很多命题不等于知道如何推理。作者提出的结构似乎要求：

```text
knowledge
+ capacity for thinking
+ biasing / selection organization
= knowing how to reason
```

## 5. 对 SRT 的核心价值

### 5.1 提供认知层面的 “selection before determinate trajectory”

SRT 可以从该文获得一个受限但清晰的桥：

```text
available cognitive continuations
    -> knowledge-shaped bias
    -> enacted reasoning trajectory
    -> conclusion / commitment / action
```

这与 `L0 -> L1 -> L2` 存在结构同构：

- 候选思考路径：局部可选择域；
- bias：有限系统的方向性约束；
- 实际推理轨迹：被锚定的过程；
- 形成习惯、技能和可复用规则：历史沉积。

但这是**认知行动桥**，不能反推宇宙本体论。

### 5.2 帮助区分“选择”与随机挑选

选择并非必须先有完全显式的主体审议。知识、注意和技能可以在前反思层面偏置路径。SRT 因而可区分：

- stochastic deviation；
- externally forced transition；
- knowledge-shaped selective transition；
- stake-bearing real choice moment；
- reflective report of choice。

该文最多支持第三层及其与行动的关系，不直接证明第四层。

### 5.3 为 `T_dir` 提供最小候选接口

若 `T_dir` 是系统对自身选择方向的可读性，该文提示至少分开：

1. **bias efficacy**：偏置确实改变推理路径；
2. **bias source**：偏置由哪些知识或习惯产生；
3. **bias readability**：主体能否识别其方向；
4. **bias revisability**：新证据是否能重定向；
5. **bias ownership**：后果是否返回同一主体。

推理可以在 1 成立、3 不成立时发生。因此 `T_dir` 不能与“有方向性 bias”同一。

## 6. 对 ChoiceMap 的直接帮助

ChoiceMap 把收敛交还用户，可以用该文重新表述：

- 模型生成选项只扩充可继续路径；
- 用户已有知识、历史和 stake 会对这些路径施加 bias；
- 真正的收敛不是从模型评分中机械推出，而是用户将某些事实、责任和后果“take as reasons”；
- ChoiceMap 应帮助用户显影 bias 的来源与可修订性，而不是试图消除所有 bias；
- “无偏决策”不是目标，**可读取、可质疑、与后果相连的偏置**才是目标。

可新增产品检查：

| 检查 | 问题 |
|---|---|
| source audit | 这个偏向来自知识、习惯、恐惧还是默认脚本？ |
| relevance audit | 它与当前后果结构相关吗？ |
| revisability audit | 什么证据会使你改变方向？ |
| horizon audit | 它只优化近端，还是覆盖长期后果？ |
| ownership audit | 谁承担这一 bias 导致的后果？ |

## 7. SRT 候选形式桥

不作为 canonical 公式，可用下式表达局部认知接口：

\[
\mathcal{C}_{t+1}
=
\operatorname{Select}
\bigl(
\mathcal{A}(\mathcal{C}_t),
B(K_t, H_t, \Theta_t)
\bigr)
\]

其中：

- `\mathcal{A}(\mathcal{C}_t)`：当前认知状态可执行的后续动作集合；
- `K_t`：显性或隐性知识；
- `H_t`：习惯与历史；
- `\Theta_t`：注意、任务和身体约束；
- `B`：方向性偏置；
- 结果是实际执行的下一步认知动作。

该形式只说明有限推理需要选择性约束，不说明 `B = \hat G_\theta`，也不说明 bias 自身就是本体论选择。

## 8. 对文章的主要压力

1. **“所有演绎都欠决定”需要精确定义。**  
   必须区分逻辑关系的确定性与行动实现的欠决定性，否则容易制造伪悖论。

2. **知识是否总是 bias 的来源？**  
   欲望、情绪、身体状态、社会权力和随机噪声同样偏置注意与推理。

3. **良性 bias 的规范标准是什么？**  
   若知识本身错误、局部或制度化，bias 可能稳定地导向坏推理。

4. **action 与 reflex 的边界可能是连续谱。**  
   熟练推理可高度自动化，但仍可能是可问责的行动。

5. **知道如何推理是否要求主体能解释？**  
   摘要倾向结构性而非报告性答案，但全文需核验。

## 12. Surviving claims

1. 有限主体的实际推理需要在多个可能认知动作中形成方向。
2. 逻辑蕴含的确定性不等于推理执行路径的唯一性。
3. 知识可通过注意和行动组织偏置推理。
4. 合理推理不是无偏，而是偏置与相关知识适当整合。
5. 该结构可作为 SRT 的认知行动桥，但不能解决 selectability 的本体论起源。
