# SourceCard: Wayne Wu — *Being Biased and Knowing How to Reason*

## 1. 一句话结论

该文的稳定贡献是：**有限主体的推理不能只被解释为“前提触发结论”的可靠反射；由于同一认知输入允许多种可执行后续，推理作为行动需要一种不作为新前提、而是结构化输入—输出耦合的 bias。学习可以把规则知识从被思考的内容转化为调节注意与行动路径的偏置，由此构成一种 knowing how to reason。**

对 SRT 而言，最重要的不是把 `bias` 升格为选择本体，而是得到一个认知层面的三分：

```text
directional efficacy
!=
directional self-readability
!=
stake-bearing ownership
```

Wu 主要解释第一项；SRT 的 `T_dir` 至少还要求第二项，并在主体性判断中继续要求第三项。

## 4. 核心论证重建

### 4.1 欠决定性首先是行动实现问题

Wu 不主张逻辑蕴含本身不确定。他主张：

> 给定有限前提，主体仍可能进行多种逻辑上允许或心理上可行的下一步操作。

例如给定 `p -> q` 与 `p`，主体可以：

- 以 modus ponens 得到 `q`；
- 进行合取引入；
- 进行析取引入；
- 重述、检查或暂停；
- 把注意转向前提的其他性质。

所以：

```text
logical support relation
!=
unique psychologically enacted continuation
```

“演绎欠决定性”应读作 **有限行动者的响应选择未被前提唯一实现**，而不是“逻辑规则没有确定性”。

### 4.2 自动性与行动并不互斥

Strawson 把大量思考理解为 mental ballistics：内容自动出现，因此不是行动。Wu 的回答是：

- 行动只需在某些描述下受意图控制；
- 有限主体不可能意图动作的全部微观性质；
- 推理过程可以符合主体的意向规格，即使最终结论的出现具有自动性；
- 控制和自动性可同时存在于同一过程的不同性质上。

因此：

```text
automatic endpoint
does not imply
non-agentive whole process
```

但这也意味着行动/反射不能仅由“是否快速、自动或无意识”划分。

### 4.3 Bias 是催化或结构化原因，不是触发原因

标准因果理论把前提信念视为 primary reasons，随后触发结论。Wu 认为这只得到 Broome 所说的 jogging：

```text
premise states
-> reliable automatic mechanism
-> conclusion
```

即使过程可靠、真值保持，也没有解释为什么这是主体进行的推理，而不是发生在主体中的理性反射。

Bias 的角色不同：

- 它不作为又一个需要被处理的前提；
- 它改变哪些输入具有行动相关性；
- 它设置注意和竞争的优先结构；
- 它使某一输入—输出耦合在多个可行耦合中被实际化；
- 它是 constraint / catalyst，而不是另一个 triggering input。

### 4.4 注意是“为行动而选择”

Wu 采用一个宽而经验兼容的注意概念：

> 心智选择某个目标供进一步处理，使其指导一个响应，同时从其他候选撤离。

在推理中，注意就是：

```text
select premise / feature
so that it informs
a cognitive response
```

所以 bias 通过设置注意，完成从“多个输入和多个响应都可用”到“某一输入实际指导某一结论”的转换。

### 4.5 Carroll 悖论显示：增加规则可能加剧欠决定性

若主体不会应用 modus ponens，向其增加一条规则作为新前提，并不会自动解决问题。它反而增加可被处理的输入以及可能响应。

这给出全文最有用的结构判断之一：

> **更多信息、规则或选项，不一定减少选择困难；若知识没有进入结构化 bias 的角色，它会扩大欠决定性。**

Ryle 的逻辑学生“知道规则”却不会推理，说明：

```text
rule as represented content
!=
rule as action-organizing knowledge
```

### 4.6 “Taking” 可以自然化为 bias

Boghossian 为避免 jogging，要求主体把前提“看作支持”结论，但最终倾向把 rule-following / taking 当作不可分析的原始能力。Wu 认为这会让所有基于理由的行动都面临自然主义不可解释性。

他的替代是：

- 保留 taking 的功能直觉；
- 不把 taking 作为额外前提；
- 把它解释成规则知识对思考能力施加的结构性偏置。

这也与 Pavese 的 input basis / structural basis 区分会合：规则是结构基础，不是输入基础。

### 4.7 经验桥：信念确实可以偏置注意

论文主要依赖以下经验路线：

1. **Symbolic spatial cueing**  
   被试知道箭头提示的有效概率，例如 80%/20%；统计期待使有效位置反应更快、更准，并给无效位置带来成本。

2. **视觉系统效应**  
   统计期待可改变包括早期视觉皮层在内的响应性质，说明高层信念能够准备低层处理能力。

3. **Retro-cueing / working memory**  
   提示可使记忆中的某个位置或项目获得优先处理。

4. **Biased competition theory**  
   多个神经输入竞争行为控制，偏置解除竞争，从神经层实现注意选择。

这些研究支持：

```text
learned representation / belief
-> attentional priority
-> changed action readiness
```

但全文没有提供直接实验：

```text
knowledge of modus ponens
-> measured attention to premise structure
-> causal production of deductive inference
```

因此经验支持是**机制类比和跨域可行性锚定**，不是演绎推理模型的直接确认。

### 4.8 学习的关键是“功能角色转化”

Wu 比较两类学生：

- Ryle 的学生记住规则，却把规则当成新内容，仍不会应用；
- 熟练学生可借助规则实际完成推理。

学习使知识发生如下变化：

```text
rule as input / premise
->
rule as bias / structural constraint
```

这不是简单增加命题库存，而是重新组织认知系统的连接方式。

### 4.9 Triangularity：知道如何推理的认知结构

论文图 6—9 用三角结构表示 know-how：

- 三角底边：可由输入指导输出的认知行动能力；
- 三角顶点：作为 bias 的规则知识、统计知识或经验形成的结构；
- 实际化：在适当场景中，顶点知识偏置底边耦合，产生符合规则的思考行动；
- 多个三角共享同一规则顶点，表示技能的泛化范围。

因此：

```text
knowing how to reason
!= isolated proposition
!= bare input-output disposition

knowing how to reason
= knowledge-organized action capacity
```

知识命题可以是 know-how 的构件，但 know-how 不被还原为单一 know-that。

### 4.10 推理可以是自动且不可报告的

Wu 用邮局职员“看起来很友善”的案例说明：

- 主体可能无法说出使用了哪些特征；
- 也无法表述从特征到“友善”的一般化；
- 过去经验形成的统计结构仍可能自动偏置相关特征；
- 主体选择性响应这些特征，使它们指导结论。

因此：

```text
bias efficacy > 0
can coexist with
explicit accessibility ≈ 0
```

这对 SRT 很关键：**方向性有效不等于方向透明。**

## 5. 全文后可安全保留的 surviving claims

1. 有限主体从认知输入到响应的实现通常面对行动欠决定性。
2. 可靠的前提—结论因果转换本身不足以解释主体为何是在推理，而非经历一个理性反射。
3. 规则或理由可以通过结构化注意和输入—输出耦合发挥作用，而不必作为新增前提。
4. 学习可能改变知识的功能角色：从被处理的内容转化为组织行动能力的偏置。
5. 信念和统计期待能够在多种实验范式中偏置注意和行动准备。
6. 自动、无意识或不可报告的选择性指导仍可能参与行动。
7. 论文没有证明所有 bias 都是良性的、都属于主体自身，或都构成 SRT 意义上的真实选择。
8. 论文没有解决选择性为何在本体论上首次出现。

## 6. 对 SRT 的直接增量

### 6.1 为“选择不是纯触发”提供认知行动桥

SRT 可安全吸收：

```text
input causally produces output
!=
agent selectively enacts output
```

在认知层，若要把转换解释为行动，需要说明：

- 有哪些可执行后续；
- 什么结构使某些后续成为当前可行动方向；
- 哪些输入被选为指导响应的依据；
- 该结构是否可学习、可冲突、可修订。

这可加固 agency ladder 中“causal transition”和“controlled selection”的区别。

### 6.2 为 L2 下向约束提供微观认知实例

规则、统计知识、schema 和历史经验可作为已有沉积，改变下一次可达的思考路径。

安全映射：

```text
learned knowledge / schema
~ cognitive L2 constraint

attentional selection
~ local L1 transition organization
```

但不能写成：

```text
all knowledge = L2
bias = G_hat_theta
deduction experiment proves L0 -> L1
```

### 6.3 对 `T_dir` 的最强贡献是“先拆开再连接”

Wu 的模型迫使 SRT 区分：

| 量 | 问题 | Wu 是否直接支持 |
|---|---|---|
| bias efficacy | 偏置是否真实改变路径？ | 是，具有哲学论证与注意研究锚点 |
| source accessibility | 主体能否报告偏置来源？ | 不必要；可为零 |
| directional self-readability | 主体能否回读正在形成的方向？ | 未直接建立 |
| reorientation capacity | 方向信号能否用于重新校准？ | 部分开放 |
| ownership / stake | 后果是否回流同一 bearer？ | 文章不处理 |

所以：

\[
E_{\mathrm{bias}}>0 \not\Rightarrow T_{dir}>0
\]

Wu 不能作为 `T_dir` 的定义依据，但可以作为“方向有效性不得与方向透明度混写”的重要外部锚点。

### 6.4 对 ChoiceMap 的关键修正：选项扩张本身可能让选择更差

ChoiceMap 现有 S1 强调扩张选项。Wu 的 Ryle/Carroll 分析提醒：

> 若只是增加更多规则、理由、信息和选项，而没有把用户知识转化为可读取、可修订的结构性 bias，欠决定性会被放大。

因此 ChoiceMap 不应只问“还有哪些选项”，还应帮助用户显影：

- 哪些知识正在设置注意；
- 哪些规则被当作结构约束，而不是另一条信息；
- 哪些 bias 与当前 stake 有关；
- 哪些证据会触发重定向；
- 多个 bias 冲突时谁拥有收敛权。

产品目标不是“消除 bias”，而是：

```text
implicit / rigid / externally installed bias
->
explicitly inspectable / challengeable / user-owned bias scaffold
```

### 6.5 对“选择先于确定轨迹”的支持范围

文章支持的是：

> 在已经存在主体、知识、输入、响应能力和学习历史的条件下，具体推理轨迹不能由输入单独唯一落实，需要选择性约束。

它不支持：

- 选择先于所有存在；
- `ε_pg` 的本体起源；
- `G_hat_theta` 的宇宙级定义；
- bias 自动构成 stake-bearing real choice moment。

## 7. SRT 形式桥（P3/P4）

### 7.1 Many-many selection problem

令：

- `X_t`：当前可指导行动的认知输入集合；
- `Y_t`：当前可执行的认知响应集合；
- `K_t`：学习获得的规则、统计结构或 schema；
- `B_t`：由 `K_t`、意图、历史和身体状态形成的偏置结构；
- `Γ_t(x,y)`：输入 `x` 对响应 `y` 的可用耦合。

无 bias 时：

\[
|\{(x,y):\Gamma_t(x,y)>0\}|>1
\]

bias 不作为新输入，而改变耦合准备度：

\[
\Gamma_t^{B}(x,y)
=
\Gamma_t(x,y)\,\Omega_B(x,y\mid K_t,H_t,I_t)
\]

实际行动是某一被组织的耦合被实现：

\[
(x^\*,y^\*) \in \operatorname{Actualize}(\Gamma_t^{B})
\]

`Ω_B` 不预设为标量效用或 argmax；它只表示结构化可达性和指导权发生改变。

### 7.2 与 `T_dir` 的安全关系

定义三个桥接读数：

- `E_B`：bias 对路径的因果有效性；
- `R_B`：系统对 bias 来源和当前方向的回读能力；
- `V_B`：系统利用该方向信号重定向的能力。

Wu 的材料主要支持：

\[
E_B > 0
\]

SRT `T_dir` 的最低角色仍更接近：

\[
T_{dir}^{v0}\sim R_B \cdot V_B
\]

因此：

\[
E_B>0 \not\Rightarrow R_B>0
\]
\[
E_B>0 \not\Rightarrow T_{dir}>0
\]

## 8. 对文章的主要压力

### 8.1 “推理 vs jogging”的分界仍可能过度依赖作者直觉

Wu 认为可靠触发不足以构成行动，但他的正面标准可能使大量自动选择都成为行动。仍需解释：

- 哪一种 guidance 属于 agent-level；
- 哪一种只属于子个人机制；
- bias 如何成为“主体的”而非仅在主体中发生；
- 控制失败、强迫、操纵与病理性固着如何分类。

SRT 可用 bearer、后果回流和可再选择性进一步限制。

### 8.2 经验支持是间接的

空间线索和 biased competition 很好地证明知识/期待能偏置注意，但从视觉空间选择外推到：

- 逻辑规则；
- 命题推理；
- Taking Condition；
- knowing-how 的构成；

仍需要直接实验。

### 8.3 “知识”承担了事实性和规范性双重负担

Wu 用宽的 learning-theoretic 语言，把知识理解为经验获得、准确且影响行动的表征。但现实推理还受到：

- 错误信念；
- 欲望与情绪；
- 权力与制度脚本；
- 创伤和强迫；
- 随机探索；
- 多个相互冲突的 bias；

共同组织。文章承认 bias 可冲突，但没有给出冲突解决和规范判准。

### 8.4 “增加规则加剧欠决定性”不是所有教学情形的定律

规则作为输入有时确实可以：

- 缩小搜索空间；
- 提供显式启发；
- 触发元认知检查；
- 通过外部脚手架帮助学习。

关键不是“规则作为内容必然无效”，而是它是否已连接到能够组织行动的能力。

### 8.5 Know-how 的 triangularity 仍是纲领性结构

三角图清楚表达功能角色，但尚未指定：

- 神经或计算实现；
- 学习算法；
- bias 冲突和权重变化；
- 泛化失败；
- 可修订性；
- 从 novice 到 expert 的可测阶段。

## 10. 可操作实验与产品测试

### 10.1 Rule-as-input vs rule-as-bias

比较两组学习条件：

- 仅呈现规则和例题；
- 通过练习使规则预测性地组织注意和响应。

测量：

- 规则迁移；
- 对无关信息的抗干扰；
- 眼动或注意分配；
- 新实例上的反应时与错误类型；
- 能否在规则不显示时继续应用。

### 10.2 多个有效结论的选择实验

给出支持多种有效推导的同一前提集，操纵：

- 任务目标；

检验不同 bias 是否改变选定推理路径，而不是只改变最后报告。

### 10.4 Novice-to-expert longitudinal test

的阶段变化。

### 10.5 ChoiceMap A/B

比较：

1. 只增加选项；
2. 增加选项 + 显影用户规则、证据和 bias 来源；
3. 增加选项 + 模型代替用户排序。

主要结果：

- 主体是否能说明收敛依据；
- 遇到反证时是否能改向；
- 是否识别默认脚本；
- 选择后是否保留可再选择性；
- 模型建议是否压过用户自身 stake。

## 12. 最低边界声明

本文可用于：

- 说明可靠因果过渡不充分等于主体推理；
- 说明有限认知行动需要结构性路径偏置；
- 说明 bias efficacy 与显式可读性可分离；
- 说明学习可改变知识的功能角色；
- 修正 ChoiceMap“只扩张选项即可改善选择”的风险。

本文不可用于：

- 证明 SRT 本体论；
- 证明选择先于所有存在；
- 把 bias 定义成 `ε_pg`、`G_hat_theta` 或 `T_dir`；
- 把注意、规则应用或推理技能当作 stake、意识或自由意志；
- 声称视觉线索研究已经验证逻辑推理的 bias 模型。
