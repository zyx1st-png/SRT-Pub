# SourceCard: Peter Schulte, *Toward a Radical Gradualism About Representation*

## 1. One-line summary

Schulte argues that the transition from mere sensitivity to genuine representation should not be modeled as crossing a strict or fuzzy natural border. Traditional necessary-and-sufficient demarcation conditions face a `problem of adjacent cases`: systems just below and just above a proposed threshold often show no corresponding discontinuity in the scientific explanatory value of representational models. He therefore proposes a robustly realist radical gradualism in which representationality itself comes in degrees, broadly tracking sensory information-processing complexity.

## 3. Demarcation question

The paper begins from the standard question:

```text
Where is the border between mere sensitivity and genuine representation?
```

Organisms from bacteria and plants to insects and mammals respond adaptively to environmental conditions. Schulte asks when such responsiveness becomes genuine representation.

He uses a standard notion of representation: an internal state with semantic content and truth-, correctness-, or fulfillment-conditions in virtue of that content. Phenomenal consciousness is explicitly bracketed.

## 4. Explanatory constraint and the low road

Schulte adopts an explanatory constraint:

```text
No representation without representational explanation, and vice versa.
```

An adequate account of representational status should attribute representations where those attributions can participate in genuine, distinctively representational explanations.

He distinguishes:

```text
high road:
build a theory of representational explanation first;

low road:
use mature scientific explanatory practice as a fallible guide to where
representational models have genuine explanatory value.
```

The paper follows the low road.

### Negative versus positive paradigms

A rifle trigger is a negative paradigm. One can redescribe the firing pin as `representing` that the trigger was pulled, but this semantic description earns no serious explanatory role in firearm engineering.

Human vision is a positive paradigm. Vision science routinely models states as representing object distance, binocular disparity, visual angle and other contents, while causal transitions are characterized as mathematical or logical operations over those contents.

The relevant criterion is therefore not vocabulary but explanatory work.

## 5. Liberal and non-liberal theories

`Liberal` theories attribute representation very widely, potentially to reflex arcs, hormonal changes, tropisms, thermostats or vending machines.

`Non-liberal` theories instead seek some condition `C` that separates genuinely representational systems from negative paradigm cases.

Schulte's main argument targets non-liberal demarcation theories.

## 6. Burge's constancy-mechanism theory

The focal case is Tyler Burge's constancy-mechanism account. In Schulte's reconstruction:

```text
an agentive system is representational
iff
it contains at least one sensory system employing perceptual constancy mechanisms.
```

Perceptual constancy solves a proximal-distal underdetermination problem. In size constancy, retinal image size alone underdetermines distal object size; a system can integrate retinal size with distance information to obtain a stable estimate of object size.

If perceptual constancy really marks the natural onset of representation, scientific explanatory practice should show a corresponding `tipping point` when constancy mechanisms appear.

## 7. The problem of adjacent cases

Schulte's strongest contribution is the `problem of adjacent cases`.

For any candidate necessary-and-sufficient condition `C`, compare:

```text
S_minus = the most developed relevant system that does not satisfy C
S_plus  = the least developed relevant system that does satisfy C
```

Then ask whether representational explanatory practice changes discontinuously between them.

If `C` is a genuine natural boundary, the transition should correspond to a real explanatory discontinuity. Schulte argues that this often fails.

### 7.1 Simple size constancy

A simple size-constancy mechanism integrates retinal image size and distance information to produce an object-size representation. Burge classifies this as genuinely representational, and representational descriptions are indeed used in cognitive-scientific explanation.

### 7.2 Desert-ant path integration

Desert ants return to their nest after irregular outbound travel by continually updating a `home vector`:

```text
old home vector
+ current travel distance
+ current travel direction
-> updated home vector
```

Burge explicitly denies that path integration is perceptual constancy because it does not solve the same proximal-distal underdetermination problem. Yet empirical explanations naturally characterize the home vector and its updating representationally.

Schulte therefore argues that moving from path integration to simple constancy does not produce the predicted explanatory tipping point.

### 7.3 Auditory cue integration

To avoid relying on whether path integration could be reclassified as constancy, Schulte gives a second case. A simple auditory system combines interaural time difference (`ITD`) and interaural level difference (`ILD`), weighting them according to reliability across frequencies, to estimate sound-source direction.

This is cue integration rather than perceptual constancy, but representational descriptions of the estimate are explanatorily central. Again, no special explanatory onset appears exactly at constancy.

## 8. Generalized threshold challenge

Schulte does not claim to have individually refuted every traditional account. Instead he proposes a general pressure test:

```text
propose condition C
-> compare nearest C-negative and C-positive cases
-> ask whether representational explanation changes discontinuously there.
```

He gives three reasons to expect the problem to generalize:

1. Burge's theory is unusually well developed and empirically informed;
2. similar pressure appears for other non-liberal accounts;
3. scientific literature on simple sensory systems appears to show an almost imperceptible increase in the seriousness of representational modeling as information-processing complexity rises.

## 9. Radical gradualism

Schulte's positive proposal removes the presupposition that representation must have a strict or fuzzy border.

Instead:

```text
representationality itself comes in degrees.
```

Systems can have zero, low, medium or high representationality. The transition from mere sensitivity to representation is an extended grey region rather than a border crossing.

## 10. Information-processing complexity

Schulte proposes sensory information-processing complexity as the main parameter underlying degrees of representationality.

It depends on:

```text
(i) the number of families of system states carrying exploitable information
    about different environmental or bodily variables;

(ii) the number and variety of systematic causal relations among those families.
```

The ant path-integration system therefore has moderate complexity because distinct state families carry information about segment length, travel direction and the home vector, with systematic relations that update the home vector.

Schulte distinguishes this from mere mechanistic complexity: a mechanism may be physically elaborate while informationally simple in the relevant sense.

The proposed relation is roughly:

```text
higher sensory information-processing complexity
-> higher representationality
-> greater explanatory value of representational models.
```

This is a philosophical proposal, not an established numerical law. Schulte also explicitly acknowledges that information-processing complexity alone is unlikely to be sufficient for representation and retains a sensory-system entry condition for convenience, while noting a producer-consumer condition as an alternative.

## 11. Robust realism versus Dennett

Schulte distinguishes his position from Dennett's intentional-stance gradualism. Dennett is neutral about the internal mechanisms that make intentional prediction successful.

Schulte instead accepts robust realism:

```text
ascribing a degree of representationality commits us to
real internal representational vehicles
and corresponding internal information-processing organization.
```

He therefore calls the view `robustly realist radical gradualism` (`RRR gradualism`).

## 12. Modified-rifle objection

A modified rifle fires only if:

```text
trigger pulled
AND
safety catch off.
```

It integrates two information-bearing conditions and performs a simple logical operation. On Schulte's account this produces minimally greater information-processing complexity and therefore a minimal degree of representationality.

Schulte accepts that consequence but denies that:

```text
has a minimal degree of representationality
```

entails:

```text
is a representational system simpliciter.
```

He compares this to graded democracy: a small degree of a property need not license ordinary binary classification.

## 13. Derivative binary classification

Ordinary binary representation-talk can be reintroduced derivatively:

```text
x is representational simpliciter
iff
x has a sufficiently high degree of representationality.
```

But such a cutoff is not a fundamental natural boundary. It is derivative, indeterminate across intermediate cases and plausibly context-sensitive.

## 14. Author-stated limits

Schulte explicitly leaves open:

- a more precise account of information-processing complexity;
- how perceptual constancy, memory, learning and multisensory integration contribute to representational degree;
- the relation between representation and phenomenal consciousness;
- the relation between representation and mind more generally.

The negative argument against hard demarcation is therefore stronger than the paper's positive metric proposal.

## 15. SRT evaluation

### 15.1 Strongest gain: adjacent-case threshold audit

The most portable result is:

```text
choose threshold C
-> identify adjacent C-negative and C-positive systems
-> compare explanatory / causal / behavioral / historical change
-> if no corresponding discontinuity appears,
   do not treat C as an established fundamental natural boundary.
```

This is useful wherever SRT risks turning an operational representation, bearer, subjecthood or agency criterion into a metaphysical discontinuity without independent evidence.

### 15.2 Evidence degree != ontological degree

Current SRT already grades evidence for representation through dimensions such as sensitivity, specificity, invariance and downstream functionality. Schulte adds a distinct question: whether representational organization itself is graded.

Keep:

```text
epistemic evidence strength for representation
!=
ontological degree of representationality.
```

### 15.3 Complexity proposal should not be adopted as definition

The modified-rifle case exposes a residual problem:

```text
more interacting information-bearing state families
may increase computational structure
without making semantic content attribution more explanatorily necessary.
```

SRT should therefore preserve its existing specificity, invariance, producer-consumer functionality and task-relative explanatory tests rather than adopting `more relations -> more representation`.

### 15.4 P3 SRT-side hypothesis: history-bearing recursive state

This is **not Schulte's claim**. His ant case motivates an SRT-side comparison between static multi-input integration and recursively updated history-bearing states:

```text
H_(t+1) = G(H_t, X_(t+1)).
```

Candidate route:

```text
past interaction / selection history
-> retained relational state
-> retained state changes present weighting / interpretation
-> current consequence rewrites the retained state
-> later accessibility / selectability changes.
```

This may help explain why a reusable home-vector state is more representationally indispensable than a fixed two-input AND gate. It remains a falsifiable P3 hypothesis, not a definition of representation.

### 15.5 Representation axis != bearer axis != phenomenality axis

Preserve:

```text
representation-bearing organization
!= bearer
!= experiencer.
```

Strong representational organization does not by itself establish same-unit consequence return, stake ownership, maintained bearer continuity or phenomenal for-me-ness.

### 15.6 Graded structure != graded event actuality

Schulte's argument pressures binary structural classifications. It does not imply that every particular history-producing event must itself be graded.

Keep:

```text
graded formation / strength of organization
!=
graded actuality of a particular selection event.
```
