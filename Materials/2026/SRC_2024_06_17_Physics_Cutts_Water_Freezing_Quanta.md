# SourceCard: Elise Cutts — *The Enduring Mystery of How Water Freezes*

## 1. 一句话结论

水结冰提供了一个高质量的物理桥：**热力学上更稳定的结果不会仅凭“更稳定”就自动实现；候选结构必须穿过成核界面造成的动力学势垒，达到临界尺度，并在增长中把既成结构变成后续过程的约束。** 对 SRT 的价值在于澄清“可能稳定、局部显现、获得锚定、历史硬化”是不同阶段；但该案例不构成选择实在论、`L_0`、`W_sel`、主体性或意识的直接证据。

## 3. 来源明确支持的科学结构

### 3.1 热力学有利不等于动力学可达

在冰相自由能更低的条件下，水仍可长时间保持过冷液态。原因不是冰态不稳定，而是从液态进入晶态必须先形成足够大的晶核。由此必须区分：

```text
final-state stability
!=
transition reachability
```

稳定性回答“形成后是否有利”；成核动力学回答“从当前状态是否能抵达”。

### 3.2 局部冰样结构不等于成功成核

随机分子运动可产生短暂的冰样胚胎。小胚胎通常消散，因为冰—水界面带来额外自由能成本；只有超过临界尺寸后，体相收益才足以压过界面代价，晶体增长才会变得自维持。

因此来源支持至少四个不同阶段：

1. 随机涨落；
2. 局部冰样结构出现；
3. 跨越临界成核门槛；
4. 晶格持续增长并约束后续排列。

### 3.3 表面和杂质重排成核成本

某些表面的晶体有序度、化学结构、孔隙尺寸和缺陷几何可降低成核势垒。细菌与真菌的冰成核蛋白可作为微观脚手架，使水分子更容易形成并维持冰样排列。

安全表述是：

> 表面没有凭空创造冰的可能性，而是改变候选结构的稳定化成本和临界门槛。

### 3.4 液—液转变论文的限定结果

PNAS 论文在机器学习粗粒化水模型 ML-BOP 中得到：

- 模型呈现高密度液体与低密度液体之间的液—液转变及临界点；
- 冷却模拟中，结晶在液—液转变线及其最大热容量的超临界延伸附近最快；
- 结果支持低密度液体的结构转变与冰形成之间存在机制关系；
- 论文没有在冰结晶温度中发现液—液临界性的直接标志；
- 这些是特定模型中的模拟结果，不是对真实水全部条件的最终裁决。

## 4. 对 SRT 的核心接口

### 4.1 “稳定”与“实现”必须分层

该案例为 SRT 提供一个明确压力：不能只用最终吸引子、最低自由能或稳定结构解释确定现实。还必须说明：

- 候选结构怎样首次出现；
- 为什么多数候选结构会消散；
- 什么门槛使局部事件转为后续过程不得不面对的条件；
- 哪些环境结构降低或提高该门槛；
- 已实现结果怎样改变后续可达性。

SRT-compatible compression:

```text
comparative stabilizability
-> local manifestation
-> threshold crossing
-> anchoring
-> inherited constraint
```

### 4.2 显现不等于锚定

短暂冰胚是“候选结构已经出现，但尚未获得持续现实重量”的清楚案例。它支持以下区分：

```text
appearance alone
!=
anchoring
```

锚定在这里可获得一个物理直觉：某一局部结构跨过门槛后，不再只是可以无痕消失的涨落，而开始系统性改变后续转移概率。

这只是 `anchoring` 的物理桥，不是 canonical 定义替换。SRT 的锚定还涉及 inscription、inheritance、cross-operator correction 等更广条件。

### 4.3 脚手架是成本重排器

异质成核表面为 SRT 的 scaffold 概念提供安全物理类比：

```text
scaffold does not choose the result
scaffold reshapes the cost landscape
```

它帮助区分：

- 候选结构是否可能；
- 候选结构是否容易形成；
- 候选结构是否容易越过临界门槛；
- 候选结构一旦形成是否能够自维持。

### 4.4 历史结果反过来塑造后续过程

晶核一旦达到可增长尺度，已有晶格便成为后续水分子排列的边界条件。此时历史不只是“被保存”，而是进入转移结构：

```text
formed structure
-> lower-cost continuation of similar structure
-> future space is pre-trimmed
```

这是 `inscription -> inheritance -> pre-trimming` 的高质量物理直觉。

### 4.5 背景状态改变候选路径的稳定化剖面

液—液转变附近结晶加速提示：成核门槛不仅取决于终态冰，也取决于背景液体的结构敏感性。SRT 可把它作为以下一般接口的物理例子：

```text
background regime changes
-> comparative resistance profile changes
-> some candidate cuts become easier to anchor
```

但低密度/高密度液态水都已经是高度确定的物理状态，不能被直接命名为 `L_0`。

## 5. `L_0 / L_1 / L_2` 安全映射

| 水结冰结构 | SRT 候选接口 | 严格限制 |
|---|---|---|
| 过冷水中的非平坦动力学景观 | 可稳定性/可达性景观的物理类比 | 不是形而上 `L_0`；状态变量和相结构已经对象化 |
| 短暂冰样胚胎 | 局部 manifestation / candidate `L_1` analogy | 随机涨落本身不自动满足 SRT selection 条件 |
| 临界晶核 | anchoring-threshold analogy | 临界核理论不穷尽 inscription、inheritance 或 cross-operator reality |
| 晶体增长 | anchoring 后的自增强与写入 | 不能从增长推出主体、价值或承担位置 |
| 已形成晶格 | 物理 `L_2` 式硬化类比 | 不是所有稳定物理结构都等同于完整 `L_2` 定义 |
| 晶格约束后续排列 | pre-trimming / inherited constraint | 只说明物理路径依赖，不说明选择特异性所有权 |

## 6. `Psi_f` 接口与非同一性守门

冰—水界面的自由能成本及临界成核势垒，可作为某个明确物理模型中的稳定化阻力指标。它适合被写成：

```text
nucleation free-energy barrier
= candidate physical proxy on a typed slice of resistance
```

不得写成：

```text
nucleation barrier = canonical Psi_f
```

原因：

1. canonical `Psi_f` 不是单一热力学量；
2. SRT 还追踪 intervention、repair、inheritance、cross-operator correction 等成本；
3. 不同领域的阻力不能因形式相似而无条件同一；
4. 物理代理的成功不证明 selection realism 的全部形而上主张。

## 7. 对 history-dependent reachability 的边界价值

该案例最适合作为**一般历史依赖与选择特异性写回之间的边界卡**。

冰结晶可表现出：

- persistence；
- hysteresis / metastability；
- path dependence；
- 已形成结构对未来转移的改变；
- 类似一般 transition-rule change 的效果。

但来源没有建立：

- 系统自己的 action -> outcome coupling；
- 实际选择历史 `h+` 与成本匹配反事实 `h-`；
- 选择内容特异的 `W_sel`；
- consequence ownership 或 bearer position。

因此安全裁决是：

> 冰结晶是物理锚定、持续性与一般历史写回的范例；它不是选择特异性写回的自然证据。

可将其作为 designed-system 论文中的自然类比或 negative-boundary example，用于提醒：

```text
P > 0
or
W_global > 0

does not by itself imply

W_sel > 0
```

## 8. 双向增益

### 8.1 新增接口

- `stability-reachability split`：终态稳定与现实可达分离；
- `anchoring-threshold interface`：显现跨越门槛后才改变未来过程；
- `scaffold-as-cost-redistributor`：脚手架不创造结果，只重排锚定成本；
- `physical history write-back`：已形成结构变成后续转移条件。

### 8.2 反向修正

该材料要求 SRT 收紧四种常见过度表述：

1. 不把所有随机结构形成都叫 selection；
2. 不把过冷水或相变背景直接叫 `L_0`；
3. 不把界面自由能直接等同 canonical `Psi_f`；
4. 不把物理路径依赖升级为 `W_sel`、主体性或 consequence-return。

### 8.3 加固内容

它加固的是以下桥级主张，而非 canonical 命题：

- object-style stability 需要生成史解释；
- manifestation 与 anchoring 可被经验上分开；
- 现实厚度包含阈值、继承和路径预裁剪；
- 脚手架可通过降低局部成本改变实现概率。

### 8.4 SRT 反哺

SRT 可以把普通“水为什么不马上结冰”的解释进一步拆成：

```text
candidate formation
critical threshold
anchoring
inheritance
future pre-trimming
```

同时用 `W_sel` 守门，防止把任何滞后、晶化或自组织都误称为“系统选择写回”。

### 8.5 残余压力

- SRT 的 anchoring 是否能给出跨域但不空泛的最小判据；
- 物理阈值模型怎样与更广义的 inscription / inheritance 区分；
- `Psi_f` 的物理代理如何注册而不造成跨层同一化；
- 自发对称破缺、相变和成核中“selection”一词是否应默认降为 selection-structure，而不是 selection-specific agency。

## 11. Surviving claims

1. 在成核过程中，终态热力学有利不保证从当前状态快速可达。
2. 短暂局部冰样结构与跨越临界成核门槛是不同事件。
3. 异质表面可通过重排局部稳定化成本显著影响成核。
4. 晶体形成后，已有结构成为后续排列的约束，提供物理历史写回的清楚类比。
5. 特定 PNAS 模型中，结晶在液—液转变及最大热容量延伸附近最快，但这不是液—液临界性在结晶温度中的直接签名。
6. 该案例支持 SRT 的桥级解释结构，不验证 SRT 的 canonical 本体论。
7. persistence、metastability 和 general rule change 不能替代 `W_sel` 的识别。

## 12. 禁止升级的主张

- 水分子“有意识地选择”结冰；
- 冰成核证明“选择先于存在”；
- 过冷水就是 `L_0`；
- 临界晶核就是完整 canonical anchoring 定义；
- 成核自由能势垒就是 canonical `Psi_f`；
- 液—液转变已经在所有真实水条件下获得最终实验确认；
- 冰晶增长证明主体性、价值、`d-value` 或 consequence-return；
- 任意相变、滞后或自组织都具有 `W_sel`。
